
# 功能描述

主营业务收入指企业从事某种主要生产、经营活动]取得的营业收入。本报表从明细科目、客户、部门、项目多维度视角反映对收入的贡献比例。通过月和年的维度反应主营业务收入变动趋势，列示主营业务收入末级科目当年及上年同期累计发生额及占比，同时可联查至凭证，为企业提供清晰的收入构成和变动情况。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

[基本栏目](javascript:void(0);)

|栏目名称|说明|
|---|---|
|科目编码|从科目维度中读主营业务收入各级科目编码|
|科目名称|从科目维度中读主营业务收入各级科目名称|
|当年累计-发生额|主营业务收入各末级科目当年累计发生额|
|当年累计-占比|主营业务收入各末级科目当年累计发生额占比|
|上年同期累计-发生额|上年同期主营业务收入各末级科目当年累计发生额|
|上年同期累计-占比|上年同期主营业务收入各末级科目当年累计发生额占比|
|比较变动-变动额|【当年累计发生额-上年累计发生额】|
|比较变动-变动率|【当年累计发生额-上年累计发生额】/上年累计发生额|
|年月|查询期所在年首月至查询月各科目的发生额|
