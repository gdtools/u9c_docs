
# 功能描述

本报表为法定报表主表之一，反映企业一定会计期间生产经营成果，他全面揭示了企业在某一特定时期实现的各种收入、发生的各种费用、成本和支出，是一个动态报表。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

[基本栏目](javascript:void(0);)

|栏目名称|说明|
|---|---|
|报表项目|列示利润表的报表项目|
|序号|报表项目行次|
|当期|查询期报表项目的发生额|
|累计|年初至查询期报表项目的累计发生额|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>财税主题－>利润表；
*  操作步骤
 
   *  第1步：输入查询条件
   *  第2步：查看数据。
