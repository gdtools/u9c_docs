
# 功能描述

本报表所指的资金即货币资金，是指企业拥有的、以货币形式存在的资产，主要包括现金、银行存款和其他货币资金。主要分析货币资金余额结构，以及增减变动和余额趋势，针对大额资金变动可穿透至凭证，针对性掌握重大异常发生原因，避免资金使用风险。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

[基本栏目](javascript:void(0);)

|栏目名称|说明|
|---|---|
|一级科目编码|从科目维度中读取资金类一级科目编码|
|一级科目名称|从科目维度中读取资金类一级科目名称|
|末级科目编码|从科目维度中读取资金类一级科目编码对应的末级科目编码提示：供穿透到科目账或凭证明细时带入科目编码|
|末级科目名称|从科目维度中读取资金类末级科目名称|
|会计期间|截止至分析月（会计月）近12月|
|期末余额|各明细资金科目各会计月期末余额可穿透至科目明细账，直至凭证|
|期间增加|各明细资金科目各会计月借方发生额可穿透至凭证明细账，直至凭证|
|期间减少|各明细资金科目各会计月贷方发生额可穿透至凭证明细账，直至凭证|
