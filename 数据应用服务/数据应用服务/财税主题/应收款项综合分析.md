
# 功能描述

应收款项是企业在日常生产经营过程中发生的各种债权，是企业重要的流动资产，主要包括应收账款、其他应收款、应收票据、预付账款。本报表主要分析企业各应收款项的占比结构及逐月趋势，对于款项占比较高的项目，可以钻取分析至科目账，直至凭证单据，洞察感知应收风险。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

[基本栏目](javascript:void(0);)

|栏目名称|说明|
|---|---|
|应收款项|从数据应用服务，报表项目中读取应收账款、其他应收款、应收票据、预付账款报表项目|
|科目编码|获取报表项目表达式定义中对应的科目编码提示：供穿透到科目账时带入科目编码|
|会计期间|截止至分析月（会计月）近12月|
|期末余额|各应收款项各会计月期末余额可穿透至科目明细账，直至凭证|
|占比|列项占比，当月各应收款项期末余额占当月应收款项总余额占比|
