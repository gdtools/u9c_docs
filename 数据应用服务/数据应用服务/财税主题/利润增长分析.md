
# 功能描述

本报表主要从利润总额及净利润额两个方面分析利润的增长，同时列示影响利润总额及净利润的项目，以及各项目的变动额和占比，管理者可以清晰的了解利润总额及净利润变动的影响因素。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

[基本栏目](javascript:void(0);)

|栏目名称|说明|
|---|---|
|影响利润额项目|利润项目的名称|
|当期发生额|查询期各利润项目的发生额|
|同期发生额|各利润项目查询期同期发生额|
|变动影响额|【当期发生额】-【同期发生额】的绝对值|
|变动影响占比|【变动影响额】/【各利润项目变动影响额总计】|
|当年累计发生额|查询期所在年年初至查询期各利润项目的累计发生额|
|上年同期累计发生额|查询期所在年上年年初至查询期同期各利润项目的累计发生额|
|变动影响额|【当年累计发生额】-【上年同期累计发生额】的绝对值|
|变动影响占比|【变动影响额】/【各利润项目变动影响额总计】|
