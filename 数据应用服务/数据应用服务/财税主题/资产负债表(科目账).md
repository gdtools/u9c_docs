
# 功能描述

本报表为法定报表主表之一，反映企业在某一特定日期全部资产、负债、所有者权益情况的报表，他表明企业在某一特定日期所拥有或控制的经济资源、所承担的现有义务和所有者对净资产的要求权，他是一张揭示企业在一定时点财务状况的静态报表。

# 业务规则

*  需要安装数据应用服务产品
