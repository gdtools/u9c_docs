
# 功能描述

销售毛利反映了企业利润创造的初步成果，销售毛利率反映了企业毛利创造的效率。本报表从存货（品类，即末级存货分类）、客户（所属区域）、员工（所属部门）多维度视角，对销售毛利额和销售毛利率综合给出企业毛利排名情况，并追溯至订单环节。

与应收管理模块下的“收入毛利分析”报表同口径。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|品类/存货/地区/客户/部门/员工|品类、存货、地区、客户、部门、员工多维度参与毛利额和毛利率排名|
|毛利额排名|依据查询区间（开始月至结束月）和组织对查询出的毛利额（销售收入-销售成本）给出排名|
|毛利率排名|依据查询区间（开始月至结束月）和组织对查询出的毛利率（毛利额/销售收入）给出排名|
|销售收入|依据查询区间（开始月至结束月）和查询组织，销售收入（本币）|
|销售成本|依据查询区间（开始月至结束月）和查询组织，销售成本|
|毛利额|销售收入-毛利额|
|毛利率|毛利额/销售收入|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>供应链主题－>销售毛利排名分析进入该界面；
*  操作步骤
 
   *  第1步：录入查询条件；
   *  第2步：查看数据。
