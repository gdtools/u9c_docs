
# 功能描述

分析供应商的交货率、及时率，看供应商交货情况，并分析出供应商是否延迟，具体延迟了多少天。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|供应商编码|供应商编码|
|供应商名称|供应商名称|
|订单额|采购订单额|
|集中度|每个供应商采购订单额的占比|
|金额交货率|到货额 / 采购订单额|
|金额及时率|准时到货额 / 采购订单额|
|数量交货率|到货数量 / 采购订单数量|
|数量及时率|准时到货数量 / 采购订单数量|
|延迟天数|到货延迟天数|
|单均延期天数|显示每张单的平均延期天数|
|信用期限|显示供应商的信用期限|
|信用额度|显示供应商的信用额度|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>供应链主题－>供应商综合评价分析进入该界面；
*  操作步骤
 
   *  第1步：录入查询条件；
   *  第2步：查看数据。
