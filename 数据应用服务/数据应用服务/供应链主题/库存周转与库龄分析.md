
# 功能描述

分析出年初到截止月的库存期末数量的变动比较，知道企业库存的变化情况。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|品类|料品末级分类名称|
|存货编码|料品编码|
|存货名称|料品编码|
|规格型号|料品规格型号|
|单位|料品对应的单位|
|销售成本|依据查询区间（开始月至结束月）和查询组织，销售成本|
|平均库存余额|(期初金额+期末金额) / 2|
|周转天数|库存周转天数|
|当前存货余额|库存期末余额|
|大于180天数量|库龄大于180的库存数量|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>供应链主题－>库存周转与库龄分析进入该界面；
*  操作步骤
 
   *  第1步：录入查询条件；
   *  第2步：查看数据。
