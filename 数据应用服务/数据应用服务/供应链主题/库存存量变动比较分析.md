
# 功能描述

分析出年初到截止月的库存期末数量的变动比较，知道企业库存的变化情况。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|存货大类|料品一级分类名称|
|存货分类|料品末级分类名称|
|年月|库存对应的月分|
|期末数量|库存期末数量|
|环比变动率|本月和上月的库存期末数量比较的增长率|
|同比变动率|本月和去年同月的库存期末数量比较的增长率|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>供应链主题－>库存存量变动比较分析进入该界面；
*  操作步骤
 
   *  第1步：录入查询条件；
   *  第2步：查看数据。
