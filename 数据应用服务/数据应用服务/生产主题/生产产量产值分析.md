
# 功能描述

本功能可用于分析料品每月的产量和产值

对比分析各类料品产量/产值的分布

对比分析各类料品产量/产值趋势

可钻取分析各具体料品的当期产量/产值、同期产量/产值、增长率

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|截止月|目标料品的生产订单日期所属月份需要在该范围--数据筛选范围为截止月的当年首月~截止月--截止月默认值为当前月示例：2022年05月，表示目标料品的生产订单日期所属月份在2022年1月到2022年05月之间|
|组织|目标料品所属生产组织|
|订单类型|目标料品所在生产订单的单据类型|
|订单类别|目标料品所在生产订单的业务类型|

报表结果

|栏目名称|说明|
|---|---|
|生产部门|生产部门|
|存货编码|料品编码|
|存货名称|料品名称|
|规格型号|料品规格|
|计量单位|料品计量单位|
|当期产量|截止分析月的当年的产量|
|同期产量|去年同时期的产量--产量：完工数量视为生产数量|
|当期产值|截止分析月的当年的产值--产值：产量×该料品近期销售价格|
|同期产值|去年同时期的产值|
|增长率|增长率=(当期-同期)/同期|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>生产与成本主题－>生产产值产量分析进入该界面；
*  操作步骤
 
   *  第1步：录入查询条件；
   *  第2步：查看数据。
