
# 功能描述

本功能可用于分析未完工生产订单的执行情况

1. 未完工生产订单的执行效率分析

1.1 分析对比各生产部门的未完工订单的执行效率，包括未完工订单数、计划期内未完工订单数、延迟未完工订单数、延迟未完工率等

1.2 分析对比各类未完工料品所属生产订单的执行效率，包括未完工订单数、计划期内未完工订单数、延迟未完工订单数、延迟未完工率等

2. 未完工的料品执行效率分析

2.1 分析对比各生产部门未完工料品的执行效率，包括未完工数量、计划期内未完工数量，延迟未完工数量、延迟未完工率等

分析对比类别未完工料品的执行效率，包括未完工数量、计划期内未完工数量，延迟未完工数量、延迟未完工率等

3. 可钻取分析各部门/各类料品的未完工生产订单明细，了解各个未完工生产订单的执行效率

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|截止月|目标生产订单的创建日期需≤截止月--截止月默认值为当前月|
|组织|目标组织|
|品类|目标生产订单需包含的料品所在分类|
|存货|目标生产订单需包含的料品名称|

报表结果

|栏目名称|说明|
|---|---|
|生产订单号|生产订单编号|
|生产订单行号|默认为10--U9C生产订单无行号|
|部门|生产部门|
|品类|料品分类|
|存货编码|料品编码|
|存货名称|料品名称|
|规格型号|料品规格|
|执行类型|生产订单的执行类型分为：计划期内未完工、延迟未完工--计划期内未完工：生产订单对应的物料未全部完工，且计划完工日期≤数据抽取日期--延迟未完工：生产订单对应的物料未全部完工，且计划完工日期＞数据抽取日期|
|销售订单号|销售订单号--前提：该生产订单来源于销售订单|
|计划发货日期|销售订单的计划发货日期--前提：该生产订单来源于销售订单|
|生产订单日期|生产订单的创建日期|
|计划完工日期|料品的计划完工日|
|实际完工日期|料品的实际完工日|
|计划期内未完工数量|生产订单计划期内未完工的物料--计划期内未完工：该物料未完工，且计划完工日期≤数据抽取日期|
|延迟未完工数量|生产订单延迟未完工的物料--延迟未完工：该物料未完工，且计划完工日期＞数据抽取日期|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>生产与成本主题－>生产未完工执行效率进入该界面；
*  操作步骤
 
   *  第1步：录入查询条件；
   *  第2步：查看数据。
