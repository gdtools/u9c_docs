
# 功能描述

此功能可用于分析生产过程的投入产出情况。

对比分析各生产部门的投入产出情况，包括产值、投入成本、投入产出比

对比分析TOP10料品分类的投入产出情况，包括产值、投入成本、投入产出比

可钻取分析各具体料品的投入产出情况，可对比该料品不同月份的投入产出情况

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|截止月|目标料品的生产订单日期所属月份的范围--数据筛选范围为截止月的当年首月~截止月--截止月默认值为当前月示例：2022年05月，表示目标料品的生产订单日期所属月份在2022年1月到2022年05月之间|
|组织|目标料品所属生产组织|

报表结果

|栏目名称|说明|
|---|---|
|存货编码|料品编码|
|存货名称|料品名称|
|规格型号|料品规格|
|计量单位|计量单位|
|产值|该料品的产量×该料品的近期销售价格|
|投入成本|该料品的入库核算成本|
|投入产出比|投入成本/产值|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>生产与成本主题－>生产投入产出分析进入该界面；
*  操作步骤
 
   *  第1步：录入查询条件；
   *  第2步：查看数据。
