
# 功能描述

本功能可用于进行料品生产进度的分析。

分析完工的料品的类别分布情况

分析生产部门计划完成情况：计划产量与实际完工产量的对比，对比各部门计划完成率、准时完工率

从料品维度，查看个料品每月的完工进度，计划与实际对比，是否准时完工，准时完工情况

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|截止月|目标料品的计划完工月份需要在该范围--数据筛选范围为截止月的当年首月~截止月--截止月默认值为当前月示例：截止月=2022年05月，表示目标料品的计划完工月份落在2022年1月到2022年05月之间|
|组织|目标料品所属生产组织|
|订单类型|目标料品所在生产订单的单据类型|
|订单类别|目标料品所在生产订单的业务类型|
|订单状态|目标料品所在生产订单的单据状态|

报表结果

|栏目名称|说明|
|---|---|
|存货编码|料品编码|
|存货名称|料品名称|
|规格型号|料品规格|
|计量单位|料品的计量单位名称|
|计划产量|该料品计划生产数量|
|累计完工|该料品累计完工数量|
|完成率|累计完工 / 计划产量|
|准时完工|该料品准时完工的数量--准时完工：该料品的实际完工日期≤计划完工日期|
|准时完成率|准时完工数量/计划产量|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>生产与成本主题－>生产计划进度分析进入该界面；
*  操作步骤
 
   *  第1步：录入查询条件；
   *  第2步：查看数据。
