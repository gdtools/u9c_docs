
# 功能描述

本功能可用于生产订单的开工执行效率分析。

生产订单的计划开工执行效率分析

分析对比各生产部门生产订单的开工执行效率，包括开工单数、准时开工单数、延迟开工单数、开工率、准时开工率等

分析对比各类料品所属生产订单的开工执行效率，包括开工单数、准时开工单数、延迟开工单数、开工率、准时开工率等

生产订单的料品计划开工执行效率分析

分析对比各生产部门生产料品的开工执行效率，包括开工数量、准时开工数量、延迟开工数量、开工率、准时开工率等

分析对比各类料品的开工执行执行效率，包括开工数量、准时开工数量、延迟开工数量、开工率、准时开工率等

可钻取分析各部门/各类料品的生产订单明细，了解各个生产订单的实际开工执行情况

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|开始年月结束年月|目标生产订单的计划开工日期需要在该范围内--结束年月必须≤开始年月--开始年月、结束年月默认值均为当前月|
|组织|目标组织|
|品类|目标生产订单需包含的料品所在分类|
|存货|目标生产订单需包含的料品名称|
|开始年月结束年月|目标生产订单的计划开工日期需要在该范围内--结束年月必须≤开始年月--开始年月、结束年月默认值均为当前月|

报表结果

|栏目名称|说明|
|---|---|
|生产订单号|生产订单编号|
|生产订单行号|默认为10--U9C生产订单无行号|
|部门|生产部门|
|品类|料品分类|
|存货编码|料品编码|
|存货名称|料品名称|
|规格型号|料品规格|
|执行类型|生产订单的执行类型分为：准时开工、延迟未开工、延迟已开工--订单准时开工：生产订单对应的物料均已开工，且实际开工日期≤计划开工日期--订单延迟未开工：生产订单对应的物料未开工或部分开工，且数据抽取日期＞计划开工日期--订单延迟已开工：生产订单行号对应的物料都已开工，且最晚的实际开工日期＞计划开工日期|
|销售订单号|销售订单号--前提：该生产订单来源于销售订单|
|计划发货日期|销售订单的计划发货日期--前提：该生产订单来源于销售订单|
|生产订单日期|生产订单的创建日期|
|计划开工日期|料品的计划开工日|
|计划完工日期|料品的计划完工日|
|实际开工日期|料品的实际开工日|
|实际完工日期|料品的实际完工日|
|计划开工数量|生产订单计划生产数量|
|已开工数量|生产订单已开工的数量|
|准时开工数量|生产订单准时开工的数量--准时开工：生产订单对应的物料都已开工，且实际开工日期≤计划开工日期|
|延迟已开工数量|生产订单延迟开工的数量--延迟开工：物料已开工，且实际开工日期≥计划开工日期|
