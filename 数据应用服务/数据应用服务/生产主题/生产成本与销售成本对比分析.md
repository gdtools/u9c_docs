
# 功能描述

分析对比出生产成本与销售成本在期间范围内的差异，从而看出来对企业毛利的影响。

# 业务规则

*  需要安装数据应用服务产品

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|品类|料品末级分类名称|
|存货编码|料品编码|
|存货名称|料品编码|
|规格型号|料品规格型号|
|入库数量|生产入库数量|
|入库成本-材料|生产成本中的材料成本|
|入库成本-人工|生产成本中的人工费用|
|入库成本-费用|生产成本中的机器费用、外协费用、制造费用|
|出库数量|销售出库数量|
|销售成本-材料|销售成本中的材料费|
|销售成本-人工|销售成本中的人工费|
|销售成本-费用|销售成本中的机器费用、外协费用、制造费用、采购成本|
|销售收入|销售应收中销售收入|
|销售毛利|销售收入-销售成本|
|毛利率|销售毛利 / 销售收入|

# 操作说明

*  通过菜单数据应用服务－>数据应用服务－>生产与成本主题－>生产成本与销售成本对比分析进入该界面；
*  操作步骤
 
   *  第1步：录入查询条件；
   *  第2步：查看数据。
