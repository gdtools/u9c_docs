
# 功能描述

## 功能概述

该功能主要是设备安装调试现场对来料进行点收、入库、发料。

## 功能说明

*  按项目任务调出单进行点收
*  按项目采购订单进行点收
*  按项目委外订单进行点收
*  按点收入库数量进行发料

# 业务规则

*  支持按标准采购进行点收，并创建标准收货单
*  支持按委外订单进行点收，并创建委外收货单
*  支持按调拨发运的调出单进行点收，并创建调入单
*  支持按点收结果快速创建生产任务的生产领料单
*  支持按点收结果快速创建现场安装任务的杂发单

# 操作说明

菜单位置：项目制造—>现场管理—>现场管理—>现场点收单。

*  **新增一张现场点收单**

点击<新增>按钮，新增一条现场点收单，操作步骤如下：

*      *  第1步：选择单据类型、项目；
   *  第2步：选择来源类别，如调拨、采购、委外，然后选择单号；
   *  第3步：在各行中录入实收数量、拒收数量；
   *  第4步：保存、审核；
   *  第5步：进行现场领用，或现场杂发；

注意事项：根据现场点收单快速创建生产领料单或者杂发单时，每张点收单审核后只能生成一次。

*  **现场领用**

若点收的物料，来自于生产订单的备料，点击<现场领用>按钮，则自动生成该生产订单的生产领料单；其中生产订单号，位于现场点收单的行上；

*  **现场杂发**

若点收的物料，来自于手工录入或BOM的调拨任务、或采购，点击<现场杂发>按钮，则自动生成杂发单；
