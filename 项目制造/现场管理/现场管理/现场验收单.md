
# 功能描述

## 功能概述

设备现场安装调试完成后，记录客户方签字验收，同时更新项目的验收标志。

## 功能说明

*  记录项目验收信息
*  更新项目验收标志

# 业务规则

*  验收单审核更新项目主档验收标志、验收人、验收时间等信息
*  所有项目均需要进行验收处理
*  启用现场管理时通过现场验收单完成
*  未启用现场管理时在项目主档通过验收功能完成

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|单据类型|现场验收单的单据类型|
|单号|单据编号，可由系统根据编号原则自动生成，也可以手工修改|
|单据日期|验收业务日期|
|项目|联查选择项目档案|
|业务员|验收责任人|
|客户|从项目档案中带出|
|客户位置|从项目档案中带出|
|项目经理|从项目档案中带出|
|项目实际开始日期|从项目档案中带出|
|项目实际完工日期|从项目档案中带出|
|状态|单据状态：开立、核准|

# 按钮说明

无

# 操作说明

菜单位置：项目制造—>现场管理—>现场管理—>现场验收单。

*  **新增一条项目验收单**

点击<新增>按钮，新增一条项目验收单，操作步骤如下：

*      *  第1步：选择单据类型，录入验收日期；
   *  第2步：选择项目、业务员；
   *  第3步：保存，自动生成单据编号；
