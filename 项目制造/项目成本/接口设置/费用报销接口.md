
# 功能描述

可以在项目成本中的“费用报销接口”功能中定义费用与项目成本项之间的影射关系。

# 业务规则

## 使用前提

*  启用项目成本模块

# 栏目说明

|栏目|说明|
|---|---|
|制造成本接口|
|编码|“费用报销接口”的编码|
|名称|“费用报销接口”的名称|
|描述|描述信息|
|来源组织|来源库存费用的所属组织|
|来源账薄|来源费用的所属账簿|
|接口类型|默认为费用接口|
|生效|标识此档案是否生效|
|生效日期|生效的起始日期|
|失效日期|生效的截止日期|
|行列表|
|行号|行号|
|项目|设置项目成本项和费用报销之间的对应关系是否考虑项目|
|分解结构|项目所属的成本分解结构，不可空|
|支出类型|根据成本分解结构过滤，选择生效的支出类型，不可空|
|单据类型|根据费用报销单单据类型设置费用与项目成本项之间的对应关系|
|费用项目|根据费用项目设置费用与项目成本项之间的对应关系|
|列支部门|根据列支部门设置费用与项目成本项之间的对应关系|
|项目成本项|根据支出类型过滤，选择生效的项目成本项，不可空|
|加成系数|可以为取得的费用制定一个系数|

# 操作说明

## 卡片画面操作说明

*  【保存】：将当前操作中编辑的内容保存在数据库中。
*  【放弃】：将当前操作编辑内容不进行保存，仍保存原有内容，画面恢复至编辑前状态。
*  【新增】：将当前画面置为空白可编辑状态；并将原画面编辑内容进行保存。
*  【删除】：删除一条已经保存的数据。
*  【复制】：将当前画面录入内容复制到新画面中，画面显示新复制过来的信息。
*  【查找】：弹出查找画面，输入查找条件，过滤已经保存的数据。
*  【列表】：从卡片录入画面切换到列表查询画面。详细操作见《列表画面**操作说明**》。
*  【首页】：显示第一条单据或档案信息。
*  【上页】：显示上一条单据或档案信息。
*  【下页】：显示下一条单据或档案信息。
*  【末页】：显示最后一条单据或档案信息。

## 卡片翻页顺序

*  从卡片的查找画面返回卡片
 
   *  返回的卡片应该是在查找画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查找方案确定；
*  从列表画面返回卡片：
 
   *  返回的卡片应该是在列表画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查询方案确定；
*  链接弹出卡片：
 
   *  档案类的链接：直接显示对应档案的卡片信息，按系统默认方案进行翻页；
   *  单据类的链接，直接显示焦点对应单据卡片：
   
      *  如果是从一个列表记录的列标题链接进入卡片的，则在该列表记录间进行翻页；
      *  如果只是一个特定的单据编号进入卡片，则按系统默认方案进行翻页；

翻页方案按行或者子行显示时要求排重后再进行整单翻页；
