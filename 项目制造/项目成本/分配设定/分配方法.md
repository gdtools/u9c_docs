
# 功能描述

对于项目的费用，可通过分配的方式计入成本的，要进行费用的分配，必须使用一定的分配方法，用户可以通过本功能配置分配方法。目前系统只提供了按固定比例、按直接成本和总工时分配费用，不能新增、删除分配方法。

# 业务规则

## 使用前提

*  启用项目成本模块

# 栏目说明

|栏目名称|说明|
|---|---|
|编码|分配方法的编码。手工录入，不可为空；在同一组织内唯一；|
|名称　|分配方法的名称。手工录入；可以选择录入中文或英文|
|说明|用户可以为所定义的分配方法添加文字描述或说明|
|自定义分配基数|用户定义新的分配方法时，必须提前定义【分配基数】，并在此引用。参照选择；用户定义新的分配方法时，此处不可为空。|
|可分配到部门|此分配方法是否可以用在部门间费用分配|
|可分配到项目　|此分配方法是否可以用在项目间费用分配|
|可分配到资源|此分配方法是否可以用在任务间费用分配|

# 操作说明

## 卡片画面操作说明

*  【保存】：将当前操作中编辑的内容保存在数据库中。
*  【放弃】：将当前操作编辑内容不进行保存，仍保存原有内容，画面恢复至编辑前状态。
*  【新增】：将当前画面置为空白可编辑状态；并将原画面编辑内容进行保存。
*  【删除】：删除一条已经保存的数据。
*  【复制】：将当前画面录入内容复制到新画面中，画面显示新复制过来的信息。
*  【查找】：弹出查找画面，输入查找条件，过滤已经保存的数据。
*  【列表】：从卡片录入画面切换到列表查询画面。详细操作见《列表画面**操作说明**》。
*  【首页】：显示第一条单据或档案信息。
*  【上页】：显示上一条单据或档案信息。
*  【下页】：显示下一条单据或档案信息。
*  【末页】：显示最后一条单据或档案信息。

## 卡片翻页顺序

*  从卡片的查找画面返回卡片
 
   *  返回的卡片应该是在查找画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查找方案确定；
*  从列表画面返回卡片：
 
   *  返回的卡片应该是在列表画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查询方案确定；
*  链接弹出卡片：
 
   *  档案类的链接：直接显示对应档案的卡片信息，按系统默认方案进行翻页；
   *  单据类的链接，直接显示焦点对应单据卡片：
   
      *  如果是从一个列表记录的列标题链接进入卡片的，则在该列表记录间进行翻页；
      *  如果只是一个特定的单据编号进入卡片，则按系统默认方案进行翻页；
*  翻页方案按行或者子行显示时要求排重后再进行整单翻页；
