
# 功能描述

可按照各种维度查询项目的成本金额。

# 业务规则

## 统计说明

### 统计数据

*  各维度下的成本金额。

### 统计条件

系统在查询方案中提供默认的统计条件，

*  不同的统计方式对应不同的统计条件。
*  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

### 统计结果

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|会计期间|项目成本分析的组织主账薄期间;参照录入，参照主账薄下的所有账薄期间|
|项目类型|参照项目类型档案|
|项目|参照项目档案|
|任务|参照任务档案|
|任务分类|下拉框选择任务分类|
|项目成本项|参照项目成本项档案录入；|

# 操作说明

执行【统计】－>【项目成本分配表】，系统打开“查询方案”画面，在其中选择统计方式与查询条件后，点击确定按钮，即可将报表显示在画面中。具体操作参见查询方案

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

具体操作参见查询方案

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
