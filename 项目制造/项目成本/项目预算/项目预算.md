
# 功能描述

支持项目预算录入制定, 项目预算按项目+任务+分解结构支出类型+项目成本项制定，一个项目只作一个预算，不支持多预算；提供预算数量、单价、金额录入，其中数量和单价可以为空；项目预算的存货成本可以不作定义，如果需要定义，指的是项目交付后的存货成本节余；

# 业务规则

## 使用前提

*  启用项目成本
*  项目已经定义成本分解结构

# 栏目说明

|栏目名称|说明|
|---|---|
|项目预算－表头|
|单据类型|参照项目预算单据类型|
|单号|系统编号或手工编号|
|日期|制单单据日期|
|项目|参照已经核准的项目档案；项目成本组织为当前组织；项目成本分解结构的预算方式为总额预算|
|成本分解结构|由项目档案带出|
|控制方向|预置枚举；枚举值为自上而下和自下而上；待分解支出不等于零时不允许切换控制方向；控制方向决定概算是从末级开始编制还是从顶端开始编制|
|币种|制定预算的币种|
|合同金额|由项目档案带出|
|单据来源类别|枚举值手工创建：手工编制概算；项目概算：由项目概算生成；系统回写不可编辑|
|预算类型|预置枚举为基准预算、执行预算基准预算发布后为执行预算；枚举值为系统写入，不可手工干预；|
|项目概算--基本页签|
|行号|单据行号|
|成本分解结构|显示成本分解结构的层级|
|支出|手工维护；分解得到；项目概算生成|
|待分解支出|分层计算；下层汇总和本层金额的差异|
|收入|手工维护；分解得到；项目概算生成|

# 操作说明

## 分解

依据选择的概算模板和录入的待分解支出计算每层级的概算金额。

分解是针对当前操作页面。

**操作前提**

*  已经选择项目及项目分解结构。
*  已已经选择概算模板。
*  已经录入待分解支出。

**操作步骤**

点击项**目预算－>分解**按钮。具体步骤如下所示。

*  **第1步：**项目预算节点 ；
*  **第2步：选择项目及概算模板；**
*  第3步：录入待分解金额；
*  第4步：执行分解功能按钮；
*  第5步：查看分解结果。
