
# 功能描述

## 功能概述

任务工作台，给用户提供了一个按条件快速选取任务、快速操作的平台。在这个工作台上，系统提供标准的查询界面，用户可以自定义查询显示条件，例如：部门、任务类型等等。

在这个工作台上，部门经理可以选定该部门相关的任务进行审核、发布。

## 功能说明

*  批量审核任务
*  批量发布任务
*  批量修改任务

# 业务规则

*  定义“项目”档案
*  进行“任务分解”的操作

# 操作说明

在Ｕ９系统中，有两种进入此界面的路径。其一：点击菜单“任务——任务工作台”；其二，用户也可以在“任务分解”的界面，点击右下角的“相关功能——任务工作台”的按钮。

在这个界面，用户可以选择任务，并进行任务的审核、发布以及批量修改。

批量修改，仅限于任务经理、部门。
