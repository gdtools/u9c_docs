
# 功能描述

## 功能概述

查询拖期未完成任务。

## 功能说明

无

# 业务规则

*  创建项目及任务
*  维护项目及任务进度

# 栏目说明

*  **项目**

|**栏目名称**|**说明**|
|---|---|
|**查询条件**|
|组织|要查询的组织；可当前组织及参照【组织隶属关系】为“工厂关系” 的下级组织及【组织业务关系】为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入；非空；|
|项目编码|查询某一或某些项目时录入；录入；可空|
|业务员|按项目所对应项目经理的描述进行查询；录入；可空|
|开始时间|按项目的预定开始时间范围进行查询时录入；录入；可空|
|完成时间|按项目的预定完成时间范围进行查询时录入；录入；可空|
|**查询栏目**|
|组织|显示作业所属的组织名称|
|项目编码|显示项目编码|
|项目名称|显示项目名称|
|项目经理|显示项目指定的项目经理|
|计划日期-开始时间|显示项目的预定开始时间|
|计划日期-完成时间|显示项目的预定完成时间|
|剩余时间|显示项目的剩余时间|

*  **任务**

|**栏目名称**|**说明**|
|---|---|
|**查询条件**|
|创建时间|按任务的创建时间进行查询时录入；录入；可空|
|创建人|按任务的创建人进行查询时录入；录入；可空|
|修改时间|按任务的修改时间进行查询时录入；录入；可空|
|**查询栏目**|
|任务序号|显示任务序号|
|任务执行版本|显示任务执行版本|
|计划时间-工期|显示任务的计划工期|
|计划时间-开始时间|显示任务的计划开始时间|
|计划时间-完成时间|显示任务的计划完成时间|
|实际时间-开始时间|显示任务的实际开始时间|
|实际时间-完成时间|显示任务的实际完成时间|
|进度|显示任务的当前进度|
