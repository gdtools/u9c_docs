
# 功能描述

## 功能概述

查询子件发运任务执行进度。

# 操作说明

*  计算在手量

点击<计算在手量>按钮，针对显示的所有子件发运任务，计算获得：未发数量（计划数量 - 已使用数量）、库存数量、缺料数量（库存数量 - 未发数量）。
