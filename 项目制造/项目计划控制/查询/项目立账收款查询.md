
# 功能描述

## 功能概述

查询项目[]()立账、收款、开票类任务的状况。这里立账、收款、开票都要有明确的、相对应的项目与任务。如果用户录入了某一笔收款，只对应了项目，而没有明确的任务，则在这里查询不到。

## 功能说明

无

# 业务规则

*  创建项目及[]()立账类、收款类、开票类任务
*  立账类、收款类、开票类任务有后续的业务发生

# 栏目说明

*  **项目信息**

|**栏目名称**|**说明**|
|---|---|
|**查询条件**|
|计划组织|要查询的组织；可当前组织及参照【组织隶属关系】为“工厂关系” 的下级组织及【组织业务关系】为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入；非空；|
|项目分类|按项目所对应项目分类进行查询时录入；录入；可空|
|项目编码|查询某一或某些项目时录入；录入；可空|
|客户|按项目的所对应的客户范围进行查询时录入；录入；可空|
|客户分类|按项目的所对应的客户类型进行查询时录入；录入；可空|
|业务员|按项目所对应项目经理的描述进行查询；录入；可空|
|**查询栏目**|
|项目编码|显示项目编码|
|名称|显示项目名称|
|立帐金额|显示项目的立帐金额|
|已立帐金额|显示项目的已立帐金额|
|开票金额|显示项目的开票金额|
|实际开票金额|显示项目的实际开票金额|
|收款金额|显示项目的收款金额|
