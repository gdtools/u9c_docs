
# 功能描述

## 功能概述

“任务控制方式”将在用户定义项目类型，或建立具体项目的时候，发挥作用。用户在这里建立任务控制的“规则”，主要是涉及到任务实际进度填报、审核等方面的。

当用户建立项目时，选择相应的“任务控制方式”。则该项目的所有任务都将按照此规则进行控制。

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|编码|任务控制方式的编码；手工录入，不可为空；在同一组织内唯一，编码格式应符合编码规则|
|名称|任务控制方式的名称|
|进度报告审核|这是一个判断，即某个具体任务有任务经理报告了“实际进度报告”时，是否需要经过审核确认；打上勾，即表示用户填写任务的实际进度时，需要经过审核；不打，则表示用户提交保存时即审核通过；注意：１、如果任务实际进度的填报，是由该任务的后续单据自动填写的。这里的设置将不起作用；2、用户在建立“项目类型”时，如果确定了“进度报告方式”为“集中报告”。这里的设置也将不起作用，系统自动这类项目的所有任务都“不需要审核”|
|进度报告审核方式|如果进度报告需要审核，这里的选择才会发生作用。这里有两个选项：确认作业：即在软件界面上直接点击“审核”按钮即可；审批流程：即通过系统内部设置好的审批流程发起并进行审批|
|任务需要审核|这也是一个判断，即新建一个任务的时候，是否需要经过审核的环节才能发布；打上勾，需要经过审核；不打，则表示用户提交保存时即审核通过|
|任务审核方式|如果任务需要审核，这里的选择才会发生作用。这里有两个选项：确认作业：即在软件界面上直接点击“审核”按钮即可；审批流程：即通过系统内部设置好的审批流程发起并进行审批|
|审核后修改重核|这是一个判断，在任务审核后，用户又进行了修改，修改后是否需要重新审核；打上勾，需要重新经过审核。审核的方式，也使用原来的设置；不打，则表示用户提交保存时即审核通过|
|修改自动提交|对于已经发布了的任务，修改后是否自动提交审核|
|审核即发布|对于任务而言，是否审核后即进自动进行“发布”的处理|
|项目优先方式|用于控制用户编辑WBS时，工期相关字段录入方式；工期优先：依据用户录入的WBS工期字段，系统自动计算WBS的开始日期或完成日期；日期优先：依据用户录入的WBS开始和完成日期，系统自动计算WBS的工期|
|审核后可改|用于控制任务处于“已核准”状态是否允许修改|
|资源参照控制|用于控制任务资源的参照范围，如果取值为true，则任务资源只能参照任务隶属部门下的资源，即资源所属工作中心的部门等于任务的隶属部门；如果取值为false，则任务资源可以参照所有资源|
