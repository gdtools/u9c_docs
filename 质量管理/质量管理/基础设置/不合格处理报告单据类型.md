
# 功能描述

本功能用来设置不合格处理报告的单据类型、编号方式、审批流程。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

MRB单据类型

|栏目|说明|
|---|---|
|编码|MRB单据类型的编码；|
|名称|MRB单据类型的名称；|
|简称|ＭＲＢ单据类型的简称；|
|质检类型|目前只支持进货质检；|
|确认方式|单据审核的方式，通过审批流程审批或通过确认作业；|
|生效|单据类型的生效标志；|
|生效日期|单据类型的生效日期；|
|失效日期|单据类型的失效日期；|
|编号方式|单据类型的编号方式；|
|编号规则|单据类型的编号规则；|
|允许手工修改|允许手工更改标志；|
|打印模板|单据类型的打印模板。|

# 操作说明

通过菜单<a href="/detail/7b0196452e8b4865b0ba16c6c50fd23d">不合格处理报告单据类型</a>进入不合格处理报告单据类型界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质量管理－>不合格处理报告单据类型按钮，进入设置画面,具体步骤如下所示。
   
      *  第1步：输入单据类型的编码、名称和简称；
      *  第2步：选择质检类型、确认方式及有效期；
      *  第3步：选择单据的编号方式， 当自动编号时输入自动编号的原则；
      *  第4步：选择打印模版。
