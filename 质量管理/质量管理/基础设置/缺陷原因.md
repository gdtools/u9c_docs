
# 功能描述

本功能用于设置质检单的缺陷原因。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

缺陷原因卡片

|栏目名称|说明|
|---|---|
|编码|输入缺陷原因编码；|
|名称|输入缺陷原因名称；|
|父缺陷原因|输入父缺陷原因；注意　:父缺陷原因与缺陷原因不能相同或循环设置。|

# 操作说明

通过菜单<a href="/detail/54ce6d0d5f4d4ff8bbe4ea85538b6e68">缺陷原因</a>进入缺陷原因界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质量管理－>缺陷原因按钮，进入画面。具体步骤如下所示：
   
      *  第1步：分别输入缺陷原因的编码、名称；
      *  第2步：如果缺陷原因有父缺陷原因，就输入父缺陷原因。
