
# 功能描述

本功能用于设置质检是否使用不合格处理报告，它是按质检类型设置的。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

参数设置

|栏目名称|说明|
|---|---|
|参数分组|显示参数的分组名称；|
|参数名称|显示参数名称；|
|参数值|显示参数值，默认为空，表示不启用。|
|描述|参数说明|
|作用范围|作用的范围|

# 操作说明

通过菜单<a href="/detail/5e138a741a384d0da6b28ce9a6def3bf">参数设置</a>进入参数设置界面；

*  本功能用来设置质检系统的参数。

      *  系统启用了质量管理系统；
      *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤

   *  点击质量管理－>参数设置按钮，进入画面。具体步骤如下所示：

      *  系统可以按质检业务类型设置参数，是否启用MRB，以后会陆续扩展新的参数。
      *  如果系统启用了该参数，在质检单行被检料品不合格时，将走不合格处理报告流程。
