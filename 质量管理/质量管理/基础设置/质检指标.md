
# 功能描述

本功能用来设置质检过程中所用到的质检指标及其指标值。

# 业务规则

*  系统启用了质量管理系统；

# 栏目说明

质检指标头

|栏目名称|说明|
|---|---|
|编码|输入质检指标的编码；|
|名称|输入质检指标的名称；|
|检验类型|选择检验指标的类型，系统提供两种计数和计量，默认计数；|
|备注|输入备注信息；|
|指标类别|选择指标的类别，可以点击链接该字段定义指标类别；|
|重要程度|选择指标的重要程度，可以双击该字段定义重要程度；|
|破坏性|定义指标是否为破坏性指标,如果是破坏性指标，样本检验时将被破坏掉；|
|生效|定义指标是否生效；|
|生效日期|定义指标的生效日期；|
|失效日期|定义指标的失效日期。|

质检指标体


|栏目|说明|
|---|---|
|质量标准|选择输入质量标准，点击本字段可以定义质量标准，同一指标在同一标准下，设置不同的指标值或指标值范围时，不能有重叠；|
|状态|选择输入，有两个选项合格和不合格。一个指标在一个质量标准下只能输入一种状态；|
|计量单位|参照输入指标的计量单位，同一个指标的计量单位必须一致；|
|指标值序号|一个指标可以定义多个指标值，系统自动产生序号；|
|比较符|对于计量型指标，比较符只能取‘=’，输入指标1，指标2和指标3，指标1为标准值，指标2和指标3表示上下偏差。此时他们的值只能为数字；|
|指标值１名称|当[比较符]不等于between时，系统自动显示‘标准值’；等于between时显示‘下限值’|
|指标值１|计量型指标只能输入数字；计数型可以输入数字、字符，输入字符时，比较符只能取等号；比较符取between时，指标值1为范围小值，指标值2为范围大值。输入数字时，小数点后最多5位小数；|
|包含|用于说明是否包含指本身,当比较符为between时可以设置为包含，否则不能设置为包含；|
|指标值２名称|选择指标值２的名称，当[比较符]为等号时，系统自动显示‘上偏差’；等于between时显示‘上限值’，其余均为空；|
|指标值２|输入指标值２的值，当[比较符]为‘=’时，可维护，表示上偏差，非空|
|包含|用于说明是否包含指本身,当比较符为between时可以设置为包含，否则不能设置为包含；|
|指标值３名称|输入指标值３的名称，当[比较符]为等号时，系统自动显示‘下偏差’；其余均为空；|
|指标值３|输入指标值３的值，当[比较符]为等号时，系统自动显示‘下偏差’；其余均为空；|
|标准差|输入计量型指标的标准差。|

# 操作说明

通过菜单<a href="/detail/994b37ae2ed84270ab73ca17cfaec4b5">质检指标</a>进入质检指标界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质量管理－>基础设置－>质检指标按钮，进入质检指标设置画面。具体步骤如下所示：
   
      *  第1步：输入质检指标信息；
      *  第2步：输入指标值信息；
      *  第3步：保存指标和指标值信息。
