
# 功能描述

本功能用来设置质检的质检方案。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  抽样质检方案、宽严程度调整规则、质检步骤设置完成。

# 栏目说明

质检方案头

|栏目名称|说明|
|---|---|
|质检方案|选择输入定义好的质检方案，点击质检方案后可以定义新的质检方案；|
|版本|系统自动生成质检方案的版本；|
|抽样层次|用于定义抽样方案的控制方式，共三种，按指标时，每个指标都可以定义自己的抽样方案，按步骤时，每个步骤可以定义自己的抽样方案；按方案时，不管有多少步骤、指标只能使用同一种抽样方案；|
|抽样方案|定义抽样方案，当抽样层次为方案且抽样方式为标准抽检和自定义抽检时才可以输入值；|
|检验水平|定义检验水平，当抽样层次为方案且抽样方式为标准抽检和自定义抽检时才可以输入值；|
|AQL|定义AQL值，当抽样层次为方案且抽样方式为标准抽检和自定义抽检时才可以输入值；|
|调整规则|定义调整规则，当抽样层次为方案且抽样方式为标准抽检和自定义抽检时才可以输入值；|
|成本计算方法|定义质检成本的计算方法，两种：按批和按指标；|
|质检成本|质检成本按批控制时才可以输入；|
|币种|系统计算成本时自动维护，如果当前组织有法人组织属性就取其主账簿的本位币；如果当前组织没有法人组织属性就取其业务关系中对应的法人组织的主账簿的本位币。|

质检方案步骤页签

|栏目名称|说明|
|---|---|
|序号|系统自动产生；|
|质检步骤|选择输入质检步骤；|
|追加　|标志该步骤是否为追加的步骤；|
|原步骤|如果步骤为追加的步骤，定义其原步骤是什么；|
|抽样方案|如果头上的抽样层次为步骤且抽样方式，才可以输入值；|
|调整规则|如果头上的抽样层次为步骤且抽样方式为标准抽检和自定义抽检时，才可以输入值；|
|检验水平|如果头上的抽样层次为步骤且抽样方式为标准抽检和自定义抽检时，才可以输入值；|
|AQL|如果头上的抽样层次为步骤且抽样方式为标准抽检和自定义抽检时，才可以输入值。|

质检方案步骤指标页签

|栏目名称|说明|
|---|---|
|序号|系统自动产生；|
|质检指标|选择输入质检步骤；|
|追加方式　|标志该步骤是否为追加的步骤；|
|追加标志|如果步骤为追加的步骤，定义其原步骤是什么；|
|原指标|输入追加指标的原指标；|
|抽样方案|如果头上的抽样层次为指标，才可以输入值；|
|调整规则|如果头上的抽样层次为指标且抽样方式为标准抽检和自定义抽检时，才可以输入值；|
|检验水平|如果头上的抽样层次为指标且抽样方式为标准抽检和自定义抽检时，才可以输入值；|
|AQL|如果头上的抽样层次为指标且抽样方式为标准抽检和自定义抽检时，才可以输入值；|
|判定标准|系统允许质检指标值定义多个质量标准，对一个质检方案要定义判断其合格与否的质量标准是什么；|
|质检员　|输入执行该质检指标检验的质检员；|
|计费方法|输入该指标的质检成本计费方法；|
|质检成本|输入质检成本；|
|币种|系统计算成本时自动维护，如果当前组织有法人组织属性就取其主账簿的本位币；如果当前组织没有法人组织属性就取其业务关系中对应的法人组织的主账簿的本位币。|

质检方案-指标值页签

|栏目名称|说明|
|---|---|
|序号|系统自动产生；|
|质量标准|选择输入质检标准；|
|状态　|指明该指标值为合格或不合格状态的值；|
|比较符|选择比较符；|
|指标值１名称|当比较符为等号时，指标值１名称为标准值，指标值２名称为上偏差，指标值３名称为下偏差，表示指标值的公差范围；当比较符为between时，指标值１名称为下限值，指标值２名称为上限值，输入指标值1和2表示指标的值的取值范围；|
|指标值１|计量型指标只能输入数字。计数型可以输入数字、字符，输入字符时，比较符只能取等号；比较符取between时，指标值1为范围小值，指标值2为范围大值；|
|包含|描述是否包含边界值的标志；|
|指标值２名称|当[比较符]为等号时，系统自动显示‘上偏差’；等于between时显示‘上限值’；其余均为空；|
|指标值２|当比较符为between时输入值表示上限值，当比较符为等号时表示上偏差；|
|指标值３名称|当[比较符]为等号时，系统自动显示‘下偏差’；|
|指标值３　|当[比较符]为等号时，输入值表示下偏差；|
|计量单位|输入指标的计量单位；|
|标准差|当指标为计量型指标时，可以输入标准差。|

质检方案判定规则

|栏目名称|说明|
|---|---|
|质检方案名称|系统自动显示当前质检方案的名称；|
|质检方案版本|系统自动生成质检方案的版本；|
|判定结果|指明符合判断条件后的判定结果，只能选择一种结果；|
|条件序号|系统自动产生，可以维护，相同条件序号表示需要同时满足，不同条件序号表示满足其中一个即可；|
|项次号|系统自动产生；|
|质检方案指标|选择输入质检方案的指标；|
|指标合格标志|指明指标合格时做为判断条件还是不合格时做为判定条件。|

# 按钮说明

*  <判定规则操作>：本功能用来设置质检方案的判定规则，只有设定了判定规则才是一个完整的质检方案。
 
   *  操作前提
   
      *  质检方案设置完成。
   *  操作步骤
   
      *  点击质量管理－>质检方案－〉判定规则按钮，进入判定规则设置画面。具体步骤如下所示：
      *  第1步：进入设置画面后，将会自动显示当前的质检方案的名称和版本信息；
      *  第2步：选择输入质检方案的判定结果；
      *  第3步:输入判定条件，判定条件可以定义一个或多个；
      *  第4步：点确定保存判定规则。

# 操作说明

通过菜单<a href="/detail/d1ce77b314934c0c880ee57374ed0dab">质检方案</a>进入质检方案界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
   *  抽样质检方案、宽严程度调整规则、质检步骤设置完成。
*  操作步骤
 
   *  点击质量管理－>质检方案按钮，进入质检方案设置画面。具体步骤如下所示：
   
      *  第1步：点击质检方案进入质检方案画面后可以新增一个质检方案；如果已经存在了一个质检方案，可以参照输入，增加一个已存在质检方案的新版本；
      *  第2步：确定质检方案的抽样层次；
      *  第3步:确定质检方案的抽样方案、检验水平、AQL值、调整规则，如果抽样层次为按方案控制，就在方案尚定义这些值，如果按步骤控制就在步骤上定义，如果在指标上控制就在指标上定义；
      *  第4步：定义质检成本计算方法；
      *  第5步：定义质检方案的有效期；
      *  第6步：定义质检方案的步骤，一个质检步骤可以有多个追加步骤，当该步骤不合格时　再进行追加步骤的检验（当选择了步骤后，系统会将该步骤下的指标、追加指标、指标值自动带入，可以修改）；
      *  第7步：定义每个步骤下的质检指标，一个指标可以定义多个追加指标，当指标不合格时再进行追加指标的检验；
      *  第8步：定义每个指标的指标值；
      *  第9步：保存质检方案。
