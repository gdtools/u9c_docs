
# 功能描述

本功能用于设置质检单被解除挂起的原因和可以对挂起的质检单进行解除操作的操作员。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

解除原因头

|栏目名称|说明|
|---|---|
|编码|输入解除原因编码；|
|名称|输入解除原因名称；|
|简称|输入解除原因的简称；|
|生效|输入解除原因的生效标志；|
|生效日期|输入解除原因的生效日期；|
|失效日期|输入解除原因的失效日期。|

解除原因体

|栏目名称|说明|
|---|---|
|操作员|输入可以执行挂起操作的操作员；|
|生效|输入该操作员具有挂起操作的生效标志；|
|生效日期|输入该操作员具有挂起操作的生效日期；|
|失效日期|输入该操作员具有挂起操作的失效日期。|

# 操作说明

通过菜单<a href="/detail/a3dc73726907467fbc6351adeeda356c">解除原因</a>进入解除原因界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质量管理－>解除原因按钮，进入画面。具体步骤如下所示：
   
      *  第1步：分别输入挂起原因的编码、名称、简称、生效标志、生效日期和失效日期；
      *  第2步：输入可以执行该操作的操作员和其生效标志、生效日期、失效日期。
