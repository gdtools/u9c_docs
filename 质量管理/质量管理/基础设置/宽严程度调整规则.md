
# 功能描述

本功能用于设置宽严程度的自动调整规则。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

宽严程度调整规则头

|栏目名称|说明|
|---|---|
|编码|输入调整规则编码；|
|名称|输入调整规则名称；|
|备注|输入调整规则的备注。|

调整结果页签

|栏目名称|说明|
|---|---|
|行号|系统自动产生行号；|
|从程度|调整结果的开始程度；|
|到程度|需要调整到的程度；|
|备注|调整结果的备注信息。注意　:从程度到程度不能一样，放宽只能到正常，加严只能到正常；调整结果不能重复设置。|

调整条件页签

|栏目名称|说明|
|---|---|
|条件序号|系统自动产生，可以手工维护，如果条件序号相同，表示相同序号的条件必须同时满足，如果条件序号不同，表示只要满足一个条件即可调整。注意　:同一调整结果的条件，只要条件序号一样，合格批数和不合格批数就不能同时出现。|
|项次号|表示调整条件的顺序号，系统自动产生；|
|连续检验批|相同条件下，连续检验的批数；|
|判定因素|判断的依据；|
|比较符|选择输入；|
|比较值|输入比较值。|

# 操作说明

通过菜单<a href="/detail/855a7c66c2994bc1a07ba854c84f0601">宽严程度调整规则</a>进入宽严程度调整规则界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质量管理－>宽严程度调整规则按钮，进入画面。具体步骤如下所示：
   
      *  第1步：输入宽严程度调整规则的编码,名称和备注;
      *  第2步：在调整结果页签输入调整结果；
      *  第3步：在调整条件页签输入调整条件。
