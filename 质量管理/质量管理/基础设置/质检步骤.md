
# 功能描述

本功能用于设置质检过程中的质检步骤及每个步骤下所包含的质检指标。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

质检步骤设置画面

|栏目名称|说明|
|---|---|
|编码|输入步骤编码；|
|名称|输入步骤名称；|
|备注|输入步骤的备注信息；|
|质检指标|参照输入质检指标；|
|追加标志|说明该指标是否是追加的指标，只有当该指标为追加的指标时才打标志；|
|原指标|指明追加指标的原指标。注意　:一个步骤下的所有质检指标不能重复，原指标必须为本步骤下的指标才可以保存成功。|

# 操作说明

通过菜单<a href="/detail/636fbb1bd28541d4af2398acf902b9ca">质检步骤</a>进入质检步骤界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质量管理－>基础设置－>质检步骤按钮，进入画面。具体步骤如下所:
   
      *  第1步：输入步骤的编码、名称和备注信息；
      *  第2步：输入步骤下的指标；
      *  第3步：如果输入的指标为追加的指标，必须输入其原指标。
