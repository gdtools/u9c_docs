
# 功能描述

本功能用来设置质检的抽样质检方案。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

抽样质检方案头

|栏目名称|说明|
|---|---|
|编码|输入抽样质检方案的编码；|
|名称|输入抽样质检方案的名称；|
|抽样方式|选择输入抽样方式，共四种：全检，按标准抽检，自定义抽检，比例抽检；全检时不用定义抽样质检方案体的内容；|
|标准类型|用户可以根据需要定义多个标准类型，当按标准抽检时，系统自动默认GB2828；|
|抽样次数|按国标进行多次抽检时，定义抽样的次数；|
|生效|抽样方案的生效标志；|
|生效日期|抽样方案的生效日期；|
|失效日期|抽样方案的失效日期。|

抽样质检方案体

|栏目名称|说明|
|---|---|
|序号|系统自动产生；|
|起始批量|输入起始批量；|
|终止批量|输入终止批量，起始批量和终止批量要连续设置；|
|全检|说明该批量范围是否需要全检；|
|检验水平|选择输入检验水平，共七种；|
|严格程度|选择输入严格程度，加严、放宽和正常；|
|AQL|在按标准抽样或自定义抽样时输入AQL值；|
|第n次抽样|在按标准抽样或自定义抽样时输入；|
|抽样数量|每次抽样的数量；|
|AC|可接受的不合格品数；|
|RE|不可接受的不合格品数。|

# 操作说明

通过菜单<a href="/detail/4d5a130111f64beeb665459699eb4a84">抽样质检方案</a>进入抽样质检方案界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质量管理－>抽样质检方案按钮，进入抽样质检方案设置画面。具体步骤如下所示：
   
      *  第1步：输入抽样质检方案的编码、名称；
      *  第2步：输入抽样方式，如果抽样方式为全检，只输入生效标志、生效日期和失效日期即可，其他字段不用输入；
      *  第3步：输入标准类型，按标准抽样时系统自动取GB2828.1；
      *  第4步：输入有效期标志；
      *  第5步：当抽样方式为按标准抽样或自定义抽样时，输入起始批量、终止批量、全检、检验水平、严格程度、AQL值、第ｎ次抽样、抽样数量、AC和RE值；当抽样方式为比例抽样时，输入起始批量、终止批量、全检和抽样比例。
