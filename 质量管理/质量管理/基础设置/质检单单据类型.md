
# 功能描述

本功能用来设置质检单的类型、编号方式、审批流程。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

质检单类型－基本页签

|栏目名称|说明|
|---|---|
|编码|质检单单据类型的编码；|
|名称|质检单单据类型的名称；|
|简称|质检单单据类型的简称；|
|质检类型|五种：进货质检、完工质检、工序质检、退货质检和其他质检；|
|确认方式|单据审核的方式，通过审批流程审批或通过确认作业。|

质检单类型－参数页签

|栏目名称|说明|
|---|---|
|编号方式|系统提供两种编号方式：手工编号，自动编号；|
|编号原则|定义自动编号的编号规则,当选择的编号方式为自动编号时，必须输入编号原则；|
|打印时机|定义单据的打印时机；|
|打印模版|定义单据打印的默认模版；|
|打印副本|定义打印时是否自动打印副本。|

# 操作说明

通过菜单<a href="/detail/8aea708a4f694043b25519f7cf4443cc">质检单单据类型</a>进入质检单单据类型界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质量管理－>质检单类型按钮，进入质检单类型设置画面。具体步骤如下所示。
   
      *  第1步：输入单据类型的编码、名称和简称；
      *  第2步：选择质检类型、确认方式及有效期；
      *  第3步：选择单据的编号方式，当自动编号时输入自动编号的原则；
      *  第4步：选择单据的打印时机、打印模版和是否需要打印副本。
