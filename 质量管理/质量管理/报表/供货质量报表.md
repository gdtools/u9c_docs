
# 功能描述

本功能用来查询分析不同供货单位的供货质量状况。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

供货质量－查询条件

|栏目名称|说明|
|---|---|
|质检类型|枚举：为空表示所有质检类型；|
|分类性质|料品分类的分类性质，枚举：库存、生产、销售、采购；|
|料品分类|参照输入料品的分类，选择料品分类时必须选择分类性质；|
|料品|参照输入料品；|
|版本|参照输入料品的版本；|
|供货单位|参照，受[质检类型]约束，当[质检类型]为进货质检时，列选值为供应商；当[质检类型]为工序质检时，列选值为工作中心；当[质检类型]为完工质检时，列选值为生产部门；|
|日期范围|输入统计期间；|
|排序方式|枚举：按批合格率、总合格率，顺序由大到小排序。|

供货质量－查询结果

|栏目名称|说明|
|---|---|
|料品|显示料品的名称；|
|版本|显示料品的版本；|
|供货单位|显示供货单位；|
|总供应批数|按质检单行进行统计，一行为一批；|
|合格批数|进货质检取值规则：与《收货单行》对应得《质检单行》[合格标志2]为合格的次数总和；工序质检取值规则：与《工序转移单》对应的《质检单行》[合格标志2]为合格的次数总和；完工质检取值规则：与《生产完工报告》对应的《质检单行》[合格标志2]为合格的次数总和；|
|批合格率|等于合格批数/总供应批数*100%；|
|总供应数量|进货质检取值规则：该物料在规定时间段内、该供应商的《收货单行》上的数量合计；工序质检取值规则：该物料在规定时间段内、该工作中心的《工序转移单》上的数量合计；完工质检取值规则：该物料在规定时间段内、该生产部门的《生产完工报告》上的数量合计。|
|总合格数量|进货质检取值规则：与《收货单行》对应的《质检单结果》[质检结果]为合格的数量总和；工序质检取值规则：与《工序转移单》对应的《质检单结果》[质检结果]为合格的数量总和；完工质检取值规则：与《生产完工报告》对应得《质检单结果》[质检结果]为合格的数量总和；|
|总合格率|等于总合格数量/总供应数量*100%。|

# 操作说明

通过菜单<a href="/detail/1526bcd8e341428a9a8702b3f7509399">供货质量报表</a>进入供货质量报表界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质检管理－>供货质量报表，进入查询条件画面，输入查询条件，确定后可以查询出相应的报表数据。
