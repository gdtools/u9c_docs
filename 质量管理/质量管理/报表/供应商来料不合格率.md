
# 功能描述

本功能用于查询供应商来料不合格率。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

供应商来料不合格率－查询条件

|栏目名称|说明|
|---|---|
|供应商分类|参照输入供应商分类；|
|供应商分类段（1..N）|选择一个或者多个段输入段值；|
|供应商|参照输入供应商；|
|供应商段（1..N）|选择一个或者多个段输入段值；|
|分类性质|料品分类的分类性质，枚举：库存、生产、销售、采购；|
|料品分类|参照输入料品的分类，选择料品分类时必须选择分类性质；|
|料品分类段（1..N）|选择一个或者多个段输入段值；|
|料号|参照输入料品；|
|料号段（1..N）|选择一个或者多个段输入段值；|
|品名|输入料品的品名；|
|品名段（1..N）|选择一个或者多个段输入段值；|
|版本|参照输入料品的版本；|
|质检期间|输入统计的期间范围，时间为质检单制单日期。|

供应商来料不合格率－查询结果

|栏目名称|说明|
|---|---|
|料号|显示料品的料号；|
|料号段|显示料品的料号段；|
|品名|显示料品的品名；|
|品名段|显示料品的品名段；|
|供应商编码|显示供应商的编码；|
|供应商编码段|显示供应商的编码段；|
|供应商名称|显示供应商的名称；|
|供应商名称段|显示供应商的名称段；|
|来料总批次|显示该供应商提供的该料品的总检验批次；|
|合格批次|显示该供应商提供的该料品的合格批次；|
|退货|显示该供应商提供的该料品的退货批次；|
|特采|显示该供应商提供的该料品的特采批次；|
|合格率|显示该供应商提供的该料品的合格率；|

# 操作说明

通过菜单<a href="/detail/a965f8aa89e24347819a7257bda23182">供应商来料不合格率</a>进入供应商来料不合格率界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质检管理－>供应商来料不合格率，进入查询条件画面，输入查询条件，确定后可以查询出相应的报表数据。
