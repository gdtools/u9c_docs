
# 功能描述

本功能主要用来查询由于质量问题所造成料品的损失数量。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

质量损失报表－查询条件

|栏目|说明|
|---|---|
|分类性质|料品分类的分类性质，枚举：库存、生产、销售、采购；|
|料品分类|参照输入料品的分类，选择料品分类时必须选择分类性质；|
|料品|参照输入料品；|
|版本|参照输入料品的版本；|
|质检日期|输入统计的期间范围。|

质量损失报表－查询结果

|栏目|说明|
|---|---|
|料品|显示料品的名称；|
|版本|显示料品的版本；|
|销售退货损失数量|显示退货质检单上质检批量之和；|
|返工损失数量|显示质检类型为工序质检或完工质检的质检单上质检结果为返工的数量之和；|
|生产报废损失数量|显示质检类型为工序质检或完工质检的质检单上质检结果为不合格数量和破坏数量之总和。|

# 操作说明

通过菜单<a href="/detail/88f821ae6a8047f59b600a4477436915">质量损失报表</a>进入质量损失报表界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质检管理－>质量损失报表，进入查询条件画面，输入查询条件，确定后可以查询出相应的报表数据。
