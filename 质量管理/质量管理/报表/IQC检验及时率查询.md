
# 功能描述

本功能用于查询供应商到货检验的及时率。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

IQC检验及时率－查询条件

|栏目名称|说明|
|---|---|
|供应商分类|参照输入供应商分类；|
|供应商分类段（1..N）|选择一个或者多个段输入段值；|
|供应商|参照输入供应商；|
|供应商段（1..N）|选择一个或者多个段输入段值；|
|分类性质|料品分类的分类性质，枚举：库存、生产、销售、采购；|
|料品分类|参照输入料品的分类，选择料品分类时必须选择分类性质；|
|料品分类段（1..N）|选择一个或者多个段输入段值；|
|料号|参照输入料品；|
|料号段（1..N）|选择一个或者多个段输入段值；|
|品名|输入料品的品名；|
|品名段（1..N）|选择一个或者多个段输入段值；|
|版本|参照输入料品的版本；|
|期间范围|输入统计的期间范围，时间为收货单行的点收时间；|
|存储地点|参照输入存储地点。|

IQC检验及时率－查询结果

|栏目名称|说明|
|---|---|
|料号|显示料品的料号；|
|料号段|显示料品的料号段；|
|品名|显示料品的品名；|
|品名段|显示料品的品名段；|
|供应商编码|显示供应商编码；|
|供应商编码段|显示供应商编码段；|
|供应商名称|显示供应商名称；|
|供应商名称段|显示供应商名称段；|
|点收时间|显示收货单行的点收时间；|
|质检时间|显示质检单行的质检时间；|
|截止时间|显示截止时间，值为点收时间+24小时工作日；|
|质检完成时间|显示质检单行的质检完成时间。|

# 操作说明

通过菜单<a href="/detail/e364d4f2a3f445a58ba0c8e276797750">IQC检验及时率查询</a>进入IQC检验及时率查询界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质检管理－>IQC检验及时率查询，进入查询条件画面，输入查询条件，确定后可以查询出相应的报表数据。
