
# 功能描述

本功能用于查询每个料品的质检汇总成本。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

质检成本汇总－查询条件

|栏目|说明|
|---|---|
|分类性质|料品分类的分类性质，枚举：库存、生产、销售、采购；|
|料品分类|参照输入料品的分类，选择料品分类时必须选择分类性质；|
|料品|参照输入料品；|
|版本|参照输入料品的版本；|
|质检日期|输入统计的期间范围。|

质检成本汇总－查询结果

|栏目|说明|
|---|---|
|料品|显示料品的名称；|
|版本|显示料品的版本；|
|进货质检成本|显示进货质检的成本；|
|完工质检成本|显示完工质检的成本；|
|工序质检成本|显示工序质检的成本；|
|退货质检成本|显示退货质检的成本；|
|其他质检成本|显示其他质检的成本。|

# 操作说明

通过菜单<a href="/detail/73d8c2d5d570491b9e274c58763ef512">质检成本汇总报表</a>进入质检成本汇总报表界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质检管理－>质量成本汇总报表，进入查询条件画面，输入查询条件，确定后可以查询出相应的报表数据。
