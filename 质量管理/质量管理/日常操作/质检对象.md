
# 功能描述

本功能用来设置质检对象质检时的宽严程度，本功能中只有一个‘宽严程度’字段可以维护。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 栏目说明

质检对象头

|栏目名称|说明|
|---|---|
|质检类型|显示质检类型；|
|料品|显示料品名称；|
|版本|如果料品有版本控制，显示料品版本；|
|供应商|进货质检时，显示供应商名称；|
|客户|退货质检时，显示客户名称；|
|工序|工序质检时，显示工序名称；|
|工作中心|显示工序对应的工作中心。|

质检对象体

|栏目名称|说明|
|---|---|
|质检方案|显示质检对象的质检方案；|
|版本|显示质检对象质检方案的版本；|
|质检步骤|质检方案按步骤控制时显示质检步骤；|
|质检指标|质检方案按质检指标控制时显示质检指标；|
|宽严程度|显示质检对象当前的宽严程度；|
|从日期|系统维护；|
|到日期|系统维护。|

# 操作说明

通过菜单<a href="/detail/e87714b982b1496898e48b05c7e61c08">质检对象</a>进入质检对象界面；

质检对象就是宽严程度调整的对象，如进货质检可以按料品＋供应商＋质检方案来进行调整。

首次按标准质检时，质检方案的宽严程度取正常，质检单审核完成后，将根据宽严程度调整规则去自动记录和更新其宽严程度，相同的质检对象在下次执行质检时将从这里取质检方案的宽严程度。

*      *  操作前提
   
      *  系统启用了质量管理系统；
      *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能；
      *  系统有经过审核的质检单。
   *  操作步骤
   
      *  点击质量管理－>质检对象按钮，进入质检对象设置画面。具体步骤如下所示：
      *  第1步：进入本功能节点后，通过查找或列表查出需要的记录；
      *  第2步：维护宽严程度字段，本画面只有这个字段可以维护；当宽严程度为免检时，系统不会自动调整为其他的宽严程度，只能手工调整为其他的宽严程度。
