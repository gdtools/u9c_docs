
# 功能描述

在系统启用了MRB后，当质检单质检质检结果为不合格时，系统可以对不合格的料品进行处理。

# 业务规则

*  系统启用了质量管理系统；
*  启用了MRB；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 操作说明

通过菜单<a href="/detail/36ec54f67546470990db6e2a1f4db617">不合格处理报告</a>进入不合格处理报告界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  启用了MRB；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质量管理－>不合格处理报告菜单，进入画面。具体步骤如下所示。
   
      *  第1步：通过查找或列表功能查找已经生成的不合格处理报告；
      *  第2步：输入样本数、样本不良品数信息，不良品描述信息及部门和负责人；
      *  第3步：在不合格处理报告行页签输入部门会判信息，一个会判部门输入一行记录；
      *  第4步：在费用页签输入不良品处理的费用信息，如果有供应商承担的费用，在单据关闭时会生成一张借向应付单；
      *  第5步：在结果页签输入最终的处理结果。
