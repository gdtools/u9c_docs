
# 功能描述

本功能用来对质检单行进行查询，可以查询质检单上每行物料的质检结果、质检指标、样本、样本值、缺陷原因、纠正预防措施和来源信息。

# 业务规则

*  系统启用了质量管理系统；
*  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。

# 操作说明

通过菜单<a href="/detail/f3acf5a7dda840cfbac6c12ca3d2e436">质检单查询</a>进入质检单查询界面；

*  操作前提
 
   *  系统启用了质量管理系统；
   *  启用了MRB；
   *  当前组织有质量管理的功能，只有物流组织、工厂组织和营运组织才有质检功能。
*  操作步骤
 
   *  点击质检管理－>质检单查询，进入质检单查询结果和质检结果画面，可以查询质检单行的信息及质检结果信息；在质检单查询结果画面点击质检过程按钮，可以进入质检步骤指标画面、样本值画面和指标缺陷原因画面可以分别查询料品每个质检指标的质量信息、每个指标中每个样本的质检信息以及指标的缺陷原因；在质检单查询结果画面点击来源单据按钮，进入来源信息画面，可以查询质检单行的来源信息；在质检结果画面点击缺陷报告按钮，可以进入缺陷原因画面和预防纠正措施画面，可以查询质检结果对应的缺陷原因信息和预防纠正措施信息。
