
# 功能描述

用于确认预算制定组织制定的预算是否控制业务以及控制预算执行数的方式。

预算控制业务有三种方式，分别为总额控制、支出类型总额控制、成本项总额控制。

如果分解结构未制定概算控制方案，引用该成本分解结构的项目不进行预算控制

目前一种成本分解结构仅支持一种控制方案；

# 业务规则

## 使用前提

*  启用项目预算

# 栏目说明

|栏目名称|说明|
|---|---|
|成本分解结构|成本分解结构参照分解结构档案；成本分解结构不可为空；成本分解结构不为空，支出类型和项目成本项为空时为总额控制。总额控制时依据预算总额及浮动金额合计值控制预算执行金额。预算执行数超过预算允许的范围时提示给用户|
|支出类型|参照成本分解结构与支出类型关系表中的支出类型；支出类型可以为空；支出类型为空时不可录入项目成本项；支出类型为空时指进行总额控制；支出类型不为空且项目成本项为空时为支出类型总额控制；支出类型总额控制指依据各支出类型的预算（包含浮动金额）分别控制对应支出类型的预算执行数|
|项目成本项|参照成本分解结构与支出类型关系表中的项目成本项；项目成本项可以为空；支出类型不为空项目成本项为空时为支出类型总额控制；支出类型不为空项目成本项不为空时为项目成本项总额控制。项目成本项总额控制指依据成本分解结构+支出类型+项目成本项制定的预算控制相应成本分解结构+支出类型+项目成本的预算执行数。如果有写控制方案行根据支出类型和项目成本项定义预算制方案，有些行支出类型为空，则优先进行特例控制，然后依据总额控制。如果未定义总额控制方案则不控制|
|浮动方式|概算控制预算时可以在预算金额基础上向上或向下浮动；浮动方式支持额度、比例、混合三种方式。浮动方式为额度时，需要录入浮动的额度，预算控制时依据预算金额+浮动金额的总额进行控制；浮动方式为比例时，需要录入浮动的比例，预算控制业务依据预算金额*（1+浮比例）对预算执行数进行控制；浮动方式为混合时，浮动额度和比例都需要维护，依据最先达到的控制金额进行控制|
|币种|制定浮动额度使用的币种；|
|浮动额度|浮动方式为额度或混合时可以维护；可以维护任意数值；|
|浮动比例|浮动方式为比例或混合时可以维护；可以维护任意数值；|
|预警浮动额度|如果需要预警时，需要设置预警浮动额度或预警浮动比例；实际预警金额=预算数+浮动额度；浮动方式为额度或混合时可以维护；可以维护任意数值；|
|预警浮动比例|如果需要预警时，需要设置预警浮动额度或预警浮动比例；实际预警金额=预算数*（1+浮动比例）；浮动方式为比例或混合时可以维护；可以维护任意数值；|
|分期控制|当成本分解结构的预算类型为阶段分期时可以勾选。如果没有勾选分期控制，则预算控制业务时进行阶段控制，不进行分期控制；如果勾选分期控制，则预算控制业务时依据相应期间的预算控制对应期间的预算执行数；|

# 操作说明

## 卡片画面操作说明

*  【保存】：将当前操作中编辑的内容保存在数据库中。
*  【放弃】：将当前操作编辑内容不进行保存，仍保存原有内容，画面恢复至编辑前状态。
*  【新增】：将当前画面置为空白可编辑状态；并将原画面编辑内容进行保存。
*  【删除】：删除一条已经保存的数据。
*  【复制】：将当前画面录入内容复制到新画面中，画面显示新复制过来的信息。
*  【查找】：弹出查找画面，输入查找条件，过滤已经保存的数据。
*  【列表】：从卡片录入画面切换到列表查询画面。
*  【首页】：显示第一条单据或档案信息。
*  【上页】：显示上一条单据或档案信息。
*  【下页】：显示下一条单据或档案信息。
*  【末页】：显示最后一条单据或档案信息。

## 卡片翻页顺序

*  从卡片的查找画面返回卡片
 
   *  返回的卡片应该是在查找画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查找方案确定；
*  从列表画面返回卡片：
 
   *  返回的卡片应该是在列表画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查询方案确定；
*  链接弹出卡片：
 
   *  档案类的链接：直接显示对应档案的卡片信息，按系统默认方案进行翻页；
   *  单据类的链接，直接显示焦点对应单据卡片：
   
      *  如果是从一个列表记录的列标题链接进入卡片的，则在该列表记录间进行翻页；
      *  如果只是一个特定的单据编号进入卡片，则按系统默认方案进行翻页；

翻页方案按行或者子行显示时要求排重后再进行整单翻页；
