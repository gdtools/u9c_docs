
# 功能描述

定义该组织下各成本分解结构的概算是否管控预算、及概算管控预算的管控方式。

# 业务规则

*  企业的概算对预算进行控制时，可以控制的范围分为三类：
 
   *  总额控制：即按“成本分解结构”定义，依据项目概算的总额对预算进行控制，只要项目预算的总额不超过概算总额即可；
   *  支出类型总额控制：即按“成本分解结构+支出类型”定义，依据项目各支出类型的概算总额分别对预算进行控制，只要项目各支出类型预算的总额不超过概算对应支出类型总额即可；
   *  成本项总额控制：即按“成本分解结构+支出类型+项目成本项”定义，依据项目各支出类型+项目成本项的概算总额分别对预算进行控制，只要项目各支出类型+项目成本项的预算的总额不超过对应支出类型+项目成本项概算总额即可；
*  一个概算对预算的管控是在支出类型级，CBS下的各支出类型分别控制预算；当企业需要在支出类型总额控制的基础上，对某一个特定的项目成本项进行特例控制时，则可以按支出类型定义控制方案，并同时定义该支出类型+某一项目成本项的控制方案。同理，当企业为项目总额控制时，也可以定义特例的支出类型或项目成本项；
*  项目概算是否进行管制预算，控制方案与项目所使用的CBS相关，当CBS在此定义了管控条件，则依据此条件进行管控，未在此定义管控条件，统一视为不管控；

# 栏目说明

|栏目名称|说明|
|---|---|
|成本分解结构|成本分解结构参照分解结构档案；成本分解结构不可为空；成本分解结构不为空，支出类型和项目成本项为空时为总额控制。总额控制时依据概算总额及浮动金额合计值控制预算总额。预算超过概算或概算允许的范围时提示给用户。|
|支出类型|参照成本分解结构与支出类型关系表中的支出类型；支出类型可以为空；支出类型为空时不可录入项目成本项；支出类型为空时指进行总额控制；支出类型不为空且项目成本项为空时为支出类型总额控制；支出类型总额控制指依据各支出类型的概算（包含浮动金额）分别控制对应支出类型的预算。|
|项目成本项|参照成本分解结构与支出类型关系表中的项目成本项；项目成本项可以为空；支出类型不为空项目成本项为空时为支出类型总额控制；支出类型不为空项目成本项不为空时为项目成本项总额控制。项目成本项总额控制指依据成本分解结构+支出类型+项目成本项制定的概算控制相应成本分解结构+支出类型+项目成本的预算；如果有写控制方案行根据支出类型和项目成本项定义概算控制方案，有些行支出类型为空，则优先进行特例控制，然后依据总额控制。如果未定义总额控制方案则不控制。|
|浮动方式|概算控制预算时可以在概算金额基础上向上或向下浮动；浮动方式支持额度、比例、混合三种方式。浮动方式为额度时，需要录入浮动的额度，概算控制时依据概算金额+浮动金额的总额进行控制；浮动方式为比例时，需要录入浮动的比例，概算控制预算时依据概算金额*（1+浮比例）对预算进行控制；浮动方式为混合时，浮动额度和比例都需要维护，依据最先达到的控制金额进行控制。|
|币种|制定浮动额度使用的币种；|
|浮动额度|浮动方式为额度或混合时可以维护；可以维护任意数值；|
|浮动比例|浮动方式为比例或混合时可以维护；可以维护任意数值；|

# 操作说明

## 卡片画面操作说明

*  【保存】：将当前操作中编辑的内容保存在数据库中。
*  【放弃】：将当前操作编辑内容不进行保存，仍保存原有内容，画面恢复至编辑前状态。
*  【新增】：将当前画面置为空白可编辑状态；并将原画面编辑内容进行保存。
*  【删除】：删除一条已经保存的数据。
*  【复制】：将当前画面录入内容复制到新画面中，画面显示新复制过来的信息。
*  【查找】：弹出查找画面，输入查找条件，过滤已经保存的数据。
*  【列表】：从卡片录入画面切换到列表查询画面。
*  【首页】：显示第一条单据或档案信息。
*  【上页】：显示上一条单据或档案信息。
*  【下页】：显示下一条单据或档案信息。
*  【末页】：显示最后一条单据或档案信息。

## 卡片翻页顺序

*  从卡片的查找画面返回卡片
 
   *  返回的卡片应该是在查找画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查找方案确定；
*  从列表画面返回卡片：
 
   *  返回的卡片应该是在列表画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查询方案确定；
*  链接弹出卡片：
 
   *  档案类的链接：直接显示对应档案的卡片信息，按系统默认方案进行翻页；
   *  单据类的链接，直接显示焦点对应单据卡片：
   
      *  如果是从一个列表记录的列标题链接进入卡片的，则在该列表记录间进行翻页；
      *  如果只是一个特定的单据编号进入卡片，则按系统默认方案进行翻页；

翻页方案按行或者子行显示时要求排重后再进行整单翻页；
