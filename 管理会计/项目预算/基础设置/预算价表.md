
# 功能描述

预算价表是预算控制中价格管控的前提；

预算价表主要用于采购业务价格管控、业务发生时仅有数量没有成本时的预算金额管控。

# 业务规则

## 使用前提

*  启用项目预算模块

# 栏目说明

|栏目名称|说明|
|---|---|
|编码|价表编码；|
|名称|价表名称；|
|币种|价表使用的币种；建议使用本币；|
|状态|开立态价表可以修改；审核态价表可以用于取价；|
|料品|定价的料品；|
|计量单位|用于定价的单位；|
|单价|制定的控制价格；|
|生效日期||
|失效日期||

# 操作说明

## 审批参数

用于定义预算价表的确认方式。

**操作前提**

*  启用项目预算；

**操作步骤**

点击项**目预算－>预算价表－>审批参数**按钮。具体步骤如下所示。

*  **第1步：**项**目预算－>预算价表－>审批参数**按钮；
*  **第2步：配置参数后保存；**
*  **第3步：价表操作；**
