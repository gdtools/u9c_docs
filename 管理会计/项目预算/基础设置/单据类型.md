
# 功能描述

集中管理项目预算模块使用到的单据类型。

单据类型是单据的业务参数集合。

单据类型支持增删改。

支持单据类型范围：项目预算单据类型、项目概算单据类型、项目预算变更单据类型、项目概算变更单据类型、项目收款计划单据类型、项目收入计划单据类型、项目资源计划单据类型。

# 业务规则

## 使用前提

*  启用项目预算

# 栏目说明

|栏目名称|说明|
|---|---|
|表头|
|单据类型|项目概算变更单单据类型；项目预算变更单单据类型；项目预算单据类型；项目概算单据类型；项目收款计划单据类型；项目资源计划单据类型；项目收入计划单据类型；预算价表变更单单据类型；报价单单据类型|
|单据类型|
|编码|手工输入，当前单据类型的编码。注意编码不能重复|
|名称|手工输入，当前单据类型的名称，可空|
|描述|可空，当前单据类型的描述|
|单据类型参数|
|确认方式|选择单据审核确认的方式：（１）确认作业：即单据需要提供单独的审核操作按钮，执行审核处理；（２）审批流程：即单据需要执行多个审核环节，需要设置审批流程。|
|审批方式|确认方式为审批流程，选择审批方式：1.岗位汇报关系审批2.工作流审批|
|上游单据推出|表示当前单据类型为当前上游单据推出默认的单据类型。不同的业务类型会有不同的默认单据类型。|
|编号方式|选择单据号的编号方式。（１）手工编号：即单据号手工录入。（２）自动编号：即由系统根据编号规则，自动生成每张单据的单据编号。此种方式下需要设置编号规则。|
|编号规则|在自动编号方式下，录入单据号的编号规则。参照单据编码规则档案录入。|
|打印模版|参照打印模版录入。|
|最大打印份数|设置允许单据打印的最大份数。为0时，表示不控制打印次数。|
|打印时机|及时打印： 即单据可以在任何时候打印；核准后打印 ，单据只能在核准后才可以打印；不能打印 ，单据任何时候都不能打印|
|打印副本|单据类型上的最大打印份数只控制正本打印，超过部分如可以打印副本则打印为副本，副本打印份数不受限制。|

# 操作说明

## 卡片画面操作说明

*  【保存】：将当前操作中编辑的内容保存在数据库中。
*  【放弃】：将当前操作编辑内容不进行保存，仍保存原有内容，画面恢复至编辑前状态。
*  【新增】：将当前画面置为空白可编辑状态；并将原画面编辑内容进行保存。
*  【删除】：删除一条已经保存的数据。
*  【复制】：将当前画面录入内容复制到新画面中，画面显示新复制过来的信息。
*  【查找】：弹出查找画面，输入查找条件，过滤已经保存的数据。
*  【列表】：从卡片录入画面切换到列表查询画面。
*  【首页】：显示第一条单据或档案信息。
*  【上页】：显示上一条单据或档案信息。
*  【下页】：显示下一条单据或档案信息。
*  【末页】：显示最后一条单据或档案信息。

## 卡片翻页顺序

*  从卡片的查找画面返回卡片
 
   *  返回的卡片应该是在查找画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查找方案确定；
*  从列表画面返回卡片：
 
   *  返回的卡片应该是在列表画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查询方案确定；
*  链接弹出卡片：
 
   *  档案类的链接：直接显示对应档案的卡片信息，按系统默认方案进行翻页；
   *  单据类的链接，直接显示焦点对应单据卡片：
   
      *  如果是从一个列表记录的列标题链接进入卡片的，则在该列表记录间进行翻页；
      *  如果只是一个特定的单据编号进入卡片，则按系统默认方案进行翻页；

翻页方案按行或者子行显示时要求排重后再进行整单翻页；
