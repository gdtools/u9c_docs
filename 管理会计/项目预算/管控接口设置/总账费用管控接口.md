
# 功能描述

总帐记账的载体是会计科目和账簿，项目预算制定是依赖成本分解结构、支出类型、项目成本项。总帐费用接口是建立总帐会计科目与项目预算的对应关系，实现对总帐发生的费用进行管控。

# 业务规则

## 使用前提

*  启用项目预算

# 栏目说明

|栏目名称|说明|
|---|---|
|成本分解结构|参照成本分解结构档案；不可空|
|行号|系统编号|
|支出类型|参照成本分解结构与支出类型关系表中的末级支出类型；支出类型依据所选成本分解结构过滤；支出类型不可空|
|项目成本项|支出类型上指定的项目成本项；项目成本项依据支出类型过滤；项目成本项不可空|
|来源组织|参照组织档案；指会计科目记账组织|
|来源账簿|来源组织或来源组织法人组织主账簿；来源组织多币种账簿|
|账簿版本|参照账簿版本|
|会计科目|依据账簿过滤；所选账簿的会计科目；会计科目的版本等于账簿版本；会计科目支持定义公式|

# 操作说明

## 卡片画面操作说明

*  【保存】：将当前操作中编辑的内容保存在数据库中。
*  【放弃】：将当前操作编辑内容不进行保存，仍保存原有内容，画面恢复至编辑前状态。
*  【新增】：将当前画面置为空白可编辑状态；并将原画面编辑内容进行保存。
*  【删除】：删除一条已经保存的数据。
*  【复制】：将当前画面录入内容复制到新画面中，画面显示新复制过来的信息。
*  【查找】：弹出查找画面，输入查找条件，过滤已经保存的数据。
*  【列表】：从卡片录入画面切换到列表查询画面。
*  【首页】：显示第一条单据或档案信息。
*  【上页】：显示上一条单据或档案信息。
*  【下页】：显示下一条单据或档案信息。
*  【末页】：显示最后一条单据或档案信息。

## 卡片翻页顺序

*  从卡片的查找画面返回卡片
 
   *  返回的卡片应该是在查找画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查找方案确定；
*  从列表画面返回卡片：
 
   *  返回的卡片应该是在列表画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查询方案确定；
*  链接弹出卡片：
 
   *  档案类的链接：直接显示对应档案的卡片信息，按系统默认方案进行翻页；
   *  单据类的链接，直接显示焦点对应单据卡片：
   
      *  如果是从一个列表记录的列标题链接进入卡片的，则在该列表记录间进行翻页；
      *  如果只是一个特定的单据编号进入卡片，则按系统默认方案进行翻页；

翻页方案按行或者子行显示时要求排重后再进行整单翻页；
