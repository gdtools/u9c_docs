
# 功能描述

收入计划可以实现以项目为单位进行应收账款管理。

通过项目收入计划可以为项目制定确认收入的计划时间和计划金额。并且可以查看实际确认收入的时间和金额。

项目收入计划可以手工维护也可以从项目计划控制获取数据。

# 业务规则

## 使用前提

*  启用项目预算

# 栏目说明

|栏目名称|说明|
|---|---|
|项目收入计划-单据头|
|单据类型|参照单据类型档案；只可参照项目收入计划单据类型；|
|单号|单据编号；可以自动编号，也可手动编号；|
|日期|制单日期；|
|项目|参照项目档案；项目成本组织为当前组织；|
|币种|收入计划使用的币种；|
|合同额|项目的合同金额；|
|应收合计|汇总实际应收未税金额；|
|项目收入计划-计划收入明细|
|行号|系统编号；|
|计划收入未税金额|手工录入，或取任务类型为立账类型的任务的总金额；|
|计划收入税额|手工录入；来源于项目计划控制时为空；|
|计划收入日期|手工录入；任务的计划开始时间；|
|项目收入计划-实际应收明细|
|行号|系统编号；|
|实际收入未税金额|手工录入；来源应收单；|
|实际收入税额|手工录入；来源应收单；|
|实际应收日期|手工录入；来源应收单；|

# 操作说明

## 项目计划控制生成

用于生成收入计划。

**操作前提**

*  已经立项，并且已经进行了任务分解。

**操作步骤**

点击**收款计划－>项目计划控制生成**

按钮。具体步骤如下所示。

*  **第1步：进入收**入计划节点
*  **第2步：项**目计划控制生成功能按钮
*  **第3步：**录入项目，配置相关参数，确定后返回。
*  第4步：查看结果。

## 重取实际收款

用于重新获取实际立账情况。

**操作前提**

*  项目已经确认收入。

**操作步骤**

点击**收款计划－>重取实际收入数据**按钮。具体步骤如下所示。

*  **第1步：进入收**款计划节点
*  **第2步：**执行重取实际收入数据功能按钮
*  **第3步：查看结果。**
