
# 功能描述

基准状态的概算可以执行发布功能，发布后概算状态变更为执行概算。

发布后的概算不可以弃审。如需要弃审需要先执行取消发布、取消评审。

# 业务规则

## 使用前提

*  已经存在基准预算

# 栏目说明

|栏目名称|说明|
|---|---|
|概算发布－待发布概算|
|项目|显示概算的项目；|
|项目概算|显示概算编码；|
|概算总额|显示项目概算的金额。|
|概算发布－待发布概算|
|项目|显示概算的项目；|
|项目概算|显示概算编码；|
|概算总额|显示项目概算的金额。|

# 操作说明

## 概算发布--查询

查询需要进行发布的概算或已经发布的概算。

## 概算发布--发布

选择概算行进发布。

概算发布后概算状态改为执行概算。

执行概算控制预算。

## 概算发布--取消发布

选择概算行进取消发布。

概算发布后概算状态改为基准概算。

基准概算可以取消评审。
