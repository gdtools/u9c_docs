
# 功能描述

已经执行的预算如果需要调整预算额度需要通过预算变更功能节点。

# 业务规则

## 使用前提

*  已经制定执行的项目预算。
*  项目预算已经使用。

# 栏目说明

|栏目名称|说明|
|---|---|
|项目概算变更－表头|
|单据类型|参照项目概算变更单单据类型|
|单号|系统编号或手工编号|
|业务日期|变更日期|
|项目概算|参照执行预算|
|项目|由选择的项目概算带出|
|成本分解结构|由选择的项目概算带出|
|币种|由选择的项目概算带出|
|项目概算变更--单据行|
|行号|单据行号|
|展开标记|可以展开或收起|
|成本分解|显示成本分解结构的层级由选择的项目概算带出|
|原支出|由选择的项目概算带出|
|新支出|手工录入末级项目成本项新的支出或依据调整支出反算|
|支出调整额|手工录入或依据新支出反算|

# 操作说明

## 项目概算变更-添加分解结构

当项目概算的成本分解结构发生变化以后，可以通过添加成本分解结构将新增加的支出类型或项目成本项加入项目概算变更单。

开立状态的概算调整单可以添加成本分解结构；

执行添加成本分解结构按钮弹出分解结构选择的页面，用户可以勾选需要增加的成本分解结构。

成本分解结构可以增加支出类型或项目成本项，不可以删除。
