
# 功能描述

按业务单据范围及项目范围重取预算执行数

# 业务规则

## 使用前提

*  启用项目预算

# 栏目说明

|栏目名称|说明|
|---|---|
|总账费用管控接口|设置重取预算执行数的业务单据范围|
|制造成本管控接口|设置重取预算执行数的业务单据范围|
|库存费用管控接口|设置重取预算执行数的业务单据范围|
|费用报销管控接口|设置重取预算执行数的业务单据范围|
|从日期|设置重取预算执行数的业务日期范围|
|到日期|设置重取预算执行数的业务日期范围|
|成本分解结构|设置重取预算执行数的项目范围|
|项目|设置重取预算执行数的项目范围|
|成本分解结构|设置重取预算执行数的项目范围|

# 操作说明

## 取数
