
# 功能描述

项目预算评审完成后必须经过批复才可以生成执行预算，进行预算管控。

一般项目主管会计，项目经理有批复的权限。

# 业务规则

## 使用前提

*  项目预算已经经过评审。

# 栏目说明

|栏目名称|说明|
|---|---|
|预算批复－待批复预算|
|项目|显示预算项目|
|预算类型|显示预算的预算类型|
|成本分解结构|显示预算的成本分解结构|
|支出类型|显示预算的支出类型，总额预算时为空|
|单号|显示预算单单号|
|预算批复－已批复预算|
|项目|显示预算项目|
|预算类型|显示预算的预算类型|
|成本分解结构|显示预算的成本分解结构|
|支出类型|显示预算的支出类型，总额预算时为空|
|单号|显示预算单单号|

# 操作说明

## 预算批复－查询

查询预算单据。支持预算单据上的主要字段作为查询条件。

## 预算批复－批复

针对选中的预算单据执行批复操作，将预算单据的预算类型改为执行预算。

## 预算批复－取消批复

针对选中的预算单据执行取消批复操作，将预算单据的预算类型改为基准预算。
