
# 功能描述

主要用于调整考核价表价格；

支持对指定价表指定行的料品价格进行调整

# 业务规则

考核调价单审核时将每一行成本更新至指定价表，更新内容为指定责任主体、指定料号、指定计量单位、指定价格、指定生效日期、指定失效日期。对原记录的失效日期为指定生效日期-1.原记录生效日期不能大于修改后的失效日期。

# 栏目说明

|栏目名称|说明|
|---|---|
|考核价表调价单|
|考核价表|参照选择考核价表实体，不可为空|
|币种|根据考核体系带出，不可编辑|
|考核体系|根据价表带出，不可编辑|
|责任主体|依据所选考核体系过滤|
|价格类型|根据考核价表带出不可编辑|
|对方责任主体|依据所选考核体系过滤|
|料品|参照料品档案|
|单位|参照计量单位档案|
|原价格|根据考核价表+责任主体+料号+计量单位查找来源价表最近生效的价格，如果没有找到则为空|
|新价格|手工录入，不可为空|
|考核价表选择|
|考核体系|参照选择考核体系档案；如果调价单已经选择考核体系，需将考核体系赋值给价表选择界面的考核体系，并且不可修改。如果调价单已经选择考核价表，需要将价表带入价表选择界面，不可修改。|
|考核价表|参照价表档案|
|责任主体|参照考核体系下责任主体档案|
|对方责任主体|参照考核体系下责任主体档案|
|价格类型|枚举值|
|料品|参照料品档案|
|单位|参照计量单位档案|
|币种|参照币种档案|
|价格|根据考核价表+责任主体+料号+计量单位查找来源价表最近生效的价格，如果没有找到则为空|

# 操作说明

## 考核价表选择

查找：根据录入查询条件过滤，将过滤结果返回行

确定：将查询结果返回调价单行，并且将考核体系等信息赋值给调价单头，及调价单行；返回时检查调价单

取消：查询结果不返回到调价单
