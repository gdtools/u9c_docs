
# 功能描述

查询考核中心内的直接数据信息。

# 业务规则

## 使用前提

*  已执行责任核算

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|会计年度|考核数据所属的考核年度|
|期间号|考核数据所属的考核期间|
|考核体系|考核数据对应的考核体系|
|来源组织|考核数据对应的来源组织|
|考核要素|考核数据对应的考核要素|
|要素层级|考核要素所属层级|
|责任主体|考核数据对应的责任主体|
|核算对象|考核数据对应的核算对象|
|金额|考核数据取数的金额|

# 操作说明

## 查询

点击界面中的**[查询]**按钮，可以定义查询方案，包括查询条件、栏目及排序。
