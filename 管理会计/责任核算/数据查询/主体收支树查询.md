
# 功能描述

当责任主体为树形结构时，提供利润构成的层层展开。既能查看顶层责任主体的利润构成，也可分析顶层利润的来源责任主体。 上层责任主体的利润仅来自下层责任主体，本身不产生利润，不提供责任主体间利润的抵消处理。

# 业务规则

## 查询算法

*  根据查询条件录入考核体系展开责任主体的树状结构，展开至末级；
*  如果查询条件录入责任主体，则只根据选定的责任主体向下展开至末级责任主体；
*  如果查询条件未录入责任主体，则根据选定的考核体系展开所有责任主体至末级责任主体。
*  末级考核要素收入的取值方式：根据要素类型，取要素类型为收入的考核要素，当方向为增加时记正数，减少记负数； 末级考核要素为支出的取值方式：取要素类型为成本或费用的考核要素，当方向为增时为正数，方向为减少时为负数。利润=收入-支出。
*  非末级考核要素的收入、支出计算方式：由下级向上汇总，不做内部抵消。利润=收入-支出

# 栏目说明

|栏目名称|说明|
|---|---|
|查询条件|
|考核体系|默认当前组织考核体系，必选|
|考核期间|参照，考核体系档案会计日历，必选。默认当前登录日期所在考核期间|
|责任主体|考核体系下的责任主体，默认空|
|考核中心利润树状显示画面|
|左：考核体系树状展开|根据选择的考核体系展开责任主体至末级|
|左：责任主体|当未选择责任主体时，根据考核体系展开；当选择责任主体时根据选择的责任主体展开至末级|
|考核体系|根据选择的考核体系返回|
|考核期间|根据选择的考核期间返回|
|责任主体|显示左树焦点行对应的责任主体|
|考核要素|显示责任主体所有有成本发生的考核要素|
|收入|考核要素类型收入，增加为正减少为负|
|支出|考核要素类型成本或费用，增加为正减少为负|
|利润|滚动计算，考核要素作为栏目不作为行分组|
|树状展开画面:单击树状展开进入|
|展开级别|显示每级展开的级别|
|考核体系|根据条件选择的考核体系返回|
|考核期间|根据条件选择的考核期间返回|
|责任主体|根据考核体系及已选择责任主体展开至末级|
|考核要素|显示责任主体所有有成本发生的考核要素|
|收入|考核要素类型收入，增加为正减少为负|
|支出|考核要素类型成本或费用，增加为正减少为负|
|利润|每行计算，收入-支出|
|树状展开查询条件|
|责任主体|根据考核体系过滤，空为全部，默认空|
|展开级别|可以选择显示某个级别|
|收入|根据金额比较结果返回|
|支出|根据金额比较结果返回|
|利润|根据金额比较结果返回|

# 操作说明

## 查询

点击界面中的**[查询]**按钮，可以定义查询方案，包括查询条件、栏目及排序。
