
# 功能描述

本功能用来查询考核体系本期的间接费用分配情况，主要用于责任核算的稽核。

# 业务规则

## 使用前提

*  已执行责任核算

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|会计年度|考核费用分配所属的考核年度|
|期间号|考核费用分配所属的考核期间|
|考核体系|考核费用分配对应的考核体系|
|来源组织|显示费用分配的来源组织|
|从考核要素|考核费用分配的来源考核要素|
|从责任主体|考核费用分配的来源责任主体|
|到考核要素|考核费用分配的目标考核要素|
|到责任主体|考核费用分配的目标责任主体|
|到核算对象|考核费用分配的目标核算对象|
|分配金额|考核费用分配的分配金额|
|待分金额|考核费用分配的待分配金额|
|分配比例|考核费用分配的分配比例|
|分配方法|考核费用分配的分配方法|

# 操作说明

## 查询

点击界面中的**[查询]**按钮，可以定义查询方案，包括查询条件、栏目及排序。
