
# 功能描述

查询指定责任主体的收入、成本、利润和单位时间附加值情况；。

# 业务规则

## 使用前提

*  已执行考核期间的责任核算

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|考核要素|责任体系对应的考核要素表下的考核要素|
|损益调整|损益调整类考核要素发生额合计(责任调整单，收入、成本、费用类)|
|方向|考核要素发生额的方向。增项、减项|
|发生额|考核要素发生额|
|成本合计|成本类要素发生额增、减项、损益调整合计|
|主营利润|收入-成本合计|
|费用合计|费用类考核要素增、减项、损益调整合计|
|净利润|主营利润－费用合计|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
