
# 功能描述

对象损益趋势分析是对责任主体下的某一核算对象在一段时期内不同核算期间的利润表进行比较，以了解对象利润表各项要素的升降的趋势。

# 业务规则

## 使用前提

*  已执行考核期间的责任核算；

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|考核体系|参照考核体系档案，生效责任体系|
|责任主体|参照责任主体档案，依据责任体系过滤|
|责任期间|参照核算期间档案|
|核算对象|核算对象档案, 根据责任主体过滤|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
