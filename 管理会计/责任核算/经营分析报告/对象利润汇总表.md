
# 功能描述

对象利润汇总表用于查询指定考核体系下各责任主体的核算对象利润完成状况，查询结果按照责任主体+核算对象汇总；

# 业务规则

## 使用前提

*  已执行考核期间的责任核算；
*  核算体系为权责发生；

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|考核体系|参照责任体系档案|
|责任主体|参照责任主体档案|
|考核期间|参照核算期间档案|
|核算对象|核算对象档案，根据责任主体过滤|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
