
# 功能描述

通过定义考核体系档案，对同一考核体系下的考核对象统一管理，达到同一考核体系下考核对象的考核标准一致。

同一考核体系下不同的责任主体拥有相同的考核要素表、考核日历、考核币种、汇率类型、及料品分类体系。

# 业务规则

## 使用前提

*  已定义考核要素表

# 栏目说明

|栏目名称|说明|
|---|---|
|编码|不可重复、不可为空|
|考核要素表|参照考核要素表档案|
|考核日历|参照会计日历档案|
|考核币种|参照币种档案|
|会计基础|收付实现、权责发生|
|描述|可空，当前考核体系的描述|
|是否有效|默认T，可为F|

# 操作说明

## 卡片画面操作说明

*  【保存】：将当前操作中编辑的内容保存在数据库中。
*  【放弃】：将当前操作编辑内容不进行保存，仍保存原有内容，画面恢复至编辑前状态。
*  【新增】：将当前画面置为空白可编辑状态；并将原画面编辑内容进行保存。
*  【删除】：删除一条已经保存的数据。
*  【复制】：将当前画面录入内容复制到新画面中，画面显示新复制过来的信息。
*  【查找】：弹出查找画面，输入查找条件，过滤已经保存的数据。
*  【列表】：从卡片录入画面切换到列表查询画面。详细操作见《列表画面**操作说明**》。
*  【首页】：显示第一条单据或档案信息。
*  【上页】：显示上一条单据或档案信息。
*  【下页】：显示下一条单据或档案信息。
*  【末页】：显示最后一条单据或档案信息。

## 卡片翻页顺序

*  从卡片的查找画面返回卡片
 
   *  返回的卡片应该是在查找画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查找方案确定；
*  从列表画面返回卡片：
 
   *  返回的卡片应该是在列表画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查询方案确定；
*  链接弹出卡片：
 
   *  档案类的链接：直接显示对应档案的卡片信息，按系统默认方案进行翻页；
   *  单据类的链接，直接显示焦点对应单据卡片：
   
      *  如果是从一个列表记录的列标题链接进入卡片的，则在该列表记录间进行翻页；
      *  如果只是一个特定的单据编号进入卡片，则按系统默认方案进行翻页；

翻页方案按行或者子行显示时要求排重后再进行整单翻页；
