
# 功能描述

考核要素是将考核数据依据来源进行分类;

# 业务规则

## 使用前提

*  已定义考核要素表

# 栏目说明

|栏目名称|说明|
|---|---|
|考核要素表|参照考核要素表档案，不可为空。，不可编辑|
|编码规则|将考核要素表编码规则带如考核要素卡片|
|上级考核要素|参照考核要素档案，条件为考核要素卡片指定考核要素表，并且在有效范围内，生效标志为T|
|编码|保存时素判断当前当前所在层级，根据当前层级编码规则检查是否符合编码规则，不可为空|
|要素类型|可扩展枚举。枚举值为收入、成本、费用，不为空|
|方向|枚举选项，预置增项、减项。当要素类型为收入时，方向为增项、减项。默认增加；当要素类型为成本和费用时，方向默认为增加，可以为减少|
|明细要素|系统自动赋值。新增考核要素默认为T。当增加下级考核要素时，下级考核要素保存将上级考核要素【明细要素】修改为F|

# 操作说明

## 卡片画面操作说明

*  【保存】：将当前操作中编辑的内容保存在数据库中。
*  【放弃】：将当前操作编辑内容不进行保存，仍保存原有内容，画面恢复至编辑前状态。
*  【新增】：将当前画面置为空白可编辑状态；并将原画面编辑内容进行保存。
*  【删除】：删除一条已经保存的数据。
*  【复制】：将当前画面录入内容复制到新画面中，画面显示新复制过来的信息。
*  【查找】：弹出查找画面，输入查找条件，过滤已经保存的数据。
*  【列表】：从卡片录入画面切换到列表查询画面。详细操作见《列表画面**操作说明**》。
*  【首页】：显示第一条单据或档案信息。
*  【上页】：显示上一条单据或档案信息。
*  【下页】：显示下一条单据或档案信息。
*  【末页】：显示最后一条单据或档案信息。

## 卡片翻页顺序

*  从卡片的查找画面返回卡片
 
   *  返回的卡片应该是在查找画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查找方案确定；
*  从列表画面返回卡片：
 
   *  返回的卡片应该是在列表画面中选择的记录，若选择的记录是行记录或者子行记录，则卡片上焦点应该自动定位在对应行上；
   *  卡片的翻页顺序应该根据当前查询方案确定；
*  链接弹出卡片：
 
   *  档案类的链接：直接显示对应档案的卡片信息，按系统默认方案进行翻页；
   *  单据类的链接，直接显示焦点对应单据卡片：
   
      *  如果是从一个列表记录的列标题链接进入卡片的，则在该列表记录间进行翻页；
      *  如果只是一个特定的单据编号进入卡片，则按系统默认方案进行翻页；
*  翻页方案按行或者子行显示时要求排重后再进行整单翻页；
