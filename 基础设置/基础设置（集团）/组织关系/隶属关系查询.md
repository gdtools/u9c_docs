
# 功能描述

用于查询组织间的隶属关系。

# 业务规则

*  查询数据
 
   *  组织隶属关系
*  查询条件
 
   *  关系类型
*  查询结果
 
   *  选择不同的关系类型决定了查询结果的不同。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|关系类型|分别按照行政、法人、营运、核算、工厂、物流、资产、人事等组织职能设置组织的上下级关系。选择一种关系类型后，系统将具有此关系类型的组织全部列表显示。|
|组织|显示组织。|
|组织形态|显示组织档案中设置的组织形态信息。|
|上级组织|显示上级组织。如果某组织没有上级，则为空。|


# 操作说明

*  通过菜单[隶属关系查询](/detail/6b312cfabd144fc0adf33e24c3df571c)进入该界面；
 
   *  操作步骤：
   
      *  第1步：选择关系类型；
      *  第2步：查看查询结果；
