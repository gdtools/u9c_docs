
# 功能描述

用于查询组织间的业务关系及其组织关系间的料品设置信息。

# 业务规则

*  查询数据
 
   *  组织业务关系
   *  组织业务关系料品子表
*  查询条件
 
   *  系统在查询方案中查询方案提供默认的查询条件。可以设置来源组织、目的组织。
   *  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。如果需要查询组织关系间的料品设置信息，请在“属性选取”画面中将组织营业行为关系料品子表中的栏目设置为查询条件。
*  查询结果
 
   *  不同查询条件决定了查询结果的不同。

# 按钮说明

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|来源组织编码|显示来源组织编码|
|来源组织名称|显示来源组织名称|
|来源组织编码|显示来源组织编码|
|来源组织名称|显示来源组织名称|
|业务关系类型|显示业务关系类型|


# 操作说明

*  通过菜单[业务关系查询](/detail/bf4781bee9894cc4a86fdca0898b9b27)进入该界面；
 
   *  操作步骤：
   
      *  第1步：点击查询按钮；
      *  第2步：输入查询条件，点击确定；
      *  第3步：查看查询结果；
