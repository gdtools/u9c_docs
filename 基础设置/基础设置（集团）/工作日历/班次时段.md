
# 功能描述

设置工作日历、考勤系统中使用的班次时段信息。

# 业务规则

*  需定义班次类别（必做）
*  编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入班次编码。|
|班次|录入班次名称。|
|班次类别|选择班次所属类别。点击字段下划线，弹出班次类别用户自定义画面，可以在线新增班次类别。|
|应出勤天数|录入出勤的天数|
|描述|录入班次时段的描述信息。|
|生效|录入生效标识|
|生效日期|录入生效日期|
|失效日期|录入失效日期|
|序号|录入班次序号|
|时段|录入班次下每个时段的时段名称。|
|进入时间|录入时段的进入时间。|
|退出时间|录入时段的退出时间。|
|小时数|系统自动计算工作小时数。|
|弹性时间|标识进入时间与退出时间跨越零点时，是否以进入时间为依据。|
|描述|录入时段的描述性说明。|
|跨天是否以进入时间为准|可选框|
|开始签到时间|录入开始签到的时间|
|截止签退时间|录入截止签退时间|
|开始休息时间|录入开始休息时间|
|截止休息时间|录入截止休息时间|
|休息时长|录入休息时长|
