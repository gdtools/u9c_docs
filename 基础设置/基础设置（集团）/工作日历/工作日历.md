
# 功能描述

提供对工作日历的查询、修改功能。

根据系统设置的工作日规则生成工作日历后，用户可以在此进行查询，如果对某一天是否工作日或班次进行临时性修改，可以在本功能完成。

# 业务规则

*  需定义工作日历规则（必做）
*  编码不允许重复。

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|工作日历|默认显示当前登录组织使用的工作日历。用户可以参照工作日历档案，查询其他工作日历信息。|
|开始日期|默认显示当前登录日期所在自然月份的开始日期。用户可以手工输入其他需要查询的日期范围。|
|结束日期|默认显示当前登录日期所在自然月份的结束日期。用户可以手工输入其他需要查询的日期范围。|
|工作日编号|按照工作日历范围显示每个工作日的顺序编号。|
|日期|显示日期范围内的具体日期。|
|星期名称|显示对应星期几|
|工作日|显示是否工作日。如果是工作日加注标识。|
|日期类型|显示日期类型，工作日、休息日或节假日|

班次显示画面

|栏目|说明|
|---|---|
|编码|显示班次编码。当光标在某班次行上时，在时段显示画面，显示对应的时段信息。|
|名称|显示班次名称。|
|产能策略|显示产能策略|

时段显示画面

|栏目名称|说明|
|---|---|
|进入时间|显示班次下设置的每个时段的进入时间。|
|退出时间|显示班次下设置的每个时段的退出时间。|


修改-基本栏目

|栏目|说明|
|---|---|
|日期|显示工作日对应的具体日期。|
|星期|显示工作日对应星期几。|
|工作日|标识根据工作日规则，某一天是否是工作日。如果需要将某个工作日改为非工作日，则取消标记。注意：同时将班次信息删除。如果需要将某个非工作日改为工作日，加注此标记。注意：同时增加设置班次信息。|
|班次|显示工作日设置的班次信息。|
|时段|显示每个班次对应的时段信息。|

# 按钮说明

*  <组织机构>：导航到[组织机构](/detail/fe4f658572b34cbc88dbb1dc6016d079)档案设置功能节点。
*  <部门>：导航到[部门](/detail/fffd959d9f19411e89e79315cf33eef2)档案设置功能节点。
*  <修改>：对某工作日或非工作日进行规则修改。点击修改按钮，弹出工作日规则修改画面，可以某工作日改为非工作日，或将某非工作日设置为工作日，修改完毕，务必保存修改内容。

# 操作说明

*  通过菜单[工作日历](/detail/ae8d14ba5b014c58a576007b44aac9b9)进入该界面；
*  操作步骤
 
   *  第1步：选择工作日历和时间范围。
   *  第2步：点击查找。
   *  第3步：修改相关信息后保存工作日历。
