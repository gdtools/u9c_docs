
# 功能描述

设置工作日规则。即设置在一段时间范围内，哪些天是工作日，哪些天不是工作日；

设置工作日班次规则。即设置每个工作日有哪些具体班次。

系统将根据设置的工作日规则及班次规则生成具体的每个工作日历。对系统生成的工作日历，用户还可以根据特殊情况进行调整。

# 关键应用

*  追加工作日历的日期范围
 
   *  如果需要在一个已经使用的工作日历的日期范围之外，在增加日期时，可以直接调出需要修改的工作日历，直接修改“结束日期”，然后保存修改数据，并再此执行“生成日历”功能即可。
   *  操作前提
   
      *  设置工作日规则，并保存设置内容。
      *  生成工作日历。
   *  操作步骤
   
      *  直接修改“结束日期”，点击保存按钮，将修改内容保存。
      *  点击　生成日历　按钮。生成工作日历后，系统将在提示栏提示“工作日历编译成功！”
      *  导航到工作日历功能节点，按照新的日期范围进行工作日历查询。

# 业务规则

*  需设置班次规则。（必做）
*  编码不允许重复。
*  务必针对每条“工作日规则”设置班次规则。否则，对某类工作日将没有班次信息，影响系统正常使用。

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|工作日历信息||
|编码|录入工作日历编码。|
|名称|录入工作日历名称。|
|基础日历|录入当前设置的工作日历参考的基础日历的时间范围。参照工作日历档案录入。|
|开始日期|如果录入基础日历，则默认基础日历的开始日期，可以修改。可以直接录入当前使用的工作日历的开始日期。|
|结束日期|如果录入基础日历，则默认基础日历的结束日期，可以修改。可以直接录入当前使用的工作日历的结束日期。|
|工作日规则信息||
|类型|选择工作日类型。系统提供以下规则类型：１、固定日期：系统可以将某固定日期指定为工作日或非工作日。此时必须录入年月日具体日期。２、周：系统可以一周中哪些天是工作或非工作日。此时，必须录入一周中从周一到周日的具体日期。３、月：系统可以指定一个月内的某些天为工作日或非工作日。此时，必须录入一个月内从１日－－３１日的具体哪天。４、年：系统可以指定一年内，哪个月的哪天为工作日或非工作日。此时，必须录入一个具体月、具体日。5、默认班次：可以设置一个缺省班次的工作日。系统在生成日历时会把所有未定义班次规则的工作日，按缺省班次规则生成日历。|
|工作日|标识当前设置的是工作日或非工作日。如果是工作日，加注标识。如果将某天做为非工作日处理，则不能加注标识。|
|日期|如果选择的工作日规则类型是“固定日期”，则录入具体日期。|
|月|如果选择的工作日规则类型是“年”，则录入某年中具体哪个月中哪一天是工作日或不是工作日。|
|日|如果选择的工作日规则类型是“年”，则录入某年中哪个月具体哪天。|
|周|如果工作日规则是“周”，则录入从周一到周日具体哪天。|
|规则优先顺序|如果对某一具体日期，根据不同的规则类型设置了不同的规则，则需要设置系统优先级处理的原则。系统以优先级最高的为最终计算结果。例如：规则１－周一是工作日，优先级为１；规则２－５月１日是非工作日，并且５月１日正逢周五，优先级为２　，则系统将把５月１日这一天按非工作日处理。|
|日期类型|设置日期类型为工作日、休息日或者节假日|

班次规则栏目

|栏目名称|说明|
|---|---|
|产能策略|参照产能策略录入。默认为“标准产能”。|
|班次|录入工作日班次信息，只有“工作日”才允许设置班次信息。参照班次档案录入。一个工作日可以有多个班次。|


# 按钮说明

*  <生成日历>：系统将根据工作日规则，按日生成工作日历。
*  <工作日历>：导航到[工作日历](/detail/ae8d14ba5b014c58a576007b44aac9b9)档案设置功能节点。

# 操作说明

*  通过菜单[工作日历设置](/detail/98d1281cf53d48cbbf8e1319a3e9b4b4)进入界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：录入工作日历规则、班次规则等相关信息。
   *  第3步：保存工作日历。
   *  第4步：点击　生成日历　按钮。生成工作日历后，系统将在提示栏提示“工作日历编译成功！”
