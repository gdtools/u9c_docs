
# 功能描述

各业务模块转总帐时可以参照基础设置的分录汇总条件方案，如果各模块转总帐时未选择分录汇总条件方案则取账簿的分录汇总条件方案。

# 业务规则

*  编码不允许重复。
*  用于ＡＡＩ传总账凭证，确定一张凭证的行之间是否合并，只有法人组织的主帐簿和报告帐簿才可以设置分录汇总条件

# 栏目说明

基本

|栏目|说明|
|---|---|
|编码|录入分录汇总条件方案编码。|
|名称|录入分录汇总条件方案名称。|
|描述|录入分录汇总条件方案说明信息。|

分录汇总条件

|栏目|说明|
|---|---|
|会计科目相同|用户选择默认值：是|
|借贷方向不同|用户选择默认值：是相同会计科目合并时选择，合并后的方向为金额最大方的方向|
|合并后分录顺序|在相同会计科目合并时选择枚举 ：先借后贷（默认）先贷后借不排序|
|按科目编码排序|当[合并后的分录顺序]＝“先借后贷”Or“先贷后借”时设置，同方向分录是否按科目编码排序 默认值：否|
|汇率不一致|用户选择默认值：是合并后的汇率重新反算|
|任务相同合并|默认：否。任务不做为合并条件如果选择：是。表明如果任务相同时，分录进行合并|
|项目相同合并|默认：否。项目不做为合并条件如果选择：是。表明如果项目相同时，分录进行合并|
|银行账号相同合并|默认：否。银行账号不做为合并条件如果选择：是。表明如果银行账号相同时，分录进行合并|
|结算方式相同合并|默认：否。结算方式不做为合并条件如果选择：是。表明如果结算方式相同时，分录进行合并|
|收支项目相同合并|默认：否。收支项目不做为合并条件如果选择：是。表明如果项目任务相同时，分录进行合并|
|票据号相同合并|默认：否。票据号不做为合并条件如果选择：是。表明如果票据号相同时，分录进行合并|
|摘要不同合并|缺省合并|
|摘要合并方式|可空，摘要不同=TRUE时的合并规则 取值可以为：1.常数2.最后一行的摘要（默认）3.合并|
|摘要|可空 摘要合并方式=“常数”时非空。|
|零交易分录处理|用户选择：忽略（默认）、抛异常。如果生成了值为0的凭证分录，是忽略转总账通过还是系统会进行提示。|
|银行回单日期相同|勾选表示当银行回单日期相同时，分录进行合并|


# 操作说明

*  通过菜单[分录汇总条件方案](/detail/6e685687440e4f54a49cf246a5b28f25)进入该界面；
 
   *  操作步骤：
   
      *  第1步：维护编码、名称等信息；
      *  第2步：选择分录汇总条件；
      *  第3步：保存分录汇总条件方案；
