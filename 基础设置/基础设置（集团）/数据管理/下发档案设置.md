
# 功能描述

在多组织业务模式下，通过本功能设置需要下发的档案，从而实现档案信息在各组织之间的共享。

该功能画面上显示的档案，系统都可以支持下发，但是否需要下发，由用户根据业务需要设置。

可以支持下发的档案，均为与组织相关的一些档案，如客户、供应商、物料、价目表、折扣表、BOM、工艺路线、预算等 。

对于私有档案，如部门、业务员、存储地点等，系统不支持下发。

只有在该功能画面上设为下发的档案才可执行下发；否则不可下发，档案画面中下发相关功能按钮全部置灰。

一个档案一旦设置为下发，则表示其在所有组织内都可以下发；反之，则其在所有组织内都不可以下发。

# 业务规则

*  如果需要将档案下发到其他组织，在画面加注标记：√
*  当档案设置为下发时，如果已经执行过下发，则不能在将其修改为不下发；当档案设置为不下发时，如果档案的数据已经被使用，则不能在将其修改为下发。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|档案名称|均为与组织相关的一些档案，如客户、供应商、物料、价目表、折扣表、BOM、工艺路线、预算等 。由系统预置。|
|下发|如果需要将档案下发到其他组织，在画面加注标记：√当档案设置为下发时，如果已经执行过下发，则不能在将其修改为不下发；当档案设置为不下发时，如果档案的数据已经被使用，则不能在将其修改为下发。|
