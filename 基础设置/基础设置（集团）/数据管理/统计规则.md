
# 功能描述

设置系统执行数据统计的统计期间规则。

# 业务规则

*  编码不允许重复。
*  如果<期间单位>=[年]，只能输入**年1月1日，期间长度只能=1；期间号=1；
*  如果<期间单位>=[半年]，只能输入**年1月1日或**年7月1日，期间号最大=2；
*  如果<期间单位>=[季]，只能输入**年1月1日、4月1日、7月1日、10月1日，期间号最大=4 ；
*  单行基本栏目为执行“生成统计期间”操作，按照单头所输入期间规则自动生成，对应统计年度中每个统计期间的名称以及起止日期

# 栏目说明

单头基本栏目

|栏目|说明|
|---|---|
|编码|录入统计规则的编码。|
|名称|录入统计规则的名称。|
|期间单位|设置执行统计的期间类型。可以按年、半年、季、月、半月、旬、周、日进行统计。|
|期间长度|设置经过多长的期间单位执行一次统计。例如：期间单位＝日，期间长度＝５，表示５天执行一次统计；期间单位＝月，期间长度＝１，表示１个月执行一次统计。|
|起始日期|设置从哪天开始执行统计。例如：期间单位＝日，期间长度＝５，起始日期＝２００７／０７／０１，则到２００７／０７／０５执行第一次统计。|
|[生成统计期间]|点击该按钮，生成第一个统计年度的统计期间|

单行基本栏目

|栏目|说明|
|---|---|
|年度|系统维护，不可改|
|期间号|系统维护，不可改|
|名称|系统维护，不可改|
|开始日期|系统维护，不可改|
|结束日期|系统维护，不可改|

# 按钮说明

<追加统计期间>:按照期间类型及期间长度，增加一个统计年度内的所有统计期间数据。

<删除统计期间>:删除最后一个没有执行统计功能的统计年度中的全部统计期间数据。


# 操作说明

*  通过菜单[统计规则](/detail/4dd8edc3e6ef45bf8175a668228db55a)进入该界面；
*  操作步骤
 
   *  第1步：维护编码和名称等信息。
   *  第2步：选择期间单位、起始日期等信息。
   *  第3步：保存统计期间。
