
# 功能描述

设置国家/地区档案。

# 业务规则　

*  编码不允许重复。
*  如果系统预置的地址格式中没有某国家／地区对应的内容，点击字段下划线，弹出地址格式设置画面，可以在线新增地址格式信息。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入国家／地区的编码。|
|国家／地区|录入国家／地区名称。|
|简称|录入国家／地区简称。|
|描述|录入国家／地区的描述性说明信息。|
|地址格式|录入国家／地区使用的地址格式。由于不同国家有不同的地址描述形式，在此需要选择每个国家／地区习惯使用的地址格式信息。地址格式将影响地址信息的输出打印形式。|


# 按钮说明

*  <省／自治区>：导航到省／自治区档案设置功能节点。
*  <城市>：导航到城市档案设置功能节点。
*  <区县>：导航到区县档案设置功能节点。
*  <邮政编码>：导航到邮政编码档案设置功能节点。
*  <地址>：导航到地址档案设置功能节点。

# 操作说明

*  通过菜单《基础设置：基础设置（集团）：地址：国家／地区》进入该界面；
*  操作步骤
 
   *  第1步：录入编码、国家/地区等相关信息。
   *  第2步：选择地址格式。
   *  第3步：保存国家/地区。
