
# 功能描述

设置港口档案。

# 业务规则

*  编码不允许重复。

# 栏目说明

港口

|栏目|说明|
|---|---|
|编码|录入港口的编码。|
|名称|录入港口的名称。|
|简称|录入港口的简称。|
|地址|参照录入地址档案。|
|所属关区|录入所属关区。|
|关区代码|录入关区代码。|
|基本港|打勾选择，是否基本港。|
|备注|录入备注信息。|
|生效|标识此档案是否生效。|
|生效日期|生效的起始日期。|
|失效日期|生效的截止日期。|

# 操作说明

*  通过菜单[港口](/detail/9def7b75ea91460baea3a7bce3630feb)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：保存港口。
