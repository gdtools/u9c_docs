
# 功能描述

设置国家／地区以及省／自治区下瞎的城市档案。

# 业务规则

*  编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|国家／地区|录入城市所属的国家／地区。参照国家／地区档案录入。|
|省／自治区|录入城市所的省／自治区。参照省／自治区档案录入。|
|编码|录入城市编码注意　:同一国家／地区同一省／自治区下的城市编码不允许重复。|
|城市|录入城市名称。|
|简称|录入城市简称。|
|描述|录入对城市的描述性说明信息。|
