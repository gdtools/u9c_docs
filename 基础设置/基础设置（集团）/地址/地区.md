
# 功能描述

设置地区档案。

用户可以对自己的客户或供应商按照地区进行分类管理。

# 业务规则

*  编码不允许重复。
*  需设置地区档案的编码结构。（必做）
*  需定义国家／地区档案。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|国家／地区|参照国家／地区档案录入。由于企业所划分的地区范围可能会超越国家，如亚太地区，所以本字段可以为空。|
|编码|录入地区的编码结构。点击功能按钮弹出编码结构段值录入画面，用户可以根据段对应的值集录入相关内容。|
|名称|录入地区名称。|
|简称|录入地区的简称。|
|描述|录入地区的描述性说明信息。|

# 按钮说明

*  <客户>：导航到[客户](/detail/b5256b547b394d6c9dff0c3beaeb50cf)档案设置功能节点。
*  <供应商>：导航到[供应商](/detail/b0b40041a9ff4402a2244dc6fd71b531)档案设置功能节点。

# 操作说明

*  通过菜单[地区](/detail/23bb2ba7d1934358a3facf2d08f7c291)进入该界面；
*  操作步骤
 
   *  第1步：选择国家／地区。
   *  第2步：录入编码、名称等相关信息。
   *  第3步：保存地区。
