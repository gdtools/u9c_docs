
# 功能描述

设置地址档案。

# 业务规则

*  编码不允许重复。
*  需定义国家／地区档案（必做）
*  需定义省／自治区档案（必做）
*  需定义城市档案
*  需定义区县档案
*  需定义邮政编码档案

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|设置地址编码。|
|名称|录入地址名称|
|国家／地区|参照国家／地区档案录入。|
|省／自治区|参照省／自治区档案录入。|
|城市|参照城市档案录入。|
|区县|参照区县档案录入。|
|邮政编码|录入地址的邮政编码。上各字段如果不录入，可以通过后续字段分别带出显示。例如：您可以只需录入邮政编码，从邮政编码档案中可以分别带出国家／地区、省／自治区、城市、区县等相关信息。提高您的档案录入效率。|
|地址一|录入地址段一详细内容。|
|地址二|录入地址段二详细内容。|
|地址三|录入地址段三详细内容。|

# 操作说明

*  通过菜单[地址](/detail/2e3932d1cda7456387e3bc125200668d)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：选择国家／地区、省／自治区、城市等信息。
   *  第3步：保存地址。
