
# 功能描述

设置国家／地区、省／自治区州以及城市下设的区县档案。

# 业务规则

*  编码不允许重复。
*  定义国家／地区档案（必做）
*  定义省／自治区档案（必做）
*  定义城市档案（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|国家／地区|录入区县所属的国家／地区。参照国家／地区档案录入。|
|省／自治区州|录入区县所属的省自治区。参照省／自治区档案录入。|
|城市|录入区县所属的城市。参照城市档案录入。|
|编码|录入区县编码。|
|区县|录入区县名称。|
|简称|录入区县简称。|
|描述|录入对区县的描述性说明信息。|
