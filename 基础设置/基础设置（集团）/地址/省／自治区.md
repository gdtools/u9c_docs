
# 功能描述

设置各国家中的省／自制区档案。

# 业务规则

*  编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|国家／地区|录入省／自治区所属的国家／地区。参照国家／地区档案录入。|
|编码|录入省／自治区编码。注意　:同一国家中省／自治区编码不允许重复。|
|省／自治区|录入省／自治区名称。|
|简称|录入省／自治区简称。|
|描述|录入省／自治区的描述性信息。|

# 按钮说明

*  <[城市](http://wangwq/U9C/help/zh-CN/Content/CBO/Function/CBO.Base.Location.City.htm)>：导航到[城市](/detail/c7c2d8a9fad6478491e2c1021c4d0790)档案设置功能节点。
*  <[区县](http://wangwq/U9C/help/zh-CN/Content/CBO/Function/CBO.Base.Location.County.htm)>：导航到[区县](/detail/fa49c7d862c34ba0b171e7f30ecba86c)档案设置功能节点。
*  <[邮政编码](http://wangwq/U9C/help/zh-CN/Content/CBO/Function/CBO.Base.Location.PostalCode.htm)>：导航到[邮政编码](/detail/6d3ab3fb099046f4bf3cfbf4063b5ee0)档案设置功能节点。
*  <[地址](http://wangwq/U9C/help/zh-CN/Content/CBO/Function/CBO.Base.Location.Location.htm)>：导航到[地址](/detail/2e3932d1cda7456387e3bc125200668d)档案设置功能节点。

# 操作说明

*  通过菜单[地址](/detail/2e3932d1cda7456387e3bc125200668d)进入该界面；
*  操作步骤
 
   *  第1步：选择国家地区。
   *  第2步：录入编码、简称等相关信息。
   *  第3步：保存地址。
