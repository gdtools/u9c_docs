
# 功能描述

邮政编码档案信息。

# 业务规则

*  编码不允许重复。
*  需定义国家／地区档案（必做）
*  需定义省／自治区档案（必做）
*  需定义城市档案
*  需定义区县档案

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|国家／地区|录入邮编所属的国家／地区。参照国家／地区档案录入。|
|省／自治区|录入邮编所属的省／自治区州。参照省／自治区档案录入。|
|城市|录入邮编所属的城市。参照城市档案录入。|
|区县|录入邮编所属的区县。参照区县档案录入。|
|邮政编码|录入邮政编码。|

# 按钮说明

*  <地址>：导航到[地址](/detail/2e3932d1cda7456387e3bc125200668d)地址档案设置功能节点。

# 操作说明

*  通过菜单[邮政编码](/detail/6d3ab3fb099046f4bf3cfbf4063b5ee0)进入该界面；
*  操作步骤
 
   *  第1步：选择国家／地区、省／自治区、城市等相关信息。
   *  第2步：录入邮政编码。
   *  第3步：保存邮政编码。
