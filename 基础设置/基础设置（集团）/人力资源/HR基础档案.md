
# 功能描述

定义学历、学位、专业、专业技术职务、民族档案。

# 业务规则

*  编码不允许重复。

# 栏目说明

基础档案画面

|栏目|说明|
|---|---|
|上级学历|选择上级学历信息|
|编码规则|显示档案的编码规则|
|编码|按照相应的编码规则，录入学历、学位、专业、专业技术职务、民族的编码。|
|名称|录入学历、学位、专业、专业技术职务、民族的名称|
|简称|录入学历、学位、专业、专业技术职务、民族的简称|
|描述|录入档案的说明信息|


# 操作说明

*  通过菜单[HR基础档案](/detail/21246e90bdff47c5ae39b8950a88f86e)进入该界面；
*  操作步骤
 
   *  第1步：点击新增按钮。
   *  第2步：维护编码、名称等信息。
   *  第3步：保存HR基础档案。
