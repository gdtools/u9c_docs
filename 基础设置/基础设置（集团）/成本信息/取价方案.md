
# 功能描述

用于定义一些业务的取价来源及取价顺序。

方案定义以后需要在单据类型或库存参数或其他手工选择取价方案的地方选择才会有效。

# 业务规则

*  编码不允许重复。

# 栏目说明

取价方案－基本页签

|栏目|说明|
|---|---|
|编码|档案编码；|
|名称|档案名称；|
|生效|生效标记勾选的取价时才会有效；|
|生效日期|档案的开始生效时间；|
|失效日期|档案的失效时间；|


取价方案－状态页签


|栏目|说明|
|---|---|
|选取|勾选的行有效；|
|取价方案|支持上月结存、最新结存、最近一次入、最近一次出、参考成本、订货价格+分摊费用、采购价表、标准/计划价。上月结存：最近一次月结的结存单价，标准价成本类型不适合使用。订货价格+分摊费用和采购价表仅限于采购业务使用；标准/计划价：使用与标准价或计划价成本类型取价；|
|顺序号|数字越小，优先级越高；|



# 操作说明

*  通过菜单[取价方案](/detail/0833c24f6d894569a7c272ee297c47ea)进入该界面；
 
   *  操作步骤：
   
      *  第1步：维护编码、名称等信息；
      *  第2步：选择取价方案，维护顺序号；
      *  第3步：保存取价方案；
