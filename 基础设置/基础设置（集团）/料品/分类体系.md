
# 功能描述

设置料品分类体系档案。料品分类体系是料品进行分类管理的基础数据，用户在实际使用系统前，应当根据自己企业的实际业务，明确划分料品的有效分类。

料品分类体系中需要记录具体料品分类的编码结构，不同分类体系的料品可以设置不同的料品分类编码结构。例如：在采购环节需要对料品的来源地进行分类管理，则可以将“地区”设置为料品采购分类编码中的“段”（详见“编码结构”部分说明）设置编码结构；而在销售环节又需要对客户所属行业进行分类管理，就可以将“行业”设置为料品销售分类编码中的“段”设置编码结构。

料品分类支持多编码结构。即用户可以根据业务需要，分别设置料品采购分类、销售分类、库存分类、生产分类等多种不同的编码结构进行分类管理。

# 业务规则

*  编码不允许重复。
*  需定义料品分类编码结构（必做）
*  料品分类体系中必须指定一种分类标识。即不允许出现9类标识全部为空的分类体系。
*  一个分类标识在分类体系中只能出现一次。即不允许两个或以上的分类体系都标注“库存”标识，以此类推。
*  料品的所有分类体系中，只能有一个分类体系作为主分类。
*  当“料品段使用规则”被选中且料品档存在料品记录，主分类不能由选中改为不选中。
*  选中主分类体系时，我们将根据料品所属分类与主分体系下的分类相同的分类的值，自动确定物料所属主分类。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入料品分类体系编码。|
|名称|录入料品分类体系名称|
|库存分类|如果当前设置的分类体系包含库存分类，加注此标识。|
|生产分类|如果当前设置的分类体系包含生产分类，加注此标识。|
|销售分类|如果当前设置的分类体系包含销售分类，加注此标识。|
|采购分类|如果当前设置的分类体系包含采购分类，加注此标识。|
|MRP分类|如果当前设置的分类体系包含ＭＲＰ分类，加注此标识。|
|成本分类|如果当前设置的分类体系包含成本分类，加注此标识。|
|价格分类|如果当前设置的分类体系包含价格分类，加注此标识。|
|财务分类|如果当前设置的分类体系包含财务分类，加注此标识。|
|信用分类|如果当前设置的分类体系包含信用分类，加注此标识。|
|分类编码结构|录入料品分类体系下的料品分类编码结构。参照料品分类编码结构录入；如果没有设置对应的料品分类编码结构，点击字段，弹出料品分类编码结构设置画面，在线新增料品分类编码结构信息。|
|主分类体系|指定当前料品分类体系是否是主分类|
|料品左树右表|当前料品分类体系为主分类体系时，在此指定在物料档列表中是否以“左树右表”的形式展现料品，参见料品|
|树型段|选择该分类体系对应的分类编码弹性域结构的段，必须为树形段|
|料品段使用规则|定义当前分类体系所对应的料品分类中是否使用料品的关键弹性域，参见料品分类[主分类体系]被选中时，可以修改，否则不可编辑物料主档无料品记录，可以修改|

# 操作说明

*  通过菜单[分类体系](/detail/e0649a8e5aef437b8f1c5081f67dd8ae)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：选择分类体系、分类编码结构、主分类体系等信息。
   *  第3步：保存分类体系。
