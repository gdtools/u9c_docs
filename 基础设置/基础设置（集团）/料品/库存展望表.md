
# 功能描述

查询指定日期料品的预计库存情况。

利用这个功能业务人员可以随时了解料品的预计库存情况，参考预计库存数据做业务处理。

*  详细功能如下：
 
   *  可查各业务的预计出入库数量
   *  预计入库数量包括：请购单、采购订单、收货单、杂收单、生产订单、形态转换单、调入单、调出单
   *  预计出库数量包括：销售订单、出货计划、出货单、杂发单、生产备料、形态转换单、调入单、调出单、委外订单备料
   *  可选择查哪些业务的预计出入库数量
   *  各业务数据的数量都自动转换成料品的库存主单位
   *  可按多维度汇总料品的预计出入库数量
   *  维度包括：等级、成分、自由项、厂牌、项目、番号、存储地点、批号、货主组织
   *  可指定按哪些维度汇总预计出入库数量
   *  可查询任意组织范围料品的预计出入库数量(数据范围受查询的数据权限控制)
*  查询料品的条件
 
   *  按料品的默认采购员查
   *  按料品的默认计划员查
   *  按料品的默认销售员查
   *  按料品的默认库管员查
   *  按料品分类查
   *  按指定的料品范围查

# 业务规则

*  统计数据
 
   *  查指定日期的预计库存数量，包括当前库存现存量、当前日期到指定日期的预计入库数量和预计出库数量
*  统计条件
 
   *  系统在查询方案中提供默认的统计条件，具体的统计条件如下：
   *  组织：可选任意组织
   *  料号、品名、规格、参考料号1、参考料号2、等级、成分、自由项、厂牌：料品的基本查询条件
   *  展望日期：查截至到展望日期的预计库存情况
   *  料号段、品名段、料品扩展字段：料品段相关条件
   *  料品分类、料品分类段：料品分类相关条件
   *  物料形态属性：料品的物料形态属性
   *  番号
   *  项目
   *  存储地点
   *  货主组织
   *  批号、批号段
   *  计划员：查 料品档案的默认计划员 查询
   *  采购员：按 料品档案的默认采购员 查询
   *  销售员：按 料品档案的默认销售员 查询
   *  库管员：按 料品档案的默认库管员 查询
   *  包含库存现存量、包含杂发单的预计出等：勾选后，报表的栏目中将包括对应业务的预计数据
*  统计结果
 
   *  统计结果中统计单据数据的基本条件是
   *  库存异动单据：未审核的单据作为预计出入库数量。
   *  非库存异动单据：已审核、未关闭、未挂起、未终止的单据作为预计出入库数量。预计出（入）库数量=计划出（入）数量-已执行数量。

# 栏目说明

*  统计结果中包括如下数据：
 
   *  库存现存量：库存在手量的库存现存量
   *  杂收预计入库数量：未审核的杂收单入库数量
   *  杂发预计出库数量：未审核的杂发单出库数量
   *  形态转换单行/子行预计入库数量：未审核的形态转换单转换后数量
   *  形态转换单行/子行预计出库数量：未审核的形态转换单转换前数量
   *  调出单行预计出库数量：未审核的调出单调出数量
   *  调出单子行预计入库数量：已审核的调出单未调入的数量
   *  调入单行预计入库数量：未审核的调入单的调入数量（不包括库位调拨业务）
   *  调入单行预计出库数量：未审核的一步式调入单的调出数量（不包括库位调拨业务）
   *  请购单行的预计入库数量：已审核未转采购订单的预计入库数量。（如果请购单已转采购订单但未关闭，那么未转的请购数量统计在请购单行的预计入库数量中，已转采购订单的数量统计在采购订单子行的预计入库数量中）
   *  采购订单子行的预计入库数量：已审核未转收货的预计入库数量。（如果已转收货单，但是收货单未审核，那么这部分数量统计在收货行的预计入库数量中）
   *  收货行的预计入库数量：未审核收货单的预计入库数量
   *  销售订单子行的预计出库数量：已审核未做出货计划或未做出货的预计出货数量（已转出货计划或出货单，但是出货计划或出货单未审核，这部分数量统计在出货计划或出货单的预计出货数量）
   *  出货计划行的预计出库数量：未关闭的出货计划预计出库数量（扣除已转出货单的数量）
   *  出货单行的预计出库数量：未关闭的出货单预计出库数量
   *  生产订单的预计入库数量：已审核未关闭的生产订单预计入库数量（扣除已入库数量）
   *  生产订单备料的预计出库数量：已审核未关闭的生产订单备料的预计出库数量（扣除已生成领料单的数量）
   *  生产领料单的预计出库数量：当（生产订单单据类型）.[领料数量控制时机]=“单据审核”时，统计未关闭 并且 已审核 的领料单；当（生产订单单据类型）.[领料数量控制时机]=“单据创建”，统计未关闭的领料单
   *  委外订单备料的预计出库数量：已审核未关闭的委外订单备料的预计出库数量（扣除已生成领料单的数量）
   *  委外领料单的预计出库数量：当（委外订单单据类型）.[领料数量控制时机]=“单据审核”时，统计未关闭 并且 已审核 的领料单；当（委外订单单据类型）.[领料数量控制时机]=“单据创建”，统计未关闭的领料单；

# 按钮说明

*  <查询方案>：弹出查询方案界面，可以定义查询方案，包括查询条件、栏目及排序。
*  <调整列宽>：弹出调整列宽界面，可以调整列表栏目显示及打印的宽度。

# 操作说明

*  通过菜单[库存展望表](/detail/44fb60148d9044808e1b7806f8fb7b20)系统打开“查询方案”画面，在其中选择统计方式与查询条件后，点击确定按钮，即可将报表显示在画面中。
*  查询方案
 
   *  点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。
*  调整列宽
 
   *  点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。
