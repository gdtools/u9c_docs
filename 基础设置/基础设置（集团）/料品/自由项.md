
# 功能描述

设置料品自由项档案；

自由项是系统提供用来描述料品属性的工具。对于一些很难通过系统进行定置的料品属性可以使用自由项进行描述。例如：服装行业生产的服装，颜色、型号是随着市场的需求不断变化的，冬季颜色可能以黑色、棕色为主，夏季可能以白色、黄色为主，这样，为了能够满足服装行业的要求，就可以使用“颜色”、“型号”2个自由项进行描述； 

系统预置了十个自由项，用户可以修改自由项的名称，将自由项设置为自己企业实际需要的内容；针对每个料品可以使用其中的三个自由项进行管理。 

自由项的应用步骤如下：

步骤一：设置料品自由项集合及自由项目值 例如：颜色、型号、产地可以做为自由项目，而对于颜色自由项，还需要设置具体颜色：红、白、黑、黄等自由项值。

步骤二：设置自由项值之间的依赖关系 例如：颜色自由项中的红色，只能在产地-北京生产，白色只能在上海生产，这样的相互控制就形成了自由项值之间的依赖关系。

步骤三：在料品档案中引用自由项。 在维护料品档案时，选择具体料品使用了哪些自由项。并设置是否根据不同的自由项是否影响成本、影响收款、影响付款等业务参数。

# 业务规则

*  编码不允许重复。
*  系统预置十个自由项档案（必做）。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|系统预置１－１０个自由项编码。|
|名称|用户可以将预置的自由项名称进行修改。|
|简称|录入自由项简称。|
|描述|录入对自由项的描述信息。|
|值编码|录入自由项下每个自由项值的编码。|
|名称|录入自由项值的名称。|
|描述|录入对自由项值的描述信息。|

值依赖设置画面-基本栏目

|栏目|说明|
|---|---|
|来源自由项值|参照自由项值录入。|
|来源自由项|显示自由项值所属自由项。|
|目的自由项值|参照自由项值录入。目的自由项值与来源自由项值不能属于同一自由项。|
|目的自由项|显示自由项值所属自由项。|


# 按钮说明

*  <值依赖>：设置不同自由项下的值之间的相互关系。
*  <料品>：导航到[料品](/detail/c073bf1ac1f349569ad5439839776131)档案设置功能节点。

# 操作说明

*  通过菜单[自由项](/detail/a96a434e831d4bdeb55505bbb18da1fd)进入该界面；
*  操作步骤
 
   *  第1步：录入名称、简称等相关信息。
   *  第2步：维护值、名称等信息。
   *  第3步：保存自由项。
