
# 功能描述

海关编码即HS编码，我们可在此维护企业料品对应的海关编码。

在料品档中可指定料品对应的海关编码

计算退税金额时，首先自海关编码档中取征税率与退税率，若未设置，

则从料品档中取退税率

# 业务规则

*  编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|HS编码|手工输入HS编码|
|名称|手工输入HS编码对应名称|
|关税|手工输入HS编码对应的关税，输入小数|
|退税率|手工输入HS编码对应的退税率，输入小数|
|描述||
|生效分区|参见档案有效性|



# 按钮说明

*  <料品>：导航到[料品](/detail/c073bf1ac1f349569ad5439839776131)档案设置功能节点。

# 操作说明

*  通过菜单[海关编码设置](/detail/0556c262d0494e36a74d84c656924316)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：维护关税、退税率等信息。
   *  第3步：保存海关编码。
