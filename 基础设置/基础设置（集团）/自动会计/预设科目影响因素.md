
# 功能描述

由于不同的业务内容，在会计凭证中将会归入不同的预设科目，将这些影响预设科目归属的业务要素，称为影响因素。

本功能提供设置预设科目的不同归属要素。

同一个预设科目在不同业务单据中、在不同的核算账簿中可以分别设置不同的影响因素。

# 业务规则

*  定义预设科目（必做）
*  相同的业务活动，在不同的会计准则下可以有不同的预设科目。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|预设科目||
|会计准则|参照会计准则录入。|
|预设科目|参照预设科目档案录入。|
|自动会计类型|参照录入各业务系统提供的业务单据。同一个预设科目在不同的业务单据下，可能有不同的影响因素。或可以这样理解：同一个因素在不同的单据中可能入不同的预设科目。|
|账簿|参照账簿档案录入。|
|方向|选择录入预设科目影响因素方向。1、双向2、借方3、贷方当选择双向时，则无论科目是发生在借方还是贷方，都按该因素取值。当选择借方或贷方时，则当科目发生在借方时按借方因素取值，发生在贷方时按贷方因素取值。|
|影响因素|一个预设科目在一个单据，在一个账簿中，最多可以有２０个影响因素。|
|因素１|参照系统预置的影响因素录入。|
|因素２||
|因素......||
