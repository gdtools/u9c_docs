
# 功能描述

可以查询预设科目被哪些分录模版使用。

可以查询预设科目在分录模版上的设置情况，如查看借贷方向。

可以预设科目设置了哪些影响因素。

# 业务规则

*  定义预设科目（必做）
*  相同的业务活动，在不同的会计准则下可以有不同的预设科目。
*  查询数据
 
   *  预设科目
   *  分录模版
   *  预设科目影响因素
*  查询条件
 
   *  系统在查询方案中（查询方案）提供默认的查询条件。用户通过查询方案画面的“属性选取”操作自定义查询条件。
*  查询结果
 
   *  不同的查询条件决定了查询结果的不同。用户可根据需要组织查询条件并生成报表。

# 按钮说明

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。

# 操作说明

*  通过菜单[预设科目设置查询](/detail/a0e186fa24ee4e37b56e9c0b68305d61)进入该界面；
*  操作步骤
 
   *  第1步：点击查询方案。
   *  第2步：选择相关查询条件。
   *  第3步：点击确定后返回查询结果。
