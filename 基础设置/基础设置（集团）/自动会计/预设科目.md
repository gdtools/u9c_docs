
# 功能描述

设置交易分录中使用的预设科目档案。

预设科目的作用是分别按不同的业务系统，设置对应业务系统原始单据生成凭证时需要用到的入账科目，即对经营业务按照会计科目进行的一种归纳，这种归纳的内容就是预设科目。

应当注意这里的预设科目，不是具体的会计科目。

这里的预设科目是一种不确定的科目集合。预设科目还要设置与真正的明细会计科目的对应关系。

预设科目在定义凭证模板时，可以被引用。凡是在由业务单据生成凭证时可能用到的入账科目，均应该归类，并在这里进行定义。

系统预置了企业经营核算中经常使用的预设科目。用户可以根据自己的实际需要增加相应科目。

# 业务规则

*  一个会计准则下的预设科目编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|会计准则|参照会计准则档案录入。点击字段下划线，弹出会计准则设置画面，可以在线新增会计准则档案。|
|编码|录入预设科目编码。|
|名称|录入预设科目名称。|
