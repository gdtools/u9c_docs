
# 功能描述

设置交易分录中使用的预设科目档案。

由于不同的业务内容，在会计凭证中将会归入不同的预设科目，将这些影响预设科目归属的业务要素，称为影响因素。

U9系统里预置了一些影响因素，在这个节点中，可以通过手工维护增加预置影响因素之外的因素。

在这里增加的影响因素，可以在预设科目影响因素中参照出来，方便用户进行设置。

# 业务规则

*  编码不允许重复。
*  需定义预设科目（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|因素编码|手工录入；必须唯一|
|因素名称|手工录入；非空|
|因素取值类型|非空枚举 1、单据实体字段 2、单据枚举字段 3、单据布尔字段 4、单据文本字段 5、公共扩展字段 6、实体私有字段 手工录入时，能显示并选择1、2、3、4、6|
|值集|参照值集录入当因素取值类型为1、2、6时才可编辑、非空；否则，置灰、必为空 。|
|因素状态|显示项，置灰，不可编辑枚举 1、系统预置 2、公共扩展字段 3、自定义 手工录入时，该字段只能为3、自定义。|
