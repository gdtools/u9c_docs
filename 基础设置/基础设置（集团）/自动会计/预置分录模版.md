
# 功能描述

系统按多数用户的实际情况预置了大量重要业务的分录模版信息。

预置的分录模板只能查看不能修改，不能生成交易分录。

用户可以选择预置的分录模板快速复制到业务组织账簿中，并进行部分调整。

复制到业务组织中的分录模板可以生成交易分录。

# 业务规则

*  需定义账簿（必做）
*  需定义凭证类型（必做）

# 栏目说明

分录头－基本页签

|栏目|说明|
|---|---|
|自动会计类型|选择系统预置的业务单据。|
|会计准则|参照会计准则档案录入。|
|账簿|参照账簿录入。|
|编码|录入交易分录模版编码。|
|名称|录入交易分录模版名称。|
|凭证类型|参照凭证类型档案录入。|
|制单日期|设置交易分录中“制单日期”字段在单据中的取值规则。建议：与单据中的“单据日期”或“业务日期”字段对应。|
|附件数|设置交易分录中“附件数”字段在单据中的取值规则。如果找不到对应的取值字段，可以输入一个固定值“１”，即一张交易分录对应一张业务单据。|
|记账期间|设置交易分录中“记账期间”字段在单据中的取值规则。建议：与单据中的“记账期间”字段对应。|
|转总账|标识当前设置的模版生成的交易分录是否执行转总账处理。可以执行交易分录“转总账”的系统包括：应收、应付、采购、薪资、固定资产、存货、成本。|
|生效|相同自动会计类型、会计准则、账簿、业务条件下，只能有一个生效的模板。失效的模版不能生成交易分录。|
|业务属性１－６|根据自动会计类型，系统提供了最多６个与其相关的业务数据，用户可以再在同一个自动会计类型下不同的单据类型、业务类型等参数，设置不同的交易分录模版。业务属性是根据自动会计类型动态生成的，在画面初始时，没有显示内容。|

分录头－参数页签

|栏目|说明|
|---|---|
|增加分录|如果生成的交易分录允许增加交易行信息，则加注此标识。|
|修改分录|如果生成的交易分录允许修改交易行信息，则加注此标识。|
|删除分录|如果生成的交易分录允许删除交易行信息，则加注此标识。|
||注意　:加注标识后，用户就可以在生成的交易分录中随意增加、删除生成的会计信息，容易造成财务数据与业务数据的不一致，上述三个字段的标识，请务必仔细。|
|扩展字段|点击按钮，弹出交易分录头扩展字段取值规则设置画面，分别设置扩展字段的对应单据中的取值规则。|

分录行－分录页签

|栏目|说明|
|---|---|
|行号|显示交易分录行号|
|摘要|显示摘要字段的取值规则。|
|方向|显示交易分录中科目方向取值。|
|预设科目|显示交易分录中设置的预设科目。|
|币种|显示交易分录中币种的取值规则。|
|原币金额|显示交易分录中原币金额的取值规则|

分录行－参数页签

|栏目|说明|
|---|---|
|预设科目|设置交易分录中预设科目。参照预设科目档案录入。|
|科目可改|如果在生成的交易分录中，允许修改系统根据会计科目模版取值规则生成的会计科目，加注此标识。|
|业务实体类型|显示交易分录对应的业务单据数据表名。本字段一般是系统预置字段，建议用户操作中在不熟悉Ｕ９数据表结构的情况下不要随意修改，可以由实施人员协助调整。|
|业务实体路径|显示交易分录从哪个数据表取数。本字段一般是系统预置字段，建议用户操作中在不熟悉Ｕ９数据表结构的情况下不要随意修改。|
|排除条件|显示交易分录从哪个数据表取数时，需要排除的内容。一般情况下不需要设置。|
|摘要|设置交易分录中“摘要”字段在单据中的取值规则。|
|摘要可改|如果在生成的交易分录中，允许修改摘要内容，加注此标识。|
|方向|设置预设科目对应的会计科目的记账方向。|
|方向可改|如果在生成的交易分录中，允许修改会计科目的记账方向，加注此标识。|
|原币币种|设置交易分录中“原币币种”字段在单据中的取值规则。建议：与单据中的“原币币种”字段对应。|
|原币金额|设置交易分录中“原币金额”字段在单据中的取值规则。|
|本币金额|设置交易分录中“本币金额”字段在单据中的取值规则。建议：与单据中的“本币币种”字段对应。如果设置了本字段，系统在生成交易分录时，将以此数据为准，不再根据原币金额＊汇率进行计算。|
|原币金额可改|如果在生成的交易分录中，允许修改原币金额，加注此标识。|
|零金额显示|交易分录的金额为零时，标识此条交易分录是否显示。如果交易分录的金额为零时，不需要显示此分录，则可以不加此标识。|
|负金额调整方向|设置当前金额取值为负数时，负数金额的记账方向。可以根据科目的借贷方向显示直接显示负数金额，也可以调整到对方以正数显示。|
|汇率类型|设置交易分录中“汇率类型”字段在单据中的取值规则。建议：与单据中的“汇率类型”字段对应。|
|汇率|设置交易分录中“汇率”字段在单据中的取值规则。建议：与单据中的“汇率”字段对应。|
|数量|设置交易分录中“数量”字段在单据中的取值规则。建议：与单据中的“数量”字段对应。|
|计量单位|设置交易分录中“计量单位”字段在单据中的取值规则。由于在业务单据中有多个计量单位，建议用户设置时，务必仔细。|

# 按钮说明

*  <预设科目影响因素>：导航到[预设科目影响因素](/detail/1bdf2234447b4f5b868846d6efb1b7e2)档案设置功能节点。
*  <会计科目模版>：导航到[会计科目模版](/detail/66a3648b9d254e9f9c4e32490429d9a0)档案设置功能节点。
*  <预设科目>：导航到[预设科目](/detail/39c8986eaa5645c1a8ef485b32306e44)档案设置功能节点。
*  <分录模版>：导航到[分录模版](/detail/3cfc903bc8d14eeab311635345a58bb6)档案设置功能节点。
*  <生成分录模版>：由于预置的分录模版不能生成交易分录，通过本功能可以快速的将预置的分录模版复制当前组织账簿下。
*  <查询执行结果>：查询最近一次生成分录模版的执行结果。
*  <批量导入>：多会计准则应用下，支持按会计科目准则进行批量导入。

# 操作说明

*  通过菜单[预置分录模版](/detail/1a63825f03364a16b7afee730ae2da9e)进入该界面；
*  操作步骤
 
   *  第1步：选择会计准则。
   *  第2步：点击生成分录模版。
   *  第3步：选择账簿、凭证类型。
   *  第4步：点击确定。
