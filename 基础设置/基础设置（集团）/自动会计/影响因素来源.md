
# 功能描述

设置交易分录中使用的预设科目档案。

影响因素来源为系统自动预置，该功能用于查看影响因素对应的取值关系。

列表显示栏目可以通过”查询“方案进行设置。

# 业务规则

*  一个会计准则下的预设科目编码不允许重复。
*  定义预设科目（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|自动会计类型|参照录入各业务系统提供的业务单据。同一个预设科目在不同的业务单据下，可能有不同的影响因素。或可以这样理解：同一个因素在不同的单据中可能入不同的预设科目。|
|因素|选择影响因素。|
|借贷方向|录入借贷方向。|
|业务对象|维护业务对象|
|全局段|自动带入，不可维护|
|取值规则|录入取值规则|
|因素来源状态|自动带入，不可维护|


# 按钮说明

*  <预设科目影响因素>：导航到[预设科目影响因素](/detail/1bdf2234447b4f5b868846d6efb1b7e2)档案设置功能节点。
*  <会计科目模版>：导航到[会计科目模版](/detail/66a3648b9d254e9f9c4e32490429d9a0)档案设置功能节点。

# 操作说明

*  通过菜单[影响因素来源](/detail/a5869845a468498cb0f050ce807ddcec)进入该界面；
*  操作步骤
 
   *  第1步：点击新增。
   *  第2步：选择自动会计类型、因素等信息。
   *  第3步：维护业务对象、取值规则等信息。
   *  第4步：保存影响因素来源。
