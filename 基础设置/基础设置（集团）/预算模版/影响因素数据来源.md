
# 功能描述

影响因素来源为系统自动预置，该功能用于查看影响因素对应的取值关系。列表显示栏目可以通过”查询“方案进行设置。

# 业务规则

*  需要先定义预算目的和定义预算指标（必做）。
*  查看单据类别的数据来源影响因素。

# 栏目说明

[表头](http://wangwq/U9C/help/zh-CN/Content/FI/TB/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|单据类别|参照单据类别录入|


[列表](http://wangwq/U9C/help/zh-CN/Content/FI/TB/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|预算因素编码|系统预置的预算因素编码|
|预算因素名称|系统预置的预算因素名称|
|取值规则|因素数据来源|
|单据类别|因素取值来源的单据类别|


# 按钮说明

*  <查询>：点击查询按钮，弹出查询对话框，输入查询条件，在列表中查询符合条件的行，参照公共。
*  <预算模版>：导航到《基础设置:基础设置（组织）：预算模版：[预算模版](http://wangwq/U9C/mvc/main/javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkUFIDA.U9.ABI.TBTemplateMainUIForm&sId3000nid&mId1001101159165155","%E9%A2%84%E7%AE%97%E6%A8%A1%E7%89%88");)》预算模板界面。

# 操作说明

*  通过菜单[影响因素数据来源](/detail/7b6168b2929d4a888010f860b3a5e9e8)进入该界面；
*  操作步骤
 
   *  第1步：选择单据类别。
   *  第2步：查看单据类别的数据来源影响因素。
