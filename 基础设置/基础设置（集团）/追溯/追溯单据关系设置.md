
# 功能描述

设置追溯单据关系档案。

# 业务规则

*  相同来源单据类型和去向单据类型只能定义一个业务关系。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|来源单据类型|选择来源单据类型|
|去向单据类型|选择去向单据类型|
|关系名称|维护关系名称|
|关系字段|选择关系字段|


# 操作说明

*  通过菜单[追溯单据关系设置](/detail/8757ac90940a40bd81ea1c99fa9b840e)进入该界面；
 
   *  操作步骤：
   
      *  第1步：选择来源单据类型、去向单据类型等信息；
      *  第2步：维护关系名称、关系字段；
      *  第3步：保存追溯单据关系设置；
