
# 功能描述

设置追溯单据档案。

# 业务规则

*  一个追溯单据类型只能定义一个。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|追溯单据类型|选择追溯单据类型|
|单头实体|选择单头实体|
|子实体|选择子实体|
|业务条件|录入业务条件|
|主实体Key|录入主实体Key|
|组织|录入组织|
|单号|录入单号|
|行号|录入行号|
|料号|录入料号|
|单头展示项|录入单头展示项|
|明细展示项|录入明细展示项|
|页面URI|页面URI|


# 按钮说明

*  <追溯单据关系设置>：导航到[追溯单据关系设置](/detail/8757ac90940a40bd81ea1c99fa9b840e)档案设置功能节点。　　　　　　　　　　　　　　　　　　　　

# 操作说明

*  通过菜单[追溯单据设置](/detail/2ad6abf2360146ae997596c53b559f5b)进入该界面；
 
   *  操作步骤：
   
      *  第1步：选择追溯单据类型、单头实体、子实体等信息；
      *  第2步：选择业务条件；
      *  第3步：选择主实体Key，组织单号、行号、料号等信息；
      *  第4步：保存追溯单据设置；
