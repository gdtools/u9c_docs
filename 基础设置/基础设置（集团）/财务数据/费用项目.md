
# 功能描述

设置费用项目档案。

# 业务规则

*  编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入费用项目编码。|
|名称|录入费用项目名称。|
|描述|录入费用项目的说明信息。|
|用户费用报销|表示项目费用是否用户费用报销项目。|
|报销必须申请|表示项目费用用户费用报销项目是否需要申请。|
|生效|表示费用项目是否为有效状态。与生效日期是逻辑与的关系。|
|生效日期||
|失效日期||


# 按钮说明

*  <结算方式>：导航到[结算方式](/detail/71fe9c7d822145eb8a11f20819da3063)档案设置功能节点。
*  <账龄区间>：导航到[账龄区间](/detail/3867923adf334821b48cda23c6742556)档案设置功能节点。
*  <项目任务>：导航到[项目](/detail/1294ce2ac74747028eb175181ecc0828)档案设置功能节点。

# 操作说明

*  通过菜单[费用项目](/detail/2703be6bdd4245e0a0b0ecf81dda84d6)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：维护用户报销费用、费用报销必须申请等信息。
   *  第3步：保存费用项目。
