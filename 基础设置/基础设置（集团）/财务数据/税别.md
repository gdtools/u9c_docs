
# 功能描述

设置企业经营活动过程中需要缴纳的各种税别。

# 业务规则

*  编码不允许重复。
*  需定义税别档案（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入税别编码。|
|名称|录入税别名称。|
|增值税|如果某税别属于增值税，在画面加注标记：√|
|税率%|录入税率。|
|税额优先|如果税的计算是按税额优先，加注此标记；否则，系统按照金额优先的算法进行税额计算。|
|税计算方法|选择税额计算方法。系统提供了以下几个税计算方法：1、 按金额课税（外加）纳税额 = 不含税金额 * 税率2、 按金额课税（内含）纳税额 = 含税金额 * 税率３、 按其他税别的税额课税纳税额 = 其他税别的纳税额 * 税率４、 按其他税别的(税基+税额)课税纳税额 = 其他税别（税基+税额） * 税率|
|优先原则|如果税计算方法为“按金额课税（外加）”时，选择不含税额的优先计算原则：１、金额优先：即先算不含税金额，倒挤税额。２、税额优先：即先算税额，倒挤不含税金额。两种方法的计算结果可能存在尾差。|
|基础税别|如果税计算方法是[按别的税别课税]输入计税的基础税别。|
