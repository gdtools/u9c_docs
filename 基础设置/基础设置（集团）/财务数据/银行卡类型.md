
# 功能描述

可以设置员工账号所属的银行卡类型，如牡丹卡、龙卡等。

# 业务规则

*  编码不允许重复。
*  需定义发卡银行（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入卡名编号。|
|卡名|录入卡名。|
|发卡银行|录入银行。参照银行档案录入。点击字段下划线，弹出银行档案编辑查询画面，可以在线新增开户银行信息。|
|卡号码位数|录入银行卡卡号的编码长度。|

# 操作说明

*  通过菜单[银行卡类型](/detail/3b94e384ec554a769b2851aa419b31ad)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：选择发卡银行等信息。
   *  第3步：保存银行卡类型。
