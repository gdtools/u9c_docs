
# 功能描述

设置结算银行档案。

# 业务规则

*  编码、银行类别编码不允许重复。
*  需定义国家／地区档案（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入银行编码。|
|名称|录入银行名称。|
|ＳＷＩＦＴ号码|录入银行在国际报文传输中使用的专有号码。|
|对账单方向|选择银行对账单的记账方向。系统提供两种选项：１、与银行日记账同向；２、与银行日记账反向。|
|国家／地区|录入银行所在的国家／地区。参照国家／地区档案录入。|
|地址|录入银行所在地址。参照地址档案录入。点击字段下划线，弹出地址编辑查询画面，可以在线新增地址档案。|
|电话|录入银行联系电话。|
|地区|录入银行所属地区。|
|机构号|录入银行在人民银行注册的机构编号。|
|联行号|录入银行的联行号。|
|网银系统版本号|录入网银系统版本号。|
|类别|参照银行类别档案录入。点击字段下划线，弹出银行类别编辑查询画面，在线新增银行类别档案。具体项目见银行类别设置栏目说明|

银行类别设置栏目

|栏目|说明|
|---|---|
|编码|录入银行类别编码。|
|名称|录入银行类别名称。|
|标识|选择银行标识。银行标识主要用于网银系统。|
|企业账号定长|标识某银行的企业账号是否固定长度。如果固定长度，加注此标识。|
|企业账号长度|录入企业账号长度。|
|个人账号定长|标识某银行的个人账号是否固定长度。如果固定长度，加注此标识。|
|自动带出账号长度|录入由系统自动带出个人账号时，默认的个人账号输入长度。|

*  通过菜单[银行](/detail/e504ed35e69b415eb05f805a2fc39003)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：选择银行类别等信息。
   *  第3步：保存银行。
