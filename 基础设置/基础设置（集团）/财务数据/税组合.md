
# 功能描述

设置税别组合。

税组合是由增值税类型的税别组成的纳税组合。

在我国，税组合全部是由单一税别组成，没有多种税别组合而成的税组合形式。

税组合主要应用在美国、日本； 例如：在美国一笔销售业务中需要缴纳的税组合就是由“联邦税”+“州税”+“地方税”等组合而成。因此，需要将各类税别组合设置为“税组合”。 

在税组合中主要反映了各种税别的计算顺序关系。 税组合分为单头税组合、单行税组合；如果在单据头定义了税组合，则全部单据行中将不允许输入税组合，全部采用单据头的税组合类型。

# 业务规则

*  编码不允许重复。
*  需定义税别档案（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入税组合编码。|
|名称|录入税组合名称。|
|类型|录入税组合类型。系统提供两种税组合类型：1、 单据行税：表示设置的税组合应用在单据行中，每行可以有不同的税组合。2、 单据头税：表示设置的税组合应用在整张单据中，各行使用统一的税组合。|
|税别|录入组成税组合的税别种类。参照税别档案录入。|
|税率|显示税别对应的税率。|
