
# 功能描述

设置收支项目档案。

# 业务规则

*  编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入收支项目编码。|
|名称|录入收支项目名称。|
|方向|选择收支项目方向。１、收入：此项目为收入类项目；２、支出：此项目为支出类项目；３、收支：此项目即可以做为收入项目也可以做为支出项目。|

# 按钮说明

*  <结算方式>：导航到[结算方式](/detail/71fe9c7d822145eb8a11f20819da3063)档案设置功能节点。
*  <账龄区间>：导航到[账龄区间](/detail/3867923adf334821b48cda23c6742556)档案设置功能节点。
*  <项目任务>：导航到[项目](/detail/1294ce2ac74747028eb175181ecc0828)档案设置功能节点。

# 操作说明

*  通过菜单[收支项目](/detail/a42ec3931a714d82964e20a567f21a2e)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：选择方向等信息。
   *  第3步：保存收支项目。
