
# 功能描述

设置组织进行会计核算使用的会计日历；

会计日历与我们日常生活中使用的自然日历不同，可以以年为周期，也可以根据会计核算要求以季度、月为周期；会计日历可以是跨自然年度的。

例如：从上一年度的四月一日到本年度的三月三十一日为一个会计年度； 

会计日历的应用非常灵活，在应用系统帮助进行会计核算工作之前，应设置好组织使用的各类会计日历。

# 业务规则

*  编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|会计日历||
|编码|录入会计日历编码。|
|名称|录入会计日历名称。|
|开始日期|录入一个会计年度的开始日期。|
|结束日期|录入一个会计年度的结束日期。|
|期间类型|录入会计日历的期间类型。系统提供以下期间类型供选择1、 年：以一年划分为一个会计期间；2、 季：以一个季度划分为一个会计期间；3、 月：以一个月划分为一个会计期间；4、 四周：以四周划分为一个会计期间；5、 周：以周划分为一个会计期间；6、　日：以每天划分为一个会计期间；|
|会计期间||
|会计年度|会计期间所属年度。|
|期间号|每个会计年度中的会计期间序号。|
|开始日期|每个会计期间的开始日期。|
|结束日期|每个会计期间的结束日期。一个会计年度的最后一个期间的结束日期不允许修改，其他期间的结束日期允许修改，修改后，系统自动计算下一个期间的开始日期，保持会计期间的连续性。|
|季度|如果会计期间类型为“月”、“四周”时，录入会计期间属于会计年度中的哪个季度。例如：会计日历的起始日期是每年 7月1日，截止日期是来年 6月30日，第一个会计期间按照自然日历属于第三季度，但在会计年度中则可以属于第一季度，在此录入会计期间属于哪个季度。|
|月|如果会计期间类型为“四周”、“周”时，录入会计期间属于会计年度中的哪个月。|
|周|如果会计期间类型为“日”时，录入会计期间属于会计年度中的哪个周。|


# 按钮说明

*  <账簿>：导航到[账簿](/detail/c0a5572e8d3147c0a785f14285118370)档案设置功能节点。
*  <账簿会计日历>：导航到[账簿会计日历](/detail/c9af2659854244a4a426f96d5d414729)档案设置功能节点。
*  <追加会计期间>：系统自动追加一个新会计年度的全部期间。

# 操作说明

*  通过菜单[会计日历](/detail/d7e35aab5e0046d29e71e065417cf4d9)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：点击生成会计区间。
   *  第3步：维护会计开始日期、结束日期保存会计日历。
