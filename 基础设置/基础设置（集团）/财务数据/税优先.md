
# 功能描述

由于在料品、客户、客户位置、供应商、供应商位置等档案中都设置了税组合，在具体应用时，到底先算哪个、后算哪个，在此设置税组合的优先计算原则。

# 业务规则

*  编码不允许重复。
*  需定义税别档案（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入税优先选取原则编码。|
|名称|录入税优先选取原则名称。|
|类型|录入税优先原则的计算类型。系统提供两种类型：1、 采购：表示税优先原则适用于采购系统。2、 销售：表示税优先原则适用于销售系统。|
|税组合取值|当[选取类型]= 销售时；可以选择以下内容： 料品、客户、客户位置、客户+料品 当[选取类型]= 采购时；可以选择以下内容： 料品、供应商、供应商位置、供应商+料品|

# 操作说明

*  通过菜单[税优先](/detail/af73384769044ee98795ace0fc9f5ff7)进入该界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：选择类型、税组合取值等信息。
   *  第3步：保存税优先。
