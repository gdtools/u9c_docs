
# 功能描述

设置两种货币之间的转换率参数。

需要转换的货币为“源币”，转换后的货币为“目标币”。

汇率表主要设置的是“源币/目标币”的转换率。

源币/目标币的转换率，称为正向汇率；目标币种/源币种的转换率，称为反向汇率。

汇率类型即每日币种兑换率的类型。

汇率类型是用户自定义项目。汇率类型可以根据兑换对象设置为：公司汇率、客户汇率、供应商汇率；也可以按照兑换方向设置为：买入汇率、卖出汇率；还可以根据兑换市场设置为：国内市场、香港市场、纽约市场等等。

用户可以每天设置不同币种之间的转换率　。以满足业务交易中货币交换的需要。

也可以设置一段时间内的两两币种之间的转换率，即设置汇率的起始日期、截止日期； 

如果用户企业有比较频繁的外币交易业务，建议您务必在此功能中维护以下币种汇率；

各种货币对美圆的正向汇率、反向汇率；

各种货币对欧元的正向汇率、反向汇率；

这样，即使源币/目标币没有直接汇率，系统也可以通过各币种对美圆、欧元等国际货币的汇率，自动计算两币种之间的汇率。

# 业务规则

*  编码不允许重复。
*  需定义货币（必做）
*  需定义汇率类型（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|币种信息|
|原币|录入需要进行转换的货币。参照货币档案录入。|
|目标币|录入转换后的目标货币。例如：将人民币转换成美圆，人民币为原币种，美圆就是目标币种。|
|汇率类型|录入原货币与目标货币转换的汇率类型。选择汇率类型输入。如果没有设置相应的汇率类型点击字段，弹出汇率类型设置画面，在线新增汇率类型档案。|
|汇率精度|录入原货币与目标货币转换要求的小数点精度。|
|反向精度|录入目标货币与原货币反向转换要求的小数点精度。|
|控制差异|如果不允许用户输入超出差异值范围的汇率，则加注此标识。|
|差异值|源币种到目标币种汇率的差异值。|
|反向差异值|目标币种到源币种汇率的差异值。|
|汇率信息|
|起始日期|执行某项汇率的开始日期。|
|截止日期|执行某项汇率的截止日期。在这段时间范围内原货币与目标货币的转换将执行统一的汇率。|
|汇率|录入某日期范围内，原货币与目标货币转换的汇率值。|
|反向汇率|系统自动计算原货币与目标币的反向汇率值。|

# 按钮说明

*  <编译>：将您设置的日期范围系统生成每天可以使用的汇率数据。
*  <按日期查询>：按日期查询原币、目标币的汇率值。
*  <按币种查询>：按原币、目标币查询一段时间范围内的汇率值。　　　　　　　　　　　　　　　　　　　　　　　　　　　　　

# 操作说明

*  通过菜单[汇率](/detail/73a2a85350034593bb95b29004618839)进入该界面；
 
   *  操作步骤：
   
      *  第1步：选择原币；
      *  第2步：选择目标币；
      *  第3步：选择汇率类型；
      *  第4步：保存汇率；
*  <编译>：将您设置的日期范围系统生成每天可以使用的汇率数据。
 
   *  操作前提
   
      *  设置原币、目标币、日期范围、汇率等相关信息。
      *  保存录入信息
   *  操作步骤
   
      *  点击［编译］按钮。
      *  系统自动执行编译，只有经过编译后，您才可以按天查询相应的汇率数据。
*  <按日期查询>：按日期查询原币、目标币的汇率值。
 
   *  操作前提
   
      *  设置原币、目标币、日期范围、汇率等相关信息。
      *  保存录入信息。
      *  执行编译功能。
   *  操作步骤
   
      *  点击［按日期查询］按钮
*  <按币种查询>：按原币、目标币查询一段时间范围内的汇率值。
 
   *  操作前提
   
      *  设置原币、目标币、日期范围、汇率等相关信息。
      *  保存录入信息。
      *  执行编译功能。
   *  操作步骤
   
      *  点击［按币种查询］按钮。
