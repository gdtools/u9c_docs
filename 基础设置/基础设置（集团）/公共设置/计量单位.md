
# 功能描述

设置料品在企业生产活动过程中使用的度量单位；

系统提供了“重量、长度、体积、时间、数量”等计量单位组。

用户可以选择设置不同计量单位组下的具体计量单位；

每个计量单位组中必须指定唯一基准计量单位；

如果不同计量单位组间的计量单位需要进行单位转换，需要通过[组间转换率]设置功能，定义不同计量单位组间基准单位之间的转换率。

# 业务规则

*  定义计量单位组（必做）
*  每个计量单位组中只能有一个基准计量单位。
*  一般选择一个计量单位组中较小单位为基准计量单位。
*  计量单位编码不允许重复。
*  不能相同计量单位组之间相互转换。

# 栏目说明

[基本栏目](http://wangwq/U9C/help/zh-CN/Content/CBO/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|编码|录入计量的单位编码。|
|名称|录入计量单位名称。|
|计量单位组|选择计量单位所属计量单位组。系统预置了数量、面积、体积、长度、时间、重量等计量单位组供选择。如果需要增加计量单位组，点击字段下划线，弹出计量单位组定义代码设置画面，用户可以新增其他计量单位组信息。|
|基准单位|如果当前设置的计量单位是一个计量单位组中的基准单位，则需要加注标识。每个计量单位组中只能有一个基准计量单位。一般选择小单位为基准计量单位。|
|副单位|主要用于记录单位的规格。比如一根钢材规格为9米，则计量单位“根”的副单位为“米”，主单位-副单位的转换率为9。 交易单位如果为基准单位则主单位=副单位，如米是基准单位，则其副单位也为米。|
|转换率|交易单位如果不是基准单位就需要维护交易单位的主单位-副单位的转换率。例如：1箱=10包、1包=10盒、1盒=5个，设置如下交易单位是“个”，副单位是“个”， 主单位-副单位的转换率为1，为基准单位；交易单位是“盒”，副单位是“个”， 主单位-副单位的转换率为5；交易单位是“包”，副单位是“盒”， 主单位-副单位的转换率为10；交易单位是“箱”，副单位是“包”， 主单位-副单位的转换率为10。交易单位一定要有一个基准单位。主单位和副单位属于同一计量单位组|
|精度|录入使用当前计量单位计录的料品数量的小数点后有效位数。例如：以“米”做单位，计量时，保留小数点后２位，则精度就是２|
|舍入类型|录入小数点精度的处理方式。系统以下三种方式：１、全部进位：即小数点精度的后一位数字不论是大小，都做进位处理；２、全部舍位：即小数点精度的后一位数字不论是大小，都做舍位处理；３、按值舍入：即按照设置的固定值，只要大于等于该数值，就做进位处理，只要小于该数值，就做舍位处理。|
|舍入值|如果上述“舍入类型”是“按值舍入”时，录入舍入处理的参考数值。例如：精度＝２，舍入类型＝按值舍入，舍入值＝５，则在数量计算时，参考小数点后第３位的数值，如果大于等于５，就进位；如果小于５，则舍去。|

[组间转换率栏目说明](http://wangwq/U9C/help/zh-CN/Content/CBO/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|计量单位组－头|选择一个原计量单位组。例如：长度　－－　重量、体积转换。长度为原计量单位组。|
|计量单位|显示选中的计量单位组中的基准计量单位名称。|
|计量单位组－行|选择转换的目标计量单位组。例如：长度　－－　重量、体积转换。重量、体积就是目标计量单位组。|
|计量单位|显示计量单位组中的基准计量单位名称。|
|转换率|录入两个基准计量单位之间的转换率。|

# 按钮说明

*  <组间转换率>：设置不同计量单位组中的基准计量单位之间的转换率。对于不同计量单位组中其他单位之间的转换，是计量单位通过与基准单位之间的转换实现。
 
   *  操作前提
   
      *  各计量单位组中定义基准单位
   *  操作步骤
   
      *  点击<组间转换率>按钮。
      *  弹出组间转换率设置画面，详见栏目说明－组间转换率。
*  <料品>：导航到[料品](/detail/c073bf1ac1f349569ad5439839776131)档案设置功能节点。
