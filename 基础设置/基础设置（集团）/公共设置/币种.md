
# 功能描述

设置企业经营活动中使用的货币种类。

# 业务规则

*  系统预置了企业在经营活动中经常使用的交易货币，用户可以根据自己企业的实际情况进行调整。
*  舍入类型＝按值舍入，舍入值＝５，则在数量计算时，参考小数点后第３位（精度＝２）的数值，如果大于等于５，就进位；如果小于５，则舍去。
*  货币编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入货币编码。|
|名称|录入币种名称。|
|ISO代码|录入货币在国际货币基金组织中的国际代码。|
|货币符号|录入货币符号。|
|欧元区货币|如果设置的币种是欧元区货币，加注此标识。|
|金额精度|录入货币金额的处理精度。即处理到小数点后第几位。可以改大，不能改小。|
|单价精度|录入货币单价的处理精度。即处理到小数点后第几位。可以改大，不能改小。|
|舍入类型|录入货币金额精度的处理方式。系统以下三种方式：1、 全部入：即小数点后数字不论是大小，都做进位处理；2、 全部舍：即小数点后数字不论是大小，都做舍位处理；3、 按值舍入：即按照设置的固定值，只要大于等于该数值，就做进位处理，只要小于该数值，就做舍位处理。|
|舍入值|如果上述“舍入类型”是“按值舍入”时，录入舍入处理的参考数值。|
|核销允差|设置将当货币做为中间货币，其他任何两种货币核销时，转化为中间货币后，允许的差异范围。允差包括正允差、负允差。例如：当前币种是“人民币”，允许=50，有A、B两种货币进行核销，则A转化为人民币=175；B转化为人民币=185，AB两币种的核销差异=10，在核销的允差范围之内。|
