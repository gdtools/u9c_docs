
# 功能描述

设置用户自定义项目。

Ｕ９将用户自定义项目分为以下两类：

系统定义项目：即系统预置的项目，不能由用户扩展的项目。例如：单据的核销方式，系统提供的核销方式是不允许由用户自由扩展的。在此可以对这些自定义项目进行查询；

用户定义项目：即系统预置了一部分内容，可以由用户在此基础上进行扩展定义。例如：汇率类型，系统预置了“买入”、“卖出”，用户还可以按照市场定义“大陆市场”、“香港市场”等。

# 业务规则

*  系统预制的数据不能修改和删除。

# 栏目说明

[基本栏目](http://wangwq/U9C/help/zh-CN/Content/CBO/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|代码类型|参照系统预置的自定义代码类型录入。|
|是否参照显示R|默认不勾选，即枚举项默认全部为下拉选择勾选后，枚举项显示为参照样式。修改后影响未来|
|编码|录入自定义项目编码。|
|名称|录入自定义项目名称。|
|值|系统判断时使用，用户无需关心，系统自动维护|
|系统预置|如果是系统预置的定义项目，显示系统预置标识。|

# 操作说明

*  通过菜单[自定义代码](/detail/f063b451029e495ca9e9186f65d3de3f)进入界面；
*  操作步骤
 
   *  第1步：选择代码类型。
   *  第2步：添加相关枚举信息。
   *  第3步：保存枚举项。
