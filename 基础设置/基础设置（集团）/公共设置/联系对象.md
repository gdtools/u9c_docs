
# 功能描述

联系对象是关联客户、供应商、组织、员工的重要内容。

如果您的某个客户和供应商设置了相同的联系对象，则说明这个客户即是您的客户又是您的供应商。

如果您的某个客户（或供应商）和某组织设置了相同的联系对象，则说明这个客户（或供应商）是您的内部关系企业。


# 业务规则

*  一个联系对象可以同时加注组织、客户、供应商标识，表示这个联系对象同时具有这三种职能。
*  一个联系对象如果具有上述三个职能之一，就不能再具有“员工”职能。
*  联系对象编码不允许重复。

|员工|如果某联系对象是一个员工，加注此标识。|

|即时消息|如果某联系对象的即时通讯方式是发送即时消息，加注此标识。|
|姓名|录入联系人名。也可以点击字段下划线，弹出姓名录入画面，录入联系人名。具体项目见姓名弹出画面。如果某联系对象类型是“人”，则需要输入。|

|头衔|录入联系人头衔。|
