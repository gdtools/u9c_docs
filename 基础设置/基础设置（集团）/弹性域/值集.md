
# 功能描述

值集，一组数据的集合。值集是构成编码结构、扩展字段的重要基础数据。

设置编码结构和公共扩展字段、实体扩展字段中引用的值集档案。

值集有四种类型：

（１）实体：系统中某个基础档案可以做为值集被引用。例如：部门是基础档案中的一个重要档案，就可以作为一个实体值集；

（２）自定义：用户可以自定义某个档案做为值集被引用。例如：在系统提供的基础档案中没有“销售渠道”这样一个档案，用户为了满足管理要求，就可以将销售渠道作为一个自定义的值集，通过本功能设置此档案，再被客户、供应商等档案的编码结构引用，广泛用于各类查询、统计；

（３）无档案：不需要建立档案进行记录的某类数据，例如：流水号、序号等它们也是一个值集，但不需要设置专门的档案记录；

（４）枚举：即系统提供的各类枚举字段，也可以做为值集应用。

对于不同类型的值集，要求用户输入的主要数据项目不同，用户需要仔细制定值集应用方案后，再在系统中进行设置。

# 业务规则

*  编码不允许重复。
*  各级位长之间用“－”分割输入。　
*  在编码结构中只能引用段值类型为“整数”和“字符”类型的值集。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|值集：设置一个值集的基本说明信息|
|类型|选择值集的类型：（１）实体：对应系统的某个数据实体表。需要设置值集与数据实体的映射关系。（２）无档案：不对应具体的档案信息，但需要设置值集的字段类型和字段最大长度。如果是数值型字段，可以设最大值、最小值。（３）自定义：自定义值集需要设置是否有树型结构，以及树型结构的编码级长。（４）枚举：枚举类型的值集，需要设置值集对应的具体的枚举字段。|
|编码|录入值集的编码。|
|名称|录入值集的名称。|
|树型结构|对于“自定义”类型的值集，设置值集值是否分级设置。例如：销售渠道如果需要分级管理，分为“省级”、“市级”、“地区”等不同级次时，需要设置为树型结构。|
|编码规则|对于树型结构的值集，设置级次结构和每级的数值取值长度。例如：３－２－３，表示值集有３级，每级位长分别为３２３。|
|依赖值集：设置当前值集和其他值集是否存在联动关系。例如：部门和人员两个值集。人员是属于某个部门的，因此，在设置“人员”这个值集时，就需要指定依赖关系，被依赖的值集应当是“部门”。如果某值集和其他值集有联动关系，需要设置以下内容。以下设置可以修改，修改影响未来|
|依赖关系|如果某值集和其他值集有联动关系，加注此标识。|
|依赖值集|如果某值集和其他值集有依赖关系，录入被依赖的值集。参照值集档案录入。|
|约束值集：用于定义多个值集之间的约束，例如：门把手值集的被约束值集分别为锁心、锁方向、门颜色，不同的锁心、锁方向、门颜色决定了可以选择的门把手。如果某值集和其他值集有约束关系，需要设置以下内容。|
|约束关系|如果当前值集和其他值集有约束关系，加注此标识。注意　:本栏目一旦使用，不可修改|
|约束值集1|如果当前值集和其他值集有约束关系，录入约束的值集。参照值集档案录入。注意　:为空时，可以从空改为非空；非空时，若有此值集的约束记录，不允许修改，否则可以修改|
|约束值集２|同上|
|约束值集３|同上|
|段值：如果值集类型是无档案，则需要设置值集的段值类型等信息。|
|段值类型|系统提供以下段值类型：１、整数２、字符３、日期４、数字５、布尔６、日期时间|
|精度|如果段值类型为“数字”，录入数字的取值精度。|
|最小值|如果段值类型为“整数”、“日期”、“数字”、“日期时间”时，输入对应的最小值。|
|最大值|如果段值类型为“整数”、“日期”、“数字”、“日期时间”时，输入对应的最小值。|
|编码最大长度|如果值集类型为“自定义”则根据用户输入树编码规则，系统自动计算并显示编码最大长度。如果值集类型为“无档案”，则根据输入的最大值自动计算长度。|
|应用数据：如果值集类型为“实体”，需要设置以下值集和实体的映射。|
|实体|参照各应用系统的数据实体档案录入。|
|对应编码字段|设置值集的编码字段对应在实体中是哪个字段。一般设置对应到实体的编码字段。|
|对应名称字段|设置值集的名称字段对应在实体中是哪个字段。一般设置对应到实体的名称字段。|
|关联字段|如果某值集设置了依赖关系，还要设置值集的哪个字段和依赖值集进行关联。参照对应实体中的某字段录入。|
|过滤条件|如果值集的取值内容是对应实体中的部分数据时，设置取值的筛选过滤条件。点击功能按钮，弹出过滤条件输入画面，输入过滤条件内容。|
|枚举：如果值集类型为“枚举”时，录入值集对应的枚举项目名称|
|枚举|参照系统提供的枚举项目录入。|
|生效|值集有效期设置|
|生效日期||
|失效日期||

# 按钮说明

*  <编码结构>：导航到[编码结构](/detail/6161a031d4bb4e6d821fc1df90ecf820)设置功能节点。
*  <公共扩展字段>：导航到[公共扩展字段](/detail/dff60c99f17b44659354f5c71dfd5380)设置功能节点。
*  <值集值>：如果值集类型为“实体”，通过本功能画面查询值集对应的实体中的具体数据取值。如果值集类型为“自定义”，通过本功能画面设置值集对应的具体数据值。如果值集类型为“枚举”，通过本功能画面查询具体枚举值名称。

# 操作说明

*  通过菜单[值集](/detail/f5149f275a634656b4b5a3f00d169def)进入该界面；
*  操作步骤
 
   *  第1步：选择类型。
   *  第2步：录入编码、名称等相关信息。
   *  第3步：保存值集。
