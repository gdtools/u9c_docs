
# 功能描述

公共扩展字段是用户自定义的可以在各个应用系统，各个组织、不同单据、不同档案上共同使用的扩展自定义信息。

Ｕ９系统提供用户可以设置３０个这类的公共扩展字段。这些扩展字段对应相应的值集，可以被不同单据、不同基础档案引用。

# 业务规则

*  编码不允许重复。
*  需定义值集档案（必做）。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|段号|系统提供１－３０个公共扩展字段；段号可以手工修改，系统自动按照编号顺序排序。|
|段名称|录入段名称。|
|描述|录入对段的描述性信息。|
|值集|录入段对应的值集。参照值集档案录入。|

# 按钮说明

*  <实体扩展字段>：导航到[实体扩展字段](/detail/8482b046b7d4485881b1313cc0ccada8)档案设置功能节点。

# 操作说明

*  通过菜单[公共扩展字段](/detail/dff60c99f17b44659354f5c71dfd5380)进入该界面；
*  操作步骤
 
   *  第1步：录入段编码、名称等相关信息。
   *  第2步：选择值集。
   *  第3步：保存公共扩展字段。
