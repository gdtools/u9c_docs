
# 功能描述

设置单据、基础档案中需要引用的扩展字段。

实体扩展字段有两类：公共扩展字段、私有扩展字段

公共扩展字段可以在上下游单据间移转；

私有扩展字段不能在上下游单据间自动移转。实体私有扩展字段可以支持上下文相关段，可以通过一个参考字段的取值自动确定上下文，可以根据设置来确定用户能否改变这个上下文。

# 业务规则

*  需定义值集（必做）
*  需定义公共扩展字段（必做）
*  如果用户需要设置交易分录模版头的扩展字段，参照实体必须参照录入总账系统下的凭证实体。否则，交易分录模版无法取到扩展字段内容。
*  如果用户需要设置交易分录模版行的扩展字段，参照实体必须参照录入总账系统下的凭证实体。
*  如果用户需要设置交易分录模版备查项的扩展字段，参照实体必须参照总账系统下的凭证备查实体。
*  总账系统中能够有效设置并使用扩展字段的单据实体只有：凭证、凭证行、凭证备查。这一点请用户在设置总账系统的扩展字段时，务必仔细！

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|实体|录入设置扩展字段的实体。参照系统预置的实体档案录入。|
|上下文相关|如果扩展字段需要使用上下文相关段，加注标识。启用上下文相关段后，可以根据上下文值，处理不同的上下文字段。|
|上下文可改|如果启用了上下段，设置上下文段的段值在具体实体中是否允许修改。|
|上下文相关段数|设置上下文相关的段数。上下文相关段数最多３０段。|
|参考字段|如果将实体中的某个字段做为上下文值的参考字段，参照实体中的字段录入这个参考字段。录入参考字段后，上下文集合中的上下文值应当与参考字段值相吻合。|
|上下文集合页签||
|上下文值|系统默认了两类上下文值类型，针对不同的上下文值，设置不同的扩展字段（１）公共扩展字段：系统默认的一种上下文值。此种类型下，在字段定义页签设置的是公共扩展字段；（２）全局段：系统默认的另一种上下文值。此种类型下，在字段定义页签设置的是全局扩展字段；（３）上下文字段（私有段）：即根据参考字段的字段取值，可以设置不同的上下文相关段。|
|上下文名称|与上下文值对应的上下文名称。|
|默认|设置一个实体中默认的上下文值。|
|字段定义页签||
|公共扩展字段|如果上下文值为“公共扩展字段”，则参照公共扩展字段档案录入当前单据或档案实体中使用哪些公共扩展字段。|
|段序号|如果上下文值为“全局段”或“上下文值（私有段）”，设置对应的具体段的内容。|
|段名称|录入扩展字段的显示名称。|
|段描述|录入扩展字段的说明信息。|
|值集|参照值集档案录入扩展字段对应的值集。|
|段数据源页签|对上下文集合页签中的全局段可定义的取值公式，公共扩展字段或上下文相关字段不可编辑，一般应用在 下游单据弹性域根据上游单据的其他字段生成时|
|来源实体|若全局段的表达式需根据具体来源单据中的数据项进行定义，可在此指定对应的来源单据，指定后才可以在下文表达式画面中引用来源单据的数据项|
|表达式|定义全局段的取值公式，操作参见界面个性化|
|描述||

# 操作说明

*  通过菜单[实体扩展字段](/detail/8482b046b7d4485881b1313cc0ccada8)进入该界面；
*  操作步骤
 
   *  第1步：选择实体。
   *  第2步：录入公共扩展字段、私有扩展字段相关信息。
   *  第3步：保存实体扩展字段。
