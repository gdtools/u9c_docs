
# 功能描述

设置以下基础档案的编码结构。

（１）料品分类编码

（２）料品编码

（３）料品名称

（４）客户分类编码

（５）客户编码

（６）供应商分类编码

（７）供应商编码

（８）科目编码

（９）批号编码

（１０）序列号编码

（１１）地区编码

（１２）库位编码

其中，料品分类、科目、批号、序列号可以设置多个编码规则。画面首先显示编码结构段的列表，用户可以双击焦点行切换到编码结构段设置画面。

# 业务规则

*  编码不允许重复。
*  需定义值集档案（必做）。
*  一个弹性域结构中的段值不能包含分割符；弹性域结构嵌套时，两个弹性域结构分割符不能相同。

# 栏目说明

编码结构列表栏目

|栏目|说明|
|---|---|
|编码结构类型|显示编码结构类型。例如：客户、客户分类、供应商、供应商分类......|
|结构名称|显示结构名称|
|分割符|显示编码结构中各段的分割符号。|
|段１|显示每个编码结构的第一段的名称|
|段２|显示每个编码结构的第二段的名称|
|......|......|
|段２０|显示每个编码结构的第二十段的名称，一个编码结构最多可以设置二十个段。|

编码结构设置栏目

|栏目|说明|
|---|---|
|编码结构定义||
|编码结构类型|由于只有“科目、批号、序列号、料品分类”可以设置多个编码结构，因此，编码结构类型只能选择其中之一。其余档案只有一个编码结构，由系统默认。|
|结构编码|如果有多个编码结构录入结构编码。|
|结构名称|录入结构名称。|
|缺省结构|如果有多个编码结构标识是否是默认结构。|
|分割符|选择编码结构各段之间的分割符号。|
|动态增加|如果编码结构段对应的值集值可以动态增加，加注此标识。|
|交叉校验|如果编码结构各段取值需要进行合法性校验，加注此标识。|
|冻结|只有未冻结的编码结构可以使用。如果需要对编码结构中的设置内容进行调整，必须标识为“冻结”状态。只有在“冻结”状态下，可以进行编码结构的编译处理。|
|编译|如果编码结构编译成功，由系统显示编译标识。只有编译成功的编码结构，后续才能使用。|
|编码结构段定义||
|段编号|显示段号从１－２０个段。|
|名称|录入各段的段名称。|
|值集|参照值集档案录入。|
|动态值集段|如果段所取的值集需要依据相邻的上一段的值集值的不同而定义,请加注此标识。|
|限定|如果是“科目编码”结构，显示科目各段中设置的限定信息。其他编码结构，本字段显示为空。|
|动态值集规则||
|下限组合码|录入所依赖的段值的下限值。|
|上限组合码|录入所依赖的段值的上限值。|
|值集|参照值集档案录入。确定当所依赖的段值在上下限范围内所引用的值集。|


# 按钮说明

*  <实体扩展字段>：导航到[实体扩展字段](/detail/8482b046b7d4485881b1313cc0ccada8)档案设置功能节点。
*  <公共扩展字段>：导航到[公共扩展字段](/detail/dff60c99f17b44659354f5c71dfd5380)档案设置功能节点。
*  <编译>：设置完毕的编码结构必须编译之后，才能被使用。只有编码结构为“冻结”状态“允许执行编译。

# 操作说明

*  通过菜单[编码结构](/detail/6161a031d4bb4e6d821fc1df90ecf820)进入该界面；
*  操作步骤
 
   *  第1步：选择编码结构进入维护界面。
   *  第2步：录入段编号、名称、选择值集信息等相关信息。
   *  第3步：保存编码结构。
