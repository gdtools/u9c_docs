
# 功能描述

定义静态报表（资产负债表、损益表、现金流量表）的项目，用于定义静态报表结构和展现。

只有Excel端，三大报表数据存储为静态数据，portal端才能查询到三大报表。此档案是定义报表项目和在报表中展现位置的。

# 业务规则

*  编码不允许重复。
*  需设置标准科目（必做）

# 栏目说明

表头

|栏目|说明|
|---|---|
|标准科目|选择标准科目|

表体

|栏目|说明|
|---|---|
|所属报表|枚举值：资产负债表、利润表、现金流量表。|
|编码|设置编码，必输。|
|名称|设置名称，必输。|
|报表位置|在所属报表上的显示位置，3位的整数，第一位表示表中的列（资产负债表必须为1、4；其他表必须为1），后面位数表示行号。 必输|
|是否项目分类|必输，默认为否。|
|是否合计行|必输，默认为否。|


# 按钮说明

*  <预置导入>：导入预置报表项目。

# 操作说明

*  通过菜单[报表项目](/detail/ea9048b85d154a319918ed3d04383647)进入该界面；
*  操作步骤
 
   *  第1步：选择科目、报表类型等信息。
   *  第2步：录入编码、名称、行号、列号等相关信息。
   *  第3步：选择是否项目分类、是否合计、项目属性等信息。
   *  第4步：保存报表项目。
