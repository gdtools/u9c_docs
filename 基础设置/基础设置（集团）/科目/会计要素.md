
# 功能描述

维护会计要素。

# 业务规则

*  编码不允许重复。
*  需定义会计要素表（必做）
*  若目标会计要素表已经被标准科目表引用，不能导入； 
*  若系统预置会计要素表的［科目属性编码规则］最大已使用级次与目标会计要素表的编码规则不相似，不能导入。如预置表编码规则4-2-2-2，最大已使用3级，目标表为4-2-3，不能导入；
*  若系统预置会计要素表的［科目属性编码规则］最大已使用级次大于目标会计要素表的［科目属性编码规则］的最大级次，不能导入；
*  若目标会计要素表已经被标准科目表引用，不能复制；
*  若源会计要素表的最大已使用级次与目标会计要素表的编码规则不相似，不能导入。如源表编码规则4-2-2-2，最大已使用3级，目标表为4-2-3，不能复制；
*  若源会计要素表的最大已使用级次大于目标会计要素表的编码规则的最大级次，不能复制；

# 栏目说明

会计要素

|栏目|说明|
|---|---|
|会计要素表|参照会计要素表|
|编码|录入会计要素编码|
|名称|录入会计要素名称|
|方向|枚举值：借方（默认）贷方|
|表外科目|用户选择，新增时，默认：False|
|损益科目|用户选择，新增时，默认：False|

会计要素分类

|栏目|说明|
|---|---|
|编码|录入会计要素分类编码|
|名称|录入会计要素分类名称|


# 按钮说明

*  <导入系统预置>：将系统预置的会计要素表下的会计要素和科目属性导入到当前会计要素表下的会计要素和科目属性中。
*  <复制会计要素表>：选择已经存在的会计要素表(是否系统预置=‘否’)，　　　将其下所有的会计要素和科目属性复制到当前会计要素表下的会计要素和科目属性中。　　

# 操作说明

*  通过菜单[会计要素](/detail/adb75261f3b14b4693c513a267955e92)进入该界面；
*  <导入系统预置>：将系统预置的会计要素表下的会计要素和科目属性导入到当前会计要素表下的会计要素和科目属性中。
 
   *  操作步骤
   
      *  第１步：在会计要素界面，点击操作－导入系统预置按钮，参照出系统预置的会计要素表：
      *  第２步：确定后，会将系统预置的会计要素表下的会计要素和科目属性导入到当前会计要素表下。
*  <复制会计要素表>：选择已经存在的会计要素表(是否系统预置=‘否’)，　　　将其下所有的会计要素和科目属性复制到当前会计要素表下的会计要素和科目属性中。
 
   *  操作步骤
   
      *  第１步：在会计要素界面，点击操作－复制会计要素表按钮，参照出已经存在的会计要素表：
      *  第２步：确定后，会将目标的会计要素表下的会计要素和科目属性导入到当前会计要素表下。
