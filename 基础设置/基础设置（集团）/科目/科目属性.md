
# 功能描述

维护及查询科目属性。

# 业务规则

*  编码不允许重复。
*  需定义会计要素（必做）

# 栏目说明

科目属性

|栏目|说明|
|---|---|
|会计要素表|参照会计要素表|
|会计要素|参照会计要素|
|编码|输入科目属性编码|
|名称　|输入科目属性名称|
|上级|上级科目属性默认为左树中焦点所在的会计要素或科目属性，用户可改；其他情况默认空 ；|
|方向|科目属性方向，新增时：一级科目属性的方向默认取所属会计要素的方向非一级科目属性的方向默认取上级科目属性的方向，用户可改|


# 按钮说明

*  <会计要素>：导航到[会计要素](/detail/adb75261f3b14b4693c513a267955e92)档案设置功能节点。
*  <标准科目>：导航到[标准科目](/detail/35bb5ee74b5743729f9b6b10066be188)档案设置功能节点。

# 操作说明

*  通过菜单[科目属性](/detail/95f66ccafba6453d8ca7999deb674456)进入该界面；
*  操作步骤
 
   *  第1步：点击新增按钮。
   *  第2步：选择会计要素表、会计要素等信息。
   *  第2步：新增节目录入编码、名称等相关信息。
   *  第3步：保存科目属性。
