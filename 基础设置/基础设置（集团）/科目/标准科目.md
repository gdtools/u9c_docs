
# 功能描述

提供标准科目维护。

# 业务规则

*  需建立标准科目表（必做）
*  标准科目表删除：支持未被任何弹性域结构引用的标准科目表可直接删除，同时级联删除标准科目
*  若目标标准科目表已经被SOB引用，不能导入。
*  若目标标准科目表引用的会计要素表已经被除目标标准科目表外的其他标准科目表引用，不能导入。
*  若系统预置标准科目表的最大已使用级次与目标标准科目表的编码规则不相似，不能导入。如预置表编码规则4-2-2-2，最大已使用3级，目标表为4-2-3，不能导入。
*  若系统预置标准科目表的最大已使用级次大于目标标准科目表的编码规则的最大级次，不能导入

# 栏目说明

标准科目

|栏目|说明|
|---|---|
|标准科目表|参照标准科目表|
|编码规则|根据［标准科目表］带出|
|科目编码|用户录入标准科目编码|
|科目名称|用户录入标准科目名称|
|科目属性|一级科目：若从根结点“科目”中新增，默认为空；否则，默认从左树结点中带入，可修改。非末级科目：本字段不可编辑，由上级科目带出。只能选择所属标准科目表引用的会计要素表所属的科目属性|
|余额方向|枚举值：借方余额、贷方余额、双向，由用户选择默认：一级科目的余额方向默认取科目属性的［借贷方向］，非末级科目的余额方向默认取直接上级的［余额方向］，用户可改。|

标准科目表

|栏目|说明|
|---|---|
|编码|标准科目表编码，系统维护|
|名称|录入标准科目名称|
|编码规则|在界面上直接录入科目编码级次；被引用后，不可以修改|
|会计要素表|参照录入会计要素表|

# 按钮说明

*  <复制标准科目表>：选择已经存在的标准科目表，将其所有的标准科目复制到当前标准科目表中，覆盖写入目标标准科目表，若目标标准科目表不能删除，则复制不成功。
*  <复制下级科目>：选择已经存在的标准科目，将焦点行科目的下级复制到其他同级科目中。源标准科目与目标标准科目必须为同一级次；目标标准科目必须已经创建，且必须为末级科目 ；系统为目标科目自动创建与源标准科目结构一致的下级科目。
*  <合并科目>：只有非末级标准科目才能合并其所有下级标准科目。若当前标准科目的所有下级标准科目未生成任何会计科目，不能合并。
*  <拆分科目>：只有末级标准科目才允许被拆分。若拆分标准科目未生成任何会计科目，不能拆分。
*  <导入系统预置>：将系统预置的标准科目表下的标准科目导入到当前标准科目表下的标准科目。同时将系统预置标准科目表引用的会计要素表下的会计要素和科目属性，导入到目标标准科目表引用的会计要素表下的会计要素和科目属性。
*  <显示／隐藏被合并科目>：显示被合并的下级科目

# 操作说明

*  通过菜单[标准科目](/detail/35bb5ee74b5743729f9b6b10066be188)进入该界面；
*  复制标准科目表：选择已经存在的标准科目表，将其所有的标准科目复制到当前标准科目表中，覆盖写入目标标准科目表，若目标标准科目表不能删除，则复制不成功。
 
   *  操作前提
   
      *  已经存在标准科目表．
   *  操作步骤
   
      *  点击操作－>复制标准科目表按钮。具体步骤如下所示。
      *  第1步：参照选择源标准科目表 ；
      *  第2步：系统自动带入当前的＂目的标准科目表＂；
      *  第3步：确定，完成复制标准科目表。
*  复制下级科目：选择已经存在的标准科目，将焦点行科目的下级复制到其他同级科目中。源标准科目与目标标准科目必须为同一级次；目标标准科目必须已经创建，且必须为末级科目 ；系统为目标科目自动创建与源标准科目结构一致的下级科目。
 
   *  操作前提
   
      *  已经存在有下级科目的标准科目。
   *  操作步骤
   
      *  点击操作－>复制下级科目按钮。具体步骤如下所示。
      *  第1步：参照选择源标准科目，必须有下级科目；
      *  第2步：参照选择＂目的标准科目＂；
      *  第3步：确定，完成复制下级科目。
*  合并科目：只有非末级标准科目才能合并其所有下级标准科目。若当前标准科目的所有下级标准科目未生成任何会计科目，不能合并。
 
   *  操作前提
   
      *  已经存在有下级科目的标准科目。
   *  操作步骤
   
      *  点击操作－>合并科目按钮。具体步骤如下所示。
      *  第1步：参照选择源标准科目，必须有下级科目；
      *  第2步：点击“合并科目”；
      *  第3步：确定，完成合并下级科目。
*  拆分科目：只有末级标准科目才允许被拆分。若拆分标准科目未生成任何会计科目，不能拆分。
 
   *  操作前提
   
      *  已经被使用的末级标准科目。
   *  操作步骤
   
      *  点击操作－>拆分科目按钮。具体步骤如下所示。
      *  第1步：参照选择源标准科目，必须为末级；
      *  第2步：点击“拆分科目”，在弹出的画面中录入拆分的科目编码、名称；
      *  第3步：确定，完成拆分科目。
*  导入系统预置：将系统预置的标准科目表下的标准科目导入到当前标准科目表下的标准科目。同时将系统预置标准科目表引用的会计要素表下的会计要素和科目属性，导入到目标标准科目表引用的会计要素表下的会计要素和科目属性。
 
   *  操作步骤
   
      *  点击操作－>导入系统预置按钮。具体步骤如下所示。
      *  第1步：参照选择源标准科目，必须为末级；
      *  第2步：点击“拆分科目”，在弹出的画面中录入拆分的科目编码、名称；
      *  第3步：确定，完成拆分科目。
*  显示／隐藏被合并科目：显示被合并的下级科目
 
   *  操作前提
   
      *  存在被合并的下级科目。
   *  操作步骤
   
      *  点击操作－>显示被合并科目按钮，系统自动显示合并之前的下级科目。
      *  点击操作－>隐藏被合并科目按钮，如果是显示了合并之前的下级科目，点击这个按钮，系统按照合并之后的科目进行显示。
