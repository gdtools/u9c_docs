
# 功能描述

用于查询系统自动生成的条码。

# 业务规则

*  查看生成的条码。
*  针对不使用的条码可以作废。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|产生条码业务对象|产生条码的业务对象。如MO的工序表、MO的备料|
|条码代码|显示完整的条码。|
|段1|显示条码结构中第一个段的内容。|
|段2|显示条码结构中第二个段的内容。|
|...|...|


# 按钮说明

*  <条码主档>：导航到[条码主档](/detail/64cc98cf06f44c53b25768cff5f53606)档案设置功能节点。
*  <作废>：作废条码。　　　　　　　　　　　　　　　　　　　　　　

# 操作说明

*  通过菜单[条码主档](/detail/64cc98cf06f44c53b25768cff5f53606)进入该界面；
 
   *  操作步骤：
   
      *  第1步：点击查找；
      *  第2步：选择条码；
      *  第3步：查看条码信息；
