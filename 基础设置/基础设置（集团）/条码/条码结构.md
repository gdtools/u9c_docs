
# 功能描述

有些企业通过引进条码设备以减少繁杂的单据录入。例如，生产订单确认时，根据其备料子表自动产生条码，存入条码主档；库管员根据备料表进行备料，并打印出条码挂在备料托上，备料齐全后领料，领料员领料时扫描条码，自动产生领料单。又如，生产订单确认时，根据其工序子表产生条码主档，工序转移进行工序申报时，扫工序条码，自动产生工序转移单。

目前产品中支持的条码均为活动条码。 

通过设置条码结构指定条码生成的规则，系统根据条码规则自动生成条码。

# 业务规则

*  规则编号不允许重复。。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入编号。|
|名称|录入名称。|
|条码种类|产生条码的业务对象；如MO工序、MO备料|
|产生条码单据|产生条码的单据，如MO、工序转移单。|
|产生条码的业务对象|为产生条码单据下的业务对象。如MO的工序表、MO的备料。|
|是否有校验码||
|总长度||
|段序号|显示使用了几个段，分别显示每个段的段序号。|
|附加段|如果为附加段，则不参与产生条码代码，只用于记录一些附加信息。|
|段类型|选择每个段的数据来源。系统提供以下段类型：（１）字段值：即选中单据实体中的某个字段将做为条码编码中的字段。（2）固定值：即设置一个常数做为条码中的某段。|
|段值|根据录入的段值类型，录入段的具体取值规则：（１）如果段类型为“字段值”，参照实体中的字段录入具体字段。例如：如果希望根据单据中的“日期”字段进行条码编号，就可以选择“日期”字段做为段值。（ 2 ）如果段类型为“固定值”，则录入一个常量值。建议常量以字母表示。|
|段长度|如果段类型分别为“字段值”，设置字段的取值长度。如果段类型为“固定值”，则根据录入的常量值，系统自动计算段长度。|
|日期格式|如果设置的段值为“日期”，录入日期的处理格式。|
|小数位数|如果段类型为小数，则设置其小数的位数。|
|小数点符号|如果段类型为小数，则设置其小数点的符号。|
