
# 功能描述

将系统中的基础设置、总账、应收应付、固定资产、员工薪酬等信息按照审计署接口要求导出；

# 业务规则

*  起始期间、终止期间不能为空。

# 栏目说明

审计署接口导出－基本栏目

|栏目名称|说明|
|---|---|
|基础设置导出|是否导出基础设置|
|总账导出|是否导出总账|
|应收应付导出|是否导出应收应付|
|固定资产导出|是否导出固定资产|
|员工薪酬导出|是否导出员工薪酬|
|导出年度导出|导出年度|
|起始期间导出|导出的起始期间|
|终止期间导出|导出的终止期间|

# 按钮说明

*  <导出>：导出相关数据。
*  <下载>：弹出下载界面，选择下载相关数据。

# 操作说明

*  通过菜单[审计署接口导出](/detail/4ae8cc54597b4ca1a346e4c3a37994f6)进入该菜单界面；
*  操作步骤
 
   *  第1步：选择导入的数据范围。
   *  第2步：选择导出年度、起始期间、终止期间信息。
   *  第3步：点击导出按钮。
