
# 功能描述

如档案不能下发到目的组织，在目的组织处理业务时，档案的数据可以在任意组织中选择，从而参照到来源组织下的档案数据。通过本功能设置档案参照画面上的默认参照来源组织，比如当前组织如果经常与A组织发生业务往来，则可以将档案的默认参照来源组织设为A。

# 关键应用

# 业务规则

*  档案在下发档案设置中已经置为不下发。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|档案名称|显示档案名称。只有在下发档案设置中设置为不下发的档案才可在此显示。|
|默认参照组织|设置档案参照画面上的默认参照来源组织。比如当前组织如果经常与A组织发生业务往来，则可以将档案的默认参照来源组织设为A。|

# 操作说明

*  通过菜单[默认参照设置](/detail/d0f6d43677bb40a4990c8072c237f8d5)进入默认参照设置界面；
*  操作步骤
 
   *  第1步：选择档案的参照组织。
   *  第2步：点击“保存”，保存默认参照设置。
