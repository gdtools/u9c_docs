
# 功能描述

提供基本档案的批量下发功能,用于将档案下的所有数据批量下发到目的组织。

# 关键应用

# 业务规则

*  档案在下发档案设置中已经置为不下发。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|档案名称|选择下发的档案|
|组织|选择下发的目的组织|

# 按钮说明

*  <下发>：导航到下发功能节点。
*  <取消下发>：导航到取消下发功能节点。
*  <定时调度下发>：导航到定时调度下发参数功能节点。

# 操作说明

*  通过菜单[批量下发](/detail/156d45748c344d358d8213046b5ad386)进入批量下发界面；
*  操作步骤
 
   *  第1步：选择档案。
   *  第2步：点击“下发”，将选择的档案下的所有数据批量下发到目的组织。
