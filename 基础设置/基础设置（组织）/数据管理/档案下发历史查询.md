
# 功能描述

按照指定方式查询基础档案下发历史的明细情况。

# 关键应用

# 业务规则

*  已下发的基础档案

# 栏目说明

查询条件：系统在查询方案中提供默认的统计条件，

1. 查询条件可以自定义（通过属性选取设置），档案下发去向表的每一个字段都可以作为查询条件；
2. 另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

查询结果：不同的查询方式、查询条件决定了查询结果的不同。用户可根据需要任意组织查询条件和要显示的栏目。

# 操作说明

*  通过菜单[档案下发历史查询](/detail/c8b4c3510af743978b3e85d2da4816c8)进入档案下发历史查询界面；
*  操作步骤
 
   *  第1步：点击“查询”。
   *  第2步：录入查询条件。
   *  第3步：点击“保存”，保存档案下发历史查询。
