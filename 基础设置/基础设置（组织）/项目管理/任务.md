
# 功能描述

建立了“项目”以后，为了更好地执行项目，针对于项目做的进一步分解工作，即形成了若干条的“任务”。这个的任务分解工作，只能够针对在“基础设置－财务数据”中定义“项目”。

用户在“项目制造”模块中建立的项目，是不能在此处进行任务分解的。用户可以对其在“项目制造”模块中，对其进行详细的分解，定义产出、设置逻辑关系、并进行排程。这些工作在此处都是无法执行的。当用户在“项目制造”模块中对项目、任务进行“发布”以后，这些任务会自动在此处生成。

关于“任务分解”理论上的一些深度详细介绍，参考“项目制造”模块中的说明。

# 业务规则

*  编码不能重复。
*  需在“基础设置－财务数据”中定义“项目”（必做）。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|基本||
|项目|用户在这里录入项目编码。在这里，只能选择用户在“基础设置－财务数据”中定义的“项目”。|
|编码|录入任务的编码。|
|名称|录入任务的名称。|
|描述|录入任务的说明信息|
|层次|这个信息来源于“项目制造”模块的“任务分解”的，当用户进行项目和任务的“发布”操作时，此信息会自动生成（或自动更新）。如果，用户是在此界面中直接新增“项目”的，这个信息是无法录入的。此外，在此界面中，其他的信息，例如：来源、序号、执行组织、部门、任务经理、任务经理名称、任务地址、进度、里程碑、关键任务、终止人、终止日期、挂起原因、解除原因、进度、生效日期、失效日期、删除标识、等方面的信息也都是从“项目制造”模块传递过来的。关于这些内容的解释请参考“项目制造”模块中的说明。|
|计划日期||
|从日期|来源于任务分解中的计划开始日期；新增任务时可以手工录入计划开始日期|
|到日期|来源于任务分解中的计划完成日期；新增任务时可以手工录入计划完成日期|
|工期（天）|来源于任务分解中的计划工期；新增任务可根据录入的计划开始完成日期自动计算工期|
|实际日期||
|从日期|来源于任务分解中的实际开始日期|
|到日期|来源于任务分解中的实际结束日期|
|工期（天）|来源于任务分解中的实际时间工期；只有进度为100%时此字段才会回写|
