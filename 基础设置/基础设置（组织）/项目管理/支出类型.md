
# 功能描述

成本分解结构对项目执行过程中发生的成本按其所属的不同阶段或不同的管理目的，可以划分为不同类型，就是成本分解结构的支出类型。

项目支出类型可以按树状结构组织，可以定义任意多层项目支出类型，末级项目支出类型下可以挂“项目成本项”。末级支出类型与任务相关，不同的任务可以挂不同的末级支出类型，也可以挂相同的末级支出类型。因为有些费用不能分配到任务，而只能分配到项目上，所以项目上也可以挂末级支出类型。

项目支出类型是项目成本的管理分类依据，是成本分解结构的主干支撑。

操作说明：本功能画面左边是一颗支出类型树行结构，首层节点为“成本分解结构”，可使用“新增子节点”增加支出类型节点节点。

# 栏目说明

支出类型

|栏目|说明|
|---|---|
|成本分解结构|选择一个“成本分解结构”，为其定义支出类型结构。|
|编码|“支出类型”的档案编码。|
|名称|“支出类型”的档案名称。|
|描述|描述信息。|
|父节点|显示当前支出类型的父节点，若是首层支出类型，则父节点为空；不可编辑。|
|末级支出类型|标识本支出类型是否末级节点，只有末级节点才能挂项目成本项。|
|生效|标识此档案是否生效。|
|生效日期|生效的起始日期。|
|失效日期|生效的截止日期。|

项目成本项

末级支出类型可以定义使用全部项目成本项还是使用指定的部分项目成本项；不指定项目成本项则代表可以使用全部项目成本项。

# 按钮说明

*  <新增子节点>：可使用“新增子节点”增加支出类型节点节点。

# 操作说明

*  通过菜单[支出类型](/detail/05f915503f52437cbaff1d03dc12acab)进入支出类型界面；
*  操作步骤
 
   *  第1步：录入成本分解结构等相关信息。
   *  第2步：录入编码。
   *  第3步：保存支出类型。
