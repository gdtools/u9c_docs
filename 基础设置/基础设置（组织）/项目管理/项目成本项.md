
# 功能描述

有一些费用在各个支出类型下都会出现，如材料费，人工费，因此可以把这部分共同的费用抽象出来，称为项目成本项。项目成本项可以挂在末级项目支出类型下，作为项目成本组成的明细信息。

# 关键应用

# 业务规则

*  编码不能重复。

# 栏目说明

项目成本项

|栏目|说明|
|---|---|
|编码|“项目成本项”的档案编码。|
|名称|“项目成本项”的档案名称。|
|描述|描述信息。|
|费用属性|枚举值 包含（变动生产支出，固定生产支出，其他生产支出，间接支出）|
|生效|标识此档案是否生效。|
|生效日期|生效的起始日期。|
|失效日期|生效的截止日期。|

# 按钮说明

*  <下发>：可通过此功能将此当前档案下发到其他关联组织。
*  <取消下发>：若当前档案已经下发到其他关联组织,可通过此功能将关联组织的通过下发产生的档案删除。
*  <下发参数>：可通过此功能定义下发参数，如是否可改等。

# 操作说明

*  通过菜单[项目成本项](/detail/1dc3a6e2d6b6438cbebd6e34c200638f)进入项目成本项界面；
*  操作步骤
 
   *  第1步：录入编码等相关信息。
   *  第2步：选择费用构成。
   *  第3步：选择存货成本分项。
   *  第4步：保存项目。
