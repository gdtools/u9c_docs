
# 功能描述

成本分解结构（Cost Breakdown Structure，即CBS）是从成本管理的视角，按某种方法（如成本的经济用途）对项目进行分类，同时各分类都可以向下分解成任意的明细成本或费用类型。

# 关键应用

# 业务规则

*  编码不能重复。

# 栏目说明

成本分解结构

|栏目|说明|
|---|---|
|编码|“成本分解结构”的档案编码。|
|名称|“成本分解结构”的档案名称。|
|描述|描述信息。|
|生效|标识此档案是否生效。|
|生效日期|生效的起始日期。|
|失效日期|生效的截止日期。|
