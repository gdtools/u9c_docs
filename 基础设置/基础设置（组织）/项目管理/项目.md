
# 功能描述

“项目”的国际标准定义是“为创造独特的产品、服务或成果而进行的一次性工作”。项目最大的特点也就是：唯一性、一次性和渐进明晰。

在企业的管理过程中，很多业务都是可以被看成是“项目”，为了更好地对项目进行跟踪、分析和管理。U9cloud系统将“项目”以及项目的“任务”作为重要基础数据，生产制造、供应链、财务系统的业务处理中很多单据都要使用此信息。

在U9cloud系统中，用户可以通过两个途径来新增“项目”。

其一，就是在此处，“财务数据”里面进行新增。这是一种快速新增项目的情景，用户在这里新增的项目，是不能在“项目制造”模块里显示的。此项目信息，可以被财务、供应链、生产制造的系统被引用。

其二，是在“项目制造”模块中，“项目计划控制－项目工作台－项目主档”的界面里进行新增。用户在“项目主档”中，也可以建立、录入项目的信息，其信息量要比这个界面中的信息要丰富；当项目被“审核”后，其主要信息会自动在此处“财务数据”中生成。

这里讲一下，单独在“财务数据”中新增项目，与在“项目制造”模块中新增项目的区别。在“财务数据”中新增的项目，以及“任务”，是不能定义其“产出”的。“任务”之间也不能设置逻辑关系、进行“排程”的。也因此，是不能进行ＰＲＰ运算的。

由此，可以看出。如果用户的业务环境是一些小项目，周期短，任务少，比较容易控制，可以在此处建立。如果，用户面对的是一些复杂的项目、大项目，希望能够对项目的进度、成本进行有效的控制和管理，希望能够及时管理、事中管理，就需要在“项目制造”模块中建立。

# 业务规则

*  项目编码不能重复。
*  需在自定义代码功能中定义项目分类（不必做）。
*  项目编码不允许重复。
*  这里“项目分类”中所包含的信息也是在“项目制造”模块里定义。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|项目名称|录入项目名称。|
|描述|录入项目的说明信息|
|版本|这个信息来源于“项目制造”模块的“项目主档”的版本，当用户进行项目的“发布”操作时，此信息会自动生成（或自动更新）；如果，用户是在此界面中直接新增“项目”的，这个信息是无法录入的。此外，在此界面中，其他的信息，例如：来源、成本组织、工作日历、项目地址、币种、汇率类型、项目状态、是否终止、终止人员、终止日期、关闭人、关闭日期、挂起原因、解除原因、完成百分比、实际日期等方面的信息也都是从“项目制造”模块传递过来的。关于这些内容的解释请参考“项目制造”模块中的说明。|
|项目分类|用户在此选择项目的分类信息。|
|负责部门|此项目的负责部门。|
|项目经理|用户在此处选择此项目的项目经理。系统自动在下面一栏中显示项目经理的名称。|
|计划日期|用户可以在这里，录入项目的计划开始日期、计划完成日期，系统会自动计算出项目|
|实际日期|来源项目主档的实际开始日期、实际结束日期和实际工期|

# 按钮说明

*  <下发>：执行对项目的下发,由本组织下发到目的组织。
*  <取消下发>：取消当前项目对某组织的下发处理,即在目的组织删除已经下发的项目记录。
*  <下发参数>：项目的下发参数设置:对于下发字段在目的组织中是否允许修改，以实现数据的集中统一管理
*  <部门>：导航到[部门](/detail/fffd959d9f19411e89e79315cf33eef2)档案设置功能节点。
*  <业务员>：导航到[业务员](/detail/efb2e2b4d2e0459ebcd41054a3c9e3dd)档案设置功能节点。
*  <审批参数>：弹出审批参数设置画面。

# 操作说明

*  通过菜单[项目](/detail/1294ce2ac74747028eb175181ecc0828)进入项目界面；
*  操作步骤
 
   *  第1步：录入项目编码等相关信息。
   *  第2步：录入项目名称。
   *  第3步：保存项目。
