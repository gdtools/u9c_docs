
# 功能描述

包主档记录料品的包信息，包括料品各维度信息和包号等信息，一个包编号对应一个包主档。

# 关键应用

# 业务规则

*  只能查询，不能新增、修改或删除数据，包主档的数据是通过成品入库的“按料品默认包装方案打包”功能自动生成的。

# 栏目说明

|栏目|说明|
|---|---|
|料号|料号|
|品名|品名|
|规格|规格|
|包编码|包的编码|
|包名称|包的名称|
|描述|包的描述|
|每单位包数|单位料品共有几个包|
|计量单位|指包的计量单位，如包按件计量，那么计量单位就是“件”|
|长|包的长度|
|宽|包的宽度|
|高|包的高度|
|尺寸单位|包的尺寸单位|
|体积|包的体积|
|体积单位|包的体积单位|
|毛重|包的毛重|
|净重|包的净重|
|重量单位|包的重量单位|
|条码|包的条码|
|打包单据类别|哪个业务单据做的打包操作|
|打包来源单据信息|打包单据的单据号、行号等信息|
|创建主档的单据信息|创建包主档的单据信息。目前打包和创建包主档的业务单据都是成品入库单|

# 操作说明

*  操作步骤
