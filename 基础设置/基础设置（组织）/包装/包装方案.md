
# 功能描述

包装方案记录料品如何包装。一个料品可以定义多个包装方案。

# 关键应用

# 业务规则

*  包装方案编码不能为空，不能重复。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|包装方案的编码|
|名称|包装方案的名称|
|描述|包装方案的描述|
|料品|指定义的是哪个料品的包装方案|
|规格|料品的规格|
|数量|料品的数量（默认=1，即表示定义的是单位料品如何包装）|
|库存单位|料品的库存单位|
|每单位包数|指包装方案中共有多少包，系统根据包装方案中定义的包数汇总。|

料品属性页签

设置包可以唯一标识料品的哪些属性，勾选就表示知道包号后就可以确定其对应的属性值。

例如：料品按批号管理并且料品属性中勾选了“批号”，那么相同批号的料品包号相同，知道包号后就可以确定料品的批号。

例如：料品按序列号管理并且料品属性中勾选了“序列号”，那么每个序列号的料品包号都不同，知道包号就可以确定料品的序列号。

可选属性包括：版本、等级、成分、厂牌、项目、番号、批号、序列号。（料号是必选属性，不可改。）

单行包页签

|栏目|说明|
|---|---|
|包编码|包的编码|
|包名称|包的名称|
|每单位包数|单位料品共有几个包|
|计量单位|指包的计量单位，如包按件计量，那么计量单位就是“件”|
|长|包的长度|
|宽|包的宽度|
|高|包的高度|
|尺寸单位|包的尺寸单位|
|体积|包的体积|
|体积单位|包的体积单位|
|毛重|包的毛重|
|净重|包的净重|
|重量单位|包的重量单位|
|自动编号|勾选时表示包需要自动编号|
|编号规则|如果包只定义了一条编号规则，那么在这个字段中显示编号规则，否则在弹出的包编号规则画面显示。|

包编号规则画面

|栏目|说明|
|---|---|
|行号|系统自动生成|
|编号规则|包的编号规则，从已经设置好的包装编号规则中选取|
|编号实体|指根据哪个实体对包进行自动编号。仅支持生产入库单。|
|编号中包含流水号|指编号规则中是否包括流水号。=true，包含流水号=false，不包括流水号,比如定义编号规则是生产入库单的单据日期+料品批号+包编号,那么这个编号规则就不包括流水号。|

# 按钮说明

*  <设置为料品默认包装方案>：将当前的包装方案设置为料品档案的默认包装方案。
*  <包编号规则>：维护包的编号规则。
*  <审批参数>：支持“即时确认”和“确认作业”两种方式，不支持审批流程。

# 操作说明

*  通过菜单[包装方案](/detail/560a06a84bb946f995dc65095f1e51bd)进入包装方案界面；
*  操作步骤
 
   *  第1步：录入基本信息。
   *  第2步：录入包信息。
   *  第3步：点击“保存”，保存包装方案。
