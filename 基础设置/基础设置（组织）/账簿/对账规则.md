
# 功能描述

产品提供总帐与业务系统对账功能，对账规则主要用于设置总帐科目的查询条件和相匹配的业务系统的查询条件。

对账规则保存后可以再各业务系统查询总帐与业务系统对账时参照选择到。各业务系统参照对账规则时会根据业务系统过滤。比如库存模块总帐与业务系统对账只可参照到对账系统为存货核算的对账规则。

# 关键应用

# 业务规则

*  对账规则编码不允许重复。

# 栏目说明

对账规则－基本页签

|栏目|说明|
|---|---|
|编码|手工录入；|
|名称|手工录入；|


对账规则－对账系统

|栏目|说明|
|---|---|
|对账业务系统|支持固定资产、存货核算、成本会计、应收管理、应付管理；选择对账业务后可以编辑相应对账业务系统的业务数据的查询条件；每个对账规则只可定义一个对账系统且一个对账业务类型的张表匹配条件；|
|对账业务类型|依据对账业务系统过滤；代表预设科目；主要支持：固定资产、存货、生产成本、应收管理、应付管理。|

对账规则－对账数据类型

|栏目|说明|
|---|---|
|余额|如果勾选，业务系统计算差异时显示差异；|
|借方发生额|如果勾选，业务系统计算差异时显示差异；|
|贷方发生额|如果勾选，业务系统计算差异时显示差异；|

对账规则－对账内容

|栏目|说明|
|---|---|
|原币|如果勾选，报表显示原币信息；|
|本币|如果勾选，报表显示本币信息；|
|对账币种|对原币业务过滤有效；|


对账规则－总帐过滤条件

|栏目|说明|
|---|---|

# 操作说明

*  通过菜单[对账规则](/detail/5827c31fc43a47b8985374e9dc4926cb)进入对账规则界面；
*  操作步骤
 
   *  第1步：录入对账规则编码等相关信息。
   *  第2步：选择对账业务系统和对账业务的类型。
   *  第3步：保存对账规则。
