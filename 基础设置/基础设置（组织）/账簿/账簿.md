
# 功能描述

用于对会计主体及会计主体的下属组织的经济业务进行会计上反映的实体，在一个账簿中要指定该账簿所使用的会计科目结构、本位币和会计日历。

账簿是Ｕ９系统重要的基础数据。在用户设置账簿档案之前请务必仔细阅读、掌握《Ｕ９应用特征－多账簿》部分的说明内容。

# 关键应用

# 业务规则

*  编码不允许重复。
*  定义组织机构（必做）。
*  定义会计日历档案（必做）。
*  定义科目编码结构（必做）。
*  定义币种 （必做）。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|账簿基本信息||
|组织职能|选择当前登录组织的组织职能。系统可以根据组织的不同职能设置不同的账簿。１、法人组织可以设置：主账簿、内账、报告账簿；只有法人组织可以设置“主账簿”，其他组织职能的主账簿是通过组织间的“＊＊－法人”的业务关系系统可以自动找到对应的法人组织的主账簿。２、工厂组织、资产组织、人事组织可以设置“多币种账簿”，其主账簿是通过“工厂－法人”或“资产－法人”系统自动找到对应的主账簿；３、营运组织、物流组织、核算组织只有主账簿，也是通过“营运－法人”、“物流－法人”、“核算－法人”的组织间业务关系找到对应的法人组织的主账簿。因此，这些类型的组织不需要再设置其账簿档案。|
|编码|录入账簿编码。|
|名称|录入账簿名称。|
|类型|选择账簿类型。|
||不同的组织职能可以设置不同类型的账簿。|
|描述|录入对账簿的说明信息。|
|会计要素||
|会计准则|录入账簿遵循的会计准则。参照会计准则档案录入。|
|会计日历|录入账簿使用的会计日历。参照会计日历档案录入。|
||由于每个账簿需要根据会计日历生成各自的会计期间数据，因此，用户在选择会计日历时，务必谨慎。|
|本币|录入账簿使用的本位币。参照币种档案录入。|
|默认汇率类型|录入账簿中记录的各类经济业务的不同交易币种与本位币进行转换时，使用的默认的汇率类型。选择汇率类型自定义项目录入。|
|科目编码结构|录入账簿进行会计核算时，使用的会计科目的编码结构。|
||１、Ｕ９系统的会计科目，可以采用不同的编码结构方式，形成多套科目体系。２、不同的账簿可以使用不同的科目体系。例如：主账簿可以使用大陆的会计科目体系，而报告账簿可以使用香港的会计科目体系，分别满足基本会计核算和报账、并账的要求。|
|启用公司间平衡段|标识会计科目编码结构中是否将“科目段”以前设置的各段做为平衡段使用。关于平衡段，请参见《会计科目编码结构－平衡段》说明。如果启用科目平衡段则加注此标识。|
||此标识只有在某会计科目编码结构在第一次被引用时，可以设置。以后其他账簿再引用相同的科目编码结构时，将不允许再修改此参数。即如果某科目编码结构在第一次被账簿Ａ引用时，标识了“启用公司间平衡段”，则以后再有账簿引用相同的编码结构时，一定也是启用公司间平衡段的。反之，如果第一次没有启用，则以后各引用账簿也不允许再启用平衡段。|

状态

|栏目|说明|
|---|---|

|失效时间|生效结束时间|

版本

|栏目|说明|
|---|---|

账簿参数栏目说明

|栏目|说明|
|---|---|
|科目编码显示方式|1、显示全科目末级编码； 2、显示非0段末级编码。|
|科目名称显示方式|1、显示全科目末级名称；2、显示全科目首末级名称；3、显示全科目全部级名称；4、显示非0段末级名称；5、显示非0段首末级名称；6、显示非0段全部级名称；7、自定义。|
|科目弹性域段号|当科目名称显示方式为"7、自定义"时可以设置每个段的名称显示方式。此处引用科目编码结构段号|
|名称显示方式|当科目名称显示方式为"7、自定义"时可以设置每个段的名称显示方式。1、显示末级名称；2、显示首末级名称；3、显示全部级次名称。|
|0段是否显示|当科目名称显示方式为"7、自定义"时可以设置每个段的名称显示方式。用于设置为“0”的段是否显示。|

账簿打印规则栏目说明

|栏目|说明|
|---|---|
|编码|用户录入，不得为空|
|名称|用户录入|
|账簿|选择账簿|
|账簿版本|选择账簿版本|
|科目弹性域段|引用所选账簿的科目弹性域段|
|编码打印方式|选择段编码的打印方式|
|名称打印方式|选择段名称的打印方式|
|是够打印0段|段为空是否打印|

# 按钮说明

*  <账簿参数>：按账簿中定义的参数[科目编码显示方式]，[科目名称显示方式]显示首末级，交易分录行、凭证上的科目均按此显示。参见账簿参数栏目说明。
*  <账簿会计日历>：导航到[账簿会计日历](/detail/c9af2659854244a4a426f96d5d414729)档案设置功能节点。
*  <账簿科目>：导航到[会计科目规则](/detail/69a26d21ed7b4918a7bb984d2d3f46fd)档案设置功能节点。
*  <会计科目>：导航到[会计科目](/detail/124bab1cc4ca4a97895b749e58a107f3)档案设置功能节点。。
*  <版本启用>：当公共参数“允许账簿启用版本管理”=true时，启用版本管理才可用。
*  <版本变更>：当要生成新的账簿版本时候点击该按钮，前提是版本管理已经启用。


# 操作说明

*  通过菜单[账龄区间](/detail/3867923adf334821b48cda23c6742556)进入账龄区间界面；
*  操作步骤
 
   *  第1步：选择组织职能。
   *  第2步：录入编码、名称、类型等信息。
   *  第3步：选择会计要素等信息。
   *  第4步：保存账簿。
