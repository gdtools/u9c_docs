
# 功能描述

用于全球合并系统内部交易自动抵消。

# 关键应用

# 业务规则

*  定义账簿

# 栏目说明

关系企业匹配规则

|栏目|说明|
|---|---|
|转出账簿|参照账簿选择；可以选择主账簿、报告账簿、内帐及合并账簿作为转出账簿；|
|开始会计科目|参照转出账簿的账簿会计科目录入；|
|结束会计科目|参照转出账簿的账簿会计科目录入；|
|关系企业|参照组织档录入；|

# 操作说明

*  通过菜单[关系企业匹配规则](/detail/29e8ee12792f4acd9af707fb241c35d3)进关系企业匹配规则界面；
*  操作步骤
 
   *  第1步：选择转出账簿；
   *  第2步：选择开始会计科目、结束会计科目、关联企业；
   *  第3步：保存关系企业匹配规则。
