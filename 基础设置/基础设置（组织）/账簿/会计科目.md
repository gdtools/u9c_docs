
# 功能描述

会计科目维护，初始进入为列表界面，点击新增或双击一行进入维护界面。

# 关键应用

# 业务规则

*  编码不能重复。
*  建立账簿。
*  已生成会计科目。
*  要求科目弹性域引用的值集值中， 编码不能使用0 ，名称中不能使用科目编码结构中使用的分割符。

# 按钮说明

*  <汇总科目>：若当前账簿的科目弹性域是全局段结构，置灰不可用；若当前账簿的科目弹性域不是全局段结构，但除科目段外的所有段的值集的［是否有层次］为‘否’，置灰不可用。只有当账簿引用的科目编码结构的有效段数>1时需要设置此模版。
*  <批量维护>：选择多个会计科目后，批量维护会计科目的属性；可以批量维护会计科目的“基本信息”、“备查簿”、“核算币种”、“授控系统”。需要选择多个会计科目。
*  <同步科目名称>：选择多个会计科目后，点击“同步科目名称”，在弹出的界面中操作科目名称同步；这个功能主要是针对科目弹性域引用的值集值的名称发生了变化，且已经形成了会计科目。那么会计科目的名称不会因为值集值名称的变化而变化。提供了同步会计科目名称的功能，就能保证会计科目名称的变化与值集值一致。

# 操作说明

*  通过菜单[会计科目](/detail/124bab1cc4ca4a97895b749e58a107f3)进入会计科目界面；
*  操作步骤
 
   *  第1步：选择账簿。
   *  第2步：新增会计科目。
   *  第3步：录入编码等相关信息。
   *  第4步：保存账簿会计科目。
