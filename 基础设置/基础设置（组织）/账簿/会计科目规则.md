
# 功能描述

维护账簿科目．

维护科目的段可使用规则:在账簿科目中可以设置科目段的那些段可以使用，那些段必输，而且有级次的值集还可以指定在录入的时候是否必须为末级.如果是核销科目,在段可使用规则中还需要维护某个普通段是否为核销依据.如果指定为核销依据,则科目核销时,必须按照科目+核销依据段进行核销；

在账簿科目上,可以指定指定该科目是否为核销科目,而且可以指定科目核销的启用期间;

科目段弹性域结构进行调整后,可以在"辅助核算"页签查询调整之前的段可使用规则;

在账簿科目中可以设置科目的备查规则,可以设置备查是否必输,是否可以作为核销依据;

|计量单位|［数量核算］为是时，有效且非空，否则不可用参照：计量单位卡片界面增加下级科目时，自动携带到下级科目的本属性值，可改非末级和末级科目都可以任意修改系统按末级科目控制|

|现金类科目|用户选择默认值：否增加下级科目时，自动携带到下级科目的本属性值，可改非末级和末级科目都可以任意修改系统按末级科目控制如果需要登记现金银行模块的现金日记账，且当前科目是现金类的科目，此标志为Ｔ其他控制见“现金及现金等价物”项目描述|

|分析主表项目|系统维护选择现金及现金等价物＼现金类科目＼银行类科目，则系统默认分析主表项目，附表项目可选。|
|分析附表项目|用户手工维护根据业务需要定义科目是否进行现金流量附表项目分析。|
|余额控制|用户选择默认值：否［余额方向］=‘双向’时，固定为否，不可修改增加下级科目时，自动携带到下级科目的本属性值，可改非末级和末级科目都可以任意修改|
|余额控制方式|［余额控制］=‘是’时，有效下拉框：控制(默认)、不控制增加下级科目时，自动携带到下级科目的本属性值，可改非末级和末级科目都可以任意修改|

|预算执行方式|下拉框：借增、贷增、借增贷减、贷增借减系统按科目性质预置默认值，可改增加下级科目时，自动携带到下级科目的本属性值，可改非末级和末级科目都可以任意修改系统按末级科目控制|
|核销对象|手工指定该科目是否为核销科目|
|核销启用期间|指定什么时候开始做科目的核销．必须大于等于总账的账簿启用期间|
|启用|系统维护该标志．仅显示不可修改．注：在科目期初未达节点，通过平衡检查后，可以进行启用的操作．|
|汇总打印科目|参照输入只有末级标准科目可以修改该属性若为其增加了下级科目，则保存下级科目时，清空本科目的该栏目值|

辅助核算页签

|栏目|说明|
|---|---|
|账簿会计期间|科目调整弹性域结构后，形成新的段可使用规则，通过下拉菜单可以查看之前期间的段可使用规则|
|平衡段名称|非空 显示平衡段名称参照对应的值集值录入。参照值集值时：若有明确定义的平衡体，必须参照该平衡体的辅助核算； 未明确定义的平衡体，系统自动参照“其他”；增加下级科目时，自动携带到下级科目的本属性值，可改非末级和末级科目都可以任意修改系统按末级科目控制没有设置的平衡段不显示该列|
|普通段名称|用户选择 默认：False没有设置的普通段不显示该列|
|普通段是否可用|针对普通段进行定义。“是”，表明会计科目录入的时候可以选择该普通段的内容进行录入；“否”，表明会计科目录入的时候不能选择该普通段的内容进行录入，系统置为０；默认“否”|
|普通段是否必输|针对普通段进行定义。如果段可使用，系统自动置为必输，用户可编辑。“是”，表明会计科目录入的时候该普通段一定录入，否则系统提示；“否”，表明会计科目录入的时候该普通段可以不录入|
|普通段是否末级|针对普通段进行定义。“是”，会计科目进行录入的时候该普通段只能录入末级；“否”，会计科目进行录入的时候该普通段可以录入非末级|
|普通段是否核销依据段|如果该科目为核销科目，可以指定某段是否为核销依据段．如果是核销依据段，科目核销时必须按照核销依据段进行核销．|

# 按钮说明

*  <账簿科目复制>：按账簿进行科目复制
*  <同步会计科目（卡片画面）>：在卡片画面进行的操作；批量维护当前账簿科目对应的所有会计科目的属性与当前账簿科目一致．
*  <批量维护（列表界面）>：在列表画面进行的操作；选择多个账簿科目后，可以同步维护多个账簿的辅助核算内容；无论选择的账簿科目已经存在的辅助核算是什么，如果进行批量维护辅助核算的操作，始终保持与批量维护画面的辅助核算内容一致；
