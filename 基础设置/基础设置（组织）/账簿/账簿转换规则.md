
# 功能描述

通过账簿转换功能可以实现在不同账簿间业务数据的传递和转换满足如下业务应用：

业务系统单据的多币种分录转至总账的报告账簿；

集团合并母子公司账簿；

转换报告币种满足海外上市公司的发布报告或海外集团合并账簿的需要；

特殊的要求需要把某些数据统一到一个特定的账簿的需要；

V2.0版本所做的修改

放开了组织的限制。只要转入或者转出组织为当前法人组织的账簿转换规则都可以设置；可以执行包含当前组织的账簿转换规则，不论是转入组织还是转出组织；但是只能是创建组织对账簿转换规则进行修改。

放开了对于账簿转换的账簿类型的限定。当设置组织内的转换时，可以从主账簿、报告账簿、内账转换到内账、报告账簿。不是组织内的转换时，不受账簿的限制。

转换时，可以设置查询方案，在查询方案中可以设置不同的过滤条件限定转出凭证的范围。

一个账簿转换规则可以设置多套转出凭证方案，在执行长不转换的时候可以指定本次按照那个方案执行转换。

# 关键应用

# 业务规则

*  编码不能重复
*  定义账簿(必做)
*  设置账簿总账参数(必做)
*  设置账簿凭证类型(必做)

# 栏目说明

基本页签

账簿转换规则

|栏目|说明|
|---|---|
|汇率类型|转出账簿与转入账簿的本位币币种相同时为空，否则非空。根据此汇率类型和对应的汇率将转出账簿的原币金额折算为转入账簿的本币金额。若转入账簿凭证分录会计科目未设置对应的转出账簿凭证的分录币种，注意下面两种情况：若转出凭证分录币种为转出账簿的本位币币种，则将转出账簿的凭证分录币种(转出账簿本位币币种)转换为转入账簿的本位币币种。如固定资产以历史成本计价，一般情况下，以外币购入的固定资产入账时，以购入时的汇率将购入金额直接折算为本位币金额作为固定资产的初始价值。但有些会计科目并非如此，如债权、债务会计科目需要核算原币的原始金额，需要期末调汇处理。因此，在执行账簿转换前，请仔细检查转入会计科目是否设置了必要的核算币种。若转出凭证分录币种不是转出账簿的本位币币种，则转换不会成功。|
|转出账簿|非空。|
|转入账簿|非空。不能与转出sob相同，转出sob+转入sob的组合必须唯一|
|触发方式|手工：手工执行转换自动：转出账簿凭证记账时，自动转换。如果触发方式为自动，必须指定转出凭证方案。如果不指定，就默认转出账簿的所有凭证。此方式仅为总账启用的账簿有效。|
|自动记账|选择此选项，转入账簿凭证生成时自动记账。此方式仅为总账启用的账簿有效。|
|转入原币|可以选择转出原币、转出本币|
|转入本币|可以选择转出本币、重新计算|
|币种不存在处理方式|币种不存在有两种处理方式：报错或者转出币种折算后转本币|

会计期间映射规则页签

|栏目|说明|
|---|---|
|转出会计期间|系统自动列出转出账簿的所有会计期间。|
|转入会计期间|为转出会计期间映射对应的转入会计期间。系统根据期间类别自动给出默认值，转出账簿的调整期对应的转入会计期间默认与转出账簿调整期的前一普通会计期间相同。如转出账簿会计期间01默认映射为转入账簿会计期间01，则转出账簿调整期01A默认映射为转入账簿会计期间01。用户可改。|

如果转换双方帐簿的本位币不相等，不存在转入本币=转出本币的情况，在帐簿转换规则保存的时候进行校验。

科目映射规则页签

|栏目|说明|
|---|---|
|转入科目|转入账簿的会计科目，参照会计科目录入。若存在转出/转入会计科目映射，则以此优先。否则根据段映射规则确定转入科目。|
|转出科目起始|转出账簿的会计科目，参照会计科目录入。|
|转出科目结束|转出账簿的会计科目，参照会计科目录入。|
|汇率类型|可以单独按照会计科目设置汇率类型|
|转入原币|可以单独按照会计科目设置转入原币的对应规则，以此优先|
|转入本币|可以单独按照会计科目设置转入本币的对应规则，以此优先|

段映射规则页签

|栏目|说明|
|---|---|
|转入段|转入账簿的会计科目编码结构的段，系统自动列出。|
|映射方法|非空，选择一个段值映射方法：复制转出方段值：为转入段指定一个转出段，且转入段的段值与转出段的段值一一对应；使用固定值：为转入段指定一个固定的段值；使用规则：使用段值映射规则确定转入段的段值。映射方法中的使用规则：可以只设置转出段值与转入段值不一致的段值映射。没有设置的映射内容，可以选择“复制转出方”的方式进行处理。如果没有选择“复制转出方”且没有设置对应的映射规则，则生成转入会计科目时将不会成功。|
|转出段|选择一个转出账簿的段：当映射方法为[复制转出方段值]时，非空，用户需选择与转入段对应的转出SOB会计科目弹性域结构中的一个段；当映射方法为[使用固定值]时，为空。当映射方法为[使用规则]时，用户需选择与转入段对应的转出SOB会计科目弹性域结构中的一个段，可以选择多个转出段与一个转入段对应。|
|固定段值|当映射方法为[使用固定值]时，用户在转入段的值集中选择一个段值作为固定值。|

凭证映射规则页签

|栏目|说明|
|---|---|
|转出凭证类型|若转入账簿与转出账簿都是法人职能组织的账簿，可用。若转入账簿与转出账簿不属于同一法人职能组织时，非空。支持转出凭证类型与转入凭证类型的一对一、多对一。如果某个凭证上面的凭证类型没有设置映射关系，那该凭证就不能执行转换。|
|转入凭证类型|同上|

来源系统

|栏目|说明|
|---|---|
|选择|用户选择需要转换的来源应用。如果不选，默认所有。如果选择了，就只转换选择的内容|
|来源|列示出所有的应用|
|单据类型|用户选择应用后，列示出该应用对应的单据类型|

并账页签

为“全球合并”系统提供账簿转换的基础设置；

可以指定汇总的明细程度：凭证、期间汇总；选择凭证意味着所有的凭证在合并账簿生成一张大凭证，包括所有的分录信息（凭证类型是默认的条件）；期间汇总需要指定汇总项目。

如果汇总项目选择科目，表明所有科目相同的合并生成一条分录，如果选择科目＋币种，表明科目和币种相同的合并生成一条分录。

# 按钮说明

*  <设置转出凭证方案>：设置转出凭证的方案，指定账簿转换时针对那些转出账簿的凭证进行转换。可以按照记账期间、科目弹性域结构等设置凭证过滤的条件。

# 操作说明

*  通过菜单[账簿转换规则](/detail/ea64d7f1b6d0409a8ddfd5e3c5e2664f)进入账簿转换规则界面；
*  操作步骤
 
   *  第1步：录入编码等信息；
   *  第2步：选择转出账簿；
   *  第3步：选择转入账簿；
   *  第4步：若转出账簿与转入账簿的本位币币种不同，选择汇率类型；
   *  第5步：设置映射规则。包括期间映射、会计科目映射、段映射、凭证类型的映射等。
   *  第6步：保存账簿转换规则。
