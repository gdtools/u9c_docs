
# 功能描述

提供对凭证类型的新增、修改、删除等基本功能；

提供对该凭证类型的凭证控制方案的设置 ；

只有法人组织可以进行凭证类型的维护。

# 关键应用

# 业务规则

*  编码不能重复。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|用户录入，非空|
|凭证类型字|用户录入，非空|
|名称|用户录入，可空|
|描述|用户录入，可空|
|系统编号原则|参照选择编码规则画面；系统显示编号——在凭证维护的其他页签中的字段；只有当进行凭证编号整理后才能有系统显示编号字段；一般都是按照会计期间进行编码的排序。|
|序号编号原则|参照选择编码规则画面；序号——在凭证维护的其他页签中的字段；在整理凭证编号节点可以选择是进行系统显示编号的整理还是序号的整理；一般按照整个会计年度进行排序。|
|修改作废他人凭证|用户选择，默认：T|
|制单人可审|用户选择，默认：Ｆ|

# 按钮说明

*  <账簿凭证类型>：导航到[账簿凭证类型](/detail/10426e42253b4acc9b3bf171b65c8558)档案设置功能节点。
*  <导入系统预制>：点击“导入系统预制”，确定后，当前凭证类型转为系统预制凭证类型。

# 操作说明

*  通过菜单[凭证类型](/detail/54135dfbff834f1fbd45c9ac1de16a69)进入凭证类型界面；
*  操作步骤
 
   *  第1步：录入编码等相关信息。
   *  第2步：录入凭证类型字。
   *  第3步：选择系统编号规则。
   *  第4步：保存凭证类型。
