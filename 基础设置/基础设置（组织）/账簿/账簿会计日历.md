
# 功能描述

根据账簿档案中设置的账簿会计日历生成具体的会计期间。

主账簿可以设置每个会计期间是否有调整期。

# 关键应用

# 业务规则

*  定义账簿档案（必做）
*  只有主账簿、报告账簿需要设置账簿会计日历。
*  内账、多币种账簿的会计日历与主账簿相同。
*  U9cloud系统进行会计核算使用的会计年度、会计期间是指的账簿会计日历中设置的年度和期间。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|账簿|参照账簿档案输入。|
|会计日历|显示账簿使用的会计日历的名称。|
|会计年度|显示当前登录日期所在的会计年度。如果账簿使用的会计日历已经生成有登录日期所在年度以前或以后年度的会计期间，在此可以选择某账簿需要生成会计期间的具体会计年度。|
|会计期间页签||
|期间号|显示会计年度下会计期间的顺序号。如果某期间设置了调整期，则在会计期间后顺序显示调整期的期间号。|
|开始日期|显示一个会计期间的开始日期。|
|结束日期|显示一个会计期间的结束日期。|
|期间状态|显示每个期间的期间状态。|
|调整期|如果某期间设置了“调整期”，则显示启用调整期标识。|
|调整期页签|如果需要对某会计期间设置调整期，则在焦点会计期间行，点击本页签，可以设置对应期间的调整期。|
|调整期编号|显示调整期的期间编号。调整期编号是系统处理的，按照焦点的会计期间号+A、B、C等顺序编号。例如在第3个会计期间设置3个调整期，则调整期编号顺序为：3A、3B、3C|
|开始期间|选择调整期的开始期间。开始期间可以选择当前焦点会计期间以前的期间。例如：焦点会计期间为３，则开始期间可以选择：１、２、３|
|结束期间|选择调整期的结束期间。结束期间系统默认当前焦点会计期间。上例结束期间都是３。完整的调整期就是：调整期编号：3A　　开始期间 1；结束期间 3调整期编号：3B 开始期间 2；结束期间 3调整期编号：3C 开始期间 3；结束期间 3|

# 操作说明

*  通过菜单[账簿会计日历](/detail/c9af2659854244a4a426f96d5d414729)进入账簿会计日历界面；
*  操作步骤
 
   *  第1步：选择账簿。
   *  第2步：选择会计年度。
   *  第3步：保存账簿会计日历。
