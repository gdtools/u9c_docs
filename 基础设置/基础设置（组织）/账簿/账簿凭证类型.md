
# 功能描述

按账簿对凭证类型设置限制科目；

可以参照该组织建立的所有账簿进行设置；

如果当前登录组织不是法人组织，则按照组织关系参照法人组织的“凭证类型” 。

# 关键应用

# 业务规则

*  定义账簿（必做）
*  定义会计科目（必做）
*  定义凭证类型（必做）

# 栏目说明

账簿凭证类型

每个凭证类型可有多种限制类型，每个限制类型可有多个受限会计科目；

在凭证制单时，只能选择在账簿类型里面已经增加的凭证类型。

|栏目|说明|
|---|---|
|账簿|用户参照选择；首次使用默认为主账簿；新增时自动带入当前账簿，可改|
|凭证类型|参照输入凭证类型|
|是否默认|可以按照账簿指定默认凭证类型。这样在增加凭证时，不需要选择，也会自动携带出默认的凭证类型|
|允许多借多贷|指增加凭证时，是否允许多借多贷的凭证存在。默认为Ｔ，允许这样的凭证存在。|
|允许单向凭证|指增加凭证时，是否允许只有借方或者只有贷方的凭证存在。默认为Ｔ，允许这样的凭证存在。|
|允许自动拆分|是指凭证保存的时候，是否由系统自动拆分为一借一贷的子凭证。|
|借方必有|表示该凭证类型的所有凭证借方必有在此设置的科目。可直接录入科目或参照输入科目。可以只录入部分段，不录入的段表示包含所有的值；可以选择非末级会计科目，表示所有的下级会计科目|
|借方必无|表示该凭证类型的所有凭证借方必无在此设置的科目。|
|贷方必有|表示该凭证类型的所有凭证贷方必有在此设置的科目。|
|贷方必无|表示该凭证类型的所有凭证贷方必无在此设置的科目。|
|凭证必有|表示该凭证类型的所有凭证借方或贷方必有在此设置的科目。|
|凭证必无|表示该凭证类型的所有凭证借方或贷方必无在此设置的科目。|

*  操作步骤
 
   *  第1步：选择凭证类型；
   *  第2步：保存账簿凭证类型。
