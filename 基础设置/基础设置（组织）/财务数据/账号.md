
# 功能描述

设置组织使用的银行账户档案。当前账户如果允许设置子账号，则在此画面中设置子账号信息。

# 关键应用

# 业务规则

*  定义开户银行档案（必做）。
*  定义组织档案。
*  在同一银行下，银行账号不允许重复。
*  银行账户长度只能小于等于开户银行银行类别中定义的企业银行账号长度。
*  银行账户允许设置子账户。
*  银行账户档案已经设置。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|银行账号|录入银行账号。|
|账户名称|录入账户名称。|
|开户银行|录入开户银行。参照银行档案录入。点击字段下划线，弹出银行档案编辑查询画面，可以在线新增开户银行信息。|
|开户人类型|系统默认为“组织”。|
|拥有组织|录入当前账户归属组织。组织类型只能是法人或核算组织。参照组织档案录入。|
|默认账户|如果当前账户是业务单据中自动带入的默认账户，加注此标识。|
|多币种账户|如果当前账户允许有多个币种，加注此标识。|
|基本账户|如果当前账户是企业银行结算的基本账户，加注此标识。|
|允许子账户|如果当前账户允许设置子账户，加注此标识。|
|网银账号|如为网银账号，加注此标识。开户人类型为“组织”时，才可进行设置。|
|暂封|如该账号不可用于网银交易，则加注此标识。账号为网银账号时，才可进行设置。|
|检查签约标志|银行类别=“建行”时，需要录入检查签约标志。1、检查收付款账号2、只检查付款账号账号为网银账号，才可进行设置。|
|客户签名|银行类别为“光大”时，需要录入客户签名。|
|账号币种页签|设置账户币种信息|
|币种|参照币种档案录入币种信息。|
|最低金额|如果当前账户需要按照币种控制最低存款余额，录入最低存款金额。|
|最高金额|如果当前账户需要按照币种控制最高存款余额，录入最高存款金额。|
|最低金额控制方式|选择录入最低金额控制方式。1、严格控制：超额时提示用户，不允许通过。2、不控制。|
|最低金额允超额度|录入最低金额允超额度。|
|最低金额超额表示|选择录入最低金额超额表示。1、金额：超额时以金额表示2、比例：超额时以百分比表示|
|最高金额控制方式|选择录入最高金额控制方式。1、严格控制：超额时提示用户，不允许通过。2、不控制。|
|最高金额允超额度|录入最高金额允超额度。|
|最高金额超额表示|选择录入最高金额超额表示。1、金额：超额时以金额表示2、比例：超额时以百分比表示|

子账号—基本栏目

|栏目|说明|
|---|---|
|银行账号|录入银行账号。弹出画面时，系统默认当前银行账号，用户可以参照银行账号档案进行修改。也可以为其他有子账号管理的银行账号，设置子账号。|
|币种|录入选种的银行账户下的币种信息。|
|子账号|录入子账号。|


# 按钮说明

*  <子账号>：当前账户如果允许设置子账号，则在此画面中设置子账号信息。

# 操作说明

*  通过菜单[账号](/detail/ce4c657e148a4eca9ecacbebdeca93f1)进入账号界面；
*  操作步骤
 
   *  第1步：编辑银行账号、名称等信息。
   *  第2步：选择开户银行、收支方向。
   *  第3步：保存账号。
