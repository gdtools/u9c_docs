
# 功能描述

设置现金账号。

# 关键应用

# 业务规则

*  无

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|现金账号|录入现金账号。|
|账户名称|录入账户名称。|
|描述|录入描述内容|
|拥有组织|自动动带出当前组织|
|生效|默认勾起，立即生效|
|生效日期|默认当前日期，支持手动修改|
|失效日期|支持手动修改|



# 操作说明

*  通过菜单[现金账号](/detail/aecaa8bf8d204d40a9d83d4ed326fbe0)进入现金账号界面；
*  操作步骤
 
   *  第1步：录入现金账号、账号名称等信息。
   *  第2步：保存现金账号。
