
# 功能描述

本功能节点完成对现金账号的增加、现金账号信息的维护、查询和输出以及人员的删除。

# 业务规则

*  现金账号不能为空。

# 栏目说明

现金账号-基本

|栏目名称|说明|
|---|---|
|现金账号|现金账号|
|账号名称|账号名称|
|描述|现金账号的描述|
|拥有组织|现金账号的拥有组织|
|是否生效|当前公告版块是否已经生效|
|生效日期|当前现金账号的生效日期|
|失效日期|当前现金账号的失效日期|

# 操作说明

*  通过菜单[现金账号](/detail/aecaa8bf8d204d40a9d83d4ed326fbe0)进入现金账号界面；
*  操作步骤
 
   *  第1步：录入现金账号、账号名称等信息。
   *  第2步：点击保存按钮。
