
# 功能描述

设置组织用于进行应收、应付款项账龄以及库存库龄分析的账龄区间档案；

账龄区间是组织进行各项业务分析的重要基础数据。

# 关键应用

# 业务规则

*  账龄区间方案编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入账龄区间方案编码。|
|名称|录入账龄区间方案名称。|
|时间单位|选择账龄区间的间隔单位。系统提供以下区间间隔：１、日：以“天”为时间间隔单位，提供统计数据；２、周：以“周”为时间间隔单位，提供统计数据；３、月：以“月”为时间间隔单位，提供统计数据。|
|描述|录入账龄区间的描述性说明。|
|开始账期|录入每个账龄区间的开始账期数。第一个账龄区间输入后，以后每个区间的开始账期将由系统自动计算。开始账期可以为负数、零、正数；如果用户需要设置一个无限远的开区间，则将本字段置为空，系统将默认－９９９９９为无限远的开始账期。|
|结束账期|录入每个账龄区间的结束账期数。结束账期可以为负数、零、正数。如果用户最后一个账期为无穷大期间，则为空，不需输入任何数值。|
