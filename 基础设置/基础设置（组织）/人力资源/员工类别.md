
# 功能描述

定义员工类别档案。

# 关键应用

# 业务规则

*  员工编码不能为空，不能重复

# 栏目说明

员工类别画面

|栏目|说明|
|---|---|
|编码|按照员工类别的编码结构，录入员工类别编码。如果还没有建立需要的编码结构，可以点击本项下划线，弹出设置画面，在线设置。|
|名称|录入员工类别名称|
|简称|录入员工类别简称|

# 按钮说明

*  <下发>：导航到下发功能节点。
*  <取消下发>：导航到取消下发功能节点。
*  <下发参数>：导航到下发参数功能节点。

# 操作说明

*  通过菜单[员工类别](/detail/c807507e04774d299cf7aac096a197f7)进入员工类别界面；
*  操作步骤
 
   *  第1步：录入编码等相关信息。
   *  第2步：保存员工类别。
