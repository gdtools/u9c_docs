
# 功能描述

定义职务类别档案。

# 关键应用

# 业务规则

*  按照职务类别的编码结构，录入职务类别编码。

# 栏目说明

职务类别画面

|栏目|说明|
|---|---|
|编码|如果还没有建立需要的编码结构，可以点击本项下划线，弹出设置画面，在线设置。|
|名称|录入职务类别名称|
|简称|录入职务类别简称|

# 按钮说明

*  <下发>：导航到下发功能节点。
*  <取消下发>：导航到取消下发功能节点。
*  <下发参数>：导航到下发参数功能节点。

# 操作说明

*  通过菜单[职务类别](/detail/4a2d19301eb84447bd3c52b98a7802cf)进职务类别界面；
*  操作步骤
 
   *  第1步：点击“查询”。
   *  第2步：录入查询条件。
   *  第3步：点击“确定”。
