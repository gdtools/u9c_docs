
# 功能描述

定义岗位类别档案。

# 关键应用

# 业务规则

*  岗位类别的编码不能为空，不能重复。

# 栏目说明

岗位类别画面

|栏目|说明|
|---|---|
|编码|按照岗位类别的编码结构，录入岗位类别编码。如果还没有建立需要的编码结构，可以点击本项下划线，弹出设置画面，在线设置。|
|名称|录入岗位类别名称|
|简称|录入岗位类别简称|

# 按钮说明

*  <下发>：导航到下发功能节点。
*  <取消下发>：导航到取消下发功能节点。
*  <下发参数>：导航到下发参数功能节点。

# 操作说明

*  通过菜单[岗位类别](/detail/9136e706e0d940fa80640488f809392e)进入岗位类别界面；
*  操作步骤
 
   *  第1步：录入编码相关等信息。
   *  第2步：保存岗位类别。
