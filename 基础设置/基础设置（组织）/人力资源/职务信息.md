
# 功能描述

实现对职务定义。

实现对职务结构的定义。

实现职务与角色的关联。

# 关键应用

# 业务规则

*  定义职务类别
*  定义职务编码结构
*  职务的编码不能为空，不能重复。
*  当没有引用的职务类别时，通过职务类别标签链接到职务类别设置界面增加职务类别。

# 栏目说明

职务基本信息

|栏目|说明|
|---|---|
|编码|职务的编码。|
|名称||
|简称||
|职务类别|职务的分类。由用户进行自定义设置。请参见相关功能-职务类别。|
|描述||

职务汇报关系页签

|栏目|说明|
|---|---|
|业务组织|限于职务的所属组织存在“组织-人事”关系的组织。|
|部门|业务组织下的部门。|
|责任类型|枚举：行政。支持用户自定义。。请参见自定义代码。|
|上级工作人事组织|汇报的上级所属的工作人事组织。|
|上级业务组织|限与上级工作人事组织存在“组织-人事”关系的组织，含上级工作人事组织。|
|上级部门|限上级业务组织下的部门|
|上级职务|限上级工作人事组织内的所有职务|
|上级岗位|限上级业务组织部门下的岗位|
|开始日期||
|结束日期||

职务角色关系页签

|栏目|说明|
|---|---|
|业务组织|限于职务的所属组织存在“组织-人事”关系的组织。|
|部门|业务组织下的部门。|
|组织|限与登录组织具有“组织-人事”关系的组织（含自己）。|
|角色|限组织内的角色。|

# 操作说明

*  通过菜单[职务信息](/detail/dc8a6ab60afc4d89a3ab14f063f0b211)进入职务信息界面；
*  操作步骤
 
   *  第1步：录入编码相关信息。
   *  第2步：录入职务汇报关系和职务角色相关信息。
   *  第3步：保存职务信息。
