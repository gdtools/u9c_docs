
# 功能描述

实现增加、删除员工，查询、维护和输出员工信息的功能。

# 关键应用

# 业务规则

*  定义类型为人员的联系对象
*  定义国家/地区档案
*  定义地址档案

# 按钮说明

*  <查找历史人员>：在增加员工时，可以增加系统内没有的人员，即录入人员的所有信息，也可以增加系统内已有的人员，即先调出人员的已有信息，再录入其员工工作记录，从而实现历史人员再入职，或者是系统内已有人员在当前工作人事组织内的任职。
*  <表格输出>：基于word模版输出人员履历表。

# 操作说明

*  通过菜单[人员信息](/detail/4292190299614a7989d2ebd7c926abed)进入人员信息界面；
*  操作步骤
 
   *  第1步：录入人员基本信息。
   *  第2步：录入员工工作记录。
   *  第3步：录入员工任职记录和员工工作汇报关系。
   *  第4步：保存人员信息。
