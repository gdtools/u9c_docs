
# 功能描述

实现对岗位定义。

实现对岗位结构的定义。

实现岗位与角色的关联。

# 关键应用

# 业务规则

*  定义职务
*  定义岗位类别
*  定义岗位编码结构

# 栏目说明

岗位基本信息

|栏目|说明|
|---|---|
|编码|岗位的编码。不能为空，不能重复。|
|名称|岗位的名称。|
|简称|岗位的简称。|
|岗位分类|岗位的分类。由用户进行自定义设置。请参见功能节点-岗位类别。当没有引用的岗位类别时，通过岗位类别标签链接到岗位类别设置界面增加岗位类别。|
|状态||
|职务|参照职务设置岗位。引用职务后，岗位与职务相同的字段的值从职务中复制过来，用户可再编辑。职务的设置参见功能节点-职务。当没有引用的职务时，通过职务标签链接到职务设置界面增加职务。|
|业务组织||
|部门||

岗位汇报关系页签

|栏目|说明|
|---|---|
|责任类型|枚举：行政。支持用户自定义。请参见自定义代码。|
|上级工作人事组织|汇报的上级所属的工作人事组织。|
|上级业务组织|限与上级工作人事组织存在“组织-人事”关系的组织，含上级工作人事组织。|
|上级部门|限上级业务组织下的部门|
|上级职务|限上级工作人事组织内的所有职务|
|上级岗位|限上级业务组织、部门下的岗位|
|开始日期||
|结束日期||

岗位角色关系页签

|栏目|说明|
|---|---|
|组织|限与登录组织具有“组织-人事”关系的组织（含登录组织）。|
|角色|限组织内的角色。|
