
# 功能描述

通过本功能来定义组织内部各成本域使用的成本类型。

成本类型是指组织内料品的成本计算方法，是使用不同方法计算归集的成本集合。同一个组织内，每个成本类型可以属于不同的成本域，每个料品可以有多个成本类型分别用来处理不同的成本管理业务，如模板成本、成本记账。但料品用来记账的成本只能使用其中的一种成本类型。

更详细说明，请参见成本类型应用专题。

# 关键应用

# 业务规则

*  参数设定，与成本域相关参数。
*  已定义【存储地点】和【账薄】档案。
*  用户自定义的编码应遵循一定的规则，因为用户自定义编码会在系统应用中被广泛使用，比如用于排序或者是指定范围。
*  目前版本料品成本初始化完成后，不允许新增成本域，但允许新增成本域构成。新增加的仓库应为空仓，如非空仓，应手工调整或维护该仓库所拥有料品的存货成本和料品成本，并作相应的账务处理。
*  目前版本一旦“是否已完成初始化”参数＝True，将不再允许新增成本类型。

# 栏目说明

成本类型

|栏目|说明|
|---|---|
|成本域|要定义的成本类型属于哪一个成本域。参照录入，不可为空；|
|编码|用户自定义的成本类型的编码。手工录入，不可为空。在同一成本域内唯一；用户自定义的编码应遵循一定的规则，因为用户自定义编码会在系统应用中被广泛使用，比如用于排序或者是指定范围。|
|名称|用户自定义的成本类型的名称。手工录入；可以选择录入中文或英文。|
|会计日历|成本域下至少有一个会计日历为法人组织主账簿所使用的日历。 默认为法人组织主账簿所使用的会计日历|
|用于记账|本成本类型对于成本域内的料品是否为默认的记账成本类型。手工选择；1、成本类型是否用于记账是针对料品设置的，在此勾选了成本类型用于记账，意味着本成本类型是成本域内所有料品的默认记账类型，用户可以在【料品成本类型】操作中指定特例料品的记账成本类型。2、每一个料品在一个成本域下可以有多个记账成本类型，但各记账成本类型的账簿不能相同。|
|成本方法|本成本类型对应的成本计算方法，使用本成本类型的各料品，都将使用本成本计算方法进行料品计价。手工选择，不可为空；|
|暂估来源|手工选择参考成本成本类型对于非实时成本计算方法，必须指定料品日常流转时使用的暂估成本类型，作为其出入库的暂时计价成本类型。可以选择参考成本作为暂估成本，也可以选择其他成本类型的成本作为暂估成本。|
|暂估成本类型|当暂估来源＝成本类型时，选择同成本域下其他成本类型的料品成本作为出入库的暂时计价成本。参照选择已经定义的成本类型；只在成本方法为“全月平均”、“计划”时可以选择暂估成本类型。|
|暂估期间|对于非实时成本计算方法，指定其暂估成本类型取哪一个期间的成本作为暂估成本。手工选择；当成本方法为“全月平均”时只能选择“上期结存”。|
|期初成本来源|单选： 　指定来源成本类型　记账用成本类型　手工维护默认为手工维护 当[料品成本初始完成]＝F 时，成本期初来源＝手工维护，不可改。|
|来源成本类型|当“期初成本来源＝指定来源成本类型”时，当前登录组织下所有成本类型|
|来源账簿|当“期初成本来源＝指定来源成本类型”时，“成本类型账簿关系”下所有对应账簿|
|修改受控|本成本类型是否“修改受控”。手工选择，默认为“否”；只可以由“否”改为“是”；只有“标准”或“计划”成本类型可以修改受控；|
|生效日期|默认当前日期，可改 非记账成本类型的生效日期不得早于当前生效的记账成本类型的生效日期。  生效期间必须晚于系统已有成本类型的最后月结期间，如果系统不存在已经月结的成本类型，则晚于初始期间|
|失效日期|默认最大日期，可改 非记账成本类型的失效日期不得晚于当前生效的记账成本类型的失效日期。  失效期间必须晚于系统已有成本类型的最后月结期间，如果系统不存在已经月结的成本类型，则为晚于初始期间|
|账簿|账簿必须为成本类型对应的成本域下定义的有效账簿。记账成本类型可以无主账簿，最多只能包括一个主账簿。同一个成本类型下的账簿必须属于同一个组织或该组织对应的法人组织，要么是本组织的账簿，要么是货主组织的账簿。|
|币种|根据选择的账簿对应的币种自动显示|
