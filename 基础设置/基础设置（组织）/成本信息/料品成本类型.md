
# 功能描述

定义料品所属的成本域和所使用的成本类型。料品在哪个成本域中进行成本计算，计算哪些成本类型的成本，使用哪些成本类型记账，使用哪个成本类型进行暂估都需要在此指定。

料品成本类型的关系可以通过特定料品来指定，也可以通过料品分类或形态属性指定，使用料品分类还是形态属性指定，由系统参数决定。如果用户企业内所有料品都使用相同的成本域成本类型，也可以定义一条或几条形态属性、料品分类和料品均为空的料品成本类型关系。

# 关键应用

# 业务规则

*  参数设定，与成本域相关参数。
*  已定义【存储地点】和【账薄】档案。
*  用户自定义的编码应遵循一定的规则，因为用户自定义编码会在系统应用中被广泛使用，比如用于排序或者是指定范围。
*  目前版本料品成本初始化完成后，不允许新增成本域，但允许新增成本域构成。新增加的仓库应为空仓，如非空仓，应手工调整或维护该仓库所拥有料品的存货成本和料品成本，并作相应的账务处理。
*  目前版本一旦“是否已完成初始化”参数＝True，将不再允许新增成本类型。

# 栏目说明

料品成本类型

|栏目|说明|
|---|---|
|形态属性|当参数：料品成本类型指定方式＝“型态属性”时，该字段可输，否则置灰，料品的形态属性模型按订单拣货按订单装配可选类委外加工件工序委外件虚拟计划系列采购件制造件最终装配件套件工艺低值易耗品商品杂项料品服务资产备件配方重复费用性料品|
|料品分类|当参数：料品成本类型指定方式＝“料品分类”时，取参数表中“料品成本类型定义所用分类”中定义的料品分类的明细。|
|料品|要定义记账成本类型的料品。参照录入，可空；|
|成本域|料品所在的成本域。参照录入，不可为空；|
|成本类型|要处理的成本类型。当料品成本类型指定方式＝“型态属性”时，对型态属性＝“资产”的料品，不能选择计价方式＝“LIFO/STD/PLAN/MAVG”的成本类型。手工录入，不可为空。|
|用于记账|由成本类型带入，不可修改。|
|成本方法|成本类型对应的成本计算方法，系统根据成本类型自动填写。|
|暂估来源|单选：参考成本成本类型|
|暂估成本类型|成本类型对应的暂估成本类型。参照选择已经定义的成本类型；只在成本类型对应的成本方法为“全月平均”、“计划”时可以选择暂估成本类型。当暂估成本＝料品成本类型时有效|
|暂估期间|暂估成本类型取哪一个期间的成本作为暂估成本。由成本类型带入当“暂估成本类型”有值时可修改。通过下拉框选择： 即期、上期结存暂估成本类型为ＭＡＶＧ时，只能选上期 。|
|生效|手工选择，默认为生效|
|生效日期|手工录入，默认为当前日期|
|失效日期|手工录入，大于等于生效日期，默认为最大日期|

# 操作说明

*  通过菜单[料品成本类型](/detail/2402745c6b23499cbcf52e0d3ad58536)进入料品成本类型界面；
*  操作步骤
 
   *  第1步：点击料品成本类型操作按钮，系统导航到料品成本类型定义窗口。
   *  第2步：按形态属性或料品分类或料品录入记账成本类型或暂估成本类型，也可以不指定具体的形态属性、料品分类、料品。
   *  第3步：点击“保存”，保存新增或修改的数据。
