
# 功能描述

计入产品成本的生产费用，按照其在生产过程中的用途进行分类，这些分类被称为成本要素，其作用在于反映产品成本的构成和水平。

U9将企业的成本要素按其核算内容的不同，划分为：材料费用、人工费用、制造费用、外协费用和机器费用五种要素类型，并且为系统预置了材料费、人工费、制造费、外协费和机器费五种成本要素作为一级成本要素。

依据企业情况的不同，用户可以通过此功能在这五种一级成本要素下建立各自不同的明细成本要素。

# 关键应用

# 业务规则

*  成本要素编码不能为空，不能重复。

# 栏目说明

成本要素

|栏目|说明|
|---|---|
|上级成本要素|要建立的明细成本要素的上级成本要素。参照选择，必须为明细成本要素；不可为空。|
|编码规则|成本要素的编码规则。系统提示信息，不可编辑。明细成本要素的编码格式必须根据此编码规则进行定义。说明：系统依据【基础设置】－【参数设置】中的“成本要素编码级长”来提示成本要素的编码规则|
|编码|明细成本要素的编码。手工录入，不可为空。在同一组织内唯一，编码格式应符合编码规则；|
|名称|明细成本要素的名称。手工录入，不可为空；可以选择录入中文或英文。|
|简称|手工录入明细成本要素的简称。|
|描述|手工录入明细成本要素的文字描述或说明。|
|类型|明细成本要素所属的要素类型。系统根据上级成本要素自动识别，自动填入；不可编辑。|
|明细要素|标识本成本要素是否为末级成本要素。系统根据上级成本要素自动识别，自动填入；不可编辑。|
