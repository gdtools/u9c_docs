
# 功能描述

成本域定义了组织料品成本核算的范围，提供一个能够使用相同的计价方法进行料品成本管理的逻辑边界。

成本域与已定义的组织机构、仓库和货主组织相关， 根据组织、存储地点和货主组织来设置。一个工厂组织可以定义多个成本域，在不同的成本域中使用不同的成本方法进行核算。

每个成本域可以设置在本成本域内记账的账薄，每个成本域可以设置多个账薄，各成本域都至少应有一个主账薄。


更详细说明，请参见成本域应用专题。

# 关键应用

# 业务规则

*  参数设定，与成本域相关参数。
*  已定义【存储地点】和【账薄】档案。
*  用户自定义的编码应遵循一定的规则，因为用户自定义编码会在系统应用中被广泛使用，比如用于排序或者是指定范围。
*  目前版本料品成本初始化完成后，不允许新增成本域，但允许新增成本域构成。新增加的仓库应为空仓，如非空仓，应手工调整或维护该仓库所拥有料品的存货成本和料品成本，并作相应的账务处理。

# 栏目说明

成本域

|栏目|说明|
|---|---|
|编码|用户自定义的成本域的编码。手工录入，不可为空。在同一组织内唯一；|
|名称|用户自定义的成本域的名称。手工录入；可以选择录入中文或英文。|
|零成本|手工勾选，成本域被使用后不可以修改。|

构成

|栏目|说明|
|---|---|
|存储地点|成本域的范围包括哪些存储地点。参照录入。当参数“按存储地点划分＝T”时，此字段不能为空；|
|货主组织|成本域的范围包括哪些货主组织。参照录入。当参数“按货主组织划分＝T”时，此字段不能为空；|

账薄

|栏目|说明|
|---|---|
|账薄|成本域下的记账账薄。参照录入。可以选择登录工厂组织对应的法人组织主账薄、成本域货主组织对应的法人组织主账簿和货主组织对应的多币种账薄|

# 操作说明

*  通过菜单[成本域](/detail/7b6e42a459bd472f8bb176f6e068cb1d)进入成本域界面；
*  操作步骤
 
   *  第1步：录入编码等信息。
   *  第2步：录入构成和账簿信息。
   *  第3步：保存成本域。
