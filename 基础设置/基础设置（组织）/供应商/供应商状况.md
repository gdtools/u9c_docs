
# 功能描述

提供对供应商业务状况、财务状况的综合查询。

在供应商档案设置、采购订单、应付单、付款单等相关功能节点，都可以链接查询供应商状况。

# 关键应用

# 业务规则

*  定义供应商档案（必做）
*  本状况表的的显示栏目可以通过系统提供的“查询”功能进行自定义。
*  本供应商位置表的的显示栏目也可以通过系统提供的“查询”功能进行自定义。

# 栏目说明

基本查询栏目

|栏目|说明|
|---|---|
|供应商状况表|显示供应商基本档案中的主要供应商信息。|
|供应商位置|显示供应商状况表中焦点行供应商的每个位置的主要信息。在供应商状况表画面，双击焦点行，供应商位置信息随主画面行进行相应变动。|
|供应商状况||
|未立账金额|显示向供应商已经采购但未立账的款项金额。|
|未收货额|显示供应商的已经采购但未收到的货物款项金额。|
|应付款|显示供应商的应付账款余额。|
|挂起额|显示供应商被挂起的款项金额。|
|预付款|显示供应商的预付款金额。|
|暂收款|显示供应商的暂收款金额。|
|暂付款|显示供应商的暂付款余额。|
|质保金|显示供应商的质保金余额。|
|保证金|显示供应商的保证金余额。|
|累计退货额|显示供应商的累计退货金额。|
|业务日期查询|提供供应商各项业务的最近执行日期查询。|

# 操作说明

*  通过菜单[供应商状况](/detail/5fba64e31dfc40ab8ad41e0872ee6527)进入供应商状况界面；
*  操作步骤
 
   *  第1步：点击“查询”。
   *  第2步：录入查询条件。
   *  第3步：点击“确定”。
