
# 功能描述

设置供应商分类档案。

# 关键应用

# 业务规则

*  供应商分类编码不允许重复
*  定义供应商分类编码结构（必做）
*  供应商分类编码采用编码结构段录入。

# 栏目说明

基本栏目设置

|栏目|说明|
|---|---|
|编码|录入供应商分类编码。点击按钮，弹出编码结构段值录入画面，按照段对应值集，录入各段取值。|
|名称|录入供应商分类名称。|
|描述|录入供应商分类的描述性说明信息。|

# 按钮说明

*  <供应商>：导航到[供应商](/detail/b0b40041a9ff4402a2244dc6fd71b531)档案设置功能节点。
*  <客户分类>：导航到[客户分类](/detail/e16ec18ab1b542b5bca83ba67ac0e7e1)档案设置功能节点。
*  <料品分类>：导航到[分类](/detail/c242fe5169134b37910750a6f1ec53d2)档案设置功能节点。

# 操作说明

*  通过菜单[供应商分类](/detail/90dd168fb5544b0794ea9d64ba0e786b)进入供应商分类界面；
*  操作步骤
 
   *  第1步：录入编码信息。
   *  第2步：录入名称描述等信息。
   *  第3步：保存供应商分类。
