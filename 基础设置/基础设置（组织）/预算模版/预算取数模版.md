
# 功能描述

预算指标的执行数从业务系统取数时，为各业务系统的单据或统计表配置取执行数模板，仅指取预算执行数据部分。

# 关键应用

# 业务规则

*  模板编码不能重复。
*  定义预算目的。
*  定义预算指标（必做）。

# 栏目说明

页签--预算模板

|栏目|说明|
|---|---|
|单据类别|U9各业务系统的单据类别。|
|条件|录入匹配当前模板的条件，如应付单：作废=否 and 期初=否|
|预算期间|为预算期间指定来源。|
|单据原币|为单据原币指定来源|
|原币金额|为单据原币金额指定来源。金额指标有效。若预算编制数据的币种包含单据原币币种：预算执行金额（原币）=单据原币金额；若预算编制数据的币种不包含单据原币币种：预算执行金额（原币）=单据原币金额；|
|单据本币|为单据本币指定字段来源|
|本币金额|为单据本币金额指定字段来源|
|是否折算预算本币|是：预算本币金额=预算原币金额*按预算执行汇率类型取【业务日期】汇率；否：若预算原币同预算本币币种，则预算本币金额=预算原币金额；若单据本币同预算本币，则预算本币金额=单据本币金额；否则，按【业务日期】汇率折算预算本币金额。|
|单价|为单价指定来源。金额指标有效。|
|数量|为数量指定来源。数量指标有效。|
|单位|如果是数量指标，为单位指定字段来源。系统取执行数时，自动折算为预算指标【计量单位】属性的数量；|
|业务日期|为汇率折算指定折算日期字段来源。|
|摘要|为摘要指定来源。|
|模板类型|保留：定义保留模板。执行：定义执行模板|
|替代线索|指定替代保留时的上一环节线索来源。|
|自动保留方式|为单据自动新增、替代、取消、执行保留。|
|执行时机|指定预算执行或预算保留执行的时机。|
|生效|是：模板生效。否：模板失效。|

# 按钮说明

*  <下发>：将当前预算模板批量下发到其他预算组织。点击下发按钮，弹出下发对话框，选择目的预算组织，点击确定，将预算模板下发给其他预算组织。
*  <取消下发>：批量取消下发当前预算模板。点击取消下发按钮，弹出取消下发对话框，选择目的预算组织，点击确定，取消下发给目的预算组织的预算模板。

# 操作说明

*  通过菜单[预算取数模版](/detail/5ac03ebef4264e29a9c403f40215007e)进入预算取数模版界面；
*  操作步骤
   *  第1步：录入模板编码、名称等相关信息。
   *  第2步：选择单据类型、模板类型、执行时机、预算期间等信息。
   *  第3步：保存预算取数模板。
