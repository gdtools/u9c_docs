
# 功能描述

预算指标的执行数从业务系统取数时，为各业务系统的单据或统计表配置取执行数模板。

本功能是系统已经预置的取数模板，方便用户直接创建后修改使用。

# 关键应用

# 业务规则

*  定义预算目的。
*  定义预算指标（必做）。

# 栏目说明

表头

|栏目|说明|
|---|---|
|预设目的|参照预算目的录入|
|预算组织|参照预算组织录入|

页签--指标影响因素

|栏目|说明|
|---|---|
|单据类别|参照单据类别录入。为该单据类别配置预算模板|
|因素１|参照系统预置的影响因素录入。作为预算对象数据来源或影响条件的段。当业务单据类别是凭证或账簿时，因素1必须为账簿。|
|因素２||
|因素......||

页签--指标模板(上列表)

|栏目|说明|
|---|---|
|(预算维度1)-预算因素|参照系统预置的影响因素录入。一般为预算主体。为当前预算维度指定因素数据来源。如果预算主体是部门，可以选部门为影响因素。|
|(预算维度2)-预算因素|参照系统预置的影响因素录入。|
|......|对于上列表选中的影响因素与预算维度的对应关系，需要点【更新维度】按钮，系统才会自动更新到下列表中。|

页签--指标模板(下列表)

|栏目|说明|
|---|---|
|条件-影响因素1|录入具体每个影响因素的值|
|条件-影响因素2|录入具体每个影响因素的值|
|条件-。。。|如果与预算维度对应的值集是同一个，不需逐个匹配，在上列表录入后，自动带入下列表|
|预算对象-预算主体|参照维度值集录入为当前预算对象指定具体维度值。|
|预算对象-预算指标|从左预算指标树焦点行带入，不可改。|
|预算对象-其他预算维度。。。|为当前预算对象指定具体维度值|

页签--预算取数模板

|栏目|说明|
|---|---|
|预算取数模板|选择预算取数模板，预算取数模板需要先通过预置模板生成。|
|模板类型|系统从预算取数模板带出。保留：定义保留模板。执行：定义执行模板|
|自动保留方式|系统从预算取数模板带出。为单据自动新增、替代、取消、执行保留。|
|执行时机|系统从预算取数模板带出。指定预算执行或预算保留执行的时机。|
|生效|是：模板生效。否：模板失效。|

# 按钮说明

*  <创建预算模板>：将当前预置预算模板复制生成用户的预算模板。点击创建预算模板按钮，弹出创建结果对话框，查看创建结果。
*  <创建预算模板日志>：查看批量创建预算模板日志。点击创建预算模板日志按钮，弹出创建日志对话框。

# 操作说明

*  通过菜单[预置预算取数模版](/detail/8d51fe6b996f4a1fa2bc5914ca5a54f1)进入预置预算取数模版界面；
*  操作步骤
   *  第1步：选择预置预算取数模板。
   *  第2步：双击单行预置预算取数模板，查看模板的详细内容。
