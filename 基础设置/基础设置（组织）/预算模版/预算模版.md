
# 功能描述

预算指标的执行数从业务系统取数时，为各业务系统的单据或统计表配置取执行数模板，包括取数来源因素设置、映射预算指标、预算取数模板设置等等。

某个组织替其他业务组织编制预算，希望直接取其他组织的业务单据数据，作为预算执行数，或者做预算控制。需要在其他组织里也设置预算模板。预算模板可以批量复制到其他组织。

# 关键应用

# 业务规则

*  定义预算目的。
*  定义预算指标（必做）。
*  预算取数模板（必做）。
*  设置的预算模板自动写预算执行数的条件，下面缺一不可：相应的预算期间执行状态已经打开；对应的预算对象已经完成预算编制，并已批复生效；预算模板匹配到了具体预算对象，且在单据上可以匹配到；如果需要做预算控制，预算对象上须定义预算控制方案。
*  为提高预算模版的录入效率，系统放开了预算模版的OBA导入导出，可通过OBA模版导入预算模版。
*  由于预算的维度不同，OBA导入导出的格式也会不同，故没有预置系统模板，需要自己在OBA端创建自己的模版。 Excel中创建导入导出模板时，选择的后台实体是“指标模版”，后台实体表名：ABI_TBFigureTemplet
*  注意预算取数模版，没法同步导入，需要手工维护。
*  建议先录入几个合法模版，导出后修改，再导入。

|因素２||
|因素......||

页签--指标模板(上列表)

|栏目|说明|
|---|---|
|(预算维度1)-预算因素|参照系统预置的影响因素录入。一般为预算主体。为当前预算维度指定因素数据来源。如果预算主体是部门，可以选部门为影响因素。|
|(预算维度2)-预算因素|参照系统预置的影响因素录入。|

页签--指标模板(下列表)

|栏目|说明|
|---|---|
|条件-影响因素1|录入具体每个影响因素的值|
|条件-影响因素2|录入具体每个影响因素的值|
|条件-。。。|如果与预算维度对应的值集是同一个，不需逐个匹配，在上列表录入后，自动带入下列表|

|预算对象-预算指标|从左预算指标树焦点行带入，不可改。|
|预算对象-其他预算维度。。。|为当前预算对象指定具体维度值|

页签--预算取数模板

|栏目|说明|
|---|---|
|预算取数模板|选择预算取数模板，预算取数模板需要先通过预置模板生成。|
|模板类型|系统从预算取数模板带出。保留：定义保留模板。执行：定义执行模板|
|自动保留方式|系统从预算取数模板带出。为单据自动新增、替代、取消、执行保留。|
|执行时机|系统从预算取数模板带出。指定预算执行或预算保留执行的时机。|
|生效|是：模板生效。否：模板失效。|

# 按钮说明

*  <批量复制：将当前预算模板批量复制到其他预算组织。点击批量复制按钮，弹出批量复制对话框，选择目的预算组织，点击确定，将预算模板复制给其他预算组织。
*  <批量删除>：批量删除当前预算模板。点击批量删除按钮，弹出批量删除对话框，选择目的预算组织，点击确定，批量删除目的预算组织的预算模板。

# 操作说明

*  通过菜单[预算模版](/detail/7a37da88f6fb4d68a95d574899630323)进入预算模版界面；
*  操作步骤
   *  第1步：选择预算目的、预算组织信息。
   *  第2步：选择预算指标的费用类型。
   *  第3步：选择单据类别项。
   *  第4步：保存预算模板。
