
# 功能描述

用于维护交易过程中所采用的结算方式和各结算方式下的支付比例，及交易中的现金折扣条件的规则。

收款条件档被建立后，可被销售订单、出货单等单据引用。

# 关键应用

# 业务规则

*  定义币种（可选）
*  定义结算方式（可选）
*  收款条件编码不允许重复

# 栏目说明

收款条件单头

|栏目|说明|
|---|---|
|编码|必输， 录入收款条件的编码。|
|名称|可选， 录入收款条件的名称|
|适用币种|可选，若此收款条件只适用于某特定币种下的往来交易，则在此设定币种限制； 若此处未设定适用币种，则表明该收款条件适用所有币种下的交易。|
|单据可改|可选，由于收款条件被订单引用后会随单保存，此处标示订单引用了该收款条件后，是否允许用户在订单中修改随单保存的收款条件的具体内容（如现金折扣天数/比例、结算方式等）。|
|“现金折扣”分区|
|折扣依据|必输，若此收款条件存在现金折扣，则此处标明现金折扣额的计算是以交易过程中的“无税金额”还是“含税金额”为基准计算。|
|多折扣率|若此收款条件存在现金折扣，是只允许一段现金折扣期间还是允许存在多段现金折扣期间/比例。|
|部分付款享受折扣|当收款在时间条件上满足现金折扣的期间条件、但在金额上却未收完当期应付的全部款项时，该标志用于判断这种情况下是否还允许享受现金折扣。|
|“计息”分区|
|超期罚息|若超过账期后还未付清款项，是否对超期未付部分的金额计算利息。|
|免息天数|超过账期后多少天内，暂时不予以罚息； 当超过“账期到期日”+“免息天数”后，将计息。|
|最大计息天数|超期罚息到一定天数（日期超过“账期到期日”+“免息天数”+“最大计息天数”）后若仍未收清款项，可能将采取法律行为或其他措施请款。|
|复利计息|计息时按照单利还是复利方式进行。|
|计息率|若超期要计息（罚息），则可在此录入利息率。|
|提前催请天数|在应收到期前多少天可对客户进行请/催款。|
|描述|可选， 录入收款条件的说明、描述|
|“状态”分区|
|生效||
|生效日期|此收款条件可以被启用的生效/起始日期。|
|失效日期|此收款条件可以被启用的失效/截止日期。|

收款条件单体－现金折扣页签

|栏目|说明|
|---|---|
|折扣天数|可选， 录入该现金折扣分段的天数。|
|折扣率|可选， 录入该折扣分段的折扣率。例如：折扣天数和折扣率常用3/10，2/20，n/30这种方式表示，其中10、20、30就是折扣天数，其中3、2就代表折扣率3%和2%|
||说明：若【单头】•[多折扣率]=True时，允许在“现金折扣页签”录入多行；否则最多只允许录入一行。|

收款条件单体－支付方式页签

|栏目|说明|
|---|---|
|支付方式|可选， 录入该收款条件的结算方式。在一个收款条件中，可以由多种结算方式混合支付。|
|支付比例|录入每种结算方式下支付金额占总支付金额的比例。|
