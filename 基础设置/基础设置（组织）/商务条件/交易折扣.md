
# 功能描述

用于定义销售过程中的折扣项目。用户需要在销售过程中使用人工折扣，则需要在此事先定义可能会涉及到的折扣。

# 关键应用

# 业务规则

*  交易折扣编码不允许重复
*  当[折扣类型]为“整单折扣”时，[折扣依据]必须为“金额”（即按整单金额计算折扣）。
*  [折扣额]和[折扣率]只能有一个非空。

# 栏目说明

交易折扣－基本页签

|栏目|说明|
|---|---|
|折扣编号|当前折扣档编号|
|折扣原因|可空，手工输入|
|折扣依据|计算折扣时，是按商品的交易单价来计算折扣，还是按交易金额计算折扣。|
|折扣类型|若该折扣和交易的具体商品相关，折扣的计算依物料的不同而不同，则为“行折扣”； 若该折扣和每个具体交易的商品无关，而和单笔交易的总金额有关，则为“整单折扣”。|
|折扣方向|表明计算折扣时，是按“正方向”计算还是按“反方向”计算。 系统提供如下几个选项值：“正扣”——折扣额=交易额*折扣率，实际成交价=交易额*(1-折扣率)“倒扣”——折扣额=交易额*(1-折扣率)，实际成交价=交易额*折扣率|
|折扣金额|此时折扣额是一个绝对值。例如：彩电折扣为300元/台。|
|折扣率|此时折扣是一个相对的比率，折扣额需要根据单价/金额和折扣率共同计算才能得到。例如：单价1000元/台、正扣、7折，则折扣额为300元/台。|
|失效|当前折扣档是否生效|
|生效日期|当前折扣档的生效日|
|失效日期|当前折扣档的失效日|

# 操作说明

*  通过菜单[交易折扣](/detail/1f5235afd62a4dd6aafae19393c52fc6)进入交易折扣界面；
*  操作步骤
