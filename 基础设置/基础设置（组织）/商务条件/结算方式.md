
# 功能描述

设置系统收付款结算过程中使用的结算方式档案。

# 关键应用

# 业务规则

*  结算方式编码不允许重复

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入结算方式编码。|
|名称|录入结算方式名称。|
|结算方式类|选择系统预置的结算方式所属类型。|
|业务属性|选择结算方式属于“现金业务”或“银行业务”。如果是“现金业务”将登记在现金日记账中；如果是“银行业务”将登记在银行日记账中。|
|支付手续费|如果结算业务需要支付手续费，加注此标记。|
|承担方|如果需要支付手续费，选择手续费的承担人。|
|支付方式|如果需要支付手续费，选择手续费的支付方式。|
|缴存现金|如果结算方式需要缴存现金，加注此标记。|

# 操作说明

*  通过菜单[结算方式](/detail/71fe9c7d822145eb8a11f20819da3063)进入结算方式界面；
*  操作步骤
 
   *  第1步：录入结算方式编码等相关信息。
   *  第2步：选择折结算方式类型、业务属性。
   *  第3步：保存结算方式。
