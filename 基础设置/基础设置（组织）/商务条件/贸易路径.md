
# 功能描述

用于设置多角贸易时业务单据的流转顺序。

通过定义贸易路径，可驱动下列单据在组织间协同：

销售订单协同为另一个组织的采购订单；

采购订单协同为另一个组织的销售订单；

采购收货协同为另一个组织的销售出货；

销售出货协同为另一个组织的采购收货。

# 关键应用

# 业务规则

*  贸易路径编码不允许重复
*  定义自动编号的单据类型（必做）

# 栏目说明

头栏目

|栏目|说明|
|---|---|
|编码|贸易路径编码|
|名称|贸易路径名称|
|当前组织|贸易路径开始的第1个组织，也就是当前组织。|
|抛砖方向|正抛，是指出货或收货动作，由订单发起方来按贸易路径抛向其它组织；逆抛，和正抛恰恰相反，即由贸易路径的最末端的一个组织发起，逆贸易路径向前抛单据|
|首站使用范围|销售订单内抛：表示首站的SO先在当前组织内抛为PO销售订单外抛：表示首站的SO直接抛为对方组织的PO采购订单外抛：表示首站的PO直接抛为对方组织的SO|
|首站PO停顿点|Y：表示当前组织内抛形成的PO需要人工触发继续抛转N：表示当前组织内抛形成的PO被抛来后处于核准状态且自动继续抛向下一单据|
|首站PO停顿点状态|开立：表示当前组织内抛形成的PO被抛转过来时处于开立状态。核准：表示当前组织内抛形成的PO被抛转过来时处于核准状态|
|首站收货停顿点|Y：表示当前组织的外抛形成的收货单需要人工触发继续抛转N：表示当前组织外抛形成的收货单被抛来后处于核准状态且自动继续抛向下一单据|
|首站收货停顿状态|开立:表示当前收货单被抛转过来时处于开立状态。核准:表示当前收货单被抛转过来时处于核准状态|
|首出货停顿点状态|开立:表示当前出货单被抛转过来时处于开立状态。核准:表示当前出货单被抛转过来时处于核准状态|
|首站出货方式|抛转出货:首站SO的出货是由下游单据的收货抛转生成的。集中出货:首站SO的出货不是由其下游单据的收货抛转生成的，而是人工选择该SO开具出货单，这时允许首站销售订单做出货计划。|
|记录原始客户|销售订单内抛时，可以设置原始订单的客户是否传递到下游抛转的单据中。若选中，则表示抛转的下游单据中记录销售订单的原始客户（外部客户）。|
|内抛时销售赠品转为采购赠品|若选中，则表示销售订单的赠品行抛转生成的采购订单行也是赠品。|
|退货协同抛转|勾选时，表示退货可以协同抛转|
|退货抛转方向|目前产品支持的是：1.销售订单内抛：逆抛，即由尾站触发退货抛转2.采购订单外抛：正抛，即由首站触发退货抛转|
|采购退货停顿点|Y：表示当前组织抛转形成的采购退货单需要人工触发继续抛转N：表示当前组织抛转形成的采购退货单被抛来后处于核准状态且自动继续抛向下一单据|
|采购退货停顿点状态|开立：表示当前组织抛转形成的采购退货单被抛转过来时处于开立状态核准：表示当前组织抛转形成的采购退货单被抛转过来时处于核准状态|
|销售退货停顿点|Y：表示当前组织抛转形成的销售退货单需要人工触发继续抛转N：表示当前组织抛转形成的销售退货单被抛来后处于核准状态且自动继续抛向下一单据|
|销售退货停顿点状态|开立：表示当前组织抛转形成的销售退货单被抛转过来时处于开立状态核准：表示当前组织抛转形成的销售退货单被抛转过来时处于核准状态|

|PO停顿点状态|开立：表示当前PO被抛转过来时处于开立状态。核准：表示当前PO被抛转过来时处于核准状态。|
|收货停顿点|Y：表示当前组织的收货单需要人工触发继续抛转。N：表示当前组织的收货单被抛来后处于核准状态且自动继续抛向下一单据。|
|收货停顿点状态|开立:表示当前收货单被抛转过来时处于开立状态。核准:表示当前收货单被抛转过来时处于核准状态。|
|出货停顿点|Y：表示当前组织的出货单需要人工触发继续抛转。N：表示当前组织的出货单被抛来后处于核准状态且自动继续抛向下一单据。|
|出货停顿点状态|开立:表示当前出货单被抛转过来时处于开立状态。核准:表示当前出货单被抛转过来时处于核准状态。|
|价格控制|供方定价：按PO的价格为准。需方定价：按SO的价格为准。|
|结算方式|按原始售价倒扣：两组织之间按首站SO的售价乘以双方约定的扣率作为双方的结算价格.按约定价表：表示指两组织之间按双方约定的价目表作为双方的结算价格。|
|价目表|录入所需要的价目表。采购订单外抛时，贸易路径的第1条记录可以指定供方的销售价表。|
|结算币种|当销售订单内抛并且[结算方式]=“按原始售价倒扣”时可指定[结算币种]，默认为“供应商默认币种”。供应商默认币种：销售订单内抛的采购订单，采购订单的交易币和核币取供应商档案的默认币种。原始订单币种：销售订单内抛的采购订单，采购订单的交易币和核币等于销售订单的交易币和核币。|
|采购退货停顿点|勾选退货协同抛转时，可设置是否为采购(销售)退货停顿点及停顿点状态。销售订单内抛：退货协同由尾站触发，所以尾站的退货停顿点及停顿点状态不需要设置；中间站和首站 必须设置 是否为停顿点及停顿点状态。采购订单外抛：退货协同由首站触发，所以首站的退货停顿点及停顿点状态不需要设置；中间站和尾站 必须设置 是否为停顿点及停顿点状态。|
|采购退货停顿点状态|同上|
|销售退货停顿点|同上|

# 操作说明

*  通过菜单[贸易路径](/detail/c0a5fef9d9764b839dd93753d34e80a3)进入贸易路径界面；
*  操作步骤
 
   *  第1步：录入贸易路径编码等相关信息。
   *  第2步：选择一个站点组织。
   *  第3步：保存贸易路径。
