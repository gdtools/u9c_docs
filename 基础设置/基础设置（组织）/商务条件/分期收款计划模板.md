
# 功能描述

本功能节点完成对分期收款计划模板的增加、现金账号信息的维护、查询和输出以及人员的删除。

# 业务规则

*  编码不能为空。

# 栏目说明

分期收款计划模板－基本

|栏目|说明|
|---|---|
|编码|分期收款计划的编码|
|名称|账号名称|
|是否生效|当前公告版块是否已经生效|
|生效日期|当前现金账号的生效日期|
|失效日期|当前现金账号的失效日期|

分期收款计划模板－行

|栏目|说明|
|---|---|
|行号|分期收款计划的编码|
|分期类型|分期收款计划的分期类型|
|收款比例|分期收款计划的收款比例|
|备注|分期收款计划的备注|

# 按钮说明

*  <下发>：弹出下发功能节点界面。
*  <取消下发>：弹出下发功能节点界面。

# 操作说明

*  通过菜单[分期收款计划模板](/detail/7b88ff9911124e61ba767be9b6f58f66)进入四级菜单界面；
*  操作步骤
 
   *  第1步：录入编码、名称信息。
   *  第2步：录入分期类型、分期比例等行信息。
   *  第3步：点击保存按钮。
