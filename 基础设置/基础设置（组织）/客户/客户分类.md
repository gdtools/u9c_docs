
# 功能描述

设置客户分类档案。

# 关键应用

# 业务规则

*  定义客户分类编码结构（必做）
*  客户分类编码采用编码结构段录入。
*  客户分类编码不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入客户分类编码。点击按钮，弹出编码结构段值录入画面，按照段对应值集，录入各段取值。|
|名称|录入客户分类名称。|
|描述|录入客户分类的描述性说明信息。|

# 按钮说明

*  <下发>：导航到下发功能节点。
*  <取消下发>：导航到取消下发功能节点。
*  <下发参数>：导航到下发参数功能节点。
*  <客户>：导航到[客户](/detail/b5256b547b394d6c9dff0c3beaeb50cf)档案设置功能节点。
*  <供应商分类>：导航到[供应商分类](/detail/90dd168fb5544b0794ea9d64ba0e786b)档案设置功能节点。
*  <料品分类>：导航到[分类](/detail/c242fe5169134b37910750a6f1ec53d2)档案设置功能节点。

# 操作说明

*  通过菜单[客户分类](/detail/e16ec18ab1b542b5bca83ba67ac0e7e1)进入客户分类界面；
*  操作步骤
 
   *  第1步：录入客户编码、名称等信息。
   *  第2步：保存客户分类
