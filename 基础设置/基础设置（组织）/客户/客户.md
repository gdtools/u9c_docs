
# 功能描述

设置客户档案。

客户档案主要包括：

１、客户主档信息

２、客户位置档信息

３、客户联系人信息

４、客户银行账户信息

５、客户之间关联关系信息

在多元化经营的环境下，企业内部生产、销售、仓库、财务等业务职能部门可能分布在不同地点、不同城市、不同地区，这样就形成了对客户位置的管理。

对于一个客户不仅要建立客户自己的相关管理信息，还需要建立客户不同业务职能地点的位置信息。

例如：某客户A ，注册地在北京，主要管理机构财务部门在上海，在全国各地有经销网点，在上海、北京、广州设有物流仓库。在这样的一个客户办公地点分布情况下，可以建立以下的客户及客户位置档： 主档：客户A 位置档1：上海，位置属性：发票位置、出货位置； 位置档2：北京，位置属性：出货位置； 位置档3：广州，位置属性：出货位置；

客户位置可以具有以下业务属性，履行不同的业务职能：

1、出货位置：客户出货的位置。 在销售系统的销售订单、订单计划行的出货信息中需要记录具有此标识的位置信息。

2、发票位置：给客户开具销售发票的位置。 在应收系统的应收单、应收核销处理中需要根据有此标识的客户位置进行业务处理。

3、索赔位置：客户索赔的位置。

4、付款位置：客户汇款的位置。

5、对账位置：与客户进行业务对账的位置。

客户的一个位置，可以只具有一个业务属性，也可以同时具有上述多个业务属性；

客户的多个位置也可以同时具有相同的业务属性，但只能有一个位置是默认的；

客户设置了一个“出货位置”一定要设置一个与之对应的“发票位置”，或者“出货位置”同时具有“发票位置”的业务属性；

# 关键应用

# 业务规则

*  客户编码不允许重复
*  定义客户分类（必做）
*  定义客户编码结构（必做）
*  定义货币档案（必做）
*  定义收款条件（必做）
*  定义出货原则
*  定义应收账款立账条件

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|录入客户编码。客户编码需要根据编码结构段录入，点击功能按钮，弹出客户编码结构录入画面，按照编码结构中各段对应的值集录入。如果用户能够确切知道各段值，也可以手工直接在画面中录入段值编码。|
|名称|录入客户名称。|
|简称|录入客户简称。|
|搜索码|录入用于快速查找该客户的代码。|
|客户分类|录入客户所属分类。参照客户分类档案录入。点击字段下划线，弹出客户分类档案编辑查询画面，可以在线新增客户分类档案。|
|地区|录入客户所属地区。参照地区档案录入。点击字段下划线，弹出地区档案编辑查询画面，可以在线新增地区档案。|
|行业|选择客户所属行业。系统预置了工业、商业两个行业供选择。如果需要增加其他行业，点击字段下划线，弹出行业自定义代码设置画面，用户可以新增其他行业信息。|
|联系对象|录入客户联系对象。参照联系对象档案录入。通过联系对象系统可以建立客户与供应商与内部组织的关联关系。点击字段下划线，弹出联系对象编辑查询画面，可以在线新增联系对象档案。|
|语言|录入客户使用的语言信息。参照语言档案录入。点击字段下划线，弹出语言查询画面，查询使用语言的详细信息。|
|一次性客户|如果用户在经营活动中有大量的只进行一次或很少交易的客户，又不需要为其每个都建立档案进行管理，可以在客户档案加注一次性标识。|
|注册资金币种|录入客户注册资金使用的币种信息。参照币种档案输入。|
|注册资金|录入客户的注册资金信息。系统将可以按照资金规模进行客户状况的统计、查询。|
|营业额币种|录入客户营业额使用的币种信息。参照币种档案输入。|
|营业额|录入客户的营业额信息。系统将可以按照营业额规模进行客户经营情况的统计、查询。|
|员工人数|录入客户企业的员工人数信息。|
|成立日期|录入客户企业的创立日期。|
|工商注册码|录入客户企业的工商注册代码。|
|办公地址|录入客户的具体办公地址信息。参照地址档案录入。点击字段下划线，弹出地址编辑查询画面，可以在线新增客户注册地址信息。|
|注册地址|录入客户的注册地址信息。参照地址档案录入。|
|客户状况|用于标识当前客户是否是核准客户。系统提供对客户的审核功能。只有审核通过的客户，才允许交易。|
|挂起|用于标识当前客户是否被挂起。如果某客户的账目出现异常，可以先对该客户执行挂起处理，然后进行账目的调整。被挂起的客户除收款活动外，不允许执行任何交易活动。被挂起的客户，可以通过“解除”操作，取消挂起，重新恢复与其的交易活动|

商务页签

|栏目|说明|
|---|---|
|部门|录入客户所属销售部门。参照部门档案录入。如果没有输入销售部门，而输入了销售员，可以根据销售员所属部门带出本字段。次时本字段置灰，如果需要修改部门内容，需要首先将销售员字段清空。|
|业务员|录入负责本客户销售业务的业务员。参照业务员档案录入。|
|允限销类型|如果针对某客户，只允许销售某类或某几类商品，选择“允销”；此时，用户还需要在销售系统设置允许销售的商品目录。如果针对某客户，需要限制销售某类或某几类商品，选择“限销”；此时，用户还需要在销售系统设置限制销售的商品目录。如果针对某客户，不需要进行允销或限销商品的控制，选择“不控制”。此时，用户不需要设置允销或限销商品目录。|
|成交方式|选择客户的成交方式。系统预置了成交方式供选择。。如果需要增加其他成交方式，点击字段下划线，弹出成交方式自定义代码设置画面，用户可以新增其他成交方式信息。|
|交易币种|录入与客户进行交易的默认币种。参照币种档案录入。|
|价目表|录入与客户进行交易的价目信息。参照价目表档案录入。点击字段下划线，弹出价目表编辑查询画面，可以在线新增客户的价目表信息。|
|价目表可改|标识在业务单据中是否可以修改价目表中的价目数据。如果针对某客户，不允许在销售时，业务员随意修改某商品的价格数据，则加注次标识；如果允许业务员调整对该客户的价目信息，则不需要加注此标识。|
|必须有合同|若与客户进行销售业务时，必须签订合同，则加注此标识。|
|出货原则|设置对客户的出货控制参数。主要包括：是否允许提前出货、最大提前天数、是否允许延迟出货、最大延迟天数、是否允许超量出货、最大超量比例、是否允许缺量出货、最大缺量比例、是否允许替代出货等。参照出货原则档案录入。点击字段下划线，弹出出货原则编辑查询画面，在线新增出货原则档案。|
|出货原则可改|标识在业务单据中是否可以修改出货原则中设置的参数内容，以及是否严格按照出货原则参数进行控制。如果针对某客户，不允许修改出货原则参数，加注此标识。如果允许修改，则不需要加注此标识。|
|运输提前期（天）|录入运输的提前期天数。|
|退货条件|录入给予客户的退货约束条件。即该客户在哪些条件下，哪些商品允许退货。参照退货货条件档案录入。点击字段下划线，弹出退货条件编辑查询画面，可以在线新增退货条件档案。|
|出货条件|录入需要在出货前进行检查的出货条件，若不录入则不需要检查。参照出货条件档案录入。点击字段下划线，弹出出货条件编辑查询画面，可以在线新增出货条件档案。|
|税组合|录入某客户的税组合信息。参照税组合档案录入。|
|国税号|录入客户在税务登记机构注册的国家统一纳税号。|
|地税号|录入客户在税务登记机构注册的地方统一纳税号。|
|启用门户|如客户需要启用门户管理，则加注此标识。|
|门户编号|启用门户成功后，系统自动显示客户的门户编号。|

财务页签

|栏目|说明|
|---|---|
|收款币种|录入该客户的收款的默认币种。参照币种档案录入。|
|收款条件|设置对客户的收款参数。主要包括给与的折扣条件、货款的支付方式等。参照收款条件档案录入。点击字段下划线，弹出收款条件编辑查询画面，可以在线新增收款条件档案。|
|收款条件可改|标识在业务单据中是否可以修改收款条件中设置的参数内容，以及是否严格按照收款条件参数进行收款控制。如果针对某客户，不允许修改收款条件参数，加注此标识。如果允许修改，则不需要加注此标识。|
|收款人|录入负责某客户收款活动的默认收款人。|
|缴纳保证金|如果某客户需要缴纳保证金，加注此标识|
|预收款|如果某客户需要缴纳预收款，加注此标识。|
|预收比例|录入某客户需要缴纳的预收款比例。|
|预收比例可改|如果允许在销售时修改客户需要缴纳的预收比例，则加注此标识，否则必须按照客户上的预收比例向客户收取预收款。|
|享受折扣|如果给予某客户销售折扣，加注此标识。|
|质保方式|录入客户要求的质保方式。系统提供以下三种方式：１、空：即客户不需要提供质保金；２、现金质保：即客户要求以现金做为质保金，质保金可以做为一笔应收款项，记录在某客户的应收账款账户中。３、押单质保：即客户要求以某笔交易单据的应收账款做为质保金，用户不必以自己的现金支付与客户的质保金。|
|应收立账条件|录入客户交易的应收账款的默认立账参数。参照应收立账条件档案录入。点击字段下划线，弹出应收立账条件编辑查询画面，可以在线新增应收立账条件档案。|
|立账条件可改|标识在业务单据中是否可以修改立账条件中设置的参数内容，以及是否严格按照立账条件参数进行立账控制。如果针对某客户，不允许修改立账条件参数，加注此标识。如果允许修改，则不需要加注此标识。|
|按余额开票|如果对客户应收账款是按余额进行收款开票的，加注此标识。|
|核销顺序|选择客户应收账款的核销方法。系统提供：１、后进先出：即从最后一笔开始按照日期逐笔往前核销应收账款；２、先进先出：即从最早一笔开始按照日期逐笔往后核销应收账款；3、 从小到大：即按照每笔应收款的余额，从小到大逐笔核销应收账款；4、 从大到小：即按照每笔应收款的余额，从大到小逐笔核销应收账款；5、　优先等级：即按照设定的应收账款的优先登记核销。|
|核销明细|选择客户应收账款核销的明细程度。系统提供以下内容：１、按客户２、按单３、按行４、按分期收款行|
|按账龄催款|标识某客户是否按照账龄区间范围进行应收账款催收。如果某客户需要按照账龄区间范围进行催款，加注此标识。|
|邮寄对账单|如果某客户需要邮寄对账单，加注此标识。|
|对账期间|选择发送对账单的期间间隔。可以一按日、周、旬、半月、月、季度、半年、年与客户进行对账，并邮寄对账单。|
|对账单格式|录入对账单的打印格式。参照打印方案录入。|
|催款函格式|录入催款函打印格式。|
|订单格式|录入销售订单打印格式。|
|发票格式|录入发票打印格式。|
|信用检查|如果在与客户的交易活动中需要检查客户的信用，则加注此标识。标识与某客户交易时，是否需要进行客户信用检查。如果某客户在签定销售订单时，需要检查其信用状况，则加注此标识。否则，不必加注此标识。|
|信用政策|参照录入客户的信用政策。如果已经在客户位置上设置了信用政策、信用等级，则不能在客户位置上再设置信用政策、信用等级。|
|信用等级1|指定与客户签单时的信用等级。如果是在与客户签单时控制信用，即信用政策中的信用控制点为“开单”或“开单+出货”，则录入信用等级1。|
|信用等级2|指定对客户出货时的信用等级。如果是在对客户出货时控制信用，即信用政策中的信用控制点为“出货”或“开单+出货”且开单与出货使用不同的信用等级，则录入信用等级2。|
|收款力度政策|可空，指定针对当前客户所使用的收款力度政策|
|逾期收款力度政策|可空，指定针对当前客户所使用的逾期收款力度政策当前栏目与“收款力度政策”栏目实际上都是引用收款力度政策，只是政策上“逾期”栏目取值有不同|

|信用等级1|指定与客户位置签单时的信用等级。如果是在与客户签单时控制信用，即信用政策中的信用控制点为“开单”或“开单+出货”，则录入信用等级1。|
|信用等级2|指定对客户位置出货时的信用等级。如果是在对客户出货时控制信用，即信用政策中的信用控制点为“出货”或“开单+出货”且开单与出货使用不同的信用等级，则录入信用等级2。|
|状态||
|挂起|用于标识客户位置是否被挂起。如果某客户位置的账目出现异常，可以先对该客户位置执行挂起处理，然后进行账目的调整。被挂起的客户位置除收款活动外，不允许执行任何交易活动。被挂起的客户位置，可以通过“解除”操作，取消挂起，重新恢复与其的交易活动。|
