
# 功能描述

提供对客户业务状况、财务状况的综合查询。

在客户档案设置、销售订单、应收单、收款单等相关功能节点，都可以链接查询客户状况。

# 关键应用

# 业务规则

*  定义客户档案（必做）
*  本状况表的的显示栏目可以通过系统提供的“查询”功能进行自定义。
*  本客户位置表的的显示栏目也可以通过系统提供的“查询”功能进行自定义。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|客户查询区|显示客户基本档案中的主要客户信息。|
|客户位置查询区|显示客户状况表中焦点行客户的每个位置的主要信息。在客户状况表画面，双击焦点行，客户位置信息随主画面行进行相应变动。|
|客户状况查询区||
|未立账金额|显示客户的已经销售但未立账的款项。|
|未出货额|显示客户的已经销售但未发出的货物款项。|
|应收款|显示客户的应收账款余额。|
|逾期应收款|显示累计查询日期客户的逾期应收账款金额。|
|坏账额|显示客户发生的坏账金额。|
|预收款|显示客户的预收款金额。|
|暂收款|显示客户的暂收款金额。|
|应收周转率|显示累计查询日期客户的应收账款周转率状况。|
|累计退货额|显示客户的累计退货金额。|
|业务日期查询区|提供客户各项业务的最近执行日期查询。|

# 操作说明

*  通过菜单[客户状况](/detail/48127f1994124e269c3bfae04c26d929)进入客户状况界面；
*  操作步骤
 
   *  第1步：点击“查询”。
   *  第2步：录入查询条件。
   *  第3步：点击“确定”。
