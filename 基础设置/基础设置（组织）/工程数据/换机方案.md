
# 功能描述

换机方案换机方案主要用于定义机台类资源在生产不同料品时需要的换装时间。

可定义料品的不同属性作为换机维度。

可以不同的资源定义其换机方案，但是换机维度只能使用一套。

# 关键应用

# 业务规则

*  定义料品
*  定义资源
*  定义换机维度

# 栏目说明

换机方案

|栏目|说明|
|---|---|
|编码|用户输入换机方案编码|
|名称|用户输入换机方案名称|
|标准方案|缺省=false|
|名称|同一换机方案下的不同换机维度集合名称|
|换机维度1~10|最多可以设定10个料品维度作为换机维度；换机维度可以设定为空/不同/相同三种匹配方式。|
|换机时间|用户输入该换机维度集合的换机时间|
|换机时间单位|缺省为小时；时间单位参照|

# 按钮说明

*  <换机维度设置>：对资源换机方案设置其换机维度。

# 操作说明

*  通过菜单[换机方案](/detail/e470c590e3c24e9088f19dc925f0212f)进入换机方案界面；
*  操作步骤
 
   *  第1步：录入换机方案编码、名称等相关信息。
   *  第2步：录入子表内容。
   *  第3步：保存模型件预配置。
