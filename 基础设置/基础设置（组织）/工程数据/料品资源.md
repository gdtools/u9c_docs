
# 功能描述

料品资源定义指定料品所用的到资源，并设定资源数量、资源用量、成本相关属性等。

定义料品资源的标准费率和实际费率；

# 关键应用

# 业务规则

*  定义资源
*  定义成本要素
*  同一个资源不能在工作中心资源和物料资源下同时引用

# 栏目说明

物料资源

|栏目|说明|
|---|---|
|料品|需要定义料品资源的料品名称。手工录入，参照［可生产标识］为“是”的料品录入；料品和料品分类择一而录，不允许同时录入或同时为空；|
|料品分类|需要定义料品资源的料品分类名称。参照参数表中定义“料品资源定义所用分类性质”的料品分类；料品和料品分类择一而录，不允许同时录入或同时为空；|
|顺序号|系统给定资源的顺序号|
|资源|
   
||
|---|
|资源名称，参照当前组织，［计算成本］为“是”且［计费时机］为“工单入库”的资源录入|
|
|仅卷积|布尔值，默认false；区分该料品资源仅在成本卷积、成本模拟时使用，不计算生产成本。|
|资源数量|资源的个数由资源带入，可修改；当资源分类为人工/机器时必须录入。|
|资源数量单位|由资源带入，不可维护。|
|资源分类|显示资源的分类：人工/机器/委外/空闲/其他。由资源带入，不可维护|
|资源用量基础|选择录入：料品/批次。|
|每资源用量|生产单位产品所需要消耗的每个资源的用量与单位资源生产量互算：每资源用量＝（1/单位资源生产量）/资源数量|
|资源用量单位|由资源带入，不可修改。|
|单位资源生产量|单位资源用量所产生的产品数量与每资源用量互算：单位资源生产量＝1/每资源用量×资源数量|
|资源计费基础|带出资源中设置的资源计费基础，可以修改|
|成本要素|带出资源中设置的成本要素，可改必须是末级成本要素|
|生效日期|录入物料资源的生效日期，不可大于失效日期|
|失效日期|录入物料资源的失效日期，不可小于生效日期|

# 按钮说明

*  <标准费率设置>：对所选的物料资源设置其标准费率。
*  <实际费率设置>：对所选的物料资源设置其实际费率。

# 操作说明

*  通过菜单[料品资源](/detail/ce4cd01eea1f453d96a435259c8c0b70)进入料品资源界面；
*  操作步骤
 
   *  第1步：选择料品、料品分类。
   *  第2步：录入子表内容。
   *  第3步：保存料品资源。
