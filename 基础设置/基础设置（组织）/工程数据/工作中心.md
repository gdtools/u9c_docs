
# 功能描述

工作中心被用于定义标准工序、定义工艺路线，在生产订单工序及生产领料单中可指定工作中心。

可定义不同类型的工作中心，如：内部工作中心、协同工厂工作中心、关系工厂工作中心；

可指定工作中心是否计算能力，及能力计算依据：工作日历/标准产能／24小时可用；

定义工作中心所用的资源；

# 关键应用

# 业务规则

*  定义资源
*  定义部门
*  定义组织（协同工厂／关系工厂）（可选）
*  定义工作日历（可选）
*  工作中心的编码不允许重复

# 栏目说明

工作中心

|栏目|说明|
|---|---|
|编码|工作中心在一个组织内的唯一编码。手工录入； 不可为空 。|
|名称|手工录入工作中心的名称|
|分组|说明工作中心所在的工作中心分组|
|部门|显示部门名称，参照本组织的部门档案录入；表示此工作中心所属的部门|
|类型|
   
||
|---|
|表明此工作中心的类型内部工作中心：指本组织内部的工作中心协同工厂：多工厂协同时，将协同工厂的工作中心定义为此类型，同时还应指定协同工厂。关系工厂：关系企业委外时，将关系工厂的工作中心定义为此类型，同时还应指定关系工厂|
|多工厂协同是指某工厂组织的产品，在生产时某工序是在另外一个工厂组织执行的，除设置协同工厂类型的工作中心外，还应在设置工艺路线时，设定包含此工作中心的工序。关系企业委外是指某工厂组织的产品，在生产时某工序委托另一工厂组织工厂加工，除设置关系工厂类型的工作中心外，还应在设置工艺路线时，设定包含此工作中心的工序，并设定类型为委外资源、委外方式为关系工厂的工序资源。|
|
|工厂|工厂的名称，参照组织档案录入。类型为协同工厂时，参照组织营业行为关系为工厂－工厂，且关系企业标志为否的组织。类型为关系工厂时，参照组织营业行为关系为工厂－工厂，且关系企业标志为是的组织。当工作中心类型为协同工厂或关系工厂时，指定本工作中心所属的协同工厂或关系工厂|
|关键工作中心|对于关键工作中心，将进行有限产能排产，和计算能力无关|
|关键类别|指定关键资源的类别是人工还是机器|
|生效日期|设定工作中心的生效日期，生效日期要小于等于失效日期|
|失效日期|设定工作中心的失效日期，失效日期要大于等于生效日期|
|计算能力|· 表明该工作中心是否要计算能力，当勾选为是时，能力相关的属性才有意义|
|工作日历|计算能力时按工作日历的工作时间计算。与24小时可用、标准产能只可录入其一。|
|24小时可用|计算能力时按24小时可用计算。与工作日历、标准产能只可录入其一。|
|标准产能|计算能力时按周标准产能计算。与24小时可用、工作日历只可录入其一。|
|理想产能|理想产能对标准产能的产能比率|
|正常产能|正常产能对标准产能的产能比率|

# 按钮说明

*  <标准费率设置>：对所选的工作中心资源设置其标准费率。
*  <实际费率设置>：对所选的工作中心资源设置其实际费率。
*  <协同标准费率设置>：对所选的工作中心资源设置其协同标准费率。
*  <协同实际费率设置：对所选的工作中心资源设置其协同实际费率。
*  <作业>：导航到[作业](/detail/69d18f6db4bc4b788dee957d3cbf4bf3)档案设置功能节点。

# 操作说明

*  通过菜单[工作中心](/detail/7aea06dfcbe5495185cab261982d1790)进入工作中心界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：选择部门。
   *  第3步：保存工作中心。
