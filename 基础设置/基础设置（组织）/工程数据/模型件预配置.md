
# 功能描述

1、对模型件进行预配置，产生ATO件料号、BOM及工艺路线。

2、在销售订单、采购订单、生产订单、购销合同等功能点，对模型件进行配置时，也会弹出此画面，对模型件进行配置，产生FAS件的料号、BOM及工艺路线

# 关键应用

# 业务规则

*  定义模型件BOM（必做）
*  定义模型件工艺路线（可选）
*  参数设定，与模型件预配置相关的参数

|参数编码|参数名称|说明|
|---|---|---|
|BOM001|FAS是否自动产生低层配置产品的生产定单|Y: 系统自动创建本层配置产品的生产订单，以及下层配置产品的生产订单。N:系统仅仅自动创建本层配置产品的生产订单。|
|BOM002|销售配置FAS件编码规则|1.单号加顺序号：如果配置产品存在配置件，配置件的产品编码按照“订单编码+行号＋顺序号”编码。2.模型件料号加顺序号：检索物料档案中“模型件”编码一致的物料编码，按“顺序号”中的最大值+1设置|
|BOM003|销售配置FAS件品名生成规则|1.模型件品名加选中的所有下级子件品名：选配得到的FAS件的品名由模型件的品中与选中的下级子件品名共同构成。2.模型件品名：选配得到的FAS件的品名与模型件品名相同。|
|BOM024|FAS件编码顺序号长度|参数销售配置FAS件编码规则设置为单号加顺序号时，定义顺序号的长度。|
|BOM028|销售配置默认选配方式|枚举值：所有选项：由销售订单进入选配画面时，展现所有选项的选配方式；可选项：由销售订单进入选配画面时，展现可选项的选配方式必选项:由销售订单进入选配画面时，展现必选项的选配方式|
|BOM026|选配过程中是否根据选配约束规则对选配数据做实时的检查和调整|是：选配过程中左树勾选时,实时的查找出相应的选配约束规则,检查和调整数据；否：选配过程中左树勾选时,不会实时的查找出相应的选配约束规则,在保存时进行检查和调整数据|
|BOM029|销售配置默认展现方式|选中节点信息: 进入选配画面时，展现选中节点信息。 本次选配结果: 进入选配画面时，展现本次选配结果 最终产品清单:进入选配画面时，展现最终产品清单枚举值：选中节点信息：由销售订单进入选配画面时，展现选中节点信息；本次选配结果：由销售订单进入选配画面时，展现本次选配结果最终产品清单:由销售订单进入选配画面时，展现最终产品清单。|
|BOM036|选配确认方式|枚举值：不受来源单据影响：即选配的确认方式与来源单据的确认方式无关，直接确认；受来源单据影响：即来源单据的确认方式决定选配的确认方式。|

# 按钮说明

*  <标准费率设置>：对所选的物料资源设置其标准费率。
*  <实际费率设置>：对所选的物料资源设置其实际费率。
*  <结果BOM查询>：当结果料号非空时，此按钮可用，弹出窗口显示此结果BOM。
*  <选配方式>：可以通过下拉选项选择不同的选配方式进行选配，当选配方式选择“所有选项”时，BOM树展现完整的BOM结构进行产品选配，当选配方式选择“必选项”时，BOM树只提供必须进行选配的可选类的BOM结构进行产品选配，当选配方式选择“可选项”时，BOM树显示所有必选及可选项的BOM结构进行产品选配。
*  <新增子项>：可以添加BOM子项中不存在的物料，添加完成后自动增加BOM子项，选配标志=true。
*  <展现方式>：可以通过下拉选项选择不同的展现方式，当展现方式选择“选中节点信息”时，选配行显示左树上选中结点的子件列表，当选配方式选择“本次选配结果”时，选配行显示模型件BOM中子项“必选”设置为“是”且已被选中的子件列表，当选配方式选择“最终产品清单”时，选配行显示本次选配结果的清单列表。

# 操作说明

*  通过菜单[模型件预配置](/detail/790eff6f4cbc442f86ba2b8661f978b6)进入模型件预配置界面；
*  操作步骤
 
   *  第1步：选择BOM母件。
   *  第2步：录入子表内容。
   *  第3步：保存模型件预配置。
