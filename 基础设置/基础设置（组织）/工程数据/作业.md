
# 功能描述

作业用来定义经常在生产中使用的工序，在定义工艺路线时，可参照作业带入默认值，以减少定义工艺路线的工作量。

# 关键应用

# 业务规则

*  定义资源
*  定义工作中心
*  定义存储地点（可选）
*  定义库位（可选）
*  作业的编码不允许重复

# 栏目说明

作业－基本页签

|栏目|说明|
|---|---|
|编码|手工录入作业的编码，不可为空|
|描述|手工录入作业的描述，不可为空|
|报告产出点|　　用于控制工序转序如果是报告产出点，必须输入工序完工数量及转下道工序的数量，并且支持打印工序转序单由相关人员签字确认。工序完工时，将上个报告产出点和本报告产出点之间没有倒冲的进行处理。最后一道工序必须为报告产出点。合并拆分工序必须是报告产出点如果工序需要质检，则该工序必须为报告产出点如果工序是委外工序，则该工序及前一工序和后一工序必须为报告产出点。|
|准备时间　|工序的准备时间，手工录入，不可为空|
|加工时间|工序的加工时间，手工录入，不可为空|
|时间单位|准备工时与加工工时的时间单位参照计量单位分组为“时间”的计量单位录入|
|工作中心|作业默认的加工工作中心参照工作中心档案录入|
|分组|带出工作中心所属的分组。不可维护|
|生效|表明该作业是否已生效|
|生效日期|对生效的作业定义其开始生效的日期，应小于或等于失效日期。|
|失效日期|对生效的作业定义其失效的日期，应大于或等于生效日期。|
|允许非连续加工|如果等于true，则可以间断生产，否则不行必须连续加工缺省=false；可改|

作业－车间页签

|栏目|说明|
|---|---|
|完工地点|在产品及委外工序完工时缺省的存储地点参照位置属性不等于“报废仓”的存储地点录入|
|完工库位|在产品及委外工序完工时缺省的库位参照完工地点的库位档案录入|
|领料地点|工序领料时缺省的存储地点参照位置属性不等于“报废仓”的存储地点录入|
|领料库位|工序领料时缺省的库位参照领料地点的库位档案录入|
|批号控制|为T时，要求后续工序转移必须录入批号|
|序列号控制|为T时，要求后续工序转移必须录入序列号|


作业－倒冲页签

|栏目|说明|
|---|---|
|倒冲材料|选择自动计算工序成本时该选项生效，工序完工时将自动归集材料对应的成本|
|倒冲人工|选择自动计算工序成本时该选项生效。工序完工时将自动归集人工对应的成本|
|倒冲机器　|选择自动计算工序成本时该选项生效，工序完工时将自动归集机器对应的成本|
|倒冲其他资源|选择自动计算工序成本时该选项生效，工序完工时将自动归集其他资源对应的成本|

作业－检验页签

|栏目|说明|
|---|---|
|检验|说明该工序是否需要检验|
|检验方案|在“检验”选择为“是”时必须输入表明所选用的检验方案|
|检验方案版本|在“检验”选择为“是”时必须输入表明所选用的检验方案版本|


作业资源

|栏目|说明|
|---|---|
|顺序|系统给定，表明工序资源的顺序号|
|资源组序号|用来定义资源组替代的序号，即组队组的替代|
|资源|资源名称，参照作业的工作中心资源录入定义作业所用到的资源|
|类型|由所选的资源带入，显示资源的分类：人工/机器/委外/空闲/其他。不可维护|
|数量|录入作业资源同时需要的资源数量；当资源分类为人工/机器时必须录入。不可大于工作中心定义的资源数量|
|数量单位|由资源带入，不可修改。|
|用量|录入，指所有资源同时开工时，每资源的用量|
|资源用量单位|由资源带入，不可修改。|
|用量计算基础|如果选批次，则每一批次计算一次资源用量，比如准备工时。如果选料品，则根据生产数量乘以资源用量来计算资源的使用量选择录入。|
|资源替代组|在资源替代过程中，把已设置的资源替代关系设置为组，方便后续资源替代录入|
