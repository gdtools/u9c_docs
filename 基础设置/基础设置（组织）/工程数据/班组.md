
# 功能描述

班组被用于派工单；

被用于新车间任务管理；

定义班组所用的资源

定义班组成员信息

# 关键应用

# 业务规则

*  定义资源
*  定义成员
*  定义部门
*  定义工作日历（可选）
*  班组的编码不允许重复

# 栏目说明

班组

|栏目|说明|
|---|---|
|编码|班组在一个组织内的唯一编码。手工录入；不可为空 。|
|名称|手工录入班组的名称|
|部门|显示部门名称，参照本组织的部门档案录入；表示此班组所属的部门|
|工作日历|默认带入部门的工作日历，可改。|
|生效|默认=true；如果等于false，则班组不能使用。|
|生效日期|默认=系统当前日期。|
|失效日期|默认=9999.12.31。|

班组资源--基本页签

|栏目|说明|
|---|---|
|资源|资源名称，参照当前组织［粗能力专用］为“否”的资源录入不能选择委外类型的资源不能选择[资源成本计费基础]=“总金额”的资源|
|资源数量|由资源带入，可修改；当资源分类为人工/机器时必须录入；不可大于资源上所设置的资源数量。|
|资源数量单位|由资源带入，不可修改。|
|生效日期|带入资源的生效日期，可改，不可大于失效日期|
|失效日期|带入资源的失效日期，可改，不可小于生效日期|

班组成员--基本页签

|栏目|说明|
|---|---|
|员工|员工，参照当前组织员工信息内容,员工为在职的人员只能参照此班组所属部门的员工|
|工号|由员工带入,不可修改|
|姓名|由员工带入，不可修改|
|进入时间|员工进入班组时间，可改，不可大于离开时间|
|离开时间|员工进入班组时间，可改，不可小于进入时间|

# 操作说明

*  通过菜单[班组](/detail/d95d79c1164c47db82540a34daabd89b)进入班组界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：选择部门。
   *  第3步：保存班组。
