
# 功能描述

资源资源可以是生产过程中除了材料以外的任何东西。如人工、机器、厂房等；

可定义多种类型的资源，如：人工类资源、机器类资源、委外类资源、空闲类资源等；

可定义资源的成本信息，如资源的标准费率、实际费率；

可以不同的资源定义其资源计费时机和计费基础。

# 关键应用

# 业务规则

*  定义成本要素（可选）
*  定义供应商（可选）
*  定义组织（关系工厂）（可选）
*  定义人员档案（可选）
*  资源的编码不允许重复

|失效日期|设定资源的失效日期，失效日期要大于等于生效日期|

# 按钮说明

*  <标准费率设置>：对资源设置其标准费率
*  <实际费率设置>：对资源设置其实际费率
*  <标准费率查询>：查询此资源的所有标准费率
*  <实际费率查询>：查询此资源的所有实际费率
*  <资源用途设置>：对资源设置其适制料品或料品分类关系，以及单位资源用量（即生产速率）；料品和料品分类允许重叠，优先使用料品生产速率数据。

# 操作说明

*  通过菜单[资源](/detail/2bce5f23d88d48909433c51f8177fb26)进入资源界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：选择资源分类、用量单位。
   *  第3步：保存资源。
