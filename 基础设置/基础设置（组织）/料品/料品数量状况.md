
# 功能描述

提供对料品的采购量、销售量、生产量、库存量等数量状况的综合查询。

# 关键应用

# 业务规则

*  定义料品档案（必做）
*  本状况表的的显示栏目可以通过系统提供的“查询”功能进行自定义。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|料品查询区|显示料品档案中的主要料品信息。|
|料品明细查询区|显示料品状况表中焦点行每个料品的版本、等级、成分等信息。在料品状况表画面，双击焦点行，本画面内容随主画面行进行相应变动。|
|库存数量|显示料品的库存数量和库存预留数量信息|
|销售数量|显示料品的销售未出货量、销售预测量以及销售预留数量信息。|
|采购数量|显示料品的采购定货量、采购预留量数量信息。|
|计划生产数量|显示料品的生产计划量、在制量等数量信息。|

# 按钮说明

*  <库存明细>：导航到库存明细功能节点。
*  <销售明细>：导航到销售明细功能节点。
*  <采购明细>：导航到采购明细功能节点。
*  <生产明细>：导航到生产明细功能节点。
*  <预留明细>：导航到预留明细功能节点。

# 操作说明

*  通过菜单[料品数量状况](/detail/b850e9ebf7c14d789a5690859dfee156)进入料品数量状况界面；
*  操作步骤
 
   *  第1步：点击“查询”。
   *  第2步：录入查询条件。
   *  第3步：点击“确定”。
