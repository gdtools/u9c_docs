
# 功能描述

设置料品的关联产品，比如说替代关系还是新旧关系。

# 关键应用

# 业务规则

*  定义料品（必做）
*  定义厂牌（可选）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|料品|参照录入料品|
|料品版本|如果料品有版本，参照料品版本档案录入。|
|料品厂牌|如果料品有厂牌，参照料品厂牌档案录入。|
|关联类型|选择两个料品之间的关联关系：（１）替代料品：即两个料品之间可以相互替代（２）新旧料品：即原料品是旧料，关联料品是新料|
|关联料品|参照料品档案录入与原料品关联的料品。一个原料品可以设置多个替代料品或有多新料品。当料品厂牌和关联料品厂牌相同时，料品和关联料品不可相同，|
|关联料品版本|如果关联料品有版本，参照料品版本档案录入。|
|关联料品厂牌|如果关联料品有厂牌，参照料品厂牌录入。|
|顺序号|定义优先选取的顺序|
