
# 功能描述

设置料品分类体系档案。料品分类体系是料品进行分类管理的基础数据，用户在实际使用系统前，应当根据自己企业的实际业务，明确划分料品的有效分类。

设置料品档案。

料品档案主要设置内容：

1. 料品主档
2. 料品分类
3. 料品版本
4. 料品关系
5. 关键子件
6. 组间转换率
7. 组内转换率
8. 自由项约束值

# 关键应用

# 业务规则

*  定义料品编码结构（必做）
*  定义料品名称编码结构（必做）
*  定义计量单位档案（必做）
*  定义币种档案（必做）
*  定义存储地点
*  定义业务员
*  定义拣货规则
*  定义理货规则
*  定义批号参数
*  定义序列号参数
*  定义ＡＴＰ规则

# 按钮说明

*  <左树右表显示>：界面左边为树状结构展示料品分类，右边为列表格形式显示料品信息。
*  <组内转换率>：如果某料品有自己特定的转换率，通过本功能设置料品在一个计量单位组内，不同计量单位与基准单位的特殊转换率。
*  <组间转换率>：通过本功能设置料品在不同计量单位组间的计量单位之间的特殊转换率。
*  <自由项值>：设置料品自由项的固定取值。如果需要对料品自由项进行取值约束，通过本功能设置这些固定的取值。
*  <审批参数>：设置物料档案的审批参数。
*  <关键子件>：如果料品形态属性为“商品”并且序列号参数设置为“使用阶层”，通过本功能设置料品的关键子件。
*  <料品关系>：设置料品的替代料。如果两个料品是新旧料品，设置它们之间的对应关系，
*  <料品版本>：如果料品需要进行数量版本控制，并且没有启用ＢＯＭ，需要手工通过本功能设置料品的版本信息。同时，如果系统启用了ＢＯＭ，则可以通过ＢＯＭ维护料品的版本信息，通过本功能可以进行料品版本信息查询。
*  <料品分类>：设置料品所属分类。一个料品可以设置采购分类、销售分类、库存分类、财务分类等不种不同的分类体系。
*  <下发参数>：设置料品档案中哪些字段可以下发给下级组织或复制给业务平行组织。档案下发或复制是Ｕ９系统实现多组织运做管理的重要基础，实现多组织间的基础数据共享。料品档案的下发参数设置包括：料品主档、料品库存信息、料品采购信息、料品销售信息、料品生产信息、料品计划信息等，可以设置对这些档案中哪些字段可以下发给其他组织使用，对于下发字段还可以设置是否允许其他组织在本组织中是否允许修改，以实现数据的集中统一管理。
*  <下发>：执行对料品档案的下发。料品档案可以在具有上下级管理关系的垂直组织间，由上级组织下发给下级组织。料品档案只能下发给具有营运、核算、法人、工厂、物流职能的下级组织。其他职能的组织如果要共享数据，则通过平行关系进行复制功能实现。
*  <取消下发>：取消当前料品档案对某组织的下发处理。即在目的组织删除已经下发的料品档案记录。
*  <生产损耗率>：只有当生产损耗率类型为阶梯损耗率时才能维护。
*  <物料－客户交叉>：批量维护当前物料多个客户的客户交叉表。
*  <工艺路线>：导航到[工艺路线](/detail/9afe2a379fba4ab0a4fed3c49bdb2b5a)档案设置功能节点。
