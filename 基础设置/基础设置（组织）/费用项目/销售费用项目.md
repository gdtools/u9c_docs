
# 功能描述

维护销售过程中可能涉及到的各项费用（如装卸费、运输费等），及各项费用的分担/分摊规则、所适用的费用税等信息；如果要在销售合同/销售订单/出货单等单据中录入费用项目，则必须先在此定义后才能在单据中引用。

# 关键应用

# 业务规则

*  销售费用项目编码不允许重复
*  定义币种
*  定义税组
*  定义计量单位

# 栏目说明

销售费用项目维护

|栏目|说明|
|---|---|
|编码|销售费用项目编码，可手工输入，注意编码不能重复。|
|名称|销售费用项目名称|
|费用项目|若该项费用和交易的具体物料相关，即费用的发生和计算依物料的不同而不同，则为“行费用”，如磨具费； 否则为“整单费用”，如教育费及附加。|
|对应料品|若该项费用和交易的具体物料相关，可选择当前费用相关的料品；点击栏目链接允许在线维护料品信息。|
|适用币种|参照输入；指定该项费用在发生时，以何种币种进行结算。|
|计费依据|指明销售单据中计算该项费用金额的“费基”；同时，在费用分配（单据内与单据间）时做为费用的分配依据计算被分配的费用金额默认=“2：按税后金额”，可选内容包括1、按税前金额；2、按税后金额；3、按税额4、按数量；5、按体积；6、按重量；7、按件数8、单据；9、指定|
|计算系数|费用项目实际发生额费用=［计费依据］*［计算系数］。当[计费依据]=1-3时，录入百分比；当[计费依据]=4-9时，录入数值|
|计量单位|若计费依据为数量、体积、重量时，设定计算费用的计量单位。例如：装卸费为6元/吨，[计费依据]=“按重量”，[计算系数]=6，[计费单位]=“吨”当[计费依据]=4-7时该栏目才能录入|
|费用性质|标明该项费用发生时的实际承担方。枚举值：“代收代付”——由客户全额承担，但由销售方代收代付；费用单独立帐时可立应收、应付。“自行负担”——由销售方全额承担；费用单独立帐时可立应付。“向客户收取”——由客户全额承担； 费用单独立帐时可立应收。|
|费用用途|参照录入当前费用项目所对应的运输方式。销售—成本报价单引用，录入报价单时可自动带入对应“费用用途”的费用。|
|客户承担率|定义当前费用项目实际发生客户承担比例。[费用性质]＝“向客户收取”时本栏目才可以输入|
|摊入售价|定义费用项目实际发生时是否要摊入到销售的价格里去，再单列，默认为“否”。费用类型=“整单费用”，默认为“否”，不可改为“真”.|
|计入成本|销售—成本报价单引用，为真的费用项目与成本模块取出的料品成本共同做为料品的总成本|
|费用种类|销售—成本报价单引用，默认=“国内费用”，若需计算外销CIF价，则发生的国外运费、国外保费等费用必须设为“国外费用”|
|计税|定义当前费用项目实际发生时是否需要单独计税，默认为“真|
|税组合|若该项费用需要单独纳税，则在此定义当前费用项目实际发生时所适用的税组|
|失效|当前费用项目是否失效|
|生效日期|当前此费用项目可以被启用的生效/起始日期。|
|失效日期|当前此费用项目可以被启用的生效/起始日期。|

# 操作说明

*  通过菜单[销售费用项目](/detail/dec4cae70264412c9966d1f6b4395689)进入销售费用项目界面；
*  操作步骤
 
   *  第1步：录入销售费用项目编码等相关信息。
   *  第2步：选择费用项目、对应料品、适用币种、计费依据。
   *  第3步：保存销售费用项目。
