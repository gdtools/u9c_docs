
# 功能描述

维护采购过程中可能涉及到的各项费用，及各项费用的分担/分摊规则、所适用的费用税等信息；如果要在采购合同/采购订单/收货单等单据中录入费用项目，则必须先在此定义后才能在单据中引用。

# 关键应用

# 业务规则

*  采购费用项目编码不允许重复
*  定义币种
*  定义税组
*  定义计量单位

# 栏目说明

采购费用项目维护

|栏目|说明|
|---|---|
|编码|采购费用项目编码，可手工输入，注意编码不能重复。|
|名称|采购费用项目名称|
|费用类型|若该项费用和交易的具体物料相关，即费用的发生和计算依物料的不同而不同，则为“行费用”，如磨具费； 否则为“整单费用”，如教育费及附加。|
|对应料品|若该项费用和交易的具体物料相关，可选择当前费用相关的料品；点击栏目链接允许在线维护料品信息。|
|适用币种|参照输入；指定该项费用在发生时，以何种币种进行结算。|
|计费依据|指明计算该项费用的“费基”，默认=“2：按税后金额”，可选内容包括按税前金额；按税后金额；按税额按数量；按体积；按重量；按件数单据；指定|
|计算系数|费用项目实际发生额费用=［计费依据］*［计算系数］。当[计费依据]=1-3时，录入百分比；当[计费依据]=4-9时，录入数值|
|计量单位|若计费依据为数量、体积、重量时，设定计算费用的计量单位。例如：装卸费为6元/吨，[计费依据]=“按重量”，[计算系数]=6，[计费单位]=“吨”当[计费依据]=4-7时该栏目才能录入|
|费用性质|1标明该项费用发生时的实际承担方。 系统提供如下三个选项值：“代收代付”——由供应商全额承担，但由采购方代收代付；“自行负担”——由采购方全额承担；“向供应商收取”——由供应商（全额或部分）承担；|
|供应商承担率|定义当前费用项目实际发生供应商承担比例。[费用性质]＝“向供应商收取”时本栏目才可以输入|
|摊入售价|定义费用项目实际发生时是否要摊入到采购的价格里去，不再单列，默认为“否”。费用类型=“整单费用”，默认为“否”，不可改为“真”.|
|计税|定义当前费用项目实际发生时是否需要单独计税，默认为“真|
|税组合|若该项费用需要单独纳税，则在此定义当前费用项目实际发生时所适用的税组|
|失效|当前费用项目是否失效|
|生效日期|当前此费用项目可以被启用的生效/起始日期。|
|失效日期|当前此费用项目可以被启用的生效/起始日期。|
