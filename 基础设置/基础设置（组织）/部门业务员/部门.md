
# 功能描述

设置各组织机构下的行政部门档案；

部门是系统进行业务管理、财务核算的基础业务单元；

# 关键应用

# 业务规则

*  部门编码不允许重复。必须按照部门编码层级设置，现设一级部门，再设二、三级部门。
*  定义工作日历（必做）
*  参数设定在系统参数设置功能节点应首先设置各组织下的部门档案的级次编码。


# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|按照部门编码规则，录入各级部门编码。|
|名称|录入部门名称。|
|工作日历|录入每个部门使用的工作日历。参照工作日历档案录入；如果没有建立某部门使用的工作日历档案，可以点击本字段下划线，弹出工作日历设置画面，在线新增工作日历档案。生产管理系统可以根据各部门的工作日历进行排班管理。人力资源系统可以根据各部门工作日历进行考勤管理。|
|地址|录入部门的办公地址。参照地址档案录入；如果没有建立某部门的地址档案，可以点击本字段下划线，弹出地址设置画面，在线新增地址档案。|
|生产相关|如果该部门生产领用需要计入制造费用，请加注此标识。如果该标志为“true”，后续杂发业务会将该标识带入杂发单，以便于制造费用的统计。|

# 按钮说明

# 操作说明

*  通过菜单[部门](/detail/fffd959d9f19411e89e79315cf33eef2)进入部门界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：录入生产相关信息。
   *  第3步：保存部门。
