
# 功能描述

设置各部门的业务员档案。

# 关键应用

# 业务规则

*  编码不能重复。
*  定义组织档案（必做）。
*  定义部门档案。
*  定义员工档案。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|部门|录入业务员所属部门。参照部门档案录入；如果没有建立相应的部门档案，可以点击本字段下划线，弹出部门设置画面，在线新增部门档案。|
|编码|录入业务员编码。同一个部门中业务员编码不允许重复。|
|名称|录入业务员名称。|
|联系对象|录入业务员对应的联系对象。参照员工雇佣档案录入；如果没有建立某业务员对应的员工雇佣档案，点击本字段下划线，弹出员工雇佣信息设置画面，在线新增员工雇佣信息 。|

表体

|栏目|说明|
|---|---|
|业务员类型|录入业务员类型。选择系统提供的业务员类型录入。一个业务员可以同时担当多个角色，但不允许重复|

# 按钮说明

*  <部门>：导航到[部门](/detail/fffd959d9f19411e89e79315cf33eef2)档案设置功能节点。

# 操作说明

*  通过菜单[业务员](/detail/efb2e2b4d2e0459ebcd41054a3c9e3dd)进入业务员界面；
*  操作步骤
 
   *  第1步：录入部门、编码等相关信息。
   *  第2步：选择业务员类型。
   *  第3步：保存业务员。
