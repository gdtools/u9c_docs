
# 功能描述

提供企业使用的批号的编号规则设置功能。由于不同类型企业对批号的管理方式不同，批号的编号规则也不同，系统提供了５种批号的管理方式供用户选择。可以手工编制批号；也可以自动编制批号，批号的编号规则采用了编码结构的设置形式，可以采用不同的段对应不同值集设置批号的组织内容，提供了系统应用的灵活性。

系统提供的５种批号管理方式如下：

（１）按料品创建组织统一编号：即全部料品不论在任何组织均采用统一的编号规则，通过此种方式可以实现批号的集中管理。

（２）按当前组织编号：即每个组织可以设置自己的批号编码规则，但一个组织下的全部料品采用同一个编号规则；每个组织在自己组织中设置自己的批号编码规则。通过此种方式可以实现各组织批号的自我管理。

（３）按当前组织下的料品编号：即每个组织可以设置不同种类料品的批号编码规则。针对不同料品采用不同批号，真正实现料品的精细化管理。

（４）按料品编号：即各组织下相同的料品采用统一批号管理，但不同分类的料品可以设置自己的批号编号规则，即实现了批号统一管理，又可以针对不同料品特性提供不同的批号编码内容。

（５）按当前组织下的存储地点编号：即每个组织可以按照本组织下不同的仓库分别设置批号的编号规则。但存储在统一仓库中的料品使用的是相同的编号规则。

# 关键应用

# 业务规则

*  系统参数中启用批号管理参数（必做）
*  定义批号的编码结构（必做）
*  定义料品
*  定义存储地点
*  批号编码规则最多只能根据系统提供的５种批号管理方式，设置５种形式。
*  自动编号时，在批号编码结构中有且必有一个“数字段”，记录批号的流水号，该字段对应的值集必须满足以下要求：

（１）值集类型为“无档案”

（２）段值类型为“整数”

（３）务必设置“最大值”、“最小值”

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入批号编码规则的编号。|
|名称|录入批号编码规则的名称|
|编号方式|根据系统提供的５种类型选择录入：（１）按料品创建组织编号：选择此种编号方式后，画面列表行中有且必有一条批号编码规则数据；以实现批号集中统一管理。（２）按当前组织编号：选择此种编号方式后，画面列表行中有且必有一条本组织使用的全部料品统一的批号编码规则数据。（３）按当前组织下料品编号：选择此种方式后，画面列表行中可以有多行编码规则数据。如果企业有５种料品，有２种有自己的编码规则，其他３种采用相同的编码规则，用户可以先分别设置那２类料品的编码规则，再设置一条料品字段为空的编码规则记录，则表示其余３种料品都采用此种编码规则，提高用户的录入效率。（４）按料品编号：选择此种方式后，画面列表行中可以针对本组织或其他组织下发来的料品分别设置不同的编号规则。如果有些料品采用统一编号规则，有些料品有特殊编码规则，可以采用上述设置一行料品字段为空的记录行的方式，提高录入效率。（５）按当前组织下的存储地点编号：选择此种方式后，画面列表行中可以针对本组织下的不同存储地点设置多行编码规则记录。|
|批号编码|录入批号的编号。|
|批号名称|录入批号的名称。|
|使用组织|显示可以使用此批号的组织名称。如果本字段为空，表示全部组织都可以使用本批号。|
|存储地点|录入可以使用此批号的存储地点名称。只有当批号编号方式为“按当前组织下的存储地点”编号时，可以参照存储地点档案录入。|
|料品|录入可以使用此批号的料品。参照料品档案录入。如果没有设置对应料品，可以点击字段下划线在线新增料品信息。如果本字段为空，则表示全部了料品使用此批号。|
|自动编号|如果需要系统自动编制批号，则加注此标识；如果手工编制批号，则不加注此标识。|
|预先批号编号规则|录入批号的具体编号规则。参照批号编号结构档案录入。自动编号时，业务处理时会根据此规则自动生成批号编码，不可为空；手工编号时，可以为空。|
|随机自动编号规则|参照单据编码规则录入。用于在单据保存时根据单据上的信息自动生成编号。|
|随机自动编号对象|录入自动编号的单据。|
|数字段|显示批号编号结构中数字段的段名称。自动编号时用于指定将该字段做为流水字段，不能为空，手工编号时，可以为空。如果在批号的编码结构中设置了多个数字段，可以选择将哪个数字段做为流水字段。|
|长度|显示数字段的段长度，用户可以根据需要修改数字段长度。自动编号时；手工编号时，可以为空。|
