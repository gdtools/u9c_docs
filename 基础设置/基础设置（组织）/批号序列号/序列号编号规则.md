
# 功能描述

提供企业使用的序列号的编号规则设置功能。由于不同类型企业对序列号的管理方式不同，序列号的编号规则也不同，系统提供了２种序列号的管理方式供用户选择。可以手工编制序列号，也可以自动编制序列号，编号规则采用了编码结构的设置形式，可以采用不同的段对应不同值集设置序列号的内容，提供了系统应用的灵活性。

系统提供的２种序列号管理方式如下：

（１）按料品创建组织统一编号：即全部料品不论在任何组织采用统一的编号规则，通过此种方式可以实现序列号的集中管理。

（２）按当前组织编号：即每个组织可以设置自己的序列号编码规则，但一个组织下的全部料品采用同一个编号规则；每个组织在自己组织中设置自己的序列号编码规则。通过此种方式可以实现各组织序列号的自我管理。

# 关键应用

# 业务规则

*  系统参数中启用序列号管理参数（必做）
*  定义序列号编码规则（必做）
*  序列号编码规则最多只能根据系统提供的２种批号管理方式，设置２种形式。
*  自动编号时，在序列号编码结构中有且必有一个“数字段”，记录序列号的流水号，该字段对应的值集必须满足以下要求：

（１）值集类型为“无档案”

（２）段值类型为“整数”

（３）务必设置“最大值”、“最小值”

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入序列号编码规则的编号。|
|名称|录入序列号编码规则的名称|
|编号方式|根据系统提供的２种类型选择录入：（１）按料品创建组织编号：选择此种编号方式后，画面列表行中有且必有一条序列号编码规则数据；以实现序列号集中统一管理。此规则会被下发到与本组织具有垂直关系的下级组织以及具有平行关系的其他业务组织通过此种方式可以实现序列号的集中管理。（２）按当前组织编号：选择此种编号方式后，画面列表行中有且必有一条本组织使用的全部料品统一的序列号编码规则数据。|
|序列号编码|录入序列号的编号。|
|序列号名称|录入序列号的名称。|
|使用组织|显示可以使用此序列号的组织名称。如果本字段为空，表示全部组织都可以使用本序列号规则。|
|自动编号|如果需要系统自动编制序列号，则加注此标识；如果手工编制序列号，则不加注此标识。|
|预先序列号编号规则|录入序列号的具体编号规则。参照序列号编号结构档案录入。自动编号时，业务处理时会根据此规则自动生成序列号编码，不可为空；手工编号时，可以为空。|
|随机序列号编号规则|参照单据编码规则录入。用于在单据保存时根据单据上的信息自动生成编号。|
|随机序列号编号对象|录入自动编号的单据。|
|数字段|显示序列号编号结构中数字段的段名称。自动编号时用于指定将该字段做为流水字段，不能为空，手工编号时，可以为空。如果在序列号的编码结构中设置了多个数字段，可以选择将哪个数字段做为流水字段。|
|长度|显示数字段的段长度，用户可以根据需要修改数字段长度。自动编号时；手工编号时，可以为空。|
