
# 功能描述

提供序列号生成、查询功能。

对于预先产生的序列号，在此根据序列号规则，产生序列号记录；

提供全部序列号信息的列表查询。

# 关键应用

# 业务规则

*  系统参数中启用序列号管理参数（必做）
*  定义序列号编码规则（必做）
*  定义料品序列号参数

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码原则|参照序列号编码规则档案录入。|
|使用组织|显示序列号编码规则中设置的使用该编码原则的使用组织名称。|
|序列号类型|选择生成的序列号的类型：（１）标准：即产生料品的标准序列号（２）箱号：即产生料品包装时，外包装箱的序列号|
|序列号编号规则|点击功能按钮，编码结构段录入画面，根据编码结构段对应的值集录入相应段值内容。|
|序列号|根据录入的段值内容，系统产生序列号。序列号为手工编号时，则手工录入批号编码。|
|客户|如果该序列号是某客户指定的序列号，则录入客户信息。参照客户档案录入。|
|供应商|如果该序列号是供应商提供的序列号，则录入供应商信息。参照供应商档案录入。|

# 按钮说明

*  <料品>：导航到[料品](/detail/c073bf1ac1f349569ad5439839776131)档案设置功能节点。
*  <批量生成>：提供批量生成序列号的处理功能。用户可以输入产生序列号的数目，系统将根据序列号编码规则，一次产生多个序列号，提高用户的使用效率。

# 操作说明

*  通过菜单[料品序列号参数](/detail/0035350eff584d778a12f5a293300e53)进入料品序列号参数界面；
*  操作步骤
 
   *  第1步：选择编码规则、序列号类型等相关信息。
   *  第2步：选择料品、客户、供应商等相关信息。
   *  第3步：保存序列号主档。
