
# 功能描述

提供批号生成、查询功能。

对于预先产生的批号，在此根据批号规则，产生批号记录；

提供全部批号信息的列表查询。

# 关键应用

# 业务规则

*  系统参数中启用批号管理参数
*  定义批号编码规则（必做）
*  定义料品批号参数（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码原则|参照批号编码规则档案录入。|
|使用组织|显示批号编码规则中设置的使用该编码原则的使用组织名称。|
|存储地点|显示批号编码规则中设置的使用该编码原则的存储地点名称。|
|料品|显示批号编码规则中设置的使用该编码原则的料品名称。|
|批号编号规则|点击功能按钮，编码结构段录入画面，根据编码结构段对应的值集录入相应段值内容。如果批号编码规则中定义批号为手工编号，则不可编辑本字段。|
|批号|批号编码规则中定义批号为自动编号时，根据录入的段值内容，系统产生批号；批号为手工编号时，则手工录入批号编码。|
|客户|如果该批号是某客户指定的批号，则录入客户信息。参照客户档案录入。|
|供应商|如果该批号是供应商提供的批号，则录入供应商信息。参照供应商档案录入。|

# 按钮说明

*  <批量生成>：提供批量生成批号的处理功能。用户可以输入产生批号的数目，系统将根据批号编码规则，一次产生多个批号，提供用户的使用效率。
*  <料品>：导航到[料品](/detail/c073bf1ac1f349569ad5439839776131)档案设置功能节点。

# 操作说明

*  通过菜单[批号主档](/detail/e497f86db5ac482b8f99e4831bf5744e)进入批号主档界面；
*  操作步骤
 
   *  第1步：选择编码规则等相关信息。
   *  第2步：选择客户、供应商等信息。
   *  第3步：保存批号主档。
