
# 功能描述

可以查询会计科目对应的预设科目被哪些分录模版使用及其在分录模版上的设置。

可以查询会计科目与预设科目的对应关系。

可以查询会计科目的段设置。

# 关键应用

# 业务规则

*  必须先定义可选配物料。有关“可选配物料”的概念请参考“应用专题-参数化选配”中有关“可选配物料”的描述。
*  必须要定义相关值集。值集决定了参数的类型。如：数字、字符串、参照等。
*  如果参数已经被选配公式、选配约束引用，或已经做过选配业务，则无法直接删除参数，此时可以失效参数。
*  虽然值集类型包括日期、布尔。但这两种类型对参数没有意义，不建议使用。
*  问题分类和公共属性的区别是：问题分类是将相关参数放在一起显示，而公共属性是对相关参数同时维护参数值。
*  在选配时，系统可以按物料或按问题分类两种方式来过滤参数。具体可参考“应用专题-参数化选配”中有关“选配参数：选配显示方式”的描述。

# 栏目说明

查询数据

1. 会计科目模版
2. 预设科目
3. 分录模版

查询条件：系统在查询方案中（查询方案）提供默认的查询条件。用户通过查询方案画面的“属性选取”操作自定义查询条件。

查询结果：不同的查询条件决定了查询结果的不同。用户可根据需要组织查询条件并生成报表。

# 操作说明

*  通过菜单[会计科目设置查询](/detail/3686514d650344ffa33c5aa0820bb183)进入会计科目设置查询界面；
*  操作步骤
 
   *  第1步：点击“查询”。
   *  第2步：录入查询条件。
   *  第3步：点击“保存”，保存会计科目设置查询。
