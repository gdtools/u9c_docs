
# 功能描述

设置预设科目与会计科目的对应关系。

在前面两章节，我们介绍了预设科目与预设科目的影响因素，但预设科目只是对业务活动的进行会计核算的一种归集，还不是真正的会计科目，本功能提供用户设置这些业务活动真正对应的会计科目的功能。

# 关键应用

# 业务规则

*  定义预设科目影响因素（必做）
*  定义账簿

# 栏目说明

[基本栏目](javascript:void(0);)

|栏目|说明|
|---|---|
|会计准则|参照会计准则录入。|
|预设科目|参照预设科目档案录入。|
|自动会计类型|参照系统提供的各系统的单据类型录入。|
|账簿|参照账簿档案录入。可以选择当前组织下的多币种账簿以及对应的法人组织的主账簿。如为HR组织时，可以选择其对应的结算组织的账簿。如为资产组织时，可以选择其对应的货主组织的账簿。当选择了账簿后，系统将根据账簿中设置的科目编码结构在以下“科目影响因素”页签中显示出科目段结构，用户可以根据科目段结构分别设置每个段对应的影响因素。|
|账簿版本|如果启用了账簿版本，则参照录入账簿版本号|
|方向|如果预设科目影响因素是按借、贷方设置的，需要录入方向。|
|科目段-影响因素|根据账簿中设置的科目编码结构，显示以下科目段结构及设置每个段对应的影响因素|
|科目段１－影响因素|根据科目编码结构设置段１对应的影响因素。参照预设科目中设置的影响因素录入。为保证设置内容的正确性，系统会根据科目段对应的值集，以及预设科目中设置的影响因素，进行自动预置。例如：科目段对应的值集是“部门”，某预设科目有一个影响因素也是“部门”，则在参照中系统将自动默认因素部门就是科目段对应的因素。如果科目段的对应值集的每一个取值，分别对应影响因素的每个因素值，则可以直接录入因素就可以了。但如果科目段的对应值集的每个取值不能与因素值一一对应，则此时本科目段对应的因素应当为空，不设置，以便在“科目取值规则”页签分别设置因素值与科目段值集值的对应关系。|
|科目段２－影响因素|根据科目编码结构设置段２对应的影响因素。方法同上。|
|科目段Ｎ－影响因素|如果科目段对应的值集是“标准科目”则需要在“科目取值规则”页签设置对应的标准科目。|
|科目取值规则||
|因素１－－Ｎ|分别显示预设科目在选中账簿中设置的影响因素。用户可以针对这些因素的具体取值分别设置对应于哪个标准科目段；|
|科目段**|显示在“科目段-影响因素页签”中没有设置对应影响因素的科目编码结构中的段，用户可以在这个页签中分别设置哪些具体因素值，分别对应这些科目段的哪些具体值集值。已经在“科目段-影响因素页签”中设置了对应影响因素的科目段将不再显示。|
|标准科目段|科目编码结构中的标准科目段是预设科目与会计科目对应的最基础科目，在此设置所有因素组合后，对应的标准科目。|

# 操作说明

*  通过菜单《基础设置：基础设置（组织）：自动会计：[会计科目模版](http://10.16.9.23/U9C/mvc/main/javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkCBO.Pub.AccountTemplate.AccountTemplate&sId3000nid&mId1001101159162222","%E4%BC%9A%E8%AE%A1%E7%A7%91%E7%9B%AE%E6%A8%A1%E7%89%88");)》进入会计科目模板界面；
*  操作步骤
 
   *  第1步：录入会计准则、预设科目等信息。
   *  第2步：点击“查询”。
   *  第3步：点击“保存”，保存会计科目模板。
