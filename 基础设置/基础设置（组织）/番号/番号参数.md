
# 功能描述

传统的MRP在物料的规划上只能实现按料以及料的固有属性来进行，不能实现按管理目的来规划物料。Seiban就是按管理目的进行物料规划的工具。如企业主要经营围绕几个大客户进行，则可以按大客户指定番号；如销售按区域管理、主要物料规划专人负责，则可以按区域指定番号；如按销售订单交期的上旬、中旬、下旬合并生产，则可以按交期指定番号等。

# 关键应用

# 业务规则

*  番号参数编码不能为空，不允许重复。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|规划范围|V5只支持销售业务规划，计划、生产、库存、采购不能独立seiban。|
|规划方式|提供两种方式生成番号：1、手工指定：需要先行创建番号档案，在销售计划行和销售订单发货计划行上手工指定番号。2、自动生成：不能自行创建番号档案，MRP规划时，系统自动按规划方式产生番号|
