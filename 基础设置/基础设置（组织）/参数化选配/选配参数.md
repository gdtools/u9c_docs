
# 功能描述

参数决定了一个物料的可变部分。客户通过选择不同的参数来满足其个性化的需求。如：生产家具的企业，允许客户定制家具的颜色、尺寸、形状等。生产服装的企业，允许客户定义款式、颜色等。这里面的颜色、尺寸、形状就是所谓的参数。一个物料可以有一组参数来描述。这类物料称作“可选配物料”。本功能就是用来定义及维护可选配物料的参数信息。

# 关键应用

# 业务规则

*  必须先定义可选配物料。
*  必须要定义相关值集。值集决定了参数的类型。
*  如果参数已经被选配公式、选配约束引用，或已经做过选配业务，则无法直接删除参数，此时可以失效参数。
*  虽然值集类型包括日期、布尔。但这两种类型对参数没有意义，不建议使用。
*  问题分类和公共属性的区别是：问题分类是将相关参数放在一起显示，而公共属性是对相关参数同时维护参数值。
*  在选配时，系统可以按物料或按问题分类两种方式来过滤参数。具体可参考“应用专题-参数化选配”中有关“选配参数：选配显示方式”的描述。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|料品|选择一个“可选配物料”。选择之后如果已经为该物料定义过参数，则系统会自动加载出这些参数，加载出来的参数可以进行增删改操作。如未定义参数，可以增加参数。|
|问题编号|系统编码，即行号。|
|问题名称|参数的名字。如：长、宽、面积等。|
|答案值集|即参数类型。目前系统支持数字、字符串、枚举、参照。具体是哪种类型，是通过值集的类型来决定的。|
|默认值|可以为参数指定一个默认值。在选配时系统默认显示该值。|
|是否必填|如果勾选，在选配时一定要为该参数录入一个值。如：选配电脑时，CPU、硬盘、内存必须要选择，而操作系统用户可以不选择。|
|影响SKU料号|即该参数是否做为影响SKU料号的因素。关于SKU物料的具体说明，请参阅“应用专题-参数化选配”中有关“SKU物料”的描述。|
|配置序号|配置串方式选配时，用来决定参数的显示顺序。序号越小，显示位置越靠前。|
|公共属性|公共属性把相似的参数组成一组。在选配时通过维护公共属性，系统自动维护该公共属性所关联的所有参数，从而简化选配的操作过程。关于公共属性的具体说明，请参阅“应用专题-参数化选配”中有关“公共属性”的描述。|
|是否计算列|如果勾选，表示该参数为“计算类型”参数。即在选配时系统根据其它参数的值自动计算出该参数的值。如：面积参数即是通过“参数：长*参数：宽”自动计算得出。计算类型的参数在选配时不可人工编辑。对“计算类型”参数，需要定义“计算表达式”。|
|计算表达式|如果勾选了“是否计算列”，则需要定义一个计算表达式。通过点击“计算表达式”的超链接弹出“计算表达式”窗口：虽然表达式可以完全手工录入，但并不推荐这样做。一方面容易录错，另一方面也很难记住所有参数、函数的名字。所以建议通过直接选择表达式窗口提供的参数、函数及各种操作符的方式来维护表达式。例如：生产桌子的企业，桌子的长、宽由用户根据自己的需求决定。所以，桌子的参数包括长、宽。但在选配时业务员需要直观的看到桌子的面积。为此可为桌子定义一个面积参数，且该参数为计算类型参数，计算表达式为：长*宽。在定义该计算表达式时，操作步骤如下：首先点击料品右侧的放大镜图标，并在弹出窗口中选择物料：桌子。然后，点击问题右侧的放大镜图标，并在弹出窗口中选择问题：长，并点击问题右侧的!图标。此时表达式编辑框中就会出现类似“{桌子}.s10.Value”字样的内容，其含义为“桌子参数：长的值”其中“{桌子}”代表桌子物料，s10代表参数：长，Value代表参数：长的值。将鼠标光标定位到表达式编辑框最后一个字符的后面，并点击图标，则表达式编辑框内容变为：“{桌子}.s10.Value *”。图标代表“乘以”。将鼠标光标定位到表达式编辑框最后一个字符的后面，并点击问题右侧的放大镜图标，并在弹出窗口中选择问题：宽，并点击问题右侧的图标。此时表达式编辑框内容变为：“{桌子}.s10.Value * {桌子}.s20.Value”。其中“s20”代表参数：宽。至此，表达式定义完成。完整的表达式为“{桌子}.s10.Value * {桌子}.s20.Value”，含义为“桌子的参数：长乘以桌子的参数：宽”。也可通过点击表达式窗口中的“显示值”页签来查看系统针对当前表达式内容的释义。在表达式窗口中，系统提供一些预置的函数，如：Round、ABS、MOD等。其中函数可以获取料品档案的任意字段值来参与表达式的计算。点击“取料品属性”函数时，表达式编辑框中的内容为：GetItemFieldValue(,)，其中“GetItemFieldValue”是取料品函数的名字，该函数有两个参数，“，”前面的参数是料号编码，即取哪个物料的字段。实际使用时，并不是人工录入料品编码，而是用某个参数值来代表料品编码。第二个参数是具体字段的英文名称，并用双引号括起（字段的英文名字可通过U9提供的数据字典来获取）。举例如下：生产电梯的企业，电梯的承载人数是由组成电梯的曳引机决定的。企业提供两种型号的曳引机：曳引机1可承载6人，曳引机2可承载8人。两个曳引机在物料档案中进行定义，并启用扩展字段1来记录承载人数。电梯的参数包括曳引机型号、承载人数等。对参数：曳引机型号，参数类型为“参照类型”，并参照物料档案。对参数：承载人数，参数类型为“数值型”，并设置为“计算类型”。其计算表达式为“GetItemFieldValue({电梯}.s10.Value,"PrivateDescSeg1")，其中第一个参数代表参数：曳引机型号的值，第二个参数是物料档案的扩展字段1的字段英文名称。在选配时，当用户对参数：曳引机型号选择曳引机1时，系统会根据计算表达式获取该曳引机1的承载人数信息，并自动更新参数：承载人数的值为6。|
|问题分类|用于将参数分组，同组的参数在一起显示。如汽车的参数可以分为：车身、发动机、变速箱等。车身包括：长度、宽度、高度、轴距等，发动机包括：发动机型号、排量等。|
|是否生效|随着企业业务的发展及变化，有些参数不需要让用户来定制或需要增加新的参数让用户来定制。对已有参数，由于已被系统使用，是无法直接删除的。针对此种情况，可以失效该参数。这样在下次选配时就不会出现该参数了。但查询历史销售选配时还是可以看到该参数的。|

# 操作说明

*  通过菜单[选配参数](/detail/d72869bd6dbc42beb5369fa241a6c004)进入选配参数界面；
*  操作步骤
 
   *  第1步：选择料品。
   *  第2步：录入料品相关信息。
   *  第3步：点击“保存”，保存选配参数。
