
# 功能描述

该功能用来执行实际的选配操作。在接到客户订单后即可通过该画面根据客户的实际需求进行选配。或在接单前也可通过该功能执行“预配置”的选配。

关于参数化选配的具体说明，请参阅“应用专题-参数化选配”中有关“选配”的描述。

# 关键应用

# 业务规则

*  必须定义了可选配物料的参数。
*  已设置了番号相关的参数。
*  定义了选配公式。
*  定义了选配约束。（可选）
*  定义了价表及折扣单。（可选）

|番号|选配保存成功后，此处显示系统自动产生的番号。|
|来源单号|订单选配时，此处显示订单编码、行号、客户信息。|
|来源行号|
|客户|
|价格|
|定价方式|从BOM中带入，只显示不可修改。|
|价表|默认带入SO行的价表，也可手工进行修改。当定价方式=母件定价时，无法修改价表。|
|价格|系统根据定价方式自动计算出的价格，不可修改。多层选配时，此处显示的是顶层物料的价格。|
|备注页签|
|备注|用来填写选配时的一些描述信息。在实际选配时，有时并不会把客户所有可能的个性化需求全部转换为结构化的参数形式体现。例如：生产家具的企业，可能只会把如：长、宽、颜色等定义为家具的参数。至于有的客户需要在桌面上打个孔，或需要把桌板的四个角变为圆弧型的这种特殊需求，就可以通过备注来进行描述。在选配保存时，备注信息会同时写到番号的备注字段上。由于番号会传递到后续的业务单据上，如：生产订单。这样车间生产时就可以参考番号的备注信息进行实际的加工操作。|
|基本页签（下）|
|选择配置范围|当可选配物料的参数很多或有多层选配时，系统提供了两种过滤参数的方式来过滤参数：按物料：多层选配时选择此选项。可以按物料来切换参数。如：电脑由主机、显示器组成。电脑和主机都可单独销售，所以都定义了相应的参数信息。在销售电脑时，就可以切换电脑或主机的参数。按问题分类：当参数较多时，可将参数进行逻辑上的分组。如：生产汽车的企业，可以将参数分为：发动机、变速箱、车轮制动等类别。在销售汽车时，可以按这些类别来切换参数。系统通过参数：选配显示方式，来控制采用哪种方式。具体可参考“应用专题-参数化选配”中有关“参数设置”的描述。当选择按物料来过滤参数时，选择配置范围中会显示顶层物料及所有下阶可选配物料。当选择按问题分类来过滤参数时，选择配置范围中会显示“选配参数”中指定的问题分类。无论选择哪种方式，选择配置范围中都提供“全部”选项，用来显示所有参数。|
|料品|用来标识参数所对应的可选配料品。|
|问题|即参数。系统会列出目前有效的参数，并按“选配参数”中的问题编号进行排序。|
|答案|即参数值。根据客户需求来录入或选择具体的参数值。初始值为在“选配参数”功能中定义的默认值。如果定义了“选配约束”，则可选择或能够录入的答案值受选配约束的控制。|
|公共属性|
|显示选项|当公共属性较多时，用来过滤公共属性。有三个选项：默认属性：只显示在“选配公共属性”功能中勾选了“默认显示”的公共属性。非默认属性：只显示在“选配公共属性”功能中未勾选“默认显示”的公共属性。全部：显示所有公共属性。|
|公共属性|即公共属性的名称。|
|公共属性答案|即公共属性值。根据客户需求来录入或选择具体的公共属性值。初始值为在“选配公共属性”功能中定义的默认值。如果在“选配公共属性”功能中定义了“值约束”，则能选择或能够录入的答案值受值约束的控制。|
|左侧树视图|
|树视图|在选配画面上，通过点击“三角箭头”图标，来显示或隐藏树视图。通过树视图，可按BOM结构显示选配内容，便于用户查看及核对。只有在选配保存后，才可以查看树视图内容。|

# 按钮说明

*  <维护公共属性>：用于对公共属性进行增、删、改操作。
*  <订单选配>：用于接单后根据客户需求进行选配的操作。
*  <预配置>：用于接单前根据销售历史、未来预测所进行的选配操作。
*  <配置串选配>：用于接单后根据客户需求进行选配的操作。
*  <按已有配置选配>：接单后，直接参考已有配置进行选配的操作。预配置无法按已有配置选配。
*  <订单改配>：用于修改已有的订单选配。
*  <预配置改配>：用于修改已有的预配置选配。
*  <配置串改配>：用于修改已有的订单选配。
*  <删除配置>：用于删除预配置的配置内容。订单配置无法删除，当删除订单时系统会自动删除订单的配置内容。在删除配置时，系统会尝试删除SKU料及番号。
*  <配置检查>：用于订单配置或预配置时，检查配置内容的合法性。为检查配置内容，必须要先定义“选配约束规则”。在选配时，可随时通过点击选配画面的“验证配置”按钮来检查当前的配置是否合法。如不合法系统会抛出异常并告诉具体违反了哪条约束规则。在选配保存时，系统会自动做配置检查，如不合法，系统同样会抛出异常信息。
*  <生成配置BOM>：根据订单的配置结果产生BOM。产生的BOM可以在“工程数据-物料清单”中查看及修改。

# 操作说明

*  通过菜单[参数化选配](/detail/f992d22275124e258254a4bca542fe8c)进入参数化选配界面；
*  操作步骤
 
   *  第1步：录选择料品。
   *  第2步：录入料品的相关信息。
   *  第3步：点击“保存”，保存参数化选配。
