
# 功能描述

选配公式用来定义参数值与BOM子项物料、用量之间的映射关系。在选配过程中，系统根据此映射关系构建出订单BOM。

# 关键应用

# 业务规则

*  必须先定义可选配物料。
*  必须先为可选配物料定义BOM。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|母项料品|即可选配物料。|
|子项料品|这四个字段组合运用，可用来定义参数值与子件物料的映射关系或修改子件用量。例1：销售电脑的企业，组成电脑的内存有2G、4G、8G三种规格让用户选择。电脑的BOM子件物料为2G内存、4G内存、8G内存。电脑的参数“内存”有三个选项：2G、4G、8G。则定义：子项料品=2G内存，条件表达式=“内存!=2G”，设值字段=子件用量，值表达式=0。上述定义的含义是如果内存参数没有选择2G内存时，则系统认为2G内存的用量为0。这样系统在产生订单BOM时，就会过滤掉这个子件物料。同理还要定义出4G内存、8G内存两个子件物料的选配公式。在选配时，如果用户选择的是2G内存，则系统会认为4G内存和8G内存的用量为0，用量为0的子件物料就不会出现在最终的订单BOM中了。例2：销售实木家具的企业，其材料是固定的，用户无法选择。但用户可自定义家具的长、宽等参数。长、宽的不同会决定最终材料的用量。做如下定义：子项料品=实木材料，条件表达式=any，设值字段=子件用量，值表达式=长*宽。上述定义的含义是：无论用户如何选择，子项料品“实木材料”都会固定包含进来，其用量为“参数长*参数宽”的值。这里面，“any”是系统预置的一个关键词，代表固定为真的含义。由于用户无法选择生产家具所用到的材料，所以将条件表达式设置为“any”。例3：销售电脑的企业，组成电脑的内存有2G、4G、8G三种规格，硬盘有500G、1T两种规格。电脑的BOM只包括2G内存、500G硬盘两个子件物料，代表的是电脑的默认配置。电脑有内存、硬盘两个参数，且参数的值集为物料参照。现做如下定义：子项料品=2G内存，条件表达式=any，设值字段=子项物料，值表达式=内存.值。上述定义的含义是根据参数：内存的值来替换子项料品，但用量保持不变。当用户选择4G内存时，则系统会用4G内存替换2G内存产生订单BOM。同理，系统也能在选配公式中通过引用BOM子项的扩展字段，来对子项扩展字段赋值。这样可以将选配的一些关键信息带到BOM子项上，进而带到生产执行环节中用于指导生产。关于条件表达式、值表达式画面的具体用法，可参考“选配参数功能”中“计算表达式”的用法。当可选配物料的选配公式比较多时，也可通过OBA的方式批量导入。|

# 按钮说明

*  <维护公式>：用于对可选配物料的选配公式进行增、删、改操作。

# 操作说明

*  通过菜单[选配公式](/detail/b6f9b327250d413cb572726b607b9f72)进入选配公式界面；
*  操作步骤
 
   *  第1步：选择母项料品和顶层料品。
   *  第2步：录入子表信息。
   *  第3步：点击“保存”，保存选配公式。
