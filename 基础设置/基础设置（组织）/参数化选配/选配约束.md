
# 功能描述

用来定义参数之间的默认值关系及参数值的合法性。

# 关键应用

# 业务规则

*  必须先定义可选配物料。
*  必须为可选配物料定义了参数。
*  在选配参数中设置的默认值是固定不变的，而通过约束设置的默认值是动态变化的。
*  在维护表达式时，也可以通过“取料品属性”函数来获取料品的某些字段值做为表达式的一部分。关于“取料品函数”的用法，可参考“选配参数功能”中有关“计算表达式”部分的描述。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|可选配物料||
|序号|可以为一个可选配物料定义多个约束。当有多个约束时，需要分别定义。此时序号相当于约束只见的顺序。在选配过程中，系统会按照序号的先后顺序进行约束的合法性检查。序号越小顺序越靠前。|
|编号|即行号，系统维护。无业务含义。|
|关系|这几个字段配合使用，用来定义约束符合的条件。系统在进行约束检查时，如果条件结果为true，则进行合法性检查，否则不执行。例如：销售电脑的企业，电脑参数包括CPU和主板，CPU包括AMD、intel两个选项。主板包括AMD主板、intel主板两个选项。要求当CPU选择AMD时，主板只能选择AMD主板。CPU选择intel时，主板只能选择intel主板。这里面有两个约束规则。第一个约束规则的约束条件为“CPU选择AMD时”，检查的内容为”主板是否选择了AMD主板”。第二个约束规则的约束条件为“CPU选择intel时”，检查的内容为“主板是否选择了intel主板”。约束条件可以是一个表达式，或由多个表达式组成。当由多个表达式组成时，各表达式之间需要用关系操作符：与、或来连接。表达式由三部分组成，参数、比较操作符，值。一个典型的表达式如：“CPU = intel CPU”。这里面的“CPU”是电脑的参数。“=”是操作符。“intel CPU”是比较的值。表达式之间可用与、或关系运算符来连接。也可以使用括号来改变整个表达式的计算顺序。按上例，约束条件分别定义如下：CPU选择AMD时：关系=空，左括号=空，料品=电脑，问题=CPU，比较符=“==”，答案值=AMD，表达式=空，右括号=空。CPU选择intel时：关系=空，左括号=空，料品=电脑，问题=CPU，比较符=“==”，答案值=intel，表达式=空，右括号=空。各字段详解如下：关系：可选择空、与、或。当一个约束的条件有多个时，可用与或“或”连接。例如：当“主板选择intel主板且硬盘选择256G时，内存必须选择4G”。这里面的约束条件就是两个，分别是“主板选择intel主板”和“硬盘选择256G”，这两个条件之间是“且”的关系，所以关系选择“与”。左括号：可选择空、左括号。当一个约束的条件有多个时，一方面通过括号来让整个约束条件变得清晰易懂。另一方面括号的使用可改变整个约束条件执行的先后顺序。例如：约束条件“A 与 B 与 C”，系统会先计算”A与B”的结果，然后再计算该结果与C的结果。如果约束条件为“A 与 （B与C）”，则系统会先计算B与C的结果，然后再计算该结果与A的结果。括号必须成对使用。比较符：支持==，>=,<=,>,<，!=这几种操作符。例如：“硬盘 != 256G”时，或“长度 > 2”时。答案值：当要比较的值是一个固定值时，可在答案值中直接录入或选择。表达式：当要比较的值是一个表达式时，如“面积>长*宽+2”时。这里面的“长*宽+2”就是一个表达式。右括号：同左括号。|

# 按钮说明

*  <新增约束>：用于增加可选配物料的约束规则。
*  <修改约束>：用于修改可选配物料已存在的约束规则。
*  <删除约束>：用于删除可选配物料已存在的约束规则。
*  <复制约束>：用于根据已有的约束规则产生新的约束规则。

# 操作说明

*  通过菜单[选配约束](/detail/930759f237b04e1d864f234e04c04d63)进入选配约束界面；
*  操作步骤
 
   *  第1步：选择可选配物料。
   *  第2步：录入序号。
   *  第3步：点击“保存”，保存选配约束。
