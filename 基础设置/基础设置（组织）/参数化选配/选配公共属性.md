
# 功能描述

用来维护选配用到的公共属性信息。

# 关键应用

# 业务规则

*  必须要定义相关值集。值集决定了公共属性的类型。
*  虽然值集类型包括日期、布尔。但这两种类型对公共属性没有意义，不建议使用。
*  要逐条录入两个属性之间的所有可能的默认值组合。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|基本页签|
|编码|系统编码，即行号。|
|名称|公共属性的名字。如：颜色。|
|值集|即公共属性类型。目前系统支持数字、字符串、枚举、参照。具体是哪种类型，是通过值集的类型来决定的。|
|默认值|可以为公共属性指定一个默认值。如果指定了，在选配时系统默认显示该值。|
|默认显示|指公共属性在选配时是否默认出现在选配画面中。在选配时，系统通过“显示选项”来控制显示哪些公共属性：默认属性：只显示勾选了默认显示的公共属性。非默认属性：只显示未勾选默认显示的公共属性。全部：显示所有公共属性。|
|值约束页签|
|条件属性|约束用来定义属性之间的默认值联动关系。例如：当公共属性“材质”选择“布面”时，公共属性“颜色”默认为“红色”。如果选择“皮面”时，默认为“白色”。这里的公共属性“材质”就是条件属性，属性值“布面”就是条件属性答案。“颜色”就是约束属性，属性值“红色”就是约束属性答案。在选配时，当为公共属性“材质”选择“布面”时，公共属性“颜色”的默认值就为“红色”。|
|条件属性答案|
|约束属性|
|约束属性答案|

# 按钮说明

*  <维护公共属性>：用于对公共属性进行增、删、改操作。

# 操作说明

*  通过菜单[选配公共属性](/detail/605c483815ce454a8f4009d33304ff7c)进入选配公共属性界面；
*  操作步骤
 
   *  第1步：新增选配公共属性。
   *  第2步：录入相关信息。
   *  第3步：点击“保存”，保存选配公共属性。
