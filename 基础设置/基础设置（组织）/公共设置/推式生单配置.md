
# 功能描述

用户可以根据自己的业务需要按预置条件，设置上游单据推出的下游单据的单据类型。满足不同的条件，可推出不同单据类型的下游单据。

# 关键应用

# 业务规则

*  需定义自动编号的单据类型（必做）

# 栏目说明

基本栏目

|**栏目**|**说明**|
|---|---|
|**来源单据**|选择来源单据|
|**目的单据**|选择目的单据|
|**来源组织**|可按来源组织设定不同的下游单据的单据类型。|
|**条件1**|系统预置了一些上游单据推出的下游单据的条件。根据所选的来源单据、目的单据不同，条件也不同。根据业务需要设置条件的值。|
|**条件2**|同上|
|**...**||
|**来源单据类型**|上游单据类型作为可配条件|
|**目的单据类型**|设置上游单据推出的下游单据的单据类型。|

# 操作说明

*  通过菜单[推式生单配置](/detail/ff513fe3d59c4d87845b8bb9da5a0674)进入推式生单配置界面；
*  操作步骤
 
   *  第1步：选择来源单据相关信息。
   *  第2步：选择目的单据内容。
   *  第3步：保存推式生单配置。
