
# 功能描述

分配集是一个物料范围。在定义分销清单时通过指定分配集来定义哪些物料受补货规则的约束。

# 关键应用

# 业务规则

*  分配集编码不能为空，不允许重复
*  定义物料（必做）

# 栏目说明

分配集

|栏目|说明|
|---|---|
|编码||
|名称||
|说明||

分配集明细

|栏目|说明|
|---|---|
|分配类型|可以选择料品、料品分类。按料品时必须穷举出所有相关的物料。此时必须要维护物料字段。按料品分类时必须选择一个或多个物料分类。此时必须要维护物料分类字段。在这种方式下，所有属于该物料分类的物料都遵守相同补货规则。|
|料品分类|分配类型为料品分类时必须维护。|
|料品|分配类型为料品时必须维护，只能选择DRP/DRP+MPS/DRP+MRP的物料。|

# 操作说明

*  通过菜单[分配集](/detail/d72ec0290b6b4b01ae1598e34667cc1e)进入分配集界面；
*  操作步骤
 
   *  第1步：录入编码等相关信息。
   *  第2步：录入字表相关信息。
   *  第3步：保存分配集。
