
# 功能描述

定义补货路径，同一补货规则可以应用在不同物料或物料分类中。

# 关键应用

# 业务规则

*  补货规则编码不能为空，不允许重复
*  定义存储地点（必选）

# 栏目说明

补货规则页签

|栏目|说明|
|---|---|
|编码||
|名称||
|描述||
|供应类型|本组织：由本组织的其它仓库补货。如果选择该选择，则“补货组织”固定为当前组织，且只能选择本组织的补货存储地点。其它组织调拨：由其它组织的仓库补货。|
|补货组织|供应类型＝其它组织调拨时，可选择与当前组织有“销售-物流”、“物流-物流”、“物流-工厂”、“销售－工厂”、“工厂－工厂”平行关系的目的组织。|
|补货存储地点|可以选择补货组织的存储地点，必填。|
|优先顺序|表示补货的先后顺序。DRP计算时按该顺序查找每个补货仓库的供应，计算净需求。|
|货主组织方式|执行DRP计算时，当需求在组织间传递时，货主：依需求组织：表示货主为净需求上指定的货主组织。 依供应组织：表示货主为相应的供应组织。|
|分配百分比|DRP计算时先按优先顺序查找每个补货仓库的供应，如果供应不足，则产生净需求。对净需求按分配百分比将需求转移到对应的补货仓库中。|
|补货提前期|定义在一条补货路径的两个仓库之间的运输提前期。DRP计算时，如果产生净需求，则将净需求按分配百分比转移到补货仓库中。此时补货仓库中该需求的需求日期为：净需求.需求日期 - 补货提前期。|
|提前期单位|补货提前期的单位。|

# 操作说明

*  通过菜单[补货规则](/detail/47d30fc395834b3f8aa0b8ac7de4a44d)进入补货规则界面；
*  操作步骤
 
   *  第1步：录入编码等相关信息。
   *  第2步：录入字表相关信息。
   *  第3步：保存补货规则。
