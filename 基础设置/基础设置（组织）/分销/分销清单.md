
# 功能描述

定义组织内或组织间不同仓库时间的补货路径。在DRP计算前必须要定义分销清单。每个组织定义自己的分销清单。

# 关键应用

# 业务规则

*  分销清单编码不能为空，不允许重复
*  定义存储地点。
*  定义物料。

|---|---|
|编码||
|名称||
|描述||
|生效||
|生效日期|生失效日期不能重叠。|

分销清单明细

|栏目|说明|
|---|---|
|存储地点|指需求的存储地点，即该存储地点的需求可以由哪些存储地点供应。只能选择本组织存储地点。|
|补货规则|补货规则定义了补货的策略，需要事先定义。如果两个存储地点的补货规则相同，则可以共用相同的补货规则。必填。|
|分配集|分配集是一个物料范围，需要事先定义。如果选择了分配集，表示在分配集内的物料受补货规则约束。如果没有选择，表示所有物料都受同样的补货规则约束。|
|生效日期|可以定义在不同时间段内补货规则不同。同一存储地点生失效日期不能重叠。|
|失效日期||

# 操作说明

*  通过菜单[分销清单](/detail/c23e8a58f25b45b3bc3dc5668fa30466)进入分销清单界面；
*  操作步骤
 
   *  第1步：录入编码等相关信息。
   *  第2步：录入字表相关信息。
   *  第3步：保存分销清单。
