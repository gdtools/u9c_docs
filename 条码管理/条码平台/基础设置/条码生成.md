
# 功能描述

*  条码生成节点主要用于非外部条码的手工创建。
*  支持对要创建条码的实体自定义查询。
*  存储地点、库位、人员、料品档案等根据基础档案设置的条码规则或者根据可用量等后台实体需从该节点进行条码的创建。

# 业务规则

*  条码规则.条码类别=单据条码，则条码.数量均为1，后续使用时无实际意义；
*  条码规则.条码类别=料品条码且数量类型=单据数量，则条码.数量=条码规则.料品数量。如果指定的来源单据数量不能被条码规则.料品数量整除，则最后一个条码主档.料品数量=余数。如：单据数量=10，料品数量=3，则创建4个条码，前三个条码的料品数量为3，第四个料品数量=1。
*  条码规则.条码类别=料品条码且数量类型=指定数量，则创建的条码.数量=单行.交易单位数量/指定数量，余数放在最后一个条码；如：收货行交易数量=10，指定数量=3，则创建3个条码，前2个条码的数量时3，最后一个条码的个数是4。
*  校验：当条码规则.条码类别=料品条码且数量类型=固定数量时，创建条码时需校验：
*  若本次预创建的条码个数+已生成的条码个数>条码规则.条码个数，系统提示用户且不创建条码，反之则创建条码主档。
