
# 功能描述

用于配置移动端条码子应用在提交后，回写条码主档流转状态、现存量的更新规则。可按需根据不同子应用和条件，指定多条规则。

# 业务规则

*  应用可以指定具体子应用，可以为空，空代表所有应用。
*  如果应用不为空，选择该应用对应的实体行。实体行可查看应用实际创建的使用档进行选择。

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|应用|选择具体子应用，可空。空代表所有子应用。|
|实体|选择应用对应实体行业。|
|条件|通过公式编辑器触发条件。|
|条件名称|用于定义条件名称|
|条码流转状态|条件满足情况下，条码主档状态赋值|
|是否更新存量|条件满足情况下，是否更新条码主档现存量字段。|
|方向|条件满足情况下，异动方向设置|
|备注|用于定义备注信息。|
