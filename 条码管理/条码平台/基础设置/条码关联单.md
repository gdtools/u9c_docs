
# 功能描述

*  目前条码关联单支持的场景：母子件装配场景、物料条码换码场景。
*  关联单数据可用于产品追溯查询。

# 业务规则

* 条码输入方式支持扫码输入和手工输入两种方式。扫码输入操作方法光标定位条码字段，然后扫描条码即可。
* 关系类型包括：装配、合并、拆分、换码

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**表头信息**|
|单据编号|系统预置条码关联单的单据编号规则，单据编号按预置规则自动生成，不可改。|
|关系类型|用于设置条码关联场景：装配：母子件装配场景；合并：条码合并场景；拆分：条码拆分场景；换码：条码换码场景|
|条码|装配场景：母件条码；换码场景：原条码；合并场景：并入目标条码；拆分场景：被拆分条码；|
|**表体信息**|
|条码|装配场景：子件条码；换码场景：新条码；合并场景：被并入条码；拆分场景：拆分新条码；|
