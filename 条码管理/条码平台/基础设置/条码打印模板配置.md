
# 功能描述

用于条码应用移动打签场景配置标签打印模板。

注意，用户需要提前沟通云标签平台产品。

# 业务规则

*  系统预置所有应用的条码打印模板（预置数据标签模板和条码规则为空）。
*  用户在页面头部设置应用默认打印模板，在行上依据子应用和物料设置专属打印模板；
*  条码应用优先获取专属打印模板，如果未设置则获取应用默认模板。

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**表头信息**|
|条码应用|系统维护字段，移动应用名称。|
|标签类型|系统维护字段，用于标签分类，目前产品支持物料标签、箱码、托码、仓库标签、库位标签、人员标签、工作中心标签、班组标签、资源标签、工序标签等。|
|标签模板|设置云标签平台定义的标签模板|
|条码规则|设置当前标签使用的条码规则|
|打印份数|设置移动端打印标签默认份数。|
|是否预置|系统维护字段|
|是否生效|设置当前应用默认标签是否生效。|
|**表体信息**|
|行号|系统维护字段，默认为10，步长为10|
|子应用场景|用于设置专属标签对应子应用场景。|
|物料|用于设置专属标签对应物料信息。|
|客户|用于设置专属标签对应客户。|
|条码规则|用于设置专属标签的条码规则。|
|标签模板|用于设置专属标签的标签模板。|
|打印份数|用于设置专属标签的默认打印份数。|
|是否生效|用于设置专属标签是否生效。|
|是否预置|系统维护字段|

# 按钮说明

<同步标签模板>：用于获取云标签平台最新自定义模板。
