
# 功能描述

装箱单用于生产现场装箱打包场景，记录装箱明细信息。

# 业务规则

*  装箱单可以在生成物料条码主档时自动创建，详见条码规则。
*  通过装箱应用在移动端针对装箱单进行装箱条码调整。
*  支持多层装箱场景；
*  支持扫码生成装箱单，亦支持手工录入装箱单行；

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**表头信息**|
|单号|系统维护字段|
|业务类型|系统维护字段|
|装箱日期|用于定义箱码生成日期。|
|仓库|用于定义箱码关联的仓库信息。|
|箱码|用于定义箱码ID|
|条码规则|用于定义箱码条码规则。|
|创建人|用于装箱单的创建人。|
|**表体信息**|
|箱码|多层装箱场景使用，用于定义箱码信息。|
|条码|用于定义装箱的物料条码信息。|
