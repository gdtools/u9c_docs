
# 功能描述
*  条码主档是记录条码信息的档案，记录依据条码规则创建的条码所有段的取值；
*  支持维护条码主档记录的可用性；
*  记录条码对应的数量信息；
*  支持记录条码的当前状态：创建未使用、使用中、作废等，暂时不支持更详细的状态（如：在制、在库、出售等）
*  支持指定打印标签对选中的条码主档进行批打和连打；
*  支持条码打印及条码补丁；
*  支持作废条码。


# 业务规则


*  条码主档创建时机：

1. 支持从条码生成节点拉式生成。
2. 业务单据节点单据打印：如果选择的是带条码的打印模板，则根据单据实体对应的所有条码规则推式创建条码主档；
3. 业务单据节点条码打印：根据单据实体对应的所有条码规则推式创建条码主档。

*  作废：所有条码均可作废，作废后不可使用；
*  打印：仅对未打印过的条码主档执行标签打印，打印标签按照条码主档对应的条码规则设置的标签模板进行打印。
*  补打：仅对已经打印过的条码主档执行标签打印。
*  支持对选中的条码主档执行批打、连打。例：选中两个条码分别为001，002，打印份数设置为2份；批打时打印顺序为：001,002；001,002；连打时打印顺序为001,001；002,002；

*  档案敏感性

   修改：可以变更部分显示段、现存量等信息。

   删除：条码未被引用且状态为作废的条码才能在画面进行删除处理。

*  标签设计

   条码标签设置在ubf工具中完成。

# 按钮说明

*  <操作-批量作废>：批量执行条码作废操作。
*  <操作-批量挂起>：批量执行条码挂起操作。
*  <操作-解除挂起>：批量执行条码解除挂起操作。
*  <补打>：对已打印条码执行补打操作。
*  <变更显示段>：执行条码显示段变更。
