
# 功能描述

针对产成品条码追溯子件装配关系场景，可以通过条码装配子应用创建子件条码装配信息；同时也可通过当前应用设置调度程序，依据发料子应用生成发料单异步创建产品的子件条码关联单，完善产品子件的装配追溯信息。

*  支持入库单生成产品条码与材料条码绑定场景；
*  支持生产订单生成产品条码与材料条码绑定场景；
*  支持委外收货单生成产品条码与材料条码绑定场景；

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|自动生成规则|选择条码绑定场景。|
|启用|如果为true，则系统启动调度程序定时执行。|
|实体全名|系统维护字段|
|实体显示名称|系统维护字段|
|实体匹配规则|依据公式编辑器编辑匹配条件。|

# 按钮说明

*  <生成装配关系>：依据设置起始和终止日期自动启动装配关系配置程序，生成条码关联单覆盖原历史数据。
