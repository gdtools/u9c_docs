
# 功能描述

期初在库条码应用为库存物料条码初始化工具，用于库存在手量数据快速生成物料条码，并选择PC端打印或移动端打印。

# 业务规则

*  依据库存在手量实体定义条码规则（实体：UFIDA.U9.InvTrans.WhQoh.WhQoh）。
*  如果需要在移动端打印标签，同步条码打印模板（条码打印模板配置）。
*  设置查询条件加载库存在手量数据信息。
*  依据焦点行创建条码或执行条码打印。
*  如果移动端打签，需要在生成条码前，选择标签模板，条码主档绑定标签模板信息。

# 按钮说明

<查询>：通过查询条件获取库存在手量信息。

<创建条码>：依据库存在手量焦点行创建条码主档。

<条码打印>：将当前库存在手量焦点行关联条码执行标签打印。
