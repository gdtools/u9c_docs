
# 功能描述

  条码子应用设计配置用于U9条码应用移动端UI个性化配置。标准产品针对每个条码移动应用提供UI提供预置模板。用户可以通过配置工具对预置模板进行修改：修改数据排序规则、新增显示内容、控制字段编辑、配置自定义属性回写等。


# 业务规则

*  系统针对条码应用的每个UI提供预置模板，模板修改后，保存即刻发版到移动端。
*  系统预置模板明细行不可被删除，但是用户可以编辑排序规则、单位精度、回写规则等。
*  用户可以在预置模板基础上新增明细行，保存后即刻发版到移动端。
*  只有230530版发布的新应用支持UI模板配置，具体应用范围详见条码应用参照明细。

# 栏目说明


|**栏目名称**|**说明**|
|---|---|
|**基本信息**|
|模板名称|用于定义模板名称|
|业务类别|新应用将交互页面标准化，分为来源单据页、单据行明细页和条码明细页。**来源单据页**：用于展示业务处理单据，如依ASN单收货场景，来源单据为ASN单。收货单确认场景，来源单据是收货单。**单据行明细页**：用于展示业务行明细信息，如依ASN单收货场景，单据行明细页为ASN单据行。**条码明细页**：用于展示业务行对应条码明细。|
|条码应用|用于参照支持UI可视化配置的条码应用。|
|生效组织|赋值为空，表示适配所有组织。如果指定组织表示该模板只适配该组织。|
|主实体|用于设置当前单据对应实体。|
|**系统解析SQL**|
|SQL|系统依据用户自定义模板自动解析SQL|
|**自定义解析SQL**|
|SQL|用户依据系统生成SQL，进行个性化编辑和修改。|
|**明细信息**|
|显示位置|移动端页面布局目前只支持头体结构，头部显示区域为卡片，表体显示区域为列表。通过此属性设置当前字段显示位置。|
|行号|用于设置UI端字段显示顺序，越小越优先。|
|字段编码|用于定义显示字段编码，预置字段此属性不可修改。|
|字段名称|用于定义字段UI端显示名称。|
|维度类型|用于标识UI显示字段维度信息，用于条码自动匹配。|
|段值|用于设置需要展示实体关联字段。|
|是否解析|系统维护字段，不可修改。|
|排序顺序|用于设置表体显示区域，当前属性是否参与排序。设置为0则表示不参与排序，大于0表示参与排序，数值大小表示排序优先级，越小越优先|
|排序方向|用于设置此属性排序方向|
|显示方式|用于设置此字段显示方式。**不显示 ：**表示当前字段在UI端不显示。**弹性显示：**表示当前字段有值则显示，为空值是不显示。**固定显示：**表示当前字段在UI端固定显示。|
|是否修改|用于设置此字段在UI端是否可修改。|
|控件类型|用于设置此字段在UI端适配控件。目前支持文本、日期、数字、参照、布尔、枚举|
|精度|用于设置数字类型字段，显示精度。|
|单位|用于设置数字类型字段显示单位。如：100 件，50台注意：设置显示单位为当前模板行字段的字段编码|
|参照类型|参照类型字段需要设置默认系统参照，已经支持系统参照包括：客户、组织、项目、番号、供应商、计量单位、存储地点、库位。|
|参照查询条件|当前属性依赖于当前模板属性作为查询条件的，通过此属性进行设置。如库位字段，依赖于存储地点字段进行查询。|
|参照过滤项|用于参照类型属性的显示数据过滤。|
|参照编码段|用于参照类型字段的编码与ID字段关联。|
|参照名称段|用于参照类型字段的名称与ID字段关联。|
|是否回写|用于设置当前字段是否需要回写。|
|回写字段映射|用于设置回写单据的相关字段。|
|系统预置|用于标识系统预置字段，预置字段不可删除，字段编码、维度类型、段值不可修改。|
|**汇总信息**|
|用于条码应用业务行汇总页签数据分组属性设置。汇总页签数据由明细页签自动带入，不支持人工添加。|
|分组项|用于设置参与分组的字段|
|分组项编码段|用于分组参照类型字段的编码与ID字段关联。|
|分组项名称段|用于分组参照类型字段的名称与ID字段关联。|
