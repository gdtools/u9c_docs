
# 功能描述

用于针对当前站点所有授权应用执行更新、下载或安装操作。

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|领域|子应用所属业务领域或模块名称|
|分组|应用场景名称|
|OpenID|子应用ID|
|编码|用于展示子应用编码|
|名称|用于展示子应用名称|
|应用类型|用于展示应用类型：条码APP和子应用|
|版本|用于展示当前站点应用当前版本号|
|商城最新版本|用于展示U9条码商城应用最新版本号|
|最新可更新版本|依据本地补丁依赖可更新应用版本号|
|可更新|如果标识为是，表示当前版本可升级到可更新版本。|
|存在更新|如果标识为是，标识当前版本可升级到商城最新版本。|
|||

# 按钮说明

*  <查询>：调用查询条件界面，重新设置查询条件，进行新的查询；
*  <检查更新>：系统检查是否有可更新版本，如果有更新应用对应的可更新和存在更新标识。
*  <上传导入>：系统环境不能联通外网的情况下，在外网下载最新应用补丁后，通过此按钮上传最新补丁。
*  <更新>：更新选中应用到可更新版本。
*  <全部更新>：更新所有应用到可更新版本。
*  <应用安装>：关于U9条码应用APP安装，系统支持两种方式：

方式一 ：通过扫码安装按钮展示U9条码应用下载二维码，通过移动终端扫码，下载U9条码应用APP安装。

方式二 :通过下载安装按钮手动下载U9条码应用，拷贝到移动终端，再进行安装。
