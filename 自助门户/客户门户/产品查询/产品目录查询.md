
# 功能描述

进入【客户门户】－>【产品查询】－>【产品目录查询】

显示客户可购买的产品信息，可通过配置查询方案查产品的相关属性。。

# 使用前提

*  客户档案上设置允限销类型（可选）
*  销售模块系统参数勾选上“允限销控制”（可选)
*  设置客户的允销或限销范围（可选)

# 栏目说明

产品目录

|**栏目**|**说明**|
|---|---|
|**料号**|料号|
|**品名**|品名|
|**规格**|料品的规格|
|**图片**|可通过链接打开料品的图片|
|**料品档案其他**||

# 按钮说明

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。
*  <调整列宽>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。
