
# 功能描述

进入客户门户－>应收管理－>信用查询；

“信用查询”的含义是：查询登录对象信用状况，如即将出货、逾期帐款、账期、临时额度、逾期天数等

# 业务规则

*  启用销售系统
*  启用客户门户
*  启用应收管理
