
# 功能描述

进入【客户门户】－>【应收管理】－>【信用明细查询】，查询信用对象当前客户的信用明细情况。

# 业务规则

*  启用销售系统
*  启用客户门户
*  启用应收管理

# 按钮说明

*  <查询>：

点击**客户门户－>应收管理－>信用明细查询－>查询**，选择条件过滤出对应的客户信用明细。
