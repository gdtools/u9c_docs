
# 功能描述

可以查询应收款发生、收回及余额的情况。

# 业务规则

*  启用应收管理

# 栏目说明

查询条件

|**栏目**|**说明**|
|---|---|
|**核算组织**|参照组织档案录入|
|**来源组织**|参照组织档案录入|
|**业务组织**|参照组织档案录入|
|**结算组织**|参照组织档案录入|
|**查询类型**|可以选择：
   *  按期间：即按期间来查询期初余额、本期应收、本期收回、余额. 
*  按单据：与期间无关，与截止日有关，无期初余额，将截止日期前的所有(结清或未结清)单据列出，查看单据原始金额、累计收回金额、余额
|
|**期间类型**|枚举值：
   *  会计期间（默认）
*  统计期间
*  自然日期
|
|**会计期间范围**|当［期间类型］＝会计期间，可用枚举值：
   *  当前期间
*  上一期间
*  去年同期
*  指定期间
|
|**会计期间**|当［期间范围］＝指定期间，可用参照选择|
|**统计期间规则**|当［期间类型］＝统计期间，可用参照选择|
|**统计期间范围**|当［期间类型］＝统计期间，可用|
|**统计期间**|当［期间类型］＝统计期间，可用|
|**自然日期**|当［期间类型］＝自然日期，可用|
|**业务类型**|可限定查询应收单的业务类型范围|
|**单据类型**|可限定查询应收单的单据类型范围|
|**包含未立账**|确定满足截止时间的未立账单据是否包括在查询范围内|
|**未立账单据**|当[是否包含未立账]＝true时，可指定包含哪些未立账的单据类别，如未立账销售订单、预出货单、出货单、退货单、销售发票、资产调出单、管销费用单，未开票销售订单、出货单、退货单等|
|**有余额无发生显示**|若查询期间无发生额，但有期初数，是否显示|
|**包含已结清**|查询类型=按单据时，有效|
|**对账方式**|查询类型＝按期间时，有效 可以选择：
   *  明细：普通查询方式，按汇总项进行本期应收、本期收回、余额(期初余额)查询
*  回款：按应收单据查看本期应收、本期收回(包括收回期初应收和收回本期增加的应收)、单据余额、余额(/期初余额)查询
|
|**对应单据显示方式**|收/付款单始终按行显示，可以选择：
   *  整单(默认)
*  单行
*  分期行
|
|**回款明细显示**|对账方式 = 回款时，或者查询类型 = 按单据时，有效；可以选择时或者否；
   *  是：每一笔应收单后显示针对此笔应收的详细的核销情况
*  否：每一笔应收单后显示针对此笔应收的详细的核销情况
|
