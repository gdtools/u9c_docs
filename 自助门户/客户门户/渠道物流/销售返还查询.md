
# 功能描述

提供销售返还主档数据查询功能。

# 使用前提

*  销售返还已启用
*  定义统计期间，参见统计期间

# 统计说明

**统计数据**

返还主档节点.直接客户=true，同时客户编码=登录客户编码

**统计条件**

系统在查询方案中（查询方案）提供默认的统计条件，不同的统计方式对应不同的统计条件。另外用户通过查询方案画面的“属性选取”操作自定义查询条件。统计条件默认销售返还单主档数据。

**统计结果**

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 按钮说明

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。
*  <调整列宽>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。
