
# 功能描述

进入【客户门户】－>【发货管理】－>【发货通知】

企业（U9C购买者）在U9C发货管理系统中，发布出货通知，用于通知客户出货已确认，可以准备收货，客户（客户门户的使用者）可以自助的查询出货通知，包含预计交货时间、运输方式、发货人、收货人、承运人等信息 ）

# 业务规则

*  启用销售系统
*  启用客户门户
*  销售系统发布出货通知

# 栏目说明

发货通知页签

|**栏目**|**说明**|
|---|---|
|**出货单号**|出货单号|
|**商品名称**|出货商品的总称|
|**总件数**|出货商品的总件数|
|**运输方式**|运输的方式|
|**收货地址**|客户收货的地址|
|**预计到货日期**|预计到货的日期|
|**联系人**|出货联系人|
|**联系电话**|出货联系人的联系电话|
|**通知时间**|发布出货通知的时间|

# 按钮说明

*  <查询>：

点击**客户门户－>发货管理－>发货通知 －>查询**，选择条件查询订单执行状况。

*  <详细信息>：

点击**客户门户－>发货管理－>发货通知 －>出货签收**，弹出选中行出货单行“门户出货签收画面”，进行签收
