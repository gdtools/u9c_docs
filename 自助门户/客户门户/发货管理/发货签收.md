
# 功能描述

*  进入【客户门户】－>【发货管理】－>【发货签收】
*  客户自助确认收货情况，客户门户支持多次签收，用于企业一次发货分多次送抵客户的情况。

# 业务规则

*  启用销售系统
*  启用客户门户

# 按钮说明

*  <查询>：

点击**客户门户－>发货管理－>发货通知 －>查询**，选择条件查询出货单行。

*  <出货签收>：

点击**客户门户－>发货管理－>发货通知 －>出货签收**，弹出选中行出货单行“门户出货签收画面”，进行签收

*  <快速签收>：

点击**客户门户－>发货管理－>发货通知 －>快速签收**，可以一次选择多行，确认选中行的料品可签收数量已全部收到，常用于客户货物已清点完毕，没有拒收和途损的情况

*  <相关功能-签收历史>：

点击**客户门户－>发货管理－>发货通知 －>相关功能 －>签收历史**，查询选中行料品在客户门户签收历史记录

*  <相关功能-出货行>：

点击**客户门户－>发货管理－>发货通知 －>相关功能 －>出货单行**，查询选中行的出货单明细信息

*  <相关功能-销售订单>：

点击**客户门户－>发货管理－>发货通知 －>相关功能 －>销售订单**，查询选中行对应的销售订单明细信息
