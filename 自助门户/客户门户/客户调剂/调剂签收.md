
# 功能描述

进入客户门户－>客户调剂－>客户签收；

“客户签收”的含义是：：当不需要配送时，调入客户自行录入实际送达、接受的信息

# 业务规则

*  启用销售系统
*  启用客户门户
*  启用库存管理

# 栏目说明

主页签

|**栏目**|**说明**|
|---|---|
|调入量|用户实际确认的收货数量|
|拒收量|由于各种原因需要拒收的量|
|实际送达日期|货物实际送达客户的数量|

# 按钮说明

*  <查询>：

点击**客户门户－>客户调剂－>客户签收－>查询**，选择条件查询需要签收的客户调剂单。

*  <签收>：

点击**客户门户－>客户调剂－>客户签收－>签收**，对所签收的信息进行确认，表明签收成功。

*  <序列号>：

点击**客户门户－>客户调剂－>客户签收－>序列号**，按调出的序列号逐个进行签收
