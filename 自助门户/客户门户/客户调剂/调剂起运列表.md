
# 功能描述

进入客户门户－>客户任务单－>任务单签收，

“任务单签收”的含义是：客户针对配送任务单自助确认签收的数量、拒收的数量以及拒收原因

# 业务规则

*  启用销售系统
*  启用客户门户
*  启用渠道管理
*  启用库存管理

# 栏目说明

**基本**

实际送达日期

**行**

|**栏目**|**说明**|
|---|---|
|子行号|子行号|
|料号|料号|
|品名|品名|
|版本|版本|
|等级|等级|
|成分|成分|
|自由项|自由项|
|批号|批号|
|库存单位|库存单位|
|起运数量|配送任务单行起运数|
|签收数量|客户实际签收的数量|
|拒收数量|因为各种原因拒收的数量|
|拒收原因|拒收的原因|

# 按钮说明

*  <查询>：

点击**客户门户－>客户任务单－>任务单签收－>查询**，选择条件查询对应的配送任务单。

*  <任务单签收>：

点击**客户门户－>客户任务单－>任务单签收－>任务单签收**，对所签收的信息进行确认，表明签收成功。
