
# 功能描述

进入【客户门户】－>【客户调剂】－>【客户确认】，

“客户确认”的含义是：调出方确认可调出的数量、批号等信息

# 业务规则

*  启用销售系统
*  启用客户门户
*  启用渠道管理

# 栏目说明

进入后首先展示的是客户调剂单的列表画面；

选择待确认的调剂单双击后即弹出该调剂单，客户录入对应的确认信息后即可确认；

栏目说明参见客户调剂单

|**栏目名称**|**说明**|
|---|---|
|单据编号|单据编号|
|业务日期|业务日期|
|单据类型|单据类型|
|调剂类型|调剂类型|
|调入组织|调入组织|
|调入客户|调入客户|
|调入地区|调入地区|
|运输方式|运输方式|

# 按钮说明

*  <查询>：

点击**客户门户－>客户调剂－>客户确认－>查询**，选择条件过滤出对应的客户调剂单。

*  <确认>：

点击**客户门户－>客户调剂－>客户确认－>确**认，对相应的客户调剂单进行确认。
