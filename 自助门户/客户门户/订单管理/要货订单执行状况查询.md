
# 功能描述

*  进入【客户门户】－>【订单管理】－>【要货订单执行状况查询】
*  显示客户可购买的产品信息，可通过配置查询方案查产品的相关属性。。

# 使用前提

# 栏目说明

查询条件

|**栏目**|**说明**|
|---|---|
|**单号**|要货订单的单据号|
|**料号**|要货订单的料号|
|**品名**|要货订单的品名|
|**规格**|要货订单料品的规格|
|**单据日期**|要货订单的单据日期|
|**交期**|要货料品要求交货日期|
|**状态**|要货订单行的状态|
|**关闭**|勾选时，表示查关闭的要货订单|
|**已转销售订单**|勾选时，表示查已转销售订单的要货订单|

# 按钮说明

*  <查询>：点击客户门户－>订单管理－>要货订单执行状况查询－>查询，选择条件查询要货订单执行情况。
