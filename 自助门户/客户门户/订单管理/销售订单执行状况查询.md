
# 功能描述

*  进入【客户门户】－>【订单管理】－>【执行状况查询】
*  客户在此查询销售订单的出货、签收、开票、收款数量 为目的）

# 使用前提

*  启用销售系统
*  启用客户门户

# 栏目说明

订单执行状况－订单执行状况查询页签

|**栏目**|**说明**|
|---|---|
|**订单号**|销售订单的编号（U9购买者）|
|**客户订单号**|客户采购订单的编号（客户门户的使用者）|
|**单据日期**|销售订单单据日期|
|**料品编码**|料品编码（U9购买者）|
|**品名**|料品名称（U9购买者|
|**客户料号**|客户的料品编码（客户门户的使用者）|
|**客户品名**|客户的料品名称（客户门户的使用者）|
|**厂牌**|厂牌|
|**计价单位**|计价单位|
|**订货数量**|订货数量|
|**出货数量**|出货数量|
|**签收数量**|签收数量|
|**开票数量**|开票数量|
|**收款数量**|收款数量|

# 按钮说明

*  <查询>：点击客户门户－>订单管理－>执行状况查询 －>查询，选择条件查询订单执行状况。
*  <查看订单>：点击客户门户－>订单管理－>执行状况查询 －>查看订单，查看选中行订单的明细信息
