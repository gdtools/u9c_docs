
# 功能描述

*  进入【客户门户】－>【订单管理】－>【订单确认】
*  “订单确认”的含义是：客户自助确认订单的价格、数量、交期、付款、交货信息是否输入正确。

# 使用前提

*  启用销售系统
*  启用客户门户

# 栏目说明

订单确认－订单确认页签

|**栏目**|**说明**|
|---|---|
|**订单号**|订单号 销售订单的编号（U9购买者）|
|**客户订单号**|客户采购订单的编号（客户门户的使用者）|
|**单据日期**|销售订单的单据日期|
|**币种**|销售订单币种（交易币种）|
|**价税合计**|销售订单的总金额|
|**确认状态**|销售订单的客户确认状态|
|**状态**|销售订单的业务状态|

# 按钮说明

*  <查询>：点击客户门户－>订单管理－>订单确认－>查询，选择条件查询订单。
*  <客户确认>：点击客户门户－>订单管理－>订单确认－>客户确认，确认选中行的订单
