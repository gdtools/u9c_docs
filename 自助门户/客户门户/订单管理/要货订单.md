
# 功能描述

进入【客户门户】－>【订单管理】－>【要货订单】

客户维护要货订单，录入要货的料品、数量、交期。

要货料品的价格根据客户档案的价表取价。可通过EXCEL导入要货料品清单。

# 使用前提

*  要货订单单据类型；
*  客户档案：交易币种、价表；

# 栏目说明

要货订单头

|**栏目**|**说明**|
|---|---|
|**单据类型**|要货订单的单据类型|
|**单号**|要货订单的单据号|
|**客户**|登录用户对应的客户，不可改|
|**日期**|当前日期，不可改|
|**交期**|画面项，作为单体“要求交货日期”的默认值|
|**交易币种**|交易币种；=客户档案的交易币种，不可改|
|**价格含税**|价格是否含税；=客户档案默认价表的价格含税属性，不可改|
|**价表**|客户档案的默认价表|
|**占用额度**|画面项，作为单体“占用额度”的默认值|
|**信用客户位置**|画面项，作为单体“信用客户位置”的默认值|
|**订货客户地址**|系统自动带入客户的默认地址，可修改|
|**订货客户联系人**|系统自动带入客户的默认地址，可修改|
|**收货位置**|客户的收货位置；|
|**收货地址**|系统自动带入收货位置的默认地址，可修改|
|**收货联系人**|系统自动带入收货位置的默认联系人，可修改|
|**状态**|要货订单的状态，包括开立、核准中、审核共三个状态。|
|**备注**|要货订单的备注|

要货订单行

|**栏目**|**说明**|
|---|---|
|**行号**|要货订单行的行号|
|**料号**|要货的料号|
|**品名**|要货料品的品名|
|**规格**|要货料品的规格|
|**数量**|要货数量|
|**销售单位**|默认为料品的销售单位|
|**单价**|要货料品的单价；由系统根据价表计算，用户不可修改|
|**计价数量**|计价单位的要货数量|
|**计价单位**|料品的计价单位|
|**交期**|要求交货日期|
|**税组合**|税组合|
|**税率**|税率|
|**价税合计**|价税合计|
|**未税金额**|未税金额|
|**税额**|税额|
|**占用额度**|是否占用信用额度|
|**信用客户位置**|占用信用的客户位置|
|**备注**|备注|

# 按钮说明

*  <Excel导入>：将Excel文件中的要货信息导入到要货单行，方便客户快速录入要货信息。Excel文件格式是：料号、品名、数量、交期。
*  <操作—整单关闭>：关闭整个要货订单。
*  <操作—行关闭>：关闭选中要货订单行。
*  <操作—整单打开>：打开整个要货订单。
*  <操作—行打开>：打开选中要货订单行。
*  <下载Excel模板>：下载Excel导入模板。
*  <选配>：要货订单选配
