
# 功能描述

*  进入【客户门户】－>【订单管理】－>【进度状况查询】
*  客户在此查询销售订单的生产进度状况，计划开工日期、计划完工日期、计划完工数量、实际完工数量。

# 使用前提

*  启用销售系统
*  启用制造系统
*  启用客户门户

# 栏目说明

执行进度－执行进度查询页签

|**栏目**|**说明**|
|---|---|
|**订单号**|销售订单的编号（U9购买者）|
|**客户订单号**|客户采购订单的编号（客户门户的使用者）|
|**单据日期**|销售订单单据日期|
|**料品编码**|料品编码（U9购买者）|
|**品名**|料品名称（U9购买者|
|**客户料号**|客户的料品编码（客户门户的使用者）|
|**客户品名**|客户的料品名称（客户门户的使用者）|
|**承诺交期**|订单出货计划承诺的交货日期|
|**单位**|库存单位名称|
|**计划出货量**|订单出货计划的计划出货数量|
|**生产订单号**|生产订单号|
|**计划开工日期**|计划开工日期|
|**计划完工日期**|计划完工日期|
|**实际完工日期**|实际完工日期|
|**计划生产数量**|计划生产数量|
|**实际完工数量**|实际完工数量|

# 按钮说明

*  <查询>：点击客户门户－>订单管理－>进度状况查询 －>查询，选择条件查询订单进度状况。
*  <详细进度>：点击客户门户－>订单管理－>执行状况查询 －>详细进度，查看选中生产订单的详细生产进度。
*  <查看订单>：点击客户门户－>订单管理－>执行状况查询 －>查看订单，查看选中行订单的明细信息
