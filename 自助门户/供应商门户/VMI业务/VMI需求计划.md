
# 功能描述

进入供应商门户－>VMI业务－>VMI需求计划：

是采购方在自己系统中针对VMI物料运行MRP或者库存规划得到的最新净需求，已经明确供应商；

是一种针对未来一段期间内的VMI补货预测；从当前日期所在的计划周期开始，向后展开n个周期。

# 使用前提

*  启用采购系统
*  定义供应商档案
*  定义组织档案
*  定义人员档案
*  定义物料档案
*  定义计量单位
*  定义币种
*  启用供应商门户
*  货源表中启用要货计划

# 栏目说明

**表头画面**

自查询条件画面中带入,不可修改

**表体画面**

显示所查询的详细的料品的需求计划,下文仅介绍关键数据项

|**栏目**|**说明**|
|---|---|
|数量|区分为以下纬度的几种数量
   *  预测量:根据MRP或者库存规划计算的料品需求数量
*  本次补货量:用户手工可改,做为转补货订单的数量
*  累计补货量:VMI料品在补货PO中的[计划到货数量] －[累计到货数量]
*  补货差额:=[预测量] －[累计补货量]
|
|查询期间|按照查询条件中所设定的展开期数展开的查询期间|

# 按钮说明

*  <补货>：点击供应商门户－>VMI业务－>VMI需求计划 －>补货，根据表体中所输入的本次补货量生成VMI补货订单。
*  <查询>：点击**供应商门户－>VMI业务－>VMI需求计划－>查询**，可以选择条件查询VMI需求计划。
*  <设置>：设置需求集合生单条件，分单条件等。
