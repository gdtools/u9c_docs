
# 功能描述

本功能用于查询各会计期间的存货的明细账。只能查询末级存货的某段时间的收发存信息；明细账（数量）是按末级存货设置的,用来反映存货的某段时间的收发存的数量的变化。

注意：本报表只能查询某个料品的明细帐，基于效率考虑，无论查询条件选择了几个料品，结果画面都需要用户手工在单头选择需要查看的一个料品，点击查找后才能看到此料品的明细帐结果。

# 使用前提

*  采购系统已启用
*  库存模块
*  定义统计期间，参见统计期间

# 统计说明

**统计数据**

库存收、发单据的数量信息

**统计条件**

系统在查询方案中（查询方案）提供默认的统计条件，不同的统计方式对应不同的统计条件。另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

**统计结果**

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 按钮说明

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。
*  <调整列宽>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。
