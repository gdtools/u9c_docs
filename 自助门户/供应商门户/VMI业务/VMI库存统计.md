
# 功能描述

进入供应商门户－>VMI业务－>VMI库存统计；

供应商在此查询所有需求组织VMI仓中，当前供应商编号所供应料品的收发存状况。

# 使用前提

*  存在VMI数据

# 统计说明

**统计数据**

存在VMI数据

**统计条件**

系统在查询方案中（查询方案）提供默认的统计条件，不同的统计方式对应不同的统计条件。另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

**统计结果**

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 栏目说明

**VMI库存统计列表画面**

统计表中为供应商所供应料品的收发情况，不再做详细描述

*  已消耗汇总量= 出库量-退回量
*  已消耗汇总金额= 出库成本金额-退回成本金额

# 按钮说明

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。
*  <调整列宽>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。
