
# 功能描述

进入供应商门户－>VMI业务 －>VMI收货,供应商可以进行VMI收货。

# 使用前提

*  启用采购系统
*  定义供应商档案
*  定义组织档案
*  定义人员档案
*  定义物料档案
*  定义计量单位
*  定义币种
*  启用供应商门户

# 栏目说明

*  单头画面

供应商可在单头画面中维护单据类型\承运人\送货单号\车牌号等基本信息。

*  单行基本页签

供应商可在此维护收货单行的基本信息,如料品与计划到货数量,查看或维护其他单行信息时可切换到物料\到货等页签。

*  单行物料页签

供应商可以在画面中维护料品的自由项\批号\序列号等信息。

*  单行到货页签

供应商可在到货页签中维护料品的实际到货数量,计划到货数量，计量单位由系统维护不可改。

*  单行其他页签

供应商可在其他页签中维护料品的发货位置\重量\体积等信息,其他信息由系统维护,不可改。

# 按钮说明

*  <批量收货>：

**概述：**

可选多个来源单据，批量生成多个的单据。

**操作前提：**

存在上游单据。

**操作步骤：**

点击供应商门户－>VMI业务 －>VMI收货－>批量收货，可以进行批量生单操作。具体步骤如下所示。

*      *  第1步：点击“批量收货”按钮，弹出批量生单过滤画面。
   *  第2步：批量生单过滤画面，根据需要选择过滤条件过滤来源单据：
   *  第3步：点击“确定”按钮，进入批量生单列表画面。
   *  第4步：批量生单列表画面中，选中本次需要转成收货单的记录，在记录前打“√”；
   *  第5步：可以手工调整“本次收货数量1”，双数量可以使用“本次收货数量2”。
   *  第6步：若要设置分单条件，点击批量生单列表画面上的“设置”按钮，进行设置，设置完毕点击“确定”返回。
   *  第7步：批量生单列表画面中，点击“确定”按钮，批量生单完毕。
*  <终止>：点击供应商门户－>VMI业务 －>VMI收货－>终止，可以将整单终止收货。
