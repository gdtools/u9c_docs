
# 功能描述

进入供应商门户－>VMI业务－>VMI库存规划计算

*  供应商登录门户，自行触发VMI物料的库存规划计算
*  供应商可以自行运算其所管理的VMI物料的库存规划，以便随时获取该VMI料的净需求。

# 使用前提

*  存在VMI库存规划数据

# 统计说明

**统计数据**

存在VMI库存规划数据

**统计条件**

系统在查询方案中（查询方案）提供默认的统计条件，不同的统计方式对应不同的统计条件。另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

**统计结果**

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 栏目说明

上列表画面

*  显示按“查询条件”查询出来的料品及相关信息，不可修改
*  在上列表中切换选择不同的行，下列表中联动显示对应的库存规划

下列表画面

显示库存规划情况，除下文数据项外，不再特别描述

|**栏目**|**说明**|
|---|---|
|安全库存|对应物料的库存规划方法为“再订货点”或（“盘点再补货”且定义了再订货量）有值，否则为空|
|再订货量|
|上限|对应物料的库存规划方法“最高点最低点”或（“盘点再补货”且定义了库存上下限）时有值，否则为空|
|下限|

# 按钮说明

*  <重新计算>：点击供应商门户－>VMI业务－>VMI库存规划计算－>重新计算，弹出库存规划查询条件页面。选择条件后，点击[确定]之后，在当前[需求组织]执行库存规划运算，计算补货量，规划表自动保存，并自动完成需求处理。
