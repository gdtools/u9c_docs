
# 功能描述

用于设定供应商门户系统的运行过程中，对供应商门户的参数设置。

供应商门户参数的取值定义后，允许再次修改。修改后对以往单据不做修改，仅对未来采购单据产生影响。。

# 业务规则

*  启用供应商门户
*  用户有设置供应商门户参数的权限
*  。

# 参数说明

供应商门户参数设定说明

|**参数分组**|**参数名称**|**参数取值及说明**|
|---|---|---|
|**供应商门户**|计划默认展开期间数|对应“要货计划——查询画面“与“VMI需求计划——查询画面”中的[展开期数]。所输入数值将做为该数据项的默认值。|
|**供应商门户**|供应商门户查询根据组织过滤|供应商门户查询根据组织过滤|
