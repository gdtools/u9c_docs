
# 功能描述

进入供应商门户－>配送－>运费对帐,供应商能够查询到核定后的运费,并进行确认。

# 关键应用

# 业务规则

*  存在当前供应商的状态在（报价中、供应商返回、核准中、已核准、逾期关闭、比价完成）中的询价单;

# 栏目说明

与采购模块下询价单栏目相同

# 按钮说明

*  <提交报价>

报价中状态且当前系统日期<=报价截止日期的询价单允许提交报价。不支持行提交报价。提交报价后，单头单体状态为“供应商返回”，当单据类型中要求供应商对商务项进行响应时，规定的商务项为空不允许提交报价。

*  <撤销报价>

报价中状态的询价单允许撤销报价、供应商返回态的且当前系统日期<=报价截止日期的询价单允许撤销报价，不支持行撤销报价。撤销报价后单头、单体状态为“发布”态。
