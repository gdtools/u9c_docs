
# 功能描述

可以查询应付款期初、本期应付、付款及余额的情况；可以查询单据余额；可以查询逾期的应付；可以查询到期的应付；可以查询还在折扣期的应付；

# 关键应用

# 业务规则

*  已启用应付管理;

# 栏目说明

<查询条件>

|**栏目**|**说明**|
|---|---|
|**核算组织**|参照组织档案录入|
|**来源组织**|参照组织档案录入|
|**业务组织**|参照组织档案录入|
|**结算组织**|参照组织档案录入|
|**期间类型**|枚举值：
   *  会计期间（默认）
*  统计期间
|
|**会计期间范围**|当［期间类型］＝会计期间，可用枚举值：
   *  当前期间
*  上一期间
*  去年同期
*  指定期间
|
|**会计期间**|当［期间范围］＝指定期间，可用参照选择|
|**统计期间规则**|当［期间类型］＝统计期间，可用参照选择|
|**统计期间范围**|当［期间类型］＝统计期间，可用|
|**统计期间**|当［期间类型］＝统计期间，可用|
|**业务类型**|可限定查询应付单的业务类型范围|
|**单据类型**|可限定查询应付单的单据类型范围|
|**包含未立账**|确定满足截止时间的未立账单据是否包括在查询范围内|
|**未立账单据**|当[是否包含未立账]＝true时，可指定包含哪些未立账的单据类别，如未立账的应付单、采购收货单、采购订单、配送对账单、资产调入单、管销费用单等|
|**有余额无发生显示**|若查询期间无发生额，但有期初数，是否显示|

<查询结果>

|**栏目**|**说明**|
|---|---|
|**期初_数量****期初_核币****期初_本币**|显示应付款期初余额|
|**应付_数量****应付_核币****应付_本币**|显示应付款本期贷方发生额|
|**付款_数量****付款_核币****付款_本币**|显示应付款本期借方发生额|
|**期末_数量****期末_核币****期末_本币**||

# 按钮说明

*  <联查应付明细账>

在列表下方，联查栏目目选择“应付明细账”，可查询焦点行的明细账。

*  <联查到期应付表>

在列表下方，联查栏目目选择“到期应付表”，可查询焦点行的到期应付表。

*  <联查逾期应付表>

在列表下方，联查栏目目选择“逾期应付表”，可查询焦点行的逾期应付表。
