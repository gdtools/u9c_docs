
# 功能描述

要货计划是采购方发布的对未来某段时期内可能需要采购料品的一种数量型承诺与远期预测的混合体。

# 关键应用

# 业务规则

*  供应商能及时了解采购方今后一段期间的的需求状况，方便其合理安排其自身的生产进度。
*  供应商可对要货计划上进行确认处理，方便采购方及时了解供应商的供货能力，及时调整用户的采购策略。

# 栏目说明

**表头画面**

|**栏目**|**说明**|
|---|---|
|采购方|不可改，自查询条件画面带入|
|需求方与物料|不可改，自查询条件画面带入|
|期间数据|不可改，自查询条件画面带入|

**表体画面**

要货计划表体中黄色区域表示当前期间为锁定期,该期间的数量除“确认量”外均不可修改，处于锁定期外的数量允许修改。

|**栏目**|**说明**|
|---|---|
|要货方|不可改，系统维护|
|物料|不可改，系统维护|
|单位|不可改，系统维护|
|数量|根据要货方与物料查询的要货数量,区分为以下状态发布:表示查询期间的[发布要货量]确认:表示供应商确认在查询期间可以供应的数量,处于锁定期内的确认量一旦保存不允许再次修改执行:表示查询期间的[累计发货量]或者[PO累计核准量]差异:表示查询期间的[本期差异]累差:表示查询期间的[累计差异]|
|查询期间|根据查询条件中确定的查询期间|

# 按钮说明

*  <明细查询>

选择要货计划行后点击**供应商门户－>要货计划－>操作－>明细查询**，或者直接双击焦点对应的要货计划；弹出要货计划卡片画面，查询明细情况。

*  <执行状况>

点击供应商门户－>要货计划－>操作－>执行状况，可以将查看要货计划执行情况。

查询内容为要货计划对应采购订单的执行情况,包括订货\实收\付款\退扣等数量

*  <查询>

点击供应商门户－>要货计划－>要货计划－>查询，可以选择条件查询要货计划。
