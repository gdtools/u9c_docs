
# 功能描述

供应商在此可以查询所有业务组织的采购订单情况。

# 使用前提

*  已启用采购
*  已启用供应商门户

# 栏目说明

取采购订单实体栏目

|**栏目名称**|**说明**|
|---|---|
|订单编号|订单编号|
|业务类型|业务类型|
|单据类型|单据类型|
|单据日期|单据日期|
|采购部门|采购部门|
|采购员|采购员|
|交易币种|交易币种|
|价税合计|价税合计|
|确认状态|确认状态|
|单据状态|单据状态|
|供应商发货位置|供应商发货位置|

# 按钮说明

*  <查询>:根据条件查询采购订单；
*  <批量打印>：打印选中订单；
*  <批量输出>：输出选中订单。
