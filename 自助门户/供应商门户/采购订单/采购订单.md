
# 功能描述

需要供应商确认的采购订单,供应商在此进行确认及取消确认操作。

*  可以根据需要利用查询功能自定义设置查询条件及栏目；
*  支持对所选条目进行批量确认及取消确认。

# 使用前提

*  已启用采购
*  已启用供应商门户
*  存在需要供应商确认的采购订单

|确认状态|确认状态|
|单据状态|单据状态|
|供应商发货位置|供应商发货位置|

# 按钮说明

*  <查询>:根据条件查询需确认的采购订单；
*  <批量确认>：选择订单，供应商批量确认；
*  <取消确认>：选择订单，供应商批量取消确认。
