
# 功能描述

进入供应商门户－>配送－>任务接受,展示企业方发布且承运商未接受的运输配送任务,承运商可以在网上查看配送任务单，可以接受配送任务，或者拒绝任务；

# 关键应用

# 业务规则

*  展示承运商未接受的运输配送任务;

# 栏目说明

**承运列表画面**

列表中显示企业发布且当前承运商未接受的配送任务

|**栏目**|**说明**|
|---|---|
|选择框|可单选或多选，|
|其他数据项|显示配送任务的基本信息，不可修改|

**承运明细画面**

显示配送任务的明细情况，如料品、起运日期、送达客户等，不可修改

# 按钮说明

*  <查询>

点击供应商门户－>配送－>任务接受－>查询，可以输入查询条件查找配送任务

查询方案的使用方法可参见相关文档

*  <接收>

在“承运列表”中选择配送任务后，点击**供应商门户－>配送－>任务接受－>接收**，即可接收配送任务；

配送任务一旦接收，在当前节点中不可见，可在后续操作中查看该配送任务

承运商一旦接受任务，则任务不可逆；如有误操作可通知企业相关人员在配送模块中进行修改

*  <拒绝>

在“承运列表”中选择配送任务后，点击**供应商门户－>配送－>任务接受－>拒绝**，可以拒绝企业发布的配送任务

承运商一旦拒绝接受任务，则操作不可逆；如有误操作可通知企业相关人员在配送模块中进行修改

*  <查看任务单>

在“承运列表”中选择配送任务后，点击**供应商门户－>配送－>任务接受－>查看任务单**，可以查看配送任务单中的明细信息。
