
# 功能描述

**进入供应商门户－>配送－>起运确认,**承运商网上查看已经接收的任务单，进行起运确认并维护起运信息；

# 关键应用

# 业务规则

*  查看已经接收的任务单;

# 栏目说明

**承运列表画面**

列表中显示当前承运商已接受未起运的配送任务

|**栏目**|**说明**|
|---|---|
|选择框|可单选或多选|
|其他数据项|显示配送任务的基本信息，不可修改|

**配送起运画面**

在承运列表中选择配送任务后，执行“批量起运”或“当前行起运”操作后弹出“配送起运画面”，承运商可在此维护起运信息。

|**栏目**|**说明**|
|---|---|
|单头画面：承运商维护起运信息|
|起运日期|默认=当前系统日期，可改|
|预计送达日期|默认=当前系统日期，可改|
|承运商单号|可空，承运商手工输入运单号|
|运输车型|必输的选择项，如不可录入，可通知企业方对该数据项进行维护|
|车牌|非空必输项|
|司机1|非空必输项|
|司机1联系电话|非空必输项|
|司机2|可空|
|司机2联系电话|可空|
|单行信息：列表显示配送料品的品名、数量等信息，|
|起运数量|当用户执行“当前行起运”操作进入当前画面时，可修改配送任务的起运数量|
|其他数据项|任何情况下都不可修改|

# 按钮说明

*  <查询>

点击供应商门户－>配送－>起运确认－>查询，可以输入查询条件查找配送任务

查询方案的使用方法可参见相关文档

*  <批量起运>

**概述**

承运商可选多个配送任务进行起运作业，

**操作前提**

存在已接受的配送任务。

**操作步骤**

点击供应商门户－>配送－>起运确认－>批量起运，打开配送起运画面，维护起运信息（参见上文配送起运画面描述）。

起运确认后，单据自动流转至“代客签收”环节，如误操作，可通知企业方人员进行修改

批量起运，不能维护每个配送任务的“起运数量”

*  <当前行起运>

选择某条配送任务后，点击供应商门户－>配送－>起运确认－>当前行起运，可以针对所选定的配送任务进行确认，维护起运信息。操作基本同“批量起运”操作。

*  <查看任务单>

在“列表”中选择配送任务后，点击**供应商门户－>配送－>起运确认－>查看任务单**，可以查看配送任务单中的明细信息。
