
# 功能描述

已经配送的任务单，可以由客户在客户门户上签收，也可由承运商进入**供应商门户,**在其中代替客户进行签收作业；

# 关键应用

# 业务规则

*  只能查看已经配送的任务单;

# 栏目说明

**代客签收列表画面**

列表中显示当前承运商已接受起运确认的配送任务

|**栏目**|**说明**|
|---|---|
|选择框|可单选或多选|
|其他数据项|显示配送任务的基本信息，不可修改|

**配送签收画面**

在代客签收列表中选择配送任务后，执行“批量签收”或行“当前行签收”后打开配送签收画面

|**栏目**|**说明**|
|---|---|
|**单头画面**||
|送达日期|默认=当前系统日期，可改，只可向前改，不可向后改|
|**单行画面**|如执行“批量签收”，在单行画面中显示数据为空；执行“当前行签收”，可修改“签收数量”等信息|
|签收数量|执行“当前行签收”操作，可修改，只可小于等于起运数量|
|拒收数量|执行“当前行签收”操作，可修改|
|拒收原因|执行“当前行签收”操作，可修改|
|途损数量|系统自动计算=[起运数量]－[签收数量] －[拒收数量]|
|其他数据项|其他数据项为配送任务单相关，不可修改|

# 按钮说明

*  <查询>

点击供应商门户－>配送－>代客签收－>查询，可以输入查询条件查找配送任务

查询方案的使用方法可参见相关文档

*  <批量签收>

**概述**

承运商可选多个配送任务进行签收作业，

**操作前提**

存在已起运确认的配送任务。

**操作步骤**

选择需签收的配送任务后，点击供应商门户－>配送－>代客签收－>批量签收，打开配送签收画面，（参见上文配送签收画面描述）。

输入送达日期，点击“签收确认”即完成签收作业。点击“取消”可放弃签收作业

签收作业后，配送任务完成，如误操作，可通知企业方人员进行修改

批量签收，认为全部的起运数量都被签收，不能维护每个配送任务的“签收数量”、“拒收数量”。

*  <当前行签收>

选择某条配送任务后，点击**供应商门户－>配送－>代客签收－>当前行签收**，可以针对所选定的配送任务进行签收操作，维护签收数量。操作基本同“批量签收”操作。

*  <查看任务单>

在“列表”中选择配送任务后，点击**供应商门户－>配送－>代客签收－>查看任务单**，可以查看配送任务单中的明细信息。
