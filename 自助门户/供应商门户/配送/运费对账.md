
# 功能描述

进入供应商门户－>配送－>运费对帐,供应商能够查询到核定后的运费,并进行确认。

# 关键应用

# 业务规则

*  存在已审核且未收货完成的采购订单;

# 栏目说明

**对帐列表页签**

显示当前可以进行确认的对帐单。

|**栏目**|**说明**|
|---|---|
|选择框|可多选|
|其他数据项|显示对帐单的一些基本信息，包括对帐期间、费用费用合计、罚赔款合计、实结金额等信息|

**对帐明细页签**

在列表画面中选择对帐单后，点击对帐明细页签后，可查看各项费用的明细核定情况,包括核定的各项配送费用,核定的罚赔费用等

# 按钮说明

*  <查询>

**点击供应商门户－>配送－>运费对帐－>查询，**可以输入查询条件查找对帐单

查询方案的使用方法可参见相关文档

*  <对帐确认>

在“列表”中选择对帐单后，点击**供应商门户－>配送－>运费对帐－>对帐确认，**即表示承运商认可企业方对运费的核定结果,企业方可据此立账

*  <对账单查询>

在“列表”中选择对帐单后，点击供应商门户－>配送－>运费对帐－>对帐单查询，可以查看配送任务单中的明细信息。
