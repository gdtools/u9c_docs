
# 功能描述

进入供应商门户－>配送－>运费申报,供应商能够对运费进行网上申报。

# 关键应用

# 业务规则

*  必须有处于接受、已起运、已完成的配送任务
*  输入配送费用，以配送单头费用为准提交申报
*  所申报费用的币种以配送任务单上的费用币种为准，承运商有异币种费用，需自行转换为配送单费用币种后再申报

# 栏目说明

**运费申报列表画面**

显示当前可以申报费用的配送任务单

|**栏目**|**说明**|
|---|---|
|选择框|可单选|
|其他数据项|显示配送任务的基本信息，不可修改|

**配送任务单头画面**

在列表画面中选择配送任务后，执行“当前行录入费用”后，进入配送任务单画面

单头画面中除“申报费用”页签外，其他页签数据项为配送任务的明细信息，承运商只可查看，不可修改，此处不再描述

|**栏目**|**说明**|
|---|---|
|申报费用合计|=当前页签所列各项申报费用合计|
|申报包装费|=单行“包装费”合计，可手工修改，修改不影响单行数据|
|申报装车费|=单行“装车费”合计，可手工修改，修改不影响单行数据|
|申报运输费|=单行“运输费”合计，可手工修改，修改不影响单行数据|
|申报卸车费|=单行“卸车费”合计，可手工修改，修改不影响单行数据|
|申报其它发货杂费|=单行“其它发货杂费”合计，可手工修改，修改不影响单行数据|
|申报其它收货杂费|=单行“其它收货杂费”合计，可手工修改，修改不影响单行数据|
|申报费用备注|手工输入，可改|

配送任务单行列表画面

单行画面中除“费用”页签外，其他页签数据项为配送任务的明细信息，承运商只可查看，不可修改，此处不再描述

|**栏目**|**说明**|
|---|---|
|费用合计|=当前页签所列各项申报费用合计|
|包装费|手工输入，可改|
|装车费|手工输入，可改|
|运输费|手工输入，可改|
|卸车费|手工输入，可改|
|其它发货杂费|手工输入，可改|
|其它收货杂费|手工输入，可改|
|费用备注|手工输入，可改|

# 按钮说明

*  <查询>

点击供应商门户－>配送－>运费申报－>查询，可以输入查询条件查找配送任务

查询方案的使用方法可参见相关文档

*  <当前行录入费用>

在“列表”中选择配送任务后，点击**供应商门户－>配送－>运费申报－>当前行录入费用**，打开配送任务单，在其中录入配送费用，参见上文描述。
