
# 功能描述 

进入智能分析－>智能分析－>基础设置－>数据刷新配置；

对界面数据刷新的方案进行配置。

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|编码|定义配置的编码|
|名称|定义配置的名称|
|执行周期|定义多少个周期执行一次，最小值为1|
|周期单位|定义执行的周期，系统支持的周期为：年、月、周、日、时、分|
|首次执行时间|定义调度开始的时间|
|结束方式|定义调度的结束方式，目前结束方式有三种：无结束时间；重复次数，即执行定义的次数后结束；结束时间，即执行到指定的时间后结束|
|结束时间|默认等于空，定义结束时间|
|重复次数|默认等于1；定义重复执行的次数|


# 操作说明

*  通过菜单智能分析－>智能分析－>基础配置－>数据刷新配置进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息；
   *  第2步：维护周期单位、重复周期、首次执行时间等信息；
   *  第3步：点击保存按钮。
