
# 功能描述

为客户提供投入产出成本分析，包括：期初成本、本期成本、入库成本、在制成本和投入产出数量分析，包括：期初数量、本期数量、入库数量、在制数量。

# 业务规则

*  启用智能分析模块。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织|默认=所有非空|
|期间|默认=所有非空|
|账簿|默认=所有非空|
|成本域|默认=所有|
|料品|非空|
|物料分类|默认=所有非空|

# 操作说明

*  通过菜单智能分析－>智能分析－>成本－>投入产出分析进入该界面；
*  操作步骤
 
   *  第1步：选择查询条件；
   *  第2步：查看对应的报表数据。
