
# 功能描述

提供生产完成情况分析，包括按照部门统计生产完成状况和按照产品分类统计生产完成情况，包括开工量和完工量的情况分析。

# 业务规则

*  启用智能分析模块。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|生产组织|默认=所有非空|
|生产部门|默认=所有非空|
|产品分类|默认=所有非空|
|计划开工日期|输入从日期-到日期非空|
|计划完工日期|输入从日期-到日期非空|
|项目|默认=所有非空|
|番号|默认=所有非空|
|需求分类|默认=所有非空|

# 操作说明

*  通过菜单智能分析－>智能分析－>生产－>生产完成情况分析进入该界面；
*  操作步骤
 
   *  第1步：选择查询条件；
   *  第2步：查看对应的报表数据。
