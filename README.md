# 用友 U9C 运维与使用文档

> 本仓库收录用友 ERP **U9C（U9 Cloud）** 系统的运维文档与业务使用文档，覆盖财务、供应链、生产制造、人力资源等核心模块的实操说明与配置指引。

## 一、文档定位

- **运维文档**：系统部署、参数配置、权限与组织设置、日常运维操作、问题排查等面向管理员/实施顾问的内容。
- **使用文档**：各业务模块的功能说明、操作路径、字段含义、典型业务流程，面向最终用户与关键用户。

文档以 Markdown 形式组织，便于版本化管理、检索与协同维护。

## 三、如何使用

1. 按业务域进入对应一级目录，再进入二级子目录查找具体文档。
2. 文档命名建议包含「模块 - 功能 - 操作类型」（例如：`总账-凭证录入-操作手册`）。
3. 涉及系统配置/运维的操作，请先确认环境与组织上下文，避免误操作。
