
# 功能描述

本功能是根据料品档案，在料品成本表中检查各料品的各成本域、成本类型、账簿、记账期间成本，如果料品对应查询条件里的成本域、成本类型，期间，账簿在【料品成本表】里没有记录，则作为查询结果在此表显示。

本功能只检查标准和计划成本类型的未定义成本，本功能只检查指定日期所在期间生效料品的完整性。

# 栏目说明

成本完整性检查

|栏目|说明|
|---|---|
|成本域|要进行料品成本完整性检查的成本域参照录入，可为空；如果不选择，对全部成本域进行检查。|
|成本类型|要进行料品成本完整性检查的成本类型。参照录入，可为空；如果不选择，则对全部成本类型进行检查。|
|账簿|要进行成本完整性检查的的账簿。参照录入，可以为空；如果为空，则全部账簿进行检查。|
|料品分类|要进行料品成本完整性检查的料品库存分类。参照录入，可为空；如果不选择，则对全部料品分类进行检查。|
|查询日期|选择进行成本完整性检查的日期选择录入，不可为空；|

成本完整性检查－检查结果

|栏目|说明|
|---|---|
|成本域|未定义成本的料品所在的成本域|
|成本类型|未定义成本的料品所在的成本类型|
|账簿|未定义成本的料品所在的账簿|
|计量单位|未定义成本的料品的计量单位|
|料品|未定义成本的料品|
|料品版本|未定义成本的料品的版本|
|形态属性|未定义成本的料品的形态属性|
|可生产标记|未定义成本的料品是否为可生产料品|
|查询日期|成本完整性查询所依据的查询日期|
|操作时间|成本完整性查询的实际查询时间|

# 操作说明

## 检查

根据录入的参数检查料品档案中未定义料品成本的料品。

**操作前提**

*  已经定义了料品档案。

**操作步骤**

点击**料品成本－>成本完整性检查－>检查**按钮，进行料品成本完整性检查。

## 查看结果

点击查看料品成本完整性检查的结果列表。

**操作步骤**

点击**料品成本－>成本完整性检查－>查看结果**按钮，导航到结果列表查看页面。

如果需要在结果中继续过滤查看，请点击**查询**按钮进行查询过滤。

如果需要根据查询结果立即录入成本数据，请点击**快速录入**按钮，系统导航到“料品成本快速录入”功能节点

# 初始准备

*  已经定义【成本域】、【成本类型】；
*  已经定义【账簿】档案和【账簿会计日历】；
*  已经定义【料品】档案；
