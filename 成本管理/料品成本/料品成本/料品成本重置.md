
# 功能描述

支持任意未月结期间的料品成本的变更。

# 栏目说明

料品成本重置

|栏目|说明|
|---|---|
|成本域|需要进行成本变更的目标成本域；|
|成本类型|需要进行成本变更的目标成本类型；|
|账簿|需要进行成本变更的目标账簿；|
|基准期间|由于已经发生业务的期间不可以进行成本变更，因此需要先将成本变更在未发生业务的期间，这个期间即基准期间；成本变更时以基准期间成本为准，调整变更起始期间及后续期间的成本。|
|变更起始期间|需要进行成本变更的期间；|
|变更全部料品|如果全部料品都需调整，则勾选此参数。否则需要选择需要成本变更的料品。|
|料品|需要进行成本变更的目标料品；|

# 操作说明

## 料品成本重置

料品成本重置可以实现对已经使用的料品成本的价格进行变更。并同时对已经发生的业务进行修正。

**操作前提**

*  已经将新的料品成本变更在未发生业务的期间。
*  变更生效期间未月结。

**操作步骤**

点击料**品成本－>料品成本重置－>变**更按钮。具体步骤如下所示。

*  **第1步：进入料品成本重置节点**
*  **第2步：选择需要进行成本变更的成本域、成本类型、账簿、变更基准期间、变更生效期间、需要进行成本变更的料品。**
*  **第3步：执行变更操作。**
*  **第4步：查看生成的料品成本变更单。**

# 初始准备

*  定义料品标准/计划成本
*  变更期间有业务发生或已经存在标准/计划成本；
