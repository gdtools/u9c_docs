
# 功能描述

本功能主要用来满足批量成本赋值的需求。

料品成本拷贝支持料品成本从一个记账期间拷贝到另一个记账期间；从一个成本类型拷贝到另一个成本类型；从一个成本域拷贝到另一个成本域；料品成本拷贝应遵守同级拷贝的原则，即拷贝来源如果选择了成本域＋成本类型＋生产目的＋账簿的范围，目标也必须是同样的范围。

对于记账的“标准”和“计划”成本类型下的料品成本拷贝，系统将自动生成拷贝目标方的成本变更单，对其它成本类型下的料品成本拷贝，直接生成新的料品成本

# 栏目说明

料品成本拷贝

|栏目|说明|
|---|---|
|来源成本域|成本拷贝来源成本域参照录入，不可为空；|
|来源成本类型|成本拷贝来源成本类型。参照录入，不可为空；|
|来源账簿|成本拷贝来源账簿。参照录入，不可为空；|
|来源记账期间|成本拷贝来源成本记账期间。选择录入，不可为空；|
|目标成本域|成本拷贝目标成本域参照录入，不可为空；|
|目标成本类型|成本拷贝目标成本类型。参照录入，不可为空；目标成本类型不能是“修改受控”的成本类型；|
|目标账簿|成本拷贝目标账簿。参照录入，不可为空；|
|目标记账期间|成本拷贝目标成本记账期间。选择录入，不可为空；|

# 操作说明

## 拷贝

执行料品成本拷贝。

**操作前提**

*  已经正确选择限定了料品成本拷贝的来源和目标范围。

**操作步骤**

点击**料品成本－>料品成本拷贝－>拷贝**按钮，进行料品成本拷贝。

## 成本查询

点击查询拷贝来源料品的成本。

**操作步骤**

点击**成本查询**按钮，弹出成本查询页面。具体步骤如下所示。

*  **第1步：**查询拷贝料品的成本。
*  **第2步：**点击**返回**按钮，返回【料品成本拷贝】主界面。

# 初始准备

*  已经定义了拷贝来源方的料品成本；
