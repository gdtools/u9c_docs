
# 功能描述

将不同来源的单价显示在同一张报表内，供用户分析使用。

# 栏目说明

料品单价比较报表－查询条件

|栏目|说明|
|---|---|
|组织|参照组织档案；默认当前登录组织；不可为空；|
|分析类型|明细数据分析：全部行分组固定显示，不可去掉；查看所有料品所有维度的单价；汇总数据分析：灵活选择分组栏目。单价根据行分组维度进行处理，取每一分组平均值。|
|账簿|参照账簿档案；单选，不可空；账簿范围：当前组织账簿、当前组织法人组织主账簿、当前组织二级核算管控组织二级核算账簿；|
|期间|参照账簿会计期间；单选，不可空；|
|成本域|参照成本域档案；成本域根据录入组织过滤；成本域支持多选，不可空；|
|成本类型|参照成本类型档案；录入组织的成本类型；|
|料品|参照料品档案；多选，可空；|
|料品分类性质|枚举类型；单选；使用料品分类条件时不可空；|
|料品分类|参照料品分类档案；一句料品分类性质过滤；|
|料品存货维度|支持等级、成分、厂牌、番号、自由项等。|
|料品形态属性|枚举选项，支持多选。|
|定价策略|汇总分析时有效；针对一个取价来源时取到多个价格时，对取价结果进行过滤。支持最高、最低、平均三种处理方式；|
|价表供应商|当取价来源为采购价时有效；用于对价表价格进行过滤；|
|价表客户|当取价来源为销售价表时有效；用于对销售价表价格进行过滤；|
|取价方案|当取价来源为模拟成本时有效；用于确定原材料的取价来源；|
|模拟版本|当取价来源为模拟成本时有效；用于确定成本模拟时BOM版本。|

料品单价比较报表－明细数据分析结果

|栏目|说明|
|---|---|
|账簿|表头；查询条件录入的账簿；|
|期间|表头；查询条件录入的期间；|
|成本域|查询结果数据的成本域；当分析类型为明细数据时仅作为栏目显示，不作为分组计算依据。|
|成本类型|查询结果数据的成本类型；当分析类型为明细数据时仅作为栏目显示，不作为分组计算依据。|
|料号|查询结果数据的料号；仅作为栏目，不作为分组对象；|
|成本单位|查询结果料品的成本单位；仅作为栏目，不作为分组对象；|
|价格类型|显示取到的价格的来源业务类型，比如来源参考成本、生产成本、结存成本、模拟成本、采购单价、销售单价等。|
|价格来源|显示取到的单价的价格来源；比如当取价来源为参考成本时显示料号；取价来源为采购价表时，显示价表的单号及行号；|
|单价|取到的具体的单价；单价需要转换为成本单位单价；如果相同条件存在多个单价时全部显示。|
|存货维度|显示单价存货维度；支持番号、项目、供应商、等级、成分、厂牌、自由项等；存货维度仅作为显示栏目，不作为分组计算项；|

品单价比较报表－汇总数据分析结果

|栏目|说明|
|---|---|
|账簿|表头；查询条件录入的账簿；|
|期间|表头；查询条件录入的期间；|
|成本域|查询结果数据的成本域；当分析类型为汇总数据时作为分组计算依据。|
|成本类型|查询结果数据的成本类型；当分析类型为汇总数据时作为分组计算依据。|
|料号|查询结果数据的料号；仅作为栏目，不作为分组对象；|
|成本单位|查询结果料品的成本单位；仅作为栏目，不作为分组对象；|
|单价|取到的具体的单价；单价需要转换为成本单位单价；如果相同条件存在多个单价时根据定价策略计算。|
|存货维度|显示单价存货维度；支持番号、项目、供应商、等级、成分、厂牌、自由项等；当分析类型为汇总数据时作为分组计算依据。|
|参考成本|查询料品档案参考成本；如果为空，报表显示为零；如果参考成本币种和指定账簿币种不一致，需要进行转换，将料品档案币种成本转换为查询条件币种成本；单位存储料品档案成本单位；取价结果和存货维度无关；|
|未税采购价|价表日期取指定期间最后一天；依据指定供应商进行取价；仅取未税的厂商价表并根据指定供应商进行过滤；如果未指定供应商则取全部；显示各自取价来源；按照汇总数据分析时根据选择的行分组维度及定价策略取最高、最低或平均价；|
|含税采购价|取价来源为含税价表；其他同上；|
|上月结存|取存货维度上期结存表，根据条件过滤，按照最细维度存储。|
|生产成本|取自成本计算结果，根据入库成本/入库数量 计算。按照成本域、成本类型、账簿、记账期间、等级、成分存储。|
|未税销售价表|取自销售价目表；价表日期取指定期间最后一天；依据税策略及指定供应商进行取价。 仅取未税的客户价表并根据指定供应商进行过滤；如果未指定客户，则取全部；取到多个则根据选择的行分组维度及定价策略取最高、最低或平均价；|
|含税销售价表|取价来源为含税价表；其他同上；|
|定额成本|取成本会计定额成本表；取指定会计期间最后一天生效的定额成本；定额成本类型为正常；取分项定额成本合计；币种转换为指定账簿币种；料品单位为成本单位。|
|模拟成本|调用成本模拟的算法进行计算。|
|标准成本|取符合条件的料品成本中存储的标准成本类型成本。|
|计划成本|取符合条件的料品成本中存储的计划价成本类型成本。|

# 操作说明

## 料品单价比较报表-明细数据

将同一料品不同来源的单价集中在一张报表内显示，便于比较分析。

**操作前提**

*  相应取价来源有数据。

**操作步骤**

点击料**品成本－>料品单价比较报表－>查**询按钮。具体步骤如下所示。

*  **第1步：进入料品成本模块**
*  **第2步：打开料品单价比较报表**
*  **第3步：分析类型选择[明细数据]**
*  **第4步：录入查询条件**
*  **第5步：查看分析结果**

## 料品单价比较报表-汇总数据

将同一料品不同来源的单价集中在一张报表内显示，便于比较分析。

**操作前提**

*  相应取价来源有数据。

**操作步骤**

点击料**品成本－>料品单价比较报表－>查**询按钮。具体步骤如下所示。

*  **第1步：进入料品成本模块**
*  **第2步：打开料品单价比较报表**
*  **第3步：分析类型选择[汇总数据]**
*  **第4步：录入查询条件**
*  **第5步：查看分析结果**
