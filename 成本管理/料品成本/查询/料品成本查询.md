
# 功能描述

本功能用来查询料品成本。

# 栏目说明

料品成本查询－查询条件

|栏目|说明|
|---|---|
|成本域|要查询成本的料品所在的成本域。参照录入为空时表示查询所有成本域；|
|成本类型|要查询的成本类型。参照录入。为空时表示查询成本域下的所有成本类型；|
|账薄|要查询的账薄。参照录入，参照成本域下的所有账薄。为空时表示查询成本域下的所有账薄；|
|记账期间|要查询的账薄期间。参照录入，参照账薄下的所有账薄期间。为空时表示查询该账薄下的所有账薄期间；|
|料品|要查询的料品。参照录入。为空时表示查询所有料品；|
|等级|料品的等级。选择录入。为空时表示查询料品所有的等级；|
|成分|料品的成分。选择录入。为空时表示查询料品所有的成分；|
|厂牌|要查询的料品的厂牌。选择录入。为空时表示查询料品所有厂牌的成本；|
|料品版本　|要查询的料品的版本。选择录入。为空时表示查询料品所有版本的成本；|
|生产目的|要查询成本的料品对应的BOM的生产目的。选择录入。为空时表示查询料品BOM所有的生产目的的成本；|
|BOM版本|要查询成本的料品对应的BOM版本。选择录入，可多选。为空时表示查询料品所有的BOM版本的成本；|
|工艺版本|要查询成本的料品对应的工艺版本。选择录入，可多选。为空时表示查询料品所有的工艺版本的成本；|
|批量|手工录入要查询成本的料品对应的BOM批量。|
|缺省批量|选择要查询成本的料品对应的BOM批量是否为缺省批量。|
