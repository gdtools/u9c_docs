
# 功能描述

料品卷积成本按成本BOM结构查询： 支持单结构树的逐层展开； 支持选定节点的料品要素成本查询； 支持料品分项成本的材料或资源明细组成查询； 支持单结构树料品成本按结构展开后的平铺成本查询；

# 操作说明

## BOM树料品成本查询-查询

对成本卷积结果按照树状结构逐层分析。

**操作前提**

*  必须有BOM；
*  必须依据BOM进行了成本卷积；

**操作步骤**

点击**料品成本－>料品BOM树状查询－>查询**按钮。具体步骤如下所示。

*  **第1步：进入料品成本模块；**
*  **第2步：进入料品BOM树状查询节点**
*  **第3步：点查询按钮，录入查询条件；**
*  **第4步：分析查询结果；**

# 初始准备

*  已经进行成本卷积。
