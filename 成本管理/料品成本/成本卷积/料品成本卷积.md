
# 功能描述

料品成本卷积是系统根据物料清单与工艺路线，从某一层级料品的成本卷算出其上级料品成本的过程，是系统确定制造件料品标准成本类型与计划成本类型成本的基础 。

料品成本卷积会区分料品的本阶、下阶成本进行卷积，下阶成本主要由下层料品的半成品材料成本组织，本阶成本主要包括下层原材料成本、本层工艺资源成本和本层料品相关的料品资源成本。

料品成本卷积包括单层卷积、仅向上卷积与多层卷积、BOM不向上展开四种方式：

**单层卷积：**从卷积料品的下一层向上卷积，得到目标卷积料品及其以上直到顶层的相关料品的成本。

**仅向上卷积：**从卷积料品本层向上卷积，得到目标卷积料品以上直到顶层的相关料品的成本。

**多层卷积：**将目标卷积料品的物料清单分解到最底层，并从最底层向上卷积目标卷积料品的相关料品成本，一直卷积到顶层相关料品的成本。

**BOM不向上展开：**将目标卷积料品的物料清单分解到最底层，并从最底层向上卷积目标卷积料品的相关料品成本，一直卷积到目标料品的成本，不再向目标料品的上层卷积。

若调整了半成品的料品成本导致该料品的料品成本被置为手工修改，可通过更新手工修改选择是否需要更新。若用户勾选了更新手工修改的料品成本，则手工修改的料品不再取料品成本，而由其子件卷积生成。

# 栏目说明

料品成本卷积

|栏目|说明|
|---|---|
|成本域|要进行料品成本卷积的成本域参照录入，可为空；如果不选择，对全部成本域进行料品成本卷积。|
|成本类型|要进行料品成本卷积的成本类型。参照录入，可为空；如果不选择，则对全部标准或计划类成本类型进行成本卷积。|
|账簿|要卷积料品成本的账簿。参照录入，可以为空；如果为空，则全部账簿进行成本卷积。|
|卷积日期|选择料品成本卷积的日期选择录入，不可为空；![http://10.16.226.26/U9/help/zh-CN/Content/Resources/Images/%E6%B3%A8%E6%84%8F.jpg](https://ncc-pub-ublim.oss-cn-beijing.aliyuncs.com/help/photo/d40449bd-2293-4d5f-a50e-2118f96f08e9.png)　注意　:应正确输入卷积日期，系统将根据卷积日期进行成本卷积的记账期间的确认。|
|从等级|“从等级”和“到等级”　共同标识成本卷积的料品的等级范围，从等级定义了料品等级范围的起始等级。选择录入，可为空；从等级为空时，卷积料品的等级范围包括无等级料品。|
|到等级|“从等级”和“到等级”　共同标识成本卷积的料品的等级范围，到等级定义了料品等级范围的结束等级。选择录入，可为空；到等级为空时，卷积料品的等级范围包括无等级料品。从等级不为空时，到等级≥从等级。|
|从成分|“从成分”和“到成分”　共同标识成本卷积的料品的成分范围，从成分定义了料品成分范围的起始成分。选择录入，可为空；从成分为空时，卷积料品的成分范围包括无成分料品。|
|到成分|“从成分”和“到成分”　共同标识成本卷积的料品的成分范围，到成分定义了料品成分范围的结束成分。选择录入，可为空；到成分为空时，卷积料品的成分范围包括无成分料品。从成分不为空时，到成分≥从成分。|

|BOM版本|进行料品成本卷积依据的BOM版本。参照录入；|
|工艺生产目的|进行料品成本卷积依据的工艺路线的生产目的。选择录入。|
|工艺版本　|进行料品成本卷积依据的工艺版本。参照录入；![http://10.16.226.26/U9/help/zh-CN/Content/Resources/Images/%E6%B3%A8%E6%84%8F.jpg](https://ncc-pub-ublim.oss-cn-beijing.aliyuncs.com/help/photo/d40449bd-2293-4d5f-a50e-2118f96f08e9.png)注意　:料品成本卷积必须依据一定的工艺版本或BOM版本，因此，“BOM版本”和“工艺版本”至少应有一个有值；如果不指定“BOM版本”或“工艺版本”，则卷积时查找成本卷积默认为T的BOM或工艺路线进行卷积。|
|仅向上卷积|料品成本卷积的方式。当BOM版本有值时才可勾选。|

# 操作说明

## 卷积

执行料品成本卷积。

**操作前提**

*  已经正确选择限定了料品成本卷积的范围。

**操作步骤**

点击**料品成本－>料品成本卷积－>卷积**按钮，进行料品成本卷积，卷积完成后，将弹出卷积结果界面，供用户查询。

## 调度

按规则设定卷积执行时间，由应用服务按时间计划进行执行卷积操作。

**操作步骤**

点击**调度**按钮，弹出时间计划排定页面。具体步骤如下所示。

*  **第1步：**根据需要，选择【执行一次】或【重复执行】
*  **第2步：**若选择【执行一次】，选择录入执行日期／时间。
*  **第3步：**若选择【重复执行】，则选择预设的调度方案进行调度安排。
*  **第4步：**点击【确定】，完成调度计划设定。

# 初始准备

*  已经定义【成本域】、【成本类型】；
*  已经定义【账簿】档案和【账簿会计日历】；
*  已经定义【料品】档案；
*  已经定义【物料清单】或【工艺路线】；
*  已经录入与卷积相关的下层采购件料品的各成本类型的成本；
