
# 功能描述

料品模拟成本按成本BOM结构查询： 支持单结构树的逐层展开； 支持多结构树的逐层展开； 支持选定节点的料品要素成本查询； 支持料品分项成本的材料或资源明细组成查询； 支持多结构树料品成本按结构展开后的平铺成本查询；

# 操作说明

## 模拟成本结构

按照BOM树展开的方式查询成本模拟的结果。

**操作前提**

*  有BOM和工艺路线
*  执行成本模拟

**操作步骤**

点击料**品成本－>模拟成本结构**。具体步骤如下所示。

*  **第1步：**进入料品成本模块；
*  **第2步：**进入模拟成本结构节点；
*  **第3步：**录入查询条件，确定后返回查询结果画面；
*  **第4步：**定位需要分析的料品，查看料品的要素成本及子件的成本构成；
*  第5步：成本展开按钮，查看目标料品整棵BOM树成本的平铺展开结果；

# 初始准备

*  已经执行成本模拟功能
*  成本模拟时保存模拟结果
