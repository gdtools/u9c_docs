
# 功能描述

本功能用来定义成本模拟的取价来源。

成本模拟可以指定的来源包括询价价格、采购订单价格、收货单价格、发票价格、料品成本类型成本和参考成本，不同的取价来源又可以对应不同的取价策略。通过各种取价策略的组合，用户可以确定最优成本模拟方案。

# 栏目说明

取价方案维护

|栏目|说明|
|---|---|
|方案维护|取价方案编码|
|方案名称　|取价方案名称|
|生效|取价方案的生效标记。|
|资源加成系数|定义资源的加成系数，模拟时资源成本=资源定义的费率*（1+加成系数）。|

取价方案维护－数据来源

|栏目|说明|
|---|---|
|选取|用户通过选取列选择要使用哪个来源类型|
|来源类型|成本模拟时的单价来源。来源于询价价格、采购订单价格、采购收货单价格、发票价格、成本类型成本、参考成本。用户通过勾选选择使用哪个来源取数。|
|来源组织|来源类型的数据源自哪个组织。参照录入，一旦勾选确定为来源，不可为空；|
|顺序号|当选择取价来源为多个来源时，选择取价的优先顺序。手工录入；相同的顺序号时以自然顺序靠前的优先。|
|取价加成系数|定义取价加成系数，模拟时成本=料品取到的成本价格*（1+加成系数）。|
