
# 功能描述

本节点用于查询业务系统中生成的交易分录，根据查询条件，显示符合条件的交易分录

# 栏目说明

交易分录查询 - 查询条件

|栏目|说明|
|---|---|
|账簿|交易分录查询的目标账薄。参照录入，不可为空。|
|自动会计业务类型|包括领料单、完工报告、成本调整单、生产费用、资源报告、时间报告、IPV差异、协同子单成本|
|业务日期|业务单据发生日期|
|记账期间|进行交易分录查询的目标账簿期间|
|单据号|交易分录业务对应的业务单据号|
|借方原币金额||
|贷方原币金额||
|借方本币金额||
|贷方本币金额||
|会计科目|交易分录所进入的会计科目|
|科目编码|会计科目的编码|


交易分录查询结果

|栏目|说明|
|---|---|
|账簿|显示查询交易分录的账簿|
|记账期间|显示查询的记账期间|
|自动会计业务类型|显示查询的自动会计业务类型|
|单据类型|显示查询的业务单据类型|
|业务类型|显示查询的单据业务类型|
|单据日期|显示查询的单据的业务日期|
|单据号|显示查询的单据号|
|凭证类型|显示查询的凭证类型|
|凭证号|显示查询的交易分录生成的凭证号|
|摘要|显示查询的交易分录的摘要|
|科目编码|显示查询的交易分录的科目编码|
|科目|显示查询的交易分录的科目|
|借方原币金额|显示查询的交易分录的借方原币金额|
|贷方原币金额|显示查询的交易分录的贷方原币金额|

# 操作说明

## 查找

点击功能按钮，弹出查找项目输入画面，用户可以输入查找条件，在列表中查询符合条件的交易分录信息。

## 原始单据

点击功能按钮，查看焦点行的来源单据。

# 初始准备

*  交易分录已生成；
