
# 功能描述

本功能用来分品种查询指定期间的料品成本。

# 栏目说明

品种成本查询－查询条件

|栏目|说明|
|---|---|
|成本域|要查询成本的品种所在的成本域。参照录入为空时表示查询所有成本域；|
|成本类型|要查询的成本类型。参照录入，参照成本域下的所有成本类型。为空时表示查询成本域下的所有成本类型；|
|账薄|要查询的账薄。参照录入，参照成本域下的所有账薄。为空时表示查询成本域下的所有账薄；|
|记账期间|要查询的账薄期间。参照录入，参照账薄下的所有账薄期间。为空时表示查询该账薄下的所有账薄期间；|
|料品|要查询的品种。参照录入。为空时表示查询所有品种；|
|等级|品种的等级。选择录入。为空时表示查询品种所有的等级；|
|成分|品种的成分。选择录入。为空时表示查询品种所有的成分；|
|类型|要查询的品种的产出类型。选择录入。为空时表示查询品种所有的产出类型；|
|是否记账|查询记账成本还是非记账成本。单项选择。为空时表示查询品种所有的成本；|
|入库标志|选择显示品种完全成本还是分等级入库成本。单项选择。为空时表示两者全部查询；　说明　:品种的完全成本是指该品种未进行联副产品和等级品分配前的成本，该成本将包括在制成本。分等级入库成本是指该品种经过联副产品和等级品分配后，实际入库的分等级品种的成本，该成本将不包括在制成本。|

# 操作说明

## 品种成本查询

通过品种成本查询，可以查询产品品种实际发生的要素成本和分项成本。

**操作步骤**

点击**成本会计－>品种成本查询　**进行查询。具体步骤如下所示。

*  **第1步：**点击**查询**按钮，弹出查询界面，录入查询条件，确定后得到品种列表，显示在品种成本查询列表中。
*  **第2步：**在品种成本查询列表中双击需要查询的品种行，在明细要素成本列表中显示该品种的明细要素成本。
*  **第3步：**如需要查询该品种的分成本大项的合计成本，请点击**分项成本**按钮，弹出分项成本显示界面，显示本品种各成本大项分本阶和下阶的成本列表。
