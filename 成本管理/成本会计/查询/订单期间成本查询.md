
# 功能描述

本功能用来查询生产订单的期间成本。

# 操作说明

## 订单成本查询

通过订单成本查询，用户可以查询生产订单或者生产线日计划发生的要素成本或分项成本。

**操作步骤**

点击**成本会计－>订单成本查询　**进行查询。具体步骤如下所示。

*  **第1步：**点击**查询**按钮，录入查询条件，确定后得到生产订单和生产线日计划列表，显示在订单成本查询列表中。
*  **第2步：**在订单成本查询列表中双击需要查询的生产订单和生产线日计划行，在明细要素成本列表中显示该生产订单或生产线日计划的明细要素成本。
*  **第3步：**如需要查询该订单的分成本大项的合计成本，请点击**分项成本**按钮，弹出分项成本显示界面，显示本生产订单或生产线日计划各成本大项分本阶和下阶的成本列表。

# 初始准备

*  成本核算对象为“生产订单和生产线日计划”
*  进行了查询期间的成本计算。
