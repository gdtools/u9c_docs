
# 功能描述

成本结转方式是“分项结转”时，对于库存出库，需要在此维护初始的存货成本出库分项还原比例。

# 栏目说明

**成本要素还原比例**

|栏目|说明|
|---|---|
|成本域|指定分项还原成本对应的成本域。参照录入，非空；|
|成本类型|还原对应的成本类型。参照录入，非空；为成本域下的成本类型；|
|账薄|还原对应的账簿。参照录入，非空；成本类型下的账簿；|
|记账期间|账薄的记账期间参照录入，不可空；根据账薄选择记账期间。|
|料品|需要指定分项还原的料品，只可选择“可生产”或“可库存”料品；|
|等级|料品的等级|
|成分|料品的成分。|
|项目|料品对应的项目。|
|批号|料品对应的批号。|
|番号|料品对应的番号。|
|是否固定比例|已定义的还原比例，是否可以系统自动修改。是：该料品的还原比例为手工维护的固定比例，系统不得修改；否：还原比例可手工维护也可系统修改。|
|成本要素|要素还原比例所要指定的成本要素。参照录入；|
|成本要素类型|由成本要素带出。|
|期初成本－本层成本|期初的本层成本，系统自动计算。|
|期初成本－下层成本|期初的下层成本，系统自动计算。|
|本期发生－本层成本|本期发生的本层成本，系统自动计算。|
|本期发生－下层成本|本期发生的下层成本，系统自动计算。|
|本层比例|本层成本在本要素类型下所有本层成本中的占比。手工维护，≥0，≤1。每要素类型下的各明细要素的比例应保证和为1.|
|下层比例|下层成本在本要素类型下所有下层成本中的占比。手工维护，≥0，≤1。每要素类型下的各明细要素的比例应保证和为1|

# 初始准备

*  参数设定与定额成本相关参数【成本结转方式=分项结转】；

# 操作说明

## 重置期初成本

根据已经维护的**成本要素还原比例**，按当期存货的结存情况重新计算期初成本。

**操作前提**

*  已维护**成本要素还原比例**。

**操作步骤**

点击**成本会计－>成本要素还原比例－>重置期初成本**按钮，系统自动进行数据重置。
