
# 功能描述

企业生产的产品存在联副产品或等级品时，其成本计算会首先记入主产品中，需要按一定的比例进行分配，通过此功能可以定义联副产品及等级口的成本分配系数。

# 栏目说明

等级分配系数

|栏目|说明|
|---|---|
|从料品|联副产品及产品等级品分配时，从哪一个料品的成本向外分配。|
|到料品|联副产品及产品等级品分配的目标　料品。|
|类型|成本分配的目标料品是主产品还是联产品、副产品、撤线入库。|
|等级|成本分配目标料品的等级。当类型＝撤线时，不可维护|
|成分|成本分配目标料品的成分。当类型＝撤线时，不可维护|
|产出比例系数|成本分配的比例。手工录入，不可为空；＞0，默认为1。|

# 初始准备

*  参数设定与等级分配系数相关参数【等级分配系数生成方式】；
*  定义【料品】档案及其等级成分

# 操作说明

## 生成

通过本操作，可以从【物料清单】的等级品产出比例中取得联副产品及等级成分分配比例,也可从产量数据中取得联副产品和

等级成分入库比例,作为等级分配分配系数。

在取得分配系数后，用户可以进行手工调整。

操作前提

*  在取数来源为BOM时,确保已启用工程数据系统,已定义物料清单的“等级品产出比例”。
*  取数来源为按入库数量,确保已经手工维护或从制造取过产量数据。

操作步骤

第1步：点击成本会计－>等级分配系数－>操作->生成 按钮;

第2步：系统自动进行取数。

第3步：取数完成后，用户可以查询修改取得的数据。
