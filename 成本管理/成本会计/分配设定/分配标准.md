
# 功能描述

企业每一期间发生的间接生产费用在归集到费用分配组后，会通过一定的分配方法分配到目标对象，本功能用来为费用分配建立分配标准。

用户可以通过本功能定义各期间间接费用的分配路径。

# 业务规则

*  必须为所有的待分配费用定义分配标准；未定义分配标准的待分配间接生产费用，在间接费用分配时将不参与分配。
*  分配标准制定时，应保证所有费用分配组内的间接费用最终分配到成本核算对象。否则，成本计算后，核算对象的成本将不包括未分配到成本核算对象的间接费用。
*  分配标准可以根据分配标准方案每期间生成对应的分配标准。。

# 栏目说明

分配标准

|栏目名称|说明|
|---|---|
|从日期|“从日期”和“到日期”　共同标识分配标准的有效期，从日期定义了有效期的开始时间。手工录入或弹出选择，不可为空；默认为当前日期，用户可修改。|
|到日期|“从日期”和“到日期”　共同标识分配标准的有效期，到日期定义了有效期的结束时间。默认为最大日期，用户不可修改。|
|分配方法|本分配标准分配时使用的分配方法。参照录入，不可为空；注意　:用户应为分配标准选用正确的分配方法；选用的分配方法应当已经维护有分配基数值；选用的分配方法允许分配到的目标对象应当与分配的目标对象一致。关于分配方法允许分配到的目标对象，请参见【分配方法】定义。举例1：当“分配方法＝料品重量”时，用户应当在所有目标料品档案中录入料品的重量。举例2：当用户希望将费用分配给部门时，“分配方法”应当允许分配给部门。|
|从费用分配组|本分配标准分配时的来源费用分配组，即要分配的费用所在的费用分配组。参照录入，不可为空；|
|来源类型|本分配标准所分配费用的来源类型。选择录入，默认为“空”类型；|
|来源对象|为已经选择的来源类型指定一个来源对象。根据来源类型的不同而参照录入；当来源类型为空时可不录入；|
|目标类型|本分配标准所分配费用的目标类型。供选择对象：部门、工作中心、生产线、产品族、订单、日计划、品种、资源。选择录入，默认为“部门”；当从费用分配组＝资源费用类分配组时：目标类型不能为产品簇、品种、生产订单、日计划当从费用分配组＝间接费用类分配组时：目标类型不能为资源|
|关联来源对象|用于指定目标对象是否根据来源对象进行过滤。是：目标对象会根据其与来源对象的关系进行过滤，用户只能选择来源对象下的目标对象；否：目标对象不会根据其与来源对象的关系进行过滤，用户可以选择任意本组织下的合法目标对象；如果目标对象为资源时，则一定默认为是，并只读|
|目标对象过滤参考|用于指定目标对象是否根据本期实际产量或工时进行过滤。不限：目标对象不作过滤，无论本期是否存在入库产量或工时消耗，都作为目标对象；按实际产量：过滤出本期有实际入库产量的目标对象，用户只能在本期有入库产量的目标对象中进行选择；按实际工时：过滤出本期有实际工时的目标对象，用户只能在本期有工时消耗的目标对象中进行选择；按领料情况: 过滤出本期有实际领料的目标对象；按主产品实际产量: 过滤出本期有实际主产品产出的目标对象；|
|说明|用户可以为所定义分配标准添加文字描述或说明。手工录入；|

# 初始准备

*  已定义【费用分配组】和【分配方法】；
*  已定义【部门】、【生产线】、【工作中心】、【料品】档案；
*  如果以“生产订单和生产线日计划”为核算对象，必须已经运行【生产订单】和【生产线日计划】业务。

# 操作说明

## 推广

标准推广是用户快速定义分配标准的工具，通过本操作，以当前已经定义完成的分配标准作为模板，将其分配标准推广到任意费用分配组、来源类型、来源对象。

在多个费用分配组、来源类型、来源对象使用相同的目标对象时，使用本功能操作能够一次完成全部的标准定义。

操作前提

*  已定义“模板”分配标准，并已保存。

操作步骤

点击成本会计－>分配标准－>标准推广按钮，系统弹出推广设置界面。

*  第1步：选择要推广到的来源“部门”、“生产线”、“工作中心”、“费用分配组”。
*  第2步：如果需要将模板分配标准推广到“空”来源类型，勾选“推广到空类型”。
*  第3步：点击“确定”，系统将模板分配标准推广到所有已经选择的目标“来源类型”和目标“从费用分配组”中。
*  第4步：点击“取消”，系统关闭标准推广窗口，返回分配标准主界面。

## 对象查找删除

提供对本分配标准的目标分配对象的快速查找定位和删除，当目标分配对象很多时，用户可以通过本操作快速调整目标分配对象。

操作前提

*  打开已定义的分配标准。

操作步骤

点击成本会计－>分配标准－>对象查找删除按钮，系统弹出查找条件录入界面。

*  第1步：录入查找条件。
*  第2步：点击“确定”，系统将根据用户录入的查找条件，自动在已选择的分配标准对象中查找符合条件的记录，并删除。
