
# 功能描述

定义产品品种的折标系数，主要用于废品入库成本分配。

可按料品或料品分类定义废品行废品成本入库系数，不同要素类型系数可不同。

# 栏目说明

品种系数

|栏目|说明|
|---|---|
|系数类型|品种系数的类型，系统预置“废品行废品成本入库系数”。|
|料品分类性质|当按料品分类定义品种系数时，所依据的料品分类性质。|
|生效日期|本系数的生效日期。|
|失效日期|本系数的失效日期。|
|料品分类|依据指定的料品分类性质，选择品种系数定义依据的料品分类。参照录入，可为空；|
|品种|按品种定义品种系数时，指定要定义折标系数的品种。参照录入；|
|材料系数|材料分项的折标系数。0－1之间的值，默认为0；|
|制造系数|制造分项的折标系数。0－1之间的值，默认为0；|
|人工系数|人工分项的折标系数。0－1之间的值，默认为0；|
|外协系数|外协分项的折标系数。0－1之间的值，默认为0；|
|机器系数|机器分项的折标系数。0－1之间的值，默认为0；|

# 初始准备

*  定义【料品】档案及其等级成分。
