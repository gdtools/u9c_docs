
# 功能描述

约当系数表示企业在制品的完工程度，即在制品相当于完工品的百分之几。

通过约当系数，将企业在制品数量转换为约当完工品的数量，从而使企业可以视情况向在制品分配生产成本，即将本期间发生的所有成本，在完工品与在制品之间进行分配。

可为一个物料建立综合的约当系数,也可分工序建立约当系数,分成本要素类型建立约当系数,或分工序同时分成本要素类型建立约当系数。

# 栏目说明

约当系数

|栏目|说明|
|---|---|
|从日期|“从日期”和“到日期”　共同标识约当系数的有效期，从日期定义了有效期的开始时间。手工录入或弹出选择，不可为空；默认为当前日期，用户可修改。|
|到日期|“从日期”和“到日期”　共同标识约当系数的有效期，到日期定义了有效期的结束时间。默认为最大日期，用户不可修改。|
|料品|要制定約当系数的料品。参照录入，不可为空；只为“可生产”的料品制定约当系数。|
|工艺路线|料品生产所使用的工艺路线。参照录入；当“在制品约当系数制定方式”为“按工序制定”时可录入。|
|生产目的|参照生产目的，默认为“主制造”|
|工序|料品的在制品所在的工序。参照录入；根据工艺路线录入。|
|综合约当系数|按品种综合制定的約当系数。手工录入；≥0　并且　≤1　当“在制品分配方法”为“约当产量（综合）”时不可空。|
|材料系数|按料品的材料要素制定的分项約当系数。手工录入；≥0　并且　≤1　当“在制品分配方法”为“约当产量（分项）”时不可空。|
|人工系数|按料品的人工要素制定的分项約当系数。手工录入；≥0　并且　≤1。当“在制品分配方法”为“约当产量（分项）”时不可空。|
|制造系数|按料品的制造要素制定的分项約当系数。手工录入；≥0　并且　≤1。当“在制品分配方法”为“约当产量（分项）”时不可空。|
|外协系数|按料品的外协要素制定的分项約当系数。手工录入；≥0　并且　≤1。当“在制品分配方法”为“约当产量（分项）”时不可空。|
|机器系数|按料品的机器要素制定的分项約当系数。手工录入；≥0　并且　≤1。当“在制品分配方法”为“约当产量（分项）”时不可空。|

# 初始准备

*  参数设定与约当系数相关参数【在制品分配方法】和【在制品约当系数的制定方式】；
*  定义【料品】档案；
*  按工序制定约当系数时，必须提前定义【工艺路线】和【工序】；
