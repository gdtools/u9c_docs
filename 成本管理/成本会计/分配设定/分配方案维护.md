
# 功能描述

间接费用分配依据的分配标准，需要每期间末成本计算之前进行定义，工作量大，同时企业各期间的费用分配方案和范围相似，为了提高使用效率，用户可在此定义分配方案并保存，月末依据此方案自动生成分配标准，用于成本分配。

# 业务规则

*  必须为所有的待分配费用定义分配标准；未定义分配标准的待分配间接生产费用，在间接费用分配时将不参与分配。
*  分配标准制定时，应保证所有费用分配组内的间接费用最终分配到成本核算对象。否则，成本计算后，核算对象的成本将不包括未分配到成本核算对象的间接费用。
*  分配标准可以根据分配标准方案每期间生成对应的分配标准。。

# 栏目说明

分配方案维护

|栏目|说明|
|---|---|
|编码|分配方案的编码。手工录入，不可为空。在同一组织内唯一；|
|名称|分配方案的名称。手工录入；可以选择录入中文或英文。|
|料品分类性质|使用料品分类进行目标对象过滤时所依据的分类性质。选择录入；|
|是否生效|分配方案是否生效。|

分配方案维护-来源

|栏目|说明|
|---|---|
|来源类型|费用分配时，费用的来源类型。选择录入，可选值为组织、部门、工作中心、生产线；不可为空，默认为组织；|
|部门|当来源类型为“部门”时，如果需要为某个部门单独定义分配方案，可以在此选择对应的部门进行方案定义。参照录入，可选择所有本组织的有效部门；来源类型为“部门”时有效；|
|生产线|当来源类型为“生产线”时，如果需要为某个生产线单独定义分配方案，可以在此选择对应的生产线进行方案定义。参照录入，可选择所有本组织的有效生产线；来源类型为“生产线”时有效；|
|工作中心|当来源类型为“工作中心”时，如果需要为某个工作中心单独定义分配方案，可以在此选择对应的工作中心进行方案定义。参照录入，可选择所有本组织的有效工作中心；来源类型为“工作中心”时有效；|
|目标类型|本分配标准所分配费用要分配到的目标实体的类型。选择录入，可选值为部门、工作中心、生产线、品种、生产订单或日计划；不可为空； 当来源类型为组织、部门时，目标类型不能为工作中心、生产线；当来源类型为工作中心或生产线时：可选品种、订单和日计划； 目标类型受系统参数“成本核算对象”的制约，当核算对象为“订单”时，目标类型不能是品种。当核算对象为“品种”时，目标不能是订单和日计划。|
|分配方法|指定进行费用分配时所使用的分配方法。参照录入，不可为空；|
|关联来源对象|用于指定目标对象是否根据来源对象进行过滤。是：目标对象会根据其与来源对象的关系进行过滤，用户只能选择来源对象下的目标对象；否：目标对象不会根据其与来源对象的关系进行过滤，用户可以选择任意本组织下的合法目标对象；|
|目标对象过滤参考|用于指定目标对象是否根据本期实际产量或工时进行过滤。 不限：目标对象不作过滤，无论本期是否存在入库产量或工时消耗，都作为目标对象； 按实际产量：过滤出本期有实际入库产量的目标对象，用户只能在本期有入库产量的目标对象中进行选择； 按实际工时：过滤出本期有实际工时的目标对象，用户只能在本期有工时消耗的目标对象中进行选择； 按领料情况：过滤出本期有实际领料的目标对象进行费用分配，未领料的目标对象不参与分配； 按主产品实际产量：过滤出本期有实际主产品产量的目标对象进行费用分配，无主产品产出的目标对象不参与分配|

分配标准-费用分配组

|栏目|说明|
|---|---|
|来源分配组|本分配标准分配时的来源费用分配组，即费用要从哪个费用分配组分配出来。参照录入，不可为空；|
|目标分配组|本分配标准分配时的目标费用分配组，即费用需要分配到哪些费用分配组。参照录入，不可为空；目标费用分配组的“性质”必须等于来源费用分配组的“性质”，要么都是“资源费用”类分配组，要么都是“间接费用”类分配组|

分配标准-目标部门

|栏目|说明|
|---|---|
|部门|目标分配对象，表明费用需要分配到哪些具体的部门对象上。参照录入；目标类型为“部门”时有效|
|生产相关|所选部门是否“生产相关”。系统带出，不可维护；|
|描述|描述说明，手工维护。|

分配标准-目标工作中心

|栏目|说明|
|---|---|
|工作中心|目标分配对象，表明费用需要分配到哪些具体的工作中心对象上。参照录入；目标类型为“工作中心”时有效；当关联来源对象＝T、“来源类型＝部门、　来源对象≠空”时：工作中心所属部门　＝来源部门。|
|所属部门|所选工作中心对应的部门。系统带出，不可维护；|

分配标准-目标生产线

|栏目|说明|
|---|---|
|生产线|目标分配对象，表明费用需要分配到哪些具体的生产线对象上。参照录入；目标类型为“生产线”时有效；当关联来源对象＝T、“来源类型＝部门、　来源对象≠空”时：生产线所属部门＝来源部门。|
|所属部门|所选生产线对应的部门。系统带出，不可维护；|

分配标准-目标对象

|栏目|说明|
|---|---|
|生产部门|目标分配对象为生产订单或日计划时，使用订单或日计划的生产部门过滤目标对象。目标分配对象为品种时，使用品种对应的生产部门过滤目标对象。参照录入；|
|订单单据类型|目标分配对象为生产订单时，使用订单的单据类型过滤目标对象。参照录入；|
|日计划单据类型|目标分配对象为生产线日计划时，使用日计划的单据类型过滤目标对象。参照录入；|
|业务类型|目标分配对象为生产订单或日计划时，使用订单或日计划单据类型中对应的业务类型过滤目标对象。参照录入；|
|BOM目的|目标分配对象为生产订单或日计划时，使用订单或日计划对应的BOM目的过滤目标对象。参照录入；|
|工艺目的|目标分配对象为生产订单或日计划时，使用订单或日计划对应的工艺目的过滤目标对象。参照录入；|
|项目|目标分配对象为生产订单或日计划时，使用订单或日计划对应的项目过滤目标对象。目标分配对象为品种时，使用品种对应的项目过滤目标对象。参照录入；|
|是否不入库|目标分配对象为生产订单或日计划时，使用订单或日计划中对应的“是否不入库”选项过滤目标对象。参照录入；|

# 初始准备

*  已定义【费用分配组】和【分配方法】；
*  已定义【部门】、【生产线】、【工作中心】、【料品】档案；
*  如果以“生产订单和生产线日计划”为核算对象，必须已经运行【生产订单】和【生产线日计划】业务。

# 操作说明

## 生成分配标准

使用已定义的分配方案生成分配标准。

操作前提

*  已定义分配方案，并已保存。

操作步骤

*  第1步：点击成本会计－>分配方案维护－>生成分配标准按钮，系统弹出生成分配标准界面；
*  第2步：在界面中选择要生成分配标准的会计期间；
*  第3步：点击确定，系统生成指定期间的分配标准。
