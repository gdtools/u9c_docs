
# 功能描述

成本会计进行成本核算时，可以从库存管理系统取得杂发材料领用数据，作为成本系统制造费用的数据来源。

要从库存管理系统取杂发材料领用数据，必须先定义从库存系统取数的规则，本功能节点提供用户定义材料费用取数规则，使库存管理系统与生产相关的材料杂发数据与成本的费用分配组对应。

只有在用户已经启用了库存管理系统时，才可以从库存管理系统取数，定义从库存系统取数的规则才有意义。

# 栏目说明

库存费用接口

|栏目|说明|
|---|---|
|从日期|“从日期”和“到日期”　共同标识本条库存费用接口数据的有效期，从日期定义了有效期的开始时间。手工录入或弹出选择，不可为空；默认为当前日期，用户可修改。|
|到日期|“从日期”和“到日期”　共同标识本条库存费用接口数据的有效期，到日期定义了有效期的结束时间。系统自动置为最大日期，用户可修改；到日期≥从日期|
|费用分配组|定义库存费用接口取来的数据要存放在成本系统的哪一个费用分配组。参照录入，不可空；|
|部门|费用的受益实体，标识材料费用需要在哪个受益部门归集。参照录入；|
|生产线|费用的受益实体，标识材料费用需要在哪个生产线归集。参照录入，可以为空；|
|工作中心|费用的受益实体，标识材料费用需要在哪个受益工作中心归集。参照录入，可以为空；　注意　:1、部门、生产线、工作中心同为费用的受益实体，费用一旦取入受益实体，将按一定的分配方法在受益对象之间进行分配。2、可以不指定受益实体，未指定受益实体，则必须指定受益对象。|
|分类性质|领用料品的分类对应的分类性质。|
|料品分类|领用料品在指定分类性质下定义的分类。|
|料品|产生材料费用的料品。|
|厂牌|料品的厂牌。|
|单据分类|标示此库存单据是杂发单还是杂收单|
|单据类型|料品领用时所使用的单据类型。|

库存费用接口－自动生成设置

|栏目|说明|
|---|---|
|分类性质|选择所发料品自动生成库存费用接口时所使用的分类性质。|
|单据类型(杂发)|选择生产相关杂发业务单据的单据类型。|
|单据类型(杂收)|选择生产相关杂收业务单据的单据类型。|
|料品分类|选择所发料品在料品分类性质下的料品分类。|
|费用分配组|维护各类业务对就的费用分配组，生成费用接口数据时，将各单据类型和料品分类对应的费用取到对应的费用分配组中。|

# 初始准备

*  参数设定与库存费用接口【相关参数】
*  已经定义【费用分配组】；
*  已经定义【账薄】；
*  定义【部门】、【生产线】、【工作中心】档案；
*  已经定义了【料品】档案、【料品分类】体系或【杂发单据类型】；
*  已经启用【库存管理】系统；
