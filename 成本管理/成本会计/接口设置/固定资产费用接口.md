
# 功能描述

成本会计进行成本核算时，可以从固定资产系统取得期间已计提的资产折旧，作为成本系统机器费用或制造费用的数据来源。

要从固定资产系统取得折旧数据，必须先定义从固定资产系统取数的规则，本功能节点提供用户定义折旧取数规则，使固定资产系统的折旧数据与成本的费用分配组对应。

只有在用户已经启用了固定资产系统时，才可以从固定资产系统取数，定义从固定资产系统取数的规则才有意义。

# 栏目说明

|栏目|说明|
|---|---|
|从日期　|“从日期”和“到日期”　共同标识本条固定资产费用接口数据的有效期，从日期定义了有效期的开始时间。手工录入或弹出选择，不可为空；默认为当前日期，用户可修改。|
|到日期|“从日期”和“到日期”　共同标识本条固定资产费用接口数据的有效期，到日期定义了有效期的结束时间。系统自动置为最大日期，用户可修改；到日期≥从日期|
|成本账薄|指定固定资产费用接口取来的数据要存放在成本系统的哪一个账薄。参照录入，不可空；可以是本组织对应的法人组织的主账薄。|
|费用分配组|定义固定资产费用接口取来的数据要存放在成本系统的哪一个费用分配组。参照录入，不可空；|
|成本域|定义从固定资产接口取得的数据属于哪个成本域。如果用户不能确定费用所属成本域或不区分成本域，可以不录入。参照录入，可以为空；|
|资产组织|负责资产管理的组织。参照录入，不可空；与成本系统对应的工厂组织在同一个法人组织下；资产组织与工厂组织的关系为“使用－资产”关系。　注意　:成本会计默认为资产组织与资产对应的货主组织为同一个组织，如果资产组织与货主组织不是同一个组织，成本会计不支持从固定资产取数。|
|部门|计提折旧的部门，即接口要取哪一个部门的资产折旧。参照录入；为工厂组织下的部门。　注意　:如果资产卡片对应的资产分布在多个使用部门，并且要求按部门统计计提折旧时，必须　录入部门。|
|折旧账薄|数据来源账薄，指定固定资产接口取数的数据来源于哪一个折旧账薄。参照录入，不可空；|
|从资产卡片|计提折旧的资产，“从资产卡片”和“到资产卡片”共同决定折旧的资产范围。参照录入；|
|到资产卡片|计提折旧的资产，“从资产卡片”和“到资产卡片”共同决定折旧的资产范围。参照录入；到资产卡片≥从资产卡片|
|比例|定义从折旧账薄取数的比例。取数的比例 ＜＝100% 默认为100%；相同的卡片段比例之和不能＞1注：折旧费用可以取到不同的成本域，当企业折旧费用未按成本域分别记录时，需要指定费用取值到各成本域的比例。|

# 初始准备

*  已定义【费用分配组】；
*  已定义【账薄】；
*  已启用【固定资产】系统；
