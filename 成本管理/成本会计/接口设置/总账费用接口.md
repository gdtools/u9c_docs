
# 功能描述

成本会计进行成本核算时，可以从总账取得间接费用，如制造费，也可以从总账取得直接费用，甚至可以将总账作为成本的唯一取数源。

要从总账取数，必须先定义从总账取数的规则，本功能节点提供用户定义总账取数规则，使总账科目数据与成本的费用分配组对应。

# 栏目说明

|栏目|说明|
|---|---|
|从日期|“从日期”和“到日期”　共同标识本条总账费用接口数据的有效期，费用取数自动按照期间结束日期找对应生效接口手工录入或弹出选择，不可为空；默认为当前日期，用户可修改。|
|到日期|“从日期”和“到日期”　共同标识本条总账费用接口数据的有效期，费用取数自动按照期间结束日期找对应生效接口系统自动置为最大日期，用户不可修改；当系统制定后续期间同样对象的接口时，该到日期自动置为新接口生效日期|
|成本账薄|指定总账接口取来的数据要存放在成本系统的哪一个账薄。|
|费用分配组|定义总账接口取来的数据要存放在成本系统的哪一个费用分配组。|
|成本域|定义从总账接口取得的数据属于哪个成本域。如果用户不能确定费用所属成本域或不区分成本域，可以不录入。参照录入，可以为空；注：如果费用要取入最终核算对象，作为直接费用时，应指定成本域 如果费用不取入最终核算对象，则可以不指定成本域。 费用可以按成本域范围进行分配，也可以在不同的成本域中进行分配。 是否在指定的成本域中进行分配，主要依据组织参数“间接费用分配匹配成本域”的设置|
|部门|费用的受益实体，标识总账接口取来的是哪一个受益部门的费用数据。|
|生产线|费用的受益实体，标识总账接口取来的是哪一个受益生产线的费用数据。|
|工作中心|费用的受益实体，标识总账接口取来的是哪一个受益工作中心的费用数据。注意　:1、部门、生产线、工作中心同为费用的受益实体，费用一旦取入受益实体，将按一定的分配方法在受益对象之间进行分配。2、可以不指定受益实体，未指定受益实体，则必须指定受益对象。|
|项目|费用的受益对象，标识总账接口取来的是哪一个受益项目的费用数据。|
|品种|费用的受益对象，标识总账接口取来的是哪一个受益品种的费用数据。|
|生产订单|费用的受益对象，标识总账接口取来的是哪一个受益生的费用数据。|
|生产线日计划|费用的受益对象，标识总账接口取来的是哪一个受益生产线日计划的费用数据。注意　:1、品种、生产订单、生产线日计划同为费用的受益对象，费用一旦取入受益对象，将直接归集在该受益对象中。2、费用的受益对象与系统参数“成本核算对象”相关：当成本核算对象＝“品种”时，费用受益对象必须是品种，当成本核算对象＝“生产订单和生产线日计划”时，费用受益对象必须是生产订单或生产线日计划。3、可以不指定费用的受益对象，未指定受益对象，则必须指定受益实体。|
|来源组织|来源于哪个组织的总账数据可以是工厂组织或物流组织。一般存货核算，可以来源于不同货主组织的账薄。|
|总账账薄|数据来源账薄，指定总账接口取数的数据来源于哪一个总账账薄。|
|方向|定义接口取数时，所取数据的方向，是借方数据、贷方数据还是取科目净额。|
|取数科目|指定总账接口取数对应的科目。如果未指定“总账账薄”，则不能指定科目。当用户定义了多段式科目编码结构时，系统将提供按科目段的科目录入界面。当某科目段有下级时，允许用户选择“包含下级”，从而汇总下级发生额作为本科目费用额。当指定　的科目为明细科目，并且该科目定义了备查项时，允许用户输入备查项。|
|LSC规则|制定总账科目的每一段的取数规则：Ｌ：为循环段，总账取数会把该段各个明细取回存储到各个受益对象上，暂时系统只支持部门、生产线、工作中心、项目以及各个最终对象；Ｓ：为汇总段，总账取数会把该段各个科目进行汇总后返回到接口指定的受益对象上；Ｃ：为定值段，总账取数会按照科目配置取固定科目值到接口指定的受益对象上；|
|包含损益结转凭证|指定总账取数是否包含损益结转凭证：是，默认值；否；|
|从备查项|“从备查项”和“到备查项”共同决定总账接口取数时费用在科目中的备查项范围，一旦指定备查项范围，该备查项范围中的合计费用将被存入已经指定的费用分配组。从备查项指定费用的起始备查项。只有指定的“科目”中定义了备查项，才能进行备查项选择。|
|到备查项|指定费用的结束备查项。只有指定的“科目”中定义了备查项，才能进行备查项选择。系统将按备查项范围汇总本币发生额。注意　:系统根据备查项对应的值集的值决定备查项范围的起止范围合法性，维护时应保证“到备查项”对应的弹性域值集值≥“从备查项”对应的值集值。举例1：备查项1对应的弹性域的值集为实体类型部门实体，则应保证“到备查项”对应的部门编码≥“从备查项”对应的部门编码。举例2：备查项2对应的弹性域的值集为无档案类型日期型段值，则应保证“到备查项”对应的日期≥“从备查项”对应的日期。|
|比例|从指定科目或科目备查项中取数的比例＜＝100% 默认为100%相同的科目费用比例之和不能＞1注：一个科目的费用可以取到不同的成本域，当企业费用未按成本域分别记录时，需要指定费用取值到各成本域的比例|

# 初始准备

*  参数设定，与总账费用接口【相关参数】
*  已经定义【费用分配组】；
*  已经定义【账薄】及其【账薄科目】；
*  已经定义【部门】、【生产线】、【工作中心】、【料品】档案；
*  以“生产订单和生产线日计划”为核算对象时，必须已经运行【生产订单】和【生产线日计划】业务。
