
# 功能描述

对生产过程中发生的间接费用，成本会计是通过分配的方式计入成本的，系统已经为用户提供了多种分配方法，为了满足用户特殊的成本分配需要，用户可以通过本功能自定义分配基数，从而产生新的分配方法用于成本分配。

系统给定的分配基数分配对象包括：部门、生产线、工作中心。

分配基数一般采用“同级分配”的原则，即分配对象在同一个级别内进行分配。

# 栏目说明


|栏目名称|说明|
|---|---|
|编码|费用分配组的编码。手工录入，不可为空；在同一组织内唯一； |
|名称|费用分配组的名称。手工录入；可以选择录入中文或英文。|
|成本要素|选择费用分配组所属的明细成本要素。参照选择，不可为空；必须为明细成本要素；|
|是否分配到资源|手工选择，默认为false是：此费用分配组中归集的间接费用将允许分配到工序资源；否：此费用分配组中归集的间接费用不允许分配到工序资源；|
