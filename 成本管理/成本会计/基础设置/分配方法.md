
# 功能描述

对生产过程中发生的间接费用，成本会计是通过分配的方式计入成本的，要进行间接费用的分配，必须使用一定的分配方法，用户可以通过本功能定义或修改分配方法。

U9cloud系统已经为用户预先定义了多种分配方法，为了满足用户特殊的成本分配需要，用户还可以在定义了【分配基数】的基础上，通过此功能增加新的分配方法。

# 关键应用

系统预定义的分配方法包括如下几类共33个：

*  产出类：

包括：完工数量、投入数量、入库数量、返工数量、报废数量、负担成本数量；

*  实际消耗类：

包括：实际工时、实际加工工时、实际准备工时、实际机时、实际加工机时、实际准备机时、实际空闲时间和实际材料成本。

*  定额消耗类：

包括：计划总工时、定额工时、定额加工工时、定额准备工时、定额机时、定额加工机时、定额准备机时、定额空闲时间、定额入库工时、定额工时（不含返工，返修）。

*  定额成本类：

包括：综合定额成本、分项定额成本、定额入库成本、明细定额成本、分项定额投入成本、明细定额本层成本。

*  物理属性类：

包括：料品重量、料品体积。

*  其他类：

包括：固定比例分配法、用户通过定义分配方法来指定该分配方法用于分配到哪些对象。

# 栏目说明


|栏目名称|说明|
|---|---|
|编码|分配方法的编码。手工录入，不可为空；在同一组织内唯一；提示:编码0-50预留给系统预定义的分配方法，用户定义新的分配方法，编码必须大于50。|
|名称　|分配方法的名称。手工录入；可以选择录入中文或英文。|
|自定义分配基数|用户定义新的分配方法时，必须提前定义【分配基数】，并在此引用。参照选择；用户定义新的分配方法时，此处不可为空。|
|用于分配至部门|定义此分配方法是否可以用于分配至部门。|
|用于分配至生产线|定义此分配方法是否可以用于分配至生产线。|
|用于分配至工作中心|定义此分配方法是否可以用于分配至工作中心。|
|用于分配至产品簇|定义此分配方法是否可以用于分配至产品簇。|
|用于分配至品种|定义此分配方法是否可以用于分配至品种。|
|用于分配至生产订单|定义此分配方法是否可以用于分配至生产订单。|
|用于分配至生产线日计划　|定义此分配方法是否可以用于分配至生产线日计划。|
|用于分配至资源|定义此分配方法是否可以用于分配至资源|
|关联来源对象|定义此分配方法是否仅用于分配到关联的来源对象勾选后，某部门费用只能分配到在该部门加工的订单上,生产线和工作中心同理;|
|说明|用户可以为所定义的分配方法添加文字描述或说明。|
