
# 功能描述

费用分配组是建立在明细成本要素下的费用分组，通过费用分配组，用户可以非常灵活对生产费用进行分组归集，将不同性质的人工、制造等间接生产费用进行分组归集，然后对不同分配组的费用按不同的分配方法分配给对应的核算对象。

间接生产费用首先要归集入费用分配组，然后再根据【分配标准】来进行分配。

# 关键应用

*  用户可以在一个明细成本要素下建立多个费用分配组，也可以在多个明细成本要素下建立同一个费用分配组，每一个可能发生间接费用 的明细要素下至少应建立一个费用分配组，否则当该明细要素下有间接费用发生时，会影响成本计算的正常进行。
*  费用分配组的细化：费用分配组可以因其所属的受益实体（部门、生产线、工作中心）而被进一步细化，U9cloud允许对同一个明细要素制定多个费用分配组，每一个费用分配组＋受益实体使用不同的分配方法进行费用分配。

# 栏目说明

|栏目名称|说明|
|---|---|
|编码|费用分配组的编码。手工录入，不可为空；在同一组织内唯一； |
|名称|费用分配组的名称。手工录入；可以选择录入中文或英文。|
|成本要素|选择费用分配组所属的明细成本要素。参照选择，不可为空；必须为明细成本要素；|
|是否分配到资源|手工选择，默认为false是：此费用分配组中归集的间接费用将允许分配到工序资源；否：此费用分配组中归集的间接费用不允许分配到工序资源；|

# []()[]()应用举例

企业制造费用中的电费明细要素下可以定义两个费用分配组：生产用电费用分配组、照明用电费用分配组一车间和二车间都有电费发生，此时两个费用分配组在两个部门可以使用不同的分配方法进行费用分配。
