
# 功能描述

推算成本阶级，通过成本阶层实现成本分步计算。

成本计算将按成本阶层输出计算成果，也就是说，成本计算时，用户可以分成本阶层进行成本计算、检查和调整计算结果。

成本阶层的推算依赖于生产领料、联副产出、形态转换等生产相关的实际业务。

成本阶层的推算与会计期间相关，每一期间都应推算本期间的成本阶层。

# 业务规则

*  成本阶层是成本计算的基础，用户在运行【成本计算】之前，必须推算成本阶层；
*  如果某次成本阶层推算后，下次成本计算前，发生了领退料或形态转换等业务，用户应重新进行成本阶层推算，然后再成本成本计算。否则材料费用取数、成本计算都将产生差异。

# 按钮说明

*  <成本阶层推算>：进行成本阶层推算，根据本期实际备料情况，推算本期间的成本阶层。
*  <循环业务查询>：查询在进行成本阶层推算时，遇到的循环领用或形态转换的料品。
*  <成本阶层查询>：查询成本阶层推算结果。
*  <成本维度阶层查询>：查询成本维度的计算顺序，比如成本域Ａ调拨到成本域Ｂ且成本联动，那么Ａ域顺序为１，Ｂ域顺序为２
