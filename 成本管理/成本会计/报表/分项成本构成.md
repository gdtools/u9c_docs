
# 功能描述

本功能是对指定成本对象、在指定成本域成本类型和会计期间内各分项成本的发生额占总成本比例的分析，本功能也可以提供单位成本的比例分析。

# 栏目说明

分项成本构成－查询条件

|栏目|说明|
|---|---|
|成本域|分项成本构成分析的目标成本域。本组织内的成本域，参照录入，不可为空。系统会默认给出一个包含主账薄的成本域，用户可以参照修改。|
|成本类型|分项成本构成分析的目标成本类型。成本域下的所有成本类型，参照录入，不可为空；统会默认给出指定成本域下的记账成本类型，用户可以参照修改。|
|账薄|分项成本构成分析的目标账薄。参照录入，不可为空。|
|记账期间|分项成本构成分析的目标账薄期间。参照录入，参照账薄下的所有账薄期间。可以录入期间段；|
|生产订单|分项成本构成分析的目标生产订单。参照录入，可以为空。当成本核算对象为“品种”时，可以不录入。|
|生产线日计划|分项成本构成分析的目标生产线日计划。参照录入，可以为空。当成本核算对象为“品种”时，可以不录入。|
|品种|分项成本构成分析的目标品种。参照录入。当成本核算对象为“品种”时，在此录入要进行分项成本构成分析的品种，不可为空。当成本核算对象为“生产订单和生产线日计划”时，在此录入生产订单或者生产线日计划的生产料品，可以为空，为空时表示订单或日计划　生产的品种。|
|等级|分项成本构成分析的目标品种的等级。选择录入，可以为空。|
|成分|分项成本构成分析的目标品种的成分。参照录入，可以为空。|

# 操作说明

## 分项成本构成

通过分项成本构成分析功能，可以进行目标对象的各成本项目在总成本中的比例分析，可以分成本总额和单位成本进行分别分析，并可以生成分项成本构成分析表，打印输出。

**操作步骤**

点击**成本会计－>分项成本构成　**进入分项成本构成分析功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件，在此可以选择进行单位成本分析还是成本总额分析，以及分项成本构成分析涉及到的各条件项目。
*  **第2步：**确定后显示分项成本构成分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
