
# 功能描述

依据库存费用接口方案配置的取数条件从库存获取生产相关的杂收杂发数据与费用取数结果比较，计算差异。实现业务与成本的快速对账。

# 栏目说明

|杂发单据类型|成本分析的目标杂发单。参照录入。按当前组织过滤。可空，空为全部|

|受益部门|成本分析的目标部门。参照录入，可以为空。|

# 操作说明

## 库存费用接口对账表

使用库存费用接口对账表可以帮助用户核对费用取数结果与实际业务是否一致。排除费用取数后是否存在新增业务。

新增业务包含生产相关杂收杂发单据的审核和弃审。

**操作前提**

*  完成库存费用接口取数。

**操作步骤**

点击**成本会计－>库存费用接口对账表　**进入库存费用接口对账功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件。
*  **第2步：**确定后显示库存费用接口对账结果报表。用户可以输出或打印结果报表。

# 初始准备

*  设置库存费用接口方案；
*  库存费用接口取数完成；
