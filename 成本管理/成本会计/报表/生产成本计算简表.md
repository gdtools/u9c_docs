
# 功能描述

生产成本计算简表是生产成本计算表的简化格式，可以按照成本要素类型分析发生成本。期初和转出成本不支持按照按照成本要素类型分析。

# 栏目说明

生产成本计算简表－查询条件

|栏目|说明|
|---|---|
|分析类型|针对成本会计核算的对象不同生产成本计算简表提供两类分析对象。生产计算简表的分析对象分别为生产订单和品种。分析类型生产订单：可以按照生产订单汇总分析成本流转过程，报表行分组不可选品种。分析类型品种：可以按照品种汇总分析成本流转过程，报表行分组不可选生产订单。|
|组织|需要进行成本分析的组织。可以是当前组织或当前组织的工厂组织。|
|账薄|所选组织法人账簿或多币种账簿。|
|记账期间|需要进行成本分析的账簿会计期间。|
|成本域|需要进行成本分析的成本域。|
|成本类型|需要分析的成本类型。|
|产品类型|产出的类型，分为主产品、副产品、联产品、撤线。|
|成本类别|用于区分普通生产成本和返修生产成本。|

# 操作说明

## 生产成本计算简表

生产成本计算简表是成本模块预置的成本分析报表。主要以订单或品种为分析对象，分析成本的投入产出状况。

报表特点是没有将成本要素类型和成本要素作为可选行列分组，而是将要素类型作为固定列展现成本的发生明细。其他成本未细化到要素类型及要素。

生产成本计算简表降低了用户配置的难度，以一种比较简单直观的方式提供成本计算过程的分析。

**操作前提**

*  成本计算完成。

**操作步骤**

点击**成本会计－>成本计算简表　**进入成本计算简表功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件。
*  **第2步：**确定后显示成本计算简表结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
