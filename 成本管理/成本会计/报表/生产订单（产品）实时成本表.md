
# 功能描述

提供生产订单领料、资源、分摊费用等成本的实时分析。报表查询不依赖成本计算。

# 栏目说明

生产订单（产品）实时成本表－查询

|栏目|说明|
|---|---|
|组织|当前组织及工厂组织。默认当前组织。不可空。|
|账簿|查询组织主账簿、多币种账簿、二级核算账簿。默认查询组织主账簿。不可空。|
|成本域|按查询组织过滤。可空。空为全部。|
|成本类型|按所选成本域过滤。可空。空为全部记账成本类型。|
|料品|按所选组织过滤。可空。料品为生产订单或日计划生产料品。|
|生产订单|按所选组织过滤。可空。|
|日计划|按所选组织过滤。可空。|
|成本来源类型|默认为空。可空，空为全部。枚举值：直接材料、直接资源、间接成本 。直接材料成本取自领料单成本。直接资源成本取自资源报告成本。间接成本为成本会计间接费用分配结果。|
|项目|参照项目档案。默认当前组织项目档案。项目为生产订单项目。|
|实际开始日期|生产订单或日计划开始日期。默认当前期间第一天。|
|实际结束日期|生产订单或日计划结束日期。默认当前期间最后一天。|
|成本要素|参照成本要素档案。默认空，空为分析对象成本的全部成本要素成本。|

# 操作说明

## 生产订单（产品）实时对账表

提供分析生产订单或日计划发生的实时直接成本。

数据来源包括直接材料、资源、分摊费用。

直接材料包括该生产订单或产品发生的直接领料、退料、生产相关杂发/杂收（指定了具体生产订单号或产成品）。

资源取相关资源报告，分摊费用取分摊到该mo的费用。

数据是跟该Mo相关的累积发生值，不区分期间

**操作前提**

*  适用原材料采用实时核算的用户。

**操作步骤**

点击成**本会计－>生产订单（产品）实时成本表－>查询**进入生产订单（品种）实时成本表话查询条件录入画面。

具体步骤如下所示。

*      *  **第1步：**录入查询分析条件。
   *  **第2步：**确定后显示生产订单（品种）实时成本表。用户可以输出或打印结果报表。

# 初始准备

*  有生产订单领料、资源申报业务发生。
