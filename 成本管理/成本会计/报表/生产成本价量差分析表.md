
# 功能描述

根据订单的标准用量、标准成本单价和实际用量、实际成本单价为依据分析价量差异

# 业务规则

## 使用前提

*  启用成本会计模块

# 栏目说明

|栏目名称|说明|
|---|---|
|组织|价量差分析所需要订单或品种所在的组织，默认为当前登录组织|
|账簿|价量差分析的账薄；参照录入，参照账薄下的所有账薄期间|
|期间|价量差分析期间|
|成本域|价量差分析的成本域。参照录入，不可为空|
|成本类型|价量差分析的成本类型。参照录入，不可为空；参照成本域下的所有成本类型|
|生产订单|价量差分析的生产订单。参照录入，可以为空|
|日计划|价量差分析的生产线日计划。参照录入，可以为空|
|部门|价量差分析的部门参照录入，可以为空|
|生产料号|价量差分析的生产料号参照录入，可以为空|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
