
# 功能描述

当核算对象为订单时，汇总报表企业本期间订单生产成本。本功能也可以得到在订单核算下的按品种成本的汇总表和企业期间生产成本表。

# 栏目说明

生产成本明细表－按订单查询时的查询条件

|栏目|说明|
|---|---|
|汇总方式|成本汇总分析的方式。选择录入，包括“按订单”“按品种”两个可选项。选择“按订单”时，将使用下列查询项。|
|成本域|成本分析的目标成本域。参照录入，不可为空。|
|成本类型|成本分析的目标成本类型。参照录入，不可为空；参照成本域下的所有成本类型。|
|账薄|成本分析的目标账薄。参照录入，不可为空。|
|记账期间|成本分析的目标账薄期间。参照录入，参照账薄下的所有账薄期间。可以录入期间段；|
|订单类型|成本分析的目标订单的订单类型。参照录入|
|生产订单|成本分析的目标生产订单。参照录入，可以为空。当成本核算对象为“品种”时，可以不录入。|
|生产线日计划|成本分析的目标生产线日计划。参照录入，可以为空。当成本核算对象为“品种”时，可以不录入。|
|料品|成本分析的目标品种。参照录入，不可为空。当成本核算对象为“品种”时，在此录入要进行成本分析的品种。当成本核算对象为“生产订单和生产线日计划”时，在此录入生产订单或者生产线日计划的生产料品。|
|等级|成本分析的目标品种的等级。选择录入，可以为空。|
|成分|成本分析的目标品种的成分。参照录入，可以为空。|

# 操作说明

## 生产成本明细表

通过生产成本明细表，可以进行期间成本按订单汇总、按品种汇总、按订单汇总后再按品种汇总的成本分析，并可以生成成本分析报表，打印输出。

**操作步骤**

点击**成本会计－>生产成本明细表　**进入生产成本明细表功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件，在此可以选择进行何种成本汇总类型，以及成本汇总分析涉及到的各条件项目。
*  **第2步：**确定后显示成本汇总分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
