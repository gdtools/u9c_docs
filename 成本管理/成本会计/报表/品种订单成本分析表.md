
# 功能描述

当核算对象为订单时，通过本功能分析同一品种在一定期间内的各订单中的成本分布比例。

# 栏目说明

品种订单成本分析表－查询条件

|栏目|说明|
|---|---|
|成本域|成本分析的目标成本域。参照录入，不可为空。|
|成本类型|成本分析的目标成本类型。参照录入，不可为空；参照成本域下的所有成本类型。|
|账薄|成本分析的目标账薄。参照录入，不可为空。|
|记账期间|成本分析的目标账薄期间。参照录入，参照账薄下的所有账薄期间。可以录入期间段；|
|料品|成本分析的目标品种。参照录入，不可为空。录入生产订单或者生产线日计划的生产料品。|
|等级|成本分析的目标品种的等级。选择录入，可以为空。|
|成分|成本分析的目标品种的成分。参照录入，可以为空。|

# 操作说明

## 品种订单成本分析表

通过品种订单成本分析表，可以按品种查找生产该品种的订单或生产线日计划，并分析该品种的成本在各生产订单或生产线日计划中的分布情况，可以生成成本分析报表，打印输出。

**操作步骤**

点击**成本会计－>品种订单成本分析表　**进入品种订单成本分析表功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件。
*  **第2步：**确定后显示成本汇总分析结果报表。用户可以输出或打印结果报表。
*  **第3步：**点击“生产订单”或“生产线日计划”上的链接，可以得到生产订单或生产线日计划的成本明细。

# 初始准备

*  进行了分析期间的成本计算。
