
# 功能描述

本功能是对指定生产订单或生产线日计划、在指定成本域成本类型和会计期间内各个工序进行期间实际成本和标准成本的差异分析。

# 栏目说明

期间工序成本差异分析－查询条件

|栏目|说明|
|---|---|
|成本域|分项成本构成分析的目标成本域。本组织内的成本域，参照录入，不可为空。系统会默认给出一个包含主账薄的成本域，用户可以参照修改。|
|成本类型|分项成本构成分析的目标成本类型。成本域下的所有成本类型，参照录入，不可为空；统会默认给出指定成本域下的记账成本类型，用户可以参照修改。|
|账薄|分项成本构成分析的目标账薄。参照录入，不可为空。|
|记账期间|分项成本构成分析的目标账薄期间。参照录入，参照账薄下的所有账薄期间。可以录入期间段；|
|生产订单|目标生产订单。同生产线日计划互斥|
|生产线日计划|目标生产线日计划。同生产订单互斥|
|工序|生产订单工序或日计划工序.工序参照录入。|
|成本要素|参照录入，可以多选，为空时取全部要素。|

# 操作说明

## 期间工序成本差异分析

通过期间工序成本差异分析功能，可以进行目标订单或日计划的的各工序各成本要素的标准成本和实际成本的差异和差异率分析，并可以生成成本分析表，打印输出。

**操作步骤**

点击**成本会计－>期间工序成本差异分析　**进入期间工序成本差异分析功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件，在此可以选择进行分析的订单或日计划工序成本要素等条件项目。
*  **第2步：**确定后显示分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的工序成本计算，维护了工序的标准成本。
