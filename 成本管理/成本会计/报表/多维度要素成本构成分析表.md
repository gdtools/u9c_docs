
# 功能描述

多维度成本构成分析是对不同部门、生产线、工作中心等维度在某会计时期内成本要素的成本发生及其所占的比例的分析。

# 操作说明

## 多维度要素成本构成分析

通过多维度要素成本构成分析，可以进行指定期间段内各个维度的要素成本构成分析，并可以生成成本分析报表，打印输出。

**操作步骤**

点击**成本会计－>多维度要素成本构成分析　**进入多维度要素成本构成分析功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件
*  **第2步：**确定后显示多维度要素成本构成分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
