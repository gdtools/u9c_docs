
# 功能描述

对某会计期间段内各成本对象，生产订单或品种的实际单价与标准单价、实际成本与标准成本以及两者之间的差异进行分析，并提供订单或品种的产量。

# 栏目说明

订单品种成本差异分析－查询条件

|栏目|说明|
|---|---|
|分析类型|成本差异分析的生产成本对象按订单；按品种，默认显示。|
|组织|成本差异分析所需要订单或品种所在的组织，默认为当前登录组织。|
|成本域|成本分析的目标成本域。参照录入，不可为空。|
|成本类型|成本分析的目标成本类型。参照录入，不可为空；参照成本域下的所有成本类型。|
|账薄|成本差异分析的目标账薄。参照录入，不可为空。|
|期间|成本差异分析的目标账薄期间。参照录入，参照账薄下的所有账薄期间。|
|料号|可空，空为料品分类对应的全部料品，如果分类为空，则为全部。默认为空 必须为“可生产”|
|品名|成本差异分析的目标品种。手工录入，字串，可空，支持模糊，空为全部|
|生产订单|成本差异分析的目标生产订单。参照录入，可以为空。当成本分析类型为“按品种”时，不必维护。可以为空，空为所有的订单，当生产订单和生产线日计划同时为空时，为所有订单和所有日计划。|
|生产线日计划|成本差异分析的目标生产线日计划。参照录入，可以为空。当成本分析类型为“按品种”时，不必维护。可以为空，空为所有的日计划，当生产订单和生产线日计划同时为空时，为所有订单和所有日计划。|

|---|---|

订单品种成本差异分析－分析结果表体

|栏目|说明|
|---|---|
|料号|显示成本差异分析的对象料号|
|品名|显示成本差异分析的对象品名|
|产量|显示成本差异分析的成本单位产量|
|标准单价|显示成本差异分析的标准单价|

# 操作说明

## 订单品种成本差异分析

通过订单品种成本差异分析，可以分析一个期间内各订单、日计划或品种的

生产数量、标准单价、实际单价、标准成本、实际成本、成本差异等成本情况，可以形成报表，打印输出。

**操作步骤**

点击**成本会计－>订单品种成本差异分析　**进入订单品种成本差异分析功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件。
*  **第2步：**确定后显示成本差异分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
