
# 功能描述

对某会计期间段内某一成本对象，如订单或品种的资源标准与实际的耗用量及标准与实际的成本额进行分析，并提供标准成本与实际成本的成本差异及成本总差异。

# 操作说明

## 材料资源成本价量差分析

通过材料资源成本价量差分析，可以分析一个期间内某一订单、日计划或品种的资源的

标准与实际用量、标准与实际单价、标准与实际成本、成本的价量差、成本的总差异等成本情况，可以形成报表，打印输出。

**操作步骤**

点击**成本会计－>材料资源成本价量差分析　**进入材料资源成本价量差分析功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件。
*  **第2步：**确定后显示价量差分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
