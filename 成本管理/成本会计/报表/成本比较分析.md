
# 功能描述

本功能用来对成本对象两个不同的成本类型或期间的成本进行比较，以了解成本升降的情况。成本比较分析只针对品种成本对象进行。

# 操作说明

## 成本比较分析

通过成本比较分析功能，可以进行两个不同目标对象的总成本或单位成本的比较分析，并可以生成成本分析报表，打印输出。

**操作步骤**

点击**成本会计－>成本比较分析　**进入成本比较分析功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件，在此可以选择进行何种成本分析，以及成本分析涉及到的各条件项目。
*  **第2步：**确定后显示成本分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
