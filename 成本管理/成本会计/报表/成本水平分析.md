
# 功能描述

当核算对象为品种时，分析各品种在一指定的期间段内各期间产品成本的明细及其分阶段平均成本报表。

# 栏目说明

成本水平分析－查询条件

|栏目|说明|
|---|---|
|成本域|成本分析的目标成本域。参照录入，不可为空。|
|成本类型|成本分析的目标成本类型。参照录入，不可为空；参照成本域下的所有成本类型。|
|账薄|成本分析的目标账薄。参照录入，不可为空。|
|从期间|成本分析的目标账薄期间段的开始期间。参照录入，参照账薄下的所有账薄期间。|
|到期间|成本分析的目标账薄期间段的结束期间。参照录入，参照账薄下的所有账薄期间。到期间≥从期间|
|料品分类|成本分析的目标品种的料品分类。|
|料品|成本分析的目标品种。参照录入，不可为空。|

成本水平分析－分析结果

|栏目|说明|
|---|---|
|成本域|显示成本分析的成本域。|
|成本类型|显示成本分析的成本类型。|
|账薄|显示成本分析的账薄。|
|从期间|显示成本分析的账薄期间段的起始期间。|
|到期间|显示成本分析的账薄期间段的结束期间。|
|制表人|显示分析报表制表人|
|制表日期|显示分析报表的制表日期|
|料品分类|显示成本分析的目标品种的料品分类。|
|品名|显示成本分析的目标品种名称。|
|料号|显示成本分析的目标品种代码。|
|期间成本|显示成本分析的目标品种在各会计期间的成本额。|
|总平均|显示成本分析的目标品种在各会计期间的成本额的平均值。|
|一年平均|显示成本分析的目标品种在最近一年内各会计期间的成本额的平均值。|
|半年平均|显示成本分析的目标品种在最近半年内各会计期间的成本额的平均值；|

# 操作说明

## 成本水平分析

通过成本水平分析，可以进行一个期间段内同一个品种的生产成本的变动分析，并可以生成成本分析报表，打印输出。

**操作步骤**

点击**成本会计－>成本水平分析　**进入成本水平分析功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件。
*  **第2步：**确定后显示成本分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
