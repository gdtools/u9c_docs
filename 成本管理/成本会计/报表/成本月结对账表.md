
# 功能描述

本节点用于成本计算完成后，分录转总账前的辅助对账。

用户可以通过灵活配置报表的行分组和列分组，从而实现以下两种方式的成本月结核对：

1、按业务线索查询核对，即依据业务类型查询业务金额和科目明细；

2、依据明细科目查询相关业务类型和金额。

# 栏目说明

成本月结对账 - 查询条件

|栏目|说明|
|---|---|
|组织|对账组织参照录入，不可为空。|
|账簿|成本月结对账的目标账薄。参照录入，不可为空。|
|记账期间|进行对账的目标账簿期间|
|会计科目|对账的目标会计科目，对哪些会计科目进行对账|
|自动会计业务类型|对账所依据的自动会计业务类型。可多选。包括生产领料单、生产相关杂收单、生产相关杂收单、协同子单、资源耗用报告、资源时间报告、完工报告、成本调整单、生产费用核算、IPV差异|


成本月结对账-分析结果

|栏目|说明|
|---|---|
|记账期间|显示对账的记账期间；|
|自动会计业务类型|显示对账的自动会计业务类型；|
|单据类型|显示对账的业务单据类型；|
|业务类型|显示对账的单据业务类型；|
|业务金额|显示对账业务单据的业务金额；支持数据钻取，点击后联查转移到“交易分录对账”；|
|科目编码|显示对账的交易分录的科目编码；|
|科目名称|显示对账的交易分录的科目名称；|
|借方原币金额|显示对账的交易分录的借方原币金额；支持数据钻取，点击后联查转移到“交易分录对账”；|
|贷方原币金额|显示对账的交易分录的贷方原币金额；支持数据钻取，点击后联查转移到“交易分录对账”；|
|科目模板|显示AAI转总账使用的会计科目模板；支持数据钻取，点击后联查对应的会计科目模板；|
|分录模板|显示该业务的分录模板；支持数据钻取，点击后联查对应的分录模板；|
