
# 功能描述

分析比较企业各品种在指定的期间段内各期间产品单位成本的构成和分布情况的报表。

# 栏目说明

历史成本比较分析－查询条件

|栏目|说明|
|---|---|
|成本域|成本分析的目标成本域。参照录入，不可为空。|
|成本类型|成本分析的目标成本类型。参照录入，不可为空；参照成本域下的所有成本类型。|
|账薄|成本分析的目标账薄。参照录入，不可为空。|
|从期间|成本分析的目标账薄期间段的开始期间。参照录入，参照账薄下的所有账薄期间。|
|到期间|成本分析的目标账薄期间段的结束期间。参照录入，参照账薄下的所有账薄期间。到期间≥从期间|
|料品分类|成本分析的目标品种的料品分类。|
|料品|成本分析的目标品种。参照录入，不可为空。|

历史成本比较分析－分析结果

|栏目|说明|
|---|---|
|成本域|显示成本分析的成本域。|
|成本类型|显示成本分析的成本类型。|
|账薄|显示成本分析的账薄。|
|从期间|显示成本分析的账薄期间段的起始期间。|
|到期间|显示成本分析的账薄期间段的结束期间。|
|制表人|显示分析报表制表人|
|制表日期|显示分析报表的制表日期|
|料品分类|显示成本分析的目标品种的料品分类。|
|品名|显示成本分析的目标品种名称。|
|料号|显示成本分析的目标品种代码。|
|期间成本|显示成本分析的目标品种在各会计期间的单位成本。|
|历史平均成本|显示成本分析的目标品种在各会计期间的单位成本的平均值。|
|参考成本|显示成本分析的目标品种的参考单位成本。|

|与上期相比|显示成本分析的目标品种最后期间单位成本与上一期间单位成本的比值。＝（最后期间实际单位成本－上一期间单位成本）/上一期间单位成本×100%|
|与参考相比|显示成本分析的目标品种最后期间单位成本与参考单位成本的比值。＝（最后期间实际单位成本－参考单位成本）/参考单位成本×100%|

# 操作说明

## 历史成本比较分析

通过历史成本比较分析，可以进行指定期间段内各品种单位成本的比较分析，并可以生成成本分析报表，打印输出。

**操作步骤**

点击**成本会计－>历史成本比较分析　**进入历史成本比较分析功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件
*  **第2步：**确定后显示历史成本比较分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
