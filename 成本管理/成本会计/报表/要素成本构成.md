
# 功能描述

本功能是对指定成本对象、在指定成本域成本类型和会计期间内各要素成本的发生额占要素类型成本的比例，以及占总成本比例的分析，本功能也可以提供单位成本的比例分析，并提供按要素类型的数据钻取。

# 栏目说明

|栏目|说明|

# 操作说明

## 要素成本构成

通过要素成本构成分析功能，可以进行目标对象的要素成本在要素类型合计成本以及总成本中的比例，并可以生成成本分析报表，打印输出。

**操作步骤**

点击**成本会计－>要素成本构成　**进入要素成本构成分析报表功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件，在此可以选择进行何种成本分析，以及成本分析涉及到的各条件项目。
*  **第2步：**确定后显示成本分析结果报表。用户可以输出或打印结果报表。
*  **第3步**：用户还可以通过点击有链接的“成本要素”项，进行数据钻取，得到该成本要素下的成本明细。

**注意：**

数据钻取时，如果核算对象成本包括期初初始成本，钻取得到的明细成本将不包括初始成本。

# 初始准备

*  进行了分析期间的成本计算。
