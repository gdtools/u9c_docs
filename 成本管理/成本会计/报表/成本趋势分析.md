
# 功能描述

本功能用来对同一成本对象进行成本趋势分析。

成本趋势分析是对成本对象在一段时期内不同会计期间成本发生进行比较，以了解成本升降的趋势。成本趋势分析只针对产品成本对象进行。

# 栏目说明

成本趋势分析－查询条件

|栏目|说明|
|---|---|
|分析类型|成本分析的类型。选择录入。可选择项：“单位成本”“成本额”，默认为“成本额”。|
|比较方式|成本趋势分析的比较方式，包括基比和环比两种方式。选择录入。　说明　:基比：选择一个记账期间作为基准期间，其它期间与基准期间进行比较。环比：连续记账期间的后记账期间与前记账期间进行比较。|
|成本域|成本分析的目标成本域。参照录入，不可为空。|
|成本类型|成本分析的目标成本类型。参照录入，不可为空；参照成本域下的所有成本类型。|
|账薄|成本分析的目标账薄。参照录入，不可为空。|
|记账期间|成本分析的目标账薄期间。参照录入，参照账薄下的所有账薄期间。录入期间段；|
|基准期|趋势分析的比较方式为“基比”时的基准期间。参照录入，参照账薄下的所有账薄期间。|
|品种|成本分析的目标品种。参照录入，不可为空。|
|等级|成本分析的目标品种的等级。选择录入，可以为空。|
|成分|成本分析的目标品种的成分。参照录入，可以为空。|
|成本要素|成本分析的目标成本要素。参照录入，可多选，可以为空。|

# 操作说明

## 成本趋势分析

通过成本趋势分析功能，可以对目标对象在不同期间内的成本进行连续的成本增减分析，并可以生成成本分析报表，打印输出。

**操作步骤**

点击**成本会计－>成本趋势分析　**进入成本趋势分析报表功能界面。具体步骤如下所示。

*  **第1步：**录入查询分析条件，在此可以选择进行何种成本分析，以及成本分析涉及到的各条件项目。
*  **第2步：**确定后显示成本分析结果报表。用户可以输出或打印结果报表。

# 初始准备

*  进行了分析期间的成本计算。
