
# 功能描述

用户可以通过本功能录入或修改维护产品的期间实际产量，包括完工量、入库量、返工量、报废量和在制量。

用户也可以通过本功能从制造自动取得产量数据，并可通过本功能进行在制量的约当计算，生成约当产量，当产量数据来源为制造取数时，不允许手工新增产量数据。

# 栏目说明

**产量数据**

|栏目|说明|

|会计期间|主账薄对应的会计日历的会计期间，为当前产量数据的核算期间参照录入，不可空；|
|成本域|产量入库对应的成本域参照录入，不可空；|
|部门|产出产量的部门。参照录入；|
|生产线|产出产量的生产线。参照录入；|
|工作中心|产出产量的工作中心。参照录入；　注意　:1、部门、生产线、工作中心同为产量的产出实体，同一笔产量对应的产出实体只能有一个，如果对应的实体有多个，按工作中心、生产线、部门的顺序进行确认。2、可以不指定产出实体，如果用户有按产出实体统计产量和成本的要求，必须录入正确的产出实体。|
|产品簇|产量对象。参照录入；当成本核算对象＝产品簇时可录入；只可选择未财务关闭并且实际开始日期在本期间结束日期前的生产订单对应的产品簇 。|
|品种|产量对象。参照录入；当成本核算对象＝品种时可录入；只可选择未财务关闭并且实际开始日期在本期间结束日期前的生产订单对应的品种。|
|生产订单|产量对象。参照录入；当成本核算对象＝生产订单和生产线日计划时可录入；与生产线日计划只能选择一个录入；只可选择未财务关闭并且实际开始日期在本期间结束日期前的生产订单。|
|生产线日计划|产量对象。参照录入；当成本核算对象＝生产订单和生产线日计划时可录入；与生产线日计划只能选择一个录入；只可选择未财务关闭并且实际开始日期在本期间结束日期前的生产线日计划。　注意　:1、产品簇、品种、生产订单、生产线日计划同为产量对象，用户必须录入一个产量对象。2、产量对象与系统参数“成本核算对象”相关：当成本核算对象＝“产品簇”时，产量对象必须是产品簇，当成本核算对象＝“品种”时，产量对象必须是品种，当成本核算对象＝“生产订单和生产线日计划”时，产量对象必须是生产订单或生产线日计划。3、必须指定一个产量对象。|
|类型|产出的类型，包括主产品、联产品和副产品。手工选择，默认为主产品；|
|料品|产量对象对应的料品。系统根据产量对象自动维护，不可修改；|
|主产品|当产出为联副产品时，对应的主产品|
|工艺路线|产出产量的工艺路线。参照选择；当“在制造约当系数制定方式＝按品种”时可以不录入，当“在制造约当系数制定方式＝按工序”时必须录入。|
|工序号|产出产量的工序。参照选择或手工录入；当“在制造约当系数制定方式＝按品种”时可以不录入，当“在制造约当系数制定方式＝按工序”时必须录入。工序号根据工艺路线的选择而录入。|
|是否不入库|本产出是否入库，对工艺订单或不入库的虚拟订单，产出直接作为母单的投入，不作入库处理。|
|计算顺序|用以区别是标准订单还是返修订单（核算对象为订单时）或者正常下发的物料还是返修的物料（核算对象为品种时）等于1时为标准订单或正常下发的物料等于2时为返修订单或返修的物料系统自动判断填写，不可修改|
|母件订单|生产订单的母件订单，对工艺订单或不入库的虚拟订单，需要指定对应的母单。|
|母件料品|生产订单母件订单的生产料品。|
|母子单关系类型|核算对象为订单时，母单与子单的关系类型。|
|成本单位|产量的成本计量单位。系统自动填写为料品的成本计量单位，不可修改；|

|本期投入数量|核算对象按成本单位的本期投入数量。产量数据来源＝手工时，手工录入，≥0。产量数据来源＝制造时：不可编辑。|
|投入数量|核算对象按成本单位的投入数量。产量数据来源＝手工时，手工录入，≥0。产量数据来源＝制造时：不可编辑。|
|完工数量|成本计量单位的完工数量。产量数据来源＝手工时，手工录入，≥0，（入库数量＋返工数量＋报废数量）≤完工数量；产量数据来源＝制造时：不可编辑|
|入库数量|成本计量单位的产品入库数量。产量数据来源＝手工时，手工录入，≥0，（入库数量＋返工数量＋报废数量）≤完工数量；产量数据来源＝制造时：不可编辑，入库数量＝∑子表入库数量|
|返工数量|成本计量单位的返工数量。手工录入；≥0|
|报废数量|成本计量单位的报废数量。产量数据来源＝手工时：手工录入，≥0，（入库数量＋返工数量＋报废数量）≤完工数量；产量数据来源＝制造时：不可编辑。　注意　:入库数量＋返工数量＋报废数量不能大于投入数量|
|在制数量|成本计量单位的在制品数量。手工录入；≥0|
|约当数量|按综合约当系数计算的在制品约当数量。由“约当计算”得到，不可修改；|
|材料约当数量|按分项约当系数计算的在制品材料约当数量。由“约当计算”得到，不可修改；当“在制品分配方法＝分项约当系数”时有值。|
|人工约当数量|按分项约当系数计算的在制品人工约当数量。由“约当计算”得到，不可修改；当“在制品分配方法＝分项约当系数”时有值。|

# 操作说明

## 接口取数

接口取数操作提供用户从制造自动取得期间生产**产量数据**。

**操作前提**

*  系统参数“**产量数据**来源”设置为“制造”
*  已启用生产订单系统和车间管理系统，并有产品完工、入库。

**操作步骤**

点击成**本会计－>产量数据－>接口取数**操作，弹出取数日期选择，确定后系统自动取数。具体步骤如下所示。

*  **第1步：**点击**接口取数**操作，系统弹出取数日期录入窗口。
*  **第2步：**录入取数日期，取数日期应在核算期间的起止日期范围之内。
*  **第3步：点**击“**确定**”，系统根据取数日期所在期间进行自动取数，并将**产量数据**存入产量表。
*  **第4步**：点击“**取消**”，系统关闭取数日期录入窗口，返回**产量数据**主界面。用户可以在此查询已取得的产量数据，并可进行调整修改。

## 约当计算

通过约当计算，可以得到本期间**产量数据**中在制数量的约当产量。

**操作前提**

*  已经定义【约当系数】。

**操作步骤**

点击成**本会计－>产量数据－>约当计算**按钮，弹出计算日期选择窗口，确定后系统进行约当计算。具体步骤如下所示。

*  **第1步：**点击**约当计算**操作按钮，系统弹出计算日期录入窗口。
*  **第2步：**录入计算日期，计算日期应在核算期间的起止日期范围之内。
*  **第3步：点**击“**确定**”，系统根据计算日期所在期间计算该期间的**产量数据**中在制数量的约当产量。并将计算得到的约当产量存入产量表。
*  **第4步**：点击“**取消**”，系统关闭计算日期录入窗口，返回**产量数据**主界面。用户可以在此查询已计算得到的约当产量数据。
