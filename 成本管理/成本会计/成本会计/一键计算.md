
# 功能描述

本功能依据一键计算方案定义的操作节点和系统默认的操作顺序，自动完成成本会计系统月末的一系列月末操作。

# 业务规则

*  目前版本对入库成本的调整：用户在成本会计系统进行了**入库成本调整**后，需要在存货维度中手工维护存货维度信息；
*  价差、量差在启用责任成本价量差核算后可用；

# 栏目说明

一键计算

|栏目|说明|
|---|---|
|计算日期|一键计算的日期，决定在哪个期间核算。手工录入，不可为空；　注意　:对已经结账的会计期间不能进行一键计算。|

# 操作说明

## 一键计算

依据已定义的一键计算方案，按系统默认顺序进行期末处理。

**操作步骤**

点击一**键计算**操作，系统依次各相关操作节点的计算。

## 一键计算调度

允许用户按规则设定成本计算的执行时间，由应用服务按时间计划执行一键计算操作。

**操作步骤**

点击**调度**按钮，弹出时间计划排定页面。具体步骤如下所示。

*  **第1步：**根据需要，选择【执行一次】或【重复执行】
*  **第2步：**若选择【执行一次】，选择录入执行日期／时间。
*  **第3步：**若选择【重复执行】，则选择预设的调度方案进行调度安排。
*  **第4步：**点击【确定】，完成调度计划设定。

## 错误信息查询

系统在进行一键计算的同时，会对各业务节点涉及到业务数据进行错误或不合法检查，在一键计算完成后，如果存在错误，系统会抛出错误信息列表，将检查到的全部错误信息显示出来，供用户查错。

**操作步骤**

当用户一键计算完成后，如果计算不成功，可以点击**成本会计**－>**一键计算**->错误信息查询按钮，查询出错信息。

## 一键计算按错误重新执行

在一键计算完成后，如果存在错误，用户应进行相关业务数据调整或修改，在调整完成后，可以在此进行重新执行。

**操作步骤**

点击**成本会计－>一键计算－>一键计算按错误重新执行**按钮。
