
# 功能描述

对于生产周期较长的企业，支持用户将在某个时点的在制信息和在制成本信息录入系统，以便将期初订单成本状况纳入系统管理或调整订单的期初成本。 对于期初订单要求在上线时对车间在制的现状做清点，并将此类信息反映到新系统中，使新旧系统更好的衔接。

# 业务规则

系统支持正常生产订单在任何期间初始化该期间期初成本。

# 栏目说明

期初订单成本开账

|栏目|说明|
|---|---|
|成本域|确定订单所在的成本域，非空|
|成本类型|确定要维护哪种计价方式的成本，非空|
|账簿|确定成本所在的账簿，非空|
|记账期间|确定该数据所在的期间，非空|
|生产订单|选择指定成本域范围内的生产订单|
|订单工序|从生产订单工序中选择要维护成本的工序|
|料品|生产订单对应的料品，不可改|
|成本要素|选定明细成本要素|
|本层期初成本|录入订单期间的本层期初成本|
|下层期初成本|录入订单期间的下层期初成本|
|本层期初成本价差|录入订单期间的本层期初成本价差，仅启用计划价责任成本可用|
|下层期初成本价差|录入订单期间的下层期初成本价差，仅启用计划价责任成本可用|
|本层期初成本量差|录入订单期间的本层期初成本量差，仅启用计划价责任成本可用|
|下层期初成本量差|录入订单期间的下层期初成本量差，仅启用计划价责任成本可用|
|总期初成本|本层期初成本＋下层期初成本+本层期初成本价差+下层期初成本价差+本层期初成本量差+下层期初成本量差|

# 初始准备

*  维护了【期初生产订单】生产订单带“期初”标志；
*  必须提前定义【成本域】和【成本类型】【账簿】等；
