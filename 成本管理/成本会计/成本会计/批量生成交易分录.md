
# 功能描述

本节点用于各类型业务单据集中、批量生成交易分录。

# 关键应用

在填制各类业务单据时，为了提高单据保存处理效率，在单据保存时，先不生成交易分录。每天定期将各业务单据的交易分录集中、批量生成。

可以设置系统自动调度程序，定期由系统自动生成交易分录。用户只需在此查询生成结果。

可以用于查看所有未生成交易分录的业务单据。

设置查询条件，手工选择单据生成交易分录。

设置调度方案，定期系统自动生成交易分录。

提供交易分录生成结果报告。 如果生成过程有误，提供错误信息报告。

# 操作说明

## 查询

用户输入需要生成交易分录的业务单据的查询条件。 具体操作参见【查询方案】说明。

## 生成交易分录

根据列表画面上所选择的单据生成交易分录。

并显示分录生成结果信息：本次处理的单据总数，成功处理单据张数，处理失败的单据张数以及处理失败的单据列表。

对于处理失败的单据，用户可以查找原因，重新生成交易分录。

**操作前提**

*  已经在列表中选择本次要生成分录的业务单据。可以选择一张，也可以选择多张。

**操作步骤**

点击**程序－>批量生成交易分录－>查询**按钮，进入【查询条件】画面。具体步骤如下所示：

*  **第1步：**输入生成易分发录的单据查询条件
*  **第2步：**在‘栏目’页签选择单据列表中需要显示项
*  **第3步：**选择完成后，点击‘**确定**’按钮，返回查询结果画面
*  **第4步**：在查询结果列表中选择需生成交易分录的单据记录，点击‘**生成交易分录**’按钮，系统自动生成相应的交易分录。

## 批量生成分录

用于根据查询方案，自动将符条件的未生成分录的单据，批量生成交易分录。

**操作前提**

*  已定义批量生成交易分录查询条件的方案

**操作步骤**

*  **第1步：**在查询结果单据列表界面中，点击‘批量生成分录’按钮，弹出界面中选择查询方案；
*  **第2步：**如果点击‘调度生成分录’，则弹出‘调度选择’界面；在‘调度选择’界面中选择调度方案，‘**确定**’后，系统根据定义的调度方案按查询方案自动生成交易分录。
*  **第2步：**如果点击‘生成分录’，系统按查询方案自动生成交易分录。

## 查询错误报告

由于在调度生成交易分录时，批量生成分录如果发生错误，不能及时告知用户。用户可以使用本功能查询执行结果，查看失败原因。

# 初始准备

*  参数设置中已选择生成交易分录；
*  成本计算已完成；
*  业务单据必须为未生成交易分录，本功能不处理已生成交易分录的业务单据。
