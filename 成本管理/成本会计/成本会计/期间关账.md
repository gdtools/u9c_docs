
# 功能描述

期间关账主要用于控制特定期间内是否可以进行生产相关的业务操作。

一般是在成本会计收集成本核算数据之前执行。执行期间关账后，关账期间将不可进行生产相关的业务操作，保证成本核算时采集的业务数据的准确性。

# 栏目说明

期间关账

|栏目|说明|
|---|---|
|会计年度|需要进行关账操作的会计年度。默认为当前系统日期对应的会计期间的会计年度。可以根据录入的会计年度刷新会计期间。|
|会计期间|需要进行关账操作的会计期间。需要选择会计期间进行关账。|
|已关账|关账执行成功后回写已关账标识。未关账时为空白。关账成功后打标记。|
|关账日期|执行关账操作的日期。|
|关账人|执行关账操作的业务员。|
|系统关闭|未执行手工关账，成本月结时自动关账。手工关账时为空。月结关账时打标记。|

# 操作说明

## 期间关账-关账

期间关账成功后，已关账期间不能进行生产相关业务操作。

生产相关受控业务范围包含：订单（期初订单、大生产订单、普通生产订单）审核/弃审；订单（期初订单、大生产订单、普通生产订单）开工/反开工；工序转移审核/弃审；派工单审核/弃审；派工单完工申报单审核/弃审；完工报告审核/弃审；完工报告入库/取消入库；完工申报单审核/弃审；成品入库单审核/弃审；完工红冲单审核/弃审；成品出库单审核/弃审；在制品入库单审核/弃审；资源报告审核/弃审；时间报告审核/弃审；工时维护保存/增删改；生产订单撤线审核/弃审；生产订单复线审核/弃审；质检单审核/弃审；领料单；资源报告；时间报告；工时维护。

**操作前提**

*  确定关账期间不再有业务发生。

**操作步骤**

点击成**本会计－>期间关账－>关账**按钮。具体步骤如下所示。

*  **第1步：录入会计年度。**
*  **第2步：选择会计期间。**
*  **第3步：单击关账按钮。**
*  **第4步：确认关账是否成功。**

## 期间关账-取消关账

取消关账后，取消关账的期间可以继续补录业务单据。

受控业务范围包含：订单（期初订单、大生产订单、普通生产订单）审核/弃审；订单（期初订单、大生产订单、普通生产订单）开工/反开工；工序转移审核/弃审；派工单审核/弃审；派工单完工申报单审核/弃审；完工报告审核/弃审；完工报告入库/取消入库；完工申报单审核/弃审；成品入库单审核/弃审；完工红冲单审核/弃审；成品出库单审核/弃审；在制品入库单审核/弃审；资源报告审核/弃审；时间报告审核/弃审；工时维护保存/增删改；生产订单撤线审核/弃审；生产订单复线审核/弃审；质检单审核/弃审；领料单；资源报告；时间报告；工时维护。

**操作前提**

*  需要取消关账期间未月结。

**操作步骤**

点击成**本会计－>期间关账－>关账**按钮。具体步骤如下所示。

*  **第1步：录入会计年度。**
*  **第2步：选择会计期间。**
*  **第3步：单击取消关账按钮。**
*  **第4步：确认取消关账是否成功。**

# 初始准备

*  启用成本会计模块。
*  已经完成操作期间的业务数据。
