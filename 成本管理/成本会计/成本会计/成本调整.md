
# 功能描述

本功能完成成本计算后，对成本计算结果的调整，并可以自动生成交易分录。

# 业务规则

*  目前版本对入库成本的调整：用户在成本会计系统进行了**入库成本调整**后，需要在存货维度中手工维护存货维度信息；
*  价差、量差在启用责任成本价量差核算后可用；

# 操作说明

## 订单（品种）成本查询

通过订单（品种）成本查询，查找并指定要进行**成本调整**的订单或品种。

**操作步骤**

点击**成本调整-->订单（品种）成本查询**按钮，弹出订单（品种）成本查询页面，用户双击选择要调整成本的订单或品种，返回到**成本调整**主界面进行成本调整。

## 交易分录查询

查询**成本调整**后生成的交易分录。

**操作前提**

*  **成本调整**账薄期间未结账

**操作步骤**

点击**成本会计－>成本调整－>交易分录查询**按钮，弹出交易分录查询界面，进行交易分录查询。

## 批量弃审

如果**成本调整**单较多，使用此功能可以一次批量弃审多张**成本调整**单。（成本计算只删除系统自动产生的成本调整单，对于用户手工新增或者调整过的**成本调整**单，需要批量弃审）

**操作前提**

*  单据所在期间未月结

**操作步骤**

点击**成本调整**列表，在列表状态下，可以一次选择多个**成本调整**单，然后点击“弃审”按钮，对已经选择的成本调整单进行批量弃审。

# 初始准备

*  参数设定，与**成本调整**相关参数

|参数编码|参数名称|说明|
|---|---|---|
|CA-099|实时产生交易分录|成本调整之后是否实时生成交易分录：是：成本调整之后生成交易分录；否：成本调整之后不生成交易分录；|
|CA-098|自动生成成本调整单|成本计算完成时是否自动生成成本调整单是：成本计算后自动生成成本调整单；否：成本调整之后不生成交易分录；　注意　:订单范围：本期间关闭或取消的订单订单成本：有在制作成本|
|CA-120|有入库量的完工订单在制成本是否生成成本调整单|成本计算时，有入库数量的订单结存成本处理方式：是：在制成本在成本计算后保留为结存成本；否：在制成本随入库的完工报告入存货；　注意　:订单范围：本期间关闭或取消的订单|
|成本选项|品种法下成本调整是否考虑后续业务|品种法下成本调整是否考虑后续业务是：后续有该品种订单在产，不生成成本调整单；否：后续有该品种订单在产，生成本期调整单；|

*  已经进行【成本计算】；
*  如果需要生成交易分录，要求已经定义了【会计科目模板】和【分录模板】。
