
# 功能描述

多组织应用环境下，库存规划的净需求会传递到相关组织的库存规划接口表，由相关组织继续规划计算，直至确定最终的补货组织和补货形式。

此功能可以用于：

*  上级组织查看下级组织传递上来的需求；
*  下级组织查看自己的需求转给哪些组织处理。

# 栏目说明

库存规划接口

|栏目名称|说明|
|---|---|
|供应组织|接收需求的组织|
|料号|需补货的料品编码|
|品名|需补货的料品名称|
|单位|需补货的料品的库存主单位|
|需求数量|需补货数量|
|需求日期|应补货日期|
|需求组织|提出需求的组织|
|需求存储地点|提出需求的存储地点|
|已补总量|调出单销抵需求的合计数量|

# 初始准备

*  设置料品档计划方法为空
*  设置料品档规划方法为“最高最低点法”、“再订货点法”或“盘点补货法”
*  设置料品档规划时机；
*  根据需要设置料品的：库存上限、库存下限、安全库存、再订货量。
*  设置组织间业务关系。
