
# 功能描述

库存日关账是库存严格管理的一种手段，适用于对库存信息及时性要求高的企业。 当日发生的出入库业务必须当日记账，每日营业结束时需清查库存，保证账实相符。

日关账的范围可是可选择的，可对企业全部或部分存储地点进行日关账。

已关账日的出入库单据不得再做增删改操作。

月结时系统会自动日关账至当前会计期间末。

# 栏目说明

存储地点日关账列表

|栏目名称|说明|
|---|---|
|存储地点|列示当前组织下所有存储地点，系统维护|
|最近关账日|带入当前存储地点最新的关账日期，系统维护|
|关账人|关账人，系统维护|
|处理日期|默认取最近关账日＋1，首次使用时为启用前一日可修改，系统按此日期进行关账、取消关账操作输入此日期，点关账，则表示关账至该日（含）；点取消关账，则表示取消关账至该日（含）|

# 操作说明

## 关账

选择存储地点，输入处理日期，执行此操作，系统进行日关账处理。

若选定存储地点在处理日期内有未审核的出入库单据，择会给出提示，必须先审核这些单据才能执行日关账。

## 取消关账

选择存储地点，输入处理日期，执行此操作，系统进行取消日关账处理。
