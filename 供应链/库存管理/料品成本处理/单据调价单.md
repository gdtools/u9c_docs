
# 功能描述

主要用于调整单据的收或发的单价。发主要是指指定发单价的发业务。收主要是指非联动的收业务。收业务不包含采购收货。

# 栏目说明

单据调价单－单头

|栏目名称|说明|
|---|---|
|单据类型|参照单据调价单的单据类型档案|
|单号|手工编号或系统编号|
|单据日期|业务发生的日期。|
|调整为按照计价方式计算|将指定发单价改为按照计价方式计算整单调整时勾选|

单据调价单－单行

|栏目名称|说明|
|---|---|
|行号||
|单据号|需要调整单价的单据的编号|
|单据行号|需要调整单价的单据的行号|
|料号|需要调整单价的单据的料号|
|数量|需要调整单价的单据行的成本单位数量|
|原始单价|需要调整单价的单据行的原始单价|
|原始金额|需要调整单价的单据行的原始金额|
|调价后单价|需要调整单价的单据行的调整后单价|
|调价后金额|需要调整单价的单据行的调整后金额|
|零成本|需要调整单价的单据行如果调整后单价为零时勾选|
|调整为按计价方式计算|将单据行指定的价格改为按照计价方式计算|

# 操作说明

## 单据调价单-获取数据

从数据表中取得需要调整单价的单据的单据行。

**操作前提**

*  单据已经审核；

**操作步骤**

点击库**存管理－>单据调价单－>获**取数据按钮。具体步骤如下所示。

*  **第1步：进**入库存管理模块单据调价单节点；
*  **第2步：录入单据类型、单据编号等单据头信息；**
*  **第3步：**点获取数据按钮，录入查询条件，确认后返回查询结果。查看返回的结果。

## 单据调价单-取价

查询出需要调整单价的单据后执行取价功能，进行系统取价，或手工录入价格，当价格为零时勾选零成本标记。

**操作前提**

*  已经执行了获取数据；

**操作步骤**

点击库**存管理－>单据调价单－>取**价按钮。具体步骤如下所示。

*  **第1步：进**入库存管理模块单据调价单节点；
*  **第2步：录入单据类型、单据编号等单据头信息；**
*  **第3步：**点获取数据按钮，录入查询条件，确认后返回查询结果。查看返回的结果。
*  **第4步：执**行取价功能按钮，录入取价方案，确定后查看取价结果。

# 初始准备
