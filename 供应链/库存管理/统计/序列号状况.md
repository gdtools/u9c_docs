
# 功能描述

提供序列号使用状况的一览表。可查：

1、 库存序列号。

2、被占用的库存序列号，即序列号虽然在库存中，但是已被出库单据录入，不能再被其他出库单据开出。

3、 序列号的使用状况。

4、 序列号档中尚未被使用的序列号

# 业务规则

## 使用前提

*  料品启用序列号。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|序列号状态|按序列号状态查询|
|组织|查询所选组织数据|
|料号|查询所选料号数据|
|品名|查询所选品名数据|
|序列号|查询所选序列号数据|
|货主组织|查询所选货主组织数据|
|存储地点|查询所选存储地点数据|
|库位|查询所选库位数据|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
