
# 功能描述

按生产订单维度或品种维度分析在指定会计期间内发生的直接费用、分配的间接费用以及转出成本，并能够追溯到每一笔费用的具体来源和去向。

# 业务规则

## 使用前提

*  成本计算已完成。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|分析类型|如果核算对象为订单，则查询条件可以选择订单，品种是有订单带出来的，不能选择品种否则可以选择品种，不能选择订单|
|账簿|按当前组织过滤账簿信息，默认为主账簿|
|成本域|按当前组织过滤，不可空默认为包含主账薄的成本域，如果有多个，取第一个成本域。|
|成本类型|按当前成本域过滤默认为当前成本域记账成本类型|
|记账期间|按当前账薄过滤，默认为当前期间|
|生产订单|如果核算对象为订单或日计划，则查询条件可以选择订单,否则不能选择，同生产线日计划互斥|
|生产线日计划|如果核算对象为订单或日计划，则查询条件可以选择日计划,否则不能选择同生产订单互斥|
|料号|成本核算对象为订单，非空，不能选择成本核算对象为品种时，可以选择，可空|
|品名|手工录入，字串，可空，支持模糊查询|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
