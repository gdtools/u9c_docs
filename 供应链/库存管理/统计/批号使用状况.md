
# 功能描述

提供批号在系统中的使用情况一览表，列示批号被使用的日期、单据、组织、存储地点、数量等信息。

# 业务规则

## 使用前提

*  业务单据上录入了料品批号。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|使用组织|查询所选组织|
|料号|查询所选料号|
|品名|查询所选品名|
|批号|查询所选批号|
|使用日期|按使用日期查询|
|存储地点|查询所选存储地点|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
