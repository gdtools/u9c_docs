
# 功能描述

通过分析一定时段内料品的平均库存和周转数额，得出料品的周转次数、周转天数、周转率等周转指标。

可以分别对数量，金额进行分析；可以进行料品周转指标的排名和比较。

# 业务规则

## 使用前提

*  料品有出入库业务发生。
*  对一定时段进行周转数量分析时，要求该时段必须先做库存日关账。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织|查询所选组织|
|分析类型|可根据周转分析、周转排名、周转比较类型查询|
|期间类型|可根据会计期间、统计期间类型查询|
|期间范围|可以指定期间范围查询|
|期间规则|可以指定期间规则查询|
|期间|可以指定期间查询|
|前排名|分析类型为周转排名时可选|
|排名顺序|分析类型为周转排名时可选|
|比较方式|分析类型为周转比较时可选|
|基数|比较方式为基期逐期比较时可选|
|历史年度|分析类型为周转比较时可选|
|分析依据|可根据数量分析、金额分析依据查询|
