
# 功能描述

查询指定期间的期初在途、本期调出、本期调入、期末在途。查询调拨单范围为组织内调拨、非关系企业组织间调拨的在途成本。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|调出组织|为空表示所有调出组织；与登陆组织的关系为同一法人下的所有组织，默认登陆组织|
|调入组织|为空表示所有调入组织。与登陆组织的关系为同一法人下的所有组织，默认空|
|账簿|必选项，默认 = 法人组织主账簿，根据录入组织过滤法人组织账簿|
|会计期间|选择会计期间查询|
|调出货主组织|选择调出货主组织查询，可空。默认=空，空表示所有。与登陆组织为同一法人|
|调入货主组织|选择调入货主组织查询，可空。默认=空，空表示所有。与登陆组织为同一法人|
|调出存储地点|选择调出组织的存储地点查询，为空表示所有。|
|调入存储地点|选择调入组织的存储地点查询，为空表示所有。|
|料号|选择料号查询；|
|品名|选择品名查询；|
|项目|选择项目查询；|
|批号|选择批号查询；|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
