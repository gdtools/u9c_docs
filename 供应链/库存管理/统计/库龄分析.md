
# 功能描述

以库存现存量表为对象，按库龄区间分析其数量在库存中的未发生业务的时间长短状况，提供下面几种分析方法：

1、最近一次异动日期——以最近一次出入库日期（用户可选考虑哪些出入库活动）为基准分析库龄。

2、批号入库日期——以此料品的批号入库日期分析料品的各批号数量的库龄，一般用于料品每次完工入库都会产生一个新批号的情况。

3、入库日期（先进先出规则）——按先进先出规则出库消耗入库，剩余未被耗用的入库按其入库日期为基准分析库龄。

# 业务规则

## 使用前提

*  有料品库存。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|分析依据|根据不同分析依据统计数据|
|查询历史|是否查询历史数据|
|期间类型|可根据会计期间、统计期间、日期类型查询|
|会计期间|可以指定会计期间查询|
|账龄区间|可以指定账龄区间查询|
|组织|查询所选组织|
