
# 功能描述

本功能用于查询各会计期间的存货的明细账。只能查询末级存货的某段时间的收发存信息；明细账（金额）是按末级存货设置的,用来反映存货的某段时间的收发存的数量和金额的变化。并可用于查询按计划价核算的已记账存货本会计年度各月份的差异/差价账。

**统计说明**

**统计数据**

*  库存收、发单据的数量、成本信息

**统计条件**

系统在查询方案中（查询方案）提供默认的统计条件，

*  不同的统计方式对应不同的统计条件。
*  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

**统计结果**

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 栏目说明

|栏目名称|说明|
|---|---|
|期间类型|可根据期间类型查询|
|日期范围|可以指定日期范围查询|
|日期期间|可以指定日期期间查询|
|组织|查询所选组织的库存数据|
|货主组织|查询所选货主组织的库存数据|
|存储地点|查询所选存储地点的库存数据|
|料号|查询所选料号的库存数据|
|品名|查询所选品名的库存数据|
|料品规格|查询所选料品规格的库存数据|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
