
# 功能描述

列示库存中已临近、到期或过期的预留记录。

# 业务规则

## 使用前提

*  库存中有预留记录，且其预留时间已临近、到达或超过料品档定义的预留天数。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|异常类型|根据临近、到期、过期三种异常类型查询|
|临近天数|异常类型=临近时，输入临近天数查询|
|过期天数|异常类型=过期时，输入过期天数查询|
|物流组织|根据物流组织查询|
|存储地点|根据存储地点查询|
|料号|根据料号查询|
|品名|根据品名查询|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
