
# 功能描述

列示ATP料的可承诺量和供应、需求状况。

# 业务规则

## 使用前提

*  设定ATP检查的料品。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|查询对象|可承诺量：查询指定料品的可承诺量；需求明细：查询指定料品的需求明细；供应明细：查询指定料品的供应明细；|
|ATP规则|指定ATP规则查询；|
|组织|根据组织查询|
|货主|根据货主查询|
|存储地点|根据存储地点查询|
|项目|根据项目查询|
|番号|根据番号查询|
|需求分类|根据需求分类查询|
|料号|根据料号查询|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
