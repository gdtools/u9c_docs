
# 功能描述

提供的库存数量收发存汇总账（期初结存、入库、出库、期末结存）。 可按不同粒度（分组项目）汇总统计。

**统计说明**

**统计数据**

*  库存期初数量、收数量、发数量、结存数量等。

**统计条件**

系统在查询方案中（查询方案）提供默认的统计条件，

*  不同的统计方式对应不同的统计条件。
*  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

**统计结果**

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

收数量，可钻取查看对应的“入库流水（数量）”。

发数量，可钻取查看对应的“出库流水（数量）”。

结存数量，可钻取查看对应的“明细帐（数量）”。

# 栏目说明

条件

|栏目名称|说明|
|---|---|
|期间类型|可根据期间类型查询|
|日期范围|可以指定日期范围查询|
|日期期间|可以指定日期期间查询|
|组织|查询所选组织的库存|
|存储地点|查询所选存储地点的库存|
|料号|查询所选料号的库存|
|品名|查询所选品名的库存|
|规格|查询所选规格的库存|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。

# 初始准备

*  库存系统已启用
*  统计数据已更新
*  定义统计期间
