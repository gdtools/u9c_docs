
# 功能描述

可查询内部交易产生虚拟调入单和结算清单。

# 业务规则

## 使用前提

*  内部交易业务已产生虚拟调入单或已产生结算清单。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|单据来源组织|根据单据来源组织查询|
|内部交易类型|根据内部交易类型查询|
|查询对象|查询对象=内部交易时根据虚拟产生的调入单查询；查询对象=内部交易结算清单根据结算清单查询|
|应收组织|根据应收组织查询|
|应付组织|根据应付组织查询|
|使用组织|根据使用组织查询|
|供应方存储地点|根据供应方存储地点查询|
|使用方存储地点|根据使用方存储地点查询|
|料号|根据料号查询|
|品名|根据品名查询|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。
