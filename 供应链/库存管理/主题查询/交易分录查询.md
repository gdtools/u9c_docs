
# 功能描述

本功能节点主要是提供对库存管理系统中生成的所有交易分录进行列表查询，可用于期末对账。

交易分录包括所有库存单据产生的交易分录，以及销售、采购的库存收发单据更新异动明细后，由异动明细产生的交易分录，包含转总帐的和不转总帐的所有分录。

|业务日期|业务单据发生日期|
|记账期间|进行交易分录查询的目标账簿期间|
|单据号|交易分录业务对应的业务单据号|
|借方原币金额||
|贷方原币金额||
|借方本币金额||
|贷方本币金额||
|会计科目|交易分录所进入的会计科目|
|科目编码|会计科目的编码|

# 操作说明

## 查询方案:

用户可以输入查找条件，并保存为方案。对账时可录入会计科目，查询此会计科目的相关交易分录。

## 单据链接：

点击单据号可链接至相应的单据画面，用户可查看产生此交易分录的业务单据的详细信息。
