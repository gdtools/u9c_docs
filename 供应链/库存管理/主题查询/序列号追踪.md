
# 功能描述

提供序列号装配和适用状况的一览表。可查：母件的序列号由哪些子件序列号装配而成。以及这些序列号的使用状况。

# 栏目说明

序列号追踪– 序列号追踪关系

|栏目名称|说明|
|---|---|
|序列号|序列号|
|料号|显示序列号编码规则中设置的该编码原则的料号|
|品名|带出料号对应的品名|
|料品规格|带出料号对应的料品规格|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

## 调整列宽

点击列表下的**[调整列宽]**按钮，可以调整列表栏目显示及打印的宽度。

# 初始准备

*  料品启用序列号。
