
# 参数概述

用于设置库存管理系统存货成本核算及月末处理运行的细节选项，成本选项的设置决定系统的运行细节。

# 功能描述

存货参数对存货成本处理及月末处理进行了定义。

## []()参数清单

路径：供应链>库存管理>基础设置>存货选项

|**序号**|**参数名称**|**参数值**|**默认值**|**参数说明**|
|---|---|---|---|---|
|月末单据重新取价|
|1|取价时机|手工执行；库存成本计算；成本会计费用接口取数|手工执行|手工执行：通过执行库存成本计算[单据月末取价]功能按钮，驱动重取单据单价，适用于成本计算前需要分析取价结果是否合理和存货需要按成本域计算的企业；库存成本计算：通过执行库存成本计算驱动单据重新取价，不区分已选择成本计算范围，全部单据取价，适用于不需要按成本域计算成本的企业；库存费用取数：通过执行库存费用取数功能驱动单据取价，适用于启用成本会计，且不需要分步核算的企业；|
|2|取价方案|取价方案实体参照|空|月末单据按指定取价方案进行取价；|
|3|单据范围|杂收；杂发；调出；形态转换（是、否）|否|月末单据取价范围|
|4|业务控制范围|手工录入零成本重新取价；手工录入非零成本重新取价；存货取价业务重新取价；单据实时取价业务重新取价；（是、否）|否|重新取价业务控制范围|
|成本处理|
|1|取价方案|取价方案实体|库存管理->基础设置->参数设置->取价方案|存货成本对零成本、负成本处理时按取价方案取价时采用此取价方案|
|2|零成本处理|上期结存；零成本；取价方案|零成本|存货成本对零成本处理时指定的处理方案|
|3|负成本处理|负成本；取价方案|负成本；|存货成本对负成本处理时指定的处理方案|
|转总账|
|1|是否汇总生成交易分录|是；否|否|在汇总生成交易分录模式下，月末批量生成交易分录时明细单据的交易分录不能转总账；且该模式下相关自动会计类型影响因素不支持扩展字段。|
|2|分项选择|出货单；调拨单；仓库转出抵消；成本分期档；（是、否）|否|汇总生成交易分录的单据范围|
|异常金额调整方案|
|1|自动生成异常金额成本调整单|是、否|否|数量为零金额不为零的异常金额的处理方式|
|2|异常金额查询维度|按存货核算维度；按存储地点（货主组织）+存货核算维度|按存货核算维度|判断为异常金额的查询维度|
|3|仓库间成本转移|是、否|否|对于按异常金额查询维度选择“按存储地点（货主组织）+存货核算维度“时，是否仓库的异常金额在此维度下其他仓库间做转移处理|
|会计期间统计维度配置|
|1|会计期间按配置统计更新|是、否|是|1.此配置,影响会计期间统计更新数据;2.统计维度越多,数据量越大,性能越差;3.保存后自动重新生成统计值(请求名称为"会计期间统计维度变更");4.请求未完成时不要做会计期间统计更新.|
|2|维度|维度、是否统计|空|维度值由[否]变更为[是]时,已统计的会计期间统计数据不会自动升级.如:项目维度由[否]变更为[是],已统计的会计期间统计数据,项目为空.|
