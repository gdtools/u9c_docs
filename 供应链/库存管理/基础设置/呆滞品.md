
# 功能描述

系统会按存储地点、货主组织、料号、品名、库存单位为维度列出现有的库存记录，用户可将此记录表示的库存记录手工置为呆滞品，表示此料品已积压了一定时间。

# 栏目说明

呆滞品

|栏目|说明|
|---|---|
|呆滞品|用户手工维护，标识此库存记录是否为呆滞品。|
|置呆日期|若用户表示一条库存记录为呆滞品，则可以录入置呆日期；否则不可维护。|
|存储地点|当前库存记录的存储地点。|
|货主组织|当前库存记录的货主组织。|
|料号|当前库存记录的料号。|
|品名|当前库存记录的品名。|
|库存单位|当前库存记录的库存单位。|
|数量|当前库存记录的库存单位数量。|

# 操作说明

## 指定范围

可以定制查询条件，查出用户所需的库存记录。查询条件可以选择“库存现存量表”中的属性。
