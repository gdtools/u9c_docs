
# 功能描述

规定可用量计算的一组参数,这些参数定义了可用量的需求、供给、时间范围、计算规则等。

可用量计算时会按照本功能设置的“可用量规则”进行处理。

可参见库存应用专题可用量。

# 栏目说明

可用量规则

|栏目|说明|
|---|---|
|编码|用户可录入“可用量规则”的档案编码。|
|名称|用户可录入“可用量规则”的档案名称。|
|可用量不足|设定接单时可用量检查不过时的处理方式：拒绝活动执行、仅警告。|
|允许负库存时检查|料品或存储地点的参数允许负库存=True时，是否需要检查可用量。该参数为True时同样执行检查；否则不检查。默认=True。|
|检查范围：||
|供需计算范围|“不考虑未来需求”，表示开单进行可用量检查时，此单据出库日期之后的需求和供应不会被纳入可用量计算。“考虑未来需求”，表示开单进行可用量检查时，此单据出库日期之后的需求会被纳入可用量计算，而这些需求之前的供应也会被纳入可用量计算。|
|未来供需天数|指可用量检查时所考虑未来供应、需求截止时点，可以录入大于等于0的数。|
|检查对象：||
|销售出货检查|设定销售出货单是否启用可用量检查。|
|生产领料检查|设定生产领料单是否启用可用量检查。|
|调拨待出检查|设定调拨待出是否启用可用量检查。|
|杂发检查|设定杂发是否启用可用量检查。|
|采购退货检查|设定采购退货是否启用可用量检查。|
|完工回退检查|设定完工回退检查是否启用可用量检查。|
|借出检查|设定借出是否启用可用量检查。|
|盘亏检查|设定盘亏是否启用可用量检查。|
|形态转换检查|设定形态转换是否启用可用量检查。|
|盘点补货检查|设定盘点补货是否启用可用量检查。|
|废品处理检查|设定废品处理是否启用可用量检查。|
|借入还出检查|设定借入还出是否启用可用量检查。|
|检查时机：||
|保存|设定在单据上进行可用量检查的时机，目前仅支持保存时检查。|
|需求来源：||
|生产领料|用户可配置“需求来源”是否包含“生产领料单”。 生产领料启用可用量检查时，此项必选。|
|调拨待出|用户可配置“需求来源”是否包含“调拨待出”。调拨待出启用可用量检查时，此项必选。|
|杂发|用户可配置“需求来源”是否包含“杂发”。杂发启用可用量检查时，此项必选。|
|采购退货|用户可配置“需求来源”是否包含“采购退货”。采购退货启用可用量检查时，此项必选。|
|完工回退|用户可配置“需求来源”是否包含“完工回退”。完工回退启用可用量检查时，此项必选。|
|借出|用户可配置“需求来源”是否包含“借出单”。借出启用可用量检查时，此项必选。|
|借入还出|用户可配置“需求来源”是否包含“借入还出”。借入还出启用可用量检查时，此项必选。|
|盘点补货|用户可配置“需求来源”是否包含“盘点补货”。盘点补货启用可用量检查时，此项必选。|
|形态转换|用户可配置“需求来源”是否包含“形态转换”。形态转换启用可用量检查时，此项必选。|
|废品处理|用户可配置“需求来源”是否包含“废品处理”。废品处理启用可用量检查时，此项必选。|
|销售出货|用户可配置“需求来源”是否包含“销售出货单”。销售出货启用可用量检查时，此项必选。|
|盘亏|用户可配置“需求来源”是否包含“销售出货单”。销售出货启用可用量检查时，此项必选。|
|领料退料|用户可配置“需求来源”是否包含“领料退料”。|
|供应来源：||
|完工报告|用户可配置“供应来源”是否包含“完工报告”。|
|采购收货|用户可配置“供应来源”是否包含“采购收货”。|
|调拨待入|用户可配置“供应来源”是否包含“调拨待入”。|
|杂收|用户可配置“供应来源”是否包含“杂收”。|
|销退收货|用户可配置“供应来源”是否包含“销退收货”。|
|借入|用户可配置“供应来源”是否包含“借入”。|
|借出还入|用户可配置“供应来源”是否包含“借出还入”。|
|盘盈|用户可配置“供应来源”是否包含“盘盈”。|
|形态转换|用户可配置“供应来源”是否包含“形态转换”。|
|期初开账|用户可配置“供应来源”是否包含“期初开账”。|
