
# 功能描述

企业的存货应当在会计期末时，按照“账面成本与可变现净值孰低法”的原则进行计量。“可变现净值”指企业在正常经营过程中，以估计售价减去估计完工成本及销售所必需的估计费用后的价值。料品市价表就是存储可变现净值的价目表，用于提取存货跌价准备时提供可变现净值。

# 栏目说明

料品市价-单头

|**栏目**|**说明**|
|---|---|
|编码|用户可录入“料品市价”的档案编码。|
|名称|用户可录入“料品市价”的档案名称。|
|价格员|可选择业务员录入。|
|币种|币种为当前组织对应法人组织的主账簿的本位币，可以维护。|
|毛利率|用户手工录入，会利用此毛利率计算料品的预计销售费用。|
|状态|系统维护，不可维护。|
|生效日期|生效的起始日期。|
|失效日期|生效的截止日期。|
|备注|用户可在此处录入备注信息。|

# 操作说明

## 相关功能

### 导入市价

导入市价可选择导入全部物料或指定物料。

导入市价可选择3种导入方法：

*  最近一次采购价
*  供应商最近报价
*  厂商价目表

以上3种方法可以任意组合，取价原则为按顺序取到即止。
