
# 功能描述

规定ATP计算的一组参数,这些参数定义了ATP的需求、供给、时间范围、计算规则等。

ATP计算时会按照本功能设置的“ATP规则”进行处理。

可参见库存应用专题【ATP】。

# 栏目说明

ATP规则

|栏目|说明|
|---|---|
|编码|用户可录入“ATP规则”的档案编码。|
|名称|用户可录入“ATP规则”的档案名称。|
|朝前消耗|表示可以借用以前期间的ATP。|
|朝后消耗|表示可以借用未来期间的ATP。|
|累计ATP|每期供应与需求相抵后的净供应量累计。选中，则ATP查询时可查看累计ATP。|
|可调后天数|朝后消耗时，可设置向后借的天数。|
|ATP不足|设定接单时ATP检查不过时的处理方式：不允许保存；单据自动挂起。|
|时格|ATP计算时会按预先设定的“时格”分期间列示每期的需求、供给、预计库存量。时格用于分期间观察ATP数据，一般的，近期时格期间窄，远期时格期间宽。|
|过去需求天数|ATP计算时，以“当前日期＋过去需求天数”作为需求起始时点，此时点前的需求不纳入ATP计算。|
|过去供应天数|ATP计算时，以“当前日期＋过去供应天数”作为供应起始时点，此时点前的供应不纳入ATP计算。|
|供应截至日|指ATP计算时所考虑未来供应、需求截止时点：累计制造提前期: 取料品的‘制造提前期’作为未来供需的截止时点；本层制造提前期：取料品的‘固定提前期＋变动提前期’作为未来供需的截止时点；累计汇总提前期：取料品的‘汇总提前期’作为未来供需的截止时点；使用者自定义： 按使用者手工设定的期间确定未来供需的截止时点；|
|供应截至天数|“供应截至日”设置为“使用者自定义”时，可以录入大于等于0的数。|
|销售订单|用户可配置“需求来源”是否包含“销售订单”。|
|生产订单备料|用户可配置“需求来源”是否包含“生产订单备料”。|
|重复日计划备料|用户可配置“需求来源”是否包含“重复日计划备料”。|
|外部需求|用户可配置“需求来源”是否包含“外部需求”。外部需求是其他组织转到本组织需要本组织进行生产的需求。可在需求计划－>外部需求来源中查看。|
|供应范围|指ATP计算时获取供应时的地理范围，供应范围有以下选项：单一组织:按组织计算ATP。单一存储地点:供应范围为本组织下的某个特定的存储地点。|
|库存可用量|用户可配置“供应来源”是否包含“库存可用量”。|
|生产订单|用户可配置“供应来源”是否包含“生产订单”。|
|重复日计划|用户可配置“供应来源”是否包含“重复日计划”。|
|调拨在途|用户可配置“供应来源”是否包含“调拨在途”。|
|采购订单|用户可配置“供应来源”是否包含“采购订单”。|
|相关组织|用户可配置“供应来源”是否包含相关组织对本组织的调拨在途和采购在途。|

# 操作说明

## 相关功能

### 下发

可通过此功能将此当前档案下发到其他关联组织。

### 取消下发

若当前档案已经下发到其他关联组织,可通过此功能将关联组织的通过下发产生的档案删除。

### 下发参数

可通过此功能定义下发参数，如是否可改等。
