
# 功能描述

用于定义“存储地点”，“存储地点”在系统中表示仓库，表示用于存放物料的场所。

# 栏目说明

存储地点

|栏目|说明|
|---|---|
|编码|用户可录入“存储地点”的档案编码。|
|名称|用户可录入“存储地点”的档案名称。|
|所属部门|当前“存储地点”隶属的部门。|
|负责人|当前“存储地点”的负责人，可录入“业务员类型”为“库管员”的业务员。|
|联系电话|负责人的联系电话。|
|地址|当前“存储地点”的地址。|
|地区|所属的地区。|
|承运商|当前“存储地点”的承运商。|
|位置属性|按存储地点的用途对存储地点进行分类：普通仓露天仓外寄仓寄外仓在制品报废参见库存应用专题【存储地点】。|
|普通/露天仓|普通仓、露天仓可分为：存货仓固定资产仓费用仓参见库存应用专题【存储地点】。|
|待出货区|当存储地点“位置属性”为“在制品”时，可定义此“在制品仓”是否为“待出货区”。|
|保税仓|用户可定义此存储地点是否为“保存仓”。|
|盘点再补货|用户可定义此存储地点的补货方式是否为“盘点再补货”，参见【盘点补货单】。|
|外寄仓|位置属性为“外寄仓”时，可以录入，外寄仓分为：VMI外寄仓客户外寄仓参见库存应用专题【存储地点】。|
|寄外仓|位置属性为“寄外仓”时，可以录入，寄外仓分为：委托代销寄外仓委外加工寄外仓参见库存应用专题【存储地点】。|
|默认客户|存储地点为“委托代销寄外仓”、“客户外寄仓”时可以录入。单据录入“委托代销寄外仓”、“客户外寄仓”时，会将默认客户带入为单行的客户，允许修改，且此时客户是库存管理的维度。|
|默认供应商|存储地点为“委外加工寄外仓”、“VMI外寄仓”时可以录入。单据录入“委外加工寄外仓”、“VMI外寄仓”时，会将默认供应商带入为单行的供应商，允许修改，且此时供应商是库存管理的维度。|
|存储类型|在这里录入存储类型，在库存单据上，选择存储地点，能够自动带出此默认的存储类型。|
|允许负库存|用户可定义此存储地点是否在库存可用量不足的情况下进行出库业务。此项目在基础档案参数“允许负库存”为是时才可以维护。|
|盘点冻结标志|盘点冻结标志为是时，表示此存储地点已被期末盘点做快照标识，在盘点期间此存储地点的出入库记录，系统会对出入库记录做快照处理；盘点冻结标志为否时，此存储地点未被期末盘点做快照处理。|
|库位管理|用户可定义此存储地点是否进行库位管理。此项目在基础档案参数“库位管理”为是时才可以维护。|
|批号管理|用户可定义此存储地点是否进行库位管理。此项目在基础档案参数“批号管理”为是时才可以维护。参见【库存中的批号】。|
|序列号管理|用户可定义此存储地点是否进行库位管理。此项目在基础档案参数“序列号管理”为是时才可以维护。参见【库存中的批号】。|
|默认入库库位|该存储地点入库时默认的入库库位。入库单据录入时，系统自动按如下顺序为入库单据赋默认库位：存储地点料品交叉关系档默认入库库位；料品档默认库位；存储地点档的默认入库库位。|
|默认出库库位|该存储地点出库时默认的出库库位。出库单据录入时，系统自动按如下顺序为出库单据赋默认库位：存储地点料品交叉关系档默认出库库位；料品档默认库位；存储地点档的默认出库库位。|
|生效|标识此档案是否生效。|
|生效日期|生效的起始日期。|
|失效日期|生效的截止日期。|

存储地点下存储类型的可用性定义

|栏目|说明|
|---|---|
|存储类型|按以下存储类型列示：可用待检在检不合格报废冻结退回参见【存储类型】。|
|可用类型|可定义此存储地点下各存储类型的可用类型，可以类型分为：可收发:可库存收发，不可预留，不参与ATP、MRP运算。可ATP：可库存收发，可预留，可参与ATP计算，不参与MRP运算。可MRP：可库存收发，可预留，可参与ATP、MRP运算。|
