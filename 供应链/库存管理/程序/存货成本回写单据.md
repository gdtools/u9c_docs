
# 功能描述

用于将成本计算出的单价及成本回写给异动单据。异动单据一般指出入库单据。主要场景是为节省成本计算的效率。

# 栏目说明

存货成本回写单据－日期

|栏目名称|说明|
|---|---|
|开始日期|回写单据范围的开始日期|
|结束日期|回写单据范围的结束日期|

# 操作说明

## 存货成本回写单据-执行

依据选择的日期范围及单据范围将成本计算的单价回写到单据。

**操作前提**

*  已经执行成本计算；

**操作步骤**

点击库**存管理－>存货成本回写单据**－>执行按钮。具体步骤如下所示。

*  **第1步：库存管理模块存货成本回写单据节点；**
*  **第2步：选择需要回写单据成本的单据的日期范围；**
*  **第3步：选择需要回写单据成本的单据的单据范围；**

# 初始准备

*  库存参数【成本计算成本回写单据】为F；
*  完成成本计算；
