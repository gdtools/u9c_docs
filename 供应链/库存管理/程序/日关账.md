
# 功能描述

日关账功能加入系统调度，既可以即时执行，又可定期自动运行。

# 业务规则

*  可指定存储地点，可设置关账前置天数。

# 栏目说明

|栏目名称|说明|
|---|---|
|组织|默认当前组织，不可选|
|存储地点|指定存储地点关账，空表示全部|
|关账前置天数|设置关账前置天数|

# 操作说明

## 执行

选择合适的条件后，点击“执行”按钮立即执行本程序。

## 调度

选择合适的条件后，点击“调度”按钮自动执行本程序。

**操作前提**

*  定义调度计划，可以在线新增

**操作步骤**

点击**库存管理－>程序－>日关账－>调度**按钮，可以进行调度操作。具体步骤如下所示。

*  **第1步：**点击按钮执行“调度”功能，系统自动弹出调度画面。
*  **第2步：**若本程序只执行一次，选择“执行一次”，录入执行时间。
*  **第3步：**若本程序需要重复执行，选择“重复执行”，参照录入调度计划，当前程序就可以按照调度计划定时执行本程序；
