
# 功能描述

库存规划批量计算功能加入系统调度，既可以即时执行，又可定期自动运行。

# 栏目说明

|栏目名称|说明|
|---|---|
|当前组织|当前登录的组织|
|规划层级|根据 [库存规划层级]带入，有以下两个选项：组织：按组织补货，在整个组织范围内计算供需；存储地点：按存储地点补货，在每个存储地点内计算供需|
|规划过去天数|执行规划计算的过去天数|
|规划未来天数|执行规划计算的未来天数|
|货主组织|用来规划的货主组织范围|
|存储地点|[库存规划层级]=存储地点时，非空|
|计划员|表示按指定的计划员规划计算。计算时，只处理计划员所对应的物料的供需|
|规划对象|计算后生成规划对象的库存规划计算表|
|料品分类|表示按指定的料品分类范围规划计算|
|料品|表示按指定的物料范围规划计算。计算时，只处理指定物料范围的供需|
|是VMI|用来指定规划范围|
|项目|用来指定规划范围|
|需求分类|用来指定规划范围|
|考虑过期供应|库存规划计算时，是否考虑过期供应|
|考虑过期需求|库存规划计算时，是否考虑过期需求|

# 操作说明

## 执行

选择合适的条件后，点击“执行”按钮立即执行本程序。

## 调度

选择合适的条件后，点击“调度”按钮自动执行本程序。

**操作前提**

*  定义调度计划，可以在线新增

**操作步骤**

点击**库存管理－>程序－>库存规划计算－>调度**按钮，可以进行调度操作。具体步骤如下所示。

*  **第1步：**点击按钮执行“调度”功能，系统自动弹出调度画面。
*  **第2步：**若本程序只执行一次，选择“执行一次”，录入执行时间。
*  **第3步：**若本程序需要重复执行，选择“重复执行”，参照录入调度计划，当前程序就可以按照调度计划定时执行本程序；
