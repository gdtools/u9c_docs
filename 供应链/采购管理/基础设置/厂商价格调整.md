
# 功能描述

厂商价目表一旦核准生效后，就不允许直接对其随意修改。对核准生效后的价表进行价格调整或新增价目，将通过调价单来完成。调价单生效后，将根据调价单修改价表，并生成新版本的价表。

# 关键应用

*  支持工作流配置；
*  支持Excel导入；
*  ……

# 业务规则

*  厂商调价审核后更新价表行；
*  厂商调价单终止后取消原调价结果；
*  厂商调价单不支持弃审；
*  相同供应商，价表可多次调价，调价会导致之前价表记录失效。

# 按钮说明

*  <操作—价目选择>：

1）操作概述：对同一价表可以进行批量物料取价。

2）操作前提：当前调价单处于开立或新增未保存时、未终止、且单头[价目表]非空时，

3）操作步骤：选择供应商和价表，点击【操作】－>【价目选择】按钮，弹出批量取价画面，点击“查找”按钮，查询当前价表所有物料，选择需要调价的物料，点击确定，能够将物料带到成当前价目中。；

*  <操作—终止>：

1）操作概述：对调价单执行终止操作，终止后的调价单不能再使用。

2）操作前提：调价单必须为“已核准”状态；

3）操作步骤：点击【操作】－>【终止】按钮，即完成当前调价单的终止操作。

注意：终止后的调价单不能再启用，此操作为不可逆操作，要谨慎使用！

*  <操作—取价>：

1）操作概述：

此功能可以将对应的价目表上的价格信息取到调价单行上，提高效率，也方便输入。

2）操作前提：调价单头必须指定了价表。

3）操作步骤：

第1步：在调价单头指定价表；

第2步：点击【操作】－>【取价】按钮，即可根据调价行录入的物料信息（版本、等级、成分、自由项、计价单位、物料类）和调价生效时间，从调价单头指定的价表里找该价目表的[价目表表体>的[单价]和[定价百分比]，做为当前调价单里的[调前单价]和[调前定价百分比]。

*  <操作—下载Excel模板>：下载Excel导入厂商调价单模板；
*  <Excel导入>：根据Excel模板导入厂商调价单；
