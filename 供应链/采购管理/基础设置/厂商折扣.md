
# 功能描述

定义厂商折扣， 厂商折扣是针对厂商价目表的折扣

# 关键应用

*  支持工作流配置；

# 业务规则

*  折扣单与价表配合使用
*  数量折扣仅支持当前单据
*  折扣单参照非折扣价表，折扣单才参与取价

*  已核准：核准后单据可以使用，可以对核准状态的厂商折扣表进行终止操作或变更有效期

厂商折扣行--明细页签

|**栏目名称**|**说明**|
|---|---|
|行号||
|**“料品”分区**|维护并查看折扣料品的相关信息.|
|**“折扣”分区**||
|折扣方式|枚举值：
   *  **数量折扣：**打折多少与购买料品的数量段有关；
初次录入[折扣方式]=“数量折扣”时自动弹出分段折扣设定画面。若[折扣方式]=“数量折扣”，则点击链接可打开分段折扣设定画面。**例如：**购买50个以下打9折、50-100打8.5折； 
   *  **普通折扣：**打折多少与购买料品的数量段无关；
**例如：**xxx物料五一期间一律打8折，购买多少数量都执行此折扣。|
|累进方式|折扣方式为“数量折扣”时有效，枚举值：
   *  **全额计算：**根据折扣的分段规则决定总交易数量落在哪个分段区间，总交易量均采用该分段区间所对应的折扣。 
*  **分层累进：**将总交易数量按照折扣的数量分段规则分成若干段，各段内的数量采用该分段所对应的折扣来计算交易额，然后将各段的交易金额累加起来.
**例如：**手机原价1000元，3-5台每台优惠100元，5台以上每台优惠200元，若客户购买10台，则在分层累进的计算方法下，交易金额为2*1000+3*(1000-100)+5*(1000-200)=8700；在全额计算的方法下，交易金额就是10*(1000-200)=8000|

# 按钮说明

*  <操作—价目选择>：点击<凭证>按钮，查询光标所在行凭证

1）操作概述

对同一价表可以进行批量物料取价。

2）操作前提

当前厂商折扣单处于开立或新增未保存时、未终止、且单头[价目表]非空时，

3）操作步骤

选择供应商和价表，点击【操作】－>【价目选择】按钮，弹出批量取价画面，点击“查找”按钮，查询当前价表所有物料，选择需要定义折扣的物料，点击确定，能够将物料返回到主画面。

*  <操作—终止>：

对厂商折扣执行终止操作，终止后的厂商折扣不能再使用。

1）操作前提：

厂商折扣必须为“已核准”状态；

2）操作步骤：

点击【操作】－>【终止】按钮，即完成当前厂商折扣单的终止操作。

注意：终止后的厂商折扣单不能再启用，此操作为不可逆操作，要谨慎使用！

*  <操作—有效期变更>：

对厂商折扣单的生效日期、失效日期进行调整，可以在原来有效期的基础上缩短或延长；

1）操作前提

厂商折扣单必须为“已核准”状态；

2）操作步骤

点击【操作】－>【有效期变更】按钮，调出厂商折扣单有效期变更画面，录入“新生效日期”或“新失效日期”，点击【确定】，即完成厂商折扣单的有效期变更。

*  <操作—审批参数>：可以定义厂商折扣单确认方式是“即时确认”、“确认作业”、或走“审批流程”。
*  <相关功能—下发>：点击【下发】按钮，可以把当前记录下发到其他组织；
*  <相关功能—取消下发>：点击【取消下发】按钮，可以取消下发到其他组织的下发记录；
*  <相关功能—下发参数设置>：点击【下发参数设置】按钮，可以调整下发参数，然后根据下发参数下发；
