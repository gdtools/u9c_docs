
# 功能描述

本节点提供采购单据中挂起原因的设置。

# 关键应用

*  设置挂起原因
*  设置挂起原因的有效性和有效时间区间
*  设置允许使用该挂起原因的用户
*  为特定用户使用该挂起原因设定有效性和有效时间区间

# 业务规则

*  同一个应用下，挂起原因编码不能相同；

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**挂起设置画面表头**|
|编码|手工输入当前挂起原因的编码|
|名称|当前挂起原因的描述|
|简称|当前挂起原因的简称|
|生效|当前挂起原因是否生效的状态|
|生效日期|当前挂起原因的生效日期|
|失效日期|当前挂起原因的失效日期|
|**挂起设置画面表体**|
|操作员|选择对当前挂起原因有使用权的用户，只有在此列表中的用户才有权使用当前挂起原因|
|生效|当前列表行的用户是否有权使用当前挂起原因的状态|
|生效日期|当前列表行的用户允许使用当前挂起原因的开始日期|
|失效日期|当前列表行的用户允许使用当前挂起原因的结束日期|
