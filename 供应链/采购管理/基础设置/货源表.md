
# 功能描述

货源表是用来定义一个物料的可选供应商范围，以及各供应商的优先供货顺序及配额比例

# 关键应用

# 业务规则

*  若料品档定义[货源管控]，则必须在货源表中定义该料品的货源；
*  根据自由项等多个维度及其组合定价；
*  货源表的定义，将影响配额计算以及采购订单的生成；
*  同一个组织，供应商，料品，厂牌，等级成分，自由项，生效时间等维度不能出现重复。

# 按钮说明

*  <操作—下发参数>：点击下发参数，可以调整下发参数，然后根据下发参数下发；
*  <操作—下发>：选择下发，可以把当前记录下发到其他组织；
*  <操作—取消下发>：选择下发取消，可以取消下发到其他组织的下发记录；
*  <操作—审批参数>：选择审批参数，可以设置货源表确认方式“及时确认”、“确认作业”、“审批流程”；
*  <配额计算>：点击配额计算，可以计算供应商配额比例计算；
*  <快速创建相关信息>：执行本操作，录入信息，会同时生成厂商价表、供应商料品交叉档中的相关数据。

# 操作说明

采购管理基础设置货源表，录入供应商，料品等其他信息，保存后可以创建新的货源表。

# 应用举例

**采购配额：**指一个物料有多个正式供应商供货时，在各供应商间确定采购量的一种策略。U9系统提供了7种配额处理方式。

注意：若物料主档设置配额阀值，只有当大于阀值时，才按配额处理 。物料中还可定义配额的供应商范围，配额时在该范围内进行处理。

U9系统中对于采购需求进行配额处理的时机随是否启用供应商门户而有所不同

*  启用供应商门户时，外系统（MRP、库存规划）转到采购系统时，首先需要进行配额处理，将启用门户的供应商的需求传递到对应的门户中
*  不启用供应商门户时，则在采购系统中转采购订单时进行配额处理

本采购系统中，有以下7种确定供应商和采购数量的方式：

*  **主供应商优先：**指在任何时候都先找主供应商。超过其最大供货能力后，其它供应商顺序候补。
 
   *  在此方式下，当有采购需求时首先会找主供应商，为主供应商创建采购单； 将本次采购数量与主供应商的最大供货能力比较；
   *  如果超出主供应商的最大供应货能力的话，则超出部分分配给第二供应商，为第二供应商创建采购单；
   *  依次处理，如果分配给第二供应商的采购量也超过了其最大供货能力，则再顺序找第三供应商。
   *  这种策略的出发点是，以主供应商为主，其它供应商属于应急的供应商。
   *  此方式下，每次可能会有多个供应商。
*  **只考虑主供应商：在任何情况下，均只考虑主供应商。** 
   *  超出主供应商最大供货能力后，系统会给出警告，但并不终止当前操作。
   *  这种方式下，只有一个供应商。
*  **顺序轮流分配：**系统会按<采购货源表>中定义的供应商顺序，轮流分配。这次给1号供应商，下次就给2号供应商，再下次给3号供应商，一直顺序轮流下去。
 
   *  这种策略的出发点是：和每家供应商都搞好关系，不分亲疏伯仲。
*  **最近一期消耗量分配：**系统会统计最近一个期间中，当前各供应商供应的当前物料的消耗量。根据消耗量来计算本次采购数量在各家供应商间进行分析。
 
   *  这种策略的出发点是：车间肯定爱用质量好的料。所以质量好的料我就多采购，但和其它供应商的关系也得靠继续订货来维持。
   *  在此方式下，可能会有多个供应商。
   *  注意：系统在真正配额时仅取货源表中的配额比例，用户需要及时通过货源表中“配额计算”及时按消耗量修正配额比例
*  **逐笔按固定比例分配：**把每次的采购数量按<采购货源表>中定义的比例，在多家供应商间进行分配。
 
   *  这种策略的出发点是：每次采购数量都特别大，任何一家供应商都无法单独满足，所以只能每次采购时在多个供应商间进行分配。
   *  在此方式下，可能会有多个供应商。
*  **按动态比例分配：**系统会统计最近一个期间中，当前各供应商供应的当前物料的订单量。根据订单量来计算本次采购数量在各家供应商间进行分析。
 
   *  这种策略的出发点是：不疏远任何一家供应商，按订单量来执行配额。
   *  在此方式下，可能会有多个供应商。
   *  注意：系统在真正配额时仅取货源表中的配额比例，用户需要及时通过货源表中“配额计算”及时按订单量修正配额比例
   *  建议供应商：则按物料主档中默认供应商为建议供应商。

**U9系统中的处理**

*  **“主供应商优先”的设置** 
   *  基础设置---料品---主供应商：设置主供应商
   *  基础设置---料品---采购配额方式：主供应商优先
   *  基础设置---供应商---采购货源---货源序号
   *  当主供应商无法满足本次采购的需求数量时，系统将按货源序号来找下一个供应商。
*  **“只考虑主供应商”的设置** 
   *  基础设置---料品---主供应商：设置主供应商
   *  基础设置---料品---采购配额方式：只考虑主供应商 系统将只考虑该主供应商。
*  **“顺序轮流分配”的设置** 
   *  基础设置---料品---采购配额方式：顺序轮流分配
   *  基础设置---供应商---采购货源---货源序号
   *  系统将自动维护各供应商的“最近一次采购时间”，用来根据货源序号判定本次采购时应该找哪个供应商。
*  **“最近一期消耗量”的设置** 
   *  基础设置---料品---采购配额方式：最近一期消耗量
   *  基础设置---料品---统计期间： 系统将自动维护各供应商的“累计采购量/消耗量”，用来判定本次采购时应该找哪个供应商。
*  **“逐笔按固定比例分配”的设置** 
   *  基础设置---料品---采购配额方式：逐笔按固定比例分配
   *  基础设置---供应商---采购货源---货源序号
   *  基础设置---供应商---采购货源---配额比例
*  **“按动态比例分配”的设置** 
   *  基础设置---料品---采购配额方式：按动态比例分配
   *  基础设置---供应商---采购货源---货源序号
   *  基础设置---供应商---采购货源---配额比例 系统将自动维护各供应商的“累计采购量/消耗量”，用来判定本次采购时应该找哪个供应商。
*  **“建议供应商”的设置** 
   *  基础设置---料品---采购配额方式：建议供应商
   *  基础设置---料品---建议供应商
