
# 功能描述

维护采购管理下各类单据（包括采购订单，请购单、收货单、退货申请单、询价单，采购合同，厂商调价单，比价单，采购订单变更单，委外发料单，核销单，ASN单）的单据类型。

# 业务规则

*  不同的业务类型，意味着在不同的应用，不同的业务流程

# 栏目说明

[单据类型- 基本页签（适用于采购订单）](http://wangwq/U9C/help/zh-CN/Content/SCM/PM/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|"基本"分区||
|编码|单据类型编码|
|名称|单据类型名称,命名时最好能根据对单据类型的设定进行命名,便于使用时进行区分.|
|描述|单据类型描述|
|业务类型|适用的采购业务类型，枚举值：标准采购VMI需求补货VMI采购结算工序外协采购全程委外采购借入转采购|
|"立账与预付"分区||
|立账方式|定义使用当前单据类型的订单及其后续业务采取何种方式进行立账,枚举值：1：凭单制（拉式）:应付模块中选取可立账单据立应付2：非凭单制（推式） :立账单据审核后自动立应付注意：订单立账只适用于"借入转采购"、"VMI采购结算"；其他业务类型中，PO单据类型将带入收货单，决定收货单的立账方式|
|需预付|采购订单审核前是否必须录入预付单是:采购订单审核前必须要录入预付单；否则不允许审核通过。否:采购订单中预付单可录可不录|
|"其他"分区||
|价格可改|PO中价格是否可以修改,有两方面的含义按取价规则取得的po价格是否可以修改未取得价格时是否允许手工输入|
|需供方确认|采购订单是否需要供应商确认是:订单下达前必须录供应商确认数量，下达则必须在供应商确认后，否:不需进行供应商确认，订单核准后即可下达。|
|外协价格为0需立账|仅当“外协价格可为0”为真时有效是:外协采购订单采购价格为0时可以立账否:外协采购订单采购价格为0时不可以立账。|
|补单|表示当前是否在补录以前已发生业务的单据 是:补录已经发生业务的单据，则诸如最高库存、库存周转率等检查会忽略过去否:录入当前发生的业务，则系统要求单据日期大于等于系统时间|
|"流程"分区||
|期初订单|选中，代表采购订单为“期初订单”|
|补货|选中，代表采购订单为“补货订单”|
|合同采购|选中，在采购订单必须录入合同|
|项目采购|选中，在采购订单必须录入项目信息|
|自动处理倍量|选中，在采购订单中会自动根据倍量调整采购数量|

|入库确认日期默认值|收货单上[入库确认日期]的处理方式,枚举值核准前手工指定:用户在核准前必须手工指定“入库确认日期”；核准时空取单据日期:收货单核准时“入库确认日期”若为空,则系统自动取“单据日期”做为入库确认日期；核准时为空取系统日期:用户在核准前可手工指定，若未指定,在核准时系统自动取“系统日期”做为入库确认日期；|
|"流程"分区||
|项目采购|选中，收货单中必须录入项目，仅当收货单类型为“采购收货单或采购退货单”时，允许修改|
|有合同|选中，收货单中必须录入合同，仅当收货单类型为“采购收货单”时，允许修改|
|收货至工单|仅适用于标准采购业务类型的采购收货是：收货单收货后，自动将料品出库至相应的工单上，生成领料单。否：正常采购收货|
|退货类型|仅当收货单类型为“采购退货”时有效，[参见应用专题“采购退货”](http://wangwq/U9C/help/zh-CN/Content/SCM/PM/App/scm.pm.app.return.htm)枚举值:收货退货检验退货在库退货|
|据源单退货|仅当[业务类型]=“采购退货”时有效，[参见应用专题“采购退货”](http://wangwq/U9C/help/zh-CN/Content/SCM/PM/App/scm.pm.app.return.htm)是:进行采购退货的收货单必须来源于普通收货单行否:不需要根据收货单进行退货|
|补货收货|代表当前收货单为补货收货单|
|退补产生订单|选中，代表退补需要产生订单，[参见应用专题“采购退货”](http://wangwq/U9C/help/zh-CN/Content/SCM/PM/App/scm.pm.app.return.htm)|
|VMI|选中，代表当前收货为VMI业务|

# 操作说明

*  通过菜单《供应链：委外管理：基础设置：[单据类型](http://wangwq/U9C/mvc/main/javascript:menuManager.closeBox();TabPanelManager.addUrlTab()》进入该界面；
*  操作步骤
 
   *  第1步：选择采购单据类型；
   *  第2步：维护编码、名称等信息。
   *  第3步：维护单据类型相关参数信息。
   *  第4步：点击保存。
