
# 功能描述

VMI规则主要是定义VMI结算时所使用的规则。

# 关键应用

# 业务规则

*  同一组织下VMI规则编码唯一；
*  同一组织下VMI规则生效+生效日期+失效日期+价格依据1+价格依据2唯一；

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**基本信息**|
|编码||
|名称||
|价格依据1|表示消耗时结算时价格的取法，可定义两个价格依据。
   *  厂商价表:取当时厂商价表中的价格。
*  采购订单价格（按批号）：按批号找到对应的采购订单，取该订单上的价格。
*  采购收货单价格（按批号）：按批号找到对应的采购收货单，取该收货上的价格。
*  最新料品成本：取月结时更新的最新的料品成本。
|
|价格依据2|表示消耗时结算时价格的取法，可定义两个价格依据。

*  采购订单价格（按批号）：按批号找到对应的采购订单，取该订单上的价格。
*  采购收货单价格（按批号）：按批号找到对应的采购收货单，取该收货上的价格。
*  最新料品成本：取月结时更新的最新的料品成本。
|
