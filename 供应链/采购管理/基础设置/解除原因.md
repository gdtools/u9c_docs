
# 功能描述

本节点提供采购单据中解除挂起原因的设置。

# 关键应用

*  设置解除挂起原因
*  设置解除挂起原因的有效性和有效时间区间
*  设置允许使用该挂起原因的用户
*  为特定用户使用该挂起原因设定有效性和有效时间区间
*  设定解除挂起原因与挂起原因之间的关联

# 业务规则

*  相同应用里解除原因编码不能重复；
*  解除原因可配对多个挂起原因；

# 栏目说明

[**解除设置画面表头**](javascript:void(0);)

|**栏目名称**|**说明**|
|---|---|
|编码|手工输入当前解除原因的编码注意: 编码不能重复|
|名称|当前解除原因的描述|
|简称|当前解除原因的简称|
|生效|当前解除原因是否生效的状态|
|生效日期|当前解除原因的生效日期|
|失效日期|当前收款单解除原因的失效日期|

[**解除设置画面表体－权限设定**](javascript:void(0);)

|**栏目名称**|**说明**|
|---|---|
|用户|选择对当前解除原因有使用权的用户，只有在此列表中的用户才有权使用当前解除原因|
|生效|当前列表行的用户是否有权使用当前解除原因的状态|
|生效日期|当前列表行的用户允许使用当前解除原因的开始日期|
|失效日期|当前列表行的用户允许使用当前解除原因的结束日期|

[**解除设置画面表体－原因匹配**](javascript:void(0);)

|**栏目名称**|**说明**|
|---|---|
|挂起原因|选择当前解除原因所对应的收款单挂起原因|
|生效|当前解除原因针对当前收款单挂起原因的有效状态|
|生效日期|当前解除原因针对当前收款单挂起原因的生效日期|
|失效日期|当前解除原因针对当前收款单挂起原因的失效日期|
