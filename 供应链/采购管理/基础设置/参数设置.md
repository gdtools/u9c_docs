
# 功能描述

用于设定采购系统的运行过程中，对采购价格、收货、税等的控制方法以及控制策略。

采购参数的取值定义后，允许再次修改。修改后对以往单据不做修改，仅对未来采购单据产生影响。

# 业务规则

*  支持按照企业账号级设定参数，设定后，参数对企业内所有组织有效；
*  支持按照组织级（只能为采购组织）设定参数，设定后，参数只对该组织有效，不影响其他组织。

*  否:订单中录入的物料自由项，携带至收货单后可手工修改。

*  收货—点收—检验—入库
*  收货—入库—检验（作废）

*  创建补货单追踪:指创建一张新的补货订单对拒收数量进行补货
注意：本参数取值做为拒收处理时的默认值，操作人员在实际拒收时可根据业务需要更改处理方式。|
