
# 功能描述

询价范围用于定义询价供应商集合，其定义的数据被采购询价类引用，在询价时可据此确定询价供应商。

# 关键应用

*  支持工作流配置；
*  支持与询比价配合使用；
*  ……

# 业务规则

*  询价范围实质上是设定询价供应商的集合，
*  可设置同一供应商、不同位置的集合
*  定义询价顺序，“定期询价”时优先取较小的询价顺序对应的供应商作为询价供应商

# 栏目说明

[询价范围－单头](javascript:void(0);)

|**栏目名称**|**说明**|
|---|---|
|**基本信息**|
|编码|根据“采购参数—询价范围编码规则”自动编码，也可手工输入|
|名称|询价范围的名称，用户手工输入|
|日期|默认＝当前系统日期，可改|

|说明|可空，对当前询价范围说明性描述|

询价范围－单体

|**栏目名称**|**说明**|
|---|---|
|**询价信息**|
|供应商|非空，参照供应商档案录入需询价的供应商|

|最近一次询价人|显示当前供应商最近一次询价人，仅供查阅，不可修改|

# 按钮说明

*  <操作—下发参数>：点击下发参数，可以调整下发参数，然后根据下发参数下发；
*  <操作—下发>：选择下发，可以把当前询价范围表记录下发到其他组织；
*  <操作—取消下发>：选择下发取消，可以取消下发到其他组织的下发记录；
*  <操作—审批参数>：点击审批参数，可以调整当前询价范围的审批方式是即时确认或者确认作业等；
