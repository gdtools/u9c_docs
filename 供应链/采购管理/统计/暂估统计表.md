
# 功能描述

暂估统计表对估价入库的物料及其匹配信息提供明细及汇总查询。

# 关键应用

*  采购系统已启用
*  统计数据已更新，[参见统计更新](http://10.16.226.67/U9C/help/zh-CN/Content/SCM/PM/Function/SCM.PM.PM8060_10.htm)
*  定义统计期间，[参见统计期间](http://10.16.226.67/U9C/help/zh-CN/Content/SCM/PM/Function/CBO.Pub.StatPeriodStatus.StatPeriodStatus.3016.htm)[](javascript:void(0);)

# 业务规则

*  **统计数据**

收货单入库确认或业务关闭，退货非补货单追踪

*  **统计条件**

系统在查询方案中（查询方案）提供默认的统计条件，

不同的统计方式对应不同的统计条件。

另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

*  **统计结果**

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 栏目说明

**统计结果**

|**栏目**|**说明**|
|---|---|
|期初余额_数量|本期以前暂估未匹配数量；一般来说等于 上一个统计期间期末期末暂估数量。|
|期初余额_金额|本期以前暂估未匹配金额；一般来说等于 上一个统计期间期末期末暂估金额。|
|入库数量|本期暂估入库数量|
|暂估单价|暂估单价＝暂估金额/入库数量|
|暂估金额|本期暂估金额|
|本期匹配总数量|本期进行匹配的总数量|
|前期发生本期匹配数量|前期发生本期匹配数量|
|本期发生本期匹配数量|本期发生本期匹配数量|
|本期匹配总金额|本期进行匹配总金额|
|前期发生本期匹配金额|前期发生暂估本期进行匹配金额|
|本期发生本期匹配金额|本期发生暂估本期进行匹配金额|
|期末暂估数量|期末暂估数量＝期初余额_数量＋入库数量－本期匹配总数量|
|期末暂估金额|期末暂估金额＝期初余额_金额＋暂估金额－本期匹配总金额|

# 按钮说明

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。具体操作参见查询方案；
*  <调整列宽>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度；
