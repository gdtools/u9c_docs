
# 功能描述

针对以采购主导的全程委外业务，查询统计委外料品在指定期间内的委外订单，以及订单的执行信息，如委外料品的下单量、加工子件的成本、数量以及收回情况。

# 使用前提

*  采购系统已启用
*  定义统计期间，参见统计期间

# 统计说明

**统计数据**

采购主导的全程委外订单（已核准），老全程委外订单，现在工序委外

**统计条件**

系统在查询方案中（查询方案）提供默认的统计条件，不同的统计方式对应不同的统计条件。另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

**统计结果**

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 栏目说明

统计结果

|||
|---|---|
|**栏目**|**说明**|
|委外PO||
|母件相关|委外加工的成品|
|子件相关|委外加工过程中由我方提供的加工子件|
|委外商相关||
|委外发出数量|指我方提供的加工子件通过杂发单发出数量|
|收回/剩余数量金额|成品委外收货时，计算对应加工子件的收回及剩余数量等信息|

# 按钮说明

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。
*  <调整列宽>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。
