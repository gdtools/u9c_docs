
# 功能描述

## 功能概述

本节点提供配额比例计算,参见业务专题采购中的供应商配额管理。

## 功能说明

*  支持本组织配额计算；
*  可根据物料分类或料品计算。

# 业务规则

本采购系统中，有以下7种确定供应商和采购数量的方式：

*  主供应商优先：指在任何时候都先找主供应商。超过其最大供货能力后，其它供应商顺序候补；
*  只考虑主供应商：在任何情况下，均只考虑主供应商；
*  顺序轮流分配：系统会按【采购货源表】中定义的供应商顺序，轮流分配。这次给1号供应商，下次就给2号供应商，再下次给3号供应商，一直顺序轮流下去；
*  最近一期消耗量分配：系统会统计最近一个期间中，当前各供应商供应的当前物料的消耗量。根据消耗量来计算本次采购数量在各家供应商间进行分析；
*  逐笔按固定比例分配：把每次的采购数量按【采购货源表】中定义的比例，在多家供应商间进行分配；
*  按动态比例分配：系统会统计最近一个期间中，当前各供应商供应的当前物料的订单量。根据订单量来计算本次采购数量在各家供应商间进行分析；
*  建议供应商：则按物料主档中默认供应商为建议供应商。

# 按钮说明

*  <执行>：调用查询条件界面，重新设置查询条件，进行新的查询；

概述：选择合适的条件后，点击“执行”按钮手动执行本程序。

操作前提：维护好采购货源表中需要配额计算的物料

操作步骤：点击采购管理－>程序－>配额计算－>执行按钮，可以进行执行操作。

*  <调度>

概述：

选择合适的条件后，点击“调度”按钮自动执行本程序。

操作前提：

定义调度计划，可以在线新增

操作步骤：

点击采购管理－>程序－>配额计算－>调度按钮，可以进行调度操作。具体步骤如下所示。

第1步：点击按钮执行“调度”功能，系统自动弹出调度画面。

第2步：若本程序只执行一次，选择“执行一次”，录入执行时间。

第3步：若本程序需要重复执行，选择“重复一次”，参照录入调度计划，当前程序就可以按照调度计划定时执行本程序。
