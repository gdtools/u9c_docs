
# 功能描述

本节点提供手动或系统自动地定期询价。

# 关键应用

# 业务规则

是否询价、如何询价、在什么范围内询价构成了物料的询价策略。U9支持如下的询价策略：

*  不询价：表示当前物料发生采购行为时，不必询价。
*  定期询价：表示当前物料不论是否发生采购行为，都要按固定的间隔进行询价，获取最新市价资料，适合于价格相对较稳定的物料。
*  每次询价：表示当前物料只有在发生采购行为时，才进行询价，并以询价结果影响本次采购。适合于价格波动较大且频繁的物料。
*  按询价类询价：根据料品档上的询价类进行询价，询价类是定义料品在询价过程中的处理参数，并据此对询价行为加以控制。

# 栏目说明

定期询价画面

|**栏目**|**说明**|
|---|---|
|组织|定期询价的组织|
|料品类|定期询价的料品类|
|料品|定期询价的料品|
|询价类|指定定期询价的询价类|
|截至日期|指定定期询价的截至日期，我们按截至日期查找需定期询价的料品|

# 按钮说明

*  <执行>

**概述**

选择合适的条件后，点击“执行”按钮手动执行本程序。

**操作前提**

物料为定期询价物料，且在询价范围表中已经定义完毕

**操作步骤**

点击采购管理－>程序－>定期询价－>执行按钮，可以进行执行操作。

*  <调度>

**概述**

选择合适的条件后，点击“调度”按钮自动执行本程序。

**操作前提**

定义调度计划，可以在线新增

**操作步骤**

点击采购管理－>程序－>统计更新－>调度按钮，可以进行调度操作。具体步骤如下所示。

第1步：点击按钮执行“调度”功能，系统自动弹出调度画面。

第2步：若本程序只执行一次，选择“执行一次”，录入执行时间。

第3步：若本程序需要重复执行，选择“重复一次”，参照录入调度计划，当前程序就可以按照调度计划定时执行本程序。
