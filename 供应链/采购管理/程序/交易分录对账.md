
# 功能描述

日常使用中，总会有一些系统的、人为的因素导致业务单据和交易分录不一致，从而使总账和业务账不一致，比如模版设置错误或手工修改交易分录等等。本功能用于核对单据与交易分录是否一致，主要用于核对明细。

# 关键应用

# 业务规则

*  需要事先根据总账和业务账不一致所涉及的科目和业务单据，通过分录模版查询出其所对应的业务对象。
*  通过本功能，按单据（即业务对象）查询出业务单据及交易分录金额明细信息，核对是否正确。

# 操作说明

**第1步：**首先要确定总账和业务账不一致所涉及的科目，比如应收账款。

**第2步：**根据科目确定所涉及的单据（即自动会计类型），比如应收单。

**第3步：**进入分录模版功能节点，按自动会计类型、科目查询其对应的业务对象，如图所示：

![http://localhost/u9/help/zh-CN/Content/PO/Model_443x296.jpg](https://ncc-pub-ublim.oss-cn-beijing.aliyuncs.com/help/photo/1dd0c706-7fe4-43a3-94b2-d01715b6f090.png)

**第4步**：进入本功能节点，选择**单据**为第三步中所查询出的业务对象。点击**查询**按钮，系统已预置了默认的查询条件及栏目，用户可以根据需要进行设置和修改，确定后显示查询结果。查询结果中可以显示业务单据及交易分录金额明细信息，核对是否正确。
