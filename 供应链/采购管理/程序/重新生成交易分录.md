
# 功能描述

查询各类业务单据已生成的交易分录。选择已经生成交易的业务单据，重新生成交易分录。

# 关键应用

# 业务规则

*  只能处理已经生成交易分录的业务单据；
*  对于手工修改过的交易分录，重新生成交易分录时，可以选择不覆盖已经手工修改的交易分录

# 栏目说明

|**栏目**|**说明**|
|---|---|
|**方案选择**|选择系统定义的查询方案做为批量生成分录的条件。|
|**增量生成**|交易分录后台会记录版本。如下变化，会导致版本发生变化：1、AAI模板变化2、科目模板变化3、业务单据变化选为“是”时，只对交易分录上版本发生变化的交易分录重新生成，以提高处理效率。默认为“否”|
|手工修改分录重新生成|交易分录上有[手工已修改]标记，用于记录交易分录是否手工修改过。选为“否”时，重新生成交易分录时不覆盖已经手工修改的交易分录。默认为“是”|

# 按钮说明

*  <查询>：用户输入需要生成交易分录的业务单据的查询条件。 具体操作参见【查询方案】说明；
*  <生成交易分录>

根据列表画面上所选择的单据生成交易分录。

并显示分录生成结果信息：本次处理的单据总数，成功处理单据张数，处理失败的单据张数以及处理失败的单据列表。

对于处理失败的单据，用户可以查找原因，重新生成交易分录。

**操作前提**

已经在列表中选择本次要生成分录的业务单据。可以选择一张，也可以选择多张。

**操作步骤**

点击程序－>批量生成交易分录－>查询按钮，进入查询条件画面。具体步骤如下所示：

第1步：输入生成易分发录的单据查询条件

第2步：在‘栏目’页签选择单据列表中需要显示项

第3步：选择完成后，点击‘确定’按钮，返回查询结果画面

第4步：在查询结果列表中选择需生成交易分录的单据记录，点击‘生成交易分录’按钮，系统自动生成相应的交易分录。

*  <批量生成分录>

用于根据查询方案，自动将符条件的未生成分录的单据，批量生成交易分录。

**操作前提**

已定义批量生成交易分录查询条件的方案

**操作步骤**

**第1步：**在查询结果单据列表界面中，点击‘批量生成分录’按钮，弹出界面中选择查询方案；

**第2步：**如果点击‘调度生成分录’，则弹出‘调度选择’界面；在‘调度选择’界面中选择调度方案，‘**确定**’后，系统根据定义的调度方案按查询方案自动生成交易分录。

**第2步：**如果点击‘生成分录’，系统按查询方案自动生成交易分录。

<查询错误报告>

*  由于在调度生成交易分录时，批量生成分录如果发生错误，不能及时告知用户。用户可以使用本功能查询执行结果，查看失败原因。
*  <交易分录> 查看交易分录
