
# 功能描述

采购系统费用性物料采购后产生的交易分录可以转入总账功能。

# 关键应用

*  可以将系统的交易分录转入总账系统生成记账凭证；
*  可以选择是否合并原始单据的交易分录生成记账凭证；
*  可以设定合并生成凭证的合并规则 可以批量生成总账凭证；
*  可以联查交易分录相关的总账凭证和业务单据。

# 业务规则

*  已经执行转总账功能，生成总账凭证的交易分录不允许重复生成；
*  交易分录执行转总账功能后，对应的业务单据将不允许修改；
*  在“转总账”功能中对已经转总账的交易分录，提供“删除凭证”功能，系统将删除交易分录生成的主账簿的凭证信息。如果系统有多币种账簿转到主账簿的凭证，也同时被删除；
*  如果交易分录所转主账簿已经做了月结，则不允许删除凭证；
*  各业务系统在做月结时，必须要将需要转总账的交易分录执行“转总账”处理；
*  总账系统对外部系统转来的凭证不允许执行删除或修改处理；

# 按钮说明

*  <生成凭证>：将列表上所选择的交易分录传递到总账并生成记账凭证。

**操作前提**

已经生成交易分录

**操作步骤**

进入转总账业务操作画面。具体步骤如下所示。

第1步：进入转总账单据列表画面，列表显示所有未转总账的交易分录；

第2步：在列表中选择本次需要转总账的交易分录，点击生成凭证按钮，弹出凭证生成画面；

第3步：在凭证生成画面中选择是否需要合并制单以及合并制单的条件；

第4步：点击生成凭证按钮，系统自动生成总账系统的记账凭证，并返回转总账列表画面，在凭证类别、会计期间和凭证号栏目显示生成的记账凭证信息；

第5步：可以通过追溯查询－>联查凭证、联查单据按钮查询当前交易分录所生成的记账凭证和与当前交易分录相关的业务单据。

*  <批量转总账>：用于根据查询方案，自动将符条件的交易分录批量传递到总账生成记账凭证。

**操作前提**

已定义批量生成交易分录查询条件的方案

**操作步骤**

进入转总账业务操作画面。具体步骤如下所示。

**第1步：**进入转总账单据列表画面，列表显示所有未转总账的交易分录；

**第2步：**点击**批量转总账**按钮，弹出批量转总账画面,选择查询方案；

**第3步：**在批量生成凭证画面中选择生成凭证的条件范围以及是否需要合并制单以及合并制单的条件；如果点击‘调度方案’，则弹出‘调度选择’界面；在‘调度选择’界面中选择调度方案，‘**确定**’后，系统根据定义的调度方案按查询方案自动生成交易分录;如果点击‘**确定**’，系统按查询方案自动生成交易分录。

**第4步：**系统根据批量生成条件，自动生成总账系统的记账凭证，在转总账列表画面，凭证类别、会计期间和凭证号栏目显示生成的记账凭证信息；

**第5步：**可以通过**追溯查询－>联查凭证、联查单据**按钮查询当前交易分录所生成的记账凭证和与当前交易分录相关的业务单据。

*  <删除凭证>

将列表画面上业务单据在总账系统的记账凭证删除处理。

**操作前提**

交易分录已经转总账生成记账凭证。

**操作步骤**

**第1步：**进入转总账单据列表画面，查询已经转总账的交易分录；

**第2步：**在列表中选中需要删除的凭证，点击**删除凭证**按钮；

**第3步：**系统将已经转总账的记账凭证删除。经过处理后，用户可以再次执行转总账处理。

*  <作废凭证>：将列表画面上业务单据在总账系统的记账凭证作废处理。作废后，原来的记账凭证仍然可以查询，是一种有痕迹的删除处理。

**操作前提**

交易分录已经转总账生成记账凭证。

**操作步骤**

**第1步：**进入转总账单据列表画面，查询已经转总账的交易分录；

**第2步：**在列表中选中需要作废的凭证，点击**作废凭证**按钮；

**第3步：**系统将已经转总账的记账凭证作废。作废后的凭证仍然可以查询，但不能进行任何业务处理。

*  <批量删除凭证>：可以选择多张凭证,将已经转总账的记账凭证进行批量删除处理。

**操作步骤**

**第1步：**，进入转总账单据列表画面，查询已经转总账的交易分录；

**第2步：**点击**批量删除凭证**按钮，弹出已经转总账的凭证列表，选择需要删除的凭证，执行批量删除处理；

*  <批量作废凭证>：可以选择多张凭证,将已经转总账的记账凭证进行批量作废处理。

**操作步骤**

**第1步：**进入转总账单据列表画面，查询出已经转总账的交易分录；

**第2步：**点击**批量作废凭证**按钮，弹出已经转总账的凭证列表，选择需要作废的凭证，执行批量作废处理；
