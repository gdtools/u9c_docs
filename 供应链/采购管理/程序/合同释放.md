
# 功能描述

本节点提供手动或系统自动将合同释放为采购订单，要求合同流程为“合同—合同下达—采购单”。

# 栏目说明

合同释放画面

|**栏目**|**说明**|
|---|---|
|合同号|需要释放的合同号|
|料品|需要释放的合同号料品|
|料品分类|需要释放的合同号料品分类|
|展望期|输入时只能输入非负整数|

# 按钮说明

*  <执行》

**概述**

选择合适的条件后，点击“执行”按钮手动执行本程序。

**操作前提**

存在需要释放的合同

**操作步骤**

点击**采购管理－>程序－>合同释放－>执行**按钮，可以进行执行操作

*  <调度>

**概述**

选择合适的条件后，点击“调度”按钮自动执行本程序。

**操作前提**

定义调度计划，可以在线新增

**操作步骤**

点击采购管理－>程序－>需求接口表处理－>调度按钮，可以进行调度操作。具体步骤如下所示。

第1步：点击按钮执行“调度”功能，系统自动弹出调度画面。

第2步：若本程序只执行一次，选择“执行一次”，录入执行时间。

第3步：若本程序需要重复执行，选择“重复一次”，参照录入调度计划，当前程序就可以按照调度计划定时执行本程序；
