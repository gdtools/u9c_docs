
# 功能描述

在采购业务发生前，先对可能的供应商发出询价单，对各供应商反馈回来的报价单进行比较，从而确定最优价格的过程。

# 关键应用

# 业务规则

*  定期询价：按一定周期进行询比价，比价结果保存在系统中，在该周期内每次的采购活动均采用该次比价结果，比较适合价格相对较稳定的物料
*  每次询价：每次采购业务发生之前均需要进行询比价，每次询比价的结果仅对本次采购业务有效，比较适合价格波动较大且频繁的物料
*  任意询价：对任意一个物料、请购单、需求接口表可展开询价；请购单、需求接口表有比价接受记录后可按比价结果转下游单据

**询价单行－报价页签**

本页签内容为供应商针对询价单返回的报价信息，只可通过“供应商录入报价”操作后才可以录入，否则只可以查看；

|**栏目**|**说明**|
|---|---|
|“厂商料品”分区||
|厂商料号|手工录入询价料品的供应商料号，可空|
|厂商品名|手工录入询价料品的供应商品名|
|报价厂牌|当前料品为厂牌管理时，要求必须录入“报价厂牌”；否则可空|
|“数量”分区||
|需求数量+计价单位|手工创建时可改，若自需求单据（PR／DI）带入，则不可改|
|累进方式|枚举值：
   *  **全额计算：**根据折扣的分段规则决定总交易数量落在哪个分段区间，总交易量均采用该分段区间所对应的折扣。 
*  **分层累进：**将总交易数量按照折扣的数量分段规则分成若干段，各段内的数量采用该分段所对应的折扣来计算交易额，然后将各段的交易金额累加起来.
**![http://10.16.226.26/U9/help/zh-CN/Content/Resources/Images/%E4%B8%BE%E4%BE%8B.jpg](https://ncc-pub-ublim.oss-cn-beijing.aliyuncs.com/help/photo/c5e3bab7-30a8-4668-9a89-db5d01cee65c.png)例如：**手机原价1000元，3-5台每台优惠100元，5台以上每台优惠200元，若客户购买10台，则在分层累进的计算方法下，交易金额为2*1000+3*(1000-100)+5*(1000-200)=8700；在全额计算的方法下，交易金额就是10*(1000-200)=8000|
|折扣类型|折扣的类型，枚举值：
   *  折扣率**：**表示打折后价格为原来价格的百分比；
*  单位折扣额：表示每计价单位的物料打折的金额（即扣减的单价金额）
*  一口价：表示每计价单位的物料的折后价格；
|
|采购价格|维护供应商对询价料品的报价价格；“累进方式”与“折扣类型”非空时表示供应商对当前询价料品的报价有折扣；点击链接可打开分段折扣录入画面，该画面操作[参见厂商折扣](http://10.16.226.26/U9/help/zh-CN/Content/SCM/PM/Function/CBO.SCM.MF3020_10.htm)|
|“其他”分区||
|商务条件|点击链接可打开“商务条件”卡片画面，维护供应商对询价料品报价时对应的商务条件；注意：单头商务条件非空时，询价单行上商务条件默认＝单头商务条件|

|报价英文货描|可空|
|报价备注|与“备注页签”的报价备注保持一致|

# 按钮说明

*  <批量生单－按物料供应商>：可选多个供应商多个物料，批量生成多个的单据；

操作步骤：点击采购管理－>询/比价－>询价－>批量生单－>按物料供应商，可以进行批量生单操作。具体步骤如下所示。

第1步：点击“批量生单”－>“按物料供应商”按钮，弹出物料供应商批量生单过滤画面。若[确定后刷新界面]选中时,询价单生单时询价批时自动获取系统时间；

第2步：批量生单过滤画面，根据需要选择过滤条件过滤来源单据：

选择录入询价信息，包括卡片头上询价批、价格含税、付款要求、支付币种等；

过滤条件：可以选择供应商信息、物料信息、交易信息，允许多选；

过滤范围:

询价类：选中此项表明将按询价类确定询价料品以及询价供应商

按货源表询价：选中此项表明将按照货源表确定料品的询价供应商

每次采购需询价料：选中此项表明所过滤出的询价料品对应料品档上定义为每次询价料

按价表过滤：选中此项表明将按照价表确定料品的询价供应商

第3步：点击“确定”按钮，进入物料供应商选择画面。

物料供应商选择画面中，选中本次需要转成询价单的料品与供应商，在记录前打“√”；

若对应询价类中规定允许直接增加供应商或料品对应询价类为空，可在供应商列表中增加供应商；

第４步：物料供应商选择画面点击“确定”按钮，批量生单完毕。

*  <批量生单－按请购单>：根据请购单批量生成询价单；

操作前提：存在请购单。

操作步骤：点击采购管理－>询/比价－>询价－>批量生单－>按请购单，可以进行批量生单操作。具体步骤如下所示。

第1步：点击“批量生单”－>“按请购单”按钮，弹出按请购单批量生单过滤画面。

第2步：批量生单过滤画面，根据需要选择过滤条件过滤来源单据：

按单据过滤：选择单号、日期、物料等，允许多选；

支持所有过滤条件同时进行过滤。

过滤范围：[包含正在询价记录]选中时在当前过滤数据中包含请购单行询价状态为正在询价的记录，否则不包含正在询价的纪录。

询价汇总维度：维护询价的汇总维度，支持按料品信息、加工件定义汇总维度。当“加工件”作为汇总维度后，相同委外件，不同加工件将分别询(比)价。询(比)价画面中显示“加工件料号”和“加工件品名”属性；询价单转比价单，加工件信息也带到比价单上，作为比价的维度。

其余同按物料供应商生单

第3步：点击“确定”按钮，进入物料供应商选择画面。

物料供应商选择画面中，选中本次需要转成询价单的料品与供应商，在记录前打“√”；

画面上端为“需求汇总”列表与“物料明细”列表，由系统根据料品对应的询价类自动汇总，“明细”列表可增删来源请购单行，修改后将重新汇总。

若对应询价类中规定允许直接增加供应商或料品对应询价类为空，可在供应商列表中增加供应商；

第４步：物料供应商选择画面，点击“确定”按钮，批量生单完毕。

*  <批量生单－按需求接口表>：基本同按请购单生单，只是询价来源为需求接口表；具体操作参见按请购单生单。
*  <批量生单－按定期程序>：若物料档中定义为定期询价料，可在此直接按定期询价规则生成询价单，不需要走程序调度。具体操作参见定期询价。
*  <供应商－供应商录入报价>：在询价单行“报价”页签录入供应商价格以及相关的商务条件。
*  <供应商－供应商状况查询>：查看当前供应商的财务状况以及最近业务发生日期。
*  <供应商－供应商交易查询>：查询供应商的历史交易订单。
*  <物料－料品状况查询>：可以查询料品状况查询。
*  <物料－产品结构查询>：点击采购管理－>询/比价－>询价－>产品结构查询
*  查询料品对应的产品结构，仅当料品为KIT/FAS/Model件时有效
*  所查询料品对应“物料页签”的BOM取值非空
*  <物料－物料交易查询>：可查询物料最近采购情况。
*  <物料－货源表查询>：可查询物料所对应的货源记录
*  <操作－整单关闭>：可以手工关闭当前询价单。关闭的询价单不可以进行任何操作。
*  <操作－行关闭>：可以手工关闭当前询价单行。关闭的询价单行不可以进行任何操作。
*  <操作－终止>：可以手工终止当前询价单。终止的询价单不可以进行任何操作。
*  <操作－批量录入报价>：支持针对某物料一次性录入各个供应商的报价。

进入画面时用户可输入询价批及物料信息查找询价单

批量录入卡片画面上列表显示所查询的询价批以及物料信息，在下列表中录入对应询价批、料品的供应商报价

在批量录入时，对于新增的行系统将创建一张“供应商返回报价”的询价单；删行时将删除对应询价单中的询价行

*  <操作－创建供应商档>
 
   *  仅针对询价单头供应商为“未建档供应商”时有效
   *  执行操作，将打开供应商画面，可在其中新增供应商档案对应未建档供应商
   *  在画面中确定返回询价单画面中，将用增加的供应商档案替换未建档供应商
*  <追溯查询－比价查询>：弹出列表画面，显示当前询价单所生成的比价单及比价单基本信息，点击列表中比价单号，可打开比价单卡片画面查看比价单明细内容。
