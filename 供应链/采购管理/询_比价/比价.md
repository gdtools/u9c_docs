
# 功能描述

在U9通过比价活动，将各供应商反馈回的价格进行比较，从而确定最优的采购价格，系统支持按多种因素排列组合进行排序处理，方便用户直观感受价格高低情况。

# 关键应用

# 业务规则

*  请购单或需求接口表支持按接受的比价结果生成采购订单
*  比价单支持无来源的手工创建，也支持来源于请购单、需求接口表与询价单
*  同询价，来源于请购或需求接口表的比价，可将需求数据汇总后再进行比价
*  已比价完成的询价单可再次参与比价
*  比价结果可“接受”或“备用”，并据此更新厂商价表
*  比价单支持审批

*  比价单体——商务条件页签画面

维护供应商对料品报价时所对应的商务条件；

所输入的商务条件仅是对供应商报价的描述，对后续采购业务无影响

比价行来源于询价单时，再此维护的“商务条件”将与对应询价单行上“商务条件”保持联动

若比价记录被接受且商务条件中的[承诺交期]非空时，请购单或需求接口表生成采购订单时，采购订单的交期默认等于商务条件上的[承诺交期]

*  比价单体——供应商页签画面

查看供应商基本信息，如编码、名称、联系人等信息，并维护料品的厂商料号、品名以及报价厂牌等信息。

# 按钮说明

*  <报表打印>：单击比价单工具栏按钮“报表打印”可弹出报表格式的打印模板，在此报表模板的“查询方案”处，还可以自定义显示栏目、顺序等信息；
*  <批量生单--按物料供应商>：

概述：可选多个供应商多个物料，批量生成多个的单据。

操作步骤：同询价单

*  <批量生单--按请购单>：

概述：根据需求接口表批量生成比价单。

操作前提：需求接口表中存在需求记录。

操作步骤：同询价单

*  <批量生单--按需求接口表>：

概述：根据请购单批量生成比价单。

操作前提：存在请购单。

操作步骤：同询价单

*  <批量生单--按询价单>：

概述：根据询价单生成比价单。

操作前提：询价单已审核

操作步骤：点击采购管理－>询/比价－>询价－>批量生单－>按询价单，可以进行批量生单操作。具体步骤如下所示。

第1步：点击“批量生单”－>“按询价单”按钮，弹出批量生单过滤画面。

第2步：批量生单过滤画面，根据需要选择过滤条件过滤来源单据：

输入过滤条件，包括料品、询价批、询价类等

已比价的询价记录：被选中，则列表中显示已比价完成的询价单行，选择该行，可对已比价的询价单行进行重新比价。

第3步：选中本次需要转成比价单的询价单行，在记录前打“√”。

第４步：点击“确定”按钮，批量生单完毕。

*  <转PO>：

概述：询价单处理完毕后需要下订单的单据，通过本功能直接将询价单对应的来源请购单或需求接口表自动转换为订单。

操作前提：比价单已经审核

比价单或者比价单的来源询价单的来源单据为请购单或需求接口表

操作步骤：点击采购管理－>询/比价－>比价－>转PO，可以进行转采购订单单操作。具体步骤如下所示。

第1步：选择表头的【来源单据】，系统根据所选来源单据在列表中显示可转采购订单的来源单据行；注意：当来源单据中既包含请购单也包含需求接口表时，需分别选择【来源单据】，分别进行转单.

第2步：可修改【PO单据日期】，所修改的值将作为采购订单的单据日期

第3步：点击“设置”按钮可以对分单参数、分单条件、合行条件进行设置，支持按扩展字段分单或合行。

第4步：在列表中选中本次需要转成采购订单的记录，在记录前打“√”

第4步：可以修改转PO数量1，若是双数量，可以修改转PO数量2。

第6步：“点击“确定”，转采购订单操作完毕。

*  <供应商--供应商状况查询>：查看当前供应商的财务状况以及最近业务发生日期。
*  <供应商--供应商交易查询>：查询供应商的历史交易订单
*  <物料--料品状况查询>：可以查询料品状况查询
*  <物料--产品结构查询>：
*  查询料品对应的产品结构，仅当料品为KIT/FAS/Model件时有效
*  所查询料品对应“物料页签”的BOM取值非空
*  <物料--物料交易查询>：可查询物料最近采购情况
*  <物料--货源查询>：可查询物料所对应的货源记录
*  <历史价格查询>：可查询物料历史采购订单价格
*  <操作--更新厂商价表>：对价表进行修改，可区分成两种方式，在操作中只能选择一种方式进行，不能两种方式同时进行

方式一：生成一张新价表

方式二：生成一张已审核的调价单，由调价单可自动更新“指定价表”。

操作前提：比价单已审核

界面栏目

|**栏目**|**说明**|
|---|---|
|勾选|我们将在列表中列出可允许更新或生成价表的比价单行，已生成价表的比价单行不允许再次生成价表|
|指定价表|方式一，在此指定需要调价的价表|
|调价单号|方式一，若已定义调价单号自动编号，可空；否则手工输入调价单编号|
|新价表编号|方式二，生成价表，手工输入生成新价表的编号|
|新价表名称|方式二，手工输入生成新价表的名称|

*  <操作--创建供应商档>：
*  仅针对询价供应商为“未建档供应商”时有效，
*  执行操作，将打开供应商画面，可在其中新增供应商档案对应未建档供应商
*  在画面中确定返回询价单画面中，将用增加的供应商档案替换未建档供应商
