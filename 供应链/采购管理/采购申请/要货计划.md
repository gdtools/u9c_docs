
# 功能描述

进入采购管理－>采购申请－>要货计划，打开要货计划画面：

要货计划是采购方发布的对未来某段时期内可能需要采购料品的一种数量型承诺与远期预测的混合体。

# 关键应用

# 业务规则

*  系统可自动生成或手工新增要货计划，并发布至供应商门户；
*  采购方可查询指定期间内料品的供应商确认数量、累计执行数量等信息；
*  供应商可在供应商门户上对要货计划进行确认，方便采购方及时了解供应商的供货能力，据此调整采购策略

# 栏目说明

初始进入画面，系统打开查询条件画面，用户在其中输入期间、供应商等条件，系统按指定条件将查询结果显示在要货计划画面中。

**表头画面**

|**栏目**|**说明**|
|---|---|
|供应商与物料|不可改，自查询条件画面带入|
|期间数据|不可改，自查询条件画面带入|

**表体画面**

要货计划表体中黄色区域表示当前期间为锁定期,该期间的数量均不可修改，处于锁定期外且数量类型为修订的栏目允许编辑。

|**栏目**|**说明**|
|---|---|
|要货方|不可改，系统维护|
|物料|不可改，系统维护|
|单位|不可改，系统维护|
|数量|根据要货方与物料查询的要货数量,区分为以下类型：修订：表示查询期间的[修订要货量]，非锁定期间查询期间内，数据允许修改发布:表示查询期间的[发布要货量]确认:表示供应商在门户上的所确认可以供应的数量,供应商在门户中可对确认数量进行修改执行:表示查询期间的[累计发货量]或者[PO累计核准量]差异:表示查询期间的供应商确认数量与执行量之间的差值累差:表示查询期间的[累计差异]，累积的期数由货源表参数[累计差异有效期数]决定|
|查询期间|根据查询条件中确定的查询期间|

# 按钮说明

*  <操作—转订单>：

点击采购管理－>采购申请－>要货计划－>操作－>转订单，

可以将所选择的单元格，在锁定期内的已经进行供应商确认完毕的要货计划转订单。

注意，此时最多只能选定一个单元格

*  <操作—批量转订单>：

点击采购管理－>采购申请－>要货计划－>操作－>批量转订单，可以将所选择的在锁定期内，已经进行供应商确认完毕的要货计划批量转订单；

*  <操作—明细查询>：

点击采购管理－>采购申请－>要货计划－>操作－>明细查询，可以打开要货计划卡片画面。

点击采购管理－>采购申请－>要货计划－>新增，系统打开空白要货计划卡片画面，用户可在其中手工新增要货计划

*  <操作—发布>：

点击采购管理－>采购申请－>要货计划－>操作－>发布，可以将当前要货计划列表中的内容发布到供应商门户上。供应商可在门户中查询采购方的要货量

*  <查询>：

点击采购管理－>采购申请－>要货计划－>查询，可以选择条件查询要货计划

*  <追溯查询—订单追踪>：

点击采购管理－>采购申请－>要货计划－>操作－>订单追踪，可以查看要货计划卡片执行情况。
