
# 功能描述

系统提供对请购单的合并分割处理，可以分别针对需求提出方、采购方从不同的角度来审视请购信息。

# 关键应用

*  系统中存在请购单据数据（必做）
*  要合并分割的请购单，未转采购/需求接口，未关闭、挂起、取消

# 业务规则

*  通过分割合并将原有的PR行进行重新组合，行成新的PR单
*  分割合并后原PR将关闭，不再执行。

# 按钮说明

*  <查询>：选择需要合并分割的请购单，点击采购管理－>采购申请－>请购单分割/合并－>查询，可以设置查询条件重新查询请购单；
*  <设置>：选择需要合并分割的请购单，点击采购管理－>采购申请－>请购单分割/合并－>设置，可以设置合并分割的参数；
*  <合并分割>：选择需要合并分割的请购单，点击采购管理－>采购申请－>请购单分割/合并－>合并分割，根据设置参数自动生成新的请购单。
