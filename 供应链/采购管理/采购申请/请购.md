
# 功能描述

采购申请单是采购需求的主要来源之一，是使用部门或计划部门根据采购计划或物料需求，向采购部门提出申请采购的单据；申请单经过相关部门审核后，才能进行采购。

# 关键应用

*  对于需要进行请购的物料，可以通过本节点创建请购单进行请购
*  可以手工创建或从需求接口表生成；
*  在请购单环节，系统还可以进行预算保留、预算执行等操作
*  可将PR提交询价、转PO（可逐行）处理；
*  系统还提供对请购单的合并分割处理

# 业务规则

*  请购单转采购后，根据允许超额请购控制是否可超量转采购；
*  非审核态请购可分割合并；
*  请购单指定建议供应商，转采购默认取建议供应商；
*  请购单转采购后，不可弃审
*  请购单终止后，不可取消终止

# 按钮说明

*  <快速生单-快速录入>：可按物料多选录入请购单；
*  <快速生单-按物料清单请购>：可按物料清单录入请购单，通过指定母项料品或BOM，指定母项的数量、展开阶数等信息，自动展开其中可采购的料品到单据上进行请购；
*  <批量生单>：可选多个来源单据，批量生成多个的单据
*  <转PO>：本功能能够将当前请购单直接转采购订单
*  <拆分>：请购单的物料，需要部分使用替代品，那么原来的行可以进行拆分操作，拆分结果是由一行变成两行，原料品和替代品两行。
*  <库存查询>：可以查询料品所在仓库的库存状况，包括库存可用量、库存量、预留量、当前预留量、预留占用量等信息
*  <物料—货源查询>：可以查询当前物料的货源情况；
*  <物料—料品状况查询>：可以查询料品状况查询；
*  <物料—配置>：可以查询配置清单；
*  <物料—产品结构查询>：可以查询产品结构查询；
*  <物料—替代>：单据中的物料可以使用替代品，通过本功能进行物料的替代操作
*  操作前提：

定义替代料品：在物料主档点击“后续处理”按钮的“料品关系”定义替代料品（“关联类型”＝“替代料品”）。具体操作参加物料主档。

*  操作步骤：

第1步：选择某行，点击物料－>替代按钮，弹出替代画面。

第2步：替代画面列出替代品。

第3步：选择替代品，点击“确定”按钮，返回请购单主画面。

第5步：保存请购单，替代完毕。

*  <物料—预算保留>：请购单可以对财务预算进行预算保留操作，

本功能可以：设置请购单预算保留；查询预算保留；取消当前订单预算保留；

*  操作前提：

启用总帐模块，且存在当前账簿当前会计期间的预算数据。

*  操作步骤

第1步：点击需要预算保留的行，再点击“预算保留”按钮，系统自动弹出预算保留画面；

第2步：列表中选择录入“摘要”、“预算控制对象”、“预算专项”、“预算控制周期”；

第3步：录入预算保留金额。

第4步：点击“保留查询”，可以查看预算保留详细信息

第5步：点击“取消保留”，可以取消当前请购单上的预算保留。

第6步：点击“确定”按钮，返回请购单主画面。

第7步：保存请购单，预算保留操作完毕。

*  <物料—历史价格查询>：可以查询当前物料的历史采购价格情况
*  <操作—整单关闭>：

可以手工关闭当前请购单。关闭的请购单不可以进行任何操作，只能通过“整单打开”操作将单据打开

*  <操作—行关闭>：可以手工关闭当前请购单行。

关闭的请购单行不可以进行任何操作，只能通过“行打开”操作将单据行打开

*  <操作—整单打开>：可以打开手工关闭的请购单
*  <操作—行打开>：可以打开手工关闭的请购单行
*  <操作—挂起>：请购单由于某种原因需要将单据挂起，等待问题解决后再解除挂起。
*  操作前提：定义挂起原因
*  操作步骤：点击采购管理－>采购申请－>请购－>操作－>挂起按钮，可以进行挂起操作。具体步骤如下所示。

第1步：点击按钮执行“挂起”功能，系统自动弹出挂起画面。

第2步：选择挂起原因

第3步：点击确定，挂起完毕，可以在状态弹出画面中查看挂起情况；

*  <操作—解除>：请购单由于某种原因需要将单据挂起，等待问题解决后再解除挂起。
*  操作前提：定义解除原因，解除原因要与挂起原因关联起来。
*  操作步骤：

点击采购管理－>采购申请－>请购－>操作－>解除 按钮，可以进行解除操作。具体步骤如下所示。

第1步：点击按钮执行“解除”功能，系统自动弹出解除画面。

第2步：选择解除原因

第3步：点击确定，解除完毕，可以在状态弹出画面中查看解除情况；

*  <操作—终止>：可以手工终止当前请购单
*  <操作—批量删除>：可以对请购单行进行批量删除。第一次点击时行号前显示复选框按钮，第二次点击时删除勾选的行；此勾选记录针对请购单其他操作无效
*  <操作—可用量查询>：可以将请购单行料品的库存可用量及查询库存的时间显示在行上
*  <操作—预算执行>：可以根据PR预算模板将当前PR数据纳入预算控制体系，并查看预算执行结果
*  <操作--发布采购云>：请购单审核后，点击发布到友云采，系统将请购单中需要询价料品的请购单行发布到友云采系统的采购需求中。请购单的一行对应友云采系统中的一张采购需求单。在友云采系统询价完成并采购定标后，友云采系统的采购订单会自动同步U9系统的采购订单
*  <追溯查询—业务执行>：可以查询当前请购单后续业务执行情况，包括询比价，采购，收货
*  <追溯查询—采购订单查询>：可以查询当前请购单后续采购订单情况
*  <追溯查询—整单预算执行>：可以查询当前请购单整单预算执行情况
*  <追溯查询—询价单查询>：可以查询当前请购单后续询价单情况
*  <追溯查询—比价查询>：可以查询当前请购单后续比价单情况
*  <追溯查询—全程追溯>：可以查询请购后所有关联业务单据执行情况
*  <相关功能—标准采购>：导航到标准采购节点
*  <相关功能—标准收货>：导航到标准收货节点
*  <相关功能—供应商>：导航到供应商节点
*  <相关功能—料品>：导航到料品节点
*  <相关功能—料品数量状况>：导航到料品数量状况
*  <相关功能—下载PLM文档>：弹出下载PLM系统文档，可下载
