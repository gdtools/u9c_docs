
# 功能描述

对于集中展示其他系统、组织产生的，而需要本组织进行采购处理的原始需求。

# 关键应用

*  由第三方产品导入的采购需求，必须放在采购需求接口表中等待处理。
*  由其它组织/工厂传来的需要当前组织处理的采购需求，可根据企业对MRP的应用层次来决定

# 业务规则

*  外系统导入的采购需求；
*  本系统其它组织/工厂传来的需求处理的采购需求
*  采购需求转[采购订单]时，会受系统中的“供应商采购配额”的影响

# 按钮说明

*  <转采购>：调用查询条件界面，重新设置查询条件，进行新的查询；
*  <全部转采购>：点击<凭证>按钮，查询光标所在行凭证；
*  <查询>：可切换显示中、英文科目名称。前提需要在科目表中定义英文科目名称，否则切换的结果为空。
*  <回绝—原组织自行采购>：

可以回绝需求接口表记录。不支持来源请购单转出组织不唯一的情况下进行此业务。已经回绝的记录在回绝组织不能继续生单业务，可以在原组织继续生单。仅回绝勾选的记录，对未勾选的记录不做处理

*  <回绝—来源组织和料回绝>：

可以回绝需求接口表记录。已经回绝的记录不能继续生单业务。

当回绝某一行时，与该行物料信息相同、来源组织相同的其它所有行且未处理的均一同回绝

*  <回绝—按料回绝>：可以回绝需求接口表记录。

已经回绝的记录不能继续生单业务。当回绝某一行时，与该行物料信息相同的其它所有行且未处理的均一同回绝

# 操作说明

# 应用举例

**[例如]**

*  长采购周期的海外采购件的需求处理

通常海外采购的周期会比较长（大于总装提前期），视情况一般在1-3个月间；

如果通过跑MRP或通过MO下达时才产生此类海外采购件的需求，就会来不及了；

通常的做法是把此类海外采购件的计划属性设置为MPS，在运行MPS产生出计划订单后，可直接将此类海外采购件的计划订单通过MO（先释放成MO）释放为海外采购单；

企业中通常还会有一些委外加工件，因加工周期比较长，需要提前下达委外加工订单。此类加工件的外协订单也可在MPS阶段对计划订单通过MO（先释放成MO）进行释放，形成委外加工采购单；

还有一种情形是，对MPS的结果进行粗能力平衡后，企业可能会将自身无法满足的部件进行外协生产。

*  相关需求的处理

相关需求是指MRP跑出来的需求；

独立需求的处理；

这里的独立需求指企业中的办公用品、生产用辅材（无法体现在BOM中）、备品配件、劳保用品等；

此类物料的需求通常是以“再订货点”、“上下限”、“盘点再补货”来产生净需求。在U9系统中，运行库存规划系统可以计算出此类物料的需求。
