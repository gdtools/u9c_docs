
# 功能描述

适用于关系企业协同或者多角贸易时公司间单据协同

可以将向关系企业采购的采购订单批量生成关系企业的销售订单。

# 业务规则

# 栏目说明

进入采购管理－>采购－>订单批量抛转，其主要功能：

|**栏目**|**说明**|
|---|---|
|选择框|可多选|
|其他数据项|PO单据信息,只可查看,不可修改|

# 按钮说明

*  <查询>：点击界面中的**[查询]**按钮，可以定义查询方案，包括查询条件、栏目及排序。具体操作参见查询方案
*  <抛转>

**概述**

可以将选择的采购订单抛转生成关系企业销售订单。

**操作前提**

系统中存在向关系企业采购的采购订单且已审核

**操作步骤**

采购订单批量抛转，具体步骤如下所示。

第1步：进入“批量抛转”列表；

第2步：在列表中选择需要抛转的订单；

第3步：点击“抛转”按钮；即可将选择单据抛转生成关系企业的销售订单。

*  <设置>

点击界面中的**[设置]**按钮，可以设置是否[显示生成单据]。
