
# 功能描述

可以将采购单进行分割合并。

# 关键应用

# 业务规则

*  分割的采购订单未关闭，未挂起，未终止
*  相同供应商采购订单可合并

# 栏目说明

同标准采购订单：

采购单分割/合并－上列表

|**栏目**|**说明**|
|---|---|
|欠交数量|订单未交货数量|

# 按钮说明

*  <过滤>

选择需要合并分割的采购订单，点击**采购管理－>采购－>采购订单分割/合并－>过滤**，可以设置过滤条件重新查询采购订单。

*  <设置>

选择需要合并分割的采购订单，点击**采购管理－>采购－>采购订单分割/合并－>设置**，可以设置合并分割的参数。

*  <整单分割>

选择需要合并分割的采购订单，点击采购管理－>采购－>采购订单分割/合并－>整单分割，

一单多行的时候，可以将整张采购订单的多行数据自动从上列表带到下列表进行分割操作。

*  < 分割合并>

**概述**

可以将采购单进行分割合并。

**操作前提**

系统中存在采购订单

**操作步骤**

采购单分割合并，具体步骤如下所示。

第1步：进入“采购单分割/合并列表”列表；

第2步：在上列表中选择需要分割的订单计划行，双击，

第3步：在下方列表中出现已经选中的内容，若当前单据有其他计划行需要加入到下方列表进行合并分割的，请点击“整单分割”按钮；

第4步：手工调整“要求交货日期”和“计划到货数量”，回车后，会新增新行。

第5步：调整新行“要求交货日期”和“计划到货数量”，可以新增多行

第6步：点击“分割合并”按钮，分割合并操作完毕。
