
# 功能描述

进入采购管理－>采购－>借入采购 ，可以查看借入转采购订单，本订单由借入单转采购生成。

# 关键应用

# 业务规则

*  借入转采购订单无需收货，订单立账；
*  借入采购订单不可手工录入；

# 栏目说明

无交货信息，无交期，无计划行；

栏目说明内容同标准采购订单，下边的描述的是与标准采购订单差异之处：

**采购订单头－基本页签**

|**栏目**|**说明**|
|---|---|
|来源类型|默认值＝借入单|
|来源单据|显示借入单号|

**采购订单头－商务页签**

|**栏目**|**说明**|
|---|---|
|价格含税|**借入采购**订单，“价格含税”属性可改|
