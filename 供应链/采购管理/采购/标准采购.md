
# 功能描述

采购订单是企业为购买商品或劳务，与供应商签定的具有法律效力的单据，主要内容包括采购什么货物、采购多少、由谁供货，什么时间到货、到货地点、运输方式、价格、运费等。

# 关键应用

*  标准采购
*  VMI需求补货

# 业务规则

*  采购订单创建的时机为请购转采购，同时支持一张请购单生成多张采购单；
*  系统支持跨组织的采购业务，既可以处理当前组织的请购，也可以处理其他组织的请购；
*  采购订单支持供应商确认；
*  采购订单可以作为供给方对各类需求进行预留；
*  可以进行版本管理，记录多次订单修改纪录；
*  可以进行预算保留；
*  支持全面预算控制 ；
*  在采购单环节还可以处理预付款业务；
*  支持费用的预估及分摊处理，并保留费用分摊的痕迹；
*  支持对项目任务的管理；
*  支持赠品的处理；
*  支持多币种的采购业务；

## 损益结转凭证

依据账簿参数“本年利润结转方法”生成结转凭证:

*  账结法：每月生成损益结转凭证；
*  表结法：1~11月不生成损益结转凭证，结账检查时判断通过检查，12月生成损益结转凭证。

***注意：根据是否执行损益结转任务判断结账检查是否通过。若当月无数据生成凭证，结账检查时仍判断通过检查。***

### []()一键整理凭证号

**方法二（没有场景时，直接描述功能，如档案）**

*【对于有些节点的内容可以很系统的描述的，就可以使用此方案进行编写，编写规则如下：】*

*  单击主菜单中的<设置>，然后单击设置菜单中的“定义核算对象”，进入过滤界面；
*  过滤条件中下拉选择“成本对象类型”，主要分为“基本成本对象”、“计划成本对象”、“实际成本对象”，未选择时，默认显示“实际成本对象”
 
   *  基本成本对象：主要应用范围为“设置”部分—定义分配率_产品权重系数；
   *  实际成本对象：主要应用范围为“期初余额调整”、数据录入各表、成本计算、报表、预测、分析、凭证处理，可以按期间查询各历史实际成本对象，按品种核算，如果是多成本中心生产，系统目前仅刷新出一个成本中心的成本对象，可以批量选择该成本中心实际成本对象记录行，然后点“增加成本对象”按钮，系统可以在现有成本中心下生成另外成本中心下的实际成本对象（不需要再物料清单子件设置多个领料部门完成多部门核算的业务）；如果该类实际成本对象未被录用表引用，可以通过“删除成本对象”删除自行增加的计划成本对象；
   *  计划成本对象：主要应用范围为“设置”部分—定额管理、计划成本部分
   
      *  如果是多成本中心生产，按订单核算需要提前制定相应定额工时或按品种核算无法制定多成本中心的计划成本对象，可以先选择相应计划成本对象，然后点“增加成本对象”按钮，系统可以在先有成本中心下生成另外成本中心下的计划成本对象；如果该类计划成本对象未被录入表引用，可以通过“删除成本对象”删除自行增加的计划成本对象；
      *  如果是非成本中心生产，且选项中选择“核算订单成本”或成本中心选择“按订单核算”或“按工序核算”，也不需要提前制定相应定额工时、计划成本，可以不需要再物料清单中制定领料部门，系统自动按生产订单中生产部门同步计划成本对象部门。
*  过滤条件中下拉选择“成本对象状态”，主要分为“启用”、“停用”、“全部”，未选择时，默认仅显示“启用”状态的成本对象；
*  确定后，进入点击界面中的“刷新成本对象”按钮，可得到最新的产品信息。

***注意：根据是否执行损益结转任务判断结账检查是否通过。若当月无数据生成凭证，结账检查时仍判断通过检查。***
