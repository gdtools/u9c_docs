
# 功能描述

针对采购管理模块，核准后不可改采购订单修改。

# 关键应用

# 业务规则

*  核准后可改：订单对应单据类型上参数【核准后可改】＝真时，表示订单已经审核后，订单内容也可修改，但修改的内容受订单实际执行情况的制约。例如，订单订货数量为１００，实际收货数量为４０，则修改订货数量时不得小于实际收货数量。
*  核准后不可改： 订单对应单据类型上参数【核准后可改】＝假时，表示订单审核后，内容不可进行修改。若要变更，必须填写订单变更单，变更单审核通过后更新采购订单。注意：通过变更单修改采购订单时，同样受订单实际执行情况的制约。

# 栏目说明

**采购订单变更单单头——基本页签画面**

录入或显示变更单的基本信息，如单号、日期、变更原因等基本信息

|**栏目**|**说明**|
|---|---|
|单据类型|非空，需要选择不同的单据类型；**![http://10.16.226.67/U9C/help/zh-CN/Content/Resources/Images/%E6%B3%A8%E6%84%8F.jpg](https://ncc-pub-ublim.oss-cn-beijing.aliyuncs.com/help/photo/d40449bd-2293-4d5f-a50e-2118f96f08e9.png)注意　:**请在使用前维护好单据的[单据类型](http://10.16.226.67/U9C/help/zh-CN/Content/SCM/PM/Function/CBO.SCM.MF2040_10.htm)。|
|单号|变更单单号|
|变更订单|非空，指定当前变更单需要修改的订单；链接可查看变更前订单卡片画面|
|日期|变更单单据日期|
|第几次变更|系统维护，表明当前变更单对订单的第几次变更|
|变更原因|手工维护|
|更新订单版本|指定当前变更单审核更新订单时是否生成新版本订单|
|状态|点击链接可打开状态画面，变更单具有以下几种状态：
   *  开立；
*  核准中：指已经提交，但尚未完成核准；
*  已核准：指单据通过核准；
|

**变更单行**

变更单行页签是根据订单变更内容自动组装的，只有存在对应的变更，变更行页签才显示，初始进入变更单时，变更单行为空； 变更单行页签包括：订单头变更、订单行变更、订单计划行变更、费用行变更、折扣行变更、税明细变更、订单地址变更、订单联系人变更、订单选配变更、订单备注变更 。![http://10.16.226.67/U9C/help/zh-CN/Content/Resources/Images/%E4%B8%BE%E4%BE%8B.jpg](https://ncc-pub-ublim.oss-cn-beijing.aliyuncs.com/help/photo/c5e3bab7-30a8-4668-9a89-db5d01cee65c.png)例如：修改订单头上供应商以及订单行上料品数量，则变更单行上包括两个页签：订单头变更与订单行变更；以此类推

|**栏目**|**说明**|
|---|---|
|变更类型|系统维护，表明当前订单是修改、新增还是删除|
|变更|对于“变更类型”是订单修改时有效，此时，变更单行上对应为“变更前”、“变更后”行，分别展示订单修改前后的内容|
|变更栏目|变更栏目是由系统根据“方案”设置中的内容显示，具体设置参见下文|

# 按钮说明

*  <变更>

**概述**

打开对应订单卡片画面，修改订单

根据当前变更单查看变更后订单内容；

**操作前提**

变更单头“变更订单”栏目非空

当前变更单未审核

**操作步骤**

点击采购管理－>采购订单－>采购订单变更单－>变更，可以打开需要变更的订单卡片画面。具体步骤如下所示。

第1步：根据需要对订单内容进行修改。

第2步：在订单卡片画面中执行保存操作，我们会关闭订单卡片画面，返回变更单画面，并根据所修改内容重新生成变更单；

第3步：在变更单中执行“保存”操作，保存对订单的变更

*  <方案>

**概述**

我们目前支持订单头变更、订单行变更、订单计划行变更、费用行变更、折扣行变更、税明细变更、订单地址变更、订单联系人变更、订单选配变更、订单备注变更 。用户可根据需要设置或修改对应变更单行页签所显示栏目；

**操作前提**

无。

**操作步骤**

点击采购管理－>采购订单－>采购订单变更单－>方案，弹出方案设置画面。

我们目前支持订单头变更、订单行变更、订单计划行变更、费用行变更、折扣行变更、税明细变更、订单地址变更、订单联系人变更、订单选配变更、订单备注变更 。用户可根据需要设置或修改对应变更单行页签所显示栏目

可在列表中增加、删除、上移、下移栏目，参见公共操作[查询方案](http://10.16.226.67/U9C/help/zh-CN/Content/PO/PO.Query.htm)

始终显示变更项：勾选该选项，对于默认在栏目中未选择的变更的项目，订单变更后也显示在变更单行对应页签中

注意，不同于公共操作，整个变更单只支持一份方案。

*  <订单变更历史>

概述

显示变更单对应订单的变更历史

*  < 追溯查询>

概述

查询当前变更单所对应订单的执行情况，具体操作同[采购订单。](http://10.16.226.67/U9C/help/zh-CN/Content/SCM/PM/Function/SCM.PM.PM5010_10.PM5010.htm)
