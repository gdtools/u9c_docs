
# 功能描述

采购合同主要适用于采购工业性产品（非消费类产品）的企业，与上游供货商签订的一揽子订单或年度性采购意向协议。

# 关键应用

*  支持工作流配置；
*  价格合同、数量合同、金额合同、或它们之间的组合；
*  合同直接收货。注：合同的“流程类型”需要设置为“合同—收货单”
*  参照合同生成请购单或采购单。注：合同的“流程类型”需要设置为“合同—请购单/采购订单”
*  自动定期释放出有固定数量和交期的合同为采购单。注：合同的“流程类型”需要设置为“合同—合同下达—采购单”
*  MRP释放采购订单时，可以自动扣减相应的合同。 注： 不需要设置，系统会自动执行。

# 业务规则

*  数量、金额类合同，随着执行数的增加，当达到合同数时，合同会自动关闭。
*  合同的数量金额可以设置容差范围。
*  合同生效后不支持变更。如果有变更，需要终止当前合同，重新签定新的合同。
*  合同中的价格、数量等对后续业务是否严格控制，可以在合同类型中设置。

# 应用举例

*  价格合同： 即合同上确定料品的采购价格，合同执行时按约定的价格结算。

价格合同又分两种定价方式：

（1）合同上明确约定料品的单价。这种情况常见于价格变化比较少、或一年定一次价的产品。如5号铁矿石的2006年的采购价为70美元/吨，在合同约定的时间范围内，都按此价格进行结算。

（2）合同不约定料品的具体价格，只约定企业所适用的价格类型（即指定厂商价表）。合同执行时，按该价格类型当时的即期价格定价。这种情况常用于价格不是很稳定的产品的采购。

*  数量合同： 即合同上约定向供应商采购的数量。

数量合同又分两种：

（1）合同上只约定向供应商采购的总数量，不约定具体供货日期或间隔周期。如2006年度将向宝钢采购5000吨轧钢。此类合同适用于货物特别紧俏、价格波动异频繁的形情，双方只能约定保证供应多少数量，具体价格则随行就市。

（2）合同上约定供应商每次向我方供货的数量及供货间隔周期（分批交货合同）。如2006年度宝钢每隔一个月就向我方提供400吨轧钢。此类合同有明确的数量和交期。

*  金额合同： 即合同上约定向供应商采购的总金额。

这种情况常见于年度供货协议，如苏宁与格力签订的2006年度空调采购合同，约定2006年苏宁向格力采购20亿的空调机。

*  其它：

合同可不与供应商约定具体的供货料品，而作为年度性交易协议存在。如只与供应商约定当期交易的结算条款（立账条件和付款条件等）、预付款条件、供货周期等等。合同核准后，这些交易协议将会被更新到U9的相关档案中。
