
# 功能描述

在此可以查询一段时期内的采购订单情况；可以追溯查询请购单的相关处理情况（例如收货，立账等情况）；

# 关键应用

# 业务规则

*  查询条件可以自定义（通过属性选取设置），采购订单上的每一个字段都可以作为查询条件；
*  默认查询结果为按采购订单显示每单的请购状况；

# 栏目说明

*  采购订单汇总查询

按采购单显示每一个采购单的情况；

*  行明细记录查询

按采购单显示每一行的采购信息；

*  计划行明细查询

按采购订单计划行显示具体的采购交期信息；

*  收货明细查询

显示采购订单的收货信息；

# 按钮说明

<查询>：定义采购订单查询的条件和栏目

<财务执行状况>：可显示采购订单的财务执行状况，比如立账信息、匹配信息等；
