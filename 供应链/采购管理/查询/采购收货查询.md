
# 功能描述

*  在此可以查询一段时期内的收货单情况；
*  可以追溯查询收货单的相关处理情况（例如立账情况）；

# 关键应用

# 业务规则

*  查询条件可以自定义（通过属性选取设置），收货单上的每一个字段都可以作为查询条件；
*  默认查询结果为按收货单显示每单的收货状况；

# 栏目说明

*  <收货单汇总查询>

按收货单显示每一单的情况；

*  <明细记录查询>

按采购单行显示每一行的收货信息；

# 按钮说明

*  <查询>：调用查询条件界面，重新设置查询条件，进行新的查询；
*  <执行-去向状况>：导航到收货去向状况查询；
*  <执行-财务执行>：导航到财务状况查询
*  <执行-预计收货>:导航到预计收货查询
*  <相关功能-采购订单>:导航到采购订单
*  <相关功能-采购收货>：导航到采购收货单
*  <相关功能-采购退货>：导航到采购退货单
