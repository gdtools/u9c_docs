
# 功能描述

*  在此可以查询一段时期内的请购单情况；
*  可以追溯查询请购单的相关处理情况（例如下订单情况）

# 关键应用

# 业务规则

*  查询条件可以自定义（通过属性选取设置），请购单上的每一个字段都可以作为查询条件；
*  默认查询结果为按请购单显示每单的请购状况；

# 栏目说明

*  请购单汇总查询

按请购单显示每一个请购单的情况；

*  明细记录查询

按请购单显示每一行的请购单行信息；

*  执行单据信息

显示请购单转订单的情况；

*  追溯单据查询

显示请购单来源单据信息

# 按钮说明

*  <查询>：调用查询条件界面，重新设置查询条件，进行新的查询；
*  <预算保留>：查询选中请购单预算保留信息；
