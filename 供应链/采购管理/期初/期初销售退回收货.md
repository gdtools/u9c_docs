
# 功能描述

系统初始上线时，需要将此前已收退回货物,但是未开红票给客户的记录录入系统中，以便在系统上线后做销售退回处理。

# 关键应用

# 业务规则

*  “快速收货”、“批量生单”功能不可用。

# 栏目说明

*  栏目说明内容同【销售退回收货】;
*  以下描述是与销售退回收货单不同之处:

|**栏目**|**说明**|
|---|---|
|退货类型|只能为接收并退款|
|单据日期|不得晚于销售管理模块系统启用日期|
|序列号|不能维护序列号|
|记账期间|根据单据日期确定,不可维护|
|批号|批号相关规则，不可用|

# 按钮说明

*  参见销售退回收货
*  “快速收货”、“批量生单”功能不可用。
