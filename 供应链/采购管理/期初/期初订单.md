
# 功能描述

系统初始上线时，需要将此前部分还未执行完的采购订单录入进系统中，以便在系统上线后也能记录下这些订单并对其进行控管。

期初订单用于期初订单录入。

# 关键应用

# 业务规则

*  期初订单不做数据合法性的校验，请用户确保数据的正确性；

# 栏目说明

栏目说明内容同标准采购订单，下边的描述的是与标准采购订单差异之处：

采购订单行－执行页签

|**栏目**|**说明**|
|---|---|
|累计实收数量1|在标准订单中，该字段为系统回写的字段，只能看不能改，在期初订单中把字段放开，在画面上直接录入栏目值（不能点开链接录明细，只能录汇总值）。|
|累计实收数量2|同上|
|累计立帐数量(计价单位)|同上|
|累计立帐价税合计（核算币种）|同上|
|累计立帐未税金额（核算币种）|同上|
|累计立帐税额（核算币种）|同上|
|累计匹配数量（计价单位）|同上|
|累计匹配未税金额（核算币种）|同上|
|累计匹配税额（核算币种）|同上|
|累计匹配价税合计（核算币种）|同上|
|累计付款数量（计价单位）|同上|
|累计付款金额(核算币种)|同上|
|已执行预付数量（采购单位）|同上|
|已执行预付金额（核算币种）|同上|
