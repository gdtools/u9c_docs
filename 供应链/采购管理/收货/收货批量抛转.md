
# 功能描述

适用于关系企业协同或者多角贸易时公司间单据协同。

# 关键应用

采购收货单已经入库确认。

# 业务规则

*  适用于关系企业协同或者多角贸易时公司间单据协同
*  可以将向来源于内抛生成的采购订单的收货单批量生成本组织的出货单。
*  参见关系企业协同

# 栏目说明

批量抛转列表

进入**采购管理**－>**收货**－>**收货批量抛转，其主要功能：**

|**栏目**|**说明**|
|---|---|
|选择框|可多选|
|其他数据项|采购收货单据信息,只可查看,不可修改|
|默认抛转日期|收货单抛转后出货单默认日期，可改|

# 按钮说明

*  <继续选单>

点击界面中的[继续选单]按钮，可以定义查询方案，包括查询条件、栏目及排序。

具体操作参见查询方案

*  <抛转>

概述:可以将选择的采购收货单抛转生成本企业的销售出货单。

操作前提:收货单已经入库确认。

操作步骤:采购收货单的批量抛转，具体步骤如下所示。

第1步：进入“批量抛转”列表

第2步：在列表中选择需要抛转的收货单

第3步：点击“抛转”按钮；即可将选择单据抛转生成本组织的销售出货单
