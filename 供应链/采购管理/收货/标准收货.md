
# 功能描述

采购收货主要处理供应商送货到达本收货组织后，如何进行清点、检验、办理入库手续的活动，同时根据采购收货的实际情况还可以确定同供应商之间的应付关系，并确定相应的入库成本。

# 关键应用

*  采购收货
*  销售退回收货
*  委外收货
*  合同收货
*  期初收货单
*  ASN单转收货
*  ASN单

# 业务规则

*  采购收货用于记录供应商交付货物的过程与结果。
*  采购收货可以反应收货过程中的“收”“点”“验”“入”等过程。
*  支持收货时的多种估价方式。支持无采购订单的收货。
*  提供多种快速收货模式。
*  支持多种业务模型的收货。
*  可以收到仓库，也可收到线上仓、收至工单、收货至工序、收到固定资产、收货后直接分发等。
*  可以按采购收货的情况进行立账

# 按钮说明

*  <快速录入>：

快速录入功能能够快速录入多条物料信息，包括物料、数量、计量单位、交期信息。该功能能够提高单张单据的录入效率。

点击采购管理－>收货－>采购收货－>快速录入，可以进行快速录入操作。具体步骤如下所示。

第1步：点击“快速录入”按钮，弹出快速录入画面；

第2步：录入物料、实到数量、存储地点等信息；

第3步：点击“确认”按钮，将快速录入的信息带入单据行中。快速录入操作完毕。

*  <快速收货>：

本系统支持快速收货，收货模式分三种方式：

指定料品盲目收货

指定订单瀑布收货

一单准确收货

参见专题快速收货模式

操作前提：

采购订单已经审核

订单上录入存储地点；或者在采购参数中设置“默认收货地点”；并保证存储地点上的收货部门等信息完整。

操作步骤：

点击采购管理－>收货－>采购收货－>快速收货按钮，可以进行采购订单转收货单快速收货操作。

指定料品盲目收货，具体步骤如下所示。

第1步：点击单据下方“快速收货”按钮，弹出“快速收货”弹出画面；

第2步：收货模式＝“指定料品盲目收货”；

第3步：参照选择录入供应商。

第4步：参照选择录入物料。

第5步：点击“确定”，快速收货操作完毕。

指定订单瀑布收货，具体步骤如下所示：

第1步：点击单据下方“快速收货”按钮，弹出“快速收货”弹出画面；

第2步：收货模式＝“指定订单瀑布收货”；

第3步：参照选择录入供应商。

第4步：参照选择录入订单号

第5步：参照选择录入物料。

第6步：点击“确定”，快速收货操作完毕。

一单准确收货，具体步骤如下所示：

第1步：点击单据下方“快速收货”按钮，弹出“快速收货”弹出画面；

第2步：收货模式＝“一单准确收货”；

第3步：参照选择录入订单号；

第4步：点击“确定”，快速收货操作完毕。

操作前提：

存在上游单据，例如采购订单等。

操作步骤：

点击采购管理－>收货－>采购收货－>批量生单，可以进行批量生单操作。

具体步骤如下所示：

第2步：批量生单过滤画面，根据需要选择过滤条件过滤来源单据：

按供应商等过滤：可以选择供应商信息、物料信息、交易信息，允许多选；

按单据过滤：选择某类单据，例如采购订单，在采购订单后打“√”，再选择单号和日期，允许多选；支持所有过滤条件同时进行过滤。

第7步：批量生单列表画面中，点击“确定”按钮，批量生单完毕。

【按交期分单的使用说明】：

查询画面“生单”页签中的“可选分单条件”设置：

[计划到货日期]：勾选，则表示需要按照交期分单。勾选后，下面的两个字段才可编辑。

[时段]：即天数，多少天生成一张收货单，以“分单时界”为起点。

[分单时界之前单据处理]：交期在“分单时界”之前的收货处理规则。

正常分单：即按照时段进行生单；

合并一单：交期在“分单时界”之前的所有收货生成一张单据；

合并至第一个时间段：将交期在“分单时界”之前的所有收货跟交期在“分单时界”之后第一个时段的收货生成一张单据。

批量生单上界面“分单时界”的设置：默认为当前系统日期。需要按交期分单时该字段要求非空。

*  <操作-挂起>：

概述：

收货由于某种原因需要将单据挂起，等待问题解决后再解除挂起。

操作前提：

定义挂起原因

操作步骤：

点击采购管理－>收货－>采购收货－>操作－>挂起按钮，可以进行挂起操作。具体步骤如下所示。

第1步：点击按钮执行“挂起”功能，系统自动弹出挂起画面。

第2步：选择挂起原因

第3步：点击确定，挂起完毕，可以在状态弹出画面中查看挂起情况；

*  <操作-分发>：

概述：

当物料为费用性物料时，收货可以不入库，而是选择直接分发；另外一种情况是生产领料，例如分发到生产订单。

操作步骤：点击采购管理－>收货－>采购收货－>操作－>分发，可以进行分发操作。

具体步骤如下所示。

第1步：点击操作－>分发按钮，弹出分发画面；

第2步：分发列表，参照录入生产订单（费用采购请录入领用部门）等信息；

第3步：修改配料数量/分发数量；

第4步：分发列表录入多行数据，点击“确定”按钮，返回收货单画面。

第5步：保存收货单，分发完毕。

*  <操作-预占库位（整单预占库位、行预占库位）>：

概述：

当收货程序中先入库后检验的时候，需要预占库位。

操作前提：

收货程序＝“收货—点收—入库—检验”或“收货—入库—检验”

操作步骤：

点击采购管理－>收货－>采购收货－>操作－>预占库位，可以进行预占库位，等待检验后再入库确认。

*  <操作-检验>：

概述：

当收货程序中具有检验的时候，需要进行检验操作。

操作前提：

收货程序中含检验

未启用退货申请

操作步骤：

点击采购管理－>收货－>采购收货－>操作－>检验，可以进行检验，并根据质检结论将原来的行分为“合格接收”、“不合格接收”、“不合格拒收”三行数据。

具体步骤如下所示：

第1步：点击后续处理－>检验按钮，弹出检验画面；

第2步：检验列表，若存在检验合格料品，选择“质检结论”＝“合格接收”，录入合格数量到“检验数量”；

第3步：若存在检验不合格料品，也要接收的，增加行，检验列表，选择“质检结论”＝“不合格接收”，录入不合格接收数量到“检验数量”；

第4步：若存在检验不合格料品，不需要接收的，增加行，检验列表，选择“质检结论”＝“不合格拒收”，录入不合格拒收数量到“检验数量”；

第3步：检查数据正确后，点击“确定”按钮，返回收货单画面。

第5步：检验子行新增到收货单行上，保存收货单，检验完毕

*  <操作-理货（整单理货、行理货）>：

概述：

在进行库位管理时使用理货功能。

操作前提：

进行库位管理

操作步骤：

点击采购管理－>收货－>采购收货－>操作－>整单理货/行理货，可以进行整单理货/行理货操作。

*  <操作-预算执行>：

概述：全面预算控制时，可通过此功能设置＼调整对应的预算指标（指标值）　。

操作步骤：点击采购管理－>收货－>采购收货－>操作－>预算执行

*  <操作-后续调价>：

概述：对于允许事后调价的料，允许先收货，然后在立应付之前调整收货单中的价格。

操作步骤：点击采购管理－>收货－>采购收货－>操作－>后续调价。

*  <后续处理-退货申请>：

概述：

退货申请将当前收货单数量转退货申请单。

操作前提：

收货程序中含检验

操作步骤：

点击采购管理－>收货－>采购收货－>后续处理－>退货申请，可以进行转退货申请操作。

具体步骤如下所示。

第1步：点击后续处理－>退货申请按钮，弹出退货申请画面；

第2步：录入“退补数量1”、“退补数量2”、“退扣数量1”、“退扣数量2”；要求拒收=退扣+退补

第3步：检查数据正确后，点击“确定”按钮，返回收货单画面，退货申请完毕。

*  <后续处理-退出库位>：

概述：

当收货程序中有预占库位，检验后存在“不合格拒收”的料品，需要退出库位，转为退货单。

操作前提：

收货程序中有预占库位，且检验后存在“不合格拒收”的料品

操作步骤：

点击采购管理－>收货－>采购收货－>后续处理－>退出库位，可以进行退出库位，将“不合格拒收”的料品转到退货单。

具体步骤如下所示。

第1步：点击后续处理－>退出库位按钮，弹出收货推退货画面；

第2步：收货推退货列表，选择需要推退货的行；

第3步：录入“本次退货数量1”，若使用双数量可以录入“本次退货数量2”；

第4步：点击设置按钮，可以设置分单条件；

第5步：点击“确定”按钮，返回收货单画面。

第6步：生成退货单，退出库位完毕。

*  <后续处理-补货>：

概述：

补货将对当前单据进行补货，生成新的单据。

操作前提：无

操作步骤：

点击采购管理－>收货－>采购收货－>后续处理－>补货，可以进行补货操作。

具体步骤如下所示。

第1步：点击后续处理－>补货按钮，弹出补货画面；

第2步：录入“本次补货数量1”、“本次补货数量2”；

第3步：点击“设置”，可以设置分担条件

第4步：检查数据正确后，点击“确定”按钮，返回收货单画面，补货完毕

*  <预付款录入>

概述：收货单可以直接选择应付系统中已有的付款单，也可以在线新增预付款单。

操作前提：启用应付模块

操作步骤：收货单的预付款在单头和单行都能进行设置。

单头：若应付系统中已有的付款单，只需要关联预付款单，具体步骤如下所示。

第1步：进入单头财务页签。

第2步：点击预付款单后参照按钮，选择应付系统中已有的付款单

第3步：点击“确定”按钮，返回收货单主画面。

第4步：保存收货单，关联预付款单完毕。

单头：若需要在线新增预付款单，具体步骤如下所示。

第1步：进入单头财务页签。

第2步：点击预付款单栏目链接，弹出新增付款单画面

第3步：录入结算方式、预付款金额和其他预付信息。

第4步：点击“确定”按钮，返回收货单主画面。

第5步：保存收货单，在线新增预付款完毕。

单行：若应付系统中已有的付款单，只需要关联预付款单，具体步骤如下所示。

第1步：选择某行，进入行上财务页签。

第2步：点击预付款单后参照按钮，选择应付系统中已有的付款单

第3步：点击“确定”按钮，返回收货单主画面。

第4步：保存收货单，关联预付款单完毕。

单行：若需要在线新增预付款单，具体步骤如下所示。

第1步：选择某行，进入行上财务页签。

第2步：点击预付款单栏目链接，弹出新增付款单画面

第3步：录入结算方式、预付款金额和其他预付信息。

第4步：点击“确定”按钮，返回收货单主画面。

第5步：保存收货单，在线新增预付款完毕。
