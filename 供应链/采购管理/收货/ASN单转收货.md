# 业务规则

# 按钮说明

*  <ASN收货>：将选中的ASN单记录转为收货单。

操作步骤：点击采购管理－>收货－>ASN单转收货按钮。具体步骤如下所示。

第1步：点击“查询”按钮弹出查询条件画面，根据需要选择过滤条件过滤ASN单据。

第2步：画面中选中本次需要转成收货单的记录，在记录前打“√”。

第3步：可以手工调整“本次收货数量1”，双数量可以使用“本次收货数量2”进行调整。

第4步：若要设置分单条件，点击“设置”按钮，设置分单条件，设置完毕点击“确定”返回。

第5步：点击“ASN收货”按钮，生单完毕；

*  <追溯查询>：选择列表中的记录，点击**采购管理－>收货－>ASN单转收货－>追溯查询**，可以查看当前ASN单所生成的收货单；
*  <设置>：设置ASN单转收货的分单条件，可根据勾选条件，对勾选多条记录分别生成收货单。
