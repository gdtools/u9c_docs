
# 功能描述

在U9中退货单仍然采用的是收货单单据类型，只是其为采购退货，其数量也仅处理退货方面的数量。当退货单确认时，系统自动办理出库手续，扣减库存。

# 关键应用

# 业务规则

*  1：进入“采购管理”—“基础设置”---“[参数设置](http://10.16.226.26/U9/help/zh-CN/Content/SCM/PM/Function/CBO.Base.Profile.Profile.3016.htm)”（采购的参数）：

“启用退货申请”：设置为Y，表示发生采购退货时必须走“采购退货申请单”；

*  2：进入“采购管理”—“基础设置”---“[单据类型](http://10.16.226.26/U9/help/zh-CN/Content/SCM/PM/Function/CBO.SCM.MF2040_10.htm)”（采购单据的单据类型定义）；

将采购单的单据类型中“是否补货”设置为Y，表示该单据类型的订单是一张描述补货的采购订单；

设置收货单的单据类型中“退货类型”；

设置收货单的单据类型中“补货收货”，置为Y，表示当前业务收的是一笔补货；

设置收货单的单据类型中“是否源单退货”；为Y，表示退货时一定要要对应的收货单。

设置收货单的单据类型中“退补产生订单”，设置为Y，表示采购补货时必须生成采购补货单；

*  3：定义退货原因:“采购管理”—“基础设置”---“[退货原因](http://10.16.226.26/U9/help/zh-CN/Content/SCM/PM/Function/CBO.SCM.MF2020_10.htm)”
*  4：关于采购退补货：

采购管理模块有两个系统参数,分别是[默认的采购拒收处理]方式及[在库退补货方式]，两个参数的参数值均为“按原单追踪”及“创建补货单追踪”，系统的处理逻辑如下:

参数值设置：当[默认采购拒收处理方式]的参数值为“创建补货单追踪”时，[在库退补货方式]的参数值 必须为“创建补货单追踪”。

退补货方式的处理：采购退补货时,如果退补货的来源能够追溯到采购订单,退补货方式遵循采购订单中的[默认的采购拒收处理方式]处理；如果退补货的来源无法追溯到采购订单，则退补货方式为“创建补货单追踪”

# 按钮说明

*  <快速录入>

概述：快速录入功能能够快速录入多条物料信息，包括物料、退扣数量、退补数量。该功能能够提高单张单据的录入效率。

操作前提：无

操作步骤：点击采购管理－>收货－>退货－>快速录入，可以进行快速录入操作。具体步骤如下所示。

第1步：点击“快速录入”按钮，弹出快速录入画面；

第2步：录入物料、退扣数量、退补数量、存储地点等信息；

第3步：点击“确认”按钮，将快速录入的信息带入单据行中。快速录入操作完毕。

*  <批量生单单--指定来源退>：可选多个供应商的多个来源单据，批量生成多个的单据。

操作前提：存在上游单据，例如收货单等。

操作步骤：点击采购管理－>收货－>退货－>批量生单－>指定来源退，可以进行批量生单操作。具体步骤如下所示。

第1步：点击“批量生单”按钮，弹出批量生单过滤画面。

第2步：批量生单过滤画面，根据需要选择过滤条件过滤来源单据：

按供应商等过滤：可以选择供应商信息、物料信息、交易信息，允许多选；

按单据过滤：选择某类单据，例如收货单，在收货单后打“√”，再选择单号和日期，允许多选；

支持所有过滤条件同时进行过滤。

第3步：点击“确定”按钮，进入批量生单列表画面。

第4步：批量生单列表画面中，选中本次需要转成退货单的记录，在记录前打“√”；

第5步：可以手工调整“退货数量1”、“退扣数量1”、“退补数量1”，双数量可以使用“退货数量2”、“退扣数量2”、“退补数量2”。

第6步：若要设置分单条件，点击批量生单列表画面上的“设置”按钮，进行设置，设置完毕点击“确定”返回。

第7步：批量生单列表画面中，点击“确定”按钮，批量生单完毕。

*  <批量生单--汇总退料退>：

根据指定期间的生产退料单等，汇总生成在库RTN退货的物料及数量；

操作前提：存在上游单据，例如生产退料单。

操作步骤：点击采购管理－>收货－>退货申请－>批量生单－>汇总退料退。具体步骤如下同“批量生单－指定来源退”。

*  <批量生单--按库存状况退>

概述：指定存储地点、库存、存储类型等，生成在库RTN退货的物料及数量；

操作前提：存在可退库存。

操作步骤：点击采购管理－>收货－>退货申请－>批量生单－>按库存状况退。具体步骤如下同批量生单－指定来源退。

*  <补货>

概述：执行本操作，可以进行补货操作，由当前退货单自动生成补货收货单。

操作前提：退货单已审核

操作步骤：点击采购管理－>收货－>退货－>补货，可以进行补货操作。

具体步骤如下所示。

第1步：点击补货按钮，弹出补货画面。

第2步：可以手工调整“本次补货数量1”，双数量可以使用“本次补货数量2”。

第3步：点击设置可以设置分单条件。

第4步：点击“确定”按钮，返回退货单画面。

*  <拣货（整单拣货、行拣货）>

概述：拣货操作作进行库位管理的时候，能够按照拣货规则获取库位。

操作步骤：点击采购管理－>收货－>退货－>整单拣货/行拣，可以自动拣货操作。

*  <供应商状况>
*  <查询库存>

点击**采购管理－>采购申请－>请购－>查询库存**，可以查询料品所在仓库的库存状况，包括库存可用量、库存量、预留量、当前预留量、预留占用量等信息。

# 操作说明

*  采购退货协同销售退货：

概述：当买卖双方为关系企业时，实现采购组织制作采购退货单自动协同生成销售组织销售退回收货单的业务。

*  相关操作及说明如下：

进入“采购管理”—“基础设置”---“参数设置”（采购公共的参数），将采购退货协同销售退货参数值设为“是”。

当退货单中供应商的联系对象为内部组织，拒收数量=退扣数量，退至存储地点不为空时，退货单审核后，系统会生成内部组织的销售退回收货单，该销售退回收货单的来源类别为“采购退货”，该单据后续只能推式生成退回处理单。

当采购系统参数“采购退货生成销售退货需要签收”为“否”时,生成的销售退回收货单状态为“已核准”态，采购退货单弃审时自动删除其生成的销售退回收货单；当该参数为“是”时，生成的销售退回收货单状态为“开立”，采购退货单弃审时，系统会判断销售退回收货单状态：如果状态为“业务关闭”则不允许采购退货单弃审；如果状态不为“业务关闭”，弃审时自动删除销售退回收货单。

当采购退货单中的定价依据为“退货方”时，生成的销售退回收货单中的[实收数量]、[核定数量]、[核定价格]均不可改，当采购退货单中的定价依据为“收货方”且单据未立账时，生成的销售退回收货单中的[实收数量]、[核定数量]、[核定价格]可改。

销售退回收货单推出的退回处理单未立帐时，才允许对采购退货单做弃审操作。
