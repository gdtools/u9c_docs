
# 功能描述

进入采购管理－>收货－>销售退回收货。本模块专门维护销售退货的商品进行收货。

# 关键应用

# 业务规则

*  定期询价：按一定周期进行询比价，比价结果保存在系统中，在该周期内每次的采购活动均采用该次比价结果，比较适合价格相对较稳定的物料
*  每次询价：每次采购业务发生之前均需要进行询比价，每次询比价的结果仅对本次采购业务有效，比较适合价格波动较大且频繁的物料
*  任意询价：对任意一个物料、请购单、需求接口表可展开询价；请购单、需求接口表有比价接受记录后可按比价结果转下游单据
