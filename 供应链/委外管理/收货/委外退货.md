
# 功能描述

进入委外管理－>收货－>委外退货；

退货单仍然采用的是收货单单据类型，只是其为采购退货，其数量也仅处理退货方面的数量。当退货单确认时，系统自动办理出库手续，扣减库存。

# 业务规则

*  启用委外系统（必做）；
*  参数设定；
*  定义退货单单据类型（必做）；
*  定义供应商档案（必做）；
*  定义组织档案（必做）；
*  定义采购业务部门（必做）；
*  定义采购业务员（必做）；
*  定义料品档案（必做）；
*  定义计量单位（必做）；
*  定义币种（必做）；
*  定义存储地点（必做）；
*  定义退货原则（必做）；
*  定义税组合（必做）；
*  定义单据类型（必做）；
*  定义应付立账条件档；
*  定义付款条件档。

# 按钮说明

*  <快速录入>：快速录入功能能够快速录入多条物料信息，包括物料、退扣数量、退补数量。该功能能够提高单张单据的录入效率。
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击委外管理－>收货－>退货－>快速录入，可以进行快速录入操作。具体步骤如下所示。
      *  第1步：点击“快速录入”按钮，弹出快速录入画面；
      *  第2步：录入物料、退扣数量、退补数量、存储地点等信息；
      *  第3步：点击“确认”按钮，将快速录入的信息带入单据行中。快速录入操作完毕。
*  <批量生单单－指定来源退>：可选多个供应商的多个来源单据，批量生成多个的单据。
 
   *  操作前提
   
      *  存在上游单据，例如收货单等。
   *  操作步骤
   
      *  点击委外管理－>收货－>退货－>批量生单－>指定来源退，可以进行批量生单操作。具体步骤如下所示。
      *  第1步：点击“批量生单”按钮，弹出批量生单过滤画面。
      *  第2步：批量生单过滤画面，根据需要选择过滤条件过滤来源单据：
      *  按供应商等过滤：可以选择供应商信息、物料信息、交易信息，允许多选；
      *  按单据过滤：选择某类单据，例如收货单，在收货单后打“√”，再选择单号和日期，允许多选；
      *  支持所有过滤条件同时进行过滤。
      *  第3步：点击“确定”按钮，进入批量生单列表画面。
      *  第4步：批量生单列表画面中，选中本次需要转成退货单的记录，在记录前打“√”；
      *  第5步：可以手工调整“退货数量1”、“退扣数量1”、“退补数量1”，双数量可以使用“退货数量2”、“退扣数量2”、“退补数量2”。
      *  第6步：若要设置分单条件，点击批量生单列表画面上的“设置”按钮，进行设置，设置完毕点击“确定”返回。
      *  第7步：批量生单列表画面中，点击“确定”按钮，批量生单完毕。
*  批量生单－汇总退料退：根据指定期间的生产退料单等，汇总生成在库RTN退货的物料及数量；。
 
   *  操作前提
   
      *  存在上游单据，例如生产退料单。
   *  操作步骤
   
      *  点击委外管理－>收货－>退货申请－>批量生单－>汇总退料退。具体步骤如下同“批量生单－指定来源退”。
*  <批量生单－按库存状况退>：指定存储地点、库存、存储类型等，生成在库RTN退货的物料及数量；
 
   *  操作前提
   
      *  存在可退库存。
   *  操作步骤
   
      *  点击委外管理－>收货－>退货申请－>批量生单－>按库存状况退。具体步骤如下同批量生单－指定来源退。
*  <补货>：执行本操作，可以进行补货操作，由当前退货单自动生成补货收货单。
 
   *  操作前提
   
      *  退货单已审核
   *  操作步骤
   
      *  点击委外管理－>收货－>退货－>补货，可以进行补货操作。
      *  具体步骤如下所示。
      *  第1步：点击补货按钮，弹出补货画面。
      *  第2步：可以手工调整“本次补货数量1”，双数量可以使用“本次补货数量2”。
      *  第3步：点击设置可以设置分单条件。
      *  第4步：点击“确定”按钮，返回退货单画面。
*  <拣货（整单拣货、行拣货）>：拣货操作作进行库位管理的时候，能够按照拣货规则获取库位。
 
   *  操作步骤
   
      *  点击委外管理－>收货－>退货－>整单拣货/行拣，可以自动拣货操作。
*  <查询库存>
 
   *  操作步骤
   
      *  点击委外管理－>采购申请－>请购－>查询库存，可以查询料品所在仓库的库存状况，包括库存可用量、库存量、预留量、当前预留量、预留占用量等信息。
*  <供应商-供应商状况查询>
 
   *  操作步骤
   
      *  点击委外管理－>采购单－>标准采购－>供应商－>供应商状况查询，可以查询供应商状况。
*  <供应商-价格重算（整单价格重算、行价格重算 ）>：本功能能够安系统的取价原则自动获取价格。
 
   *  操作步骤
   
      *  点击委外管理－>收货－>退货－>供应商－>整单价格重算/行价格重算，可以进行价格重算操作。
*  <料品-料品状况查询>
 
   *  操作步骤
   
      *  点击委外管理－>收货－>退货－>物料－>料品状况查询，可以查询料品状况查询
*  <料品-产品结构查询>
 
   *  操作步骤
   
      *  点击委外管理－>收货－>退货－>操作－>产品结构查询，可以查看产品结构查询。
*  <料品-序列号查询>
 
   *  操作步骤
   
      *  点击委外管理－>收货－>采购收货－>物料－>序列号查询，可以查询料品的序列号信息，包括已录序列号数量，子行号对应的序列号等。
*  <操作-分发>：物料形态属性=费用或固定资产，可以进行分发操作。
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击委外管理－>收货－>采购退货－>操作－>分发按钮，可以进行分发操作。具体步骤如下所示。
      *  第1步：点击按钮执行“分发”功能，系统自动弹出分发画面。
      *  第2步：录入分发信息
      *  第3步：点击确定，分发完毕；
*  <操作-解除>：退货由于某种原因需要将单据挂起，等待问题解决后再解除挂起。
 
   *  操作前提
   
      *  定义解除原因，解除原因要与挂起原因关联起来。
   *  操作步骤
   
      *  点击委外管理－>收货－>采购退货－>操作－>解除按钮，可以进行解除操作。具体步骤如下所示。
      *  第1步：点击按钮执行“解除”功能，系统自动弹出解除画面。
      *  第2步：选择解除原因
      *  第3步：点击确定，解除完毕，可以在状态弹出画面中查看解除情况；
*  操作-挂起：退货由于某种原因需要将单据挂起，等待问题解决后再解除挂起。
 
   *  操作前提
   
      *  定义挂起原因
   *  操作步骤
   
      *  点击委外管理－>收货－>采购退货－>操作－>挂起按钮，可以进行挂起操作。具体步骤如下所示。
      *  第1步：点击按钮执行“挂起”功能，系统自动弹出挂起画面。
      *  第2步：选择挂起原因
      *  第3步：点击确定，挂起完毕，可以在状态弹出画面中查看挂起情况；
*  <操作-个别计价匹配>：个别计价匹配是指进行层级匹配。
 
   *  操作前提
   
      *  存在层级信息
   *  操作步骤
   
      *  点击委外管理－>收货－>采购退货－>操作－>个别计价匹配，可以进行分发操作。
      *  具体步骤如下所示。
      *  第1步：点击>操作－>个别计价匹配按钮，弹出个别计价匹配画面；
      *  第2步：选择成本域成本类型；
      *  第3步：在上下列表中选择需要匹配的数据，录入本次匹配数量；
      *  第4步：点击“匹配”按钮，匹配完毕；
      *  第5步：点击“关闭”按钮，返回退货单画面。

*  操作步骤

   *  第2步：选择料品等信息；
   *  第3步：维护退货数量、退货原因等信息；
