
# 功能描述

进入采购管理－>收货－>委外收货；

本模块是工序外协和全程委外两种订单生成的收货单。

# 业务规则

*  启用委外系统（必做）；
*  同标准收货单（必做）；
*  存在工序外协和全程委外订单。

# 栏目说明

栏目说明内容同标准收货单，下边的描述的是与标准收货单差异之处：注意当工序外协时，委外订单展示的是工序外协件，而在委外收货时，展示的则是具体需要加工的料件

# 按钮说明

*  参见[标准收货](/detail/943233560f96423bbf7436e16184978f)：
*  <材料构成>：全程委外，点击采购管理－>收货单－>委外收货－>物料－>材料构成，可以查询同一订单的收货、发料情况，并可以手工调整收发料的对应关系以调整委外收货的入库成本构成。

# 操作说明

*  通过菜单委外管理－>收货－>委外收货进入该界面；
*  操作步骤
 
   *  第1步：选择单据类型、供应商等等单头信息；
   *  第2步：选择来源单据外协采购；
   *  第3步：输入收货数量、存储地点、最终价格；
   *  第4步：点击保存按钮。
