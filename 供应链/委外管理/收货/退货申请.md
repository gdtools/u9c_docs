
# 功能描述

进入委外管理－>收货－>退货申请

提供RTN（退货申请）的处理，它仅仅是退货申请，通过RTN明确退货的总数量以及具体的退货扣款数量和退货补货数量。

# 业务规则

*  启用委外系统（必做）
*  同收货单（必做）

# 按钮说明

*  <快速录入>：实现快速录入退货料品，退货数量，退补数量信息
 
   *  操作前提
   
      *  存在料品信息
   *  操作步骤
   
      *  第1步：点击快速录入，弹出退货申请快速录入画面。
      *  第2步：在退货申请快速录入画面的料号列，通过料品过滤按钮在弹出的料品参照画面中选择本次需要做退货申请的料品信息，料品信息支持多选。
      *  第3步：录入退扣数量或退补数量，同一行上不支持同时录入退扣、退补数量。在退货原因、项目、任务栏目中维护对应的信息。
      *  第4步：点击“确定”按钮，快速录入完毕。
*  <批量生单－指定来源退>：可选多个供应商的多个来源单据，批量生成多个的单据。
 
   *  操作前提
   
      *  存在上游单据，例如收货单。
   *  操作步骤
   
      *  点击委外管理收货－>委外退货－>批量生单－>指定来源退，可以进行批量生单操作。具体步骤如下所示。
      *  第1步：点击“批量生单”按钮，弹出批量生单过滤画面。
      *  第2步：批量生单过滤画面，根据需要选择过滤条件过滤来源单据：
      *  按供应商等过滤：可以选择供应商信息、物料信息、交易信息，允许多选；
      *  按单据过滤：选择某类单据，例如收货单，在收货单后打“√”，再选择单号和日期，允许多选；
      *  支持所有过滤条件同时进行过滤。
      *  第3步：点击“确定”按钮，进入批量生单列表画面。
      *  第4步：批量生单列表画面中，选中本次需要转成采购申请的记录，在记录前打“√”；
      *  第5步：可以手工调整“拒收数量1”，双数量可以使用“拒收数量2”。
      *  第6步：若要设置分单条件，点击批量生单列表画面上的“方案”按钮，进行设置，设置完毕点击“确定”返回。
      *  第7步：批量生单列表画面中，点击“确定”按钮，批量生单完毕。
*  <批量生单－汇总退料退>：根据指定期间的生产退料单等，汇总生成在库RTN退货的物料及数量；。
 
   *  操作前提
   
      *  存在上游单据，例如生产退料。
   *  操作步骤
   
      *  点击委外管理收货－>委外退货－>批量生单－>汇总退料退。具体步骤如同“批量生单－指定来源退”。
*  <批量生单－按库存状况退>：指定存储地点、库存、存储类型等，生成在库RTN退货的物料及数量；
 
   *  操作前提
   
      *  存在可退的库存余额。
   *  操作步骤
   
      *  点击委外管理收货－>委外退货－>批量生单－>按库存状况退。具体步骤如同批量生单－指定来源退。
*  操作－整单打开
 
   *  点击委外管理收货－>委外退货－>操作－>整单打开，可以手工按单据打开退货申请单。
*  <操作－行打开>
 
   *  点击委外管理收货－>委外退货－>操作－>行打开，可以手工打开退货申请行。
*  <操作－整单关闭>
 
   *  点击委外管理收货－>委外退货－>操作－>整单关闭，可以手工按单据关闭退货申请单。
*  <操作－行关闭>
 
   *  点击委外管理收货－>委外退货－>操作－>行关闭，可以手工关闭退货申请行。
*  <供应商－供应商状况>
 
   *  点击委外管理收货－>委外退货－>供应商－>供应商状况查询，可以对供应商的状况进行查询,如:供应商的未立账金额、未收货金额、应付款、挂起额、预付款、暂收款、暂付款、质保金等信息。
*  <物料－物料状况查询>
 
   *  点击委外管理收货－>委外退货－>物料－>物料状况查询，可以查询物料状况，如物料的库存数量、销售数量、采购数量、计划生产数量等的相关信息。
*  <物料－产品结构查询>
 
   *  点击委外管理收货－>委外退货－>物料－>产品结构查询，可以查询物料的产品结构。
*  <后续处理－退货>：退货申请单核准后，需要退货的可以直接生成退货单。
 
   *  操作前提
   
      *  退货申请单已核准。
   *  操作步骤
   *  点击委外管理－>收货－>委外退货－>后续处理－>退货，可以进行退货操作。具体步骤如下所示。
   
      *  第1步：点击“退货”按钮，弹出退货列表画面。
      *  第2步：退货列表画面中，选中本次需要转成退货单的记录，在记录前打“√”；
      *  第3步：退货列表画面中，点击“确定”按钮，退货完毕。

# 操作说明

*  通过菜单委外管理－>收货－>退货申请进入该界面；
*  操作步骤
 
   *  第1步：选择单据类型、退货对象等信息；
   *  第2步：选择料品等信息；
   *  第3步：维护退货数量、退货原因等信息；
   *  第4步：点击保存按钮。
