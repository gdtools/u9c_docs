
# 功能描述

按照统计期间、会计期间查询委外材料明细的数量信息。

# 业务规则

*  启用委外系统（必做）

# 按钮说明

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。
*  <调整列宽>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。

# 操作说明

*  通过菜单委外管理－>统计－>委外材料收发明细帐进入该界面；
*  操作步骤
 
   *  点击委外管理－>统计－>委外材料收发明细帐，进入主界面。具体步骤如下所示；
   *  第1步：点击委外管理－>统计－>委外材料收发明细帐，进入主界面；
   *  第2步：点击查询，输入查询条件：
   *  第3步：点击确定，查看查询结果。
