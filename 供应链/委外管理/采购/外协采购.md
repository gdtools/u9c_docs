
# 功能描述

进入委外管理－>采购－>外协采购；

标准采购是采购业务中最常见最普通的采购流程；

外协采购单支持分工序外协和全程委外加工两种业务类型：

1、工序外协:工序委外的料品必须是“工序委外件”；

2、全程委外加工:委外加工的料品必须是“委外加工件”。

# 业务规则

*  同标准采购订单（必做）；
*  必须有外协的MO或工序转移单（工序委外必做）。

# 按钮说明

*  参见[标准采购](/detail/31f9061702a846b588178e4c16d1b9ff)
*  <展开关联子件>：点击委外管理－>采购单－>委外采购－>物料－>展开关联子件，当全程委外时，可根据母件ｂｏｍ展开其对方备料的子项作为母项物料的关联子件。
*  <材料构成>：全程委外，点击委外管理－>采购单－>委外采购－>物料－>材料构成，可以查询同一订单的收货、发料情况，并可以手工调整收发料的对应关系以调整委外收货的入库成本构成。

# 操作说明

*  通过菜单委外管理－>采购－>外协采购进入该界面；
*  操作步骤
 
   *  第1步：选择单据类型；
   *  第2步：维护单头供应商、币种等信息；
   *  第3步：维护单行料品、数量、价格等信息；
   *  第4步：点击保存。
