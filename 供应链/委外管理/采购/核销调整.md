
# 功能描述

进入委外管理－>采购－>核销调整；

对于已经核销的委外收货单，支持进行核销调整。核销调整在核销调整节点进行。

# 业务规则

*  启用委外系统（必做）

# 操作说明

*  通过菜单委外管理－>采购－>核销单进入该界面；
*  操作步骤
 
   *  第1步：点击新增按钮，输入查询条件后点击确定按钮；
   *  第2步：选择需要核销调整的委外收货订单；
   *  第3步：选择单据类型、会计期间等信息；
   *  第4步：维护本次核销数量；
   *  第5步：点击保存。
