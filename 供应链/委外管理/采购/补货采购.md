
# 功能描述

进入委外管理－>采购－>补货采购，可以新建补货订单。

# 业务规则

*  同标准采购订单（必做）；
*  单据类型上“补货”＝“√”。

# 栏目说明

栏目说明内容同参见[标准采购](/detail/31f9061702a846b588178e4c16d1b9ff)，下边的描述的是与标准采购订单差异之处：

采购订单头－基本页签

|栏目名称|说明|
|---|---|
|单据类型|单据类型上“补货”＝“√”|

# 按钮说明

*  参见[标准采购](/detail/31f9061702a846b588178e4c16d1b9ff)

# 操作说明

*  通过菜单委外管理－>采购－>外协采购进入该界面；
*  操作步骤
 
   *  第1步：选择单据类型；
   *  第2步：维护单头供应商、币种等信息；
   *  第3步：维护单行料品、数量、价格等信息；
   *  第4步：点击保存。
