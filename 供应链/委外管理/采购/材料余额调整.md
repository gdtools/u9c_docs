
# 功能描述

本结点处理用户上线初期或者在应用过程中，委外订单的发料与订单收货情况无法进行核销勾稽，通过材料余额调整，将对应的材料费调整至成品成本中，同时在委托发出材料明细账中体现此部分调整数量信息。

# 业务规则

*  启用委外系统（必做）

# 栏目说明

材料余额调整

|栏目名称|说明|
|---|---|
|调整数量|=发料单.实发数量-累计退料数量-累计核销数量-累计材料调整数量|
|调整日期|用户指定调整日期|
|批号|如委外订单的产品是进行批号管理的，则用户指定对应材料需调整至成品的批号信息|
|调整至成本域|用户指定对应材料调整的至的成品的成本域信息|
|已调整|调整创建成本调整单更新已调整标识|
|调整单据|调整创建成本调整单更新记录创建的成本调整单信息|


# 按钮说明

*  <调整>：点击委外管理－>材料余额调整，进入材料余额功能功能。

# 操作说明

*  通过菜单委外管理－>采购－>材料余额调整进入该界面；
*  操作步骤
 
   *  第1步：点击委外管理－>材料余额调整，进入材料余额调整维护主界面；
   *  第2步：点击调整范围按钮，录入需要调整材料余额的对应领料单信息。
   *  第3步：在调整范围结果画面，录入调整的成品批号，成品的成本域等信息；
   *  第4步：点击调整按钮，则创建存货成本调整单，来源为对应的生产领料单，将对应领料单未核销部分成本金额调整至对应成品的的指定成本域的存货成本中；
   *  第5步：调整成功后，材料余额调整记录已调整及调整线索信息；
   *  第6步：调整成功后，委外发出材料明细账中体现材料调整的数量等信息。
