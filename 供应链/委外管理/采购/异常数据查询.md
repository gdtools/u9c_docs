
# 功能描述

按照查询条件查询委外的异常数据信息。

# 业务规则

*  启用委外系统（必做）。

# 栏目说明

默认查询条件

|栏目名称|说明|
|---|---|
|委外商|输入委外商，支持多选。|
|料品|输入料品，支持多选。|
|发料日期从|选择发料起始日期|
|到|选择发料结束日期|
|委外订单号|输入委外订单号|
|发料单号|输入发料单号|

# 按钮说明

*  <查找>：点击界面中的查找按钮，可以按照查询条件查询异常的委外数据。

# 操作说明

*  通过菜单委外管理－>采购－>异常数据查询进入该界面；
*  操作步骤
 
   *  点击委外管理－>采购－>异常数据查询，进入主界面。具体步骤如下所示；
   *  第1步：点击委外管理－>采购－>异常数据查询，进入主界面；
   *  第2步：输入查询条件；
   *  第3步：点击查找，查看查询结果。
