
# 功能描述

本结点提供委外退料的操作，主要功能如下：

创建退料单；

维护退料单；

提交、审核或弃审退料单；

维护退料料品的序列号；

对已审核的退料单确认退料；

挂起退料单；

解除已挂起的退料单；

查看与退料单相关的交易分录；

# 业务规则

*  启用委外系统（必做）
*  有已发料确认的外协领料单存在。

# 按钮说明

*  <退料确认>：退料确认，就是根据领料单更新库存明细账的过程。
 
   *  操作前提
   
      *  有处于开立状态的领料单存在。
   *  操作步骤
   
      *  点击委外管理－>委外发料－>委外退料，进入退料单维护主界面。具体步骤如下所示。
      *  第1步：点击委外管理－>委外发料－>委外退料，进入退料单维护主界面。
      *  第2步：点击查找按钮，或者通过上页下页定位到退料单。
      *  第3步：点击“退料确认”。
*  <查看交易分录>：查看此领料单所生成的成本交易分录信息。
 
   *  操作前提
   
      *  退料单状态为‘关闭’时。
   *  操作步骤
   
      *  点击委外管理－>委外发料－>委外退料，进入退料单维护主界面。具体步骤如下所示。
      *  第1步：点击委外管理－>委外发料－>委外退料，进入退料单维护主界面。
      *  第2步：点击交易分录按钮弹出交易分录画面，可以看到该领料单所生成的成本及所生成的交易分录的信息。

# 操作说明

*  通过菜单委外管理－>委外发料－>委外退料进入该界面；
*  操作步骤
 
   *  点击委外管理－>委外发料－>委外退料，进入退料单维护主界面。具体步骤如下所示。
   *  第1步：点击委外管理－>委外发料－>委外退料，进入退料单维护主界面。
   *  第2步：点击新增按钮进入新增状态（点击委外管理－>委外发料－>委外退料直接进入新增状态，如果当前屏幕为其它状态单击新增按钮可以进入新增状态。）；
   *  第3步：输入退料单表头的单据类型、单据号、发料人等信息；
   *  第4步：输入退料单表体-基本页签中的委外领料单行、实退数量等；
   *  第5步：如果备料有批号等要求，在退料单表体-库存页签中进行确认；
   *  第6步：输入完毕，点击保存。
