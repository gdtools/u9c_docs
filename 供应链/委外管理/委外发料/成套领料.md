
# 功能描述

本结点用于维护委外领料的相关操作，主要功能如下：

可以手工创建领料单；

可以按条件生成成套领料的领料单；

可以支持跨组织领料；

提供领料单的删除、修改、取消等基本维护操作；

提供领料单的提交、审核、弃审等操作；

可以维护或查看需领用备料的详细的委外和库存信息；

可以维护或查看需领用备料的批号序列号数据；

可以挂起或释放领料单；

可以按最小发料量和发料备料调整领料单的发料数量；

可以进行发料确认；

可以触发退料；

可以查看领料单相关的交易分录及发料明细[]()；

# 业务规则

*  启用委外系统（必做）
*  有已审核但还没有领料的外协订单存在。

# 按钮说明

*  <发料确认>：发料确认，就是根据领料单更新库存明细账的过程。
 
   *  操作前提
   
      *  有处于开立状态的领料单存在。
   *  操作步骤
   
      *  点击委外管理－>委外发料－>成套领料，进入领料单维护主界面。具体步骤如下所示。
      *  第1步：点击委外管理－>委外发料－>成套领料，进入领料单维护主界面。
      *  第2步：点击查找按钮，或者通过上页下页定位到领料单。
      *  第3步：点击“发料确认”。
*  []()<发料明细>：本功能用于为将发料的领料单确定发料明细
 
   *  操作前提
   
      *  领料单状态为‘开立’时。
   *  操作步骤
   *  点击委外管理－>委外发料－>成套领料，进入领料单维护主界面。具体步骤如下所示。
   *  第1步：点击委外管理－>委外发料－>成套领料，进入领料单维护主界面。
   *  第2步：查找需要维护发料明细的领料单，点击发料明细按钮，弹出发料明细画面；
   *  第3步：发料明细画面由三个页签构成：需求页签显示当前领料单的领料需求，供应页签显示可以为当前需求做供应的库存可用量，匹配页签显示最终需求和供应匹配的结果；
   *  第4步：选择需求和供应的排序顺序，点击自动匹配生成匹配结果至匹配页签中；
   *  第5步：点击确定，将匹配结果返回至领料单行并保存。
*  <查看交易分录>：查看此领料单所生成的成本交易分录信息。
 
   *  操作前提
   
      *  领料单状态为‘关闭’时。
   *  操作步骤
   
      *  点击委外管理－>委外发料－>成套领料，进入领料单维护主界面。具体步骤如下所示。
      *  第1步：点击委外管理－>委外发料－>成套领料，进入领料单维护主界面。
      *  第2步：点击交易分录按钮弹出交易分录画面，可以看到该领料单所生成的成本及所生成的交易分录的信息。

# 操作说明

*  通过菜单委外管理－>发料－>成套领料进入该界面；
*  操作步骤
 
   *  点击委外管理－>委外发料－>成套领料，进入领料单维护主界面。具体步骤如下所示。
   *  第1步：点击委外管理－>委外发料－>成套领料，进入领料单维护主界面。
   *  第2步：点击新增按钮进入新增状态，选择需要领料的单据；
   *  第3步：输入领料单表头的单据类型、单据号、发料人等信息；
   *  第4步：输入领料单表体-基本页签中的委外订单备料、实发数量等；
   *  第5步：如果备料有批号等要求，在领料单表体-库存页签中进行确认；
   *  第6步：输入完毕，点击保存。
