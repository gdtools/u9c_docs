
# 功能描述

设置渠道管理系统的参数。

# 业务规则

*  支持按照企业账号级设定参数，设定后，参数对企业内所有组织有效；
*  支持按照组织级设定参数，设定后，参数只对该组织有效，不影响其他组织。

# 参数说明

# []()

|**参数分组**|**参数名称**|**参数取值及说明**|
|---|---|---|
|**渠道物流**|**商品流向单允许修订天数**|表示已提交的商品流向单在流向统计截止日期后，N天内允许修改单据，超过N天不能修改。此参数值为节点产品线交叉关系中对应字段的默认值。|
|****|**商品流向单允许更正期间数**|表示流向单更正允许更正当前日期所在期间前N个期间的商品流向单。|
|****|**出货数据协同生成节点流入数据的时点**|可以选择：“出货签收”或者“出货核准”。
   *  选择出货签收时，系统根据客户的销售出货单的签收数量生成流向单。
*  选择出货核准，系统根据客户核准后的销售出货单生成流向单。
|
|****|**退货数据协同生成节点流入数据的时点**|可以选择：“退货收货”或者“退货核准”。
   *  选择退货收货时，销售退回申请单、销售退回处理单在收货后，根据收货数量生成流向单。
*  选择退货核准时，根据核准后的销售退回申请单、销售退回处理单生成流向单。
|
|**销售返还**|||
|****|**返还单中返还政策允许为空**|**可以选择：是或者否。****表示在录入返还单时是否必须选择“销售返还政策”。**|
|****|**返点使用申请单中返点使用政策允许为空**|**可以选择：是或者否。**
   *  **表示在录入销售返点使用申请单时是否必须选择“销售返点使用政策”。**
|
|****|**销售返还使用后取消方式**|**可以选择：“回冲原主档”或者“创建新主档”。****此参数影响当前已经使用销售返还的单据，在取消返还使用时，对原返还主档的影响。**
   *  **选择“回冲原主档”，取消返还的使用时，直接更新或删除当前单据在返还主档中的使用记录。**
*  **选择“创建新主档”，取消返还的使用时，当前单据在返还主档中的原使用记录保留，用当前单据的原使用记录创建新的销售返还主档。新返还主档的[返还金额]=原使用记录[使用金额]，使用有效期天数是原使用记录的使用日期到原销售主档的失效日期之间的天数。**
**提示**
   *  **参数选择“回冲原主档”，有可能出现取消使用后，主档有剩余金额可用，但是返还主档已过期或即将过期的情况。**
**参数选择“创建新主档”，可以避免取消返还使用后，原主档有剩余金额可用，但是返还主档已过期或即将过期的情况。**|
|****|**默认汇率类型**|
   *  **设置在使用销售返还时，待使用返还的单据中币种与返还的币种不同时的默认汇率类型。参照汇率类型档录入。**
|
||**是否创建折扣行**|
   *  **返还处理方式影响原行金额或创建折扣行**
|
