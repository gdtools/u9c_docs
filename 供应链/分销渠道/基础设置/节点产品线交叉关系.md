
# 功能描述

按产品线（或品牌）设置在不同地区的地区重要度，及各地区节点流向数据的上报周期、上报方式。

# 关键应用

# 业务规则

*  此设置可作为后续设置节点产品线交叉的默认值；

# 栏目说明

产品线地区设置画面

|**栏目**|**说明**|
|---|---|
|**产品线/品牌**|参照料品档案选择，只能选择[料品形态属性]为“系列件”且[系列件层级]为“产品线”或“品牌”的料品。不可为空|
|**地区**|参照地区档案选择，不可为空**注意：**由于在渠道管理中广泛应用到地区，建议地区按树状结构设置。例如编码01代表北京市，0101代表海淀区，这样在渠道管理中所有按地区编码01的设置，其有效的地区范围包括所有以编码以01开始的地区。如果针对海淀区的设置与北京市不同，可以对海淀区单独设置。|
|**地区重要度**|参照地区重要度档案选择，不可为空。|
|**流向统计期间规则**|表示流向上报的期间规则（按月、周等）。参照统计规则档案选择，不可为空。|
|**流向编辑方式**|表示指定地区的节点上报该产品线或品牌的流向时的默认流向编辑方式。非空，枚举：
   *  流入流出：表示只上报流入和流出数据
*  流入库存：表示只上报流入和库存数据
*  流出库存：表示只上报流出和库存数据
|
|**流入来源明细**|[流向编辑方式]选“流入流出”或“流入库存”时有效。被勾选时表示上报流向时需要上报流入的来源明细数据。|
|**流出去向明细**|[流向编辑方式]选“流入流出”或“流出库存”时有效。被勾选时表示上报流向时需要上报流出的去向明细数据。|
