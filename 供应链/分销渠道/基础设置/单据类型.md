
# 功能描述

用户可维护渠道管理中各业务单据的单据类型档案。

# 关键应用

# 业务规则

*  商品流向单；
*  销售返还单；
*  销售返点单；
*  销售返点使用申请单；
*  销售返利额度单；
*  销售返利额度使用申请单；

# 栏目说明

执行【渠道管理】－>【基础设置】－>【单据类型】，打开单据类型定义画面。

在画面选择单据类型，在页面中维护单据类型参数。

不同单据类型画面中“单据参数页签”中栏目是一致的，我们可在其中设置单据的编号方式，打印方式等。具体设置参见单据参数定义。

单据类型画面栏目

|**栏目**|**说明**|
|---|---|
|**基本分区**|
|编码|手工输入，当前单据类型的编码。注意编码不能重复。|
|名称|手工输入，当前单据类型的名称，可空。|
