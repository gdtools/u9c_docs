
# 功能描述

设置料品在渠道中的库存滞销条件，用于渠道库存滞销计算。

# 关键应用

# 业务规则

滞销库存判定依据有两种：库龄和周转次数

*  库龄：料品按批号、序列号管理的情况下，可按库龄判断滞销。料品同时按批号和序列号管理的情况下，优先按序列号计算库龄。流向单库存表体的库龄≥设定的滞销库龄天数，系统认定为滞销库存。
*  周转次数：＝流向单流出表体[流出数量]/库存表体[本期库存]。节点连续n期流向单的库存周转次数都≤设定的最低周转次数，系统认定为滞销库存。

# 栏目说明

渠道库存滞销条件画面

|**栏目**|**说明**|
|---|---|
|**库存分类**|参照料品分类，可选[分类体系]•[库存分类]＝true的料品分类|
|**料品**|参照料品档，只能选料品主档中[渠道库存滞销检查]＝true的料品；[库存分类]≠null时，只能选择该[库存分类]下的料品|
|**序列号管理**|枚举：
   *  无限制：表示不管料品[序列号参数]是否为空，都可匹配当前记录
*  是：表示只有[序列号参数]非空的料品才能匹配当前记录
*  否：表示只有[序列号参数]为空的料品才能匹配当前记录
**注意：**所选[料品]的[料品形态属性]≠“系列”时，料品[序列号参数]非空，只能选择“是”；[序列号参数]为空，只能选择“否”|
|**批号管理**|枚举：
   *  无限制：表示不管料品[批号参数]是否为空，都可匹配当前记录
*  是：表示只有[批号参数]非空的料品才能匹配当前记录
*  否：表示只有[批号参数]为空的料品才能匹配当前记录
**注意：**所选[料品]的[料品形态属性]≠“系列”时，料品[批号参数]非空，只能选择“是”；[批号参数]为空，只能选择“否”|
|**滞销判定依据**|枚举：周转次数库龄[序列号管理]和[批号管理]都为否时，只能选择周转次数|
|**最低周转次数**|[滞销判定依据]=周转次数时有效|
|**持续期数**|[滞销判定依据]=周转次数时有效|
|**滞销库龄天数**|[滞销判定依据]=库龄时有效|
