
# 功能描述

对于直接客户的节点，由于系统中有客户的销售单据，这部分节点不需要上报流入数据，可通过程序“流向单生成”，系统将该客户的销售出货单、销售退回申请单、销售退回处理单、销售退回收货单，生成流向单的流入数据。

# 关键应用

# 业务规则

*  程序执行时，按照指定的条件，在当前组织及当前组织与其的业务关系为“销售－物流”、“销售－工厂”的组织中，找出[营运组织]＝当前组织且未生成流向单流入表体的销售单据行，生成程序条件指定的节点＋产品线（或品牌）的流向单流入表体。
*  程序执行的间隔周期不宜过长。

# 栏目说明

流向单生成画面栏目说明

|**栏目**|**说明**|
|---|---|
|节点|可空，参照节点档|
|产品线/品牌|可空，参照料品主档中[系列件层级]＝产品线或品牌的料品；节点不为空时，只能选产品线地区交叉档中，包含当前节点•[地区]的产品线或产品线所辖的品牌。|
|开始日期|默认=系统当前日期，必输|

# 按钮说明

*  <执行>：在画面中设定过滤条件后，点击【执行】按钮即可；
*  <调度>：将程生成加入系统调度，在指定时间自动执行。

操作前提：如需重复执行，需先设定“调度计划”。

操作步骤：在画面中设定过滤条件后，点击【调度】，打开调度画面，选择调度方式。

*  执行一次：设定执行日期，系统将在指定日期执行程序。
*  重复执行：指定“调度计划”，系统根据“调度计划”中定义的重复周期定期执行程序。如未设定“调度计划”，可点击栏目链接在线创建调度计划。调度计划定义可参见相关文档。

点击画面中【确定】按钮，将程序加入系统调度，点击【取消】按钮，放弃返回主画面。

# 相关主题

1、设置渠道参数“出货数据协同生成节点流入数据的时点” （必须）

参数选择出货签收时，系统根据客户的销售出货单的签收数量生成流向单。

参数选择出货核准，系统根据客户核准后的销售出货单生成流向单。

2、设置渠道参数“退货数据协同生成节点流入数据的时点” （必须）

参数选择退货收货时，销售退回申请单、销售退回处理单在收货后，根据收货数量生成流向单。参数选择退货核准时，根据核准后的销售退回申请单、销售退回处理单生成流向单。

3、设置节点档（必须）；

4、在料品档中设置“产品线”、“品牌”、“子品牌”，即“料品形态属性”为“系列件”的料品，并指定其“系列件层级”（必须）；

5、设置客户档（必须）；

6、录入销售出货单、销售退回申请单、销售退回处理单、销售退回收货单（必须）

7、设置节点产品线交叉关系（必须）；
