
# 功能描述

按程序设定的异常条件，系统定期执行，找出符合条件的异常流入流出数量勾稽记录，以便渠道管理人员核实异常的原因，通过“流向数量异常处理”功能及时处理。

# 关键应用

# 业务规则

*  流入异常：节点的流向单流入表体中[勾稽结束标识]=false的行，视为流入异常。此异常说明，系统在该流入行来源节点的流向单中，未找到对应的流出记录，或流出记录中流出数量与该流入行流入数量不符。
*  流出异常：节点的流向单流出表体中[勾稽结束标识]=false的行，且系统日期所在统计期间－该流向单的流向统计期间的期间，超过条件“间隔期间数”n，该流出行视为流出异常。此异常说明可能为节点谎报、错报去向，或者去向节点没有及时或没有上报正确的流入数据。

# 栏目说明

流向数量异常检查画面栏目说明

|**栏目**|**说明**|
|---|---|
|流入异常|默认＝true，可改|
|流出异常|默认＝true，可改|
|地区|参照地区档，可为空|
|产品线|可空，参照料品主档中[系列件层级]＝产品线的料品；|
|品牌|可空，参照料品主档中[系列件层级]＝品牌的料品；|
|料品|可空，参照料品主档中[料品形态属性]≠“系列”的料品|
|间隔期间数n|≥0；流出异常＝true时有效。|

# 按钮说明

*  <执行>：在画面中设定过滤条件后，点击【执行】按钮即可；
*  <调度>：将程生成加入系统调度，在指定时间自动执行。

操作前提：如需重复执行，需先设定“调度计划”。

操作步骤：在画面中设定过滤条件后，点击【调度】，打开调度画面，选择调度方式。

*  执行一次：设定执行日期，系统将在指定日期执行程序。
*  重复执行：指定“调度计划”，系统根据“调度计划”中定义的重复周期定期执行程序。如未设定“调度计划”，可点击栏目链接在线创建调度计划。调度计划定义可参见相关文档。

点击画面中【确定】按钮，将程序加入系统调度，点击【取消】按钮，放弃返回主画面。
