
# 功能描述

通过程序中设定的异常条件，系统定时在商品流向单的流入表体、流出表体、库存表体填报的序列号，检查符合条件的序列号异常记录。

# 关键应用

# 业务规则

指定四种异常检查方式：重复库存检查、重复纯销检查、流入异常检查、流出异常检查。

*  重复库存检查：在条件指定的“重复库存统计截止日期”之前，相同的序列号出现在2个和2个以上节点的最新一期流向单库存数据中，即为重复库存。此检查可以跨组织检查。
*  重复纯销检查：同一个的序列号，在检查条件“检查期间数n”的n个统计期间内，在流出数据中存在2条和2条以上[是否纯销]=“true”的记录，即为“重复纯销”。此检查可以跨组织检查。
*  流入异常检查：在检查条件“检查期间数n”的n个统计期间内，流入表体中序列号，在其“来源节点”的流出记录中，没有找到对应序列号，即为“流入异常”。如节点A有流入序列号001，来源节点是B，在节点B流出数据中无去向节点是A、序列号为001的流出记录，或无去向节点为空、序列号为001的流出记录。此检查只可以在当前组织检查。
*  流出异常检查：在检查条件“检查期间数n”的n期之前发生的流出表体中序列号，在其“去向节点”的流入记录中，没有找到对应序列号，即为“流出异常”。如n期之前节点A有流出序列号002，去向节点为C，在节点C流入数据中无来源节点是A、序列号为002的流入记录，或无来源节点为空、序列号为002的流入记录。此检查只可以在当前组织检查。

# 栏目说明

序列号流向异常检查画面栏目说明

|**栏目**|**说明**|
|---|---|
|组织范围|枚举：跨组织、单组织，可选其一，默认单组织。跨组织是指异常检查的范围为当前Site中的所有营运组织；单组织：异常检查的范围为当前组织。|
|地区|参照地区档，可为空|
|渠道级别|参照渠道级别UDC档，可为空|
|重复库存检查|默认＝true，可改；|
|重复纯销检查|默认＝true，可改；|
|流入异常检查|默认＝true，可改；“组织范围”选“跨组织”时，＝false，且不可改；|
|流出异常检查|默认＝true，可改；“组织范围”选“跨组织”时，＝false，且不可改；|
|产品线|可空，参照料品主档中[系列件层级]＝产品线的料品；|
|检查期间数n|不可为空，≥1。条件“重复纯销检查”＝true或“流出异常检查”＝true时有效。|
|重复库存统计截止日期|默认系统日期，可改。“重复库存检查”＝true时有效。|

# 按钮说明

*  <执行>：在画面中设定过滤条件后，点击【执行】按钮即可。；
*  <调度>：将程生成加入系统调度，在指定时间自动执行。

操作前提：如需重复执行，需先设定“调度计划”。

操作步骤：在画面中设定过滤条件后，点击【调度】，打开调度画面，选择调度方式。。

*  执行一次：设定执行日期，系统将在指定日期执行程序。
*  重复执行：指定“调度计划”，系统根据“调度计划”中定义的重复周期定期执行程序。如未设定“调度计划”，可点击栏目链接在线创建调度计划。调度计划定义可参见相关文档。

点击画面中【确定】按钮，将程序加入系统调度，点击【取消】按钮，放弃返回主画面。
