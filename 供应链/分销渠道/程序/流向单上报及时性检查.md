
# 功能描述

按节点＋产品线/品牌检查所有当前应该上报商品流向单的节点＋产品线/品牌是否及时完成了上报。

# 关键应用

# 业务规则

*  系统从【节点产品线交叉档】中，取[商品流向统计]＝true的节点＋产品线/品牌，按其指定的[流向统计期间规则]，得到当前系统日期对应的统计期间M；
*  根据条件指定的检查期间数N，检查是否存在该节点＋产品线/品牌，从M至M－N这些期间的流向单，且流向单已提交；
*  如果找到满足条件的流向单，则判断该期流向单是否及时上报：流向单的[上报日期]在流向单•[修订截止日期]之前时，为及时上报。

# 栏目说明

流向单上报及时性检查画面栏目说明

|**栏目**|**说明**|
|---|---|
|产品线/品牌|可空，参照料品主档中[系列件层级]＝产品线或品牌的料品；|
|检查期间数N|输入，不可为空，≥0。|

# 按钮说明

*  <执行>：在画面中设定过滤条件后，点击【执行】按钮即可；
*  <调度>：将程生成加入系统调度，在指定时间自动执行。

操作前提：如需重复执行，需先设定“调度计划”。

操作步骤：在画面中设定过滤条件后，点击【调度】，打开调度画面，选择调度方式。

*  执行一次：设定执行日期，系统将在指定日期执行程序。
*  重复执行：指定“调度计划”，系统根据“调度计划”中定义的重复周期定期执行程序。如未设定“调度计划”，可点击栏目链接在线创建调度计划。调度计划定义可参见相关文档。

点击画面中【确定】按钮，将程序加入系统调度，点击【取消】按钮，放弃返回主画面。
