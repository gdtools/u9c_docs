
# 功能描述

通过程序系统按渠道库存滞销条件，定期对渠道流向单库存数据检查是否属于滞销库存。

# 关键应用

# 业务规则

对程序“库存滞销计算”结果，可通过功能“滞销库存核实”，修改和核准节点的滞销库存。

滞销库存判定依据有两种：库龄和周转次数

*  库龄：料品按批号、序列号管理的情况下，可按库龄判断滞销。料品同时按批号和序列号管理的情况下，优先按序列号计算库龄。流向单库存表体的库龄≥设定的滞销库龄天数，系统认定为滞销库存。
*  周转次数：＝流向单流出表体[流出数量]/库存表体[本期库存]。节点连续n期流向单的库存周转次数都≤设定的最低周转次数，系统认定为滞销库存。

# 栏目说明

库存滞销计算画面栏目说明

|**栏目**|**说明**|
|---|---|
|统计期间规则|参照统计规则，可空；|
|最大提前量m|不可为空，≥1；|
|滞销核准|默认否，与条件“手工录入滞销”不能同时选中。此条件选中表示[手工录入滞销]=false且[滞销核准]＝true的滞销数据需要重新计算；|
|手工录入滞销|默认否，与条件“滞销核准”不能同时选中。此条件选中表示[手工录入滞销]=true且[滞销核准]＝false的滞销数据需要重算。|

# 按钮说明

*  <执行>：在画面中设定过滤条件后，点击【执行】按钮即可；
*  <调度>：将程生成加入系统调度，在指定时间自动执行。

操作前提：如需重复执行，需先设定“调度计划”。

操作步骤：在画面中设定过滤条件后，点击【调度】，打开调度画面，选择调度方式。

*  执行一次：设定执行日期，系统将在指定日期执行程序。
*  重复执行：指定“调度计划”，系统根据“调度计划”中定义的重复周期定期执行程序。如未设定“调度计划”，可点击栏目链接在线创建调度计划。调度计划定义可参见相关文档。

点击画面中【确定】按钮，将程序加入系统调度，点击【取消】按钮，放弃返回主画面。
