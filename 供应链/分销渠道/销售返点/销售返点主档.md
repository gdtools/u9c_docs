
# 功能描述

销售返点主档记录节点产生的销售返点数据，通过主档可以查看返点的来源和使用明细。

# 关键应用

# 业务规则

*  销售返点单审核后，会创建销售返点主档，并记录来源明细。
*  返点使用申请单保存后，在销售返点主档记录使用明细。
*  销售返点主档是后续返点使用申请的依据，返点的使用参见【应用专题―销售返还―销售返点】。

# 栏目说明

**销售返点主档头**

|**栏目**|**说明**|
|---|---|
|建档日期|建档的系统日期|
|节点|来源单据表头对应值|
|返还代号|来源单据带入|
|余额作废|来源单据带入；＝true时，每条返点主档记录仅允许被使用1次，没有用完的余额自动作废；|
|返点数|来源单据带入|
|使用点数|＝当前主档∑【销售返点使用明细】中[使用点数]；|
|剩余点数|[余额作废]＝false时，＝[返点数]－[使用点数]；[余额作废]＝true时：[使用点数]＝0，则＝[返点数]；[使用点数]≠0，则＝0；|
|使用生效日期|来源单据带入；|
|使用失效日期|来源单据带入；|
|来源单据|来源单据编号|
|状态|枚举：
   *  开立：主档创建时为此状态；
*  业务关闭：[剩余点数]＝0时，系统置为此状态（不考虑[使用失效日期]是否早于系统日期）；
*  失效关闭：可通过操作“失效关闭”置为此状态，此状态主档不可用；
|

# 按钮说明

*  <操作—取消关闭>：通过此操作，可将主档置为“失效关闭”状态；

操作前提

目标主档的[剩余点数]≠0

操作步骤

在返点主档画面，点击【操作】->【失效关闭】按钮

*  <操作—失效关闭>：通过此操作，将关闭的主档取消关闭；此操作后主档可用。

操作前提

目标主档的[剩余点数]≠0，且当前系统日期早于[使用失效日期]

操作步骤

在返点主档画面，点击【操作】->【取消关闭】按钮。
