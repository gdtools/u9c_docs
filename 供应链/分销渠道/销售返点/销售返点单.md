
# 功能描述

销售返点是以返还点数的形式体现的返利。使用时，可以转销售返还，或者直接转赠品（通过杂发单），或者自定义的其他形式（如提供培训等，系统不做后续处理）。

# 关键应用

# 业务规则

*  可以转销售返还；
*  可以转销售返还；
*  自定义的其他形式;
*  销售返点单在审核之后创建销售返点主档

# 栏目说明

**销售返点单表头**

|**栏目**|**说明**|
|---|---|
|单据类型|非空，选择录入单据类型名称，点击栏目可以在线维护。|
|单号|显示或输入本单的编号。当所选的【单据类型】定义为自动编号时，本栏目显示系统自动生成的单据编号；当所选的【单据类型】定义为手工编号时，需要在本栏目中输入单据编号。**注意:**单据编号不允许重复，在手工输入单号时需特别注意！|
|日期|非空，可改。|
|节点|可空，参照节点档；保存后不可修改；|
|返还代号|表示企业在每次计算返点时指定的代号；录入，不得为空；|
|返点数|＝∑对应表体行[返点数]；系统维护，不可改|
|核准返点数|＝∑对应表体行[核准返点数]；系统维护，不可改|
|余额作废|＝true时，表示当前返点单创建的返点主档记录仅允许被使用1次，没有用完的返点余额自动作废；|
|使用生效日期|表示当前销售返点单所创建返点主档的使用有效期的起始日期；默认＝当前日期，可改，不可为空；|
|使用失效日期|表示当前销售返点单所创建返点主档的使用有效期的终止日期；默认＝9999.12.31，可改，不可为空；|

**销售返点单表体**

|**栏目**|**说明**|
|---|---|
|物料|参照料品主档中[料品形态属性]≠“系列”的料品；|
|子品牌|参照料品主档中[系列件层级]＝子品牌的料品；[物料]＝null时，可编辑；|
|品牌|参照料品主档中[系列件层级]＝品牌的料品；[物料]和[子品牌]都为空时，可编辑；|
|产品线|参照料品主档中[系列件层级]＝产品线的料品；[物料]和[品牌]都为空时可编辑；|
|返点数|手工录入，＞0|
|核准返点数|默认＝[返点数]，审核时可改；|
