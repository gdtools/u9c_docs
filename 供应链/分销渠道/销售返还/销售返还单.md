
# 功能描述

将在系统外计算出的客户的销售返还，通过销售返还单录入到系统中，审核后生成销售返还主档。

# 关键应用

# 业务规则

*  在渠道参数中设置参数“返还单中返还政策允许为空”；

# 栏目说明

销售返还单头-基本页签

|**栏目**|**说明**|
|---|---|
|单据类型|非空，选择录入单据类型名称，点击栏目可以在线维护。|
|单号|显示或输入本单的编号。当所选的【单据类型】定义为自动编号时，本栏目显示系统自动生成的单据编号；当所选的【单据类型】定义为手工编号时，需要在本栏目中输入单据编号。![http://10.16.226.26/U9/help/zh-CN/Content/Resources/Images/%E6%B3%A8%E6%84%8F.jpg](https://ncc-pub-ublim.oss-cn-beijing.aliyuncs.com/help/photo/d40449bd-2293-4d5f-a50e-2118f96f08e9.png)**注意:**单据编号不允许重复，在手工输入单号时需特别注意！|
|日期|非空，可改。|
|节点|可空，参照节点档；保存后不可修改![http://10.16.226.26/U9/help/zh-CN/Content/Resources/Images/%E6%B3%A8%E6%84%8F.jpg](https://ncc-pub-ublim.oss-cn-beijing.aliyuncs.com/help/photo/d40449bd-2293-4d5f-a50e-2118f96f08e9.png)**注意:**返还政策＋返还代号＋节点不允许重复；|
|返还代号|表示企业在每次计算返还时指定的代号；录入，不得为空；|
|返还政策|表示当前返还所依据的返还政策。参照当前组织中的返还政策主档，保存后不可修改；![http://10.16.226.26/U9/help/zh-CN/Content/Resources/Images/%E6%B3%A8%E6%84%8F.jpg](https://ncc-pub-ublim.oss-cn-beijing.aliyuncs.com/help/photo/d40449bd-2293-4d5f-a50e-2118f96f08e9.png)**注意:**
   *  是否允许为空取决于org级渠道参数“返还单中返还政策允许为空”的取值； 
*  单据保存之前，[返还政策]修改、清空后，将清空表体；
*  如果所选[返还政策]的[政策相关性]＝“地区”或“物料地区”，则[节点]的[地区]必须在所选[返还政策]的地区范围内。
|
|使用币种限制|[返还政策]≠null时，默认＝[返还政策]对应值；[返还政策]＝null时，默认＝false。可改|
|币种|参照币种档，默认＝当前组织所属法人组织的本位币；可改，不可为空|
|返还金额|＝∑对应表体行[返还金额]；系统维护，不可改|
|核准返还金额|＝∑对应表体行[核准返还金额]；系统维护，不可改|

销售返还单头-使用方式页签

|**栏目**|**说明**|
|---|---|
|转赠品|＝true，表示当前返还单生成的返还主档，在使用时可在杂发单中使用，将返还金额通过为客户提供赠品的方式使用返还；[返还政策]≠null时，默认＝[返还政策]对应值；[返还政策]＝null时，默认＝true；可改|
|订单冲减|＝true，表示当前返还单生成的返还主档，可在销售订单中用于冲减订单金额；[返还政策]≠null时，默认＝[返还政策]对应值；[返还政策]＝null时，默认＝true；可改|
|出货冲减|＝true，表示当前返还单生成的返还主档，可在销售出货单中使用，冲减出货金额；[返还政策]≠null时，默认＝[返还政策]对应值；[返还政策]＝null时，默认＝true；可改|
|应收冲减|＝true，表示当前返还单生成的返还主档，可在应收单中用于冲减应收金额；[返还政策]≠null时，默认＝[返还政策]对应值；[返还政策]＝null时，默认＝true；可改|
|税务发票冲减|＝true，表示当前返还单生成的返还主档，可在税务发票中用于冲减发票金额；[返还政策]≠null时，默认＝[返还政策]对应值；[返还政策]＝null时，默认＝true；可改|
|使用生效日期|表示当前销售返还单所创建返还主档的使用有效期的起始日期；[返还政策]≠null时，＝null，不可改；[返还政策]＝null时，默认＝当前日期，可改，不可为空；|
|使用失效日期|表示当前销售返还单所创建返还主档的使用有效期的终止日期；[返还政策]≠null时，＝null，不可改；[返还政策]＝null时，默认＝9999.12.31，可改，不可为空；|

*  表头[返还政策]的政策物料页签中，行[物料]和[子品牌]为空、[品牌]非空时：如果[渠道级别]为空，可选择所有归属该品牌的物料；如果[渠道级别]非空，表头节点＋该[品牌]或[品牌]归属的[产品线]在【节点产品线交叉档】中的[渠道级别]等于该[渠道级别]，则可选择所有归属该品牌的物料；
*  表头[返还政策]的政策物料页签中，行[物料]、[子品牌]和[品牌]为空、[产品线]非空时：如果[渠道级别]为空，可选择所有归属该产品线的物料；如果[渠道级别]非空，表头节点＋该[产品线]在【节点产品线交叉档】中的[渠道级别]等于该[渠道级别]，则可选择所有归属该产品线的物料；

# 相关主题

在渠道参数中设置参数“返还单中返还政策允许为空”；

设置销售返还政策（可选）；

设置节点（必须）；

设置料品（必须）；

在料品档中设置“产品线”、“品牌”、“子品牌”，即“料品形态属性”为“系列件”的料品，并指定其“系列件层级”（可选）；
