
# 功能描述

销售返还主档记录节点产生的销售返还，通过主档可以查看返还的来源和使用明细。

# 关键应用

# 业务规则

*  销售返还单、销售返点使用申请单（“兑换形式”为“转返还”）、销售返利额度使用申请单的审核后，会创建销售返还主档，并记录来源明细；
*  在销售订单、销售出货单、杂发单、税务发票、应收单，使用销售返还后，在销售返还主档记录使用客户、使用金额、使用单据等使用明细；

# 按钮说明

*  <操作--失效关闭>：

操作概述：通过此操作，可将主档置为“失效关闭”状态；

操作前提 ：目标主档的[返还金额]≠[使用金额]

操作步骤：在返还主档画面，点击【操作】->【失效关闭】按钮

*  <操作—取消关闭>：

操作概述：通过此操作，将关闭的主档取消关闭；此操作后主档可用。

操作前提：目标主档的[返还金额]≠[使用金额]，且当前系统日期早于该主档[使用失效日期]

操作步骤：在返还主档画面，点击【操作】->【取消关闭】按钮。
