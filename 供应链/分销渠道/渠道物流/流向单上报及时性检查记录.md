
# 功能描述

渠道管理人员查看程序“流向单上报及时性检查”的检查结果，了解节点是否上报了商品流向，及是否及时上报。

# 关键应用

# 业务规则

*  可根据检查结果，对节点进行奖惩。
*  查询结果不可编辑。

# 栏目说明

检查记录画面栏目

|**栏目**|**说明**|
|---|---|
|**检查日期**|显示程序检查的系统日期|
|**节点**|显示检查的节点|
|**产品线/品牌**|显示检查的产品线、品牌|
|**流向统计期间规则**|显示节点＋产品线/品牌在【节点产品线交叉档】中“流向统计期间规则”|
|**流向统计期间**|显示流向统计期间|
|**流向统计起始日期**|显示“流向统计期间”的起始日期|
|**流向统计截止日期**|显示“流向统计期间”的截止日期|
|**及时上报**|[流向单编号]不为空，且流向单•[上报日期]在流向单•[修订截止日期]之前，=true；否则，=false。|
|**流向单编号**|节点＋产品线/品牌对应的流向单编号。|
