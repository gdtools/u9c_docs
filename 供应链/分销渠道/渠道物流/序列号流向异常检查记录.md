
# 功能描述

渠道管理人员查看程序“序列号流向异常检查”的结果，在查明异常原因后，对异常记录进行处理。

# 关键应用

# 业务规则

*  渠道管理人员查看程序“序列号流向异常检查”的结果，在查明异常原因后，对异常记录进行处理；

# 栏目说明

序列号流向异常检查记录画面表头

|**栏目**|**说明**|
|---|---|
|**检查日期**|程序“序列号流向异常检查”执行时的系统日期，不可改|
|**组织范围**|枚举：
   *  跨组织
*  单组织
程序“序列号流向异常检查”的检查条件，不可改|
|**重复库存**|表示相同的序列号出现在2个和2个以上节点的最新一期流向单库存数据中。程序“序列号流向异常检查”执行时系统维护，不可改|
|**重复纯销**|表示同一个的序列号，在多个节点的流出数据中存在2条和2条以上[是否纯销]=“true”的记录。程序“序列号流向异常检查”执行时系统维护，不可改|
|**流入异常**|表示流向单流入表体中序列号，在其“来源节点”的流出记录中，没有找到对应序列号。如节点A有流入序列号001，来源节点是B，在节点B流出数据中无去向节点是A、序列号为001的流出记录，或无去向节点为空、序列号为001的流出记录。程序“序列号流向异常检查”执行时系统维护，不可改|
|**流出异常**|表示流出表体中序列号，在其“去向节点”的流入记录中，没有找到对应序列号。如节点A有流出序列号002，去向节点为C，在节点C流入数据中无来源节点是A、序列号为002的流入记录，或无来源节点为空、序列号为002的流入记录。程序“序列号流向异常检查”执行时系统维护，不可改|
|**检查期间数n**|程序“序列号流向异常检查”的检查条件，不可改|
|**异常料品**|出现异常序列号的[料品]，不可改|
|**异常序列号**|出现异常的序列号，不可改|
|**重复库存统计截止日期**|程序“序列号流向异常检查”的检查条件，不可改|
|**异常原因**|枚举，根据查明的异常原因选择：
   *  窜货
*  谎报数据
*  上报错误
*  退货后再次销售
*  其他
|
|**详细说明**|录入异常原因调查的详细说明|
|**取消异常检查**|选择true，则保存后系统将序列号的[异常检查]值改为true，下一次程序“序列号流向异常检查”执行时跳过该序列号。|
|**处理日期**|系统日期，不可改|
|**处理人**|当前操作用户，系统自动维护，不可改|

序列号流向异常检查记录画面表体

|**栏目**|**说明**|
|---|---|
|**流向单号**|出现异常序列号的流向单号；系统自动维护，不可改|
|**流向统计期间**|出现异常序列号的的流向单的[流向统计期间]；系统自动维护，不可改|
|**上报日期**|出现异常序列号的的流向单的[上报日期]；系统自动维护，不可改|
|**异常组织**|出现异常序列号的流向单的[组织]；系统自动维护，不可改|
|**异常节点**|出现异常序列号的流向单行的[节点]；系统自动维护，不可改|
|**流入来源组织**|出现异常序列号的流向单行为流入表体时，为表体行的[来源组织]；系统自动维护，不得手工修改|
|**流入来源仓库**|出现异常序列号的流向单行为流入表体时，为表体行的[来源仓库]；系统自动维护，不得手工修改|
|**流入来源节点**|出现异常序列号的流向单行为流入表体时，为表体行的[来源节点]；系统自动维护，不得手工修改|
|**流出去向节点**|出现异常序列号的流向单行为流出表体时，为表体行的[去向节点]；系统自动维护，不得手工修改|
