
# 功能描述

渠道管理人员查看程序“流向数量异常检查”的结果，在查明异常原因后，对异常记录进行处理。

# 关键应用

# 业务规则

*  渠道管理人员查看程序“流向数量异常检查”的结果，在查明异常原因后，对异常记录进行处理。

# 栏目说明

流向数量异常处理画面

|**栏目**|**说明**|
|---|---|
|**检查日期**|程序“流向数量异常检查”执行时的系统日期，不可改|
|**流入异常**|表示节点的流入数据中，系统在其流入数据的来源节点的流向单流出数据中，未找到对应的流出记录，或流出记录中流出数量与节点流入数量不符。程序“流向数量异常检查”执行时系统维护，不可改|
|**流出异常**|表示节点的流出数据中，系统在其流出数据的去向节点的流向单流入数据中，未找到对应的流入记录，或流入记录中流入数量与节点流出数量不符，视为流出异常。程序“流向数量异常检查”执行时系统维护，不可改|
|**间隔期间数n**|程序“流向数量异常检查”的检查条件，不可改|
|**异常单据**|程序“流向数量异常检查”执行时系统维护，为出现异常的商品流向单号，不可改|
|**异常节点**|出现异常的流向单行的[节点]，不可改|
|**来源节点**|发现异常的为流向单流入表体，为流入表体的[来源节点]，不可改|
|**去向节点**|发现异常的为流向单流出表体，为流出表体的[去向节点]，不可改|
|**异常料品**|出现异常的流向单行的[料品]，不可改|
|**等级**|出现异常的流向单行的[等级]，不可改|
|**成分**|出现异常的流向单行的[成分]，不可改|
|**料品自由项1-3**|出现异常的流向单行的[料品自由项]，不可改|
|**批号**|出现异常的流向单行的[批号]，不可改|
|**项目**|出现异常的流向单行的[项目]，不可改|
|**单位**|出现异常的流向单行的[单位]，不可改|
|**流出数量**|发现异常的为流向单流出表体，为表体行[流出数量]，不可改|
|**流入数量**|发现异常的为流向单流入表体，为表体行[流入数量]，不可改|
|**勾稽累计差额**|发现异常的为流向单流入表体，为流入表体的[流入数量]－[流出勾稽累计]，不可改；发现异常的为流向单流出表体，为流出表体的[流出数量]－[流入勾稽累计]，不可改；|
|**异常原因**|枚举，根据查明的异常原因选择：1、来源非法2、谎报数据3、对方上报数据错误4、其他流入异常＝true时，可以选择1、3、4流出异常＝true时，可以选择2、3、4|
|**详细说明**|录入异常原因调查的详细说明|
|**取消异常检查**|选择true，则保存后系统将流向单行的[勾稽结束标识]值改为true，下一次程序“流向数量异常检查”执行时跳过该行。|
|**处理日期**|系统日期，不可改|
|**处理人**|当前操作用户，系统自动维护，不可改|
