
# 功能描述

商品流向单记录渠道节点在特定时间内发生的商品流入、流出和库存结余数据。

# 关键应用

# 业务规则

*  节点可根据节点产品线交叉中设置的流向编辑方式，在流向单中填报流入、流出或库存三种数据中的任意两种。
*  如要求节点上报流入流出数据，系统根据节点上报的流入、流出，自动根据上期库存计算出本期的库存。

# 按钮说明

*  <带入上期库存>：

操作概述：

[流向编辑方式]＝“流入库存”或“流出库存”时，通过此操作，可将上期流向单的库存表体的所有记录，带入当前流向单库存表体，减少录入的工作量。

操作前提：

流向单表头[流向编辑方式]＝“流入库存”或“流出库存”

操作步骤：

点击【带入上期库存】按钮，系统将上期流向单的库存表体的所有记录，带入当前流向单库存表体中。
