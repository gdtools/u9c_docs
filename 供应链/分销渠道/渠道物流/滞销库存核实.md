
# 功能描述

通过程序“库存滞销计算”计算完节点的滞销库存，渠道物流管理人员与节点沟通，核实库存的滞销数量，修改和核准节点的滞销库存。

# 关键应用

# 业务规则

*  渠道物流管理人员与节点沟通，核实库存的滞销数量，修改和核准节点的滞销库存；

# 栏目说明

滞销库存核实画面――基本页签

|**栏目**|**说明**|
|---|---|
|**滞销量**|当前行不存在序列号子表时，可编辑；默认取符合条件流向单库存表体行[滞销量]；当前行存在序列号子表时，＝序列号子表中[滞销状态]为true的序列号数量**注意：**
   *  [滞销量]＞0时，必须≤[库存量]
*  [滞销核准]＝true时，[滞销量]必须＞0
|
|**滞销核准**|表示节点此料品的滞销量已经核实；[滞销量]＞0时，可编辑；|
|**手工录入滞销**|系统维护，不可编辑；行[滞销量]修改，或者序列号子表中的[滞销状态]修改，则[手工录入滞销]=true|

滞销库存核实画面――序列号页签

|**栏目**|**说明**|
|---|---|
|**序列号**|不可编辑|
|**库龄**|取符合条件流向单库存序列号子表行[库龄]；不可编辑|
|**滞销状态**|取流向单库存表体序列号的[滞销状态]；可编辑|
