
# 功能描述

查询料品某序列号的流入流出路径。

# 关键应用

# 业务规则

*  统计数据

已提交流向单参与统计。

流向单的“流向统计起始日期”≥条件指定的“起始日期”，“流向统计截止日期”≤条件指定的“结束日期”。

*  统计条件

系统在查询方案中（查询方案）提供默认的统计条件，

不同的统计方式对应不同的统计条件。

另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

*  统计结果

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。
