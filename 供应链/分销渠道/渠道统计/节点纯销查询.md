
# 功能描述

查询各节点的料品纯销数据。

# 关键应用

# 业务规则

*  统计数据

已提交流向单参与统计。

流向单的“流向统计起始日期”≥条件指定的“起始日期”，“流向统计截止日期”≤条件指定的“结束日期”。

纯销数量：为流向单流出表体行[是否纯销]＝true的数量；

*  统计条件

系统在查询方案中（查询方案）提供默认的统计条件，

不同的统计方式对应不同的统计条件。

另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

*  统计结果

不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 栏目说明

# 按钮说明

*  <查找>：点击【查找】按钮，在弹出画面中设置过滤条件，系统按照过滤条件，从节点已经提交的流向单库存表体中，查找符合条件的库存行。

库存表体行需满足：

*  表体[料品]必须为[料品形态属性]≠“系列”的料品，且
*  流向单已提交，且
*  节点＋料品的流向单[流向统计截止日期]距离当前日期最近，且
*  库存表体行[本期库存]＞0

查找条件栏目说明

|**栏目**|**说明**|
|---|---|
|**地区**|参照地区档，可为空；此条件约束查询结果中的[节点]•[地区]＝条件指定的[地区]|
|**客户**|参照客户档，可为空；此条件约束查询结果中的[节点]•[对应客户]＝条件指定的[客户]|
|**节点**|参照节点档，可为空；**注意：**
   *  条件[地区]非空时，节点•[地区]在条件选择的[地区]范围内；
*  条件[客户]非空时，节点的[对应客户]＝所选[客户]。
|
|**库存分类**|只能选对应[分类体系]•[库存分类]＝true的料品分类，可为空；|
|**料品**|参照料品主档，可为空；只能选[可统计流向]＝true的料品；[库存分类]非空时，可选[料品]的[库存分类]＝所选[库存分类]|
|**批号**|输入，可为空。|
|**仅限滞销**|＝true时，表示只查询[滞销量]＞0的流向单库存表体行；＝false时，不限制|
|**滞销核准**|条件[仅限滞销]＝true时有效；＝true时，表示只查询[滞销核准]＝true流向单库存表体行|
|**手工录入滞销**|条件[仅限滞销]＝true时有效；＝true时，表示只查询[手工录入滞销]＝true流向单库存表体行|
|**库龄（≥）**|输入，可为空；此条件约束查询出的流向单库存表体的[库龄]必须≥条件指定的[库龄]；|
|**周转次数（≤）**|输入，可为空；此条件约束查询出的流向单库存表体的[周转次数]必须≤条件指定的[周转次数]；|

*  <保存>：点击【保存】按钮，保存画面编辑结果；
*  <审核>：多选行，点击【审核】按钮，将选中行的[滞销状态]置为true
