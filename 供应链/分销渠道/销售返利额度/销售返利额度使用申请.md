
# 功能描述

通过返利额度使用申请，将节点符合使用要求、可以使用的返利额度，申请转为返还。

# 关键应用

# 业务规则

*  返利额度使用申请在审核之后，生成返还主档，并记录在返还主档的来源明细中；
