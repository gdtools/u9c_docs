
# 功能描述

销售返利额度主档记录节点产生的销售返利额度数据，通过主档可以查看返利额度的来源和使用明细。

# 关键应用

# 业务规则

*  销售返利额度主档是后续返利额度使用申请的依据；
*  销售返利额度单审核后，会创建销售返利额度主档，并记录来源明细。
*  返利额度使用申请单保存后，在销售返利额度主档记录使用明细

# 按钮说明

*  <操作--失效关闭>：可将主档置为“失效关闭”状态

操作前提 ：目标主档的[返利额度]≠[使用额度]

操作步骤：在返利额度主档画面，点击【操作】->【失效关闭】按钮。

*  <操作--取消关闭>：将关闭的主档取消关闭；此操作后主档可用；

操作前提：目标主档的[返利额度]≠[使用额度]且当前系统日期早于[使用失效日期]

操作步骤：在返利额度主档画面，点击【操作】->【取消关闭】按钮。

*  <相关功能--销售返利额度单>：导航到销售返利额度单功能节点。
*  <相关功能--销售返利额度使用申请>：导航到销售返利额度使用申请功能节点。
