
# 功能描述

进入销售管理－>期初－>期初出货

系统初始上线时，需要将此前未立账未开票的出货记录录入进系统中，以便在系统上线后可以针对出货记录开票和立账。与标准出货相比，存在以下差异：

*  只可以手工录入，不可以根据订单和出货计划生成。
*  不可以进行信用检查。
*  不可以录入预收款。
*  根据启用日期确定记账期间，不可以手工选择。
*  单据日期不可以晚于系统启用日期。
*  无论是否自动生成业务分录参数取何值，均不可以生成业务分录。

# 业务规则

*  参数设定，与标准出货相关参数
*  必须先设定单据类型
*  必须先设定立帐条件、收款条件
*  必须先设定料品的存储地点
*  必须先设定出货原则
*  有价格管理的应用需定义价目表；
*  管控信用，需要启用应收系统，定义信用政策；

# 按钮说明

*  <使用销售返还>：出货单中使用销售返还，是通过使用销售返还，用使用的销售返还额冲减出货单行的“价税合计”，并影响“最终价”和冲减客户的应收。
*  <销售返还使用明细>：查看单据行的销售返还使用明细信息。焦点在单头，此操作为单操作；焦点在行，此操作为行操作。
*  <补货>：当前出货单如需要补货，根据当前出货单生成补货订单。
*  <发布>：出货后，可将出货通知发布在客户门户上通知客户，有客户签收的可在客户门户上进行签收。
*  <交易分录>：点击销售与分销－>出货－>标准出货－>操作－>交易分录，默认显示出货单生成的库存异动记录对应的交易分录，可通过翻页显示出货单对应的业务分录。
*  <批量拆行/拆行>：在拆行画面中，显示出货单行料品在当前组织的不同仓库中的可用数量，由用户选择后，分解成出货单行。
*  <快速录入>：为提高录入效率，用户可通过“快速录入”画面录入出货单相关料品信息
*  <批量调价>：提供根据一定条件，对当前出货单的最终价进行批量调整功能。
*  <协同抛单>：是指根据销售出货单中销售订单中相关业务信息（客户及联系对象、贸易路径等），生成关系企业组织采购收货单；并可根据贸易路径的设置是否继续进行抛转。
*  <整单预收特例>：针对当前单据单头申请特殊的预收政策。
*  <行预收特例>：针对当前单据单行申请特殊的预收政策。
*  <整单/行价格重算>：根据出货单上已录入的价表、折扣等信息重新计算料品的价格相关项目，如金额、税额等。可重算整个出货单所有料品；也可选定某个出货单行重新计算指定料品。参见应用专题——销售中的价格与折扣
*  <客户状况>：查询出货单订货客户的情况，包括客户的相关财务情况与最近发生业务的日期，如应收款、最近订货日、最近发货日等。
*  <立账收款计划>：无来源的、来源于合同的出货单，系统根据单头立账条件以及单据行金额，自动创建立账收款计划。用户可通过本功能查看、编辑立账收款计划。来源于订单、预出货单的出货单，可通过本功能查看立账收款计划。（此时不可修改立账收款计划，如需修改，必须从源头单据修改，然后系统会自动同步到出货单。）
*  <产品结构查询>：当出货单料品为PTO\ATO\FAS\Model等物料形态时，可在此查询料品的BOM结构。
*  <替代>：以其他料品替代当前出货单行料品
*  <料品状况查询>：查看出货单料品的情况，包括料品的库存、销售、采购以及计划生产信息。画面为查询画面，不可编辑。
*  <来源生单操作>：指定出货单的具体来源单据生成出货单,订单来源单据包括合同、订单、出货计划、预出货单。来源生单一次仅能生成一张销售订单。
*  <包装>：维护出货单料品的包装信息。
*  <快速形态转换>：当前出货单行，料品项目号的库存可用量不足时，可以通过快速形态转换，将其他项目号的库存转换成当前出货单行项目号的库存。
