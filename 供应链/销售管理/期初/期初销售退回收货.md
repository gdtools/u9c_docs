
# 功能描述

系统初始上线时，需要将此前已收退回货物,但是未开红票给客户的记录录入系统中，以便在系统上线后做销售退回处理。


# 业务规则

*  参数设定
*  定义收货单单据类型（必做）
*  定义供应商档案（必做）
*  定义组织档案（必做）
*  定义采购业务部门（必做）
*  定义采购业务员（必做）
*  定义料品档案（必做）
*  定义计量单位（必做）
*  定义币种（必做）
*  定义存储地点（必做）
*  定义收货原则（必做）
*  定义税组合（必做）
*  定义单据类型（必做）
*  定义应付立账条件档
*  定义付款条件档
*  启用销售管理模块

# 按钮说明

*  <快速录入>：快速录入功能能够快速录入多条物料信息，包括物料、数量、计量单位、交期信息。该功能能够提高单张单据的录入效率。
*  <查询库存>：导航到[请购](/detail/019c4a5a090a491dbb30452da04b6759)可以查询料品所在仓库的库存状况，包括库存可用量、库存量、预留量、当前预留量、预留占用量等信息。
*  <预付款挪用（整单预付挪用、行预付挪用）>：当前收货单可以挪用其他单据的预付款，执行本操作后，其他单据的预付款要自动扣减。
*  <整单价格重算>：价格重算是对物料重新进行取价计算的操作。
*  <行价格重算>：价格重算是对物料重新进行取价计算的操作。
*  <供应商状况>：导航到[供应商状况](javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkCBO.Pub.Supplier.SupplierReport&sId3000nid&mId1001101159162174","%E4%BE%9B%E5%BA%94%E5%95%86%E7%8A%B6%E5%86%B5");)可以查询供应商状况。
*  <替代>：单据中的物料可以使用替代品，通过本功能进行物料的替代操作。
*  <料品状况查询>：导航到[料品数量状况](/detail/b850e9ebf7c14d789a5690859dfee156)查询料品状况。
*  <产品结构查询>：点击产品结构查询，可以查询料品的产品结构
*  <序列号查询>：点击序列号查询，可以查询料品的序列号信息，包括已录序列号数量，子行号对应的序列号等。
*  <交易分录>：点击交易分录，可以查看收货单交易分录情况。
*  <协同抛单>：当收货单来源于多角贸易的采购订单时，点击协同抛单，可以自动将的采购收货单抛转为本组织的出货单。
*  <取消抛单]>：当收货单来源于多角贸易的采购订单时，点击取消抛单，可以自动取消采购收货单抛转的本组织的出货单。
*  <点收（整单点收、行点收）>：点击整单点收，可以整单点收当前收货单。点击行点收，可以对当前收货单行点收。
*  <拆行>：点击拆行，弹出“批量拆解批号画面”，可以将一行拆解成多行，形成多个批号。
*  <显示拆前行/隐藏拆前行>：点击显示拆前行，可以显示收货单检验前的拆前行。点击隐藏拆前行，可以隐藏收货单检验前的拆前行。
*  <解除>：收货由于某种原因需要将单据挂起，等待问题解决后再解除挂起。
*  <挂起>：收货由于某种原因需要将单据挂起，等待问题解决后再解除挂起。
*  <分发>：当物料为费用性物料时，收货可以不入库，而是选择直接分发；另外一种情况是生产领料，例如分发到生产订单。
*  <预占库位（整单预占库位、行预占库位）>：当收货程序中先入库后检验的时候，需要预占库位。
*  <检验>：当收货程序中具有检验的时候，需要进行检验操作。
*  <理货（整单理货、行理货）>：在进行库位管理时使用理货功能。
*  <预算执行>：全面预算控制时，可通过此功能设置＼调整对应的预算指标（指标值）　。
*  <后续调价>：对于允许事后调价的料，允许先收货，然后在立应付之前调整收货单中的价格。
*  <退货申请>：退货申请将当前收货单数量转退货申请单。
*  <退出库位>：当收货程序中有预占库位，检验后存在“不合格拒收”的料品，需要退出库位，转为退货单。
*  <补货>：补货将对当前单据进行补货，生成新的单据。
*  <预付款录入>：收货单可以直接选择应付系统中已有的付款单，也可以在线新增预付款单。
