
# 功能描述

退货申请，是指客户因物品质量、品种、数量不符合要求或者其它原因，而将已购货物申请退回。

# 关键应用

*  提供公共基本操作：增、删、改、印、保存、查询、复制、提交审批、状态维护；
*  可以查看退货料品的收货、开票、立账等信息；

# 业务规则

*  提供序列号检查、数量检查和三包期限检查；
*  根据样品检验结果，确定核定处理类型；
*  提供按批号和按序列号的蹿货控制；
*  对退货申请的核定处理，可拆行按数量确定核定处理类型。
*  对需要维修的退货，可在线维护其维修状态。

# 按钮说明

*  <快速退货>:

根据用户常用的属项快速指定退回单的具体来源出货单，生成一张退货申请单。支持按序列号退货、按批号退货、按料品序列号退货和按料品批号退货四种快速退货模式。

**操作前提:**无。

**操作步骤:**

**第1步：**点击【快速退货】功能按钮。

**第2步：**根据快速退货模式输入过滤条件后确定。

按序列号退货：必须输入退货客户和序列号。

按批号退货：必须输入退货客户和批号。

按料品序列号退货：必须输入退货客户、料品和序列号。

按料品批号退货：必须输入退货客户、料品和批号。

**第3步：**在“出货单行列表画面”中选择来源单据，点击确定按钮生成退货申请单并返回原画面；点取消放弃操作返回原画面。

系统自动将所选单据的内容带入到当前单据中

点击[来源单据]栏目链接可查看来源单据的详细内容。

*  <操作_批量生单[头]>:此功能用于将所选择的订单和出货单批量生成多张退货申请。

**操作前提**

无

**操作步骤**

**第1步：**点击**【操作】->【批量生单】**按钮，弹出批量生单过滤画面。

**第2步：**输入退货客户、退货料品或合同号等过滤条件后确定。

**第3步**：在批量生单来源单据列表视需要输入要退货的数量，点击确定按钮生成退货申请单并返回原画面。

*  <操作_拆行[行]>

如果客户请求退货的料品，经过核定，需要进行不同的退货处理，则可用功能将选定的退货申请行生张多行，按分拆后的行确定核定的RMA类型。

**操作前提**

无

**操作步骤**

**第1步：**点击**【操作】->【拆行】**按钮，弹出拆行画面。

**第2步：**在拆行画面中输入每行的数量及核定的RMA类型后确定。

**第3步**：返回原画面即会按拆行画面拆分退货申请行。

*  <操作_受理[单]>

根据退回商品的具体情况，判定该退货申请可以进行后续处理。

**操作前提:**已定义退货条件及退货、换货和维修期限,当前退货申请已保存。

**操作步骤**

点击【操作】->【受理】按钮操作，系统根据规则自动进行期限检查、数量检查、批号和序列号检查。只可整单执行，不可以按行执行。受理不过，系统将给出提示。

*  <操作_序列号结果[子行]>:可弹出序列号结果画面，用于显示和维护退回商品的序列号情况。

针对退货单的行进行操作

操作步骤

点击【操作】->【样品检测结果】按钮，弹出“样品检测结果”画面，此画面为列表画面，具体栏目说明参见上表。在此画面可以进行【新增】、【插入】、【删除】行等操作。设置完成，点击画面上的【确定】按钮，即保存样品检测结果。如果要取消当前录入，点击画面上的【取消】按钮即可返回主画面。

*  <操作_期限检查[单]>

根据退回商品的销售日期，以及退货条件中定义的退换货期限，判定客户是否允许退货、换货和维修。

**操作前提**

定义退货条件及退货、换货和维修期限

仅对“赊账RMA”、“接收并退款RMA”、“调换RMA”和“维修RMA”有效，对其他RMA类型无效。

**操作步骤**

点击【操作】->【期限检查】按钮操作，系统根据规则自动检查当前单据料品是否符合退货条件。只可按单执行，不可按行执行

*  <操作_数量检查[单]>:根据退货单与来源单据的，以及退货条件中定义的退换货期限，判定客户是否允许退换货。

**操作前提:**单据类型中，定义此种单据类型需要进行数量检查。

**操作步骤:**点击【操作】->【数量检查】按钮操作，系统根据规则自动检查当前单据料品是否合法。按单执行，不可按行执行

“赊账RMA”、“接收并退款RMA”和“调换RMA”类型退货申请，检查未通过将弹出警示画面。

*  <操作_挂起[单]>:“挂起”用于在业务进行中，由于某种原因需要暂时对单据或单据行中断业务进程，此时可以使用此功能。此操作可逆，可以用“解除”功能取消挂起。

**操作前提:**目标未关闭、未挂起、未终止

**操作步骤:**点击【操作】->【挂起】按钮，即可以完成对当前目标的挂起。

*  <操作_解除[单]>：此操作为“挂起”操作的逆操作，可以对已挂起的目标取消挂起，以便进行完后续的业务流程。

**操作前提：**目标为已挂起状态

**操作步骤：**点击【操作】->【解除】按钮，即可以完成对当前目标的取消挂起。

*  <操作_终止[单]>：对于一张单据，如果业务终结，系统自然关闭，则此单据不能再打开；相反，如果由于短缺或其它原因手工关闭的单据可以再次打开，进行后续业务流程。

**操作前提：**当前单据必须是“打开”未“挂起”未“终止”状态

**操作步骤：**点击【操作】->【关闭】按钮，即可以完成对当前目标的关闭。

*  <操作_终止[单]>:对于由于某种原因，不能或没必要进行完业务流程的单据或单据行，可以通过此功能强行终止业务。终止后的单据或单据行永久无效，此操作不可逆。

**操作前提:**目标为非挂起、非关闭、非终止状态

**操作步骤:**点击【操作】->【终止】按钮，即可以完成对当前目标的终止。

*  <执行情况>：可弹出“退货行执行情况”画面显示该退货申请的收货、开票、立账等信息。

**操作前提：**无

**操作步骤：**点击【执行情况】按钮，即可打开画面查询退货行的执行情况。

*  <来源生单>:指定退货申请的具体来源单据，包括订单、出货单。来源生单一次仅能生成一张退回单。

**操作前提:**

订单或出货单所属组织必须与当前组织一致。

订单或出货单的物料行中【允许退货】为真。

**操作步骤:**

**第1步：**在[来源类别]中确定本次操作的来源单据是订单还是出货单。

**第2步：**确定[来源类别]后，点击[来源单据]栏目选择按钮，打开“来源单据列表画面”。

来源单据列表画面中除[本次退货数量1]、[本次退货数量2]外，其他栏目均为显示项，显示来源单据的基本情况，不可编辑。

所输入的[本次退货数量1]、[本次退货数量2]将代入到所生成的退回单中。

**第3步：**在“来源单据列表画面”中选择来源单据，点击确定按钮生成退回单并返回原画面；点取消放弃操作返回原画面。

系统自动将所选单据的内容带入到当前单据中

点击[来源单据]栏目链接可查看来源单据的详细内容。
