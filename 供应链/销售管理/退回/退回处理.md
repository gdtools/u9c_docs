
# 功能描述

退货处理，是退货申请的后续执行单据，可以根据需要立账开票，也可生成补货订单。

# 关键应用

# 业务规则

*  提供公共基本操作：增、删、改、印、保存、查询、复制、提交审批、状态维护；
*  进行退货价格方面的检查；
*  对退货过程中所发生业务的管理：税、费用等；
*  视需要生成补货订单。
*  对需要换货的退货单，可推式生成补货订单；

# 按钮说明

*  <查询>：调用查询条件界面，重新设置查询条件，进行新的查询；
*  <发布>：将选中的记录发布到供应商门户，询价单发布后供应商才可在门户中查看；
*  <取消发布>：对已经发布的询价单进行取消发布操作，仅发布态的询价单才可取消发布。
*  <询价明细>：查看询价批对应的询价明细信息，采购系统参数进行中的报价是否可见=False时，只有到报价截止日期才可查看。
