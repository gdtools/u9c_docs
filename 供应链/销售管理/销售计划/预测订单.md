
# 功能描述

当企业出于管理上的需要、不希望以销售计划来描述和驱动预先采购原材料、预先进行生产的活动时，可以用“预测订单”的实体来驱动这种预投活动。

可维护以“预投”为目的的预测订单，也可维护以“预采”为目的的预测订单。

预测订单核准后，可被MPS、MRP计算时抓取，用于产生预投的生产订单和采购订单。预测订单的修改、删除、关闭、打开，都会影响到MRP/MPS的需求。

预测订单保存后，可以将该预测订单行拆分为时栅更细的预测订单行，使得预采/预投的数量在一个时间跨度内分布得更加均衡。拆分后，旧行删除，新行将替代旧行参与的MRP/MPS计算。

对预测订单的分期可多次进行，已做过分期的预测订单再次分期时，需要保证再次分期的时栅不大于原有分期的时栅。

# 业务规则

*  定义组织
*  定义客户
*  定义物料
*  定义计量单位
*  定义预测订单单据类型

预测订单头—分期页签

|栏目名称|说明|
|---|---|
|起始日期|表示分期的开始日期，默认为空|
|结束日期|表示分期的开始日期，默认为空。[截止日期]须大于[起始日期]。|
|分期方式|表示预测订单的周期类型, 仅当[起始日期]和[结束日期]都非空时，才能维护[分期方式]栏目。枚举值:自然周：预测订单的周期类型为周日：预测订单的周期类型为天，此时需要在[天数]栏目设定天数值系统会依据预测订单的起止日期与本栏目中的值，自动生成预测订单的分期记录，具体分期记录内容可点击画面下方的【操作】->【预测分期】按钮查看。|

# 按钮说明

*  <预测分期>：用于查看分期、或按单头分期参数生成实际预测分期。若预测订单已做过分期，则通过此功能查看分期情况，若修改了单头分期参数，则通过此功能生成实际分期。
*  <料品库存查询>：在录入了物料的情况下，可在此查询料品的库存。
*  <整单/行关闭>：执行对整单或单体的行关闭。关闭整单还是单体的行，依据焦点位置而定，焦点在单头时可以关闭整单，焦点在行上时关闭行或关闭整单。已关闭的预测订单或订单行将不再参与MRP计算。
*  <整单/行打开>：对于已关闭的预测订单，可以再次打开，参与MRP计算。
