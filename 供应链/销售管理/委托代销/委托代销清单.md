
# 功能描述

委托代销结算清单主要功能是记录外寄仓的业务行为，主要包括外寄仓的对外销售、退货汇总等数量信息和以及对外销售的零售价、价格属性以及零售折扣等信息。

# 关键应用

# 业务规则

*  委托代销清单正结算可推式生成委托代销订单
*  委托代销清单负结算可推式生成退回单。
*  对当前料品进行个别计价匹配
*  可针对委托代销结算清单执行拣/理货操作
*  可联查客户、料品状况；

# 按钮说明

*  <代销结算>

操作概述:

执行结算操作，并根据结算情况生成委托销售订单或退回单

操作前提：

当前结算清单已核准未关闭。

操作步骤：

点击【代销结算】，打开待结算的委托代销清单行列表画面，在其中执行代销结算操作。

**第1步：**在列表中选择需要结算的清单行行。录入[本次结算数量1]、[本次结算数量2]，列表中其他栏目为显示项，不可编辑。

[本次结算数量1]默认=销售数量1-累计已结数量1，手工可改。

[本次结算数量2]默认=销售数量1-累计已结数量1，手工可改。

**第3步：**在列表中点击【确定】按钮，系统将本次结算数量1或本次结算数量2非空的计划行生成销售订单/退回单。

按照组织、受托代销方、币种、价表、料品以及料品的物料纬度对“结算数量”进行分组汇总。

分组汇总结果为正的单行生成销售订单，为负则生成退回单。

**第3步：**在列表画面中点**【设置】**按钮，可打开“设置画面”设置是否显示所生成单据。

*  <操作--快速录入>

操作概述：根据委托代销寄外仓中的料品存量，快速生成委托代销清单。

操作前提：无

操作步骤：打开当前画面，选中一个委托代销寄外仓，点击【操作】－>【快速录入】按钮，即可进入快速录入弹出画面，选中料品并录入数量，确定后即带入委托代销清单画面。

*  <操作--个别计价匹配>

**操作概述**

当当前料品在某个成本域内采用[个别计价](javascript:void(0);)时，需要在发出单据上指定匹配的成本层。本操作完成“成本层”的匹配。

几个“个别计价”的计价方法，就需要指定几笔匹配的Layer。

清单行中物料、版本、等级、成份、自由项、厂牌、存储地点、货主组织、成本单位数量等影响个别计价匹配的结果的数据项发生改变，自动清除匹配历史结果。

**操作前提**

*  只能选择行类型=“发出“的清单行进行操作。
*  清单行料品某个成本域内采用个别计价法。
*  所选清单行状态为开立或核准中。
*  清单中任意项修改后，“个别计价匹配功能”都不可用，报错。只有用户保存单据后，功能才可用。

**操作步骤**

打开清单或选中清单行，点击【操作】－>【个别计价匹配】按钮，打开“个别计价匹配画面”，画面栏目参见下文。

**第1步：**在画面顶端选择需要进行匹配的成本域、成本类型不可编辑。若有多个“个别计价”，需指定多次。

**第2步：**在画面中部“可选层次列表”中选择可匹配当前料品的层次，并输入【匹配数量】

点击【匹配】按钮，系统自动将该层匹配结果转移到画面中部“已匹配层次列表”中；

匹配完成后，可点击【取消匹配】按钮，取消所进行的匹配

一个单据的一个“个别计价”方法，必须全匹配或全取消。若一个单据涉及多个“个别计价”方法，则可以一个匹配，一个不匹配。

**第3步：**在列表画面中点**【关闭】**按钮，保存匹配结果并返回上层画面。

*  <操作--价格重算>

**操作概述**

根据清单上已录入的价表、折扣等信息重新计算料品的价格相关项目，如金额、税额等。可重算整个清单所有料品；也可选定某清单行重新计算指定料品。

**操作前提**

当前清单或清单单行处于开立或核准中。

*  <操作--整单/行拣货>

**操作概述**

根据料品的拣货规则，在发出的当前料品出库时执行本操作。

**操作前提**

当前料品在单行的【行类型】=“发出”；

单行状态为开立或核准中；

在存储地点－料品交叉关系或在料品档中定义料品的理货规则；

**操作步骤**

点击【操作】－>【整单/行拣货】按钮，对料品执行拣货操作。

整单执行，对本单所有料品进行拣货，也可指定某行对料品执行拣货操作；

系统自动执行拣货，先按照“存储地点－料品交叉关系”中定义拣货规则进行，再按照“料品”档中定义进行。

执行拣货操作成功后，会在单行库位页签记录拣货库位的分配情况；对于有批号、序列号管理的当前料品，还将记录料品的批号、序列号。

可多次执行，每次均清空库位页签中的拣货历史或手工录入的拣货情况；

执行完毕后，会在画面底部显示拣货执行结果信息。

*  <追溯查询--客户状况查询>

**操作概述**

查询清单中委托代销方的情况，包括客户的相关财务情况与最近发生业务的日期，如应收款、最近订货日、最近发货日等。

**操作前提**

【委托代销方】栏目非空，否则查询画面为空画面。

**操作步骤**

点击【追溯查询】－>【客户状况查询】按钮，打开客户状况画面即可。画面为查询画面，不可编辑。

*  <追溯查询--料品状况查询>

**操作概述**

查看当前料品的情况，包括料品的库存、销售、采购以及计划生产信息。画面为查询画面，不可编辑。

**操作前提**

所选行【料品】栏目非空，否则查询画面为空画面

**操作步骤**

点击【追溯查询】－>【料品状况查询】按钮，打开料品状况画面即可。关闭窗口返回上层画面。
