
# 功能描述

本功能实质是一种操作,帮助用户批量对符合条件的委托代销结算清单进行结算，结算后会根据结算数量的差异生成委托代销订单或退货处理单。

# 关键应用

# 业务规则

点击【销售与分销】－>【委托代销】－>【委托代销结算】，打开“委托代销结算清单过滤条件”画面。

*  第1步：在“委托代销结算清单过滤条件”画面中输入客户、料品以及结算清单单据号等信息，系统按照所输入信息自动筛选需要结算的委托代销结算清单，并显示在“委托代销结算”列表画面中。
*  第2步：在列表中选择需要结算的清单行行。录入[本次结算数量1]、[本次结算数量2]，列表中其他栏目为显示项，显示结算清单的基本信息，不可编辑。

[本次结算数量1]默认=销售数量1-累计已结数量1，手工可改。

[本次结算数量2]默认=销售数量1-累计已结数量1，手工可改。

*  第3步：在列表中点击【确定】按钮，系统将本次结算数量1或本次结算数量2非空的计划行生成销售订单/退回单。

按照组织、受托代销方、币种、价表、料品以及料品的物料纬度对“结算数量”进行分组汇总。

分组汇总结果为正的单行生成销售订单，为负则生成退回单。

*  第4步：在列表画面中点【设置】按钮，可打开“设置画面”设置是否显示所生成单据。
