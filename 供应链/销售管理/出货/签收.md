
# 功能描述

用户可通过本操作实现出货单的批量签收功能。具体功能包括：

输入料品的签收、拒收、途损以及需补货信息

可以根据签收情况生成补货订单或补货出货单

# 业务规则

*  出货单已出货确认
*  出货单对应的单据类型规定【签收策略】为“手工签收”

# 栏目说明

# 按钮说明

*  <基本操作_保存>：在界面中输入相关签收信息后，点击保存按钮，如保存成功即视为出货单行签收成功。关闭当前画面重新进入时，签收成功的出货单行将不再显示在签收界面中。签收成功后，出货单行的签收信息将不允许再次修改。
*  <重新选单>：执行本操作，在弹出画面中设置过滤条件，系统按照过滤条件重新组织“签收画面”中的出货单行列表。查看历史已签收数据，在弹出画面中的过滤条件【签收状态】选择“已签收”或“全部”即可。
*  <继续选单>：执行本操作，在弹出画面中设置过滤条件，系统在保留“签收画面”中出货单列表的基础上，追加新的符合条件的出货单行，并自动剔除重复的单据。查看历史已签收数据，在弹出画面中的过滤条件【签收状态】选择“已签收”或“全部”即可。
*  <补货>：根据画面中输入补货数量推式生成补货订单。
   *  操作前提
      *  当前出货单上行料品的[未签收补货数量］大于 [累计补货数量（销售单位）]
   *  操作步骤
      *  点击【后续处理】－>【补货】，显示当前出货单的可以补货的出货单行列表。具体步骤如下所示。
      *  第1步：在列表中选择需要补货的出货单行。列表窗口栏目说明见下表：
      *  第2步：在列表中点击【确定】按钮，系统将补货数量1或补货数量2非空的生成补货订单。
      *  第3步：在列表画面中点【设置】按钮，可打开分单条件设置画面。在其中设定分单条件后，根据分单条件生成相应的补货订单。
   *  <栏目说明>：

|栏目|说明|
|---|---|
|复选框|选择单据时，可同时选择多个出货单行生成补货订单|
|行号|显示项，出货单行上对应行号。|
|料品|显示项，出货单行上对应料品。|
|批号|显示项，出货单行上料品对应批号。|
|单位1|显示项，出货单行上料品对应销售单位。|
|数量1|显示项，出货单行上料品对应未签收需补货数量（销售单位）。|
|单位2|显示项，出货单行上料品对应销售基准单位。|
|数量2|显示项，出货单行上料品对应未签收需补货数量（销售基准单位）。|
|补货数量1|手工可改。|
|补货数量２|手工可改。|
|收货位置|显示项，订单出货计划行上对应收货位置。|

*  <拒收收货>：根据画面中输入本次收货数量推式生成销售退回收货单。
   *  操作前提
      *  当前出货单上行料品的( [拒收数量+[途损数量]-[拒收退回收货占用量] )大于零
   *  操作步骤
      *  点击【拒收收货】，显示当前出货单的可以拒收收货的出货单行列表。具体步骤如下所示。
      *  第1步：在列表中选择需要补货的出货单行。列表窗口栏目说明见下表：
      *  第2步：在列表中点击【确定】按钮，系统将本次收货数量1非空的生成销售退回收货单。
      *  第3步：在列表画面中点【设置】按钮，可打开分单条件设置画面。在其中设定分单条件后，根据分单条件生成相应的销售退回收货单。
   *  <栏目说明>：

|栏目|说明|
|---|---|
|复选框|选择单据时，可同时选择多个出货单行生成销售退货收货单|
|日期|显示项，出货单的单据日期。|
|单号|显示项，出货单的单号。|
|行号|显示项，出货单行上对应行号。|
|订货客户|显示项，出货单的订货客户。|
|收货位置|显示项，出货单行的收货位置。|
|立账位置|显示项，出货单行的立账位置。|
|料品|显示项，出货单行上对应料品。|
|品名|显示项，出货单行上对应料品的品名。|
|退回收货存储地点|手工可改，默认为出货单的出货存储地点。|
|单位1|显示项，出货单行上料品对应销售单位。|
|拒收收货数量1|显示项，出货单行的拒收收货数量1（销售单位）。|
|途损收货数量1|显示项，出货单行的途损收货数量1（销售单位）。|
|已拒收收货数量1|显示项，出货单行的拒收退回收货占用量（销售单位）。|
|本次收货数量1|手工可改。|

*  <签收完成>：对当前出货单行置签收完成标记，签收完成后不允许再签收。也可通过批量签收完成功能对当前所有的行全部签收完成。
*  <取消签收完成>：取消出货单行的签收完成标记，签收、途损、拒收等数量也都清为零。
*  <初始化签收>：未签收完成的出货单行，将签收、途损、拒收等数量都清为零。
*  <按出货量签收>：对出货单行的签收数量赋值，签收数量=本次出货数量。

# 操作说明

通过菜单<a href="/detail/8112bdb16ebc41f8b52f1432b95a02a6">签收</a>进入签收界面；

*  操作步骤
 
   *  第1步：录入签收人、日期等信息。
   *  第2步：选择签收订单。
   *  第3步：点击“保存”，保存签收。
