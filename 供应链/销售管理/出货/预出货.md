
# 功能描述

预出货的应用场景与使用方法参见。参见《应用专题—销售中的预出货》,本文仅介绍预出货单界面的操作，进入【销售与分销】－>【出货】－>【预出货】，打开预出货画面，包括以下功能：

完成预出货单的增、删、改、保存、查询、复制、提交审批/核准、状态维护等基本操作；

支持物料出库时的替代与拣货操作；

支持预出货推式或拉式立帐；

支持预出货单推式生成出货单；

可连查客户状况与料品状况；


# 业务规则

*  参数设定，与预出货相关参数
*  必须先设定单据类型
*  必须先设定立帐条件、收款条件
*  必须先设定料品的存储地点
*  必须先设定出货原则
*  有价格管理的应用需定义价目表；

# 栏目说明

预出货单画面栏目

预出货画面栏目与标准出货栏目基本相同，下表仅介绍预出货与标准出货不同的栏目，未列明栏目请参见标准出货。

|栏目名称|说明|
|---|---|
|单头—基本页签|
|单据类型|非空，选择录入预出货单的单据类型名称，点击栏目可以在线维护“单据类型”数据。注意　:预出货单来源单据类型决定预出货单的流程以及编码规则等|
|单据号|非空,显示或输入预出货单的编号。当用户所选的【单据类型】定义为自动编号时，本栏目显示系统自动生成的单据编号；而【单据类型】定义为手工编号时，请在本栏目中输入单据编号。注意　:单据编号不允许重复，用户在手工输入单号时需特别注意！|
|客户外寄仓|非空，选择存储地点录入。选择【存储地点】必须满足条件【存储地点】必须是“外寄仓|
|立应收|选择项，表明当前预出货单核准后是否推式立帐。允许预出货单立应收必须满足条件：所有预出货单行立账依据都=出货所有预出货单行立账方式=‘非凭单式’预出货单行上料品不能是套件的子件|
|来源单据类型|预出货单与出货单的来源单据不同，预出货单的来源类型只能是：销售订单：根据销售订单生成预出货单。出货计划：根据出货计划生成预出货单。|
|内部直运|表示当前单据后续是否会产生内部交易；选中后单头的营运组织与所有行货主组织必须是关系企业；未选中，单头的营运组织与所有行货主组织必须是非关系企业；手工创建时可勾选，默认＝false；|
|单头－财务页签|
|信用免检|约定本次销售业务是否进行信用检查|
|预收环节|表示当前单据可以预收款的业务环节，不可改。参数“启用预收政策”＝false，为空；参数“启用预收政策”＝true，=单头[预收政策]对应值。|
|预收政策|表示当前单据的预收检查规则。参数“启用预收政策”＝true时有效；参照[物料相关]＝false的预收政策。参数“启用预收政策”＝false时，为空，不可改。|
|需预收比例|表示需要收取的预收款金额占单据金额的比例。参数“启用预收政策”＝false时，为空，不可改。 参数“启用预收政策”＝true时，从预收政策带入，不可改。参见应用专题—销售中的预收及挪用。|
|需预收金额|按预收比例计算的需要预收的金额。参数“启用预收政策”＝false时，为空，不可改参数“启用预收政策”＝true时，根据预收政策计算，不可改。参见应用专题—销售中的预收及挪用。|
|单体—基本页签|
|客户寄外仓|默认=头的预外仓，可改|
|批号|预出货料品单独管理时，批号控制方式与普通出货单相同；预出货料品混合管理时，则批号必空。|
|序列号|预出货料品单独管理时，序列号控制方式与普通出货单相同；预出货料品混合管理时，则批号必空。|
|单体－财务页签|
|预收环节|表示当前单据行可以预收款的业务环节，不可改。参数“启用预收政策”＝false，为空；参数“启用预收政策”＝true，=单行[预收政策]对应值。|
|预收政策|表示当前单据行的预收检查规则。参数“启用预收政策”＝true时有效；参照[物料相关]＝true的预收政策。参数“启用预收政策”＝false时，为空，不可改。|
|需预收比例|表示需要收取的预收款金额占单据行金额的比例。参数“启用预收政策”＝false时，为空，不可改。 参数“启用预收政策”＝true时，从预收政策带入，不可改。参见应用专题—销售中的预收及挪用。|
|需预收金额|按预收比例计算的需要预收的金额。参数“启用预收政策”＝false时，为空，不可改参数“启用预收政策”＝true时，根据预收政策计算，不可改。参见应用专题—销售中的预收及挪用。|
|单体—调出库位页签如果预出货料品实物管理方式为混合管理，则不需指定调出库位；如果预出货料品的实物管理方式为单独管理，则需要指定普通仓的出货库位。|
|库位|普通仓的出货库位，可参照录入，也可以通过拣货生成|
|分配数量|该库位的出货数量，可录入，也可以通过拣货生成|
|序列号|该库位的出货序列号，可录入，也可以通过拣货生成|
|单体—调入库位页签如果预出货料品实物管理方式为混合管理，则不需指定调入库位；如果预出货料品的实物管理方式为单独管理，则需要指定外寄仓的入库库位。|
|库位|外寄仓的入库库位，可参照录入，也可以理货生成。|
|分配数量|该库位的入库数量，可录入，也可以通过理货生成|
|序列号|入库料品的序列号|

# 按钮说明

预出货单操作与标准出货操作基本相同，请参见标准出货

*  <批量生单>：预出货单批量生单只能根据销售订单与出货计划。操作同[标准出货]
*  <出货>：预出货单推式生成生成出货单
   *  操作前提
      *  预出货单已核准；
   *  操作步骤：点击【出货】，显示当前的可以出货的预出货单行列表。具体步骤如下所示。
      *  第1步：点击【确定】按钮，即可生成出货单；
      *  第2步：点击【取消】按钮，放弃生成出货单返回预出货单画面；
      *  注意：表头的[出货日期]将被赋到所有被推出的出货单上做为单据日期。
*  <客户_整单预收特例>：针对当前单据单头申请特殊的预收政策。
   *  操作前提
      *  当前单据的[营运组织]的参数“启用预收政策”＝true；
      *  单据已保存、未提交；
      *  [单据类型]中[需预收]=true；
      *  单头[预收政策]非空且来源单据单头[预收政策]为空；
      *  注意：
         *  单头[立应收]＝true此操作无效；
         *  期初预出货此操作无效；
   *  操作步骤
   *  点击【客户】－>【整单预收特例】按钮，在弹出画面编辑预收政策内容。参见基础设置—预收政策。
*  <客户_行预收特例>：针对当前单据单行申请特殊的预收政策。
   *  操作前提
      *  当前单据的[营运组织]的参数“启用预收政策”＝true；
      *  单据已保存、未提交；
      *  [单据类型]中[需预收]=true；
      *  单行[预收政策]非空且来源单据单行[预收政策]为空；
      *  注意：
         *  单头[立应收]＝true此操作无效；
         *  期初预出货此操作无效；
   *  操作步骤
      *  点击【客户】－>【行预收特例】按钮，在弹出画面选中需要单据行，点确定，在弹出画面编辑预收政策内容。参见基础设置—预收政策
