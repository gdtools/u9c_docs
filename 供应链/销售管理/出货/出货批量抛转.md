
# 功能描述

是指把已经核准的符合协同条件的销售出货单通过批量抛转功能，生成关系企业的采购收货单的功能。

# 业务规则

*  销售出货单必须已核准；

# 栏目说明

销售出货单抛转画面

画面显示可以进行抛转的订单列表，所有栏目均取自对应的销售订单，不可修改；但可以通过查询方案修改显示栏目等。

|栏目名称|说明|
|---|---|
|单据编号|销售出货单编号|
|业务日期|销售出货单单据日期|
|出货确认日|订单子行号|
|客户|客户|
|单据类型|销售出货单单据类型|
|业务员|销售出货单所属销售业务员|
|部门|销售出货单所属销售部门|

# 按钮说明

*  <查询>：设置出货批量抛转的查询条件、显示栏目及排序条件。
   *  操作步骤：执行【查询】操作，在打开的画面中设置查询过滤条件后，点“确定”按钮即可；点“取消”放弃查询返回抛转画面。
*  <抛转>：将所选择的出货单进行抛转。
   *  操作前提：销售出货单必须已核准；
   *  操作步骤：执行【抛转】操作即可将所选择出货单整单进行抛转。

# 操作说明

通过菜单<a href="/detail/594309bf8b8a4af885b5ad5648bb4b24">出货批量抛转</a>进入出货批量抛转界面；

*  操作步骤
 
   *  第1步：选择相应单据。
   *  第2步：点击“抛转”。
