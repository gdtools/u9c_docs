
# 功能描述

进入【销售与分销】－>【出货】－>【出货计划出货】 ,按出货计划出货实质上是一种操作，帮助用户根据出货计划批量生成出货单。

# 业务规则

*  参见标准出货

# 操作说明

*  通过菜单<a href="/detail/4e8ccea6eae643869cac3d11a54ae103">计划出货</a>进入计划出货界面；
*  操作步骤
 
   *  第1步：进入【销售与分销】－>【出货】－>【按出货计划出货】，系统按默认查询条件打开可生成出货单的出货计划计划行列表（栏目说明见下文）。
   *  第2步：如出货计划列表画面中未列出可生成出货单的出货计划行，执行【继续选单】操作，打开“出货计划过滤条件画面”，在其中设定过滤条件（出货计划料品、客户、交易信息），执行后系统将把查找到的出货计划行显示在列表画面。如出货计划列表画面中已列出合适的出货计划，本步骤可以省略。
   *  第3步：在出货计划行列表画面中，点击【设置】按钮，打开“出货计划出货设置”画面（栏目说明见下文）设定出货计划生成出货单时的分单条件。如省略当前步骤，系统将按照默认分单条件生成一张或多张出货单。
   *  第4步：在出货计划行列表中选择可生成出货单的出货计划（可多选），并确定本次出货数量，点击【确定】按钮即可生成出货单。
