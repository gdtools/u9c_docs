
# 功能描述

按照指定方式查询出货单明细以及出货单财务执行情况。

出货单查询：查询出货单，以及出货单行的情况。

出货单财务执行查询：按出货单行查看财务执行情况，包括开票、立账和回款；并可查看对应的发票、应收单和收款单的明细。

# 业务规则

*  销售系统已启用(此项必需)

# 栏目说明

查询数据

*  出货单已核准

查询条件

系统在查询方案中提供默认的查询条件，
            *  查询条件可以自定义（通过属性选取设置），出货单上的每一个字段都可以作为查询条件；
            *  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

查询结果

*  不同的查询方式、查询条件决定了查询结果的不同。用户可根据需要任意组织查询条件和要显示的栏目。

# 操作说明

*  通过菜单<a href="/detail/fdda9c1d6be7460e96f9537564cdb5a2">出货单查询</a>进入出货单查询界面；
*  操作步骤
 
   *  第1步：录入查询条件。
   *  第2步：点击保存。
   *  第3步：点击确定。
