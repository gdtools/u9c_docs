
# 功能描述

按照指定方式查询销售订单的明细情况。

销售订单查询：查看销售订单，销售订单行以及销售订单计划行。

销售订单业务执行查询：按销售订单计划行查看业务执行情况，并可显示对应的出货单的明细。


# 业务规则

*  销售系统已启用(此项必需)

# 栏目说明

查询数据

*  已核准的订单，且需要"客户确认"的订单已经确认

查询条件
系统在查询方案中提供默认的统计条件，
         *  查询条件可以自定义（通过属性选取设置），销售订单上的每一个字段都可以作为查询条件；
         *  另外用户通过《查询方案》画面的“属性选取”操作自定义查询条件。

查询结果

*  不同的查询方式、查询条件决定了查询结果的不同。用户可根据需要任意组织查询条件和要显示的栏目。

# 操作说明

*  通过菜单<a href="/detail/3d310a2b1ad84969b70cd6db7cab294d">销售订单查询</a>进入销售订单查询界面；
*  操作步骤
   *  第1步：录入查询条件。
   *  第2步：点击保存。
   *  第3步：点击确定。
