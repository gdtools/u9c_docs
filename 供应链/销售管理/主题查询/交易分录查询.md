
# 功能描述

提供对系统生成的交易分录进行列表查询。

列表显示栏目可以通过”查询“方案进行设置。详见《公共操作》中的《查询方案》。

# 业务规则

*  业务已生成交易分录
*  拥有交易分录查询的权限

# 栏目说明

具体栏目参见《公共操作》中的《交易分录查询》栏目说明

# 按钮说明

具体操作参见《公共操作》中的《交易分录查询》操作说明

# 操作说明

*  通过菜单<a href="/detail/b1a3f9c6ab1c499e8e28e1dc51bd12b1">交易分录查询</a>进入交易分录查询界面；
*  操作步骤
 
   *  第1步：录入查询方案信息。
   *  第2步：点击保存。
   *  第3步：点击确定。
