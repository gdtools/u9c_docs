
# 功能描述

销售业务员选择已审核的要货订单转成销售订单。

# 业务规则

*  要货订单行已审核未关闭。
*  要货订单行已转订单数量 小于 要货数量。

# 栏目说明

要货订单转销售订单画面

画面显示可以转销售订单的要货订单列表，栏目取自对应的要货订单。

|栏目名称|说明|
|---|---|
|单号|要货订单单号|
|客户|要货订单的客户|
|料号|要货订单行的料号|
|品名|要货订单行的料品品名|
|规格|要货订单行的料品规格|
|数量|要货订单行的要货数量|
|交易单位|要货订单行料品的要货计量单位|
|交期|要货订单行料品的交期|
|本次转单数量|默认=要货数量-已转订单数量，可修改|

# 按钮说明

*  <转销售订单>：选中的要货订单行点击“转销售订单”。
*  <设置>：设置转销售订单时的合单条件。

# 操作说明

*  通过菜单<a href="/detail/e2db4e75c3b3489eb0fca2d48325fbf8">要货订单转销售订单</a>进入要货订单转销售订单界面；
*  操作步骤
 
   *  第1步：选择对应的单据。
   *  第2步：点击转销售订单。
