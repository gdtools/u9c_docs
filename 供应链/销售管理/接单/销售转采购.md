
# 功能描述

供应类型=“供应商”并且已核准的销售订单计划行通过此功能转采购订单或外协订单。

|**后续单据**|**下达前提**|
|---|---|
|采购订单|1、业务类型为标准销售，[供应组织]=外部供应商时可下达转采购订单；2、供应商直运标识为真，[供应组织]=外部供应商时可下达转采购订单；3、业务类型为标准销售，转外协，且物料的[供应类型]为“转外协”可下达转全程委外订单。|


# 业务规则

*  销售订单必须整单核准；
*  销售订单计划行未挂起、为关闭、未终止；

# 栏目说明

销售转采购画面

画面显示可以转采购/委外的订单列表，栏目取自对应的销售订单。

|栏目名称|说明|
|---|---|
|单号|订单编号|
|日期|订单单据日期|
|客户|订单订货客户|
|料品|订单计划行中可转采购/外协的料品|
|...|...|
|存储地点|默认=订单计划行的存储地点，可改|
|供应商|默认=订单计划行的供应商，可改|
|本次采购数量|默认=本次可转采购数量，可改|
|采购订单单据类型|指定转采购订单/外协订单的单据类型|

# 按钮说明

*  <查询>：设置过滤可转采购的销售订单条件。

操作步骤：执行【查询】操作，在打开的画面中设置查询过滤条件后，点“确定”按钮即可；点“取消”放弃查询返回销售转采购画面。

*  <设置>：设置转采购的分单和合行条件（外协订单不支持合行）。

操作步骤：执行【设置】操作，在打开的画面中勾选需要作为分单/合行的数据项，点“确定”按钮即可；点“取消”放弃设置返回销售转采购画面。

*  <转采购>：将所选择的订单转采购订单/外协订单。

操作前提：销售订单必须整单核准完毕；销售订单计划行未挂起、为关闭、未终止。

操作步骤：执行【转采购】操作即可将选择出来所有订单计划行转采购订单

*  <取消转采购>：删除所选择的订单已转的采购订单/外协订单。

操作前提：销售订单已转采购订单/外协订单；销售订单已转的采购订单/外协订单必须满足可删除的条件。若不满足，则不能取消转采购。

*  操作步骤：执行【取消转采购】操作即可
