
# 功能描述

进入【销售与分销】－>【接单】－>【标准销售】，打开标准销售订单。

标准销售是销售业务中最常见最普通的销售流程（参见业务特性—标准销售），

完成开订单工作，并可便捷的进行与接单相关的查询、管理、订单执行等活动。

支持多组织多地点运营：接单、执行、出货、核算、结算、开票组织可各不相同；订货、收货、收票、付款客户可各不相同。

处理下列产品的接单：标准产品、配置产品、PTO、KIT、一次性物料

能处理下列客户：可处理常规客户、新客户、一次性客户的接单

可以按订单立账、收款、确认收入、成本。


# 业务规则

*  参数设定，与销售订单相关参数
*  定义客户档案（必做）
*  定义组织档案（必做）
*  定义销售业务部门（必做）
*  定义销售业务员（必做）
*  定义料品档案（必做）
*  定义计量单位（必做）
*  定义币种（必做）
*  定义单据类型（必做）
*  设定立帐条件（必做）
*  设定收款条件（必做）
*  设定出货原则（必做）
*  设定预收政策
*  定义税组合
*  有价格管理的应用需定义价目表；
*  管控信用，需要启用应收系统，定义信用政策；
*  查询管控料品ATP，需要启用库存系统，定义ATP规则

# 栏目说明

标准订单头

订单头栏目主要包括基本页签、币种页签、外销页签、商务页签、物流页签、财务页签、备注页签；（栏目带*号的表示必输项） 具体内容如下所示：

标准销售订单头－基本页签

|栏目名称|说明|
|---|---|
|单据类型|非空，选择录入订单单据类型名称，点击栏目可以在线维护“单据类型”数据。根据不同的业务类型和业务特性需要选择不同的单据类型，不同的单据类型在订货、出货、立账等业务处理上遵循不同的业务处理规则。|
|单号|显示或输入本订单的编号。当您所选的【单据类型】定义为自动编号时，本栏目显示系统自动生成的单据编号；当您所选的【单据类型】定义为手工编号时，请在本栏目中输入单据编号。单据编号不允许重复，您在手工输入单号时需特别注意！|
|客户|非空，选择本订单的订货客户。栏目为空时点击栏目可以在线维护客户数据；非空时点击栏目可以在线维护录入订货客户的地址、联系人。|
|交期|方便录入用，在此录入后，做为订单行中新增行中［交期］的默认值。|
|日期|系统默认取当前的日期，可改,代表当前订单的单据日期。|
|币种|非空，选择本次销售业务所使用的交易币的币种。默认取自客户档。若订单有来源单据、且来源单据的交易币种非空，则[币种]取自来源单据的交易币种，不可改；否则手工录入|
|业务员|可空， 选择本业务所涉及的销售业务员，默认取自客户档，可改。点击栏目可以在线维护业务员数据。若销售部门非空，则只能选择隶属于销售部门的销售业务员。|
|部门|可空，选择当前订单的销售部门。默认取自客户档案，可改。点击栏目可在线维护部门数据。|
|来源类别|在本栏目确定当前单据的上游单据类别，默认为“手工创建”，标准销售可来源于以下三种单据：报价单：当前订单来源于报价单销售合同：当前订单来源于销售合同销售订单：当前订单来源于其他销售订单。预测订单：当前订单来源于预测订单要货订单：当前订单来源于要货订单必须输入当前订单的[单据类型]以及[客户]等必输项后，才可以选择[来源类别]|
|来源单据|根据已经选择的来源类别，在本栏目我们可以选择具体来源单据生成销售订单。来源生单操作详见下文。|
|贸易路径|说明该笔销售订单抛转的方向和节点。销售订单抛转时，有如下两种方式：1、销售订单外抛：如果客户为内部组织，则可以指定这笔销售业务的贸易路径。2、销售订单先内抛为对关系企业的采购订单，然后采购订单再外抛为另一组织的销售订单。如果是第1种，则整个销售订单只支持一个贸易路径；如果是第2种，则销售订单按订单行确定贸易路径，此处的贸易路径作为销售订单行贸易路径的默认值。|
|状态|显示本订单目前所处的状态，点击链接可查看当前订单状态的明细情况。|
|变更次数|显示本订单通过变更单所做的变更次数，点击链接可查看当前订单变更历史。|
|补单|标明该笔业务是否反映实时的销售业务。|

|金额|非空，表示当前料品的交易的金额|

# 按钮说明

*  <价格重算_整单/行价格重算>：根据订单上已录入的价表、折扣等信息重新计算料品的价格相关项目，如金额、税额等。可重算整个订单所有料品；也可选定某个订单行重新计算指定料品。
*  <预留_整单/行预留>：根据订单上已录入的料品信息等对料品进行预留，可对整单所有料品预留；也可选定某个订单行执行预留操作。
*  <预留_整单/行预留释放>：释放当前SO或SO行所预留的物料
*  <操作_快速录入>：为提高录入效率，用户可通过“快速录入”画面录入订单相关料品信息
*  <操作_历史版本>：若当前订单存在多个版本，则可通过此功能查看该订单的历史版本。 只有最新版本的订单可以进行维护操作；对于订单的历史版本，只能显示，不能做任何操作。
*  <操作_按项目产出生单>：对于已经存在的项目以及项目产出，系统提供了根据项目产出快速生成销售订单的功能。
*  <操作_存为新版本>：将当前订单存为一个新的版本，相当于文件的“另存”功能
*  <操作_交易分录>：点击销售与分销－>接单－>标准销售－>操作－>交易分录，可以查看订单交易分录情况。
*  <操作_终止>：对于由于某种原因，不能或没必要进行完业务流程的单据或单据行，可以通过此功能强行终止业务。终止后的单据或单据行永久无效，此操作不可逆。本操作是针对整单还是单据行，要看焦点位置而定，焦点在单头则针对整单终止，焦点在单行则针对单行终止。
*  <操作_整单/行关闭>：执行对整单或单体的行关闭。关闭整单还是单体的行，依据焦点位置而定，焦点在单头时可以关闭整单，焦点在行上时关闭行或关闭整单。对于一张单据，如果业务终结，系统自然关闭，则此单据不能再打开；相反，如果由于短缺或其它原因手工关闭的单据可以再次打开，进行后续业务流程。
*  <操作_整单/行打开>：如果销售订单单据类型中约定关闭的单据可以再次打开，那么可以再打找开销售订单，进行后续业务流程。
*  <操作_挂起>：“挂起”用于在业务进行中，由于某种原因需要暂时对单据或单据行中断业务进程，此时可以使用此功能。本操作是针对整单还是单据行，要看焦点位置定，焦点在单头则针对整单挂起，焦点在单行则针对单行挂起。此操作可逆，可以用“解除”功能取消挂起。
*  <操作_解除>：此操作为“挂起”操作的逆操作，可以对已挂起的目标取消挂起，以便进行完后续的业务流程。本操作是针对整单还是单据行，要看焦点位置定，焦点在单头则针对整单取消挂起，焦点在单行则针对单行取消挂起。
*  <操作_批量生单>：可选多个客户的销售合同和报价单生单，按来源单据分单条件生成多张订单。
*  <操作_发布>：订单涉及客户的信息已维护完毕，可发布到门户供客户确认是否正确。
*  <操作_批量分割>：支持对当前订单满足分割条件的计划行进行批量分割。执行后关闭选定的计划行，并将剩余未执行数量生成新计划行。
*  <操作_规划方法批量调整>：支持批量调整出货计划行上“MRP需求”及“库存规划”的状态标志，由“是”改为“否”或由“否”改为“是”。
*  <操作_批量调价>：提供根据一定条件，对当前销售订单的最终价进行批量调整功能。
*  <操作_订单变更>：直接在订单上进行变更，由系统自动记录并生成销售变更单。
*  <操作_可用量查询>：将当前单据料品的库存可用量及查询库存的时间显示在行上。
*  <后续处理_下达>：是指根据销售订单中相关业务信息（供应类型、供应组织、供应来源等），生成后续业务处理单据的过程。
*  <后续处理_取消下达>：取消订单下达操作并将订单转化单据数量更新为下达前的数值。
*  <后续处理_内抛>：是指根据销售订单中相关业务信息（客户及联系对象、贸易路径等），生成本组织采购订单的过程。
*  <后续处理_外抛>：是指根据销售订单中相关业务信息（客户及联系对象、贸易路径等），生成另一组织采购订单的过程。
*  <后续处理_出货>：销售订单推式生成生成出货单
*  <后续处理_出货计划>：根据销售订单做出货的预先安排，是库存、仓储、运输作业的来源依据。一张销售订单可同时生成多个出货计划。
*  <后续处理_补货>：当前销售订单如需要补货（[未签收需补货数量（销售单位）]-[累计补货数量(销售单位)] >0），根据当前销售订单生成补货订单或补货出货单。
*  <客户_客户状况>：查询订单付款客户的情况，包括客户的相关财务情况与最近发生业务的日期，如应收款、最近订货日、最近发货日等。
*  <客户_客户确认>：输入客户对当前销售订单的确认情况
*  <客户_整单/行预收款挪用>：当前订单从其它有预收款的单据中挪用一部分预收款做为当前单据的预收款。
*  <客户_整单预收特例>：针对当前单据单头申请特殊的预收政策。
*  <客户_行预收特例>：针对当前单据单行申请特殊的预收政策。
*  <客户_整单/行毛利估算>：订单开立时估算本张订单或订单行的近似毛利/毛利率；以及计算外销时订单的出口换汇成本。参见应用专题——销售中的毛利预估。
*  <客户_价格过程>：查询当前订单行上料品最终价格得出的过程。
*  <客户_整单/行临时额度>：为当前订单的订货客户或信用对象申请临时信用额度。
*  <客户_使用销售返还>：订单中使用销售返还，是通过使用销售返还，用使用的销售返还额冲减订单行的“价税合计”，并影响“最终价”和冲减客户的应收。
*  <客户_销售返还使用明细>:查看单据行的销售返还使用明细信息。焦点在单头，此操作为单操作；焦点在行，此操作为行操作。
*  <客户_立账收款计划>：创建业务单据时，系统根据单头立账条件以及单据行金额，自动创建立账收款计划。用户可通过本功能查看、编辑立账收款计划。立账收款计划包含以下信息，立账日/到日期、分期情况，各期金额，每期是按比例还是按绝对金额控制等；立账收款计划是否可改，受【立账条件】。[单据上是否可改]以及单据是否立账控制。已立账的分期行不可进行修改。对于设置了分期立账条件的订单，可通过主画面“客户_立账收款计划”功能维护当前行的立账收款明细，或通过“交期”画面的“立账收款计划”功能维护当前子行的立账收款明细。对于立帐条件不分期的订单，则不可查看立帐收款计划。
*  <ATP>：对订单中的料品进行可承诺量检查，若检查通过，则自动进行ATP预留,否则在打开的ATP画面中具体分析，并执行后续操作。
*  <料品状况>：查看订单料品的情况，包括料品的库存、销售、采购以及计划生产信息。画面为查询画面，不可编辑。
*  <替代>：以其他料品替代当前订单行料品
*  <配置>：当订单料品为模型件的时候，可通过本功能对料品进行选配。
*  <产品结构查询>：当订单料品为PTO\ATO\FAS\Model件等物料形态时，可在此查询料品的BOM结构。
*  <来源生单>：指定订单的具体来源单据生成销售订单,订单来源单据包括报价单、合同、订单。来源生单一次仅能生成一张销售订单。
*  <快速形态转换>：当前销售订单行，料品项目号的库存可用量不足时，可以通过快速形态转换，将其他项目号的库存转换成当前销售订单行项目号的库存。
*  <计算促销结果>：根据销售订单指定的促销方案计算促销结果。销售订单指定了促销方案，在销售订单提交前必须执行“计算促销结果”，否则销售订单不允许提交。
*  <清除促销结果>：清除销售订单的促销结果。如果有促销赠品行，那么删除促销赠品行；如果料品最终价有调整，那么将料品最终价还原到使用促销前的最终价。清除促销结果只调整销售订单，不清除销售订单的促销明细记录。
*  <促销明细>：执行“计算促销结果”后系统记录销售订单促销的详细信息，包括销售订单行使用了哪些促销政策，促销结果是赠品，还是折扣等。如果记录促销历史版本，那么可以查看每次执行“计算促销结果”的促销信息。
