
# 功能描述

销售订单变更单，是对销售订单进行变更的一种方式。当企业审核流程规定订单核准后不可改、但又必须对订单做更正时，可使用变更单来完成。

选择【销售与分销】－>【接单】－>【销售订单变更单】，可创建变更单；也可以通过销售订单画面中的功能【操作】－>【订单变更】直接在订单上修改而自动产生变更单。变更单核准后方可真正将结果反映到订单中。

注意　:当企业规定订单审核后允许修改时（订单对应单据类型上参数【核准后可改】＝是），可在审核后直接修改订单内容，此时不能使用变更单。

无论是否使用变更单，核准后的修改都要受订单执行情况的制约。如，订单已出货，则修改订货数量时不得小于实际出货数量

# 业务规则

*  参数设定，与销售变更单相关参数
*  定义变更单的单据类型
*  要进行变更的订单单据类型上约束为审核后不可改
*  要进行变更的订单已核准、未财务关闭、未挂起、未取消

# 栏目说明

销售变更单头－基本页签

|栏目名称|说明|
|---|---|
|单据类型|非空，选择变更单单据类型名称，点击栏目可以在线维护“单据类型”数据。|
|单号|显示或输入销售变更单的编号。当您所选的【单据类型】定义为自动编号时，本栏目显示系统自动生成的单据编号；当您所选的【单据类型】定义为手工编号时，请在本栏目中输入单据编号。单据编号不允许重复，您在手工输入单号时需特别注意！|
|变更订单号|表明是针对哪张订单作变更。非空，点击琏接可以查看变更前订单详细信息。|
|单据日期|非空，默认取当前系统日期，可改,代表当前变更单的单据日期。|
|第几次变更|非空，系统维护，表明是对订单的第几次变更。|
|调整原因|对订单调整的说明，可空。|
|更新订单版本|表明变更单生效后、订单是否存为新的版本。若销售参数[订单版本控制]=否 ，则此处必为否，不可改；否则，默认值从单据类型上的[更新订单版本]带入，可改。|
|备注|可空,关于变更单的说明或描述。|

销售变更单体-公共数据项

|栏目名称|说明|
|---|---|
|变更类型|系统维护，不可改。如订单行新增、订单行修改、订单行删除等。|
|变更|系统维护，不可改。新增或删除的变更类型，本项取值为空。否则，会在上下两行中分别显示“变更前”、“变更后”。|
|行号/子行号|定位变更的具体位置|
|变更栏目|根据“方案”功能中设置的内容显示|

注意　:

变更单单体根据实际变更情况自动生成。

变更数据项为UI所有前台显示的数据项，包括订单头、行、计划行、子表（费用、折扣、税、地址、联系人、备注、选配结果、立账收款计划、弹性域等），以及被联动修改的数据项。

对不同数据项的修改分别显示在不同的页签中，如，对订单行的增删改会显示在订单行页签中，由其联动修改的子行数据项会显示在子行页签中。只有存在对应的变更，相应的行页签才会出现。初始进入变更单时，变更单行为空。

页签内所显示列为功能“方案”中所确定数据项。

# 按钮说明

*  <变更>：针对选定的订单，弹出订单维护画面，在该画面进行必要变更后，执行确定操作，系统会根据订单卡片所修改的数据项生成变更单行。

操作前提：变更单头[变更订单号]非空；当前变更单未审核。

操作步骤：

第1步：在变更单头指定订单号后，点击[变更]按钮，即可打开该订单维护画面，进行必要变更。

第2步：在订单卡片中执行“确定”，返回变更单画面，系统根据修改的内容自动生成变更单行。

第3步：在变更单画面中执行“保存”操作，保存本次变更。

注意：通过此功能生成变更单后，原订单数据并未更新。只有生成的变更单核准后，才会更新原订单。

*  <变更评估>：针对选定的订单，查看当前变更单对毛利的影响情况。

操作前提：当前变更单处于开立或核准中。

操作步骤：

生成变更单行后，点击[变更评估]按钮，即可查看变更前后毛利的变化。

有可能引起毛利变化的数据项为主要是订单行上单价、数量等。

*  <方案>：设定变更单行各页签的显示字段。

操作步骤：点击【方案】按钮，进入各个页签，可配置变更单行对应页签的显示项。

可在列表中增加、删除、上移、下移栏目，具体操作参见公共操作查询方案。

栏目说明

|栏目|说明|
|---|---|
|始终显示变更项|选中则表示：若方案中未选择的栏目在订单中被变更，则也要显示在打开的变更单中；否则按方案中所确定的栏目显示。|

*  <追溯查询_出货查询>：查询被变更订单生成的直接下游出货单。
*  <追溯查询_收款查询>：查询被变更订单的收款情况。
*  <追溯查询_采购订单>：查询被变更订单生成的采购订单。
*  <追溯查询_变更历史查询>：查询被变更订单所对应的所有变更单信息。
