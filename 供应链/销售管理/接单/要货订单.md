
# 功能描述

销售业务员审核客户提交的要货订单，还可以弃审、关闭或打开要货订单。

选择【销售与分销】－>【接单】－>【要货订单】，打开要货订单。

要货订单画面中栏目、功能操作基本与要货订单相同。

# 业务规则

*  客户提交要货订单；（必做）

# 栏目说明

栏目与要货订单相同。

# 按钮说明

*  审核要货订单
*  弃审要货订单
*  关闭要货订单
*  打开要货订单

# 操作说明

*  通过菜单<a href="/detail/267782d86f834be88e70ec22ac372d8a">要货订单</a>进入要货订单界面；
*  操作步骤
 
   *  第1步：选择单据类型信息。
   *  第2步：录入子表信息。
   *  第3步：点击“保存”，保存要货订单。
