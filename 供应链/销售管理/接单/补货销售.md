
# 功能描述

补货订单是根据订单、出货单或者退回单所生成的进行补货业务的销售订单。

选择【销售与分销】－>【接单】－>【补货销售】，打开补货订单。

补货订单画面中栏目、功能操作基本与标准销售订单相同。


# 业务规则

*  参数设定，与补货订单相关参数
*  定义补货的单据类型（必做）
*  其他定义参见标准销售订单

# 栏目说明

补货的栏目基本与标准销售订单相同，未列明栏目请参见标准销售订单相同，下表中仅列出补货订单与标准销售订单在栏目上的不同

|栏目名称|说明|
|---|---|
|订单头－基本页签|
|单据类型|只能选择参数［是否补货］为真的单据类型|
|来源类别|有多种的来源类别可以参照生成标准销售订单，当前单据的上游单据类别在本栏目确定。来源类别包括：订单出货单退回单|
|来源单据|根据已经选择的来源类别，在本栏目我们可以选择具体来源单据生成补货销售订单。|

# 按钮说明

*  补货订单的操作基本与标准销售订单相同，请参见标准销售订单

# 操作说明

通过菜单<a href="/detail/6e341ff694f149d9b521549c0b102e42">补货销售</a>进入补货销售界面；

*  操作步骤
 
   *  第1步：选择单据类型、客户等相关信息。
   *  第2步：录入字表信息。
   *  第3步：点击“保存”，保存补货销售。
