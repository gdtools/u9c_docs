
# 功能描述

委托代销结算订单是委托代销业务中根据[委托代销结算清单（结算清单）所生成的销售订单。

选择【销售与分销】－>【接单】－>【委托代销销售】，打开委托代销结算订单。

画面中栏目、功能操作基本与标准销售订单相同，有以下几点不同：

不支持交期，即不支持手工录入订单的出货计划行；

不支持预留、料品的可承诺量查询、CTP查询、现存量查询；

不支持预收款；

不支持出货、出货计划、补货活动

# 栏目说明

委托代销结算订单的栏目基本与标准销售订单相同。下表中仅列出委托代销结算订单与标准销售订单的不同栏目。

|栏目|说明|
|---|---|
|订单头－基本页签|
|单据类型|只能选择业务类型为委托代销结算的单据类型|
|交期|为空，不可维护|
|来源类别|默认＝“委托代销结算清单”，不可改。|
|来源单据|不可改|
|订单头－物流页签||
|收货位置|为空，不可维护|
|出货原则|为空，不可维护|
|出货方式|为空，不可维护|
|需求分类|为空，不可维护|
|装运港|为空，不可维护|
|目的港|为空，不可维护|
|订单头－财务页签||
|预收款单|为空，不可维护|
|预收金额|为空，不可维护|
|订单行－基本页签||
|料品|不支持套件不成套发货|
|交期|为空，不可维护.|

# 按钮说明

*  借出转销售订单的基本与标准销售订单相同，请参见标准销售订单
*  <批量生单>：可选多个委托代销结算清单（结算清单）生成委托代销结算订单。

操作步骤

点击【操作】－>【批量生单】按钮。弹出批量生单的过滤条件画面，具体步骤如下所示。

第1步：在过滤条件画面中设定批量生单的过滤条件，即通过客户信息、料品信息、交易信息，或者指定来源单据号范围筛选生成销售订单的委托代销结算清单。点【确定】按钮，打开生单列表画面。

第2步：在生单列表画面中执行生单操作，生单列表画面见下文“栏目说明”。

【确定】：在画面中选择合适的结算清单，点【确定】按钮即可生成并打开委托代销订单，同时提示生成单据张数，此为第几张等。

【重新选单】：弹出批量生单的过滤条件画面，重新设定新的过滤条件

【设置】：打开分单条件设置画面。在其中设定分单条件后，在生单列表画面中选择了多个来源单据时，将根据分单条件生成多张委托代销订单。

栏目说明

|栏目|说明|
|---|---|
|复选框|选择单据时，可同时选择多条委托代销结算清单|
|行号|显示项|
|行类型|显示项|
|料品|显示项|
|数量1|显示项，销售单位数量|
|单位1|显示项，销售单位|
|数量2|显示项，销售基准单位单位数量|
|单位2|显示项，销售基准单位|
|本次结算数量1|可改，默认=数量1－累计已结数量（销售单位）|
|本次结算数量2|可改，默认=数量2－累计已结数量（销售基准单位）|
