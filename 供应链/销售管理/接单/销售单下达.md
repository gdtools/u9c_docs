
# 功能描述

销售单下达是指根据已经核准的销售订单的[执行组织]、[MRP需求]、[库存规划需求]、[供应来源]、[供应组织]和[需求转化类型]等数据项的具体值，生成后续业务处理单据的功能。后续业务处理单据包括：采购订单、生产订单、销售订单。

|后续单据|下达前提|
|---|---|
|采购订单|1、业务类型为标准销售，[供应组织]=外部供应商时可下达转采购订单；2、供应商直运标识为真，[供应组织]=外部供应商时可下达转采购订单； 3、业务类型为标准销售，转外协，且物料的[供应类型]为“转外协”可下达转全程委外订单。|
|生产订单|业务类型为标准销售，物料的[计划方法]为“LRP”，且[供应类型]=转制令且[供应组织]=内部工厂组织时，可下达转生产订单。|
|销售订单|订单的执行组织为另一营运组织（与当前组织的“营业行为关系类型”=“销售—销售”），下达后，源订单将关闭。|
|||


# 业务规则

*  参数设定，与销售单下达相关参数
*  销售订单必须整单核准；
*  销售订单计划行未挂起、为关闭、未终止
*  管控信用且订单下达点为信用控制检查点，若信用检查不通过则订单不能下达；
*  订货客户的状态允许订单下达。
*  订单计划出货数量没有全部被预留

# 按钮说明

*  <继续选单>：重新设置过滤条件，但保留原来选择的记录，追加，并自动剔除重复的计划行。

操作步骤：执行【继续选单】操作，在打开的画面中设置查询过滤条件后，点“确定”按钮即可；点“取消”放弃查询返回下达画面。

*  <设置>：设置销售订单生成PO/MO的分单条件。

操作步骤：执行【设置】操作，在打开的画面中设置选择分单栏目（【物料形态属性】、【收货客户】、【承诺交货日期】）后点“确定”按钮即可；点“取消”放弃设置返回下达画面。

*  <下达>：将所选择出来所有订单计划行进行下达。

操作前提：当前订单【已下达】＝false

操作步骤：执行【下达】操作即可将选择出来所有订单计划行进行下达

*  <取消下达>：将所选择出来所有订单整单进行取消下达。

操作前提：当前订单【已下达】＝true

取消下达，必须先将后续的业务单据取消，即删除已生成采购订单/生产订单，如采购订单/生产订单已核准，不允许取消下达。

操作步骤：执行【取消下达】操作即可
