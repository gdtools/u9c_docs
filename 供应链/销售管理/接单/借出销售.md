
# 功能描述

借出转销售订单是借出转销售业务，根据借出单生成的销售订单。

选择【销售与分销】－>【接单】－>【借出销售】，打开借出转销售订单。

画面中栏目、功能操作基本与标准销售订单相同，有以下几点不同：

不支持交期（无订单出货计划行）

不支持预留、料品的可承诺量查询、CTP查询、现存量查询；

不支持预收款；

不支持出货、出货计划、补货活动

# 关键应用

# 业务规则

*  参数设定，借出转销售订单相关参数
*  定义参见标准销售订单

# 栏目说明

借出转销售订单的栏目基本与标准销售订单相同。下表中仅列出借出转销售订单与标准销售订单的不同栏目。

|栏目|借出转销售订单|
|---|---|
|订单头－基本页签|
|单据类型|只能选择业务类型为借出转销售的单据类型|
|交期|为空，不可维护|
|来源类型|不可维护|
|来源单据|不可维护|
|订单头－商务页签||
|价表|当“转销售价格”＝“自动取价表”时，默认从客户收货位置或客户主档带入，否则为空，不可维护|
|价格含税|当“转销售价格”＝“自动取价表”时，默认从价表中带入，可改。否则为空，不可维护|
|订单头－物流页签||
|收货位置|为空，不可维护|
|出货原则|为空，不可维护|
|出货方式|为空，不可维护|
|需求分类|为空，不可维护|
|装运港|为空，不可维护|
|目的港|为空，不可维护|
|订单头－财务页签||
|预收款单|为空，不可维护|
|预收金额|为空，不可维护|
|订单行－基本页签||
|料品|不支持套件不成套发货|
|交期|为空，不可维护.|

# 按钮说明

借出转销售订单的基本与标准销售订单相同，请参见标准销售订单
