
# 功能描述

除了随单发生的费用外，还有一些费用，发生时并不能明确其具体受益对象，如按期间发生的仓储费用、港杂费用等，U9提供管销费用单，来处理此类业务。

# 关键应用

*  管销费用处理；
*  管销费用分配；
*  管销费用立账；
*  管销费用的多组织。

# 业务规则

*  管销费用可处理自行负担、客户承担或代收代付的费用。
*  管销费用不能摊入到料品的售价中。
*  管销费用可以分配订单中，或分配到出货单上(按组织参数确定）。
*  管销费用分配到订单时，还会按正向分配机制分配到出货单；分配到出货单时，还会按反向分配机制更新至订单。
*  管销费用可批量分配至指定单据。
*  管销费用支持拉式立应收、应付。
*  管销费用可分配至指定单据，随指定单据立账。
*  费用所属组织：按费用所属组织进行管销费用分配。
*  费用支付组织：按费用支付组织立应付。
*  当两个组织对应的核算组织不同时，形成内部的应收应付。

# 栏目说明

执行**【管销费用】－>【管销费用单】**操作，系统打开管销费用单画面.栏目带*号的表示必输项。

管销费用单头－基本页签

|**栏目**|**说明**|
|---|---|
|单据类型|选择录入单据类型名称，点击栏目可以在线维护“单据类型”数据。|
|单据号|管销费用单的单据编号。|
|单据日期|管销费用单的业务发生的日期。|
|分摊依据|参照录入管销费用单所发生的费用分配到订单或出货单的分摊依据，每项分配依据对应订单或出货单的相关栏目。分摊依据：按未税金额、按价税合计、按数量、按体积、按重量、按体积。|
|费用发票号|当前管销费用所对应的发票编号。|
|费用项目|参照录入费用项目。|
|费用类型|系统维护，表示当前费用项目所对应的费用类型。|
|费用性质|系统维护，由所选的费用项目带出。|
|费用币种|当前所发生的管销费用的币种。|
|无税金额|管销费用的无税的费用金额。|
|含税金额|管销费用的含税的费用金额。|
|核算组织|应收、应付的默认值核算组织，可带入管销费用单的应收/应付页签，可改。|
|结算组织|应收、应付的默认值结算组织，可带入管销费用单的应收/应付页签，可改。|

当费用性质=“客户负担”时，本页签内容不可改。

|对帐日期|手工录入对帐的日期。|

# 按钮说明

*  < 操作--分配范围>

弹出“分配范围”对话框，根据所输入条件查找并指定可分配单据。

*  <操作--重新分配>

将当前单行中分配金额清零，并按照分配规则重新将单头[含税金额]分配至单行。

*  <操作--取消分配>

将当前单行中分配金额清零。

*  <操作--批量分配>

根据指定的条件(“批量分配查找”画面)，将需进行分配的管销费用单列出（上列表）；再根据指定的“分配范围”过滤出可分配的订单/出货单，在一个界面里进行多对多的批量操作。

*  <操作--关闭>

手工关闭当前管销费用单，管销费用关闭后不能再分配了。

*  <操作--打开>

手工将已关闭的管销费用单打开，打开后可以重新进行分配。
