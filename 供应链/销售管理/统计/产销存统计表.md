
# 功能描述

1、按照指定方式对料品的完工数量、销售数量、立账数量和库存数量进行统计。并可按期间进行对比。

2、本报表可统计的数据

完工数量，本期间内完工入库的数量。

出货数量，本期间销售出货的数量。

退货数量，本期间销售退货的数量。

发出商品数量，出货数量减去退货数量。

正立账数量，本期间正向立账的数量。

负向立账数量，本期间负向立账的数量。

立账数量，本期间正向立账数量减去本期间负向立账数量。

# 业务规则

*  销售系统已启用
*  统计数据已更新，参见统计更新
*  定义统计期间，参见统计期间

# 栏目说明

统计条件：系统在查询方案中提供默认的统计条件，

         *  不同的统计方式对应不同的统计条件。
         *  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

统计结果：不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

   *  第1步：录入查询方案。
   *  第2步：点击确定。
