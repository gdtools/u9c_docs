
# 功能描述

按照指定方式对销售订单的订货数量、订货金额进行统计，系统提供三种统计方式：

销售分析：本报表中默认的统计方式

销售排名：支持前排名、后排名两种排名方式

销售比较 ：支持基期逐期比较、历年同期比较、环比三种比较方式


# 业务规则

*  销售系统已启用
*  统计数据已更新，参见统计更新
*  定义统计期间，参见统计期间

# 栏目说明

统计数据

*  已核准的订单,且需要"客户确认"的订单已经确认
*  委托代销订单与借出订单不参与统计

统计条件：系统在查询方案中提供默认的统计条件，

*  不同的统计方式对应不同的统计条件。
*  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

统计结果

*  不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 按钮说明

执行【统计】－>【接单统计表】，系统打开“查询方案”画面，在其中选择统计方式与查询条件后，点击确定按钮，即可将报表显示在画面中。具体操作参见查询方案

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。
*  <调整列宽>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。

# 操作说明

*  通过菜单<a href="/detail/8aefe6f543c44b80bce79cfa188f67c6">接单统计表</a>进入接单统计表界面；
*  操作步骤
 
   *  第1步：录入查询条件。
   *  第2步：点击保存。
   *  第3步：点击确定。
