
# 功能描述

1、按照指定方式对料品的委托代销发货数量、结算数量、立账数量和开票数量进行统计。并可按期间进行对比。

2、本报表可统计的数据：

发货数量，本期间从普通仓调往委托代销寄外仓的数量。

退回数量，本期间从委托代销寄外仓退回普通仓的数量。

调出数量，本期间从当前委托代销寄外仓调往其它委托代销寄外仓的数量。

调入数量，本期间从其它委托代销寄外仓调入当前委托代销寄外仓的数量。

结算数量，本期间委托代销结算的数量。

立账数量，本期间委托代销立账的数量。

开票数量，本期间委托代销开票的数量。


# 业务规则

*  销售系统已启用
*  统计数据已更新，参见统计更新
*  定义统计期间，参见统计期间

# 栏目说明

统计条件：系统在查询方案中提供默认的统计条件，
         *  不同的统计方式对应不同的统计条件。
         *  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

统计结果：不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。
