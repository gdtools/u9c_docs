
# 功能描述

1、按照销售计划统计其完成情况，包括需求量、出货量、完成率和库存量，并可指定纬度进行小计。

2、本报表可统计的数据

需求数量，销售计划的预测订货数量。

出货数量，销售计划的实际出货数量。

完成率，实际出货量的完成百分比。

库存数量，料品的结存数量。


# 业务规则

*  销售系统已启用

# 栏目说明

统计条件：系统在查询方案中提供默认的统计条件，          *  不同的统计方式对应不同的统计条件。
         *  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

统计结果：不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。
