
# 功能描述

按明细查询销售出货的出货数量及金额，结转销售成本数量及金额，以及未结转销售成本的剩余发出商品数量及金额。

可以通过查询条件自行配置

各种销售退货类型是否影响发出商品（或销售成本）

各种销售退货单据类型是否影响发出商品（或销售成本）

各种销售退货申请单据类型是否影响发出商品（或销售成本）

各种销售退货处理单据类型是否影响发出商品（或销售成本）

赠品、免费品出货、退货是否影响销售成本

出货但不立帐是否影响销售成本

# 业务规则

*  销售系统已启用
*  统计数据已更新，参见统计更新
*  定义统计期间，参见统计期间

# 栏目说明

统计数据：出货数量、出货成本金额、结转销售成本数量、结转销售成本金额、剩余发出商品数量、剩余发出商品成本金额

统计条件：系统在查询方案中提供默认的统计条件，
         *  不同的统计方式对应不同的统计条件。
         *  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

统计结果：不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 按钮说明

执行【统计】－>【发出商品表】，系统打开“查询方案”画面，在其中选择统计方式与查询条件后，点击确定按钮，即可将报表显示在画面中。具体操作参见查询方案

*  <查询方案>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。具体操作参见查询方案。
*  <调整列宽>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。
