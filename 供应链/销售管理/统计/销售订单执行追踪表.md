
# 功能描述

根据选中条件查询销售订单执行情况，包括出货数量、金额，立账数量、金额，收款数量、金额，退货数量、金额等

# 关键应用

# 业务规则

*  销售系统已启用

# 按钮说明

执行【统计】－>【销售订单执行追踪表】，系统打开“查询方案”画面，在其中选择统计方式与查询条件后，点击确定按钮，即可将报表显示在画面中。具体操作参见[查询方案](javascript:void(0);)

*  [<查询方案](javascript:void(0);)>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。具体操作参见[查询方案](javascript:void(0);)
*  [<调整列宽](javascript:void(0);)>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。
