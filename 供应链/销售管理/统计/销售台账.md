
# 功能描述

是销售管理部门对经销商往来业务的状态的一种统计，通常是指定止始日期，统计到指定日期为止对经销商的出货、欠票、欠款的情况。

销售台帐通常以金额体现，多数情况下无法提供数量信息（如，按非产品的维度进行汇总统计时，数量通常是没有意义的）。

从企业角度看销售台帐会有多种维度，如：

按部门，按业务员，按组织，

按客户，按客户类，按客户位置，按客户集团

# 关键应用

# 业务规则

*  销售系统已启用

# 栏目说明

统计数据：

|业务角度关注的字段：|
|---|
|
   *  期初已发货未回款
|
|
   *  本期发货（含退货，价差，票折）
|
|
   *  本期收款（含返利，费用抵款）
|
|
   *  本期业务余额
|
||
|财务角度关注的内容：|
|
   *  期初已发货未开票
|
|
   *  期初已开票未回款
|
|
   *  本期开票
|
|
   *  本期收款（同上）
|
|
   *  期末已发货未开票
|
|
   *  期末已开票未回款
|

统计条件：系统在查询方案中提供默认的统计条件，

*      *           *                *  不同的统计方式对应不同的统计条件。
         *  另外用户通过[查询方案](javascript:void(0);)画面的“属性选取”操作自定义查询条件。

|过滤条件项|规则及约束|备注|
|---|---|---|
|客户|单选，为空表示全部|　|
|客户位置|单选，为空表示全部|　|
|客户集团|单选，为空表示全部|　|
|币种|单选，必选|　|
|地区|单选，为空表示全部|　|
|组织|多选，为空表示全部|　|
|部门|多选，为空表示全部|　|
|业务员|单选，为空表示全部|　|
|项目号|多选，为空表示全部|　|
|开始日期|单选非空，默认为当前系统让日期|　|
|截止日期|单选非空默认为当前系统日期|出库确认日，应收：单据日期，核销日期|
|……|||
|包含未核销的到款|Y/N|注：到款包括未核销的收款单、贷向单、应付单、应收票据；未使用的销售返还。|
|包含费用折扣金额|Y/N|=Y时，则在显示栏目中可拖出费用折扣金额栏目；|
|=N时，则不允许拖出；|
|包含出退明细|Y/N（视实现情况而定）|=Y时，在栏目列中显示相应的出和退明细；|
|=N时，则不显示；|

统计结果：不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。

# 按钮说明

执行【统计】－>【销售台账】，系统打开“查询方案”画面，在其中选择统计方式与查询条件后，点击确定按钮，即可将报表显示在画面中。具体操作参见[查询方案](javascript:void(0);)

*  [<查询方案](javascript:void(0);)>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。具体操作参见[查询方案](javascript:void(0);)
*  [<调整列宽](javascript:void(0);)>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。

# 操作说明

*  通过菜单《供应链：销售管理：统计：销售台账》进入销售台账界面；
*  操作步骤
 
   *  第1步：录入查询方案。
   *  第2步：点击确定。
