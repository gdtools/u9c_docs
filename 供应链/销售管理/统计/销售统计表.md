
# 功能描述

1、按照指定方式对订单、出货单进行统计，系统提供三种统计方式：

销售分析：本报表中默认的统计方式

销售排名：支持前排名、后排名两种排名方式

销售比较 ：支持基期逐期比较、历年同期比较、环比三种比较方式

2、本报表可统计的数据

订货数量、订货金额

出货数量、出货金额

退货数量、退货金额

开票数量、开票金额

立账数量、立账金额

回款数量、回款金额

退货数量、退货金额

退货收货数量


# 业务规则

*  销售系统已启用
*  统计数据已更新，参见统计更新
*  定义统计期间，参见统计期间

# 栏目说明

统计数据

*  已核准的订单,且需要"客户确认"的订单已经确认
*  委托代销订单与借出订单不参与统计
*  出货单已核准

统计条件：系统在查询方案中提供默认的统计条件，

*  不同的统计方式对应不同的统计条件。
*  另外用户通过查询方案画面的“属性选取”操作自定义查询条件。

统计结果

*  不同的统计方式、统计条件决定了统计结果的不同。用户可根据需要任意组织统计条件并生成报表。
