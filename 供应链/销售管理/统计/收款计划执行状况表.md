
# 功能描述

执行追踪销售订单收款情况，包括出货收款，下单收款，计划收款，其他等

# 关键应用

# 业务规则

*  销售系统已启用

# 按钮说明

执行【统计】－>【计划收款执行状况表】，系统打开“查询方案”画面，在其中选择统计方式与查询条件后，点击确定按钮，即可将报表显示在画面中。具体操作参见[查询方案](javascript:void(0);)

*  [<查询方案](javascript:void(0);)>：点击界面中的[查询方案]按钮，可以定义查询方案，包括查询条件、栏目及排序。具体操作参见[查询方案](javascript:void(0);)
*  [<调整列宽](javascript:void(0);)>：点击列表下的[调整列宽]按钮，可以调整列表栏目显示及打印的宽度。

# 操作说明

*  通过菜单《供应链：销售管理：统计：计划收款执行状况表》进入计划收款执行状况表界面；
*  操作步骤
 
   *  第1步：录入查询方案。
   *  第2步：点击确定。
