
# 功能描述

进入【客户门户】－>【客户调剂】－>【客户确认】

“客户确认”的含义是：调出方确认可调出的数量、批号等信息。

# 业务规则

*  启用销售系统（必做）
*  启用渠道管理（必做）
*  启用客户门户（必做)

# 栏目说明

进入后首先展示的是客户调剂单的列表画面。

选择待确认的调剂单双击后即弹出该调剂单，客户录入对应的确认信息后即可确认。

栏目说明参见客户调剂单。

# 按钮说明

*  <查询>：点击客户门户－>客户调剂－>客户确认－>查询，选择条件过滤出对应的客户调剂单。
*  <确认>：点击客户门户－>客户调剂－>客户确认－>确认，对相应的客户调剂单进行确认。

# 操作说明

*  通过菜单[调剂确认列表](/detail/null)进入调剂确认列表界面；
*  操作步骤
 
   *  第1步：录入查询条件。
   *  第2步：进行客户确认。
