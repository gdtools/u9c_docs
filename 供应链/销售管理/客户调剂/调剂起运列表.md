
# 功能描述

进入【客户门户】－>【客户调剂】－>【客户起运】

当不需要配送时，由调出方进行起运操作，录入实际调出量、批号、序列号等。

# 业务规则

*  启用销售系统（必做）
*  启用渠道管理（必做）
*  启用客户门户（必做)

# 栏目说明

进入后首先展示的是客户调剂单的列表画面

选择待确认的调剂单双击后即弹出该调剂单，客户录入对应的确认信息后即可确认

栏目说明参见客户调剂单

行页签

|栏目名称|说明|
|---|---|
|批号|客户确认的可以用于调出的该物料的批号|
|调出数量（库存）|以库存单位表示的客户起运的调出去的数量|
|调出数量（计价）|以计价单位表示的客户起运的调出去的数量|

其他栏目说明参见客户调剂单

# 按钮说明

*  <查询>：点击客户门户－>客户调剂－>客户确认－>查询，选择条件过滤出对应的客户调剂单。
*  <起运确认>：点击客户门户－>客户调剂－>客户确认－>确认，对相应的客户调剂单的起运信息进行确认。
*  <序列号>：物料进行序列号管理，点击客户门户－>客户调剂－>客户确认－>链接－>序列号，通过本操作录入起运的序列号。

# 操作说明

*  通过菜单[调剂起运列表](/detail/null)进入调剂起运列表界面；
*  操作步骤
 
   *  第1步：录入查询条件。
   *  第2步：查询起运信息。
