
# 功能描述

区域库存调度员对客户调剂单通过对账处理，对账通过的调剂单，系统创建针对调出方的RMA、RCV的创建；创建针对调入方的销售出货单。

# 关键应用

*  管销费用处理；
*  管销费用分配；
*  管销费用立账；
*  管销费用的多组织。

# 业务规则

*  客户调剂单已核准；
*  管销费用不能摊入到料品的售价中。
*  管销费用可以分配订单中，或分配到出货单上(按组织参数确定）。
*  管销费用分配到订单时，还会按正向分配机制分配到出货单；分配到出货单时，还会按反向分配机制更新至订单。
*  管销费用可批量分配至指定单据。
*  管销费用支持拉式立应收、应付。
*  管销费用可分配至指定单据，随指定单据立账。
*  费用所属组织：按费用所属组织进行管销费用分配。
*  费用支付组织：按费用支付组织立应付。
*  当两个组织对应的核算组织不同时，形成内部的应收应付。

# 栏目说明

客户调剂单对账画面头

|**栏目**|**说明**|
|---|---|
|**调出对账成功**|默认＝false，可改；|
|**调入对账成功**|默认＝false，可改；|

客户调剂单对账画面行

|**栏目**|**说明**|
|---|---|
|**调出对账量**|参见客户调剂单表体[调出对账量-库存]，可改；|
|**调入对账量**|参见客户调剂单表体[调入对账量-库存]，可改；|
|**拒收对账量**|参见客户调剂单表体[拒收对账量-库存]，可改；|

# 按钮说明

*  <查询>

根据条件查询满足条件的客户调剂单。

*  <序列号>

弹出选中行对应的序列号子表数据，可以修改、增删行。

*  <对账处理>

所有表体行[调入对账成功]、[调出对账成功]标志均为true的调剂单，自动完成对账操作。

# 操作说明

*  在客户调剂单对账画面，表头显示待对账调剂单头数据（已核准状态），其中调入、调出对账成功标志可手工勾选；表体显示表头列表中选中的调剂单的表体信息；
*  可在调剂单的表体中，修改项目、批号、调出对账数量、调入对账数量、拒收对账数量、实际起运日期、实际到达日期等；
*  点击序列号，弹出选中行对应的序列号子表数据，可以修改、增删行；
*  点击保存按钮，保存调剂对账数据；

注意：

[调出对账成功]和[调入对账成功]=true的表体行，[调出对账量（库存）]必须＝[调入对账量（库存）]+[拒收对账量（库存）]，[调出对账量（计价）]必须＝[调入对账量（计价）]+[拒收对账量（计价）]；

存在序列号记录的调剂单表体行，[调出对账成功]=true时，序列号记录数量必须＝[调出对账量]；

存在序列号记录的调剂单表体行，[调入对账成功]=true时，序列号记录中[签收]=true的数量必须＝[调入对账量]；

*  点击对账处理按钮，所有表体行[调入对账成功]、[调出对账成功]标志均为true的调剂单，自动完成对账操作。
