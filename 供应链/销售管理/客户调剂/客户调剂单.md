
# 功能描述

通过客户调剂单，在客户之间调剂库存，将有滞销库存的客户的库存，调给其他客户。

# 关键应用

*  管销费用处理；
*  管销费用分配；
*  管销费用立账；
*  管销费用的多组织。

# 业务规则

*  管销费用可处理自行负担、客户承担或代收代付的费用。
*  管销费用不能摊入到料品的售价中。
*  管销费用可以分配订单中，或分配到出货单上(按组织参数确定）。
*  管销费用分配到订单时，还会按正向分配机制分配到出货单；分配到出货单时，还会按反向分配机制更新至订单。
*  管销费用可批量分配至指定单据。
*  管销费用支持拉式立应收、应付。
*  管销费用可分配至指定单据，随指定单据立账。
*  费用所属组织：按费用所属组织进行管销费用分配。
*  费用支付组织：按费用支付组织立应付。
*  当两个组织对应的核算组织不同时，形成内部的应收应付。
