
# 功能描述

如果出货计划行上录入了出货条件，则表明必须对其所对应的出货条件项目一一确认已完成准备，此出货计划才能核准生效，才能安排出货。

出货评估就是为了完成对出货计划里的出货条件项目进行确认的。

可对指定的出货计划行或按过滤条件查找出来的一批出货计划行，查看或维护其出货条件项目的准备状态。

画面初始加载时按默认过滤条件显示（当月1号到目前为止，准备出货的出货计划行），可通过修改过滤条件列出其他出货计划。


# 业务规则

*  出货计划单行，录入出货条件。

# 栏目说明

主画面－基本页签

|栏目名称|说明|
|---|---|
|出货计划上的信息|客户、出货位置、料品、出货计划、行号、计划出货日、计划出货量等列，均为待评估的出货计划上的有关信息。|
|"出货条件项目"|此处为动态创建列，为当前列出的所有待评估的出货计划行所挂出货条件对应的出货条件项 目的最大集合。如出货计划行10的出货条件项目为关务、货运，出货计划行20的出货条件项 目为检验检疫、关务，则此处将共列示三列：关务、货运、检验检疫。由于此处是列示所有出货计划行的出货条件项目全集，所以有的出货条件项目列在某些出货 计划行里是没有的，这些单元格上就显示“---”，他们是不能做处理的。系统提供了批量处理的功能，可通过对列头的□进行打勾或去勾，可对整列值进行批量处理。选中一个单元格，可在“明细”页签里查看出货计划详细信息，并查看/维护评估信息。注意：对于已关闭、已终止、已挂起或已核准的出货计划行，此处只能看、不能编辑。|
|状态|这是系统自动维护的列，用于显示各待评估的出货计划行，其所有出货条件项目是否都已 准备齐全。若全部准备齐全，则此处会显示符号“√”；否则显示空白。|

主画面－明细页签

|栏目名称|说明|
|---|---|
|基本分区|显示出货计划的客户、出货位置、及出货料品的详细信息。|
|出货计划分区|显示出货计划的地点、数量和时间等信息。|
|评估结果|显示和维护该出货条件项目的准备情况，若还未完成准备，可录入未完成原因原因、备注等信息。|

# 按钮说明

*  <设置画面－过滤条件>：

|栏目名称|说明|
|---|---|
|组织|目前只能查找当前组织下的出货计划|
|出货计划|可指定只查询某出货计划。|
|料品|可指定料品过滤条件。|
|客户|可指定只查某客户的出货计划。|
|计划出货日|可查询某段日期范围内的出货计划。|
|出货条件|可指定下挂什么出货条件的出货计划。|
|出货条件项目|可指定包含什么出货条件项目的出货计划，如所有需要办理关务的出货计划。|
|包含项目且未完成的|可设定只显示未完成某项目的出货计划，如所有需要办理关务、但还未办理完的出货计划。|
|包含项目且已完成的|可设定只显示已完成某项目的出货计划，如所有需要办理关务、且已办完的出货计划。 若勾选，则仅显示所有项目都完成准备的出货计划。|
|评估状态|按评估状态查找过滤，单选，非空 。枚举：未通过评估且未审核（默认）已通过评估且未审核已通过评估且已审核空|
|显示已终止记录|若未勾选，则仅显示还存在未完成准备项目的出货计划，不显示已全部完成的出货计划。|
|显示已关闭记录|若未勾选，则仅显示未终止的出货计划，已终止的出货计划不显示。|

# 操作说明

*  通过菜单<a href="/detail/a843c0038b33498ea07d8363b6d45d32">出货评估</a>进入出货评估界面；
*  操作步骤
 
   *  第1步：选择单据类型、计划员等相关信息。
   *  第2步：编辑子表行信息。
   *  第3步：点击“保存”，保存出货计划。
