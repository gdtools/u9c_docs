
# 功能描述

立即或定期进行销售统计数据的更新。

在执行统计查看相关报表时，提高效率。

以保证销售统计报表的正确性与及时性。


# 业务规则

*  拥有统计更新的权限。

# 按钮说明

*  <统计>：立即执行统计更新
*  <调度方案>：将销售统更新加入系统调度，在指定时间自动执行统计更新。
   *  操作前提：如需重复执行，需先设定“调度计划”。
   *  操作步骤：在画面中设定过滤条件后，点击【调度方案】，打开调度画面，选择调度方式。。
      *  执行一次：设定执行日期，系统将在指定日期执行统计更新。
      *  重复执行：指定“调度计划”，系统根据“调度计划”中定义重复执行统计更新。如未设定“调度计划”，可点击栏目链接在线创建调度计划。调度计划定义可参见相关文档。
      *  点击画面中【确定】按钮，将统计更新加入系统调度，点击【取消】按钮，放弃返回上级画面
