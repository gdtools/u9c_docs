
# 功能描述

本节点用于将资源报告业务生成的交易分录转为总账系统的记账凭证，主要功能如下：

可以将销售订单计算系统的交易分录转入总账生成记账凭证

可以删除的转入总账的记账凭证

可以选择是否合并生单

可以设定合并生单的合并规则

可以设置转总账规则

可以联查交易分录相关的总账凭证和业务单据

更多内容请参照公共操作转总账

# 业务规则

*  总账系统启用（必做）
*  总账系统账簿、凭证等相关设置完成（必做）
*  交易分录已经生成（必做）
*  设置账簿转换规则（多币种帐簿时必做）
*  定义调度方案

# 栏目说明

合同释放画面

|栏目名称|说明|
|---|---|
|合同号|需要释放的合同号|
|料品|需要释放的合同号料品|
|料品分类|需要释放的合同号料品分类|
|展望期|输入时只能输入非负整数|

# 按钮说明

*  <查询>：输入查询转总账分录的条件画面，默认的查询条件包含[已转总账]=false等，查询条件中需要显示已经在各应用相关的实体上已经启用的公共扩展字段。
*  <生成凭证>：将列表上所选择的交易分录传递到总账并生成记账凭证。
   *  操作前提：已经生成交易分录
   *  操作步骤：进入转总账业务操作画面。具体步骤如下所示。
      *  第1步：进入转总账单据列表画面，列表显示所有未转总账的交易分录；
      *  第2步：在列表中选择本次需要转总账的交易分录，点击生成凭证按钮，弹出凭证生成画面；
      *  第3步：在凭证生成画面中选择是否需要合并制单以及合并制单的条件；
      *  第4步：点击生成凭证按钮，系统自动生成总账系统的记账凭证，并返回转总账列表画面，在凭证类别、会计期间和凭证号栏目显示生成的记账凭证信息；
      *  第5步：可以通过追溯查询－>联查凭证、联查单据按钮查询当前交易分录所生成的记账凭证和与当前交易分录相关的业务单据。
*  <删除凭证>：将列表画面上业务单据在总账系统的记账凭证删除处理。
   *  操作前提：交易分录已经转总账生成记账凭证。
   *  操作步骤
      *  第1步：进入转总账单据列表画面，查询已经转总账的交易分录；
      *  第2步：在列表中选中需要删除的凭证，点击删除凭证按钮；
      *  第3步：系统将已经转总账的记账凭证删除。经过处理后，用户可以再次执行转总账处理。
*  <作废凭证>：将列表画面上业务单据在总账系统的记账凭证作废处理。作废后，原来的记账凭证仍然可以查询，是一种有痕迹的删除处理。
   *  操作前提：交易分录已经转总账生成记账凭证。
   *  操作步骤
      *  第1步：进入转总账单据列表画面，查询已经转总账的交易分录；
      *  第2步：在列表中选中需要作废的凭证，点击作废凭证按钮；
      *  第3步：系统将已经转总账的记账凭证作废。作废后的凭证仍然可以查询，但不能进行任何业务处理。
*  <交易分录>：本按钮可以查询交易分录的具体内容。
