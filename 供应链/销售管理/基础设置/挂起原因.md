
# 功能描述

本节点提供生产订单中挂起原因的定义，主要功能点如下：

1. 定义挂起原因
2. 定义挂起原因的有效性和有效时间区间
3. 定义允许使用该挂起原因的操作员
4. 为操作员使用该挂起原因设定有效性和有效时间区间

# 业务规则

*  挂起原因编码不能为空，不允许重复

# 栏目说明

挂起原因定义表头

|栏目名称|说明|
|---|---|
|编码|输入当前挂起原因的编码。|
|名称|当前挂起原因的描述。|
|简称|当前挂起原因的简称。|
|生效|当前挂起原因是否生效。|
|生效日期|当前挂起原因的生效日期。|
|失效日期|当前挂起原因的失效日期。|


挂起原因定义表体

|栏目名称|说明|
|---|---|
|操作员|定义对当前挂起原因有使用权的操作员，只有在此列表中的操作员才有权使用当前挂起原因。|
|生效|当前列表行的操作员是否有权使用当前挂起原因。|
|生效日期|当前列表行的操作员允许使用当前挂起原因的开始日期。|
|失效日期|当前列表行的操作员允许使用当前挂起原因的结束日期。|

# 操作说明

*  通过菜单[挂起原因](javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkCBO.Base.HoldRelease.HoldReason&AppID3015&sId3015nid&mId1001101160311863","%E6%8C%82%E8%B5%B7%E5%8E%9F%E5%9B%A0");)进入挂起原因界面；

   *  第2步：选择操作员。
