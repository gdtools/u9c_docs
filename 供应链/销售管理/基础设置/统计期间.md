
# 功能描述

用于定义“库存统计表”所应用的“统计期间规则”，可为“库存统计表”定义多套“统计期间规则”，统计时会按照本功能节点设定的“统计期间规则”进行统计，产生多套“统计期间规则”的“库存统计表。”


# 业务规则

*  统计表名不能为空；
*  期间类型不能为空。

# 栏目说明

统计期间

|栏目名称|说明|
|---|---|
|应用系统|固定为“库存系统”，不可维护。|
|统计表名|库存系统中只有一张统计表：“库存统计表”，不可维护。|
|期间类型|枚举值：1．统计期间：选择本选项，查询报表会按统计期间来进行统计；2．会计期间：选择本选项，查询报表会按会计期间来进行统计；|
|期间规则|可参照录入，参见统计期间规则。|
|账簿|若期间类型＝2．会计期间，本栏目可参照录入账簿。|
|生效|标识此档案是否生效。|
|生效日期|生效的起始日期。|
|失效日期|生效的截止日期。|

# 操作说明

*  通过菜单[统计期间](javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkCBO.Pub.StatPeriodStatus.StatPeriodStatus&ApplicationID3015&sId3015nid&mId1001101160311865","%E7%BB%9F%E8%AE%A1%E6%9C%9F%E9%97%B4");)进入统计期间界面；
*  操作步骤
 
   *  第1步：选择统计表名、期间类型等信息。
   *  第2步：选择期间规则。
   *  第3步：点击“保存”，保存统计期间。
