
# 功能描述

规定哪个地区、哪类客户、或哪个客户（位置），可以由哪个组织、哪个存储地点来供应。即，规定客户的供应范围。

# 业务规则

*  按“渐近”规则匹配的。若某条记录不指定客户纬度（客户地区、客户分类、客户、客户位置），则表示供应范围与客户信息无关，只与供应组织（或存储地点）有关。
*  当组织参数“启用供应规则”被选中时，销售合同、销售计划、销售报价单和销售订单均会调用此规则,进行供应范围的合法性检查。

# 栏目说明

供应规则界面栏目

|栏目名称|说明|
|---|---|
|客户地区|可以按客户所属地区作为纬度来设定供应范围，可空。|
|客户分类|可以按客户分类作为纬度来设定供应范围，可空。|
|客户|可以按客户作为纬度来设定供应范围，可空。|
|客户位置|可以按客户位置作为纬度来设定供应范围，可空。|
|供应组织|指定可进行供应的组织，可空。供应组织与存储地点二者至少有一个非空。其可选范围是当前组织(若当前组织有物流/工厂机能），或与当前营运组织构成供应关系的物流/工厂组织（销售-物流、销售-工厂）。|
|存储地点|指定可进行供应的存储地点，可空。供应组织与存储地点二者至少有一个非空。若指定了供应组织，则存储地点只能是供应组织下的存储地点；若未指定供应组织，则存储地点只能是当前组织下的存储地点。|
|生效|当前供应规则是否生效|
|生效日期/失效日期|当前供应规则的有效期间|

*  通过菜单[供应规则](javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkCBO.SCM.MF5040_30&sId3015nid&mId1001101160311866","%E4%BE%9B%E5%BA%94%E8%A7%84%E5%88%99");)进入供应规则界面；
*  操作步骤
 
   *  第1步：选择客户地区、客户分类等信息。
   *  第2步：选择客户。
   *  第3步：点击“保存”，保存供应规则。
