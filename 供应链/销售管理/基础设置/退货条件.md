
# 功能描述

对于销售退回业务，可以按料品或料品类设定退货、换货或维修的时限条件。

退货条件分配给客户后，客户在发生退回业务时，按此政策进行相应控制。

注意：客户必须被分配一个退货条件，才允许进行退换货业务。

# 关键应用

# 业务规则

*  退货条件编码不能为空，不允许重复。

# 栏目说明

退货条件单头－基本页签

|栏目|说明|
|---|---|
|编码|非空，手工维护。|
|名称|可空，当前退货条件名称|
|描述|可空，对该退货条件的简单说明。|
|生效|当前退货条件是否生效|
|生效日期|当前退货条件生效/起始日|
|失效日期|当前退货条件失效/截止日|

退货条件单体—行页签:按照料品或料品分类定义退货条件

|栏目|说明|
|---|---|
|行号|系统编号|
|料品|参照料品档录入,点击链接可创建新料品或查看所选料品的明细内容,所选定料品在料品档中定义必须是可销售且可退货的。在一行中，[料品]和[料品分类]栏目不能同时非空。同时为空表示针对所有物料均适用当前行的退货政策要求(同时为空的记录仅能有一条).|
|料品分类|参照料品分类档录入,点击链接可创建新料品分类或查看所选料品分类的明细内容。|
|控制换货期限|对于换货业务，是否控制退回的时限，默认为True。如出货后3月内可换。|
|换货时限|[控制换货期限]=True时有效，允许输入非负整数|
|控制退货期限|对于退货业务，是否控制退回的时限，默认为True。如出货后1月内可退。|
|退货时限|[控制退货期限]=True时有效，允许输入非负整数|
|控制维修期限|对于维修退回业务，是否控制退回的时限，默认为True。如出货后1年内包修。|
|维修期限|[控制退货期限]=True时有效，允许输入非负整数|
|时间单位|单选，当[控制换货期限]、[控制退货期限]、[控制维修期限]有一项为True时非空。结合[退货时限]、[换货时限]、[维修期限]使用。枚举值年月(默认值)周天例如：退货时限=2,时间单位=月,则控制退货时限为2个月。|
|起算时间|指计算退回时间是否超出退回期限时的时间计算起点是从发货时间点起算还是从客户签收时点起算。枚举值：发货起算（默认值）签收起算[控制换货期限]、[控制退货期限]、[控制维修期限]栏目中至少有1个为True（被勾选），则此栏目非空必录； 若[控制换货期限]、[控制退货期限]、[控制维修期限]栏目都未勾选，则此栏目必为空，不可编辑。|

退货条件单体—料品信息页签

|栏目|说明|
|---|---|
|行号|显示项，与行页签中[行号]保持一致|
|料品．版本|显示项，料品名称与版本，与行页签中[料品]保持一致|
|等级|可改，料品等级当系统对料品进行等级成分管理,且所选定料品在料品档中定义进行等级控制,当前栏目有效可改|
|成分|可改，料品成分当系统对料品进行等级成分管理,且所选定料品在料品档中定义进行成分控制,当前栏目有效可改|

# 操作说明

*  通过菜单[退货条件](/detail/4db231ebe29f48479efb52c8b30edd8b)进入退货条件界面；
*  操作步骤
 
   *  第1步：录入退货条件编码、名称等相关信息。
   *  第2步：选择料品相关信息。
   *  第3步：保存退货条件。
