
# 功能描述

价目表一旦核准生效后，就不允许直接对其随意修改。对核准生效后的价表进行价格调整或新增价目，将通过调价单来完成。调价单生效后，将根据调价单修改价表，并生成新版本的价表。

# 关键应用

# 业务规则

*  定义价目表（必选）
*  定义客户/客户位置/客户分类（可选）
*  定义物料/物料类（可选）
*  定义物料等级、成份、自由项（可选）
*  定义计量单位（可选）

# 栏目说明

调价单头

|栏目|说明|
|---|---|
|基本分区|
|单据类型|非空，选择录入调价单单据类型名称，点击栏目可以在线维护“单据类型”数据。|
|调价单号|非空，调价单编码。可根据系统定义编码规则自动生成或手工维护|
|价表|非空，表示现在调整的是哪个价目表。|
|单据日期|调价单的录入日期。|
|描述|关于当前调价单的描述信息|
|状态分区|
|状态|系统维护,表示调价单的当前状态.点击链接可打开状态明细画面.|
|终止|系统维护,调价单执行终止操作后(参见下文)，此栏目为选中状态|
|后续期间失效|UI项。修改单头[后续期间失效]，会将所有符合如下条件的调价行的[后续期间失效]联动等于单头:调价行.失效=False 且调价行.失效日期<9999.12.31|

调价单体-行页签

|栏目|说明|
|---|---|
|行号||
|料号|进行调价的料品；若通过“价表-调价”进入画面，则自动带入选中价表行上的料品，可改；此栏目与【明细页签】的[料品]字段联动，保持一致。料品与料品分类不能同时为空,也不能同时非空；|
|品名|系统维护，所调物料的品名|
|料品分类|进行调价的料品分类；若通过“价表-调价”进入画面，则自动带入选中价表行上的料品类，可改；此字段与【明细页签】的[料品分类]字段联动，保持一致。|
|计价单位|表示料品（分类）定价时依据的计量单位； 计价单位不同，相同的调价策略下价格调整的幅度可能会不同。|
|生效时间/失效时间|当前调价价格的有效期，可以做临时调价（如夏季临时调价）、也可以做永久调价。|
|后续期间失效|选中则表示当前调价物料，在[失效时间]后不再存在任何有效报价。默认为未选中状态，可编辑性：当调价行.[失效]=False且[失效时间]<9999.12.31时，[后续期间失效]可编辑；当调价行.[失效]=True或[失效时间]>=9999.12.31时，[后续期间失效]=False、置灰不可改。|
|调后单价|需要调到的价格。|
|调前单价|当前价目在调价前的价格，可通过“操作-取价”获得，或从“价目选择”画面带入。|

调价单体-明细页签

|栏目|说明|
|---|---|
|行号|系统维护，等于当前页面对应的【行页签】的记录的“行号”|
|料品分区|
|料品|参见【行页签】相同栏目说明|
|厂牌|[料品]非空时才可录入，可空；系统支持按物料厂牌定价。|
|等级|[料品]非空时才可录入，可空；系统支持按等级、成份、自由项定价。|
|成分|同上|
|自由项1-3|同上|
|料品分类|参见【行页签】相同栏目说明|
|客户分区|
|客户|当前调价单执行调价的客户名称，可空,是调价单与价目表匹配的条件之一；如果通过销售价目表画面进入此画面，自动带入所选中的价目表行上的客户名称，可以修改；|
|客户位置|当前调价单执行调价的客户位置 ，客户不为空时，此字段可录入,可空；是调价单与价目表匹配的条件之一；|
|客户分类|当前调价单执行调价的客户分类名称，可空；是调价单与价目表匹配的条件之一；如果通过销售价目表画面进入此画面，自动带入所选中的价目表行上的客户分类名称，可以修改；|
|立帐条件|参照应收立账条件录入,可空。|
|收款条件|参照收款条件录入,可空。|
|价格分区|
|调前单价|参见【行页签】相同栏目|
|调价幅度|按调后单价、调前单价算出来的调价幅度|
|调后单价|参见【行页签】相同栏目|
|计价单位|参见【行页签】相同栏目|
|依赖型价目调价分区|
|依赖料品(版本)|当B料品定价依赖于A料品时，此处输入A料品的名称及版本；当此项为空时，“调前单价”与“调后单价”不为空，“调前定价百分比”与“调后定价百分比”为空；|
|调前定价比|当前料品定价为依赖料品的百分比，若单头价目表非空，从价目表画面的调价功能进入调价画面时，带入选定价目表行的“定价百分比”；|
|调后定价比|调整价格后料品价格等于依赖料品价格的百分比，调后定价百分比=调前定价百分比*（1+调价幅度）；|
|“有效期”分区||
|生效时间/失效时间|当前调价单生效的有效期间，非空。与行页签里的有效期间保持联动一致。|
|失效|选中则表明物料在当前调价的时间段内，将不再存在有效报价。|
|来源分区||
|来源|系统维护，表明调价单的来源手工录入：表示手工创建的调价单；报价单：表明是通过报价单自动创建的调价单|
|单号|系统维护，来源单据的单据编号|

# 按钮说明

*  <价目选择>：大规模调价时，可从指定的价目表里批量选择价目进行调价。
*  <终止>：对于不需要的调价单可以通过此功能对其进行终止，终止后调价单不再有用。调价单终止后不能恢复，此操作须谨慎！
*  <取价>：此功能可以将对应的价目表上的价格信息取到调价单行上，提高效率，也方便输入。

# 操作说明

*  通过菜单[销售价格调整](/detail/d752dd4ae803458eb3bf612a7d5dcc36)进入销售价格调整界面；
*  操作步骤
 
   *  第1步：选择单据类型。
   *  第2步：录入调价单号、价表等相关信息。
   *  第3步：录入子表相关信息
   *  第4步：点击“保存”，保存销售价格调整。
