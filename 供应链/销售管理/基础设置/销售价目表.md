
# 功能描述

销售价表是用来确定商品销售的价格清单。可以按照不同的角度，如不同的客户群体、不同的销售对象或不同的销售方式等，制定不同的价目表。参见应用专题【销售中的价格与折扣】

1. 可以对销售价表设定折扣；
2. 可以对销售价表进行调价操作；
3. 价目表可以在组织间进行下发。

# 关键应用

# 业务规则

*  定义币种[必选]
*  定义计量单位[必选]
*  定义客户（可选）
*  定义客户分类（可选）
*  定义物料（可选）
*  定义物料分类（可选）
*  定义物料等级、成分（可选）
*  定义物料自由项（可选）

# 栏目说明

销售价表头

|栏目|说明|
|---|---|
|基本分区|
|价表编码|销售价表编码.版本，版本表示价目表的当前版本，系统生成，不可维护，一个价目表可能有多个版本 。价表编码可自动生成，也可手工维护，由组织参数[价目表默认编码规则]决定。|
|名称|价目表名称。|
|币种|当前价格是基于什么币种设定的,销售订单引用价目表时，订单的销售币种应当与此币种相同。|
|一个价目表只能有一个币种，不同币种的报价应该设置不同的价目表。|
|折扣价表|表明当前价表的属性；非折扣价表，销售单据要通过此价表取得价格；折扣价表，销售单据要通过此价表取得折扣率。|
|价格含税|表示当前价格是否含税，价表被订单引用后，此栏目的值会自动带到订单的相同栏目。|
|成交方式|表明当前价表适用的成交方式。业务单据引用价表时，将匹配单据上的成交方式与价表成交方式，相同的方可引用。|
|价格员|当前价目表的定价人员或录入人员；|
|描述|可空,关于当前价目表的描述信息。|
|显示风格|加载价表时的默认显示风格从组织参数[价表显示风格]得到，可手工修改，即时刷新。新创建的价表，显示风格只能是“显示全部”。各选项含义如下：1.显示全部：显示该价表里所有有效的价目行，不管是否已过期 。2.显示最后：显示各价目里日期最后的那条有效的价目记录。如，价目表数据库里有如下记录：153V 红色 10元/个 2009.1.1-2009.5.31153V 红色 9元/个 2009.6.1-2009.7.31153V 红色 8元/个 2009.8.1-2009.12.31153V 红色 10元/个 2010.1.1-9999.12.31 失效153V 蓝色 11元 2009.1.1-9999.12.31加载价表时只显示日期最后的那条有效价目(按物料类+ItemInfo+厂牌+计量单位+依赖信息区分价目):153V 红色 8元/个 2009.8.1-9999.12.31153V 蓝色 11元 2009.1.1-9999.12.313.显示当前：按当前系统日期进行过滤，显示当前有效的价目。如，当前系统日期为2009.7.13，则在上述例子中显示的记录如下：153V 红色 9元/个 2009.6.1-2009.7.31153V 蓝色 11元 2009.1.1-9999.12.31|
|状态分区|
|状态|系统维护,表示价表的当前状态.点击链接可打开状态明细画面。|
|终止|系统维护,价表执行终止操作后(参见下文)，此栏目为选中状态。|

销售价表单体--行页签

|栏目|说明|
|---|---|
|行号|行记录的序号。|
|料品|参照【料品档】录入当前价表所针对的料品，是销售订单等单据取价表的依据之一。点击链接可进入料品画面查看料品明细情况或创建新料品。料品与料品分类不能同时为空，此字段与【明细页签】的[料品]字段联动，保持一致。|
|料品分类|参照【料品分类档】当前价表所针对的料品分类，是销售订单等单据取价表依据之一。点击链接可进入料品分类画面查看料品分类明细情况或创建新料品分类。料品与料品分类不能同时为空，此字段与【明细页签】的[料品分类]字段联动，保持一致。|
|客户|可空,参照【客户档】录入当前价表针对的客户名称,是销售订单等单据取价表的依据之一；点击链接可进入客户设置画面查看客户明细情况或创建新客户。此字段与【明细页签】的[客户]字段联动，保持一致。客户与客户分类不能同时录入。|
|客户位置|当客户不为空时，此字段可录入，表示价目表适用于客户的位置。例如：北京商贸公司东城分店，而其它位置的分店则不应用此价格。|
|客户分类|可空,参照【客户分类档】录入当前价表针对的客户分类,是销售订单取价表的依据之一；点击链接可进入客户分类设置画面查看客户分类明细情况或创建新客户分类。此字段与【明细页签】的[客户分类]字段联动，保持一致。客户与客户分类不能同时录入。|
|单价|非空，手工录入。表示单位计量单位料品（类别）的价格。|
|计价单位|参照录入，非空。表示为料品(类别)定价时依据的计量单位。|
|生效时间/失效时间|此价目的有效期间，非空。定价可考虑季节性因素，如春季是一个价，夏季是另一个价。|

# 按钮说明

*  <下发>：导航到下发功能节点。
*  <取消下发>：导航到取消下发功能节点。
*  <下发参数>：导航到下发参数功能节点。
*  <终止>：对价目表执行终止操作，终止后的价目表不能再使用，也不能对其进行调价或设定折扣的操作。价目表一旦终止，则其下所有版本均作废。
*  <其它版本>：查看当前价目表的其它版本的内容。
*  <分配客户>：将价目表分配给客户，与该客户的交易,使用价目表约定的价格。
*  <调价>：按设定的过滤条件，将当前价目表里的指定价目，批量带入调价单进行调价。
*  <已分配客户>：通过此功能可以查看当前价目表已分配给哪些客户使用了。
*  <折扣单>：通过此功能可以导航到“销售折扣”设定画面。关于“销售折扣”画面的详细内容可参见销售折扣的说明。
*  <调价单>：价目表一旦启用后，就对业务部门的销售业务产生了价格指导和约束作用，因而不允许手工随意修改，以防错误操作或人为扰乱企业的价格体系。价目表启用后，价格调整由调价单完成。关于调价单相关内容可参见销售价格调整的说明。

# 操作说明

*  通过菜单[销售价目表](/detail/aec04c795bfb4e4696554c9844537bf0)进入销售价目表界面；
*  操作步骤
 
   *  第1步：录入名称等相关信息。
   *  第2步：选择币种。
   *  第3步：录入行相关信息。
   *  第4步：保存销售价目表。
