
# 功能描述

用户可以使用本功能结点设置客户的允销或限销范围：即可以向某客户销售哪些商品，不可以销售哪些商品。当组织参数[允现销控制]被选中时,订单会根据此处的设置进行检查.

允限销有两种设置方式(在客户档案上设定)：

允销模式：对于经营面窄的客户，可以设置哪些商品可以销售给该客户；只有本表中的物料记录才能销售给客户。

限销模式：对于经营面广的客户，可以设置哪些商品不可以销售给该客户；本表中的物料记录不能销售给客户，本表中没有的物料记录可以销售给客户。

# 关键应用

# 业务规则

*  若所选择客户分类下的客户的[限制类型]不一致，将抱错，只有分类下的客户限制类型一样，才能录入客户分类。
*  [客户]和[客户分类]必须选择一个，且只能选择一个。
*  [料品]和[料品分类]必须选择一个，且只能选择一个。
*  若客户限制类型=不控制，则[允限销处理方式]=包含，不可改。

# 栏目说明

允销/限销画面栏目

|栏目|说明|
|---|---|
|基本分区|
|客户分类|参照客户分类档案录入，点击链接可查看客户分类的定义情况或创建一个新的客户分类表示按“客户分类”定义料品的允/限销情况|
|客户|参照客户档案录入，点击链接可查看客户的定义情况或创建一个新的客户表示按“客户”定义料品的允/限销情况|
|料品分类|参照物料分类档案录入，点击链接可查看物料分类的定义情况或创建一个新的物料分类表示按“物料分类”定义客户的允/限销情况|
|料品|参照物料档案录入，点击链接可查看物料的定义情况或创建一个新的物料表示按“物料”定义客户的允/限销情况|
|客户限制类型|系统维护,不可改,取自“客户档案”|
|限制类型|非空，单选。枚举：包含：客户限制类型=[允销]，表示可以销售此物料（类）给此客户（类）；若客户限制类型=[限销]，则表示不能销售此物料（类）给此客户（类）排除：客户限制类型=[允销]，表示不能销售此物料（类）给此客户（类）；若客户限制类型=[限销]，则表示可以销售此物料（类）给此客户（类）|
|状态分区|
|生效|当前允/限销是否失效|
|生效日期|当前允/限销定义的生效／起始日期|
|失效日期|当前允/限销定义的失效／截至日期|
