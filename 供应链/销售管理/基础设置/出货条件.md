
# 功能描述

在进行销售出货前，实务上通常还需要做一些出货前的准备工作，如包装、货柜租恁、内陆运输安排、报关、船期安排等等，或按照客户指定的要求做相应的特殊安排。只有在这些安排都处理妥当后，才能真正进行出货。

我们按照目的地特性、出货客户特性、销售业务特性、销售商品特性、或其它特性，把这些出货前的安排(即出货条件项目)进行组合，取名为“出货条件”，如内销的出货条件、出口美国的出货条件、出口欧洲的出货条件、副食品销售的出货条件、生猪肉销售的出货条件。

出货条件可按客户设定默认值，带到出货计划（行）上，可改。出货计划可看成是出货安排或出货指令，若出货计划上挂了出货条件，则必须满足了这些出货条件项目后，才能核准出货计划、并进行出货。

出货计划上的出货条件检查工作，通过出货评估来完成。

# 关键应用

# 业务规则

*  出货条件编码不能为空，不允许重复。
*  定义出货条件的项目（UDC）。

# 栏目说明

出货条件头

|栏目|说明|
|---|---|
|编码|出货条件的编码，如CheckList01|
|名称生效生效日期失效日期|出货条件的名称，如牛肉出口出货条件表明此档案是否有效此档案从什么时候可以开始使用此档案在何时开始不再使用|

出货条件行

|栏目|说明|
|---|---|
|出货条件项目|此出货条件包含的出货安排项目，如牛肉出口出货条件包含如下几个出货条件项目：动物署检验检疫、海关检疫、报关、船期、货柜、冷冻处理。出货条件项目是用户自定义项目，由用户自己定义和扩展。|

# 操作说明

*  通过菜单[出货条件](/detail/cc870380607045eb84bca48c0a0646fa)进入出货条件界面；
*  操作步骤
 
   *  第1步：录入出货条件编码、名称等相关信息。
   *  第2步：选择出货条件项目。
   *  第3步：保存出货条件。
