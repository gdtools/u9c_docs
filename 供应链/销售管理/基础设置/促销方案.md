
# 功能描述

确定促销的时间范围、地域范围、使用群体范围及具体执行政策。

一个促销方案可选多个促销政策。

# 业务规则

*  促销方案编码不能为空，不允许重复；
*  已定义促销政策

# 栏目说明

促销方案.表头－基本页签

|栏目名称|说明|
|---|---|
|组织|checkbox。可空。空代表所有组织|
|客户分类|checkbox。可空。空代表所有客户分类|
|客户|checkbox。可空。空代表所有客户|

促销方案.表头－使用范围页签

|栏目名称|说明|
|---|---|
|组织|基本页签对应的选项为true时可录入具体组织范围|
|客户分类|基本页签对应的选项为true时可录入具体客户分类范围|
|客户|基本页签对应的选项为true时可录入具体客户范围|

促销方案.表体

|栏目名称|说明|
|---|---|
|促销政策|参照促销政策.单品买赠、促销政策.促销折扣档案|
|促销方式|从促销政策带入，不可改|

# 按钮说明

*  <下发>：导航到下发功能节点。
*  <取消下发>：导航到取消下发功能节点。
*  <下发参数>：导航到下发参数功能节点。
*  <单品买赠>：导航到促销政策.单品买赠画面。
*  <促销折扣>：导航到促销政策.促销折扣画面。
