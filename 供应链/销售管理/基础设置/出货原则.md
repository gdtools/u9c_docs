
# 功能描述

出货原则是出货环节中影响或者约束出货行为的一系列规则或约束的集合。

在销售订单出货时，会依订单上指定的出货原则检查，看出货行为是否符合要求。

# 关键应用

# 业务规则

*  出货原则编码不能为空，不允许重复。

# 栏目说明

出货原则界面栏目

|栏目|说明|
|---|---|
|编码|所定义的出货原则的编码|
|名称|所定义的出货原则的名称|
|描述|所定义的出货原则的文字描述|
|分批出货|表明订单的一个分期出货子行（ShipLine）、出货计划上的数量是否还可以分多次出货。|
|单据可改|当前出货原则被订单引用后，整个出货原则的内容将随（订）单保存。 此标志用于标明该出货原则的内容随订单保存后，可否在订单上修改其属性的值。在U9cloud当前版本下，未用到此栏目的控制逻辑。|
|提前出货|订单或出货计划安排出货时，是否允许提前安排出货（早于计划出货日期）。|
|提前天数|[提前出货]为真（被勾选）时有效，表示最多可提前几天出货。|
|延迟出货|据订单或出货计划安排出货时，是否允许推迟安排出货（晚于计划出货日期）。|
|延迟天数|[延迟天数]为真（被勾选）时有效，表示最多可延迟几天出货。|
|超量出货|据订单或出货计划安排出货时，实际出货的数量是否允许多于计划安排的出货数量。|
|超量比例|[超量出货]为真（被勾选）时有效，表示可超量的最大比例：[实际出货量]<=[计划出货量]*(1+[超量比例])。|
|短缺出货|据订单或出货计划安排出货时，实际出货的数量是否允许少于计划安排的出货的数量。允许分批出货时， 此设置不起作用。不允许分批出货时(一次出完)，要求[实际出货量]>=[计划出货量]*(1-[缺货比例])。|
|缺货比例|[短缺出货]为真（被勾选）时有效，表示可短缺的最大比例。|
|替代件出货|当料品存在替代件时，在出货环节是否允许使用替代件出货。例如：客户订购了100个A12型号的插座，但在出货时A12的插座没有或不够，则可用A13代替A12出货。|
|生效|当前出货原则是否生效|
|生效日期|当前出货原则的生效／起始日期|
|失效日期|当前出货原则的失效／截至日期|
