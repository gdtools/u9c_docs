
# 功能描述

维护退货原因档案。
在进行销售退货时，需指定发生退货的原因。系统可按退货原因对客户发生的退货业务进行统计分析。

# 关键应用

# 业务规则

*  退货原因编码不能为空，不允许重复。

# 栏目说明

退货原因画面栏目

|栏目|说明|
|---|---|
|基本|
|编码|非空，手工维护。|
|名称|可空，当前退货原因名称|
|描述|可空，对该退货原因的简单说明。|
|状态|
|生效|当前退货原因是否生效|
|生效日期|当前退货原因生效/起始日|
|失效日期|当前退货原因失效/截止日|
|||

# 操作说明

*  通过菜单[退货原因](/detail/d66caf26991e40ab8e022ead61a539d1)进入退货原因界面；
*  操作步骤
 
   *  第1步：录入退货原因编码、名称等相关信息。
   *  第2步：保存退货原因。
