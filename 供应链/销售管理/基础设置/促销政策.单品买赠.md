
# 功能描述

定义发出商品汇总表统计更新的统计规则。

可以通过设置“发出商品统计规则”自行配置

各种销售退货类型是否影响发出商品（或销售成本）

各种销售退货单据类型是否影响发出商品（或销售成本）

各种销售退货申请单据类型是否影响发出商品（或销售成本）

各种销售退货处理单据类型是否影响发出商品（或销售成本）

赠品、免费品出货、退货是否影响销售成本

出货但不立帐是否影响销售成本


# 业务规则

*  促销政策.单品买赠编码不能为空，不允许重复；

# 栏目说明

促销政策

|栏目名称|说明|
|---|---|
|促销方式|单品买赠|
|料品分类|参照料品销售分类，与料品互斥|
|料号|参照可销售=true的料品，与料品分类互斥|
|品名|如果输入的是料品分类则该字段置灰；如果录入的是料号，则根据料号带入，不可改。|
|规格|如果输入的是料品分类则该字段置灰；如果录入的是料号，则根据料号带入，不可改。|
|销售单位|料品录入时由料品带入。 如果录入的是料品分类，交易单位参照计量单位档案。|
|买赠类型|可扩展枚举；预制枚举值：比例、数量阶梯|
|购买数量|正数 买赠类型=比例时必输|
|购买数量起|买增类型=数量阶梯时必输，区间控制：左闭右开|
|购买数量止|买增类型=数量阶梯时必输，区间控制：左闭右开|
|赠品|参照料品档案|
|销售单位|赠品带入，不可改。|
|赠品数量|录入|
