
# 功能描述

按照合同的流程、控制内容、交易方式等角度对销售合同进行分类。

# 业务规则

*  合同类型编码不能为空，不允许重复

# 栏目说明

合同类型栏目

|栏目名称|说明|
|---|---|
|基本|
|编码|非空，合同类型编码，手工录入。|
|名称|非空，当前定义的合同类型的名称。|
|合同类别|非空，默认=“内销”。枚举值：内销：当前定义的合同类型是内销合同专用出口：当前定义的合同类型是出口合同专用|
|合同流程|非空，定义合同执行过程中所走的流程。枚举值:合同－出货计划－出货单：分批数量合同，出货计划参照合同拉式生单合同－出货单：分批数量合同，出货单参照合同拉式生单合同－销售订单：非分批合同，销售订单参照合同拉式生单合同－合同下达－销售订单 ：分批数量合同，通过合同下达动作，自动推式生成销售订单，不允许手动参照合同生成订单。无流程:非分批合同。合同不生成下游单据，常用于只签订立账、付款方式等商务条款、但却不指定具体合同标的的年度合同。当[合同类别]=“出口”时，枚举值不包括“合同－出货计划－出货单”与“合同－出货单”两种流程。|
|立账条件|参照立账条件档案录入。所选立账条件作为默认值带入合同。|
|收款条件|参照收款条件档案录入。所选收款条件作为默认值带入合同。|
|描述|可空，对当前合同类型的描述|
|合同内容分区：定义合同必须确定的内容，可复选。|
|客户层次|非空，可选，枚举值客户:表示与客户的总公司订合同。所签订的合同可以有多个收货位置。客户位置:表示与客户的位置层订合同。所签订的合同只能有一个收货位置。|
|合同料品|非空，可选，枚举值料品:合同上指定具体的适用物料。料品分类:合同上不指定具体的适用物料，而是针对一个物料类别来设定，具体执行物料在销售订单上来指定。若[合同流程]栏目的值=“合同－合同下达－销售订单”、“合同－出货计划－出货单”或“合同－出货单”，则本栏目的值只能是“料品”。|
|价格合同|定义合同执行时，是否按照签订的价格严格控制选中:表示合同执行时，必须按照合同头中价表或合同行中料品价格（二者不能共存）控制执行。未选中:表示合同执行时，合同行中录入价格可修改，修改范围依据下文[控制价格]与[价格允差]进行若[合同料品]=“料品分类”，则[价格合同]为空且不可编辑；若[合同流程]栏目的值=“合同－合同下达－销售订单”，则[价格合同]一定被选中。|
|累计量取价|对于流程为“合同-订单”、且指定价目表的价格合同，本参数的含义是：选中:表示据此合同生成订单时，订单上的价格（数量折扣）还要考虑合同上的累计订单量，即要以（订单的当前下单量+对应合同的过去累计订单量）取价（数量折扣）。未选中:表示订单上只以订单的当前下单量取价（数量折扣）。|
|分批交货|定义合同执行时，对料品数量和交期的控制.选中:表示合同执行时，合同行上必须确定数量和交期分割信息。未选中:表示合同执行时，合同行上不能录入交期分割信息,但可以录入数量。若[合同料品]=“料品分类”，[分批交货合同]为空且不可编辑。若[合同流程]栏目的值=“合同－合同下达－销售订单”或“合同－出货计划－出货单”或“合同－出货单”，则[分批交货合同]一定被选中。|
|数量合同|默认为False，对合同上料品数量的控制。选中:合同行上必须录入料品数量未选中:合同行上不能录入料品数量。[数量合同]与[金额合同]不能同时都为True，但可同时为False；若[分批交货]=True，则[数量合同]必=True、[金额合同]必=False|
|金额合同|默认为False，对合同上金额的控制。选中：合同头上必须确定总金额。未选中:合同头和行上可以金额可录可不录，但合同执行时不按金额合同进行控制。|
|预收款类型|默认为“其他”，单选，枚举值 周转金：表示合同生成后续单据时可以“使用”该合同上的预收款合同保证金：表示合同执行时会检查合同上的保证金是否已足额预缴，且合同生成后续单据时不能使用该合同上的预收款其他：表示合同上可录预收款，也可不录，对合同执行没有任何限制和影响。|
|预收比例|若[预收款]为空，则本栏目必空； 反之则本栏目可改可空,所输入的数值必须在[0，1]之间。|
|执行控制：合同执行过程中对后续单据的控制方式。|
|控制执行|若[价格合同]=True或[金额合同]=True，则[是否控制合同执行]=True。选中：则按照下文中的项目控制合同执行时的价格、金额、数量等。未选中：则本分区下文中的项目都为空且无效(界面上为灰)，在合同执行的过程中对价格、金额、数量等内容都可随意修改。|
|控制价格|合同执行时，是否可以对所生成的下游单据的价格进行修改。选中:则合同行上必须确定单价，合同执行时下游单据的价格必须满足条件：[合同价]×（1－[价格允差]）<=下游单据价格<=[合同价]×（1＋[价格允差]）。未选中:则合同执行时下游单据的价格可以随意修改。当[控制执行]=True时有效；当[价格合同]=True时，[控制价格]必为True且不可改。。|
|价格允差|结合[控制价格]对合同执行时下游单据的价格进行控制。所输入的数值必须在[0，1]之间。当[控制执行]=True且[控制价格]=True时有效且不为空，否则为空。|
|控制金额|合同执行时，下游单据金额的控制方式。选中:合同头上必须确定金额。当[合同金额]×（1－[金额允差]）<=合同的累计执行金额 时，合同自动关闭。未选中:当[合同金额] <=合同的累计执行金额 时，合同自动关闭。当[控制执行]=True时有效；当[金额合同]=True时，[控制金额]必为True且不可改。|
|金额允差|结合[控制金额]对合同的累计执行金额进行控制。所输入的数值必须在[0，1]之间。当[控制执行]=True且[控制金额]=True时有效且不为空，否则为空。|
|出货原则|参照出货原则档案录入，可点击链接在线创建出货原则。[数量合同]=True且[控制执行]=True时有效，当前选择的“出货原则”将作为默认值带到合同上。|
|异常处理|合同执行过程中，上文各控制项目校验未通过时的处理方式，枚举值：提示：将错误信息抛出后继续执行。挂起：挂起当前执行的单据（合同执行生成的单据）拒绝：不允许继续执行，必须修正或取消执行单据内容。|
|更新客户档案：合同执行时是否更新客户基础档案的参数选项，可复选。|
|客户价表|当[价格合同]=True时才有效，若[客户价表]=True且合同头上指定了价目表，则该合同在执行时，用合同上所指定的价目表来更新客户档案上的价目表。|
|备损率|默认为False，若为真时且【合同行】•[备损品供货比率]>0，则合同在执行时，会自动更新【物料客户交叉档案】上[备损品供货比率]|
|立账条件|默认为False，若为真时且【合同头】•[立帐条件]非空，则合同在执行时自动更新客户档案的立帐条件。|
|收款条件|默认为False，若为真时且【合同头】•[收款条件]非空，则合同在执行时自动更新客户档案的收款条件。|

# 操作说明

*  通过菜单[合同类型](javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkCBO.SCM.MF4020_10&sId3015nid&mId1001101160311862","%E5%90%88%E5%90%8C%E7%B1%BB%E5%9E%8B");)进入合同类型界面；
*  操作步骤
 
   *  第1步：录入编码、名称等信息。
   *  第2步：选择合同类别、合同流程信息。
   *  第3步：选择客户层次、合同料品等信息。
   *  第4步：点击“保存”，保存合同类型。
