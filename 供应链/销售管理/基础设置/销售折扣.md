
# 功能描述

销售折扣用于对销售业务各商品或客户所使用的系统折扣；

可以针对具体的销售价目表设定折扣；如不指定具体的价目表，此时折扣单对所有销售价目表有效；

在同一时间点上，可以存在多个系统折扣，如商品折扣和VIP客户折扣，系统只取对买方最有利的折扣（即折扣额最高的）。

折扣单可在组织间进行下发。

# 业务规则

*  定义币种（可选）
*  定义价目表（可选）
*  定义客户（可选）
*  定义客户分类（可选）
*  定义物料（可选）

*  定义等级、成分（可选）
*  定义物料自由项（可选）
*  定义计量单位（可选）
*  定义折扣原因（可选）

|生效日期|设定折扣单生效日期。|

|地区|说明当前折扣适用的地区。|
|客户分类|参见【行页签】相同栏目说明。|
|立账条件|参照应收立账条件录入,可空。可根据立账条件设定折扣，如一次立账可享受95折，分3期立账则只能享受98折。订单上根据当前所选择的立账条件来适配对应折扣。|
|收款条件|参照收款条件录入，可空。可根据收款条件设定折扣，如现金或支票可享受95折，商业承兑汇票则只能享受98折。订单上根据当前所选择的收款条件来适配对应折扣。|
|折扣分区|
|折扣方式|枚举值：数量折扣：打折多少与购买料品的数量段有关；初次录入[折扣方式]=“数量折扣”时自动弹出分段折扣设定画面。若[折扣方式]=“数量折扣”，则点击链接可打开分段折扣设定画面。例如：购买50个以下打9折、50-100打8.5折；普通折扣：打折多少与购买料品的数量段无关；例如：xxx物料五一期间一律打8折，购买多少数量都执行此折扣。|
|累进方式|折扣方式为“数量折扣”时有效，枚举值：全额计算：根据折扣的分段规则决定总交易数量落在哪个分段区间，总交易量均采用该分段区间所对应的折扣。分层累进：将总交易数量按照折扣的数量分段规则分成若干段，各段内的数量采用该分段所对应的折扣来计算交易额，然后将各段的交易金额累加起来。例如：手机原价1000元，3-5台每台优惠100元，5台以上每台优惠200元，若客户购买10台，则在分层累进的计算方法下，交易金额为2*1000+3*(1000-100)+5*(1000-200)=8700；在全额计算的方法下，交易金额就是10*(1000-200)=8000|

|折扣金额|参见【行页签】相同栏目说明。|

|折扣限量|说明当前折扣的最大数量限制。|
|折扣原因|默认=单头[折扣原因]，可参照【折扣原因】档修改。|

# 按钮说明

*  <下发>：导航到下发功能节点。
*  <取消下发>：导航到取消下发功能节点。
*  <下发参数>：导航到下发参数功能节点。
*  <审批参数>：设置客户档案的审批参数。
*  <终止>：对折扣单执行终止操作，终止后的折扣单不再生效。终止后的折扣单不能再启用，此操作为不可逆操作，要谨慎使用！
*  <有效期变更>：通过此功能可以对折扣单的有效期进行缩短或延长。

# 操作说明

*  通过菜单[销售折扣](/detail/26b64e40fcdf41b6bfd19fc766314d06)进入销售折扣界面；
*  操作步骤
 
   *  第1步：录入名称、价表等信息。
   *  第2步：录入行、明细子表信息。
   *  第3步：点击“保存”，保存销售折扣。
