
# 功能描述

用于设定销售系统的运行过程中，对销售价格、订货量、税等的控制方法以及控制策略。

销售参数的取值定义后，允许再次修改。修改后不影响已发生的业务，仅对未来单据或业务操作产生影响。

# 关键应用

# 业务规则

*  有参数设置的权限

# 栏目说明

销售参数设定说明

|参数分组|参数名称|参数取值及说明|
|---|---|---|
|公共|默认销售部门|参照部门档案录入，创建销售单据时，单据中默认的销售部门。销售单据上的默认销售部门，优先从客户档取，取不到时才从组织参数上取。|
||默认销售员|参照销售类型的业务员录入，创建销售单据时，单据中默认的销售员。销售单据上的默认销售员，优先从客户档取，取不到时才从组织参数上取。注意：【默认销售部门】不为空时，所选销售员只能是该部门的业务员|
||计划滚动修正|若选中，则该组织下的主计划允许通过“滚动修正”操作来自动调整预测值。注意：“滚动修正”操作只能调整未过期的计划，不能调已过期的计划。关于计划的滚东修正，详见销售计划一节。|
||实时产生AAI分录|被选中，则销售订单、预出货单、出货单、退回处理单会随单产生交易分录；否则不随单产生交易分录，可通过“批量生成交易分录”和“重新生成交易分录”人工触发产生交易分录。|
||销售管销费用分配单据|设定销售管销费用进行分配的单据是销售订单还是销售出货单，单选。详见管销费用单一节。|
||记录价格过程|若选中，销售订单上会记录价格的取得和计算过程；否则订单上只记录最终取得的价格、并不记录这个价格是怎么来的。|
||补货方式|设定销售补货（订单出货不足补货、出货途损/拒收补货、退换货）的默认流程。若选择“新单补货”，则由订单/出货单/退回单创建一张补货订单，根据该订单安排 （生产）出货；若选择“源单补货”，则由订单/出货单/退回单直接创建补货出货单，直接从库存出货这个参数只是一个默认值带到补货画面，在实际进行补货业务时还可以手工调整。|
||销售单据非工作日调整方式|设定销售合同、报价单、销售订单和出货计划中出货日期适用工作日历的方式。空：即不处理，遇非工作日不会自动调整。后延：遇非工作日会自动后延至第一个工作日。提前：遇非工作日会自动提前至第一个工作日.|
||启用供应规则|若选中，则在销售合同、销售报价单、销售订单和销售计划上会检查录入的客户/供应组织/仓库等信息是否符合供应规则的规定；否则不校验。|
||随单费用立账核币|默认值=1，有效值是0 或 1。0：出货单费用立账币种=出货单核币。1：出货单费用立账币种=费用币种。|
||允许多个MRP的主计划|若选中，允许相同期间内存在多个计划目的为MRP的主计划。|
||修改数量不重新取价|若选中，销售订单、出货单修改数量后不自动重新取价。|
||单据行税组合与客户位置档税组合一致性|若选中，销售订单行、出货单行、报价单行的税租合必须与收货位置（即订货客户位置）档案的税组合一致。|
|价格|定价方式|表示销售单据中料品的定价方式，包括：手工录入：在单据中手工录入料品的价格。最新售价：取该料品上一次卖给此客户的订单价格作为当前交易价格。注意：只有当销售单据中未指定价目表，或从价目表里未找到物料的有效价格时，才按此参数决定如何定价。|
||价格控制策略|当交易价格出现异常时的系统处理策略。包括以下几种策略：不处理：业务正常进行，不出提示信息拒绝活动执行：抛出异常，不允许业务继续进行仅警告：只在状态栏出现提示信息，不影响业务进行整单挂起：将单据挂起举例：价格异常包括单据中手工改价时，修改幅度超过参数【价格修改幅度】的限制；或者料品档案中定义了料品的限价方式，但成交价格不在限价范围内。|
||默认价表|参照当前组织下的有效销售价表录入。销售单据上优先从客户档带入默认价表，取不到时才从参数档取默认价表。|
||价格修改幅度|表示订单中允许对系统价进行人工调整的最大幅度。当客户档上的[价表可改]标识勾上时，按此参数控制订单在系统取得的价格基础上，可以人工调整的上下限幅度。如价表里定义的单价是100元，参数规定修改幅度是20%，则在订单上可以在80元-120元之间调整。当客户档上的[价表可改]标识未勾上时，订单上的系统价不允许人工调整。|
||毛利控制|被选中，则表示订单上需要控制毛利：若订单毛利低于参数【销售最低毛利率】，则依参数【毛利控制策略】进行处理。未选中，则订单不进行毛利检查。|
||销售最低毛利率|参数【毛利控制】被选中时有效，表示订单要求达到的最低毛利率。录入百分比，精度为4位小数，|
||毛利估算扣除预估费用|被选中，则表示销售单据在计算毛利时，会扣除销售单据上录入的费用。|
||毛利控制策略|参数【毛利控制】被选中时有效，表示订单毛利低于参数【销售最低毛利率】时的系统处理策略。包括以下几种策略：不处理：业务正常进行，不出提示信息拒绝活动执行：抛出异常，不允许业务继续进行仅仅警告：只在状态栏出现提示信息，不影响业务进行整单挂起：将单据挂起|
||价目表默认编码规则|设置销售价表的编码方案：在销售价目表里按此方案自动编码，不允许手工编码。若未设置，则销售价目表里只支持人工编码、不支持自动编码。|
||折扣单默认编码规则|设置销售折扣单的编码方案：在销售折扣单里按此方案自动编码，不允许手工编码。若未设置，则销售折扣单里只支持人工编码、不支持自动编码。|
||价表显示风格|在“销售价目表”节点里加载价表时，默认的显示风格。在价表画面里，显示风格可以随时修改、即时刷新。显示全部：显示该价表里所有有效的价目行，不管是否已过期显示最后：显示各价目里日期最后的那条有效的价目记录显示当前：按当前系统日期进行过滤，显示当前有效的价目以上选项的具体说明，参见“销售价目表”一节。|
||源单退货价格确定方式|根据来源订单/出货单进行销售退货业务时，退货价格如何确定：来源单据：以来源单据上的价格作为退货价格，即以原售价作为退货价客户价表：从客户的默认价表上现取价作为退货价，即以现售价作为退货价关于退货的说明，参见“退回处理”一节|
|报价单|报价单实行系统版本控制|被选中，则报价单审核后变更时，既支持人工另存为一个新版本、也支持修改关键数据项时自动创建一个新版本。若未选中，则报价单变更时不支持版本记录。|
||退税记入毛利|仅对成本报价单有效，选中时表明外销报价单的毛利计算，要把退税额记入毛利。|
||毛利预估是否包含费用|仅对成本报价单有效，选中时表明不计入成本的销售费用要影响毛利计算。|
||退税是否考虑国内费用|仅对成本报价单有效，选中时表明退税时以含国内费用的FOB价计算退税。|
||毛利预估是否含成本税|仅对成本报价单有效，选中时表示成本税额影响毛利计算。|
||毛利计算方式|仅对成本报价单有效，决定计算毛利率的方式：利润/收入：基于收入计算毛利，毛利率=利润金额/收入金额利润/成本：基于成本计算毛利，毛利率=利润金额/成本金额注意：普通报价单和销售订单上的毛利计算，仅支持按收入计算毛利。|
||报价单价格控制方式|仅对成本报价单有效；成本报价单上最终价的价格控制方式，结合成本报价单行中[限价幅度]对[最终价]进行控制，包括以下三种方式以最低毛利率控制：报价单上的最终价要求符合最低毛利要求，报价行毛利率>=报价行[限价幅度];此时报价单行上的[限价幅度]栏目的含义是最低毛利以送审价的下限百分比来控制：若报价单在审核后修改最终价，需要符合报价单行上的[限价幅度]要求，最终价>=送审价*(1-限价幅度)以绝对最低售价来控制：报价单上的最终价要求>=物料最低售价，此时报价单行上的[限价幅度]栏目的含义是物料最低售价|
||报价单价格控制策略|仅对成本报价单有效,报价单[最终价]不符合[报价单价格控制方式]里的设置时的处理:不处理：业务正常进行，不出提示信息拒绝活动执行：抛出异常，不允许业务继续进行仅警告：只在状态栏出现提示信息，不影响业务进行整单挂起：将单据挂起|
|订单|订单版本控制|被选中，则销售订单审核后变更时，既支持人工另存为一个新版本、也支持修改关键数据项时自动创建一个新版本。若未选中，则订单变更时不支持版本记录。|
||订单业务关闭后可再打开|被选中，则表明短缺关闭的订单，可以人工再次打开（以继续出货）。|
||订货控制自由项|被选中则表明，对于启用自由项的物料，在订单上必须录入自由项；未选中则标明，对于启用自由项的物料，在订单上可不指定自由项(指定亦可)，而在出货环节再指定。注意：对于未启用自由项的物料，这个参数没有作用。|
||允许销售选配|被选中，则可以在销售订单中对模型件进行在线选配。注意：在当前版本下，如果需要支持模型件和PTO件销售，请把此参数勾上。|
|出货|默认供应来源|当前组织的默认供应方式，枚举值：供应商：表明通过向供应商采购来满足销售需求。内部组织：表明通过内部组织出货来满足销售需求。关系企业：目前暂不支持，表明通过关系企业满足销售需求。转生产制造 ：表明通过生产制造来满足销售需求。当前组织（默认）：表明通过本组织交货满足销售需求。订单上的供应来源，默认先从客户-物料交叉档取，取不到则取物料档，再取不到则最后从参数档取。|
||默认供应组织|表示出货时默认的料品供应组织，所取值与参数【默认供应来源】的值一一对应。供应来源为内部组织：参照“物流组织”、“工厂组织”输入，且当前组织与供应组织营业行为类型为：销售-物流或销售-工厂。若当前组织具有工厂或物流职能，也可参照出来。供应来源为关系企业：目前暂不支持。供应来源为转生产制造 ：参照[组织职能]=“工厂组织”的[组织档案]输入，且当前组织与供应组织营业行为类型为：销售-工厂。若当前组织具有工厂职能，也可参照出来。供应来源为当前组织：为当前组织，不可改。|
||默认供应商|参照【供应商档】录入。【默认供应来源】＝“供应商”时，指定默认的供应商。|
||出货默认存储地点|参照[存储地点档] 录入当前组织下的存储地点。订单上的默认存储地点，优先从客户物料交叉档取，取不到则从物料档取，再取不到则从组织参数档取。|
||默认需求转化类型|又叫供应类型，表示以什么供应方式来满足需求，需求转化类型与供应来源配套使用。枚举值包括：转当前组织采购：[默认供应来源]=“供应商”时的默认值，可改；跨组织出货：[默认供应来源]=“内部组织”时的默认值，此时不可改；转制令：[默认供应来源]=“转制令”时的默认值，此时不可改；当前组织出货：[默认供应来源]=“当前组织”时的默认值，此时不可改；转外协：[默认供应来源]=“供应商”时的可选值，可改。订单上的默认供应类型，默认先从客户-物料交叉档取，取不到则取物料档，再取不到则最后从参数档取。|
||出货控制自由项|被选中时表示，订单上确定的自由项，在出货环节不可改；未选中则表示，订单上录入的自由项，在出货环节可调整。注意：对于启用自由项的物料，在出货环节必须录入自由项，此参数只是控制是否必须按订单上规定的自由项出货；对于未启用自由项的物料，这个参数没有作用。|
||SO内抛下游单据是否合并行默认值设置|若选中，SO内抛的采购订单合行。|
||KIT不成套发货时按KIT子件取供应类型等默认值|若选中，销售订单KIT母件不成套发货时，按KIT子件取销售订单计划行的供应类型等字段的默认值。 适用于KIT子件供应类型基本稳定，但同一KIT母件下不同KIT子件供应类型不同的场景。比如，有的子件本组织生产并出货，有的子件从外部采购。|
||销售订单整单金额与收款计划整单金额一致性|销售订单金额发生变更时，根据此参数判断收款计划金额是否要与销售订单金额一致。 若选中，销售订单金额与收款计划整单金额必须一致。 若不选中，销售订单金额与收款计划整单金额可以不一致。|
|订货量控制|允限销控制|被选中，则在订货时需要按允限销规则进行控制。具体控制参见“允销/限销”|
||控制最大订货量|被选中，则在订货时，订货量要<=最大订货量。其中最大订货量的取数，优先找客户料品交叉档、找不到再找料品档。|
||控制最小订货量|被选中，则在订货时，订货量要>=最小订货量。其中最小订货量的取数，优先找客户料品交叉档、找不到再找料品档。|
||控制订货批量|被选中，则在订货时，订货量要等于订货批量的倍数。其中订货批量的取数，优先找客户料品交叉档、找不到再找料品档。|
||订货量控制策略|参数【控制最大订货量】或【控制最小订货量】或【控制订货批量】被选中时有效，表示订货量不满足参数要求时的处理策略。包括以下几种策略：不处理：业务正常进行，不出提示信息拒绝活动执行：抛出异常，不允许业务继续进行仅警告：只在状态栏出现提示信息，不影响业务进行整单挂起：将单据挂起|
|赠品|赠品处理方式|订单中的赠品，在出货时的成本处理方式，枚举值：进销售费用：赠品成本进销售费用进销售成本：赠品成本进销售成本|
||备损件处理方式|订单中的备损件，在出货时的成本处理方式，枚举值：进销售费用：备损件成本进销售费用进销售成本：备损件成本进销售成本|
||赠品允许立账|若选中，销售订单、出货单、预出货单赠品可立账。具体说明参见销售中的赠品与备损件一节。|
||备损件允许立账|若选中，销售订单、出货单、预出货单备损件可立账。具体说明参见销售中的赠品与备损件一节。|
|汇率|默认汇率类型|销售单据里默认的汇率类型，参照【汇率类型档】录入。|
|税|税优先原则|当前组织下的销售单据中，默认税组合按什么规则确定。参照[税优先原则档] 录入。|
||默认税组合|当前组织下的默认税组合。参照[税组合档]录入。销售单据中的默认税组合，是按税优先原则来确定的。当税优先原则里规定优先 从“组织”取时，就是从这里取。|
|预收|启用预收政策|参数选中，表示当前组织中的销售单据，按单据中的预收政策来检查和控制预收款|
||预收政策默认编码规则|设置预收政策的编码方案，只对特例预收政策有效。|
|促销|启用促销方案|参数选中，表示当前组织中的销售订单可指定促销方案。|
||记录单据促销历史|参数选中，表示销售订单每次做“计算促销结果”操作时，都会记录促销结果。|
||促销基准价|指定单品折扣时，按“定价”还是“系统价”计算销售订单的最终价。当选择“定价”时，销售订单行的最终价=定价*折扣率；当选择“系统价”时，销售订单行的最终价=系统价*折扣率；|
