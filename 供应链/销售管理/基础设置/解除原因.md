
# 功能描述

本节点提供销售单据中解除挂起原因的设置，主要功能如下：

1. 设置解除挂起原因
2. 设置解除挂起原因的有效性和有效时间区间
3. 设置允许使用该挂起原因的用户
4. 为特定用户使用该挂起原因设定有效性和有效时间区间
5. 设定解除挂起原因与挂起原因之间的关联

# 业务规则

*  解除原因编码不能为空，不允许重复

# 栏目说明

解除设置画面表头

|栏目名称|说明|
|---|---|
|编码|手工输入当前解除原因的编码|
|名称|当前解除原因的描述|
|简称|当前解除原因的简称|
|生效|当前解除原因是否生效的状态|
|生效日期|当前解除原因的生效日期|
|失效日期|当前收款单解除原因的失效日期|

解除设置画面表体－权限设定

|栏目名称|说明|
|---|---|
|用户|选择对当前解除原因有使用权的用户，只有在此列表中的用户才有权使用当前解除原因|
|生效|当前列表行的用户是否有权使用当前解除原因的状态|
|生效日期|当前列表行的用户允许使用当前解除原因的开始日期|
|失效日期|当前列表行的用户允许使用当前解除原因的结束日期|

解除设置画面表体－原因匹配

|栏目名称|说明|
|---|---|
|挂起原因|选择当前解除原因所对应的收款单挂起原因|
|生效|当前解除原因针对当前收款单挂起原因的有效状态|
|生效日期|当前解除原因针对当前收款单挂起原因的生效日期|
|失效日期|当前解除原因针对当前收款单挂起原因的失效日期|

# 操作说明

*  通过菜单[解除原因](javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkCBO.Base.HoldRelease.ReleaseReason&AppID3015&sId3015nid&mId1001101160311864","%E8%A7%A3%E9%99%A4%E5%8E%9F%E5%9B%A0");)进入解除原因界面；
*  操作步骤
 
   *  第1步：录入编码、名称等信息。
   *  第2步：选择操作员、挂起原因。
   *  第3步：点击“保存”，保存解除原因。
