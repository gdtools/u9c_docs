
# 功能描述

设置在库存调剂时，存储地点周边客户之间调剂库存的承运商、运输方式、运费、费用项目，及调剂双方的运费承担比例。

# 业务规则

*  库存调剂组编码不能为空，不允许重复；
*  设置料品；
*  设置供应商；
*  设置运输方式；
*  设置存储地点；
*  设置币种；
*  设置费用项目

# 栏目说明

库存调剂组画面表头

|栏目名称|说明|
|---|---|
|编号|非空，不可重复，保存后不可修改|
|名称|可空，调剂组名称|
|运输方式|可空，参照运输方式档|
|承运商|可空，参照供应商档|
|运费币种|非空，参照币种档|
|费用项目|参照销售费用项目；可选费用项目需满足以下条件：[适用币种]=[运费币种]，且[费用性质]=客户负担|
|关联仓库|可空,参照存储地点档|
|运输天数|用于计算客户调剂单中的到达日期默认值可空，输入具体天数|

库存调剂组表体—运费页签

|栏目名称|说明|
|---|---|
|料品|参照【料品档】，非空|
|运费单价|输入|
|运费计价单位|参照计量单位档，可取值范围：当前[物料]的[库存单位]和所在计量单位组中的所有值；[运费单价]非空时，不得为空|
|运费计价依据|非空，枚举：库存单位，库存主单位；|

库存调剂组表体-分担比例页签

|栏目名称|说明|
|---|---|
|调剂类型|参照调剂类型UDC档，非空|
|调入方承担比例|输入|
|调入方承担比例|输入|
