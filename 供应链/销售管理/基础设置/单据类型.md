
# 功能描述

用户可维护当前系统下销售系统中各业务单据（销售订单、出货单）的单据类型档案，单据类型决定了单据的流程、编码等。

用户可根据单据类型设定销售单据的业务流程，如出货单是否有签收、对帐；

一种销售单据可定义多个单据类型，不同的单据类型对应不同业务流程。

用户可指定当前单据类型所对应的单据的编码规则

用户可指定当前单据类型所对应的单据是否可由上游单据推出

为方便使用，系统预制了相关销售单据的单据类型。


# 业务规则

*  编码不能为空，不允许重复
*  启用销售系统

# 栏目说明

执行【销售管理】－>【基础设置】－>【单据类型】，打开单据类型定义画面。

在画面选择当前单据类型对应的销售单据，选择不同的单据，页面中的内容随之变化。

单据类型有：调价单、销售合同、报价单、销售订单、出货计划、出货单及预出货单、委托代销清单、退货申请、退货处理、管销费用单、客户调剂单、预测订单、销售订单变更单。不同销售单据类型画面中“单据参数页签”中栏目是一致的，我们可在其中设置单据的编号方式，打印方式等。具体设置参见【单据参数定义】。
