
# 功能描述

用于定义委托代销业务中各商品或客户的倒扣率。

委托代销清单上，将根据零售价、适用的委托代销倒扣政策自动计算得出结算价（系统价）。

# 关键应用

# 业务规则

*  倒扣单号不能为空，不允许重复

# 栏目说明

倒扣单头

|栏目|说明|
|---|---|
|倒扣单号|非空，倒扣单编码。|
|名称|可空，倒扣单名称|
|备注|对倒扣政策的说明。|
|倒扣属性|非空，枚举值零售价：按零售价确定委托代销结算倒扣率。零售扣率：以零售价对价表价格的折扣来确定委托代销结算倒扣率。|
|币种|非空,参照【币种】档录入，表示倒扣单适用的币种。|
|生效日期|设定倒扣单生效/起始日期|
|失效日期|设定倒扣单失效/截至日期|
|状态|系统维护,表示倒扣单的当前状态.点击链接可打开状态明细画面.|
|终止|系统维护,倒扣单执行终止操作后(参见下文)，此栏目为选中状态|

倒扣单体-行页签

|栏目|说明|
|---|---|
|行号|系统维护,自动编号。|
|客户类|可空,参照【客户分类档】录入，表示该客户类别下的所有客户都使用相同的倒扣方式。点击链接可进入客户分类设置画面查看客户分类明细情况或创建新客户分类。此字段与【明细页签】的[客户类]字段联动，保持一致。在一行中，[客户]和[客户类]两个栏目最多只能有一个非空。.|
|客户|可空,参照【客户档】录入当前倒扣针对的客户名称；点击链接可进入客户设置画面查看客户明细情况或创建新客户。此字段与【明细页签】的[客户]字段联动，保持一致。在一行中，[客户]和[客户类]两个栏目最多只能有一个非空。|
|料品|参照【料品档】录入当前倒扣针对的料品。点击链接可进入料品画面查看料品明细情况或创建新料品。在一行中，[物料]和[物料类]两个栏目最多只能有一个非空。此字段与【明细页签】的[料品]字段联动，保持一致。|
|料品类|参照【料品分类档】录入，表示该物料类别下的所有物料都使用相同的倒扣方式。点击链接可进入料品分类画面查看料品分类明细情况或创建新料品分类。在一行中，[物料]和[物料类]两个栏目最多只能有一个非空。此字段与【明细页签】的[料品分类]字段联动，保持一致。当[倒扣属性]=‘零售价’时，必空；当[倒扣属性]=‘零售倒扣’时，可空，只能取【物料分类】•[分类体系->分类性质]=“价格”的物料类进行设定。|
|存储地点|可空，表示 ，点击链接可进入存储地点画面查看存储地点明细情况或创建新存储地点。只能录入属性为寄外仓的存储地点，并与【明细页签】的同名字段联动，保持一致。|
|价格属性|委托代销结算时取倒扣的纬度之一；此字段与【明细页签】的同名字段联动，保持一致。委托代销清单上录入零售价时，会根据指定的价格属性匹配对应的倒扣政策。枚举值：正价特价|

# 按钮说明

*  <终止>：对倒扣单执行终止操作，终止后的倒扣单不再生效。
*  <有效期变更>：通过此功能可以对倒扣单的有效期进行缩短或延长。
*  <分段折扣>：可以分不同的数量段设定不同的折扣。关于分段折扣设定画面栏目参见下表的栏目说明。

# 操作说明

*  通过菜单[委托代销倒扣政策](javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkCBO.MF.MF5050_10&sId3015nid&mId1001101160311860","%E5%A7%94%E6%89%98%E4%BB%A3%E9%94%80%E5%80%92%E6%89%A3%E6%94%BF%E7%AD%96");)进入委外代销倒扣政策界面；
*  操作步骤
 
   *  第1步：录入倒扣单号、名称等信息。
   *  第2步：选择倒扣属性、币种信息。
   *  第3步：录入子表信息。
   *  第4步：点击“保存”，保存委外代销倒扣政策。
