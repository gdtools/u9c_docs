
# 功能描述

提供对单品折扣及促销价促销政策档案的维护画面。

# 业务规则

*  促销政策.促销折扣编码不能为空，不允许重复；

# 栏目说明

促销折扣.表头

|栏目名称|说明|
|---|---|
|促销方式|枚举值：单品折扣、促销价|
|币种|默认法人组织主账簿币种。在销售价表基础上再折扣时，作为匹配价表的维度|
|价格含税|默认=false。在销售价表基础上再折扣时，作为匹配价表的维度|

促销折扣.表体

|栏目名称|说明|
|---|---|
|料号|参照可销售=true的料品档案，与料品分类互斥。|
|品名|料号带入，不可改|
|规格|料号带入，不可改|
|料品分类|参照料品销售分类。与料品互斥|
|客户分类|参照客户分类档案。与客户互斥|
|客户|参照客户档案。与客户分类互斥|
|计价单位|料品档案带入；可改。 如果录入的是料品分类，则参照计量单位档案|
|折扣方式|单头促销方式=单品折扣时可维护。 默认=普通折扣；枚举值：普通折扣/阶梯折扣|
|累进方式|折扣方式=阶梯折扣时可维护。 默认=全额计算；枚举：分层累进/全额计算|
|促销价|单头促销方式=促销价时必输。 其他促销方式时不可编辑|
|折扣率|促销方式=单品折扣且累计方式=普通折扣时必输|

促销折扣.阶梯折扣

|栏目名称|说明|
|---|---|
|数量段起|第一行的[数量段起]大于0，以后各行系统自动将上一行的[数量段止]作为本行的[数量段起]的值。 最后一行的[数量段止]为空（表示无穷大）。 除最后一行，各行的[[数量段止]]>=[数量段起]。 区间控制：左闭右开|
|数量段止|第一行的[数量段起]大于0，以后各行系统自动将上一行的[数量段止]作为本行的[数量段起]的值。 最后一行的[数量段止]为空（表示无穷大）。 除最后一行，各行的[[数量段止]]>=[数量段起]。 区间控制：左闭右开|
|折扣率|1>=[折扣率]>=0|

# 按钮说明

*  <下发>：导航到下发功能节点。
*  <取消下发>：导航到取消下发功能节点。
*  <下发参数>：导航到下发参数功能节点。
*  <促销方案>：导航到促销方案画面。

# 操作说明

*  通过菜单[促销政策.促销折扣](javascript:menuManager.closeBox();TabPanelManager.addUrlTab("../../erp/display.aspx?lnkSCM.SD.PurPresentUI&sId3015nid&mId1001508290521743","%E4%BF%83%E9%94%80%E6%94%BF%E7%AD%96.%E5%8D%95%E5%93%81%E4%B9%B0%E8%B5%A0");)进入促销政策.促销折扣界面；
*  操作步骤
 
   *  第1步：录入编码、名称等信息。
   *  第2步：录入行信息。
   *  第3步：点击“保存”，保存促销政策.促销折扣。
