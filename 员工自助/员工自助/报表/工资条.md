
# 功能描述

该节点用于员工个人工资条查询。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 栏目说明

|栏目|说明|
|---|---|
|查询条件||
|计薪方案|选择要查询的计薪方案|
|日期范围|选择要查询的日期范围|
|日期|选择要查询的日期|
|工作人事组织|默认仅可查询当前登录员工的工作人事组织|
|任职业务组织|默认仅可查询当前登录员工的任职业务组织|
|员工类别|默认仅可查询当前登录员工的员工类别|
|部门|默认仅可查询当前登录员工的部门|
|发薪申请单状态|选择要查询的发薪申请单状态|
|员工|默认仅可查询当前登录员工|
|职务|默认仅可查询当前登录员工的职务|
|职级|默认仅可查询当前登录员工的职级|
|内部工龄|默认仅可查询当前登录员工的内部工龄|
|国籍|默认仅可查询当前登录员工的国籍|
|年龄|默认仅可查询当前登录员工的国籍|
|纸张类型|选择纸张类型|
|方向|选择纸张方向|
|查询结果||
|工作人事组织|显示当前员工的工作人事组织|
|任职业务组织|显示当前员工的任职业务组织|
|部门名称|显示当前员工的部门名称|
|员工类别名称|显示当前员工的员工类别名称|
|员工编号|显示当前员工的员工编号|
|姓名|显示当前员工的姓名|
|现任职务|显示当前员工的现任职务|
|职级职等|显示当前员工的职级职等|
|现任岗位|显示当前员工的现任岗位|
|计薪方案|显示查询条件中选择的计薪方案|
|货币符号|显示货币符号|
|计税年|显示计税年|
|计税月|显示计税月|

# 操作说明

*  通过点击菜单[工资条](/detail/900b4b009ea44b6793204347856aa471)，弹出查询条件窗口，选择查询条件，可按条件显示个人工资条信息。
