
# 功能描述

该节点用于员工查看自己的签到数据。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象
*  存在员工签到数据

# 栏目说明

|栏目|说明|
|---|---|
|考勤卡号|员工考勤卡号|
|打卡时间|打卡时间，注意：每次打卡均会生成一个打卡时间记录|
|数据来源|显示数据来源，包含：考勤机、手工、异常说明、出差单|
|考勤机|显示系统中维护的考勤机名称|
|考勤机类型|显示系统中维护的考勤机类型|
|员工|显示当前登录账号对应的员工姓名|

# 按钮说明

*  <查询>：点击该按钮，可进入查询画面，员工可选择查询条件，查询自己的考勤数据。

# 操作说明

*  通过点击菜单[签到数据查询](/detail/04f1738bb248428787cf4df40008dcc5)，进入列表画面，可直接查看个人的所有签到数据；
*  点击<查询>可以对个人签到数据进行查询。
