
# 功能描述

该节点用于员工管理自己的请假单。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 栏目说明

|栏目|说明|
|---|---|
|单据类型|请假单的单据类型|
|单号|请假单的单据编号|
|日期|请假申请日期，不可更改|
|工作组织|员工的工作人事组织，不可更改|
|员工|组织部门下的员工，不可更改|
|部门|员工的部门，不可更改|
|假期类别|前请假单假期类别有病假、事假、年假、婚假、产假、倒休、丧假等。用户可以点击假期类别变更|
|请假开始时间|请假开始时间|
|请假结束时间|请假结束时间|
|时间单位|由相应休假规则带入，默认为天|
|请假时间合计|本次请休假包含的工时|
|请假原因|请假的原因|
|请假说明|请假的详细说明|
|申请人|申请人|

# 操作说明

*  通过点击菜单[请假单](/detail/2a69449806a449959efe24c9374663a2)，进入请假单新增画面，员工可新增请假单；
*  其他一般性操作见U9C表单类统一操作。
