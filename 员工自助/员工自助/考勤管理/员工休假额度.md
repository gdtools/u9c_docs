
# 功能描述

该节点用于查看员工个人的休假额度。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|工作组织|员工的工作组织，仅可查看|
|员工|当前登录员工，仅可查看|
|起始年度|休假额度起始年度，仅可查看|
|起始月份|开始月份，仅可查看|
|可休额度|系统维护 ，由“员工休假额度明细计算”得到，可休假的天数，仅可查看|
|表行-员工休假额度明细||
|假期类别|为空表示组织内的默认请假规则，否则为这个请假类别的请假规则，未定义休假规则的请假类别表示不限制，仅可查看|
|年度|休假年度，仅可查看|
|期间|如果该休假类型的周期类型为年度或终身时，则为空。如果该休假类型的周期为季，则为1－4的数值，该休假类型的周期为月，则为1－12的数值，仅可查看|
|可休额度|可休假的天数，仅可查看|
|本期休假额度|本期可休假的天数，仅可查看|
|前期结转额度|前期结转的可休假天数，仅可查看|
|已休天数|该可休假的开始时间，仅可查看|
|是否结转|本期的休假额度是否结转至下一期。默认为false,休假额度结转时系统自动置为true，仅可查看|
|结转日期|休假额度结转时系统自动维护，仅可查看|
|表行-本期休假额度变更记录|对应员工休假额度明细行，仅可查看|
|变更日期|休假额度变更日期，仅可查看|
|原额度|原额度，仅可查看|
|变更后额度|变更后额度，仅可查看|
|变更原因|变更原因，仅可查看|
|变更来源|休假额度变更来源，仅可查看|
|变更单号|加班存休时为对应的加班单，额度调整是为对应的休假额度调整单，仅可查看|
|表行-休假额度增减明细||
|来源单据类型|仅可查看|
|来源单据号|仅可查看|
|来源单据行号|仅可查看|
|额度值|仅可查看|
|业务日期|仅可查看|

# 操作说明

*  通过点击菜单[员工休假额度](/detail/bfd702bf4f144ac88e7e837530f49aec)，进入员工休假额度查看画面，仅可查看，无其他操作。
