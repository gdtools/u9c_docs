
# 功能描述

该节点用于员工管理自己的调班单。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|调班单的单据类型|
|单号|调班单的单据编号|
|日期|调班单的申请日期|
|工作组织|当前登录员工的工作人事组织|
|业务组织|当前登录员工的业务组织|
|部门|当前登录员工的部门|
|调班原因|调班的原因|
|申请人|当前登录员工|
|单据状态|当前调班单的单据状态有：开立、核准中、已核准、作废等|
|表行||
|员工|当前登录员工|
|开始日期|调班人员1调班开始日期|
|截止日期|调班人员1调班截止日期|
|员工|需要进行调班的员工2|
|开始日期|调班人员2调班开始日期|
|截止日期|调班人员2调班截止日期|

# 操作说明

*  通过点击菜单[调班单](/detail/84d9046e5ec44ddba57f59b9e00fffad)，进入调班单新增画面，员工可新增调班单；
*  其他一般性操作见U9C表单类统一操作。
