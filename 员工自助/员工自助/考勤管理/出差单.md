
# 功能描述

该节点用于员工管理自己的出差单。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|出差单单据类型|
|单号|出差单单据编号|
|日期|申请出差单日期|
|出差类别|为空表示组织内的默认出有效期补休规则|
|开始时间|开始出差的时间|
|结束时间|结束出差的时间|
|出差天数|可空。系统计算或用户维护，本次出差包含的工时，时间单位为天|
|出差事由|出差原因|
|出差说明|出差事由的详细说明|
|是否存休|此次出差是否进行存休|
|业务组织|当前员工业务组织|
|部门|当前员工的部门|
|申请人|当前员工|
|申请日期|单据申请日期，默认当前日期|
|单据状态|当前出差单的状态都有：开立、核准中、已核准、作废等|
|表行||
|序号|系统自动编号|
|工作组织|员工的工作人事组织，不可更改|
|业务组织|员工的业务组织，不可更改|
|部门|员工的部门，不可更改|
|员工|需要出差的员工，不可更改|

# 操作说明

*  通过点击菜单[出差单](/detail/f40f60c9053041098728baaaff8a1af7)，进入出差单新增画面，员工可新增出差单；
*  其他一般性操作见U9C表单类统一操作。
