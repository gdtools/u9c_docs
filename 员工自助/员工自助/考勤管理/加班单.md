
# 功能描述

该节点用于员工管理自己的加班单。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|分为加班申请和加班确认两种类型，当单据中‘是否考勤’为true时，是加班申请的类型；当‘是否签到’为false时，是加班确认的类型。|
|单号|当前单据编号|
|日期|申请加班日期|
|工作组织|当期加班员工的工作人事组织|
|业务组织|当期加班员工的业务组织|
|部门|当期加班员工的部门|
|加班类别|加班的类别，用户可以点击加班类别更改类别|
|是否存休|是否不计入加班时间，用补休抵扣|
|加班原因|员工加班的原因|
|加班说明|员工加班的说明|
|申请人|当前登录员工|
|单据状态|当前加班单的单据状态都有：开立、核准中、已核准、拒绝、作废等。|
|表行-加班时间安排||
|行号|可空，自动生成|
|开始日期|加班的开始日期|
|截止日期|加班的截止日期|
|加班安排方式|当前加班单安排方式有：延时下班、提前上班、按班次时间、指定时间等。|
|基准班次|选择加班单的基准班次|
|开始时间|加班的开始时间|
|结束时间|加班的截止时间|
|加班工时|加班的合计工时，保存时系统自动合计|
|表行-加班人员安排|该页签不可用，加班人员默认为当前登录员工|

# 操作说明

*  通过点击菜单[加班单](/detail/d69e93ff63514bcf96c2eedef47ef648)，进入加班单新增画面，员工可新增加班单；
*  其他一般性操作见U9C表单类统一操作。
