
# 功能描述

该节点用于维护员工个人借款数据。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 栏目说明

|栏目|说明|
|---|---|
|表头-借款信息||
|单据类型|单据类型|
|借款日期|默认当前日期|
|记账期间|默认当前日期对应期间|
|预计还款日期|默认当前日期|
|借款组织|默认当前登录组织|
|借款部门|当前登录员工部门|
|费用项目|参照选择费用项目|
|用途|说明借款用途|
|借款人组织|默认当前登录组织|
|借款人|默认登录用户对应的员工|
|银行卡类型|参照选择银行卡类型|
|员工银行卡号|参照选择员工银行卡号|
|借款币种|默认人民币|
|汇率类型|根据币种带出汇率类型|
|汇率|根据系统汇率设置带出|
|借款金额|填写借款金额|
|借款本币金额|显示本币金额|
|确认金额|确认金额|
|确认本币金额|确认本币金额|
|借款余额|借款余额|
|借款本币余额|借款本币余额|
|状态|显示单据当前状态|
|项目|参照选择项目|
|任务|参照选择任务|
|表头-联系信息||
|固定电话|从联系对象带出|
|移动电话|从联系对象带出|
|电子邮件地址|从联系对象带出|
|即时通讯|从联系对象带出|
|表头-对单位支付||
|付款给开票单位|选择是否付款给开票单位|
|收款银行账号|填写收款银行账号|
|收款银行账户名称|填写收款银行账户名称|
|收款银行|选择收款银行|
|来源单号|填写来源单号|
|对私账号|选择是否未对私账号|

# 按钮说明

*  <追溯查询-信用余额查询>：点击该按钮，可查看信用余额情况；
*  <追溯查询-信用使用明细查询>：点击该按钮，可查看信用使用明细数据；
*  <相关功能-借款单类型>：点击该按钮，可进入借款单类型维护画面；
*  <相关功能-还款单>：点击该按钮，可进入还款单画面；
*  <相关功能-报销单>：点击该按钮，可进入报销单画面。

# 操作说明

*  通过点击菜单[借款](/detail/738968818176484abfb6e9ee9f0eb420)，进入新增借款画面，员工填写相关信息，可提交借款；
*  其他见U9C表单类一般操作功能。
