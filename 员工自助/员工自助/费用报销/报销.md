
# 功能描述

该节点用于员工报销单维护。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 按钮说明

*  <相关功能-报销单类型>：点击该按钮，进入报销单类型画面；
*  <相关功能-还款>：点击该按钮，进入员工还款画面；
*  <发票导入-引用票夹>：点击该按钮，进入发票夹画面；
*  <发票导入-点票导入>：点击该按钮，可进入电票导入画面；
*  <发票导入-纸质扫码>：点击该按钮，可进入纸质扫码画面。

# 操作说明

*  通过点击菜单[报销](/detail/3467d4d3e8924bb0a027c72fcb2b1705)，进入费用报销新增画面，员工可维护报销单数据；
*  其他见U9C表单类一般操作功能。
