
# 功能描述

该节点用于员工个人信息变更。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 栏目说明

|栏目|说明|
|---|---|
|表头||
|单据类型|参照选择单据类型|
|单号|显示单据编号|
|日期|当前操作日期|
|变更日期|变更日期|
|变更原因|变更原因|
|申请业务组织|当前员工的登录组织|
|申请部门|当前员工所在部门|
|申请人|当前登录的员工|
|申请日期|申请日期|
|状态|同U9C单据统一状态|
|备注|备注信息|
|表体||
|序号|默认编号，自动编号|
|数据表|选择需要变更的数据表|
|字段|选择需要变更的数据表字段|
|变更前值|带出变更前的值|
|变更后值|根据字段类型修改变更后值|
|变更日期|选择变更日期|
|变更原因|录入变更原因|
|操作类型|默认更新|
|备注|备注信息|
|扩展字段|扩展字段|

# 操作说明

*  通过点击菜单[自助信息变更集](/detail/0e205c9efe4a411b87457623a9303201)，进入列表画面，点击新增，员工可维护变更信息；
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<提交>提交表单，审核通过后，变更生效。
