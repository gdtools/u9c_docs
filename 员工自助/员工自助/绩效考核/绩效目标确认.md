
# 功能描述

员工确认本人的绩效目标，经理确认下级员工的绩效目标，绩效目标维护；打开此节点，默认显示考核对象为本人的未进行确认的考评表。

# 业务规则

*  当前登录账号在系统已存在员工信息；
*  登录账号和员工为同一个联系对象；
*  存在已启动的绩效期间，当前登录者本人或下级含有未确认考评表。

# 栏目说明

|栏目|说明|
|---|---|
|绩效期间|显示当前绩效期间|
|考评单元|显示考评单元|
|考评对象类型|显示考评对象类型|
|部门|当前登录员工的部门|
|员工|当前登录员工|
|绩效目标|显示当前登录员工的绩效目标|
|考评负责人|当前登录员工的考评负责人|
|员工确认日期|员工确认日期|
|绩效目标确认人|绩效目标确认人|
|上级确认日期|上级确认日期|

# 按钮说明

*  <本人>：显示当前操作员本人的未确认考评表，显示本人考评的情况下不能对考评表的任何内容进行修改；
*  <下级>：显示直接上级等于当前登录员工的未确认考评表，一旦考评表修改后，员工确认日期和经理确认日期置为空；
*  <确认>：当前操作员确认本人或下级未确认的绩效目标，确认后员工确认日期或经历确认日期为当前登录日期；如果员工确认绩效目标为true且当前登录日期小于等于绩效期间的最晚确认日期，则员工确认日期为空时，不能进行上级确认；如果当前登录日期大于绩效期间的最晚确认日期，确认动作只能由上级进行；
*  <申诉>：考评对象对本人的绩效目标或打分结果不满意时，可以提起申诉。

*  其他一般性操作见U9C统一操作。
