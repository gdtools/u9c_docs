
# 功能描述

查找考评表，进行自评或打分，记录考核周期内的关键事件，跟踪前期的绩效改进计划执行情况，参考其他考评人的打分情况。

# 业务规则

*  当前登录账号在系统已存在员工信息；
*  登录账号和员工为同一个联系对象；
*  存在已启动的绩效期间，含有经理及本人确认的考评表。

# 操作说明

*  <打分>：对当前选中考评表进行打分；打开考评打分界面，进行打分或自评；对需要进行绩效目标确认的考评单元，如果考评表的经理确认日期为空，则不能进行打分；对需要逐级考评的考评单元，如果当前登录用户的对考评表的考评角色为“上上级”，则必需其它角色全部打分完成后才能打分，如果当前登录用户的对考评表的考评角色为“上级”，则必需除“上级”和“上上级”之外的其它角色打分完成后才能打分，如果当前登录用户的对考评表的考评角色为“同级”、“下级”或“其它”考评角色时，则必需“本人”打分完成后才能进行打分；

*  <结果确认>：确认考评结果，只对已打分完毕并且完成计算的考评表；如果考评单元的员工确认考评结果为TRUE，则只能由考核对象本人进行确认；结果确认后考评表的绩效结果确认日期为当前登录日期；
*  <计算>：计算当前选中考评表的考评结果；
*  <申诉>：进行考核申诉，申诉页面栏目说明，同“绩效目标确认”节点申诉页面栏目说明。
