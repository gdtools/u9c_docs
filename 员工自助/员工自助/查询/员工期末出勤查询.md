
# 功能描述

本节点主要功能是查询员工个人在任意考勤期间的出勤结果。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象

# 按钮说明

*  <操作-日出勤结果>：点击该按钮，可查看员工个人的日出勤结果；
*  <操作-实际刷卡情况>：点击该按钮，可查看员工个人的实际刷卡情况；
*  <操作-请假情况：点击该按钮，可查看员工个人的请假情况；
*  <操作-出差情况>：点击该按钮，可查看员工个人的出差情况；
*  <操作-休假额度>：点击该按钮，可查看员工个人的休假额度。

# 操作说明

*  通过点击菜单[员工期末出勤查询](/detail/3880c1055dc64f88a19b78a5a9f9ff89)，进入列表画面，员工查看自己的期末出勤数据；
*  <查询>：可根据考勤日历、考勤期间等条件，查询出需要的出勤结果。
