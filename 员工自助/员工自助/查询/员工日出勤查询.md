
# 功能描述

本节点主要功能是查询员工个人日出勤的详细数据，可对个人每天的应出勤以及实际出勤记录的查看、修改、计算等功能。

# 业务规则

*  当前登录账号在系统已存在员工信息
*  登录账号和员工为同一个联系对象
