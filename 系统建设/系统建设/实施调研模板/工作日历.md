
# 功能描述

用户完成工作日历的实施工作。设置工作日默认规则模板。即设置在一段时间范围内，哪些天是工作日，哪些天不是工作日；

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入工作日历编码。注意　:工作日历编码不允许重复。|
|名称|录入工作日历名称。|
|开始日期|如果录入基础日历，可以直接录入当前使用的工作日历的开始日期。|
|结束日期|如果录入基础日历，可以直接录入当前使用的工作日历的结束日期。|
|周六休息|是否周六休息|
|周日休息|是否周日休息|
|上班时间|显示班次下设置的每个时段的上班时间。|
|下班时间|显示班次下设置的每个时段的下班时间。|
|默认|是否默认工作日历|


# 操作说明

*  通过菜单系统建设－>系统建设－>实施调研模板－>工作日历执行进入该界面；
*  操作步骤
 
   *  第1步：输入编码名称等信息。
   *  第2步：输入上班时间、下班时间等信息。
   *  第3步：点击保存按钮。
