
# 功能描述

用户完成组织的实施工作。设置组织的相关信息。

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|录入组织的编码。|
|名称|录入组织的名称。|
|组织职能|选择组织的职能。|
|实施工作日历|选择实施工作日历|
|实施办公地址|选择实施办公地址|


# 操作说明

*  通过菜单系统建设－>系统建设－>实施调研模板－>组织构建执行进入该界面；
*  操作步骤
 
   *  第1步：输入编码、名称等信息。
   *  第2步：选择组织职能、实施工作日历、实施办公地址等信息。
   *  第3步：点击保存按钮。
