
# 功能描述

根据用户选择的调研模板，进行初始化。支持多选。

# 业务规则

*  定义系统建设的基础档案

# 栏目说明

[初始化](http://wangwq/U9C/help/zh-CN/Content/SC/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|调研模板分类|模板分类属性|
|编码|模板编码|
|名称|模本名称|
|是否成功初始化|系统回写|
|初始化时间|初始化时间|
|操作人|操作人|


# 按钮说明

*  [初始化](http://wangwq/U9C/help/zh-CN/Content/SC/Function/javascript:void(0);)：点击后操作初始化。
*  [错误日志](http://wangwq/U9C/help/zh-CN/Content/SC/Function/javascript:void(0);)：点击后查看错误日志。

# 操作说明

*  通过菜单系统建设－>系统建设－>实施调研模板－>初始化执行进入该界面；
*  操作步骤
 
   *  第1步：选择实施调研模板。
   *  第2步：点击初始化按钮。
