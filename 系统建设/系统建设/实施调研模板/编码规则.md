
# 功能描述

用户完成系统编码规则的实施工作。设置默认简单的规则。

# 业务规则

*  需要有相应的管理权限。

# 操作说明

*  通过菜单系统建设－>系统建设－>实施调研模板－>编码规则执行进入该界面；
*  操作步骤
 
   *  第1步：维护相关编码规则信息。
   *  第2步：点击保存按钮。
