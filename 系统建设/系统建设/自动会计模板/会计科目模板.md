
# 功能描述

AAI（自动会计平台）设置，是每个项目上线必需的内容，U9C会计平台的设置比较抽象，顾问比较难理解，具体设置的工作量也比较大。针对这种情况，标准产品进行功能增强，增加部分预置数据，可直接导入相关配置。设置预设科目与会计科目、影响因素的对应关系。

# 业务规则

*  定义预设科目实施方案（必做）
*  定义依赖科目影响因素实施方案（必做）；

# 栏目说明

基本栏目-头

|栏目|说明|
|---|---|
|方案|会计科目模板的实施方案名称|
|依赖科目设置|会计科目依赖科目模板的实施方案名称|
|依赖因素设置|会计科目依赖科目影响因素方案名称|

基本栏目-行

|栏目|说明|
|---|---|
|预设科目|参照预设科目档案录入。|
|影响因素方向|选择录入预设科目影响因素方向。1、双向2、借方3、贷方当选择双向时，则无论科目是发生在借方还是贷方，都按该因素取值。当选择借方或贷方时，则当科目发生在借方时按借方因素取值，发生在贷方时按贷方因素取值。|
|标准科目|录入标准科目|
|科目段１－影响因素|根据科目编码结构设置段１对应的影响因素。参照预设科目中设置的影响因素录入。为保证设置内容的正确性，系统会根据科目段对应的值集，以及预设科目中设置的影响因素，进行自动预置。例如：科目段对应的值集是“部门”，某预设科目有一个影响因素也是“部门”，则在参照中系统将自动默认因素部门就是科目段对应的因素。如果科目段的对应值集的每一个取值，分别对应影响因素的每个因素值，则可以直接录入因素就可以了。但如果科目段的对应值集的每个取值不能与因素值一一对应，则此时本科目段对应的因素应当为空，不设置，以便在“科目取值规则”页签分别设置因素值与科目段值集值的对应关系。|
|科目段２－影响因素|根据科目编码结构设置段２对应的影响因素。方法同上。|
|科目段Ｎ－影响因素|如果科目段对应的值集是“标准科目”则需要在“科目取值规则”页签设置对应的标准科目。|

# 操作说明

*  通过菜单系统建设－>系统建设－>会计科目模板进入该界面；
*  操作步骤
 
   *  第1步：点击系统建设－>会计科目模板，进入会计科目模板维护主界面；
   *  第2步：点击新增按钮。
   *  第3步：录入方案和选择依赖方案。
   *  第4步：录入预设科目、影响因素等信息。
   *  第5步：点击保存。
