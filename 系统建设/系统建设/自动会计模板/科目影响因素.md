
# 功能描述

由于不同的业务内容，在会计凭证中将会归入不同的预设科目，将这些影响预设科目归属的业务要素，称为影响因素。

本功能提供设置预设科目的不同归属要素的实施方案配置。

同一个预设科目在不同业务单据中、在不同的核算账簿中可以分别设置不同的影响因素。

# 业务规则

*  定义预设科目（必做）

[基本栏目](http://wangwq/U9C/help/zh-CN/Content/CBO/Function/javascript:void(0);)-行

|栏目|说明|
|---|---|
|预设科目|参照预设科目档案录入。|
|方向|选择录入预设科目影响因素方向。1、双向2、借方3、贷方当选择双向时，则无论科目是发生在借方还是贷方，都按该因素取值。当选择借方或贷方时，则当科目发生在借方时按借方因素取值，发生在贷方时按贷方因素取值。|
|影响因素|一个预设科目在一个单据，在一个账簿中，最多可以有1０个影响因素。|
|因素１|参照系统预置的影响因素录入。|

# 操作说明

*  通过菜单系统建设－>系统建设－>科目影响因素进入该界面；
*  操作步骤
 
   *  第1步：点击系统建设－>科目设置，进入科目影响因素主界面；
   *  第2步：点击新增按钮。
   *  第3步：录入预设科目。
   *  第4步：录入科目影响因素等信息。
   *  第5步：点击保存。
