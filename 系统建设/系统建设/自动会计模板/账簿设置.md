
# 功能描述

设置组织账簿的实施方案。

# 业务规则

*  存在科目设置方案。

# 栏目说明

基本栏目-头

|栏目|说明|
|---|---|
|方案|账簿设置实施方案名称|


基本栏目-行

|栏目|说明|
|---|---|
|组织|账簿的组织|
|编码|账簿的编码|
|名称|账簿的名称|
|本币|账簿的本币|
|依赖方案|账簿的依赖方案|
|描述|账簿的描述|

# 操作说明

*  通过菜单系统建设－>系统建设－>账簿设置进入该界面；
*  操作步骤
 
   *  第1步：点击系统建设－>账簿设置，进入账簿设置主界面；
   *  第2步：录入方案名称。
   *  第3步：录入组织、编码、名称、依赖方案等信息。
   *  第4步：点击保存。
