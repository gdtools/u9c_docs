
# 功能描述

设置预置的科目体系、辅助核算、会计科目规则。

# 业务规则

*  预制科目设置方案不支持修改。

# 栏目说明

基本栏目-头

|栏目|说明|
|---|---|
|方案|科目设置实施方案名称|


基本栏目-左树

|栏目|说明|
|---|---|
|会计要素+科目属性|左树按照会计要素+科目属性展示，左树右表数据联动；|

基本栏目-右列表

|栏目|说明|
|---|---|
|编码|会计科目编码|
|名称|会计科目名称|
|核算币种|参照币种档案，支持多选；多选结果用逗号隔开；|
|余额方向|“余额方向”设置科目余额方案，枚举值：借、贷|
|受控系统|“受控系统”设置科目受控系统，参照系统模块|
|银行|是否是银行科目|
|现金|是否是现金科目|
|辅助核算|选择科目的辅助核算项目|

# 操作说明

*  通过菜单系统建设－>系统建设－>科目设置进入该界面；
*  操作步骤
 
   *  第1步：点击系统建设－>科目设置，进入会计科目设置主界面；
   *  第2步：点击新增按钮。
   *  第3步：录入方案。
   *  第4步：录入科目编码、科目名称、辅助核算项目等信息。
   *  第5步：点击保存。
