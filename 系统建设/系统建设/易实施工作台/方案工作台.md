
# 功能描述

本结点提供与实施方案相关的所有操作和活动。包括方案的发布、导入、导出。

# 业务规则

*  维护实施方案（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|分类编码|实施方案的分类编码|
|分类名称|实施方案的分类名称|
|方案编码|实施方案的方案编码|
|方案名称|实施方案的方案名称|

# 按钮说明

*  <发布>：选中方案后点击操作发布。
*  <导入>：弹出导入界面，选择导入的方案文件，导入生成方案。
*  <导出>：选择方案导出方案文件。

# 操作说明

*  通过菜单系统建设－>系统建设－>实施工作台－>方案工作台进入该界面；
*  操作步骤
 
   *  第1步：选择查询。
   *  第2步：选择实施方案。
   *  第3步：点击发布按钮。
