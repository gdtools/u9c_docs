
# 功能描述

配置U8与系统的对接方案；

# 业务规则

*  编码不能重复。

# 栏目说明

基本栏目-头

|栏目|说明|
|---|---|
|编码|导入方案的编码|
|名称|导入方案的名称|
|创建人|导入方案的创建人|
|描述|导入方案的描述|


基本栏目-数据库配置

|栏目|说明|
|---|---|
|DB服务器|导入的DB服务器|
|DB名称|导入的DB名称|
|年分|导入的年分|
|U9账簿|导入的U9账簿|

基本栏目-总体映射规则

|栏目|说明|
|---|---|
|第三方字段|导入的第三方字段|
|映射规则|导入的映射规则|
|U9字段|导入的U9字段|

基本栏目-明细映射字段

|栏目|说明|
|---|---|
|U8取值|导入的U8取值|
|第三方取值名称|导入的第三方取值名称|
|U9取值|导入的U9取值|
|U9取值名称|导入的U9取值名称|

# 操作说明

*  通过菜单系统建设－>系统建设－>与U8集成－>导入方案进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：维护数据库配置、总体映射规则、明细映射规则信息。
   *  第3步：点击保存按钮。
