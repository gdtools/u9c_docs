
# 功能描述

记录U8导入日志和执行情况；

# 业务规则

*  配置U8导入方案（必做）

# 栏目说明

基本栏目-操作日志

|栏目|说明|
|---|---|
|导入时间|记录导入时间|
|导入方式|记录导入方式|
|导入人|记录导入人|
|编码|记录编码|
|名称|记录名称|
|U8账套|记录U8账套|
|U9账套|记录U9账套|


基本栏目-导入结果

|栏目|说明|
|---|---|
|第三方单据号|第三方单据号|
|U9单据号|U9单据号|
|是否成功|是否成功|
|错误信息|错误信息|

# 操作说明

*  通过菜单系统建设－>系统建设－>与U8集成－>导入日志进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定按钮。
