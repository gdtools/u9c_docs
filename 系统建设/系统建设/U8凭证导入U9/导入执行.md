
# 功能描述

执行导入方案；

# 业务规则

*  配置导入方案（必做）

|导入方式|导入的导入方式|

# 操作说明

*  通过菜单系统建设－>系统建设－>与U8集成－>导入执行进入该界面；
*  操作步骤
 
   *  第1步：选择导入方案。
   *  第2步：维护开始结束日期、导入方式、作废凭证等导入信息。
   *  第3步：点击确定按钮。
