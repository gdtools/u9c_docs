
# 功能描述

本结点提供按照来源组织的数据复制到目的组织和导出方案文件等相关的操作。

系统参数：基础参数、模块参数以及系统管理等参数；

# 业务规则

*  相关模块已经启用（必做）

# 栏目说明

基本栏目-头

|栏目名称|说明|
|---|---|
|来源组织|选择来源组织|

基本栏目-左列表

|栏目名称|说明|
|---|---|
|分类编码|实施方案的分类编码|
|分类名称|实施方案的分类名称|

基本栏目-右列表

|栏目名称|说明|
|---|---|
|目的组织编码|目的组织编码|
|目的组织名称|目的组织名称|

# 按钮说明

*  <复制>：来源组织的数据复制到目的组织。
*  <导出>：选择来源组织导出方案文件。

# 操作说明

*  通过菜单系统建设－>系统建设－>易实施工作台－>数据工作台进入该界面；
*  操作步骤
 
   *  第1步：选择来源组织。
   *  第2步：选择复制的数据类别和目的组织。
   *  第3步：点击复制按钮。
