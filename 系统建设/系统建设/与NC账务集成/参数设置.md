
# 功能描述

设置相关参数，支持将系统中的凭证同步到NC系统中；

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|是否NC接口流程|设置是否NC接口流程|
|NC服务地址|设置NC服务地址|
|NC账套编码|设置NC账套编码|
|NC集团编码|设置NC集团编码|
|NC外部系统编码|设置NC外部系统编码|
|NC账簿编码|设置NC账簿编码|
|NC组织编码|设置NC组织编码|
|NC现金流量科目段编码|设置NC现金流量科目段编码|
|弃审时自动删除NC凭证|设置弃审时自动删除NC凭证|


# 操作说明

*  通过菜单系统建设－>系统建设－>与NC财务集成－>参数设置执行进入该界面；
*  操作步骤
 
   *  第1步：输入相关对接信息。
   *  第2步：点击保存按钮。
