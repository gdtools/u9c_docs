
# 功能描述

设置系统与NC科目对照关系，支持将系统中的凭证同步到NC系统中；

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

科目对照-头

|栏目|说明|
|---|---|
|账簿|选择账簿|


科目对照-行

|栏目|说明|
|---|---|
|NC辅助核算项目编码|设置NC辅助核算项目编码|
|NC辅助核算项目名称|设置NC辅助核算项目名称|
|是否为部门字段|设置是否为部门字段|
|是否为标准科目|设置是否为标准科目|
|NC辅助核算项目编码|设置NC辅助核算项目编码|


# 操作说明

*  通过菜单系统建设－>系统建设－>与NC财务集成－>科目对照执行进入该界面；
*  操作步骤
 
   *  第1步：输入相关对接信息。
   *  第2步：点击保存按钮。
