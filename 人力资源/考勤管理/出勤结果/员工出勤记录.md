
# 功能描述

本节点主要功能是记录员工日出勤的详细数据，可进行对每个员工每天的应出勤以及实际出勤记录的查看、修改、计算等功能。

# 操作说明

*  <查询>：可根据工作组织、日期、员工等条件，查询出需要的考勤记录
*  <创建员工出勤记录>：点击则弹出“根据工作日历批量生成员工出勤记录”，可根据各种条件创建出相应的员工应出勤记录，前提是相应的员工的排班方式为工作日历。若是通过排工申请单生成的员工出勤记录，无需点击该按钮，排工申请单审核通过后，系统自动生成员工出勤记录。
*  <日考勤计算>：点击则弹出日考勤计算弹窗，可根据各种条件计算出相应的员工日出勤结果，前提是该员工有相应的应出勤记录。
*  <调度计算>:U9C统一功能，参见公共说明。
*  <生成异常说明单>：选择相应的异常记录，点击此按钮即可生成相应的开立的考勤异常说明单。
*  <生成倒休请假单>：选择相应的异常记录，点击此按钮即可生成相应的开立的倒休请假单。
