
# 功能描述

本节点主要功能是定义期末考勤结果中各项目的含义。

# 栏目说明

|栏目|说明|
|---|---|
|考勤项目|对应的期末考勤结果中的字段名称。|
|系统项目|是否系统项目。描述性弹性域为非系统项，其它为系统项目，系统维护。|
|项目类型|对系统项目，项目类型不能调整。|
|项目描述|考勤项目的说明，默认等于[考勤项目]对应字段的描述|
|计量单位|计量单位有：天、小时、分钟等。类型为“时间”时不能为空。|

# 操作步骤

*  期末考勤项目增加操作步骤

1. 在基础设置中增加 “期末考勤结果”的实体扩展字段（公共扩展字段、全局段均可）。
2. 在新增期末考勤项目中参考到扩展字段，用于定义用户所需的扩展栏目。
3. 定义期末考勤项目设置，对于非系统项目的考勤项目，必须定义公式或者用日出勤记录中的日考勤项目进行汇总（注意：在期末考勤项目设置的公式编辑器中，增加了“考勤系统扩展函数”，在日考勤项目设置中没有）。
4. 期末考勤项目设置中属于系统项目的期末考勤项目，不能定义公式。
