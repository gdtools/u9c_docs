
# 功能描述

本节点主要功能是定义日考勤结果中各项目的含义。

# 业务规则

*  数据来源等于“考勤机”或“异常说明单”的数据不允许修改。

# 栏目说明

|栏目|说明|
|---|---|
|考勤项目|对应的日考勤结果中的字段名称。|
|系统项目|描述弹性域为非系统项，其它为系统项目。|
|项目类型|如果[考勤项目]的类型为整数时，只能是“次数”类型的项目如果[考勤项目]的类型为数值时，只能是“时间”类型的项目。其它类型的[考勤项目]，只能是备注类型的项目对系统项目，项目类型不可改。加班这几项暂先不计算|
|项目描述|考勤项目的说明，默认等于[考勤项目]对应字段的描述。|
|计量单位|类型为“时间”时不能为空。非时间类型置空。注意：根据选择的项目类型（对应到员工出勤记录的字段），自动带出计量单位。|

# 操作步骤

*  日考勤项目增加操作步骤

1）在基础设置中增加 “员工出勤记录”的实体扩展字段（公共扩展字段、全局段均可）；

2）然后定义日考勤项目设置，对于非系统项目的考勤项目，必须定义公式，并且只支持对现有项目的引用及其加减乘除计算，不支持函数及上下文的使用

3最后做员工的日出勤记录、日常加班、请假、出差等单据，并计算，即可得到所需的扩展栏目及其值（此处为位扩展到页面上的展示效果，用户可根据自己的需求，将字段扩展到卡片）
