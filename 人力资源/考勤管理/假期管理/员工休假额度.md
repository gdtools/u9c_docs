
# 功能描述

本节点主要功能是定义每个员工每个期间内的休假额度。

# 栏目说明

|栏目|说明|
|---|---|
|表头||
|工作组织|员工的工作组织。|
|员工|员工。|
|起始年度|休假额度起始年度。|
|起始月份|开始月份。|
|可休额度|系统维护 ，由“员工休假额度明细计算”得到，可休假的天数。|
|表行-员工休假额度明细||
|假期类别|为空表示组织内的默认请假规则，否则为这个请假类别的请假规则，未定义休假规则的请假类别表示不限制。|
|年度|休假年度。|
|期间|如果该休假类型的周期类型为年度或终身时，则为空。如果该休假类型的周期为季，则为1－4的数值。该休假类型的周期为月，则为1－12的数值。|
|可休额度|可休假的天数。|
|本期休假额度|本期可休假的天数。|
|前期结转额度|前期结转的可休假天数。|
|已休天数|该可休假的开始时间。|
|是否结转|本期的休假额度是否结转至下一期。默认为false,休假额度结转时系统自动置为true。|
|结转日期|休假额度结转时系统自动维护。|
|表行-本期休假额度变更记录|对应员工休假额度明细行|
|变更日期|休假额度变更日期。|
|原额度|原额度。|
|变更后额度|变更后额度。|
|变更原因|变更原因。|
|变更来源|休假额度变更来源。|
|变更单号|加班存休时为对应的加班单。额度调整是为对应的休假额度调整单。|
|表行-休假额度增减明细||
|来源单据类型||
|来源单据号||
|来源单据行号||
|额度值||
|业务日期||

# 按钮说明

*  <操作-结转>：选中一行，点击该按钮可结转选中行的休假额度，并另起一行，自动生成下一期员工休假额度明细。
*  <操作-撤销结转>：选中已结转的行，可插销结转。
