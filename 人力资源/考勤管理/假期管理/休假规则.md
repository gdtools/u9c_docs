
# 功能描述

本节点主要功能是定义员工休假的各种规则。如果未定义任何休假规则，则表示没有休假额度的限制。

# 栏目说明

|栏目|说明|
|---|---|
|表头||
|假期类别|为空表示组织内的默认请假规则,否则为这个请假类别的请假规则,未定义休假规则的请假类别表示不限制。|
|编码|当前休假规则的编码。|
|名称|当前休假规则的名称。|
|计量单位|当前休假规则的加量单位有：天、小时、分钟等。|
|带薪假|休假是否带薪。|
|额度检查方式|当前休假规则的额度检查方式有：请假时警告、请假时限制。|
|休假额度周期|当前休假规则的休假额度周期有：月、季、年、终身等。|
|休假额度计算方式|固定额度时所有统一额度。按休假规则指按“休假规则明细”控制休假。|
|固定额度|休假规则的固定额度。|
|每期最大次数|每期最多可休假的次数。为空或0表示不受限制。|
|每次最大数量|如果进行休假，每次最少要休的天数，为空或0表示不受限制。如请假时间不足最小请假时间，则按最小请假时间计算。|
|每次最小数量|如果进行休假，每次最少要休的天数，为空或0表示不受限制。如请假时间不足最小请假时间，则按最小请假时间计算。|
|结转方式|该休假的结转方式。无限期结转：可连续结转，即本期内所有休假额度余额都可结转至下期。只结转上期：该类型休假结转的休假额度不能超过本期的休假额度。不结转：本期休假额度余额不结转至下期。有限期结转：|
|有效结转期(月)||
|表行||
|优先序号|从1开始，表示休假规则的优先顺序，序号小的优先匹配。|
|工作组织|员工的工作组织。|
|业务组织|[组织] 或 和[组织]有平行关系的组织。|
|部门|[业务组织]下的部门|
|人员类别|引用“人员类别”|
|职务|引用“职务”|
|性别|员工性别|
|婚姻状况|员工婚姻状况|
|最低职等|员工最低职等|
|最高职等|员工最高职等|
|岗位|引用“岗位”|
|最小司龄|员工最小司龄|
|最大司龄|员工最大司龄|
|额度|员工休假额度|
