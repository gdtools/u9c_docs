
# 功能描述

本节点主要功能是用于休假额度调整申请。

# 栏目说明

|栏目|说明|
|---|---|
|单据类型|休假额度变更单的单据类型。|
|单号|休假额度变更单的编号。|
|日期|休假额度变更单的申请日期。|
|工作组织|员工工作组织。|
|员工|申请休假额度变更单的员工。|
|假期类别|当前休假额度变更单假期类别有病假、事假、年假、婚假、产假、倒休、丧假等。用户可以点击假期类别变更。|
|年度|休假额度变更年度。|
|期间|如果该休假类型的周期类型为年度或终身时，则为空。如果该休假类型的周期为季，则为1－4的数值。如果该休假类型的周期为月，则为1－12的数值。|
|原额度|原来的额度，系统可自动带出。|
|变更后额度|变更后的额度。|
|变更原因|变更原因。|
|申请人|申请人。|
|申请日期|默认当时日期。|
|单据状态|当前休假额度变更单单据状态有：开立、核准中、已核准、作废等。|

# 操作步骤

*  一般操作见公共操作说明。
