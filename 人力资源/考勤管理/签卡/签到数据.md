
# 功能描述

本节点主要用于外部签到数据导入本系统，进行员工签到数据的管理。

# 业务规则

*  数据来源等于“考勤机”或“异常说明单”的数据不允许修改。

# 栏目说明

|栏目|说明|
|---|---|
|考勤卡号|员工打卡所使用的卡的编号。|
|打卡时间|从考勤机下载的打卡时间|
|考勤机|哪个考勤机上采集的数据。|
|考勤机类型|当前考勤机的类型。|
|员工|考勤卡号对应的员工。[员工]和[考勤卡号]不能同时为空|
|数据来源|考勤机：从考勤机下载的签到数据。手工：手工维护或导入的签到数据。异常说明单：通过考勤异常说明单生成的签到数据。|

# 按钮说明

*  <查询>：点击该按钮，用户可以根据考勤卡号、考勤机、考勤机类型、员工、打卡时间、数据来源、异常说明单等查询员工签到数据。
*  <签到数据导入>：当考勤方式为机器考勤时，员工签到的数据，上传打卡数据，指上传从考勤机中下载的考勤数据文件，链接到上传打卡数据画面。
*  <导出文件模板>：选择需要的签到数据模板，点击该按钮即可导出相应的签到数据模板。

# 操作步骤

*  通过考勤机刷卡，有了考勤数据后点击<签到数据导入>按钮会自动弹出签到数据导入-网页对话框。
