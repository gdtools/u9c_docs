
# 功能描述

本节点主要用于设置参加考勤的人员的考勤卡，用于考勤计算时签到数据与考勤卡的关联。

# 业务规则

*  对同一考勤人员，[开始日期、截止日期]不交叉。

# 栏目说明

|栏目|说明|
|---|---|
|考勤卡-表头||
|工作组织|当前员工的工作组织|
|员工|使用当前考勤卡的员工|
|考勤机类型|使用当前考勤卡的考勤机类型（不可编辑，表体里填写后会自动生成）。|
|考勤卡号|考勤卡号（表体里填写后会自动生成）。|
|考勤卡-表体||
|考勤机类型|当前考勤卡所属的考勤机类型，为空时表示有限考勤机类型，考勤卡可在任意考勤机上刷卡。|
|考勤卡号|考勤卡号|
|开始时间|使用当前考勤卡的开始时间。|
|截止时间|使用当前考勤卡的截止时间。|

# 按钮说明

*  <未设置考勤卡查询>：点击该按钮，弹出未设置考勤卡查询画面，选择工作组织、现任业务组织、部门、人员，选择是否过期，点击<查询>可查看查询结果。
