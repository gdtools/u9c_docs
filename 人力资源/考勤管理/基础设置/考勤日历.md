
# 功能描述

本节点主要是设置考勤日历。

*  各考勤中心可以定义本组织的基准期间、考勤日历；
*  基准期间分：年、季、月、周、日，主要用于划分员工的期末考勤计算的期间。
*  考勤日历是同一类型的基准期间集合，其中包括基准年度、基准期间，与我们日常生活中使用的日历不同，可以跨自然年度。例如：从上一年度的五月一日到本年度的四月三十日为一个基准年度。

# 栏目说明

|栏目|说明|
|---|---|
|考勤说明-表头||
|工作组织|显示当前日历所属的考勤工作组织。不可编辑。登录考勤中心后可以创建本组织的考勤日历。|
|编码|当前考勤日历项目的编码。|
|名称|当前考勤日历的名称。|
|简称|当前考勤日历的简称。|
|描述|当前考勤日历的说明。|
|期间类型|当前考勤日历的期间类型。以下期间类型供选择：年：以一年为一个期间；季：以一个季节为一个期间；月：以一个月为一个期间；周：以一周为一个期间；日：以一天为一个期间。|
|开始时间|当前考勤日历的有效开始时间。|
|截止时间|当前考勤日历的有效截止时间。|
|起始基准年度|指基准期间所属的起始年度。注：考勤日历的考勤中心+期间类型+工作组织不能相同。|
|考勤日历-行||
|年度|指基准期间所属的所有年度。注：根据开始、截止时间自动生成。|
|期间|根据当前考勤年度和期间所生成的期间。|
|期间名称|根据当前考勤年度和期间所生成的期间名称。|
|开始日期|根据当前期间所生成的开始日期。|
|截止期间|根据当前期间所生成的截止日期。|

# 按钮说明

*  <生成考勤期间>：根据基准期间类型、开始日期，系统自动生成一个考勤年度的全部期间。
*  <追加考勤期间>：根据基准时间类型、上一年度的结束日期，系统自动追加一个新考勤年度的全部期间。
