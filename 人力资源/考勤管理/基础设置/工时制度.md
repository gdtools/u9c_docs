
# 功能描述

本节点主要功能是按国家地区定义系统应遵守的工时制度。

# 业务规则

*  对同一[工作人事组织, 业务组织, 部门, 职务, 岗位, 员工]，[开始日期，截止日期]时间不交叉。
*  当使用岗位体系时，使用部门或者部门加岗位维护工时制度（设置部门加职务会自动默认岗位为空）。
*  当使用职务体系时，使用部门或者部门加职务维护工时制度。

# 栏目说明

|栏目|说明|
|---|---|
|工时制度-表头||
|编码|当前工时制度项目的编码。|
|名称|当前工时制度项目的名称。|
|国际/地区|当前工时制度所属的国家/地区。如果没有建立需要的国家/地区档案可以点击本项目下划线，弹出国家/地区设置画面，在线设置。|
|定时工作|定时工作：基于上下班定点时间进行考勤。非定时工作：即弹性工作，和[弹性周期]配合使用计算员工的考勤。|
|弹性周期|对非定时工作，按天或考勤期间进行弹性。天：按天弹性，在每天规定的上班时间范围内出勤时间达到班次的时间长度即认为正常考勤期间：按考勤期间进行弹性，在考勤期间内，上班时间总和达到要求即认为正常|
|允许旷工工时(小时)||
|标准日工时|每天标准的工作时长，以小时为单位|
|最大日工时|每天最大的工作时长，以小时为单位。员工日工作时间预警依据：员工某天的工作时间（上班时间+加班时间）不应超过最大日工时，空或0表示不限。|
|标准周工时|每周标准的工作时长，以小时为单位|
|最大周工时|每周最大的工作时长，以小时为单位|
|标准月工时|每周标准的工作时长，以小时为单位|
|最大月工时|每周最大的工作时长，以小时为单位。员工周工作时间预警依据：员工周工作时间（上班时间+加班时间）不应超过最大周工时，空或0表示不限。|
|加班抵扣旷工|在工时统计周期内，是否允许用加班时间抵扣旷工时间|
|加班抵扣请假|在工时统计周期内，是否允许用加班时间抵扣请假时间|
|加班抵扣欠班|在工时统计周期内，是否允许用加班时间抵扣欠班时间|
|生效|生效：在有效日期期间内有效。非生效：在有效日期期间内无效。|
|生效日期|当期工时制度的有效日期|
|失效日期|当期工时制度的无效日期|
|工时制度-表体||
|序号|当前工时制度的序号。|
|考勤中心|使用当前工时制度的考勤中心。|
|工作组织|当前考勤中心管理的工作组织。|
|业务组织|当前工作组织管理的下属组织。|
|部门|当前业务组织的下属部门。|
|职务|当前部门所属的职务|
|岗位|当前部门所属的岗位。|
|开始日期|当前序号工时制度的开始日期。|
|截止日期|当前序号工时制度的截止日期。|
