
# 功能描述

本节点主要功能是员工停工时申请的单据。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|停工单单据类型。|
|单号|停工单单据编号。|
|日期|停工单申请日期，默认为当天。|
|工作组织|员工的工作人事组织。|
|业务组织|员工的业务组织。|
|部门|员工的部门。|
|停工开始时间|停工开始时间。|
|停工截止时间|停工截止时间。|
|班次|为空，表示停工时间段内不限班次。|
|停工原因|停工的原因。|
|停工描述|停工的详细描述。|
|申请人|申请人。|
|单据状态|当前停工单单据状态有：开立、核准中、已核准、作废等。|
|表行||
|部门|当[停工单].[部门]非空时，为[停工单].[部门]或其下级部门，否则为[停工单].[业务组织]下的部门。|
|班组|[员工]非空时，等于[员工]的所属班组，否则，[部门]非空时，为[部门]下的班组，否则为[停工单].[业务组织]下的班组。|
|人员类别|[员工]非空时，等于[员工].[部门]，否则，[停工单].[工作人事组织]下的人员类别。|
|职务|[员工]非空时，等于[员工].[部门]，否则，[停工请单].[工作人事组织]下的职务。|
|岗位|[员工]非空时，等于[员工].[部门]，否则，如果[部门]非空，限[部门]下的岗位，否则，限[停工单].[业务组织]下的岗位|
|员工|[部门]非空时，为[部门]下的员工，否则为[停工单].[业务组织]下的员工，员工为空时，表示满足前面条件的所有员工。|

# 按钮说明

*  <人员明细查询>：点击该按钮，弹出停工人员明细画面，可按照条件查询停工人员。
