
# 功能描述

本节点主要功能是期末考勤计算后核对的单据。

# 业务规则

*  表体数据在选择期间保存后，自动生成，限单头（工作组织、业务组织、部门、班组）范围内的所有已计算但未审核的期末考勤结果。
*  审核通过后回写期末考勤结果到人员管理模板的考勤数据，此时本单据的状态为“已审核”，弃审后期末考勤结果的状态变为“已计算”。
