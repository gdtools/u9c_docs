
# 功能描述

本节点主要功能是两个员工相互调班时申请的单据。

如果对应的期末考勤结果已审核，则不能调班。

对每行调班申请单明细，将在时段范围内两员工的员工出勤记录互换，同时记录调班单ID。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|调班单的单据类型。|
|单号|调班单的单据编号|
|日期|调班单的申请日期。|
|工作组织|员工的工作人事组织。|
|业务组织|员工的业务组织。|
|部门|员工的部门。|
|调班原因|调班的原因。|
|申请人|申请人。|
|单据状态|当前调班单的单据状态有：开立、核准中、已核准、作废等。|
|表行||
|员工|需要进行调班的员工1。|
|开始日期|调班人员1调班开始日期。|
|截止日期|调班人员1调班截止日期。|
|员工|需要进行调班的员工2。|
|开始日期|调班人员2调班开始日期。|
|截止日期|调班人员2调班截止日期。|

# 按钮说明

*  <人员明细查询>：点击该按钮，弹出上班人员明细画面。
*  <未排班人员>：点击该按钮，弹出未排班人员查询画面，按照查询条件查询。
*  <批量排班>：点击该按钮，弹出批量排班窗口，可在“排班人员”页签批量选择排班人员，在“批量排班”页签，开始日期和截止日期内，选择不同日期的班次，进行批量排班，批量排班画面，头数据不可修改。
