
# 功能描述

本节点主要功能是员工班次排工申请时使用的单据。

# 栏目说明

|栏目|说明|
|---|---|
|单头-排班方式||
|排工类型|排工、变更|
|变更类型||
|来源单据||
|单头-基本||
|单据类型|班次排工申请单的单据类型|
|单号|班次排工申请单的编号。|
|日期|班次排工申请单的申请日期。|
|工作组织|员工的工作人事组织。|
|业务组织|员工的业务组织。|
|部门|员工的部门。|
|开始日期|班次排工申请单的开始日期。|
|截止日期|班次排工申请单的截止日期。|
|默认班次|手工排班时非空。|
|单头-班次信息||
|直落班|为直落班时，班段间的休息时间直接作为加班时段。|
|直落班休息时间(分钟)|为直落班时，中间加班的休息时长。|
|延时下班|延长下班加班时间，生成应加班时段。|
|延时时长(小时)|延长的时间长度，以小时为单位。|
|延时下班休息时长(分钟)|延时下班的休息时长。|
|提前上班|提前上班加班，生成应加班时段。|
|提前时长(小时)|提前上班的时间长度。|
|提前上班休息时长(分钟)|提前上班的休息时长。|
|加班类别|直落班、延时加班、提前加班时的加班类别。|
|单头-状态||
|申请人|申请人。|
|单据状态|当前排工单单据状态有：开立、核准中、已核准、作废等。|
|表行-上班时间安排||
|班次|对应的班次，默认时单头的默认班次。|
|开始日期|班次排工单申请开始日期，对同一排工单，[开始日期，截止日期]不交叉。|
|截止日期|班次排工单申请截止日期。|
|表体-上班人员安排||
|部门|当[排工申请单].[部门]非空时，为[排工申请单].[部门]或其下级部门，否则为[排工申请单].[业务组织]下的部门。|
|班组|[员工]非空时，等于[员工]的所属班组，否则，[部门]非空时，为[部门]下的班组，否则为[排工申请单].[业务组织]下的班组。|
|人员类别|[员工]非空时，等于[员工].[部门]，否则，[排工申请单].[工作人事组织]下的人员类别。|
|职务|[员工]非空时，等于[员工].[部门]，否则，[排工申请单].[工作人事组织]下的职务。|
|岗位|[员工]非空时，等于[员工].[部门]，否则，如果[部门]非空，限[部门]下的岗位，否则，限[排工申请单].[业务组织]下的岗位。|
|员工|[部门]非空时，为[部门]下的员工，否则为[排工申请单].[业务组织]下的员工，员工为空时，表示满足前面条件的所有员工。|

# 按钮说明

*  <人员明细查询>：点击该按钮，弹出上班人员明细画面。
*  <未排班人员>：点击该按钮，弹出未排班人员查询画面，按照查询条件查询。
*  <批量排班>：点击该按钮，弹出批量排班窗口，可在“排班人员”页签批量选择排班人员，在“批量排班”页签，开始日期和截止日期内，选择不同日期的班次，进行批量排班，批量排班画面，头数据不可修改。
