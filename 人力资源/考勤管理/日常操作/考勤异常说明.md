
# 功能描述

本节点主要功能是对每个考勤异常说明明细，对相应上班时段，留下考勤异常说明线索，同时重补实际上下班时间。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|考勤结果异常说明单单据类型。|
|单号|考勤结果异常说明单单据编号。|
|日期|考勤结果异常说明单单据日期。|
|工作组织|员工的工作人事组织。|
|业务组织|员工的业务组织。|
|部门|员工的部门。|
|说明|考勤结果异常说明单的详细说明。|
|申请人|申请人。|
|单据状态|当前停工单单据状态有：开立、核准中、已核准、作废等。|
|表行-考勤异常说明明细||
|员工|上班时段.员工。|
|日期|考勤结果异常说明日期。|
|班次|对应的班次。|
|上班时段|上班时段。|
|异常原因|当前考勤结果异常原因有：考勤机坏、忘打卡、因公外出。|
|异常说明|异常详细说明。|
|手工补卡|如果手工补卡为true，则在“考勤异常说明-补卡”页签进行手工补卡；如果手工补卡为false，则系统自动重补正常刷卡。|
|表行-考勤异常说明补卡||
|补卡|如果手工补卡为true，则在本页签进行手工补卡。|

# 按钮说明

*  <查看打卡记录>：点击该按钮，弹出签到数据画面，可维护打卡数据，在该画面点击<新增>按钮，可打开签到数据新增页面，完成考勤维护。
