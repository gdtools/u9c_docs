
# 功能描述

本节点主要功能是定义员工出差时的各种补休规则。

# 栏目说明

|栏目|说明|
|---|---|
|表头||
|出差类别|为空表示组织内的默认出差有效期补休规则，否则为这个出差类别的出差补休规则。|
|允许补休|如果允许补休，则按补休规则，在期末计算时计入员工休假额度。|
|补休类型|补休时的请假类别，允许补休为True时不能为空。|
|补休顺序|补休顺序一致，则先出差先补休。|
|表行||
|序号|当前出差补休规则的序列号。|
|起始出差天数|开始出差天数。|
|截止出差天数|截止出差天数。为空表示不限。对同一出差补休规则，[起始出差天数，截止出差天数]不交叉。|
|补休天数|在这个区间段内的补休天数。|
