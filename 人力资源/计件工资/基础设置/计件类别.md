
# 功能描述

计件类别是计件工资计算、归集的基本范围约定，计件单价表、工资计算必须在指定的计件类别下进行。

计件类别需指定薪资日历，可启用/不启用保底工资，若勾选“最低保障工资”，在工资计算时，在员工日计件工资列表行上可维护最低保障工资，核准工资后可以得到员工最终的计件工资。

# 业务规则

*  计件类别一旦被引用，不可删除，修改影响未来。
*  最低保障工资表示该计件类别允许在[员工日计件工资](/detail/68b50f91474c432a99e6dce25daba9fc)列表中调整员工最低保障工资。
*  录入管理岗位工资计算标准表达式可以计入[计件人员单价表](/detail/77a575e24a6344fe9d4294194185d173)，从而能计算出当前员工或班组的薪资状况,此项目会在单价表使用对象起到作用。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|计件组织|默认等于当前登录组织，暂不支持修改|
|编码|必填项，允许输入中文、数字、字母、符号等，无限制|
|名称|必填项，允许输入中文、数字、字母、符号等，无限制|
|薪资日历|参照“薪资日历”档案|
|管理岗位工资标准|可录入公式，公式编辑器为U9C统一编辑器|
|最低工资保障|布尔型，默认FALSE|
|状态|同U9C统一规则|

# 按钮说明

*  <计件单价表>：点击该按钮可进入计件单价表新增画面，详情请查看[计件单价表](/detail/b51234e27fc94dcfa2a5a2711cb477cb)新增画面功能。

# 操作说明

*  点击计件类别，进入计件类别新增画面，填入所需字段。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的计件类别进行查找。
*  点击列表可查看已保存的全部计件类别信息。
