
# 功能描述

计件要素是定义计件的范围、业务动作，一个计件工作，可以从多角度描述，即计件要素，一个计件工作可由不同的计件要素形成，不同的计件要素的不同组合可以成为不同的价格。

关于来源方式“字段”描述如下：

字段是影响计件工作数据的实体上的属性，也可以是实体上的弹性域字段。可以参照料品、工序、工艺路线、车间管理的任务汇报单和员工信息档案等。如 颜色、形状、部门、工序号、编号、单据状态等一些属性值，本次迭代需求增加“派工单完工申报单”单据字段，详细见下文描述。

例如：

计件工作：制作鼠标

计件要素：颜色（黑、红）、按键数分类（双键、三键、多 键）、外部构造（无线、有线）

计件工作数据：黑色-双键-有限（15元）

黑色-三键-有限（20元）

红色-多键-无限（50元）...

# 业务规则

*  计件要素一旦被引用不可删除，修改影响未来。
*  计件工作数据要素需要同时为“是否车间报工”下的字段或同时不是“是否车间报工”下的字段,不能交叉。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|计件组织|默认当前登录组织，不可修改|
|编码|必填项,录入计件要素编码|
|名称|必填项,录入计件要素名称|
|描述|非必填项,可录入描述|
|是否车间报工|默认勾选，勾选后，“字段”可选择“任务汇报单、派工单完工申报单”，若不勾选，“字段”可选择“任务汇报单、派工单完工申报单、人员信息、料品信息、工艺路线、工序信息”|
|来源方式|默认为字段，不可修改|
|字段|受“是否车间报功”影响，勾选与否，可选实体不同|
|数据类型|根据所选字段，自动显示数据类型，不可修改|
|状态|同U9C统一规则|

# 按钮说明

*  <计件工作>：点击该按钮可进入计件工作新增画面，详情请查看[计件工作](/detail/032cdc90cd9346a8b4507ae30b6e94d8)新增画面功能。

# 操作说明

*  点击计件类别，进入计件类别新增画面，填入所需字段。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的计件类别进行查。
*  点击列表可查看已保存的全部计件类别信息。
