
# 功能描述

计件工作是定义计件的范围、业务动作，一个计件工作，可以从多角度描述，即计件要素，一个计件工作可由不同的计件要素形成，不同的计件要素就是“计件工作数据”。

# 业务规则

*  计件工作一旦被引用不可修改不可删除。
*  计件工作数据一旦被引用不可修改不可删除。
*  计件工作数据”显示的是影响计件数量的计件要素。
*  计件类型=计件，计件数量取值中业务对象可参照“任务汇报单”和“派工单完工申报单，选择业务对象后，系统可自动带出默认值。
*  若业务对象选择派工单完工申报单，且该单据中“报废原因”为“人工报废”，计件数量取值中“工废数量”对应默认值为派工单完工申报单中“返修数量”，“料废数量”对应默认值为0。
*  若业务对象选择派工单完工申报单，且该单据中“报废原因”为“材料报废”，计件数量取值中“料废数量”对应默认值为派工单完工申报单中“返修数量”，“工废数量”对应默认值为0。
*  若业务对象选择任务汇报单，且该单据中“报废原因”为“人工报废”，计件数量取值中“工废数量”对应默认值为任务汇报单中“报废数量”，“料废数量”和“废品数量”对应默认值为0。
*  若业务对象选择任务汇报单，且该单据中“报废原因”为“材料报废”，计件数量取值中“料废数量”对应默认值为任务汇报单中“报废数量”，“工废数量”和“废品数量”对应默认值为0。
*  选择业务对象后，手动修改默认值时，在Fx编辑框内，需要首先输入实体表名.字段名，否则选择的字段不能显示成中文，任务汇报单实体名：SFCTasksReport，派工单完工申报单实体名：DispatchCompleteOrderDocLine，举例：设置“任务汇报单”中“正品数量”对应“待返工数量”时，点开Fx函数后，在表达式中输入如下函数：SFCTasksReport.ReworkQtyProduct，如下图：

*  计件类型=计时，计件数量取值不可用。
*  在计件工作数据中批量增加要素值时，自动生成计件工作码编号规则：计件工作编码+计件工作数据行号。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|工作人事组织|默认当前登录组织，不可修改|
|编码|必填项，允许输入中文、数字、字母、符号等，无限制|
|名称|必填项，允许输入中文、数字、字母、符号等，无限制|
|计件属性|必填项，枚举，计件、计时，默认值计件|
|计价单位|参照计量单位，表示计件工作在计价数量下的单位|
|数量单位|参照计量单位，表示计件工作的实际工作量的单位|
|业务对象|非必填，计件数量直接取值的实体，包含任务汇报单、派工单完工申报单|
|正品数量|非必填，参照业务对象，指定具体字段|
|次品数量|非必填，参照业务对象，指定具体字段|
|废品数量|非必填，参照业务对象，指定具体字段|
|工废数量|非必填，参照业务对象，指定具体字段|
|料废数量|非必填，参照业务对象，指定具体字段|
|影响计件数量|布尔，默认TRUE|
|影响计件价格|布尔，默认TRUE；影响计件数量=TRUE，影响计件价格必须=TRUE，不可修改|
|状态|同U9C统一规则|

# 按钮说明

*  <计件要素>：点击该按钮可进入计件要素新增画面，详情请查看[计件要素](/detail/3ee67229325349f9b18ffffcd7d1bac1)新增画面功能。
*  <计件工作数据>：点击该按钮可进入计件工作数据新增画面，录入计件工作码和“影响计件数量”的计件要素；
*  在计件工作数据新增画面中，点击<批量增加要素值>，可进入批量增加要素画面，直接增加“影响计件数量”的计件要素，确定后系统自动生成计件工作码。

# 操作说明

*  点击计件工作，进入计件工作新增画面，填入所需字段。
*  在计件工作新增画面行上，点击<新增>，可新增行，需填写计件要素，勾选是否影响计件数量或影响计件价格，勾选影响计件数量，默认勾选影响计件价格。计件要素参照为第4.2章节已将创建的计件要素，并且，此处所选计件要素需按照“计件数量取值”中“业务对象”所选业务单据进行过滤，不一致时则会报错，若“业务对象”为空，计件要素显示所有。
*  在计件工资的整个流程中，计件工作数据占据着重要位置，新增计件工作后，需要添加计件工作数据，在计件工作底部栏目中点击<计件工作数据>,可进入计件工作数据页面，在行上点击<新增>按钮，可增加一条计件工作数据，填写计件工作码、选择计件要素，可完成一个计件工作数据的录入，
