
# 功能描述

按集体计件时，集体是计件统计的单位，计件集体是定义计件集体的构成、计件集体工资的分配方法等。

计件集体并不与部门、班组严格一致，经常有借调人情况，因此集体计件的组成是动态的，可以由部门、班组、工作中心、不同职务、不同岗位的人员组合而成。

# 业务规则

*  计件集体一旦被引用不可删除，修改影响未来。
*  “组成”是车间工作量取数后的匹配依据，因车间业务单据中负责的团队多为工作中心或班组，此处，通常录入工作中心或录入班组。
*  分摊方式：以计件集体为单位，计算出集体工资后，按照此分摊方式给员工分摊工资，分摊方式：所有人均摊、是否有出勤分摊、根据出勤时间分摊、按人员权重分摊、按出勤人员权重分摊，默认值“所有人均摊”。
*  按日分摊：支持按日分摊，也支持按薪资期间（月）一起分摊。
*  “成员”为实际分摊计件集体工资的人员。
*  分摊方式为“按人员权重分摊”或“按出勤人员权重分摊”时，需要录入分摊权重，所有成员分摊权重的合计必须等于1。
*  组成和成员两个页签没有连动关系，组成和成员分别有自己的使命，组成用于工作量取数后的计件集体的匹配，成员用于计件集体中员工的工资分配，使用场景：将班组1、班组2组成计件集体，但是班组1中的员工A调走去做其他工作，又从班组3中调来员工C，组成了计件集体，则该计件集体的组成包括：班组1、班组2，但是实际算计件工资的时候，是班组1中除了员工A的其他人+班组2的所有人+班组3中的员工C。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|必输，不可重复|
|名称|必输|
|说明|文本|
|部门|参照|
|分摊方式|枚举，默认“所有人均摊”|
|按日分摊|布尔，默认FALSE；FALSE时按月分摊|
|生效|是否生效，默认为“生效”|

组成页签

|栏目|说明|
|---|---|
|业务组织|参照当前组织，单选|
|部门|参照当前组织下部门，单选|
|工作中心|参照所选部门下工作中心，单选，若未选择部门，参照已选组织下工作中心|
|班组|参照所选部门下班组，单选，若未选择部门，参照已选组织下班组|

成员页签

|栏目|说明|
|---|---|
|业务组织|参照当前组织，单选|
|部门|参照当前组织下部门，单选|
|工作中心|单选，筛选上一级|
|班组|参照所选部门下班组，单选，若未选择部门，参照已选组织下班组|
|职务|参照所选组织下职务，单选|
|岗位|参照所选部门下岗位，单选，若未选择部门，参照已选组织下岗位，单选|
|员工编码|取工作中心、班组、职务、岗位下的员工编码并集，支持多选|
|姓名|根据编码带出，不可编辑|
|分摊权重|0-1的数字|

工资分摊方式

|栏目|说明|
|---|---|
|所有人员均摊|根据【计件集体-成员】，取得分摊日期的计件集体成员和数量，工资总额/成员数量，计算每人的工资金额|
|按是否有出勤均摊|根据【计件集体-成员】，取得分摊日期的计件集体成员，再判断计件集体是否有出勤，取得有出勤的成员，基于这些有出勤的成员，按所有人员均摊的规则计算每人的工资金额|
|按出勤时间分摊|根据【计件集体-成员】，取得分摊日期的集体成员，再从员工日工时表中取得这些集体成员在分摊日期的【总工时【，分别按【总工时】的加权平均计算每人的工资金额|
|按人员权重分摊|根据【计件集体-成员】，取得分摊日期的计件集体成员，再按照已录入的【计件集体-成员-分摊权重】，计算每人的工资金额|
|按出勤人员权重分摊|根据【计件集体-成员】，取得分摊日期的集体成员，再根据【员工日工时表】断计件集体成员是否有出勤，取得有出勤的计件集体成员，基于这些有出勤的成员按人员权重分摊规则计算每人的工资金额|

# 操作说明

*  通过点击[计件集体](/detail/e1867a3a9fbf4e058ebbb24e1958dd33)，进入计件集体新增画面，填入所需字段。F
*  计件集体新增画面行-组成页签，在行上点击<新增>，可新增行，可选择计件集体的组成。
*  计件集体新增画面行-组成页签，在行上点击<新增>，可新增行，可选择计件集体的成员，成员至少要有一行，否则无法计算该计件集体的工资，注意：当“分摊方式”选择“按人员权重分摊”或“按出勤人员权重分摊”时，需要在“成员”页签手动录入分摊权重；各成员分摊权重，合计必须等于1。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的计件集体进行查找。
*  点击列表可查看已保存的全部计件集体信息。
