
# 功能描述

计件工资发放申请主要功能是提交计件工资发放申请，审核通过后可生成期初数据。

# 栏目说明

表头字段

|栏目|说明|
|---|---|
|单据类型|必填项，计件工资发放申请单据类型，可手动添加|
|单号|默认自动编号，不可修改|
|日期|必填项，默认当前日期，可修改|
|薪资日历|必填项，取自薪资管理-薪资日历|
|薪资期间|必填项，取自薪资管理-计薪期间|
|工资总额|保存后自动计算得出|
|申请人|必填项，可选择|
|申请状态|默认为开立，审核功能为U9C统一功能|

行字段

|栏目|说明|
|---|---|
|日期|保存后，系统自动填入|
|员工编号|保存后，系统自动填入|
|人员姓名|保存后，系统自动填入|
|计件工作编码|保存后，系统自动填入|
|计件工作名称|保存后，系统自动填入|
|核准金额|保存后，系统自动填入|

注意：当前计薪期间有多少待发放的审核通过的计件工资，就显示几个

# 按钮说明

*  <操作>中<作废>：点击该按钮可作废该单据。
*  <相关功能>中<期末计件工资发放>：点击该按钮可进入期末计件工资发放列表画面，详情请查看[期末计件工资发放](/detail/07fbe0d5a85f46408232072ee79b9c1e)列表画面。

# 操作说明

*  通过点击菜单[计件工资发放申请](/detail/a8d7269afb3944cb919275c901e41a3d)进入计件工资发放申请新增画面，填写表头字段。
*  点击<保存>按钮，保存单据的同时，系统自动筛选出所选期间的所有员工计件工资列表。
*  点击<提交>可提交该表单，等待审核，审核通过后，该表单数据可计入期末吉安工资列表。
*  点击点击<查找>可以对已保存的计件工资发放申请进行查询.
*  点击<列表>可进入计件工资发放申请表页，选择一条数据，可显示已保存的数据，列表支持输出、打印和查询。
*  在计件工资发放申请列表中，勾选一条或多条数据，点击【删除】按钮，可删除记录，一旦被引用不可删除。
*  后续的发薪过程需要到[发薪申请](/detail/a921df1dd8d94c5da7e39065794c886c)中进行，原理是将计件工资作为一个薪资项目，并设置其薪资规则，再在薪资管理中执行发薪动作。
