
# 功能描述

员工日计件工资主要是工资计算过程及计算结果的管理。

# 业务规则

*  按工资计算范围，搜符合条件、已核准的“集体日工作量”单据、“个人日工作量”单据，单据上已经匹配价表、单价，算出每日的工资额。
*  计时工资：按照计件价表和员工日工时，计算计时工资，计时工资=时间*单价*计价系数。
*  员工个人计件工资=工作量*单价*计价系数。
*  集体计件计件工资=（集体工作量*单价*计价系数），再按设置的分配方式，将金额分配给每个员工。
*  按薪资期间，及其他维度汇总计件金额：计件类别、计薪期间、日期、员工编码、员工姓名、计件工作。
*  核准金额逻辑：工资计算后，列表中“调整工资项目、保底工资”允许修改，点击<核准金额>按钮后生效，同时需重新计算核准金额。
*  工资计算结果中的“计件金额”包含扣款金额和非扣款金额，原有版本，扣款金额在工资发放申请中计算，现改为在工资计算中计算。
*  核准金额取值规则：计件/计时工资与保底工资想比较，取较大的一个值。

# 按钮说明

*  <查询>：点击该按钮弹出查询画面，选择查询条件，可按条件查询工资计算结果。
*  <员工工资计算>：点击该按钮显示“员工计件工资计算”弹窗，选择计算条件，可按照条件计算员工计件工资，计件范围非必填，若不选择，表示计算所有符合要求的员工工资。
*  <集体工资计算>：点击该按钮显示“集体计件工资计算”弹窗，选择计算条件，可按照条件计算集体计件工资，计件范围非必填，若不选择，表示计算所有符合要求的员工工资。
*  <核准金额>：勾选工资计算结果（修改调整工资项目、保底工资），点击该按钮，可核准金额，即：列表中“核准金额”重新计算，计算规则参考上述“业务规则-核准金额取值规则”。
*  <集体计件工资查询>:点击该按钮，进入集体计件工资列表画面，可以集体为单位查看员工计件工资。

# 操作说明

*  点击员工日计件工资，进入员工日计件工资列表画面，系统自动弹出“计件工资计算”弹窗，可选择计算条件，计算员工计件工资。
*  勾选员工计件工资计算结果，点击<删除>可以删除员工计件工资数据。
*  在员工计件工资结果列表中可直接修改“调整工资项目”和“保底工资”，修改后，点击底部操作栏的按钮<核准工资>，可校准列表中“核准金额”。
