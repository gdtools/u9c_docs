
# 功能描述

该功能主要是显示员工期末计件工资发放列表，由系统生成。

# 栏目说明

|栏目|说明|
|---|---|
|薪资期间|系统自动生成|
|员工编号|系统自动生成|
|员工名称|系统自动生成|
|计件类别编码|系统自动生成|
|计件类别名称|系统自动生成|
|计件应发工资|系统自动生成|
|计件工作编码|系统自动生成|
|计件工作名称|系统自动生成|

# 按钮说明

*  <查询>：点击该按钮可以对已保存的数据进行查询。

# 操作说明

*  通过点击菜单[期末计件工资发放](/detail/07fbe0d5a85f46408232072ee79b9c1e)进入期末计件工资发放列表画面，列表支持输出和打印。
