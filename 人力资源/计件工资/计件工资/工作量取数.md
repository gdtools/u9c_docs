
# 功能描述

工作量取数通过车间模块的业务单据自动获取计件工作量数据，前提是在计件类别中设置“计件数量取值”对应规则，避免手动录入的繁琐，直接从车间任务汇报单、派工单完工申报单中获取员工的工作量。

# 业务规则

*  按照业务组织，计件工作对应的实体单据、计件日期范围、单据上的部门范围、班组范围、员工范围，抽取来源单据数据，存到来源明细中。空表示全部。
*  根据来源明细上的业务组织、部门、工作中心、班组，匹配“计件集体”，匹配到的，通过抽取业务单据中工作中心、班组、人员的工作量合计，生成“集体日工作量”；根据计件工作的计件要素，汇总汇总生成行记录，如果能匹配上价表，直接匹配，不能匹配到价表，价表为空。
*  其余来源单据，根据“人员”，生成“人员日工作量”。根据计件工作的计件要素，汇总生成行记录，如果能匹配上价表，直接匹配，不能匹配到价表，价表为空。
*  支持重复抽取，如果集体日工作、人员日工作单据已经审核，系统提醒重新生单失败；如果是开立态覆盖原单，重新生成。
*  在工作量取数结果列表中增加字段“是否已生成工作量”，是、否，列表查询中增加该字段，默认查“否”。
*  勾选工作量取数结果，点击<生成工作量>，默认取勾选的数据中计件日期最大的那个（保证当月取数能够生成当月工作量）。

|业务单据|抽取依据|集体工作量匹配依据|员工个人工作量匹配依据|价表匹配依据|
|---|---|---|---|---|
|派工单完工申报单（老车间）|计件工作中定义抽取“派工单完工申报单”|根据派工单完工申报单中“工作中心、班组、人员”的工作量，匹配到计件集体中的工作中心、班组、人员上，抽取的业务数据条数小于等于集体中对应的数据条数，将匹配到的所有工作量合计显示到集体工作量中|根据派工单完工申报单中“人员”的工作量合计，匹配到员工个人工作量，精准匹配，注意：如果人员属于计件集体，优先抽取到集体工作量中|根据计件工作数据中要素的定义，与业务单据中相应字段进行匹配显示|
|任务汇报单（新车间）|计件工作中定义抽取“任务汇报单”|根据任务汇报单中“工作中心、班组、人员”的工作量，匹配到计件集体中的工作中心、班组、人员上，抽取的业务数据条数小于等于集体中对应的数据条数，将匹配到的所有工作量合计显示到集体工作量中|根据任务汇报单中“人员”的工作量合计，匹配到员工个人工作量，精准匹配，注意：如果人员属于计件集体，优先抽取到集体工作量中|根据计件工作数据中要素的定义，与业务单据中相应字段进行匹配显示|

**表格注释：**

数据条数指：工作中心、班组、人员的工作量；

匹配集体工作量时，按照“计件集体-组成”中定义的工作中心、班组进行匹配，计算计件集体中员工工资时，按照“计件集体-成员”中定义的员工进行计算。

# 按钮说明

*  <查询>：点击该按钮可进入工作量取数查询画面，选择查询条件，可查询所需数据。
*  <工作量取数>：点击该按钮可弹出工作量取数条件填写画面，填入取数条件，系统将按照条件从车间业务单据取数。
*  <生成工作量>：选择取数结果，点击该按钮，可生成待审核的工作量数据，包括集体工作量数据和员工工作量数据。

# 操作说明

*  通过点击菜单[工作量取数](/detail/bb45e1f12bdb4891ac2f7b08262dd89c)进入工作量取数结果画面，并自动弹出工作量取数条件框，可根据录入的取数条件自动从车间业务单据中取数。
*  点击<删除>可以删除取数结果，已生成工作量的数据不允许删除。
