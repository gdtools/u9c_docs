
# 功能描述

该功能主要是按照计件类别和计薪期间查询计件集体日计件工资。。

# 栏目说明

|栏目|说明|
|---|---|
|计件类别|系统自动生成|
|记薪期间|系统自动生成|
|计件集体|系统自动生成|
|日期|系统自动生成|
|计件工作|系统自动生成|
|核准金额|系统自动生成|

# 按钮说明

*  <查询>：点击该按钮可进入查询画面，选择查询条件，可按条件查询集体计件工资。

# 操作说明

*  通过点击菜单[集体计件查询](/detail/4a8451e33aee4594b7f9b4dad83166b2)进入集体计件工资列表画面，该列表支持输出和打印。
*  在集体日计件工资列表，双击一条数据可进入集体计件工资明细页面，数据仅可查看不可修改。
