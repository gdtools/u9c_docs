
# 功能描述

集体日工作量是维护某计件集体、某一天、某计件工作的工作量情况。

# 业务规则

*  表体行中明细和任务明细页签，存在对应的关系，可能一对一、也可能一对多，例如：当存在多次入库的情况时，会产生多个入库单，则需要显示多个任务明细，此处一个明细对应多个任务明细；手动添加的明细，无对应的任务明细。
*  任务明细不允许手动录入，为工作量取数后自动带出的数据。
*  集体日工作量支持手工录入、OBA导入、工作量取数。

# 按钮说明

*  <操作>中<审核参数>：点击该按钮可进入单据审核参数设置。
*  <匹配价表>：集体日工作量录入并保存后，点击该按钮可进行价表匹配，匹配到的价表可自动填入明细行数据“计件单价表”中，点击带下划线的计件单价表，可弹窗显示计件单价表表单数据，用于查询具体的价格。
*  <相关功能>中计件工作：点击该按钮可进入计件工作新增画面，详情请查看[计件工作](/detail/032cdc90cd9346a8b4507ae30b6e94d8)新增画面功能。
*  <相关功能>中计件单价表：点击该按钮可进入计件单价表新增画面，详情请查看[计件单价表](/detail/b51234e27fc94dcfa2a5a2711cb477cb)新增画面功能。

# 操作说明

*  点击集体日工作量，进入集体日工作量新增画面，可针对计件工作数据，选择计件集体，并录入集体的工作量数据。
*  明细行支持新增、插入和删除。
*  点击<保存>可以对编辑修改的内容进行保存。
*  保存后，可点击底部操作栏<匹配价表>，系统自动将匹配到的价表显示到明细行数据中。
*  点击<查找>可以对已保存的集体日工作量表进行查找。
*  点击列表可查看已保存的全部集体日工作量表单信息。
