
# 功能描述

计件人员计件单价表可以理解为标准价表（计件单价表）与人员的连接，由于计件单价表里设置的适用对象只是笼统的一个范围，详细的人员和价表的对应关系，在计件人员单价表里可以查看。

计件单价表适用对象页签，设置了适用人员并保存后，对应的计件人员单价表列表会自动生成，另外也可以手动增加一个计件人员单价表。

# 业务规则

*  适用范围内，非计件集体的人员，自动生成“人员计件价表”，如：适用对象中设置“部门”后，该部门下的人员每个人都会自动生成人员单价表。
*  定义了适用“计件集体”，该计件集体所属范围（部门、班组）在此计件工作下使用集体计件，该范围内的员工不再生成“人员计件价表”；
*  计件单价表中适用对象修改并保存后，会自动覆盖计件人员单价表列表中已经存在的数据。
*  计件人员单价表新增画面中，价格种类需与计件单价表“价表明细”中价格种类一致，否则计算员工计件工资时取不到单机表价格。
*  计件人员单价表被引用后不支持删除，未引用的可直接物理删除。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|员工|必填项|
|计件单价表|必填项，选择生效的计件单价表|
|价格种类|必填项|
|是否管理岗位|非必填|
|计价系数|必填项|
|状态|默认勾选生效，可设置生效、失效时间|

# 按钮说明

*  <相关功能>中<计件单价表>：点击该按钮可进入计件单价表新增画面，详情请查看[计件单价表](/detail/b51234e27fc94dcfa2a5a2711cb477cb)新增画面功能。

# 操作说明

*  通过点击菜单[计件集体单价表](/detail/29574879c81a49389443849d30ed427e)，进入计件人员单价表列表画面。
*  在列表中点击<新增>可进入计件人员单价表新增画面，选择员工和已存在生效的计件单价表以及其他需要填写的字段。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的计件单价表进行查找。
