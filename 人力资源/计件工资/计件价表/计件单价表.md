
# 功能描述

计件单价表是针对计件工作的价格设置，根据计件工作影响到价格的计件元素设置。若计件要素未勾选“影响计件价格”，无法设置计件工作数据在此计件要素下的价格。

# 业务规则

*  一旦被引用不可删除，修改影响未来。
*  价表明细：针对已选计件工作，可为不同计件工作数据，设置不同计价项目的价格，即：生产不同的计件工作，价格可能会不同。
*  价表明细：选择计件工作数据后，默认带出所有计件要素。
*  价表明细中计价项目包含：正品、次品、废品、料废、工废，除正品外，其余项目，默认为扣款项。
*  价表明细中价格种类可选择：单价、区间价格，区间价格时，工作量下限为必填。
*  价表明细中定价方式可选择：固定价格、表达式。
*  价表明细中正品：全合格产品。
*  价表明细中次品：有瑕疵产品。
*  价表明细中废品：全不合格产品。
*  价表明细中工废：因机器原因而造成的不合格产品。
*  价表明细中料废：因材料原因而造成的不合格产品。
*  适用对象：选择哪个计件集体或员工适用于该记表。
*  适用对象中选择计件集体，会自动生成计件集体单价表。
*  适用对象中选择组织或部门或班组或职务或岗位，均自动生成这些参数对应的人员单价表。
*  适用对象中计价系数默认为1，可修改，该参数可作为员工工资绩效系数，例如员工A绩效好，在计算工资时，可录入大于1的计价系数。
*  适用对象中宣则是管理岗，职务和岗位二者不能同时为空。
*  适用对象中价格种类为必填项，若此处价格种类与“价表明细”中计价项目不匹配，则无法计算当前人员/集体在该计价项目下的价格。
*  目前价表不支持查看历史记录，为使价表有迹可循，实施方案时，可“创建多个价表+生效日期”的方式实。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|计件组织|默认等于当前登录组织，暂不支持修改|
|编码|必填项|
|名称|必填项|
|计件类别|必填项|
|计件工作|必填项|
|计件属性|根据计件工作自动带出，不可修改|
|币种|必填项|
|状态|同U9C统一规则，同一个生效时间段内，只允许存在一个“计件组织+编码+计件类别+计件工作”|

价表明细页签

|栏目|说明|
|---|---|
|计件工作数据|表体计件工作下的计件工作数据|
|计件要素|计件工作数据自动带出的计件要素，有几个显示几个|
|计价项目|下拉选择正品、次品、废品、工废、料废|
|价格种类|单价、区间价格，若选择单价，工作量上限、工作量下限不可选择，若选择区间价格，可选择工作量上限、工作量下限|
|工作量下限|受价格种类影响，必填项|
|工作量上限|受价格种类影响，非必填，若不填，表示无穷大|
|是否为扣款|表示要扣除的计件工资，为负值，除了正品，其他计价项目默认均为扣款项|
|定价方式|分为固定价格和表达式|
|价格|若为计件工作，定价方式为固定价格时，此处直接录入价格，若为计时工作，此处价格默认为每小时的价格|
|表达式|定价方式为表达式时，此处可设置价格的表达式Fx函数|

适用对象页签

|栏目|说明|
|---|---|
|工作人事组织|必填项|
|业务组织|非必填|
|部门|非必填|
|班组|非必填|
|计件集体|非必填|
|职务|非必填|
|岗位|非必填|
|价格种类|必填项，|
|是否管理岗位|非必填，若为岗位工资，职务和岗位不能同时为空|
|计价系数|必填项，默认为1|

# 操作说明

*  点击计件单价表，进入计件单价表新增画面，填入所需字段。
*  支持批量修改价格，点击“批量修改”，可批量修改价表。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的计件单价表进行查找。
*  点击列表可查看已保存的全部计件单价表信息。
*  计件单价表支持OBA导入。
