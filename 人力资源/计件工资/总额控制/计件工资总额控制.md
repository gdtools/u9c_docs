
# 功能描述

计件工资总额控制主要是控制某一期间内的计件工资限额，若超过额度，在进行计件工资发薪申请中可给出提示。

# 业务规则

*  适用范围内，非计件集体的人员，自动生成“人员计件价表”，如：适用对象中设置“部门”后，该部门下的人员每个人都会自动生成人员单价表。
*  定义了适用“计件集体”，该计件集体所属范围（部门、班组）在此计件工作下使用集体计件，该范围内的员工不再生成“人员计件价表”；
*  计件单价表中适用对象修改并保存后，会自动覆盖计件人员单价表列表中已经存在的数据。
*  计件人员单价表新增画面中，价格种类需与计件单价表“价表明细”中价格种类一致，否则计算员工计件工资时取不到单机表价格。
*  计件人员单价表被引用后不支持删除，未引用的可直接物理删除。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|定额依据|默认为总量，不可修改|
|定额内容|不可录入|
|总额|必填项|
|定额方式|默认为金额，不可修改|
|是否单期间定额|默认不勾选，若勾选，则仅可选择起始期间，不勾选时，可选择起始期间和截止期间|
|薪资日历|必填项，参照薪资管理中已设置的薪资日历|
|起始期间|必填项，参照薪资日历中定义的期间|
|截止期间|非必填项，参照薪资日历中定义的期间|

# 操作说明

*  点击计件工资总额控制，进入计件工资总额控制画面。
*  在表头操作栏点击<新增>可进入计件工资总额控制新增画面，填写需要进行总额控制的数据，主要针对某期间内计件工资发放申请的金额限制。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的计件工资总额控制进行查找。
*  点击<删除>可以删除总额控制，后续计件工资发放申请不受金额限制。
