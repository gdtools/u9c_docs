
# 功能描述

根据招聘计划创建招聘活动，以供后续招聘人员应聘使用。

# 业务规则

*  招聘计划、招聘渠道类型、招聘渠道。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|当前招聘活动所用单据类型|
|单号|当前招聘活动的单号|
|名称|当前招聘活动的名称|
|日期|当前招聘活动的创建日期，只读，默认当前日期|
|执行招聘组织|执行此招聘活动的组织|
|地点|当前招聘活动的地点|
|招聘计划|参考状态为关闭的招聘计划|
|招聘渠道类型|当前招聘活动的招聘渠道类型|
|招聘渠道|招聘活动的的招聘渠道|
|开始日期|当前招聘活动的开始日期|
|结束日期|当前招聘活动的结束日期|
|费用承担组织|当前招聘活动费用的承担组织|
|费用承担部门|当前招聘活动费用的承担部门|
|申请人|当前招聘活动的申请人|
|说明|当前招聘活动的说明内容|
|状态|招聘活动的状态|
|表体||
|序号|只读，10开始，以10为单位递增|
|计划招聘岗位|计划招聘的岗位，实际是参考招聘计划中表体内容|
|招聘组织|招聘的组织|
|招聘业务组织|招聘的业务组织|
|招聘部门|招聘的部门|
|招聘职务|招聘的职务|
|招聘岗位|招聘的岗位|
|剩余招聘人数|招聘剩余的人数，根据招聘计划中招聘人数与招聘活动的招聘人数相减得出|
|招聘人数|此招聘活动计划招的人数|
|招聘申请|此计划招聘岗位对应的招聘申请|
|特殊要求|招聘的特殊要求|
|要求到岗日期|招聘岗要求到岗的日期|

# 操作步骤

*  <操作-作废>：单据在非关闭的状态下点击作废，该单据即作废。
