
# 功能描述

有企业缺编情况，按职务或岗位提交招聘申请。

# 业务规则

*  系统中存在部门、职务、岗位、部门岗位编制。

# 栏目说明

|栏目名称|说明|
|---|---|
|单据类型|当前招聘需求所用单据类型|
|单号|当前招聘申请单据的单号|
|日期|单据的创建日期，只读，默认当前日期|
|招聘需求日期|招聘需求的的日期，默认当前日期，可改|
|需求组织|招聘需求的组织|
|需求业务组织|招聘需求的业务组织|
|需求部门|招聘需求的部门|
|职务|招聘需求的职务|
|岗位|招聘需求的岗位|
|岗位编制|当前招聘的岗位的编制状况、只读|
|在职人数|当前招聘的职务或岗位的在职人数、只读|
|人员性质|招聘人员的性质，枚举：正式、实习生、临时工，可自定义|
|需求数量|此招聘申请需求的人数量|
|特殊要求|招聘人员的特殊要求说明|
|工作地点|当前招聘岗工作的地点|
|要求到岗日期|招聘当前岗要求的到岗日期|
|招聘原因|招聘的原因|
|申请人|当前招聘申请单据的申请人|
|单据状态|当前单据的状态|

# 操作步骤

*  <操作-作废>：单据非关闭状态下，点击作废，即将当前单据作废。
