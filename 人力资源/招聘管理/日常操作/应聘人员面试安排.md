
# 功能描述

指定应聘者的面试方式、面试人员、地点、时间。

# 业务规则

*  应聘登记、招聘组卷。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头|只能查找应聘人员登记信息，没有新建，所以表头栏目都是有应聘登记人员自动带出来。|
|人员|应聘登记人员，参考应聘登记的人员信息|
|证件号码|应聘人员的证件号码，随人员自动带出|
|人员类别|应聘人员的人员类别，随人员自动带出|
|应聘方式|当前应聘人员的应聘方式，随人员自动带出|
|工作意向|应聘人员的工作意向，随人员自动带出|
|推荐人|当前应聘人员的推荐人，随人员自动带出|
|可到岗时间|当前应聘人员的可到岗时间，随人员自动带出|
|实际应聘组织|人员实际想要应聘的组织，随人员自动带出|
|实际应聘业务组织|人员实际想要应聘的业务组织，随人员自动带出|
|实际应聘部门|人员实际想要应聘的部门，随人员自动带出|
|实际应聘职务|人员实际想要应聘的职务，随人员自动带出|
|实际应聘岗位|人员实际想要应聘的岗位，随人员自动带出|
|应聘日期|人员应聘的日期，随人员自动带出|
|备注|当前面试安排的备注信息|
|表体-面试轮次||
|面试轮次|当前面试安排此轮面试的轮次，以1开始，1为单位递增|
|本轮负责人|此轮面试的负责人|
|面试地点|此轮面试的面试地点|
|考试方式|此轮面试的考试方式，枚举：招聘笔试、面试评估、素质测评|
|试卷|此轮面试的试卷，考试方式为招聘笔试时，必填，参考招聘组卷的试卷|
|开始时间|此轮面试的开始时间|
|结束时间|此轮面试的结束时间|
|本轮是否最终结果|此轮面试是否是最终的面试结果|
|面试结果|此轮面试的面试结果|
|表体-面试人||
|面试人|选中某一轮面试。选择本轮面试的面试人，参考已入职人员|
|权重|当前面试人的权重，本轮面试的所有面试人权重之和必须为1|

# 操作步骤

*  一般操作见公共操作说明。
