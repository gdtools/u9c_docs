
# 功能描述

基于岗位缺编情况及招聘申请，制定招聘计划；

基于招聘计划可组织多个招聘活动。

# 业务规则

*  职务、岗位、部门、岗位编制、招聘申请。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|当前招聘计划所用单据类型|
|单号|当前招聘计划的单号|
|名称|当前招聘计划的名称|
|日期|当前招聘计划的创建日期，只读，默认当前日期|
|执行招聘组织|执行此招聘计划的组织|
|招聘目标|当前招聘计划的招聘目标|
|所属年度|当前招聘计划所属年度|
|币种|当前招聘计划费用的币种|
|招聘预算|招聘计划的预算费用|
|负责人|当前招聘计划的负责人|
|开始日期|当前招聘计划的开始日期|
|结束日期|当前招聘计划的结束日期|
|说明|当前招聘计划的说明内容|
|状态|招聘计划的状态|
|表体|当招聘申请不为空时，其他字段根据招聘申请信息自动带出|
|序号|招聘申请的序号，只读，10开始，以10为单位递增|
|招聘申请|参照状态为关闭的招聘申请|
|计划招聘组织|计划招聘的组织|
|计划招聘业务组织|计划招聘的业务组织|
|计划招聘部门|计划招聘的部门|
|计划招聘职务|计划招聘的职务|
|计划招聘岗位|计划招聘的岗位|
|计划招聘人数|计划招聘的人数|
|特殊要求|招聘的特殊要求|
|要求到岗日期|招聘岗要求到岗的日期|

# 操作步骤

*  <操作-作废>：单据在非关闭的状态下点击作废，该单据即作废。
*  <招聘活动>：点击该按钮，弹出招聘活动弹窗，针对此招聘计划作出招聘活动。
