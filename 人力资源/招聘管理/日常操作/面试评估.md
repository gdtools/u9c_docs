
# 功能描述

面试人给应聘人试卷中的填空题、文字题判分，选择题与标准答案对比自动判分；面试人为应聘人打评语，并确定面试结果。

# 业务规则

*  应聘人员面试安排。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|人员|应聘人员，参照相应轮次面试安排的人员信息|
|证件号码|应聘人员的证件号码，随人员自动带出|
|人员类别|应聘人员的人员类别，随人员自动带出|
|应聘方式|当前应聘人员的应聘方式，随人员自动带出|
|面试轮次|当前面试作为第几轮的面试，由相应面试轮次安排自动带出|
|面试地点|当前轮次面试的面试地点，由相应的面试轮次自动带出|
|面试人|此轮面试的负责人，由相应的面试轮次自动带出|
|考试方式|此轮面试的考试方式，自动带出，只能是面试评估|
|试卷|此次面试评估所用试卷，自动带出|
|工作意向|应聘人员的工作意向，随人员自动带出|
|推荐人|当前应聘人员的推荐人，随人员自动带出|
|实际应聘组织|人员实际想要应聘的组织|
|实际应聘业务组织|人员实际想要应聘的业务组织|
|实际应聘部门|人员实际想要应聘的部门|
|实际应聘职务|人员实际想要应聘的职务|
|实际应聘岗位|人员实际想要应聘的岗位|
|应聘日期|人员应聘的日期|
|标准用时|由表体试卷题目的参考标准用时汇总|
|总分值|由表体试卷题目的参考分值汇总|
|开始时间|本轮考试开始时间，由面试安排相应轮次时间自动带出|
|结束时间|本次考试实际结束时间，由提交面试评估结果后的时间自动回显|
|权重|当前面试轮次，当前面试人所占面试结果的权重|
|使用时间（分钟）|由结束时间减去开始时间自动得出|
|本轮是否最终结果|本轮面试是否是最后一轮面试，由相应面试轮次信息自动带出|
|总分|应聘人的总分，由表体各题目的分值汇总而得，没有试题时面试人手动打分|
|评语|本次面试人对于应聘者的评语|
|面试结果|本次面试者对应聘者这次考核的面试结果，枚举：通过、不通过，只有通过后才可进行下一轮面试，即下一轮面试轮次才可参照到此人|
|表体-题目列表||
|序号|试卷中试题的序号（由面试评估试卷自动带出）|
|试题类别|当前面试轮次对应的试卷中试题的实体类别（由面试评估试卷自动带出）|
|题型|当前面试轮次对应的试卷中试题的题型（由面试评估试卷自动带出）|
|内容|当前面试轮次对应的试卷中试题的内容（由面试评估试卷自动带出）|
|标准用时|当前面试轮次对应的试卷中试题的标准用时（由面试评估试卷自动带出）|
|分值|当前面试轮次对应的试卷中试题的分值（由面试评估试卷自动带出）|
|答案|应聘者填入的答案|
|得分|面试人员判给当前题目应聘者所给答案的得分|
|表体-答题明细|**答题明细栏目说明（题目列表栏目说明）**|

# 操作步骤

*  <新增>：点击该按钮，弹出面试评估弹窗，选定应聘人员、面试轮次、面试人员后，应聘人相应轮次的面试评估答题过的员工信息、笔试题目等自动带出。
*  <提交>：只有面试结果为通过，并且提交结果之后才能进行下一轮面试，如果此为最后一轮面试，则之后可进行录用申请。
