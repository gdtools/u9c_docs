
# 功能描述

提交员工录用申请，并在申请中确定员工的部门、职务、岗位、有无试用期、薪资待遇、合同期限等信息；发送给应聘者录用通知，并进行录用情况跟踪。

# 业务规则

*  应聘人员面试安排、应聘者面试结果通过、招聘通知。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|录用申请所用单据类型|
|单号|当前录用申请单据的单号|
|日期|创建单据的日期，默认当前日期|
|入职渠道|应聘者的入职渠道，枚举：应届毕业生、社会人士，同入职单中入职渠道，可自定义|
|应聘人|将要录用的应聘人，参照面试人员安排中通过面试的人员|
|合同期限|应聘人人的合同的期限|
|是否安排试用期|应聘人入职后是否有试用期|
|试用期（月）|应聘人入职后试用期，只有当是否安排试用期为true时可用|
|计划到岗日期|应聘人的计划到岗的日期|
|应聘组织|应聘者应聘的组织，由应聘人自动带出|
|应聘业务组织|应聘者应聘的业务组织，由应聘人自动带出|
|应聘部门|应聘者应聘的部门，由应聘人自动带出|
|应聘职务|应聘者应聘的职务，由应聘人自动带出|
|应聘岗位|应聘者应聘的岗位，由应聘人自动带出|
|员工类别|应聘者入职后的员工类别|
|申请业务组织|申请人的业务组织|
|申请部门|申请人的部门|
|申请人|申请单据的人员，参照已入职人员|
|申请日期|申请录用的日期，默认当前日期|
|单据状态|当前单据当时的状态|
|说明|单据的说明内容|
|表体||
|序号|行的序号，10开始，以10为单位递增|
|薪资项目|应聘人入职后的薪资项目|
|币种|应聘人入职后薪资项目发新的币种|
|薪资项目值|应聘人入职后薪资项目对应的薪资值|

# 操作步骤

*  <操作-作废>：单据在非关闭的状态下点击作废，该单据即作废。
*  <录用通知>：单据审核通过后，将由招聘通知中的模板发给应聘者录用通知信息。
*  <录用情况跟踪>：应聘者录用情况的跟踪，录用申请单据关闭后，点击出现录用人员信息跟踪弹窗。
 
   *  录用申请审核完毕之后才能点击<录用情况跟踪>按钮，并且录用情况跟踪填写完毕之后，点击<确定>按钮，会在[人员管理](/detail/ac1e0519b3a34df6b1a8a8c937a432a2)中自动创建[入职](/detail/8e4cdb1ff8f641a1972212ea46a14013)，若后续想删除录用申请，只能先在入职单中删除入职单，然后再删除录用申请。
