
# 功能描述

基于招聘活动，编辑、发布招聘信息；

基于招聘信息，编辑、发布招聘信息。

# 业务规则

*  招聘活动、招聘申请。

# 栏目说明

招聘活动及招聘申请前面的信息全部是招聘活动或者招聘申请带出来的。

|栏目名称|说明|
|---|---|
|表单-招聘活动||
|招聘活动名称|招聘活动的名称|
|招聘组织|招聘的组织|
|招聘业务组织|招聘的业务组织|
|招聘部门|招聘的部门|
|招聘职务|招聘的职务|
|招聘岗位|招聘的岗位|
|特殊要求|招聘的特殊要求|
|要求到岗日期|招聘岗要求到岗的日期|
|招聘人数|此招聘活动计划招的人数|
|信息发布开始日期|信息发布出去开始招聘的日期|
|信息发布结束日期|信息发布出去结束招聘的日期|
|表单-招聘申请||
|需求组织|招聘需求的组织|
|需求业务组织|招聘需求的业务组织|
|需求部门|招聘需求的部门|
|职务|招聘需求的职务|
|岗位|招聘需求的岗位|
|特殊要求|招聘人员的特殊要求说明|
|工作地点|当前招聘岗工作的地点|
|要求到岗日期|招聘当前岗要求的到岗日期|
|需求数量|此招聘申请需求的人数量|
|信息发布开始日期|发布信息的开始日期|
|信息发布结束日期|发布信息的结束日期|

# 操作步骤

*  <发布>：选中要发布的活动或者招聘申请，将发布出去招聘信息（现在不可用）。
