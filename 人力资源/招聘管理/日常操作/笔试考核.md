
# 功能描述

在选定应聘人员面试轮次以及面试人员后，自动生成相应试卷，并提供答卷时间控制；应聘人在笔试试卷上答卷；在应聘人交卷后，对于选择题自动判。

# 业务规则

*  题库、组卷、应聘人员面试安排。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头|**表头信息不能编辑，由面试人员安排中面试人员信息自动带出**|
|应聘人员|应聘人员，参考面试安排过的人员信息|
|证件号码|应聘人员的证件号码，随人员自动带出|
|人员类别|应聘人员的人员类别，随人员自动带出|
|应聘方式|当前应聘人员的应聘方式，随人员自动带出|
|面试轮次|当前笔试考核作为第几轮的面试，由相应的面试轮次自动带出|
|面试地点|当前轮次面试的面试地点，由相应的面试轮次自动带出|
|面试人|此轮面试的负责人，由相应的面试轮次自动带出|
|考试方式|此轮面试的考试方式，自动带出，只能是招聘笔试|
|试卷|此次笔试考核所用试卷，自动带出|
|工作意向|应聘人员的工作意向，随人员自动带出|
|推荐人|当前应聘人员的推荐人|
|实际应聘组织|人员实际想要应聘的组织|
|实际应聘业务组织|人员实际想要应聘的业务组织|
|实际应聘部门|人员实际想要应聘的部门|
|实际应聘职务|人员实际想要应聘的职务|
|实际应聘岗位|人员实际想要应聘的岗位|
|应聘日期|人员应聘的日期|
|标准用时|由表体试卷题目的参考标准用时汇总|
|总分值|由表体试卷题目的参考分值汇总|
|开始时间|本轮考试开始时间，由面试安排相应轮次时间自动带出|
|结束时间|本次考试实际结束时间，由提交试卷的时间回写|
|权重|当前面试轮次，当前面试人所占面试结果的权重|
|使用时间（分钟）|由结束时间减去开始时间自动得出|
|本轮是否最终结果|本轮面试是否是最后一轮面试，由相应面试轮次信息自动带出|
|表体-题目列表||
|序号|试卷中试题的序号（参考招聘组卷栏目）|
|试题类别|当前面试轮次对应的试卷中试题的实体类别（参考招聘组卷栏目）|
|题型|当前面试轮次对应的试卷中试题的题型（参考招聘组卷栏目）|
|内容|当前面试轮次对应的试卷中试题的内容（参考招聘组卷栏目）|
|标准用时|当前面试轮次对应的试卷中试题的标准用时（参考招聘组卷栏目）|
|分值|当前面试轮次对应的试卷中试题的分值（参考招聘组卷栏目）|
|答案|应聘者填入的答案|
|表体-答题明细|**同题目列表栏目**|

# 操作步骤

*  <新增>：点击该按钮，弹出笔试考核弹窗，选定应聘人员、面试轮次、面试人员后，应聘人相应轮次的面试安排书卷题目等自动带出；
*  <提交>：应聘者答题结束后只有提交试卷才能后续阅卷，点击该按钮提交。
