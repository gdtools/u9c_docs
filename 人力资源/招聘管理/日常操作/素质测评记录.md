
# 功能描述

记录应聘人被评定的素质指标等级。

# 业务规则

*  应聘登记、应聘人员面试安排。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|应聘人员|应聘人员，参考应聘登记人员信息|
|证件号码|应聘人员的证件号码，随人员自动带出|
|人员类别|应聘人员的人员类别，随人员自动带出|
|应聘方式|当前应聘人员的应聘方式，随人员自动带出|
|应聘日期|应聘人员的应聘日期，随人员自动带出|
|工作意向|应聘人员的工作意向，随人员自动带出|
|推荐人|当前应聘人员的推荐人，随人员自动带出|
|表体|参考素质测评中素质测评明细栏目说明|

# 操作步骤

*  一般操作见公共操作说明。
