
# 功能描述

定义应聘者在应聘过程中不同阶段的通知模板，例如：收到应聘登记表通知模板、面试通知模板、录取通知模板、拒绝通知等，系统预置的不满足需求还可自己增加，后续系统将按定义好的模板给应聘者发送消息。

# 栏目说明

|栏目名称|说明|
|---|---|
|编码|定义招聘通知的编码|
|名称|定义招聘通知的名称|
|通知类型|指定此通知模板的通知类型|
|标题|定义此招聘通知的标题|
|内容|定义此招聘通知的模板内容|
|有效性|指定此招聘通知是否有效|
|生效日期|定义此招聘通知的生效日期|
|失效日期|定义此招聘通知的失效日期|
