
# 功能描述

基于招聘题库手工创建笔试试卷、面试评估表；对于现场随机自动组卷方案指定组卷规则。

# 业务规则

*  招聘题库中足够符合条件的试题

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|定义试卷模板的编码|
|名称|定义当前试卷模板的名称|
|用途|指定当前试卷模板生成的试卷的用途，分为：招聘笔试、面试评估、素质测评|
|有效性|当前试卷模板是否有效|
|生效日期|当前试卷模板的生效日期|
|失效日期|当前试卷模板的失效日期|
|表单-题目类别||
|试题类别|此试卷模板中包含的试题类别，同题库中的类别，参考题库中类别的定义|
|题型|当前试题类别下的题型，枚举，同题库中题型|
|最低难度系数|当前试题类别、题型下试题的最低难度系数|
|最高难度系数|当前试题类别、题型下试题的最高难度系数|
|最低分值|当前试题类别、题型下试题的最低分制|
|最高分值|当前试题类别、题型下试题的最高分值|
|题数|当前试题组卷中符合上述条件的试题的个数|

# 操作步骤

*  <生成试卷>：根据当前试卷模板定义的规则随机抽取试题组成试卷，生成试卷在招聘组卷中显示，以提供面试者所用的试卷。
