
# 功能描述

基于招聘题库手工创建笔试试卷、面试评估表。

# 业务规则

*  招聘题库中足够的题目。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|定义招聘组卷的编码|
|名称|定义当前招聘组卷的名称|
|用途|指定当前组卷的用途，分为：招聘笔试、面试评估、素质测评|
|标准用时|说明此组卷的标准参考用时，只读，由组卷表体所有题目的标准用时汇总而得|
|总分值|说明此组卷的总分值，只读，由组卷表体所有题目的分值汇总而得|
|有效性|当前组卷是否有效|
|生效日期|当前组卷的生效日期|
|失效日期|当前组卷的失效日期|
|表单-题目类别||
|序号|当前组卷中题目的序号，只读，以10开头，10为单位递增|
|试题类别|此题目的试题类别，同题库中的类别，参考题库中类别的定义|
|试题|选择试题，参考题库中的试题，在前一项试题类别中过滤选择|
|标准用时|当前题目的标准用时，由题库中试题定义的标准用时带来|
|分值|当前题目的分值，由题库中试题定义的分值带来|

# 操作步骤

*  一般操作见公共操作说明。
