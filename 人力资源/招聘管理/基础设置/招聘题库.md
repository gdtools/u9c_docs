
# 功能描述

定义笔试测试题、面试评估题；并制定题目的使用范围；只能用此题库内容组成试卷，为后续给应聘者做笔试或者面试试卷做参考。

# 栏目说明

|栏目名称|说明|
|---|---|
|表单||
|用途|指定当前题目的用途，分别为：招聘笔试、面试评估、素质测评|
|编码|定义当前题目的编码|
|类别|定义当前题目的类别，用户可自行创建|
|题型|指定当前题目的题型，分为：单选、多选、填空、文字|
|内容|当前题目的内容|
|答案|当前题目的标准答案|
|分值|当前题目的分制|
|难度系数|当前题目的难度系数，分为1-5等五个等级，|
|标准用时（分钟）|当前题目作答的标准参考用时|
|来源|当前题目的来源，分别为：自主命题、网络、其他|
|入库日期|当前题目的入库日期|
|生效|当前题目是否有效|
|生效日期|当前题目的生效日期|
|失效日期|当前题目的失效日期|
|表单-题目类别||
|编码|指定当前题目类别的编码|
|名称|定义当前题目类别的名称|
|说明|当前题目类别的说明内容|
|生效|当前题目类别是否有效|
|生效日期|当前题目类别的生效日期|
|失效日期|当前题目类别的失效日期|
