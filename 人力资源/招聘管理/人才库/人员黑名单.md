
# 功能描述

编辑维护黑名单人员，只可维护未入职的人员。

# 业务规则

*  存在人员信息档案。

# 栏目说明

|栏目名称|说明|
|---|---|
|人员|加入黑名单的人员|
|证件号码|加入黑名单人员的证件号码，只读，由人员信息回显|
|性别|加入黑名单人员的性别，只读，由人员信息回显|
|出生日期|加入黑名单人员的出生日期，只读，由人员信息回显|
|婚姻状况|加入黑名单人员的婚姻状况，只读，由人员信息回显|
|户籍|加入黑名单人员的户籍，只读，由人员信息回显|
|加入原因|加入黑名单的原因|
|录入单位|将此人员加入黑名单的组织单位|
|录入日期|加入黑名单的录入日期|
|开始日期|开始进入黑名单的日期，此日期开始不能进行人员的异动|
|结束日期|此人员黑名单失效的日期，此日期之后可进行人员的入职等异动|
|备注|黑名单的备注说明内容|

# 操作步骤

*  一般操作见公共操作说明。
