
# 功能描述

维护内部、外部人才信息；

维护人才的简历及以往应聘信息；

筛选人员参加招聘面试。

# 业务规则

*  定义类型为人员的联系对象；定义国家/地区档案；定义地址档案；定义血型代码；定义宗教代码；定义健康状况代码；定义婚姻状况代码；定义政治面貌代码；定义社会关系代码；定义奖励类型代码；定义惩罚类型代码；定义HR基础档案，含学历、学位、专业、专业技术职务；
*  定义人才库维护模版：注意：人才库模版可以从系统预置的实体字段中以及用户自定义扩展的实体字段中选择，并且调整显示的位置，进行页签的分组。

# 栏目说明

人员基本信息、学历学位、专业技术职务、工作履历、职业资格、教育培训、证件信息、联系人、家庭成员及社会关系、离退休人员返聘信息、奖惩记录等基础档案参照人员基本信息的内容及栏目说明，这里只介绍人才特有的栏目及功能

|栏目名称|说明|
|---|---|
|表单-人才信息||
|人才来源|该人员的人才来源，枚举：内部、外部，可自定义|
|人才级别|人员的人才级别，枚举：普通、中级、高级，可自定义||
|入库日期|人员进入人才库的日期||
|推荐人|推荐此人才的人员，参照人员基本信息||
|应聘状态|该人员的应聘状态，随人员的应聘进行程度改变，只读||
|表行-应聘信息||
|应聘日期|当前人员的应聘日期|
|应聘组织|当前人员的应聘组织|
|应聘职务|当前人员的应聘的职务|
|应聘岗位|当前人员应聘的岗位|
|应聘状态|当前人员的应聘状态|
|应聘部门|当前人员应聘的部门|

# 按钮说明

*  <分组>：参考人员基本信息中的分组说明；
*  <操作>：参考人员基本信息中的操作说明；
*  <加入黑名单>：选中人员，点击加入黑名单，可将不合格人才加入黑名单，这样人员入职便可有检验，加入黑名单人员不可入职。
