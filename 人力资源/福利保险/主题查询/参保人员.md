
# 功能描述

 基于当前登录日期，查询当前登录薪资中心负责福利缴交的各工作人事组织中：参保人员的福利保险档案，及其福利保险缴费基数、福利保险缴交记录。

# 业务规则

*  系统启用福利保险模块

# 栏目说明

参保人员－查询方案

|栏目|说明|
|---|---|
|福利保险类别|查询指定福利保险类别下的参保人员|
|工作人事组织|查询指定工作人事组织下的参保人员|
|现任业务组织|查询指定业务组织下的参保人员|
|现任部门|查询指定部门下的参保人员|
|员工类别|查询指定员工类别下的参保人员|
|缴费人员类别|查询指定缴费人员类别下的参保人员|

# 按钮说明

*  <[参保人员查询操作](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)>：点击<福利保险－参保人员>，进入参保人员和缴费基数、缴交记录画面。在参保人员列表，双击选定的员工行后，缴费基数和缴交记录列表中将显示该行员工的信息。
