
# 功能描述

 基于当前登录日期，查询当前登录薪资中心负责福利缴交的各工作人事组织中：参保变动人员，及其福利保险缴费基数、福利保险变动情况、福利保险缴交记录。

# 业务规则

*  系统启用福利保险模块。

# 栏目说明

参保人员变动情况－查询方案

|栏目|说明|
|---|---|
|福利保险类别|指定查询的福利保险类别|
|变动日期|指定查询的变动日期范围|
|变动原因|指定查询的变动原因|
|工作人事组织|指定查询的工作人事组织|
|现任业务组织|指定查询的业务组织，按员工最新主任职查询|
|现任部门|指定查询的部门，按员工最新主任职查询|
|员工类别|指定查询的员工类别|
|缴费人员类别|指定查询的缴费人员类别|

# 按钮说明

*  <参保人员变动查询操作>：点击<福利保险-参保人员变动情况>，进入参保变动人员和缴交记录画面。在参保变动人员列表，双击选定的员工行后，缴交记录列表中将显示该行员工的信息。如需查看该员工的其他信息，可点击缴费基数、变动情况按钮，以分别调出缴费基数、变动情况画面。
