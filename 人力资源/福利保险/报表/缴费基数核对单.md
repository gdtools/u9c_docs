
# 功能描述

输出登录人事组织及其下级组织员工的缴费基数核对单；

在登录人事组织为薪资中心时，输出其为各工作人事组织进行福利缴交的员工的缴费基数核对单。

# 业务规则

*  系统启用福利保险模块。

# 栏目说明

缴费基数核对单－查询方案

|栏目|说明|
|---|---|
|统计范围|提供二种选择：1、按薪资中心统计2、按人事组织统计|
|人事组织|选择查询的工作人事组织。统计范围为按薪资中心统计时：默认当前登录的人事组织为薪资中心，在与其有缴交关系的人事组织中选择。统计范围为按人事组织统计时：在当前登录的人事组织，及其下级人事组织中选择。|
|任职组织|选择查询的任职组织|
|部门|选择查询的部门|
|福利保险类别|选择查询的福利保险类别|
|期间范围|指定期间范围的选择方式本月：指当前系统日期所在的年月|
|年|指定查询的年度此条件项只有在期间范围为指定年月时，才能使用|
|月份|指定查询的月份此条件项只有在期间范围为指定年月时，才能使用|

缴费基数核对单－查询结果

|栏目|说明|
|---|---|
|人事组织|员工的工作人事组织|
|任职组织|员工的任职组织|
|部门|员工的任职部门|
|姓名|员工姓名|
|员工编号|显示员工编号|
|福利账号|员工在当前福利保险类别下的福利账号|
|性别|员工性别|
|出生日期|员工出生日期|
|缴费基数|员工在当前福利保险类别、当前月份下的缴费基数|
|单位缴交比例|员工在当前福利保险类别、当前月份下的单位缴交比例|
|单位划转比例|员工在当前福利保险类别、当前月份下的单位划转比例|
|个人缴交比例|员工在当前福利保险类别、当前月份下的个人缴交比例|
|单位缴费|员工在当前福利保险类别、当前月份下的单位缴费|
|单位划转|员工在当前福利保险类别、当前月份下的单位划转额|
|个人缴费|员工在当前福利保险类别、当前月份下的个人缴费|
|缴费合计|为单位缴费与个人缴费之和|

# 操作说明

*  缴费基数核对单查询操作：点击<福利保险-福利保险缴费基数核对单>，进入核对单画面,在查询方案对话框，指定查询条件后，显示查询出的缴费基数核对单。
