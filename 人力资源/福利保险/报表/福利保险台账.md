
# 功能描述

输出登录人事组织及其下级组织，在指定福利保险类别、指定年月下的福利保险台账；

在登录人事组织为薪资中心时，输出其为各工作人事组织进行福利缴交的员工，在指定福利保险类别、指定年月下的福利保险台账。

# 业务规则

*  系统启用福利保险模块

# 栏目说明

福利保险台账－查询方案

|栏目|说明|
|---|---|
|统计范围|提供二种选择：1、按薪资中心统计2、按人事组织统计|
|人事组织|选择查询的工作人事组织。统计范围为按薪资中心统计时：默认当前登录的人事组织为薪资中心，在与其有缴交关系的人事组织中选择。统计范围为按人事组织统计时：在当前登录的人事组织，及其下级人事组织中选择。|
|任职组织|选择查询的任职组织|
|部门|选择查询的部门|
|年|指定查询的开始年此条件项只有在期间范围为指定年月时，才能使用|
|月|指定查询的开始月此条件项只有在期间范围为指定年月时，才能使用|
|结算组织|指定结算组织|
|福利保险类别|选择查询的福利保险类别|
|单据类型|指定单据类型|
|员工类别|指定员工类别|
