
# 功能描述

输出登录人事组织及其下级组织员工在各结算组织的福利保险结算情况；

在登录人事组织为薪资中心时，输出其为各工作人事组织进行福利缴交的员工在各结算组织的结算情况。

# 栏目说明

福利保险结算表－查询方案

|栏目|说明|
|---|---|
|统计范围|提供二种选择：1、按薪资中心统计2、按人事组织统计|
|人事组织|选择查询的工作人事组织。统计范围为按薪资中心统计时：默认当前登录的人事组织为薪资中心，在与其有缴交关系的人事组织中选择。统计范围为按人事组织统计时：在当前登录的人事组织，及其下级人事组织中选择。|
|任职组织|选择查询的任职组织|
|部门|选择查询的部门|
|福利保险类别|选择查询的福利保险类别|
|期间范围|指定期间范围的选择方式本月：指当前系统日期所在的年月|
|年|指定查询的年度此条件项只有在期间范围为指定年月时，才能使用|
|月|指定查询的月份此条件项只有在期间范围为指定年月时，才能使用|
|结算组织|选择查询的结算组织|
|状态|查询指定福利缴交单状态下的员工数据|

福利保险结算表－查询结果

|栏目|说明|
|---|---|
|人事组织|员工的工作人事组织|
|结算组织|员工福利缴费的结算组织|
|结算业务组织|员工福利缴费的结算业务组织|
|结算部门|员工福利缴费的结算部门|
|福利保险类别|员工的福利保险类别|
|缴交年月|员工福利缴费的缴交年月|
|任职组织|员工的任职组织|
|部门|员工的任职部门|
|姓名|员工姓名|
|员工编号|显示员工编号|
|福利账号|员工在当前福利保险类别下的福利账号|
|缴费基数|员工在当前福利保险类别、当前月份下的缴费基数|
|单位缴交比例|员工在当前福利保险类别、当前月份下的单位缴交比例|
|单位划转比例|员工在当前福利保险类别、当前月份下的单位划转比例|
|个人缴交比例|员工在当前福利保险类别、当前月份下的个人缴交比例|
|单位缴费|员工在当前福利保险类别、当前月份下的单位缴费|
|单位划转|员工在当前福利保险类别、当前月份下的单位划转额|
|个人缴费|员工在当前福利保险类别、当前月份下的个人缴费|
|补缴开始年月|员工在当前福利保险类别、当前月份下的补缴开始年月|
|补缴截止年月|员工在当前福利保险类别、当前月份下的补缴截止年月|
|单位补缴|员工在当前福利保险类别、当前月份下的单位补缴金额|
|单位补缴划转|员工在当前福利保险类别、当前月份下的单位补缴划转金额|
|个人补缴|员工在当前福利保险类别、当前月份下的个人补缴金额|
|单位缴费合计|员工在当前福利保险类别、当前月份下的单位缴费与单位补缴合计|
|个人缴费合计|员工在当前福利保险类别、当前月份下的个人缴费与个人补缴合计|
|币种|为单位缴费与个人缴费之和|

# 操作说明

*  福利保险结算表查询操作：点击<福利保险-福利保险结算表>，进入结算表画面,在查询方案对话框，指定查询条件后，显示查询出的福利保险结算表。
