
# 功能描述

输出登录人事组织及其下级组织员工在各结算组织的福利保险结算情况；

在登录人事组织为薪资中心时，输出其为各工作人事组织进行福利缴交的员工在各结算组织的结算情况。

# 业务规则

*  系统启用福利保险模块

# 栏目说明

缴交汇总表－查询方案

|栏目|说明|
|---|---|
|统计范围|提供二种选择：1、按薪资中心统计2、按人事组织统计|
|人事组织|选择查询的工作人事组织。统计范围为按薪资中心统计时：默认当前登录的人事组织为薪资中心，在与其有缴交关系的人事组织中选择。统计范围为按人事组织统计时：在当前登录的人事组织，及其下级人事组织中选择。|
|任职组织|选择查询的任职组织|
|部门|选择查询的部门|
|员工|选择查询的员工|
|福利保险类别|选择查询的福利保险类别|
|期间范围|指定期间范围的选择方式本月：指当前系统日期所在的年月|
|开始年|指定查询的开始年此条件项只有在期间范围为指定年月时，才能使用|
|开始月|指定查询的开始月此条件项只有在期间范围为指定年月时，才能使用|
|截止年|指定查询的截止年此条件项只有在期间范围为指定年月时，才能使用|
|截止月|指定查询的截止月此条件项只有在期间范围为指定年月时，才能使用|
|状态|查询指定福利缴交单状态下的员工数据|

缴交汇总表－查询结果

|栏目|说明|
|---|---|
|人事组织|员工的工作人事组织|
|任职组织|员工的任职组织|
|部门|员工的任职部门|
|姓名|员工姓名|
|员工编号|员工的员工编号|
|职务|员工的职务|
|岗位|员工的岗位|
|人员类别|员工的人员类别|
|福利账号|员工在当前福利保险类别下的福利账号|
|单位缴费|员工在当前福利保险类别、指定时间段下的单位缴费与单位补缴之和|
|单位划转|员工在当前福利保险类别、当前月份下的单位划转与单位补缴划转之和|
|个人缴费|员工在当前福利保险类别、当前月份下的个人缴费与个人补缴之和|

# 操作说明

*  缴交汇总表查询操作：点击<福利保险-缴交汇总表>，进入汇总表画面,在查询方案对话框，指定查询条件后，显示查询出的缴交汇总表。
