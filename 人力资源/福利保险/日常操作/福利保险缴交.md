
# 功能描述

按月为员工缴交以及补缴福利保险费用，本功能由负责员工福利保险的薪资中心使用。

# 业务规则

*  定义福利保险类别
*  设置组织缴费规则
*  设置福利保险档案
*  设置单据类型

# 按钮说明

*  <增加人员>：在申请单状态为开立时，通过此功能可实现缴交人员的批量增加。

操作步骤如下：

1）点击增加人员按钮，弹出增加人员对话框。在对话框中，可以按任职组织、部门、职务、岗位实现批量增加人员，也可以直接选择员工增加。

2）在对话框中，点击确定按钮，将符合条件的人员添加到单据表体中，同时自动生成员工的任职信息、缴费金额。

[批量增加栏目](http://10.16.2.212/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|按照指定员工批增|是：需要在员工条件项选择要增加的员工；否：通过选择任职组织、部门、职务、岗位，指定批增的员工范围。|
|任职组织|按指定的任职组织批增：当前福利保险类别下、在当前缴费年月、状态为活动的人员。|
|部门|按指定的部门批增：当前福利保险类别下、在当前缴费年月、状态为活动的人员。|
|包含下级部门|指定批增时，是否包含下级部门。|
|职务|按指定的职务批增：当前福利保险类别下、在当前缴费年月、状态为活动的人员。|
|岗位|按指定的岗位批增：当前福利保险类别下、在当前缴费年月、状态为活动的人员。|
|人员类别|按指定的人员类别批增：当前福利保险类别下、在当前缴费年月、状态为活动的人员。|
|员工|选择缴费人员。|

*  [删除人员](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)

在申请单状态为开立时，通过此功能可从单据表体中批量删除人员。

操作步骤：

1）选中单据表体中的行，可以选择多行。

2）点击删除人员按钮，从单据表体中删除人员。

*  [福利补缴](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)

在申请单状态为开立时，为单据中的员工计算生成补缴金额。

操作步骤：

1）在单据表体中选中要补缴的行，可以选择多行。

2）点击福利补缴按钮，弹出福利补缴对话框。

3）在对话框中，指定补交的起、止时间段后，点击确定按钮，为选中的人员计算补缴金额并显示到单据表体中。

[福利补缴栏目](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|补交开始年|录入补交开始年|
|补交开始月|录入补交开始月|
|补交结束年|录入补交结束年|
|补交结束月|录入补交结束月|

*  <重新计算>：增加人员后，会将福利保险档案中的数据带入，在福利保险缴交页面可以修改，修改后，需要计算。
*  <[操作-执行](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)>：在申请单状态为核准状态时，通过此功能关闭福利缴交单。

操作前提：

1）单据类型的流程不是核准后自动执行。

2）福利缴交单状态为已审核。

操作步骤：

1）点击查找按钮，找出要执行的申请单。

2）点击执行按钮，申请单状态由已核准转变为关闭。

*  <[操作-取消执行](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)>：在申请单状态为关闭时，通过此功能将已关闭的福利缴交单重置为已核准。

操作步骤：

1）点击查找按钮，找出已关闭的申请单。

2）点击取消执行按钮，申请单状态由关闭转变为已核准。

*  <[操作-作废](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)>：

在申请单状态为开立、核准中、已核准时，可作废。

操作步骤：

1）点击查找按钮，找出要作废的申请单。

2）点击作废按钮，申请单状态转变为作废。

*  <[操作-表格输出](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)>：U9C公共功能。
*  <[后续处理-福利结算单](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)>：在提交福利缴交单时，系统将按员工福利的结算组织，分别汇总生成各结算组织下的结算单。通过本功能可以查看当前单据生成的福利结算单。

操作前提：福利缴交单已经提交

操作步骤：

1）点击福利结算单按钮，弹出福利结算单对话框,显示当前缴交单生成的结算单。

2）在对话框中，点击交易分录按钮，进入交易分录查找界面,显示当前单据生成的交易分录。参见公共:[交易分录](http://10.16.226.67/U9C/help/zh-CN/Content/PO/PO.AAI.TranEntryMain.htm)。


生成交易分录的前提：

1）参数设置中是否生成AAI分录=是

2）已设置交易分录模版、预设科目影响因素、会计科目模版
