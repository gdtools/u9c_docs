
# 功能描述

各人事归属中心负责实现员工的开户、转入、转出、封存、启封、销户，记录员工在各年度的缴费基数。

# 业务规则

*  定义福利保险类别
*  设置组织缴费规则

# 按钮说明

*  <计算缴交金额>：用户首先需要在缴费基数记录页签选中一行，再点击<计算缴交金额>按钮，系统将为该行计算生成上年月平均工资、缴费基数、单位缴交比例、单位缴费、个人缴交比例、个人缴费。也可在修改该行的缴费基数值后，点击计算缴交金额按钮，计算生成其它项目值。
*  <相关功能>下<组织缴费规则》：点击该按钮，可导航到《人力资源:福利保险:基础操作:[组织缴费规则](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/HR.BEN.BenParamByOrg.htm)》功能节点。
*  <批量增加档案>:点击该按钮，弹出批量增加员工福利档案窗口，选择福利保险大类等信息，实现批量增加。
*  <批量账号变动>:点击该按钮，弹出批量账户变动窗口，选择需要变动的员工等信息，实现批量账户变动。
