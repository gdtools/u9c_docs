
# 功能描述

本功能节点主要是将各福利保险结算单生成的交易分录转到总账系统中，生成对应的凭证。主要功能如下:

*  将福利保险的交易分录转入总账生成记账凭证
*  选择是否合并生单
*  设定合并生单的合并规则
*  联查交易分录相关的总账凭证和业务单据

# 业务规则

*  总账系统启用（必做）
*  总账系统账簿、凭证等相关设置完成（必做）
*  交易分录已经生成（必做）
*  定义转总账规则
*  定义调度方案

# 栏目说明

转总账—批量转总账画面

|栏目|说明|
|---|---|
|方案选择|选择已保存的查询方案，对符合其查询条件的单据执行批量转总账。|
|合并制单|生成凭证时是否合并制单，选择是时，将选中的单据的交易分录按照合并规则生成到一张凭证中。|
|单据类型|选择是时，以单据类型作为合并制单条件，相同单据类型的单据的交易分录合并制单，否则不作为合并条件。|
|工作人事组织|选择是时，以工作人事组织作为合并制单条件，相同组织的单据的交易分录合并制单，否则不作为合并条件。|
|福利保险类别|选择是时，以福利保险类别作为合并制单条件，相同类别的单据的交易分录合并制单，否则不作为合并条件。|
|福利保险币种|选择是时，以福利保险币种作为合并制单条件，相同币种的单据的交易分录合并制单，否则不作为合并条件。|
|缴交年|选择是时，以缴交年作为合并制单条件，相同缴交年的单据的交易分录合并制单，否则不作为合并条件。|
|缴交月|选择是时，以缴交月作为合并制单条件，相同缴交月的单据的交易分录合并制单，否则不作为合并条件。|
|缴交日期|选择是时，以缴交日期作为合并制单条件，相同缴交日期的单据的交易分录合并制单，否则不作为合并条件。|

# 按钮说明

*  <[批量转总账](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)>：

操作步骤：

1）在转总账画面中，点击‘批量转总账’按钮，弹出批量转总账画面。

2）在批量转总账画面中选择方案及合并制单的条件，点击‘确定’按钮，系统自动在总账主账簿中生成相应的凭证。

*  <[生成凭证](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)>：

操作步骤：

1）在转总账主画面点击<查询>按钮，弹出查询对话框；

2）在转总账-查询对话框输入查询条件，点击确定按钮，返回转总账界面后显示查询出动的单据；

3）在转总账画面中，选择需要转总账的单据，点击<生成凭证>按钮，弹出生成凭证画面。

4）在生成凭证画面中选择合并制单的条件，点击<确定>按钮，系统自动在总账主账簿中生成相应的凭证。

*  <[删除凭证](http://10.16.226.67/U9C/help/zh-CN/Content/HR/BEN/Function/javascript:void(0);)>：

操作前提:

1）单据已生成凭证

2）单据中的会计期间未结账

3）删除主账簿凭证时，凭证未审核

操作步骤：

点击<福利保险-转总账>按钮，进入转总账画面。

具体步骤如下所示：

1）在转总账主画面点击<查询>按钮，弹出查询对话框；

2）在转总账-查询对话框输入查找条件，选择<已转总账=是>，点击确定按钮，返回转总账界面；

3）在转总账画面中，选择需要删除凭证的单据，点击<删除凭证>按钮，系统自动将单据生成的凭证删除。
