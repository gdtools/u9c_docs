
# 功能描述

支持人事中心设置本组织在各福利保险类别，在各省/自治区、市、区县，各年度下的缴费基数、单位缴费、单位划转、个人缴费规则。

# 业务规则

*  定义福利保险类别

# 栏目说明

组织缴费规则—表头

|栏目|说明|
|---|---|
|组织|本项目用于显示当前画面中缴费规则所属的人事中心，用户不可编辑；在新增时，默认为当前登录的人事中心。|
|福利保险类别|指定需要定义缴费规则的福利保险类别、省/自治区、市、区县、开始年月、结束年月。参照福利保险类别档案录入；如果还没有建立需要的福利保险类别，可以点击本项下划线，弹出设置画面，在线新增福利保险类别。|
|省/自治区|取自福利保险类别参照，用户不可编辑。|
|市|取自福利保险类别参照，用户不可编辑。|
|区县|取自福利保险类别参照，用户不可编辑。|
|开始年|取自福利保险类别参照，用户不可编辑。|
|开始月|取自福利保险类别参照，用户不可编辑。|
|结束年|取自福利保险类别参照，用户不可编辑。|
|结束月|取自福利保险类别参照，用户不可编辑。|
|缴费基数下限|取自福利保险类别参照，用户不可编辑。|
|缴费基数上限|取自福利保险类别参照，用户不可编辑。|
|上年工资表达式|基于公式编辑器，编辑当前组织下，所有员工的上年工资计算表达式。|
|开户银行|基于银行档案参照，选择银行。如果还没有建立需要的银行，可以点击本项下划线，弹出设置画面，在线新增银行档案。|
|单位账号|基于银行账号档案参照，选择银行账号。如果还没有建立需要的银行账号，可以点击本项下划线，弹出设置画面，在线新增银行账号档案。|

组织缴费规则—表体

|栏目|说明|
|---|---|
|条件表达式|基于条件表达式编辑器，编辑本行缴费规则适用的员工范围。如指定35岁以下员工，条件表达式为：人员基本信息.年龄 < 35|
|缴费基数取值方式|计算员工在当前省/自治区、市、区县，年度下的缴费基数，有三种方式：1、上年月平均工资2、上年月平均工资 * 比例3、定额|
|缴费基数比例|缴费基数取值方式为“上年月平均工资 * 比例”时，本项目可用；否则：不可用；|
|缴费基数金额|缴费基数取值方式为“定额”时，本项目可用；否则：不可用；|
|单位缴费取值方式|计算员工在当前省/自治区、市、区县，年度下的单位缴费，有三种方式：1、比例2、定额3、比例 + 定额|
|单位缴费比例|单位缴费取值方式为“比例、比例 + 定额”时，本项目可用；否则：不可用；|
|单位缴费金额|单位缴费取值方式为“定额、比例 + 定额”时，本项目可用；否则：不可用；|
|个人缴费取值方式|计算员工在当前省/自治区、市、区县，年度下的个人缴费，有三种方式：1、比例2、定额3、比例 + 定额|
|个人缴费比例|个人缴费取值方式为“比例、比例 + 定额”时，本项目可用；否则：不可用；|
|个人缴费金额|个人缴费取值方式为“定额、比例 + 定额”时，本项目可用；否则：不可用；|

# 按钮说明

*  <批量增加缴费基数>：点击该按钮，系统将为当前福利保险类别下、当前省/自治区、市、区县下的员工福利保险档案，批量增加当前年度下的缴费规则。
*  一般操作见公共操作说明。
