
# 功能描述

基于绩效指标，查询各个考核对象的考评结果，进行分析绩效指标间的对比分析和趋势分析，查看考评中各个指标的详细打分情况。

# 业务规则

*  系统启用绩效考核模块。

# 栏目说明

|栏目名称|说明|
|---|---|
|绩效期间|查询指定绩效期间的绩效指标打分情况|
|考评单元|查询指定考评单元的绩效指标打分情况，前提某个绩效期间的考评单元|
|绩效指标|查询指定绩效指标的绩效指标打分情况，前提某个考评单元的绩效指标|
|部门|查询指定部门的绩效指标打分情况|
|现任职务|查询指定现任职务的员工的绩效指标打分情况|
|现任岗位|查询指定现任岗位的员工的绩效指标打分情况|
|员工|查询指定员工的绩效指标打分情况|

**操作说明**

*  <查询>：点击该按钮，输入查询条件，可查询符合当前条件的绩效指标得分数据；
*  <比较分析图>：根据当前选择的绩效指标得分数据，可以点击<比较分析图>按钮、<趋势分析图>按钮得到当前员工各项指标或者各个期间同一指标的分析图；
*  <明细打分>：根据当前选择的绩效指标得分数据，可以点击<明细打分>按钮，查看各考评人对当前绩效指标的打分情况。
