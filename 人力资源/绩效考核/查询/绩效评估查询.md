
# 功能描述

查看人事、培训建议的绩效评估结果及其跟踪情况。

# 业务规则

*  系统启用绩效考核模块。

# 栏目说明

|栏目名称|说明|
|---|---|
|期间类型|查询指定期间类型的绩效评估结果跟踪情况，分为：年、半年、季、月、周、日；必填|
|绩效期间从|查询指定范围绩效期间的起始期间绩效评估结果跟踪情况，必填|
|到|查询指定范围绩效期间的末期间绩效评估结果跟踪情况，必填|
|考评单元|查询指定绩效期间的考评单元的绩效评估结果跟踪情况|
|考评对象类型|查询指定绩效期间考评单元的考评对象类型的绩效评估结果跟踪情况，由考评单元决定|
|工作人事组织|查询指定工作人事组织内的绩效评估结果跟踪情况，必填|
|业务组织|查询指定业务组织内的绩效评估结果跟踪情况，必填，由工作人事组织决定|
|被考评人|查询指定被考评人的绩效评估结果跟踪情况|
|部门|查询指定部门的绩效评估结果跟踪情况|
|职务|查询指定职务的绩效评估结果跟踪情况|
|岗位|查询指定岗位的绩效评估结果跟踪情况|

**操作说明**

*  <查询>：点击该按钮，输入查询条件，可查询符合当前条件的绩效评估结果跟踪情况。
