
# 功能描述

基于考核对象，查看考核活动的信息：考核综合得分、强制分布得分、个人总结和综合评价；对于个人或部门的考评表查看绩效指标明细结果、面谈记录、绩效改进计划、关键行为、考评结果调整、人事建议、培训建议等。

# 业务规则

*  系统启用绩效考核模块。

# 栏目说明

|栏目名称|说明|
|---|---|
|绩效期间|查询指定绩效期间的绩效结果，显示当前登录组织的已启动绩效期间|
|考评单元|查询指定考评单元的绩效结果|
|考评对象类型|查询指定考评对象类型的绩效结果|
|考核方案|查询指定考核方案的绩效结果，多选|
|部门|查询指定部门的绩效结果，多选|
|员工|查询指定员工的绩效结果，多选|

**操作说明**

*  <查询>：点击该按钮，根据输入查询条件，查找符合条件的查询结果；
*  <操作-XX>:在当前选择考评结果，点击操作，便可查询当前绩效结果的效指标明细结果、面谈记录、绩效改进计划、关键行为、考评结果调整、人事建议或培训建议。
