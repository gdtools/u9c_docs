
# 功能描述

定义本组织使用的考评打分制；对等级制的打分制，定义其各等级。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|定义当前考评打分方法的编码|
|名称|定义当前考评打分方法的名称||
|计分方式|制定当前打分方法采用的计分方式，分为：分制、等级制||
|总分|当前计分方式为分制时，分制的总分||
|级数|当前计分方式为等级制时，等级的级数||
|精度|当前计分方式为分制时，分制的精度；若为等级制，字段不可见||
|生效|当前考评打分方法是否有效||
|生效日期|当前考评打分方法的生效日期||
|失效日期|当前考评打分方法的失效日期||
|表体||
|等级序号|当前等级制打分方法的等级序号|
|等级标识|当前等级制打分方法的等级标识|
|标准分值|当前等级的标准分值|
|最低分值|当前等级的最低分值，等级序号最大的最低分值为0|
|最高分值|当前等级的最高分值，等级序号为1的最高分值为空|
