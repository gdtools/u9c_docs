
# 功能描述

维护本企业的绩效指标库，用于员工考核时的用的考评内容。

# 业务规则

*  已定义考评打分方法

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码规则|当前绩效指标的编码规则，与编码参数一致|
|编码|当前绩效指标的编码，严格按照编码规则来定义|
|名称|当前绩效指标的名称|
|绩效指标分类|归类不同的指标|
|考核方式|当前绩效指标的考核方式|
|打分方法|当前绩效指标的打分方法|
|对应素质指标|当前绩效指标对应的素质指标|
|考核目的|当前绩效指标的考核目的|
|考评参考|当前绩效指标的考评参考|
|生效|当前绩效指标是否生效|
|生效日期|当前绩效指标的生效日期|
|失效日期|当前绩效指标的失效日期|
|表体-绩效指标要素||
|序号|当前绩效指标的绩效要素的序号，系统自动生成|
|绩效要素|当前绩效指标的绩效要素的名称，选择绩效要素节点的定义|
|表体-绩效指标数据||
|行号|当前绩效指标的绩效要素的行号，系统自动生成|
|绩效指标码|当前绩效指标的绩效要素的绩效指标码，相当于该绩效指标行的代码|

# 操作说明

*  一般操作见公共操作说明。
