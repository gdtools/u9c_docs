
# 功能描述

维护本组织使用的考评表，设定考评表所使用的绩效指标及其权重；指定绩效指标的考评角色及其权重，设定绩效指标的考评标准。

# 业务规则

*  已定义绩效指标。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|当前考评表模版的编码|
|名称|当前考评表模版的名称|
|生效|当前考评表模版是否有效|
|生效日期|当前考评表模版的生效日期|
|失效日期|当前考评表模版的失效日期|
|表体-绩效指标||
|序号|当前考评表采用的绩效指标的序号，系统自动生成|
|绩效指标|考评模板使用的绩效指标，引用绩效指标档案|
|计分方式|当前绩效指标的计分方式，若绩效指标在定义时已指定打分方法，取打分方法中的计分方式；若没有，则手工录入|
|权重|当前绩效指标在考评表中的权重，所有绩效指标权重之和为1，单一绩效指标权重不大于1|
|打分方式|当前绩效指标的打分方式：分为定量、定性定性方式即手工打分；定量方式即系统根据取数规则自动取数，自动打分|
|业绩取数规则|定性方式的绩效指标的取数规则，通过定义表达式的方式取得相关数据|
|表体-定量标准|当绩效指标打分方式为定量时有效|
|序号|当前定量量级的序号|
|最低业绩|当前量级的最低业绩，同一绩效指标的最低与最高业绩首尾相连|
|最高业绩|当前量级的最高业绩|
|等级|绩效指标计分方式为等级制时，当前量级对应的等级序号|
|得分|绩效指标计分方式为分制时，当前量级对应的得分，不能超过分制的总分|
|表体-考核角色权重|当绩效指标打分方式为定性时有效|
|序号|当前绩效指标考核角色的序号|
|考核角色|可以参与当前绩效指标考核的角色|
|权重|当前考核角色在对应考核指标上的打分权重|
