
# 功能描述

定义本组织使用的强制分布法；按人数或比例定义强制分布法中各等级的人数或比例。

# 业务规则

*  已定义等级制的考评打分方法。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|定义当前强制分布法的编码|
|名称|定义当前强制分布法的名称||
|考评打分方法|选择当前强制分布法所采用的考评打分方法，只能选用等级制的考评打分方法||
|等级|当前等级制考评打分方法的等级||
|生效|当前强制分布法是否有效||
|生效日期|当前强制分布法的生效日期||
|失效日期|当前强制分布法的失效日期||
|表体||
|等级|当前强制分布的等级序号，由等级制考评打分方法决定|
|等级标识|当前强制分布的等级标识，由等级制考评打分方法决定|
|人数|定义当前等级所含的人数|
|比例|定义当前等级的人数比例|

# 操作说明

*  一般操作见公共操作说明。
