
# 功能描述

员工针对考评过程进行申诉；员工查看申诉的处理情况，对申诉处理结果进行反馈，针对申诉进行答复和处理。

# 业务规则

*  考评打分方法、考评表、考评期间以及考评单元设置。

# 栏目说明

|栏目名称|说明|
|---|---|
|申诉人|对绩效目标或打分不满意的提起申诉人，默认为当前登录者|
|问题序号|申诉问题的序号，系统自动生成|
|绩效期间|不满意提起申诉的绩效期间|
|问题分类|提起申诉的问题的分类|
|申诉日期|提起申诉的日期，默认为当前日期|
|问题描述|提起申诉的问题描述|
|处理措施|处理申诉的措施，不能由申诉人本人填写|
|处理措施说明|处理申诉的措施说明，不能由申诉人本人填写|
|答复人|处理申诉的答复人，默认为填写处理措施的人|
|答复日期|处理申诉答复的日期，默认为当前登录日期|
|申诉关闭日期|处理申诉关闭的日期，只能由申诉人本人填写|
|问题解决满意度|处理申诉问题申诉人对于解决满意的程度，只能由申诉人本人填写|
