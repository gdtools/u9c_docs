
# 功能描述

针对提出申诉或打分有误而不能更改的考核结果，可通过考核结果调整申请单做考核结果的调整，以作为最终评判结果。

# 业务规则

*  存在已启动的绩效期间，调整人员含有对应的考评表。

# 栏目说明

|栏目名称|说明|
|---|---|
|单头||
|单据类型|当前调整单单据的类型|
|单号|当前调整单单号，遵循单据类型中设置的单号规则|
|日期|当前调整单的日期，默认为当前日期|
|绩效期间|当前调整单要调整的绩效指标所属绩效期间，不能是已关闭的期间|
|考评单元|当前调整单要调整的绩效指标所属考评单元，必须是绩效期间对应的绩效计划的考评单元|
|考评对象类型|当前调整单要调整的考评对象类型|
|部门|当前调整单要调整的被考评部门|
|员工|当前调整单要调整的被考评员工|
|调整原因|当前调整单要调整结果的原因|
|申请人|当前调整单的申请人，默认为当前登录者|
|状态|当前调整单的状态|
|表体||
|序号|要调整的绩效指标的序号|
|绩效指标|要调整的绩效指标名称，一定要在当前绩效期间的考评表中存在|
|原始得分|要调整的绩效指标的原始得分，由选择的绩效指标自动带入|
|调整后得分|要调整的绩效指标调整后的得分|
|调整原因|当前绩效指标要调整的原因|

# 操作步骤

*  一般操作见公共操作说明。
