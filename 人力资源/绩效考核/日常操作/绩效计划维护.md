
# 功能描述

*  创建和维护绩效计划，确定绩效计划所使用的期间类别和期间范围，确定绩效计划的目的和目标；
*  指定绩效计划的总负责人，确定绩效计划的考核综合得分的打分模型，指定参与考评的默认考评角色及其权重；
*  创建和维护绩效计划中包含的考评单元，指定考评单元的考评负责人和考核团队（部门）员工；
*  指定考评单元中所使用的考评表，设置考评单元包含的员工范围，设置考评角色考评时的数据查看权限。

# 业务规则

*  考评打分方法的设置、考评表的设置、考评期间的设置。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头-基本||
|编码|当前绩效计划的编码|
|名称|当前绩效计划的名称|
|目标|当前绩效计划的目标|
|概要说明|当前绩效计划的概要说明|
|期间类型|当前绩效计划的期间类型|
|起始期间|当前绩效计划的起始期间|
|截至期间|当前绩效计划的截至期间|
|打分方法|当前绩效计划默认的打分方法|
|强制分布法|当前绩效计划默认的强制分布法|
|总负责人|当前绩效计划的总负责人|
|是否强制评估|当前绩效计划是否强制评估，若强制分布非空，是否强制评估为ture|
|表头-考核角色权重||
|考核角色|当前绩效计划默认的考核角色|
|是否考评|当前绩效计划的考核角色是否进行考评|
|考评权重|当前绩效计划的考核角色的权重|
|表体-考评单元||
|编码|当前考评单元的编码|
|名称|当前考评单元的名称|
|负责人|当前考评单元的负责人|
|考评对象类型|当前考评单元的考评对象类型|
|考核方案|当前考评单元的考核方案|
|考评表模版|当前考评单元的考评表模版|
|强制分布法|当前考评单元的强制分布法|
|员工确认绩效目标|当前考评单元是否由员工本人确认绩效目标|
|员工确认考评结果|当前考评单元是否由员工本人确认考评结果|
|是否逐级考评|当前考评单元是否进行逐级考评|
|表体-考核对象范围||
|序号|考评单元对应的考核对象的序号|
|工作人事组织|当前考核对象所在工作人事组织|
|业务组织|当前考核对象所在业务组织|
|部门|当前考核对象为部门时，被考核的部门；当前考核对象为人时，考核人员所属部门|
|职务|当前考核对象为人时，考核人员所在职务|
|岗位|当前考核对象为人时，考核人员所在岗位|
|开始职级|考核对象的开始职级|
|截至职级|考核对象的截至职级，起始职级和截止职级同时为空，或同时不为空|
|员工|考核对象为人时，考核的员工名称|
|是否排除关系|当前考核对象是否是考核排除之外的|

# 操作步骤

*  <创建考评表>：根据当前绩效计划的内容细化考评表，为每个考核对象自动生成一个考评表。
