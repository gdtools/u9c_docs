
# 功能描述

针对绩效考核结果，进行强制分布，并提出人事处理建议和培训建议，查看考评表中绩效指标的详细得分情况；针对已经确认的考核结果的考评表进行审核，使考核结果回显到人员管理的考核结果中。

# 业务规则

*  存在已启动的绩效期间；存在已确认的考评结果。

# 操作步骤

*  <查询>：根据当前选中的考评表，查找并显示相应的面谈记录；
*  <计算>：重新批量计算考核结果，点击出现计算页面；
 
   *  计算栏目说明

|栏目名称|说明|
|---|---|
|考核方案|要进行计算的考核方案|
|绩效期间|要进行计算的绩效期间|
|考评单元|要进行计算的考评单元，前提要先指定绩效期间|
|考评对象类型|要进行的计算的考评对象类型，根据选择的考评单元决定回显|
|工作人事组织|要进行计算的考核结果所在的工作人事组织|
|业务组织|要进行计算的考核结果所在的业务组织|
|部门|要进行金酸的被考评的部门|
|职务|要进行计算的被考评人所在职务|
|岗位|要进行计算的被考评人所在岗位|
|员工|要进行计算的考评人的员工名称|
|计算|根据所选条件进行计算|
|取消|取消计算，页面关闭，不做任何处理|

*  <强制分布>：针对考评单元内全部打分完毕的考核结果进行强制分布，按考评单元中定义的强制分布法的等级内容进行强制分布；
*  <人事建议>：针对当前考核结果提出人事建议，点击出现人事建议页面；
 
   *  人事建议栏目说明

|栏目名称|说明|
|---|---|
|绩效期间|当前人事建议的绩效期间，默认当前选择的考评表中绩效期间|
|考评单元|当前人事建议的考评单元，默认当前选择的考评表中考评单元|
|考评对象类型|当前人事建议的考评对象类型，默认当前选择的考评表中考评对象类型|
|被考核人|当前人事建议的被考评人，考评对象为人是，被考评人为被考核员工；考评对象为部门时，被考评人为部门负责人；默认当前选择的考评表中被考评人|
|处理方式|当前人事建议的处理方式|
|目标组织|当前人事建议的调整后的组织|
|目标部门|当前人事建议调整后的部门|
|目标职务|当前人事建议调整后的职务|
|目标岗位|当前人事建议调整后的岗位|
|调整后职级|当前人事建议调整后的职级|
|调整后工资级别|当前人事建议调整后的工资级别|
|状态|当前人事建议的状态，默认为未处理|
|状态说明|当前人事建议的状态说明|
|完成日期|当前人事建议的完成日期|

*  <培训建议>：针对当前考核结果提出培训建议，点击出现培训建议页面；
 
   *  培训建议栏目说明

|栏目名称|说明|
|---|---|
|绩效期间|当前培训建议的绩效期间，默认当前选择的考评表中绩效期间|
|考评单元|当前培训建议的考评单元，默认当前选择的考评表中考评单元|
|考评对象类型|当前培训建议的考评对象类型，默认当前选择的考评表中考评对象类型|
|被考评人|当前人事建议的被考评人，考评对象为人是，被考评人为被考核员工；考评对象为部门时，被考评人为部门负责人；默认当前选择的考评表中被考评人|
|序号|当前培训建议的序号|
|需要改进方面|当前培训建议的需要改进的方面|
|建议培训课程|当前培训建议中建议培训的课程|
|建议培训说明|当前培训建议中建议培训的说明|
|状态|当前培训建议的状态，默认为已处理|
|状态说明|当前培训建议的状态说明|
|完成日期|当前培训建议的完成日期|

*  <考评结果明细>：查看当前考评表的绩效指标的得分情况。
