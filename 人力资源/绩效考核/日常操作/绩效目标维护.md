
# 功能描述

细化考评表，为每个考评对象（员工或部门）生成一个考评表；调整考核指标的考核标准，对考核指标指定关键任务及目标业绩，确定考评角色对应的具体考评人，调整绩效指标的权重。

# 业务规则

*  存在已启动的绩效期间。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|绩效期间|当前考评表的绩效期间|
|考评单元|当前考评表的考评单元|
|考评对象类型|当前考评表的考评对象类型|
|部门|当前考评表考评对象范围为部门时，被考评的部门|
|员工|当前考评表考评对象范围为人时，被考评的人员|
|考核方案|当前考评表的考核方案|
|绩效目标|当前考评表的绩效目标|
|考评负责人|当前考评表的考评负责人|
|员工确认日期|员工确认绩效目标的日期|
|绩效目标确认人|当前考评表的绩效目标的确认人|
|上级确认日期|考评对象的上级确认绩效目标的日期|
|表体||
|绩效指标|当前考评表的绩效指标的序号|
|绩效指标名称|当前考评表的绩效指标的名称|
|计分方式|当前绩效指标的计分方式|
|权重|当前绩效指标的权重|
|打分方式|当前绩效指标的打分方式|
|考核标准|当前绩效指标的考核标准|
|目标业绩|当前绩效指标的目标业绩|
|关键任务|当前绩效指标的关键任务|
|考评人|当前绩效指标考评角色对应的具体考评人|
