
# 功能描述

跟踪绩效评估结果的实际执行情况，显示状态为未处理的人事建议和培训建议。

# 业务规则

*  存在已启动的绩效期间。

# 栏目说明

|栏目名称|说明|
|---|---|
|人事建议处理||
|绩效期间|当前人事建议的绩效期间，默认当前选择的考评表中绩效期间|
|考评单元|当前人事建议的考评单元，默认当前选择的考评表中考评单元|
|考评对象类型|当前人事建议的考评对象类型，默认当前选择的考评表中考评对象类型|
|被考核人|当前人事建议的被考评人，考评对象为人是，被考评人为被考核员工；考评对象为部门时，被考评人为部门负责人；默认当前选择的考评表中被考评人|
|处理方式|当前人事建议的处理方式|
|目标组织|当前人事建议的调整后的组织|
|目标部门|当前人事建议调整后的部门|
|目标职务|当前人事建议调整后的职务|
|目标岗位|当前人事建议调整后的岗位|
|调整后职级|当前人事建议调整后的职级|
|调整后工资级别|当前人事建议调整后的工资级别|
|状态|当前人事建议的状态，默认为未处理|
|状态说明|当前人事建议的状态说明|
|完成日期|当前人事建议的完成日期|
|培训建议||
|绩效期间|当前培训建议的绩效期间，默认当前选择的考评表中绩效期间|
|考评单元|当前培训建议的考评单元，默认当前选择的考评表中考评单元|
|考评对象类型|当前培训建议的考评对象类型，默认当前选择的考评表中考评对象类型|
|被考评人|当前人事建议的被考评人，考评对象为人是，被考评人为被考核员工；考评对象为部门时，被考评人为部门负责人；默认当前选择的考评表中被考评人|
|序号|当前培训建议的序号|
|需要改进方面|当前培训建议的需要改进的方面|
|建议培训课程|当前培训建议中建议培训的课程|
|建议培训说明|当前培训建议中建议培训的说明|
|状态|当前培训建议的状态，默认为已处理|
|状态说明|当前培训建议的状态说明|
|完成日期|当前培训建议的完成日期|

# 操作步骤

*  一般操作见公共操作说明。
