
# 功能描述

主要完成员工与雇主之间发生的劳动纠纷的登记、维护和浏览。

# 业务规则

*  创建员工工作记录
*  定义人员的劳动合同执行组织。

# 栏目说明

劳动争议

|栏目|说明|
|---|---|
|劳动争议编号|录入劳动争议编号|
|争议甲方|表示争议双方的企业方。注意：1、当登录组织具有法人特征时为登录组织，当登录组织不具有法人特征时，限为与当前登录组织存在组织－法人关系的法人组织2、一旦保存不可修改|
|争议乙方|表示争议双方的员工。注意：1、限登录组织负责范围内的员工。通过人员的劳动合同执行组织确定。2、一旦保存不可修改|
|争议劳动合同|表示争议双方之间的劳动合同，包括协议。注意：1、限争议双方之间尚未到期和解除的劳动合同/协议2、一旦保存不可修改|
|争议提出方|枚举：甲方 乙方|
|争议内容|录入争议内容|
|争议仲裁机构|录入争议仲裁机构|
|争议开始时间|选择争议开始时间|
|争议结束时间|争议结束时间应>=争议开始时间|
|处理结果|录入处理结果|
|处理时间|选额处理时间|
|赔偿方|枚举：甲方 乙方|
|赔偿金额|注意：当赔偿方非空时，不能为空。|
|币种|用户可进行自定义设置，请参见功能节点基础设置-币种。注意：当赔偿金额非空时，不能为空。|

# 操作说明

*  通过点击菜单[劳动争议](/detail/d5f5eedc76734424a9766260f4e6f518)，进入劳动争议新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的劳动争议单据进行查找。
*  点击列表可查看已保存的全部劳动争议单据信息，允许删除。
