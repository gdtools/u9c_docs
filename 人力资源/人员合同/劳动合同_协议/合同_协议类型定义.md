
# 功能描述

定义合同/协议类型，指定其条款、活动项目、经济赔偿规则、适用对象。

# 栏目说明

合同类型-表头画面

|栏目|说明|
|---|---|
|编码|录入合同类型的编码。|
|名称|录入合同类型的名称。|
|分类|提供三种分类：集体劳动合同、劳动合同、劳动协议。|
|类型|指定所属的类型，如果还没有建立需要的类型，可以点击本项下划线，弹出设置画面，在线新增。|
|期限类型|提供三种分类：无固定期限、有固定期限、以完成一定工作任务为期限。|
|作为劳动合同附件|只有在分类为协议时，可指定作为劳动合同附件，此时要求先签订劳动合同。|
|合同前必签协议|只有在分类为协议时，可指定作为合同前必签/协议，此时签订合同前将检查此协议是否已签。|
|与劳动合同同时解除|只有在分类为协议时，可与劳动合同同时解除。在解除合同时，将提示同时解除协议。|

|条款|指定合同的条款，如果还没有建立需要的条款，可以点击本项下划线，弹出设置画面，在线新增。|

# 操作说明

*  通过点击菜单[合同/协议类型定义](/detail/beab7274efa646a7aeba2379f8e9aa66)，进入劳动合同协议类型定义新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的劳动合同协议类型定义单据进行查找。
*  点击列表可查看已保存的全部劳动合同协议类型定义单据信息，允许删除。
