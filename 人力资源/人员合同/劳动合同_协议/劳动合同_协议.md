
# 功能描述

主要完成员工与雇主之间劳动合同/协议的签订、续签、解除发生的劳动纠纷的登记、维护和浏览。

# 业务规则

*  创建员工工作记录。
*  定义人员的劳动合同执行组织。

# 栏目说明

劳动合同/协议

|栏目|说明|
|---|---|
|**分组-基本**||
|合同类型|用户可自定义类型，参见功能节点[合同/协议类型](http://10.16.226.67/U9C/help/zh-CN/Content/HR/EN/Function/HR.HI.LaborContractType.htm)定义。|
|合同编号|录入合同编号。|
|签订类型|可选择：初签、变更、续签。|
|变更前合同|当签订类型=变更或续签时，变更前合同非空，选择乙方曾签的劳动合同/协议。|
|签订前合同类型|通过已选的变更前合同带出。|
|签订前法人|通过已选的变更前合同带出。|
|变更原因|当签订类型=变更和续签时可编辑，否则不可编辑。|
|**分组-甲方**|手动选择，或从变更前合同带出。|
|甲方|表示雇佣方。注意：1、当登录组织具有法人特征时为登录组织，当登录组织不具有法人特征时，限为与当前登录组织具有组织－法人的目的组织。2、一旦保存不可修改。3、当U9多组织特征=N时，甲方不可编辑，只能=登录的HR组织。|
|**分组-乙方**|手动选择，或从变更前合同带出。|
|乙方|表示的员工。注意：1、限登录组织负责范围内的员工。通过人员的劳动合同执行组织确定。2、一旦保存不可修改。|
|工作人事组织|通过乙方员工信息带出。|
|现任业务组织|通过乙方员工信息带出。|
|现任部门|通过乙方员工信息带出。|
|现任职务|通过乙方员工信息带出。|
|现任岗位|通过乙方员工信息带出。|
|职级职等|通过乙方员工信息带出。|
|**分组-状态**||
|合同开始日期|签订合同时，确定的合同开始日期。|
|合同截止日期|签订合同时，确定的合同截止日期。|
|合同签订日期|选择合同的签订日期。|
|签订地点|录入合同的签订地点。|
|解除日期|表示合同实际解除的日期。可以录入历史日期，不能录入将来日期。注意：必须大于等于合同开始日期。|
|解除原因|选择合同解除的原因，封闭枚举。|
|赔偿方|枚举：甲方、乙方。|
|赔补偿金额|当赔偿方非空时，非空。|
|币种|用户可进行自定义设置。请参见功能节点基础设置-币种。注意：当赔偿金额非空时不能为空。|
|状态|枚举：1、开立 2、核准中 3、已核准|

# 按钮说明

*  <操作>下<审批参数>按钮：对劳动合同/协议审批参数的设置。

审批参数栏目说明

|栏目|说明|
|---|---|
|档案名称|劳动合同|
|确认方式|枚举：即时确认、确认作业、审批流程|
|审批方式|确认方式选择审批流程时可选择。枚举：岗位汇报关系审批、工作流审批|

*  <操作>下<表格模板>按钮：以word模版输出劳动合同说明。使用前提：用word制作模版并上载劳动合同文书模版。

|栏目|说明|
|---|---|

通过行操作实现实现增加、插入、删除。

点击行操作<增加>按钮：弹出模版选择画面,选择文件，当文件不存在时刻实现文件的上载；

选择行，点击操作删除按钮：删除行，表示取消模版；

*  <批量增加合同>按钮：点击该按钮弹出批量增加人员合共画面，选择甲方（组织）、选择合同签订时间，开始时间，选择乙方（员工），可实现批量创建人员合同。
*  <批量解除合同>按钮：点击该按钮，弹出批量解除劳动合同弹窗，选择解除日期、解除原因、赔偿方、赔偿金额和币种，可完成解除动作，解除日期、解除原因会回写到列表中。

# 操作说明

*  通过点击菜单[劳动合同/协议](/detail/ab4ff6b1b33b4382b89530ce6fbe6671)，进入劳动合同协议新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的劳动合同协议单据进行查找。
*  点击列表可查看已保存的全部劳动合同协议单据信息，允许删除，支持批量解除合同。
