
# 功能描述

在进行发薪申请前，应首先定义薪资发放申请单类型。

设置单据类型的作用：

*  可以根据单据类型配置不同的审批流；
*  在单据审核通过后，确定是否自动执行单据。

# 业务规则

*  定义单据编号规则

# 栏目说明

单据类型-基本页签

|栏目|说明|
|---|---|
|编码|录入单据类型的编码。|
|名称|录入单据类型的名称。|
|简称|录入单据类型的简称。|
|描述|录入单据类型的描述。|
|业务类型|默认为薪资发放。|
|核准后自动执行|在单据被审核通过后，确定是否自动执行薪资发放。|

单据类型-参数页签

|栏目|说明|
|---|---|
|确认方式|选择单据审核确认的方式：1、确认作业：即单据需要提供单独的审核操作按钮，执行审核处理；2、审批流程：即单据需要执行多个审核环节，需要设置审批流程。|
|编号方式|选择单据号的编号方式：1、手工编号：即单据号手工录入。2、自动编号：即由系统根据编号规则，自动生成每张单据的单据编号。此种方式下需要设置编号规则。|
|编号原则|在编号方式为自动编号时，选择单据号的编号规则。|
|允许手工修改|在编号方式为自动编号时，基于编号规则生成单据号后，指定用户是否可以手工修改。|
|打印模板|基于打印模版参照选择。|
