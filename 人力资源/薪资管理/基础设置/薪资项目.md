
# 功能描述

支持各人事中心根据本企业情况自定义薪资项目。

可以为薪资项目定义适用的计薪期间类型、基准期间类型、增减属性、是否税前项目、适用的所得类别、是否分摊计税。

薪资项目可用于记录员工薪资、薪资计算、发放。

# 业务规则

*  定义薪资日历
*  定义计薪期间

# 栏目说明

薪资项目

|栏目|说明|
|---|---|
|组织|当前薪资项目所属的工作人事组织。|
|公共薪资项目|指定当前薪资项目所对应的公共薪资项目。如果需要增加公共薪资项目，点击字段下划线，弹出设置画面，用户可以在线新增。|
|编码|录入薪资项目编码|
|名称|录入薪资项目名称|
|描述|对当前薪资项目的说明|
|数据类型|支持以下类型的薪资项目：字符、数值、货币、日期、布尔、枚举、档案。|
|值集|数据类型为枚举、档案时，需要指定对应的值集。如果需要增加值集，点击字段下划线，弹出设置画面，用户可以在线新增。|
|精度|数据类型为数值时，此项目可使用。精度指数值的小数位数。例如：保留小数点后２位，则精度就是２。|
|舍入类型|数据类型为数值时，此项目可使用。录入精度后数值的处理方式。系统提供以下三种方式１、全部进位：即小数点精度的后一位数字不论是大小，都做进位处理２、全部舍位：即小数点精度的后一位数字不论是大小，都做舍位处理；３、按值舍入：即按照设置的固定值，只要大于等于该数值，就做进位处理，只要小于该数值，就做舍位处理。|
|舍入值|舍入类型为按值舍入时，此项目可使用。例如：精度＝２，舍入类型＝按值舍入，舍入值＝５，则在数量计算时，参考小数点后第３位的数值，如果大于等于５，就进位；如果小于５，则舍去。|
|形态|指当前薪资项目的形态。如果需要增加形态，点击字段下划线，弹出设置画面，用户可以在线新增。|
|计薪期间类型|指当前薪资项目的计薪期间类型。如 岗位工资的计薪期间类型为月，基准期间类型为日，是指员工的岗位工资为日薪，公司按月计算应发的岗位工资。|
|基准期间类型|指当前薪资项目的基准期间类型。|
|执行计算期间|指当前薪资项目的执行计算期间。提供三种选择：当前期间、期间延后、期间提前。如 岗位工资的计薪期间类型为月，执行计算期间为期间延后，期间偏移量为1，则当计算期间为8月时，实际计算的是员工在7月的岗位工资。|
|期间偏移量|指当前薪资项目取值期间与计算期间的偏移量。|
|档案项目|指定当前薪资项目是否档案项目|
|增减属性|系统提供以下三种选项：增项、减项、其它项。如：岗位工资为增项、病假扣款为减项、工资级别为其它项。|
|税前项目|数据类型为货币时，此项目可使用。指定当前薪资项目是否是税前项目。如：岗位工资是税前项目，养老保险是税前项目。|
|所得类别|当前薪资项目为税前项目时，此项目可使用。指定当前薪资项目所对应的所得类别。如果需要增加所得类别，点击字段下划线，弹出设置画面，用户可以在线新增。|
|社会保险公积金|指定当前薪资项目是否属于社会保险公积金。|
|分摊计税|指定当前薪资项目是否需要分摊计税例如：年奖需要分摊计税。|
|分摊月数|在当前薪资项目需要分摊计税时，指定分摊月数例如：年奖的分摊月数为12。|
