
# 功能描述

各人事中心可以定义本组织的计薪期间。

计薪期间分：年、半年、季、月、四周、两周、周、日等类型，一个计薪期间可以包含一或多个基准期间，主要用于员工薪资计算，如：按月计算月薪；按月计算日薪；按月计算小时薪。

计薪期间的应用非常灵活，在应用系统进行薪资计算工作之前，应设置好组织使用的各类计薪期间。

# 按钮说明

*  <批量增加计薪期间>：在计薪期间类型与基准期间类型相同时，可以通过指定基准期间范围，批量增加相应的计薪期间。在每个计薪期间都包含相同的基准期间时，可以通过指定开始基准期间、及每个计薪期间包含的基准期间数，批量增加相应的计薪期间。

操作前提：已定义需要的基准期间

操作步骤：点击批量增加计薪期间按钮，弹出对话框，在录入条件后，点确定按钮执行批量增加。

栏目说明-基本栏目

|栏目|说明|
|---|---|
|批量增加类型|提供四种选项：1、计薪期间-基准期间相同2、各计薪期间下基准期间数相等3、基准期间为日4、基准期间为小时|
|计薪期间类型|批量增加类型为“计薪期间-基准期间相同”，可选择：年、半年、季、月、周。批量增加类型为“各计薪期间下基准期间数相等”，可选择：年、半年、季、月、4周、2周。批量增加类型为“基准期间为日、基准期间为小时“，可选择：年、半年、季、月、4周、2周、周、日。|
|基准期间类型|提供以下选项目：年、半年、季、月、周、日、小时。基准期间类型不能大于计薪期间类型，如计薪期间类型为月时：基准期间类型可以是：月、周、日、小时，但不能是年、半年、季。|
|基准期间数|是指每个计薪期间下包含的基准期间数。只有批量增加类型为各计薪期间下基准期间数相等，本项目才可用。|
|开始基准期间|是指本次批增的第一个计薪期间所包含的第一个基准期间。批量增加类型为“计薪期间-基准期间相同、各计薪期间下基准期间数相等”时，本项目可用。|
|结束基准期间|是指本次批增计薪期间所能包含的最大基准期间。批量增加类型为计薪期间-基准期间相同时，本项目可用。|
|开始日期|是指本次批增的第一个计薪期间的开始日期。批量增加类型为“基准期间为日、基准期间为小时“，本项目可用。|
|计薪天数|是指每个计薪期间的计薪天数。批量增加类型为“基准期间为日、基准期间为小时“，本项目可用。|
|日计薪小时数|是指每个计薪期间中每一日的日计薪小时数。批量增加类型为“基准期间为日、基准期间为小时“，本项目可用。|
|合计计薪小时数|是指每个计薪期间的合计计薪小时数。批量增加类型为“基准期间为日、基准期间为小时“，本项目可用。|

*  <批量增加计薪期间>：在基准期间为日、小时时，可以通过指定开始日期、计薪天数、日计薪小时数，批量增加相应的计薪期间。
