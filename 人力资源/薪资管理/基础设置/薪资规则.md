
# 功能描述

各工作人事组织为薪资项目设置薪资规则。

薪资规则分三种：薪资标准、计算规则。对于薪资档案项目，两种都可定义，薪资标准主要用于定调资；计算规则用于薪资计算。对于其他薪资项目，只能定义计算规则。

# 业务规则

*  定义薪资项目。
*  新增薪资规则时，在编辑完表头数据后，应先点保存按钮进行保存，之后再编辑表体。
*  新增薪资规则时，在编辑完结构页签中的要素后，应先点保存按钮进行保存，之后批量增加要素值、批量设置薪资基准按钮才可使用。

# 栏目说明

薪资规则-表头

|栏目|说明|
|---|---|
|工作人事组织|指薪资规则所属的工作人事组织，不可编辑。|
|薪资项目|指薪资规则所属的薪资项目。如果需要增加薪资项目，点击字段下划线，弹出设置画面，用户可以在线新增。|
|规则类型|提供两种规则：薪资标准、计算规则。当前薪资项目为档案项目时，两种都可定义，薪资标准主要用于定调资；计算规则用于薪资计算。当前薪资项目不是档案项目时，只能定义计算规则。|
|编码|薪资规则的编码|
|名称|薪资规则的名称|
|描述|薪资规则的说明|
|币种|当前薪资项目为货币型时，可用。为当前规则的结果值指定币种。|
|默认规则|指定当前规则是否默认规则。一个薪资项目在同一日期下，只能有一个默认规则。由于允许薪资规则调用其他薪资规则，在薪资计算时，系统将按默认规则计算。|
|开始日期|规则类型为薪资标准时，此项目有效。指当前薪资规则的有效开始日期。|
|结束日期|规则类型为薪资标准时，此项目有效。指当前薪资规则的有效结束日期。|
|开始期间|规则类型为计算规则时，此项目有效。指当前薪资规则的有效开始期间。|
|结束期间|规则类型为计算规则时，此项目有效。指当前薪资规则的有效结束期间。|

[薪资规则-结构](http://10.16.226.67/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|要素|指定薪资规则的要素，最多可有6个。如果需要增加薪资规则要素，点击字段下划线，弹出设置画面，用户可以在线新增。|
|要素模式|薪资规则要素的取值模式有五种：值、[下限、上限]、（下限、上限]、[下限、上限）、（下限、上限）|

[薪资规则-数据](http://10.16.226.67/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|结果类型|当前薪资项目为档案项目，且规则类型为薪资标准 时：提供三种选项：标准值、公式、手工维护。当前薪资项目为档案项目，且规则类型为计算规则时：提供三种选项：期初值、期末值、按日计算。当前薪资项目为非档案项目，且规则类型为计算规则时：提供三种选项：标准值、公式、手工维护。结果类型为标准值时，可在薪资下限、薪资基准、薪资上限三列下录入标准值。结果类型为公式时，可在公式列录入公式。结果类型为手工维护、期初值、期末值、按日计算时，不需维护薪资下限、薪资基准、薪资上限、公式列。|
|薪资下限|结果类型为标准值时，可录入薪资下限。|
|薪资基准|结果类型为标准值时，非空。|
|薪资上限|结果类型为标准值时，可录入薪资上限。|
|公式|结果类型为公式时，非空。|

# 按钮说明

*  <批量增加要素值>：如果薪资规则有多个要素，则在每个要素列都分别指定多个值的情况下，可采用迪卡尔积方式批量增加薪资规则行。

[批量增加要素值画面](http://10.16.226.67/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|要素空增全部项目|如果要素的数据类型为枚举、档案，且该要素列下未指定值，则默认包括所有的枚举值、档案值。|
|薪资标准要素n|当要素n模式为值时，显示此项目列可增加多行录入要素值|
|薪资标准要素n下限|当要素n模式为上下限时，显示此项目列可增加多行录入要素下限|
|薪资标准要素n上限|当要素n模式为上下限时，显示此项目列可增加多行录入要素上限|

*  <[批量设置薪资基准](http://10.16.226.67/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：点击该按钮后，弹出批量设置对话框。在对话框中，录入首行行号、行数、以及首级薪资基准、薪资级差后，点确定按钮，系统将从薪资规则的指定行号起，增加多行薪资基准数据。

[批量设置薪资基准画面](http://10.16.226.67/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|首行行号|录入首行行号|
|行数|录入要批量设置的行数|
|首级薪资下限|录入首级薪资下限值|
|首级薪资基准|录入首级薪资基准值|
|首级薪资上限|录入首级薪资上限值|
|薪资级差|录入每行的薪资级差|

*  <[薪资规则要素](http://10.16.226.67/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：导航到薪资规则要素画面，设置薪资规则要素。

[薪资规则要素画面](http://10.16.226.67/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|工作人事组织|指要素所属的工作人事组织。不可编辑。|
|编码|要素的编码|
|名称|要素的名称|
|描述|要素的说明|
|来源方式|提供字段、表达式两种方式。|
|字段|来源方式为字段时，本项目可用。指当前薪资规则要素的取值字段。|
|表达式|来源方式为表达式时，本项目可用。指当前薪资规则要素的取值表达式。|
|数据类型|来源方式为字段时，默认取自当前选定字段的数据类型。来源方式为表达式时，本项目可用。|

*  <操作>下<下发>：参照下发文档。
*  <操作>下<下发参数>：参照下发参数文档。
*  <操作>下<取消下发>：参照取消下发文档。
