
# 功能描述

设置报送给银行的薪资数据文件格式。

# 业务规则

*  定义银行

# 栏目说明

代发格式－表头

|栏目|说明|
|---|---|
|编码|录入代发格式编码注意：代发格式编码不允许重复。|
|名称|录入代发格式名称|
|银行|指定银行如果需要增加银行，点击字段下划线，弹出银行设置画面，用户可以在线新增。|
|文件类型|系统支持两种文件类型：TXT文本、Excel表|
|首行汇总金额|指定是否在首行输出汇总金额|
|尾行汇总金额|指定是否在尾行输出汇总金额|
|日期型格式|指定日期型数据的输出格式|
|字段分隔符|指定字段间的分隔符号|

代发格式－表体

|栏目|说明|
|---|---|
|数据区域|系统支持为表头、表体、表尾三个区域定义输出内容。|
|字段名称|用户录入字段名称。|
|数据来源|数据来源可以是常量、发放表。|
|常量值|数据来源为常量时，常量值有效，需要用户录入常量值。例如：录入常量值 金额。|
|数据内容|数据来源为发放表时，此项目有效。用户选择的枚举项为：薪资发放表中的字段。|
|前包含内容|录入在常量值/数据内容前需要输出的内容。|
|后包含内容|录入在常量值/数据内容后需要输出的内容。|
|字段补位符|当输出内容为空时，可以输出的补位字符。|
