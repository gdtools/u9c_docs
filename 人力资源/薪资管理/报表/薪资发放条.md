
# 功能描述

基于当前登录的薪资中心，输出与其有薪资关系的工作人事组织下的员工薪资发放条。

# 栏目说明

薪资发放条－查询方案

|栏目|说明|
|---|---|
|计薪方案|选择查询的计薪方案；系统将输出此计薪方案下的薪资；|
|日期范围|提供五种选择：1、今天2、本周3、本月4、上月5、指定日期今天：指当前系统日期本月：指当前系统日期所在的年月|
|日期|当日期范围为指定日期时，要指定开始日期、结束日期|
|人事组织|基于当前登录的薪资中心，选择与其有薪资关系的工作人事组织|
|任职组织|指定查询的任职组织|
|部门|指定查询的部门|
|人员类别|指定查询的人员类别|
|发薪申请单状态|系统只输出指定单据状态下的员工发薪记录|

薪资发放条－查询结果

|栏目|说明|
|---|---|
|任职组织||
|部门||

# 按钮说明

*  <[查询方案](http://10.16.2.212/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：在薪资明细表画面，点击查询方案按钮，可以定义查询方案，包括查询条件、栏目及排序。
*  <[调整列宽](http://10.16.2.212/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：在薪资明细表画面，点击调整列宽按钮，可以调整列表栏目显示及打印的宽度。
