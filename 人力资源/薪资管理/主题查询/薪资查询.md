
# 功能描述

基于当前登录日期，查询当前登录薪资中心负责发薪的各工作人事组织中：员工的薪资档案、纳税方式、银行账号、薪资结算组织、发薪/扣款计划、计薪方案、发薪方案、发薪记录、补发记录、个税记录、发放结果。

# 业务规则

*  系统启用薪资管理模块。

# 栏目说明

薪资查询－查询方案

|栏目|说明|
|---|---|
|工作人事组织|查询指定工作人事组织下的员工|
|现任业务组织|查询指定业务组织下的员工|
|现任部门|查询指定部门下的员工|
|现任职务|查询指定职务下的员工|
|员工类别|查询指定员工类别下的员工|

# 操作说明

*  通过点击菜单[薪资查询](/detail/af04a7c369754b40ab2cc22775608df2)菜单，进入员工信息和薪资档案、纳税方式画面。在员工信息列表中，含有缺省结算组织信息，双击选定的员工行后，薪资档案和纳税方式列表中将显示该行员工的信息。
*  对于员工信息列表中的选定员工，若要查看其他信息可点击<查询内容>下的按钮。
*  点击<薪资结算组织>，查看员工其它的结算组织信息。
*  点击<薪资影响因素>，查看员工在各结算组织中是否为生成AAI分录的影响因素；
*  点击<发薪/扣款计划>，查看员工的发薪/扣款计划信息。
*  点击<薪资发放>，导航到新的画面，显示员工的计薪方案、发薪方案、银行账号。
*  在员工计薪方案列表中，选定一计薪方案后，可以点击<发薪记录>，再导航到另一画面，显示员工在该方案下的发薪记录、补发记录、个税记录。
*  在发薪记录列表中，选定一记录后，点击<发薪项目>，显示该记录中各薪资项目的计薪期间。
*  在发薪记录列表中，选定一记录后，点击<发放结果>，显示该记录的发放情况。
