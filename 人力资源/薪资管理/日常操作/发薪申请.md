
# 功能描述

支持登录薪资中心，按计薪方案、工作人事组织，提交并审核、执行员工发薪申请。员工薪资计算后的应发合计金额可以分几次发放，每次可单独提交发薪申请。

# 业务规则

*  定义发薪单据类型
*  设置个税税率
*  定义薪资日历
*  定义计薪期间
*  定义薪资项目
*  设置薪资规则
*  维护员工薪资信息
*  为计薪方案指定计薪期间
*  薪资计算

# 按钮说明

*  <[增加发薪人员](http://10.16.2.212/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：在申请单状态为开立时，通过此功能可实现发薪人员的批量增加。

操作前提：员工已执行薪资计算；已保存当前发薪申请单。

操作步骤：

1）点击增加发薪人员按钮，进入批量增加画面

2）在批量增加画面，可以按组织、部门、职务、岗位实现批量增加人员，也可以直接选择员工。点击确定按钮，将符合条件的人员（在当前计薪方案、工作人事组织、计薪日期下、已进行薪资计算的人员），添加到列表中。

批量增加栏目

|栏目|说明|
|---|---|
|按指定员工批增|允许按指定员工批增时，员工栏目可用，其他栏目不可用；否则，可用栏目相反。|
|任职业务组织|增加指定任职组织下的员工|
|部门|增加指定部门下的员工|
|包含下级部门|指定是否包含下级部门|
|职务|增加指定职务下的员工|
|岗位|增加指定岗位下的员工|
|人员类别|增加指定人员类别下的员工|
|员工|增加指定员工|

*  <[删除发薪人员](http://10.16.2.212/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：

在申请单状态为开立时，通过此功能可实现从发薪申请单-合计页签的人员列表中批量删除人员。

操作前提：保存发薪申请单。

操作步骤：

1）选中发薪人员列表中的行，可以选择多行。

2）点击删除发薪人员按钮，实现从发薪人员列表中删除人员。

*  <计算薪资>：发薪申请单状态为开立时，可用。根据本单据中指定的发薪项目，为单据中员工计算应发合计、实发合计、及个人所得税。
*  <操作>在>下<执行>：

操作前提：

1）单据类型的流程不是核准后自动执行。

2）发薪申请单状态为已审核。

操作步骤：

1）点击查找按钮，找出要执行的申请单。

2）点击执行按钮，申请单状态由已核准转变为关闭，同时对于单据中的员工，基于各自的发薪方案生成员工发薪结果（在薪资发放节点，可浏览、调整此结果）。

*  <操作-取消执行>：见U9C统一功能。
*  <操作-作废>：见U9C统一功能。
*  <操作-表格输出>：见U9C统一功能。
*  <操作-邮件发工资条>：点击该按钮，可触发工资条邮件，前提是邮箱服务已配置，且邮件发送后不会给员工发送消息通知，工资条栏目可在“员工薪资信息列表-员工薪资查询设置”中设置。
*  <操作-核对实发>：点击该按钮，可重新核对实发合计，实发合计 = 应发合计 - 社会保险公积金 - 代缴的个人所得税 - 税后扣款

*  <后续处理-薪资结算>：查看当前发薪申请单所生成的薪资结算单，以及由薪资结算单生成的交易分录。在提交发薪申请单时，对于单据中的员工，系统根据员工默认结算组织，及员工薪资项目的特殊结算组织，按结算组织，生成薪资结算单。对于每张薪资结算单，在参数是否产生AAI分录为是时，基于结算组织的法人组织的主账簿下预置的AAI分录模版，生成AAI交易分录。

操作前提：

1）在HR组织管理关系节点，按HR组织、业务组织、部门、职务、岗位指定好默认结算组织和可用的结算组织；

2）在员工薪资信息节点，为员工按薪资项目指定好默认结算组织以外的其他结算组织；

3）当前发薪申请单已被提交

操作步骤：

1）点击后续处理-薪资结算单按钮，弹出薪资结算单画面，查看薪资结算单。通过点击画面中的首页、上页、下页、末页按钮，查看不同结算组织下的薪资结算单。

2）在参数是否产生AAI分录为是，且已设置薪资的交易分录模版、预设科目影响因素、会计科目模版时，可点击交易分录按钮，查看当前结算单生成的交易分录。

参见公共:[交易分录](http://10.16.2.212/U9C/help/zh-CN/Content/PO/PO.AAI.TranEntryMain.htm)。
