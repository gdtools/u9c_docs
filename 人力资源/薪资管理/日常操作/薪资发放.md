
# 功能描述

为员工薪资指定具体的发放笔数、各笔金额；

对于由银行代发的，按预置好的银行代发文件格式生成代发文件。

# 业务规则

*  已审核并执行发薪申请单

# 栏目说明

薪资发放－表头

|栏目|说明|
|---|---|
|计薪方案||
|计薪日期||
|发薪日期||
|任职组织||
|部门||
|员工||
|实发合计||
|币种|指当前计薪方案下，实发合计的币种|

薪资发放－表体

|栏目|说明|
|---|---|
|序号|员工的实发合计金额可分多笔发放，序号用于标记笔数|
|薪资发放方式|可选择现金发放或银行代发|
|银行|发放方式为银行代发时，必须指定|
|账号|发放方式为银行代发时，必须指定|
|原币币种|即当前计薪方案下，实发合计的币种，用户不可改。|
|原币金额|发放的各笔金额用户可修改，各笔原币金额之和应等于实发合计|
|发放币种|各笔金额的币种，用户可修改。|
|发放金额|按照本笔薪资所对应的计税月上一月最后一日汇率，系统自动将薪资由原币币种换算为发放币种，用户不可改。|

# 按钮说明

*  <查询>：点击该按钮，可选择查询条件，按照查询条件对列表进行查询。
*  <生成代发文件>：点击该按钮，弹出选择保存目录对话框，指定好目录后，为当前列表中采用银行代发的员工，按所对应的银行代发文件格式，生成代发文件。
*  <套打明细>：点击该按钮，可启动打印功能。
