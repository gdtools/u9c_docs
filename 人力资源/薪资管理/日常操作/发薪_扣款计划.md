
# 功能描述

员工的薪资信息组织为人事归属中心时，需登录员工的人事归属中心，编辑、维护员工的发薪/扣款计划。

员工的薪资信息组织为工作人事组织时，需登录员工的工作人事组织，编辑、维护员工的发薪/扣款计划。

# 业务规则

*  定义计薪期间
*  定义薪资项目

# 栏目说明

发薪/扣款计划－表头

|栏目|说明|
|---|---|
|员工|可选择的员工范围：薪资信息组织为当前登录组织的员工。|
|薪资项目|执行发薪/扣款计划的薪资项目|
|总额|发薪/扣款计划的总额|
|币种|总额的币种|
|开始期间|发薪/扣款的开始计薪期间|
|期间数|发薪/扣款的总期间数|
|间隔期数|发薪/扣款的间隔期数|

发薪/扣款计划－表体

|栏目|说明|
|---|---|
|计薪期间|指定发薪/扣款的计薪期间|
|金额|指定当前计薪期间的发薪/扣款金额|

# 按钮说明

*  <生成明细>按钮：在表头中指定员工、薪资项目、总额、及默认规则后，点击生成明细按钮，系统将自动生成表体中的明细数据。
