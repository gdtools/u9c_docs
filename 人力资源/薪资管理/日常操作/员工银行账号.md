
# 功能描述

展示员工的银行账号列表，该数据是通过[员工薪资信息](/detail/ffab3eac8ff846eb8d348a435cff4ab8)维护而自动生成的。

# 业务规则

*  跨组织调动后，可设置银行账号是否在新组织中生效。
*  员工银行账号跟员工是一对一关系。

# 栏目说明

员工银行账号列表

|栏目|说明|
|---|---|
|员工编号|显示当前员工的员工编号|
|姓名|显示员工姓名|
|银行|显示银行姓名|
|账号|显示银行账号|
|账号名称|显示银行账号名称|
|默认账号|显示是否为默认账号|
|币种|显示币种|
|多币种|显示是否为多币种|
|生效|显示是否生效|
|生效日期|显示生效日期|
|失效日期|显示失效日期|

# 操作说明

*  在列表中点击可进入员工薪资信息-账号页签，详见[员工薪资信息](/detail/ffab3eac8ff846eb8d348a435cff4ab8)。
*  一般操作见公共操作说明。
