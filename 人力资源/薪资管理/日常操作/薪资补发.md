
# 功能描述

登录薪资中心，维护员工在指定计薪方案、工作人事组织、计薪日期下的补发金额。

# 业务规则

*  定义薪资日历
*  定义计薪期间
*  定义薪资项目
*  设置薪资规则
*  维护员工薪资信息
*  为计薪方案指定计薪期间

# 按钮说明

*  <操作>下<自动补发>：对于薪资档案项目，系统可基于员工薪资档案和已发放金额自动计算出补发金额，不需要用户一笔笔手工录入。

操作前提：

1）员工以往发放过薪资

2）企业给已发放的薪资又进行了调资

操作步骤：

点击自动补发按钮，弹出自动补发对话框，在指定好计薪方案、工作人事组织、计薪日期、任职组织、部门、员工、薪资项目、补发期间后，点确定按钮，系统将基于员工薪资档案和已发放金额计算生成补发金额。

栏目说明

[基本栏目](http://10.16.226.67/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|计薪方案|基于参照，选择计薪方案、工作人事组织，同时确定计薪日期、以及可补发的薪资项目。|
|工作人事组织||
|计薪日期||
|任职业务组织|基于参照，指定补发人员的业务组织|

|员工|基于参照，选择补发员工，可多选|

|补发期间|基于参照，指定补发期间，必须小于当前计薪方案计薪期间|

注意：系统允许用户手工录入补发额，但对于薪资档案项目，建议先执行自动补发，只有在计算生成的补发额与实际补发有出入时，再做手工调整。
