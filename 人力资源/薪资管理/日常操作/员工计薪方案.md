
# 功能描述

登录薪资中心后：可为计薪方案指定包含的员工，以及为员工指定可用的计薪方案。

# 业务规则

*  设置HR组织管理关系
*  定义计薪方案

# 栏目说明

员工计薪方案-表头

|栏目|说明|
|---|---|
|设置方式|提供两种设置方式：按计薪方案设置、按员工设置。|
|计薪方案|按计薪方案设置时，此项目非空；|
|工作人事组织|按员工设置时，此项目非空；组织参照：限于与当前薪资中心有薪资关系的工作人事组织。|
|员工|按员工设置时，此项目非空；员工参照：限于当前工作人事组织下、由当前登录的薪资中心负责薪资发放的员工。|

员工计薪方案-按计薪方案设置

|栏目|说明|
|---|---|
|工作人事组织|基于组织参照，选择工作人事组织。组织参照：限于与当前登录的薪资中心有薪资关系的工作人事组织。|
|员工|基于员工参照，选择员工。员工参照：限于当前工作人事组织下、由当前登录的薪资中心负责薪资发放的员工。|
|员工编号|显示员工的员工编号|
|员工类别|显示员工的员工类别|
|职级职等|显示员工的职级职等|
|现任业务组织|显示员工的现任业务组织|
|现任部门|显示员工的现任部门|
|现任职务|显示员工的现任职务|
|现任岗位|显示员工的现任岗位|
|核算组织|基于组织参照，选择核算组织。组织参照：限于与当前登录的薪资中心有核算关系的组织。|
|开始日期|指定员工在此计薪方案下的开始日期|
|结束日期|指定员工在此计薪方案下的结束日期|

员工计薪方案-按员工设置

|栏目|说明|
|---|---|
|计薪方案|基于计薪方案参照，选择计薪方案。|
|核算组织|基于组织参照，选择核算组织。组织参照：限于与当前登录的薪资中心有人事--核算关系的目的组织。|
|开始日期|指定员工在此计薪方案下的开始日期|
|结束日期|指定员工在此计薪方案下的结束日期|

# 按钮说明

*  <批量增加>：

按计薪方案设置时，基于当前计薪方案，以及该方案的计薪人员规则，自动查找并批量增加适用的员工。

按员工设置时，基于当前员工，以及各计薪方案的计薪人员规则，自动查找并为该员工批量增加适用的计薪方案。

批量增加对话框，主要用于指定批量增加时默认的核算组织、开始日期、结束日期。

操作步骤：

1）指定设置方式，并选择好计薪方案或员工；

2）点击批量增加按钮，弹出批量增加对话框，在对话框中指定核算组织、开始日期、结束日期。

3）点击确定按钮，执行批量增加。
