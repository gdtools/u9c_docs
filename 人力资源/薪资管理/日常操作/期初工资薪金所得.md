
# 功能描述

用于维护员工期初工资薪金所得数据。

# 业务规则

*  每个员工、每个计税年度，仅可以录入一条数据。不同年度之间没有影响。
*  某员工如本年度已有发薪申请（计算薪资操作），则不能录入期初数据。
*  某员工期初数据被使用后，该员工的期初数据不能修改。

# 操作说明

*  录入方式提供两种：

1）手工录入：在列表中直接录入，录入后点击<保存>可保存数据。

2）OBA工具导入

*  期初数据仅作为计算个人所得税时使用，即在发薪申请中，给某员工进行了“计算薪资”时，该员工的期初数据才算使用。

如果员工录入了期初数据，则在计算个税时，计算公式如下：

本期累计应纳税所得额=期初（累计收入-累计免税收入-累计减除费用-累计专项扣除-累计专项附加扣除-累计依法确定的其他扣除）+本期（应收合计-起征点-社保公积金-专项附加扣除-其他税前减项）

本期个税=（本期累计应纳税所得额×预扣率-速算扣除数)-期初累计减免税额-期初累计已预扣预缴税额

*  期初数据使用场景：

场景1：年中月份新启用薪资模块的企业

如某企业，2019年6月新启用U9HR模块；或1-5月份个税未使用U9HR进行计算，6月份开始使用：

*  在国税局系统中，导出2019年05月份工资薪金所得
*  将表格中的数据，通过人工录入或OBA导入到U9系统期初工资薪金所得中，计税年填写2019
*  再使用U9HR计算6月份及以后薪资，即可将期初数据计算在内

场景2：新员工第一个月需要0申报的

某员工3月入职（报税所属期为4月），国税局报税时需要对此员工税款所属期为3月进行0申报。对于这种新员工第一个月0申报的，可以通过录入期初数据，代替在U9HR中的0申报：

*  在国税局系统中，找到该员工的2019年3月份工资薪金所得
*  将该员工的数据，依次填写到“期初工资薪金所得”中，计税年填写2019
*  再计算该员工4月份个税时，即可将录入的期初数据计算在内
