
# 功能描述

在计薪方案计薪期间节点，为各工作人事组织确定计薪期间、薪资项目后，登录薪资中心，按工作人事组织计算员工的应发薪资，支持OBA导入。

# 业务规则

*  定义薪资日历
*  定义计薪期间
*  定义薪资项目
*  设置薪资规则
*  维护员工薪资信息
*  为计薪方案指定计薪期间

# 按钮说明

*  <[创建薪资记录](http://10.16.2.212/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：在用户选定打开的计薪方案、工作人事组织、计薪日期后，应首先点击该按钮，生成此计薪方案、工作人事组织、计薪日期下所有员工的薪资记录，并基于员工薪资档案计算生成各薪资档案项目值。之后，用户可手工维护非档案项目值，以及执行薪资计算。
*  <[查询](http://10.16.2.212/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：

员工薪资信息：查询选定员工的薪资档案、纳税方式、银行账号等信息。

员工补发信息：查询选定员工在当前的薪资补发信息。

*  <操作>下<[更新档案项目](http://10.16.2.212/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：在已创建过薪资记录后，如果有员工的薪资档案发生变动，可点击更新档案项目按钮，重新计算生成各薪资档案项目值。
*  <[计算应发](http://10.16.2.212/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)>：在用户手工维护完员工的非档案项目值后，可以点击计算应发按钮，生成各计算项目的值。

操作前提：

1）已创建员工薪资记录

2）已选定需要计算的人员

操作步骤：点击计算应发按钮，弹出人员范围对话框，在指定好人员范围后，点确定按钮执行薪资计算，并将计算结果显示在画面中。

注意：对于已锁定的员工，不再进行计算。

栏目说明

[基本栏目](http://10.16.2.212/U9C/help/zh-CN/Content/HR/PA/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|人员范围|系统提供四种选项。1、全部人员：为当前计薪方案、工作人事组织、计薪日期下的所有人员执行计算；2、当前页人员：为当前画面中全部人员执行计算；3、当前选中人员：为当前画面中手工选定的人员执行计算；4：符合条件人员：为当前计薪方案、工作人事组织、计薪日期下，符合以下指定条件的人员执行计算；|
|任职业务组织|人员范围为符合条件人员时，此项目可用；基于组织档案参照，选定组织；|
|任职部门|人员范围为符合条件人员时，此项目可用；基于部门档案参照，选定部门；|
|员工|人员范围为符合条件人员时，此项目可用；基于员工档案参照，选定员工；|

*  <相关功能>下<计薪期间>：点击该按钮，可导航至[计薪期间](/detail/3d786b2e542645dd9c94e6e90b39dbd5)。
*  <相关功能>下<薪资补发>：点击该按钮，可导航至[薪资补发](/detail/f7952e3bbcd344798cf4475cab0c23ff)
