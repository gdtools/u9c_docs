
# 功能描述

登录薪资中心，按计薪方案、工作人事组织，指定需要进行薪资计算的计薪日期、计薪期间、计税年月，并根据计薪期间确定需要计算、发放的薪资项目。

# 业务规则

*  在HR组织特性节点定义人事中心、薪资中心
*  在HR组织管理关系节点指定薪资中心负责薪资计算、发放的工作人事组织
*  定义薪资日历
*  定义计薪期间
*  定义薪资项目
*  定义计薪方案

# 栏目说明

表头栏目

|栏目|说明|
|---|---|
|计薪方案|基于参照，选定计薪方案|
|工作人事组织|基于参照，选定工作人事组织注意：只能选择当前登录薪资中心负责薪资计算、发放的工作人事组织|
|计薪日期|选择计薪日期|
|计税年|默认取自计薪日期，用户可修改；|
|计税月|默认取自计薪日期，用户可修改；|
|计薪期间-年|为计薪期间类型为年的薪资项目，指定本次计算的具体期间号|
|计薪期间-半年|为计薪期间类型为半年的薪资项目，指定本次计算的具体期间号|
|计薪期间-季度|为计薪期间类型为季度的薪资项目，指定本次计算的具体期间号|
|计薪期间-月|为计薪期间类型为月的薪资项目，指定本次计算的具体期间号|
|计薪期间-四周|为计薪期间类型为四周的薪资项目，指定本次计算的具体期间号|
|计薪期间-两周|为计薪期间类型为两周的薪资项目，指定本次计算的具体期间号|
|计薪期间-周|为计薪期间类型为周的薪资项目，指定本次计算的具体期间号|
|计薪期间-日|为计薪期间类型为日的薪资项目，指定本次计算的具体期间号|
|汇率类型|默认取自参数汇率类型|

员工发薪方案-表体

|栏目|说明|
|---|---|
|薪资项目|当前计薪方案、工作人事组织下，各非空计薪期间类型下的薪资项目，在用户点击生成薪资项目按钮后，由系统自动生成。|
|计薪期间类型|显示当前薪资项目的计薪期间类型|
|对应期间|显示当前薪资项目的实际计薪期间。基于表头中指定的计薪期间，以及当前薪资项目的执行计算期间、期间偏移量计算生成。例如：基本工资：执行计算期间为当前期间，表头中指定的计薪期间为2008-10，则对应期间为2008-10；奖金：执行计算期间为期间延后、期间偏移量为1，表头中指定的计薪期间为2008-10，则对应期间为2008-09；岗位补贴：执行计算期间为期间提前、期间偏移量为1，表头中指定的计薪期间为2008-10，则对应期间为2008-11；|
|发放情况|在通过发薪申请单将本薪资项目下所有员工的全部金额都已发放后（此时单据状态为关闭），将自动调整为已发放。|
