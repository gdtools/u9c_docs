
# 功能描述

登录员工的人事异动组织，进行试用期员工的转正处理。

# 业务规则

*  创建员工档案（必做）
*  定义转正单据类型（必做）

# 按钮说明

*  <操作>下<执行>按钮：

对审核通过的转正申请执行转正，则转正后的相关数据才进入人员档案，人员的状态才由试用转变为雇佣，申请单被关闭。

注意：在审核核准当前单据时，如果系统当前日期已大于等于转正日期，则系统将自动执行本单据；否则，在系统日期等于转正日期时，系统也将自动执行本单据。

操作前提：单据类型的“核准后自动执行”为否，即申请单需要手工执行。

单据状态=已核准。

*  <操作>下<作废>按钮：

将转正申请进行作废处理，作废后的单据不能进行审核和执行操作。

操作前提：创建入职单。

注意：只有状态为开立、核准中、已核准的转正申请单才能执行作废操作。

*  <操作>下<表格输出>按钮：同U9C统一输出功能描述。
*  <追溯查询>下<人员信息>按钮：显示员工信息弹窗，联查人员信息，通过[HR信息模板](http://10.16.226.67/U9C/help/zh-CN/Content/HR/HM/Function/CBO.HR.InfoTemplate.htm)，设置联查的模板并分配到转正功能节点。

操作前提：HR信息模板：分配到转正功能节点的联查模板

# 操作说明

*  通过点击菜单[转正](/detail/b71b1316a3de478f952c43f10705ac73)，进入转正申请单新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的转正申请单进行查找。
*  点击列表可查看已保存的全部转正申请单信息，允许删除。
