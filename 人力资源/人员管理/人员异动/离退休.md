
# 功能描述

实现离退休到期人员离退休业务的办理；

支持对离退休后挂在某个部门下继续发离退需工资的应用。

# 业务规则

*  定义离退休单据类型
*  定义离退休功能节点的人员信息联查模版
*  定义人员的人事异动活动组织。

# 按钮说明

*  <操作>下<执行>按钮：对于审核通过的单据，当点击执行按钮后，执行离退休，并关闭单据。

注意：在审核核准当前单据时，如果系统当前日期已大于等于离退休日期，则系统将自动执行本单据；否则，在系统日期等于离退休日期时，系统也将自动执行本单据。

操作前提：

单据状态=已核准；

单据类型的“核准后自动执行”为否，即申请单需要手工执行。

*  <操作>下<作废>按钮：

将离退休申请进行作废处理，作废后的单据不能进行审核和执行操作

操作前提：创建离退休单。

注意：只有状态为开立、核准中、已核准的离退休单才能执行作废操作。

*  <操作>下<表格输出>按钮：同U9C统一输出功能描述。
*  <追溯查询>下<人员信息>按钮：显示员工信息弹窗，联查人员信息，通过[HR信息模板](http://10.16.226.67/U9C/help/zh-CN/Content/HR/HM/Function/CBO.HR.InfoTemplate.htm)，设置联查的模板并分配到转正功能节点。

操作前提：HR信息模板：分配到转正功能节点的联查模板。

# 操作说明

*  通过点击菜单[离退休](/detail/a1d30c7e14a54340b475407ab5ce37a4)，进入离职退休申请单新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的离职退休申请单进行查找。
*  点击列表可查看已保存的全部离职退休申请单信息，允许删除。
