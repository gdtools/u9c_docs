
# 功能描述

登录员工的人事异动组织，进行员工的外派处理。

# 业务规则

*  定义外派单据类型
*  定义员工类别
*  定义组织
*  定义部门
*  定义职务
*  定义岗位
*  定义外派人员信息登记模版：注意：外派人员信息登记可以从系统预置的实体字段中以及用户自定义扩展的实体字段中选择，并且调整显示的位置，进行页签的分组。

# 按钮说明

*  <操作>下<执行>按钮：对于审核通过的单据，当点击执行按钮，执行员工外派，并关闭单据。

注意：在审核核准当前单据时，如果系统当前日期已大于等于外派开始日期，则系统将自动执行本单据；否则，在系统日期等于外派开始日期时，系统也将自动执行本单据。

操作前提：

单据状态=已核准；

单据类型的“核准后自动执行”为否，即申请单需要手工执行。

*  <操作>下<作废>按钮：

将外派申请单进行作废处理，作废后的单据不能进行审核和执行操作。

操作前提：创建外派申请单。

注意：只有状态为开立、核准中、已核准的外派申请单才能执行作废操作。

*  <操作>下<表格输出>按钮：同U9C统一输出功能描述。
*  <操作>下<编制检查>按钮：对要入职的职务、部门、业务组织、工作人事组织的编制进行检查，显示编制数、实有人数、以及缺超编人数。用作入职的参考条件，逐行显示入职的工作人事组织、业务组织、部门、职务当前的编制及实有情况，可以对检查的结果进行输出打印。

操作前提：HR信息模板：分配到转正功能节点的联查模板，且已经选择员工。

# 操作说明

*  通过点击菜单[外派](/detail/a55a1bde59c84d95948915b1c82a4d44)，进入外派申请单新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的外派申请单进行查找。
*  点击列表可查看已保存的全部外派申请单信息，允许删除。
