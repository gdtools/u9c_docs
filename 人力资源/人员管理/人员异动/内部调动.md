
# 功能描述

1、人事中心实现对员工内部调动申请的编辑和提交。

2、实现内部调动申请单的审核。

3、执行内部调动，将调动结果转入员工档案。

# 业务规则

*  定义内部调动单据类型（必做）
*  定义人员的人事异动活动组织

# 按钮说明

*  <操作>下<执行>按钮：对审核通过的内部调动申请执行调动，则调动后的相关数据才进入人员档案，调动前的任职信息进行相应的处理。申请单被关闭。

注意：在审核核准当前单据时，如果系统当前日期已大于等于员工的调动日期，则系统将自动执行该员工的内部调动；否则，在系统日期等于员工的调动日期时，系统也将自动执行该员工的内部调动。

操作前提：

单据类型的“核准后自动执行”为否，即申请单需要手工执行。

申请单审核通过。

*  <操作>下<作废>按钮：

将内部调动申请进行作废处理，作废后的单据不能进行审核和执行操作。

操作前提：创建内部调动申请。

注意：只有状态为开立、核准中、已核准的内部调动单才能执行作废操作。

*  <操作>下<表格输出>按钮：同U9C统一输出功能描述。
*  <操作>下<编制检查>按钮：对要入职的职务、部门、业务组织、工作人事组织的编制进行检查，显示编制数、实有人数、以及缺超编人数。用作入职的参考条件，逐行显示入职的工作人事组织、业务组织、部门、职务当前的编制及实有情况，可以对检查的结果进行输出打印。

# 操作说明

*  通过点击菜单[内部调动](/detail/fcda8d6e92ad48b0adb86879bdbd78e3)，进入内部调动单新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的内部调动单进行查找。
*  点击列表可查看已保存的全部内部调动单信息，允许删除。
