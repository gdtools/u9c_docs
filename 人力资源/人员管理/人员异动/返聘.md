
# 功能描述

登录员工的人事异动组织，进行退休员工的返聘入职。

# 业务规则

*  定义返聘单据类型
*  定义员工类别
*  定义组织
*  定义部门
*  定义职务
*  定义岗位
*  定义职称等级代码

# 按钮说明

*  <操作>下<执行>按钮：对于审核通过的单据，点击执行按钮后，执行返聘，并关闭单据。

注意　:

1、在审核核准当前单据时，如果系统当前日期已大于等于返聘日期，则系统将自动执行本单据；否则，在系统日期等于返聘日期时，系统也将自动执行本单据。

2、执行条件：只有在必须办理的内容都已完成后，单据才能执行成功。

操作前提

单据状态=已核准

单据类型的“核准后自动执行”为否，即申请单需要手工执行。

*  <操作>下<作废>按钮：

将返聘单进行作废处理，作废后的单据不能进行审核和执行操作。

操作前提：创建返聘单。

注意：只有状态为开立、核准中、已核准的返聘单才能执行作废操作。

*  <操作>下<表格输出>按钮：同U9C统一输出功能描述。
*  <操作>下<编制检查>按钮：对要返聘的职务、部门、业务组织、工作人事组织的编制进行检查，显示编制数、实有人数、以及缺超编人数。用作入职的参考条件。逐行显示返聘的工作人事组织、业务组织、部门、职务当前的编制及实有情况。可以对检查的结果进行输出打印。

操作前提:保存返聘单。

*  <后续处理>下<员工薪资信息>按钮：

导航到[员工薪资信息](/detail/ffab3eac8ff846eb8d348a435cff4ab8)。

注意：如果入职后员工的薪资组织不是当前登录组织，则点击后续处理-员工薪资信息后，无法显示该人员的信息。

操作前提：执行入职单，入职单状态=关闭。

# 操作说明

*  通过点击菜单[返聘](/detail/7b6e144387b341a0bf4a191534686f3f)，进入离退休返聘申请单新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的离退休返聘申请单进行查找。
*  点击列表可查看已保存的全部离退休返聘申请单信息，允许删除。
