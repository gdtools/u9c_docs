
# 功能描述

由人事中心负责实现新员工入职、离职员工再入职、调入人员入职。

# 业务规则

*  定义入职单据类型
*  定义入职渠道
*  定义员工类别
*  定义组织
*  定义部门
*  定义职务
*  定义岗位
*  定义HR基础档案，含学历、学位、专业、专业技术职务
*  定义国家/地区档案
*  定义地址档案
*  定义血型代码
*  定义宗教代码
*  定义健康状况代码
*  定义职称代码
*  定义职称等级代码
*  定义婚姻状况代码
*  定义政治面貌代码
*  定义社会关系代码
*  定义入职人员信息登记模版：注意　:入职人员信息登记可以从系统预置的实体字段中以及用户自定义扩展的实体字段中选择，并且调整显示的位置，进行页签的分组。

# 按钮说明

*  <操作>下<执行>按钮：对于审核通过的单据，点击<执行>按钮后，执行入职,并关闭单据。

注意：

1、在审核核准当前单据时，如果系统当前日期已大于等于入职日期，则系统将自动执行本单据；否则，在系统日期等于入职日期时，系统也将自动执行本单据。

1. 执行条件：只有在必须办理的内容都已完成后，单据才能执行成功。

操作前提：单据状态=已核准；单据类型的“核准后自动执行”为否，即申请单需要手工执行。

*  <操作>下<作废>按钮：

将入职单进行作废处理，作废后的单据不能进行审核和执行操作。

操作前提：创建入职单。

注意：只有状态为开立、核准中、已核准的入职单才能执行作废操作。

*  <操作>下<表格输出>按钮：同U9C统一输出功能描述。
*  <操作>下<编制检查>按钮：对要入职的职务、部门、业务组织、工作人事组织的编制进行检查，显示编制数、实有人数、以及缺超编人数。用作入职的参考条件，逐行显示入职的工作人事组织、业务组织、部门、职务当前的编制及实有情况，可以对检查的结果进行输出打印。

*  <后续处理>下<员工档案>按钮：

注意：如果入职后员工的信息维护权限不在当前登录组织，则执行后续处理-员工档案后，无法显示该人员的信息。

操作前提：执行入职单，且入职单状态=关闭。

注意：如果入职后员工的薪资组织不是当前登录组织，则点击后续处理-员工薪资信息后，无法显示该人员的信息。

注意：如果入职后员工的劳动合同组织不是当前登录组织，则点击后续处理-劳动合同后，无法显示该人员的信息。

操作前提：执行入职单，入职单状态=关闭。

*  <后续处理>下<员工保险福利档案>按钮：

# 操作说明

*  通过点击菜单[入职](/detail/8e4cdb1ff8f641a1972212ea46a14013)，进入入职单新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的入职单进行查找。
*  点击列表可查看已保存的全部入职单信息，允许删除。
