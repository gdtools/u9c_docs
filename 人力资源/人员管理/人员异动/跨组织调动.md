
# 功能描述

人事中心实现员工跨工作人事组织的调动的业务处理，直接实现员工从原工作组织的离职，目的工作人事组织的入职；

跨工作人事组织的调动可能导致人事归属组织的变化，该业务同时实现数据的处理。

# 业务规则

*  定义跨组织调动单据类型。
*  定义跨组织调动功能节点的人员信息联查模版。
*  定义人员的人事异动活动组织。

# 按钮说明

*  <操作>下<执行>按钮：对于审核通过的单据，当点击执行按钮，执行调动并关闭单据。

注意：在审核核准当前单据时，如果系统当前日期已大于等于员工的调动日期，则系统将自动执行该员工的跨组织调动；否则，在系统日期等于员工的调动日期时，系统也将自动执行该员工的跨组织调动。

操作前提：

单据状态=已核准；

单据类型的“核准后自动执行”为否，即申请单需要手工执行。

*  <操作>下<作废>按钮：

将跨组织调动单进行作废处理，作废后的单据不能进行审核和执行操作。

操作前提：创建跨组织调动单。

注意：只有状态为开立、核准中、已核准的跨组织调动单才能执行作废操作。

*  <操作>下<表格输出>按钮：同U9C统一输出功能描述。
*  <操作>下<编制检查>按钮：对要入职的职务、部门、业务组织、工作人事组织的编制进行检查，显示编制数、实有人数、以及缺超编人数。用作入职的参考条件，逐行显示入职的工作人事组织、业务组织、部门、职务当前的编制及实有情况，可以对检查的结果进行输出打印。

# 操作说明

*  通过点击菜单[跨组织调动](/detail/44a6c3673be14365966dffcc1b105aaa)，进入跨组织调动单新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的跨组织调动单进行查找。
*  点击列表可查看已保存的全部跨组织调动单信息，允许删除。
