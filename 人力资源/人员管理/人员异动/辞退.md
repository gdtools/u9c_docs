
# 功能描述

1、实现对辞退申请单的的编辑和提交。

2、实现辞退申请单的审核。

3、执行辞退，实现对员工雇佣信息和任职信息的结束处理。

# 业务规则

*  创建员工档案（必做）
*  定义辞退单据类型（必做）
*  定义辞退单据类型代码
*  定义人员类别档案

# 按钮说明

<操作>下<执行>按钮：对审核通过的辞退申请执行辞退，则辞退后的相关数据才进入人员档案，辞退前的任职信息进行相应的处理。申请单被关闭。

注意：在审核核准当前单据时，如果系统当前日期已大于等于辞退日期，则系统将自动执行本单据；否则，在系统日期等于辞退日期时，系统也将自动执行本单据。

操作前提：

单据状态=已核准；

单据类型的“核准后自动执行”为否，即申请单需要手工执行。

*  <操作>下<作废>按钮：

将辞退申请进行作废处理，作废后的单据不能进行审核和执行操作。

操作前提：创建辞退单。

注意：只有状态为开立、核准中、已核准的晋升降职单才能执行作废操作。

*  <操作>下<表格输出>按钮：同U9C统一输出功能描述。
*  <追溯查询>下<人员信息>按钮：显示员工信息弹窗，联查人员信息，通过[HR信息模板](http://10.16.226.67/U9C/help/zh-CN/Content/HR/HM/Function/CBO.HR.InfoTemplate.htm)，设置联查的模板并分配到转正功能节点。

操作前提：HR信息模板：分配到转正功能节点的联查模板。

# 操作说明

*  通过点击菜单[辞退](/detail/e02a8311fc134bd7a56b7b31ac596893)，进入辞退申请单新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的辞退申请单进行查找。
*  点击列表可查看已保存的全部辞退申请单信息，允许删除。
