
# 功能描述

登录员工的人事异动组织，进行员工的停薪留职处理。

# 业务规则

*  定义停薪留职单据类型
*  定义员工类别
*  定义组织
*  定义部门
*  定义职务
*  定义岗位
*  定义停薪留职人员信息登记模版：注意　:停薪留职人员信息登记可以从系统预置的实体字段中以及用户自定义扩展的实体字段中选择，并且调整显示的位置，进行页签的分组。

# 按钮说明

*  <操作>下<执行>按钮：对于审核通过的单据，当点击执行按钮，执行员工停薪留职，并关闭单据。

注意：在审核核准当前单据时，如果系统当前日期已大于等于停薪留职日期，则系统将自动执行本单据；否则，在系统日期等于停薪留职日期时，系统也将自动执行本单据。

操作前提：

单据状态=已核准；

单据类型的“核准后自动执行”为否，即申请单需要手工执行。

*  <操作>下<作废>按钮：

将停薪留职申请单进行作废处理，作废后的单据不能进行审核和执行操作。

操作前提：创建停薪留职申请单。

注意：只有状态为开立、核准中、已核准的停薪留职申请单才能执行作废操作。

*  <操作>下<停薪留职规定>按钮：点击可弹出停薪留职规定窗口，录入员工停薪留职的规定。栏目说明如下：

|栏目|说明|
|---|---|
|停薪留职原因|在表单中点击下划线录入停薪留职原因后，可选择|
|规定时长（月）|指当前原因下，停薪留职的时长|
|规定说明|文本录入|

*  <操作>下<表格输出>按钮：同U9C统一输出功能描述。
*  <追溯查询>下<人员信息>按钮：显示员工信息弹窗，联查人员信息，通过[HR信息模板](http://10.16.226.67/U9C/help/zh-CN/Content/HR/HM/Function/CBO.HR.InfoTemplate.htm)，设置联查的模板并分配到转正功能节点。操作前提：HR信息模板：分配到转正功能节点的联查模板。

# 操作说明

*  通过点击菜单[停薪留职](/detail/4c173436e0ee4a38aa250ed756bbce10)，进入停薪留职单新增画面，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的停薪留职单进行查找。
*  点击列表可查看已保存的全部停薪留职单信息，允许删除。
