
# 功能描述

本功能节点完成对员工的增加、员工信息的维护、查询和输出以及人员的删除。

# 业务规则

*  定义类型为人员的联系对象。
*  定义员工类别。
*  定义国家/地区档案。
*  定义地址档案。
*  定义血型代码。
*  定义宗教代码。
*  定义健康状况代码。
*  定义职称代码。
*  定义职称等级代码。
*  定义婚姻状况代码。
*  定义政治面貌代码。
*  定义社会关系代码。
*  定义奖励类型代码。
*  定义惩罚类型代码。
*  定义HR基础档案，含学历、学位、专业、专业技术职务。
*  定义人员信息维护模版：注意　:人员信息模版可以从系统预置的实体字段中以及用户自定义扩展的实体字段中选择，并且调整显示的位置，进行页签的分组。产品中预置的实体和字段如下。

# 按钮说明

*  <分组>中<XXX>

将人员的页签按分组进行显示，并且能够按组进行切换。其中基本信息、员工工作记录页签是必选的页签，其他页签根据用户需要进行裁减或添加自定义扩展的实体页签。

操作前提：基础设置/HR信息模版：设置人员信息模版，对人员的页签进行分组。

操作步骤：

第1步：点击<分组>中<XXX>按钮，界面上的页签切换为选择分组下的页签。

第2步-举例：

将人员的页签分为基础档案、工作信息、业务跟踪信息。则分组下有三个按钮：基础档案、工作信息、业务跟踪信息。

点[基础档案]按钮，则显示该分组内的页签，点[工作信息]按钮，则显示该分组内的页签

第3步：可对选择的页签行进行新增、插入和删除。

# 操作说明

*  操作-其他工作记录

以列表的方式显示人员在其他工作人事中心的工作记录，适用于一个人员在多个工作人事组织任职的情形。

操作步骤：

第1步：点击操作->其他工作记录，进入其他工作记录列表画面。

第2步：可以进行查询操作，默认显示全部。

第3步：点击确定返回调用画面，以选择行的员工工作记录替代原来的员工工作记录，点击取消返回调用画面。

*  [操作-业务执行组织设置](http://10.16.2.212/U9C/help/zh-CN/Content/HR/HM/Function/javascript:void(0);)

设置员工的业务执行组织。

操作步骤

第1步：点击操作->业务执行组织设置，弹出业务执行组织设置画面。

栏目

|栏目|说明|
|---|---|
|人事异动组织|有权为员工进行人事异动处理（如转正、调动）的组织。可以选择：人事归属组织、工作人事组织。|
|薪资信息组织|有权维护员工薪资信息、发薪/扣款计划、以及进行薪资调整的组织。可以选择：人事归属组织、工作人事组织。|
|勤务组织|有权维护员工考勤数据、考核数据的组织。可以选择：人事归属组织、工作人事组织。|
|劳动合同组织|有权维护员工劳动合同、劳动争议的组织。可以选择：人事归属组织、工作人事组织。|

第2步：在业务执行组织设置画面，指定业务执行组织。

第3步：点击确定按钮，保存并返回调用画面，点击取消按钮，放弃并返回调用画面。

*  [操作-查找历史人员](http://10.16.2.212/U9C/help/zh-CN/Content/HR/HM/Function/javascript:void(0);)

在增加员工时，可以增加系统内没有的人员，即录入人员的所有信息，也可以增加系统内已有的人员，即先调出人员的已有信息，再录入其员工工作记录，从而实现历史人员再入职，或者是系统内已有人员在当前工作人事组织内的任职。

历史人员包括：没有人事中心的人员、从其他人事中心离职的员工、当前人事中心管理范围内的人员。


操作步骤：

第1步：点击操作->查找历史人员，以列表的方式显示历史人员。

第2步：可以进行查询操作。默认显示全部。

第3步：选择人员点击确定返回调用画面，以选择行人员的信息填充画面上的栏目。

第4步：维护员工工作记录，编辑人员相关信息。

第5步：点击保存或取消。

*  [操作-表格输出](http://10.16.2.212/U9C/help/zh-CN/Content/HR/HM/Function/javascript:void(0);)：基于word模版输出人员履历表。

操作前提：用word制作人员履历表模版并上载。

栏目说明：[模版管理](http://10.16.2.212/U9C/help/zh-CN/Content/HR/HM/Function/javascript:void(0);)--模板是文档的存放地址，参照弹出文档管理器，选择文件，点击列标题，实现空白表格的打开或下载。

操作说明：

A)通过行操作实现实现增加、插入、删除。

B)点击行操作增加按钮：弹出模版选择画面,选择文件，当文件不存在时刻实现文件的上载。

C)选择行，点击操作删除按钮：删除行，表示取消模版。

D)业务员:基础设置的参数设置中业务员同步人员编码：同步可以选取员工设置业务员角色，且员工的人员编码和业务员的编码同步；如果基础设置的参数设置中业务员同步人员编码：不同步，此功能不可用。

*  操作-审批参数：U9C统一功能。
*  操作-打印工牌：可直接连接打印机进行工牌打印。
