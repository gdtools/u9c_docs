
# 功能描述

人员黑名单管理。

# 业务规则

*  人员离职后才能加入黑名单。

# 栏目说明

人员基本信息

|栏目|说明|
|---|---|
|人员|选择员工|
|证件号码|自动带出|
|性别|自动带出|
|出生日期|自动带出|
|婚姻状况|自动带出|
|户籍|自动带出|

黑名单信息

|栏目|说明|
|---|---|
|加入原因|文本录入|
|录入单位|选择组织机构，默认当前组织|
|录入日期|默认当前日期，可修改|
|录入人|选择录入人员|
|开始日期|默认当前日期，可修改|
|结束日期|选择结束日期|
|备注|文本录入|

# 操作说明

*  通过点击菜单[人员黑名单](/detail/73fed4f37d9f48a099fdba796ecc378d)，进入单据类型新增画面，选择已离职的人员，填写表单信息，完成单据的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的人员黑名单进行查找。
*  点击列表可查看已保存的全部人员黑名单信息。
