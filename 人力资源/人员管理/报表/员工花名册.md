
# 功能描述

按用户自定义查询条件，输出员工花名册。

# 业务规则

*  系统启用人事管理模块。

# 栏目说明

员工花名册－查询方案

|栏目|说明|
|---|---|
|统计范围|人事归属组织：查询人事归属组织为当前登录组织的员工；工作人事组织：查询工作人事组织为选定组织的员工；|
|工作人事组织|按选定的工作人事组织查询|
|员工类别|按选定的员工类别查询|
|业务组织|按选定的业务组织查询|
|部门|按选定的部门查询|
|职务|按选定的职务查询|
|职级职等|按选定的职级职等查询|
|入职日期|指定查询员工的入职日期范围|
|任职类型|按选定的任职类型查询|
|离职类型|按选定的离职类型查询|
|离职日期|指定查询员工的离职日期范围|

# 按钮说明

*  <查询>：点击该按钮，进入员工花名册画面。在查询方案对话框，指定查询条件后，显示查询出的员工花名册。

# 操作说明

*  通过点击菜单[员工花名册](/detail/3d579211e7774113a496e58cef88a9da)进入报表画面，选择查询条件，可按条件查询报表。
*  设置查询方案后，点击<确定>可进入查询结果列表。
