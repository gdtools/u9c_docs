
# 功能描述

按指定的统计期间，对指定组织、部门、职务的编制数以及相应员工的实际任职人数、在编人数、兼职人数、缺超编人员进行分析。

# 业务规则

*  定义统计期间
*  执行统计更新

# 栏目说明

任职情况表－查询方案

|栏目|说明|
|---|---|
|报表类型|组织任职情况：按任职组织统计员工的任职情况；部门任职情况：按部门统计员工的任职情况；职务任职情况：按职务统计员工的任职情况；|
|工作人事组织|按选定的工作人事组织查询|
|任职组织|按选定的任职组织查询|
|部门|按选定的部门查询|
|职务|按选定的职务查询|
|机构人员范围|本级人员：对各任职组织、部门，只查询本级直接包含的人员；含下级机构人员：对各任职组织、部门，只查询本级及含下级的人员；本级及含下级人员：对各任职组织、部门，分别查询本级直接包含的人员，和本级及含下级的人员；|
|统计期间|选择采用的统计期间规则|
|期间|按照选定的统计期间，基于当前登录日期，选择：当前期间、上一期间、去年同期、指定期间|
|指定期间|当期间为指定期间时，可用；指定一具体的统计期间；|
|统计类型|可以统计：期间平均人数、期初人数、期末人数；|

任职情况表－任职情况画面

|栏目|说明|
|---|---|
|工作人事组织|按工作人事组织进行统计|
|任职组织|按任职组织进行统计|
|部门|按部门进行统计|
|职务|按职务进行统计|
|含下级|指本行是否包含下级部门一起统计|
|编制|显示当前工作人事组织、任职组织、部门、职务，在截止日期的编制数统计类型为期初人数时：取统计期间开始日期时的编制；统计类型为期末人数时：取统计期间结束日期时的编制；统计类型为期间平均人数时：取统计期间结束日期时的编制；|
|任职数|统计类型为期初人数时：取统计期间开始日期时的任职人数；统计类型为期末人数时：取统计期间结束日期时的任职人数；统计类型为期间平均人数时：（期初的任职人数+期末的任职人数）/2；注意：任职数 不等于任职人数。例如：员工在某部门下除主岗任职外、还有一兼职，则任职数为2。|
|其中在编人数|统计类型为期初人数时：取统计期间开始日期时的在编人数；统计类型为期末人数时：取统计期间结束日期时的在编人数；统计类型为期间平均人数时：（期初的在编人数+期末的在编人数）/2；|
|其中兼职人数|统计类型为期初人数时：取统计期间开始日期时的兼职人数；统计类型为期末人数时：取统计期间结束日期时的兼职人数；统计类型为期间平均人数时：（期初的兼职人数+期末的兼职人数）/2；|
|超编|如果“在编人数”大于“编制数”，则显示差额|
|缺编|如果“在编人数”小于“编制数”，则显示差额|

# 按钮说明

*  <查询>：点击该按钮，进入任职情况表画面。在查询方案对话框，指定查询条件后，显示查询出的任职情况表。

# 操作说明

*  通过点击菜单[入职情况表](/detail/35cbf778e377480fb5551a4af8beb788)进入报表画面，选择查询条件，可按条件查询报表。
*  设置查询方案后，点击<确定>可进入查询结果列表。
