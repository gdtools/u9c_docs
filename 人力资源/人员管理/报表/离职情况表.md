
# 功能描述

按指定的统计期间，对指定组织、部门、职务上的期末人数、期间离职人数以及离职率进行分析。

# 业务规则

*  定义统计期间
*  执行统计更新

# 栏目说明

离职情况表－查询方案

|栏目|说明|
|---|---|
|报表类型|组织离职情况：按任职组织统计员工的离职情况；部门离职情况：按部门统计员工的离职情况；职务离职情况：按职务统计员工的离职情况；|
|工作人事组织|按选定的工作人事组织查询|
|任职组织|按选定的任职组织查询|
|部门|按选定的部门查询|
|职务|按选定的职务查询|
|机构人员范围|本级人员：对各任职组织、部门，只查询本级直接包含的人员；含下级机构人员：对各任职组织、部门，只查询本级及含下级的人员；本级及含下级人员：对各任职组织、部门，分别查询本级直接包含的人员，和本级及含下级的人员；|
|统计期间|选择采用的统计期间规则|
|期间|按照选定的统计期间，基于当前登录日期，选择：当前期间、上一期间、去年同期、指定期间|
|指定期间|当期间为指定期间时，可用；指定一具体的统计期间；|

离职情况表－离职情况画面

|栏目|说明|
|---|---|
|工作人事组织|按工作人事组织进行统计|
|任职组织|按任职组织进行统计|
|部门|按部门进行统计|
|职务|按职务进行统计|
|含下级|指本行是否包含下级部门一起统计|
|期末人数|统计期间期末的：任职数—兼职人数；|
|期间离职人数|统计期间从开始日期到结束日期的：离职人数；|
|离职率|离职率 = 期间离职人数 / 期末人数 + 期间离职人数|

# 按钮说明

*  <查询>：点击该按钮，进入离职情况表画面。在查询方案对话框，指定查询条件后，显示查询出的离职情况表。

# 操作说明

*  通过点击菜单[离职情况表](/detail/f5d9c7ea86aa4c598c6b8a1bef20ef89)进入报表画面，选择查询条件，可按条件查询报表。
*  设置查询方案后，点击<确定>可进入查询结果列表。
