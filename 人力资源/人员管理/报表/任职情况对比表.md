
# 功能描述

对指定组织、部门、职务的实际任职数按指定的基准期、比较期进行对比分析，并计算出变动人数和变动率。

# 业务规则

*  定义统计期间
*  执行统计更新

# 栏目说明

任职情况对比表－查询方案

|栏目|说明|
|---|---|
|报表类型|组织任职情况对比：按任职组织进行员工任职情况对比；部门任职情况对比：按部门进行员工任职情况对比；职务任职情况对比：按职务进行员工任职情况对比；|
|工作人事组织|按选定的工作人事组织查询|
|任职组织|按选定的任职组织查询|
|部门|按选定的部门查询|
|职务|按选定的职务查询|
|机构人员范围|本级人员：对各任职组织、部门，只查询本级直接包含的人员；含下级机构人员：对各任职组织、部门，只查询本级及含下级的人员；本级及含下级人员：对各任职组织、部门，分别查询本级直接包含的人员，和本级及含下级的人员；|
|统计期间|选择采用的统计期间规则|
|期间|按照选定的统计期间，基于当前登录日期，选择：当前期间与上一期间、当前期间与去年同期、指定期间|
|基本期间|当期间为指定期间时，可用；|
|比较期间|当期间为指定期间时，可用；|
|对比类型|提供三种对比类型：期间平均人数 期初人数 期末人数|
|统计人员类型|可以按以下人员类型统计：任职人员、在编人员、主任职人员、兼职人员|

任职情况对比表－任职情况对比画面

|栏目|说明|
|---|---|
|工作人事组织|按工作人事组织进行统计|
|任职组织|按任职组织进行统计|
|部门|按部门进行统计|
|职务|按职务进行统计|
|含下级|指本行是否包含下级部门一起统计|
|基本期人数|对比类型为期初人数时：取基本期间开始日期时的人数；对比类型为期末人数时：取基本期间结束日期时的人数；对比类型为期间平均人数时：（期初人数+期末人数）/ 2；|
|比较期人数|对比类型为期初人数时：取比较期间开始日期时的人数；对比类型为期末人数时：取比较期间结束日期时的人数；对比类型为期间平均人数时：（期初人数+期末人数）/ 2；|
|变动人数|变动人数 = 基本期人数-比较期人数|
|变动比率|变动比率 =(基本期人数-比较期人数) / 基本期人数|

# 按钮说明

*  <查询>：点击该按钮，进入任职情况对比表画面。在查询方案对话框，指定查询条件后，显示查询出的任职情况对比表。

# 操作说明

*  通过点击菜单[任职情况对比表](/detail/0d013f8fa88646638a86d4b181ea883e)进入报表画面，选择查询条件，可按条件查询报表。
*  设置查询方案后，点击<确定>可进入查询结果列表。
