
# 功能描述

查询指定组织、部门、职务，在指定日期范围、入职渠道上的入职员工数量，及在一定时间段内的人员流失情况。

# 业务规则

*  入职情况表－查询方案
*  入职情况表－查询结果画面

# 栏目说明

入职情况表－查询方案

|栏目|说明|
|---|---|
|报表类型|组织入职情况：按任职组织统计员工的入职情况；部门入职情况：按部门统计员工的入职情况；职务入职情况：按职务统计员工的入职情况；|
|工作人事组织|按选定的工作人事组织查询|
|任职组织|按选定的任职组织查询|
|部门|按选定的部门查询|
|职务|按选定的职务查询|
|来自招聘|指定是否只查询招聘人员|
|日期范围|基于当前登录日期，提供以下选项：本月、本季、半年、本年、上月、上季、去年、指定日期|
|日期|当日期范围选为指定日期时，可用；指定查询的起止日期；|
|离职时间|指定一个时间长度，用于查询入职人员在此时间长度内的离职情况|
|离职时间单位|提供以下选项：日、周、月、季、年|
|职务分类|按选定的职务分类查询|
|岗位分类|按选定的岗位分类查询|

入职情况表－查询结果画面

|栏目|说明|
|---|---|
|工作人事组织|按工作人事组织进行统计|
|任职组织|按任职组织进行统计|
|部门|按部门进行统计|
|职务|按职务进行统计|
|含下级|指本行是否包含下级部门的员工|
|职务类别|按职务类别进行统计|
|岗位类别|按岗位类别进行统计|
|入职类型|按入职类型进行统计|
|任职类型|按任职类型进行统计|
|入职渠道|按入职渠道进行统计|
|来自招聘|指本行是否只统计招聘的人数|
|入职人数|符合查询条件的入职人员的数目|
|离职人数|符合本行条件的入职人员中，在指定离职时间段内的离职人数|
|流失率|流失率 = 离职人数 / 入职人数|

# 按钮说明

*  <查询>：点击该按钮，进入入职情况表画面。在查询方案对话框，指定查询条件后，显示查询出的入职情况表。

# 操作说明

*  通过点击菜单[入职情况表](/detail/35cbf778e377480fb5551a4af8beb788)进入报表画面，选择查询条件，可按条件查询报表。
*  设置查询方案后，点击<确定>可进入查询结果列表。
