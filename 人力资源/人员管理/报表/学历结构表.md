
# 功能描述

实现指定组织、部门、职务上的员工学历分析。

# 业务规则

*  定义统计期间
*  执行统计更新

# 栏目说明

学历结构表－查询方案

|栏目|说明|
|---|---|
|报表类型|组织学历结构：按任职组织统计员工的学历结构；部门学历结构：按部门统计员工的学历结构；职务学历结构：按职务统计员工的学历结构；|
|工作人事组织|按选定的工作人事组织查询|
|任职组织|按选定的任职组织查询|
|部门|按选定的部门查询|
|职务|按选定的职务查询|
|机构人员范围|本级人员：对各任职组织、部门，只查询本级直接包含的人员；含下级机构人员：对各任职组织、部门，只查询本级及含下级的人员；本级及含下级人员：对各任职组织、部门，分别查询本级直接包含的人员，和本级及含下级的人员；|
|统计期间|选择采用的统计期间规则|
|期间|按照选定的统计期间，基于当前登录日期，选择：当前期间、上一期间、去年同期、指定期间|
|指定期间|当期间为指定期间时，可用；指定一具体的统计期间；|
|统计人员类型|可以统计：任职人员、在编人员、主任职人员、兼职人员 ；|
|学历|选择需要统计的学历|

学历结构表－学历结构画面

|栏目|说明|
|---|---|
|工作人事组织|按工作人事组织进行统计|
|任职组织|按任职组织进行统计|
|部门|按部门进行统计|
|职务|按职务进行统计|
|学历|在当前统计期间，各学历下的人数；|

# 按钮说明

*  <查询>：点击该按钮，进入学历结构表画面。在查询方案对话框，指定查询条件后，显示查询出的学历结构表。

# 操作说明

*  通过点击菜单[学历结构表](/detail/b8c85a7e16e94c08b8dd15afbed4ed67)进入报表画面，选择查询条件，可按条件查询报表。
*  设置查询方案后，点击<确定>可进入查询结果列表。
