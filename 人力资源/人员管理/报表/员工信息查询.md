
# 功能描述

基于指定条件，查询员工记录；并基于员工，查询员工的基础档案、资格及能力、人员其他信息、员工工作相关信息、人事异动、考勤考核数据、人员、岗位/职务能力对比、人员、岗位/职务能力对比、人员、岗位/职务训练要求对比、人员、岗位/职务证件要求对比、员工信息档案、员工信息发放记录、保险福利档案。

# 业务规则

*  存在员工信息

# 栏目说明

员工信息查询－查询方案

|栏目|说明|
|---|---|
|人事归属组织|按选定的人事归属组织查询|
|工作人事组织|按选定的工作人事组织查询|
|员工类别|按选定的员工类别查询|
|现任业务组织|按选定的现任业务组织查询|
|现任部门|按选定的现任部门查询|
|现任职务|按选定的现任职务查询|
|现任岗位|按选定的现任岗位查询|
|职级职等|按选定的职级职等查询|
|入职日期|指定查询员工的入职日期范围|
|任职类型|按选定的任职类型查询|
|离职类型|按选定的离职类型查询|
|离职日期|指定查询员工的离职日期范围|

# 按钮说明

*  <查询>：点击该按钮，进入员工工作记录和员工任职记录画面。在员工工作记录列表中，双击选定的员工行后，员工任职列表中将显示该行员工的信息。
*  <追溯查询-基础档案>：点击该按钮，进入基础档案查询画面。
*  <追溯查询-资质及能力>：点击该按钮，进入资质及能力查询画面。
*  <追溯查询-人员其他信息>：点击该按钮，进入人员其他信息查询画面。
*  <追溯查询-员工工作相关信息>：点击该按钮，进入员工工作相关信息查询画面。
*  <追溯查询-员工异动信息>：点击该按钮，进入员工异动信息查询画面。
*  <追溯查询-考核考勤数据>：点击该按钮，进入考核考勤数据查询画面。
*  <追溯查询-任职资格对比>：点击该按钮，进入任职资格对比查询画面。
*  <追溯查询-能力对比>：点击该按钮，进入能力对比查询画面。
*  <追溯查询-训练要求对比>：点击该按钮，进入训练要求对比查询画面。
*  <追溯查询-证件要求对比>：点击该按钮，进入证件要求对比查询画面。
*  <追溯查询-员工薪资档案>：点击该按钮，进入员工薪资档案查询画面。
*  <追溯查询-员工保险福利档案>：点击该按钮，弹出员工缴费基数记录查询窗口。

# 操作说明

*  通过点击菜单[员工信息查询](/detail/c5e867569b084ff8b35278d42e9f1d4a)进入报表画面，选择查询条件，可按条件查询报表。
*  设置查询方案后，点击<确定>可进入查询结果列表。
