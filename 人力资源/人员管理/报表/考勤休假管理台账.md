
# 功能描述

按指定的统计期间，对指定组织、部门、员工类别的人员休假数据进行分析。

# 业务规则

*  定义统计期间
*  执行统计更新

# 栏目说明

考勤休假管理台账－查询方案

|栏目|说明|
|---|---|
|年度|选择考勤年度|
|期间号|填写期间号|
|工作人事组织|按选定的工作人事组织查询|
|任职组织|按选定的任职组织查询|
|部门|按选定的部门查询|
|员工类别|按选定的员工类别查询|
|状态|按选定的状态查询|
|扩展列栏目|必填项，选择考勤项目|

# 按钮说明

*  <查询>：点击该按钮，进入考勤休假管理台账画面。在查询方案对话框，指定查询条件后，显示查询出的考勤休假数据。

# 操作说明

*  通过点击菜单[考勤休假管理台账](/detail/f861db31e2ca4e8297ce2fcbc17a385a)进入报表画面，选择查询条件，可按条件查询报表。
*  设置查询方案后，点击<确定>可进入查询结果列表。
