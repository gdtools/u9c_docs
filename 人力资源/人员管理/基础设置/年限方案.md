
# 功能描述

年限方案是基于年龄、工龄、内部工龄，定义各组织间通用的年限方案，主要用于各种年龄段、工龄段、内部工龄段的统计。

# 栏目说明

年限方案-表头

|栏目|说明|
|---|---|
|编码|年限方案的编码。|
|名称|年限方案的名称。|
|描述|当前年限方案的业务介绍。|
|年限项目|提供三种选择：年龄、工龄、内部工龄|
|区间模式|支持四种模式：1、下限 <= 年限 <= 上限2、下限 < 年限 <= 上限3、下限 <= 年限 < 上限4、下限 < 年限 < 上限|

年限方案-表体

|栏目|说明|
|---|---|
|区间名称|年限区间的名称。|
|下限|年限区间的下限。|
|上限|年限区间的上限。|

# 按钮说明

*  <查询>：点击该按钮可进入查询画面，可按照条件查询年限方案。

# 操作说明

*  通过点击菜单[年限方案](/detail/c855c34f1f374876abb2fe9722934eb4)，进入公共年限方案列表画面。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的年限方案进行查找。
*  点击列表可查看已保存的全部年限方案信息。
