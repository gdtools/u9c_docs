
# 功能描述

公共薪资项目一般用于人员异动时，要调整的薪资项目，比如岗位底薪，可能在升职或者转正的时候，联动调整金额，此时需要使用公共薪资项目。

# 业务规则

*  若为金额类型的，建议全部用货币，若是用数字，则需要指定精度（需要跟人力资源管理部门和财务共同明确）。
*  若该薪资项目需要进入员工薪资档案，则需要勾选档案项目。
*  该薪资项目在生效日期内生效。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|必填项|
|名称|必填项|
|简称|非必填|
|数据类型|必填项，可选择：字符、数值、货币、日期、是/否、枚举、档案|
|值集|枚举、档案类型的可选择弹性域字段|
|精度|数值类型的需要设置精度|
|描述|文本字段，非必填项|
|档案项目|若勾选，可显示在员工薪资档案中|
|对应薪资发放字段|系统自动生成|
|生效|勾选是否生效|
|生效日期|设置生效日期|
|失效日期|设置失效日期|

# 操作说明

*  通过点击菜单[公共薪资项目](/detail/4c5733c1ad8c40c498029e8c97f5eb7b)，进入公共薪资项目新增画面，填入所需字段完成公共薪资项目的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的公共薪资项目进行查找。
*  点击列表可查看已保存的全部公共薪资项目信息。
