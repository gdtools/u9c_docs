
# 功能描述

证件号码校验规则，与生效时间结合使用，可用于校验员工档案中的证件号码。

# 业务规则

*  不建议勾选“严格校验”，否则很多身份证号码将不符合国家原定的原则，员工档案录入会报很多错误。

# 栏目说明

表体信息

|栏目|说明|
|---|---|
|国家/地区|必填项|
|证件类别|必填项，封闭枚举|
|规则说明|文本描述信息|
|规则|可设置公式函数|
|严格校验|勾选/不勾选|
|生效|生效功能为U9C统一规则|

# 操作说明

*  通过点击菜单[证件号码校验规则](/detail/ed45c4a31c8f430185cbc8effacd2b3a)，进入身份证号码校验规则新增画面，填写栏目字段完成创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的身份证号码校验规则进行查找。
*  点击列表可查看已保存的全部身份证号码校验规则信息。
