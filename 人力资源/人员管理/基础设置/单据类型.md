
# 功能描述

对于入职、离退休人员返聘、转正、调配、离职、劳动合同、编制计划等业务，需要设置其相应的单据类型。

设置单据类型的作用：

*  可以根据单据类型配置不同的审批流；
*  指定单号生成方式。
*  指定单据办理内容。

# 业务规则

*  自动编号时需要先定义单据编码规则。

# 栏目说明

表头

|栏目|说明|
|---|---|
|人事单据分类|包括以下几种类型：入职、离退休人员返聘、转正、调配、离职、劳动合同、编制计划|
|人事单据类型|对于不同的人事单据分类，对应有相应的单据类型。入职下有：入职单；离退休人员返聘下有：离退休返聘申请单；转正下有：转正申请单；调配下有：员工类别变更单、内部调动申请单、跨组织调动申请单、晋升降职申请单、停薪留职申请单、兼职借调申请单、任免申请单、外派申请单；离职下有：离职申请单、离退休申请单、辞退申请单、兼职借调结束申请单；劳动合同下有：劳动合同变更征询单、劳动合同续签征询单、劳动合同解除单；编制计划下有：编制计划申请单、编制计划变更单；|

表体-入职单类型

|栏目|说明|
|---|---|
|编码|单据类型的编码。|
|名称|单据类型的名称。|
|简称|单据类型的简称。|
|描述|单据类型的描述。|
|同时调整薪资|指定单据的调资页签是否可用。|
|是否整单审批|指定提交单据时，是整单审批还是按单据行审批。|
|确认方式|选择单据审核确认的方式：1.确认作业：即单据需要提供单独的审核操作按钮，执行审核处理；2.审批流程：即单据需要执行多个审核环节，需要设置审批流程。|
|审核后自动执行|指定单据被核准后，是系统自动执行单据，还是由用户手工执行；|
|编号方式|选择单据号的编号方式。1.手工编号：即单据号手工录入。2.自动编号：即由系统根据编号规则，自动生成每张单据的单据编号。此种方式下需要设置编号规则。|

表体-办理内容

|栏目|说明|
|---|---|
|办理内容|指定单据的办理内容|
|必须|指定是否必须办理|
|负责岗位|指定负责岗位|
|负责人|指定负责人|

# 操作说明

*  通过点击菜单[单据类型](/detail/2d8ad58275ab4aaa8b0341a4dfad2b60)，进入单据类型新增画面，选择入职单据分类和人事单据类型，再在入职单类型和办理内容页签分别填入相应内同，完成单据类型的创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的单据类型进行查找。
*  点击列表可查看已保存的全部单据类型信息。
