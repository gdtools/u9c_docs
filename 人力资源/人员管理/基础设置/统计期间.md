
# 功能描述

设置每个应用系统的统计数据使用的统计规则。

# 业务规则

*  必须定义统计规则。

# 栏目说明

统计规则画面

|栏目|说明|
|---|---|
|应用系统|显示设置统计期间的应用系统名称。|
|统计表名|选择当前应用系统中需要的执行统计功能的报表。|
|期间类型|默认为统计期间|
|期间规则|录入统计表的统计规则。参照统计规则档案录入。点击链接，弹出统计规则编辑查询画面，可以在线新增统计规则数据。|

# 操作说明

*  通过点击菜单[统计期间](/detail/f77b64c6640e4db6a3ea51ffa4f85989)，进入统计期间新增画面，填写栏目字段完成创建。
*  点击<保存>可以对编辑修改的内容进行保存。
*  点击<查找>可以对已保存的统计期间进行查找。
*  点击列表可查看已保存的全部统计期间信息。
