
# 功能描述

登录员工的勤务组织后，在本功能节点可以维护员工的考勤数据，支持批量导入考勤数据。

# 业务规则

*  员工考勤核对单审批通过后，期末出勤结果状态从“已计算”变为“已审核”时，可从节点查看员工考勤数据。
*  直接OBA导入员工考勤数据。

# 按钮说明

|栏目|说明|
|---|---|
|档案名称|考勤记录|
|确认方式|枚举：即时确认、确认作业、审批流程|
|核准后可改|表示记录审核通过后，可以再修改。|
|核准后修改重核|表示记录审核通过后，再修改需要重新审核。|

*  <操作>下<审核参数>按钮：点击审核参数按钮，在审核参数对话框中设置审核参数，栏目说明如下：
*  <操作>下<全部提交>按钮：在列表画面，对于当前的查询结果，全部提交审核。
*  <操作>下<审核>按钮：核准提交的考勤记录。
*  <考勤数据导入>按钮：导入Execl格式的员工考勤数据文件。点击<考勤数据导入>按钮，弹出考勤数据导入对话框。在对话框中，指定年度、期间类型、期间号，并通过浏览按钮选择考勤数据文件后，点击<导入>按钮，系统将根据文件中的员工编号，导入考勤数据。

注意：执行导入时，系统是以当前登录组织为工作人事组织，按员工编号查询该组织下的员工。

操作前提：应首先点击导出文件模板，按导出的文件模板格式，生成的考勤数据文件才能被正确导入。

*  <导出文件模板>按钮：核准提交的考勤记录。

# 操作说明

*  通过点击菜单[考勤数据维护](/detail/85b0531fed75436ea4bd4022381d0e0c)，进入考勤数据列表画面，可按年度查看员工考勤数据。
*  点击<查找>可以对已存在的员工考勤数据进行查找，不支持直接删除或新增，若想删除，需要在<考勤管理:日常操作:考勤核对单>中进行弃审，弃审后，此处员工考勤数据可自动删除。
