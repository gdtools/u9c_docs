
# 功能描述

基于用户指定的人员范围，查询并输出兼职借调截止日期在提前天数内的人员名单。

# 业务规则

*  在职员工存在兼职或被借调

# 栏目说明

兼职借调到期提醒－查询方案

|栏目名称|说明|
|---|---|
|提前天数|查询兼职借调截止日期在距当前登录日期指定天数或指定天数之内的人员|
|工作人事组织|查询指定工作人事组织下的人员|
|现任业务组织|查询指定现任业务组织下的人员|
|现任部门|查询指定现任部门下的人员|
|现任职务|查询指定现任职务下的人员|
|现任岗位|查询指定现任岗位下的人员|
|员工类别|查询指定员工类别下的人员|

# 按钮说明

*  <查询>：点击该按钮，进入兼职借调到期人员列表画面。在查询方案对话框，指定查询条件后，显示查询出的兼职借调到期人员名单。
