
# 功能描述

登录员工的勤务组织后，在本功能节点可以维护员工的考核数据，支持批量导入考核数据。

# 栏目说明

考核数据画面

|栏目|说明|
|---|---|
|考核年度|注意：为方便薪资计算时获取考核数据，考核年度应与薪资年度相同。|
|考核类型||
|期间号|注意：为方便薪资计算时获取考核数据，考核期间号应与薪资计薪期间号相同。|
|员工|勤务组织为当前登录组织的在职员工|
|现任业务组织||
|现任部门||
|考核组织||
|考核负责人||
|考核应用||
|考核结果||
|考核日期||
|状态|枚举：1、开立 2、核准中 3、已核准 4、废弃|

# 按钮说明

|栏目|说明|
|---|---|
|档案名称|考核记录|
|确认方式|可选择：即时确认、确认作业、审批流程。|
|核准后可改|表示记录审核通过后，可以再修改。|
|核准后修改重核|表示记录审核通过后，修改后需要重新审核。|

*  <操作>下<审核参数>按钮：点击审核参数按钮，在审核参数对话框中设置审核参数，栏目说明如下：
*  <考核数据导入>按钮：导入Execl格式的员工考核数据文件。

点击<考核数据导入>按钮，弹出导入考核数据对话框，在对话框中，指定考核年度、考核类型、期间号，并通过浏览按钮选择考核数据文件后，点击导入，系统将根据文件中的员工编号，导入考核数据。

注意：执行导入时，系统是以当前登录组织为工作人事组织，按员工编号查询该组织下的员工。

操作前提：应首先点击导出文件模板，按导出的文件模板格式，生成的考核数据文件才能被正确导入。

*  <导出文件模板>按钮：输出Execl格式的员工考核数据文件模板。

# 操作说明

*  通过点击菜单[考核数据维护](/detail/9f5cde834f5f41f198842b5af1536014)，进入考核数据列表画面，可按考核方案查看员工考核数据。
*  点击<查找>可以对已存在的员工考核数据进行查找。
