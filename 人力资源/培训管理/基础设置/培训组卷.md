
# 功能描述

维护本企业的试卷模板。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|录入试卷模板编码|
|名称|录入试卷名称|
|用途|选择用途，分为培训测试、培训评估，选择培训测试时，可选择课程和章节，选择培训评估时，课程和章节置灰不可选，此时可选择表体的培训评估项目|
|课程|选择培训课程|
|章节|选择课程章节|
|生效|设置是否生效|
|生效日期|选择生效日期|
|失效日期|选择失效日期|
|表体||
|试题类别|选择试题类别，在培训题库中可定义试题类别|
|培训评估项目|选择培训评估项目|
|题型|选择题型，分为单选题、多选题、填空题、文字题|
|最低难度系数|设置当前试题的最低难度系数|
|最高难度系数|设置当前试题的最高难度系数|
|最低分值|设置当前试题的最低分值|
|最高分值|设置当前试题的最高分值|
|题数|设置题数|

# 按钮说明

*  <生成试卷>：点击该按钮，可生成试卷模板。

*  一般操作见公共操作说明。
