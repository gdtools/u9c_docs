
# 功能描述

维护本企业的培训设施档案。

# 栏目说明

|栏目名称|说明|
|---|---|
|编码|录入培训设施编码|
|名称|录入培训设施名称|
|所属培训机构|选择系统已创建的培训机构，可点击下划线新增|
|设施数量|维护培训设置的数量|
|是否租用设施|选择当前培训设施是否已被租用，若勾选，需维护租用价格、币种、租借时间单位|
|租借价格|录入租借价格|
|币种|选择租借币种|
|租借时间单位|选择租借时间单位，可点击下划线新增（计量单位）|
|开始日期|选择可用开始日期|
|结束日期|选择可用结束日期|
|是否已注销|可选择当前培训设施是否已注销|
