
# 功能描述

# 网上学习课件，并记录课件的学习次数。

# 业务规则

*  定义培训课程。
*  定义培训课件。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|课程类别|课程类别参照，选择课程类别后，自动带出表头课程信息|
|课程编码|仅列出当前课程类别下的未注销且有课件的课程|
|课程类别|由课程类别带出|
|课程目标|由课程类别带出|
|课程内容|由课程类别带出|
|课程学时|由课程类别带出|
|表体||
|序号|序号，系统自动生成|
|培训课件|显示培训课件|
|课件简介|显示课件简介|
|课件价格|显示课件价格|
|制作日期|显示制作日期|
|访问次数|显示访问次数|

# 操作说明

*  <打开>：选择培训课程，点击该按钮，可打开课程；
*  一般操作见公共操作说明。
