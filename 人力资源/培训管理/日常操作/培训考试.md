
# 功能描述

参与培训考试的学员，可以选择培训课程，参与培训考试。

# 业务规则

*  已定义培训活动、培训课程档案。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|培训活动|通过新增培训考试窗口数据带出|
|培训活动该课程|通过新增培训考试窗口数据带出|
|课程学时|通过新增培训考试窗口数据带出|
|试卷|通过新增培训考试窗口数据带出|
|培训费用|通过新增培训考试窗口数据带出|
|学员|通过新增培训考试窗口数据带出|
|学费|通过新增培训考试窗口数据带出|
|币种|通过新增培训考试窗口数据带出|
|培训机构|通过新增培训考试窗口数据带出|
|任课教师|通过新增培训考试窗口数据带出|
|授课地点|通过新增培训考试窗口数据带出|
|使用时间（分钟）|通过新增培训考试窗口数据带出|
|表体-试卷试题||
|序号|试卷试题序号，根据试卷系统生成|
|试题类别|试卷试题序号，根据试卷系统生成|
|题型|试卷试题序号，根据试卷系统生成|
|内容|试卷试题序号，根据试卷系统生成|
|标准用时（分钟）|试卷试题序号，根据试卷系统生成|
|分值|试卷试题序号，根据试卷系统生成|
|答案|从答题明细中带出|
|表体-答题明细||
|序号|从试卷试题中带出相应行序号|
|题型|从试卷试题中带出相应行题型|
|标准用时（分钟）|从试卷试题中带出相应行标准用时（分钟）|
|分值|从试卷试题中带出相应行分值|
|内容|从试卷试题中带出相应行内容|
|答案|录入答案|

# 操作说明

*  <开始考试>：点击该按钮，可以开始考试，在答题明细中可录入答案。
*  <提交试卷>：点击该按钮，可提交试卷，提交后不可更改。
*  <查找>：点击该按钮，可查找培训人员答卷。
*  其他一般操作见公共操作说明。
