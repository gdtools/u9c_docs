
# 功能描述

按组织统计显示人员培训记录列表，可设置查询方案查找。

# 业务规则

*  存在人员培训记录数据

# 栏目说明

|栏目名称|说明|
|---|---|
|员工_员工编号|员工编号|
|员工_人员名称|人员名称|
|序号|序号，系统生成|
|培训活动_单号|培训活动单据号|
|培训课程_课程编码|培训课程编码|
|培训课程_课程名称|培训课程名称|
|培训开始日期|培训开始日期|
|培训结束日期|培训结束日期|
|培训内容|显示培训内容|
|培训学时|显示培训学时|
|学费|显示学费|

# 操作说明

*  <查询>：点击该按钮，可进入查询方案设置画面，也可增加列表栏目字段；
*  一般操作见公共操作说明。
