
# 功能描述

针对学员的培训评估。

# 业务规则

*  已定义培训题库；
*  已定义培训组卷；
*  已定义培训活动。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|培训活动|通过新增培训考试窗口数据带出|
|培训活动该课程|通过新增培训考试窗口数据带出|
|课程学时|通过新增培训考试窗口数据带出|
|评估卷|通过新增培训考试窗口数据带出|
|培训费用|通过新增培训考试窗口数据带出|
|学员|通过新增培训考试窗口数据带出|
|学费|通过新增培训考试窗口数据带出|
|币种|通过新增培训考试窗口数据带出|
|培训机构|通过新增培训考试窗口数据带出|
|任课教师|通过新增培训考试窗口数据带出|
|授课地点|通过新增培训考试窗口数据带出|
|使用时间（分钟）|通过新增培训考试窗口数据带出|
|得分|参与培训考试的人员得分|
|评语|阅卷人可录入评语|
|表体-试卷试题||
|序号|试卷试题序号，根据试卷系统生成|
|试题类别|试卷试题序号，根据试卷系统生成|
|题型|试卷试题序号，根据试卷系统生成|
|培训评估项目|试卷试题序号，根据试卷系统生成|
|评估题||
|标准用时（分钟）|试卷试题序号，根据试卷系统生成|
|分值|试卷试题序号，根据试卷系统生成|
|评估结果|显示评估结果|
|得分|从答题明细种带入得分|
|表体-答题明细||
|序号|从试卷试题中带出相应行序号|
|题型|从试卷试题中带出相应行题型|
|标准用时（分钟）|从试卷试题中带出相应行标准用时（分钟）|
|分值|从试卷试题中带出相应行分值|
|内容|从试卷试题中带出相应行内容|
|评估结果|显示评估结果|
|标准答案|录入当前试题的标准答案|
|得分|录入当前试题得分|

# 操作说明

*  <开始答卷>：点击该按钮，可开始答卷；
*  <提交>：点击该按钮，提交培训评估结果；
*  <查找>：点击该按钮，可查找已提交的员工试卷；
*  其他一般操作见公共操作说明。
