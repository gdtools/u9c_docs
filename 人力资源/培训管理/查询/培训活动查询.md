
# 功能描述

# 操作说明

*  <查询>：点击该按钮，可设置查询方案，按方案多维度查询培训活动数据；
*  <操作-培训活动明细查询>：点击该按钮，进入培训活动明细查询画面；
*  <操作-考试卷查询>：点击该按钮，进入考试卷查询画面；
*  <操作-培训评估卷查询>：点击该按钮，进入培训评估卷查询画面；
*  其他一般操作见公共操作说明。
