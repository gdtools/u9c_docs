
# 功能描述

培训评估查询。

# 栏目说明

|栏目名称|说明|
|---|---|
|培训活动|显示培训活动|
|培训课程|显示培训课程|
|培训评估卷|显示培训评估卷|
|培训学员|显示培训学员|
|试题类别|显示试题类别|
|序号|显示序号|
|培训评估项目|显示培训评估项目|
|评估题|显示评估题|
|评估结果|显示评估结果|

# 操作说明

*  <查询>：点击该按钮，可设置查询方案，按方案多维度查询培训评估数据；
*  <操作-培训活动>：点击该按钮，进入培训活动画面；
*  <操作-培训机构>：点击该按钮，进入培训机构画面；
*  <操作-培训场地>：点击该按钮，进入培训场地画面；
*  <操作-培训设施>：点击该按钮，进入培训设施画面；
*  <操作-培训教师>：点击该按钮，进入培训教师画面；
*  <操作-培训资料>：点击该按钮，进入培训资料画面；
*  <操作-培训课件>：点击该按钮，进入培训课件画面；
*  其他一般操作见公共操作说明。
