
# 功能描述

员工培训查询。

# 栏目说明

|栏目名称|说明|
|---|---|
|部门|显示部门|
|人员|显示人员|
|职务|显示职务|
|岗位|显示岗位|
|职级职等|显示职级职等|
|培训活动|显示培训活动|
|培训课程|显示培训课程|
|培训学时|显示培训学时|
|学费|显示学费|
|币种|显示币种|
|是否签订培训协议|显示是否签订培训协议|
|培训试卷|显示培训试卷|
|试卷分数|显示试卷分数|
|培训证书名称|显示培训证书名称|
|培训证书编号|显示培训证书编号|
|培训证书颁发机构|显示培训证书颁发机构|
|培训证书颁发日期|显示培训证书颁发日期|
|培训开始日期|显示培训开始日期|
|培训结束日期|显示培训结束日期|

# 操作说明

*  <查询>：点击该按钮，可设置查询方案，按方案多维度查询员工培训数据；
*  <操作-培训课程查询>：点击该按钮，进入培训课程查询画面；
*  <操作-培训协议查询>：点击该按钮，进入培训协议查询画面；
*  <操作-培训试卷查询>：点击该按钮，进入培训试卷查询画面；
*  其他一般操作见公共操作说明。
