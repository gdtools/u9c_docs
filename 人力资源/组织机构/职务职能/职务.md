
# 功能描述

实现对职务定义。

实现对职务结构的定义。

实现职务与角色的关联。

# 业务规则

*  定义职务类别
*  定义职责
*  定义任职资格
*  定义训练要求
*  定义公共薪资项目
*  定义培训课程类别
*  定义考核指标类别
*  定义季节性工作时间
*  定义职级职等
*  定义能力指标
*  定义职务编码结构
*  定义职务在职务节点的维护模版

# 操作说明

*  分组

将职务的页签按分组进行显示，并且能够按组进行切换。

其中基本信息是必选的，其他页签根据用户需要进行裁减或添加自定义扩展的实体页签。

操作前提：础设置/HR信息模版：设置职务信息模版，对职务的页签进行分组。

操作步骤：

1）点击分组-XXX按钮，界面上的页签切换为选择分组下的页签。

2）举例：将职务的页签分为职务说明、业务相关信息。则分组下有两个按钮：职务说明、业务相关信息。点击<职务说明>按钮，则显示该分组内的页签，点击<业务相关信息>按钮，则显示该分组内的页签。

3）可对选择的页签行进行新增、插入和删除。

*  其他一般操作见公共操作说明。
