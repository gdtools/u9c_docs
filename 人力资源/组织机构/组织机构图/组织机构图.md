
# 功能描述

选中组织生成组织机构图。

# 业务规则

*  系统组织机构已建立。

# 按钮说明

*  按组织生成组织机构图

双击界面左面的树，系统生按默认的方案生成组织机构图。

横向与纵向切换：界面右下方：“方向”下拉框可选择横向或纵向。

是否显示岗位：勾选“岗位”复选框后，在组织机构图上可显示岗位信息。

*  <操作>下<选择设置>按钮：点击该按钮，可以选取不同的机构图方案，实现方案的切换。
*  <生成图片>按钮：点击该按钮，选取路径后导出，可导出组织机构图。
*  <导出Word>：点击该按钮，可以直接导出word格式的组织机构图，导出时需将需要选择要导出的组织机构。
