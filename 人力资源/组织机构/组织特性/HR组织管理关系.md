
# 功能描述

通过此功能实现HR组织间的服务关系设置以及关系的变更，可设置人事关系、薪资关系、保险福利关系、结算关系。

表示来源的相应业务指派给目的组织。

# 业务规则

*  HR多组织特征为是
*  HR组织特性设置

# 栏目说明

HR组织关系

|栏目|说明|
|---|---|
|HR组织|注意：限具有人事中心组织的HR组织。表示的是工作人事组织。|
|业务组织|注意：限与HR组织具有"组织-人事" 关系的来源组织,含HR组织|
|部门|注意：限业务组织下的部门及下级部门|
|职务|限HR组织内的职务|
|岗位|限业务组织内的岗位|
|关系类型|枚举: 人事、 薪资、 结算、 保险福利缴交|
|默认|注意：仅当关系类型=结算时可编辑。对于同一个来源的结算关系只能有一个默认。|
|目的组织|注意：当关系类型=人事，只能选有人事中心特性的HR组织当关系类型=薪资，只能选有薪资中心特性的HR组织当关系类型=保险福利缴交，只能选有薪资中心特性的HR组织当关系类型=结算，只能选有人事中心特性的HR组织 。|
|目的业务组织|注意：限与目的组织具有“组织-人事”关系的来源组织，含目的组织。|
|目的部门|注意：限目的业务组织下的部门及下级部门。|
|开始日期|表示关系的开始日期。|
|结束日期|表示关系的结束日期。|

# 操作说明

*  取消：取消某个关系，即将目的组织修改为空，同时实现对相关数据的同步处理。
*  变更目的组织：如果目的组织发生变更，可通过此操作实现，同时实现对相关数据的同步处理。
