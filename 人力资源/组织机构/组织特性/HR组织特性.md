
# 功能描述

当系统为HR多组织特性应用时，通过此功能设置及调整HR组织的人事中心特性和薪资中心特性。

# 业务规则

*  HR多组织特征为是

# 栏目说明

HR组织特性-表头

|栏目|说明|
|---|---|
|组织|为HR组织|
|人事中心|指定是否人事中心注意：组织业务关系中“组织-人事”关系的的目的组织必须具有人事中心特性。|
|薪资中心|指定是否薪资中心|

HR组织特性-变更历史

|栏目|说明|
|---|---|
|组织特性|显示HR组织的特性|
|开始日期|当前特性的开始日期。在指定组织为人事中心或薪资中心后，按保存按钮，自动把当时的系统日期保存为开始日期。|
|结束日期|当前特性的结束日期。在取消组织的人事中心或薪资中心后，按保存按钮，自动把当时的系统日期保存为结束日期。|

# 操作说明

*  新增：对于一个HR组织，如果还未设置其HR组织特性，可通过增加设置其组织特性。点击<新增>按钮后，点击<保存>按钮。操作前提：通过组织机构设置的组织具有HR组织特性。
*  修改：修改HR组织特性，需要满足一定的条件，只有满足条件的才能修改。双击需要修改的行记录，勾选或取消人事中心特性和薪资中心特性，点击<保存>按钮。
*  删除：删除HR组织特性，需要满足一定的条件,只有满足条件的才能删除。选择需要删除的行，点击<删除>按钮。
