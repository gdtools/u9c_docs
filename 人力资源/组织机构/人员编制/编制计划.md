
# 功能描述

实现为本机构及下级机构编制的申请审核。

支持从下向上的逐级汇总申请。

# 业务规则

*  定义编制计划单据类型。
*  设置用户的数据权限。

# 操作说明

*  <操作>下<执行>按钮：当单据审核通过后，单击执行，则关闭单据，将数据回写到编制记录表中。

注意：

如果上级机构含下级的编制数尚未制定（编制记录表中无记录），则下级机构的编制申请单不能执行。

如果本级的编制已经制定（编制记录表中有记录），则也不能执行。

操作前提：单据状态=已核准

*  <操作>下<作废>按钮：

将单据进行作废处理，作废后的单据不能进行审核和执行操作。

操作前提：创建编制计划单。

注意：只有状态为开立、核准中、已核准的编制计划单才能执行作废操作。

*  <操作>下<来源计划>按钮：

当下级机构已经做了编制申请，则可汇总直接下级机构的编制申请，通过此功能获得来源计划。范围限编制计划单的组织机构范围内的审核通过的编制计划申请单。
