
# 功能描述

维护工作人事组织、业务组织、部门、职务的年度编制。

注意：工作人事组织只有含下级的编制数，职务只有不含下级的编制数。而业务组织、部门既有含下级的编制数又有不含下级的编制数。含下级的编制数表示包含自己及下级机构的编制数。

# 业务规则

*  定义组织
*  定义部门
*  定义职务

# 栏目说明

编制记录基本信息

|栏目|说明|
|---|---|
|制定组织|制定编制的组织|
|年度|编制所属的年度|
|工作人事组织|用户可以选择与登录组织具有“人事关系“的工作人事组织。在HR组织管理关系节点，为登录组织指定与其有“人事关系“的工作人事组织。|
|业务组织|用户可以选择工作人事组织下的业务组织。在业务关系节点，为工作人事组织指定与其有“组织-人事“关系的业务组织。|
|部门||
|职务||
|编制数|编制数应等于表体最后一条变更记录中：变更前编制数 + 增减数量|
|含下级|表示是否为含有下级的编制数还是本级的编制数。|

编制变更记录

|栏目|说明|
|---|---|
|变更前编制数||
|增减数量|由用户录入增减数量，正数为增，负数为减。注意　:变更前编制数+增减数量应大于等于0|
|变更时间|注意：同一工作人事组织、业务组织、部门、职务下，一天只能有一条变更记录。|
|变更原因||

# 操作说明

*  <操作>下<增加编制变更历史>

弹出编制变更历史画面，用户新增变更记录。

注意：如果已存在的变更记录中有由编制计划单、编制变更单生成的，那么用户不能再手工增加，只能通过编制变更单增加。

栏目说明：

[增加编制变更历史](http://10.16.2.212/U9C/help/zh-CN/Content/HR/EM/Function/javascript:void(0);)

|栏目|说明|
|---|---|
|变更前编制数|显示变更前编制数|
|增减数量|由用户录入增减数量，正数为增，负数为减。|
|变更时间||
|变更原因||

*  <操作>下<删除编制变更历史>

用户只能从最后的编制变更记录开始，逐行删除。

如果变更记录是由编制变更单生成的，那么用户不能删除。
