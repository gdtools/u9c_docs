
# 功能描述

## 功能概述

看板是实现准时生产的工具，用于控制工厂材料流动和拉动系统实施生产。

可对通用件和专用件分别定义看板。

可定义数量触发的看板和手工触发的看板。

可定义跨组织的看板。

可与存储地点进行数量匹配。

## 功能说明

*  可对通用件和专用件分别定义看板
*  可定义数量触发的看板和手工触发的看板
*  可定义跨组织的看板
*  可与存储地点进行数量匹配

# 业务规则

*  提前定义料品
*  提前定义存储地点
*  提前定义组织（关系工厂）（可选）

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|编码|看板在一个组织内的唯一编码；手工录入或依据编码规则生成；不可为空；组织内不可重复|
|名称|看板的名称|
|看板类型|说明看板是针对的是专用件还是通用件；根据情况定义：通用／专用；对通用件，选择为“通用”；对专用件，选择为“专用”|
|驱动类型|是指看板的状态是如何触发的；手工：由手工来驱动看板的状态改变；数量：由看板数量的变化来驱动看板状态的改变|
|业务触发|指看板状态变化时，如何触发后续业务；手工：指后续业务由手工来触发；自动：指后续业务由看板状态自动触发|
|料品分类|设定料号的选择范围；非空时，料号按料品分类进行过滤|
|料号|对通用件看板，指定看板的料号；参照当前组织［可库存］为“是”且［ECN控制］为“否”且［看板驱动］为“是”的料品录入；看好板类型为“专用”时，非空；注意：同一物料在同一需求存储地点只可存在一个看板主档|
|来源类型|定义看板采用的补货方式；库存：由库存调拨进行看板卡的补货；生产线日计划：由子线生产线日计划进行看板卡的补货|
|需求存储地点|生产线生产时，由此存储地点取用零部件，通常为线边仓；当料品非空时，若［存储地点限制］为“是”时，参照物料存储地点录入，否则参照存储地点录入；当料品为空时，参照存储地点录入；非空；注意：存储地点属于当前组织；存储地点.位置属性为：普通仓（通仓属性为存货仓）/露天仓/外寄仓（外寄仓属性为VMI外寄仓）/WIP仓|
|需求库位|对库位管理的需求存储地点，指定其库位；若料品.［库位限制］为“是”时，参照物料库位录入，否则参照库位录入；注意：需求存储地点为空时，需求库位不可录入|
|供应组织|定义看板的补货组织；默认主本组织，即本组织进行看板卡的补货；其他组织补货时，参照组织档案录入；参照条件：与当前登录组织有“工厂－工厂”、“工厂－物流”的工厂/物流组织；非空|
|供应存储地点|来源类型为库存时，定义此字段值，表示由此存储地点进行看板卡的补货；当料品非空时，若［存储地点限制］为“是”时，参照物料存储地点录入，否则参照存储地点录入；当料品为空时，参照存储地点录入；非空；注意：存储地点属于供应组织；存储地点.位置属性为：普通仓（通仓属性为存货仓）/露天仓/外寄仓（外寄仓属性为VMI外寄仓）/WIP仓|
|供应库位|对库位管理的供应存储地点，指定其库位；若料品.［库位限制］为“是”时，参照物料库位录入，否则参照库位录入；注意：供应存储地点为空时，需求库位不可录入|
|安全库存|对通用件看板，显示存储地点料品交叉关系中的安全库存量|
|容器数量|每张看板卡包含的容器的数量；默认为1,可改，为自然数；非空；注意：专用件看板卡默认为1，不可改|
|容器容量|看板卡中每个容器的容量；默认为1,可改，需大于0；非空；注意：专用件看板卡默认为1，不可改|
|库存主单位|对通用件看板，录入料品时，带入料品的库存主单位，可改；对专用件看板，参照计量单位档案录入；非空|
|时间单位|补货时间非空时，必须录入；选择：时、分、秒|
|平均耗用|表明看板物料在单位时间的耗用；大于0；可空|
|补货时间|表明看板的补货周期；大于0；可空|
|安全系数|考虑废品损耗等因素，得出每张看板的安全系数值；0<=安全系数<=1；可空|
|看板卡数量|指在一张看板中，包含的看板卡的张数；当平均耗用、补给时间、安全系数全部非空时，计算得到；计算公式：向上取整（（平均耗用×补给时间×安全系数）/（容器个数×容器容量））；可手工录入，可对计算结果进行手工修改；非空|
|生效|表明看板是否已生效|
|生效日期|设定看板的生效日期，生效日期要小于等于失效日期|
|失效日期|设定看板的失效日期，失效日期要大于等于生效日期|

# 操作说明

*  **看板料品**

对专用件设定看板料品的范围。

操作步骤：点击【看板料品】按钮，即弹出看板料品设置窗口，可在窗口中维护看板料品。

*      *  **看板料品**

|**栏目名称**|**说明**|
|---|---|
|料号|参照当前组织［可库存］为“是”且［ECN控制］为“否”且［看板驱动］为“是”的料品录入；看好板类型为“专用”时，非空；注意：所选料品的库存主单位应与看板主档库存主单位一致|
|品名|由料品带入|
|起始等级|由料品带入|
|结束等级|由料品带入|
|起始成份|由料品带入|
|结束成份|由料品带入|

*  **看板卡**

查询看板主档下的所有看板卡并可维护。

数量非０时，料号、等级、项目等其他字段均不可改。

操作步骤：点击【看板卡】按钮，即弹出看板卡窗口。
