
# 功能描述

## 功能概述

本结点提供与看板相关的所有操作和活动。

## 功能说明

*  查看看板卡
*  触发看板状态转换
*  关联单据生成

# 业务规则

*  提前定义看板
*  提前定义存储地点
*  提前定义组织（关系工厂）（可选）

# 栏目说明

*  **查询条件：**

|**栏目名称**|**说明**|
|---|---|
|组织|看板主档所属组织；默认为本组织；可选择与本组织有工厂－工厂、工厂－物流关系的组织；可空，空表示全部|
|看板主档|参照录入；可空，空表示全部；组织非空时，按组织过滤|
|需求存储地点|参照录入；可空，空表示全部；组织非空时，按组织过滤|
|看板类型|选择：通用/专用；可空，空表示全部|
|驱动类型|选择：数量/手动；可空，空表示全部|
|料品分类|参照录入；可空，空表示不考虑此过滤条件|
|料品|参照当前组织［可库存］为“是”且［ECN控制］为“否”且［看板驱动］为“是”的料品录入；可空，空表示不考虑此过滤条件；组织非空时，按组织过滤|
|状态|选择：空/满；默认为空；可空，空表示全部|
|状态更新时间|录入；默认为空|
|来源类型|选择：库存/生产线日计划；可空，空表示全部|
|供应组织|看板的补货组织；默认为空，空表示全部；参照组织档案录入；参照条件：当前组织及与当前登录组织有“工厂－工厂”、“工厂－物流”的工厂/物流组织|
|供应存储地点|参照录入；可空，空表示全部；供应组织非空时，按组织过滤|

# 操作说明

*  **置空**

对数量为0且状态为满的看板卡，将状态置为空。

操作步骤：单选或多选看板卡，点击【操作－置空】按钮，即可将符合条件的记录状态置为空。

*  **置满**

对状态为空的看板卡，将状态置为满。同时触发关联单据调入，并将数量字段写入调入数量。

操作步骤：单选或多选看板卡，点击【操作－置满】按钮，即可将符合条件的记录状态置为满。

*  **失效**

将所选看板卡，将状态置为失效，数量非空时，生成调入单退库看板数量，看板卡数量为０时自动删除看板卡。

操作步骤：单选或多选看板卡，点击【操作－失效】按钮，即可将符合条件的记录状态置为失效，并删除。

注意：状态为满的看板卡，来源类型需是“库存”。

*  **新增临时看板卡**

手工新增一张临时看板卡。

操作步骤：点击【新增临时卡】按钮，即可在弹出窗口中增加临时看板卡。

*      *  **新增临时卡**

|**栏目名称**|**说明**|
|---|---|
|看板|选择本组织内的看板编码，带入看板相关的其他字段值；参照录入；不可为空|
|单头其他字段|由看板带入，显示，不可改|
|序号|看板卡的卡号；系统给出；不可改|
|临时　|默认为是；不可改|
|状态|指看板卡的状态；可选择空/满；手工控制的看板：数量为0时，可为满或空；数量非0时，只能为满；数量控制的看板，由系统控制，不可手工维护；数量为0时状态为空，非0时，状态为满|
|状态更新时间|由系统记录|
|料品|对通用件看板，默认为看板主档的料号，不可改；看板类型为“通用”时，默认为看板主档的料号，不可改；看板类型为“专用”时，选择料品范围内的料品录入；非空|
|品名|显示料品的名称|
|版本号|对版本控制的料品录入其料品版本|
|数量|默认为0；不可改|
|库存主单位|显示料品的库存主单位|
|从等级|默认为料品的起始等级；可改，应在料品的等级范围内|
|到等级|默认为料品的结束等级；可改，应在料品的等级范围内，且小于从等级|
|从成份|默认为料品的起始成份；可改，应在料品的成份范围内|
|到成份|默认为料品的结束成份；可改，应在料品的成份范围内，且小于从成份|
|项目|对专用件看板，可录入；参照项目档案；可空|
|番号|对专用件看板，可录入；参照番号档案；可空|
|厂牌|对专用件看板且厂牌管理的料品，可录入；默认还入料品档的厂牌，可参照料品厂牌范围修改；可空|
|需求单据号|看板卡的来源单据号|
|供应单据号|看板卡的补货单据号|

*  **创建日计划**

对状态为空且来源类型为生产线日计划的看板卡，创建生产线日计划。

操作步骤：单选或多选符合条件的看板卡，点击【创建日计划】按钮，即可创建，创建成功的记录会将生成的日计划单号写入关联单据字段，可链接到关联单据画面。

*  **创建调拨单**

对状态为空且来源类型为库存的看板卡，创建调入单。

操作步骤：单选或多选符合条件的看板卡，点击【创建调拨单】按钮，即可创建，创建成功的记录会将生成的调入单号写入关联单据字段，可链接到关联单据画面。

*  **删除关联单据**

对由看板卡创建的关联单据，若符合可删除条件，则可删除关联单据。

操作步骤：单选或多选符合条件的看板卡，点击【删除关联单据】按钮，即可删除。
