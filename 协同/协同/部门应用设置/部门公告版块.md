
# 功能描述

指定的部门内的公告版块管理（或公告类型管理）；

# 业务规则

*  启用协同（必做）
*  部门公告管理员

# 栏目说明

部门公告版块－列表页面

|栏目|说明|
|---|---|
|编码|公告版块的编码|
|名称|公告版块的名称|
|创建时间|当前公告版块的创建时间|
|创建人|当前公告版块的创建人|
|是否生效|当前公告版块是否已经生效|
|生效日期|当前版块的生效日期|
|失效日期|当前版块的失效日期|

部门公告版块－属性页面

|栏目|说明|
|---|---|
|编码|公告版块的编码|
|名称|公告版块的名称|
|描述|当前公告版块的备注或描述|
|部门|为当前创建的版块指定部门，即：那些部门可以使用该版块|
|顺序|当前公告版块在集团公告所以版块中的排列（显示）顺序|
|管理员|当前公告版块的管理员，可指定为部门属性内包含的部门中的任意有效用户|
|审核员|当前版块的审核人员|
|允许评论|设置是否允许评论|
|最大置顶数|当前版块中允许置顶的公告数量|
|标新天数|当前版块中的公告，被标记为新公告的天数|
|生效|当前版块是否生效|
|生效日期|当前版块的生效日期|
|失效日期|当前版块的失效日期|

# 操作说明

*  通过菜单协同－>协同－>部门应用设置－>部门公告版块进入该界面；
*  操作步骤
 
   *  第1步：输入编码、名称、部门等基本信息。
   *  第2步：输入最大置顶数、标新天数等保留信息。
   *  第3步：点击保存按钮。
