
# 功能描述

属于公文应用的基础设置。用来对公文中的类型进行管理和维护。分收文和发文两种不同的类型。

# 业务规则

*  启用协同系统（必做）

# 栏目说明

公文类型－列表页面

|栏目|说明|
|---|---|
|编码|当前行中包括的公文类型的编码|
|名称|当前行中包含的公文类型的名称|
|类别|当前行中包含的公文类型所属于的类别注意　:本版本只包括两种类别：发文和收文，并且这两种类别不可维护由系统预置|
|描述|当前行中包含的公文类型的描述|

公文类型－类型属性

|栏目|说明|
|---|---|
|编码|公文类型的编码，必填项|
|名称|公文类型的名称，必填项|
|类别|公文类型所属于的类别，下拉框选择；本版本只包括两种类别：发文和收文，并且这两种类别不可维护由系统预置|
|描述|公文类型的描述|
|生效|当前公文类型是否生效，CheckBox选择框|
|生效日期|当前公文类型的生效时间|
|失效日期|当前公文类型的失效时间|

# 操作说明

*  通过菜单协同－>协同－>公文设置－>公文类型进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：维护销毁审核员。
   *  第3步：点击保存按钮。
