
# 功能描述

属于公文应用的基础设置。用来对公文中的电子印章进行维护。是公文应用中的电子盖章的图章来源。

# 业务规则

*  启用协同系统（必做）

# 栏目说明

公文印章－列表页面

|栏目|说明|
|---|---|
|编码|当前行中包含的电子印章的编码|
|名称|当前行中包含的电子印章的名称|
|描述|当前行中包含的电子印章的描述|

公文印章－印章属性

|栏目|说明|
|---|---|
|编码|电子印章的编码字段，必填项|
|名称|电子印章的名称字段，必填项|
|图片|印章的电子图片，即电子印章|
|描述|对当前印章的描述|
|生效|Checkbox选项，用来控制当前印章是否生效|
|生效日期|用来控制当前印章的生效时间|
|失效日期|用来控制当前印章的失效时间|

# 操作说明

*  通过菜单协同－>协同－>公文设置－>公文印章进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：维护图片信息。
   *  第3步：点击保存按钮。
