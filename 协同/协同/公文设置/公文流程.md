
# 功能描述

流程图设计，即流程的步骤、流转过程、处理人等信息的设置

# 业务规则

*  启用协同系统（必做）

# 栏目说明

公文流程－列表页签

|栏目|说明|
|---|---|
|标题|当前行中包含的公文流程的标题|
|当前版本.修改日期|当前行中包含的公文流程的当前版本的最后修改日期|
|状态|当前行中包含的公文流程的启用状态：启用/禁用|

公文流程－流程属性

|栏目|说明|
|---|---|
|标题|当前公文流程的编码|
|状态|当前公文流程的启用状态|
|版本号|当前公文流程的版本号|
|定义人|当前公文流程的初始定义人|
|定义时间|当前公文流程初始定义的时间|
|修改人|当前公文流程最后一次的修改人|
|修改日期|当前公文流程最后一次修改的时间|
|描述|当前公文流程的描述信息|

流程设计－节点页签

|栏目|说明|
|---|---|
|开始节点|默认且必有的节点。该节点默认在设计器中包括，为流程的起始节点。不能删除该节点；可在在开始节点中设置可填写该公文的用户|
|结束节点|默认且必有的节点。该节点默认在设计器中包括，为流程的结束节点。不能删除该节点|
|单人活动|节点是流程中最简单的节点，不包含任何判断条件等规则限制，当前处理人处理完成后按照路由（即流程图中的箭头线）流转到指定的节点。|
|多人活动|需要多处理人都处理后才能结束的节点。|
|判断节点|用来做条件判断的节点，可为此节点设置特殊处理人。|
|消息节点|不是人工处理的节点，系统自动产生消息的节点。|
|子行审批|该节点将根据表单中的明细行产生多个审批任务，分别由多个人分别审批原表单行数据。|
|发文应用|发文流程所须的发文处理节点|

流程设计－错误列表

|栏目|说明|
|---|---|
|节点|错误所隶属于的节点名称。双击鼠标发生错误的节点将被选中（边框为红色时表示选中状态）|
|描述|错误的描述信息。双击鼠标发生错误的节点将被选中（边框为红色时表示选中状态）|


# 按钮说明

*  节点操作：选中一个节点，添加到正在设计的流程图中。包含节点为“流程设计－节点页签”中除开始节点和结束节点之外的所有节点。注：开始节点和结束节点为系统预置在流程图中的节点，每个流程图中有且只能有一个开始、一个结束节点，并且不能删除这两个节点。
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击节点－>选中一个节点。具体步骤如下所示。
      *  第1步：单击Toolbar中的节点按钮，弹出节点下拉框
      *  第2步：在节点下拉框中单击要添加到流程图中的节点
      *  第3步：流程图区域的左上角已经添加了选中的节点，单击该节点将其拖拽到流程图中合适的位置（由设计人员决定该位置）
*  路由操作：路由是流程图中节点的连接线，路由直观的标明了当前节点的流转方向。此操作是为流程节点添加路由的
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击路由按钮。具体步骤如下所示。
      *  第1步：单击Toolbar中的路由点按钮 ，鼠标指针变为小点点
      *  第2步：单击要设置流转方向的节点，节点上将增加一个可延伸的箭头线（即路由）
      *  第3步：拖动鼠标，带动箭头线到要流转到的节点上，单击鼠标。路由从要设置流转方向的节点连接到要流转到的节点，完成路由添加操作。
*  删除操作：删除流程图中的节点或路由
 
   *  操作前提
   
      *  流程图中包含路由或除开始、结束节点之外的节点
   *  操作步骤
   
      *  点击删除按钮。具体步骤如下所示。
      *  第1步：在流程图中选择要删除的节点或路由（注，当节点边框变为红色表示被选中；当路由颜色变为红色表示被选中。一次只能选中一个节点或一个路由）
      *  第2步：单击Toolbar中的删除按钮，完成删除操作（注：删除节点的时候，该节点中的路由将同时被删除）
*  属性操作：弹出节点属性设置对话框，进行节点详细信息设置
 
   *  操作前提
   
      *  选中流程图中除开始或结束节点之外的任一节点
   *  操作步骤
   
      *  点击属性按钮，弹出属性设置对话框。具体步骤如下所示。
      *  第1步：在流程图中选择要进行属性设置的节点
      *  第2步：在Toolbar中单击属性按钮，弹出属性设置对话框
      *  第3步：在属性设置对话框中填写节点的属性信息，单击确定完成属性设置操作
*  实体操作：弹出实体选择对话框，进行流程与实体的绑定
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击实体按钮，弹出实体选择对话框。具体步骤如下所示。
      *  第1步:在Toolbar中单击实体按钮，弹出实体选择对话框
      *  第2步：在实体选择对话框中，选择要绑定到该流程的实体
      *  第3步：在实体选择对话框中单击确定按钮，完成实体绑定操作
*  全屏操作：改变当前流程设计器视图的显示窗口为全屏显示
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击全屏按钮
*  放大操作：将当前流程设计器视图的显示窗口放大显示
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击放大按钮
*  缩小操作：将当前流程设计器视图的显示窗口放大显示
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击缩小按钮
*  取消操作：放弃当前的修改并关闭当前窗体
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击取消按钮

# 操作说明

*  通过菜单协同－>协同－>公文设置－>公文流程进入该界面；
*  操作步骤
 
   *  第1步：维护标题、描述信息。
   *  第2步：点击保存按钮。
