
# 功能描述

属于公文应用的基础设置。用来对公文单的设计提供数据源；

系统提供预置的数据源，包括发文实体和收文实体；用户可以根据企业公文的特性，对此实体进行扩展。但不能删除这两个实体或增加新的实体。

# 业务规则

*  启用协同系统（必做）

# 栏目说明

公文实体－列表页面

|栏目|说明|
|---|---|
|编码|当前行中包含的公文实体的编码|
|标题|当前行中包含的公文实体的名称|
|修改人|当前行中包含的公文实体的最后修改人|
|描述|当前行中包含的公文实体的描述|
|创建时间|当前行中包含的公文实体的创建时间|

公文实体－发文\收文实体属性

|栏目|说明|
|---|---|
|编码|当前发文实体的编码|
|标题|当前发文实体的标题|
|描述|当前发文实体的描述|
|树|默认为当前发文实体中包含的实体树，包括主实体、子实体和实体中的属性。在页面的左侧，与右侧列表页面联动；|
|列表|默认为实体列表页面，包括当前实体组件中的主实体、子实体；与左侧的树联动；当单击左侧树中的实体节点时，左侧自动更新为当前被单击的树节点中所包含的属性列表；|


# 按钮说明

*  发布操作：将当前的实体进行发布，只有发布后的实体才能用来进行公文单的设计
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  单击菜单“协同—>公文设置—>公文实体”，单击发布
*  添加子实体操作：为当前的实体组件添加一个或多个子实体
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  单击菜单“协同—>公文设置—>公文实体”，选择要修改的实体组件，默认是发文实体；然后，
      *  第一步：单击列表下方的添加子实体按钮，实体列表中会增加一个新行，在新行中录入新增子实体的标题等属性；
      *  第二步：单击本页Toolbar中的保存按钮，或实体列表下方的同步到实体树；
      *  第三步:在实体树中单击新增的子实体节点，然后在右侧视图中增加改实体中包括的字段并设置其字段的属性
      *  第四步：单击本页中的保存按钮，保存实体属性的设置，然后单击发布，将当前实体的新增部分发布出去

# 操作说明

*  通过菜单协同－>协同－>公文设置－>公文实体进入该界面；
*  操作步骤
 
   *  第1步：选择要修改的实体组件。
   *  第2步：维护修改的属性信息。
   *  第3步：点击保存按钮。
