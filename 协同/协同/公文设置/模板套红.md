
# 功能描述

属于公文应用的基础设置。用来对公文中红头文件进行模板设置。是公文应用中的套红模板的来源。

# 业务规则

*  启用协同系统（必做）

# 栏目说明

套红模板－列表页面

|栏目|说明|
|---|---|
|编码|当前行中包含的套红模板的编码|
|名称|当前行中包含的套红模板的名称|
|创建人.姓名|当前行中包含的套红模板的创建人|
|创建时间|当前行中包含的套红模板的创建时间|
|描述|当前行中包含的套红模板的描述|

套红模板－模板属性

|栏目|说明|
|---|---|
|编码|套红模板的编码字段，必填项|
|名称|套红模板的名称字段，必填项|
|描述|对当前套红模板的描述|
|生效|Checkbox选项，用来控制当前套红模板是否生效|
|生效日期|用来控制当前套红模板的生效时间|
|失效日期|用来控制当前套红模板的失效时间|

# 按钮说明

*  模板设计操作：为当前正在创建或修改的套红模板进行模板内容的设计或修改
 
   *  操作前提
   
      *  套红模板的基础属性已经存在与系统中
   *  操作步骤
   
      *  单击菜单“协同—>公文设置—>模板套红”进入套红模板的属性页面，单击本页面左下方的模板设计按钮，弹出包含Word编辑器的设计页面，用户可在此页面中对模板内容或格式进行设计

# 操作说明

*  通过菜单协同－>协同－>公文设置－>公文套红进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：点击保存按钮。
