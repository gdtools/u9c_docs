
# 功能描述

属于公文应用的基础设置。用来对公文中的发文进行文号的维护。主要是对文号的生成规则进行维护，不是维护具体某一个文号的。

# 业务规则

*  启用协同系统（必做）

# 栏目说明

公文文号－列表页面

|栏目|说明|
|---|---|
|名称|当前行中包括的文号的名称|
|年号|当前行中包含的文号的年号，即当前公文文号的年份|
|编码起始值|当前行中包含的文号的起始值注意　:发文文号规则定义后，发文单单中引用的是此规则，根据规则中的起始值和当前值自动按照步长为1的序列递增|
|待用编号值|当前行中包含的文号的即将使用的编号|
|预览|根据以上规则组成的完整文号的样式|

公文文号－文号属性

|栏目|说明|
|---|---|
|名称|当前文号的名称,必填项|
|年号|当前文号的年号，即当前公文文号的年份,必填项默认为当前年|
|编码起始值|当前文号的起始值,默认为1注意　:发文文号规则定义后，发文单单中引用的是此规则，根据规则中的起始值和当前值自动按照步长为1的序列递增|
|待用编号值|当前文号的即将使用的编号,默认为1|
|预览|根据以上规则组成的完整文号的样式，只读属性不可编辑|
|生效|Checkbox选项，用来控制当前文号是否生效|
|生效日期|用来控制当前文号的生效时间|
|失效日期|用来控制当前文号的失效时间|

# 操作说明

*  通过菜单协同－>协同－>公文设置－>公文文号进入该界面；
*  操作步骤
 
   *  第1步：维护名称、年号等信息。
   *  第2步：维护编号起始值、待用编号值、格式等信息。
   *  第3步：点击保存按钮。
