
# 功能描述

系统内的公告，按照类型分别分类罗列。

# 业务规则

*  启用协同（必做）

# 栏目说明

公告首页－公告类型树

|栏目|说明|
|---|---|
|公告首页|一级节点中的第一个节点，单击后右侧视图按照系统中包含的公告类型，进行分类显示公告|
|集团公告|一级节点中的第二个节点，下可包含多个子节点（即集团公告中的类型）|
|组织公告|一级节点中的第三个节点，下可包含多个子节点（即当前组织下包含的公告类型）|
|部门|一级节点中的第四个节点，下可包含多个子节点（即当前部门中包含的公告类型）|

公告首页－公告视图

|栏目|说明|
|---|---|
|公告标题|按照版块（公告类型）分别列出当前公告类型下的最新公告或置顶公告。单击查看公告详情。|
|时间|当前公告的发布时间|

# 按钮说明

*  发布公告操作：在当前公告类型中创建一个新公告
 
   *  操作前提
   
      *  当前公告类型的管理员
   *  操作步骤
   
      *  单击菜单“协同—>协同—>公告”，在公告树中单击当前操作员有发布权限的公告类型，然后在右侧视图的左下方单击发布公告，进入公告发布页面
*  管理公告操作：对当前类型下的公告进行管理（新增、删除等）
 
   *  操作前提
   
      *  当前公告类型的管理员
   *  操作步骤
   
      *  单击菜单“协同—>协同—>公告”，在公告树中单击当前操作员有发布权限的公告类型，然后在右侧视图的左下方单击管理公告，进入公告列表页面进行公告的删除、增加和查看等操作
*  发布授权操作：在当前公告类型中增加可发布公告的人员
 
   *  操作前提
   
      *  当前公告类型的管理员
   *  操作步骤
   
      *  单击菜单“协同—>协同—>公告”，在公告树中单击当前操作员有发布权限的公告类型，然后在右侧视图的左下方单击发布权限，弹出增加公告发布人对话框

# 操作说明

*  通过菜单协同－>协同－>协同－>公告进入该界面；
*  操作步骤
 
   *  第1步：输入标题、发布时间；
   *  第2步：点击查询。
