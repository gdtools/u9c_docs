
# 功能描述

为ERP中的实体和页面等数据提供一种便捷的查询方式。

类似google和baidu的搜索功能一样简便易懂，即输即搜。

超快的搜索速度。

可以同时搜索多种类型的信息。

# 业务规则

*  启用协同系统（必做）
*  系统用户
*  在“搜索栏”中点击“高级搜索“时，系统会自动把“搜索栏”画面中搜索框里面的关键字按照一定的运算规则回填到高级搜索页面的各个属性中
*  本小节中的栏目说明部分，如果配合应用主题中的“使用多个搜索关键字”的内容会更容易理解。
*  高级搜索画面中的开始时间和结束时间都不指定的情况下，系统认为此次搜索没有指定时间条件。但如果只指定开始时间没有制定结束时间，那么系统认为结束时间等于开始时间。如果结束时间小于开始时间，那么系统自动您指定的两个时间进行顺序调整，也就是说系统永远认为比较小的那个时间为开始时间，大的那个为结束时间。

# 按钮说明

*  搜索操作：根据用户指定的条件之下搜索操作，搜索结果的展现，搜搜结果汇总统计，搜索结果分组（分类）
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  第1步：录入搜索条件，点击搜索，进入搜索结果页面，详细信息如下：
*  搜索结果－搜索结果分组区页签

|栏目|说明|
|---|---|
|分组类型名|U9系统中的实体名。此处只列出包含搜索结果的实体分组类型名除了“全部结果”外其他都是实体名|
|搜索结果数量|表示在此分组中共搜索到多少条记录。“全部结果（n）”中n表示此次搜索结果的全部记录数。|

*  搜索结果－结果记录页签

|栏目|说明|
|---|---|
|超链接|是由实体名和索引中的第一个字段对应的值组成。格式为：“实体名称：索引中第一个属性名称对应的值”。关于“索引中的第一个字段（或属性）”，请参见本附录中的“搜索主题“部分。超链接中红色字体表示用户在搜索条件框中录入的搜索条件|
|摘要详细|表示的是：”搜索主题“中的摘要所包含的所有字段以及各个字段对应的值。关于”搜索主题“中的摘要字段，请参见本附录中的“搜索主题“部分。红色字体表示用户指定的搜索条件|

*  搜索结果－结果翻页页签

|栏目|说明|
|---|---|
|数字|搜索结果记录区的页标签搜索结果记录区中每页面显示15个搜索结果，用户可用过翻页页签进行页码切换。|
|上一页|当前页码所在页面的上一页。当前搜索结果记录区处于第一页或只有一页的情况下，”上一页”标签不显示。|
|下一页|当前页码所在页面的下一页。当前搜索结果记录区处于最后一页或只有一页的情况下，”下一页”标签不显示。|

*  搜索结果－结果记录状态页签

|栏目|说明|
|---|---|
|搜索结果|明确以下内容为搜索结果|
|共n条记录，|符合搜索条件的结果记录总数为n条这个数字与搜索结果分组区域中“全部结果（n）”中的n相等。|
|查询用时n.n秒。|表示系统执行此次搜索所占有的时间，单位为秒。|

*  第2步：查看搜索结果操作，详细如下：
*  查看搜索结果记录区操作：根据搜索分组区中的分组进行不同类型搜索结果记录的查看。系统默认将搜索结果区定位到“全部结果（n）”分组中。
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击搜索结果分组区中的分组名称，右侧搜索结果记录区中的记录会随之变化。
*  查看搜索结果中指定项的详细内容操作：搜索结果记录区中只把每个记录的重要属性展现给用户。用户通过单击结果记录区中的超链接部分，可以进入指定记录的详细内容画面进行指定记录详细的查看，记录的详细内容画面中的相关操作需要有相关的操作权限。
*  查看搜索结果中指定项的详细内容操作：搜索结果记录区中只把每个记录的重要属性展现给用户。用户通过单击结果记录区中的超链接部分，可以进入指定记录的详细内容画面进行指定记录详细的查看，记录的详细内容画面中的相关操作需要有相关的操作权限。
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击搜索结果记录区中的超链接部分，进入当前记录的详细内容画面。
*  结果记录区中的翻页操作：当前分组结果记录数大于15条的情况下，翻页标签可以帮助用户进行不同页面之间的切换。
 
   *  操作前提
   
      *  当前分组下的记录数大于15条
   *  操作步骤
   
      *  点击搜索结果记录区中的“上一页、数字部分、下一页”，结果记录将在不同页面间进行自动切换。
*  高级搜索操作：进一步精确搜索条件，自动提供搜索条件之间的运算关系
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  第1步：点击高级搜索－>弹出高级搜索条件对话框，包含栏目如下：
      *  第2步：高级搜索－高级搜索页签录入搜索条件－>点击－>确定，可以搜索到符合该条件的相关记录。或单击取消清除用户当前录入的搜索条件，关闭高级搜索窗体并取消搜索操作
