
# 功能描述

文档管理首页面，单击U9Portal中的菜单进入

显示系统中的全部文档区信息

跨文档区进行文档显示

跨文档区的全文搜索

# 业务规则

*  启用协同系统（必做）
*  拥有【协同模块】中【文档管理】菜单的访问权限的用户
*  文件列表中的摘要信息：文件列表中的每一个文件除了上面的四个属性外还包括文件的【上传人】和该文件的【关键字】：
 
   *  1、上传人：超链接项，单击该超链接后列表自动列出由该用户上传的所有文件
   *  2、关键字：列出当前文件中的所有关键词，每个关键词之间用空格分隔，每个关键词都是一个超链接项，单击这里的超链接项后列表自动列出使用关键词的所有文件

# 按钮说明

*  关键词操作：每个关键词都是一个超链接项，单击关键词系统会自动以该关键词为条件搜索所有文档，并将符合条件的结果展示在右边的文件列表中
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击某个关键词，文件列表被更新
*  快速查找操作：根据用户指定的条件进行查询，并将查询结果列在文件列表中
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  包括两种查询操作：
      *  第一种：输入查询条件，单击查找图标（默认按照文档标题和名称查找）；
      *  第二种：输入查询条件，单击“查询选项”在下拉菜单中选择查询范围，再选择查询方式，单击查询图标；
*  重新排序操作：单击视图选项—>在弹出的菜单中指定排序字段和排序方式（升序还是降序）—>单击重新排序按钮，当前列表将根据用户指定的排序条件重新排序；
*  全文搜索操作：此处的全文搜索是跨文档区的文件搜索
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  在快速查找操作的上方有搜索框，在此搜索框中输入搜索条件—>单击全文搜索按钮，符合条件的搜索结果将列出。此时的搜索只包含最终版本的文档，如果想包含历史版本的文件请先选择全文搜索按钮后方的历史版本复选框后再单击全文搜索按钮

# 操作说明

*  通过菜单协同－>协同－>协同－>文档进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件
   *  第2步：直接按回车键或单击查询图标
