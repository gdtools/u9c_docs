
# 功能描述

当前用户的联系人列表，仅限系统内的用户，不能创建外部联系人。

# 业务规则

*  启用协同系统（必做）

# 栏目说明

联系人－导航页签

|栏目|说明|
|---|---|
|分组列表|当前用户可将自己的联系人放置到不同的组中。单击联系人组后面的添加弹出新建组页面，填写组名，单击确定组创建成功|
|名称|单击左侧列表列出当前组中包含的联系人列表；双击联系人组名称可以弹出编辑组页面，可编辑组信息。点击名称右边的"X"可以删除该联系人组。|

联系人－列表页签

|栏目|说明|
|---|---|
|CheckBox|复选框，支持批量删除|
|类型|有两种类型，一种是用户，一种是联系人组。|
|名称|联系人名称|
|固定电话||
|移动电话||
|电子邮件||
|传真||
|部门||
|办公地址||

# 按钮说明

*  发消息操作：给指定的联系人发送消息，可同时给多个联系人发消息
 
   *  操作前提
   
      *  选则至少一个联系人
   *  操作步骤
   
      *  选择要发消息的联系人，点击发消息按钮，弹出消息属性页面

# 操作说明

*  通过菜单协同－>协同－>协同－>通信簿进入该界面；
*  操作步骤
 
   *  第1步：点击新增按钮；
   *  第2步：选择选择联系人；
   *  第3步：点击确定按钮。
