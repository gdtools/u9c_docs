
# 功能描述

“协同空间”是多个协同区（团队协同）信息的整合，您可以通过协同空间来查看您在组织中任何协同区中的相关内容,“协同空间”可以提供：

一个用于集中查看您的所有文档、日历、邮件、讨论、ERP页面、公告及协同区等信息的位置

一种跨协同区进行内容整合的方式

# 业务规则

*  启用协同系统（必做）

# 按钮说明

*  搜索操作：根据用户输入的搜索关键字执行跨协同区搜索操作
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  在搜索（或搜索关键字）文本框中输入要搜索的关键字－>单击搜索图标或搜索按钮。具体步骤如下所示。
      *  第1步：在搜索关键字文本框中录入要搜索的关键字
      *  第2步：直接按回车键或单击搜索图标或搜索按钮
      *  第3步：符合条件的搜索结果将以协同区工具类型为分组进行显示

# 操作说明

*  通过菜单协同－>协同－>协同－>团队协同进入该界面；
*  操作步骤
 
   *  第1步：在搜索关键字文本框中录入要搜索的关键字
   *  第2步：直接按回车键或单击搜索图标或搜索按钮
   *  第3步：符合条件的搜索结果将以协同区工具类型为分组进行显示
