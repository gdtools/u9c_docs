
# 功能描述

日程安排、事件记录；支持多个日历。

# 业务规则

*  启用协同系统（必做）
*  单击日历视图中的每个时间点都可快速创建该时间段内的事件
*  日历视图中可同时显示多个日历中的事件，不同日历的事件以日历的颜色进行区分。即：日历A的颜色为红色，那么日历A的事件在视图上的显示颜色即为红色。

# 栏目说明

日历－列表页签

|栏目|说明|
|---|---|
|个人日历|当前用户的日历列表，含属性：颜色框：表示此日历事件在日历视图中的颜色；日历名称：表示日历的名称。|
|他人日历|当前系统中其他用户共享出来的日历列表，含属性：颜色框：表示此日历事件在日历视图中的颜色；日历名称：表示日历的名称。|
|添加|个人日历和他人日历都附带有该操作，是用来创建新日历的。|

日历－视图页签

|栏目|说明|
|---|---|
|视图名称|分三种可选视图：日视图、月视图和周视图。默认为周视图。|
|视图|日视图：以凌晨12点为起点——下午11点截至，用一列表格以小时为单位表示；默认定位在当前系统日期上；月视图：网格形式以天为单位显示当前月份中的全部天数；周视图：以周日为起点——周六截至，以二维表格的方式显示，每天24小时为单位。|


# 按钮说明

*  创建活动操作：创建事件；可通过两种方式实现：单击日历列表上方的新增按钮，单击日历视图上的时间点快速创建
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  单击创建按钮，弹出事件信息页面。具体步骤如下所示:
      *  第1步：单击新增按钮，弹出事件信息页面
      *  第2步：在事件信息页面中填写事件的属性
      *  第3步：单击事件信息页面中的确定按钮，保存新创建的事件并关闭当前对话框；否则取消数据保存并关闭对话框

# 操作说明

*  通过菜单协同－>协同－>协同－>日历进入该界面；
*  操作步骤
 
   *  第1步：单击新增按钮，弹出事件信息页面
   *  第2步：在事件信息页面中填写事件的属性
   *  第3步：单击事件信息页面中的确定按钮，保存新创建的事件并关闭当前对话框；否则取消数据保存并关闭对话框
