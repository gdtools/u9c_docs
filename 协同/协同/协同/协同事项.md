
# 功能描述

协同工作是个人、团队、组织之间传递信息和执行规则的办公事务处理工具。

可以使用它完成日常事务的发起、处理和管理，并记录事务的处理过程和结果,可以通过发起人定义流程规则发起事务办理。

# 业务规则

*  启用协同（必做）

# 栏目说明

新建协同事项-属性页签

|栏目|说明|
|---|---|
|标题|协同事项的标题。|
|附件|关联该事项的附件，可以上传多个附件。|
|状态|只读，协同事项处理的状态。|
|重要性|协同事项的重要性：一般、重要、非常重要。|
|发起时间|只读，协同事项发起的时间。|
|流程|设置协同事项流程。|
|正文|协同事项的内容描述。|
|意见|协同事项流程处理人的处理意见。|

新建协同事项-列表页签

|栏目|说明|
|---|---|
|标题|协同事项的标题。|
|重要性|协同事项的重要性：一般、重要、非常重要。|
|修改时间|最后一次修改此协同事项的时间。|
|发起时间|只读，协同事项发起的时间。|
|状态|协同事项处理的状态。|

# 按钮说明

*  流程：点击流程链接，弹出协同事项流程画面，可以新建或者编辑流程。
*  发起：点击页面上方的发起，发起流程。
*  撤销：点击页面上方的撤销，撤销已经发起的流程。

# 操作说明

*  通过菜单协同－>协同－>协同－>协同事项进入该界面；
*  操作步骤
 
   *  第1步：输入标题、附件等信息。
   *  第2步：输入正文、意见等信息。
   *  第3步：点击保存按钮。
