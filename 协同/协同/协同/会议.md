
# 功能描述

企业中的会议管理，包括创建会议、会议通知、会议纪要等会议相关的内容；

# 业务规则

*  启用协同（必做）

# 栏目说明

会议管理－列表页面

|栏目|说明|
|---|---|
|checkbox|选择标识|
|主题|会议的主题|
|开始时间|会议召开的时间|
|结束时间|会议结束的时间|
|会议室.名称|该会议所使用的会议室名称|
|地点|该会议室的地点信息|
|负责人.名称|该会议的负责人|
|回执.回执类型|当前用户对此会议是否回执|

会议管理－属性页面

|栏目|说明|
|---|---|
|主题|会议主题|
|会议室|参照类型。召开会议所需的会议室，即在哪个会议室召开此会议|
|开始时间|会议的开始时间|
|结束时间|会议的结束时间|
|地点|该会议的地点描述|
|负责人|该会议的负责人|
|记录人|该会议的记录人，记录人可以进行会议纪要的维护|
|主持人|该会议的主持人|
|与会人员|该会议的参会人员，可选择多个人员|
|附件|召开该会议所需的附件，支持多个附件|
|是否提醒|是否在指定的时间，发消息通知会议与会人员及时参加会议|
|提前提醒时间|如果“是否提醒”选择了需要提醒，那么此属性是设置在会议召开前的多长时间时发出提醒|

会议管理－会议页面

|||

|---|---|
|会议通知|设置是否通知与会人员来参加该会议|
|正文|该会议的正文|

# 按钮说明

*  发送通知操作：为与会人员发送参会通知
 
   *  操作前提
   
      *  当前页面中包含有效的并未召开的会议
   *  操作步骤
   
      *  在当前页面左下方单击操作 --> 发送通知按钮，系统将自动给当前会议中除当前正在操作的用户外的其它人员发送会议通知；注:会议通知的发送状态将显示在当前页面的任务栏中
*  回执操作：与会人员对当前的会议给出是否参加的回复
 
   *  操作前提
   
      *  当前页面中包含有效的并未召开的会议
   *  操作步骤
   
      *  在当前页面左下方单击操作 --> 回执按钮，弹出回执对话框页面，进行出席与否的回执
*  会议纪要操作：会议记录人通过此操作进行纪要查看和纪要维护；其它与会人员通过此操作进行会议纪要的查看；
 
   *  操作前提
   
      *  当前页面中包含有效的并未召开的会议
   *  操作步骤
   
      *  在当前页面左下方单击操作 --> 会议纪要按钮，弹出会议纪要页面，录入、发送会议纪要。

# 操作说明

*  通过菜单协同－>协同－>协同－>会议进入该界面；
*  操作步骤
 
   *  第1步：输入主题、会议室、开始时间、结束时间等信息；
   *  第2步：维护负责人、主持人、记录人、与会人员、正文等信息；
   *  第3步：点击保存按钮；
