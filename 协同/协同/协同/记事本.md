
# 功能描述

用户私人的记事本。可将记事本内容以消息发送给其他人员。

# 业务规则

*  启用协同系统（必做）

# 栏目说明

记事本——列表页签

|栏目|说明|
|---|---|
|checkbox|选择标识|
|标题|当前行中包含的笔记标题|
|记事本.名称|当前行中包含的记事本名称|
|最近编辑时间|当前行中包含的笔记的最近修改时间|

记事本——视图页签

|栏目|说明|
|---|---|
|标题|笔记的名称。|
|记事本|笔记的分类。|
|最近编辑时间|只读，反映最后编辑笔记的时间。|
|正文|笔记内容，支持HTML格式。|


# 按钮说明

*  转发消息操作
 
   *  打开指定的文章
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  第1步：在当前笔记本中选择要转发消息的文章，双击标题进入文章的编辑页面
      *  第2步：单击转发消息，弹出消息属性对话框（注：系统自动将当前文章的标题和内容带到消息的标题和内容中）

# 操作说明

*  通过菜单协同－>协同－>协同－>记事本进入该界面；
*  操作步骤
 
   *  第1步：维护标题；
   *  第2步：选择记事本，维护正文信息；
   *  第3步：点击保存。
