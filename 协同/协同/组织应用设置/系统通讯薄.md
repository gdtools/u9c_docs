
# 功能描述

定义当前用户所在组织的通讯簿。

# 业务规则

*  启用协同系统（必做）
*  协同管理员操作

# 栏目说明

联系人－导航页签

|栏目|说明|
|---|---|
|分组列表|当前用户可将联系人放置到不同的组中。单击添加，弹出组维护页面，填写组名，单击确定组创建成功|
|名称|单击右侧列表列出当前组中包含的联系人列表；点击名称链接可以更改组名称。点击名称右边的"X"可以删除组。|

# 按钮说明

*  添加操作:添加新的联系人
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  点击添加按钮，弹出人员选择页面
*  删除操作:删除联系人，支持批量删除
 
   *  操作前提
   
      *  选则至少一个联系人
   *  操作步骤
   
      *  选择要删除的联系人，点击删除按钮，弹出确认对话框，单击确定
*  发消息操作:给指定的联系人发送消息，可同时给多个联系人发消息
 
   *  操作前提
   
      *  选则至少一个联系人
   *  操作步骤
   
      *  选择要发消息的联系人，点击发消息按钮，弹出消息属性页面

# 操作说明

*  通过菜单协同－>协同－>组织应用设置-系统通讯薄进入该界面；
*  操作步骤
 
   *  第1步：添加联系人组。
   *  第2步：点击新增按钮。
   *  第3步：添加联系人。
   *  第4步：点击确定按钮。
