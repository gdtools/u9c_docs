
# 功能描述

定义对部门级协同进行管理的管理员。

# 业务规则

*  启用协同系统（必做）
*  协同管理员操作

# 栏目说明

部门协同管理员－属性页签

|栏目|说明|
|---|---|
|应用部门|选择协同应用的部门|
|管理员|添加部门协同管理员|

部门协同管理员－列表页签

|栏目|说明|
|---|---|
|应用部门.编码|应用部门的部门编码|
|应用部门.名称|应用部门的部门名称|
|应用部门.上级部门.名称|应用部门的上级部门编码|
|创建时间|当前行的部门协同管理员的创建时间|
|创建人|当前行的部门协同管理员的创建人|


# 按钮说明

*  添加操作：添加新的部门协同管理员
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  选择应用部门，点击添加管理员，点击保存按钮。
*  删除操作：删除部门协同管理员
 
   *  操作前提
   
      *  选择所要删除的部门协同管理员
   *  操作步骤
   
      *  点击删除按钮，弹出确认对话框，单击确定

# 操作说明

*  通过菜单协同－>协同－>组织应用设置-部门协同管理员进入该界面；
*  操作步骤
 
   *  第1步：选择应用部门。
   *  第2步：维护管理员。
   *  第3步：点击保存按钮。
