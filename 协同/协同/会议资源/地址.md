
# 功能描述

地址是会议管理中的基础信息,为企业中的会议室提供服务。用来维护企业内的会议室的地址信息；

# 业务规则

*  启用协同系统（必做）

# 栏目说明

会议资源－地址列表

|栏目|说明|
|---|---|
|checkbox|选择标识|
|编码|地址属性的编码字段|
|名称|地址的名称|
|描述|地址的描述信息|

会议资源－地址属性页面

|栏目|说明|
|---|---|
|编码|地址属性的编码字段，必填项|
|名称|地址属性的名称字段，必填项|
|简称|地址属性的简称|
|描述|地址属性的描述|
|生效|该地址属性是否生效，当CheckBox选项为真时，表示生效，否则表示无效|
|生效日期|该地址属性的生效日期|
|失效日期|当前地址属性的失效日期|


# 按钮说明

*  建筑物：在当前页面的左下方单击相关功能—> 单击弹出的下拉列表中的建筑物，进入建筑物维护页面
*  楼层：在当前页面的左下方单击相关功能—> 单击弹出的下拉列表中的楼层，进入楼层维护页面
*  会议室：在当前页面的左下方单击相关功能—> 单击弹出的下拉列表中的会议室，进入会议室维护页面

# 操作说明

*  通过菜单协同－>协同－>会议资源－>地址进入该界面；
*  操作步骤
 
   *  第1步：输入编码、名称等信息。
   *  第2步：输入简称、描述等信息。
   *  第3步：点击保存按钮。
