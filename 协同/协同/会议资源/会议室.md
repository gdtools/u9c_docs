
# 功能描述

会议室是会议管理中的基础信息,即会议中的硬件资源。用来为会议提供会议室属性的维护；

# 业务规则

*  启用协同系统（必做）

# 栏目说明

会议资源－会议室列表

|栏目|说明|
|---|---|
|checkbox|选择标识|
|编码|会议室的编码|
|名称|会议室的名称|
|描述|会议室的描述|
|楼层.名称|会议室所属的楼层|
|楼层.建筑物.名称|会议室所属的楼层所在的建筑物的名称|
|楼层.建筑物.地址.名称|会议室所属的楼层所在的建筑物的地址|

会议资源－会议室属性页面

|栏目|说明|
|---|---|
|编码|会议室的编码字段，必填项|
|名称|会议室属性的名称字段，必填项|
|描述|会议室属性的描述|
|地址|参照类型。会议室所隶属于的建筑物的地址|
|建筑物|参照类型。会议室所隶属于的建筑物的名称|
|楼层|参照类型。会议室所属的楼层|
|生效|该会议室属性是否生效，当CheckBox选项为真时，表示生效，否则表示无效|
|生效日期|该会议室属性的生效日期|
|失效日期|当前会议室属性的失效日期|

会议资源－会议室属性页面- 所属组织列表

|栏目|说明|
|---|---|
|编码|会议室隶属于的组织的编码|
|名称|会议室隶属于的组织的名称|


# 操作说明

*  通过菜单协同－>协同－>会议资源－>会议室进入该界面；
*  操作步骤
 
   *  第1步：输入编码、名称、描述等基本信息。
   *  第2步：选择地址、建筑物、楼层、组织等信息。
   *  第3步：点击保存按钮。
