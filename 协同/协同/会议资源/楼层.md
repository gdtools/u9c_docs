
# 功能描述

楼层是会议管理中的基础信息,为企业中的会议室提供服务。用来维护企业内的会议室的楼层信息；

# 业务规则

*  启用协同系统（必做）

栏目说明

会议资源－楼层列表

|栏目|说明|
|---|---|
|checkbox|选择标识|
|编码|楼层属性的编码字段|
|名称|楼层的名称|
|简称|楼层属性的简称|
|描述|楼层属性的描述|
|建筑物.名称|楼层所隶属于的建筑物的名称|
|建筑物.地址.名称|楼层所隶属于的建筑物的地址|

会议资源－楼层属性页面

|栏目|说明|
|---|---|
|地址|参照类型。楼层所隶属于的建筑物的地址|
|建筑物|参照类型。楼层所隶属于的建筑物的名称|
|编码|楼层属性的编码字段，必填项|
|名称|楼层属性的名称字段，必填项|
|简称|楼层属性的简称|
|描述|楼层属性的描述|
|生效|该楼层属性是否生效，当CheckBox选项为真时，表示生效，否则表示无效|
|生效日期|该楼层属性的生效日期|
|失效日期|当前楼层属性的失效日期|

# 按钮说明

*  会议室：在当前页面的左下方单击相关功能—> 单击弹出的下拉列表中的会议室，进入会议室维护页面

# 操作说明

*  通过菜单协同－>协同－>会议资源－>楼层进入该界面；
*  操作步骤
 
   *  第1步：选择地址、建筑物信息。
   *  第2步：输入编码、名称、简称、描述等信息。
   *  第3步：点击保存按钮。
