
# 功能描述

对本组织内的借阅申请进行审批等管理。

# 业务规则

*  启用协同系统（必做）

# 栏目说明

借阅管理－列表页面

|栏目|说明|
|---|---|
|借阅时间|当前借阅申请的申请时间|
|到期时间|当前借阅申请的到期时间|
|借阅状态|当前借阅申请的借阅状态|
|借阅人.名称|当前借阅申请的借阅人|
|公文档案.公文类别|当前借阅申请的公文类别|
|公文档案.公文标题|当前借阅申请的档案文件的标题|
|公文档案.公文字号|当前借阅申请的档案文件的字号|

# 按钮说明

*  借阅操作：选择当前列表中的公文，进行借阅申请；
*  审核操作：对借阅申请进行审批；
 
   *  操作前提
   
      *  获得档案管理员权限
   *  操作步骤
   
      *  在当前页面中选择要审批的申请，然后单击Toolbar中审核按钮；
*  退回操作：对借阅的申请给以退回。
 
   *  操作前提
   
      *  获得档案管理员权限
   *  操作步骤
   
      *  在当前页面中选择要审批的申请，然后单击ToolBar中的退回按钮。

# 操作说明

*  通过菜单协同－>协同－>公文应用－>借阅管理进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定按钮。
