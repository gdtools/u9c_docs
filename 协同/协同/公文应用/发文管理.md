
# 功能描述

对本组织内的发文进行管理，包括：发送、查询、归档等。

# 业务规则

*  启用协同系统（必做）

# 栏目说明

发文管理－列表页面

|栏目|说明|
|---|---|
|公文状态|当前发文的状态|
|公文类型|当前发文的类型|
|发文标题|当前发文的标题|
|主题词|当前发文的主题词|
|公文文号|当前发文的文号|
|秘密等级|当前发文的秘密等级|
|审核状态|当前发文的审核状态|
|紧急程度|当前发文的紧急程度|
|打印份数|当前发文的打印份数|

# 按钮说明

*  发送操作：将当前列表中指定的公文，发送出去
 
   *  操作前提
   
      *  获得当前组织发文权限
   *  操作步骤
   
      *  在当前页面列表中选择要发送的公文，然后单击Toolbar中发送按钮
*  申请归档操作：将当前组织内已经处理完并且审批通过的公文进行归档操作
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  在当前页面的列表中选择已经完成并审批通过的公文，然后单击Toolbar上的“申请归档”。

# 操作说明

*  通过菜单协同－>协同－>公文应用－>发文管理进入该界面；
*  操作步骤
 
   *  第1步：选择公文。
   *  第2步：点击发送按钮。
