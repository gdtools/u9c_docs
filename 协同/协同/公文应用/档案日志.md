
# 功能描述

档案文件的删除日志；

# 业务规则

*  启用协同系统（必做）

# 栏目说明

档案日志－列表页面

|栏目|说明|
|---|---|
|操作类别|当前日志记录中所记载的对该公文的操作是什么|
|公文标题|当前日志所记录的公文标题|
|公文类型.名称|当前日志中的公文类型|
|公文类别|当前日志中的公文是收文类别还是发文类别|
|操作人.名称|当前公文操作的操作人是谁|
|操作时间|当前日志中的公文被操作的时间|
|描述信息|当前日志中的公文被操作时候所填写的备注信息|

# 操作说明

*  通过菜单协同－>协同－>公文应用－>档案日志进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定按钮。
