
# 功能描述

本组织内的公文档案；

# 业务规则

*  启用协同系统（必做）

# 栏目说明

档案管理－列表页面

|栏目|说明|
|---|---|
|公文字号|当前档案文件的字号|
|公文标题|当前档案文件的标题|
|描述|当前档案文件的描述信息|
|公文类别|当前档案文件的类别是收文还是发文|
|归档时间|当前档案文件的归档时间|

# 按钮说明

*  目录管理操作：对当前档案库中的目录进行管理（增加、删除修改）。
 
   *  操作前提
   
      *  获得档案管理员权限
   *  操作步骤
   
      *  在当前页面单击目录管理，弹出目录管理对话框，然后单击对话框中的操作对目录进行新建、删除或重命名操作，完成相应的操作；否则放弃相应的操作。

# 操作说明

*  通过菜单协同－>协同－>公文应用－>档案管理进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定按钮。
