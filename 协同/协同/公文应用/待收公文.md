
# 功能描述

对其它组织发来的尚未接收的公文；

# 业务规则

*  启用协同系统（必做）

# 栏目说明

待收公文－列表页面

|栏目|说明|
|---|---|
|来文标题|当前来文的类型|
|主题词|当前来文的主题词|
|来文单位|当前来文的发文单位|
|来文日期|当前来文的日期|
|来文文号|当前来文的文号|
|来文状态|当前来文的状态|
|紧急程度|当前来文的紧急程度|
|秘密等级|当前来文的秘密等级|

# 按钮说明

*  接收操作：将当前登记的来文进行接收
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  在当前页面单击Toolbar中接收按钮

# 操作说明

*  通过菜单协同－>协同－>公文应用－>发文登记进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件相关信息。
   *  第3步：点击确定按钮。
