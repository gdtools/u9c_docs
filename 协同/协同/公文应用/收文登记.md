
# 功能描述

对其它组织发来的公文进行登记；

# 业务规则

*  启用协同系统（必做）

# 栏目说明

收文登记－列表页面

|栏目|说明|
|---|---|
|名称|当前收文表单的单据编码|
|显示名称|当前收文表单的单据显示名称|
|修改人|当前收文表单的单据最后修改人|
|修改时间|当前收文表单的单据最后修改时间|
|组织相关|当前收文表单与组织的相关状态|

收文登记－属性页面

|栏目|说明|
|---|---|
|来文标题|当前来文的标题|
|来文文号|当前来文的类型|
|主题词|当前来文的主题词|
|来文单位|当前来文的发文单位|
|来文日期|当前来文的日期|
|来文类型|当前来文的类型|
|公文类型|当前所登记的公文的类型|
|来文状态|当前来文的状态|
|秘密等级|当前来文的秘密等级|
|紧急程度|当前来文的紧急程度|
|已签收|当前来文的签收状态|
|已启封|当前来文的启封状态|
|已登记|当前来文的登记状态|
|已拟办|当前来文的拟办状态|
|已请办|当前来文的请办状态|
|已批办|当前来文的批办状态|
|已分发|当前来文的分发状态|
|已承办|当前来文的承办状态|
|已归档|当前来文的归档状态|

# 按钮说明

*  数据查询：弹出数据查询功能界面。

# 操作说明

*  通过菜单协同－>协同－>公文应用－>收文登记进入该界面；
*  操作步骤
 
   *  第1步：点击新增按钮。
   *  第2步：维护来文信息。
   *  第3步：点击保存按钮。
