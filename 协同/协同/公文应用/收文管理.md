
# 功能描述

对当前组织内的收文进行管理：归档、查询、查看等；

# 业务规则

*  启用协同系统（必做）

# 栏目说明

收文管理－列表页面

|栏目|说明|
|---|---|
|来文标题|当前来文的标题|
|主题词|当前来文的主题词|
|来文单位|当前来文的发文单位|
|来文日期|当前来文的日期|
|来文文号|当前来文的文号|
|来文状态|当前来文的状态|
|紧急程度|当前来文的紧急程度|
|秘密等级|当前来文的秘密等级|

# 按钮说明

*  查询操作：根据指定的条件进行对当前组织内的收文进行过滤查询
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  在当前页面列表上方选择公文状态、公文类型、公文六长城模板(三个条件可同时指定、也可以任意指定一个或两个），然后单击其后面的查询按钮
*  申请归档操作：将当前组织内已经处理完并且审批通过的公文进行归档操作
 
   *  操作前提
   
      *  无
   *  操作步骤
   
      *  在当前页面的列表中选择已经完成并审批通过的公文，然后单击Toolbar上的“申请归档”。

# 操作说明

*  通过菜单协同－>协同－>公文应用－>收文管理进入该界面；
*  操作步骤
 
   *  第1步：选择公文。
   *  第2步：点击申请归档按钮。
