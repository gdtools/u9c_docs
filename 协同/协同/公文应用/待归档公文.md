
# 功能描述

本组织内正在等待档案管理员进行归档的公文；

# 业务规则

*  启用协同系统（必做）

# 栏目说明

待归档公文－列表页面

|栏目|说明|
|---|---|
|公文类型.名称|当前来文的类型|
|公文类别|当前来文的发文单位|
|公文标题|当前来文的日期|
|公文字号|当前来文的秘密等级|

# 按钮说明

*  归档操作：将当前待归档列表中的公文文件，进行归档。即:将待归档列表中的文件归置到指定的档案库（档案目录）中；
 
   *  操作前提
   
      *  获得档案管理权限的用户
   *  操作步骤
   
      *  在当前页面中选择要归档的文件，然后单击Toolbar中归档按钮，弹出档案室（目录）选择对话框，选择要放置的目录，单击确定按钮，完成归档操作；否则放弃归档操作；
*  取消归档操作：将当前待归档列表中的文件，从待归档列表中清除。
 
   *  操作前提
   
      *  获得档案管理员权限
   *  操作步骤
   
      *  在当前页面选择要取消归档的文件，然后单击Toolbar中取消归档按钮。

# 操作说明

*  通过菜单协同－>协同－>公文应用－>待归档公文进入该界面；
*  操作步骤
 
   *  第1步：选择公文。
   *  第2步：点击归档按钮。
   *  第3步：选择档案室。
   *  第4步：点击确定按钮。
