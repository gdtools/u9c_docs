
# 功能描述

公文应用中的发文，本页面属于发文的拟稿或起草。公文的拟稿需要有拟稿权限的用户才能使用；

# 业务规则

*  启用协同系统（必做）

# 栏目说明

发文登记－列表页面

|栏目|说明|
|---|---|
|名称|当前收文表单的单据编码|
|显示名称|当前收文表单的单据显示名称|
|修改人|当前收文表单的单据最后修改人|
|修改时间|当前收文表单的单据最后修改时间|
|组织相关|当前收文表单与组织的相关状态|

发文登记－发文属性

|栏目|说明|
|---|---|
|发文标题|当前公文的标题|
|公文类型|当前发文的类型，必填项|
|公文文号|当前公文的文号|
|主题词|当前公文的主题词|
|正式文号|当前公文的正式文号|
|公文状态|公文的当前状态|
|紧急程度|当前公文的紧急程度|
|秘密等级|当前公文的秘密等级|
|打印份数|当前公文可打印的限制份数|
|收文单位|当前公文的发送对象|

# 按钮说明

*  数据查询：弹出数据查询功能界面。

# 操作说明

*  通过菜单协同－>协同－>公文应用－>发文登记进入该界面；
*  操作步骤
 
   *  第1步：点击新增按钮。
   *  第2步：维护发文信息。
   *  第3步：点击保存按钮。
