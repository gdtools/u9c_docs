
# 功能描述

用于将成本计算出的单价及成本回写给异动单据。异动单据一般指出入库单据。主要场景是为节省成本计算的效率。

# 业务规则

## 使用前提

*  已完成成本计算；

# 栏目说明

|栏目名称|说明|
|---|---|
|单据成本回写－期间|
|会计期间|回写单据范围的会计期间；|
|单据成本回写－组织范围|
|组织范围|需要回写单据成本的组织范围；|
|组织|指定回写单据的组织；|
|存货核算已完成|显示该组织是否已经完成存货核算；|
|开始时间|回写单据开始时间，回写开始时记录；|
|结束时间|回写单据开始时间，回写完成后记录；|

# 操作说明

## 回写

依据选择的会计期间范围及组织范围将成本计算的单价回写到业务单据。

**操作前提**

*  已经执行成本计算；

**操作步骤**

点击多组织成本－>单据成本回写－>回写。
