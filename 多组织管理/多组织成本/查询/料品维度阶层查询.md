
# 功能描述

成本阶层推算后，查看料品维度阶层。

# 业务规则

## 使用前提

*  执行了阶层和联动推算

# 栏目说明

|栏目名称|说明|
|---|---|
|组织范围|显示组织范围|
|会计期间|显示会计期间|
|组织|显示组织范围内的组织|
|料号|显示料号|
|品名|显示品名|
|项目|显示料品项目维度信息|
|等级|显示料品等级维度信息|
|成分|显示料品成分维度信息|
|厂牌|显示料品厂牌维度信息|
|维度阶层|显示料品维度阶层|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

具体操作参见查询方案
