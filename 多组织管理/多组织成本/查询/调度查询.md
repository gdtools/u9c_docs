
# 功能描述

查询多组织成本计算调度执行情况，支持重新执行，支持查看调度错误信息查询。

# 业务规则

## 使用前提

*  执行了多组织成本计算

# 栏目说明

|栏目名称|说明|
|---|---|
|调度信息|
|最近执行时间|显示调度最近执行时间|
|成功|显示调度是否执行成功|
|错误信息|显示调度执行的错误信息|
|请求|显示调度请求的信息|
|提交人|显示调度执行的提交人|
|状态|显示调度的执行状态|
|描述|显示关于调度的描述|
|提交时间|显示调度的提交时间|
|组织|显示调度的执行组织|
|执行明细情况|
|执行类型|显示调度的执行类型|
|执行时间|显示调度的执行时间|
|开始时间|显示调度执行的开始时间|
|结束时间|显示调度执行的结束时间|
|成功|显示调度执行是否成功|
|错误信息|显示调度执行中的错误信息|
|创建时间|显示调度的创建时间|

# 操作说明

## 查询方案

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

具体操作参见查询方案
