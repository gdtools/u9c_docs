
# 功能描述

查询多组织成本计算进行数据检查的所有错误信息，支持查看错误明细。

# 业务规则

## 使用前提

*  执行了多组织成本计算检查功能

# 栏目说明

|栏目名称|说明|
|---|---|
|数据检查错误查询|
|组织范围|显示核算向导界面录入的组织范围|
|会计期间|显示核算向导界面录入的会计期间|
|组织|显示警告或错误所属组织|
|功能节点|显示警告或错误信息的所在的核算向导的功能节点|
|编码|显示警告或错误的编码|
|名称|显示警告或错误的名称|
|相关业务|展现核算向导检查的业务对象|
|信息类型|系统对错误信息的分类：警告、错误|
|信息内容|系统对每种错误信息的描述|
|说明|系统对每种错误可能引起的后果的概述|
|建议处理|系统给用户的针对每条错误的建议处理方案|
|明细|
|类型|错误焦点行的错误类型|
|说明|错误焦点行的错误说明|
|建议处理|错误焦点行的错误处理方式|
|组织范围|错误焦点行所属的组织范围|
|会计期间|错误焦点行所属的会计期间|
|组织|错误焦点行所属的组织|
|单据类型|错误焦点行明细信息的单据类型|
|单据号|错误焦点行明细信息的单据号|
|单据对象|一般指料号、资源编号|
|单据对象名称|一般指品名、资源名称|
|部门|单据或档案的部门|
|行号|单据行号|
|行对象编码|单据行的料号、资源编码|
|行对象名称|单据行的品名、资源名称|
|说明|对错误或警告的详细描述|

# 操作说明

点击界面中的**[查询方案]**按钮，可以定义查询方案，包括查询条件、栏目及排序。

具体操作参见查询方案
