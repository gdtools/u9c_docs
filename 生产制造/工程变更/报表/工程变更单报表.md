
# 功能描述

提供工程变更申请单的打印。

# 业务规则

*  建立工程变更申请单。

# 栏目说明

|栏目名称|说明|
|---|---|
|组织|打印指定组织的工程变更申请单　可为当前组织及参照<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|申请单编码|打印指定申请单编码的工程变更申请单录入可空；|
|变更类型|打印指定变更类型的工程变更申请单参照变更类型录入可空；|
|变更原因|打印指定变更原因的工程变更申请单参照变更原因录入可空；|
|优先级|打印指定变更优先级的工程变更申请单选择录入可空|
|变更描述|当变更描述中包含所录入的内容时，进行打印：录入可空|
|申请日期|打印申请日期在录入日期范围内的工程变更申请单录入可空|
|申请人|打印指定申请人的工程变更申请单参照人员档案录入可空|
|申请部门|打印指定申请部门的工程变更申请单参照部门档案录入可空|
|状态|打印指定状态的工程变更申请单选择录入可空|

# 操作说明

*  通过菜单生产制造－>工程变更－>报表－>工程变更申请单报表进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件。
   *  第2步：点击确定。
