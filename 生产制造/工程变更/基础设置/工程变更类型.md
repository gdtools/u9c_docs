
# 功能描述 

工程变更类型定义工程变更的类型，以对工程变更单进行分类。

在工程变更单及工程变更申请单中可以引用。

# 业务规则

*  启用工程变更系统（必做）
*  编码不能重复；

# 栏目说明

工程变更类型

|栏目说明|说明|
|---|---|
|编码|工程变更类型的编码。|
|说明|工程变更类型说明|
|生效|该工程变更类型是否是生效的，只有生效的工程变更类型才可被引用。|
|生效日期|当［生效］为“是”时，录入工程变更类型的生效日期，不可大于失效日期|
|失效日期|当［生效］为“是”时，录入工程变更类型的失效日期，不可小于生效日期|

# 操作说明

*  通过菜单生产制造－>工程变更－>基础设置－>工程变更类型维护进入该界面；
*  操作步骤
 
   *  第1步：维护编码、说明等信息。
   *  第2步：点击保存。
