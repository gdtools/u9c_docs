
# 功能描述

工程变更原因定义工程变更的原因，如产品改进，客户要求等。

在工程变更单及工程变更申请单中可以引用。

# 业务规则

*  启用工程变更系统（必做）
*  编码不能重复；

# 栏目说明

工程变更原因

|栏目说明|说明|
|---|---|
|编码|工程变更原因的编码。|
|说明|工程变更原因说明|
|生效|该工程变更原因是否是生效的，只有生效的工程变更原因才可被引用。|
|生效日期|当［生效］为“是”时，录入工程变更原因的生效日期，不可大于失效日期|
|失效日期|当［生效］为“是”时，录入工程变更原因的失效日期，不可小于生效日期|


# 操作说明

*  通过菜单生产制造－>工程变更－>基础设置－>工程变更原因进入该界面；
*  操作步骤
 
   *  第1步：维护编码、说明等信息。
   *  第2步：点击保存。
