
# 功能描述

工程变更申请创建/修改/删除/审核工程变更申请。

支持从已有的工程变更申请中拷贝。

界面：支持列表及卡片。

可以插入不同格式的附件。

可以进行如下联查。

可以联查关联的工程变更单。

# 业务规则

*  启用工程变更系统（必做）
*  使用了BOM

# 栏目说明

工程变更申请－表头

|栏目|说明|
|---|---|
|单据类型|参照单据类型录入非空|
|单号|手工录入同一组织内，单号不可重复。|
|变更类型|参照<工程变更类型>输入非空|
|变更原因|参照<工程变更原因>输入非空|
|优先级|表示变更的优先、紧急程度。枚举行，下拉选择|
|变更描述|申请单的描述性信息。手工录入，可空|
|申请人|参照人员档案录入。非空|
|申请部门|带出申请人的部门非空，不可改|
|申请日期|录入申请日期非空|
|状态|显示当前变更申请单的状态|

工程变更申请－表体

|栏目|说明|
|---|---|
|行号|系统自动按照1，2，3，4等自然数自动编号。用户不能手工修改|
|变更内容|录入变更的具体内容非空|


# 按钮说明

*  <关闭>:关闭当前工程变更申请
 
   *  操作前提
   
      *  是当前变更申请单已审核通过。
   *  操作步骤
   
      *  点击【关闭】按钮，即关闭当前申请单据，当前申请单据状态改为“关闭”。
*  <生成工程变更单>:由当前变更申请单生成工程变更单。
 
   *  操作前提
   
      *  是当前变更申请单已审核通过。
   *  操作步骤
   
      *  点击【生成工程变更单】按钮，即弹出工程变更窗体，当前申请单的基本信息带入工程变更单中，其余操作步骤见工程变更单
*  <追溯查询>:快速调用由该变更申请单生成的工程变更单、快速调用　母件结构查询－多阶 和 产品工艺路线查询;
 
   *  操作步骤
   
      *  点击【追溯查询－关联工程变更单】按钮，系统自动转入该申请单生成的变更单画面；
      *  点击【追溯查询－母件结构查询－多阶】按钮，系统自动转入该查询画面，查询相关的bom信息；
      *  点击【追溯查询－ 产品工艺路线查询】按钮，系统自动转入该查询画面，查询相关的工艺路线信息。
*  <工程变更单>:自动进入工程变更单功能节点。
 
   *  操作步骤
   
      *  点击【相关功能－工程变更】按钮，自动进入 工程变更单 功能节点。

# 操作说明

*  通过菜单生产制造－>工程变更－>工程变更－>工程变更申请进入该界面；
*  操作步骤
 
   *  第1步：选择单据类型；
   *  第2步：维护变更类型、变更原因、变更人员等信息；
   *  第3步：维护变更内容；
   *  第4步：点击保存。
