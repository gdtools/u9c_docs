
# 功能描述

工程变更用于维护工程变更单

对工程变更单进行发行前的变更分析

对工程变更单进行计划发行

对工程变更单进行手动发行

发行时，可进行现场变更

可选择进行批量变更

对变更前后的工艺路线版本和bom版本进行快速跟踪查询

# 业务规则

*  启用工程变更系统（必做）
*  定义料品
*  定义生产目的（可选）
*  定义单位
*  定义生产线（可选）
*  定义BOM分类（可选）
*  定义项目（可选）
*  定义任务（可选）
*  定义发料组织（可选）
*  定义供应商（可选）
*  定义存储地点（可选）
*  定义库位（可选）
*  定义成本要素（可选）
*  定义作业（可选）
*  定义工作中心
*  定义检验方案（可选）
*  变更类型
*  变更原因

# 栏目说明

工程变更申请－表头

|栏目|说明|
|---|---|
|单据类型|参照单据类型录入非空|
|单号|手工录入同一组织内，单号不可重复。|
|变更类型|参照<工程变更类型>输入非空|
|变更原因|参照<工程变更原因>输入非空|
|优先级|表示变更的优先、紧急程度。枚举行，下拉选择|
|变更描述|申请单的描述性信息。手工录入，可空|
|申请人|参照人员档案录入。非空|
|申请部门|带出申请人的部门非空，不可改|
|申请日期|录入申请日期非空|
|状态|显示当前变更申请单的状态|

工程变更申请－表体

|栏目|说明|
|---|---|
|行号|系统自动按照1，2，3，4等自然数自动编号。用户不能手工修改|
|变更内容|录入变更的具体内容非空|


# 按钮说明

*  <计划>:将选中的工程变更单行置为计划态，到［计划发行日期］时，系统进行自动发行。
 
   *  操作步骤
   
      *  点击【操作－计划】按钮，选中的单行状态即为“计划”。
*  <取消计划>:将选中的工程变更单行置为计划态之前的状态。
 
   *  操作步骤
   
      *  点击【操作－取消计划】按钮，在弹出窗口中，选择要恢复的状态后，确定，选中的单行状态即为选中的状态。
      *  注：计划态的行才可执行“取消计划”操作。
*  <发行>:对选中的工程变更单行进行手动发行。
 
   *  操作步骤
   
      *  点击【操作－发行】按钮，执行发行操作。发行成功后，选中的单行状态即为“发行”，同时生成新版本的BOM或工艺。当单头勾选“现场更新”时，弹出需要更新的生产订单列表，选择需要现场更新的单据，确定后完成生产订单的现场更新。
      *  注：审核态和计划态的单行才可执行“计划”操作。
*  <取消发行>:对选中的工程变更单行进行取消发行。
 
   *  操作步骤
   
      *  点击【操作－取消发行】按钮，在弹出窗口中，选择要恢复的状态后，确定，取消发行成功后，选中的单行状态即为选择的状态，。
      *  注：
     
         *  1.发行态的行才可执行“取消发行”操作；
         *  2.已进行现场更新的行不可“取消发行”；
         *  3.变更后的BOM、工艺已被引用的行不可“取消发行”。
*  <终止>:将选中的变更单行置为终止态。
 
   *  操作步骤
   
      *  点击【操作－终止】按钮，将选中的单行置为终止态。
*  <明细>:对新增和修改的BOM或工艺，在弹出的明细画面中进行维护。
 
   *           *  操作步骤
     
         *  点击【明细】按钮，即弹出BOM或工艺的明细窗口，可在窗口中新增或修改BOM或工艺。
         *  具体请参见BOM和工艺维护
*  <批量修改>：对批量勾选为true的料品新增和修改的BOM或工艺，在弹出的画面中进行维护。
 
   *  操作步骤
   
      *  点击【批量变更】按钮，即弹出BOM或工艺的明细窗口，可在窗口中新增或修改BOM或工艺。
      *  具体请参见BOM和工艺维护
*  <批量变更范围>:对批量变更的工程变更单，在此录入变更的范围，执行变更时，对在变更范围内且符合条件的记录进行变更。
 
   *  操作步骤
   
      *  点击【批量变更范围】按钮，即弹出批量变更范围窗口，可在窗口中录入过滤条件后，点击【查询】按钮，列表中列示符合查询条件的记录，勾选需要变更的记录，点击【确定】按钮。
*  <追溯查询>:针对变更单行，自动调用物料清单或工艺路线节点快速定位对应的变更前的bom或工艺路线的版本的查询**** 
   *  操作步骤
   
      *  点击【追溯查询－物料清单】按钮，转入物料清单功能节点的物料清单变更前版本的查询结果
      *  点击【追溯查询－工艺路线】按钮，转入工艺路线功能节点的工艺路线变更前版本的查询结果
*  <结果查询>:针对变更单行，自动调用物料清单或工艺路线节点快速定位对应的变更后的bom或工艺路线的版本的查询，对于进行现场变更的变更单行，可以查询已经进行变更的生产订单。
 
   *  操作步骤
   
      *  点击【结果查询－物料清单】按钮，转入物料清单功能节点的物料清单变更后版本的查询结果
      *  点击【结果查询－工艺路线】按钮，转入工艺路线功能节点的工艺路线变更后版本的查询结果
      *  点击【结果查询－现场变更订单查询】按钮，可以查询该变更单已经进行变更的生产订单的情况
*  <工程变更分析>:在变更单发行前，针对变更单进行生产计划、生产订单、采购订单、现存量、成本进行分析
 
   *  操作步骤
   
      *  点击【工程变更分析－计划建议分析】按钮，针对变更单焦点行，自动调用变更料品和下级料品的计划订单查询情况
      *  点击【工程变更分析－生产分析】按钮，针对变更单焦点行，自动调用变更料品和下级料品的生产订单查询情况
      *  点击【工程变更分析－采购分析】按钮，针对变更单焦点行，自动调用变更料品和下级料品所需要的采购件的采购订单查询情况
      *  点击【工程变更分析－库存分析】按钮，针对变更单焦点行，自动调用变更料品和下级料品的库存现存量查询情况
      *  点击【工程变更分析－计划建议分析】按钮，针对整个变更单，自动调用成本卷积，对变更料品和下级料品的的成本进行计算并进行变更前后成本的对比
*  <明细对比>:工程变更原版本(未升版本)显示变更前后数据差异对比。
*  <变更范围>:工程变更做批量变更时,记录当前变更单所生效的变更作用对象。
*  <现场变更>:对BOM(工艺路线)进行修改操作后，若本次修改会引起现场备料(工艺)的变更，则可通过现场更新操作进行现场备料(工艺)的更新。
*  <明细对比>:工程变更原版本(未升版本)显示变更前后数据差异对比。

# 操作说明

*  通过菜单生产制造－>工程变更－>工程变更－>工程变更进入该界面；
*  操作步骤
 
   *  第1步：选择单据类型；
   *  第2步：维护变更类型、变更原因、变更人员等信息；
   *  第3步：维护更改类型、变更对象、料品、变更对象等变更内容；
   *  第4步：点击保存。
