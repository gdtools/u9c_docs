
# 功能描述

## 功能概述

工序转移单用于输入工序的完工情况，并记录工序转移的状况，包括正向转移和逆向转移：

*  正向转移：比如从第一道工序的排队状态转移到第二道工序的排队状态；
*  逆向转移：比如由于操作错误或者返工从第二道工序的排队状态转移到第一道工序的加工状态；

## 功能说明

*  新增、删除、修改工序转移单；
*  可以触发维护与本次工序转移相关的资源耗用报告；
*  可以维护工时：维护工时必须在工序转移单未完成转移的情况下完成；
*  可以查看工序转移单对应的倒扣领料单；
*  可以维护在制品批号和序列号；

# 业务规则

*  车间管理参数：工序转移审核标志=True，则创建的工序转移单是开立的，否则直接进行审核；
*  维护工时必须在工序转移单未完成转移的情况下完成；
*  转移数量必须符合工序状态数量的限制；
*  在生产订单参数中有是否允许超量完工和超量完工比例的设置，在工序转移时在生产订单工序总量不超出生产数量*（1+超量完工比例）的情况下，可实现工序的超量转移；
*  如果目标工序是委外工序，则目标状态必须是排队；
*  如果目标工序是质检工序，则目标状态必须是待转移；
*  如果启用派工单，在派工汇报时将由系统自动创建相应的工序转移单；
*  从返工状态转出的关注点
 
   *  工序转移时，如果生产订单参数是否通过返工生产订单返工=False，数量可以转出；
   *  来源状态为返工时，转入的工序号必须要比转出的工序号要小；
   *  来源状态为返工时，目的状态不能再为返工；
   *  返工转出业务合法性校验：转出数量必须小于生产订单上的未处理的返工数量；

# 操作说明

*  **新增生产工序转移单**

新增一张工序转移单。

操作步骤：点击车间管理－>车间作业－>工序转移单维护，进入新增工序转移单。具体步骤如下所示：

第1步：点击车间管理－>工序转移单维护，进入生产工序转移单维护 维护主界面；

第2步：选择输入单据类型、单据号等，选择要进行工序转移的生产订单或生产线日计划，输入从工序、从状态、到工序、到状态、转移数量等；

第３步：输入完毕点击<保存>按钮，保存输入的单据；

*  **修改工序转移单**

修改一张工序转移单维护。

操作前提：存在处于开立状态的工序转移单维护。

操作步骤：点击车间管理－>车间作业－>工序转移单维护 ，进入工序转移单维护主界面。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>工序转移单维护 ，进入工序转移单维护 维护主界面；

第2步：单击<查找>按钮，进入查找界面；

第3步：输入查找条件，点击<查找>按钮，系统显示符合查找条件的工序转移单维护 ；

第4步：点击想要修改的工序转移单维护行,选中它，然后单击<确定>按钮进入工序转移单维护 修改界面；

注意：审核以后的工序转移单维护，就不能修改。

第5步：修改工序转移单维护的具体内容；

第６步：修改完毕点击<保存>按钮。

*  **删除工序转移单**

删除一张工序转移单。

操作步骤：查找到想要删除的工序转移单维护 ，点击删除按钮进行删除。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>工序转移单维护 ，进入工序转移单维护主界面；

第2步：通过<查找>按钮或者上页下页定位到想要删除的工序转移单维护；

第3步：点击<删除>按钮，系统删除该选定工序转移单维护。

注意：只能删除处于开立状态的工序转移单维护。
