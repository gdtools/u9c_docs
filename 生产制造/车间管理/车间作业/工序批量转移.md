
# 功能描述

## 功能概述

工序转移单用于输入工序的完工情况，并记录工序转移的状况，进行批量转移，自动转移到下道工序的排队：

本结点提供批量工序转移单的相关操作；

## 功能说明

*  批量新增工序转移单
*  按照生单条件设置本次转移到下道工序的状态

# 业务规则

无

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|生产订单|如果是针对生产订单的工序转移，选择输入生产订单；如果是针对生产线日计划的完工操作，忽略该字段|
|生产线|如果是针对生产线日计划的工序转移，选择输入生产线日计划；如果是针对生产订单的完工操作，忽略该字段|
|生产日期|选择生产订单或生产线日计划时自动带出|
|料品|选择生产订单或生产线日计划时自动带出|
|工序号|当前工序|
|工序说明|当前工序的工序说明|
|排队数量|输入从工序的哪个状态转移|
|加工数量|当前工序加工数量|
|待转移数量|当前工序待转移数量|
|拒绝数量|当前工序拒绝数量|
|返工数量|当前工序返工数量|
|报废数量|当前工序报废数量|
|下道工序|输入转移到哪道工序|
|下道工序说明|选择到工序带入|
|转移数量|输入转移数量|
|来源工序|来源批号的加工工序|
|来源批号|来源工序的批号|
|目的批号|本工序加工的批号|

# 操作说明

操作步骤：点击车间管理－>车间作业－>工序批量转移，进入批量新增工序转移单，具体步骤如下所示。

第1步：点击车间管理－>工序批量转移 ，进入生产工序转移单批量转移 主界面；

第2步：查询、选择选择需要转移的工序；

第３步：选择完毕，点击<批量转移>按钮，批量创建工序转移单的单据；
