
# 功能描述

## 功能概述

本结点提供与派工单完工申报单相关的所有操作和活动。

## 功能说明

*  派工单完工申报单维护
*  可以手工创建派工单完工申报单
*  可以查看、修改或删除派工单完工申报单
*  可以提交、审核或弃审派工单完工申报单
*  可以申报资源耗用

# 业务规则

*  提前定义组织、部门、单据类型、料品、BOM、工艺等基础档案
*  启用了车间，存在已经审核的派工单

# 操作说明

*  **新增派工单完工申报单**

新增一张派工单完工申报单。

操作步骤：点击车间管理－>派工单完工申报单－>新增按钮，进入新增功能。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单完工申报单，进入派工单完工申报单维护主界面；

第2步：点击新增按钮进入派工单完工申报单头－基本页签（点击车间管理－>车间作业－>派工单完工申报单直接进入新增状态，如果当前屏幕为其它状态单击新增按钮可以进入新增状态）；

第3步：输入派工单完工申报单单头-基本信息，输入完成后点击"分单条件”页签，选择分单条件；

第4步：输入完成单击保存按钮。

*  **修改派工单完工申报单**

修改一张派工单完工申报单。

操作前提：派工单完工申报单已经存在。

操作步骤：点击车间管理－>车间作业－>派工单完工申报单，进入派工单完工申报单维护主界面。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单完工申报单，进入派工单完工申报单维护主界面；

第2步：单击查找按钮，进入查找界面；

第3步：输入查找条件，点击“查找”按钮，系统显示符合查找条件的派工单完工申报单；

第4步：点击想要修改的派工单完工申报单行选中它，然后单击“确定”　按钮进入派工单完工申报单修改界面；

注意:审核以后的派工单完工申报单就不能修改。

第5步：修改派工单完工申报单的具体内容，修改完成后单击保存按钮；

第6步：如果要修改资源，单击<资源>按钮进入资源维护界面。详细参见新增资源或修改订单资源。

*  **查找派工单完工申报单**

查找一张派工单完工申报单。

操作步骤：点击车间管理－>车间作业－>派工单完工申报单，进入派工单完工申报单维护主界面。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单完工申报单，进入派工单完工申报单维护主界面；

第2步：单击查找按钮，进入查找界面；

第3步：输入查找条件，点击“查找”按钮，系统显示符合查找条件的派工单完工申报单；

第4步：点击想要查看的派工单完工申报单行选中它，然后单击“确定”　按钮就进入派工单完工申报单维护主界面查看对应派工单完工申报单；

第5步：如果要查看资源，单击“资源”　进入资源维护界面；

*  **复制派工单完工申报单**

复制一张派工单完工申报单。

操作步骤：查找到想要复制的派工单完工申报单，点击复制按钮进行复制。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单完工申报单，进入派工单完工申报单维护主界面；

第2步：通过查找按钮或者上页下页定位到想要复制的派工单完工申报单；

第3步：点击“复制”按钮，系统将复制该派工单完工申报单到新的派工单完工申报单，其余操作步骤和新增一张派工单完工申报单一致。

*  **删除派工单完工申报单**

删除一张派工单完工申报单。

操作步骤：查找到想要删除的派工单完工申报单，点击删除按钮进行删除。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单完工申报单，进入派工单完工申报单维护主界面；

第2步：通过查找按钮或者上页下页定位到想要删除的派工单完工申报单；

第3步：点击“删除”按钮，系统删除该选定派工单完工申报单。注意：只能删除处于开立状态的派工单完工申报单。

*  **审核／弃审派工单完工申报单**

可以一次审核／弃审一张派工单完工申报单，也可以一次同时审核/弃审多张派工单完工申报单。

操作前提：只有开立状态的派工单完工申报单才需要审核，只有审核状态的派工单完工申报单才可以弃审。

操作步骤（一次审核一张）：查找到想要审核／弃审的派工单完工申报单，点击审核／弃审按钮进行审核／弃审。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单完工申报单，进入派工单完工申报单维护主界面；

第2步：通过查找按钮或者上页下页定位到想要审核／弃审的派工单完工申报单；

第3步：点击“审核／弃审”按钮。

操作步骤（一次审核多张）：查找到想要审核／弃审的派工单完工申报单，点击审核／弃审按钮进行审核／弃审。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单完工申报单，进入派工单完工申报单维护主界面；

第2步：点击列表按钮，进入派工单完工申报单列表界面；

第3步：点击查询按钮系统弹出条件输入窗口，输入查找条件；

第4步：输入查找条件后，点击“查找”系统显示符合条件的派工单完工申报单列表；

第5步：选中所要审核的派工单完工申报单，按“审核/弃审”按钮。
