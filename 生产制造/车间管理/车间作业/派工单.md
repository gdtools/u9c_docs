
# 功能描述

## 功能概述

本结点提供与派工单相关的所有操作和活动。

## 功能说明

*  派工单维护
 
   *  可以手工创建派工单
   *  可以参照来源派工单生成返修派工单
   *  可以查看、修改或删除派工单
   *  可以提交、审核或弃审派工单
   *  可以对派工单行进行退回、开工操作
*  派工单资源维护
 
   *  可以按工序维护派工单所需资源
   *  可以维护资源用量信息
   *  生成并维护资源耗用报告
*  可以对当前派工单做相关处理
 
   *  关闭派工单
   *  打开已关闭的派工单
   *  取消派工单
   *  挂起派工单
   *  解除已挂起的派工单
*  可以触发与当前派工单相关的后续处理
 
   *  派工单完工

# 业务规则

*  提前定义组织、部门、单据类型、料品、BOM、工艺等基础档案
*  启用了车间，存在已经审核的生产订单及其工序

# 操作说明

*  **新增派工单**

新增一张派工单。

操作步骤：点击车间管理－>派工单－>新增按钮，进入新增功能。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单，进入派工单维护主界面；

第2步：点击新增按钮进入派工单头－基本页签（点击车间管理－>车间作业－>派工单直接进入新增状态，如果当前屏幕为其它状态单击新增按钮可以进入新增状态）；

第3步：输入派工单单头-基本信息，输入完成后点击"分单条件”页签，选择分单条件；

第4步：输入完成单击保存按钮；

第5步：如果要新增或修改订单资源，单击“资源”　进入资源维护界面。详细参见新增资源或修改资源。

*  **修改派工单**

修改一张派工单。

操作前提：派工单已经存在。

操作步骤：点击车间管理－>车间作业－>派工单，进入派工单维护主界面。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单，进入派工单维护主界面；

第2步：单击查找按钮，进入查找界面；

第3步：输入查找条件，点击“查找”按钮，系统显示符合查找条件的派工单；

第4步：点击想要修改的派工单行选中它，然后单击“确定”　按钮进入派工单修改界面；

注意:审核以后的派工单就不能修改。

第5步：修改派工单的具体内容，修改完成后单击保存按钮；

第6步：如果要修改资源，单击“资源”　进入资源维护界面。详细参见新增资源或修改订单资源。

*  **查找派工单**

查找一张派工单。

操作步骤：点击车间管理－>车间作业－>派工单，进入派工单维护主界面。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单，进入派工单维护主界面；

第2步：单击查找按钮，进入查找界面；

第3步：输入查找条件，点击“查找”按钮，系统显示符合查找条件的派工单；

第4步：点击想要查看的派工单行选中它，然后单击“确定”　按钮就进入派工单维护主界面查看对应派工单；

第5步：如果要查看资源，单击“资源”　进入资源维护界面。

*  **复制派工单**

复制一张派工单。

操作步骤：查找到想要复制的派工单，点击复制按钮进行复制。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单，进入派工单维护主界面；

第2步：通过查找按钮或者上页下页定位到想要复制的派工单；

第3步：点击“复制”按钮，系统将复制该派工单到新的派工单，其余操作步骤和新增一张派工单一致。

*  **删除派工单**

删除一张派工单。

操作步骤：查找到想要删除的派工单，点击删除按钮进行删除。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单，进入派工单维护主界面；

第2步：通过查找按钮或者上页下页定位到想要删除的派工单；

第3步：点击“删除”按钮，系统删除该选定派工单。注意：只能删除处于开立状态的派工单。

*  **新增／修改／删除派工单资源**

针对已经存在的派工单，新增／修改／删除资源。如果从派工单头开始新增，参见新增派工单。

操作步骤：查找到想要新增／修改／删除资源的派工单，点击<资源>按钮。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单， 进入派工单维护主界面；

第2步：通过查找按钮或者上页下页定位到想要新增／修改／删除工序资源的派工单；

第3步：单击<资源>按钮，进入订单工序维护界面；

第4步：将光标移动到订单工序行区域，单击鼠标左键，界面出现“新增／插入／删除”行操作按钮。

新增操作方法：点击新增或者插入，输入新的资源。选择新增时系统在最后增加新的一行，选择插入时系统在光标所在行的前面插入一行。

修改操作方法：将光标移动想要修改的资源行，直接进行修改　。

删除操作方法：将光标移动想要删除的资源行，点击删除，删除对应的资源行。

第5步：操作完毕按<确定>按钮进行保存。

*  **审核／弃审派工单**

可以一次审核／弃审一张派工单，也可以一次同时审核/弃审多张派工单。

操作前提：只有开立状态的派工单才需要审核，只有审核状态的派工单才可以弃审。

操作步骤（一次审核一张）：查找到想要审核／弃审的派工单，点击审核／弃审按钮进行审核／弃审。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单，进入派工单维护主界面；

第2步：通过查找按钮或者上页下页定位到想要审核／弃审的派工单；

第3步：点击“审核／弃审”按钮。

操作步骤（一次审核多张）：查找到想要审核／弃审的派工单，点击审核／弃审按钮进行审核／弃审。具体步骤如下所示：

第1步：点击车间管理－>车间作业－>派工单，进入派工单维护主界面；

第2步：点击列表按钮，进入派工单列表界面；

第3步：点击查询按钮系统弹出条件输入窗口，输入查找条件；

第4步：输入查找条件后，点击“查找”系统显示符合条件的派工单列表；

第5步：选中所要审核的派工单，按“审核/弃审”按钮。
