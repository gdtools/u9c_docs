
# 功能描述

本节点主要为进行可视化排程操作前的必要参数设置。

# []()业务规则

*  定义组织、部门等基础档案；
*  启用可视化排程模块。

# 栏目说明

[]()排程事务

|栏目|说明|
|---|---|
|----基本||
|事务编号|系统自动生成的该事务的一个编号。|
|操作人员编码|操作人员的编码。|
|创建时间|当前的排程事务初次创建的时间。|
|修改时间|当前的排程事务最近一次修改时间。|
|——时间参数||
|排程基准时刻|排程操作时，甘特图的起始时界排程基准时刻<=需求开始时刻|
|需求开始时刻|排程操作时，参与排程计算的初始时刻排程基准时刻<=需求开始时刻|
|需求结束时刻|排程操作时，参与排程计算的结束时刻，同时也是甘特图的截止时界排程基准时刻<=需求开始时刻|
|-----控制参数||
|考虑瓶颈工序前缓冲|排程过程中，是否考虑瓶颈工序的前缓冲时间|

排程事务－优先级

|栏目|说明|

排程事务－组织

|栏目|说明|
|---|---|
|组织|本次排程事务涵盖的组织|
|上级组织|所选组织的上级组织|
|下级组织|所选组织的下级组织|
|来源组织|所选组织的来源组织|
|目的组织|所选组织的目的组织　|
|关系企业|是否和当前组织为关系企业|
|关系类型|和当前企业的关系类型|

# 操作说明

*  通过菜单生产制造－>可视化排程－>可视化排程**－**>排程事务进入该界面；
*  操作步骤
 
   *  []()点击可视化排程－>排程事务－>新增按钮，进入新增排程功能。具体步骤如下所示。
   *  第1步：可视化排程－>排程事务，进入排程事务维护主界面；
   *  第2步：点击新增按钮进入排程事务头；
   *  第3步：输入排程事务头，输入完成后点击“排程目标”页签，输入排程目标相关信息；输入完成后点击“优先级”页签，输入排程优先级相关信息；输入完成后点击“组织”页签，输入排程组织相关信息；
   *  第4步：输入完成单击保存按钮。
