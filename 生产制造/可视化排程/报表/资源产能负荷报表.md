
# 功能描述

提供资源产能负荷的打印。

# 查询说明

[查询条件](http://wangwq/U9C/help/zh-CN/Content/MFG/OS/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|生产部门|打印指定生产部门的关联资源产能负荷参照生产部门档案录入；可空；|
|生产订单|打印指定生产订单的关联资源产能负荷参照生产订单档案录入；可空；|
|生产订单工序|打印指定生产订单工序的关联资源产能负荷参照生产订单工序档案录入；可空；|
|作业|打印指定作业的关联资源产能负荷参照作业档案录入；可空；|
|资源|打印指定资源产能负荷参照资源档案录入；可空；|
|统计日期类型|打印此时间段内的资源负荷今天、本周、本月、本季、半年、本年、昨天、上周、上月、上季、去年、指定日期|
|显示日期类型|依显示日期类型显示结果目前支持天、周、月、季|
|统计日期起|[统计日期类型]＝“指定日期”时本栏目可用|
|统计日期止|[统计日期类型]＝“指定日期”时本栏目可用|
|资源汇总格式|枚举：按归属资源按资源|
|产能策略|枚举输入选择需要试算的产能策略|
|产能单位|枚举：按时间按产量单位|

# 业务规则

*  启用可视化排程
*  执行当前排程事务

# 按钮说明

*  <后退>:返回主界面。****

# 操作说明

*  通过菜单生产制造－>可视化排程－>报表－>资源产能负荷报表进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件。
   *  第2步：点击确定。
