
# 功能描述

## 功能概述

在制品盘点：是指对领用到生产现场及生产执行过程中的各类料品的状态和数量进行清点和记录。

本节点用于盘点车间现场的在制品。

## 功能说明

*  查看由系统批量创建的盘点单
*  手工新增在制品盘点单
*  提交、审核或弃审在制品盘点单
*  挂起在制品盘点单
*  解除已挂起的在制品盘点单
*  作废在制品盘点单
*  根据盘点结果录入整单或工序的不同状态的实盘数据
*  盘点完成确认

# 业务规则

*  已由盘点快照生成盘点单

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|部门|盘点活动所针对的生产部门，每张盘点单都必须有其对应的生产部门以标识具体的生产现场|
|盘点日期|盘点日期用于标识同一次盘点，只有盘点日期完全相同的盘点单才被系统认为是同一次盘点的单据|
|执行日期|实际执行盘点的时间|
|生产订单/生产线日计划|可按生产单据盘点|
|工序|有工序表示盘点的是工序上各个状态的数量，工序空则表示盘点的是生产单据整单的数量|
|料品|盘点的在制品料号|
|整单盘点数量|以生产单据整单为对象，盘点各个状态的数量，包括：未完工数量、已完工未入库数量、已完工未入库合格数量、已完工未入库报废数量、需返工而未返工数量，如果是由系统创建的单据，上述数量系统会提供参考量|
|工序盘点数量|以生产单据工序为对象，盘点各个状态的数量，包括：排队数量、加工数量、待转移数量、拒绝数量、报废数量、返工数量，如果是由系统创建的单据，上述数量系统会提供参考量|

# 操作说明

*  **在制品盘点**

录入在制品的盘点结果。

操作前提：已创建了在制品盘点单。

操作步骤：点击生产管理－>盘点－>在制品盘点，进入在制品盘点主界面。具体步骤如下所示：

*      *  第1步：点击生产管理－>盘点－>在制品盘点，进入在制品盘点主界面；
   *  第2步：点击查找按钮，或者通过上页下页定位到要处理的盘点单；
   *  第3步：审核确认需要录入盘点结果的盘点单；
   *  第4步：在各个盘点数量中录入实盘量，点击保存按钮；
   *  第5步：录入完成后点盘点完成确认盘点结果。列表画面中可批量审核盘点单，也可批量确认录入的盘点结果。
