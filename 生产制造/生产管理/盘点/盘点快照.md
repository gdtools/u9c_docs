
# 功能描述

## 功能概述

本功能用于在制品盘点开始前获取并维护快照。

## 功能说明

*  获取快照
*  删除快照
*  生成盘点单

# 业务规则

无

# 栏目说明

*  **生成盘点单**

|**栏目名称**|**说明**|
|---|---|
|分单维度|选择批量生成盘点单时的分单维度|
|备料维度|选择备料盘点时要按何种料品维度盘点，未选择的备料维度将在备料盘点时被忽略|

# 按钮说明

无

# 操作说明

*  **快照**

手工获取车间在制品和生产备料的快照。

获取快照前应该先删除前次生成的快照。

*  **快照调度**

可设定系统调度安排获取快照。

*  **删除快照**

手工删除已生成的快照。

前次获取的快照若未完成盘点则不可删除。

*  **生成盘点单**

根据快照生成盘点单。

操作步骤：点击生产管理－>盘点－>盘点快照，进入盘点快照维护主界面。具体步骤如下所示：

*      *  第1步：点击生产管理－>盘点－>盘点快照，进入盘点快照维护主界面；
   *  第2步：点击生成盘点单按钮，弹出【分单条件画面】；
   *  第3步：设定分单条件后点确定按钮，系统自动批量创建盘点单。
