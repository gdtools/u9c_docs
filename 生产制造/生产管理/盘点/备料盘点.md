
# 功能描述

## 功能概述

本节点用于盘点已领到车间现场但未消耗的备料。

## 功能说明

*  查看由系统批量创建的盘点单
*  手工新增备料盘点单
*  审核备料盘点单
*  根据盘点结果录入备料的实盘数据
*  盘点完成

# 业务规则

*  已由盘点快照生成盘点单

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|部门|盘点活动所针对的生产部门，每张盘点单都必须有其对应的生产部门以标识具体的生产现场|
|盘点日期|盘点日期用于标识同一次盘点，只有盘点日期完全相同的盘点单才被系统认为是同一次盘点的单据|
|执行日期|实际执行盘点的时间|
|生产订单/生产线日计划|可按生产单据盘点|
|工序号|有工序表示盘点的是工序上的备料数量，工序空则表示盘点的是生产单据整单的备料数量|
|料号|盘点的备料料号|
|料品|盘点的备料料品|
|实盘数量|录入备料的实际盘点数量|

# 按钮说明

无

# 操作说明

*  **备料盘点**

盘点结果的录入。

操作前提：已创建了备料盘点单。

操作步骤：点击生产管理－>盘点－>备料盘点，进入备料盘点主界面。具体步骤如下所示：

*      *  第1步：点击生产管理－>盘点－>备料盘点，进入备料盘点主界面；
   *  第2步：点击查找按钮，或者通过上页下页定位到要处理的盘点单；
   *  第3步：审核确认需要录入盘点结果的盘点单；
   *  第4步：在各个盘点数量中录入实盘量，点击保存按钮；
   *  第5步：录入完成后点击盘点完成确认盘点结果；列表画面中可批量审核盘点单，也可批量确认录入的盘点结果；
