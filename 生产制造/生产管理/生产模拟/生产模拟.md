
# 功能描述

## 功能概述

生产模拟是应用生产计划层、短期或者实时的计划功能组件，也可以是销售接单预估备料供应能力的决策工具，它能够针对生管人员或者销售人员提供的生产需求按照预设的模拟参数设置，按照BOM结构逐层分析，最后反算出当前模拟成品相关备料供应的最小成套数，从而提供给模拟人员最准确的，实时的辅助决策信息。

模拟参数可以设置模拟的备料范围，以及备料在不同供应组织的不同供应存储地点的供应范围，这些都使生产模拟功能变得更加灵活、准确、易用。

# 栏目说明

*  **生产模拟**

|**栏目名称**|**说明**|
|---|---|
|**生产模拟－表头页签**|
|编码|用于定义和显示生产模拟方案的编码|
|名称|用于定义和显示生产模拟方案的名称|
|模拟日期|用于显示生产模拟系统日期|
|计划组织|用于显示生产模拟的计划组织|
|生产模拟方案|可以将生产模拟分析方案定义成为多套预制方案，在生产模拟分析中重复使用|
|在制需求|物料供应优先扣减在制订单的备料需求后，剩余供应用于本次生产模拟的备料齐套分析|
|只考虑关键件|用于控制本次生产模拟只分析的BOM中的关键物料，即物料档案中的【ATP检查】标识为true|
|预计可用库存|此字段用于控制本次生产模拟时，库存供应需要考虑库存的预计入和预计出。具体算法同可用量规则|
|采购在途|此字段用于控制本次生产模拟考虑供应时，需要包含采购订单已经确认但是尚未到货的采购供应|
|调拨在途|此字段用于控制本次生产模拟考虑供应时，需要包含已经调出，但是尚未调入的调拨在途供应|
|在制|此字段用于控制本次生产模拟考虑供应时，需要包含已经确认的生产订单但是尚未完工的生产在制供应|
|**生产模拟－表体页签**|
|模拟序号|考虑到多笔需求同时模拟会出现对公用料争抢情况，因此在模拟需求明细中增加优先级字段，高优先级需求优先占用公用料。模拟需求用于定义和显示本次生产模拟的需求优先级|
|BOM主档|用于参照参与生产模拟的分析物料BOM。分析物料支持制造件、重复件、KIT件、虚拟件、FAS等，为了提高客户录入料品BOM的易用性，生产模拟支持OBA导入生产模拟需求明细|
|品名|用于显示分析物料的品名|
|规格|用于显示分析物料的规格属性|
|版本|用于显示分析物料的料品版本信息|
|BOM类型|用于显示分析物料BOM的BOM类型信息|
|生产线|用于显示分析物料BOM的生产线信息|
|生产目的|用于显示分析物料BOM的生产目的信息|
|BOMECO号|用于显示分析物料BOM的ECO信息|
|模拟数量|用于定义分析物料的模拟数量，此数量已经包含物料的生产损耗|
|MRP数量|用于定义分析物料的净需求量，系统自动按产出率计算模拟数量|
|模拟单位|用于定义分析物料模拟数量单位，默认为生产单位|
|展开阶数|用于定义分析物料展开的BOM层级|
|预计开工时间|用于定义分析物料的预计开工日期，系统依据料品提前期自动计算预计完工日期|
|预计完工时间|用于定义分析物料的预计完工日期，系统依据提前期自动计算预计开工日期|
|货主组织|用于显示分析物料BOM的货主信息|
|番号|用于定义和显示分析物料的番号维度，BOM多阶展开时依据番号维度传递规则，将母件番号传递到BOM子项中|
|项目|用于定义和显示分析物料的项目维度，BOM多阶展开时，依据项目维度传递规则，将母件项目传递到BOM子项中|
|需求分类|用于定义和显示分析物料的需求分类维度，BOM多阶展开时，依据需求分类维度传递规则，将母件需求分类传递到BOM子项中|

# 按钮说明

*  **生产模拟**

<即时模拟>：实时分析、立刻得到分析结果。

<调度模拟>：指定日期系统自动执行。

*  **生产模拟结果**

<查询>：用于设置生产模拟结果画面的查询和显示方案。

<缺料明细>：用于显示分析物料不同BOM层级子件的缺料状况。

<供需匹配明细>：用于显示分析物料不同BOM层级子件匹配到供应明细信息。

<成品自制>：将用户选择的分析物料，按转生产数量生成生产订单或日计划订单。

*  **缺料明细**

<备料自制>：用于选择备料子项后，按转出数量生成生产订单和日计划订单。

<备料采购>：用于选择备料子项后，按转出数量生成采购订单。

*  **供需匹配**

<查询>：用于设置生产模拟供需匹配画面的查询和显示方案。
