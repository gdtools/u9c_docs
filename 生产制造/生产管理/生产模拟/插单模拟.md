
# 功能描述

## 功能概述

针对紧急销售订单或者紧急计划订单，通过模拟改制确定可以在现有哪些生产订单进行改制就能够满足紧急销售订单或者紧急计划订单的要求。

## 功能说明

无

# 业务规则

*  有紧急销售订单或者紧急计划订单存在
*  紧急订单通常是指，交期大于今日，且交期 - 提前期，小于今日

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**插单模拟－表头**|
|紧急订单类型|选择确定插单模拟的对象是销售订单还是计划订单|
|订单编码|如果[紧急订单类型]=销售订单，则选择输入对应的销售订单编码；如果[紧急订单类型]=计划订单，则选择输入对应的计划订单编码|
|生产目的|选择输入BOM生产目的，缺省等于主制造|
|BOM有效日期|输入BOM有效日期，用于确定BOM版本及有效的备料|
|工艺替换类型|选择输入工艺替换类型，缺省等于主制造|
|工艺有效日期|输入工艺有效日期，用于确定工艺版本及有效的工序|
|**插单模拟－表体**|
|生产数量|系统根据销售订单数量或者计划订单数量自动计算生产数量，可以手工修改|
|MRP数量|系统根据销售订单数量或者计划订单数量自动计算MRP数量，可以手工修改|
|计划开工时间|预计生产订单的开工时间，系统自动计算后可以手工修改|
|计划完工时间|预计生产订单的完工时间，系统自动计算后可以手工修改|

# 操作说明

*  **插单模拟操作**

操作步骤：点击生产管理－>生产模拟-->插单模拟，进入插单模拟界面。具体步骤如下所示：

*      *  第1步：选择进行插单模拟的销售订单或者计划订单。在插单模拟－—表头选择输入“紧急订单类型”及“订单编码”；
   *  第2步：输入BOM及工艺的生产目的及生效日期。在插单模拟－—表头输入“生产目的”、“BOM有效日期”、“工艺生产目的”、“工艺有效日期”；
   *  第3步：如果有必要，调整生产数量及开工日期。修改插单模拟－—表体“生产数量”、“MRP数量”、“计划开工时间”、“计划完工时间”；
   *  第４步：点击改制按钮，系统计算后显示可以改制的生产订单列表；
   *  第５步：如果确认系统模拟改制的结果，可以在改制列表界面点击确认按钮系统自动根据当前模拟方案创建生产订单。如果不接受模拟结果点击放弃按钮。
