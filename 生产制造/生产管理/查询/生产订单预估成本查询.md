
# 功能描述

## 功能概述

生产订单一旦审核，就会产出该订单的预估成本，通过本功能对生产订单的预估成本进行查询。

## 功能说明

无

# 业务规则

*  生产订单已经审核

# 操作说明

*  **一般操作参见公共操作说明。**
*  **生产订单预估成本查询**

查询生产订单或者生产线日计划下达时生成的预估要素成本或分项成本。

操作步骤：点击生产订单－>生产订单预估成本查询　进行查询。具体步骤如下所示：

*      *  第1步：点击查询按钮，录入查询条件，确定后得到生产订单和生产线日计划列表，显示在生产订单预估成本查询列表中；
   *  第2步：在生产订单预估成本查询列表中双击需要查询的生产订单和生产线日计划行，在分项成本表中显示该生产订单或生产线日计划的分项成本；
   *  第3步：如需要查询该订单的要素成本，请点击要素成本按钮，弹出要素成本显示界面，显示本生产订单或生产线日计划各明细成本要素分本阶和下阶的成本；
