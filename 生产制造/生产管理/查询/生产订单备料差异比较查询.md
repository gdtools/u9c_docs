
# 功能描述

## 功能概述

可比较两个不同生产订单的备料差异；

可比较两个不同BOM差异；

可比较一个生产订单备料和BOM的差异等。

## 功能说明

无

# 业务规则

*  维护物料清单
*  已经创建生产订单

# 栏目说明

*  **查询条件**

|**栏目名称**|**说明**|
|---|---|
|基准生产订单|要查询的基准生产订单；基准生产订单、基准PLS、基准BOM母项只能维护一个|
|基准PLS|要查询的基准重复计划；基准生产订单、基准重复计划、基准BOM只能维护一个|
|基准BOM母项|要查询的基准BOM；基准生产订单、基准重复计划、基准BOM只能维护一个|
|比较生产订单|要查询比较的生产订单；比较生产订单、比较PLS、比较BOM母项只能维护一个|
|比较PLS|要查询比较的PLS；比较生产订单、比较PLS、比较BOM母项只能维护一个|
|比较BOM母项|要查询比较的BOM；比较生产订单、比较PLS、比较BOM母项只能维护一个|
|考虑备料工序号|如果=是，则考虑工序号；如果=否，不考虑|
|考虑数量|如果=是，同一物料，数量（单位）不同，按属性不同处理；如果=否，同一物料，数量（单位）不同，按属性相同处理|
|比较属性|料品编码；料品全纬度|

*  **查询栏目**

|**栏目名称**|**说明**|
|---|---|
|**上列表**|
|单据编码|显示基准单据编码|
|料号|显示基准料品的料品|
|品名|显示基准料品的品名|
|版本|显示基准料品的版本号|
|生产数量|显示基准料品的生产数量|
|单位|显示基准料品的单位|
|项目|显示基准项目编码|
|货主组织|显示基准货主组织|
|**下列表**|
|单据编码|显示比较单据单据编码|
|料号|显示比较料品编码|
|品名|显示比较料品名称|
|版本|显示比较料品版本|
|生产数量|显示比较料品数量|
|单位|显示基准料品的单位|
|项目|显示项目|
|货主组织|显示货主组织|
|差异率|显示备料的差异率；差异率＝不相同备料个数/总备料个数|
