
# 功能描述

## 功能概述

本功能用来查询生产订单发生的返工或报废成本。

## 功能说明

无

# 业务规则

*  成本核算模式为“吸收”

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**生产订单品保成本查询－订单查询条件**|
|生产订单|要查询品保成本的生产订单|
|成本域|要查询品保成本的生产订单所在的成本域；参照录入；为空时表示查询所有成本域|
|成本类型|要查询的成本类型；参照录入；为空时表示查询所有成本类型|
|账薄|要查询的账薄；参照录入，参照成本域下的所有账薄；为空时表示查询成本域下的所有账薄|
|料品|生产订单生产的料品|
|记账|查询记账成本还是非记账成本|
|**生产订单品保成本查询－子订单查询条件**|
|生产订单|要查询成本的生产订单|
|料品|生产订单生产的料品|
|业务类型|要查询哪种业务类型的订单成本：返工生产；报废生产|
|**生产订单品保成本查询－订单查询结果**|
