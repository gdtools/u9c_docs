
# 功能描述

## 功能概述

本功能用来查询生产订单生产过程中外协工序发生的委外成本。

## 功能说明

无

# 业务规则

*  生产订单发生了工序委外业务

# 操作说明

*  **一般操作参见公共操作说明。**
*  **生产订单工序委外成本查询**

通过生产订单工序委外成本查询，用户可以查询到生产订单或者生产线日计划发生的委外工序的外协成本要素成本。

操作步骤：点击生产订单－>生产订单工序委外成本查询　进行查询。具体步骤如下所示：

*      *  第1步：点击查询按钮，录入查询条件，确定后得到带有外协工序的生产订单和生产线日计划列表，显示在生产订单工序委外成本查询列表中；
   *  第2步：在生产订单工序委外成本查询列表中双击需要查询的生产订单和生产线日计划行，在要素成本列表中显示该生产订单或生产线日计划委外工序的各个明细要素成本，同时在生产订单工序委外成本查询列表中按照生产订单或生产线日计划对应的外协总成本；
