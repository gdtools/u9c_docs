
# 功能描述

## 功能概述

本节点提供齐套分析的相关功能。

## 功能说明

*  按不同订单（生产订单、生产线日计划、计划生产订单、计划订单、委外订单）分析备料的齐套情况
*  指定成套策略，按照指定的成套策略分析备料的齐套情况
*  可以分析单据的所有备料或者参与齐套分析的备料
*  可以指定存储地点分析备料的供应量
*  齐套分析考虑替代情况

# 业务规则

*  提前定义组织、部门、料品、BOM、工艺等基础档案
*  存在生产订单和生产线日计划、计划生产订单、计划订单、委外订单
*  在应用服务器和数据库服务器端配置MS DTC并启动该服务

# 栏目说明

*  **齐套分析－单头**

|**栏目名称**|**说明**|
|---|---|
|**基本**|
|编码|齐套分析的编码，支持手工编码和自动编码两种方式。 自动编码需要为“齐套分析编码规则”参数（生产管理-参数设置界面）设置编码方案。如果“齐套分析编码规则”参数未设置编码方案，则齐套分析编码支持手工编码录入方式|
|名称|齐套分析的名称描述|
|模拟日期|模拟日期默认为齐套分析档案创建时的系统日期，可改。 模拟日期的另外一个用途是用于分析未来某一日期点，订单备料的齐套情况，如果当前订单备料不齐套，一周后或一个月后订单备料的齐套情况如何|
|模拟业务员|进行齐套分析的人员|
|部门|进行齐套分析的部门|
|单据|U9V3版本产品的齐套分析功能支持分析对象有生产订单、生产日计划订单、计划订单、计划生产订单|
|分析类型|选择进行的是齐套分析还是补齐套分析|
|分析策略|指定按照何种策略进行成套分析。按生产数量分析：按订单生产数量进行分析备料齐套情况。按指定套数分析：用户可以自己指定分析数量，但指定的套数不可以超过生产数量。可成套数量分析:按照定义的备料供应来源得到备料的最大可成套数量,最大可成套数量不可以超过生产数量。累计成套数量分析：按照订单的累计齐套领料数量进行分析|
|需求来源类型|取值范围：按订单分析：按指定订单的方式进行分析，即分析订单的全部备料。按备料分析：按指定备料的方式进行分析，即分析订单指定的备料。注意：齐套分析按备料进行分析时，需要设置备料方案或料品范围，用于限定本次分析的料品范围|
|分析条件档案|可以将齐套分析方案定义成为多套分析条件档案，在齐套分析中重复使用|
|优先考虑已开工订单|备料供应优先供应本次模拟外已开工订单后，剩余的备料供应再用于本次齐套分析|
|分析组织|显示进行齐套分析的默认组织|
|生效|是否失效齐套分析；如果选择失效，则齐套分析按钮就失效|
|**选项**|
|备料齐套范围|选择分析的范围|
|重复使用库存|是否可以重复使用库存|
|预计库存|是否考虑预计入和预计出|
|在制供应|是否考虑正在生产的供应|
|采购在途|是否考虑已经采购未收货的供应|
|调拨在途|是否考虑调拨在途未收货的供应|
|包含领料未发|是否考虑已领料还未发的|

*  **备料方案**

需求来源类型为“按备料分析”时，可以通过此界面定义过滤订单备料的查询方案，筛选出的备料用于本次齐套分析。

*  **备料全选**

需求来源类型为“按备料分析”时，订单备料记录数量超过5000条时，使用此功能进行全选操作。

*  **批量删除**

对齐套分析订单明细执行批量删除操作。

*  **替代模拟**

如果参与本次齐套分析的订单备料中存在替代备料，同时客户场景中希望依据目前供应情况重新分配替代备料的需求数量，则用户可以通过如下方式实现。

*      *  在齐套分析的订单明细页面录入本次参与齐套分析的订单；
   *  全选订单后，点击“替代模拟”，系统将选中的订单以及订单顺序，批量带入替代模拟画面；
   *  替代模拟具体操作详见备料替代模拟功能；
   *  用户执行替代模拟完毕，并将模拟结果更新订单备料后，返回齐套分析功能节点进行齐套分析操作；

# 操作说明

*  **齐套分析**

|生产线日计划.单据编号|如果齐套分析是按照生产线日计划进行的，显示选择的生产线日计划的编码|

|料品版本.料品版本|显示料品的版本|
|生产订单.生产投入数量|显示单据的生产数量|
|分析数量|显示本次分析的数量|
|可开工数量|显示可开工数量|
|本次开工数量|输入本次开工数量|
|已发料套数|显示单据的已发料套数|

|预计成套时间|用于展示满足订单齐套的最后一笔供应的供应日期|
|生产订单.需求分类|显示生产订单的需求分类|
|已执行开工|显示是否已经执行开工|

*  **查询**

弹出查询方案画面。

*  **缺料汇总**

以报表形式进行各种汇总展示，系统预计了一套报表方案，用户可以自行定义。

*  **缺料明细**

可以使用“缺料料品”、“不缺料料品”、“全部料品”三种方式展示订单备料的齐套情况。

*  **匹配明细**

用于展示订单备料的匹配供应数据情况。

*  **回到条件**

返回齐套分析条件主画面 保留重新选择查询结果。

*  **开工**

对选中的单据进行开工处理。

*  **按分析结果领料**

执行按分析的结果领料，弹出生成的生产领料单列表，可追踪查询领料单的明细。

*  **批量领料**

弹出批量发料条件画面，在领料列表画面选择需要创建领料单的备料。

*  **领料分单条件**

弹出分单条件画面,设置创建领料单的分单条件,可以按照单据料品等条件进行分单。

*  **结果全选**

如果本次齐套分析单据超过5000条时，通过此按钮进行齐套分析结果的全选操作。

*  **齐套确认**

用于记录本次齐套分析备料的齐套数量。即将本次齐套分析的齐套数量回写到生产订单备料的累计齐套数量字段中。

*  **释放**

如果本次齐套分析的单据为计划订单，可以按齐套数量释放计划订单。

*  **批量输出**

批量输出本次齐套分析结果。

*  **批量打印**

批量打印本次齐套分析结果。

*  **在应用服务器断和数据服务器端配置MS DTC并启动该服务**

**第一步:首先确认一下启用DTC服务 接下来对DTC进行设置：**

1. 单击"开始"，指向"程序"，指向"管理工具"，然后单击"组件服务"。

2. 在组件服务向导中，展开"组件服务"，然后双击"计算机"。

3. 右键单击"我的电脑"，然后单击"属性"。

4. 单击"MSDTC"选项卡，然后单击"安全配置"。

5. 在"安全配置"对话框中，单击以选中"网络 DTC 访问(D)"与"启用XA事务(X)"复选框。

6. 在"客户端和管理"对话框下，单击以选中"允许远程客户端(L)"和"允许远程管理(A)"。

7. 在"事务管理器通信"对话框下，单击以选中"允许入战(I)"、"允许出站(W)"、"不要求进行验证(T)"和"启用事务Internet协议(TIP)事务(P)"。

8. 确保"DTC 登录帐户"设置为"NT Authority\NetworkService"。

9. 单击"确定",确保成功退出。

**第二步:配置DTC服务权限**

1. 单击"开始"，指向"程序"，指向"管理工具"，然后单击"服务"。

2. 在服务向导中,找到服务"Distributed Transaction Coordinator"并双击打开。

3. 在"登陆"选项卡下,确保"此帐户"设置为"NT Authority\NetworkService"，硬件配置文件"Profile 1"的服务设置为"已启用"。

4. 单击"确定",确保成功退出。

**第三步：配置防火墙**

如果没有启用防火墙，可省略此步骤；

配置防火墙是为了确保MS DTC服务不受防火墙的阻拦,确保服务的正常使用。

1. 单击"开始"，指向"设置"，指向"控制面板"，然后双击"Windows 防火墙"。

2. 在"常规"选项卡下，在启用防火墙的前提下，确保没有勾选"不允许例外"选项。

3. 在"例外"选项卡下，在"程序和服务"对话框中，把"msdtc.exe"选择出来并勾选。

备注：msdtc.exe的默认路径：C:\WINDOWS\system32\msdtc.exe

**第四步： 重新启动服务器，让这些更改生效**

重新启动服务器后请检查注册表中 HKEY_LOCAL_MACHINE\Software\Microsoft\MSDTC 下面两个键的键值： AllowonlySecureRpcCalls=0 TurnoffRpcSecurity=1 如果和上面键值不一致，请更改成上面值。
