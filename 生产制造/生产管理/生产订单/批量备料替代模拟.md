
# 功能描述

## 功能概述

此功能原型客户为山西大运汽车,客户场景如下：

在生产过程中，由于一些特殊原因，技术部门提出设计变更修改原BOM子件A料为B料，并将PDM的变更结果传递到ERP中，但是物资部此时已经按子件A做备料创建大量生产订单，由于A料不再采购，物资部要求生产部门要消耗掉所有A料后再采购B料。因此，需要批量调整已经创建的订单的A料需求数量，同时考虑的订单间的占用情况。

## 功能说明

*  支持只针对替代相关物料进行备料重算,而不是整个订单备料
*  支持同时计算和调整生产订单和日计划订单替代备料
*  库存供应取值支持库存可用量和可用量两种算法
*  支持按指定存储地点范围获取替代相关物料库存供应
*  支持替换、替代、成组替代多种备料替代关系
*  支持提供备料调整建议，并支持批量备料更新功能

# 业务规则

*  提前定义物料、BOM、以及BOM子项替代关系

# 按钮说明

<查询>：用于设置参与本次替代模拟的订单和替代物料的过滤条件方案。

<执行>：在备料页签再次选择参与模拟的订单和备料后，选择执行，系统自动进行替代模拟计算。

<更新备料>：系统运算完毕，提供备料调整建议，用户可在此基础上对备料建议数量进行手工调整，调整完毕，按当前显示的备料调整建议更新对应的订单备料信息。
