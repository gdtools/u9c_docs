
# 功能描述

## 功能概述

本结点用于将系统上线时的生产情况反映到系统之中，以便后续业务继续在系统中处理，是系统上线所需的功能节点之一。

## 功能说明

*  按实际生产数量将生产订单录入系统
*  手工选择生产所用的BOM、工艺等，系统不会自动匹配
*  录入订单的计划开完工日期，系统不会自动排程
*  录入生产订单的执行情况，如：完工数量等
*  录入备料的执行情况
*  录入资源的消耗情况
*  录入现有的产出情况
*  启用车间的情况下，录入各工序的各状态的数量情况

# 业务规则

*  提前定义组织、部门、单据类型、料品、BOM、工艺等基础档案；
*  上述各数量情况是指上线时点的情况，上线时需要仔细清点生产现场的情况，以提高期初数据录入的准确性；
*  如果启用成本会计的情况下，期初成本录入功能是与本功能节点相配合的业务功能，用于录入期初订单的成本核算信息。

# 栏目说明

*  **期初生产订单主画面**

除下表所列栏目外，本画面其他栏目的使用方法与【生产订单】主画面相同。

|**栏目名称**|**说明**|
|---|---|
|展开阶数|期初生产订单不支持多层展开，因此，本栏目始终为0，如果有多层展开的期初生产订单请在本节点分别录入每一个期初生产订单，如果系统上线时部分订单尚未开工，则无需在此节点录入，直接在生产订单节点录入即可|
|BOM|手工指定本订单生产所使用的BOM|
|工艺|手工指定本订单生产所使用的工艺|
|计划开工时间|手工输入本订单的计划开工时间，系统不会为期初生产订单排程|
|计划完工时间|手工输入本订单的计划完工时间，系统不会为期初生产订单排程|
|业务开始时间|手工输入当前订单的实际的业务开始时间，此时间应该在系统启用日期之前，如果是系统启用后才实际开工的订单，请不要使用本节点所提供的功能，直接在生产订单节点录入即可|
|来源|期初生产订单不支持有来源的情况，因此，不能输入来源单据|

*  **期初生产订单备料**

期初生产订单的备料表与正常生产订单的备料表类似，区别在于期初生产订单可录入各个备料的已发料数量，以便后续控制领料数量所用。

注意：此数量不用于计算成本，期初已发生的领料成本由期初成本录入功能提供。

*  **期初生产订单产出**

期初生产订单的产出表与正常生产订单的产出表类似，区别在于期初生产订单可录入实际完工数量、实际返工数量、实际报废数量和实际入库数量。

注意：此数量用于后续的产出控制，但不会与订单的完工数据同步，二者需要分别录入并保证其一致性。

*  **期初生产订单工序**

期初生产订单的工序表与正常生产订单的工序表相同，工序的执行信息需要在生产订单执行数据维护画面录入，不在此画面录入。

*  **期初生产订单资源**

期初生产订单的资源表与正常生产订单的资源表类似，区别在于期初生产订单可录入资源的计划总用量和实际总用量。

注意：此数量不用于计算成本，期初已发生的资源耗用成本由期初成本录入功能提供。

# 操作说明

*  **创建期初生产订单**

创建一张期初生产订单。

操作步骤：点击生产管理－>生产订单－>期初生产订单－>新增按钮，进入新增期初订单功能。具体步骤如下所示：

*      *  第1步：点击生产管理－>生产订单－>期初生产订单，进入期初生产订单维护主界面；
   *  第2步：点击新增按钮进入生产订单头－基本页签（点击生产管理－>生产订单－>期初生产订单直接进入新增状态，如果当前屏幕为其它状态单击新增按钮可以进入新增状态）；
   *  第3步：输入生产订单头-基本信息；
   *  第4步：输入完成单击保存按钮；
   *  第5步：保存成功后点击快速维护按钮，弹出【生产订单执行数据维护】画面；
   *  第6步：在生产订单执行数据维护画面中录入期初生产订单的已执行信息；
   *  第7步：点击确定按钮返回期初生产订单维护主画面，点击保存完成期初生产订单的创建与维护；
   *  第8步：如果需要手工增加备料、资源、工序请点击相应的按钮进入维护画面增加并保存该期初生产订单，之后再进入生产订单执行数据维护画面维护相应的执行信息。
*  **后续处理**

期初成本：导航到【期初成本】功能节点。
