
# 功能描述

## 功能概述

本结点提供生产订单批量合并的相关操作。

## 功能说明

无

# 业务规则

*  仅处理生产订单数量批量合并，不处理工艺的批量合并

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**生产订单批量合并-单头**|
|目的单号|选择需要合并至的生产订单|
|**生产订单批量合并-单行**|
|来源单据|选择需要合并至目的订单的生产订单；合并后目的生产订单记录合并分割关系，数量为目的单号数量+Σ来源单据数量|

# 按钮说明

无

# 操作说明

*  **批量合并**

将多个生产订单合并至一个生产订单安排生产。

操作步骤：点击生产管理－>生产订单－>生产订单批量合并－>批量合并按钮，进入拆分车间任务单功能。具体步骤如下所示：

*      *  第1步：点击生产管理－>生产订单－>生产订单批量合并 ，进入批量合并维护主界面，单头选择目的生产订单；
   *  第2步：下列表选择需要合并至目的单据的生产订单；
   *  第3步：点批量合并按钮，则将来源MO合并至目的单据中；
