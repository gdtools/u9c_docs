
# 功能描述

## 功能概述

本节点功能如下：

*  按产品结构查看生产订单情况；
*  对配套生产的生产订单，查看相关生产订单信息。

无

# 业务规则

*  生产订单(必做)

# 栏目说明

*  **查询**

|**栏目名称**|**说明**|
|---|---|
|**查询条件**|
|工厂组织|当前组织为工厂组织时，默认为当前组织，可选择当前组织的下级工厂组织。当前组织为营运组织时，可选择与当前组织存在销售-工厂关系的组织录入。非空|
|营运组织|当前组织为工厂组织时，可选择与当前组织存在销售-工厂关系的组织录入，当前组织的下级工厂组织；当前组织为营运组织时，可选择当前组织的下级营运组织录入；可空|
|配套|表示是否查询配套生产的订单关系。|
|生产订单|可指定某一生产订单进行正查或反查。配套为“是”时，只可选配套生产订单的顶层母单。与销售订单必录且只可录其一|
|销售订单|可指定某一销售订单进行正查。与生产订单必录且只可录其一|
|业务类型|指定义务类型时，关联单据按照业务类型进行过滤|
|单据类型|指定单据类型时，关联单据按照单据类型进行过滤|
|状态|指定状态时，关联单据按照状态进行过滤|
|查询方向|正向：从总装向零件方向查询；反向：从零件向总装方向查询|
|关联单据开工起始日期|指定开工起始日期时，关联单据过滤出开工日期大于等于指定日期的记录|
|关联单据开工截止日期|指定开工截止日期时，关联单据过滤出开工日期小于等于指定日期的记录|
|关联单据完工起始日期|指定完工起始日期时，关联单据过滤出完工日期大于等于指定日期的记录；指定完工截止日期时，关联单据过滤出完工日期小于等于指定日期的记录|
|**查询结果**|
|单头|左树上选中节点的生产订单信息|
|单行|左树上选中节点生产订单的关联订单列表|

*  **生产控制台**

|**栏目名称**|**说明**|
|---|---|
|业务类型|显示生产单据对应的业务类型，在单据类型中定义|
|单据类型名称|显示生产单据对应的单据类型名称，在单据类型功能中定义|
|单据编号|显示生产单据的编号|
|单据状态|显示生产单据的状态|
|料号|显示生产单据的料号|
|料品|显示生产单据的料品|
|料品形态|显示生产单据的料品形态|
|料品版本|显示生产单据的料品版本|
|生产数量|显示生产单据的生产数量|
|MRP数量|显示生产单据的MRP数量|
|计划开工日|显示生产单据的计划开工日|
|计划完工日|显示生产单据的计划完工日|
|挂起|显示生产单据是否被挂起|
|财务关闭|显示生产单据是否已经财务关闭|
|多工艺生产|显示生产单据是否是多工艺生产|
