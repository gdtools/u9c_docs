
# 功能描述

## 功能概述

本节点用于用于修改生产订单的内容。

## 功能说明

*  可以快速创建生产订单变更单
*  可以查看、修改或删除生产订单变更单
*  可以提交、审核或生产订单变更单

# 业务规则

*  生产订单的状态为已核准
*  生产订单单据类型定义生产订单核准后不可改

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**生产订单变更单-基本**|
|单据类型|生产订单变更单的单据类型|
|单号|生产订单变更单的单据编号。可由系统自动生成，也可收入输入；在单据类型中定义|
|变更订单|选择需要进行变更的生产订单|
|日期|生产订单变更的日期|
|调整原因|输入生产订单变更的原因说明|
|更新订单版本|是否更新生产订单的版本|
|状态|显示生产订单变更单的状态|
|**生产订单变更单-单头变更**|
|状态|包括变更前与变更后两种状态|
|.........|分两行分别显示变更前与变更后的内容；显示栏目的多少由变更栏目的多少决定|

# 操作说明

*  **快速创建**

快速创建一张生产订单变更单。

操作前提：存在处于已核准状态的生产订单，同时生产订单单据类型定义生产订单核准后不可改。

操作步骤：点击生产管理－>生产订单－>生产订单变更单，进入生产订单变更单主界面。具体步骤如下所示：

*      *  第1步：点击生产管理－>生产订单－>生产订单变更单，进入生产订单变更单主界面；
   *  第2步：在基本页签中输入单据类型、单号、变更订单等信息；
   *  第3步：点击快速创建按钮，系统弹出生产订单画面；
   *  第4步：在生产订单画面修改完相应内容后，点击确定按钮；
   *  第5步：生产订单变更前和变更后的内容显示在单头变更页签中；
   *  第6步：点击保存按钮，完成生产订单变更单的快速创建。
