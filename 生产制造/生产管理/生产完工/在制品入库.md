
# 功能描述

## 功能概述

生产订单在生产的过程中，由于某种原因需要暂停并且料品需要暂时入库进行管理的活动，则可进行在制品入库。

本节点主要处理[是否是启用新完工模块创建]=True的生产单据的在制品入库。

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**在制品入库－单头**|
|单据类型|选择在制品入库的单据类型|
|单号|在制品入库的单据编码|
|状态|显示在制品入库的单据状态|
|收发类型|可选项有：入库：如果是在制品入库，则为入库；出库：如果是在制品出库，则为出库|
|入库人|在制品入库的入库人|
|入库日期|按单据类型的实际入库时间的参数值控制取值|
|**在制品入库－行**|
|行号|系统自动维护，不可改|
|存储类型|选择入库的存储类型。可选项有：可用、报废|
|生产订单|单据类型.业务类型<>重复生产时显示本栏目；参照生产订单产出表选择；选择开工、未挂起、未终止的生产单据；如存储类型=可用，仅显示生产单据工序表.待转移数量> 0的记录；如存储类型=报废，仅显示生产单据工序表.报废数量> 0的记录|
|生产线日计划|单据类型.业务类型=重复生产时显示本栏目；参照重复计划产出表选择；可选择重复计划.已装配上线计划=0；选择开工、未挂起、未终止的生产单据；如存储类型=可用，仅显示生产单据工序表.待转移数量> 0的记录；如存储类型=报废，仅显示生产单据工序表.报废数量> 0的记录|
|工序|选择对应生产单据下对应工序表状态数量满足条件的工序|

# 按钮说明

无

# 操作说明

审核后减少对应生产单据的工序状态的数量；

工序记录生产撤线数量半成品入库数量。
