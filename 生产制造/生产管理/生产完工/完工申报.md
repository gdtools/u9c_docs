
# 功能描述

## 功能概述

本结点提供生产单据是否启用新完工申报流程=True且系统参数.是否无完工申报直接入库=False情况下的完工申报的相关操作。

## 功能说明

*  一次汇报多张生产单据多产出类型的完工情况
*  完工齐套检查
*  挂起及释放已挂起的完工申报单
*  查看完工申报单对应的倒扣领料单
*  维护在制品的批号和序列号
*  维护完工报告对应的完工产品的序列号
*  建立在制序列号与完工入库序列号之间的关联关系，以利于序列号追踪
*  支持完工送检
*  支持快捷资源申报或工时申报
*  支持审核后自动创建入库单

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**完工申报－头**|
|单据类型|选择完工申报的单据类型|
|单号|完工申报单的单据编码|
|状态|显示完工申报单的单据状态。新建时=开立；审核后=已核准；|
|申报类型|完工申报时，申报类型=申报|
|申报日期|完工申报的日期|
|申报人|完工申报单的申报人，业务员类型=生产管理员|
|申报部门|申报人对应的部门|
|来源单据|如启用车间管理且工序级管理，则记录来源工序转移单号；如如启用车间任务管理且工序级管理，则记录来源工序转移单号|
|**完工申报－基本**|
|行号|系统自动维护，不可改|
|产出类型|可选择：主产品、副产品、联产品|
|生产订单|当单据类型.业务类型=标准生产时显示，可选择：已开工、未挂起、未取消的生产订单|
|重复计划|当单据类型.业务类型=重复生产时显示，可选择：已开工、未挂起、未取消的且非已装配上线计划的重复计划|
|料品|如为主产品及联产品时参照生产单据的产出表选择；如为副产品参照料品档案选择|
|完工时间|默认=单头.申报时间|
|完工工序|当产出类型为联产品；副产品，可选择对应生产单据的工序当为工序返工生产订单，且为主产品产出时，显示该生产订单返工工序，可改为该返工订单的母单的大于或等于返工工序的工序|
|工序状态|当为工序返工生产订单，且为主产品产出时，可改为返工工序的排队、加工、待转移状态|
|检验|当物料档案.完工质检方案不为空时为True|
|生产批号|可选为生产订单批号或工序末序待转移状态批号|
|完工数量|如启用车间，则默认为末序的待转移数量如未启用车间，则默认为累计开工数量-累计完工数量如允许超额产出，则需 <=(生产订单.生产数量+可超额量 – 已完工数量)可超量取优先取物料档案设置，如无则取生产管理参数【生产订单允许超额产出比例】设置如生产单据为重复计划，则超额量计算取【物料生产线关系】设置如为联产品或副产品汇报完工情况，不控制完工数量如需质检，则合格数量，返工数量，报废数量则通过质检系统结果回写|
|合格数量|录入完工合格数量|
|报废数量|录入完工报废数量|
|待返工数量|录入完工待返工数量|
|在检数量|如需完工质检，则在检验后回写此数量|

# 操作说明

*  **发料齐套检查**

对本次完工数量结合备料发料情况，检查备料齐套情况。

操作前提：存在处于开立状态的完工申报单。

操作步骤：

*      *  第1步：点击生产管理－>生产完工－>完工申报，进入生产完工申报单维护主界面；
   *  第2步：点击齐套检查功能按钮；
   *  第3步：系统根据检查结果，确定本次完工申报是否检查通过；
   *  第4步：根据检查情况，勾选后可将齐套差额部分创建领料单；
