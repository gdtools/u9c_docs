
# 功能描述

## 功能概述

本节点提供生产订单中挂起原因的定义。

## 功能说明

*  定义挂起原因
*  定义挂起原因的有效性和有效时间区间
*  定义允许使用该挂起原因的操作员
*  为操作员使用该挂起原因设定有效性和有效时间区间

# 业务规则

无

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**挂起原因定义表头**|
|编码|输入当前挂起原因的编码；注意：编码不能重复|
|名称|当前挂起原因的描述|
|简称|当前挂起原因的简称|
|生效|当前挂起原因是否生效|
|生效日期|当前挂起原因的生效日期|
|失效日期|当前挂起原因的失效日期|
|**挂起原因定义表体**|
|操作员|定义对当前挂起原因有使用权的操作员，只有在此列表中的操作员才有权使用当前挂起原因|
|生效|当前列表行的操作员是否有权使用当前挂起原因|
|生效日期|当前列表行的操作员允许使用当前挂起原因的开始日期|
|失效日期|当前列表行的操作员允许使用当前挂起原因的结束日期|
