
# 功能描述

## 功能概述

本节点提供单据中解除挂起原因的设置。

## 功能说明

*  设置解除挂起原因
*  设置解除挂起原因的有效性和有效时间区间
*  设置允许使用解除原因的操作员
*  为操作员使用挂起原因设定有效性和有效时间区间
*  定义解除原因与挂起原因之间的关联关系

# 业务规则

无

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**解除原因定义表头**|
|编码|输入当前解除原因的编码；注意：编码不能重复|
|名称|当前解除原因的描述|
|简称|当前解除原因的简称|
|生效|当前解除原因是否生效|
|生效日期|当前解除原因的生效日期|
|失效日期|当前解除原因的失效日期|
|**解除原因定义表体**|
|操作员|定义对当前解除原因有使用权的操作员，只有在此列表中的操作员才有权使用当前解除原因|
|生效|当前列表行的操作员是否有权使用当前解除原因|
|生效日期|当前列表行的操作员允许使用当前解除原因的开始日期|
|失效日期|当前列表行的操作员允许使用当前解除原因的结束日期|
|**原因匹配**|
|挂起原因|选择当前解除原因所对应的挂起原因|
|生效|当前解除原因对应的挂起原因的有效性|
|生效日期|当前解除原因对应的挂起原因的生效日期|
|失效日期|当前解除原因对应的挂起原因的失效日期|
