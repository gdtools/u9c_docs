
# 功能描述

## 功能概述

本功能可以用于查询生产订单完工日与销售订单交货期之间的差异，来判断生产订单是否能满足客户要求的交货期限。

## 功能说明

无

# 业务规则

由销售订单拉单生成生产订单。

无

# 操作说明

*  **销售订单和生产订单交期差异表**

操作步骤：点击生产管理－>报表－>销售订单和生产订单交期差异表，进入报表主界面。具体步骤如下所示：

*      *  第1步：点击生产管理－>报表－>销售订单和生产订单交期差异表，系统弹出查询方案界面；
   *  第2步：选择已经定义好的查询方案或者重新定义查询方案。如果存在已经定义好的查询方案（包括查询条件、显示栏目、行分组、排序），选择一个查询方案；如果没有已经定义好的查询方案，分别定义查询条件、显示栏目、行分组、排序，定义完毕保存方案。点击确定按钮，系统显示符合条件的销售订单和生产订单交期信息，显示的栏目为查询方案中设定的栏目，可以在方案中增加或者删除，显示的排序方式为查询顺序中设置好的排序方式。
