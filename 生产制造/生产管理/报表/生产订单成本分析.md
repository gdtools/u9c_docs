
# 功能描述

## 功能概述

本功能用来进行生产订单期间计入、转出成本分析，包括总构成分析、明细要素构成成本分析，同时产生分析报表。

## 功能说明

无

# 业务规则

*  已经进行了所对应分析期间的生产订单成本计算

# 栏目说明

*  **生产订单成本分析－订单计入成本总构成分析查询条件**

|**栏目名称**|**说明**|
|---|---|
|成本分析类型|成本分析的类型；选择录入；选择“订单计入成本总构成分析”时，将使用下列查询项|
|成本域|成本分析的目标成本域；参照录入，不可为空|
|成本类型|成本分析的目标成本类型；参照录入，不可为空；参照成本域下的所有成本类型|

|生产线日计划|成本分析的目标生产线日计划；参照录入，同生产线日计划互斥；只能选择单一生产线日计划|

# 操作说明

*  **一般操作参见公共操作说明**
*  **生产订单成本分析**

通过生产订单成本分析功能，可以进行目标对象的成本总构成分析、明细构成分析，成本趋势分析和成本比较分析，并可以生成成本分析报表，打印输出。

操作步骤：点击生产订单－>生产订单成本分析，进入成本分析功能界面。具体步骤如下所示：

*      *  第1步：录入查询分析条件，在此可以选择进行何种成本分析，以及成本分析涉及到的各条件项目；
   *  第2步：确定后显示成本分析结果报表，用户可以输出或打印结果报表。
