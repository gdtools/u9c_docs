
# 功能描述

## 功能概述

快速领料将生产订单、日计划订单的相关备料集中显示在同一个列表页面中，方便生产生管人员查询备料相关维度信息和工序信息，如备料对应的工作中心，工序发料地点等，同时可以查询备料的库存可用量和可用量信息。生管人员可以根据相关属性信息过滤显示订单备料，并批量执行后续备料发料功能。

## 功能说明

*  支持订单备料非成套领料
*  支持同时管理生产订单、期初生产订单、日计划订单的订单备料
*  支持按订单工序相关属性推式发料
*  支持查询订单备料的可用量和库存可用量

# 业务规则

*  先创建物料、物料清单、工艺路线
*  先创建生产订单或日计划订单

# 按钮说明

<可用量>：用于查询并显示当前页面显示的订单备料的可用量信息。

<库存可用量>：用于查询并显示当前页面显示的订单备料的库存可用量信息。

<非成套领料>：将用户选择的备料批量带人领料明细画面，用户可以执行供需“自动分配”功能进行后续发料，具体操作同生产领料单的批量发料功能。

# 操作说明

*  快速领料功能操作

操作步骤：点击生产管理－>生产领料－>快速领料按钮，进入快速领料功能页面。具体步骤如下所示：

*      *  第1步：设置查询方案中的条件、栏目、排序以及 生单条件等功能页面，执行查询；
   *  第2步：可以对订单备料进行二次查询；
   *  第3步：查询备料的可用量和库存可用量信息；
   *  第4步：选择订单备料执行费成套领料；
