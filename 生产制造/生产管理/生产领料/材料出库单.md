
# 功能描述

## 功能概述

本结点材料出库的相关操作。

## 功能说明

*  支持【是否启用领料申请流程】=True且【是否无领料申请材料出库】=True的生产单据的直接材料出库
*  可依据领料申请的明细行进行材料出库
*  可依据领料申请的明细行进行材料出库
*  支持超额材料出库
*  支持跨组织材料出库
*  支持倒冲发料
*  支持指定单价材料出库

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**材料出库单-单头**|
|单据类型|选择材料出库单单据类型，区分标准生产、重复生产、报废生产、返工生产等|
|确认日期|按单据类型指定确认日期方式取值|
|来源单据|领料申请审核自动创建材料出库单时，记录来源单据线索|
|倒冲|倒冲领料时，系统自动赋值|
|假退假领|假退假领时，系统自动赋值|
|超额|如来源为领料申请，领料申请值，否则取单据类型【超额领料】，不可改|
|**材料出库单-单行**|
|来源类型|可选来源类型：生产单据备料行；领料申请明细行；领料申请汇总行；空值。如为工序外协件发料仅可选择领料申请明细行及空值|
|来源单号|依据来源类型不同显示对应满足材料出库的来源行信息|
|料号|当来源类型=Null时，可直接指定料品进行材料出库|
|生产订单工序|当为工序外协件发料时显示|
|应发数量|如来源为领料申请汇总行，则应发数量 = 领料申请单汇总行(申请数量-累计材料出库量+累计材料退库量)；如来源为领料申请明细行，则应发数量 = 领料申请单明细行(申请数量-累计材料出库量+累计材料退库量)；如来源为MO备料行，则应发数量 = MO备料行(实际需求量-已领数量)；如来源为工序转移单，则应发数量 =转移数量*对应到工序MO工序的MO备料.每装配件用量|
|可超数量|如MO备料.超额类型=比例，则可超数量=实际需求量*比例；如MO备料.超额类型=数量，则可超数量=超额数量；如MO备料.超额类型=不控制，则可超数量=Null；如MO备料.超额领料=false，则可超数量=0；如材料出库单.超额领料=true，则可超数量=null|
|材料出库量|用户录入本次材料出库数量|
|供应组织|如备料.特定组织=T，则为备料【供应组织】且不可改；特定组织=F，则可改|
|供应地点|如备料.特定地点=T，则为备料【供应地点】且不可改；特定地点=F，则可改|
|批号|如为批号管理的料，且存储地点.批号管理=T，则可指定领料批号，不可空|
|项目|可指定材料出库项目号，遵循生产项目匹配规则|
|番号|记录备料的发料番号|
|厂牌|指定领料厂牌，不可空|
|等级|指定领料等级，不可空|
|成分|指定领料成分，不可空|

# 操作说明

*  **批量材料出库**

同批量拉单操作方式。

可在批量拉单画面选择来源为生产单据备料、领料申请明细行、领料申请汇总行生成材料出库单。
