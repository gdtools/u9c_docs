
# 功能描述

## 功能概述

提供对生产线料品计划的管理。

## 功能说明

*  按生产线显示每日各料品的计划生产数量与实际完成量；
*  对开立态的生产线料品计划可调整其计划生产数量；
*  可查看生产线料品日计划详情；

# 业务规则

*  提前定义组织、部门、料品、生产线、料品生产线关系、BOM、工艺等基础档案

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**单头**|
|生产线|选择当前组织的生产线|
|料品|选择所选生产线下的料品；可空，表示本生产线下的所有料品|
|开始日期|输入生产的开始日期|
|结束日期|输入生产的结束日期|
|**单体**|
|二维表|以二维表形式展现生产线日计划排定的结果，对当日只存在一条生产线料品日计划的情况，可直接维护计划数量，对当日存在多条生产线日计划的情况，双击计划量打开生产线料品日计划进行维护|

# 操作说明

*  **生成计划**

按日期列示每日计划量与完成量。
