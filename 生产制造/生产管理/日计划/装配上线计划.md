
# 功能描述

## 功能概述

装配上线计划主要描述一个生产单位的产品在生产线上的投料次序。

## 功能说明

无

# 业务规则

*  装配上线计划生成后，如果启用看板功能，系统自动创建专用件的看板卡；
*  在装配上线计划发生任何变更：顺序变更、插入、删除、撤线时，需要同步更新看板卡；
*  先进行生产线日计划、生产线日计划混流

# 操作说明

*  **开工上线**

对等待上线的装配上线计划，开工上线后，记录其第一个操作点，关改状态为“线上”。

操作步骤：选中要进行开工上线的装配上线计划，点击开工上线按钮，则更新操作点及状态。

*  **正向更新**

对已在线上的装配上线计划，正向移动到下一操作点。

操作步骤：选中要进行正向更新的装配上线计划，点击正向更新按钮，则更新操作点。

*  **逆向更新**

对已在线上的装配上线计划，逆向移动指定的前操作点。

操作步骤：

选中要进行逆向更新的装配上线计划，点击逆向更新按钮，在弹出窗口中指定操作点编码，确定后更新操作点。

*  **撤线**

对已在线上的装配上线计划进行撤线。

操作步骤：选中要进行撤线的装配上线计划，点击撤线按钮，在弹出窗口中录入撤线原因，确认后装配上线计划的状态变更为撤线。

*  **复线**

对已撤线的装配上线计划进行复线。

操作步骤：选中要进行复线的装配上线计划，点击复线按钮，在弹出窗口中录入复线日期，并指定顺序号，确定后更新顺序号，状态为“线上”。

*  **领料确认**

在装配上线计划更新操作点时，根据日计划备料，将当前操作点与上一扫描点之间非倒冲的备料追加至列表中。对批号序列号管理的料品，可在列表中维护批号序列号。可多选记录确认生成领料单，也可走调度方案定时生成领料单。

操作步骤：点击领料确认按钮，则弹出领料确认窗口，可对批号／序列号管理的料品维护批号／序列号，可设置调度方案，可多选记录，确定后直接生成领料单。
