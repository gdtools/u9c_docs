
# 功能描述

## 功能概述

本功能用于配置适当的条件，以便生产订单可以在符合条件时自动置于关闭状态，生管人员只需要关注未关闭的生产订单即可，可减轻生管人员甄别生产任务进展的工作量，提高工作效率。

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|产出数量达到要求|生产订单的实际合格入库数量大于等于生产订单的MRP数量|
|预计的联产品有入库数量|生产订单预计产出中如果有联产品，则所有的联产品产出均有完工申报入库数量|
|预计的副产品有入库数量|生产订单预计产出中如果有副产品，则所有的副产品产出均有完工申报入库数量|
|备料存在已发放数量|生产订单备料表中需要发料的备料都有已发放数量|
|资源申报完毕|所有资源都有过资源申报记录|
|所有子单均已关闭|强制条件，如果当前订单有子生产订单，需要所有子生产订单的状态均为关闭|
|相关业务单据已关闭|强制条件，与当前生产订单相关的业务单据（如：领料单、完工报告、资源申报记录、工序转移单等）均为完成状态|
|自定义条件|上述固定预设条件无法满足业务需求时，可以自定义条件|

# 操作说明

*  **执行**

根据上述勾选的条件，从当前未关闭的生产订单中选择符合条件的，执行生产订单关闭动作。

如果生产订单单据类型勾选了“单据自动关闭”，则在成品完工申报入库后，系统会自动按此节点中勾选的条件，判断是否已满足，对于满足条件的即时执行关闭动作。

*  **调度**

配置调度方案执行批量关闭动作，可以定时检索生产订单，发现有符合关闭条件的即执行关闭动作。
