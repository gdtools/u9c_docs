
# 功能描述

销售订单和销售预测的料品根据BOM结构展开子件的相依需求的数量和需求日期。

# 业务规则

*  执行了MPS/MRP计算。

# 栏目说明

结果栏目

|栏目|说明|
|---|---|
|单据编码|表示需求的单据编码|
|客户名称|表示需求的客户名称|
|层码|表示需求料品的层码|
|料品|表示需求的料品|
|品名|表示需求的品名|
|数量|表示需求的数量|
|单位名称|表示需求的数量单位名称|
|需求日期|表示需求的需求日期|
|项目名称|表示需求的项目名称|
|供应组织名称|表示需求的供应组织名称|
|货主组织名称|表示需求的货主组织名称|


# 操作说明

*  通过菜单生产制造－>需求计划－>报表－>毛需求报表进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件。
   *  第2步：点击确定。
