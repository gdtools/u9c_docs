
# 功能描述

可按料、时间段查看MPS/MRP计算后的总体供需平衡状况，辅助计划员进行人工调整。此报表是基于MPS/MRP计算时的快照数据来查询的。而单阶供需报表是基于实时供需数据来查询的。

# 业务规则

*  必须运行了MPS/MRP计算。
*  计划名称、计划版本：必填项，表示按此版本的快照数据进行查询。 
*  时格：必填项。系统按时格定义的纬度来汇总供需数据，如：按周、旬、月汇总。
*  组织：可查看特定组织的供需数据。 
*  料号：可查看特定物料的供需数据。 
*  项目、番号、需求分类：可查看特定项目、番号、需求分类的供需数据。

# 栏目说明

查询结果栏目

|栏目|说明|
|---|---|
|组织|表示参与MPS/MRP计算的工厂组织。|
|料号、品名|表示工厂组织的物料。点击物料可导航到“[供需报表（明细）报表](http://wangwq/U9C/help/zh-CN/Content/MFG/MRP/Function/mfg.mrp.report.dsinfodetailreport.htm)”中，查看该物料的供需明细记录。|
|库存单位|指物料的库存主单位。|
|安全库存量（-）|指物料的安全库存，如果为动态安全库存则为零。|
|现存量（+）|指物料在当前时刻的库存可用量。|
|预测量（-）|指在某时段内的汇总预测量。预测指销售预测、预测订单。|
|订单量（-）|指在某时段内的汇总订单量。订单指销售订单、合同、报价单。|
|在制量（+）|指在某时段内的汇总在制量。在制量指MO、日计划。|
|在途量（+）|指在某时段内的汇总在途量。在途量指请购单、采购单、采购合同。|
|计划备料量（-）|指在某时段内计划订单的汇总备料量。|
|实际备料量（-）|指在某时段内在制订单的汇总备料量。实际备料量指MO、日计划的备料。|
|计划投入量（+）|指在某时段内产生的计划订单量。|
|结存量|指在某时段的期末可用余量。|


# 操作说明

*  通过菜单生产制造－>需求计划－>报表－>供需报表（汇总）进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件。
   *  第2步：点击确定。
