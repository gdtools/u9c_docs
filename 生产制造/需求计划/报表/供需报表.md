
# 功能描述

按照料品纬度查询供需状况,包括其他管理纬度的供应数量,由用户决定是否需要做形态转换.

# 业务规则

*  执行了MPS/MRP计算。
*  计划名称、计划版本：必填项，表示按此版本的快照数据进行查询。

# 栏目说明

结果栏目

|栏目|说明|
|---|---|
|安全库存量|指物料的安全库存，如果为动态安全库存则为零。|
|在库数量|指物料在当前时刻的库存可用量。|
|需求数量|指在某时段内的汇总订单量。订单指销售订单、合同、报价单。|
|在制数量|指在某时段内的汇总在制量。在制量指MO、日计划。|
|在途数量|指在某时段内的汇总在途量。在途量指请购单、采购单、采购合同。|
|计划数量|指在某时段内产生的计划订单量。|
|结存量|指在某时段的期末可用余量。|


# 操作说明

*  通过菜单生产制造－>需求计划－>报表－>供需报表进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件。
   *  第2步：点击确定。
