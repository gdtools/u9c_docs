
# 功能描述

对MRP计算产生的资源需求状况进行查询。

# 业务规则

*  执行了MPS/MRP计算。
*  计划名称、计划版本：必填项，表示按此版本的快照数据进行查询。

# 栏目说明

结果栏目

|栏目|说明|
|---|---|
|执行组织|显示执行组织|
|工厂组织|显示工厂组织|
|单号|单号|
|资源名称|资源名称|
|需求数量|资源的需求数量|
|用量单位名称|资源的用量单位名称|
|开始使用时间|资源的开始使用时间|


# 操作说明

*  通过菜单生产制造－>需求计划－>报表－>资源需求报表进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件。
   *  第2步：点击确定。
