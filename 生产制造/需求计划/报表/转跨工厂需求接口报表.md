
# 功能描述

查询指定工厂组织的需求接口表中的信息。

# 业务规则

*  执行了MPS/MRP计算。
*  计划名称、计划版本：必填项，表示按此版本的快照数据进行查询。

# 栏目说明

结果栏目

|栏目|说明|
|---|---|
|组织|工厂组织|
|需求分类|指具体业务单据上的需求分类信息。|
|开始日期|需求的开始日期|
|结束日期|需求的结束日期|
|货主组织|指具体业务单据上的货主组织信息|
|数量|指单据的需求数量。|
|厂牌|指需求单据的厂牌信息。|
|项目|指需求单据的项目信息。|
|任务|指需求单据的任务信息。 |
|番号|指需求单据的番号信息。|
|等级|指需求单据的等级信息。|
|成分|指需求单据的成分信息。|

# 操作说明

*  通过菜单生产制造－>需求计划－>报表－>转跨工厂需求接口报表进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件。
   *  第2步：点击确定。
