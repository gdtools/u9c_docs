
# 功能描述

按料号查看与该料号有关的所有下阶子件的供需状况。

# 业务规则

*  执行了MPS/MRP计算。
*  料品：查询该料品及组成该料品的所有下阶子件的供需状况。
*  向下展开：为true，则同时查看所有下阶子件的供需状况，否则只查询物料自身的供需状况。

# 栏目说明

结果栏目

|栏目|说明|
|---|---|
|物料编码|指物料及其所有下阶子件物料的编码。|
|物料名称|指物料及其所有下阶子件物料的名称。|
|规格|指物料及其所有下阶子件物料的规格。|
|需求日期|指物料及其所有下阶子件物料的独立/相依需求的需求日期。|
|单位|指物料的库存主单位。|
|调整单据|调整创建成本调整单更新记录创建的成本调整单信息|
|毛需求量|指该需求日期下所有独立、相依需求的汇总和。|
|现存量|指物料当前的现存量。|
|在制量|指能满足该需求日期下的所有需求的MO/重复计划的供应汇总和。|
|采购在途|指能满足该需求日期下的所有需求的采购汇总和。|
|MPS|指能满足该需求日期下的所有需求的MPS供应汇总和。|
|调拨量|指能满足该需求日期下的所有需求的调拨供应汇总和。|
|净需求量|毛需求量－现存量－在制量－采购在途－MPS－调拨量。|
|计划订单量|指为满足净需求而需要生产/采购的供应量。|


# 操作说明

*  通过菜单生产制造－>需求计划－>报表－>需求计划报表（按料号）进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件。
   *  第2步：点击确定。
