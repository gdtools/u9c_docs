
# 功能描述

查看指定组织、物料的供需明细状况，并计算每日的结存量及ATP量。此报表是基于MPS/MRP计算时的快照数据来查询的。可通过“供需报表（汇总）”功能进入，也可单独点击相应菜单进入。

# 业务规则

*  必须运行了MPS/MRP计算。
*  计划名称、计划版本：必填项，表示按此版本的快照数据进行查询。 
*  工厂组织：必填项，表示查看哪个工厂组织的供需记录。 
*  料品：必填项，表示查看哪个物料的供需记录。 
*  项目、番号、需求分类：可查看特定项目、番号、需求分类的供需数据。

# 栏目说明

结果栏目

|栏目|说明|
|---|---|
|供需日期|表示单据的供/需日期。系统对检索到的所有供需单据按日期进行排序展示。|
|供需类型|表示具体的供需单据，如：SO、PO等。|
|单据号|表示具体的业务单据编码。|
|需求分类|指具体业务单据上的需求分类信息。|
|货主组织|指具体业务单据上的货主组织信息|
|数量|指业务单据的净供应/需求数量。对于需求单据按负数显示。|
|结存量|指截止到供应/需求日期时的供应余量。结存量=供应/需求日期之前累计的供应量（含供应/需求日期） –供应/需求日期之前累计的需求量（含供应/需求日期）。|
|ATP|系统自动计算的ATP量。|
|厂牌|指供需单据的厂牌信息。|
|项目|指供需单据的项目信息。|
|任务|指供需单据的任务信息。 |
|番号|指供需单据的番号信息。|
|等级|指供需单据的等级信息。|
|成分|指供需单据的成分信息。|

# 操作说明

*  通过菜单生产制造－>需求计划－>报表－>供需报表（明细）进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件。
   *  第2步：点击确定。
