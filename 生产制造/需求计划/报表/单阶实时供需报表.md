
# 功能描述

按料实时查询供需平衡结果，计算每日的供应余量及ATP量。此功能可协助企业监控料品的需求和供应，为企业未来的料品计划提供有用的信息。

# 业务规则

*  启用需求计划系统（必做）
*  料号：必填项，表示要进行供需平衡的物料，目前只支持一次查询一个物料。
*  料品版本：如果录入，表示只针对该版本的供需进行平衡。
*  查找日期至：供需平衡时，系统只处理当前日期到查找日期至范围内的供需单据。 默认为系统当前日期。
*  需求类型：可以选择不同的需求来源进行供需平衡，可选择多个。
*  供应类型：可以选择不同的供应来源进行供需平衡，可选择多个。

# 栏目说明

报表结果

|栏目|说明|
|---|---|
|日期|表示单据的供/需日期。系统对检索到的所有供需单据按日期进行排序展示。|
|类型|表示具体的供需单据，如：SO、PO等。|
|单号|表示具体的业务单据编码。|
|单据部门|指单据上的业务部门，如MO上的生产部门。|
|已调整|调整创建成本调整单更新已调整标识|
|调整单据|调整创建成本调整单更新记录创建的成本调整单信息|
|需求数量|表示需求单据上的净需求数量。对于供应单据为零。|
|供应数量|表示供应单据上的净供应数量。对于需求单据为零。|
|客户|如果为销售单据，表示单据上的客户信息。|
|供应商|如果为采购单据，表示单据上的供应商信息。|
|父项|如果为相依需求，如：MO备料等，表示生产的母项料品。 |
|结存|指截止到供应/需求日期时的供应余量。结存量=供应/需求日期之前累计的供应量（含供应/需求日期） –供应/需求日期之前累计的需求量（含供应/需求日期）。|
|ATP|系统自动计算的ATP量。|


# 操作说明

*  通过菜单生产制造－>需求计划－>报表－>单阶实时供需报表进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件。
   *  第2步：点击确定。
