
# 功能描述

多阶缺料模拟主要用于对局部需求进行计划模拟，MPS/MRP是从全局角度对需求进行规划。通过这个功能可以：

设定模拟参数，如考虑哪些单据作为供应等。

设定哪些需求参与模拟，如：SO、预测。也可手工录入需求数据。

可查看模拟过程中出现的错误及相关信息。

可查看缺料信息，并可将缺料结果释放为PO、MO来驱动生产或采购。

# 业务规则

*  定义物料（必做）
*  定义SO（可选）
*  定义销售预测（可选）
*  定义组织间平行关系（可选）

# 按钮说明

*  需求维护：可手工录入或根据SO、预测自动产生需求数据。在模拟之前必须要定义相应的需求数据。
 
   *  操作步骤
   
      *  点击【操作-需求维护】按钮。弹出需求维护画面：

行页签

|栏目|说明|
|---|---|
|需求组织|默认为当前组织，可以选择其它组织。|
|供应组织|默认为当前组织，可以选择其它组织。|
|料品||
|版本|如果为特定版本的需求则选择一个版本。|
|交易单位||
|需求数量|根据SO、预测自动生成时，默认为原始需求数量，可改。|
|原始需求数量|如果根据SO、预测自动生成，则记录原始的净需求量。手工增加的需求固定为零不可改。|
|预留量|根据SO、预测自动生成时，对应业务单据上的预留量。|
|已发货量|根据SO、预测自动生成时，对应业务单据上的已发货量。|
|存储地点|根据SO、预测自动生成时，为对应业务单据上的存储地点，可改。|
|需求日期|根据SO、预测自动生成时，为对应业务单据上的交期。手工创建的需求，默认为当前日期，可改。|

*  加载条件：点击该按钮，则根据SO、预测自动创建需求。具体步骤为：
 
   *  点击“操作-加载条件”按钮，则弹出加载条件窗口中，在该窗口中输入具体的加载条件：
   *  需求组织：加载哪个组织的SO或预测。
   *  料品分类：如果选择表示加载属于该料品分类的物料的SO或预测。
   *  料品：如果选择表示加载特定料品的SO或预测。
   *  项目：如果选择表示加载该项目的SO或预测。
   *  起始需求日期、结束需求日期：如果选择表示加载SO或预测的交期在起始..结束日期范围内的需求。
   *  覆盖：如果选择表示系统先删除已经存在的由系统自动生成的需求，再产生新的需求。
   *  来源类型：订单/预测。表示是根据订单还是预测创建需求。
   *  番号：如果选择表示加载该番号的SO或预测。
   *  单号：如果来源类型为订单，可直接输入销售单号作为查询条件。
*  计算：进行模拟计算。
 
   *  操作步骤
   
      *  点击【操作-计算】按钮。计算结束后通过模拟结果来查看缺料信息。
*  释放：将勾选的模拟结果释放为MO或PO。
 
   *  操作步骤
   
      *  点击【操作-释放】按钮。释放结束后显示释放结果，具体参见“计划订单释放”功能中的释放结果。

# 操作说明

*  通过菜单生产制造－>需求计划－>多阶缺料模拟－>多阶缺料模拟运算进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：点击保存。
   *  第3步：维护需求信息。
   *  第4步：点击计算。
