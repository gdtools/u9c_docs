
# 功能描述

粗能力计算对MPS计划进行粗能力运算。

对同一计划，可选择不同的资源清单集进行运算

可进行全组织的运算，也可只算指定组织的粗能力

可选择运算时是否包含计划订单。

# 业务规则

*  参数设定，与粗能力计算相关参数

|参数编码|参数名称|说明|
|---|---|---|
|RCCP001|默认资源清单集|设置进行粗能力计算时的默认资源清单集系统默认值为空，可参照资源清单集进行录入|
|RCCP002|是否包含计划订单|设置进行粗能力计算时，默认是否包含计划订单系统默认值为“是”，即粗能力计算包含计划订单|

*  定义资源清单
*  完成MPS运算

# 栏目说明

粗能力计算

|栏目|说明|
|---|---|
|计划名称.版本|参照计划名称录入；只能参照[计划方法]=“MPS”的计划名称录入。计划名称非空版本：参照计划名称的版本录入，非空|
|计划组织|参照计划名称的计划组织录入；默认为空，为空时表示对所有的计划组织进行运算非空时只运算指定组织的粗能力|
|资源清单集|默认为参数中定义的“默认资源清单集”，可参照资源清单集档案进行修改；非空|
|起始日期|带出计划名称的起始日期，可以修改非空只能大于计划名称的开始日期。|
|截止日期|带出主计划的截止日期，可以修改非空只能小于主计划的截止日期。|
|包含计划订单|定义粗能力计算时是否包含计划订单|


# 按钮说明

*  执行：立即运行粗能力计算。
 
   *  操作步骤
   
      *  点击【执行】按钮，即开始粗能力计算。
*  调度：定时执行粗能力计算．
 
   *  操作步骤
   
      *  点击调度按钮，弹出调度页面，选择【执行一次】或【重复执行】，调度执行粗能力计算。
      *  当选择【执行一次】时，需选择执行的日历；当选【重复执行】时，需选择预定的调度规则。
*  未建资源清单料品：用于显示粗能力计算过程中未建立资源清单的物料信息
 
   *  操作步骤
   
      *  点击【未建资源清单料品】按钮，即未建资源清单料品窗口，可在窗口中查看未建立资源清单的料品明细。
*  未建资源清单料品

|栏目|说明|
|---|---|
|计划组织|显示未建资源清单料品所属的组织|
|料品|显示未建资源清单料品|
|版本|显示未建资源清单料品的版本|
|等级|显示未建资源清单料品的等级|
|成份|显示未建资源清单料品的成份|


# 操作说明

*  通过菜单生产制造－>需求计划－>能力计划－>粗能力计算进入该界面；
*  操作步骤
 
   *  第1步：选择计划版本。
   *  第2步：选择资源清单集和起始日期。
   *  第3步：点击执行。
