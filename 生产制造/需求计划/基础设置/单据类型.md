
# 功能描述

设置生产计划的单据类型。

# 业务规则

*  启用需求计划系统（必做）
*  编码不能重复；

# 栏目说明

单据类型- 基本页签

|栏目|说明|
|---|---|
|"基本"分区||
|编码|单据类型编码|
|名称|单据类型名称,命名时最好能根据对单据类型的设定进行命名,便于使用时进行区分.|
|描述|单据类型描述|

单据类型- 参数页签

|栏目|说明|
|---|---|
|"流程"分区||
|上游单据推式生成|表示当前单据类型为当前上游单据推出默认的单据类型。不同的业务类型会有不同的默认单据类型。|
|确认方式|可以设置当前单据类型是需要简单确认还是需要走审批流程。枚举值：确认作业审批流程|
|核准后是否可改|适用于订单是:采购订单审核后可以手工修改,修改根据执行量进行控制否:采购订单审核后必须弃审才可以修改订单|
|"编号"分区||
|编号方式|单据号的编号方式。枚举值：自动编号手工编号|
|编号原则|当“编号方式”＝自动编号时候，需要选择编号原则。|
|"打印"分区||
|打印模版|默认的打印模板|
|"状态"分区||
|生效||
|生效日期||
|失效日期||

# 操作说明

*  通过菜单生产制造－>需求计划－>基础设置－>单据类型维护进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：维护单据类型相关参数信息。
   *  第3步：点击保存。
