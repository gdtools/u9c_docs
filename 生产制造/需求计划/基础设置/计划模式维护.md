
# 功能描述

系统预置常用的计划模式，如果不满足企业需求，可通过此功能来自定义计划模式。关于“计划模式”的概念，可参考“计划模式应用专题”中的描述。

# 业务规则

*  勾选了参数：启用新计划模块。

# 栏目说明

主界面

|栏目|说明|
|---|---|
|编码|编码小于100的为系统预置的计划模式。新增的模式编码从100开始。|
|需求时栅原则|用来设置该计划模式对时栅的处理方式。关于“时栅”的概念，可参考“时栅应用专题”中的描述。|
|需求时栅天数|
|计划时栅原则|
|计划时栅天数|
|销售订单|用来设置该计划模式对需求的处理方式。即该计划模式考虑哪些需求，不考虑哪些需求。|
|销售预测|
|预测订单|
|生产计划|
|WBS|
|WBS版本|

# 操作说明

*  通过菜单生产制造－>需求计划－>基础设置－>计划模式进入该界面；
*  操作步骤
 
   *  第1步：维护编码等信息。
   *  第2步：维护时栅相关参数信息。
   *  第3步：维护需求处理方式相关信息。
   *  第4步：点击保存。
