
# 功能描述

定义计划运算的组织范围和所包含的计划区域。通过计划范围，可明确计划运算时包括哪些组织的供需。

可以定义多套计划范围，以满足企业的不同业务需求。在计划运算时，可选择一套计划范围进行运算。有关“计划范围”的概念，可参考“计划范围应用专题”中的描述。

# 业务规则

*  勾选了参数：启用新计划模块。
*  定义组织业务关系。
*  定义了计划区域。（可选）

# 栏目说明

主界面

|栏目|说明|
|---|---|
|组织范围页签|
|工厂组织|具体可参考“计划者工作台”功能中关于“计划组织”的描述。|
|组织形态|
|营运组织|
|净需求货主组织方式|
|计划区域页签|
|计划区域|选择计划运算包括的计划区域。|

# 操作说明

*  通过菜单生产制造－>需求计划－>基础设置－>计划范围维护进入该界面；
*  操作步骤
 
   *  第1步：维护计划组织范围信息。
   *  第2步：维护计划区域信息。
   *  第3步：点击保存。
