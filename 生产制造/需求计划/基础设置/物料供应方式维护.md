
# 功能描述

定义物料的供应方式：自制、采购、委外。当一个物料有多种供应方式时，可通过此功能来指定计划运算时物料的供应方式。如果不指定，系统自动根据物料形态属性来决定供应方式。

可以定义多套物料供应方式，以满足企业的不同业务需求。在计划运算时，可选择一套物料供应方式进行运算。

# 业务规则

*  勾选了参数：启用新计划模块。
*  定义物料，且物料至少勾选了“可生产”、“可采购”、“可委外”三个选项中的两个。

# 栏目说明

主界面

|栏目|说明|
|---|---|
|工厂组织|指定要为哪个组织的物料定义供应方式。|
|关系类型|系统支持按物料或物料分类来定义供应方式。|
|料品|如果选择按物料定义供应方式时，需指定一个具体物料。|
|料品分类|如果选择按物料分类定义供应方式时，需指定一个具体的物料分类。|
|生产比例|用来设置物料的供应方式。如：物料A既可以生产，也可以采购。如果希望计划运算时物料A全部自制，则可以将生产比例设为100%，采购比例、委外比例均设为0%。如果希望计划运算时物料A部分自制、部分采购，可以将生产比例、采购比例设置为合适的比例值，但生产比例、采购比例、委外比例之和必须为100%。只有在物料档案中勾选了“可XX”时，才能维护对应的比例值。|
|采购比例|
|委外比例|

# 操作说明

*  通过菜单生产制造－>需求计划－>基础设置－>物料供应方式进入该界面；
*  操作步骤
 
   *  第1步：维护工厂组织等信息。
   *  第2步：维护料品、料品分类、比例相关参数信息。
   *  第3步：点击保存。
