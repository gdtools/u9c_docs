
# 功能描述

资源清单集对资源清单集进行维护。

# 业务规则

*  启用需求计划系统（必做）
*  编码不能重复

# 栏目说明

资源清单集

|栏目|说明|
|---|---|
|编码|录入资源清单集的编码不可为空|
|描述|录入资源清单集的描述|
|生效|定义资源清单集是否生效|
|生效日期|设定资源清单集的生效日期，生效日期要小于等于失效日期|
|失效日期|设定资源清单集的失效日期，失效日期要大于等于生效日期|

# 操作说明

*  通过菜单生产制造－>需求计划－>基础设置－>资源清单集进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：点击保存。
