
# 功能描述

通过计划方案，可以：动态设定物料的供应方式，例如：采购转自制、自制转采购等。在计划名称按存储地点执行时，设定存储地点范围。

# 业务规则

*  定义物料（可选）。
*  定义MRP分类（可选）。
*  定义存储地点（可选）。

# 栏目说明

计划方案头

|栏目|说明|
|---|---|
|计划方案编码|计划方案的编码；  不可为空 。|
|计划方案名称|计划方案的名称； 不可为空|

计划方案体-料品设置

|栏目|说明|
|---|---|
|工厂组织|必填。  |
|关系类型|表示是按料品还是料品分类设定。|
|料品|可选择制造件、采购件。|
|料品分类|可选择MRP分类。|
|形态属性|默认料品主档形态属性 不可维护|
|可生产|不可维护。等于物料档案.可生产。|
|可采购|不可维护。等于物料档案.可采购。|
|可委外|不可维护。等于物料档案.可委外。|
|按比例计划|计划订单按照比例拆分为多张计划订单|
|生产比例|决定生成供应类型为[自制]的计划订单的比例|
|采购比例|决定生成供应类型为[采购]的计划订单的比例|
|委外比例|决定生成供应类型为[委外]的计划订单的比例|

计划方案体-存储地点

|栏目|说明|
|---|---|
|组织|必填。  |
|存储地点|选择组织的存储地点，必填。|

# 操作说明

*  通过菜单生产制造－>需求计划－>基础设置－>计划方案进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：维护料品、存储地点相关参数信息。
   *  第3步：点击保存。
