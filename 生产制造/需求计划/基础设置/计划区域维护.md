
# 功能描述

定义计划运算的供需范围。可以定义多套计划区域，以满足企业的不同业务需求。有关计划区域的概念，可参考“计划区域应用专题”中的描述。

# 业务规则

*  勾选了参数：启用新计划模块。
*  定义了存储地点。（可选）
*  定义了需求分类。（可选）

# 栏目说明

主界面

|栏目|说明|
|---|---|
|仅做为供应存储地点|按存储地点划分计划区域时，如果勾选此选项，表示指定的存储地点只用来过滤供应，不过滤需求。否则指定的存储地点既过滤供应，又过滤需求。|
|排除需求分类|按需求分类划分计划区域时，如果勾选此选项，表示指定的需求分类的供需不会被计划运算所考虑。否则计划运算时只考虑指定的需求分类的供需。|
|存储地点页签|
|组织|如果希望按存储地点划分计划区域时，需指定具体的存储地点。|
|存储地点|
|处理方式|可以选择依委外商和依需求分类。|
|需求分类范围|如果需要按照存储地点的处理方式是依需求分类，则可以维护需求分类，该存储地点只能给这个需求分类使用。|
|需求分类页签|
|需求分类|如果希望按需求分类划分计划区域时，需指定具体的需求分类。在定义计划区域时，存储地点、需求分类至少要选择一个进行指定。|

# 操作说明

*  通过菜单生产制造－>需求计划－>基础设置－>计划区域进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：维护存储地点、需求分类相关信息。
   *  第3步：点击保存。
