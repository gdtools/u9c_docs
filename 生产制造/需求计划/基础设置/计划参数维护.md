
# 功能描述

在启用新计划模块时，用来设置与计划运算有关的参数信息。

# 业务规则

*  勾选了参数：启用新计划模块。

# 栏目说明

由于计划参数维护功能代替了原计划模块中的“MRP系统参数设定”功能、“LRP参数设置”功能、“参数设置”功能及“计划者工作台”功能中的大部分参数。所以此处仅描述有差异部分的内容，相同部分可参考相应功能中的描述。

基本

|栏目|说明|
|---|---|
|默认MPS计划模式|用来设置计划运算时的默认计划模式。最终以计划运算画面中指定的计划模式为准。|
|默认MRP计划模式|
|默认LRP计划模式|
|默认计划范围|用来设置计划运算时的默认计划范围。最终以计划运算画面中指定的计划范围为准。|
|过期供需天数|代替原有的“考虑过期供需”参数。在计划运算时，只有当过期供需的日期在“过期供需天数”到当前日期之间时系统才会考虑。|
|计划订单合单规则|通常情况下，如果设置了时格系统会按照时格合并计划订单。如果未设置时格，系统自动合并同交期计划订单。但有时企业希望即使同交期的计划订单也不合并，这样便于计划人员分析计划结果。通过此选项来控制同交期的计划订单是否合并：同交期合并：默认选项。合并交期相同的计划订单。自制计划订单不合并：仅对自制物料的计划订单不合并。采购计划订单不合并：仅对采购物料的计划订单不合并。不合并：所有物料的计划订单都不合并。|
|是否收集返修订单自身备料|如果通过存储地点单独管理或通过存储类型来标识待返修物料的库存时，不要勾选此选项。因为此时待返修物料的库存往往不会参与计划运算，所以其自身备料也不做为需求。否则，需要勾选此选项，来避免出现供应虚增的问题。|

高级

|栏目|说明|
|---|---|
|启用计划中心模式|在V3版本之前，计划中心模式是按插件方式提供。从V3版本开始做为标准产品的一部分来提供。勾选此选项表示启用计划中心方式来进行计划运算。|
|计划订单生单组织|在启用计划中心模式后，通过此选项来设置计划订单的供应组织。具体可参考“计划中心应用专题”中的描述。|

# 操作说明

*  通过菜单生产制造－>需求计划－>基础设置－>计划参数维护进入该界面；
*  操作步骤
 
   *  第1步：维护相关MRP计划参数等信息。
   *  第2步：维护MRP计划订单释放相关参数信息。
   *  第3步：点击保存。
