
# 功能描述

进行MPS计算。

# 业务规则

*  勾选了参数：启用新计划模块。
*  计划参数维护：设置了”编号规则”字段。
*  定义了计划范围。
*  定义了计划模式。（可选）
*  进行MPS运算的物料，计划方法已设置为“MPS”。

# 栏目说明

主界面

|栏目|说明|
|---|---|
|运算编号|运算编号用来标识每次计算产生的计划订单。系统会在计划订单上记录运算编号信息。在计划订单功能中，可按运算编号做为条件检索相应的计划订单。运算编号由系统根据参数：编号规则的设置自动产生。|
|计划范围|计划范围决定了本次计算的组织范围、仓库范围等信息。必须要选择一个计划范围。可通过在“计划参数维护”中设置一个默认的计划范围。|
|计划模式|计划模式决定了计算的供需范围及计算的业务逻辑。必须要选择一个计划模式。可通过在“计划参数维护”中设置一个默认的计划模式。|
|计划展望日期|设置计划展望的结束日期。计划展望期决定了计划运算的时间范围。系统默认为9999-12-31。|
|多阶|如果存在多阶MPS业务，可勾选此选项来对所有MPS物料进行计算。|
|模拟|如果勾选此选项，表示是模拟计算。系统并不会产生正式的计划订单。模拟结果可以通过“计划者工作台”功能中的供需资料来查看。|

# 按钮说明

*  调整：点击委外管理－>材料余额调整，进入材料余额功能功能。
*  MPS计算：进行MPS运算，产生计划订单。
 
   *  操作步骤
   
      *  如果计划范围为空，选择一个计划范围。
      *  如果计划模式为空，选择一个计划模式。
      *  根据实际情况，设置计划展望日期。
      *  点击“计算”按钮。系统产生运算编号并更新到屏幕的“运算编号”栏位中。运算结束后，可通过“计划订单”功能，按运算编号来查询产生的MPS数据。
*  多阶MPS计算：进行MPS运算，产生计划订单。
 
   *  操作步骤
   
      *  如果计划范围为空，选择一个计划范围。
      *  如果计划模式为空，选择一个计划模式。
      *  根据实际情况，设置计划展望日期。
      *  勾选“多阶”。
      *  点击“计算”按钮。系统产生运算编号并更新到屏幕的“运算编号”栏位中。运算结束后，可通过“计划订单”功能，按运算编号来查询产生的MPS数据。

# 操作说明

*  通过菜单生产制造－>需求计划－>运算－>MPS运算进入该界面；
*  操作步骤
 
   *  第1步：如果计划范围为空，选择一个计划范围。
   *  第2步：如果计划模式为空，选择一个计划模式。
   *  第3步：根据实际情况，设置计划展望日期，点击计算。
