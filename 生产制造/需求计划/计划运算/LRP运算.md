
# 功能描述

进行LRP计算。

# 业务规则

*  勾选了参数：启用新计划模块。
*  计划参数维护：设置了”编号规则”字段。
*  定义了计划范围。
*  定义了计划模式。（可选）
*  进行LRP运算的物料，计划方法已设置为“MPS”或“MRP”。

# 栏目说明

主界面

|栏目|说明|
|---|---|
|运算编号|运算编号用来标识每次计算产生的计划订单。系统会在计划订单上记录运算编号信息。在LRP工作台功能中，可按运算编号做为条件检索相应的计划订单。运算编号由系统根据参数：编号规则的设置自动产生。|
|计划范围|计划范围决定了本次计算的组织范围、仓库范围等信息。必须要选择一个计划范围。可通过在“计划参数维护”中设置一个默认的计划范围。|
|计划模式|计划模式决定了计算的供需范围及计算的业务逻辑。必须要选择一个计划模式。可通过在“计划参数维护”中设置一个默认的计划模式。|
|来源类型|指定LRP计算的需求来源。LRP支持销售订单、生产订单、计划订单、预测订单、生产计划。必须要选择一个。|
|显示已执行单据|默认情况下已做过LRP计算的需求单据是不会出现在选择单据画面中的。通过勾选此选项，可以在选择单据画面中选择跑过LRP计算的需求单据，重新进行LRP计算。|
|来源单据|选择要进行LRP计算的需求单据。|
|重展计划订单备料|每次LRP计算产生的计划订单，都会根据当时的BOM结构产生计划订单备料数据。当计算后BOM结构发生变化时，可通过勾选此选项在本次LRP计算时更新已有计划订单的备料数据。|

# 按钮说明

*  LRP计算：针对选择的需求单据进行LRP运算，产生计划订单。
 
   *  操作步骤
   
      *  如果计划范围为空，选择一个计划范围。
      *  如果计划模式为空，选择一个计划模式。
      *  选择来源类型。
      *  如果想针对已做过LRP计算的需求单据重新进行LRP运算，则勾选“显示已执行单据”选项。
      *  选择一个或多个来源单据。
      *  点击“计算”按钮。系统产生运算编号并更新到屏幕的“运算编号”栏位中。运算结束后，可通过“LRP工作台”功能，按运算编号来查询产生的计划订单数据。

# 操作说明

*  通过菜单生产制造－>需求计划－>运算－>LRP运算进入该界面；
*  操作步骤
 
   *  第1步：如果计划范围为空，选择一个计划范围。
   *  第2步：如果计划模式为空，选择一个计划模式。
   *  第3步：根据实际情况，选则来源类型和来源单据，点击计算。
