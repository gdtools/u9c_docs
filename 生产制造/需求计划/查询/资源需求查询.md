
# 功能描述

对MRP计算产生的资源需求状况进行查询。

# 业务规则

*  执行了MRP计算。

# 栏目说明

资源需求查询-查询条件

|栏目|说明|
|---|---|
|计划名称|必填项。只能选择当前登录组织定义的计划名称。|
|计划版本|必填项。选择该计划名称下的某个版本。|
|组织|可空。只能选择属于该计划名称的工厂组织。|
|料品|可空。只能选择属于该组织的物料。|
|工作中心|可空。选择组织下的工作中心。|

资源需求查询栏目

|栏目|说明|
|---|---|
|计划名称||
|版本||
|组织|指工厂组织。|
|工作中心|资源所属的工作中心。|
|资源||
|资源用量单位||
|需求用量|指对资源的需求用量。|
|开始使用时间|指要求资源的开始使用日期。|
|单据编号|指计划订单的单号。|


# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>资源需求查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
