
# 功能描述

对MRP计算产生的工作中心需求状况进行查询。

# 业务规则

*  执行了MRP计算。

# 栏目说明

工作中心查询-查询条件

|栏目|说明|
|---|---|
|计划名称|必填项。只能选择当前登录组织定义的计划名称。|
|计划版本|必填项。选择该计划名称下的某个版本。|
|组织|可空。只能选择属于该计划名称的工厂组织。|
|物料|可空。只能选择属于该组织的物料。|
|物料版本|可空。手工输入物料的版本号。|

工作中心查询栏目

|栏目|说明|
|---|---|
|计划名称||
|计划版本||
|组织名称|指工厂组织。|
|工作中心名称|指工厂组织的工作中心。|

# 操作说明

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>工作中心查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
