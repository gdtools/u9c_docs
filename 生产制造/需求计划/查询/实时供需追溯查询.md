
# 功能描述

查询通过实时供需追溯产生的供需信息。

# 业务规则

*  勾选了参数：启用实时供需追溯。(工程数据-参数设置）
*  运行了MPS/MRP/LRP。

# 栏目说明

|计划分配量|只适用于供应类单据。表示该供应单据应该用于满足对应需求的数量。例如：销售订单数量100，库存数量150，销售订单需求全部由库存来满足。则该库存的计划分配量为100。|
|实际分配量|只适用于供应类单据。表示该供应单据实际满足对应需求的数量。按上例销售订单的需求应该是由库存来满足。但如果库存被其它订单出货80，则库存量只剩下70。那么，该库存用于满足订单需求的实际分配量就为70。|
|可分配量|只适用于供应类单据。表示该供应单据除了满足对应需求之外，富余的供应量。例如：两笔销售订单，数量分别为100、50，库存量为180，则该库存除了用于满足两笔销售订单需求外，还剩余30。则可分配量为30。|

# 按钮说明

*  按业务单据查询：给出特定的业务单据号，系统自动检索出与该单据有关的多层供需追溯信息。例如：销售订单001，由工单001满足，工单001的备料由工单002满足，工单002的备料由库存满足。则录入销售订单号：001，系统自动检索出销售订单001、生产订单001、生产订单001备料、生产订单002、生产订单002备料、库存记录，并按树形结构进行展示。点击查询按钮，弹出查询方案对话框，在条件：单据编号中选择相应的业务单据，可以选择多个。
*  按物料查询：给出特定的物料，系统自动检索出与该物料有关的所有供需追溯信息，并按树形结构进行展示。点击查询按钮，弹出查询方案对话框，在条件：物料中选择相应的物料，可以选择多个。

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>实时供需追溯查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
