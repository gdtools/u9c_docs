
# 功能描述

查询系统中的生产计划；

可以依据不同的查询条件进行过滤；

输出栏目及顺序根据用户的需要定制；

可以查询生产计划的不同版本；

可以联查生产计划的详细内容；

# 业务规则

*  维护生产计划；

# 栏目说明

生产计划-查询条件

|栏目|说明|
|---|---|
|组织|要查询生产计划的组织参照录入非空；|
|来源组织|要查询生产计划的来源组织参照录入非空；|
|计划编号|用户录入可以为空，空表示全部；|
|母计划编号|用户录入可以为空，空表示全部；|
|计划员|参照录入可以为空，空表示全部；|
|周期类型|用户选择可以为空，空表示全部；|
|开始日期|用户录入可以为空，空表示不考虑开始日期条件；|
|结束日期|用户录入可以为空，空表示不考虑结束日期条件；|
|状态|用户选择可以为空，空表示全部；|

查询栏目

|栏目|说明|
|---|---|
|组织|显示生产计划的组织编码|
|来源组织|显示生产计划的来源组织编码|
|计划编号|显示生产计划的计划编号|
|计划名称|显示生产计划的计划名称|
|主计划|显示生产计划是否为主计划|
|开始日期|显示生产计划的开始日期|
|结束日期|显示生产计划的结束日期|
|周期类型|显示生产计划的周期类型|
|计划员|显示生产计划的计划员|
|状态|显示生产计划的状态|

生产计划版本-栏目设置

|栏目|说明|
|---|---|
|计划编号|显示生产计划的计划编号|
|版本|显示生产计划的计划版本|
|说明|显示生产计划的说明|

排序条件

根据所选栏目进行排序（升序／降序）

计划明细-栏目设置

|栏目|说明|
|---|---|
|行号|显示计划行的行号|
|料品名称|显示计划行的料品名称|
|计划分期|显示计划行的计划分期|
|开始日期|显示计划行的开始日期|
|结束日期|显示计划行的结束日期|
|原始数量|显示计划行的原始数量|
|生产单位|显示计划行的生产单位|

排序条件

根据所选栏目进行排序（升序／降序）

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>生产计划查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
