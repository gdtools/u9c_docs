
# 功能描述

查询计划订单释放的明细信息。

# 业务规则

*  对计划订单执行了“计划订单释放”操作。

# 栏目说明

计划订单释放查询-查询条件

|栏目|说明|
|---|---|
|工厂组织|必填项。选择一个工厂组织。|
|料品|可空。只能选择属于该工厂组织的物料。|
|单据编号|可空。输入一个计划订单单号。|

计划订单释放查询栏目

|栏目|说明|
|---|---|
|计划组织|定义计划名称的组织。|
|计划名称|在查询条件中给出的计划名称。|
|工厂组织|模拟计划订单上的供应组织。|
|计划版本号|在查询条件中给出的计划版本号。|
|料品名称|物料编码。|
|物料版本|物料版本号。|
|从等级|模拟计划订单的等级范围。|
|到等级|
|从成分|模拟计划订单的成分范围。|
|到成分|
|需求编号|模拟计划订单的需求分类。|
|货主组织|模拟计划订单的货主组织。|
|供应商|模拟计划订单的供应商。|
|存储地点|模拟计划订单的存储地点。|

计划订单明细查询栏目

|栏目|说明|
|---|---|
|单据编号|模拟计划订单的单号。|
|紧急|指是否为紧急的模拟计划订单。|
|库存单位|物料的库存主单位。|
|数量|指模拟计划订单上的数量。|
|需求日期|指模拟计划订单的需求日期。|
|行动日期|指模拟计划订单的行动日期。|
|已发放数量|指模拟计划订单的已发放数量。|
|开工日期|指模拟计划订单的开工日期。|
|锁定|指模拟计单是否已锁定。|

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>计划订单释放查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
