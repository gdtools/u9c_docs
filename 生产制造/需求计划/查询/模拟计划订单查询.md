
# 功能描述

查询某个计划版本产生的所有模拟计划订单信息。

# 业务规则

*  定义计划名称，并执行了MRP计算。

# 栏目说明

模拟计划订单查询-查询条件

|栏目|说明|
|---|---|
|计划名称|必填项。只能选择当前登录组织定义的计划名称。|
|计划版本|必填项。选择该计划名称下的某个版本。|
|工厂组织|可空。只能选择属于该计划名称的工厂组织。|
|料品|可空。只能选择属于该组织的物料。|
|供应商|可空。只能选择属于该组织的供应商。|
|存储地点|可空。只能选择属于该组织的存储地点。|
|货主|可空。选择一个组织。|
|从等级|可空。选择查询的等级范围。|
|到等级|
|从成分|可空。选择查询的成分范围。|
|到成分|
|需求分类|可空。选择一个需求分类。|

模拟计划订单查询栏目

|栏目|说明|
|---|---|
|计划组织|定义计划名称的组织。|
|计划名称|在查询条件中给出的计划名称。|
|工厂组织|模拟计划订单上的供应组织。|
|计划版本号|在查询条件中给出的计划版本号。|
|料品名称|物料编码。|
|物料版本|物料版本号。|
|从等级|模拟计划订单的等级范围。|
|到等级|
|从成分|模拟计划订单的成分范围。|
|到成分|
|需求分类|模拟计划订单的需求分类。|
|货主组织|模拟计划订单的货主组织。|
|供应商|模拟计划订单的供应商。|
|存储地点|模拟计划订单的存储地点。|

模拟计划订单明细查询栏目

|栏目|说明|
|---|---|
|单据编号|模拟计划订单的单号。|
|紧急|指是否为紧急的模拟计划订单。|
|库存单位|物料的库存主单位。|
|数量|指模拟计划订单上的数量。|
|需求日期|指模拟计划订单的需求日期。|
|行动日期|指模拟计划订单的行动日期。|
|已发放数量|指模拟计划订单的已发放数量。|
|开工日期|指模拟计划订单的开工日期。|
|锁定|指模拟计单是否已锁定。|

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>模拟计划订单查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
