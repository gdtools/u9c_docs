
# 功能描述

按不同的物料纬度，对MPS/MRP计算所规划的物料进行查询。

# 业务规则

*  执行了MPS/MRP计算。

# 栏目说明

规划物料查询-查询条件

|栏目|说明|
|---|---|
|计划名称|必填项。只能选择当前登录组织定义的计划名称。|
|计划版本|必填项。选择该计划名称下的某个版本。|
|工厂组织|可空。只能选择属于该计划名称的工厂组织。|
|料品|可空。只能选择属于工厂组织的物料。|
|存储地点||
|计划员|可空。按计划员查询相应的物料。|
|从等级|可空。只查询该等级范围内的物料。|
|到等级|
|从成分|可空。只查询成分范围内的物料。|
|到成分|

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>规划物料查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
