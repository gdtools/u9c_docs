
# 功能描述

生产计划查询按资源汇总的资源需求量和可用量

查询资源在不同时间段的资源需求量和可用量。

可以跟踪具体的需求来源

# 业务规则

*  参数设定，与粗能力查询相关参数

|参数编码|参数名称|说明|
|---|---|---|
|RCCP003|超载率|· 设置超载比率，即负载超过这个数值标记为超载· 系统默认为1,可改|
|RCCP004|低载率|设置低载比率，即负载超过这个数值标记为低载系统默认为0.8,可改|
|RCCP005|默认时格|粗能力查询的默认时格，参照时格录入，可空|

*  已完成粗能力计算；

# 栏目说明

粗能力查询-查询条件

|栏目|说明|
|---|---|
|组织|录入要查询哪个运算组织的粗能力缺省为当前组织参照<组织隶属关系>关系为“工厂关系” 的下级组织及<组织业务行为>关系为“工厂－工厂”的组织录入可空|
|计划名称|录入要查询哪个计划名称的粗能力参照所查询组织的计划名称录入非空；|
|计划版本|参照计划名称的版本录入非空；|
|执行组织|录入查询哪个执行组织的粗能力参照<计划名称>的计划组织录入。可以为空，空表示全部；|
|资源清单集|录入要查询针对哪个资源清单集的粗能力参照资源清单集录入非空；|
|起始日期|查询的起始日期默认显示对应“计划名称”中的起始日期，可改非空|
|结束日期|查询的起始日期默认显示对应“计划名称”中的起始日期，可改非空|
|时格|录入粗能力显示的时格参照时格录入非空|

资源需求能力

|栏目|说明|
|---|---|
|执行组织编码|显示执行组织的编码|

|资源可用量|显示资源在查询日期范围内的总可用能力|
|单位|显示资源的能力单位|
|负载率|显示资源的负载率：需求用量/可用能力|
|负载状态|显示资源状态：超载/低载/正常|

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>粗能力查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
