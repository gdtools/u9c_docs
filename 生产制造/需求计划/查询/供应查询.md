
# 功能描述

查询某个计划版本的所有供应信息，即有哪些供应参与了MPS/MRP计算。

# 业务规则

*  定义计划名称，并执行了MRP计算。

# 栏目说明

供应查询-查询条件

|栏目|说明|
|---|---|
|计划名称|必填项。只能选择当前登录组织定义的计划名称。|
|计划版本|必填项。选择该计划名称下的某个版本。|
|组织|可空。只能选择属于该计划名称的工厂组织。|
|料品|可空。只能选择属于该组织的物料。|
|供应商|可空。只能选择属于该组织的供应商。|
|存储地点|可空。只能选择属于该组织的存储地点。|
|货主组织|可空。选择一个组织。|

查询栏目

|栏目|说明|
|---|---|
|计划名称|在查询条件中给出的计划名称。|
|计划方法|计划名称对应的计划方法。|
|版本|在查询条件中给出的计划版本号。|
|工厂组织|对于采购供应，指产生采购需求的需求组织。对于生产供应，指供应的组织。|
|组织|指供应的组织。|
|料品|物料编码。|
|料品名称|物料名称。|
|料品版本|物料版本号。|
|从等级|可供应的等级。|
|到等级||
|从成分|可供应的成分。|
|到成分||
|需求分类|供应所属的需求分类。|
|货主组织|供应的货主组织。|
|存储地点|供应的存储地点。|
|供应商|供应的供应商。|
|项目|供应所属的项目。|
|任务|供应所属的任务。|
|单据编号|供应单据编号，如：生产订单号，采购订单单号等。|
|单据版本|供应单据版本。|
|单号形态|供应的类型，包括：请购采购订单库存生产订单重复计划主生产计划一揽子采购库存在途|
|行号|供应单据行号。|
|计划行号|供应单据计划行号。|

|供应日期|可供应的日期。|
|锁定标识|指供应是否已锁定。|

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>供应查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
