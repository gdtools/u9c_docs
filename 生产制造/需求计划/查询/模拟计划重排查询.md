
# 功能描述

查询MPS/MRP计算对供应产生的重排建议。

# 业务规则

*  执行了MPS/MRP计算。

# 栏目说明

模拟计划重排查询-查询条件

|栏目|说明|
|---|---|
|计划名称|必填项。只能选择当前登录组织定义的计划名称。|
|计划版本|必填项。选择该计划名称下的某个版本。|
|组织|可空。只能选择属于该计划名称的工厂组织。|
|物料|可空。只能选择属于该组织的物料。|
|厂牌|可空。只能选择属于该组织的供应商。|
|存储地点|可空。只能选择属于该组织的存储地点。|
|货主组织|可空。选择一个组织。|

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>模拟计划重排查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
