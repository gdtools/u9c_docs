
# 功能描述

查询状态为紧急的模拟计划订单。

# 业务规则

*  执行了MPS/MRP计算。

# 栏目说明

紧急模拟计划订单查询-查询条件

|栏目|说明|
|---|---|
|计划名称|必填项。选择当前登录组织的计划名称。|
|计划版本|必填项。选择计划名称的一个版本。|
|工厂组织|可空。按组织查询时，选择属于计划名称的工厂组织。|
|料品|可空　。按料品查询时，选择一个工厂组织的物料。|
|供应商|可空　。按供应商查询时，选择一个工厂组织的供应商。|
|存储地点|可空　。按存储地点查询时，选择一个工厂组织的存储地点。|
|货主|可空　。按货主组织查询时，选择一个组织。|
|从等级|可空。按等级查询时，选择等级的范围。|
|到等级|
|从成分|可空。按成分查询时，选择成分的范围。|
|到成分|
|需求分类|可空。按需求分类查询时，选择一个需求分类。|

# 操作说明

*  通过菜单生产制造－>需求计划－>查询－>紧急模拟计划订单查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
