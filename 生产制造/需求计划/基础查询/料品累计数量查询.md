
# 功能描述

查询MPS/MRP计算时的物料累计生产、采购数量的快照信息。

# 业务规则

*  执行了MPS/MRP计算。

# 栏目说明

具体栏目参考料品栏目相关说明。

|栏目|说明|
|---|---|
|累计生产数量|显示料品的累计生产数量|
|此次计划新增生产数量|显示料品的此次计划新增生产数量|
|此次计划新增领料数量|显示料品的此次计划新增领料数量|

# 操作说明

*  通过菜单生产制造－>需求计划－>基础查询－>料品累计数量查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
