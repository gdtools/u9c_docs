
# 功能描述

批量处理LRP物料的销售订单，产生生产订单。

# 业务规则

*  定义LRP物料的销售订单（必做）
*  定义生产订单单据类型（必做）
*  设置生产订单-参数设置（必做）

# 按钮说明

*  计算：进行批量LRP计算，产生生产订单。
 
   *  操作步骤
   
      *  首先通过界面最上方的“组织”及“物料”两个查询条件，查询出要进行计算的销售订单记录。
      *  通过勾选每条记录最左侧的复选框来批量选择要进行计算的销售订单记录。如果想计算所有记录，则勾选最上方的复选框，系统会自动选中所有记录。
      *  点击【计算】按钮，进行批量计算。

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>LRP批量计算进入该界面；
*  操作步骤
 
   *  第1步：选择组织和料品。
   *  第2步：选择销售订单信息。
   *  第3步：点击计算。
