
# 功能描述 

计划者工作台对当前组织的需求计划进行创建、修改、删除，并支持不同版本之间的比较和拷贝。

进行MRP业务数据收集、调度和MRP计算。

进行DRP计算。

进行PRP计算。

对当前计划名称下的主需求计划(MDS)进行创建、修改、删除，并支持不同计划下的MDS拷贝。

对当前计划名称下的主生产计划(MPS)进行创建、修改、删除，并支持不同计划下的MPS拷贝。

察看当前计划版本计算产生的模拟计划订单、供需资料、供需追溯、毛需求和建议重排。

察看当前计划版本运算的映像数据。

对当前计划版本进行粗能力计算。

# 业务规则

*  定义计划参数
*  定义料品
*  定义料品清单
*  定义计量单位
*  定义组织营运行为关系（可选）
*  定义生产线（可选）

*  定义项目（可选）
*  定义任务（可选）
*  定义供应商（可选）

*  操作
 
   *  查询：点击后弹出标准查询窗口，输入相应的查询条件，系统查找符合条件的主需求记录。
   *  列表：进入列表画面。在该画面中，可批量删除MDS、批量锁定、取消锁定MDS、对于DRP产生的MDS，还可以根据MDS自动创建调拨单。具体操作为：
   
      *  查询：点击后弹出标准查询窗口，输入相应的查询条件，系统查找符合条件的主需求记录。
      *  操作-锁定：锁定选中的主需求记录。在将主需求计划作为需求时，系统只把锁定的MDS作为需求。

      *  点击【主需求】按钮，选择【主需求复制】，可在窗口中进行主需求复制操作。

|开始日期|用于复制特定时间段内的MPS。默认为当前日期。复制时只复制MPS的供应日期在开始..结束日期范围内的MPS。|
|结束日期|用于复制特定时间段内的MPS。默认为当前日期。|
|覆盖|先删除目的版本中已存在的所有MPS，再新增。覆盖和新增只能选择一个。|
|新增|先删除目的版本中与来源版本相同的MPS后，再新增。|


*  MPS下发：将MPS下发到指定的工厂组织中。
 
   *  操作步骤
   
      *  点击【MPS】按钮，选择【MPS下发】，弹出MPS下发窗口。在该窗口中输入下发参数：
      *  来源计划名称：待下发的MPS的计划名称。
      *  来源计划版本：待下发的MPS的计划版本。
      *  目的组织：选择下发的目的组织，目的组织必须在计划名称的计划组织范围内。
      *  目的计划名称：选择一个目的组织的计划名称。
      *  目的计划版本：选择目的计划名称下的一个计划版本。MPS会复制到该计划版本下。
      *  参数输入完毕后，点击确定按钮，则进行MPS下发。点击取消按钮放弃本次操作。

   *  操作步骤
   
      *  点击【MPS】按钮，选择【MPS释放】，弹出MPS释放窗口。

      *  批量勾选待释放的MPS记录后，单击“释放”按钮产生相应的生产或采购单据。
      *  释放结束后，弹出释放结果窗口，如果出错，显示详细的错误信息。
      *  在MPS释放画面中，通过点击“采购分单条件”按钮，来设定采购分单条件。关于采购分单条件请参见："MRP系统参数设定功能中关于采购分单条件的描述。
