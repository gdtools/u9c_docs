
# 功能描述

以二维表格方式进行生产线排产。

# 业务规则

*  执行过计划运算。（可选）

# 栏目说明

主界面-头

|栏目|说明|
|---|---|
|当前组织|显示当前组织名称|
|展望范围|排产的时间范围类型|
|日期|根据展望范围确定排产的时间范围|

主界面-左列表

|栏目|说明|
|---|---|
|紧急|显示计划订单的紧急标识|
|单据编码|显示计划订单的单据编码|
|工厂组织|显示计划订单的工厂组织|
|供应组织|显示计划订单的供应组织|
|料品|显示计划订单的料品|
|调整后需求日期|显示计划订单的调整后需求日期|
|需求日期|显示计划订单的需求日期|
|项目|显示计划订单的项目|
|需求分类|显示计划订单的需求分类|
|料品|显示计划订单的料品|
|供应商|显示计划订单的供应商|

主界面-右列表

|栏目|说明|
|---|---|
|部门名称|系统固定按计划订单的做为维度来显示计划订单在各生产线的生产数量，当前分配数量。|
|生产线编码|
|生产线名称|
|料品编码|
|料品名称|
|料品规格|
|料品备注|
|生产数量|
|当前分配数量|
|xx-xx~xx-xx|系统从开始日期，直至展望期的结束日期为止，并汇总每个日期的排产数量。|

# 按钮说明

*  自动排产：按照排产规则自动进行排产；
*  分割：分割计划订单；
*  按产线排产：按产线排产；
*  手工排产：手工进行排产；

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>生产线排产进入该界面；
*  操作步骤
 
   *           *  第1步：点击“查询”按钮。
      *  第2步：输入查询条件。
      *  第3步：点击确定。
      *  第4步：选择计划订单。
      *  第5步：选择展望范围和日期。
      *  第6步：按照日期维护相关数量或者点击自动排产等相关按钮。
      *  第7步：点击保存按钮。
