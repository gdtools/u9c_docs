
# 功能描述

进行LRP计算。

# 业务规则

*  通过“LRP参数设置”功能维护了LRP参数。
*  进行LRP运算的物料，计划方法已设置为“MPS”或“MRP”。
*  如果是多组织，已设置了相应的业务关系。

# 栏目说明

主界面

|栏目|说明|
|---|---|
|计划批号|计划批号用来标识每次计算产生的计划订单。系统会在计划订单上记录计划批号信息。在LRP工作台功能中，可按计划批号做为条件检索相应的计划订单。如果将参数：编号方式设置为“自动编号”，则每次LRP计算时系统会根据“编号规则”自动产生一个计划批号。如果将参数：编号方式设置为“手工编号”，则在每次LRP计算时，需人工给出计划批号。|
|来源类型|指定LRP计算的需求来源。LRP支持销售订单、生产订单、计划订单、预测订单、生产计划。必须要选择一个。|
|来源单据|选择要进行LRP计算的需求单据。|
|显示已执行单据|默认情况下已做过LRP计算的需求单据是不会出现在选择单据画面中的。通过勾选此选项，可以在选择单据画面中选择跑过LRP计算的需求单据，重新进行LRP计算。|
|重展计划订单备料|每次LRP计算产生的计划订单，都会根据当时的BOM结构产生计划订单备料数据。当计算后BOM结构发生变化时，可通过勾选此选项在本次LRP计算时更新已有计划订单的备料数据。|
|计划方案|如果需要按存储地点进行LRP运算，或设置了物料的供应方式（自制/采购/委外）时，可选择计划方案。|

# 按钮说明

*  LRP计算：针对选择的需求单据进行LRP运算，产生计划订单。

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>LRP计算进入该界面
*  操作步骤
 
   *  第1步：选择来源类型。
   *  第2步：如果想针对已做过LRP计算的需求单据重新进行LRP运算，则勾选“显示已执行单据”选项。
   *  第3步：选择一个或多个来源单据。
   *  第4步：点击“计算”按钮。如果计划批号设置为自动产生，则系统产生计划批号并更新到屏幕的“计划批号”栏位中。运算结束后，可通过“LRP工作台”功能，按计划批号来查询产生的计划订单数据。
