
# 功能描述

以二维表格方式编辑计划订单。

# 业务规则

*  执行过计划运算。（可选）

# 栏目说明

主界面

|栏目|说明|
|---|---|
|组织|系统固定按计划订单的“组织、料品、项目、番号、需求分类”做为维度来汇总显示计划订单。|
|料品|
|项目|
|番号|
|需求分类|
|汇总|显示当前维度下计划订单的汇总数量。|
|xx-xx日之前|当前日期之前的时间系统固定做为一个时段来处理。并汇总早于当前日期的计划订单的数量。|
|xx-xx~xx-xx|系统从当前日期开始，按查询方案中的分期类型划分时间段，直至查询方案中的展望期为止，并汇总每个时段内的计划订单数量。例如：分期类型=周，展望期=月，当前日期为1月1号。则系统划分的时间段如下：1月1日-1月7日，1月8日-1月14日，1月15日-1月21日，1月22日-1月28日，1月29日-1月31日。注意：系统是按照自然日历的方式来划分时间段的。|
|xx-xx日之后|系统自动将展望期之后的时间做为一个时段来处理。并汇总该时段内的计划订单数量。|

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>计划订单二维表进入该界面；
*  操作步骤
 
   *           *  第1步：点击“新增”按钮增加一个空白行。
      *  第2步：录入组织、物料信息，并在对应的时段内录入数量信息。
      *  第3步：如果想在时段内录入多条计划订单的数量，则需要点击时段栏目的链接，系统弹出计划订单维护画面。在该画面中可录入多条数据，点击确定按钮后返回到主画面。同时，系统自动汇总时段内的数量信息。
      *  第4步：点击保存按钮。
