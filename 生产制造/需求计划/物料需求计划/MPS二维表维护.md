
# 功能描述

通过二维表的方式来维护MPS数据。

# 业务规则

*  已进行过MPS计算。

# 栏目说明

主界面-头

|栏目|说明|
|---|---|
|基本页签|
|计划名称|选择一个要进行MPS维护的计划名称。|
|工厂组织|如果希望按组织来过滤MPS数据，则选择一个工厂组织。|
|纬度|
|显示等级|如果希望按等级、成分来显示MPS数据，则勾选这两个选项。如果勾选，系统按“物料+等级、成分”来汇总显示MPS数据。否则按物料汇总显示。|
|显示成分|

主界面-体

|栏目|说明|
|---|---|
|行页签|
|显示需求数量|如果勾选，系统会同时显示物料在每个时段内的需求数量、预计库存量及物料的安全库存量信息。预计库存为该时段的期末结存量。勾选对应选项后，要点击“刷新”按钮，系统才会在界面上显示相应选项的数据。|
|显示预计库存|
|显示安全库存|
|显示日期范围|系统固定按30天做为一个显示区间对计划名称的展望期进行划分，且每次只能显示一个区间的MPS数据。例如：计划展望期为1月1日-2月28日，则系统自动划分为两个显示区间：1月1日-1月30日，1月31日-2月28日。通过切换显示区间来查看对应显示区间的MPS数据。|
|增删行|勾选此选项后，系统进入编辑模式。可以对MPS数据进行增删改操作。勾选此选项后，就无法勾选显示预计库存、显示需求数量、显示安全库存这几个选项。|
|组织、料号、品名、料品版本|系统自动按“组织+物料+物料版本”维度来汇总每个时段内的MPS数量。如果勾选了“显示等级”、“显示成分”选项，则再加上等级、成分这两个维度。|
|当前库存|这里的库存是进行MPS运算时的库存量，是一个“快照”数据。通过点击“刷新供需”可获取到当前的库存量。|
|时间段|对每个显示区间，系统固定按“日”来划分时段。如：显示区间：1号-30号，系统自动划分30个时段。对每个时段，系统汇总相应的计划数量（即MPS数量）、需求数量（如果勾选显示需求数量）、预计库存量（如果勾选显示预计库存），并获取物料的安全库存（如果勾选显示安全库存）。对每个时间段内的计划数量，可以进行编辑。如果某时间段内的计划数量是由多个MPS数据汇总得出的则无法编辑。|

# 按钮说明

*  MPS维护
 
   *  操作步骤
   
      *  选择计划名称、计划版本
      *  根据需要，可选择一个工厂组织。
      *  点击“计划”按钮，系统弹出“选择料品”对话框。可多选该计划名称的MPS物料，并点击“确定”按钮。
      *  系统自动根据计划名称的展望期划分显示区间，对每个显示区间按日划分时段。并自动加载第一个区间的MPS数据。
      *  可通过切换“显示日期范围”来查看不同区间内的MPS数据。
      *  如果需要，可勾选显示需求数量、显示预计库存、显示安全库存选项，并点击“刷新”按钮来显示勾选的选项的内容。
      *  如果需要，可点击“刷新供需”按钮，刷新需求数量等信息。
      *  如果需要编辑MPS数据，可勾选“增删行”选项，系统进入编辑模式。在编辑模式中，可对MPS数据进行增、删、批改操作。

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>MPS二维表维护进入该界面；
*  操作步骤
 
   *           *  第1步：选择计划名称、计划版本
      *  第2步：根据需要，可选择一个工厂组织。
      *  第3步：点击“计划”按钮，系统弹出“选择料品”对话框。可多选该计划名称的MPS物料，并点击“确定”按钮。
      *  第4步：系统自动根据计划名称的展望期划分显示区间，对每个显示区间按日划分时段。并自动加载第一个区间的MPS数据。
      *  第5步：可通过切换“显示日期范围”来查看不同区间内的MPS数据。
      *  第6步：如果需要，可勾选显示需求数量、显示预计库存、显示安全库存选项，并点击“刷新”按钮来显示勾选的选项的内容。
      *  第7步：如果需要，可点击“刷新供需”按钮，刷新需求数量等信息。
      *  第8步：如果需要编辑MPS数据，可勾选“增删行”选项，系统进入编辑模式。在编辑模式中，可对MPS数据进行增、删、批改操作。
