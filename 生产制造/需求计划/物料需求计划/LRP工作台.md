
# 功能描述

用来查看并维护LRP计算产生的计划订单。

# 业务规则

*  进行了LRP计算。

# 栏目说明

LRP工作台的内容和“计划订单”功能类似。下面仅描述差异的部分，相同的部分请参考“计划订单”功能中的说明。

主界面

|栏目|说明|
|---|---|
|基本页签|
|计划批号|LRP计算时产生的运算编号。可用来做为查询计划订单的条件。对手工增加的计划订单，也可以选择计划批号。|
|毛需求量|按物料汇总的各类供需数量信息。可用来指导计划人员调整计划订单数量。各个数量的具体含义请参考“LRP应用专题”中的描述。|
|生产领料量|
|订单量|
|预测量|
|现存量|
|在制量|
|计划订单量|
|采购在途量|
|请购在途量|
|调拨在途量|
|层级编码|用来记录计划订单在BOM结构中的位置。通过对层级编码排序，可实现按BOM层次显示计划订单。|
|供需明细页签|
|供/需，单据类型，单号，组织，数量，需求/供应日期，项目，番号，需求分类，替代标志|该页签用来显示当前物料详细的供需数据，计划员可通过该信息来了解物料供需的现状。|


# 按钮说明

*  LRP工作台的内容和“计划订单”功能类似。参照“计划订单”按钮说明。

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>LRP工作台进入该界面；
*  操作步骤
 
   *  第1步：点击查询，查找相关计划订单。
   *  第2步：修改供应类型，供应组织等信息。
   *  第3步：修改调整后数量、日期等信息调整后信息。
   *  第4步：点击保存。
