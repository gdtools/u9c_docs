
# 功能描述

批量执行重排建议。

# 业务规则

*  进行了净改变计算。
*  如果物料受等级、成分控制，则对MO的变更建议不能执行。
*  对重复计划不会产生重排建议。
*  如果对一张MO或PO产生两笔重排建议，如：MO001，20号完工，数量100。为MO001产生两笔重排建议，分别是10号完工50，20号完工50。则MO001不能执行重排建议，需要用户手工处理。

# 栏目说明

具体见“计划者工作台”功能中关于重排建议查询部分的描述。

# 按钮说明

*  查询：弹出查询条件窗口，用来过滤重排建议。
 
   *  操作步骤
   
      *  点击【查询】按钮弹出查询条件窗口，在该窗口中输入相应的查询条件后点击“确定”返回。
*  批量执行：对勾选的重排建议，执行重排建议。
 
   *  操作步骤
   
      *  勾选要执行的重排建议，并点击【批量执行】按钮。
      *  注意：如果该重排建议不能执行，则勾选复选框为灰色，无法勾选。
*  查看单据：查看重排建议的原始业务单据信息。如对MO的重排建议，弹出“生产订单”窗口来查看该MO的详细信息。
 
   *  操作步骤
   
      *  选中一条要查看的重排建议，并单击【查看单据】按钮。弹出相应业务单据窗口显示与该业务单据有关的详细信息。

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>重排建议执行进入该界面；
*  操作步骤
 
   *  第1步：点击查询，输入查询条件。
   *  第2步：选择需要执行的重排建议。
   *  第3步：点击批量执行。
