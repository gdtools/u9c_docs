
# 功能描述

用来查看物料详细的供需资料信息，核对计划结果是否正确。

# 业务规则

*  进行了计划运算。

# 栏目说明

|栏目|说明|
|---|---|
|组织|这几个栏目代表了查看供需资料的维度。具体按哪几个维度查看，可通过查询方案的“分组选项”条件进行设置。如：分组选项设置为组织、项目，则系统按照“物料+组织+项目”的方式来查看供需资料。同时，在该窗口中只显示物料、组织、项目这几个栏目。系统支持的维度包括：组织、项目、番号、需求分类、存储地点。物料为固定维度。|

|规格|

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>供需查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询。
   *  第2步：输入查询条件。
   *  第3步：点击确定。
