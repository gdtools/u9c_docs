
# 功能描述

计划订单为MPS/MRP运算产生的结果数据，可用于释放为MPS、生产订单、采购订单等：

查看及修改MPS/MRP运算产生的结果数据，如：物料、交期、数量等。

可手工新增计划订单。

可批量锁定、取消锁定计划订单。

可释放计划订单。

如果计划订单可优化，则可以进行优化调整。

# 业务规则

*  定义MRP计划参数（必做）
*  定义工厂组织（必做）
*  定义物料（必做）
*  定义计量单位（必做）
*  定义物料版本（可选）
*  定义等级、成分（可选）
*  定义需求分类（可选）
*  定义存储地点（可选）
*  定义供应商（可选）
*  定义项目、任务（可选）
*  定义番号（可选）
*  定义计划员（可选）
*  单头上的累计调整后投入量、累计已释放量、本次累计发放量表示当前屏幕上显示的所有计划订单的调整后投入量、已释放量、本次释放量的和。累计时如果计量单位不同则不做转换。

# 栏目说明

计划订单－基本页签

|栏目|说明|
|---|---|
|单号|系统根据MRP计划参数中设置的[编码方案]自动产生，不可编辑。|
|工厂组织|如果为制造件，表示由哪个工厂组织来生产。如果为采购件，表示为哪个工厂组织来采购。|
|供应组织|手工录入，必填项。只能选择：当前有效的组织。与工厂组织有“工厂-采购”、“工厂-工厂”、“物流-采购”关系的组织。工厂组织自身。|
|料号|手工录入，必填项。只能选择：当前有效的物料。物料形态属性为ATO、委外加工、采购件、制造件，FAS，重复件。MRP规划的物料。保存后不可修改。|
|品名|物料的名称。|
|BOM版本|如果指定：在将锁定计划订单作为供应时，系统会按此BOM版本展开下阶子件作为需求。计划订单释放MO时，按此BOM版本展开备料需求。MPS/MRP计算时，固定匹配“主制造”的BOM。但在某些场景中，如化工行业的配方，可能会按照其它生产目的的BOM来组织生产，此时就可以在计划订单中指定BOM版本。|
|数量|对于手工录入的计划订单，等于[调整后数量]，不可编辑。对于系统产生的计划订单，表示由MPS/MRP计算出的需要净需求数量，不可编辑。如果想手工调整，只能修改[调整后数量]。计划订单中所有数量的计量单位都是库存主单位。|
|调整后数量|对于系统产生的计划订单，等于按批量、倍量修正后的净需求数量]，可改。否则手工录入。调整后数量是一个不考虑损耗的供应量，在录入调整后数量且光标焦点改变时，自动计算[MRP数量]、[投入量]。计算公式如下：MRP数量 = 调整后数量 * （1+物料档案.库存损耗率）投入量 = MRP数量 / （1 - 物料档案.生产损耗率）|
|MRP数量|MRP数量是一个考虑了库存损耗的供应量，根据[调整后数量]自动计算。|
|调整后MRP数量|指手工调整后的MRP量。|
|投入量|投入量在MRP数量的基础上考虑了生产损耗，根据[调整后数量]自动计算。|
|调整后投入量|指手工调整后的投入量。|
|库存主单位|等于物料档案.库存单位，在选择物料后自动带出，不可编辑。|
|需求日期|对于手工录入的计划订单，等于[调整后需求日期]，不可编辑。对于系统产生的计划订单，表示由MPS/MRP计算出的可供应日期，不可编辑。如果想手工调整，只能修改[调整后需求日期]。|
|调整后需求日期|对于系统产生的计划订单，默认等于[需求日期]，可改。否则手工录入。调整后需求日期、调整后开工日期、调整后行动日期必须是工作日。在录入了调整后需求日期且光标焦点改变时，自动计算［调整后开工日期］、［调整后行动日期］，计算公式如下：如果供应类型=采购：调整后开工日期 = 调整后需求日期 - 处理提前期 - 后处理提前期调整后行动日期 = 调整后开工日期 - 前处理提前期如果供应类型=制造、委外：调整后开工日期 = 调整后需求日期 - 后处理提前期　- 固定提前期 - 变动提前期 * 投入量调整后行动日期 = 调整后开工日期　- 前处理提前期|
|开工日期|对于手工录入的计划订单，等于[调整后开工日期]，不可编辑。对于系统产生的计划订单，表示由MPS/MRP计算出的预计开工日期，不可编辑。如果想手工调整，只能修改[调整后开工日期]。|
|调整后开工日期|对于系统产生的计划订单，默认等于[开工日期]，可改。否则手工录入。调整后开工日期不能大于调整后需求日期。|
|行动日期|对于手工录入的计划订单，等于[调整后行动日期]，不可编辑。对于系统产生的计划订单，表示由MPS/MRP计算出的预计行动日期，不可编辑。如果想手工调整，只能修改[调整后行动日期]。|
|调整后行动日期|对于系统产生的计划订单，默认等于[行动日期]，可改。否则手工录入。调整后行动日期不能大于调整后开工日期。|
|锁定|锁定表示计划员对计划订单信息的确认。在MRP计算时，可以将锁定的计划订单作为供应。对于锁定计划订单，系统会产生重排建议，但不会执行该建议，只能由人工进行调整。|
|紧急|在MPS/MRP计算时，由于计划时栅的控制，导致计划订单的开始日期比要求的开始日期晚。系统会自动将该计划订单设置为紧急，表示企业应尽早将该计划订单进行释放。对于过期需求产生的计划订单也会打上紧急标志。|
|优先级|优先级表示计划订单的重要程度。对于通过MPS/MRP运算产生的计划订单，等于相应需求的优先级，不可改。对于手工录入的计划订单，新增时默认为零，在保存后不可修改。优先级数值越小表示订单的重要程度越高。|
|主供应商|物料档案中定义的主供应商。不可改。|
|可优化|表示该计划订单是否可做优化调整，系统维护。|
|释放单据类型|决定本次释放的业务单据：生产：供应类型=自制或采购，同时物料勾选了[可生产]时，可以将计划订单释放为MO或生产线日计划。采购：供应类型=自制或采购，同时物料勾选了[可采购]时，可以将计划订单释放为PO或PR。委外：供应类型=委外时，可以释放为委外类型的PO。|
|计划生产|表示此计划订单是否要释放为计划生产订单。MPS/MRP计算时，如果勾选了自动释放且定义了计划生产订单时界日期，则系统自动将此时界日期范围内的计划订单设为“计划生产”。 可手工修改。|
|释放量|本次释放的计划订单数量。默认等于投入量-已释放量。计划订单可以多次释放，但释放的总量不能超过计划订单的投入量。|
|已发放量|表示计划订单已释放为生产/采购的数量。|
|生产订单单据类型|默认为空，如果指定，表示按该单据类型创建MO。|

计划订单－物料页签

|栏目|说明|
|---|---|
|料品版本|物料受版本控制时，默认带出当前版本，并可选择其它版本，否则不可编辑。保存后不可修改。物料版本并不是必填项，即使物料受版本控制。|
|等级|物料不做等级控制时不可编辑，否则默认为物料标准等级，可改。保存后，不可修改。|
|成分|物料不做成分控制时不可编辑，否则默认为物料标准成分，可改。保存后，不可修改。|
|需求分类|手工选择一个需求分类。保存后，不可修改。|
|货主组织|默认等于工厂组织，可参照选择其它组织，必填项。保存后，不可修改。|
|存储地点|手工录入，参照选择工厂组织下有效的存储地点。保存后，不可修改。|
|厂牌|如果物料做厂牌管理，则可为计划订单指定一个特定厂牌。指定时只能从物料-厂牌交叉档中选择厂牌。|
|项目|参照选择工厂组织的项目。保存后，不可修改。在MPS/MRP计算时，项目会从原始需求单据带到计划订单及释放产生的MO、PO上，以实现按项目跟踪。|
|任务|参照选择项目所属的任务。保存后，不可修改。|
|番号|参照选择工厂组织的番号。保存后不可改。|

计划订单－供应/来源页签

|栏目|说明|

|建议生产线|MPS/MRP计算时，取优先级最高的生产线作为建议生产线，不可改。|
|来源WBS需求|如果为PRP，表示该计划订单是用来满足wbs需求的。|
|计划名称|表示该计划订单是由哪个计划名称产生的，不可改。|
|来源采购合同单号|MPS/MRP计算时，如果采购合同作为供应来满足需求，则会产生一笔相应的计划订单，该计划订单释放时会产生PO来销抵相应的采购合同。|

# 按钮说明

*  查询：按一定条件查询计划订单记录。
 
   *  操作步骤
   
      *  给出查询条件，并点击【查询】按钮。
*  操作-批量修改：批改计划订单信息，目前只支持批改计划生产、生产订单单据类型、BOM版本信息。
 
   *  操作步骤
   
      *  首先查询出相关的计划订单记录。
      *  然后勾选要批改的计划订单。
      *  点击“操作”菜单，并选择“批量修改”菜单项。
      *  弹出批量修改窗口，可根据需要修改计划生产、生产订单单据类型、BOM版本信息。修改BOM版本时，如果勾选的计划订单包含不同的物料，则可以在批量修改窗口中切换物料来批改BOM版本。
      *  在弹出窗口中点击“确定”按钮，完成本次批改操作。
*  操作-优化调整：人工调整系统优化后的结果。
 
   *  操作步骤
   
      *  点击【优化调整】按钮，弹出优化调整画面。
      *  界面左侧显示待优化调整的计划订单。右上显示该计划订单供应的独立需求，如：SO、预测等。右下显示目前调整的结果。
      *  手工修改调整结果画面内的数量，调整后的数量之和必须等于分配给该独立需求的数量。
      *  点击保存按钮，保存所做的调整。
*  操作-释放单据：释放计划订单为相关业务单据，如：PO、MO等。
 
   *  操作步骤
   
      *  首先查询出相关计划订单，并勾选要释放的计划订单。
      *  如果需要，可修改本次释放量、生产订单单据类型、释放类型等信息。
      *  如果需要释放为计划生产订单，可修改勾选计划生产标志。
      *  点击“操作”菜单，并选择“释放单据”菜单项。释放结束后会显示释放结果画面。
      *  有关计划订单释放的更多信息，可参考“计划订单释放”功能。
*  操作-释放MPS：释放计划订单为MPS。
 
   *  操作步骤
   
      *  首先查询出相关计划订单，并勾选要释放的计划订单。
      *  如果需要，可修改本次释放量。
      *  点击“操作”菜单，并选择“释放单据”菜单项。释放结束后会显示释放结果画面。
      *  有关释放MPS的更多信息，可参考“计划订单释放”功能。
*  操作-全部释放：释放查询出的所有计划订单，此操作不需要勾选计划订单。
 
   *  操作步骤
   
      *  首先查询出要释放的计划订单。
      *  如果需要，可修改本次释放量。
      *  点击“操作”菜单，并选择“全部释放”菜单项。
*  采购条件-分单条件：计划订单释放时按此分单条件创建采购订单。如果此处没有定义分单条件，则系统按采购模块中设置的分单条件创建采购订单。
*  采购条件-合行条件：计划订单释放时按此合行条件创建采购订单。如果此处没有定义合行条件，则系统按采购模块中设置的合行条件创建采购订单。
*  供需资料：查看选中计划订单对应物料的供需资料信息。
 
   *  操作步骤
   
      *  点击【供需资料】按钮。
      *  弹出供需资料画面，显示当前焦点的计划订单物料对应的供需资料信息。
      *  点击【关闭】　　按钮，返回计划订单窗口。
*  计划订单释放：导航到计划订单释放画面。具体参见“计划订单释放”功能的描述。
*  计划订单分层释放：导航到计划订单分层释放画面。具体参见“计划订单分层释放”功能的描述。

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>计划订单进入该界面；
*  操作步骤
 
   *  第1步：点击查询，查找相关计划订单。
   *  第2步：修改供应类型，供应组织等信息。
   *  第3步：修改调整后数量、日期等信息调整后信息。
   *  第4步：点击保存。
