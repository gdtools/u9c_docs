
# 功能描述

通过外部需求来源可以维护多种来源的需求，如：销售订单、销售计划等。外部需求来源主要用于：

做为与其它系统的接口。例如在企业使用第三方的销售系统时，通过外部需求来源手工录入这些销售需求来参与MPS/MRP运算。

做为上下游组织间、不同规划方法物料间、不同计划方法物料间需求的载体。例如：上游组织通过外部需求来源产生对下游组织的的需求。

# 业务规则

*  定义组织（必做）
*  定义物料（必做）
*  定义计量单位（必做）
*  定义物料版本（可选）
*  定义等级、成分（可选）
*  定义需求分类（可选）
*  定义存储地点（可选）
*  定义供应商（可选）
*  定义项目、任务（可选）

# 栏目说明

外部需求来源头

|栏目|说明|
|---|---|
|组织|指供应该笔需求的组织，只能选择：当前登录组织为工厂组织时，可以选择当前登录组织。与当前登录组织有业务关系的工厂组织。是当前登录组织的下级工厂组织。必填项，保存后不可修改。|
|料品|手工录入，必填项。只能选择：MRP规划的物料。物料形态属性为ATO、委外加工、工序委外、采购件、制造件，FAS，重复件。必填项，保存后不可修改。|
|版本|物料受版本控制时，默认带出当前版本，并可选择其它版本，否则不可编辑。保存后，不可修改。物料版本并不是必填项，即使物料受版本控制。|
|从等级|物料不做等级控制时不可编辑，否则默认为物料标准等级，可改。保存后，不可修改。|
|到等级|物料不做等级控制时不可编辑，否则默认为物料标准等级，可改。保存后，不可修改。|
|从成分|物料不做成分控制时不可编辑，否则默认为物料标准成分，可改。保存后，不可修改。|
|到成分|物料不做成分控制时不可编辑，否则默认为物料标准成分，可改。保存后，不可修改。|
|需求分类|手工选择一个需求分类。保存后，不可修改。|
|货主组织|参照选择一个组织，必填项。保存后，不可修改。|
|存储地点|手工录入，参照选择组织下有效的存储地点。保存后，不可修改。|
|批号|如果物料受批号管理，则可以手工输入一个批号，否则不可编辑。保存后，不可修改。|
|厂牌|手工录入，参照选择组织下有效的供应商。保存后，不可修改。|
|项目|手工录入，参照选择组织下的项目。保存后，不可修改。|
|任务|手工录入，选择项目所属的任务。保存后，不可修改。|
|番号|如果想按番号跟踪需求，则输入一个番号。对于相依需求，表示来源需求的番号。|
|备注|可录入描述性信息。|

外部需求来源体－明细页签

|栏目|说明|
|---|---|
|来源类型|指需求的来源，包括：预测报价单销售订单销售合同库存规划MPS计划订单DRP负库存来源类型为MPS、计划订单、DRP的外部需求是在MPS/MRP/DRP计算时，系统自动产生的。对于这些需求，不允许修改其来源类型。来源类型为库存规划的外部需求是库存规划时产生的。对于这种需求，不允许修改其来源类型。否则可以手工选择一个来源类型。|
|开始日期|当物料为重复件或来源类型等于“预测”时，表达需求时段的始点。因为在这种情况下，可能会用一段时间内的需求量来表达需求。例如：1日到10日需求100个，则开始日期为1日。否则开始日期就是需求的要求交货日期。|
|结束日期|当物料为重复件或来源类型等于“预测”时，表达需求时段的结束点。因为在这种情况下，可能会用一段时间内的需求量来表达需求。例如：1日到10日需求100个，则结束日期为10日。否则结束日期固定等于开始日期。当物料为重复件时，结束日期必须大于等于开始日期。|
|交易单位|默认为物料的库存单位，可改，必填项。|
|交易单位数量|指需求数量，必须大于零。|
|库存主单位|物料的库存单位，不可改。|
|需求数量|指库存主单位的需求数量，保存时系统自动计算，公式为：需求数量 = 交易单位数量 * 交易-库存|
|交易-库存|指交易单位对库存单位的转换率。在选择了交易单位后自动计算。如果物料为固定转换率则不可改，否则可改。转换率必须大于零。|
|锁定|锁定表示对外部需求内容的确认。在MPS/MRP运算时，只考虑锁定的外部需求。|
|来源组织|指需求组织，默认为当前登录组织，可改。|
|来源存储地点|对于DRP，表示需求的来源存储地点。|
|计划到货日期|对于DRP，表示上游需求的原始需求日期。需求日期=计划到货日期-运输周期。|
|已释放数量|对于DRP，记录产生的调拨单数量。|
|备注|可录入描述性信息。|

外部需求来源体－来源页签

|栏目|说明|
|---|---|
|来源单据号|来源类型=计划订单时，记录相应的计划订单单号。其余情况下为空。|
|版本|来源单据的版本。|
|行号|来源单据的行号。|
|计划行|来源单据的计划行号。|

外部需求来源体－销抵页签

|栏目|说明|
|---|---|
|单据类别|DRP时，在调出单审核时会销抵外部需求以保证供需之间平衡。此时单据类别为调出单。其它情况下为空。|
|单据组织|表示调出单的调出组织。|
|来源单据号|表示调出单的单号。|
|来源单据版本|表示调出单的版本号。|
|来源单据行号|表示调出单的行号。|
|来源单据计划行号|表示调出单的计划行号。|
|销抵数量|表示调出单的调出数量。|
|单位|物料的库存主单位。|
|销抵日期|表示调出单审核的业务日期。|

# 按钮说明

*  调拨单：对于DRP，外部需求来源中记录了下级分销中心对上级分销中心的需求。上级分销中心可以使用该操作产生对下级分销中心的调拨单。
 
   *  操作步骤
   *  点击【列表】按钮，进到列表画面。
   *  在该画面中批选要产生调拨单的外部需求来源记录。
   *  点击“调拨单”按钮，弹出“生成调拨单”画面，该画面的信息项如下：
   *  生成调拨单

|栏目|说明|
|---|---|
|调出组织|调出组织、调出存储地点等信息都是从外部需求来源记录中带过来的，且不可改。|
|调出存储地点||
|调入组织||
|调入存储地点||
|料号||
|品名||
|库存单位||
|本次释放量|表示本次要产生调拨单的数量。外部需求记录可多次释放为调拨单。|
|可释放量|表示可释放为调拨单的数量。可释放量=需求数量-已释放量。|
|料品版本||
|等级||
|成分||
|项目||
|任务||
|需求分类||
|番号||
|厂牌||
|货主组织||

*      *  在该画面中点击“生单条件”按钮，则弹出“生单条件”窗口。在该窗口中可设置生单类型及分单条件等信息。具体为：
   *  调拨类型：可选择是一步式调拨还是两步式调拨。
   *  调拨日期：默认为当前日期。
   *  分单纬度：可按调入组织、调入存储地点、调出存储地点、项目、任务、番号来分单。

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>外部需求来源进入该界面；
*  操作步骤
 
   *  第1步：选择组织和料品。
   *  第2步：维护等级、成分、项目等信息。
   *  第3步：维护时间、数量等明细信息。
   *  第4步：点击保存。
