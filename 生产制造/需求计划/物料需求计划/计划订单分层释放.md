
# 功能描述

按BOM结构显示计划订单并释放为相应业务单据。

# 业务规则

*  定义MRP计划参数（必做）
*  定义BOM（必做）
*  定义工厂组织（必做）
*  定义物料（必做）
*  定义计量单位（必做）
*  定义物料版本（可选）
*  定义等级、成分（可选）
*  定义需求分类（可选）
*  定义存储地点（可选）
*  定义供应商（可选）
*  定义项目、任务（可选）
*  定义计划员（可选）

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|工厂组织|按该组织定义的BOM结构分层展示，必填。|
|料品|待展开的物料，必填。|
|BOM生效日期|用来决定按哪个BOM版本的BOM结构分层展示，默认为当前日期。|
|项目|如果输入，则按特定项目的BOM结构进行分层展示。|
|计划名称|如果输入，表示只查找该计划名称、版本下的计划订单。|
|计划版本|
|单号|如果输入，表示按照该单号对应的料号进行BOM展开。必须录入计划名称、版本条件后才能选择单号。录入单号与录入料品条件是等价的，只是使用习惯不同。|
|BOM类型|必填，表示是按照自制还是委外BOM进行展开。|

窗口左侧显示按查询条件匹配到的BOM结构树，根节点为查询条件中指定的物料。单击节点左侧的“+”号，则按BOM结构展开一层。单击节点本身，则查找该节点物料的计划订单。

窗口右侧显示某节点物料的计划订单，在该窗口中可以批选计划订单进行释放。该窗口的内容见“计划订单释放”功能。

# 按钮说明

*  调整：点击委外管理－>材料余额调整，进入材料余额功能功能。
*  查询：输入BOM匹配的条件，输入查询计划订单的条件。
 
   *  操作步骤
   
      *  给出查询条件，并点击【查询】按钮。
*  操作-批量修改：具体见“计划订单释放”功能中的描述。
*  操作-释放单据：根据计划订单中规定的[释放单据类型]产生相应的单据，并返回释放结果。具体见“计划订单释放”功能。
 
   *  操作步骤
   
      *  在右侧画面中选中要释放的计划订单并点击【操作-释放单据】按钮。
*  操作-释放MPS：将计划订单释放为MPS。释放结束后显示释放结果。具体见“计划订单释放”功能。
 
   *  操作步骤
   
      *  在右侧画面中选中要释放为MPS的计划订单并点击【操作-释放MPS】按钮。
*  采购条件-分单条件：具体见“计划订单释放”功能中的描述。
 
   *  操作步骤
   
      *  在主画面中点击【采购条件】按钮。
*  采购条件-合单条件：具体见“计划订单释放”功能中的描述。
 
   *  操作步骤
   
      *  在主画面中点击【采购条件】按钮。
*  模拟：具体见“计划订单释放”功能中的描述。
 
   *  操作步骤
   
      *  在主画面中点击【模拟】按钮。
*  相关功能-计划订单维护：导航到“计划订单维护”画面。具体参见该画面的描述。
 
   *  操作步骤
   
      *  在主画面中点击【相关功能-计划订单维护】按钮。

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>计划订单分层释放进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件，查找相关计划订单。
   *  第2步：选择计划订单。
   *  第3步：点击释放。
