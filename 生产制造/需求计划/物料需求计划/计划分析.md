
# 功能描述

针对MRP运算的过程中的可能存在的异常情况的原因进行分析，展示分析的结果。

# 业务规则

*  已经进行过MRP运算。

# 栏目说明

计划分析头

|栏目|说明|
|---|---|
|我想知道|选择要分析的情况|
|请选择计划版本|选择需要分析的计划版本|


计划分析-需求没参与计算

|栏目|说明|
|---|---|
|需求类型|选择需求类型|
|来源单据|选择没参与计算的单据|

计划分析-供应没参与计算

|栏目|说明|
|---|---|
|供应类型|选择供应类型|
|来源单据|选择没参与计算的单据|

计划分析-没产生计划订单

|栏目|说明|
|---|---|
|物料|选择物料|
|需求单据|选择相关单据|

计划分析-BOM没展出子项

|栏目|说明|
|---|---|
|母件计划订单|选择母件计划订单|
|子件物料|选择子件物料|
|母件BOM|选择母件BOM|

计划分析-供应没有被使用

|栏目|说明|
|---|---|
|物料|选择物料|
|需求单据|选择相关单据|
|供应单据|选择相关单据|

计划分析-分析结果

|栏目|说明|
|---|---|
|行号|显示行号|
|分析项目|显示分析项目|
|异常信息|显示异常信息|
|行动建议|显示行动建议|
|分析结果|显示分析结果|

# 按钮说明

*  分析：分析异常原因。

# 操作说明

*  通过菜单生产制造－>需求计划－>物料需求计划－>计划分析进入该界面；
*  操作步骤
 
   *  第1步：选择分析类型和计划版本。
   *  第2步：选择相关数据。
   *  第3步：点击分析。
