
# 功能描述

计划模板是用来约定计划录入格式的档案，以保证采用以相保同证模板的计录入格式是一致的。

若计划/预测需要拆解/下发到各子计划里,则需要事先定义各子计划的模板,以约束各子计划采用相同的纬度和时格。如部门计划要拆分到各业务员头上，必须先指定各业务员采用相同的计划录入格式，才能按此格式进行拆解和下发。

此外，模板之间还可存在父子层次关系，可用于确定计划合并上传的路径。例如，为部门X计划制定模板1，按此模板制定 X部门的计划A（可以是一个只有格式、没有内容的空计划）。在部门计划模板1下，制定两个子模板1-1和1-2，分别适用 于X部门的业务员1和业务员2的计划。业务员1和业务员2分别按照子模板1-1和1-2规定的格式制定各自的计划A1和A2。业务员按照模板间的父子关系路径往上追溯，分别将计划A1和A2上传到X部门的计划A里进行合并，部门X在合并后的A计划 里进行修正，形成正式部门计划。

# 业务规则

*  启用需求计划系统（必做）
*  定义组织
*  如未做特别说明，则计划模板画面中各栏目遵循如下规则：
 
   *  计划的状态对画面栏目的约束：
   
      *  若当前模板为Open状态，则可随便修改
      *  若当前模板已Cancel，则不能做任何操作
      *  若当前模板已核准，且已被计划引用、或被下层模板引用，则模板不可弃审和修改
      *  若当前模板已核准，但还未被计划或其他模板引用，则模板可弃审后再修改
   *  对模板内容的修改约束：若当前模板有父模板，则
   
      *  只能在父模板的纬度基础上加纬度、不能减纬度。
      *  当前模板的时栅只能小于或等于父模板的时栅。
      *  当前模板的每个分期不能跨父模板的多个分期。
      *  模板之间不能形成死循环，如A的父模板是B，B的父模板是C，C的父模板是A 。

# 栏目说明

计划模板头--基本页签

|栏目|说明|
|---|---|
|父模板组织/父模板|若模板之间需要形成父子层次关系，则需要指定父模板所在的组织（只能是当前组织或上 级营运组织）及对应的父模板。若计划要做上传/合并，则必须指定其所采用的模板间的父子关系。建立模板时，应该从最顶层模板开始建立，直至最低层模板。若父模板组织不是当前组织，而是上级营运组织，则计划可做跨组织上传/合并。|
|模板编号|录入当前模板的编码,非空|
|模板名称|录入当前模板的名称,非空|
|起始日期/截止日期|确定当前模板所对应计划的起止日期,非空对于没有父模板的计划模板，手工录入，要求[截止日期]>=[起始日期]。对于有父模板的计划模板，有效期等于父模板的有效期，不可改。|
|计划时格|表示计划里每期的间隔期,枚举值:年度，如5年计划里每年做为1个分期，一共5个分期季度，如年度计划里每个季度做为1个分期，一共4个分期月，如年度计划里每个月做为1个分期，一共12个分期周，如月度计划里每周做为一个分期，一共5个分期。此处周指自然周。日，如月度计划里每天做为一个分期，一共30个分期。此时需要在[天数]栏目设定天数值，可以设定3天或N天为一期。绝对日期：表示各计划分期的起止日期由人工确定，此时需在单体行里手工录入各个分期的起止日期；注意:若所选的时格不是“绝对日期”，则系统会依据计划的起止日期与每个分期的 时格，自动生成计划的分期记录，显示在单体中。若[计划时格]为空，则系统会自动清空单体里的记录。|
|天数|仅当[计划时格]=日时，本栏目可编辑且非空，输入正整数表明每个计划分期的天数；|
|分期数|系统维护,当前模板一共包含多少个分期。|
|锁定期|表明采用此模板的计划，在计划核准后，系统日期后多少个分期内的预测值不允许调整。如生产计划提前考虑3个月内的销售预测，若调整3个月内的预测，将严重影响到生产计 划和产能安排，此时可以锁定当前月份、下月、下下月的预测不允许调整。而此时间范围 之后的预测值允许人工调整。若锁定期为0，则表示系统日期后的预测值均可以调整，不做限制。|
|说明|对当前模板的说明。|
|状态|当前模板所处状态，点开链接可看到状态明细信息。|

# 按钮说明

*  操作->终止：将当前模板作废不再使用。此操作影响未来，对于已经采用该模板的计划仍然有效。若当前模板已核准、未终止，则本操作有效，可以通过终止操作弹出终止画面录入终止原因、终止日期，并将其状态改为“终止”；若当前模板处于其它状态或已终止，则当前操作不可用。。
*  操作->联动终止：此操作将作废当前模板及其所有下层模板，往下遍历直至已终止的子模板或最底层子模板。
*  操作->物料限定：可限定引用此模板的计划，只能录入哪些物料的预测。
*  如，部门1只负责A、B、C三个物料，不负责其他物料，则可以在部门1适用的计划模板里限定只允许录这些料。
*  后续处理->创建子模板：创建当前模板的下层子模板。当前操作只是一项便捷录入方式。只有当前模板已核准、未终止才能使用此项功能。当前操作和复制效果类似，只是将当前模板作为新模板的父模板，清除新模板的模板编码、模板名称、说明、状态信息，其他内容全部复制到新模板里（包括纬度值限定信息）。
*  追溯查询->子模板：查看当前模板的直接下层模板
*  追溯查询->引用计划：查看引用了当前模板的计划

# 操作说明

*  通过菜单生产制造－>需求计划－>生产计划－>计划模板进入该界面；
*  操作步骤
 
   *  第1步：维护模板编码和模板名称等信息。
   *  第2步：维护模板分期行等信息。
   *  第3步：点击保存。
