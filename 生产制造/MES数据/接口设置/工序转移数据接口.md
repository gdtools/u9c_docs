
# 功能描述

获取生产订单的工序数量数据

# 业务规则

*  启用工序委外系统（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|生产订单|获取工序数量的生产订单单号|
|料品|获取工序数量的生产订单料品|
|工序|获取工序数量的生产订单工序|
|业务日期|获取工序数量的生产订单业务日期|
|业务类型|获取工序数量的生产订单业务类型|
|数量|获取工序数量的生产订单数量|
|计量单位|获取工序数量的生产订单计量单位|
|业务部门|获取工序数量的生产订单业务部门|
|项目|获取工序数量的生产订单项目|
|是否首序|获取工序数量的工序是否首序|
|是否末序|获取工序数量的工序是否末序|


# 按钮说明

*  接口取数：从第三方系统获取工时数据。

# 操作说明

*  通过菜单生产制造－>工序委外管理－>接口设置－>工序转移数据接口进入该界面；
*  操作步骤
 
   *  第1步：点击生产制造－>工序委外管理－>接口设置－>工序转移数据接口进入维护主界面。
   *  第2步：点击接口取数按钮。
   *  第3步：选择时间范围。
   *  第4步：点击确定按钮。
