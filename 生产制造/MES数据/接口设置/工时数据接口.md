
# 功能描述

获取生产订单的工时数据

# 业务规则

*  启用工序委外系统（必做）

# 栏目说明

列表栏目

|栏目|说明|
|---|---|
|生产订单|工时数据对应的生产订单编码|
|料品|工时数据对应的生产订单料品|
|工序号|工时数据对应的生产订单工序号|
|业务日期|工时数据对应的生产订单业务日期|
|工时类型|工时数据对应的生产订单工时类型|
|总工时|工时数据对应的生产订单总工时|
|工时单位|工时数据对应的生产订单工时单位|
|业务部门|工时数据对应的生产订单业务部门|


# 按钮说明

*  接口取数：从第三方系统获取工时数据。

# 操作说明

*  通过菜单生产制造－>工序委外管理－>接口设置－>工时数据接口进入该界面；
*  操作步骤
 
   *  第1步：点击生产制造－>工序委外管理－>接口设置－>工时数据接口进入维护主界面。
   *  第2步：点击接口取数按钮。
   *  第3步：选择时间范围。
   *  第4步：点击确定按钮。
