
# 功能描述

主要用于查询数据同步的执行情况。

# 业务规则

*  启用工序委外系统（必做）。
*  执行了数据同步。

# 操作说明

*  通过菜单生产制造－>工序委外管理－>接口设置－>数据接口同步日志查询进入该界面；
*  操作步骤
 
   *  第1步：点击生产制造－>工序委外管理－>接口设置－>数据接口同步日志查询进入主界面。
   *  第2步：点击查询按钮。
   *  第3步：输入查询条件。
   *  第4步：点击确定按钮。
