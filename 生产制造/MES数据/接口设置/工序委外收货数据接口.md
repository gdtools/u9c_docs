
# 功能描述

获取生产订单的委外工序的收货数据

# 业务规则

*  启用工序委外系统（必做）

# 栏目说明

列表栏目

|栏目|说明|
|---|---|
|生产订单|工序委外收货数据的生产订单编码|
|料品_品名|工序委外收货数据的生产订单料品_品名|
|工序|工序委外收货数据的生产订单工序|
|业务日期|工序委外收货数据的生产订单业务日期|
|业务类型|工序委外收货数据的生产订单业务类型|
|废品原因|工序委外收货数据的废品原因|
|数量|工序委外收货数据的数量|
|金额|工序委外收货数据的金额|
|委外供应商|工序委外收货数据的委外供应商|
|委外部门|工序委外收货数据的委外部门|
|已处理|已处理|


# 按钮说明

*  接口取数：从第三方系统获取工时数据。

# 操作说明

*  通过菜单生产制造－>工序委外管理－>接口设置－>工序委外收货数据接口进入该界面；
*  操作步骤
 
   *  第1步：点击生产制造－>工序委外管理－>接口设置－>工序委外收货数据接口进入维护主界面。
   *  第2步：点击接口取数按钮。
   *  第3步：选择时间范围。
   *  第4步：点击确定按钮。
