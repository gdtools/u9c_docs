
# 功能描述

期间关账主要用于控制特定期间内是否可以进行工序委外相关的业务操作。

# 业务规则

*  启用工序委外系统（必做）
*  需要取消关账期间未月结。

# 栏目说明

期间关账

|栏目|说明|
|---|---|
|会计年度|需要进行关账操作的会计年度。默认为当前系统日期对应的会计期间的会计年度。可以根据录入的会计年度刷新会计期间。|
|显示期间|需要进行关账操作的会计期间。需要选择会计期间进行关账。|
|是否关闭|关账执行成功后回写已关账标识。未关账时为空白。关账成功后打标记。|
|关账日期|执行关账操作的日期。|
|关账人|执行关账操作的业务员。|


# 按钮说明

*  期间关账-关账：期间关账成功后，已关账期间不能进行工序委外相关业务操作。
 
   *  操作前提
   
      *  确定关账期间不再有业务发生。
   *  操作步骤
   
      *  点击工序委外管理－>期间关账－>关账按钮。具体步骤如下所示。
      *  第1步：录入会计年度。
      *  第2步：选择会计期间。
      *  第3步：单击关账按钮。
      *  第4步：确认关账是否成功。
*  期间关账-取消关账：取消关账后，取消关账的期间可以继续补录业务单据。
 
   *  操作前提
   
      *  需要取消关账期间未月结。
   *  操作步骤
   
      *  点击工序委外管理－>期间关账－>关账按钮。具体步骤如下所示。
      *  第1步：录入会计年度。
      *  第2步：选择会计期间。
      *  第3步：单击取消关账按钮。
      *  第4步：确认取消关账是否成功。

# 操作说明

*  通过菜单生产制造－>工序委外管理－>结算处理－>期间关账进入该界面；
*  操作步骤
 
   *  第1步：点击生产制造－>工序委外管理－>结算处理－>期间关账进入维护主界面。
   *  第2步：录入会计年度。
   *  第3步：选择会计期间。
   *  第4步：单击关账按钮。
   *  第5步：确认关账是否成功。
