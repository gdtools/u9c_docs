
# 功能描述

对组织内的工艺路线进行创建、修改、删除。

工艺路线用于定义生产制造某一产品所需要明细信息。包括需要执行的工序（或作业）、次序、工作中心、标准准备工时及加工工时等。在有些公司，工艺路线也包括工具、操作者技术水平、检验工序及测试设备等。也叫工序清单、操作指令表。

# 关键应用

*  对工艺路线进行组织间下发
*  对工艺路线按不同的审批方式进行审批
*  查看共享料品的工艺路线
*  查看通过ECN创建的工艺路线
*  对可进行现场更新的工艺路线进行现场工艺的更新

# 业务规则

提前定义：

*  参数设定，与工艺路线相关参数
*  定义料品
*  定义生产目的（可选）
*  定义单位
*  定义生产线（可选）
*  定义项目（可选）
*  定义作业（可选）
*  定义工作中心
*  定义存储地点（可选）
*  定义库位（可选）
*  定义检验方案（可选）

# 操作说明

*  工序资源

维护所选工序的资源。

操作步骤：点击【工序资源】按钮，即弹出工序资源设置窗口，可在窗口中维护工序资源。

|**栏目名称**|**说明**|
|---|---|

*  替代资源

可以为工艺路线工序资源定义替代资源。

操作步骤：点击【资源】按钮，即弹出资源设置窗口，点击【替代资源】按钮可在窗口中维护工艺路线的资源的替代资源。

具体栏目说明请参考资源设置。

*  下发参数

若工艺路线欲进行下发，则应先设置下发参数。

操作步骤：点击【下发参数】按钮，即弹出下发参数设置窗口，可在窗口中维护工艺路线的下发参数。

具体请参见下发参数设置

*  下发

对所选的工艺路线进行下发

操作步骤：点击【后续处理－下发】按钮，即弹出下发窗口，选择组织后，下发。

*  审核参数

对工艺路线的审核方式等进行设置。

操作步骤：点击【后续处理－审核参数】按钮，即弹出审核参数设置窗口，可在窗口中维护工艺路线的审核参数。

具体请参见审核参数设置

*  现场变更

对工艺路线进行修改操作后，若本次修改会引起现场工艺的变更，则可通过现场更新操作进行现场工艺的更新。

操作步骤：点击【后续处理－现场变更】按钮，即弹出相关生产订单列表，选择要进行变更的订单，点击【变更】按钮后即完成相关订单的工艺更新。
