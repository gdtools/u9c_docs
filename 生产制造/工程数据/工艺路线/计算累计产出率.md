
# 功能描述

计算选定物料的：【物料档案】.【损耗率】，以及这些物料对应所有工艺路线的：【工艺路线】.【累计工序产出率】。

# 关键应用

无

# 业务规则

无

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|从料品分类|如果计算范围按物料分类确定，输入从物料分类，到物料分类；如果输入从物料分类到物料分类则不能输入从物料/到物料；可以为空，为空表示全部|
|到料品分类|如果计算范围按物料分类确定，输入从物料分类，到物料分类；如果输入从物料分类到物料分类则不能输入从物料/到物料；可以为空，为空表示全部|
|从料品|如果计算范围按物料确定，输入从物料，到物料；如果输入从物料到物料则不能输入从物料分类到物料分类；可以为空，为空表示全部|
|到料品|如果计算范围按物料确定，输入从物料，到物料；如果输入从物料到物料则不能输入从物料分类到物料分类；可以为空，为空表示全部|
|生效日期|缺省带入当天日期，可以修改；用于判断工艺路线等的生效日期|
|更新料品损耗率|Y覆盖（用新的计算结果直接替换原来的数据）（缺省为Y）；N不覆盖（保留原值不变）|

# 操作说明

*  执行

立即执行累计产出率计算。

操作步骤：点击【执行】按钮，执行累计产出率计算。

*  调度

对本次累计产出率计算进行调度设置。

操作步骤：点击【调度】按钮，即弹出调度设置窗口，对本次累计产出率计算进行调度设置

栏目说明同标准调度。
