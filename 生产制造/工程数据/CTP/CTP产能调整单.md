
# 功能描述

用于人工调整CTP资源的产能状况，目前只能调整资源的总能力。

# 关键应用

无

# 业务规则

提前定义：

*  执行了<CTP产能编译>功能

# 栏目说明

产能调整单：

|**栏目名称**|**说明**|
|---|---|
|单据类型|调整单的单据类型|
|单号|受单据类型控制，可自动编号也可手工输入；必填|
|调整原因|企业自定义的调整原因|
|状态|默认为开立，系统自动维护|

产能调整单明细：

|**栏目名称**|**说明**|
|---|---|
|资源|要调整的资源|
|起始日期|支持两种产能调整方式：调整单个日期的产能：开始日期等于结束日期；调整一段日期的产能：结束日期大于开始日期，此时调整产能表示在起始与结束日期范围内每天要调整的产能；开始日期必须大于等于当前日期，结束日期必须大于等于起始日期|
|结束日期||
|调整产能|可正可负，正数表示增加总能力，负数表示减少总能力；减少总能力时，不能少于已占用的能力|
|产能单位||

# 按钮说明

无

# 操作说明

*  审核

审核调整单，只有审核成功了才能更新资源的总能力。

审核时，如果调整后的总能力小于已占用能力，则审核失败。

*  弃审

弃审调整单，只有弃审成功了才能更新资源的总能力。

弃审时，如果调整后的总能力小于已占用能力，则弃审失败。
