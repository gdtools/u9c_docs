
# 功能描述

用户手工定义CTP物料的资源清单或调整系统自动产生的资源清单。

# 关键应用

无

# 业务规则

提前定义：

*  定义CTP物料
*  定义CTP资源
*  执行了<生成CTP资源清单>功能（可选）

# 栏目说明

CTP资源清单：

|**栏目名称**|**说明**|
|---|---|
|物料|只能选择CTP物料,必填|
|批量|默认为1；资源的用量是基于该批量的标准用量；如果为自动产生的数据，则不允许修改|
|生产单位|默认为物料档案的生产单位，必填；资源的用量是基于该生产单位的标准用量。例如：批量=1，生产单位=KG，则表示在生产1KG成品/半成品时CTP资源的标准耗用量；如果为自动产生的数据，则不允许修改|

CTP资源清单明细：

|**栏目名称**|**说明**|
|---|---|
|工序号|表示资源所属的工序，默认为10|
|资源序号|表示资源投入的先后顺序|
|资源|表示生产需要投入的资源；只能选择当前组织有效的CTP资源|
|资源用量|表示在生产批量单位物料时的标准耗用量|
|用量单位|目前只能选择时间类型的单位|
|计算基础|表示资源的用量和生产数量的关系，有两个选择：料品：表示资源的用量与生产数量有关。例如：生产1个物料需要2小时，则生产10个物料就需要20个小时。批次：表示资源的用量是固定的，与生产数量无关。例如：生产1个物料需要2小时，则生产10个物料还是2小时|
|资源数量|表示在生产时必须要同时投入的资源数量|
|来源料品|表示资源的来源物料。例如：A由B组成，A有CTP资源R1，B有CTP资源R2。则对于A的资源清单来说，有两个CTP资源，一个是R1，来源料品为A，一个是R2，来源料品为B|
|资源组号|如果存在替代资源则在此处录入替代组号。关于资源组号的用法见<[工艺路线维护](http://localhost/U9C/help/zh-CN/Content/MFG/BOM/Function/CBO.MFG.Routing.Routing.htm)>功能中的描述|
