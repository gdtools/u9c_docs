
# 功能描述

## 功能概述

生产期间与我们日常生活中使用的自然日历不同，可以以年为周期，也可以根据生产核算要求以季度、月为周期；生产期间可以是跨自然年度的。

例如：从上一年度的四月一日到本年度的三月三十一日为一个生产期间。

## 功能说明

*  无

# 业务规则

*  生产期间的应用非常灵活，在应用系统进行生产核算工作之前，应设置好组织使用的各类生产期间；

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**基本信息**|
|编码|录入生产期间编码|
|名称|录入生产期间名称|
|期间类型|录入生产期间的期间类型系统提供以下期间类型供选择：年：以一年划分为一个生产期间；季：以一个季度划分为一个生产期间；月：以一个月划分为一个生产期间；四周：以四周划分为一个生产期间；周：以周划分为一个生产期间；日：以每天划分为一个生产期间；|
|工作日历|参照录入生产期间对应的工作日历|
|开始日期|录入一个生产年度的开始日期|
|结束日期|录入一个生产年度的结束日期|
|**行**|
|年度|生产期间所属年度|
|期间号|每个生产年度中的生产期间序号|
|开始日期|每个生产期间的开始日期|
|结束日期|每个生产期间的结束日期|

# 按钮说明

*  <生成生产期间>：点击<生成生产期间>按钮，按照当前生产期间设置，系统自动生成一个生产年度的全部期间；
*  <追加生产期间>：点击<追加生产期间>按钮，系统自动追加一个新生产年度的全部期间；

# 操作说明

一个生产年度的最后一个期间的结束日期不允许修改，其他期间的结束日期允许修改，修改后，系统自动计算下一个期间的开始日期，保持生产期间的连续性。
