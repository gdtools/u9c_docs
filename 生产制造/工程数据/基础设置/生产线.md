
# 功能描述

生产线设置是重复生产的基础设置，用于对组织内的生产线进行定义。

# 关键应用

*  指定生产线所属的部门；
*  指定生产线所用的工作日历；
*  定义生产线的正常产能与理想产能；
*  对生产线的操作点进行定义；
*  定义生产线的生效期间。

# 业务规则

*  需按重复排产的产能对象，定义生产线；
*  根据需要，定义操作点，可为空。

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**基本**|
|编码|手工录入生产线的编码；同一组织下的生产线编码不能重复|
|名称|手工录入生产线的名称|
|部门|生产线所属的部门；参照本组织下的部门档案录入|
|工作日历|生产线所用的工作日历；参照工作日历录入|
|正常产能|正常产能与标准产能的比率|
|理想产能|理想产能与标准产能的比率|
|排产方式|生产线按照哪种排产方式进行排产；可选择产能完全占用/均分|
|**状态**|
|生效|说明该生产线是否是生效的|
|生效日期|当［生效］为“是”时，表示生产线的生效日期，不可大于失效日期|
|失效日期|当［生效］为“是”时，表示生产线的失效日期，不可小于生效日期|
|**操作点**|
|编码|手工录入操作点的编码；同一组织下的操作点编码不能重复|
|名称|手工录入操作点的编码|
|申报点|同一组织下的操作点编码不能重复|
|正常周期下限|定义本操作点的正常周期的下限；不可大于正常周期上限|
|正常周期上限|定义本操作点的正常周期的上限；不可小于正常周期下限|
|时间单位|录入周期的时间单位。|
|显示异常|定义本操作点是否要显示异常信息|

# 按钮说明

*  <追溯查询—料品生产线关系列表>：调用料品生产线关系列表界面，显示与当前生产线有关系的重复件料品；
*  <相关功能—物料清单>：调用物料清单界面；
*  <相关功能—料品生产线关系>：调用料品生产线关系界面。
