
# 功能描述

支持树状维护,即左树右卡片的形式维护物料清单。

*  一个装配件的所有子装配件、部件、零件和原材料的列表。它用于连接主生产计划，以便决定哪些需要采购哪些需要生产；
*  一个生产过程所需要的所有原材料的列表。这个生产过程可能一个产品，也可能作为其它客户的供应商生产部件或者某种成份。在有些流程行业，物料清单也叫做配方、处方或者成份列表。

# 关键应用

*  对组织内的物料清单进行创建、修改、删除；
*  对物料清单进行组织间下发；
*  对物料清单按不同的审批方式进行审批；
*  查看共享料品的BOM；
*  查看通过ECN创建的BOM；
*  对可进行现场更新的BOM进行现场备料的更新；
*  对BOM进行成本模拟。

# 相关参数

|**参数代码**|**参数名称**|**注释**|
|---|---|---|
|BOM006|BOM子项项次初始值|新增BOM时，第一行项次的默认值，可以修改为1－100以内的整数|
|BOM007|BOM子项项次自动增长步长|新增BOM时，新增行项次的缺省的增加值。可以修改为1－100以内的整数。系统按照上一行的项次＋步长确定本行的项次|
|BOM015|BOM维护是否权限控制|枚举值：True：要按照权限针对不同操作员设定的不同权限，决定操作员可执行的BOM操作；False：不进行权限控制；系统默认值为“True”|
|BOM016|是否维护采购件BOM|枚举值：True：可对采购料品维护其BOM；False：采购件不可维护BOM；系统默认值为“True”|
|BOM017|BOM最大阶数|控制BOM的最大阶数（考虑多组织），可以设为5－99的正整数|
|BOM019|是否允许副产品产出|枚举值：True：可在BOM母项多产品产出页签维护联副产品记录False：不可维护联副产品记录。系统默认值为“True”|
