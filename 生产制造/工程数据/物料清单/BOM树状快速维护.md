
# 功能描述

## 功能概述

考虑到用户在查看BOM结构的同时,快速、方便的维护物料清单，工程数据模块新增BOM树状快速维护功能界面，其功能特点如下所示：

*  采用平台最新JMF框架实现，操作效率会有显著提升。
*  UI显示字段做了精简，只保留必填项或重要字段（其它字段可以通过个性化配置）。
*  BOM子项明细页面新增全屏显示功能。
*  备注字段新增全屏显示功能。

# 操作说明

*  BOM子项明细全屏展示，具体步骤如下所示：
 
   *  第1步：保证当前鼠标焦点在BOM子项上（即使用鼠标随意选择一个BOM子项）。
   *  第2步：在键盘上点击Ctrl+↑键，则BOM子项全屏展示；在键盘上点击Ctrl+↓键，则BOM子项显示还原。
*  BOM备注字段全屏展示，具体步骤如下所示：
 
   *  第1步：保证当前鼠标焦点在BOM备注字段。
   *  第2步：在键盘上点击Ctrl+↑键，则BOM备注字段全屏展示；在键盘上点击Ctrl+↓键，则BOM备注字段显示还原。
