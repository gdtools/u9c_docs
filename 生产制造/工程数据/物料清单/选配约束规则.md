
# 功能描述

选配约束规则定义配置选项之间的约束规则；

选配时检查选配结果是否满足“选配约束规则”；

可对选配约束规则进行组织间下发。

# 关键应用

*  无

# 业务规则

*  先定义模型件BOM；
*  包含规则： 指在产品选配的过程中，由于已经选择了某一选项而必须选择另外一个选项的规则。比如，用户选择了英文操作系统，则只能选择英文操作手册；
*  排斥规则：指在产品选配的过程中，由于已经选择了某一选项而不能选择另外一个选项的规则。比如，某家具供应商制造橡木、松木、桃木家具，如果某客户选择了松木桌面，则不能选择橡木桌腿。

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**基本信息**|
|规则编码|手工录入；非空；同一模型件＋BOM版本的规则编码不可重复|
|规则名称|录入规则的名称|
|料品.版本|参照模型件及BOM版本录入；非空|
|生效日期|录入规则的生效日期，不可大于失效日期|
|失效日期|录入规则的失效日期，不可小于生效日期|
|**条件区**|
|条件编码|系统给定；可改；非空；|
|关系|选择本条件和上一条件的关系；同一选配规则编码下，可以有多个条件，不同条件之间支持“与”“或”逻辑关系；只有第一个选配条件的关系可以为空，其他条件必须指定关系|
|左括号|选择；默认为空|
|BOM母项|参照基本信息中物料的BOM及其下级的模型件、选项类录入；非空|
|版本号|参照BOM母项的版本录入；非空|
|约束类型|选择母项是包含还是排斥子项|
|BOM子项|参照BOM母项的子项录入；非空|
|版本号|参照BOM子项的版本录入；非空|
|右括号|选择；与左括号需成对出现。|
|**约束规则明细区**|
|行号|系统给定；|
|BOM母项|参照基本信息中物料的BOM及其下级的模型件、选项类录入；非空|
|版本号|参照BOM母项的版本录入；非空|
|约束类型|选择母项是包含还是排斥子项|
|BOM子项|参照BOM母项的子项录入；非空|
|版本号|参照BOM子项的版本录入；非空|

# 按钮说明

*  <下发参数>：定义下发参数，确定各字段的下发规则；
*  <后续处理—下发>：执行下发；
*  <后续处理—取消下发>：取消下发；

# 操作说明[]()

*  下发参数

若欲对选配约束规则进行下发，则应先设置下发参数。

操作步骤：点击<下发参数>按钮，即弹出下发参数设置窗口，可在窗口中维护选配约束规则的下发参数。

具体请参考下发参数设置；

*  下发

对所选的选配约束规则进行下发；

操作步骤：点击<后续处理—下发>按钮，即弹出下发窗口，选择组织后，下发。
