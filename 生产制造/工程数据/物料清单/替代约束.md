
# 功能描述

定义替代物料之间的约束规则。

# 关键应用

*  替代时检查替代结果是否满足“替代约束规则”；
*  可对替代约束规则进行组织间下发；
*  包含规则： 指在物料替代的过程中，由于已经选择了某一替代物料而必须选择另外一个替代物料的规则；
*  强制：则当满足替代条件时，替代约束必须起作用；

# 业务规则

*  提前定义BOM子项的替代件
*  建议用<成组替代>代替<替代约束>

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**基本信息**|
|BOM母件|母件名称，手工录入，参照已经建立BOM的物料，选择后代入物料编码，名称/BOM版本/替换类型/批量/单位/生产线|
|版本号|BOM版本|
|生产目的|BOM的生产目的|
|批量|BOM批量|
|单位BOM生产单位|BOM生产单位|
|BOM生效日期|BOM生效日期|
|BOM失效日期|BOM失效日期|
|规则名称|录入规则的名称|
|生效日期|录入规则的生效日期，不可大于失效日期|
|失效日期|录入规则的失效日期，不可小于生效日期|
|**约束条件区**|
|条件编码|系统给定；可改；非空；|
|关系|选择本条件和上一条件的关系；同一替代约束规则编码下，可以有多个条件，不同条件之间支持“与”“或”逻辑关系；只有第一个约束条件的关系可以为空，其他条件必须指定关系|
|左括号|选择；默认为空|
|替代子项料品|参照物料编码录入；非空|
|替代条件|替代；|
|替代件料品|参照物料编码录入；非空|
|右括号|选择；与左括号需成对出现|
|**约束规则明细区**|
|行号|手工录入操作点的编码；同一组织下的操作点编码不能重复|
|约束性质|手工录入操作点的编码|
|BOM子项|同一组织下的操作点编码不能重复|
|替代约束|定义本操作点的正常周期的下限；不可大于正常周期上限|
|替代件料品|定义本操作点的正常周期的上限；不可小于正常周期下限|

# 按钮说明

*  <下发参数>：定义下发参数，确定各字段的下发规则；
*  <后续处理—下发>：执行下发；
*  <后续处理—取消下发>：取消下发；

# 操作说明[]()

*  下发参数

若欲对替代约束规则进行下发，则应先设置下发参数。

操作步骤：点击【下发参数】按钮即弹出下发参数设置窗口，可在窗口中维护选配约束规则的下发参数。

具体请参考下发参数设置。

*  下发

对所选的替代约束规则进行下发。

操作步骤：点击【后续处理－下发】按钮，即弹出下发窗口，选择组织后，下发。
