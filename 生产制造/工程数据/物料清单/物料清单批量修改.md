
# 功能描述

若BOM中的一个或多个属性值在多个BOM中都需要修改时，可执行BOM批量修改功能进行批量修改。

# 关键应用

*  批量修改BOM属性

# 业务规则

*  可在此功能点进行批改的BOM，为物料的［ECN控制］为“否”的BOM；
*  物料的［ECN控制］为“是”的BOM，其批改请在工程变更单功能点进行

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**基本信息**|
|变更对象|选择要修改的具体对象：BOM子项；插件位置；元件厂牌；BOM产出|
|是否增加新版本|设定本次变更的BOM是在原来BOM的基础上修改，还是增加新版本|
|版本生效日期|若［是否增加新版本］为“是”，则设定新版本的生效日期|
|是否报告|设定本次变更是否要生成执行报告|
|**行**|
|行号|系统给定|
|属性名称|参照变更对象的属性录入|
|属性原值|录入当属性等于何值时进行变更|
|属性新值|录入属性变更为何值|

# 操作说明

*  变更范围

选择本次批量变更的范围；

操作步骤：点击【变更范围】按钮，即弹出变更范围窗口，在窗口中表头录入查询条件，点击【查询】按钮后，在表体中列示符合条件的BOM，如果需要增加条件则可以点击【高级查询】按钮后，在表体中列示符合条件的BOM，选择本次要变更的BOM后点【确定】按钮，保存本次变更范围。

*  执行

立即执行变更；

操作步骤：点击【执行】按钮，执行变更功能。

*  调度

对本次批量变更进行调度设置；

操作步骤：点击【调度】按钮，即弹出调度设置窗口，对本次变更进行调度设置；

栏目说明同标准调度；

*  新增子项

选择本次需要添加或删除的BOM子项；

操作步骤：点击【新增子项】按钮，即弹出BOM子项窗口，选择新增或者删除后，在窗口中表头录入需要增加物料，点击【确定】按钮后，保存本次新增或者删除子项的信息。
