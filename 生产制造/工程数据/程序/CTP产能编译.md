
# 功能描述

产生当前组织所有CTP资源在一段时间内每日的总能力。

在更新了工作日历的每日工作小时后，需要重新执行该功能。

# 业务规则

*  定义了工作日历。
*  定义了CTP资源。

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|开始日期|输入编译的开始日期|
|结束日期|输入编译的结束日期|

# 按钮说明

*  <编译>:在执行编译前，必须维护要编译的开始日期、结束日期范围。默认都为系统当前日期。开始日期必须大于等于当前日期。结束日期必须大于等于开始日期。

# 操作说明

*  通过菜单生产制造－>工程数据－>程序－>CPT资源产能编译进入该界面；
*  操作步骤
 
   *  在维护好开始..结束日期之后，点击“编译”按钮，弹出调度画面：
   *  第1步：根据需要，选择【执行一次】或【重复执行】
   *  第2步：若选择【执行一次】，必须录入执行的时间。
   *  第3步：若选择【重复执行】，则选择预设的调度方案进行调度安排。
   *  第4步：点击【确定】，完成调度计划设定。
