
# 功能描述

计算物料的低阶码。

新增或更改主制造物料清单后，各物料的低阶码应重新计算。

# 业务规则

*  已存在定义好的BOM

# 按钮说明

*  <执行操作>:立即执行低阶码推算操作。
*  <调度操作>:按规则设定程序执行时间，由应用服务按时间计划进行执行操作。
*  <检查BOM死循环>:检查BOM中循环定义的物料和BOM。

# 操作说明

*  通过菜单生产制造－>工程数据－>程序－>低阶码推算进入该界面；
*  操作步骤
 
   *  点击调度按钮，弹出时间计划排定页面。具体步骤如下所示。
   *  第1步：根据需要，选择【执行一次】或【重复执行】
   *  第2步：若选择【执行一次】，选择录入执行日期／时间。
   *  第3步：若选择【重复执行】，则选择预设的调度方案进行调度安排。
   *  第4步：点击【确定】，完成调度计划设定。
