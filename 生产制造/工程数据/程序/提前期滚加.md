
# 功能描述

计算选定物料的：

<物料档案>.[固定提前期]

<物料档案>.[变动提前期]

<物料档案>.[累计制造提前期]

<物料档案>.[累计汇总提前期]

以及这些物料对应所有工艺路线的：

<工艺路线>.[固定提前期]

<工艺路线>.[变动提前期]

<工序>.[工序偏置百分比]

<工序资源>.[ 资源偏置百分比]

以及物料生产线关系的：

<物料生产线关系>.[提前期] （只更新提前期类型为“按工艺”的）

同时根据选项更新物料档案的：

<物料档案>.[ 计划时界天数]

<物料档案>.[ 需求时界天数]

<物料档案>.[ 发放时界天数]

# 业务规则

*  定义了物料清单。
*  定义了工艺路线。

# 栏目说明

[提前期滚加－表头](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|组织|缺省为用户登录的当前组织可以参照修改，受权限控制允许为空，为空表示所有组织|
|从料品分类|如果计算范围按物料分类确定，输入从物料分类，到物料分类；如果输入从物料分类到物料分类则不能输入从物料/到物料可以为空，为空表示全部|
|到料品分类|如果计算范围按物料分类确定，输入从物料分类，到物料分类；如果输入从物料分类到物料分类则不能输入从物料/到物料可以为空，为空表示全部|
|从料品|如果计算范围按物料确定，输入从物料，到物料；如果输入从物料到物料则不能输入从物料分类到物料分类可以为空，为空表示全部|
|到料品|如果计算范围按物料确定，输入从物料，到物料；如果输入从物料到物料则不能输入从物料分类到物料分类可以为空，为空表示全部|
|生效日期|缺省带入当天日期，可以修改。用于判断BOM、子项、工序等的生效日期。|
|本层提前期以工艺路线为准|如果等于true，则工艺路线参与提前期的计算，否则料品档案的提前期参与提前期计算|
|是否考虑失效子项|如果等于true，则失效子项也参与提前期计算|
|覆盖原有数据|Y覆盖（用新的计算结果直接替换原来的数据）（缺省为Y）N不覆盖（保留原值不变）|
|同时更新需求时界天数|如果该物料的“需求时界”选择为本层制造提前期／累计制造提前期或者累计汇总提前期，且本选项设置为Y，则同时更新对应物料的“需求时界天数”|
|同时更新计划时界天数|如果该物料的“计划时界”选择为本层制造提前期/累计制造提前期或者累计汇总提前期，且本选项设置为Y，则同时更新对应物料的“计划时界天数”|
|同时更新发放时界天数|如果该物料的“发放时界”选择为本层制造提前期/累计制造提前期或者累计汇总提前期，且本选项设置为Y，则同时更新对应物料的“发放时界天数”|
|报告计算结果|勾选为“是”时，在计算结束后，列表报告计算的结果|

# 按钮说明

*  <生成>:执行生成资源清单操作，生成时会清除上次自动产生的资源清单数据，但保留手工录入的数据。如果编辑了自动产生的资源清单数据则也清除。

# **操作说明**

*  [<执行](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)>:立即执行提前期滚加计算．
 
   *  操作步骤
   
      *  点击执行按钮，立即执行提前期滚加计算。
*  [<调度](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)>:弹出调度画面：
 
   *  操作步骤
   
      *  第1步：根据需要，选择【执行一次】或【重复执行】。
      *  第2步：若选择【执行一次】，必须录入执行的时间。
      *  第3步：若选择【重复执行】，则选择预设的调度方案进行调度安排。
      *  第4步：点击【确定】，完成调度计划设定。

# 操作说明

*  通过菜单生产制造－>工程数据－>程序－>提前期滚加进入该界面；
*  操作步骤
 
   *  根据实际情况，维护好生成参数并点击“调度”，弹出调度画面：
   *  第1步：根据需要，选择【执行一次】或【重复执行】。
   *  第2步：若选择【执行一次】，必须录入执行的时间。
   *  第3步：若选择【重复执行】，则选择预设的调度方案进行调度安排。
   *  第4步：点击【确定】，完成调度计划设定。
