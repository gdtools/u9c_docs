
# 功能描述

提供工艺路线的打印。

# 业务规则

*  建立工艺路线

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织|打印指定组织的工艺路线可为当前组织及参照<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|生产目的|打印指定生产目的的工艺路线选择生产目的录入可空；|
|料品分类|打印指定料品分类的工艺路线参照料品分类档案录入可空；|
|料品|打印指定料品的工艺路线参照料品档案录入可空；|
|版本类型|打印指定版本类型的工艺路线选择录入：最新版本/初始版本/全部版本/指定版本非空|
|工艺版本|当版本类型为“指定版本”时，录入工艺的版本：录入非空|
|生效日期|打印此日期条件生效的工艺路线录入可空|
|ECN编码|依据ECN单号进行工艺路线打印参照ECN单号录入可空|
|生产线|对重复件的工艺，只打印指定生产线的工艺路线参照生产线档案录入可空|
|项目|打印指定项目的工艺路线参照项目档案录入可空；|
|货主组织|打印指定货主组织的工艺路线参照组织录入可空；|
|是否包含工序资源|选择在打印时，是否要打印工序资源的信息|

# 操作说明

*  通过菜单生产制造－>工程数据－>报表－>工艺打印进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件；
   *  第2步：点击确定按钮。
