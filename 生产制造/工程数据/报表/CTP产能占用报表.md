
# 功能描述

对CTP资源的产能使用状况进行查询。

# 业务规则

*  执行了CTP计算。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织|表示查看哪个组织的CTP资源的产能使用状况，默认为当前组织，必填。　只能选择工厂组织。|
|资源|表示只查询特定资源的产能使用状况，可空。|
|时格|表示按时格定义的时间维度汇总资源的产能信息，必填。|

# 按钮说明

*  <资源>:在主画面中点击“资源”列则弹出“CTP产能占用-明细”画面。在该画面按时格维度汇总该资源的能力信息。
*  <开始日期>:在“CTP产能占用-明细”画面中点击“开始日期”则弹出“CTP产能占用-需求”画面。在该画面详细列出在明细画面当前行的开始..结束日期内产能占用的详细信息。即哪些销售订单占用了产能。

# 操作说明

*  通过菜单生产制造－>工程数据－>报表－>CPT产能占用报表进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件；
   *  第2步：点击确定按钮。
