
# 功能描述

提供产品结构的查询。

# 业务规则

*  建立物料清单

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织|默认是当前组织非空|
|料品|当前组织的物料非空|
|生产目的|指定生产目的的物料清单选择生产目的录入默认=主制造非空|
|BOM版本|参照录入BOM的版本非空|
|主批量|默认=true|
|批量|默认=1如果主批量=false,必须输入|
|BOM类型|分为自制和委外非空|
|日期|此日期条件生效的物料清单录入可空|
|项目|参照项目可空|
|显示子项范围|默认=当前有效可选|
|子项类型|默认为空可选标准、替代、替换|
|替代件|是否要显示子件替代件的信息|
|显示厂牌|是否要显示子件元件厂牌的信息默认为否|
|显示插件位置|是否要显示子件插件位置的信息|
|显示多产品产出|是否显示BOM中的联产品或副产品|
|展开阶数|输入默认=1.|
|状态|默认为空可选开立、审核中、已核准|

# 操作说明

*  通过菜单生产制造－>工程数据－>报表－>产品结构进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件；
   *  第2步：点击确定按钮。
