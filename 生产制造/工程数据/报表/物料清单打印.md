
# 功能描述

提供物料清单的打印。

# 业务规则

*  建立物料清单

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织|打印指定组织的物料清单　可为当前组织及参照<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|生产目的|打印指定生产目的的物料清单选择生产目的录入可空；|
|料品分类|打印指定料品分类的物料清单参照料品分类档案录入可空；|
|料品|打印指定料品的物料清单参照料品档案录入可空；|
|版本类型|打印指定版本类型的物料清单选择录入：最新版本/初始版本/全部版本/指定版本非空|
|BOM版本|当版本类型为“指定版本”时，录入BOM的版本：录入非空|
|生效日期|打印此日期条件生效的物料清单录入可空|
|ECN编码|依据ECN单号进行物料清单打印参照ECN单号录入可空|
|是否包含等级成分产出比例|选择在打印时，是否要打印多产品产出的信息|
|是否包含替代件|选择在打印时，是否要打印子件替代件的信息|
|是否包含元件厂牌|选择在打印时，是否要打印子件元件厂牌的信息|
|是否包含插件位置|选择在打印时，是否要打印子件插件位置的信息|
|是否包含工艺选配|选择在打印时，是否要打印子件工艺选配的信息|

# 操作说明

*  通过菜单生产制造－>工程数据－>报表－>物料清单打印进入该界面；
*  操作步骤
 
   *  第1步：输入查询条件；
   *  第2步：点击确定按钮。
