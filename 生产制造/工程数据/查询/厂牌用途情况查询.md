
# 功能描述

查询某厂牌的物料应用于哪些产品。

也可以不指定物料查询某“厂牌”的所有物料应用于哪些产品。

# 业务规则

*  维护物料清单

# 栏目说明

[厂牌用途](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)-[查询条件](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|厂牌|要查询的厂牌参照供应商档案录入。非空；|
|子件料品|可查询指定子件的用途参照料品档案录入可空；|
|料品版本号|可指定料品版本进行查询录入可空；|
|生效日期|非空时，只查询在指定日期生效的厂牌用途录入可空；|

[栏目设置](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|组织|显示母项所属的组织|
|BOM母项|显示所属BOM母项的料品料号|
|版本号|显示BOM母项的版本号|
|生产目的|显示BOM母项的生产目的|
|子件项次|显示用到指定厂牌的子项的项次|
|优先顺序|显示用到指定厂牌的子项的优先顺序|
|子件料号|显示用到指定厂牌的子项料号|
|版本号|显示子项的版本号|
|用量类型|显示子件的用量类型|
|子件用量|显示子件的用量|
|发料单位|显示子件的发料单位|
|厂牌.编码|显示厂牌的编码|
|厂牌.名称|显示厂牌的名称|
|数量百分比|显示子件用到这一厂牌的数量百分比|

*  通过菜单生产制造－>工程数据－>查询－>厂牌用途情况查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
