
# 功能描述

正向查询物料的多层结构。

# 业务规则

*  维护物料清单

# 栏目说明

单阶结构-查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品|要查询的BOM的料品参照料品档案录入非空；|
|生产目的|要查询的BOM的生产目的选择生产目的录入可空；|
|版本号|要查询的BOM的BOM版本录入可空|
|批量|要查询的BOM的批量手工录入可空|
|单位|要查询的BOM的单位参数计量单位录入可空|
|生产线|要查询的BOM的生产线参照生产线录入可空|
|生效日期|非空时，按此生效日期展开子件录入可空；|

# 按钮说明

*  <插件位置>：用于查询子件的插件位置情况。
 
   *  操作步骤
   
      *  点击插件位置按钮，在弹出窗口中即可看到选中子件的插件位置列表。
*  <元件厂牌>：用于查询子件的元件厂牌情况。
 
   *  操作步骤
   
      *  点击元件厂牌按钮，在弹出窗口中即可看到选中子件的元件厂牌列表。
*  <批量用量>：用于查询子件的批量用量情况。
 
   *  操作步骤
   
      *  点击批量用量按钮，在弹出窗口中即可看到选中子件的批量用量列表。

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>BOM母件结构查询-单阶查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
