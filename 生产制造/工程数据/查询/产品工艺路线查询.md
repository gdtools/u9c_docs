
# 功能描述

查询已经建立的工艺路线、工序、工序资源。

# 业务规则

*  维护物料清单；
*  维护工艺路线。

# 栏目说明

[查询条件](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品|要查询料品参照料品档案录入非空；|
|料品分类|要查询的料品分类参照料品分类录入可空|

[查询结果（工艺路线）](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|组织|显示料品所属的组织|
|料号|显示料品的编码|
|品名|显示料品的名称|
|工艺版本号|显示工艺路线的版本号|
|生产单位|工艺路线的生产单位|
|生产线|工艺路线的生产线|
|项目|工艺路线的项目|
|货主组织|工艺路线的货主组织|
|生效日期|工艺路线的生效日期|
|失效日期|工艺路线的失效日期|

[查询结果（工序）](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|工序号|工序编码|
|工作中心|对应的工作中心|
|工序说明|对工序的描述|
|是否报告产出点|工序是否要报告加工数量、完工数量等信息|
|准备工时|工序的可以开工需要的准备时间|
|加工工时|工序生产完成需要的加工时间|
|时间单位|加工的时间单位|

[查询结果（工序资源）](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|资源顺序|流水号，资源在工序的顺序|
|资源类型|资源的类型，是人工、机器还是其他等类型|
|资源的用量计算基础|资源的用量基础是以料品还是批次|
|每资源用量|每个资源所需要的用量|
|资源计费基础|决定资源的缺省分摊基础，是料品数量、还是批量等|

排序条件

根据所选栏目进行排序（升序／降序）

# 按钮说明

*  <工艺路线>：导航到[工艺路线](/detail/9afe2a379fba4ab0a4fed3c49bdb2b5a)界面。

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>工艺路线查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
