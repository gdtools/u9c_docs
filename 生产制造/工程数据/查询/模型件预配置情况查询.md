
# 功能描述

查询模型BOM的派生情况。

# 业务规则

*  维护物料清单；
*  维护工艺路线。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品|要查询料品参照料品档案，料品形态属性=模型件录入非空；|
|版本号|要查询料品的料品版本手工录入可空|

查询结果

|栏目名称|说明|
|---|---|
|组织|显示最终产品BOM母件所属的组织|
|BOM母件.料号|显示最终产品BOM母件的料品料号|
|BOM母件.料品名称|显示最终产品BOM母件的料品名称|
|BOM版本号|BOM版本号|
|生产单位|显示BOM的生产单位|
|批量|显示BOM的批量|
|组织|显示模型BOM母件所属的组织|
|模型BOM母件.料号|显示模型BOM母件的料品料号|
|模型BOM母件.料品名称|显示模型BOM母件的料品名称|
|模型BOM版本号|模型BOM版本号|
|模型BOM.生产单位|显示模型BOM的生产单位|

排序条件

根据所选栏目进行排序（升序／降序）

# 按钮说明

*  <工艺路线>：导航到[工艺路线](/detail/9afe2a379fba4ab0a4fed3c49bdb2b5a)界面。
*  <多阶查询>：导航到[母件结构查询-多阶](/detail/0a032713881e4be5b5c0370c0ac90ca9)界面。

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>模型件预配置查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
