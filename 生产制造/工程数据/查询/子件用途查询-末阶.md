
# 功能描述

查询某一指定子件被用在哪些最终产品上。

# 业务规则

*  维护物料清单。

# 栏目说明

子件用途末阶查询-查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品|要查询料品参照料品档案录入非空；|
|版本|要查询料品的料品版本手工录入可空|
|项目|要查询料品的项目参照项目档案可空|
|生效日期|按此生效日期进行过滤，即只显示在此日期，子件料品被用于哪些最终产品录入非空；|

栏目设置

|栏目名称|说明|
|---|---|
|组织|显示最终产品BOM母件所属的组织|
|BOM母件|显示最终产品BOM母件的料品品名|
|版本|显示BOM版本号|
|生产目的|显示BOM的生产目的|
|项目|显示BOM的项目|
|货主组织|显示BOM的的货主组织|
|BOM子项|显示子件的料品|
|版本|显示子件的版本号|
|用量|显示子件用于此最终产品的汇总用量|
|单位|显示子件的发料单位|


排序条件

根据所选栏目进行排序（升序／降序）

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>子件用途末阶查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
