
# 功能描述

查询某工作中心所涉及到的工序。

# 业务规则

*  维护物料清单；
*  维护工艺路线。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|生产目的|要查询工艺路线的生产目的从生产目的枚举中选择可空；|
|工作中心|要查询的工作中心参照工作中心非空；|
|显示替代资源|如果等于true则显示工作中心的替代资源，否则不显示|

查询结果（工艺路线）

|栏目名称|说明|
|---|---|
|组织|显示工艺路线所属的组织|
|料号|显示工艺路线料品编号|
|品名|显示工艺路线料品名称|
|工艺版本|工艺路线的版本|
|生产目的|工艺路线的生产目的|
|批量|工艺路线的生产批量|
|单位|工艺路线的生产单位|
|生产线|工艺路线的生产线，只针对物料形态属性是重复件的|
|项目|工艺路线的项目|
|货主组织|工艺路线的货主组织|
|生效日期|工艺路线的生效日期|
|失效日期|工艺路线的失效日期|

查询结果（工序）

|栏目名称|说明|
|---|---|
|工序号|工艺路线的工序号|
|工序说明|工艺路线工序的描述|
|是否报告产出点|工序是否需要报告加工数量等信息|
|准备工时|工艺路线物料该工序下的准备工时|
|加工工时|工艺路线物料该工序下的加工工时|

查询结果（工序资源）

|栏目|说明|
|---|---|
|资源编码|显示资源的编码|
|资源名称|显示资源的名称|
|资源分类|显示资源的类型|
|资源数量|显示资源的数量|

排序条件

根据所选栏目进行排序（升序／降序）

# 按钮说明

*  <工艺路线>：导航到[工艺路线](/detail/9afe2a379fba4ab0a4fed3c49bdb2b5a)界面。

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>工作中心工序查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
