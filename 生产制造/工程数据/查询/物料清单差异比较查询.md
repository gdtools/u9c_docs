
# 功能描述

可比较两个不同物料的BOM差异；

可比较同一物料不同生产目的或不同批量的BOM差异；

可比较同一物料在不同组织间的BOM差异等

# 业务规则

*  维护物料清单

# 栏目说明

物料清单差异比较-查询条件

|栏目名称|说明|
|---|---|
|组织（1）|要查询第一个BOM所在的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品（1）|要查询的第一个BOM的料品参照料品档案录入非空；|
|生产目的（1）|要查询的第一个BOM的生产目的选择生产目的录入非空；|
|BOM版本（1）|要查询的第一个BOM的BOM版本参照BOM版本录入非空|
|批量（1）|要查询的第一个BOM的批量手工录入非空|
|单位（1）|要查询的第一个BOM的单位参数计量单位录入非空|
|生产线（1）|要查询的第一个BOM的生产线参照生产线录入非重复料品时，可空|
|组织（2）|要查询第二个BOM所在的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品（2）|要查询的第二个BOM的料品参照料品档案录入非空；|
|生产目的（2）|要查询的第二个BOM的生产目的选择生产目的录入非空|
|BOM版本（2）|要查询的第二个BOM的BOM版本参照BOM版本录入非空|
|批量（2）|要查询的第二个BOM的批量手工录入非空|
|单位（2）|要查询的第二个BOM的单位参数计量单位录入非空|
|生产线（2）|要查询的第二个BOM的生产线参照生产线录入非重复料品时，可空|
|是否考虑子项项次|选择录入是:同一物料，子项项次不同，按属性不同处理否: 同一物料，子项项次不同，按属性相同处理|
|是否考虑优先顺序|选择录入是:同一物料，优先顺序不同，按属性不同处理否: 同一物料，优先顺序不同，按属性相同处理|
|是否考虑数量|选择录入是:同一物料，数量（单位）不同，按属性不同处理否: 同一物料，数量（单位）不同，按属性相同处理|
|全阶展开|默认=false，如果等于true则汇总后再比较，否则只比较当前BOM|
|比较栏目|默认=显示栏目，按照显示栏目作为比较栏目，否则全部属性|

查询栏目

|栏目名称|说明|
|---|---|
|料品编码|显示子件料品的料品编码|
|料品名称|显示子件料品的料品名称|
|版本|显示子件料品的版本号|
|项次（1）|若此子件料品在第一个BOM中出现，则显示在第一个BOM中的子项项次|
|优先顺序（1）|若此子件料品在第一个BOM中出现，则显示在第一个BOM中的优先顺序|
|数量类型（1）|若此子件料品在第一个BOM中出现，则显示在第一个BOM中的用量类型|
|数量（1）|若此子件料品在第一个BOM中出现，则显示在第一个BOM中的子件用量|
|计量单位名称（1）|若此子件料品在第一个BOM中出现，则显示在第一个BOM中的发料单位名称|
|项次（2）|若此子件料品在第二个BOM中出现，则显示在第二个BOM中的子项项次|
|优先顺序（2）|若此子件料品在第二个BOM中出现，则显示在第二个BOM中的优先顺序|
|数量类型（2）|若此子件料品在第二个BOM中出现，则显示在第二个BOM中的用量类型|
|数量（2）|若此子件料品在第二个BOM中出现，则显示在第二个BOM中的子件用量|
|计量单位名称（2）|若此子件料品在第二个BOM中出现，则显示在第二个BOM中的发料单位名称|
|比较结果|显示比较的结果：只在第一个BOM中出现/只在第二个BOM中出现/两个BOM中属性相同/两个BOM中属性不同|


# 按钮说明

*  <厂牌差异>：用于查询子件的元件厂牌差异情况。
 
   *  操作步骤
   
      *  点击厂牌差异按钮，在弹出窗口中即可看到选中子件的元件厂牌差异情况。

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>子件用途查询-单阶进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
