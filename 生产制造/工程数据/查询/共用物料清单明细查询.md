
# 功能描述

查询指定物料的物料清单被哪些物料共用；

查询指定物料的物料清单是共享哪个物料的；

可进行多组织的查询；

# 业务规则

*  维护物料清单

# 栏目说明

共用物料清单-查询条件

|栏目名称|说明|
|---|---|
|组织|要查询共用物料清单的组织可为当前组织，或参照<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品|指定料品，查其已共享给哪些料品参照料品档案录入可空；|
|共同BOM料品|指定料品，查其是共享哪个料品的物料清单参照料品档案录入可空；|

# 按钮说明

*  <替代件查询>：用于查询子件的替代料品情况。
 
   *  操作步骤
   
      *  点击追溯查询－替代件查询按钮，在弹出窗口中即可看到选中子件的替代件列表。
*  <插件位置>：用于查询子件的插件位置情况。
 
   *  操作步骤
   
      *  点击插件位置按钮，在弹出窗口中即可看到选中子件的插件位置列表。
*  <元件厂牌>：用于查询子件的元件厂牌情况。
 
   *  操作步骤
   
      *  点击元件厂牌按钮，在弹出窗口中即可看到选中子件的元件厂牌列表。
*  <批量用量>：用于查询子件的批量用量情况。
 
   *  操作步骤
   
      *  点击批量用量按钮，在弹出窗口中即可看到选中子件的批量用量列表。
*  <阶梯损耗查询>：用于查询子件的阶梯损耗情况。
 
   *  操作步骤
   
      *  点击追溯查询－阶梯损耗查询按钮，在弹出窗口中即可看到选中子件的阶梯损耗列表。

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>共用物料清单查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
