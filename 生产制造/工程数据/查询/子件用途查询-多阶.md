
# 功能描述

查询某一指定子件被用在零部件及最终产品的详细情况查询。

# 业务规则

*  维护物料清单

# 栏目说明

子件用途多阶查询-查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的料品所在的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空|
|料品|要查询料品参照料品档案录入非空|
|版本|要查询料品的料品版本手工录入可空|
|生效日期|按此生效日期进行过滤，即只显示在此日期，子件料品被用于哪些零部件录入可空|

栏目设置

|栏目名称|说明|
|---|---|
|组织|显示BOM母件所属的组织|
|母件料号|显示BOM母件的料品料号|
|版本号|显示BOM版本号|
|生产目的|显示BOM的生产目的|
|子项料品|显示子件的料品料号|
|版本号|显示子件的版本号|
|用量类型|显示子件的用量类型|
|子件用量|显示子件的用量|
|发料单位|显示子件的发料单位|
|子件项次|显示子件的项次|
|优先顺序|显示子件的优先顺序|
|工序号|显示子件的工序号|

排序条件

根据所选栏目进行排序（升序／降序）

# 按钮说明

*  <替代件查询>：用于查询子件的替代料品情况。
 
   *  操作步骤
   
      *  点击追溯查询－替代件查询按钮，在弹出窗口中即可看到选中子件的替代件列表。
*  <插件位置>：用于查询子件的插件位置情况。
 
   *  操作步骤
   
      *  点击插件位置按钮，在弹出窗口中即可看到选中子件的插件位置列表。
*  <元件厂牌>：用于查询子件的元件厂牌情况。
 
   *  操作步骤
   
      *  点击元件厂牌按钮，在弹出窗口中即可看到选中子件的元件厂牌列表。
*  <批量用量>：用于查询子件的批量用量情况。
 
   *  操作步骤
   
      *  点击批量用量按钮，在弹出窗口中即可看到选中子件的批量用量列表。
*  <阶梯损耗查询>：用于查询子件的阶梯损耗情况。
 
   *  操作步骤
   
      *  点击追溯查询－阶梯损耗查询按钮，在弹出窗口中即可看到选中子件的阶梯损耗列表。

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>子件用途查询-多阶进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
