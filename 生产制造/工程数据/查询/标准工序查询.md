
# 功能描述

即作业查询：

查询已建立的作业。

查询作业的资源，

查询作业被用在哪些工艺路线中；

# 业务规则

*  维护作业
*  维护工艺路线；

# 栏目说明

作业-查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|作业编码|查询某一或某些作业时录入录入可空；|
|描述|按作业的描述进行查询录入可空；|
|工作中心|按作业中的工作中心进行查询时录入录入可空；|
|工作中心分组|按工作中心所属的分组进行查询时录入录入可空；|
|显示替代资源|如果等于true，则显示替代资源，否则不显示替代资源|

查询栏目

|栏目|说明|
|---|---|
|组织|显示作业所属的组织编码|
|作业编码|显示作业编码|
|描述|显示作业的描述|
|工作中心编码|显示执行作业的工作中心编码|
|工作中心名称|显示执行作业的工作中心名称|
|是否生效|显示作业是否生效|
|生效日期|显示作业的生效日期|
|失效日期|显示作业的失效日期|

作业资源-栏目设置

|栏目|说明|
|---|---|
|资源顺序|显示资源的类型|
|资源编码|显示资源的编码|
|资源名称|显示资源的名称|
|资源分类|显示资源的分类|
|资源类型|显示资源的类型|
|资源数量|显示资源的数量|
|数量单位|显示资源的数量单位|
|资源用量|显示资源的用量|
|用量单位|显示资源的用量单位|

排序条件

根据所选栏目进行排序（升序／降序）

作业用途-栏目设置

|栏目|说明|
|---|---|
|料品|显示作业所属工艺路线的料号|
|工艺版本|显示工艺路线的版本号|
|生产目的|显示工艺路线的生产目的|
|工序号|显示作业在工艺路线中的工序号|
|作业|显示作业的编码|
|工序说明|显示工序的说明|
|报告产出点|显示工序是否为报告产出点|
|准备工时|显示工序的准备工时|
|加工工时|显示工序的加工工时|
|时间单位|显示工时的时间单位|

排序条件

根据所选栏目进行排序（升序／降序）

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>标准工序查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
