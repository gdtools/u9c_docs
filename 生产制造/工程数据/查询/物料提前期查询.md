
# 功能描述

查询料品的母项提前期、子项提前期。

# 业务规则

*  维护物料档案；
*  维护物料清单。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品|要查询料品参照料品档案录入非空；|

查询结果（物料提前期）

|栏目名称|说明|
|---|---|
|料号|显示料号|
|料品名称|显示料品名称|
|当前版本|显示料品的当前版本号|
|固定提前期|显示物料的固定提前期|
|变动提前期|显示物料的变动提前期|
|累计制造提前期|显示物料的累计制造提前期|
|累计汇总提前期|显示物料的累计汇总提前期|

查询结果（BOM母项）

|栏目名称|说明|
|---|---|
|组织|显示BOM母件所属的组织|
|料号|显示BOM母件的料品编码|
|品名|显示BOM母件的料品名称|
|版本号|显示BOM版本号|
|BOM生产目的|显示BOM的生产目的|
|批量|显示BOM母项的批量|
|生产单位|显示BOM母项的生产单位|
|生产线|显示BOM母项的生产线|

查询结果（BOM子项）

|栏目|说明|
|---|---|
|层码|显示子项料号所在的层次|
|料号|显示BOM子项的料品编码|
|品名|显示BOM子项的料品名称|
|版本|显示BOM子项的版本号|
|固定提前期|显示BOM子项的固定提前期|
|变动提前期|显示BOM子项的变动提前期|
|累计制造提前期|显示物料的累计制造提前期|
|累计汇总提前期|显示物料的累计汇总提前期|

排序条件

根据所选栏目进行排序（升序／降序）

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>物料提前期查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
