
# 功能描述

可比较两个不同物料的工艺路线差异；

可比较同一物料不同生产目的或不同批量的工艺路线差异；

可比较同一物料在不同组织间的工艺路线差异等。

# 业务规则

*  维护物料清单；
*  维护工艺路线。

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|组织（1）|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品（1）|要查询的第一个BOM的料品参照料品档案录入非空；|
|生产目的（1）|要查询的第一个BOM的生产目的选择生产目的录入非空；|
|工艺版本（1）|要查询的第一个工艺路线的工艺路线版本参照工艺路线版本录入非空|
|批量（1）|要查询的第一个工艺路线的批量手工录入非空|
|单位（1）|要查询的第一个工艺路线的单位参数计量单位录入可空|
|生产线（1）|要查询的第一个工艺路线的生产线参照生产线录入非重复料品时，可空|
|项目（1）|要查询的第一个工艺路线的项目参照项目档案录入可空|
|货主组织（1）|要查询的第一个工艺路线的货主组织参照组织录入可空|
|组织（2）|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品（2）|要查询的第二个工艺路线的料品参照料品档案录入非空；|
|生产目的（2）|要查询的第二个工艺路线的生产目的选择生产目的录入非空|
|工艺路线版本（2）|要查询的第二个工艺路线的工艺路线版本参照工艺路线版本录入非空|
|批量（2）|要查询的第二个工艺路线的批量手工录入非空|
|单位（2）|要查询的第二个工艺路线的单位参数计量单位录入可空|
|生产线（2）|要查询的第二个工艺路线的生产线参照生产线录入非重复料品时，可空|
|项目（2）|要查询的第二个工艺路线的项目参照项目档案录入可空|
|货主组织（2）|要查询的第二个工艺路线的货主组织参照组织录入可空|
|是否考虑隐藏相同属性记录|选择录入是:隐藏相同属性的记录否: 不隐藏相同属性的记录|

查询结果

|栏目名称|说明|
|---|---|
|工序组织|工艺路线工序的工序组织|
|工序号|工艺路线的工序号|
|工作中心|工序对应的工作中心|
|作业|本工序对应的标准工序|
|准备工时（1）|第一个工艺路线物料该工序下的准备工时|
|加工工时（1）|第一个工艺路线物料该工序下的加工工时|
|时间单位（1）|第一个工艺路线物料该工序的时间单位|
|准备工时（2）|第二个工艺路线物料该工序下的准备工时|
|加工工时（2）|第二个工艺路线物料该工序下的加工工时|
|时间单位（2）|第二个工艺路线物料该工序的时间单位|
|比较结果|显示两个工艺路线的工序是否相同|

排序条件

根据所选栏目进行排序（升序／降序）
