
# 功能描述

查询该物料可以替换哪些产品的那些零部件或材料。

支持单阶查询也支持多阶查询。

# 业务规则

*  维护物料清单

# 栏目说明

[替代件用途](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)-[查询条件](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|替代料品|要查询的替代料品参照料品档案录入非空；|
|料品版本|可指定料品版本进行查询录入可空；|
|生产目的|只进行某一生产目的替代件查询选择生产目的录入可空；|
|工程变更编码|工程变更维护的替代件，可按工程变更单编码进行查询手工录入可空|

[栏目设置](http://wangwq/U9C/help/zh-CN/Content/MFG/BOM/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|组织|显示替代料品的组织|

|替换顺序|显示替换顺序|
|数量|显示替换件的用量|

|用量类型|显示被替换子件的用量类型|
|子件用量|显示被替换子件的子件用量|
|发料单位|显示被替换子件的发料单位|
|子项项次|显示被替换子件的项次|
|优先顺序|显示被替换子件的优先顺序|
|母件料号|显示子件所属母件的料号|
|版本号|显示BOM母件的BOM版本|

   *  第2步：点击确定按钮。
