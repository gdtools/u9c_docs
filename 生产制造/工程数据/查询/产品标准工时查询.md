
# 功能描述

用于查询生产某产品多少数量时，总共需要各工作中心的准备工时及加工工时。

可查询生产某产品及所有子项时所需要用到的工作中心的准备工时及加工工时。

# 业务规则

*  维护物料清单；
*  维护工艺路线

# 栏目说明

标准工时-查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|母件料品|要查询的料品参照料品档案录入非空；|
|生产目的|要查询的生产目的选择生产目的录入可空；|
|BOM版本|要查询的BOM的BOM版本录入可空|
|货主组织|要查询的BOM的货主组织录入可空|
|生效日期|展开时按此生效日期过滤子件，即只展开在此日期生效的子件料品录入非空；|
|需求数量|按此需求数量计算工时录入非空；|
|生产单位|需求数量的单位选择录入非空|
|是否向下展开|选择是只计算本层物料的生产工时，还是同时计算下级所有料品的生产工时是：计算本层及所有下级件生产的生产工时否：只计算本层的生产工时|

栏目设置

|栏目名称|说明|
|---|---|
|组织|显示BOM母件所属的组织|
|母件料品|显示BOM母件的料品品名|
|版本号|显示BOM版本号|
|BOM生产目的|显示BOM的生产目的|
|批量|显示BOM母项的批量|
|生产单位|显示BOM母项的生产单位|
|生产线|显示BOM母项的生产线|
|生效日期|显示BOM母项的生效日期|
|失效日期|显示BOM母项的失效日期|
|从数量|显示BOM母项的从数量|
|到数量|显示BOM母项的到数量|

标准工时-栏目设置

|栏目名称|说明|
|---|---|
|工作中心编码|显示加工所用到的工作中心的编码|
|工作中心名称|显示加工所用到的工作中心的名称|
|工作中心分组|显示加工所用到的工作中心的所属分组|
|准备工时|显示加工所用到的工作中心的准备工时|
|加工工时|显示加工所用到的工作中心的加工工时|
|工时时间单位|显示加工所用到的工作中心的工时单位|


排序条件

根据所选栏目进行排序（升序／降序）
