
# 功能描述

查询可以建立BOM但是还没有建立的所有物料。

可以只针对某一生产分类或分类段进行查询，

也可以按照物料形态等进行查询；

# 业务规则

*  维护物料档案；
*  维护物料清单。

# 栏目说明

未建立BOM的制造物料明细-查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品分类|只查询某一或某些料品分类时录入参照料品分类档案录入可空；|
|料品分类段|只查询料品分类段等于指定分类段时录入录入可空；|
|料品形态属性|只查询某一或某些料品形态属性时录入录入可空；|

查询栏目

|栏目名称|说明|
|---|---|
|组织编码|显示料品所属的组织编码|
|组织名称|显示料品所属的组织名称|
|料品形态属性|显示料品的料品形态属性|
|料号|显示未建BOM的料品的料号|
|料品|显示未建BOM料品的品名|
|可BOM|显示料品的可BOM属性|

排序条件

根据所选栏目进行排序（升序／降序）

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>未建立BOM的制造物料明细查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
