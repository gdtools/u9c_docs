
# 功能描述

查询某产品在不同插件位置上分别有哪些插件；

查询某产品在指定的插件位置上有哪些插件。

# 业务规则

*  维护物料清单

# 栏目说明

插件位置-查询条件

|栏目名称|说明|
|---|---|
|组织|要查询的BOM所在的组织可参照当前组织及<组织隶属关系>为“工厂关系” 的下级组织及<组织业务关系>为“工厂－工厂”、“销售－工厂” 、“采购－工厂” 、“物流－工厂”的组织录入。非空；|
|料品|要查询的BOM的料品参照料品档案录入非空；|
|生产目的|要查询的BOM的生产目的选择生产目的录入可空；|
|BOM版本|要查询的BOM的BOM版本参照BOM版本录入可空|
|批量|要查询的BOM的批量手工录入可空|
|单位|要查询的BOM的单位参数计量单位录入可空|
|生产线|要查询的BOM的生产线参照生产线录入可空|
|生效日期|按此生效日期过滤子件，即只显示在此日期生效的子件料品录入可空；|
|插件位置|非空时，查询此插件位置的插件录入可空；|

栏目设置

|栏目名称|说明|
|---|---|
|组织|显示BOM母件所属的组织|
|母件料品|显示BOM母件的料品品名|
|版本号|显示BOM版本号|
|生产目的|显示BOM的生产目的|
|子项项次|显示子件的项次|
|优先顺序|显示子件的优先顺序|
|子件料品|显示子件的料品|
|版本号|显示子件的版本号|
|发料单位|显示子件的发料单位|
|行号|显示插位的行号|
|插件位置|显示插件位置编码|
|数量|显示子件在此插件的数量|

# 按钮说明

*  <替代件>：用于查询子件的替代料品情况。
 
   *  操作步骤
   
      *  点击追溯查询－替代件按钮，在弹出窗口中即可看到选中子件的替代件列表。
*  <元件厂牌>：用于查询子件的元件厂牌情况。
 
   *  操作步骤
   
      *  点击元件厂牌按钮，在弹出窗口中即可看到选中子件的元件厂牌列表。

# 操作说明

*  通过菜单生产制造－>工程数据－>查询－>插件位置查询进入该界面；
*  操作步骤
 
   *  第1步：输出查询条件；
   *  第2步：点击确定按钮。
