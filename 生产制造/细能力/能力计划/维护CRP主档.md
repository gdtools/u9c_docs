
# 功能描述

本结点用于维护CRP主档，主要功能如下：。

CRP主档的新增、删除、复制、修改；

查看CRP主档;

进行CRP运算;

查看工作日历快照;

查看生产订单快照;

执行细能力查询。

# 业务规则

*  已进行MRP运算
*  生产订单（可选）
*  计划生产订单（可选）

# 栏目说明

维护CRP主档

|栏目|说明|
|---|---|
|计划名称.版本|从当前组织的<计划名称>中选择。修改时，此字段不可改复制操作时，此字段不可改|
|名称|为CRP名称计划名称非空时，带入计划名称，不可维护计划名称为空时，录入，非空修改时，此字段不可改复制操作时，此字段不可改|
|版本|计划名称非空时：缺省为计划名称的版本,可修改。同一计划名称的CRP版本不可重复修改操作时时，此字段不可改计划名称为空时：录入，非空同一CRP名称版本不可重复修改操作时时，此字段不可改|
|截止日期|计划名称非空时：默认为<计划名称>.[结束日期］计划名称为空时：输入，但不可小于当前日期|
|产能比率|选择：理想/标准/正常。 缺省：正常|
|主版本|默认为否，可改.同一CRP名称只可有一个主版本|
|包含生产订单|默认为是，表示运算时考虑生产订单的能力占用|
|包含计划生产订单|默认为是，表示运算时考虑计划生产订单的能力占用|

# 按钮说明

*  <运行>:执行CRP运算。

# 操作说明

*  通过菜单生产制造－>细能力－>能力计划－>维护CRP主档进入该界面；
*  操作步骤
 
   *  第1步：选择MRP计划、版本等信息。
   *  第2步：维护名称、版本等信息。
   *  第3步：选择主版本、包含生产订单、包含计划生产订单、指定资源范围等选项。
   *  第4步：点击运行按钮。
