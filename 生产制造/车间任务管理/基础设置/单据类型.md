
# 功能描述

## 功能概述

本结点设置车间任务管理所使用的单据类型。

## 功能说明

*  设置车间任务单的单据类型
*  设置车间任务汇报单的单据类型
*  设置工序交接单的单据类型

# 业务规则

无

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|**单据类型:车间任务单**|
|任务类型|任务区分为标准生产、报废补投生产、返工生产类型|
|审核自动开工|如【审核自动开工】=True，则任务单在审核时自动对任务单进行开工处理|
|收货到工序|委外任务时生效，如收货到工序，则委外收货审核时，更新工序外协件存货账，通过工序外协件发料发至下序|
|开工自动发出半成品|委外任务时生效，如【开工自动发出半成品】=True,则需要进行半成品收发管理的工序计划分派的车间任务，在任务单审核时自动创建委外半成品交接单|
|**单据类型:车间任务汇报单**|
|任务类型|任务区分为标准生产、报废补投生产、返工生产类型|
|**单据类型:工序交接单**|
|交接类型|交接区分为完工交接、返工交接、委外发出交接；返工交接用于确定返工工艺后，将待返工品交接给返工加工工序首序所应用交接管理；委外发出交接用于如委外业务需进行半成品收发管理，对待加工的半成品与外协加工完成的半成品与委外商的交接管理|
