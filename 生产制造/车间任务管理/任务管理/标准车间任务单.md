
# 功能描述

## 功能概述

本结点提供车间任务的相关操作。

## 功能说明

*  依据工序产出计划分配车间任务
*  车间任务分配至班组、人员、设备
*  生产订单审核对应工序自动创建车间任务单
*  支持车间任务的拆分

# 栏目说明

|**栏目名称**|**说明**|
|---|---|
|生产订单|参照选择需要分派车间任务的生产单据，可选择的单据范围：已审核、未关闭、未挂起、未终止的生产单据；亦可直接选择生产单据的工序直接进行任务分派|
|工序号|参照选择需要分配车间任务的生产单据工序，如指定了生产单据，则仅显示对应生产单据的工序|
|作业|指定对应工序的标准作业|
|班组|指定对应工序任务的加工班组|
|人员|指定对应工序任务的加工人员|
|班次|可指定加工任务对应的工作中心工作日历中的班次|
|来源任务|如需记录前后序加工任务的关系，可指定前序对应的任务单作为来源任务|
|是否自动交接|如无需人工进行工序间的交接，则可通过自动交接进行上下序的交接；生产单据工序表中【完工自动转移】=True，则【是否自动交接】=True|
|执行数量|为自制任务的开工数量；委外或者协同任务的发出半成品数量|

# 操作说明

*  **任务单拆分**

由于产能或环境等原因将一个车间任务拆分成多个车间任务。

操作步骤：点击车间任务管理－>任务管理－>标准车间任务单－>任务拆分按钮，进入拆分车间任务单功能。具体步骤如下所示：

第1步：点击车间任务管理－>任务管理－>标准车间任务单，进入车间任务维护主界面，勾选本次需要拆分的车间任务单；

第2步：点击任务拆分按钮，弹出任务拆分画面，上列表为待拆分的任务单，下列表维护拆分结果；

第3步：在上列表切换需要拆分的任务单，在下列表新增拆分行，录入每一行拆分任务的任务数量，并可指定拆分后需分配的班组、人员、设备等信息，【是否新行】代表拆后行；

第4步：确定后按拆后行创建新的车间任务单，原行更新数量等信息。
