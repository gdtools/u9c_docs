
# 功能描述

可以按照核算组织、借款组织、借款人组织等多个维度分析借款余额分布；

可以自定义借款余额表行和列的分组汇总项目；

# 业务规则

# 栏目说明

费用分析表页签

|栏目|说明|
|---|---|
|借款人|显示借款人|
|借款单单据类型|显示借款单单据类型|
|借款单号|显示借款单号|
|借款币种|显示借款币种|
|借款金额|显示借款金额|
|借款余额|显示借款余额|
|还款金额|显示还款金额|
|报销金额|显示报销金额|
|损益金额|显示汇兑损益金额|

查询条件页签

|||

|---|---|
|借款组织|查询条件，参照组织档案录入|
|借款人组织|查询条件，参照组织档案录入|
|借款部门|查询条件，参照部门档案录入|
|借款人|查询条件，参照人员档案录入|
|余额类型|枚举下拉，历史余额，实时余额|
|期间类型|枚举下拉，会计期间，自然日期|
|截止会计期间|当选择期间类型等于会计期间时，参照会计期间录入|
|截止自然日期|当期间类型为实时余额时，参照自然日期录入|
|借款币种|查询条件，参照币种档案录入|
|是否包含未付款借款单|查询条件，枚举下拉，是，会查询未付款的借款单|
|是否包含未确认报销单|查询条件，枚举下拉，是，会查询未确认报销单的数据|
|是否包含未审核还款单|查询条件，枚举下拉，是，会查询未审核还款单的数据|
|是否包含已结清数据|查询条件，么局下拉，是，会查询已经结清数据的借款单|
