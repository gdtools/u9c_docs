
# 功能描述

设置费用报销的参数。

# 关键应用

# 业务规则

*  启用费用报销（必做）

# 栏目说明

|栏目|说明|
|---|---|
|费用计划-费用计划组织|指定费用申请单、报销单耗用费用计划的组织：报销组织：在单据的报销组织中匹配费用计划并耗用；列支组织：在单据的列支组织中匹配费用计划并耗用；此参数可以随时修改，只影响后续操作，不影响历史数据。|
|费用计划-超支控制方式|指定费用申请/费用报销超出费用计划时的控制方式:提醒:当费用申请/费用报销超出费用计划时,系统仅给出超支提醒;严格控制:当费用申请/费用报销超出费用计划时,系统严格控制不允许提交单据;特批:当费用申请/费用报销超出费用计划时,该单据需要走特批流程;此参数可以随时修改，只影响后续操作，不影响历史数据。|
|费用计划-是否启用费用计划变更单|是否启用费用计划变更单调整费用计划变更|
|费用计划-费用计划报销冲减启用未税金额|下拉选项，是或否，选择是，当报销金额=发票金额，冲减费用计划时，使用未税金额进行冲减；选择否，冲减费用计划，使用报销金额进行冲减|
|费用标准-超标准控制方式|指定费用申请/费用报销超出费用计划时的控制方式:提醒:当费用申请/费用报销超出费用标准时,系统仅给出超支提醒;严格控制:当费用申请/费用报销超出费用标准时,系统严格控制不允许提交单据;特批:当费用申请/费用报销超出费用标准时,该单据需要走特批流程;此参数可以随时修改，只影响后续操作，不影响历史数据。|
|费用申请-超支控制方式|指定费用报销超出费用申请时的控制方式:提醒:当费用报销超出费用申请时,系统仅给出超支提醒;严格控制:当费用报销超出费用申请时,系统严格控制不允许提交单据;特批:当费用报销超出费用申请时,该单据需要走特批流程;此参数可以随时修改，只影响后续操作，不影响历史数据。|
|汇兑损益-期末计算汇兑损益汇率类型|指定，买入、中间价、卖出。此参数可以随时修改，只影响后续操作，不影响历史单据。|
|汇兑损益-期末计算频度|需要在期末计算汇兑损益时需要设定计算的频度，每月或每年|
|借款信用-未报销借款天数|输入大于等于0的整数;在借款人未还款的借款单中,最早一张借款单的借款日期距离本次借款日期的天数超过这里规定的天数时,不允许再次借款;0表示不控制;此参数可以随时修改，只影响后续操作，不影响历史数据。|
|借款信用-借款限额|输入大于等于0的数值;借款人所有未还款的借款单本币余额合计超过这里规定的金额时,不允许再次借款;0表示不控制;此参数可以随时修改，只影响后续操作，不影响历史数据。|
|借款信用-未报销借款笔数|输入大于等于0的整数;借款人所有未还款的借款单的张数超过这里规定的笔数时,不允许再次借款;0表示不控制;此参数可以随时修改，只影响后续操作，不影响历史数据。|
|电子发票默认费用项目|此参数在启用电票导入功能时，必须指定默认的费用项目，电票导入后，会将指定的费用项目带到费用报销行上。|

|转总账事物的凭证张数|转总账事务的凭证粒度，为1时转总账不成功只对本张起作用不影响其它；|
|跨组织报销会计分录|跨组织报销会计分录是否合并转总账|
|月结时报销单和借款单是否必须全部已确认|月末结账时判断，报销单和借款单是否必须全部已确认|
|默认收入项目|参照收支项目；录入默认收款使用的收支项目；类型必须为“收入”或者“收支”|

|异币种核销-允差|设置异币种还款或者冲销时，允许本位币借贷方的最大净差额；此参数可以随时修改，只影响后续操作，不影响历史数据。|
|异币种核销-中间币种|设置异币种还款或者冲销借款时的默认中间币种，允许在还款和冲销借款时修改；参照币种档案录入。此参数可以随时修改，只影响后续操作，不影响历史数据。|
|报销时提示借款余额|勾选此参数，会在报销单提示借款余额。|
|列支人员必须隶属于列支项目|勾选此参数，费用报销中的单据会校验所选列支人员是否属于所选列支项目，不属于，会报错提示。|
|下级部门执行时上级自动执行|勾选此参数，匹配费用计划下级部门执行时上级自动执行|
|是否启用薪资扣还借款|勾选此参数，启用薪资扣款冲减借款|
|单据任何状态私有段可修改|勾选此参数，单据在任何状态下都可更改私有段|
|个人票夹发票列表URL|在税务云个人票夹中个人票夹列表URL|
|个人票夹修改发票URL|在税务云个人票夹中修改发票状态URL|
|个人票夹发票附件预览URL|在税务云个人票夹中发票预览附件URL|

# 操作说明

下发

*  该操作的主要目的是指定那些参数下发到那个组织中；
*  左侧的列表中可以指定针对那些参数进行下发；
*  右侧的组织列表中，可以参照出与当前核算组织有垂直隶属关系的组织列表；
*  在“下发历史”中，可以查看那些参数曾经下发到那些组织，并显示对应的操作人和操作时间；

下发参数

*  在这个操作中，可以指定参数下发后，在下发的组织中能否进行修改；
*  如果是数值型的，还可以指定上浮＼下调的幅度。例如转总账事务数和利息容差的范围；
