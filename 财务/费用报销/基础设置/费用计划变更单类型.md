
# 功能描述

可以按照不同的费用计划性质和管理要求设置不同的费用计划变更类型， 不同的费用计划变更单类型：

可以配置不同的审批流；

可以通过单据的个性化来设置不同的显示内容及格式；

可以设置不同的打印模板；

若需要使用费用计划变更功能，则必须先定义费用计划变更单类型。

注意，已经填写了费用计划变更单的单据类型不允许删除。。

# 业务规则

*  启用费用报销（必做）
*  启用费用计划（必做）

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|录入费用计划变更单类型编码；同一组织中不允许重复；|
|名称|录入费用计划变更单类型名称；|
|业务类型|系统默认“费用计划变更”，不允许修改；|
|描述|录入对费用计划变更单类型的详细说明信息。|
|默认类型|标注设置的单据类型是否是默认类型。在填写费用计划变更单时，系统将默认的费用计划变更单类型带到操作画面中，方便用户使用。|

参数页签详见公共说明
