
# 功能描述

可以按照费用的属性或者业务的划分设置不同的费用报销单类型，如：差旅费报销、交通费报销、电话费报销等；

不同的申请单类型：

*  可以配置不同的审批流；
*  可以通过单据的个性化来设置不同的显示内容及格式；
*  可以设置不同的打印模板；
*  可以规定使用不同的费用项目；
*  可以规定报销前是否必须申请；

若需要使用费用报销单，则必须先定义费用报销单类型。

注意，已经填写了费用报销单的单据类型不允许删除。

# 业务规则

*  启用费用报销（必做）
*  费用项目（可选）
*  费用申请单类型（可选）

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|录入费用报销单类型编码；同一组织中不允许重复；|
|名称|录入费用报销单类型名称；|
|业务类型|系统默认“费用报销”，不允许修改；|
|描述|录入对费用报销单类型的详细说明信息。|
|必须申请|设置该类费用报销单在报销前是否必须先填写费用申请单：选中：报销前必须申请；未选中：报销前不强制申请；|
|申请单类型|若设置为费用报销单在报销前必须先填写费用申请单，则在本栏必须指定对应的费用申请单类型；表示，报销先必须且只能按照本栏指定的申请单类型进行事先的费用申请；|
|默认类型|标注设置的单据类型是否是默认类型。在填写费用申请单时，系统将默认的费用申请单类型带到操作画面中，方便用户使用。|
|费用项目编码|设置当前费用报销单类型允许使用的费用项目；参照费用项目档录入；允许录入非末级费用项目，表示费用报销时允许使用其下级所有费用项目；|
|费用项目名称|根据费用项目编码自动从费用项目档带入，仅显示，不允许修改；|
|必须有计划|勾选后，当前报销单类型下的报销，必须有费用计划，才能操作报销业务|
|税组合|选择当前费用项目行下的税组合|
|税率|根据所选的税组合，自动带出税率|
