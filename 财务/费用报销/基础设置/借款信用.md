
# 功能描述

可以按照员工、部门设置借款部门、借款人、借款组织的借款信用。可以设置借款笔数、借款总额。

# 关键应用

# 业务规则

*  启用费用报销（必做）

# 栏目说明

|栏目|说明|
|---|---|
|控制类型|枚举下拉，员工、组织。|
|借款人组织|选择控制类型=员工时，必填，选择借款人所在组织|
|员工|选择控制类型=员工时，必填，选择具体员工|
|借款组织|选择控制类型=组织时，必填，选择具体借款组织|
|借款部门|选择控制类型=组织时，必填，选择具体借款部门|
|允许最长借款天数|输入允许最长借款天数|
|允许借款笔数|输入允许借款笔数|
|允许借款总额|输入借款总额|

# 按钮说明

<信用余额查询>：查询当前借款信用下的信用余额

|栏目|说明|
|---|---|
|控制类型|枚举下拉，员工、组织。|
|借款人组织|选择控制类型=员工时，必填，选择借款人所在组织|
|借款部门|显示借款部门|
|借款人|显示借款信用设置的借款人|
|允许借款最大笔数|显示当前借款信用设置的最大笔数|
|正在借款最长天数|显示当前借款包含借款最长天数及超过最长天数的借款笔数|
|允许借款笔数|显示允许借款笔数|
|正在借款笔数|显示未核销的借款笔数|
|允许借款总额|显示借款总额|
|已借款总额|显示未核销的借款总额|
|借款余额|显示借款余额，借款余额=借款总额-已借款总额|

<信用使用明细查询>：查询当前借款信用具体使用的明细

|栏目|说明|
|---|---|
|借款部门|显示借款单上的借款部门|
|借款人|显示借款单上的借款人|
|单号|显示借款单号|
|借款日期|显示借款单上的借款日期|
|预计还款日期|显示借款单上的预计还款日期|
|借款金额|显示借款单的借款原币金额|
|借款本币金额|显示借款本币金额|
|借款余额|显示借款原币余额|
|借款本币余额|显示借款本币余额|
|已借款天数|显示借款单已经借款天数|
