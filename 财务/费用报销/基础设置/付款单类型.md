
# 功能描述

可以按照不同的付款性质和管理要求设置不同的付款单类型，如：差旅费借款付款、部门活动借款付款等；

不同的付款单类型：

可以配置不同的审批流；

可以通过单据的个性化来设置不同的显示内容及格式；

可以设置不同的打印模板；

若需要使用付款功能，则必须先定义付款单类型。

注意，已经填写了付款单的单据类型不允许删除。。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|录入付款单类型编码；同一组织中不允许重复；|
|名称|录入付款单类型名称；|
|业务类型|系统默认“费用付款”，不允许修改；|
|描述|录入对付款单类型的详细说明信息。|
|默认类型|标注设置的单据类型是否是默认类型。在填写付款单时，系统将默认的付款单类型带到操作画面中，方便用户使用。|

参数页签详见公共说明
