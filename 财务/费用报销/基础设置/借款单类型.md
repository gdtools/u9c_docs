
# 功能描述

可以按照不同的借款性质和管理要求设置不同的借款单类型，如：差旅费借款、部门活动借款等；

不同的借款单类型：

可以配置不同的审批流；

可以通过单据的个性化来设置不同的显示内容及格式；

可以设置不同的打印模板；

可以规定借款前是否必须申请；

若需要使用借款功能，则必须先定义借款单类型。

注意，已经填写了借款单的单据类型不允许删除。

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|录入借款单类型编码；同一组织中不允许重复；|
|名称|录入借款单类型名称；|
|业务类型|系统默认“借款”，不允许修改；|
|描述|录入对借款单类型的详细说明信息。|
|必须申请|设置该类借款单在借款前是否必须先填写费用申请单：选中：借款前必须申请；未选中：借款前不强制申请；|
|默认类型|标注设置的单据类型是否是默认类型。在填写借款单时，系统将默认的借款单类型带到操作画面中，方便用户使用。|
|更新计划|勾选后，当借款单提交后，会将借款金额按照匹配规则冲减到计划的借款余额上；若不勾选，不会更新借款余额至费用计划上。|
|必须有计划|勾选后，借款单必须有费用计划才能使用。|
|信用控制|勾选后，借款金额会参与信用控制，当超过限额后，不允许再进行借款。|
