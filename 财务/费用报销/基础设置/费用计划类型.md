
# 功能描述

费用计划是对费用预算的细化，可以按照不同的级别和角色来制定不同维度和期间类型的计划；

本功能用来定义费用计划的维度和期间类型，不同的费用计划类型对应不同维度和周期的费用计划；

费用计划的维度可以为：部门、员工、项目、任务、币种、费用项目、公共扩展字段，其中币种和费用项目为必选的维度，公共扩展字段为所有类型的费用计划都有的维度无需配置，其他的维度则可以在本功能中配置；

已编制了费用计划的费用计划类型不允许修改；

已编制了费用计划的费用计划类型不允许删除；

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|录入费用计划类型编码；同一组织中不允许重复；|
|名称|录入费用计划类型名称；|
|描述|录入对费用计划类型的详细说明信息。|
|期间类型|参照统计规则档案录入；指定费用计划类型所使用的期间类型，如可以选择按照周、月或者日来编制费用计划；|
|业务类型|系统默认“费用计划”，不允许修改；|
|部门|选中，表示将部门作为费用计划的一个维度；未选中，表示不将部门作为费用计划的一个维度；|
|部门在表头|部门为选中状态时，可以选择在编制本类型的费用计划时是否将部门放在表头录入：选中，表示将部门放在费用计划的表头；未选中，表示不将部门放在费用计划的表头；|
|项目|选中，表示将项目作为费用计划的一个维度；未选中，表示不将项目作为费用计划的一个维度；|
|项目在表头|项目为选中状态时，可以选择在编制本类型的费用计划时是否将项目放在表头录入：选中，表示将项目放在费用计划的表头；未选中，表示不将项目放在费用计划的表头；|
|任务|选中，表示将任务作为费用计划的一个维度；未选中，表示不将任务作为费用计划的一个维度；|
|任务在表头|任务为选中状态时，可以选择在编制本类型的费用计划时是否将任务放在表头录入：选中，表示将任务放在费用计划的表头；未选中，表示不将任务放在费用计划的表头；|
|员工|选中，表示将员工作为费用计划的一个维度；未选中，表示不将员工作为费用计划的一个维度；|
|币种|系统默认选中，不允许修改；表示币种为费用计划的固定维度；|
|费用项目|系统默认选中，不允许修改；表示费用项目为费用计划的固定维度；|
