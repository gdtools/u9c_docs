
# 功能描述

汇集所有需要出纳进行确认的单据，包括：借款单、报销单；

出纳可以通过本功能快速查找需要处理的单据并进行处理；

# 业务规则

*  启用费用报销（必做）

# 按钮说明

<查询>：弹出查询条件画面，选择查询过滤。

<导出>：将列表数据导出本地。

<确认>：出纳确认所选单据。

<批量确认>：批量确认所选单据。

<批量确认付款>：批量确认所选单据并生成付款单。

<批量付款>：对所选已确认的单据生成付款单。

<批量取消付款>：对于未实际付款的单据取消付款，单据状态变为已确认。

# 操作说明

确认付款

*  通过菜单路径，财务->费用报销->出纳工作台进入画面，勾选列表中单据状态=已核准的数据，点击“确认”按钮，弹出确认画面；
*  在弹出框中基本信息页签中，填写确认日期，在明细行中填写确认金额，确认金额为支付金额。
*  当所选业务类型为报销单时，可以点击“选择借款单”选择已经付款的借款单，选择后，自动将所选的借款单关联到明细行上，填写冲销金额，系统会自动计算确认金额。
*  点击确认，表示当前单据已经确认，将确认金额回写到报销单行。
*  点击确认并付款，弹出付款弹窗，在付款弹窗中选择结算方式并且选择付款银行账号。
*  取消确认，在未进行最终支付的状态下，可取消确认，删除相关业务单据。

付款

*  通过菜单路径，财务->费用报销->出纳工作台进入画面，在单据状态已确认下点击“付款”按钮，弹出付款画面；
*  在付款弹窗中选择结算方式并且选择付款银行账号。
*  取消付款，在未进行最终支付的状态下，点击取消付款，删除相关业务单据。
