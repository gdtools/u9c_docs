
# 功能描述

录入还款单；

可以对还款进行还款信用管理：

*  控制还款的笔数：系统参数“未报销还款笔数”
*  控制还款的金额：系统参数“未报销还款金额”
*  控制还款的期限：系统参数“未报销还款天数”
*  可以按照部门、职务对单笔还款的额度进行约束，参见“还款额度”

# 业务规则

*  启用费用报销（必做）
*  定义还款单类型（必做）
*  借款单已经确认付款（必做）

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|单据类型|参照还款单单据类型录入；|
|单号|根据所选单据类型编码规则，自动编码或者手工编码|
|还款日期|录入还款日期；|
|还款组织|参照组织档案录入；要求选择的借款组织要与当前登录的核算组织存在“报销-核算”关系；|
|结算组织|参照组织档案录入；默认当前登录组织；实际支付资金的组织；|
|借款币种|参照币种档案录入；|
|冲销借款金额|显示累计明细行中冲销借款金额之和；|
|还款人组织|默认借款单的“借款人组织”；允许修改；|
|还款人|默认借款单的“借款人”；允许修改；|
|银行卡类型|默认借款单的“银行卡类型”；允许修改；|
|员工银行卡号|默认借款单的“员工银行卡”；允许修改；|
|还款币种|默认借款单的“借款币种”；允许修改；|
|汇率类型|录入汇率类型；|
|汇率|根据汇率档案上录入的汇率自动带出，可修改；|
|还款金额|还款币种等于借款币种时：默认借款单的“借款余额”；通过调整“借款信息”页签中的“冲销借款金额”调整；还款币种不等于借款币种时：默认根据借款单的“借款余额”计算；允许修改，修改后影响“异币种”页签中的“还款金额”；|
|状态|显示单据状态；|
|来源|显示单据来源，手工录入、报销单、发薪申请单；|

借款信息页签

|栏目|说明|
|---|---|
|借款单类型|根据所选借款单显示借款单类型；|
|借款单|参照借款组织中已经确认付款且未全部还款的借款单；可以直接录入借款单号；|
|借款人|显示借款单上的借款人；|
|借款部门|显示借款单上的借款部门；|
|借款余额|显示借款单上的借款余额；|
|借款本币余额|显示借款单上的借款本币余额；|
|冲销借款金额|默认取借款单的“借款余额”；允许修改，修改后的冲销借款金额不允许大于借款余额；|
|冲销本币金额|根据冲销借款金额和基本页签中的汇率计算；|
|项目|根据所选〔借款单〕带入，用户不可修改|
|任务|根据所选〔借款单〕带入，用户不可修改|

收款信息页签

|栏目|说明|
|---|---|
|结算方式|参照结算方式录入；|
|现金账号|当选择结算方式为现金时，选择收款的现金账号；|
|收款账号|当选择业务属性为银行业务类的结算方式，选择收款的银行账号；|
|收款子账号|根据所选收款账号，自动带出子账号；|
|票据号|当选择业务属性为票据业务类的结算方式，选择票据号；|
|回单日期|录入电子回单日期；|
|收款金额|录入收款金额；|
|收款本币金额|录入收款本币金额；|
|收款单号|显示现金银行收款单号，当审核后生成现金银行收款单自动回写；|
|收支项目|参照收支项目录入；|

[]()异币种信息页签

|栏目|说明|
|---|---|
|借款币种|显示借款单表头借款币种；|
|借款余额|显示借款单表头借款余额；|
|借款本币余额|显示借款单表头借款本币余额；|
|冲销借款金额|显示借款单表头冲销借款金额；|
|冲销本币金额|显示借款单表头冲销本币金额；|
|借款-中间汇率|默认当前汇率，允许修改|
|冲销中间币金额|显示冲销中间币种金额；|
|还款币种|基本页签的还款币种；与基本页签的还款币种同步；|
|还款金额|根据“还款中间币种金额”和“还款-中间汇率”换算还款金额；修改“还款金额”则影响“还款中间币种金额”；|
|还款本币金额|根据还款金额、汇率计算；不允许修改；与基本页签的还款本币金额同步；|
|还款中间汇率|带出汇率档案中的汇率，可修改；|
|还款中间币金额|借款币种<>还款币种时：默认=借款中间币种余额；允许修改；修改后与借款中间币种余额不允许大于系统参数“异币种核销容差”；借款币种=还款币种时：默认=借款中间币种余额；|
|中间币种|借款币种与还款币种不同时，选择按照中间第三种币种进行折算；|
|中间币-本币汇率|带出汇率档案中的汇率，可修改；|
|中间币差额|显示中间币种差额,中间币差额 = 借款币种折算中间币种的借款金额 - 还款币种折算中间币种的还款金额|
|中间币允差|显示参数设置中的异币种核销的允差|
|本币差额|显示折算中间币种折算的本币差额；|

# 按钮说明

<交易分录>：显示当前单据生成的交易分录。

<还款单类型>：导航到[还款单类型](/detail/c0c3ed6a840b4a228cbe37cf34e906ec)档案设置功能节点。

# 操作说明

通过菜单路径财务->费用报销->还款进入画面，填写还款信息页签，保存，提交。
