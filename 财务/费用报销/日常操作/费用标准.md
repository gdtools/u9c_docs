
# 功能描述

设置费用标准，可按照组织、岗位、职务、费用项目等维度设置不同的费用标准。

# 业务规则

*  启用费用报销（必做）

# 栏目说明

|栏目|说明|
|---|---|
|编号|输入费用标准方案编号|
|名称|输入费用标准方案名称|
|组织|参照组织档案录入|
|岗位|参照岗位档案录入|
|职务|参照职务档案录入|
|费用项目|参照费用项目档案录入|
|控制参数|下拉选项，天-当天费用总额不能超过设置的费用标准；月-当月费用总额不能超过设置的费用标准；人-每人费用总额不能超过设置的费用标准；总金额-总额不能超过设置的费用标准；|
|币种|参照币种录入|
|金额|输入金额，该金额为费用发生上限|
