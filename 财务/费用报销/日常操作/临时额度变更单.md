
# 功能描述

调整已经启用的借款信用。

# 关键应用

# 业务规则

*  启用费用报销（必做）
*  定义临时额度变更单类型（必做）

# 栏目说明

|栏目|说明|
|---|---|
|单据类型|参照录入临时额度变更单单据类型|
|单号|根据所选单据类型设置的编码规则，自动生成或手工编号|
|申请日期|录入申请变更日期|
|备注|填写备注|
|控制类型|枚举下拉，员工、组织。|
|借款人组织|选择控制类型=员工时，必填，选择借款人所在组织|
|员工|选择控制类型=员工时，必填，选择具体员工|
|借款组织|选择控制类型=组织时，必填，选择具体借款组织|
|借款部门|选择控制类型=组织时，必填，选择具体借款部门|
|允许最长借款天数|输入允许最长借款天数|
|允许借款笔数|输入允许借款笔数|
|允许借款总额|输入借款总额|
|生效日期|输入单据生效日期|
|失效日期|输入单据失效日期|
|状态|显示单据状态|
