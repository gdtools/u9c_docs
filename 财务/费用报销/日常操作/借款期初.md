
# 功能描述

录入费用报销系统启用前尚未还款的借款单，期初借款单不生成交易分录。

# 关键应用

# 业务规则

*  启用费用报销（必做）
*  定义借款单类型（必做）

# 栏目说明

|栏目|说明|
|---|---|
|单据类型|参照借款单类型录入；|
|单号|根据所选的单据类型的系统编号设置自动编号或手动编号|
|借款组织|参照组织档案录入；要求选择的借款组织要与当前登录的核算组织存在“报销-核算”关系；|
|借款日期|输入借款日期；|
|借款部门|参照借款组织下的部门档录入；|
|借款用途|输入借款用途；|
|借款人组织|默认为当前用户对应员工的主任职组织；|
|借款人|默认为当前用户对应员工；|
|银行卡类型|默认“员工账号”中定义的借款人默认账号的“卡名”；|
|员工银行卡|默认“员工账号”中定义的借款人默认账号的“卡号”；|
|借款币种|默认本位币，允许修改；|
|汇率类型|借款币种选择外币时，选择汇率类型，买入，卖出、中间价；|
|汇率|自动带出汇率档案上的汇率，允许修改；|
|确认金额|录入确认金额；注意这里录入的金额不是借款单上的借款金额，而是截止到期初未还款部分的金额；|
|借款余额|默认等于“确认金额”，不允许修改；|
|借款本币余额|显示借款本币余额，不可修改|
|项目|参照项目档案|
|任务|参照任务档案|

联系信息

|栏目|说明|
|---|---|
|固定电话|显示借款人的联系对象的固定电话|
|移动电话|显示借款人的联系对象的移动电话|
|电子邮件地址|显示借款人的联系对象的电子邮件地址|
|即时通讯|显示借款人的联系对象的即时通许地址|
