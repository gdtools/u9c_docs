
# 功能描述

本功能是对涉及外币的借款进行汇兑损益计算；

# 业务规则

*  启用费用报销（必做）
*  定义汇兑损益单类型（必做）

# 栏目说明

基本信息页面

|栏目|说明|
|---|---|
|单据类型|显示汇兑损益单单据类型|
|单据号|显示单据号|
|单据日期|显示计算汇兑损益日期|
|记账期间|显示记账期间|
|本币|显示本币币种|
|币种|显示原币币种|
|汇率类型|显示汇率类型|
|汇率|显示汇率|
|状态|显示单据状态|

明细行页签

|栏目|说明|
|---|---|
|借款日期|显示借款日期|
|借款单|显示借款单|
|余额|显示借款余额（原币）|
|本币余额|显示借款余额（本币）|
|损益金额|显示损益金额|

# 按钮说明

<交易分录>：查询交易分录。

# 操作说明

*  点击新增，在弹出框中录入汇率，点击确定，系统会自动将所选原币对应的借款单的损益余额计算出来，显示在明细行上。
*  点击确定后自动生成已核准的汇兑损益单，并且调整借款余额报表中的借款余额。
