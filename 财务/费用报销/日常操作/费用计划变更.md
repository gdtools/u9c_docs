
# 功能描述

调整已经启用的费用计划。

# 关键应用

# 业务规则

*  启用费用报销（必做）
*  定义费用计划变更类型（必做）

# 栏目说明

费用计划变更表头

|栏目|说明|
|---|---|
|单据类型|参照输入费用计划变更单单据类型|
|单号|按照所选的单据类型中设置的编号规则，自动编号或手工编号|
|日期|输入费用计划变更日期|
|计划单号|必填，参照选择费用计划|
|名称|根据所选费用计划显示费用计划名称|
|状态|显示单据状态|
|累计余额控制||
|变更说明|输入变更说明|

费用计划变更表行

|栏目|说明|
|---|---|
|是否新增|选择是，表示当前行为新增行，需要填写期间、费用项目等字段；选择否，表示需要调整原有行。|
|计划单行|当“是否新增”=否时，计划单行必填，选择费用计划行明细。|
|期间|当“是否新增”=是时，参照统计期间录入；统计期间类型必须为费用计划表头显示的统计期间类型；选择的期间必须大于等于费用计划表头的开始期间，小于等于费用计划表头的结束期间；当“是否新增”=否，显示所选计划单行的期间。|
|收支项目|当“是否新增”=是，参照收支项目录入；允许录入非末级收支项目；必输；当“是否新增”=否，显示所选费用计划行收支项目。|
|费用项目|当“是否新增”=是，参照“费用项目”档录入；允许选择非末级“费用项目”；当“是否新增”=否，显示所选费用计划行费用项目；|
|币种|当“是否新增”=是，参照币种档录入；必输；当“是否新增”=是，显示所选费用计划行币种。|
|变更前计划金额|当“是否新增”=是，显示控；当“是否新增”=否，显示所选费用计划行计划金额。|
|变更后计划金额|录入变更后计划金额，必填。|
|计划余额|费用计划余额=变更后计划金额|
|变更说明|录入变更说明|
|扩展字段|弹出费用计划的公共扩展字段录入；公共扩展字段默认为费用计划的维度；|

# 操作说明

*  通过菜单路径财务>费用报销>费用计划变更，进入费用计划变更操作画面。
*  抬头选择单据类型后，选择计划单号，才可在费用计划变更gird列表中进行操作。
