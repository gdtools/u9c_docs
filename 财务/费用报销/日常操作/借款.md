
# 功能描述

录入借款单；

可以对借款进行借款信用管理：

*  控制借款的笔数：系统参数“未报销借款笔数”
*  控制借款的金额：系统参数“未报销借款金额”
*  控制借款的期限：系统参数“未报销借款天数”
*  可以按照部门、职务对单笔借款的额度进行约束，参见“借款额度”

# 业务规则

*  启用费用报销（必做）
*  定义借款单类型（必做）
*  参数设定，定义与借款相关参数

# 栏目说明

借款信息页签

|栏目|说明|
|---|---|
|单据类型|参照借款单单据类型录入；|
|单号|根据所选单据类型，自动编号或手工编号；|
|借款日期|录入借款日期；|
|预计还款日期|录入预计还款日期，预计还款日期必须大于或等于借款日期；|
|借款组织|参照组织档案录入；要求选择的借款组织要与当前登录的核算组织存在“报销-核算”关系；|
|借款部门|参照借款组织下的部门档录入；|
|费用项目|参照费用项目档案录入，若允许借款单回写计划，根据费用项目匹配费用计划；|
|用途|录入借款用途；|
|费用申请单|借款单类型为必须申请时，本栏非空；注意选择了申请单后，借款币种必须是费用申请单上指定的币种，参照该申请的累计借款金额不允许超出申请单上规定的借款金额；|
|借款人组织|默认为当前用户对应员工的主任职组织；|
|借款人|默认为当前用户对应员工；|
|银行卡类型|默认“员工账号”中定义的借款人默认账号的“卡名”；|
|员工银行卡|默认“员工账号”中定义的借款人默认账号的“卡号”；|
|借款币种|默认本位币，允许修改；|
|汇率类型|选择外币的时候，录入汇率类型，选择下拉、买入、卖出；|
|汇率|根据所选汇率档案中定义的本位币-原币的汇率，自动带出，可更改。|
|借款金额|录入申请借款的金额；注意借款单提交时会检查借款信用及借款额度|
|借款本币金额|显示借款本币金额；|
|确认金额|录入申请单是不允许编辑；在出纳确认时维护确认金额；|
|确认本币金额|显示确认本币金额；|
|借款余额|显示当前借款单尚未还款的金额；|
|借款本币余额|显示借款本币余额；|
|项目|参照项目档案；|
|任务|参照任务档案；|

# 按钮说明

<确认付款>：确认付款，录入确认金额、付款方式，点击确定后生成现金银行付款单。

<取消确认>：单据状态为“已付款”并且未实际支付取消付款确认。

<交易分录>：显示当前单据生成的交易分录。

<追溯查询>：联查当前借款单关联的报销单、还款单、付款单、信用余额及信用余额使用明细。

<还款单>：导航到[还款](/detail/c6ceb8f9dd3e4e7f8e359f560d1e1c65)档案设置功能节点。

<借款单类型>：导航到[借款单类型](/detail/13e1869da8ec40d281ed815441a135f8)档案设置功能节点。

# 操作说明

通过菜单路径财务->费用报销->借款进入画面，填写借款信息页签，保存，提交。
