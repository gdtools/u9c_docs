
# 功能描述

填写费用报销单；

可以通过个性化工具，对不同类型的费用报销单设置不同的显示内容及格式；

# 业务规则

*  启用费用报销（必做）
*  定义费用报销单类型（必做）

# 按钮说明

<还款>：导航到[还款](/detail/c6ceb8f9dd3e4e7f8e359f560d1e1c65)档案设置功能节点。

<报销单类型>：导航到[报销单类型](/detail/85089379ad4846d9a212dd537ada04d3)档案设置功能节点。

<交易分录>：显示当前单据对应的交易分录。

<预算执行>：执行预算。

<发票导入>：通过引入票夹、纸票扫码、电票导入三种方式将发票导入；

<确认>：出纳确认，可进行异币种确认。

<付款>：出纳对于已经确认的报销单付款。

# 操作说明

确认

*  通过菜单路径，财务->费用报销->报销进入画面，在单据状态已核准下点击“确认”按钮，弹出确认画面；
*  在弹出框中基本信息页签中，填写确认日期，在明细行中填写确认金额，确认金额为支付金额。
*  可以点击“选择借款单”选择已经付款的借款单，选择后，自动将所选的借款单关联到明细行上，填写冲销金额，系统会自动计算确认金额。
*  点击确认，表示当前报销单已经确认，将确认金额回写到报销单行。
*  点击确认并付款，弹出付款弹窗，在付款弹窗中选择结算方式并且选择付款银行账号。
*  取消确认，在未进行最终支付的状态下，可取消确认，删除相关业务单据。

付款

*  通过菜单路径，财务->费用报销->报销进入画面，在单据状态已确认下点击“付款”按钮，弹出付款画面；
*  在付款弹窗中选择结算方式并且选择付款银行账号。
*  取消付款，在未进行最终支付的状态下，点击取消付款，删除相关业务单据。

引用票夹

*  通过菜单路径，财务->费用报销->报销进入画面，填写报销单表头必输字段后，点击发票导入，选择引用票夹；
*  在使用该功能前需要提前完成参数配置中个人票夹的URL地址配置，另外个人票夹的报销账号需要在税务云中开通，目前税务云个人票夹登录账号为邮箱或手机号。
*  引用票夹画面带出个人票夹中的数据，可按照需要自行选择，勾选确定后，会将发票号码、发票代码、发票金额自动带动报销费用明细行上。当报销单核准后，会自动生成增值税发票档案。

电票导入

*  通过菜单路径，财务->费用报销->报销进入画面，填写报销单表头必输字段后，点击发票导入，选择电票导入；
*  在使用该功能前需要提前完成税务发票模块的税务云相关配置。
*  在弹出画面中点击选择文件，点击确定，该电子发票自动同步税务云进行查重验伪，通过验证的发票可继续操作，不通过的发票将无法继续后续操作。保存报销单后会自动生成电子发票对应的增值税发票档案。

纸票扫码

*  通过菜单路径，财务->费用报销->报销进入画面，填写报销单表头必输字段后，点击发票导入，选择纸票扫码；
*  在使用该功能前需要提前完成税务发票模块的税务云相关配置。
*  在弹出画面中，扫码枪扫码发票码，发票代码行解析出数字后，点击发票导入，gird列表会加载出该纸票对应的数据，点击确定，将发票导入费用明细行。保存报销单后自动生成对应的增值税发票档案。
