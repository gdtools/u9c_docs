
# 功能描述

本功能提供将费用报销系统中以下业务单据生成的交易分录，转为总账系统的记账凭证的处理。

产生交易分录的业务单据如下：

*  借款单
*  报销单

转总账主要功能如下：

*  可以将系统的交易分录转入总账系统生成记账凭证；
*  可以选择是否合并原始单据的交易分录生成记账凭证；
*  可以设定合并生成凭证的合并规则；
*  可以批量生成总账凭证；
*  可以联查交易分录相关的总账凭证和业务单据；

# 业务规则

*  启用费用报销（必做）
*  总账系统启用（必做）
*  总账系统账簿、凭证等相关设置完成（必做）
*  交易分录已经生成（必做）
*  定义转总账规则（必做）
*  定义调度方案 （可选）
