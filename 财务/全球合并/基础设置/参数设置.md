设置全球合并相关参数

###  **栏目说明** 
**基本页签** 

| 栏目  |说明   |
| ------------ | ------------ |
| 自动拷贝账簿转换规则  |当合并结构变更会添加个别账簿或者减少个别账簿，这时系统会自动将变更账簿的所有上级合并账簿进行替换，这个参数是选择当替换合并账簿后，个别账簿向替换后的合并账簿转换的账簿转换规则是否自动从上个版本复制过来： 选中：表示变更时自动拷贝上一版本账簿转换规则； 未选中：表示变更时不拷贝上一版本账簿转换规则，由用户手工编制； 此参数可以随时修改，只影响后续操作，不影响历史数据。   |
| 自动拷贝抵消分录模板  |  当合并结构变更会添加个别账簿或者减少个别账簿，这时系统会自动将变更账簿的所有上级合并账簿进行替换，这个参数是选择当替换合并账簿后，是否自动复制上个版本合并账簿中的抵消分录模板： 选中：表示变更时自动拷贝上一版本抵消分录模板； 未选中：表示变更时不拷贝上一版本抵消分录模板，由用户手工编制； 此参数可以随时修改，只影响后续操作，不影响历史数据。
|股权投资比例 | 股权投资比例精度，最大允许15位
|分录模板 | 分录模板是否产生金额是0的分录
