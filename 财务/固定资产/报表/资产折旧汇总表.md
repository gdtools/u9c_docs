
# 功能描述

本功能节点主要查看资产卡片折旧期间内折旧相关信息，包括影响本期折旧的期初信息、影响本期折旧的增减变动值、本期折旧额、期末信息，可以按期间、按类别、按卡片分别查看。如果当前资产组织存在下级资产组织，在当前资产组织中还可以查看下级资产组织的资产信息，实现了上级组织对下级组织的统一管理与监控。


# 业务规则

*  启用固定资产（必做）

# 栏目说明

资产折旧汇总表-查询条件

|栏目名称|说明|
|---|---|
|折旧账簿|资产折旧查找条件，参照输入折旧账簿。如果一次查询多个账簿的资产折旧信息时，折旧账簿的会计日历、本位币必须相同。|
|折旧期间范围|资产折旧查找条件，输入折旧期间范围：当前期间、上一期间、去年同期、指定期间|
|折旧期间|资产折旧查找条件，参照输入折旧期间。当折旧期间范围=指定期间时生效|
|资产类别|资产折旧查找条件，参照输入资产类别|
|资产组|资产折旧查找条件，参照输入资产组|
|资产编号|资产折旧查找条件，输入资产编号|
|资产名称|资产折旧查找条件，输入资产名称|
|卡片类型|资产折旧查找条件，参照输入卡片类型|
|使用状况|资产折旧查找条件，参照输入卡片使用状况|
|资产来源|资产折旧查找条件，参照输入卡片资产来源|
|核算部门|资产折旧查找条件，参照输入卡片核算部门|
|管理部门|资产折旧查找条件，参照输入卡片管理部门|

资产折旧汇总表-查询结果

|栏目名称|说明|
|---|---|
|使用年限|显示资产使用年限，按资产卡片查看折旧时显示值，否则为空|
|使用期间数|显示资产使用期间数，按资产卡片查看折旧时显示值，否则为空|
|累计折旧期间数|显示资产使用期间数，按资产卡片查看折旧时显示值，否则为空|
|期间折旧率|显示资产期间折旧率，，按资产卡片查看折旧时显示值，否则为空|
|期间原值|显示影响折旧的期初原值|
|期初累计折旧|显示影响折旧的期初累计折旧|
|期初净值|显示影响折旧的期初净值|
|期初减值准备|显示影响折旧的期初减值准备|
|期初减值准备|显示影响折旧的期初减值准备|
|期初可回收市值|显示影响折旧的期初可回收市值|
|原值增加|显示影响折旧的资产原值本期增加额|
|原值减少|显示影响折旧的资产原值本期减少额|
|折旧调增|显示影响本期折旧的累计折旧本期增加值|
|折旧调减|显示影响当期折旧的累计折旧本期减少值|
|减值准备增加|显示影响当期折旧的减值准备本期增加值|
|减值准备减少|显示影响当期折旧的减值准备本期减少值|
|本期折旧额|显示固定资产本期计提的折旧金额|
|期末原值|显示期末原值,等于期初原值+原值增加-原值减少|
|期末累计折旧|显示期末原值,等于期初累计折旧+折旧调增-折旧调减+本期折旧|
|期末净值|显示期末净值,等于期末原值-期末累计折旧|
|期末减值准备|显示期末减值准备,等于期初减值准备+减值准备增加-减值准备减少|
|期末可回收市值|显示期末减值准备,等于期末净值-期末减值准备|

# 操作说明

* 点击固定资产－>报表－>资产折旧汇总表按钮，进入资产折旧汇总报表查询条件画面。具体步骤如下所示：
*  第1步：输入报表查询条件
*  第2步：在‘栏目’页签选择报表需要显示项
*  第3步：在‘行分组’页签选择报表分组汇总项

第4步：选择完成后，点击‘确定’按钮，返回查询结果画面，点击‘取消’按钮，取消查询操作。。
