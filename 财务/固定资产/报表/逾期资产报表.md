
# 功能描述

本功能节点主要查看到截至期间止已经到期的资产情况。如果当前资产组织存在下级资产组织，在当前资产组织中还可以查看下级资产组织的资产信息，实现了上级组织对下级组织的统一管理与监控。

# 业务规则

*  启用固定资产（必做）

# 栏目说明

逾期资产报表-查询条件

|栏目名称|说明|
|---|---|
|资产组织|逾期资产查找条件，参照组织档案录入，可以选择当前资产组织及其下级资产组织|
|货主组织|逾期资产查找条件，参照资产组织对应的‘资产货主关系’档案录入|
|折旧账簿|逾期资产查找条件，参照输入折旧账簿。如果一次查询多个账簿的资产折旧信息时，折旧账簿的会计日历、本位币必须相同。|
|建账期间|逾期资产查找条件，输入建账期间范围，根据建账期间查找资产卡片|
|资产类别|逾期资产查找条件，参照输入资产类别|
|资产组|逾期资产查找条件，参照输入资产组|
|卡片类型|逾期资产查找条件，参照输入卡片类型，根据卡片类型查找资产卡片|
|资产卡片|逾期资产查找条件，参照输入资产卡片编号，根据卡片编号查找|
|资产编号|逾期资产查找条件，参照输入资产编号，根据资产编号查找资产卡片|
|资产名称|逾期资产查找条件，输入资产名称|
|资产原值|逾期资产查找条件，输入资产原值，根据资产原值查找资产卡片|
|资产净值|逾期资产查找条件，输入资产净值，根据资产净值查找资产卡片|
|资产可回收市值|逾期资产查找条件，输入资产可回收市值，根据资产可回收市值查找资产卡片|
|使用年限|逾期资产查找条件，输入资产使用年限，根据使用年限查找资产卡片|
|使用期间数|逾期资产查找条件，输入资产使用期间数，根据使用期间数查找资产卡片|
|截至期间|逾期资产查找条件，输入查找截至期间|
|提前期间数|逾期资产查找条件，输入查找提前期间数。为空表示查找到期期间〈截至期间的资产卡片；非空时，表示查找截至期间-提前期<到期期间<截至期间的资产卡片。|

# 操作说明

操作步骤

点击固定资产－>报表－>逾期资产报表按钮，进入逾期资产报表查询条件画面。具体步骤如下所示：

*  第1步：输入报表查询条件
*  第2步：在‘栏目’页签选择报表需要显示项
*  第3步：选择完成后，点击‘确定’按钮，返回查询结果画面，点击‘取消’按钮，取消查询操作。
