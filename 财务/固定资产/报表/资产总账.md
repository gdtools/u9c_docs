
# 功能描述

本功能主要用于查看反映折旧期间内资产价值情况的总账，可以按资产类别、核算部门、资产编号、资产名称、资产卡片汇总查看。如果当前资产组织存在下级资产组织，在当前资产组织中还可以查看下级资产组织的资产信息，实现了上级组织对下级组织的统一管理与监控。

# 业务规则

*  启用固定资产（必做）

# 栏目说明

资产总账-查询条件

|栏目名称|说明|
|---|---|
|资产组织|资产总账查找条件，参照组织档案录入，可以选择当前资产组织及其下级资产组织|
|货主组织|资产总账查找条件，参照资产组织对应的‘资产货主关系’档案录入|
|折旧账簿|资产总账查找条件，参照输入折旧账簿。如果一次查询多个账簿的资产增减变动信息时，折旧账簿的会计日历、本位币必须相同。|
|记账期间范围|资产总账查找条件，输入记账期间范围：当前期间、上一期间、去年同期、指定期间|
|记账期间|资产总账查找条件，参照输入折旧期间。当记账期间范围=指定期间时生效|
|资产类别|资产总账查找条件，参照输入资产类别|
|资产组|资产总账查找条件，参照输入资产组|
|资产编号|资产总账查找条件，参照输入资产编号|
|资产名称|资产总账查找条件，参照输入资产名称|
|卡片类型|资产总账查找条件，参照输入卡片类型|
|卡片编号|资产总账查找条件，参照输入卡片编号|
|核算部门|资产总账查找条件，参照输入核算部门|
|管理部门|资产总账查找条件，参照输入管理部门|

|累计折旧—期末|显示累计折旧期末值|
|资产净值—期末余额|显示资产净值期末值|
|减值准备—期初余额|显示减值准备期初值|

# 操作说明

操作步骤

点击固定资产－>报表－>资产总账按钮，进入资产总账报表查询条件画面。具体步骤如下所示：

第1步：输入报表查询条件

第2步：在‘栏目’页签选择报表需要显示项

第3步：在‘行分组’页签选择报表分组汇总项

第4步：选择完成后，点击‘确定’按钮，返回查询结果画面，点击‘取消’按钮，取消查询操作。
