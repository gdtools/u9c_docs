
# 功能描述

本功能节点主要查看资产卡片在折旧期间内的折旧费用分配信息。可以按类别汇总、按使用部门汇总、按项目汇总、按任务汇总。如果当前资产组织存在下级资产组织，在当前资产组织中还可以查看下级资产组织的资产信息，实现了上级组织对下级组织的统一管理与监控。

# 业务规则

*  启用固定资产（必做）

# 栏目说明

资产折旧分配汇总表-查询条件

|栏目名称|说明|
|---|---|
|资产组织|资产折旧分配汇总表查找条件，参照组织档案录入，可以选择当前资产组织及其下级资产组织|

|使用状况|资产折旧分配汇总表查找条件，参照输入资产使用状况|
|资产编号|资产折旧分配汇总表查找条件，参照输入资产编号|
|资产名称|资产折旧分配汇总表查找条件，参照输入资产名称|
|资产来源|资产折旧分配汇总表查找条件，参照输入资产来源|
|卡片类型|资产折旧分配汇总表查找条件，参照输入卡片类型|
|卡片编号|资产折旧分配汇总表查找条件，参照输入卡片编号|
|资产标签|资产折旧分配汇总表查找条件，参照输入资产标签号|
|使用部门|资产折旧分配汇总表查找条件，参照输入使用部门|

# 操作说明

操作步骤

点击固定资产－>报表－>资产折旧分配汇总表按钮，进入资产折旧分配汇总表查询条件画面。具体步骤如下所示：

第1步：输入报表查询条件

第2步：在‘行分组’页签选择报表分组汇总项

第3步：选择完成后，点击‘确定’按钮，返回查询结果画面，点击‘取消’按钮，取消查询操作。
