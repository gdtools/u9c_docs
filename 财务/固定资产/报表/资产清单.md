
# 功能描述

本功能节点主要查看资产组织记账期间的资产信息，可以按组织、部门、卡片、资产标签、账簿等多维度查看资产数量、金额、实物状况等信息。如果当前资产组织存在下级资产组织，在当前资产组织中还可以查看下级资产组织的资产信息，实现了上级组织对下级组织的统一管理与监控。


# 业务规则

*  启用固定资产（必做）

# 栏目说明

资产清单-查询条件

|栏目名称|说明|
|---|---|
|资产组织|资产查找条件，参照组织档案录入，可以选择当前资产组织及其下级资产组织|
|货主组织|资产查找条件，参照资产组织对应的‘资产货主关系’档案录入|
|折旧账簿|资产折旧查找条件，参照输入折旧账簿。如果一次查询多个账簿的资产折旧信息时，折旧账簿的会计日历、本位币必须相同。|
|记账期间范围|资产查找条件，输入记账期间范围：当前期间、上一期间、去年同期、指定期间|
|记账期间|资产查找条件，参照输入记账期间。当记账期间范围=指定期间时生效|
|资产类别|资产查找条件，参照输入资产类别|
|资产组|资产查找条件，参照输入资产组|
|资产编号|资产查找条件，输入资产编号|
|资产名称|资产查找条件，输入资产名称|
|资产卡片|资产查找条件，参照输入资产卡片编号|
|资产标签|资产查找条件，参照输入资产标签|
|核算部门|资产查找条件，参照输入卡片核算部门|
|管理部门|资产查找条件，参照输入卡片管理部门|
|使用组织|资产查找条件，参照输入资产标签的使用组织|
|使用部门|资产查找条件，参照输入资产标签的使用部门|
|包含关闭卡片|资产查找条件，下拉选则是，展示关闭卡片信息，选择否，排除关闭卡片信息，默认为否|

# 操作说明

点击固定资产－>报表－>资产清单按钮，进入资产清单查询条件画面。具体步骤如下所示：

第1步：输入报表查询条件、

第2步：在‘栏目’页签选择报表需要显示项

第3步：在‘行分组’页签选择报表的分组汇总项

第4步：选择完成后，点击‘确定’按钮，返回查询结果画面，点击‘取消’按钮，取消查询操作。。
