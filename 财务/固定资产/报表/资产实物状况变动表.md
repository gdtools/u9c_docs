
# 功能描述

本功能节点主要查看资产标签的位置、管理部门、负责人变更情况。如果当前资产组织存在下级资产组织，在当前资产组织中还可以查看下级资产组织的资产信息，实现了上级组织对下级组织的统一管理与监控。


# 业务规则

*  启用固定资产（必做）

# 栏目说明

资产实物状况变动报表-查询条件

|栏目名称|说明|
|---|---|
|资产组织|资产实物状况变动表查找条件，参照组织档案录入，可以选择当前资产组织及其下级资产组织|
|货主组织|资产实物状况变动表查找条件，参照资产组织对应的‘资产货主关系’档案录入|
|资产类别|资产实物状况变动表查找条件，参照输入资产类别|
|资产组|资产实物状况变动表查找条件，参照输入资产组|
|资产编号|资产实物状况变动表查找条件，参照输入资产编号，根据资产编号查找资产卡片|
|资产名称|资产实物状况变动表查找条件，输入资产名称|
|资产卡片|资产实物状况变动表查找条件，参照输入资产卡片编号，根据卡片编号查找|
|资产标签|资产实物状况变动表查找条件，参照输入资产标签|
|单据日期|资产实物状况变动表查找条件，参照输入资产变更单据日期|
|单据类型|资产实物状况变动表查找条件，参照输入资产变更单单据类型|
|单据编号|资产实物状况变动表查找条件，参照输入资产变更单据编号|

资产实物状况变动表报表-查询结果

|栏目名称|说明|
|---|---|
|资产卡片|显示资产卡片编号|
|资产编号|显示资产编号|
|资产标签|显示资产资产标签号|
|资产卡片|显示资产资产标签的卡片编号|
|资产编号|显示资产编号|
|资产名称|显示资产名称|
|单据编号|显示变更单单号|
|单据日期|显示变更单日期|
|变更前位置|显示资产变更前资产位置|
|变更后位置|显示资产变更后资产位置|

# 操作说明

操作步骤

点击固定资产－>报表－>资产实物状况变动表按钮，进入资产实物状况变动表查询条件画面。具体步骤如下所示：

第1步：输入报表查询条件

第2步：在‘栏目’页签选择报表需要显示项

第3步：选择完成后，点击‘确定’按钮，返回查询结果画面，点击‘取消’按钮，取消查询操作。
