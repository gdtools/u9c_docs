
# 功能描述

资产减值准备处理是固定资产日常业务的一种处理，包括计提减值准备和转回减值准备。本功能节点主要提供如下功能：

*  手工生成减值准备单计提资产减值准备
*  手工生成减值准备单转回资产减值准备
*  对资产组进行资产减值
*  审核资产减值准备单或取消审核
*  可以查询会计分录
*  可以进行批量减值

# 业务规则

*  启用固定资产（必做）
*  定义折旧账簿（必做）
*  定义资产减值准备单类型（必做）
*  定义资产组

# 操作说明

[]()资产减值准备

操作前提

*  如果进行计提减值准备，则要求存在已核准资产卡片
*  如果进行减值准备转回，则要求存在已计提减值准备的资产卡片

操作步骤

点击财务－>固定资产－>减值准备按钮，进行入资产减值处理主画面。具体步骤如下所示。

*  第1步：点击新增按钮，弹出‘资产查找画面’；
*  第2步：在‘资产查询’画面中，先选择处理类型，然后再输入资产筛选条件，从而确定需计提资产减值准备或转回减值准备的资产；
*  第3步：在输入筛选条件后，点确定按钮，弹出‘资产减值单’画面；
*  第4步：在资产减值面中，需要用户选择单据类型，输入单据日期,输入计提减值准备金额或转回减值准备金额，同时用户可以点击行上的新增、插入按钮，增加行，追加需要进行减值准备处理的资产，也可以通过点击删除按钮，取消不需要进行减值处理的资产；
*  第5步：输入所有资产的计提减值准备金额或转回减值准备金额，点击保存按钮保存资产减值准备单，点击放弃按钮取消本次操作。

资产组减值准备

资产组减值准备业务主要是对资产组计提减值准备或转回减值准备。进行减值准备业务时，系统会将资产组减值金额按比例分摊到组内的资产卡片

操作前提

*  计提减值准备时，存在资产组且资产组内存在资产卡片
*  转回减值准备时，存在已计提减值准备的资产组

操作步骤

点击财务－>固定资产－>减值准备按钮，进行入资产减值处理主画面。具体步骤如下所示。

*  第1步：点击新增按钮，弹出‘资产查找画面’；
*  第2步：在‘资产过滤条件’画面中，先选择货主组织、减值类型，选择资产组减值准备，然后再输入其他筛选条件，从而确定需计提资产减值准备或转回减值准备的资产组；
*  第3步：在输入筛选条件后，点确定按钮，弹出‘资产减值单’画面；
*  第4步：在资产减值面中，需要用户选择单据类型，输入单据日期,输入资产组计提减值准备金额或转回减值准备金额，同时用户可以点击行上的**新增、插入**按钮，增加行，追加需要进行减值准备处理的资产组，也可以通过点击**删除**按钮，取消不需要进行减值处理的资产组；
*  第5步：输入所有资产组的减值信息，可以在卡片页签中选择卡片手工录入减值信息，如果用户手工录入卡片减值信息，则该行的‘自动分摊’标记将被取消，表示该行不参与系统分摊，如果手工录入后，将‘自动分摊’标记重新选择，则手工录入的值将被认为无效，该行仍然参与系统分摊。录入完成后，可以点击‘分摊’按钮，先查看系统分摊结果，然后再点击**保存**按钮保存资产减值单，也可以不击‘分摊’，直接点‘保存’，系统会将资产组的减值 分摊到资产卡片并保存资产减值单，点击**放弃**按钮取消本次操作.

批量减值

批量减值功能主要是对减值单行数据进行批量输入操作，减少用户重复输入的工作量

操作步骤

减值准备单行存在需要进行计提减值准备或减值准备转回资产后，可以按如下所示步骤进行批量减值，批量录入资产减值数据。

*  第1步：点击批量减值按钮，弹出‘批量减值画面’；
*  第2步：在‘批量减值’画面中，选择批量减值准备金额录入方式：按数值或按百分比，录入减值准备金额或减值准备百分比。
*  第3步：在输入完成后，点确定按钮，返回资产减值准备主画面，系统自动更新减值准备单行信息。
