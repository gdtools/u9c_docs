
# 功能描述

资产折旧单主要查看各个期间由卡片、资产计算生成的折旧单，查看各个折旧单资产折旧汇总日志及资产折旧计划分配汇总日志。


# 业务规则

*  启用固定资产（必做）
*  定义折旧账簿（必做）

# 按钮说明

<回滚>：对当前折旧单计提的折旧额回滚，若已经结转，不允许该操作。

<交易分录>：查看当前折旧单生成的交易分录。

# 操作说明

折旧单

**操作前提**

*  存在已计提折旧的资产卡片或生成折旧计算

操作步骤

点击财务－>固定资产－>折旧单按钮，进行入折旧单画面。
