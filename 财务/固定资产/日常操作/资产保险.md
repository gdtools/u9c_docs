
# 功能描述

公司可以给比较重要、贵重的资产进行资产保险，需要生成保险单记录保险的具体内容。资产保险本节点主要是在系统中增加保险单，用于记录资产投保情况。


# 业务规则

*  启用固定资产（必做）
*  定义供应商档案（必做）
*  定义保险单单据类型（必做）
*  定义联系对象档案

# 操作说明

[]()新建保险单

操作前提

*  存在已审核资产卡片
*  当前折旧期间未结账

操作步骤

点击**固定资产－>资产保险**按钮，进行入资产保险处理主画面。具体步骤如下所示。

*  **第1步：**点击**新增**按钮，弹出‘资产卡片查找’画面，
*  **第2步：**录入卡片筛选条件，点**确定**，返回资产保险主画面，
*  第3步：录入保险单头信息，同时用户可以点击行上的新增、插入按钮，增加行，追加需要进行保险的资产，也可以通过点击删除按钮，取消不需要进行保险的资产。
*  第4步：点击保存按钮，保存生成的保险单。
