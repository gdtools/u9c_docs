
# 功能描述

资产调拔业务是固定资产日常业务的一种，资产调出主要完成资产从当前资产组织调出到其他资产组织。资产调出可以分是‘非在途管理’和‘在途管理’，非在途管理时，调出单审核即减少资产，资产在途期间，调出资产组织不再对资产计提折旧；在途管理 时，资产在途期间，调出资产组织仍然对资产计提折旧，但不能进行其他操作，只有当调入资产组织进行调入确认后才能关闭调出单，从而减少资产。

如果调入核算组织与调出核算组织不同，且调拔价格不为零，则在资产调出后可以在调出核算组织中根据调出单进行应收立账,调入单审核后可以在调入核算组织中根据调入单进行应付立账。

本功能节点主要提供如下功能：

*  手工生成调出单进行资产调出
*  手工关闭调出单
*  手工取消关闭
*  可以查询会计分录


# 业务规则

*  启用固定资产（必做）
*  定义折旧账簿（必做）
*  定义资产调出单单据类型（必做）

# 栏目说明

资产调出单—表头画面

|栏目名称|说明|
|---|---|
|调出货主组织|调出资产对应的货主组织，只能选择资产货主关系中的货主组织。|
|单据类型|用户选择资产调出单的单据类型|
|单号|根据资产调出单单据类型中的编号方式由系统生成或用户输入。|
|日期|默认为当前登录日期，用户可改。|
|调出核算组织|对调出货主组织调出固定资产业务进行应收核算的组织，用户只能选择当前资产组织中‘货主核算关系’表中调出货主组织对应的核算组织。|
|调入资产组织|用户参照组织档案选择的调入资产组织，可以是当前资产组织，当调入资产组织与调出资产组织相同时，调入货主组织必须与调出货主组织不同。|
|调入货主组织|参照组织档案选择的调入货主组织，只能选择与调入资产组织存在资产货主关系的货主组织。当调入资产组织与调出资产组织相同时，调入货主组织必须与调出货主组织不同。|
|调入核算组织|对调入货主组织调入固定资产业务进行应付核算的组织，用户只能选择调入资产组织中‘货主核算关系’表中调出货主组织对应的核算组织。|
|调拔币种|用户录入的资产调拔币种，默认为调出主账簿的本位币，可改。|
|调出价格|调出单中调出资产的调拔价格，等于行上所有调出资产调出价格的合计。|
|在途管理|资产调出是否进行在途管理。选择在途管理，表示资产在调拔途中仍归调出资产组织管理，选择非在途管理，表示资产在调拔途中调出资产组织不再对其进行管理。|
|调入单号|调入资产组织进行资产调入时生成的调入单号，调入资产组织生成调入单后回写。|
|调入确认|是否调入确认，调入资产组织对资产调入单审核后进行回写。|
|立账金额|显示调出单生成应收后的、用调拔币种表示的立账金额。汇总行上的应收立账金额生成，当立账金额等于调出价格时，表示该调出单已全部生成应收。|
|调拔原因|用户录入的进行资产调拔的原因。|
|关闭日期|在途管理，在调出单关闭时根据录入的关闭日期回写。非在途管理等于单据日期。|
|状态|显示资产调出单状态,用户不可修改。|
|折旧账簿|显示主折旧账簿，点击该按钮可查看资产调出单的所有折旧账簿信息。|
|记账期间|显示单据日期在折旧账簿中的记账期间。|
|影响折旧期间|显示资产调出影响折旧的期间。|
|财务关闭|对应的账簿当前期间是否财务关闭。|

# 操作说明

资产调出

调出非在途管理时，可以对资产卡片进行全部调出，也可以进行部分调出，调出在在途管理时，资产卡片必须全部调出，全部调出后资产卡片将变为关闭状态，不能再进行任何业务处理，部分调出后，资产卡片数量变为调出后剩余资产数量，未调出资产还可以进行日常业务。

调出在途管理时，在调出当期必须先计提折旧，在关闭期间如果没有计提折旧，调出单关闭时系统会自动计提当期折旧；调出非在途管理时，如果当期未计提折旧，调出单审核关闭时系统会自动计提当期折旧。调出资产卡片属于资产组时，调出单关闭当期必须先计提折旧。

**操作前提**

*  存在已核准的资产卡片

**操作步骤**

点击财务－>固定资产－>资产调出按钮，进行入资产调出主画面。具体步骤如下所示。

*  第1步：点击新增按钮，弹出‘资产查找画面’；
*  第2步：在‘资产查找’画面中，选择调出货主组织、调入资产组织，然后再输入资产筛选条件，从而确定需要调出的资产；
*  第3步：在输入筛选条件后，点确定按钮，弹出‘资产调出单’画面；
*  第4步：在资产调出单画面中，需要用户选择单据类型，输入单据日期、调入货主组织、调出核算组织、调入核算组织、调拔币种、调拔原因，选择是否进行在途管理。输入资产卡片调出数量，选择卡片中调出标签，录入调出价格。用户可以点击行上的新增、插入按钮，增加行，追加需要进行调出的资产，也可以通过点击删除按钮，取消不需要进行调出的资产；
*  第5步：输入所有资产的调出信息，点击保存按钮保存资产调出单，点击放弃按钮取消本次操作。

关闭资产调出单

资产调出单‘是否在途管理’＝F时，调出单审核即关闭；资产调出单‘是否在途管理’＝T时，只有调入确认后才能通过‘关闭’按钮进行关闭。
