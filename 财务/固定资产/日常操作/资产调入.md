
# 功能描述

资产调拔业务是固定资产日常业务的一种，资产调入主要完成资产从其他资产组织调入到当前资产组织。

# 业务规则

*  启用固定资产（必做）
*  定义折旧账簿（必做）
*  定义资产调入单单据类型（必做）

# 操作说明

**操作前提**

*  调出资产组织中的调出单已审核

操作步骤

点击财务－>固定资产－>资产调入按钮，进行入资产调入处理画面。具体步骤如下所示。

*  第1步：点击新增按钮，弹出‘资产调入－调出单查找画面’；
*  第2步：录入查找条件后，点击确定按钮，弹出‘资产调入－调出单参照画面’；
*  第3步：在‘资产调入－参照调出单画面’画面中，录入单据类型，选择调出单；
*  第4步：点确定按钮，系统根据选择的调出单生成调入单。返回生成的第一张调入单。
