
# 功能描述

资产处置处理是固定资产日常业务的一种处理，由于报废、出售、盘亏等原因，资产已不存在了，需要对资产进行资产处置处理。本功能节点主要提供如下功能：

*  手工生成处置单进行资产处置
*  进行盘亏处置
*  审核资产处置单或取消审核
*  可以查询交易分录
*  可以查资产卡片及其他单据

# 业务规则

*  启用固定资产（必做）
*  定义折旧账簿（必做）
*  定义资产处置单类型（必做）

# 操作说明

[]()资产处置

可以对资产卡片进行全部处置，也可以进行部分处置，全部处置后资产卡片将变为关闭状态，不能再进行任何业务处理，部分处置后，资产卡片数量变为处置后剩余资产数量，未处置资产还可以进行日常业务。

资产处置时，如果资产卡片属于资产组，则在处置当期必须先计提折旧，否则不能进行处置；如果卡片不属于资产组，则当期未提折旧时，可以进行处置，处置单审核时系统会自动计提当期折旧。

操作前提

*  存在已核准的资产卡片

操作步骤

点击固定资产－>资产处置按钮，进行入资产处置主画面。具体步骤如下所示。

*  第1步：点击新增按钮，弹出‘资产查找画面’；
*  第2步：在‘资产查找’画面中，输入筛选条件，从而确定需进行资产处置的卡片；
*  第3步：在输入筛选条件后，点确定按钮，返回‘资产处置单’画面；
*  第4步：在资产处置画面中，需要用户选择单据类型，输入单据日期,输入资产卡片处置数量，选择卡片中处置资产．用户可以点击行上的新增、插入按钮，增加行，追加需要进行处置的资产，也可以通过点击删除按钮，取消不需要进行处置的资产；
*  第5步：输入所有资产的处置信息，点击保存按钮保存资产处置单，点击放弃按钮取消本次操作。

盘亏处置

操作前提

*  存在已盘点且生成了盘点差异表的资产卡片

操作步骤

点击固定资产－>资产处置按钮，进行入资产处置主画面。具体步骤如下所示。

*  第1步：点击盘亏处置按钮，弹出‘盘亏处置－盘点差异表查找画面’；
*  第2步：在‘盘亏处置－盘点差异表查找画面’中，输入盘点差异表查找条件；
*  第3步：在输入盘点差异表查找条件后，点确定按钮进行查找，弹出‘盘亏[]()[]()处置—盘点差异表选择画面’，本画面中列出了所有符合查找条件的盘点差异表，用户可以通过选择或者不选择来确定需要进行资产处置的盘点差异表；
*  第4步：选择需要进行资产处置的盘点差异表后，点确定按钮，返回‘资产处置单画面’；
*  第5步：在资产处置画面中，需要用户选择单据类型，输入单据日期,输入资产卡片处置数量，选择卡片中处置资产．用户可以点击行上的新增、插入按钮，增加行，追加需要进行处置的资产，也可以通过点击删除按钮，取消不需要进行处置的资产；
*  第6步：输入所有资产的处置信息，点击保存按钮保存资产处置单，点击放弃按钮取消本次操作。
