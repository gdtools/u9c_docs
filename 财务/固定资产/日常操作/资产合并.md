
# 功能描述

资产合并业务主要是根据企业管理需要，将多张资产卡片中的资产合并成一张资产卡片进行管理。合并前卡片可以是单数量卡片也可以是多数量卡片，可以根据合并单中的合并后卡片信息生成新的资产卡片。


# 业务规则

*  启用固定资产（必做）
*  定义折旧账簿（必做）
*  定义资产合并单单据类型（必做）

# 操作说明

资产合并

资产合并主要是将多张资产卡片中的资产合并成一张资产卡片进行管理。

**操作前提**

*  存在已核准的资产卡片

操作步骤

点击财务－>固定资产－>资产合并按钮，进行入资产合并主画面。具体步骤如下所示。

*  第1步：点击新增按钮，弹出‘资产查找画面’；
*  第2步：在‘资产查找’画面中，选择货主组织、资产卡片等资产筛选条件，从而确定需要进行合并的资产；
*  第3步：在输入筛选条件后，点**确定**按钮，弹出‘资产合并单’画面；
*  第4步：在资产合并单画面中，需要用户选择单据类型，输入单据日期、合并原因等信息。用户可以点击行上的新增、插入按钮，增加行，追加需要进行合并的资产，也可以通过点击删除按钮，取消不需要进行合并的资产，但是必须保证本次合并至少有两张资产卡片；
*  第5步：输入合并信息后，点击**操作**－>**资产合并**按钮，系统根据合并前资产卡片信息生成合并资产卡片信息；
*  第6步：生成合并后资产卡片信息后，点‘保存’按钮保存资产合并。

确认

资产合并单保存后，在资产合并界面点击操作－>确认按钮，系统根据合并单中合并后资产卡片信息自动生成合并后资产卡片，合并后卡片编号、资产标签号回写到合并单中，确认后合并后资产卡片信息不可修改，如需修改只能在卡片界面中进行修改。

取消确认

资产合并确认后，如果需要对合并单进行修改，可以在资产合并界面点击操作－>取消确认按钮，系统会自动删除合并后资产卡片。
