
# 功能描述

资产拆分主要是根据企业管理需要，将一张资产卡片中的资产拆分成多张资产卡片进行管理。拆分前卡片可以是单数量卡片也可以是多数量卡片，可以根据拆分单中的拆分后卡片信息生成资产卡片。

# 业务规则

*  启用固定资产（必做）
*  定义折旧账簿（必做）
*  定义资产拆分单单据类型（必做）

# 操作说明

资产拆分

资产拆分主要是将一张资产卡片中的资产拆分成多张资产卡片进行管理。

**操作前提**

*  存在已核准的资产卡片

操作步骤

点击财务－>固定资产－>资产拆分按钮，进行入资产拆分单主画面。具体步骤如下所示。

*  第1步：点击‘被拆分卡片’的参照按钮，选择要进行资产拆分的资产卡片；
*  第2步：在拆分单表头录入单据类型、日期、拆分卡片数、拆分原因；
*  第3步：在‘拆分前卡片标签’页签中输入‘拆分至卡片’的值，决定当前标签拆分后在第几张卡片进行管理；
*  第4步：输入完成后，点击操作－>资产拆分按钮，系统根据拆分前资产卡片信息生成拆分后资产卡片信息；
*  第5步：生成拆分后资产卡片信息后，点‘**保存**’按钮保存资产拆分单。

确认

资产拆分单保存后，在资产拆分界面点击操作－>确认按钮，系统根据拆分单中拆分后资产卡片信息自动生成拆分后资产卡片，拆分后卡片编号、资产标签号回写到拆分单中，确认后拆分单中拆分后卡片信息不可修改，如需修改只能在卡片界面中进行修改。

取消确认

资产拆分确认后，如果需要对拆分单进行修改，可以在资产拆分界面点击**操作**－>**取消确认**按钮，系统会自动删除拆分后资产卡片。
