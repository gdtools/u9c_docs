
# 功能描述

资产重估处理是固定资产日常业务的一种处理，包括与重估原值、重估净值及使用年限重估。本功能节点主要提供如下功能：

*  新增重估单进行资产重估
*  审核资产重估单或取消审核
*  对资产组进行资产重估
*  可以查询会计分录
*  可以进行批量重估

# 业务规则

*  启用固定资产（必做）
*  定义折旧账簿（必做）
*  定义资产重估单类型（必做）
*  定义重估原因（必做）
*  定义资产组

# 操作说明

[]()资产重估

操作前提

*  存在已核准的资产卡片
*  如果资产变别中的变更价值当期有效，则资产在要进行重估的折旧账簿中没有计提过折旧

操作步骤

点击固定资产－>资产重估按钮，进入资产重估处理主画面。具体步骤如下所示。

*  第1步：点击新增按钮，弹出‘资产查找画面’；
*  第2步：在‘资产查找’画面中，输入筛选条件，从而确定需进行资产重估的资产；
*  第3步：在输入筛选条件后，点确定按钮，弹出‘资产重估单’画面；
*  第4步：在资产重估画面中，需要用户选择单据类型、重估原因、是否重估原值，输入单据日期,根据实际重估情况，输入重估后资产信息，同时用户可以点击行上的新增、插入按钮，增加行，追加需要进行重估的资产，也可以通过点击删除按钮，取消不需要进行重估的资产；
*  第5步：输入所有资产的重估后信息，点击保存按钮保存资产重估单，点击放弃按钮取消本次操作。

资产组重估

资产组重估业务主要是对资产组进行资产重估。进行资产组重估时，系统会将资产组重估后金额按比例分摊到组内的资产卡片

操作前提

*  资产组中存在资产卡片
*  资产卡片已核准

操作步骤

点击财务－>固定资产－>资产重估按钮，进入资产重估处理主画面。具体步骤如下所示。

*  第1步：点击新增按钮，弹出‘资产查找画面’；
*  第2步：在‘资产查找’画面中，输入筛选条件，从而确定需进行资产重估的资产；
*  第3步：在输入筛选条件后，点**确定**按钮，弹出‘资产重估单’画面；
*  第4步：在资产重估画面中，需要用户选择单据类型、重估原因、是否重估原值，输入单据日期,根据实际重估情况，输入重估后资产信息，同时用户可以点击行上的**新增**、**插入**按钮，增加行，追加需要进行重估的资产，也可以通过点击**删除**按钮，取消不需要进行重估的资产；
*  第5步：输入所有资产组的重估后信息，可以在卡片页签中选择卡片手工录入重估后的信息，如果用户手工录入卡片重估后信息，则该行的‘自动分摊’标记将被取消，表示该行不参与系统分摊，如果手工录入后，将‘自动分摊’标记重新选择，则手工录入的值将被认为无效，该行仍然参与系统分摊。录入完成后，可以点击‘分摊’按钮，先查看系统分摊结果，然后再点击保存按钮保存资产重估单，也可以不击‘分摊’，直接点‘保存’，系统会将资产组的重估价值分摊到资产卡片并保存资产重估单，点击放弃按钮取消本次操作。

批量重估

批量重估功能主要是对重估单行数据进行批量输入操作，减少用户重复输入的工作量

操作步骤

重估单行存在需要进行重估资产后，可以按如下所示步骤进行批量重估，批量录入重估后资产信息。

*  第1步：点击批量重估按钮，弹出‘批量重估画面’；
*  第2步：在‘批量重估’画面中，选择增量类型，录入重估原值增量、净值增量、使用年限增量、使用期间增量
*  第3步：在输入完成后，点确定按钮，返回资产重估主画面，系统自动更新重估单行信息。
