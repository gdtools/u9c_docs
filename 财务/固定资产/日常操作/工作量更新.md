
# 功能描述

本功能节点主要是录入资产卡片折旧期间的资产工作量，用于计提折旧的依据，适用于折旧方法=工作量法的资产卡片。

# 业务规则

*  启用固定资产（必做）

# 栏目说明

工作量更新

|栏目名称|说明|
|---|---|
|货主组织|选择需要进行工作量更新的资产卡片的货主组织|
|折旧账簿|选择需要输入资产工作量的折旧账簿。|
|折旧期间|选择需要输入资产工作量的折旧期间。|
|卡片编号|显示在折旧账簿的折旧期间内需要计提折旧且折旧方法=工作量法的资产卡片|
|资产名称|显示资产名称。|
|工作量单位|显示资产卡片的工作量计量单位。|
|预计工作量|显示资产卡片预估工作量。|
|累计工作量|显示资产卡片累计工作量。|
|上期工作量|显示资产卡片上期录入的资产工作量。|
|资产工作量|输入本期资产卡片资产工作量。|
|开始日期|折旧期间开始日期。|
|结束日期|折旧期间结束日期。|

# 按钮说明

<继承上期工作量>：点击后本期工作量=上期工作量。

<清除工作量>：清除本期工作量、累计工作量。

# 操作说明

录入资产工作量

**操作前提**

*  存在折旧方法=工作量法的已审核资产卡片

操作步骤

点击固定资产－>工作量更新按钮，弹出工作量更新主界面。具体步骤如下所示。

*  第1步：选择需要录入资产工作量的折旧账簿
*  第2步：选择需要录入资产工作量的折旧期间
*  第3步：在行中录入‘资产工作量’
*  第4步：录入全部资产的当期工作量后，点保存，完成资产工作量更新。
*  提示：用户可以通过操作－>继承上期工作量功能快速录入卡片资产工作量；也可以通过操作－>清除工作量，批量取消录入的资产工作量，重新输入资产工作量。

注意：资产卡片使用工作量法计提折旧时，应该在折旧之前录入资产工作量，否则本期折旧按照工作量=0计提折旧。
