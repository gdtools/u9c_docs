
# 功能描述

本功能节点主要是按期间、分账簿取消资产卡片已计提折旧，同时如果折旧回滚不成功可以查看折旧回滚报告查看不成功原因。


# 业务规则

*  启用固定资产（必做）

# 栏目说明

折旧回滚画面

|栏目名称|说明|
|---|---|
|货主组织|选择进折旧回滚的货主组织|
|资产组|选择进行折旧回滚的资产组，加入资产组的卡片必须按组回滚折旧。|
|折旧账簿|选择要进行折旧回滚的折旧账簿|
|折旧期间|显示可折旧回滚的折旧期间|

# 按钮说明

<折旧回滚>：折旧回滚。

<折旧回滚报告>：查看折旧回滚报告情况。

<折旧计算>：导航到[折旧计算](/detail/2ead8be14f254ecd8a6a0487dd821c39)设置功能节点。

<期末结转>：导航到[期末结账](/detail/26a15ec7f81c4f34b62b7e5a4d742a21)设置功能节点。

# 操作说明

折旧回滚

折旧回滚只能按照折旧期间从大到小的顺序回滚，如果当前折旧期间存在不能回滚的资产卡片，则不能回滚上期折旧。参照应用专题：折旧回滚

**操作前提**

*  进行折旧回滚的期间已经计提折旧
*  折旧回滚期间未结账

操作步骤

点击固定资产－>折旧回滚按钮，进入折旧回滚画面。具体步骤如下所示。

*  第1步：选择需要进行折旧回滚的货主组织、折旧账簿，如果是对资产组进行折旧回滚还要选择资产组
*  第2步：点击折旧回滚按钮，系统自动取消符合折旧回滚条件的资产卡片折旧

查看折旧回滚报告

折旧回滚报告主要用于在执行折旧回滚后，查看哪些卡片折旧回滚不成功及不成功的原因，以便能及时排查原因。

操作步骤

点击固定资产－>折旧回滚－>折旧回滚报告按钮
