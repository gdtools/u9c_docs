
# 功能描述

本功能节点主要是按期间、分账簿对资产卡片计提折旧，主要提供如下功能：

*  计提资产折旧
*  可以查询折旧报告
*  可以查询交易分录

# 业务规则

*  启用固定资产（必做）

# 栏目说明

折旧计算画面

|栏目名称|说明|
|---|---|
|货主组织|选择进行计提折旧的货主组织|
|资产组|选择进行计提折旧的资产组，加入资产组的卡片必须按组计提折旧，可以多选|
|折旧账簿|选择要进行折旧计算的折旧账簿|
|折旧期间|显示可计提折旧的最小折旧期间，只要最小期间存在未提折旧卡片，则显示该期间|
|折旧日期|输入计提折旧的日期|

# 按钮说明

<折旧计算>：按照所选计算折旧，计提折旧额。

<调度执行>：设置调度，执行折旧计算。

<折旧报告>：查看折旧生成情况。

<交易分录>：查看最近一期折旧交易分录情况。

<折旧回滚>：导航到[折旧回滚](/detail/defc34044b2f413586b501a5beb468bd)设置功能节点。

<期末结转>：导航到[期末结账](/detail/26a15ec7f81c4f34b62b7e5a4d742a21)设置功能节点。

# 操作说明

折旧计算

折旧计算只能按照折旧期间从小到大的顺序计提，如果最小折旧期间存在满足折旧条件但尚未计提的资产卡片，则不能计提下期折旧。

**操作前提**

*  计提折旧期间存在至少存在一张需提折旧的资产卡片
*  资产卡片已经审核
*  计提折旧的期间未结账

操作步骤

点击固定资产－>折旧计算按钮，进入折旧计算画面。具体步骤如下所示。

*  第1步：选择需要进行折旧的货主组织
*  第2步：选择需要进行折旧的资产组，如果不是对资产组计提折旧，可以不选择。
*  第3步：选择需要进行折的折旧账簿
*  第4步：输入计提折旧的日期
*  第5步：点击折旧计算按钮，系统自动对所有符合条件的资产卡片计提折旧

查看折旧报告

折旧报告主要用于在计提折旧后，查看哪些卡片计提不成功及不成功的原因，以便能及时排查原因。

操作步骤

点击固定资产－>折旧计算－>折旧报告按钮

查看交易分录

资产折旧生成的交易分录可以通过折旧计算画面的‘交易分录’按钮查看，由于可以随时对未折旧卡片进行折旧计算，所以通过该按钮只能查看最近一次折旧生成的交易分录，如果想查看所有的折旧交易分录，只能通过功能点‘交易分录查询’查看。

操作步骤

点击固定资产－>折旧计算－>交易分录按钮
