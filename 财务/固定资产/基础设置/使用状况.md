
# 功能描述

在本节点主要进行资产使用状况的设置，资产使用状况表明了资产的使用状态，便于管理者对资产使用情况进行管理，提高资产使用效率。


# 业务规则

*  在参数设置中定义资产使用状况编码规则（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|上级使用状况|根据用户录入的编码，系统自动显示出上级资产使用状况，用户不可修改。如果当前资产使用状况是第一级，则为空。|
|编码规则|资产使用状况档案的编码层级规则，系统默认为２-2-2，使用后不可修改。|
|编码|资产使用状况档案编码，必须符合编码规则的规定，用户必需输入。|
|名称|资产使用状况名称|
|使用类型|枚举值，在建工程、在用、处置、停用|

# 操作说明

使用状况下发

用户可以将当前资产组织的使用状况下发到其他资产组织

操作步骤

*  第1步：点击**基础设置**－>**下发档案设置**按钮，进入下发对象设置界面；
*  第2步：选择使用状况，将‘是否下发’设置为‘是’；
*  第3步：点击**固定资产**－>**使用状况**按钮，进入使用状况界面，选择需下发的使用状况；
*  第4步：点击**后续处理**－>**下发**按钮，进入下发界面；
*  第5步：在下发界面中选择要下发的目的资产组织，点‘**确定**’后，系统将当前使用状况下发到目的资产组织。

取消使用状况下发

用户可以将下发到目的资产组织的使用状况取消下发

操作步骤

*  第1步：点击**固定资产**－>**使用状况**按钮，进入**使用状况**界面，选择需取消下发的使用状况；
*  第2步：点击**后续处理**－>**取消下发**按钮，进入取消下发界面；
*  第3步：在取消下发界面中选择需要取消下发的目的资产组织，点‘**确定**’后，系统将下发到目的组织的使用状况取消下发。
