
# 功能描述

在本节点主要进行折旧方法的设置。折旧方法是计算固定资产折旧的方法，用户可以选择适合企业管理需要的折旧方法。系统预置了11种折旧方法，如果不能满足企业的需要，可以通过定义折旧率公式、折旧额公式来自定义折旧方法。

系统预置的11种折旧方法，具体使用方法请参见应用专题：多折旧方法。

# 栏目说明

折旧方法设置画面

|栏目名称|说明|
|---|---|
|类型|资产折旧方法的分类，系统根据有关规定设定了几种类型：直线法、年限法、工作量法、日折旧法|
|折旧率公式|计算固定资产折旧率的公式|
|折旧额公式|计算固定资产折旧额的公式|

# 操作说明

折旧方法下发

用户可以将当前组织自定义的折旧方法下发到其他资产组织

操作步骤

*  第1步：点击**基础设置**－>**下发档案设置**按钮，进入下发对象设置界面；
*  第2步：选择折旧方法，将是否下发设置为**是**；
*  第3步：点击**固定资产**－>折旧方法按钮，进入折旧方法界面，选择需下发的自定义折旧方法；
*  第4步：点击**后续处理**－>**下发**按钮，进入下发界面；
*  第5步：在下发界面中选择要下发的目的资产组织，点**确定**后，系统将当前折旧方法下发到目的资产组织。

取消折旧方法下发

用户可以将下发到目的资产组织的折旧方法取消下发

操作步骤

*  第1步：点击**固定资产**－>**折旧方法**按钮，进入**折旧方法**界面，选择需取消下发的使折旧方法；
*  第2步：点击**后续处理**－>**取消下发**按钮，进入取消下发界面；
*  第3步：在取消下发界面中选择需要取消下发的目的资产组织，点**确定**后，系统将下发到目的组织的折旧方法取消下发。
