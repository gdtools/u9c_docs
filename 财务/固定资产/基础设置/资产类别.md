
# 功能描述

在该节点主要是设置折旧账簿以及账簿的有关参数，也是使用固定资产模块的必须操作。固定资产模块支持多账簿核算，可以根据组织核算的需要，使用主账簿或者多币种核算账簿作为折旧账簿。

# 关键应用

# 业务规则

*  折旧账簿已经启用，不能变更。
*  定义组织档案（必做）
*  定义账簿档案（必做）
*  定义资产货主关系（必做）

# 栏目说明

|栏目|说明|
|---|---|
|编码规则|资产类别档案的编码层级规则，系统默认为２-2-2，用户不可修改|
|账簿|从折旧账簿档案中选择使用该资产类别的折旧账簿。|
|折旧参数－原值信息－原值包含税款|确定新建固定资产卡片时资产原值中是否包含税款。系统默认从资产类别头中带入,用户可以修改。选择是表示资产原值中包含货款税额，选择否表示资产原值中不包含货款税额。|
|折旧参数－原值信息－原值包含费用|确定新建固定资产卡片时资产原值中是否包含未税费用额。系统默认从资产类别头中带入,用户可以修改。选择是表示资产原值中包含未税费用额，选择否表示资产原值中不包含未税费用额。|
|折旧参数－原值信息－原值包含费用税|确定新建固定资产卡片时资产原值中是否包含费用税额。系统默认从资产类别头中带入,用户可以修改。选择是表示资产原值中包含费用税额，选择否表示资产原值中不包含费用税额。当‘原值是否包含费用’为‘否’时，默认设为‘否’，用户不可设置。|
|折旧因素默认值-计提折旧|资产是否计提折旧，如果选择‘是’，则该类别资产默认计提折旧，否则该类别资产默认不计提折旧。|
|折旧方法|如果资产默认计提折旧，则从折旧方法档案中选择默认计提方法。|
|使用年限|资产使用寿命可用整年数表示的部分。使用年限大于等0。使用年限加使用期间数为资产的使用寿命。|
|使用期间数|资产使用寿命不够用一整年表示的部分。使用期间数大于等０，小于年内期间数。|
|残值类型|资产残值的表示方式，系统提供了两种类型：１、百分比 2、金额，如果选择‘百分比’表示资产残值默认用残值率表示，字段预估残值不可编辑；如果选择‘金额’表示资产残值默认用预估残值表示，字段残值率不可编辑。系统缺省类型为‘百分比’。|
|残值率|如果残值类型＝‘百分比’，则输入该类别资产的默认预估残值率|
|预估残值|如果残值类型＝‘金额’，则输入该类别资产的默认预估残值。|
|使用状况|资产使用状况,建卡时该类别资产卡片的默认使用状况，卡片可改|
|预估工作量|建卡时卡片资产类别的默认预估工作量，卡片可改。|
|工作量单位|建卡时卡片资产类别的默认工作量单位，卡片可改。|
|允许减值准备|资产是否允许计提减值准备，选择‘是’，表示该类别资产默认允许计提减值准备；选择‘否’，表示该类别资产默认不允许计提减值准备|
|允许减值转回|资产是否允许减值准备转回，选择‘是’，表示该类别资产默认允许将计提的减值准备进行转回；选择‘否’，表示该类别资产默认不允许将计提的减值准备进行转回。|
|折旧限制|资产是否进行折旧限制，选择‘是’，表示该类别资产计提折旧时，默认要考虑预先设定的折旧限额；选择‘否’，则默认不用考虑，按系统自动计算的折旧金额。请参见应用专题：折旧限制和成本限制|
|折旧限额|如果资产进行折旧限制，则输入每年度允许计提的默认最大折旧金额，在确定资产折旧时，使用该年度内每期间的平均折旧限额与自动计算的折旧额进行比较，取两者的最小值。请参见应用专题：折旧限制和成本限制。|
|成本限制|资产是否进行成本限制，即是否对折旧计提基数进行限制,选择‘是’，表示该类别资产计提折旧时，默认要考虑预先设定的成本限额；选择‘否’，则默认不考虑，按系统自动计算的折旧计提基数计提折旧。请参见应用专题：折旧限制和成本限制。|
|成本限额|如果资产进行成本限制,则输入每期间计提折旧的默认成本限额。在确定资产计提基数时，每期间成本限额与系统自动计算的计提基数进行比较，取两者的最小值作为资产计提折旧的计提基数。请参见应用专题：折旧限制和成本限制。|
|建账期间折旧|新建资产的当期是否计提资产折旧。选择‘是’表示新增固定资产时，当期默认计提资产折旧，开始折旧期间=建账期间；选择‘否’表示新增固定资产时，当期默认不计提资产折旧，下期开始计提资产折旧，开始折旧期间=建账期间+1　。|
|变更当期是否有效-价值变更|资产价值变更是否影响变更期间折旧。选择‘是’表示变更价值影响变更当期折旧计算，选择‘否’表示变更价值影响变更下期折旧计算。|
|变更当期是否有效-使用年限变更|资产使用年限变更是否影响变更期间折旧。选择‘是’表示变更使用年限影响变更当期折旧计算，选择‘否’表示变更使用年限影响变更下期折旧计算。|
|变更当期是否有效-预估工作量变更|资产预估工作量变更是否影响变更期间折旧。选择‘是’表示变更预估工作量影响变更当期折旧计算，选择‘否’表示变更预估工作量影响变更下期折旧计算。|
|变更当期是否有效-折旧方法变更|资产折旧方法变更是否影响变更期间折旧。选择‘是’表示变更折旧方法影响变更当期折旧计算，选择‘否’表示变更折旧方法影响变更下期折旧计算。|

# 操作说明

资产类别下发

资产类别下发只支持将当前资产组织的资产类别头信息下发到其他资产组织，不支持将资产类别账簿信息下发。

操作步骤

*  第1步：点击**基础设置**－>**下发档案设置**按钮，进入下发对象设置界面；
*  第2步：选择资产类别，将‘是否下发’设置为‘是’；
*  第3步：点击**固定资产**－>资产类别按钮，进入资产类别界面，选择需下发的资产类别；
*  第4步：点击**后续处理**－>**下发**按钮，进入下发界面；
*  第5步：在下发界面中选择要下发的目的资产组织，点‘**确定**’后，系统将当前资产类别信息下发到目的资产组织。

取消资产类别下发

用户可以将下发到目的资产组织的资产类别信息取消下发

操作步骤

*  第1步：点击**固定资产**－>**资产类别**按钮，进入**资产类别**界面，选择需取消下发的使资产类别；
*  第2步：点击**后续处理**－>**取消下发**按钮，进入取消下发界面；
*  第3步：在取消下发界面中选择需要取消下发的目的资产组织，点‘确定’后，系统将下发到目的组织的资产类别信息取消下发。
