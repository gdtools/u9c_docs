
# 功能描述

资产组是具有相同属性的卡片组合，目的是对组内的资产卡片进行统一操作。在本功能节点主要是进行资产组信息的设置。

# 业务规则

*  在参数设置中定义资产位置编码规则（必做）
*  定义地址档案（必做）

# 栏目说明

资产组-表头

|栏目名称|说明|
|---|---|
|编号|资产组的编号|
|货主组织|用户选择，资产组对应的货主组织，只能选择资产货主关系表中的货主组织。|

资产组-表行

|栏目名称|说明|
|---|---|
|账旧账不|参照这就账簿录入，只能选择货主组织对应的折旧账簿|
|建账日期|资产组的建账日期，卡片加入资产组的日期必须万余该建账日期。|
|建账期间|建账日期对应的期间|
|使用年限|资产组的使用年限，加入资产组的卡片的使用年限必须一致。|
|使用期间数|资产组的使用期间数，加入资产组的卡片的使用期间数必须一致。|
|计提折旧|资产组是否计提折旧，加入资产组的卡片‘计提折旧 ’设置必须一致。如果＝T，表示资产组计提折旧，如果＝F，表示资产组不计提折旧|
|折旧方法|资产组的折旧方法，‘计提折旧’＝T时可以设置，如果折旧方法非空，则加入资产组的卡片的折旧方法必须一致，如果为空，卡片的折旧方法可以不一致。|
|折旧开始期间|资产组的开始计提折旧的期间，‘计提折旧’＝T时可以设置，加入资产组的卡片的折旧开始期间必须一致|
|下次折旧期间|资产组的下次折旧期间，新建资产组时等于折旧开始期间，资产组计提折旧后系统自动更改为下一期间。|
|残值类型|资产组的残值类型，可以选择百分比、金额，加入资产组的卡片的残值类型必须一致。|
|残值率|资产组残值率，当残值类型为百分比时录入，如果资产组的残值类型是百分比，则加入资产组的卡片的残值率必须一致。|
|允许减值准备|资产组是否允许进行计提减值准备业务，选择是，表示资产组可以进行计提资产减值业务。只要卡片加入资产组，卡片引用的资产类别中的对应设置无效，应该以资产组的设置为准，同时资产卡片不能单独进行资产减值，必须按资产组进行。|
|允许减值转回|资产组是否允许进行减值准备转回业务，选择是，表示资产组可以进行资产减值转回业务。只要卡片加入资产组，卡片引用的资产类别中的对应设置无效，应该以资产组的设置为准，同时资产卡片不能单独进行资产减值转回，必须按资产组进行。|
|资产原值|资产组的原值，等于所有加入资产组的资产卡片原值合计。|
|预估残值|资产组的预估残值，等于所有加入资产组的资产卡片预估残值合计。|
|累计折旧|资产组的累计折旧，等于所有加入资产组的资产卡片累计折旧合计|
|资产净值|资产组的净值，等于所有加入资产组的资产卡片净值合计。|
|累计减值准备|资产组的累计减值准备，等于所有加入资产组的资产卡片累计减值准备合计。|
|可回收市值|资产组的可回收市值，等于所有加入资产组的资产卡片可回收市值合计。|
