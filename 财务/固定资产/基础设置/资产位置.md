
# 功能描述

在本节点主要进行资产位置设置，资产位置用来表明固定资产的存放位置，便于管理者进行固定资产实物管理

# 关键应用

# 业务规则

*  在参数设置中定义资产位置编码规则（必做）
*  定义地址档案（必做）

# 栏目说明

资产位置设置画面

|栏目|说明|
|---|---|
|上级位置编码|根据用户录入的编码，系统自动显示出上级资产位置，用户不可修改。如果当前资产位置是第一级，则为空。|
|编码规则|资产位置档案的编码层级规则，系统默认为２-2-2，用户不可修改。|
|编码|资产位置档案编码，必须符合编码规则的规定，用户必需输入。|
|名称|资产位置名称，用户必需输入。|
|地址|参照地址档案选择输入，根据地址信息能明确每一个固定资产的存放地点。|
