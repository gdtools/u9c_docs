
# 功能描述

本节点主要是设置固定资产系统参数。


# 业务规则

*  启用固定资产（必做）。

# 栏目说明

参数设置

|栏目名称|说明|
|---|---|
|资产类别编码级次|决定资产类别编码级次及长度，档案一旦使用则不可修改。|
|资产位置编码级次|决定资产位置编码级次及长度，档案一旦使用则不可修改。|
|资产使用状况编码级次|决定资产使用状况编码级次及长度，档案一旦使用则不可修改。|
|转总账|如果为‘是’，则月末结账时应该生成转总账交易分录的单据必须都生成交易分录且已经产生的转总账交易分录必须转总账，如果为‘否’，则月结时不进行限制|
|实时产生AAI分录|是否实时产生AAI分录，如果设置为‘是’，则单据保存或审核时生成交易分录，如果设置为‘否’，则单据保存或审核时不生成交易分录，需要以后通过‘批量生成交易分录’功能来生成。|
|折旧生成分录方式|设置折旧生成交易分录的方式。如果设置为‘按折旧计划日志’，则一次折旧时生成一张交易分录凭证；如果设置为‘按折旧计划分配汇总日志’，则一次折旧时按使用组织分别生成多张交易分录凭证，如果折旧对应影响因素还存在使用部门、项目、任务则按使用组织+使用部门+项目+任务分别生成多张交易分录凭证。|
|默认汇率类型|设置建卡时主折旧账簿的默认汇率类型|

# 操作说明

下发

可以将参数下发到与当前组织具有‘隶属关系且关系类型＝资产关系’的下级资产组织中，参数‘资产类别编码级次、资产位置编码级次、资产使用状况编码级次’不支持下发。

操作步骤

点击固定资产－参数设置按钮，进入资产参数设置画面。具体步骤如下所示。

*  第1步：点击下发参数按钮，弹出‘参数下发参数’画面，可以设置下发规则，设置下发后是否允许下级资产组织修改；
*  第2步：点击下发按钮，弹出‘参数下发’对话框；
*  第3步：在‘参数下发’画面中，选择需下发的参数、下级资产组织；
*  第4步：在选择完成后，点确定按钮，完成下发。
