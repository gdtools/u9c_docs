
# 功能描述

在该节点可以进行固定资产类别设置，对资产类别在每个折旧账簿中的默认项目及控制参数进行设置。这些项目是该类别中卡片的默认值，主要是为了快捷生成卡片，系统不要钱该类别中所有卡片的这些项目完全一致，用户可以根据每个卡片的实际情况在新建卡片时进行修改。

# 关键应用

# 业务规则

*  资产类别已经启用，不能变更。
*  在参数设置中定义资产类别编码规则
*  定义折旧账簿
*  定义折旧方法

# 栏目说明

账簿页签

|栏目|说明|
|---|---|
|组织职能|显示账簿对应的组织的职能属性，用户不可课选择，如果选择的是主账簿，显示法人组织，如果选择的是多币种账簿，选择资产组织。|
|编码|选择要进行固定资产管理的账簿，可以选择资产组织下的主账簿和多币种核算账簿。|
|提示|该页签中的其他项目在账簿档案中已经设置，这里选择账簿后，系统自动带出，用户不可修改。|

固定资产页签

|栏目|说明|
|---|---|
|货主组织|为折旧账簿指定的货主组织，表明折旧账簿记录的是货主组织的资产信息。货主组织只能是资产货主关系表中的货主组织。|
|启用期间|固定资产折旧账簿的启用会计期间，最小不能小于账簿生效日期所对应的会计期间，最大不能大于账簿失效日期所对应的会计期间。折旧账簿应该在最小已关闭会计期间之后启用。|
|最大重估次数|规定卡片的最大重估次数。默认=0，标识不限制重估次数，最大可设置99。|
|百分比精度|折旧账簿中百分比数值的精度。如折旧率、残值率的表示方式。|
|折旧率精度|这就账簿中设置折旧率的精度。|
|舍入类型|设置折旧的舍入类型，选择按值舍入、全部舍位、全部进位|
|舍入值|设置舍入值的位置|

*  通过菜单财务：固定资产：折旧账簿：进入页面，在账簿页签选择组织下的主账簿或者多币种账簿，带出该账簿的基础信息；切换固定资产页签进行设置。
