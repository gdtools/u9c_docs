
# 功能描述

在本节点主要进行资产拆分单类型的设置，是进行资产拆分前必须进行的操作。如果用户需要进行资产卡片的拆分处理，则在这里至少要设置一种拆分单单据类型。用户可以根据需要设置不同的资产拆分单类型，同时可以设置该拆分单的审核流程、编号方式等。

# 栏目说明

拆分单类型-基本页签

|栏目名称|说明|
|---|---|
|业务类型|单据的业务类型，系统固定为资产拆分，用户不可修改。|

拆分单类型-单据参数页签

请参见公共单据类型参数
