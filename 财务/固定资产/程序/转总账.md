
# 功能描述

本功能提供将固定资产系统中以下业务单据生成的交易分录，转为总账系统的记账凭证的处理。

产生交易分录的业务单据如下：

资产卡片

资产处置单

资产变更单

资产重估单

资产减值单

资产折旧分配表

资产调出单

资产拆分单

资产合并单

转总账主要功能如下：

可以将系统的交易分录转入总账系统生成记账凭证；

可以选择是否合并原始单据的交易分录生成记账凭证；

可以设定合并生成凭证的合并规则；

可以批量生成总账凭证；

可以联查交易分录相关的总账凭证和业务单据；


# 业务规则

*  总账系统启用（必做）
*  总账系统账簿、凭证等相关设置完成（必做）
*  交易分录已经生成（必做）
*  定义转总账规则（必做）
*  定义调度方案
*  定义账簿转换规则

转总账-合并规则设置画面

|栏目名称|说明|
|---|---|
|合并制单|生成凭证时是否合并制单，选择是时，将选中的单据的交易分录按照合并规则生成到一张凭证中。|
|业务类型|是否根据业务类型合并制单，选择是时，以业务类型作为合并制单条件，相同业务类型的单据的交易分录合并制单，否则不作为合并条件。|
|单据类型|是否根据单据类型合并制单，选择是时，以单据类型作为合并制单条件，相同单据类型的单据的交易分录合并制单，否则不作为合并条件。|
|单据日期|是否根据单据日期合并制单，选择是时，以单据日期作为合并制单条件，相同单据日期的单据的交易分录合并制单，否则不作为合并条件。|
|资产类别|是否根据资产类别合并制单，选择是时，以资产类别作为合并制单条件，相同资产类别的单据的交易分录合并制单，否则不作为合并条件。|
|资产编号|是否根据资产编号合并制单，选择是时，以资产编号作为合并制单条件，相同资产编号的单据的交易分录合并制单，否则不作为合并条件。|
