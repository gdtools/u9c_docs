
# 功能描述

本功能节点主要提供结账及反结账功能，通过本功能可以对折旧账簿的某个折旧期间进行结账及反结账操作。

# 业务规则

*  启用固定资产（必做）

# 栏目说明

期末结账

|栏目名称|说明|
|---|---|
|货主组织|选择需要进行结账的货主组织|
|折旧账簿|选择需要进行结账及反结账的折旧账簿|
|折旧年度|选择需要进行结账及反结账的折旧年度|
|期间号|显示折旧年度的折旧期间|
|是否结账|显示期间是否结账|
|结账人|显示结账人|

期末处理

|栏目名称|说明|
|---|---|
|处理类型|显示期末结账的检查项目，系统默认了需要检查项目|
|处理情况|显示结账检查项目完成情况，打标记标识已完成，否则标识未完成|

# 操作说明

期末结账

操作步骤

点击固定资产－>期末结账按钮，进行入资产期末结账主画面。具体步骤如下所示：

*  第1步：在期末结账画面选择货主组织、折旧账簿、折旧年度、折旧期间；
*  第2步：点击操作-结账，弹出期末处理画面；
*  第3步：在期末处理画面中，系统自动进行检查，选择没有完成项目行，点击显示处理情况报告，可以查看没有完成操作的单据情况，如果所有检查项目都完成，点击完成按钮，完成结账；点击取消按钮，取消结账操作。

取消期末结账

操作步骤

点击固定资产－>期末结账按钮，进行入资产期末结账主画面。具体步骤如下所示：

*  第1步：在期末结账画面选择货主组织、折旧账簿、折旧年度、折旧期间；
*  第2步：点击操作-取消，完成取消结账操作。
