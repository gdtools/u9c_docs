
# 功能描述

本功能节点主要是对资产的各种信息进行查询,包括查询资产的财务信息、实物信息、使用信息、变更信息、减值信息、重估信息、处置信息、折旧信息、折旧预测信息。如果当前资产组织存在下级资产组织，在当前资产组织中还可以查看下级资产组织的资产信息，实现了上级组织对下级组织的统一管理与监控。


# 业务规则

*  启用固定资产（必做）

# 栏目说明

资产查询-查询条件

|栏目名称|说明|
|---|---|
|资产组织|输入要查询的资产组织，参照组织档案录入，可以选择当前资产组织及其下级资产组织|
|货主组织|输入资产卡片货主组织，参照资产组织对应的‘资产货主关系’档案录入，为空表示查找全部|
|单据编号|输入资产卡片编号，为空表示查找全部|
|单据类型|输入单据类型，为空表示查找全部|
|资产编号|输入资产编号，为空表示查找全部|
|资产名称|输入资产编号，为空表示查找全部|
|资产组|输入资产卡片的资产组，为空表示查找全部|
|资产类别|输入资产类别，为空表示查找全部|
|资产数量单位|输入资产卡片数量单位，为空表示查找全部|
|资产数量|输入资产卡片数量，为空表示查找全部|
|资产启用日期|输入资产卡片启用日期，为空表示查找全部|
|状态|输入资产卡片状态，为空表示查找全部|
|使用状况|资产查询查找条件，参照输入使用状况|

# 操作说明

操作步骤

点击固定资产－>资产查询按钮，进入资产查询结果画面，可以点击‘查询’，弹出资产查询方案画面，可以根据查询需要设置查找条件、显示栏目、排列顺序，可以保存查询方案；

第一步：查看资产的财务信息、实物信息：在资产查询结果画面中，选中一行双击，分别查看所选资产卡片的财务信息、实物信息；

第二步：查看资产的使用信息：在实物信息画面点击‘使用信息’按钮，查看资产卡片的使用信息；

第三步：查看资产变动信息：在资产查询结果画面中，选中一行后双击，然后时点‘变更信息—财务信息变更’、‘变更信息—其他信息变更’按钮，分别查看资产卡片的类别变更、财务变更、实物变更、使用情况变更信息；

第四步：查看资产处置、资产减值、资产重估信息：在在资产查询结果画面中，选中一行后双击，然后点击‘变动信息—处置变动’、‘变动信息—其他变动’按钮，分别查看资产卡片的处置信息、减值信息、重估信息；

第五步：查看资产折旧信息、折旧预测信息：在在资产查询结果画面中，选中一行后双击，然后点击‘折旧信息’按钮，分别查看资产卡片的折旧信息、折旧预测信息。。
