
# 功能描述

*  提供企业银行日记账和银行对账单的对账处理。
*  提供自动对账和手工对账两种方式。
*  银行对账采用向导式操作，提供易用性。
*  执行了银行对账功能后，系统自动对银行日记账中的收付款记录，加注到账标记。

# 业务规则

*  启用现金银行（必做）
*  参数设定，与银行对账相关参数（必做）
*  下载或录入银行对账单数据（必做）

# 栏目说明

步骤一：录入对账条件

|栏目|说明|
|---|---|
|对账日期|录入执行银行对账的对账日期。|
|开户银行|录入对账数据发生的开户银行。参照开户银行档案录入。|
|银行账号|录入对账数据发生的银行账号。参照开户银行下的银行账号档案录入。|
|币种|录入对账数据的交易币种信息。|
|开始日期|录入对账数据的发生的开始日期。|
|结束日期|录入对账数据的发生的结束日期。|
||根据上述条件筛选银行日记账和银行对账单数据。|

步骤二：显示对账内容

银行日记账

|栏目|说明|
|---|---|
|银行日记账数据|画面上半部分显示符合条件的银行日记账数据。|
|银行对账单数据|画面下半部分显示符合条件的银行对账单数据。|
|自动对账|系统默认自动对账方式。如果需要执行手工对账，则取消此标识。|

步骤三：设置对账依据

|栏目|说明|
|---|---|
|账号相同|系统默认日记账和对账单的账号必须相同才能对账。|
|币种相同|系统默认日记账和对账单的交易币种必须相同才能对账。|
|金额相同|系统默认日记账和对账单的交易金额必须相同才能对账。|
|结算方式相同|用户选择日记账和对账单的结算方式是否必须相同才能对账。|
|票据号相同|用户选择日记账和对账单的票据号是否必须相同才能对账。|
|对方单位相同|用户选择日记账和对账单的对方单位是否必须相同才能对账。|
|对方账号相同|用户选择日记账和对账单的对方账号是否必须相同才能对账。|
|发票号相同|用户选择日记账和对账单的发票号是否必须相同才能对账。|

步骤四：显示对账报告

|栏目|说明|
|---|---|
|银行日记账已核对笔数|显示执行本次对账后，银行日记账已经勾对的交易笔数。|
|银行日记账未核对笔数|显示执行本次对账后，银行日记账未勾对的交易笔数。|
|银行对账单已核对笔数|显示执行本次对账后，银行对账单已经勾对的交易笔数。|
|银行对账单未核对笔数|显示执行本次对账后，银行对账单未勾对的交易笔数。|
|各币种勾对金额|显示执行本次对账后，各交易币种核对的总金额数。|

对账结果栏目说明

|栏目|说明|
|---|---|
|选择|如果需要取消某笔对账结果，加注此标识，并执行［取消对账］操作。|
|对账日期|显示执行对账日期。|
|开户银行|显示执行对账的银行。|
|银行账号|显示执行对账的账号。|
|币种|显示执行对账的币种。|
|勾兑金额|如果是银行日记账与银行对账单勾对上，则显示“正常”；如果是对账单一笔正数与一笔负数勾对上，则显示“对账单内部”。|
|对账金额|显示勾对上的金额数。|

# 按钮说明

<查询>：点击查询，录入查询条件，根据所选条件过滤列表 。

<取消对账>：已经对账数据，说中需要取消的条目，点击按钮，取消对账。

# 操作说明

对账

*  通过菜单路径财务->现金银行->银行对账进入画面。
*  选择对账类型，银行日记账或者出纳台账勾对。
*  点击新增，唤起对账步骤向导，根据向导，一步一步操作。
