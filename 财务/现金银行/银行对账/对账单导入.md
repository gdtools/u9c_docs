
# 功能描述

通过本功能将银行提供的对账单数据导入现金银行系统，以执行企业账与银行账的对账处理。

*  网银下载：如果用户开通了开户银行提供的网上银行功能，可以通过用友公司的网银适配器，直接从开户银行将交易明细数据，也就是对账数据下载到U9系统，实现数据的“不落地”的传递，避免了手工采集对账数据的烦琐工作和造成的误差。
*  外部数据导入：如果用户没有开通网银系统，但能够获取到银行提供的交易明细数据文件，可以将此文件以html形式导入U9系统，也可以实现非手工化的数据采集处理。
*  下载对账数据
*  对账数据查询
*  生成正式对账单数据

# 业务规则

*  启用现金银行（必做）
*  若选用了银企云支付要定义参数设置中参数分组为银企云的参数（必做）
*  若其他网上银行支付需要定义网银适配器IP地址（必做）

|栏目|说明|

# 按钮说明

<网银下载>：通过网银下载银行对账单。

<生成对账单>：将网银下载的对账单导入U9c系统。

<对账单维护>：导航到[对账单维护](/detail/576241bc66904774b2aa549a82f2a47c)档案设置功能节点。

<银行对账>：导航到[银行对账](/detail/21b0467974b642a286f4bffaa957f288)档案设置功能节点。

# 操作说明

网银下载

*  通过菜单路径财务->现金银行->银行对账->对账单导入进入菜单画面。
*  点击网银下载，在对账单导入画面，录入对账单导入的相关信息。
*  若需要直接导入，点击确定；若需要调度导入，则点击调度方案进行设置。
