
# 功能描述

*  提供用户手工录入对账单数据。
*  对网银下载和外部系统导入的对账单数据，可以通过本功能进行编辑、修改。

# 业务规则

*  启用现金银行（必做）
*  定义开户银行档案（必做）
*  定义银行账号档案（必做）
*  定义结算方式档案（必做）

# 栏目说明

基本栏目说明

|栏目|说明|
|---|---|
|对账单日期|显示对账单导入的操作日期|
|银行|显示提供对账单数据的银行名称|
|银行账号|显示提供对账数据的银行账号|
|账号币种|显示交易币种信息|
|子账号|显示银行子账号|
|起始日期|显示本次导入的交易数据的起始日期|
|结束日期|显示本次导入的交易数据的结束日期|
|单首余额|录入本张对账单记录的最早余额。|
|借方合计金额|显示本次导入的交易数据的借方合计金额|
|贷方合计金额|显示本次导入的交易数据的贷方合计金额|
|单尾余额|如果开户银行的对账单与日记账同方向：单尾余额=[单首余额]+[借方合计金额]-[贷方合计金额]如果开户银行的对账单与日记账同反向：单尾余额=[单首余额]+[贷方合计金额]-[借方合计金额]|
|借方笔数|显示本次导入的交易数据的借方合计笔数|
|贷方笔数|显示本次导入的交易数据的贷方合计笔额。|
|来源|显示对账单数据的来源。如果手工录入，显示“手工”如果外系统导入，显示“接口表导入”|

网银下载操作条件

|栏目|说明|
|---|---|
|开户银行|参照银行档案录入，选择需要导入对账单的银行，必填|
|银行账号|参照账号档案录入，选择银行账号，必填|
|开始日期|录入交易起始日期|
|结束日期|录入交易结束日期|
|调度执行开始日期|录入调度执行开始日期，在启用调度方式下载时，必填|
|调度执行结束日期|录入调度执行结束日期|
|下载后自动生成收款单|勾选后，在下载对账单后，系统会同时生成现金银行收款单，若存在应收模块，也会同步生成应收收款单|
|生成收款单状态|在勾选自动生成收款单下，选择生成收款单单据状态|

对账单行栏目说明

|栏目|说明|
|---|---|
|交易代码|点击下划线，参照交易代码档案录入|
|交易描述|录入|
|交易日期|录入交易日期；如果是导入数据，不允许修改|
|借方金额|录入；如果是导入数据，不允许修改|
|贷方金额|录入；如果是导入数据，不允许修改|
|结算方式|参照结算方式档案录入|
|票据号|录入|
|委托收款单位|参照组织档案录入|
|自动内部处理|如果是对账单中相同方向的一正一负的交易，可以表示为内部处理，不需要与银行日记账进行对账|
|转回|如果某笔交易是一笔转回业务，加注转回标志。|
|转回原因|录入转回原因|
|收款单号|显示关联的收款单号|
|付款单号|显示关联的付款单号|

详细内容栏目说明

|栏目|说明|
|---|---|
|交易代码|参照交易代码录入，也可点击交易代码直接录入|
|银行唯一标识|录入银行业务的标识号|
|交易时间|录入交易时间|
|对方单位名称|录入对方收款单位名称|
|对方开户银行|录入对方开户银行名称，点击下划线参照开户银行档案录入|
|对方银行账号|录入对方银行账号|
|对方银行地址|录入对方银行地址|
|已勾对|如果对账单某行数据已经勾对，系统加注此表识|
|来源|显示对账单某行数据的来源。如果手工录入，显示“手工”如果外系统导入，显示“接口表导入”|
|收支项目|参照收支项目录入人|

# 按钮说明

<生成收款单>：根据所选明细行，需要生成收款单，点击后系统会自动生成。

<生成付款单>：根据所选明细行，需要生成付款单，点击后系统会自动生成。

<批量生成收款单>：无需勾选，会自动按照对账单明细行生成收款单。

<批量生成委托收款单>：启用资金结算模块时，点击按钮，会自动按照明细行生成委托收款单。

<对账单导入>：导航到[对账单导入](/detail/ce74f29905144fcc83054a4600642070)档案设置功能节点。

<银行对账>：导航到[银行对账](/detail/21b0467974b642a286f4bffaa957f288)档案设置功能节点。
