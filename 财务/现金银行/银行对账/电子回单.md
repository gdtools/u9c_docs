
# 功能描述

*  提供电子回单下载。
*  提供电子回单打印。
*  提供电子回单与收付款单匹配。

# 业务规则

*  启用现金银行（必做）
*  启用银企云（必做）

# 按钮说明

<查询>：点击查询，录入查询条件，根据所选条件过滤列表 。

<匹配收付款单>：根据所选条目自动匹配收付款单。

<手工匹配收付款单>：系统无法匹配的单据可通过手工匹配选择。

<删除匹配>：删除电子回单与收付款单匹配关系。

<批量打印电子回单>：批量打印电子回单。

# 操作说明

手工匹配收付款单

*  通过菜单路径财务->现金银行->电子回单进入画面。
*  点击导入，将所选银行、交易日期期间内的电子回单导入系统。
*  选择列表中某一行明细，点击手工匹配收付款单，弹出满足匹配关系的业务单据。
*  勾选，点击确定，完成匹配。

批量打印电子回单

*  通过菜单路径财务->现金银行->电子回单进入画面。
*  点击下载，将所选银行、交易日期期间内的电子回单附件导入U9c文档库。
*  选择列表中某几行，点击批量打印，唤起打印机。
*  点击确定，开始打印。
