
# 功能描述

*  根据企业实际经营过程中使用的币种的现金日记账和余额数据。

# 业务规则

*  定义现金期初余额（必做）
*  设置现金限额；
*  有结算方式为现金类的收款单或付款单登记现金日记账；
*  有存现、提现等现金银行业务发生；

# 栏目说明

币种页签

|栏目|说明|
|---|---|
|组织名称|显示组织名称|
|币种名称|显示币种|
|现金账号|显示现金账号|

现金余额页签

|栏目|说明|
|---|---|
|日期|显示业务日期|
|组织|显示组织|
|方向|显示余额方向|
|当日原币期初余额|显示当日与亲笔期初余额|
|借方原币金额合计|显示当日借方原币金额合计|
|贷方原币金额合计|显示当日借方原币金额合计|
|方向|显示当日发生额方向|
|当日原币期末余额|显示当日原币期末余额，当日原币期末余额=期初原币余额+发生额（发生额=借方原币金额合计-贷方原币金额合计）|

现金日记账

|栏目|说明|
|---|---|
|日期|显示业务日期|
|组织|显示组织|
|结算方式|显示结算方式|
|借方金额|显示借方金额|
|贷方金额|显示贷方金额|
|来源系统|显示来源业务模块|
|来源单据类型|显示来源单据类型|
|来源单据号|显示来源单据号|

# 按钮说明

<查询>：用户可以通过本操作，重新设置查询条件和币种列表栏目内容。

<栏目设置>：用户可以通过本操作，重新设置现金日记账和余额表查询栏目内容。

<现金水位分析>：用户可以通过本操作，查询现金余额与现金限额的关系图。

<来源单据>：用户可以通过本操作，查询来源单据。

<账号综合查询>：导航到[银行账号综合查询](/detail/a514f0a7244242bfb2e91f157b80336c)档案设置功能节点。
