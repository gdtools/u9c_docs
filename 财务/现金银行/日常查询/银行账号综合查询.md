
# 功能描述

*  提供每个银行账号的日记账及余额表查询。
*  根据每个银行账号中设置的控制水位，提供银行账号水位分析

# 业务规则

*  定义银行账号档案（必做）
*  设置银行账号的最高水位、最低水位；
*  设置银行账号期初余额；（必做）
*  有结算方式为银行类的收款单或付款单登记银行日记账；
*  有存现、提现、转账等银行业务发生；

# 栏目说明

|栏目|说明|
|---|---|
|日期|显示业务日期|
|方向|显示余额方向|
|当日原币期初余额|显示当日与亲笔期初余额|
|借方原币金额合计|显示当日借方原币金额合计|
|贷方原币金额合计|显示当日借方原币金额合计|

|当日原币期末余额|显示当日原币期末余额，当日原币期末余额=期初原币余额+发生额（发生额=借方原币金额合计-贷方原币金额合计）|

# 按钮说明

<查询>：用户可以通过本操作，重新设置查询条件和币种列表栏目内容。

<栏目设置>：用户可以通过本操作，重新设置现金日记账和余额表查询栏目内容。

<现金水位分析>：用户可以通过本操作，查询银行账号余额与银行账号限额的关系图。

<来源单据>：用户可以通过本操作，查询来源单据。

<现金综合查询>：导航到[现金综合查询](/detail/5b21ddce16704367af1b64d0aba87b38)档案设置功能节点。
