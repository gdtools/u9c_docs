
# 功能描述

设置U9c系统预置的货币符号与各家银行系统的货币符号的对照关系。本功能主要为网上银行的应用提供保证

# 业务规则

*  启用现金银行（必做）
*  定义币种档案（必做）

# 栏目说明

|栏目|说明|
|---|---|
|银行类别|参照银行类别档案录入。|
|币种|参照币种档案录入。用户在使用时，只要设置使用的币种的对照关系。|
|ISO代码|显示U9c系统中设置的币种对应的ISO代码。|
|货币符号|显示U9c系统中设置的币种的货币符号。|
|银行币种符号|录入银行网银系统中与当前币种对应的币种的符号。|
|银行币种编码|录入银行网银系统与当前币种对应的币种的编码|
