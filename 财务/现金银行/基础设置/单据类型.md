
# 功能描述

定义单据类别，可定义提现单、存现单、银行转账单、收款单、付款单、汇兑损益单、网银变更单、现金调拨单。

# 业务规则

*  启用现金银行（必做）

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|编码|录入单据类型编码|
|名称|录入单据类型名称|
|描述|录入描述|
|业务类型|显示业务类型，根据所选单据类型显示|
