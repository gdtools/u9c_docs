
# 功能描述

配置畅捷支付额。

# 业务规则

*  启用现金银行（必做）
*  插上UKEY（必做）

# 栏目说明

|栏目|说明|
|---|---|
|网银汇款速度|枚举下拉，用户录入，选择普通、加急|
|操作员|显示操作员，默认当前登录账户|
|操作员名册|显示操作员名称|
|开户银行|参照开户银行录入|
|银行账号|参照银行账号档案录入，选择开户银行下的银行账号|
|币种|参照币种录入|
|付款对象|选择付款对象类型，供应商、客户、员工、其他|
|客户|付款对象=客户，参照客户档案录入|
|客户位置|选择客户位置|
|供应商|付款对象=供应商，参照供应商档案录入|
|供应商位置|选择供应商位置|
|员工|付款对象=员工，参照员工档案录入|
|每次支付额度|输入支付额度|
