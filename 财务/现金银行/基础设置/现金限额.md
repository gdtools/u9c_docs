
# 功能描述

对当前组织按币种设置现金库存限额。

# 业务规则

*  启用现金银行（必做）
*  定义币种档案（必做）

# 栏目说明

|栏目|说明|
|---|---|
|币种|参照选择币种，不允许重复|
|现金账号|参照现金账号录入，不允许重复|
|最低限额|用户录入，默认：0，不允许录入负数|
|最低限额控制方式|用户选择：不控制（默认），严格控制|
|最高限额|用户录入，默认：0，不允许录入负数|
|最高限额控制方式|用户选择：不控制（默认），严格控制|
