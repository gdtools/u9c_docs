
# 功能描述

提供不同币种的现金兑换，满足外币业务下，出纳需要兑换外币的场景。

# 业务规则

*  启用现金银行（必做）
*  定义现金账号
*  定义币种；

# 栏目说明

|栏目|说明|
|---|---|
|单据类型|参照现金购汇单类型录入|
|单号|根据所选单据类型自动编号或者手工录入|
|日期|录入业务日期|
|记账期间|录入记账期间|
|摘要|录入摘要|
|转入现金账号|参照现金账号录入，可在线录入现金账号|
|转入币种|参照币种录入，选择转入币种|
|汇率类型|选择汇率类型，枚举下拉|
|转入汇率|根据汇率档案带出汇率，可修改|
|转入金额|录入转入金额（原币）|
|转入本币金额|录入转入本币金额，也可根据汇率及转入金额自动计算|
|交易价|录入交易价|
|外币折算差额|显示外币折算差额，外币折算差额 = 本币金额 - 转入本币金额|
|转出现金账号|参照现金账号录入|
|原币|显示原币币种|
|原币金额|录入原币金额|
|本币金额|显示本币金额|
|单据状态|显示单据状态|

# 按钮说明

<作废>：作废当前单据。

<交易分录>：查看当前单据的交易分录。
