
# 功能描述

*  提供录入付款单数据及查询；
*  可以新增无来源单据的付收；
*  可以查看其他单据推式立账的应付；
*  提供给应付系统进行核销；
*  没有启用应收应付系统时，现金银行的付款单建议不录入付款对象＝客户／供应商，否则不能生成交易分录。

# 业务规则

*  启用现金银行（必做）
*  设置银行账号；
*  设置币种；
*  设置结算方式；
*  设置客户、供应商档案

# 栏目说明

基本页签

|栏目|说明|
|---|---|
|单据类型|参照录入|
|单号|非空根据单据编号规则录入或系统维护如果编号原则是自动编号时,在新增状态下先显示’自动编号’，保存后，根据编号规则，系统生成单号，不可以修改如果编号原则为手工编号,用户手工录入|
|日期|默认为当前登录日期；用户可选择参照日历录入；|
|记账期间|默认为付款日期对应的最小未结账正常会计期间，可以修改；只能改为现金银行未结账的会计期间，且是非调整期；|
|付款||
|付款对象类型|用户选择，可空（默认）：客户供应商员工其他（现金银行系统的付款活动）|
|付款人位置|当付款对象类型为“供应商”时显示［供应商位置］，选择［位置属性］的［汇款位置］＝T的供应商位置[付款对象类型]＝“客户”时显示［客户位置］，选择的位置必须是该客户的［位置属性］的［付款位置］＝T的客户位置如果[付款对象类型]＝“员工”时，用户参照录入员工档案如果[付款对象类型]＝其他，不输|
|结算方式|选择“结算方式”[业务属性]=银行或现金必输|
|付款币种|参照选择默认显示当前登录组织对应主账簿的本位币|
|汇率类型|如果账号币种是本位币，本字段为空，置灰不可编辑；如果账号币种不是本位币，带出现金银行系统参数默认汇率类型选择的汇率类型名称；可以修改|
|付款币种金额|用户录入修改：重新计算[付款本币]|
|付款本币汇率|非空； 当币种不等于本位币时，由用户输入如果账号币种是本位币，汇率默认=1，用户不可编辑如果账号币种不等于本位币时，带出当前日期下的账号币种与目标币的汇率值如果没有设置对应日期的汇率值，默认汇率值 = 0，可以手工修改；[汇率类型]字段修改，本字段相应变动 [汇率]修改重新计算[付款本币金额]|
|付款本币金额|付款金额*汇率=付款本币金额[付款金额]、[汇率类型]、[汇率]字段修改后，本字段做相应变动[付款本币金额]修改后系统会重新反算汇率|
|付款银行|可空，系统维护或用户输入当用户先录入〔付款账号〕时，会自动带出|
|付款银行地址|由[付款银行]带出|
|付款账号|选择银行账号不允许选择内部账号参照银行账号档案录入，默认为当前登录组织的账号，用户可改。如果选择结算方式为银行，则本字段必输；否则不输|
|付款账户名称|系统维护，根据〔付款账号〕自动带出|
|付款账号币种|可空，系统维护默认取付款账号的默认币种用户可改，可以选择与[付款币种]不同的币种，即付款币种与账号币种不同。|
|子账号|如果所选银行账号下有子账号，参照该银行子账号录入；|
|付款账号汇率|系统自动带入，用户可改如果[付款币种]=［账号币种］，汇率默认=1，本字段置灰不可编辑如果[付款币种]不等于［账号币种］，带出当前日期下的账号币种与目标币的汇率值；如果“汇率明细”中没有设置对应日期的汇率值，默认汇率值 = 0，可以手工修改；修改时：［账号原币金额］不变，系统重新计算[账号本币金额]|
|付款账号金额|如果[付款币种]=［账号币种］，用户不需录入如果[付款币种]不等于［账号币种］，用户录入|
|账号本币汇率|当[币种]不是[本位币]时，用户输入如果账号币种=本位币，汇率默认=1，本字段置灰不可编辑如果“账号币种”不等于[本位币]时，带出当期账号币种与目标币对应汇率类型的汇率值；如果没有设置对应日期的汇率值，默认汇率值 = 0，可以手工修改；如果没设置币种与本币的汇率关系，系统报错[汇率类型]字段修改，本字段相应变动 [汇率]修改后重新计算[本币金额]|
|票据分组||
|票据结算|系统维护|
|状态|系统显示，点击链接，显示明细信息|
|票据类型|当结算方式为现金时，用户手工录入时不允许编辑[票据结算]=T，且结算方式为银行，票据类型可空或选择自动报销的空白票据。|
|票据号|票据号可空或手工录入，票据号只做备查字段记录|
|报销人|可空；用户选择业务组织的业务员档案|
|报销部门|用户选择当前组织的部门档案当用户选择自动报销的空白票据时，必输， 否则，可空|
|来源分组||
|来源单据类型|系统维护，显示单据的来源类型|
|来源单据号|系统维护，显示来源单据号，点击链接可以查询源单据信息|
|来源组织|系统维护，显示单据的来源组织|
|业务组织|系统维护或用户手工录入，默认当前组织|
|结算组织|系统维护|
|财务费用种类|系统维护：利息收支金融机构手续费汇兑损益现金折扣其他|
|核算分组||
|项目|参照“项目”档案录入|
|任务|参照项目下的任务数据录入如果项目非空,根据所选项目的组织选择任务档案若项目为空，根据多组织规则选择任务，并回写到所选任务的组织所对应的项目。|
|部门|可空，用户录入或系统维护根据当前组织选择部门档案|
|业务员|可空；用户选择业务组织的业务员档案如果[付款对象类型]＝“员工”，不允许录入，系统自动根据员工联系对象转换为业务员，如果无法转换为业务员，显示为空如果[付款对象类型]＝客户或供应商，用户可输可不输如果[付款对象类型]为空，用户可输可不输|
|收支项目|当“账号”要求必须录入收支项目时，必输，收支项目在该银行账号设置的范围内进行选择。且收支项目方向＝支出、收支。|
|预算专项|用户选择当前组织的“预算专项”数据录入|
|摘要|用户录入|
|状态|系统维护|
