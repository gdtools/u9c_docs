
# 功能描述

根据银行的对账单或到账通知,提供用户确认应收应付款项已经实际收付的一种业务处理。

# 业务规则

*  启用现金银行（必做）
*  收款单、付款单没有执行转回处理；
*  收款单、付款单没有进行勾对；
