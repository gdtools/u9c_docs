
# 功能描述

银行转账单维护

# 业务规则

*  启用现金银行（必做）
*  设置银行账号；
*  设置币种；
*  设置结算方式；

# 栏目说明

|栏目|说明|
|---|---|
|单据类型|系统维护，显示“转账单单据类型”名称|
|单号|若“单据类型”.[编号原则]=[自动编号]时,在新增状态下先显示’自动编号’，保存后，根据编号规则，系统生成单号，不可以修改若“单据类型”.[编号原则]=[手工编号]时,手工录入|
|日期|非空，用户录入默认：当前登录日期；不能小于等于最大已日结的日期|
|记账期间|非空，用户选择默认=[单据日期]对应的最小未结账正常会计期间，可以修改；只能改为现金银行未结账的会计期间，且是非调整期；|
|摘要|可空，用户录入|
|转出－开户银行|非空，参照录入|
|转出银行账号|非空，参照录入|
|账号名称|系统维护，显示“银行账号”[账户名称]|
|原币|非空，参照币种录入|
|子账号|如果所选银行账号下有子账号，参照该银行子账号录入；|
|原币金额|根据汇率、本币金额自动计算显示原币金额|
|汇率|根据汇率档案自动带出，可修改|
|本币金额|录入本币金额|
|转入传出汇率|显示转入转出汇率|
|是否网银支付|勾选是，表示网银支付，通过银企云支付转账。勾选否，不通过网银支付。|
|转入－开户银行|非空，参照录入|
|转入银行账号|非空，参照录入|
|账号名称|系统维护，显示“银行账号”[账户名称]|
|转入币种|非空，参照录入|
|子账号|如果“银行账号”.[是否允许子账号]=True，参照该账号下的“银行账号”.[子账号]录入；如果“银行账号”.[是否允许子账号]=False，本字段置灰，不可编辑|
|转入金额|必填，录入转入原币金额|
|汇率类型|枚举下拉，选择汇率类型|
|转入本币汇率|根据汇率档案自动带出，可修改|
|转入本币金额|显示转入本币金额，可修改|
|||
|核算-结算方式|可空，参照录入要求“结算方式”.[现金银行业务属性]= [1、银行业务]|
|币种|可空参照币种录入|
|票据类型|可空，参照录入参照“付票据类型”[空白票据管理]=Y 的付票据类型档案录入|
|报销人|可空，参照录入如果[票据类型]=非空，本字段非空；如果[票据类型]=空，本字段可空；|
|报销部门|可空，参照录入如果[票据类型]=非空，本字段非空；如果[票据类型]=空，本字段可空；|
|票据号|可空，用户录入用户录入如果[票据类型]=非空，本字段非空；根据开户银行、银行账号、币种、领用部门、领用人进行过滤；如果上述字段为空，则将空白票据簿中的相应内容带出如果[票据类型]=空，本字段可空；|
|项目|可空，参照录入|
|任务|可空，参照录入|
|收支项目|可空，参照录入|
|预算专项|可空，参照录入|
|原币金额|用户录入取值范围 > 0|
|单据状态|显示单据状态|
|银行回单日期|录入银行回单日期|
|手续费-结算方式|可空，参照结算方式录入|
|币种|可空，参照币种录入|
|开户银行|可空，参照开户银行录入|
|银行账号|可空，参照银行账号录入|
|现金账号|可空，参照现金账号录入|
|汇率类型|如果账号币种是本位币，本字段为空，置灰不可编辑；如果账号币种不是本位币，带出现金银行系统参数默认汇率类型选择的汇率类型名称；可以修改|
|汇率|如果账号币种=本位币，汇率默认=1，本字段置灰不可编辑如果“账号币种”≠[本位币]时，系统带出当前日期下的原币对本币的汇率，可改|
|金额|录入手续费原币金额|
|本币金额|显示手续费本币金额，可改|
