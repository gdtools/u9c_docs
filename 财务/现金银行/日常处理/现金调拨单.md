
# 功能描述

提供企业对于现金调拨业务操作，支持外币的调拨。

# 业务规则

*  启用现金银行（必做）
*  定义现金账号
*  定义币种；

# 栏目说明

|栏目|说明|
|---|---|
|单据类型|参照现金调拨单类型录入|
|单号|根据所选单据类型自动编号或者手工录入|
|日期|录入业务日期|
|记账期间|录入记账期间|
|摘要|录入摘要|
|转出现金账号|参照现金账号录入|
|转入现金账号|参照现金账号录入|
|原币|参照币种录入，选择原币币种|
|原币金额|录入原币金额|
|汇率类型|默认带出所选汇率类型|
|汇率|默认带出汇率档案的汇率|
|本币金额|根据汇率计算显示本币金额，不可修改|
|单据状态|显示单据状态|
