
# 功能描述

*  提供录入收款单数据及查询；
*  可以新增无来源单据的应收；
*  可以查看其他单据推式立账的应收；
*  提供给应收系统进行核销；
*  没有启用应收应付系统时，现金银行的收款单建议不录入收款对象＝客户／供应商，否则不能生成交易

# 业务规则

*  启用现金银行（必做）
*  设置银行账号；
*  设置币种；
*  设置结算方式；
*  设置客户、供应商档案

# []()按钮说明

<作废>：作废当前单据。

<转回>：收款转回，当前收款单未到账并且结算方式为银行类可操作转回。

<退款>：退款，当前收款单已经到账并且结算方式为银行类可操作退款，生成付款单。

<取消退款>：取消退款，已经生成付款单但未对付款单支付。

<交易分录>：查看交易分录。

<预算执行>：单选行，点击本按钮，弹出预测执行查询界面
