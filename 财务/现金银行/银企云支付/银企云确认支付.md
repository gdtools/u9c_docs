
# 功能描述

提供银企云支付功能，该功能为实际付款。

# 业务规则

*  启用现金银行（必做）
*  参数设置中定义参数分组为银企云的参数（必做）
*  若是启用人工模式或原有模式，则必须完成银企云预支付

# 按钮说明

<查询>：录入查询条件，过滤列表数据。

<预支付确认>：请求银企云，预支付确认。

<网银支付单>：查询网银支付单。
