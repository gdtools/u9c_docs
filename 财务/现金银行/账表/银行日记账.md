
# 功能描述

*  提供每日银行日记账查询。
*  如果操作员有多个组织的查询权限，可以查询其他组织的银行日记账数据。

# 业务规则

*  定义银行账号档案（必做）
*  录入银行账号期初余额
*  有结算方式为银行类的收款单或付款单登记银行日记账

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|组织|如果从“现金银行”机能进入，可以参照当前组织及与当前核算组织具有垂直关系的下级核算组织；如果从“资金结算”机能进入，可以参照当前组织及与当前组织建立“核算-结算”关系的核算组织；如果当前登录组织两个机能都有，提供当前组织及与当前核算组织具有垂直关系的下级核算组织和当前组织及与当前组织建立“核算-结算”关系的核算组织。多选默认=当前登录组织|
|银行账号|默认=当前登录组织是拥有组织的默认账号根据所选组织，提供该组织下的“银行账号数据”录入|
|币种|参照币种档案录入。|
|子账号|如果银行账号有子账号，参照子账号录入。|
|转回|用户选择|
|到账|用户选择|
|日期|录入日记账的日期范围。|
|包含未记账|用户可以选择对已记账单据或包含未记账单据在内不同范围的查询|
