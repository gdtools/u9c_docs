
# 功能描述

*  提供多组织银行存款余额调节表的汇总查询。
*  提供明细查询。

# 业务规则

*  定义银行账号档案（必做）
*  导入或录入银行对账单数据（必做）
*  有结算方式为银行类的收款单或付款单登记银行日记账 （必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|组织|参照多组织挡案录入。|
|开户银行|参照开户银行档案录入。|
|银行账号|参照开户银行下的银行账号档案录入。|
|币种|参照账号币种档案录入。|
|截止对账日期|系统将截止此日期以前的银行未达或企业未达数据做为余额调节数据。|

列表

|栏目|说明|
|---|---|
|组织|显示组织|
|开户银行|显示开户银行名称|
|银行账号|显示银行账号|
|币种|显示币种|
|银行余额|显示当前银行账号下银行余额|
|企业余额|显示当前银行账号下企业余额|
|差异|显示差异，等于银行余额-企业余额|
