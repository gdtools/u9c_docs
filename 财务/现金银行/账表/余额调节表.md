
# 功能描述

*  提供对银行存款余额调节表的查询。
*  查询截止某一天，企业银行日记账余额的调节信息。

# 业务规则

*  定义银行账号档案（必做）
*  导入或录入银行对账单数据（必做）
*  有结算方式为银行类的收款单或付款单登记银行日记账 （必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|开户银行|参照开户银行档案录入。|
|银行账号|参照开户银行下的银行账号档案录入。|
|币种|参照账号币种档案录入。|
|截止对账日期|系统将截止此日期以前的银行未达或企业未达数据做为余额调节数据。|

银行存款余额调节表-企业未达

银行日记账余额+银行方期初额

|栏目|说明|
|---|---|
|日期|显示业务日期|
|票据号|显示票据号|
|摘要|显示摘要|
|金额|显示发生额|

银行对账单账面余额-银行未达

|栏目|说明|
|---|---|
|日期|显示业务日期|
|票据号|显示票据号|
|摘要|显示摘要|
|金额|显示发生额|
