
# 功能描述

分币种录入库存现金期初余额。

# 业务规则

*  启用现金银行（必做）

# 栏目说明

|栏目|说明|
|---|---|
|账簿|显示登录组织对应的法人组织主账簿的账簿名称|
|本币|显示主账簿的本位币币种名称|
|币种|非空，参照选择|
|现金账号|参照现金账号选择；|
|业务描述|可空，用户录入默认：“期初余额”，可改|
|期初余额|可空，用户录入默认：0不允许小于0若登录组织设置了按币种的库存现金限额，要求该币种的期初余额小于等于“现金限额”注意：[期初余额]修改：重新计算[本币余额]|
|汇率类型|用户选择若[币种]=[本位币]，本字段为空，置灰不可编辑；若账号币种≠本位币，根据“系统参数”.[默认汇率类型]显示汇率类型名称，可改注意：[汇率类型]修改：重新获取币种对本币的汇率，重新计算[本币余额]|
|汇率|用户录入若“账号币种”＝[本位币]时，默认=1，不可修改若“账号币种”≠[本位币]时，系统带出启用日期时所选币种对本币的汇率若“汇率明细”中没有设置对应日期的汇率值，默认汇率值 = 0，可改；若“汇率表”中没有设置币种与本币的汇率关系，系统报错注意：[汇率]修改：重新计算[本币余额]|
|本币余额|系统维护，默认：0录入［期初余额]后，系统计算，可改企业原币余额*汇率=企业本币余额若[期初余额]、[汇率类型]、[汇率]字段修改后，本字段联动注意：[本币余额]修改：重新反算汇率|
