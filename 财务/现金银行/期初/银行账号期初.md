
# 功能描述

提供银行账户启用日期录入；

提供银行账户期初余额录入；

# 业务规则

*  启用现金银行（必做）
*  定义银行账户档案（必做）

# 栏目说明

|栏目|说明|
|---|---|
|开户银行|非空，参照选择注意：开户银行修改：单据保存时，检查银行账号是否属于[开户银行]，如果不属于录入的开户银行，系统报错。|
|银行账号|非空，参照选择［开户银行］非空，参照[开户银行]下“银行账号”[拥有组织]=当前登录组织“银行账号”数据录入［开户银行］为空，则参照“银行账号”[拥有组织]=当前登录组织“银行账号”数据录入注意：银行账号修改：如果修改后的银行账号已经设置期初余额数据，重新获取[启用日期]、[币种]、[银行期初]、[企业期初]等相关期初余额信息；如果修改后的银行账号没有设置期初余额数据，则清空[启用日期]、[币种]、[银行期初]、[企业期初]等相关期初余额信息；|
|账户名称|显示银行账号的账户名称|
|启用日期|非空，用户录入默认=当前登录日期，可改注意：账号[启用日期] ≥ [现金银行系统]启用日期银行账号的日记账数据中有“期初未达或日常业务”数据后，不允许修改本字段|
|账簿|显示登录组织对应的法人组织主账簿的账簿名称；若登录组织有法人职能，则显示其主账簿|
|本币|显示账簿的[本位币]币种名称|
|币种|非空，参照选择同一个银行账号下币种不能重|
|子账号|可空，参照选择若“银行账号”[子账号]=True，参照“银行账号”[子账号]录入；若“银行账号”[子账号]=False，本列置灰，不可编辑|
|业务描述|可空，用户录入默认：“期初余额”，可改|
|银行方余额|可空，用户录入默认：0，可改|
|企业方余额|可空，用户录入默认：0，可改|
|汇率类型|用户选择若“币种”＝[本位币]时，显示为空，不可改若“账号币种”≠[本位币]时，默认=“系统参数”.[默认汇率类型]，可改注意：[汇率类型]修改：[汇率]字段联动，重新计算[企业本币余额]|
|汇率|用户录入若“账号币种”＝[本位币]时，默认=1，不可修改若“账号币种”≠[本位币]时，系统带出启用日期时所选币种对本币的汇率若“汇率明细”中没有设置对应日期的汇率值，默认汇率值 = 0，可改；若“汇率表”中没有设置币种与本币的汇率关系，系统报错注意：[汇率]修改：重新计算[企业本币余额]|
|企业本币余额|系统维护，默认：0录入[企业原币余额]后，系统计算，可改企业原币余额*汇率=企业本币余额若[企业原币余额]、[汇率类型]、[汇率]字段修改后，本字段联动注意：[企业本币余额]修改：重新反算汇率|
