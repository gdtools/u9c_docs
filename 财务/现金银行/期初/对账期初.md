
# 功能描述

提供期初企业方未达账录入；

提供银行方未达账录入；

期初未达账对账功能；

提供期初收付款单做为银行未达账导入功能

# 业务规则

*  启用现金银行（必做）
*  设置银行账号；
*  设置银行账号启用日期、期初余额；

# 栏目说明

银行日记账对账

|栏目|说明|
|---|---|
|开户银行|显示当前登录组织的所有已启用且录入期初余额的开户银行|
|银行账号|显示银行账号|
|账户名称|显示账户名称|
|启用日期|显示该账户的启用日期|
|基本账号|是否基本账号|
|币种|显示账号币种|
|子账号|显示子账号名称|
|余额方向|显示银行账号期初余额方向|
|银行期初余额|显示银行期初余额|
|企业期初余额|显示企业期初余额|

出纳台账对账

|栏目|说明|
|---|---|
|名称|显示银行名称|
|银行账号|显示银行账号|
|账户名称|显示账户名称|
|启用日期|显示该账户的启用日期|
|基本账号|是否基本账号|
|币种|显示账号币种|
|子账号|显示子账号名称|
|台账余额方向|显示出纳台账余额方向|
|银行放期初|显示银行期初余额|
|台账原币余额|显示企业期初余额|

# []()按钮说明

<银行期初未达>：录入银行期初未达数据。

<企业期初未达>：录入企业期初未达数据。

<期初对账报告>：显示期初对账报告，是否平衡。

<收付款单导入>：导入期初收付款单。

# 操作说明

银行期初未达

*  通过菜单路径财务->现金银行->对账期初进入画面；
*  使用前提，现金银行启用期初
*  点击按钮，弹出银行期初未达画面，选择开户银行，选择所属开户银行下的银行账号，会自动带出账户名称、子账号、对账单方向，注意，对账单方向为开户银行上设置的对账方向，选择币种。
*  在gird行上录入日期、业务描述，录入借方金额、贷方金额，选择结算方式，依次按需录入。

企业期初未达

*  通过菜单路径财务->现金银行->对账期初进入画面；
*  适用前提，现金银行启用期初
*  点击按钮，弹出银行企业未达画面，选择开户银行，选择所属开户银行下的银行账号，会自动带出账户名称、子账号、对账单方向，注意，对账单方向为开户银行上设置的对账方向，选择币种。
*  在gird行上录入日期、业务描述，录入借方金额、贷方金额，选择结算方式，依次按需录入。

期初对账报告

*  通过菜单路径财务->现金银行->对账期初进入画面；
*  选中一行，点击期初对账报告，弹出对账报告画面，显示对账明细、对账结果。

收付款单导入

*  通过菜单路径财务->现金银行->对账期初进入画面；
*  使用前提，现金银行启用期初。
*  当其他模块（应收、应付、总账）等使用过该银行账号，银行日记账中也有记录，启用现金银行时，通过该功能，将业务模块的单据导入。
