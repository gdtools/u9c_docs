
# 功能描述

提供出纳台账期初导入。

# 业务规则

*  启用现金银行（必做）
*  设置银行账号；
*  设置银行账号启用日期、期初余额；

# 栏目说明

银行日记账对账

|栏目|说明|
|---|---|
|账簿|显示主账簿|
|本位币|显示主账簿的本位币|
|启用日期|显示现金账号或银行账号启用日期|
|现金账号|显示现金账号|
|开户银行|显示当前登录组织的所有已启用且发生业务的开户银行|
|银行账号|显示银行账号|
|账户名称|显示账户名称|
|币种|显示账号币种|
|子账号|显示子账号名称|
|业务描述|显示业务描述|
|基本账号|是否基本账号|
|银行方余额|显示银行方余额|
|台账余额方向|显示台账余额方向|
|台账余额|显示台账余额|
|汇率类型|显示汇率类型|
|汇率|显示汇率|
|台账本币余额|显示台账本币余额|
