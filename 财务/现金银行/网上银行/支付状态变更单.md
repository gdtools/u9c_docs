
# 功能描述

提供网银支付下支付状态变更。

# 业务规则

*  启用现金银行（必做）
*  定义网银服务器URL配置

# 栏目说明

|栏目|说明|
|---|---|
|单号类型|显示现金银行支付状态变更单类型|
|单号|显示单号，自动编号|
|日期|录入业务日期|
|付款银行|显示付款银行名称|
|付款账号|显示付款银行账号|
|账户名称|显示付款银行账户名称|
|付款币种|显示付款币种|
|支付总金额|显示付款总金额|
|单据状态|显示单据状态|
|支付单|显示所选网银支付单|
|支付日期|显示支付日期|
|明细行||
|对方银行名称|显示收款银行名称|
|对方银行账号|显示收款银行账号|
|对方账户名称|显示收款账户名称|
|支付金额|显示支付金额|
|备注|显示备注|
|原支付状态|显示原本支付状态|
|变更状态|录入变更状态，枚举下拉，未支付或者支付成功|
|变更原因|录入变更原因|

# 操作说明

新增：

*  通过菜单路径财务->现金银行->网上银行->支付状态变更单近路画面；
*  点击新增，弹出画面中选择网银支付单，勾选需要变更的单据；
*  系统会将所选支付单的关联支付单带入画面，根据所需，变更状态。
