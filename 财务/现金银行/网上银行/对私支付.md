
# 功能描述

提供网银对私付款功能。

# 业务规则

*  启用现金银行（必做）
*  定义网银服务器URL配置

# 栏目说明

单头页签

|栏目|说明|
|---|---|
|单号|显示来源单据号|
|单据日期|显示来源单据日期|
|组织|显示组织|
|付款账号|显示付款银行账号|
|账户名称|显示付款银行账户名称|
|支付日期|显示支付日期，待发起支付后，自动回写|
|付款币种|显示付款币种|
|总金额|显示付款总金额|
|网银支付状态|显示网银支付状态|
|支付速度|显示支付速度|
|支付单变更状态|显示支付单变更状态，未变更、已支付、未支付，若发现支付单变更，会将变更后的状态回写。|

基本页签

|栏目|说明|
|---|---|
|支付金额|显示明细单行支付金额，例如一张报销单上，多笔报销|
|收方银行账号|显示收款方银行账号|
|转入账户名称|显示收款方银行账号账户名称|
|支付状态|显示支付状态|

其他页签

|栏目|说明|
|---|---|
|收方地市代码|根据基本页签上所选银行账号带出账号档案上的收方地市代码|
|收方地址名称|根据基本页签上所选银行账号带出账号档案上的收方地市名称|
|收款银行名称|根据基本页签上所选银行账号带出账号档案上的收款银行名称|
|收款联行号|根据基本页签上所选银行账号带出账号档案上的收款联行号|
|收方开户地区|根据基本页签上所选银行账号带出账号档案上的收方开户地区|
|是否同行|勾选是否同行|
|是否通常|是否同城|
|用途|录入用途|
|备注|录入备注|
|网银支付状态|显示支付状态，支付后，通过交易状态查询更新该字段|
|子交易流水号|显示子交易流水号|
|收账户类型|根据基本页签上所选银行账号带出账号档案上的账户类型|

详细明细

|栏目|说明|
|---|---|
|来源系统|显示来源业务模块|
|来源单据类型|显示来源单据类型|
|来源单据号|显示来源单据号|
|对方开户银行名称|显示对方开户银行名称|
|对方银行地址|显示对方银行地址|
|对方账户名称|显示对方银行账户名称|

<网银变更单>：导航到[支付状态变更单](/detail/4bb433082dd24e1cb88c3fbe5c67a555)档案设置功能节点。
