
# 功能描述

提供网银对公付款功能。

# 业务规则

*  启用现金银行（必做）
*  定义网银服务器URL配置

# 栏目说明

|栏目|说明|
|---|---|
|日期|显示单据日期|
|支付状态|显示支付状态|
|单据类型|显示单据类型|
|单据号|显示单据号|
|业务描述|显示业务描述|
|结算方式|显示结算方式|
|账号币种|显示账号币种|
|银行账号|显示银行账号|
|账户名称|显示银行账户名称|
|开户银行|显示开户银行|
|对方单位|显示对方单位，收款单位|
|对方开户银行名称|显示对方开户银行名称，收款银行开户名称|
|对方银行账号|显示对方银行账号，收款银行账号|
|对方银行地址|显示对方银行地址，收款银行地址|
|来源系统|显示来源业务模块|
|票据号|显示票据号|
|金额|显示金额|

# 按钮说明

<查询>：输入查询条件，过滤列表数据。

<支付>：发起支付。

<网银支付单>：查询网银支付单据。
