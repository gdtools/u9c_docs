
# 功能描述

按照币种分别计算现金和每个银行账号下的汇兑损益。

# 业务规则

*  启用费用报销（必做）
*  参数设定，与汇兑损益计算相关参数
*  定义币种档案（必做）
*  定义汇率类型（必做）
*  定义汇率 （必做）

# 栏目说明

基本信息页面

|栏目|说明|
|---|---|
|单据类型|显示汇兑损益单单据类型|
|单号|显示单据号|
|日期|显示计算汇兑损益日期|
|记账期间|显示记账期间|
|本币|显示本币币种|
|币种|显示原币币种|
|汇率类型|显示汇率类型|
|汇率|显示汇率|
|状态|显示单据状态|

明细行页签

|||

|---|---|
|银行账号|单据第一行显示了：现金；从第二行开始分别显示各外币银行账号|
|账户名称|显示银行账号对应的账户名称|
|子账号|如果银行账号下有子账号，显示子账号。|
|原币余额|显示银行账号下外币余额|
|调整前本币余额|显示调整前原折余额算成本币的余额|
|调整后本币余额|显示汇兑损益计算调整后，原折余额算成本币的余额|
|差额|差额＝调整后本币余额　－　调整前本币余额|

# 按钮说明

<交易分录>：查询交易分录。

<作废>：作废当前汇兑损益单。
