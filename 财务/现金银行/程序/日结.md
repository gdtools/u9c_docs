
# 功能描述

*  本功能提供现金银行系统日结账处理。
*  某日期执行日结处理后，将不允许再录入、审核任何业务单据。即收款单、付款单、提现单、存现单、转账单、与现金银行有关的会计凭证。
*  企业一般应当按天日结，使企业的现金账、银行账做到日清月结；但由于各种系统原因，企业也可以定期执行日结。即选择日期，执行日结，系统将此日期以前没有执行日结处理的各天，全部自动按日期进行日结处理。
*  如果因业务原因，需要取消某天的日结，可以执行取消日结处理；系统将选定日期以后的各天，全部取消日结，系统维护完毕，还需要再此执行日结处理。


# 业务规则

*  日结日期以前的收款单、付款单、提现单、存现单、转账单、凭证全部审核（必做）
*  对应的交易分录全部转总账（必做）

# 栏目说明

|栏目|说明|
|---|---|
|会计期间|系统默认显示最小未结账会计期间。可以参照会计期间档案进行修改。|
|日期|显示一个会计期间下的全部业务日期。用户可以选择某个未执行日结处理的日期，批量执行日结处理；也可以选择某个已执行日结处理的日期，批量取消日结处理。|
|日结|如果某天已执行日结，则加注标志。|
|结账人|记录执行日结处理的操作员。|

# 按钮说明

<日结>：执行日结处理。系统将选定的某日期以前全部未执行日结处理的日期，自动执行日结处理

<取消日结>：执行取消日结标志处理。系统将选定的某已经日结的日期以后全部已未执行日结处理的日期，自动执行取消日结处理。

# 操作说明

日结

*  相关业务单据全部审核记账。
*  点击现金银行－>程序－>日结按钮，弹出日结处理报告画面。具体步骤如下所示。
*  选择某未执行日结处理的业务日期。
*  点击日结功能按钮。
*  弹出日结处理报告画面，画面显示系统日结检查的项目和检查结果，所有未通过的项目都可以点击显示处理情况报告按钮查看明细信息，属于日结的必要条件的项目如果未通过，系统不允许执行日结；
*  所有属于日结必要条件的项目通过后，点击完成按钮完成日结处理。

取消日结

*  某日期执行日结处理
*  点击现金银行－>程序－>取消日结按钮。
