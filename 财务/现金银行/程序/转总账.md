
# 功能描述

本节点用于将现金银行系统中生成的交易分录转为总账系统的记账凭证，主要功能如下：

*  可以将现金银行系统的交易分录转入总账生成记账凭证
*  可以选择是否合并原始单据生成记账凭证
*  可以设定合并生成凭证的合并规则
*  可以批量生成总账凭证
*  可以联查交易分录相关的总账凭证和业务单据

# 业务规则

*  总账系统启用（必做）
*  总账系统账簿、凭证等相关设置完成（必做）
*  交易分录已经生成（必做）
*  定义转总账规则（必做）
*  定义调度方案
