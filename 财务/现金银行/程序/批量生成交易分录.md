
# 功能描述

*  提供批量生成交易分录功能

# 业务规则

*  各类业务单据已经保存（必做）
*  交易分录模版设置正确（必做）
*  业务单据未生成交易 （必做）
*  定义调度方案（可选）
*  设置查询方案（可选）
