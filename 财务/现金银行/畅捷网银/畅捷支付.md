
# 功能描述

提供启用畅捷通的付款功能。

# 业务规则

*  启用现金银行（必做）
*  参数设置中定义畅捷网银商户代码（必做）
*  参数设置中定义畅捷网银UKEY使用方式（必做）

# 栏目说明

|栏目|说明|
|---|---|
|日期|显示单据日期|
|来源业务系统|显示来源业务模块|
|来源单据类型|显示单据类型|
|来源单据号|显示单号|
|开户银行|显示付款账号开户银行|
|银行账号|显示付款银行账号|
|账户名称|显示付款银行账户名称|
|账号币种|显示付款币种|
|金额|显示付款金额|
|结算方式|显示结算方式|
|票据号|显示票据号|
|业务描述|显示业务描述|
|对方开户银行|显示收款账号开户银行|
|对方银行账号|显示收款方银行账户|
|对方账户名称|显示收款方银行账户名称|
|对方单位名称|显示收方单位名称|
|支付状态|显示支付状态，未支付、支付成功等|

# 按钮说明

<查询>：弹出查询条件画面，按照查询条件，过滤列表数据。

<支付>：发起支付，请求畅捷支付。
