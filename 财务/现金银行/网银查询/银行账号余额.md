
# 功能描述

*  通过网银适配器，提供对网银交易账号余额数据的实时查询。


# 业务规则

*  定义银行账号档案（必做）
*  指定网银交易账号（必做）
*  网上付款交易（必做）

# 栏目说明

|栏目|说明|
|---|---|
|银行类别|显示银行类别名称|
|开户银行|显示开户银行名称|
|银行账号|显示银行账号|
|账号名称|显示银行账号名称|
|币种|显示币种|
|最后交易日期|显示最后交易日期|
|余额日期|显示余额日期|
|余额|显示余额|
|可用余额|显示可用余额|
|冻结余额|显示冻结余额|
|昨日余额|显示昨日余额|
|错误信息|显示错误信息|
