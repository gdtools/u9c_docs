
# 功能描述

*  提供每笔网银付款交易状态查询。
*  根据查询条件，查询出每笔付款执行时，银行接收本交易的接收信息，包括：成功、失败、状态不明、银行受理。再通过本功能，查询该笔数据最终的银行处理结果。最终结果信息包括：成功、失败、未支付。

# 业务规则

*  定义银行账号档案（必做）
*  指定网银交易账号（必做）
*  执行网上付款交易（必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|开户银行|参照开户银行档案录入。|
|银行账号|参照开户银行下的银行账号录入。|
|币种|参照银行账号的使用币种录入。|
|单据类型|录入付款交易的来源单据类型。应付系统的付款单、现金银行系统的转账单，都需要执行付款交易。|
|单据号|录入单据编号。|
|日期|录入查询付款交易的日期范围。|
|支付状态|录入当时执行付款的交易状态。|
||通过原状态可以与现在执行状态进行比较。|
