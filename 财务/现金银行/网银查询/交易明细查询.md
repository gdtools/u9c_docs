
# 功能描述

*  通过网银适配器查询网银交易账号的明细交易数据。
*  根据输入的条件，可以查询指定银行指定网银交易账号中指定日期范围内每笔交易明细信息。

# 业务规则

*  定义银行账号档案（必做）
*  指定网银交易账号（必做）
*  执行网上付款交易（必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|开户银行|录入网上银行交易的开户银行。参照开户银行档案录入。|
|银行账号|参照银行账号档案录入。|
|从交易日期|录入需要查询的交易明细数据的开始日期。|
|到交易日期|录入需要查询的交易明细数据的结束日期。|

列表

|栏目|说明|
|---|---|
|开户银行|显示开户银行名称|
|银行账号|显示银行账号|
|交易日期|显示交易日期|
|交易时间|显示交易时间|
|交易流水号|显示交易流水号|
|付方账号|显示付方银行账号|
|付方单位名称|显示付方单位名称|
|收方账号|显示收方银行账号|
|收方单位名称|显示收方单位名称|
|凭证号|显示凭证号|
|摘要|显示摘要|
|用途|显示用途|
|币种|显示币种|
|借贷标志|显示借方标志，站在银行方显示|
|交易金额|显示交易金额|
|可用余额|显示当前账号可用余额|
|付方余额|显示付方银行账号余额|
|收方余额|显示收方（我方）账号余额|
