<!--# 预算控制方案-->

### 功能描述

   若预算需要在业务单据上进行相应控制，则必须指定控制周期、当期控制或累计控制方式、是否允许超预算以及允许超预算的额度等等，这些控制要求在U9cloud系统中体现为预算控制方案。

### 相关主题

  * 定义预算目的
  * 定义预算组织
  * 定义预算指标

### 栏目说明

预算控制方案卡片

栏目名称 | 说明  
---|---  
编码 | 预算控制方案的编码。  
名称 | 预算控制方案的名称。  
控制方式 |  不控制：不执行超预算额度检查。  <br>严格控制：不允许超预算，即超预算时中断当前业务执行，系统给出提示。     
控制符 |  严格控制时，可用。  <br>**大于/大于等于** ：预算执行数 > 或 >= 预算数 X［超预算额度比例］时，为超预算。  <br>**小于/小于等于** ：预算执行数 < 或 <= 预算数X超预算额度比例］时，为超预算。     
超预算额度比例|  严格控制时，可用；表示可执行预算的比重。<br>例如：可执行预算数的90%，则此处录入0.9；执行数可超原预算数20%，则此处录入1.2。  可以手工直接录入比例值，默认100%，可以录入输入大于或小于100%的值。  <br>可以录入公式表达式表示超预算额度比例值。  检查预算时，将预算数X超预算额度比例］与执行数比较。     
允许累计控制 |  是：将预算年度初至当前预算控制期间止的预算累计数与执行累计数比较。  <br>否：当期控制，将当前预算控制期间的预算数与执行数比较。     
允许特批 |  是：可以特批处理，特批处理的预算执行另行记录，不影响预算执行数，不扣减可执行预算。  <br>否：不允许特批处理。     
允许预算保留 |  是：允许将预算执行环节的预算检查提前到业务处理的前端环节检查是否超预算。如可以在采购请购环节就事先检查预算，若预算检查通过则将预算事先占用，顺序向下游环节替代直到执行预算，如请购 -> 采购 -> 收货 -> 应付 -> 请款 -> 付款。  <br>否：不允许预算保留。      
|**预算控制方案卡片- 控制期间页签**  
行号 | 控制期间号。  
年度 | 预算年度，根据【开始预算期间】、【结束预算期间】自动产生，不需录入。  
期间号 | 预算控制的期间，根据【开始预算期间】、【结束预算期间】自动产生，不需录入。  
开始预算期间 | 预算控制期间的开始期间。  
结束预算期间 |  预算控制期间的结束期间。  <br>![alt 注意](https://iuap-aiplatform-picdoc.oss-cn-beijing.aliyuncs.com/help/photo/9ac7b8c4-6663-472e-ba82-323c0a1e0bc7.jpg)【开始预算期间】【结束预算期间】组合使用，表示预算控制的期间长度。例如：预算是按月度编制的，但预算控制时，希望按季度进行预算数控制，即1月-3月业务发生时，判断不超本季度的预算，则设置为：预算开始期间=201501，预算结束期间=201503。  同一预算年度内，不同的预算控制期间，每个期间的颗粒度可不同。  预算控制期间，不可跨预算年度设置。      
| **预算控制方案卡片- 控制保留环节页签/控制保留流程**  
采购付款 | 系统预置流程：请购 -> 采购 -> 收货 -> 应付 -> 请款 -> 付款。  
费用报销 | 费用申请 -> 费用报销。      
|**预算控制方案卡片- 控制保留环节页签/控制保留环节**  
控制保留环节 | 系统根据保留流程自动列出保留环节  
启用 |  是：启用当前保留环节。  <br>否：不启用当前保留环节。  <br>采购付款保留必须在下列两个流程内：     <br>1. 请购 -> 采购 -> 收货 -> 应付<br>2. 请购 -> 采购 -> 收货 -> 应付 -> 请款 -> 付
