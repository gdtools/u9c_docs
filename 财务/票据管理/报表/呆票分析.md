
# 功能描述

*  本节可以汇总查询应付转出、应收转出的呆票的票据类型。

# 关键应用

# 业务规则

*  票据管理启用（必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|业务组织|查询条件，参照组织录入，根据所选组织过滤业务组织等于所选组织的票据|
|结算组织|查询条件，参照组织录入，根据所选组织过滤结算组织等于所选组织的票据|
|核算组织|查询条件，参照组织录入，根据所选组织过滤核算组织等于所选组织的票据|
|票据类型|查询条件，选择特定类型的票据进行分析|
|记账期间|查询条件，可以对特定记账期间的票据进行分析|
|收款对象|查询条件，可以分客户、供应商进行分析|
|到期日|查询条件，可以选择同一到期日票据进行分析|
|票据行为|可以对特定行为的票据进行分析|
|票据号|可以对特定票号票据进行分析|
|票据面值|可以对特定范围面值的票据进行分析|
|处理日期|可以对特定处理日期范围的票据进行分析|
|收票日期|可以对特定收票日期范围的票据进行分析|
