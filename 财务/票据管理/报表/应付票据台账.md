
# 功能描述

*  本节点可以查看应付票据台账。

# 关键应用

# 业务规则

*  票据管理启用（必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|业务组织|查询条件，参照组织录入，根据所选组织过滤业务组织等于所选组织的票据|
|结算组织|查询条件，参照组织录入，根据所选组织过滤结算组织等于所选组织的票据|
|核算组织|查询条件，参照组织录入，根据所选组织过滤核算组织等于所选组织的票据|
|期间类型|查询条件，枚举下拉，会计期间、自然期间|
|截止会计期间|查询条件，参照会计期间录入|
|截止自然日期|查询条件，参照业务日期录入|
|是否包含已结清票据|查询条件，枚举下拉，是、否，选择是，包含应付票据已经收款的数据|
|票据类型|查询条件，选择特定类型的票据进行分析|
|币种|查询条件，参照币种录入|
|付票对象类型|查询条件，参照付票对象选择录入|
|客户|查询条件，参照客户档案选择，根据所选与付票对象客户进行匹配过滤|
|客户位置|查询条件，参照客户位置选择|
|供应商|查询条件，参照供应商档案，根据所选与付票供应商匹配过滤|
|供应商位置|查询条件，参照供应商位置选择|
|部门|查询条件，参照部门档案录入|
|业务员|查询条件，参照业务员档案录入|
|项目|查询条件，参照项目录入|
|任务|查询条件，参照任务录入|
|出票日期|查询条件，参照录入出票日期|
|到期日|查询条件，录入票据到期日|
|状态|查询条件，参照选择票据状态录入|
