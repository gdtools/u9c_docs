
# 功能描述

*  按票据类型、记账期间、出票对象、票据面值等查询条件，查询应收票据的票据面值及票据余额。

# 关键应用

# 业务规则

*  票据管理启用（必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|业务组织|查询条件，参照组织录入，根据所选组织过滤业务组织等于所选组织的票据|
|结算组织|查询条件，参照组织录入，根据所选组织过滤结算组织等于所选组织的票据|
|核算组织|查询条件，参照组织录入，根据所选组织过滤核算组织等于所选组织的票据|
|分析期间类型|查询条件，枚举下拉，会计期间、自然期间|
|截止会计期间|查询条件，参照会计期间录入|
|截止自然日期|查询条件，参照业务日期录入|
|是否包含已结清票据|查询条件，枚举下拉，是、否，选择是，包含应收票据已经收款的数据|
|票据类型|查询条件，选择特定类型的票据进行分析|
|币种|查询条件，参照币种录入|
|出票客户|查询条件，参照客户档案录入|
|出票客户位置|查询条件，参照客户位置录入|
|出票供应商|查询条件，参照供应商档案录入|
|出票供应商位置|查询条件，参照供应商位置录入|
|背书客户|查询条件，参照客户档案录入|
|背书客户位置|查询条件，参照客户位置录入|
|背书供应商|查询条件，参照供应商档案录入|
|背书供应商位置|查询条件，参照供应商位置录入|
|部门|查询条件，参照部门档案录入|
|业务员|查询条件，参照业务员档案录入|
|项目|查询条件，参照项目档案录入|
|任务|查询条件，参照任务录入|
|签发日期|查询条件，根据票据签发日期进行过滤|
|收票日期|查询条件，根据票据收票日期进行过滤|
|到期日|查询条件，根据票据到期日进行过滤|
