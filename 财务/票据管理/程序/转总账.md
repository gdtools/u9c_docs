
# 功能描述

本节点用于将业务系统中生成的交易分录转为总账系统的记账凭证，主要功能如下：

*  可以将票据系统的交易分录转入总账生成记账凭证
*  可以选择是否合并生单
*  可以设定合并生单的合并规则
*  可以设置转总账规则
*  可以联查交易分录相关的总账凭证和业务单据
*  。

# 关键应用

# 业务规则

*  总账系统启用（必做）
*  总账系统账簿、凭证等相关设置完成（必做）
*  交易分录已经生成（必做）
*  定义转总账规则
*  定义调度方案

# 按钮说明

<批量生成凭证>：将业务系统的数据传递到总账并批量生成总账系统的记账凭证。

<生成凭证>：单次生成记账凭证。

<交易分录>：查看所选单据生成的交易分录。

<删除凭证>：删除凭证操作用于将业务系统的数据已生成的凭证进行删除。

<作废凭证>：将业务系统的数据已生成的凭证进行作废。

# 操作说明

批量生成凭证

票据系统的数据已经生成交易分录

操作步骤

点击票据管理－>程序－>转总账按钮，进入转总账业务操作画面。具体步骤如下所示。

*  第1步：点击票据管理－>程序－>转总账按钮，进入转总账单据列表画面，列表显示本组织应收系统所有未转总账的交易分录；
*  第2步：点击批量生成凭证按钮，弹出凭证批量生成画面；
*  第3步：在凭证批量生成画面中选择筛选查询方案及是否需要合并制单以及合并制单的条件，
*  第4步：点击确定按钮根据批量方案由系统自动对符合条件的交易分录生成凭证，并返回批量转总账报告，显示转总账成功的数量、不成功的数量、生成凭证的总张数

生成凭证

*  票据系统的数据已经生成交易分录

操作步骤

点击票据管理－>程序－>转总账按钮，进入转总账业务操作画面。具体步骤如下所示。

*  第1步：点击票据管理－>程序－>转总账按钮，进入转总账单据列表画面，列表显示本组织应收系统所有未转总账的交易分录；
*  第2步：在列表中选择本次需要转总账的交易分录，点击生成凭证按钮，弹出凭证生成画面；
*  第3步：在凭证生成画面中选择是否需要合并制单以及合并制单的条件；参见：
*  第4步：点击生成凭证按钮，系统自动生成总账系统的记账凭证，并返回转总账列表画面，在凭证类别、会计期间和凭证号栏目显示生成的记账凭证信息；

删除凭证

票据系统交易分录已生成凭证

操作步骤

点击票据管理－>程序－>转总账按钮，进入转总账业务操作画面。具体步骤如下所示。

*  第1步：点击票据管理－>程序－>转总账按钮，进入转总账单据列表画面，列表显示本组织应收系统所有已转总账的交易分录；
*  第2步：在列表中选择需要删除凭证的交易分录，点击删除凭证按钮。对已生成的凭证进行删除。

作废凭证

票据系统交易分录已生成凭证

操作步骤

点击票据管理－>程序－>转总账按钮，进入转总账业务操作画面。具体步骤如下所示。

*  第1步：点击票据管理－>程序－>转总账按钮，进入转总账单据列表画面，列表显示本组织应收系统所有已转总账的交易分录；
*  第2步：在列表中选择本次需要作废的交易分录，点击作废凭证按钮，对已生成的凭证进行作废；
*  批量作废凭证是对选中多张数据已生成的凭证进行作废
