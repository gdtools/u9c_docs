
# 功能描述

本节点用于将票据管理系统所有未生成交易的各类型业务单据集中、批量生成交易分录。

主要应用场景：

*  在填制各类业务单据时，为了提高单据保存处理效率，在单据保存时，先不生成交易分录。每天定期将各业务单据的交易分录集中、批量生成。
*  可以设置系统自动调度程序，定期由系统自动生成交易分录。用户只需在此查询生成结果。

主要功能：

*  设置查询条件，手工选择单据生成交易分录。
*  设置调度方案，定期系统自动生成交易分录。
*  提供交易分录生成结果报告。
*  如果生成过程有误，提供错误信息报告。

# 关键应用

# 业务规则

*  各类业务单据已经保存（必做）
*  交易分录模版设置正确（必做）
*  业务单据未生成交易分录（必做）
*  定义调度方案（可选）
*  设置查询方案（可选）

# 栏目说明

批量生成交易分录－查询条件[]()

|栏目|说明|
|---|---|
|单据类型|需批量生成交易分录的单据的单据类型，参照单据类型录入|
|单据日期|需批量生成交易分录的单据的单据日期。|
|处理业务类型|需批量生成交易分录的单据的票据业务类型，枚举下拉，例如收票据背书、收票据贴现等|
|币种|需批量生成交易分录的单据的币种，参照选择币种|
|票据号|需批量生成交易分录的单据的票据号|
|金额|需批量生成交易分录的单据的票面价值|
