
# 功能描述

本节点提供票据系统结账功能，主要功能点如下：

*  可以查看票据期间状态
*  可以关闭待结账的期间
*  可以完成结账检查并结账
*  可以取消结账


# 关键应用

# 业务规则

*  总账系统启用（必做）
*  总账系统账簿、凭证等相关设置完成（必做）
*  交易分录已经生成（必做）
*  定义转总账规则
*  定义调度方案

# 操作说明

结账操作

本操作用于对票据系统待结账的期间结账并关闭该期间

操作前提

*  当前期间未结账
*  待结账期间之前的期间已结账

操作步骤

点击票据管理－>程序－>结账按钮，期间状态管理画面。具体步骤如下所示。

*  第1步：列表中显示应收期间状态，点击结账按钮，系统自动取最小未结账的期间结账，弹出期末处理画面；
*  第2步：期末处理画面显示系统期末检查的项目和检查结果，所有未通过的项目都可以点击显示处理情况报告按钮查看明细信息，属于结账的必要条件的项目如果未通过，系统不允许结账；
*  第3步：所有属于结账必要条件的项目通过后，点击完成按钮完成结账。
