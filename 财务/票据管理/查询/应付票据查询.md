
# 功能描述

*  本节可以查询应付票据的所有相关信息，可以按照处理行为进行查询。

# 关键应用

# 业务规则

*  票据管理启用（必做）

# 栏目说明

[]()查询条件

|栏目|说明|
|---|---|
|单据编号|用来查找特定票据|
|票据类型|用来查找特定类型票据|
|币种|用来查找特定币种的票据|
|汇率类型|用来查找特定汇率类型的票据|
|付款对象|用来查找收客户或供应商的票据|
|银行账号|用来查找特定银行账号的票据|
|开户银行|用来查找特定开户银行的票据|

应付票据查询

|栏目|说明|
|---|---|
|票据类型|显示应付票据类型|
|业务类型|显示应付票据业务类型|
|单据编号|显示应付票据单据编号|
|币种|显示应付票据币种|
|出票日期|显示付票据收票日期|
|票据到期日|显示应付票据到期日|
|票据面值|显示票据票面价值|
|部门|显示应付票据归集部门|
|业务员|显示应付票据业务员|
|状态|显示应付票据票据状态|
|对象类型|显示付票据类型，客户、供应商|
|客户|付票对象为客户时，显示客户名称|
|客户位置|付票对象为客户时，显示客户位置|
|供应商|付票对象为供应商时，显示供应商|
|供应商位置|付票对象为供应商时，显示供应商位置|
|业务组织|显示票据业务组织|
|结算组织|显示票据结算组织|
|来源单据号|显示票据来源单据号|

应付据行为查询

|栏目|说明|
|---|---|
|行为|显示票据行为|
|行为日期|显示票据行为发生日期|
|行为|显示票据行为操作人|
|行为金额|显示票据行为金额|

# 操作说明

联查行为明细：双击选中应付票据查询中的某一行应付票据，可在应付票据行为查询页签中看到票据行为信息。
