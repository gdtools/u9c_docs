
# 功能描述

*  本节可以查询空白票据的所有相关信息，可以按照处理行为进行查询。

# 关键应用

# 业务规则

*  票据管理启用（必做）

# 栏目说明

[]()查询条件

|栏目|说明|
|---|---|
|票据编号|用来查找特定票据|
|票据状态|根据空白票据未用、领用、领用退回、报销来查找|
|票据类型|用来查找特定类型票据|
|币种|用来查找特定币种的票据|
|票据簿号码|用来查找属于特定票据簿的票据|
|汇率类型|用来查找特定汇率类型的票据|
|收款对象|用来查找收客户或供应商的票据|
|银行账号|用来查找特定银行账号的票据|
|开户银行|用来查找特定开户银行的票据|
|购置人|用来查找特定购置人的票据|

空白票据查询

|栏目|说明|
|---|---|
|领用组织|显示空白票据领用组织|
|报销组织|显示空白票据业务类型|
|票据号|显示空白票据领用票据号|
|票据状态|显示空白票据状态|
|票据类型|显示空白票据票据类型|
|票据簿号码|显示空白票据票据簿号码|
|空白票据簿部门|显示空白票据簿购置部门|
|购置人|显示空白票据购置人|
|币种|显示空白票据币种|

空白票据行为查询

|栏目|说明|
|---|---|
|行为|显示票据行为|
|行为人|显示票据行为操作人|
|行为部门|显示票据行为发生部门|
|行为日期|显示票据行为发生日期|
|金额|显示票据行为金额|

# 操作说明

联查行为明细：双击选中空白票据查询中的某一行票据，可在空白票据行为查询页签中看到票据行为信息。
