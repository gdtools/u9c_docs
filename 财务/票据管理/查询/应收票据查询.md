
# 功能描述

*  本节可以查询应收票据的所有相关信息，可以按照处理行为进行查询。

# 关键应用

# 业务规则

*  票据管理启用（必做）

# 栏目说明

[]()查询条件

|栏目|说明|
|---|---|
|单据编号|用来查找特定票据|
|票据类型|用来查找特定类型票据|
|币种|用来查找特定币种的票据|
|汇率类型|用来查找特定汇率类型的票据|
|收款对象|用来查找收客户或供应商的票据|
|银行账号|用来查找特定银行账号的票据|
|开户银行|用来查找特定开户银行的票据|

应收票据查询

|栏目|说明|
|---|---|
|业务组织|显示应收票据业务组织|
|结算组织|显示应收票据结算组织|
|票据类型|显示应收票据类型|
|业务类型|显示应收票据业务类型|
|单据编号|显示应收票据单据编号|
|币种|显示应收票据币种|
|收款对象|显示应收票据收款对象，客户、供应商|
|票据面值|显示票据票面价值|
|收票日期|显示收票据收票日期|
|票据到期日|显示应收票据到期日|
|部门|显示应收票据归集部门|
|业务员|显示应收票据业务员|
|状态|显示应收票据票据状态|
|客户（背书人）|背书对象为客户时，显示背书人的客户名称|
|客户位置（背书人）|背书对象为客户时，显示背书人的客户位置|
|供应商（背书人）|背书对象为供应商时，显示背书人的供应商|
|供应商位置（背书人）|背书对象为供应商时，显示背书人的供应商位置|
|来源单据号|显示票据来源单据号|

应收票据行为查询

|栏目|说明|
|---|---|
|行为|显示票据行为|
|行为日期|显示票据行为发生日期|
|行为|显示票据行为操作人|
|行为金额|显示票据行为金额|

# 操作说明

联查行为明细：双击选中应收票据查询中的某一行应收票据，可在应收票据行为查询页签中看到票据行为信息。
