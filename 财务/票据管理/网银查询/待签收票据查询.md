
# 功能描述

本节点提供电子票据待签收查询，主要功能点如下：

*  可以查看票待签收票据
*  可以签收票据
*  可以拒签票据
*  可以查询票据流转信息


# 关键应用

# 业务规则

*  票据管理启用（必做）
*  电票通启用（必做）
