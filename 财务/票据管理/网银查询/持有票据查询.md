
# 功能描述

*  本节点提供本组织下持有票据查询

# 关键应用

# 业务规则

*  票据管理启用（必做）
*  电票通启用（必做）

# 栏目说明

持有票据查询-查找

|栏目|说明|
|---|---|
|票据种类|枚举下拉，银行承兑汇票、商业承兑汇票|
|银行编号|参照银行档案虚选择|
|账号|参照账号档案选择，与银行账号有联动，选择银行后会自动将该银行下的账号过滤出来|
|持有票据来源|枚举下拉，票据来源，背书签收、解质押签收等|
|票面到期日起始日期|查询票面到期日起始日期|
|票面到期日终止日期|查询票面到期日终止日期|
