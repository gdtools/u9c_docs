
# 功能描述

*  本节点提供电子票据业务与银行响应的查询

# 关键应用

# 业务规则

*  票据管理启用（必做）
*  电票通启用（必做）

# 栏目说明

[]()票据状态查询-查找

|栏目|说明|
|---|---|
|银行编号|参照银行档案虚选择|
|账号|参照账号档案选择，与银行账号有联动，选择银行后会自动将该银行下的账号过滤出来|
|票据编号|输入票据号|

票据状态查询

|栏目|说明|
|---|---|
|票据编号|显示票据编号|
|电子票据业务类型|显示票据业务类型，例如背书待签收|
|ECDS票据状态|显示ECDS票据状态，ECDS为电子汇票系统|
|银行响应码|显示响应码|
|银行响应信息|显示响应信息|
|银行交易日期|显示交易日期|
|银行流水|显示银行流水|
