
# 功能描述

*  本功能节点用于录入和维护空白票据簿，并提供与空白票据直接相关的领用、报销、作废、领用退回等操作，此外，还可以查询与空白票据相关的付票据等信息。

# 关键应用

# 业务规则

*  启用票据管理（必做）
*  定义组织（必做）
*  定义SOB（必做）
*  定义币种汇率（必做）
*  定义会计日历（必做）
*  定义结算方式（必做）
*  定义客户档案
*  定义供应商档案
*  定义银行账号
*  定义部门业务员档案
*  定义项目任务
*  定义预算专项
*  定义收支项目

# 栏目说明

空白票据簿领购画面

|栏目|说明|
|---|---|
|票据类型|选择票据的票据类型，参照出的票据类型必须是进行空白票据管理的。参见：付票据类型点击栏目可以在线维护付票据类型数据。|
|单位|参照计量档案输入票据簿的单位。如：张、本、卷等。|
|数量|录入领购票据簿的数量|
|币种|录入该票据簿的币种|
|票据簿号码|录入该票据簿的顺序号|
|票号前缀|录入领购票据簿中票据号的前缀|
|票号长度|录入领购票据簿中票据号的长度，必须大于票号前缀|
|起始编号|选输入领购票据簿的起始编号；注意不能与其他发票簿中的票据号重复。|
|期初|可选择是或否，当选择是时，可以录入期初空白票据，领购日期可以在系统启用前。|
|开户银行|银行账号对应的开户银行|
|银行地址|开户银行地址|
|银行账号|参照选择本票据簿的银行账号组合。参见：银行账号|
|账号名称|票据簿银行账号的名称。|
|银行子账号|银行账号的子账号|
|部门|购置部门，点击栏目可以在线维护部门档案|
|购置人|购置人，点击栏目可以在线维护人员档案|
|日期|购置日期|
|工本费|购置工本费|
|手续费|购置手续费|

# 按钮说明

<明细>：跳转空白票据簿明细页面。

<领用>：领用票据，票据未流转，仍在企业内部。

<报销>：本功能用于被支付给对方单位，不在本企业内。

<票据簿>：跳转至票据簿列表画面。

# 操作说明

进入空白票据管理后，首先看到的是空白票据簿列表画面，列出已领购的空白票据簿

领购

在发票簿列表画面中，点击新增按钮。具体步骤如下所示

操作步骤

*  在票据簿领购窗口输入领购的信息，
*  点击确认按钮生成票据簿；点击取消按钮取消本次操作；

明细

在发票簿列表画面中，点击明细按钮，可以弹出票据簿明细窗口，显示票据簿中的空白票据清单。在明细列表中可以对空白票据进行领用、报销、取消领用、退回、作废等操作

领用

*  当前票据是“未用”、“领用退回”状态。且当前票据类型按人员或部门时行领用控制时，控制人员或部门的领用未报销张数、期限未超过标准

操作步骤

点击空白票据管理－>明细－>领用按钮。

*  选择需要领用的票据，点击领用按钮，弹出领用画面，
*  录入领用金额或限额；
*  在领用画面点击领用完成领用，关闭本画面。

报销

*  当前票据已不支持自动领用且票据状态为“领用”或当前票据支持自动领用且票据状态为“领用”或“未用”状态。
*  被付款单、提现单、转账单等外部单据引用的空白票据，当外部单据作废时，空白票据置为未用状态。

操作步骤

点击空白票据管理－>明细－>报销按钮。

*  选择需要报销的票据，点击报销按钮，弹出报销画面，
*  录入报销栏目内容；
*  在报销画面点击报销完成转出，关闭本画面。

取消领用

*  当前票据处于“领用”状态

操作步骤

点击空白票据管理－>明细－>操作－>取消领用按钮。

*  选择需要取消领用的票据，点击取消领用，消除票据的领用信息

退回

*  当前票据处于“领用”状态

操作步骤

点击空白票据管理－>明细－>操作－>退回按钮

*  选择需要退回的票据，点击退回按钮，票据变为领用退回状态，但票据领用信息还保留；

作废

*  当前票据为“领用”、“未用”、“领用退回”状态

操作步骤

点击空白票据管理－>明细－>操作－>退回按钮。

*  选择需要作废的票据，点击作废按钮，录入作废原因，点作废完成操作
*  已作废的票据不能做其它操作

票据簿

点击票据簿按钮可以从空白票据列表回到票据簿列表画面
