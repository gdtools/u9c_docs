
# 功能描述

本功能节点用于输入和维护应付票据，并提供与应付票据直接相关的付款等操作，此外，还可以查询与付票据相关的对应付款单、换票明细等信息。

应用场景一（跨多个核算组织）：企业采用统收统支模式，通过结算中心对资金的收支进行管控；其管辖下的多个成员单位（核算组织）对应的多个业务组织可能与相同的客户（或供应商）同时发生多笔业务往来；针对多个成员单位对同一个客户的应收款项，客户（或供应商）可能合并开具一张票据；针对多个成员单位对同一个客户（或供应商）的应付款项，企业可能合并开出一张票据或者背书一张收票据；此类情形，结算中心都需要明确受益成员单位，以进行准确的核算和核销。

应用场景二（跨同一核算组织的多个核算项目）：核算组织或结算中心从客户（或供应商）收票，或向客户（或供应商）出票/背书，可能涉及多个受益部门，受益业务员，多个项目，多个任务，多个预算专项，收支项目；此类情况，企业也有明确核算项目，进行核算和核销的要求；

# 栏目说明

付票据－基本页签

|栏目|说明|
|---|---|
|单据类型|选择票据的单据类型。参见：收票据类型点击栏目可以在线维护收票据类型数据。|
|单号|输入单号，不可重复|
|票据号|在本栏目中输入票据编号。注意　:票据号不允许重复。若勾选了电子票据，票据编号不可编辑|
|票据类型|枚举下拉，银行承兑汇票、商业承兑汇票|
|出票日|填写应付票据出票日|
|票据期限（天）|填写票据期限，自动算出票据到期日；或者选择到期日，会自动算出票据期限。|
|到期日|填写票据到期日期，也可根据输入的票据期限自动算出到期日|
|记账期间|选择开票的会计期间|
|付票对象|选择付票对象，枚举下来，供应商、客户|
|付票客户／供应商|选择所付票据的客户/供应商，点击栏目可以在线维护客户/供应商数据。|
|付票客户／供应商位置|选择所付票据的客户位置/供应商位置点击栏目可以在线维护客户位置/供应商位置数据。|
|承兑人|用户手工维护承兑人的相关信息，若商票则为开票银行，若商票则为本组织|
|业务组织|与票据的核算组织有“业务-核算”关系的组织；标示出，该张票据是因为那个组织的业务产生的|
|结算组织|如果当前是结算中心登录，则为当前组织。如为核算组织登录，则为核算组织|
|核算组织|表示当前的票据是为那个组织核算的参照出的组织是与当前登陆的结算组织有“核算-结算”关系的组织|
|是否电子票据|默认=是，则为电子票据，可通过电票通完成线上票据行为操作。默认=否，则为手工纸票，将票据交易行为录到系统中记录票据状态。|
|币种|选择本票据的币种，点击栏目可以在线维护币种数据。|
|汇率类型|当票据币种与本位币不同时，选择票据币种对本位币的汇率类型。|
|汇率|当票据币种与本位币不同时，设定票据币种对本位币的汇率值。|
|票据面值|录入票据面值|
|票据余额|开票时，默认票据余额=票据面值。|
|票面利率|输入票面利率|
|付款账号|参照选择输入付款人账号|
|子账号|自动带出付款账号关联的子账号|
|账号名称|自动带出银行账号名称|
|银行|自动带出银行账号所属银行，也可参照选择，与付款账号联动|
|内部账号|当开票内部结算时，自动带出内部账号|
|收款账号|若供应商或客户位置上维护了默认银行账号信息，会自动带出，若未维护可以参照选择，也可在线录入|
|账号名称|账号名称|
|银行|所属银行|
|地址|银行地址|
|收款银行代码|若为电子票据，该字段必填，若收款银行上维护了银企云代码会自动带出|
|出票结算方式|参照选择结算方式，可在线录入|

|来源|票据来源|
|状态|票据状态|
|备注|备注|

# []()按钮说明

<付票>：记录纸票付票日期。

<承兑>：记录承兑状态。

<转出>：票据由于某种原因不能付款，把票据转为应付账款，需要注意的是，票据状态为已审核或未兑现时才能转出。

<未兑现>：记录票据未兑现状态。

<作废>：作废当前票据。

<展期>：票据展期，将票据到期日延长。

<换票>：记录换票状态。

<撤销>：逆操作，将票据状态及操作逆转到前序操作情况。

<付款>：票据付款，生成现金银行付款单。

<交易分录>：查看开票生成的交易分录。

<票据行为明细>：查看票据各个行为日志。

<被换票据>：查看纸票被替换的票据。

<对应付款单>：查看应收票据收票时，生成对应的应付付款单。

<换票明细>：查看换票明细。

<质押开票>：查看票据质押下，应付票据质押选择质押开票的数据。

<出票申请>：启用电票通且勾选电子票据，审核后，可点击出票申请，发送开票申请至电票通。

<网银操作状态>：出票申请后，电子网银操作状态请求最新的票据操作状态。

<撤票申请>：退票，电子票据开票后在状态=待签收及提示承兑已签收的情况下发起撤票申请。

# 操作说明

付款

操作前提

*  票据状态为已核准、已承兑。

操作步骤

点击应付票据管理－>付款按钮，可以完成付票据付款。具体步骤如下所示。

*  第1步：选择需要付款的票据，点击付款按钮，弹出付款画面；
*  第2步：录入票据付款栏目
*  第3步：在付款画面点击确定完成付款，关闭本画面。

支持多账号付款；

操作步骤

点击应付票据管理－>付款－>多账号付款按钮，可以完成付票据多账号付款。具体步骤如下所示。

*  第1步：选择需要付款的票据，点击付款－>多账号付款按钮，弹出付款画面；
*  第2步：录入付款的银行、账号、子账号。可以按行录入多条记录；
*  第3步：在多账号付款画面点击确定完成付款，关闭本画面。

转出

操作前提

*  票据状态为已核准、未兑现

操作步骤

点击应付票据管理－>操作－>转出按钮。

*  选择需要转出的票据，点击转出按钮，弹出转出画面，
*  录入票据转出栏目；
*  在转出画面点击确定完成转出，关闭本画面。

作废

操作前提

*  票据状态为已核准

操作步骤

点击应付票据管理－>操作－>作废按钮。

*  选择需要作废的票据，点击作废按钮，弹出作废画面，
*  录入票据作废栏目，可选择删除和红冲两种方式；
*  在退票画面点击确定完成转出，关闭本画面。
*  作废后票据不能做其它操作

展期

操作前提

*  票据状态为已核准

操作步骤

点击应付票据管理－>操作－>展期按钮。

*  选择需要转出的票据，点击展期按钮，弹出展期画面，
*  录入展期后到期日；
*  在展期画面点击确定完成转出，关闭本画面。

换票

操作前提

*  票据状态为已核准

操作步骤

点击应付票据管理－>操作－>换票按钮。

*  选择需要换票的票据，点击换票按钮，弹出换票画面，
*  上卡带出被换票据的数据，下栏填写换回票据的数据；
*  在换票画面点击确定完成转出，关闭本画面。
