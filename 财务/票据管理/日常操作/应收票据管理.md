
# 功能描述

*  本功能节点用于输入和维护应收票据，并提供与应收票据直接相关的收款、贴现、背书、等操作，此外，还可以查询与收票据相关的对应收款单、处理数据明细等信息。
*  V2.1版本，提供了多组织的收票和背书的处理。支持以下的业务应用场景：
*  应用场景一（跨多个核算组织）：企业采用统收统支模式，通过结算中心对资金的收支进行管控；其管辖下的多个成员单位（核算组织）对应的多个业务组织可能与相同的客户（或供应商）同时发生多笔业务往来；针对多个成员单位对同一个客户的应收款项，客户（或供应商）可能合并开具一张票据；针对多个成员单位对同一个客户（或供应商）的应付款项，企业可能合并开出一张票据或者背书一张收票据；此类情形，结算中心都需要明确受益成员单位，以进行准确的核算和核销。
*  应用场景二（跨同一核算组织的多个核算项目）：核算组织或结算中心从客户（或供应商）收票，或向客户（或供应商）出票/背书，可能涉及多个受益部门，受益业务员，多个项目，多个任务，多个预算专项，收支项目；此类情况，企业也有明确核算项目，进行核算和核销的要求；
*  针对这种应用场景，V2.1增加了票据的核算明细处理数据。相应的收票据、付票据都有对应的核算明细数据

# 按钮说明

<托收>：电票收款的一种方式，通过托收发起指令，委托银行发起消息通知付款方。

<提示>：电票消息通知，发送提示通知到付款方。

<转出>：应收票据由于某种原因不能收款，把票据转为应收账款，票据在“已核准”“拒付”“追索”。

<退票>：纸票下，由于某种原因把票据退回；电子票据不需要操作退票来进行票据退回。

<取消票据>：退票的逆操作，将票据状态转回退票之前。

<拒付>：录入票据状态，当前票据被拒付。

<追索>：票据到期后，未收到收款，可向承兑人发起追索。

<展期>：将应收票据到期日延期。

<换票>：纸票下，收到的纸票可能存在错误或者污染等情况，需要将票据退回重新开票。

<银行托管>：纸票下，将票据托管到银行进行托管。

<银行领用>：纸票下，将托管到银行的票据领用回来。

<质押>：将票据质押到银行，质押可进行质押大票换小票。

<取消质押>：将质押到银行的票据转回。

<质押转损失>：质押的票据转回损失，票据余额为0。

<撤销>：撤销，逆操作，将票据状态逆回上一笔的状态。

<背书退回>：背书给客户或者供应商的票据在票据未被被背书人签收时，由我方发起退回操作，转回票据所属权，背书退回可继续进行相关操作。

<取消背书退回>：背书背会逆操作，票据状态为背书，不可进行后续交易操作。

<收款>：表示已经收到收款，会生成现金银行的收款单。

<贴现>：票据贴现到银行，会生成现金银行的收款单。

<背书>：票据权利转移，背书会生成应付付款单，后续不可进行交易操作。

<交易分录>：查看应收票据收票生成的交易分录。

<票据行为查询>：查看应收票据收票后续背书、贴现等票据行为日志、对应的业务单据、对应票据行为生成的交易分录。

<签收状态查询>：对于签收生成的应收票据，需要查询签收状态，成功后才可进行候选操作。

<被换票据>：查看纸票被替换的票据。

<对应收款单>：查看应收票据收票时，生成对应的应收收款单。

<换票明细>：查看换票明细。

<质押开票>：查看票据质押下，应付票据质押选择质押开票的数据。

# 操作说明

收款

操作前提

*  票据状态为已核准、取消质押、背书退回下可进行收款操作。

操作步骤

点击**票据管理**－>应收票据管理按钮，进入应收票据主画面。具体步骤如下所示。

*  第1步：点击收款按钮，弹出‘收款’操作画面；
*  第2步：在‘收款’画面中，输入收款处理日期，期间；币种的汇率类型、汇率会自动带出。选择款项流入的本组织的收款银行 ，收款金额不可编辑，自动带出票面余额，输入收款费用、利息。选择结算方式、收支项目，若现金银行中已经生成了收款单可直接选择参照，若没有会自动生成；
*  第3步：点确定按钮，票据状态变为收款，后台默认生成现金银行收款单。

贴现

操作前提

*  票据状态为已核准、背书退回、取消质押

操作步骤

点击**票据管理**－>应收票据管理按钮，进入应收票据主画面。具体步骤如下所示。

*  第1步：点击贴现按钮，弹出‘贴现’操作画面；
*  第2步：在‘贴现’画面中，输入处理日期，期间；币种的汇率类型、汇率会自动带出。选择贴入本组织的收款银行 ，输入贴现率自动算出贴现息、贴现金额，输入收款费用、利息。选择结算方式、收支项目，若现金银行中已经生成了收款单可直接选择参照，若没有会自动生成；
*  第3步：点确定按钮，票据状态变为贴现，后台默认生成现金银行收款单。

背书

操作前提

*  票据状态为已核准、背书退回、取消质押

操作步骤

点击**票据管理**－>应收票据管理按钮，进入应收票据主画面。具体步骤如下所示。

*  第1步：点击背书按钮，弹出‘背书’操作画面；
*  第2步：在‘背书’画面中，输入处理日期，期间；选择被背书信息，选择被背书对象为供应商，页面上选择供应商相关信息，若选择客户，页面叶璇客户相关信息，后续生成的应付付款单的付款对象也是根据被背书对象是供应商或客户来生成；
*  第3步：点确定按钮，票据状态变为背书，后台默认生成应付付款单。

质押

操作前提

*  票据状态为已核准、背书退回、取消质押

操作步骤

点击**票据管理**－>应收票据管理按钮，进入应收票据主画面。具体步骤如下所示。

*  第1步：点击质押按钮，弹出‘质押’操作画面；
*  第2步：在‘质押’画面中，输入处理日期，期间；选择质押单位，当前U9c上只能支持银行质押，输入质押金额；
*  第3步：点确定按钮，票据状态变为质押。
