
# 功能描述

*  本功能节点用于查询票据签收情况，包括应付开票与应收收票。

# 关键应用

# 业务规则

*  启用票据管理（必做）
*  定义组织（必做）
*  定义SOB（必做）
*  定义币种汇率（必做）
*  定义会计日历（必做）
*  定义结算方式（必做）
*  定义客户档案
*  定义供应商档案
*  定义银行账号
*  定义部门业务员档案
*  定义项目任务
*  定义预算专项
*  定义收支项目
*  启用电子票据

# 栏目说明

|栏目|说明|
|---|---|
|单据类型|显示票据签收回执|
|收票单位名称|显示收票方名称|
|票据类型|枚举值，应收、应付，具体根据所选单号对应的票据所属哪一类型的票据|
|票据号|显示票据号|
|币种|显示票据币种|
|票据面值|显示票据面值|
|出票日|显示出票日|
|到期日|显示票据到期日|
|备注|显示备注|
|是否签收|显示是否签收，是代表已经签收，否代表未签收|
|签收人|显示签收人|
|签收日期|显示签收日期|

# 按钮说明

<签收>：发起票据签收请求。

<联票查询>：联查对应的票据。
