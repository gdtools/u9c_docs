
# 功能描述

*  提供预算保留执行汇总查询

# 业务规则

*  已生成凭证
*  已生成会计科目
*  建立预算年度、设置预算期间、维护科目预算科目控制方案、定义预算组、分配科目预算科目控制方案、设置预算专项，录入预算表等

# 按钮说明

<查询方案>：用户自定义设置查询方案，过滤数据。

<列宽调整>：自定义列表行距。

<打印>：打印。

# 操作说明

预算保留执行汇总查询：按照保留环节显示具体保留方式下的数据

*  点击行－>进入预算执行汇总表界面。
*  查询后点击后退按钮，返回预算保留执行汇总界面。

预算保留执行明细列表查询：显示某个具体环节的预算保留数据

*  点击行－>进入总账预算保留执行明细列表界面或者业务预算保留执行明细列表界面。
*  查询后点击后退按钮，返回预算可保留执行汇总界面。
