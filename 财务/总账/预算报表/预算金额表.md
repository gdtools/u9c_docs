
# 功能描述

*  预算金额表查询

# 业务规则

*  已生成凭证
*  已生成会计科目
*  建立预算年度、设置预算期间、维护科目预算科目控制方案、定义预算组、分配科目预算科目控制方案、设置预算专项，录入预算表等

# 操作说明

预算执行汇总查询：对预算控制对象的预算金额数据进行预算执行数据的查询

*  点击联查-预算执行－>进入预算执行汇总表界面。
*  查询后点击后退按钮，返回预算金额界面。
