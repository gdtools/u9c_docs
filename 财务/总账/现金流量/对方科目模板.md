
# 功能描述

*  提供对方科目模板定义，设置科目与现金流量项目的匹配规则。

# 业务规则

*  定义现金流量表档案（必做）
*  定义现金流量项目档案（必做）
*  定义账簿(必做)
*  设置账簿总账参数，为账簿指定参数现金流量表(必做)

# 栏目说明

|栏目名称|说明|
|---|---|
|对方科目模板-表头||
|账簿|参照选择，可选择当前组织下的账簿|
|现金流量关系企业复制对方科目段值|录入关系企业的现金流量凭证，在模板上设置取对方科目的哪一段，默认为0|
|对方科目模板-表体||
|开始会计科目|定义会计科目起始，参照标准科目录入|
|结束会计科目|定义会计科目结束，参照标准科目录入|
|科目方向|定义科目方向|
|现金流量项目|参照选择，可选择当前组织定义的现金流量项目|
|反向匹配|是否反向匹配|

# 按钮说明

<现金流量项目>：导航到[现金流量项目](/detail/af00a748f6c74ab1bbdde245988ba8ae)档案设置功能。

<复制到其他账簿>：可以把当前的对方科目模板复制到其他的账簿。 账簿参照的规则是，与当前的账簿引用同一个现金流量表。

# 操作说明

新增

*  根据菜单路径进入“对方科目模板”画面
*  点击新增，录入相关信息，点击保存。
