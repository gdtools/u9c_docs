
# 功能描述

*  通过定义凭证分录特征和现金流量项目金额占当前分录金额的比例，分析符合此模版特征的凭证的现金流量项目金额的一种方法

# 业务规则

*  定义现金流量表档案（必做）
*  定义现金流量项目档案（必做）
*  定义账簿(必做)
*  设置账簿总账参数，为账簿指定参数现金流量表(必做)

# 栏目说明

|栏目名称|说明|
|---|---|
|现金流量凭证模板-表头||
|模版类型|业务规则模版：将定义的会计科目发生的金额按一定比例直接归到现金流量项目的一种方法。手工分析模版：仅定义凭证分录模版，而不定义现金流量比例。此模版旨在帮助用户快速找到符合特定特征的凭证，由用户手工分析现金流量金额。|
|平衡实体范围|若账簿的科目结构设置了平衡段，则可以为不同的平衡体指定不同的模版；若不需要区分，则可以选择“当前账簿所有平衡实体”。|
|反向匹配|此选项若为“是”，则凭证中的借方科目与贷方科目交换方向后，仍可以应用当前模版。|
|摘要|输入摘要关键字，则只有凭证行中符合摘要的凭证才能应用当前模版。|
|描述性弹性域|输入匹配内容，则只有凭证行中符合对应描述性弹性域的凭证才能应用当前模版。注意：段值类型<>字符型时，为精确匹配；段值类型=字符型时，为模糊匹配。|
|||
|现金流量凭证模板-表体-凭证体||
|方向|凭证模版科目的方向|
|会计科目|与［会计科目范围］互斥。为模版录入需要匹配的会计科目。可以只录入部分段值内容，可以包含下级。|
|会计科目范围|与［会计科目］互斥。可以指定［所有现金流量类科目］或［所有会计科目］。现金流量类科目指现金流量类属性为是的会计科目。|
|现金流量凭证模板-表体-现金流量||
|现金流量项目|为凭证体的当前分录指定现金流量项目。|
|方向|现金流量项目的方向。流入/增项：主表项目表示流入，附表项目表示增项；流出/减项：主表项目表示流出，附表项目表示减项；|
|比例|当前现金流量项目的金额占当前分录金额的比例。注意，每条分录的现金流量项目金额的比例之和必须为100%。|
|现金流量凭证模板列表||
|账簿|参照选择，可选择当前组织下的账簿|
|模板类型|下拉选择，|
|编号|显示现金流量凭证模板编号|
|名称|显示现金流量凭证模板名称|
|描述|显示现金流量凭证模板描述|
|平衡实体范围|显示平衡实体范围|
|摘要|显示摘要|
|是否反向匹配|显示是否反向匹配|

# 按钮说明

<现金流量项目>：导航到[现金流量项目](/detail/af00a748f6c74ab1bbdde245988ba8ae)档案设置功能。
