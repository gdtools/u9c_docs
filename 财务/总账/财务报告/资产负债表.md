# 功能描述

* 用于展示从OBA保存到系统的静态资产负债表

# 业务规则

* 在基础设置中定义报表项目
* 从OBA保存报表静态数据

# 栏目说明

|栏目名称|说明|
|---|---|
|查询方案||
|账簿|选择账簿，默认为主账簿。|
|币种|选择币种，默认为本币。|
|期间类别|选择期间类型，默认为会计期间。|
|年度|选择年度。|
|期间|选择期间，默认当前期间。|
|栏目||
|制表单位|默认当前登录法人组织|
|账簿|所选账簿|
|报表期间|显示报表期间|

# 按钮说明

<报表取数>：根据设置的取数公式，重新计算报表数据。

<输出>：输出文件到本地。
