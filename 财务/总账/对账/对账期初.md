
# 功能描述

*  在该节点维护账簿启用日期之前的需要进行对账的数据。
*  对账期初的数据参与之后的对账。
*  进行对账后期初的数据不允许修改。

# 业务规则

*  启用总账（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|对账关系设置|录入对账关系的编码，用户录入，非空|
|期初对账截止日期|录入对账关系的名称，用户录入，可空|
|本方组织|系统维护。由对账关系带出|
|本方账簿|系统维护。由对账关系带出|
|对方组织|系统维护。由对账关系带出|
|对方账簿|系统维护。由对账关系带出|
|列表_本方、对方|通过本方、对方页签的切换，可以分别查看本方和对方录入的期初数据|
|制单日期|用户手工录入期初的数据；制单日期需早于表头期初对账的截止日期|
|凭证类型|用户手工录入期初凭证类型|
|摘要|用户手工录入期初凭证摘要|
|会计科目|用户手工录入期初会计科目|
|币种|用户手工录入期初币种|
|汇率类型|用户手工录入汇率类型|
|借方|用户手工录入借方发生额|
|贷方|用户手工录入贷方发生额|
