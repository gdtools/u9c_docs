
# 功能描述

凭证批是同类凭证的一个组合，通过批可以快速录入凭证，也可以控制具有相同属性凭证的相关操作。

# 业务规则

*  启用总账（必做）
*  账簿总账参数“提供凭证批”为“是”（必做）
*  账簿总账参数设置＂批编码规则＂

|本位币贷方累积金额|系统维护币种为账簿本位币：[本币贷方累积金额]=属于该批凭证的∑[本币贷方总金额]；若[控制金额]非空，且当[控制币种]为空时，凭证保存和凭证批关闭时需满足[累积金额]中的本币金额小于等于[控制金额]。批中的草稿凭证、作废凭证的金额不参与累计。|

# 操作说明



新建

*  新增一个批，批状态为打开。

删除

*  只能针对打开状态的批执行删除；
*  删除时，批内必须无提交的凭证；
*  如果批已被凭证引用，则该批不允许删除。

修改

*  只能针对处于打开状态的批修改；
*  批内无凭证，可以修改批的任意参数；批内有凭证，则凭证批不允许修改：凭证类型、记账会计期、币种；
*  修改时如果已经有提交的凭证，不能修改币种，但是可以将原来的币种清空，清空同时清空[原币累积金额]；
*  修改控制张数时，修改后的控制张数不能小于[累积张数]，也可以清空；
*  修改控制金额时，如果币种不为空，则修改后的控制金额不能小于[原币累计金额]，也可以清空；如果币种为空，则修改后的控制金额不能小于[本币累计金额]，也可以清空。

关闭

*  只能针对打开状态的批执行关闭；
*  批关闭时批内不得有草稿凭证；
*  批关闭时批内没有任何单据时不允许关闭；
*  批内存在未记账凭证不得关闭。
*  如果[累积张数]大于[控制张数]，凭证批不可以关闭。
*  如果[累积金额]大于[控制金额]，凭证批不可以关闭。
*  关闭时要校验批的控制张数与控制金额，不符合控制条件系统会提示，但不强行控制。

取消关闭

*  只能对关闭状态的批执行取消关闭；
*  取消关闭要判断当期的会计期间是否已经结账，如果已经结账，则不能取消关闭。
