
# 功能描述

为了解决凭证断号的问题，提供该功能。制单后，不运行整理凭证编号功能，凭证的系统号为空。每次运行该功能，将重新生成选择期间的所有凭证的系统编号。

*  排序依据：凭证.[记账会计期间]+ 凭证.[制单日期]+ 凭证.[系统ID]。
*  流水依据：来自账簿参数设置，会计期间包括调整期。
*  当流水依据为会计年度时，当整理前期凭证系统号时将同时整理其后续的所有期间的系统号。
*  当流水依据为会计期间时可以同时选多个期间，当流水依据为会计年度时只能选择一个会计期间进行编号整理。

# 业务规则

*  凭证类型设置系统编号原则（必做）
*  凭证类型设置序号编码规则（选做）

# 栏目说明

|栏目名称|说明|
|---|---|
|整理凭证-账簿||
|账簿|只显示当前法人组织的账簿；参照选择；默认为该操作员的默认账簿；无默认账簿时默认为该操作员上次调用此界面的账簿；首次使用默认为主账簿；|
|整理编号类型|枚举下拉，凭证系统编号、凭证序号、凭证号凭证系统编号：只能选择未关闭的期间进行系统显示编号整理；总账月结需要判断该期间是否存在为整理的凭证，如果存在，不能结账。凭证号:凭证编号。凭证序号：提供一个凭证的全年编号，通过设置不同的编码规则解决；如果凭证类型中设置了序号编码规则，就必须要整理序号，否则不允许结账。|
|整理编号方式|枚举下拉，顺序整理，序时整理|
|过滤条件||
|会计年度|用户选择|
|凭证类型|参照选择|
|记账会计期间|参照选择|
|状态||
|凭证总数|根据整理操作，更新显示整理凭证总数|
|已生成凭证编号数|根据整理操作，更新显示已生成凭证编号数|
