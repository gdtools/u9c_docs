
# 功能描述

*  查询系统中的凭证
*  可以依据不同的查询条件进行过滤
*  输出栏目及顺序根据用户的需要定制
*  可以动态查询备查凭证明细
*  可以联查凭证、交易分录及相关的来源凭证

# 业务规则

*  建立账簿
*  凭证维护；

# []()按钮说明

<查询>：用户自定义查询条件，过滤列表的数据。

<联查交易分录>：对外部凭证提供联查交易分录。
