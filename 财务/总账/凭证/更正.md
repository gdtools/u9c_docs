
# 功能描述

*  对总账生成的凭证，已审核或已记账的当前会计期及以后会计期的凭证进行有痕迹地修改
*  只能更正当前会计期间的凭证，当前会计期间是打开的会计期间
*  如果修改已经关闭期间的凭证，应通过前期调整凭证修改

# 业务规则

*  当前会计期的凭证：凭证状态＝已审核、已记账
*  账簿总账参数“审计轨迹”＝是

# 操作说明

更正

*  选择更正列表上的凭证，点击更正按钮，弹出凭证卡片，处于编辑状态。
*  凭证修改后，点击＂更正＂按钮，保存修改。
*  生成“更正凭证”，同时［作废］原凭证。
*  凭证更正时，转回设置内容不允许进行更正。
*  有痕迹更正一张已核销备查的凭证,应作废原凭证.清空原核销金额。
*  更正凭证不允许暂存。

有痕迹修改

*  选择更正列表上的凭证，点击更正按钮，弹出凭证卡片，处于编辑状态，点击“更正”按钮，弹出该凭证卡片，不允许对转回内容进行更正，不提供转回页签，只提供基本页签进行修改。
*  凭证进行修改后，录入（或系统生成）新的单据号,点击“更正”按钮，将新生成的更正凭证保存，该凭证来源方式置为：“更正凭证”,同时原凭证自动作废。
*  转回凭证不允许更正。
*  被转回凭证不允许更正。
*  如果凭证已生成转回凭证，应先删除其对应的转回凭证，才能更正该张凭证。

无痕迹修改

*  选择更正列表上的凭证，点击更正按钮，弹出凭证卡片，处于编辑状态，点击“更正”按钮，弹出该凭证卡片，不允许对转回内容进行更正，不提供转回页签，只提供基本页签进行修改。
*  对需要更正的凭证进行修改后，点击“更正”按钮，将凭证保存，该凭证来源方式仍为：“一般凭证”。

无痕迹删除

*  选择更正列表上的一个凭证。
*  点击“更正”按钮或双击该凭证，弹出该凭证卡片，点击“删除”按钮，系统直接将原凭证删除；如果有备查信息，自动取消备查簿核销，需要同步更新预算执行数和控制数。
*  如果凭证已生成转回凭证，需要先手工删除其对应的转回凭证，才能删除该张凭证。
*  如果原凭证进行了备查核销，则自动取消备查簿核销。
*  直接删除该凭证，包括备查簿信息，需要同步更新预算执行数和控制数。

有痕迹删除

*  选择更正列表上的一个凭证。
*  点击“更正”按钮或双击该凭证，弹出该凭证卡片，点击“删除”按钮，凭证勾选“作废”标志。
*  如果凭证已生成转回凭证，需要先手工删除其对应的转回凭证，才能删除该张凭证。
*  如果原凭证进行了备查核销，则自动取消备查簿核销，将原凭证作废，同时作废备查簿信息（凭证备查中依然保留备查簿的记录，但不计入备查簿中），需要同步更新预算执行数和控制数。
