
# 功能描述

*  对没有打转回标志的凭证（单张或多张），手工执行凭证转回

# 业务规则

*  凭证已经制单（必做）

# 按钮说明

<查询>：用户自定义查询条件，过滤列表的数据。

<转回>：对于勾选的凭证进行转回。

<记账>：对于勾选的已经审核的凭证取消记账。

<凭证批>：导航到[凭证批维护](/detail/3464daf06a71498bae2c5f436b711184)档案设置功能。

<凭证维护>：导航到[凭证维护](/detail/1d4492740e404d26a78182051edcd2d1)档案设置功能。

<核准>：导航到[核准](/detail/002df95e79a149fd8fc4e30e38b8e82e)档案设置功能。

<更正>：导航到[更正](/detail/823690b4f3c746ecb038823f878eb7a4)档案设置功能。

<凭证备查>：导航到[凭证备查](/detail/3e66b8fdd951449c9d18bb34e69b33ce)档案设置功能。

<前期调整>：导航到[前期调整](/detail/19047fcbda3845fc969d2c0463c37184)档案设置功能。

<整理凭证编号>：导航到[整理凭证编号](/detail/773248b44f7b49f4a983c039adccb79a)档案设置功能。

# 操作说明

转回

*  选择转回列表上的凭证，可以批量选择，点击转回按钮，弹出转回设置界面。
*  点击确定按钮，弹出转回报告界面：
*  点击确定按钮，自动生成转回凭证，返回列表界面
