
# 功能描述

*  通过本功能实现凭证中备查信息的维护，包括：录入、修改、核销等，同时可以查看备查的核销明细信息

# 业务规则

*  备查核算的凭证

# 操作说明

录入备查

*  选中备查列表上需要维护的凭证，双击－>备查维护界面。
*  录入或修改备查数据，点击确定后返回到上一界面。
*  如果是备查核销凭证，提供实时核销功能。点击操作中的实时核销按钮。进入实时核销界面。

自动核销

*  自动核销方法自动匹配：币种+科目+备查项。
*  系统采用自上向下匹配的方式冲销，即先记入备查的业务先冲销，后记入备查的业务后冲销。
*  自动核销不考虑明细按余额冲销。
*  操作步骤
 
   *  在备查页签上，选中一条备查记录，点击操作－>自动核销；或者在手动核销界面，点击操作－>自动核销。

手动核销

*  当前记录不允许核销时不提供此功能。
*  草稿凭证不允许核销。
*  操作步骤
 
   *  在备查页签上，选中一条备查记录，点击操作－>手动核销。
   *  弹出手动核销界面，列出被核销列表。
   *  点击查找按钮。进入查找界面。
   *  点击查询确定按钮，返回到核销界面，将符合查找条件的凭证列示在核销列表上，通过与“被核销列表”分配录入本次核销金额相匹配进行核销。
   *  手工录入“本次核销金额”后，点击操作－>核销按钮，系统自动控制刷新累计核销金额及核销余额，完成手动核销

核销明细

*  当前记录不允许核销时不提供此功能。
*  操作步骤
 
   *  在备查页签上，双击或点击追溯查询－>核销明细，弹出核销明细界面。
   *  点击关闭按钮，返回到上一界面。
   *  如果要取消核销，点击操作－>取消核销按钮， 取消核销当前的记录，将取消内容从当前界面删除。
   *  如果要全部取消核销，点击操作－>全部取消核销按钮，取消核销所有记录，将取消内容从当前界面删除。

取消核销

*  系统不能自动取消核销，只能手动取消核销。
*  核销的取消不受系统状态的限制，已结账月份的备查核销也可随时取消。
*  选择已被核销记录取消核销，同时取消其对应记录的核销。
*  取消核销反更新备查余额。
*  操作步骤
 
   *  在核销明细界面上，选中一条核销记录，点击操作－>取消核销按钮， 取消核销当前的记录，将取消内容从当前界面删除。

全部取消核销

*  系统不能自动取消核销，只能手动取消核销。
*  核销的取消不受系统状态的限制，已结账月份的备查核销也可随时取消。
*  选择已被核销记录取消核销，同时取消其对应记录的核销。
*  取消核销后更新备查余额。
*  操作步骤
 
   *  在核销明细界面上，选中一条核销记录，点击操作－>全部取消核销按钮，取消核销所有记录，将取消内容从当前界面删除。
