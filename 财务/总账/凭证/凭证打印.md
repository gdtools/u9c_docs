
# 功能描述

为了解决凭证打印的问题，提供该功能。

*  自定义凭证打印范围，根据所定义的过滤条件，生成打印原始数据。
*  自定义选择凭证打印格式。

# 业务规则

*  启用总账（必做）
*  定义账簿（选做）
*  定义凭证打印模板（必做）
*  定义凭证类型（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|打印范围||
|账簿|只显示当前法人组织的账簿；参照选择；默认为该操作员的默认账簿；无默认账簿时默认为该操作员上次调用此界面的账簿；|
|凭证类型|参照录入凭证类型|
|记账期间|录入记账期间范围|
|制单人|参照录入制单人|
|凭证格式|选择凭证格式|
|打印格式||
|打印格式|选择凭证打印格式|
