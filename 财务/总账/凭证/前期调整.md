
# 功能描述

*  如果需要对已关闭会计期间（本会计年度和以前会计年度）的业务进行调整，可以通过前期调整功能来完成，通过填制前期调整凭证，对前期业务进行修订，由此生成的会计凭证的凭证来源方式是“前期调整凭证。
*  前期调整凭证与普通凭证作用相同，也可以进行删除，并处理备查信息，也可进行转回，也可进行预算执行。
*  在记账方面与普通凭证不同的是：前期调整凭证审核即记账。

# 业务规则

*  账簿总账参数里设置“以前年度损益调整”科目（可做）
*  前期调整凭证可以调整损益也可以不调整损益
*  如果调整的是以前年度的损益类科目，有两种处理方式：
*  仍使用原损益科目
*  若设置账簿总账参数“以前年度损益调整”科目，则“损益类科目”用此来替换

# 操作说明

新增调整

*  有已关闭的会计期间 。
*  操作步骤
 
   *  新增调整按钮
   *  新增一张凭证，来源方式：前期调整凭证
   *  保存

修改调整

*  修改调整凭证，修改已关闭会计期间的凭证 。
*  存在前期调整凭证。
*  存在已关闭期间的凭证。
*  操作步骤
 
   *  通过查询功能选择出一个已关闭期间的凭证，选择列表上一张需要修改的凭证新增一张凭证，来源方式：前期调整凭证。
   *  系统生成一张原凭证的红字，新增一张修改数据的开立状态的前期调整凭证。
   *  保存。

删除调整

*  操作步骤
 
   *  通过查询功能选择出一个已关闭的会计期间凭证，选择列表上一张需要删除的凭证。。
   *  系统生成一张原凭证的红字，开立状态的前期调整凭证。
