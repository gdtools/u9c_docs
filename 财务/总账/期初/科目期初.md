
# 功能描述

在这个功能点中可以管理客户的科目期初数据。

*  提供科目余额表期初的手工录入；
*  提供按照总账账簿启用期间之前的期间分期进行期初数据的录入；
*  提供科目余额表期初的快速录入；
*  可以导入其他系统的期初数据。

# 业务规则

*  启用总账（必做）
*  设置编码结构
*  建立会计科目

# 按钮说明

<平衡>：进行试算平衡，要求“期初余额”的借方金额＝贷方金额根据账簿+平衡体试算平衡。

<导入>：可以导入其他系统的期初数据。通过交易分录的设置，可以按照科目导入其他系统的期初数据，满足期初对帐的要求。

<期初余额查询>：期初余额查询。

# 操作说明

录入科目期初数据

*  进入界面后，选择“会计要素”
*  点击“确定”可以加载已经录入的数据，也可以在这个界面进行数据的录入。 系统默认会计要素为“资产”。
