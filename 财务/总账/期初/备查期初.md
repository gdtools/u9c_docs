
# 功能描述

*  提供科目备查期初的详细列表查询
*  提供科目备查期初的组合显示，方便和直观的查询 　　　　　　
*  提供科目备查期初的快速录入方式
*  提供科目“会计科目”.［备查簿录入控制方向］= ＂双向＂的备查项目期初的校验平衡

# 业务规则

*  启用总账（必做）
*  设置编码结构
*  建立会计科目
*  设置会计科目备查项目

# 按钮说明

<汇总显示>：汇总显示备查期初余额。

<校验>：科目期初备查进行校验平衡。

<期初余额查询>：期初余额查询。

# 操作说明

录入科目期初数据

*  进入界面后，选择“会计要素”
*  点击“确定”可以加载已经录入的数据，也可以在这个界面进行数据的录入。 系统默认会计要素为“资产”。

录入备查

*  备查簿的启用期间不允许关闭；
*  注意事项：


总账进行备查期初的录入时，如果总账和备查的启用时间为本年度的第一个期间，要求上个年度的会计期间必须存在。

例如，总账和备查的启用期间为2008年1月，要求2007年的会计年度必须存在，否则报错

*  操作步骤

由“备查期初列表画面”、“备查期初汇总显示画面”单击【录入备查】或双击科目/组合焦点行进入

汇总显示

*  使用前提

备查簿的启用期间不允许关闭

*  操作步骤

由“备查期初画面”点击【汇总显示】，确认显示选项后进入

校验

*  对“会计科目”.［备查簿录入控制方向］= ＂双向＂的科目期初备查进行校验平衡
*  操作步骤

由“科目备查期初列表画面”点击【校验】进入
