
# 功能描述

本节点用于总账和固定资产、应收、应付、库存、成本会计业务模块的对账工作

# 业务规则

*  启动相应模块
*  定义各模块档案

# 栏目说明

|栏目名称|说明|
|---|---|
|查询条件||
|账簿|选择账簿|
|对账规则|选择对账规则，对账规则在基础设置-账簿-对账规则中进行设置，也可以直接点击本 页面下方操作按键【对账规则】链接进入|
|业务组织|选择业务组织|
|会计期间|选择会计期间|
|包含未记账凭证|是否包含未记账凭证|
|按对账维度明细展示|是否按对账维度明细显示，对账维度在对账规则中设置|
|只显示未对符数据|是否只显示对账不符合的数据，相符数据不显示|
|对账记录上报总账|如果选是，那么对账结果会上传总账，在总账【对账记录查询】中可以查到记录|
|栏目说明||
|对账规则|显示对账规则|
|总账系统|显示总账的期初、本期借方、本期贷方、期末余额|
|业务系统|显示业务的期初、本期借方、本期贷方、期末余额|
|差异|显示差异|
|是否相符|显示是否相符|
