
# 功能描述

*  提供科目明细数据按日查询，在不使用现金银行模块的时候，可以用科目日记账出具现金、银行日记账；
*  可以选择日期范围进行查询；
*  可以按照日期和会计期间进行小计；
*  可以按照对方科目进行查询并显示；
*  该报表提供承前页、过次页的功能。

# 业务规则

*  已生成凭证
