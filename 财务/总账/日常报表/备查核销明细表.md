
# 功能描述

*  显示每个备查核销的双方明细数据
*  显示被核销记录和核销记录的本次核销金额、核销余额和累计核销金额

# 业务规则

*  已生成凭证
*  设置了备查核销

# 栏目说明

|栏目名称|说明|
|---|---|
|查询方案||
|账簿|参照选择|
|期间范围|枚举值：当前期间（默认）上一期间去年同期指定期间|
|会计期间|当［期间范围］＝指定期间，可用参照选择|
|原币|参照选择|
|会计科目|参照会计科目|
|科目段|参照标准科目值集的内容|
|普通段。。。|显示对应账簿科目弹性域结构的所有普通段；可以按照不同的段值查询备查核销情况；|
|备查项|显示设置的所有备查项；参照选择|
|原币|参照币种档案选择|
|科目|参照标准科目选择|
|客户|参照客户档案选择|
|供应商|参照供应商档案选择|
|项目|参照项目档案选择|
|任务|参照任务档案选择|
|组织|参照组织档案选择|
|事业部|参照组织档案选择|
|税组合|参照税组合选择|
|部门|参照部门选择|
|工作中心|参照工作中心选择|
|员工|参照员工选择|
|物料分类|参照物料分类选择|
|账号|参照银行账号选择|
|查询栏目||
|本次核销金额|显示对应分录本次核销的金额|
|被核销记录显示被核销记录的凭证号、行号、记帐期间、制单日期等字段|其中累计核销金额和核销余额，按照核销明细的数据进行累计|
|核销记录显示核销记录的凭证号、行号、记帐期间、制单日期等字段|其中累计核销金额和核销余额，按照核销明细的数据进行累计|
|行分组||
|会计科目|按会计科目行分组和行小计按会计科目表头输出|
|原币|按币种行分组和行小计按原币表头输出|
|备查项|按备查项行分组和行小计按备查项表头输出|
|原币余额|可以按余额表头输出|
