
# 功能描述

*  提供科目核销的余额查询；
*  可以选择科目金额的方向进行查询，包括借方、贷方、双向；
*  通过科目核销余额表可以联查科目核销明细数据；
*  可以把会计科目、币种、弹性域结构中的段内容作为分组项和表头项进行查询。

# 业务规则

*  已生成凭证
*  设置了备查核销

# 按钮说明

<查询方案>：用户自定义设置查询方案，过滤数据。

<列宽调整>：自定义列表行距。

<打印>：打印。

# 操作说明

*  点击结果中的科目，进入科目核销明细数据界面，查询后点击回退按钮，返回上一界面。
