
# 功能描述

*  提供科目核销的明细查询
*  按照分录显示已核销金额和核销金额
*  通过科目核销余额表可以联查科目核销明细数据

# 业务规则

*  已生成凭证
*  设置了备查核销

# 栏目说明

|栏目名称|说明|
|---|---|
|查询方案||
|账簿|参照选择|
|期间范围|枚举值：当前期间（默认）上一期间去年同期指定期间|
|会计期间|当［期间范围］＝指定期间，可用参照选择|
|原币|参照选择|
|余额（原币）|期末余额_原币|
|余额（本币）|期末余额_本币|
|余额方向|枚举值：借方贷方双向(默认)|
|余额为零不显示|用户选择默认值：False|
|备查项|用户录入|
|包含未记账凭证|枚举值：是否（默认）|
|会计科目|参照选择|
|会计科目汇总下级|枚举值：是否（默认）|
|原币|参照币种档案选择|
|科目|参照标准科目选择|
|客户|参照客户档案选择|
|供应商|参照供应商档案选择|
|项目|参照项目档案选择|
|任务|参照任务档案选择|
|组织|参照组织档案选择|
|事业部|参照组织档案选择|
|税组合|参照税组合选择|
|部门|参照部门选择|
|工作中心|参照工作中心选择|
|员工|参照员工选择|
|物料分类|参照物料分类选择|
|账号|参照银行账号选择|
|查询栏目结果说明||
|摘要、制单日期、凭证号、账簿期间名称|显示查询结果对应的分录信息|
|借方_原币|如果选择＂借方、双向＂显示核销科目的借方原币金额|
|借方_本币|如果选择＂借方、双向＂显示核销科目的借方本币金额|
|贷方_原币|如果选择＂贷方、双向＂显示核销科目的贷方原币金额|
|贷方_本币|如果选择＂贷方、双向＂显示核销科目的贷方本币金额|
|已核销金额_原币|显示分录已经核销的原币金额|
|已核销金额_本币|显示分录已经核销的本币金额|
|方向|显示查询出的核销科目余额的方向|
|核销余额＿原币|显示查询出的核销科目的原币余额|
|核销余额＿本币|显示查询出的核销科目的本币余额|
|行分组||
|会计科目|按会计科目行分组按会计科目表头输出|
|原币|按币种行分组按原币表头输出|
|标准科目段|按照标准科目行分组按照标准科目输出|
|客户|按客户行分组和行小计按客户表头输出|
|供应商|按供应商行分组和行小计按供应商表头输出|
|项目|按项目行分组和行小计按项目表头输出|
|组织|按组织行分组和行小计按组织项表头输出|
|事业部|按事业部行分组和行小计按事业部表头输出|
|税组合|按税组合行分组和行小计按税组合项表头输出|
|部门|按部门行分组和行小计按部门表头输出|
