
# 功能描述

总账对账表主要是为了月结提供对账的数据：

*  可以按照科目显示总账总的数据、总账手工增加的数据和交易分录对应的数据
*  如果总的数据不等于总账手工的数据与交易分录的数据和，系统会显示出差异
*  通过总账对账表，可以联查总账明细账和来源明细表，追溯查询明细数据

# 业务规则

*  已生成凭证
