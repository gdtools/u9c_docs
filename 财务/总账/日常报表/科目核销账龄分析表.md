
# 功能描述

*  按实时余额或历史余额查询截止到某一天的科目核销账龄
*  提供按借、贷分析方向查询
*  可以联查明细账龄数据
*  可以提供多套账龄区间的分析
*  包含账期内和逾期的查询

# 业务规则

*  已生成凭证
*  设置了备查核销
