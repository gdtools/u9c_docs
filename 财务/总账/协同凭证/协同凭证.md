
# 功能描述

*  在该节点维护协同凭证。
*  录入发送方的协同分录后，按照协同凭证类型中的设置，生成接收方协同分录的内容。
*  发送方和接收方可以通过确认得动作最终形成双方的记账凭证，此过程可以往返多次。
*  通过协同凭证类型中的设置，可以设置是否记录双方确认的过程。
*  生成的双方的记账凭证为“开立”状态，对于协同生成的记账凭证的处理等同于“来源外系统凭证。
*  只有发送方能进行协同凭证的审核／取消审核的操作，且只能是协同凭证为“交易确认完成”状态。
*  协同凭证可以追溯查询生成的记账凭证。
*  协同凭证生成记账凭证后，自动打上已对账标记。

# 业务规则

*  启用总账（必做）
*  建立账簿，设置总账参数（必做）
*  建立凭证类型（必做）
*  设置会计科目
*  协同凭证类型（必做）

# 按钮说明

<备查>：如果协同分录上的科目设置了备查，点击“备查”按钮进行备查的录入。处理与凭证相同。

<协同日志>：可以进行日志的查询。显示确认人、确认时间和确认描述。

<联查凭证>：可以联查由协同凭证生成的记账凭证。

# 操作说明

审核/取消审核

*  如果“交易确认完成”为Ｔ，说明双方都进行了确认的操作。此时发送方可以进行审核的操作；
*  只有发送方能执行审核的操作；
*  由协同凭证生成的双方的记账凭证如果没有审核，记账，发送方可以取消审核。取消审核后，删除对应的记账凭证。

确认/取消确认

*  发送方凭证第一次确认时，按照协同凭证类型的设置，生成接受方的协同分录内容；
*  当某一方修改协同分录的金额、数量等内容与对方不一致时，自动修改对方状态为“未确认”；
*  如果协同凭证类型中，选择了“控制数量”，双方确认时，要求协同分录的数量也必须相等；
*  确认后可以进行“取消确认”的操作。
