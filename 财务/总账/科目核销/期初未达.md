
# 功能描述

*  校验核销科目启用之前的科目期初未达余额和科目余额是否相等
*  期初未达的数据参与后续的核销
*  提供了主账簿和报告账簿的期初未达数据录入

# 业务规则

*  启用总账（必做）
*  定义了核销科目和启用期间（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|期初未达-表头||
|账簿|参照等前登录组织对应的主账簿、报告账簿|
|核销科目|参照账簿对应的核销科目|
|启用期间|由核销科目带入|
|平衡体|参照平衡体进行录入|
|打印格式|录入核销科目的期初未达数据；如果科目设置了核销依据段，则核销依据段也必须录入。|
|凭证日期|用户手工录入。不能晚于科目核销启用期间|
|记账期间|用户手工录入，不能晚于科目核销启用期间|
|凭证类型|用户手工录入|
|摘要|用户手工录入|
|会计科目|用户手工录入|
|票据号|用户手工录入|
|币种|用户手工录入|
|方向|用户手工录入|
|原币|用户手工录入|
|本币|用户手工录入|

# 按钮说明

<检查>：提供期初未达数据与科目的余额进行比较。

<启用>：进行启用的操作。启用后，期初数据不允许修改。

<取消启用>：进行启用的操作。启用后，期初数据不允许修改。

<清空核销期初>：清空核销期初操作。

# 操作说明

检查

*  按照不同的平衡体、核销科目（如果设置了核销依据段，按照不同的核销依据段进行列示），币种进行数据的比较。
*  提供期初未达数据与科目的余额进行比较。
*  比较的内容为：期初未达的原币、本币金额和科目余额的原币、本币金额。系统会自动计算差异进行显示。

启用/取消启用

*  如果期初检查没有差异，可以进行启用的操作。启用后，期初数据不允许修改。
*  如果没有该核销科目没有进行后续的核销操作。可以执行“取消启用”的操作。
*  启用/取消启用的操作，同步维护账簿科目上的“是否启用”标记。
