
# 功能描述

*  在该节点进行科目的核销操作。
*  提供了手工核销、自动核销两种操作。
*  核销时可以显示分录的本次核销金额、累计核销金额、核销余额等信息
*  提供了红蓝对冲和双向核销两种核销方式。
*  可以追溯查询历史核销明细。
*  可以手工取消核销。

# 业务规则

*  启用总账（必做）
*  核销科目已经启用（必做）

# 按钮说明

<新增>：新增核销。

*  点击“新增”按钮，显示查询条件画面。
*  用户手工录入需要核销的条件。其中核销科目必选。

# 操作说明

手工核销／手工红蓝对冲

*  录入本次核销金额，选择记录后，点击手工核销／手工红蓝对冲；
*  如果双方本次核销金额相等，核销成功。如果金额不相等，系统会进行提示“是否强制核销”，如果选择“是”，则系统会按照较小的金额核销双方的记录。

自动核销／自动红蓝对冲

*  过滤出数据后，点击“自动核销／自动红蓝对冲”系统自动进行核销的处理；
*  自动核销默认金额相等；
*  系统采用自上向下匹配的方式冲销，按照凭证日期进行排序。

追溯查询——历史核销明细

*  输入查询条件，可以显示已经核销的分录信息；
*  通过基础／明细的页签切换，可以查询分录对应的核销明细数据。

取消核销

*  查询出已核销数据后，点击明细页签的核销明细，可以进行取消核销的操作。
