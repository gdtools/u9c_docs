
# 功能描述

*  设置对应的凭证记账信息，供登记现金日记账、银行日记账使用

# 业务规则

*  启用总账（必做）
*  设置银行档案
*  当“是否支持从总账凭证登记银行日记账”=FALSE时，此功能不能使用

# 栏目说明

|栏目名称|说明|
|---|---|
|日记账项目|用户录入，可选择：结算票号、对方单位名称、对方开户银行名称、对方银行账号、对方银行地址、发票号|
|扩展字段|用户录入，参照基础档案中设置的实体扩展字段|
