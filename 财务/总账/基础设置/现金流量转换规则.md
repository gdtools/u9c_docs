
# 功能描述

*  定义现金流量表以及现金流量项目之间的转换关系。在账簿转换时，按照现金流量转换规则，转换对应凭证上的现金流量项目。

# 业务规则

*  启用总账（必做）
*  设置现金流量表（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|转出现金流量表|参照选择|
|转入现金流量表|显示所选现金流量表编码规则|
|转出现金流量项目起|用户录入选择转出现金流量表中的现金流量项目|
|转出现金流量项目止|用户录入选择转出现金流量表中的现金流量项目|
|转入现金流量项目|选择转入现金流量表中的现金流量项目|
