
# 功能描述

*  当在单一账簿中通过平衡段实现多个公司（或部门）独立核算时，可以通过此功能设置跨公司凭证的自动处理规则，通过本规则设置，可以实现：
*  在制单时，系统依据在此处定义的科目自动产生公司间平衡分录，实现跨公司凭证的借贷平衡；

# 业务规则

*  启用总账（必做）
*  定义凭证类型（必做）
*  建立账簿
*  建立该账簿使用的编码结构以及设置会计科目
*  编码结构中必须使用了平衡段
*  编码结构中定义公司间平衡段（可选），账簿“启用公司间平衡段”为是

# 栏目说明

对同一个账簿：[凭证来源]+[凭证类型]不能重复设置，包括空值；

*  处理一个凭证平衡时的顺序： 
*  首先匹配[凭证来源]+[凭证类型]，若有规则，则按此规则处理，否则继续匹配
*  匹配[凭证来源]+[凭证类型=空]，若有规则，则按此规则处理，否则继续匹配 
*  匹配[凭证来源=空]+[凭证类型]，若有规则，则按此规则处理，否则继续匹配 
*  匹配[凭证来源=空]+[凭证类型=空]

|栏目名称|说明|
|---|---|
|账簿|用户参照选择；只显示当前法人组织的账簿；账簿只显示主账簿、内账；默认为该操作员的默认账簿；无默认账簿时默认为该操作员上次调用此界面的账簿；首次使用默认为主账簿；新增时自动带入当前账簿，可改|
|编码|用户录入，非空说明：在用户制单时第一次使用“生成公司平衡分录”时系统自动产生一个编码为“０００００“”默认规则，的默认规则用户不可删除，需要用户设置借／贷平衡科目 账簿=当前账簿 公司间科目规则=“00000” 描述=“默认规则” 凭证来源=空 凭证类型=空 其它字段取默认值|
|描述|用户录入，可空|
|凭证来源|用户选择，可空默认为空；空表示其他未在此表中出现的凭证来源系统|
|凭证类型|用户选择，可空默认为空；空表示其他未在此表中出现的凭证凭证类型|
|平衡方式|枚举值：汇总方式（将凭证中有相同科目的分录合并，针对合并后的分录处理平衡体的平衡）明细方式（默认） （不做汇总，直接针对原始分录处理平衡体的平衡）|
|序号|系统维护|
|平衡体|对每一个规则，可以定义一条平衡体为空（其他）的记录，用于处理未在此表中出现的平衡体和凭证中平衡体多对多的情况（称为缺省平衡科目） 一个平衡体只能定义一组借方平衡科目、贷方平衡科目当平衡体由多个段组成时，段值之间用“―”分隔，顺序与编码结构中的定义顺序相同|
|借方平衡科目|参照或手工录入会计科目平衡体可以为空平衡分录的金额发生在借方时的科目规则|
|贷方平衡科目|参照或手工录入会计科目平衡体可以为空平衡分录的金额发生在借方时的科目规则说明：借方平衡科目规则和贷方平衡科目规则可以相同|
