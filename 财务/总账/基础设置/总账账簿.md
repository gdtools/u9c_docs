
# 功能描述

设置总账账簿参数。

# 业务规则

*  启用总账（必做）
*  定义账簿（必做）

# 栏目说明

总账参数页签

|栏目名称|说明|
|---|---|
|提供凭证批|用户选择默认值：否系统是否支持凭证批的处理；|
|批编码规则|只有“提供凭证批”＝“是”时可以设置|
|制单序时|用户选择默认值：否若序时控制，则新凭证制单日期不能小于系统中已经存在的凭证的制单日期；关于凭证制单序时的控制凭证序时控制，应该在凭证编号的范围内控制。如果日期为1、2、3，对应凭证编号为001、002、003。把002凭证删除后，再重新插入002，系统现在控制制单日期必须为3号之后的，应该为1、3号之间|
|自动记录备查|用户选择默认值：否若用户对科目设置了备查项目，系统可自动将分录的科目、币种、方向、金额、备查项目默认值写入备查|
|现金流量表|非空，用户参照选择|
|关系企业现金流量|默认值：否如果选择是，该参数的主要含义是，进行现金流量分析时，需要录入现金流量项目关系企业的相关信息。主要应用的场景是在全球合并系统中，可以按照关系企业进行现金流量项目的抵消。|
|前期调整编码依据|用户选择：制单期间、记账期间。如果选择制单期间，编码结构中有记账期间的段值用制单期间替代|
|允许科目授控|用户选择默认值：是针对主账簿、内账，内账必须与主账簿相同；对于授控科目，只有选定的授控系统可以使用该科目；|
|尾差入账科目|用户选择，可空；在凭证上根据原币、汇率折算本币时，会由于尾差造成借贷不平，系统将金额差额记入该尾差入账科目 <br>-账簿转换时，由于不同科目汇率类型不同，转换到目的账簿后借贷不同，差额走这个科目。合并账簿中该科目通常指定为“外币报表折算差额” <br>- 没有设置此科目时，表示用户不使用该特性，系统将尾差记入金额最大的科目的分录中（平衡体处理同上）|
|以前年度损益调整|用户选择， 可空用于生成前期调整凭证（平衡体处理同上）|
|期末损益凭证可改|用户选择默认值：否|
|汇兑损益凭证可改|用户选择默认值：否|
|模版常用凭证可改|用户选择默认值：否|
|审计轨迹|用户选择默认值：否控制凭证更正方式：ture：只能作废不能删除（注意：草稿凭证可以删除）false:只能删除，不能作废|
|结账损益余额清零|用户选择默认值：是如果设置为ture，则要求月结前，损益类科目余额必须结转为零|
|允许反记账|用户选择默认值：否|
|允许反结账|用户选择默认值：否|
|未来期间数|用户录入，非空|
|启用期间|根据账簿生效日期找到对应账簿会计期间，用户可改|
|从科目取银行账号|默认值：否该参数的主要作用是指定，如果总账需要登记现金＼银行日记账，账号信息是从科目段里面取，还是从凭证分录更多信息中的银行账号字段取。|
|银行账号科目段|如果“从科目取银行账号”为Ｔ，则可以编辑该字段。主要是指定科目弹性域中使用那个段登记银行日记账。参照的内容为科目弹性域中，引用银行账号值集的普通段。|
|录入方式|枚举：录入期初、录入年初。指科目期初的录入方式。如果录入年初，表示科目期初录入时，年初余额是录入的栏目，期初余额是计算出来的。公式为年初余额＋借方累计－贷方累计＝期初余额。如果录入期初，表示科目期初录入时，期初余额是录入的栏目，年初余额是计算出来的。公式为年初余额＋借方累计－贷方累计＝期初余额。|

分录汇总条件页签

用于ＡＡＩ传总账凭证，确定一张凭证的行之间是否合并，只有法人组织的主账簿和报告账簿才可以设置分录汇总条件

|栏目|说明|
|---|---|
|会计科目相同|用户选择默认值：是|
|借贷方向不同|用户选择默认值：是相同会计科目合并时选择，合并后的方向为金额最大方的方向|
|合并后分录顺序|在相同会计科目合并时选择枚举 ：先借后贷（默认）先贷后借不排序|
|按科目编码排序|当[合并后的分录顺序]＝“先借后贷”Or“先贷后借”时设置，同方向分录是否按科目编码排序 默认值：否|
|汇率不一致|用户选择默认值：是合并后的汇率重新反算|
|任务相同合并|默认：否。任务不做为合并条件如果选择：是。表明如果任务相同时，分录进行合并|
|项目相同合并|默认：否。项目不做为合并条件如果选择：是。表明如果项目相同时，分录进行合并|
|银行账号相同合并|默认：否。银行账号不做为合并条件如果选择：是。表明如果银行账号相同时，分录进行合并|
|结算方式相同合并|默认：否。结算方式不做为合并条件如果选择：是。表明如果结算方式相同时，分录进行合并|
|收支项目相同合并|默认：否。收支项目不做为合并条件如果选择：是。表明如果项目任务相同时，分录进行合并|
|票据号相同合并|默认：否。票据号不做为合并条件如果选择：是。表明如果票据号相同时，分录进行合并|
|摘要不同合并|缺省合并|
|摘要合并方式|可空，摘要不同=TRUE时的合并规则 取值可以为：1.常数2.最后一行的摘要 （默认）3.合并|
|摘要|可空 摘要合并方式=“常数”时非空。|
|零交易分录处理|用户选择：忽略（默认）、抛异常。如果生成了值为0的凭证分录，是忽略转总账通过还是系统会进行提示。|
