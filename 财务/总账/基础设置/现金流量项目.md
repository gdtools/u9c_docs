
# 功能描述

*  定义每个现金流量表下的具体的现金流量项目

# 业务规则

*  启用总账（必做）
*  设置现金流量表（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|现金流量表|参照选择|
|编码规则|显示所选现金流量表编码规则|
|编码|用户录入自动带入上级项目的编码，可改必须符合层级规则|
|名称|用户录入，非空|
|描述|用户录入，可空|
|来源|用户选择：主表（默认）附表说明：若带入上级项目的该属性，不可改|
|项目属性|用户选择：流入／增项（默认）流出／减项|
|文本项|用户选择默认值：否|
|汇率调整项目|用户选择默认值：否说明：当［来源］＝附表时，不可选|
|附表调整项目|用户选择默认值：否说明：当［来源］＝主表时，不可选|
