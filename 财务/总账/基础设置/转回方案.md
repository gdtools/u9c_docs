
# 功能描述

*  凭证转回设置用于凭证的自动转回情形下使用，例如月底暂估月初转回的业务； 
*  用户可以依据不同的凭证凭证类别分别设置；
*  当录入凭证时，若该凭证的凭证类别已经定义了转回方案则系统会自动为该凭证打上转回标志，同时依据转回设置生成该凭证的对应的转回凭证。

# 业务规则

*  启用总账（必做）
*  定义凭证类型（必做）

# 栏目说明

|栏目|说明|
|---|---|
|账簿|用户参照选择；只显示当前法人组织的账簿；账簿只显示主账簿、内账；默认为该操作员的默认账簿；无默认账簿时默认为该操作员上次调用此界面的账簿；首次使用默认为主账簿；新增时自动带入当前账簿，可改；|
|名称|录入转回方案名称|
|凭证类型|对照凭证类型档案|
|转回方法|枚举值：转换借贷方向（原凭证的借方金额记为转回凭证的贷方金额，数值不变，原凭证的贷方金额记为转回凭证的借方金额，数值不变）红冲（原凭证的借方金额记为转回凭证的借方金额，数值取反，原凭证的贷方金额记为转回凭证的贷方金额，数值取反）|
|生成时机|枚举值：凭证记账（凭证记账时系统自动生成转回凭证）手工转回（用户执行转回功能时可选择凭证转回）保存凭证（除草稿凭证、作废凭证外，当凭证为OPEN状态时，用户随时可设置凭证的需转回标志，保存此标志时系统自动生成对应的转回凭证）说明：无论选择哪个生成时机，都要保证系统是在已打开的会计期间生成转回凭证|
|记账期间类型|枚举值：年季度会计期间说明：只能选择大于当前账簿会计期间类型的期间类型|
|调整期|用户选择若账簿会计期间未设置调整期，则用户不需选择|
|期初／期末|用户选择期初：所选记账期间的第一个期间期末：所选记账期间最后一个期间|
|本期／下期记账|枚举值：本期记账下期记账(默认)|
|自动记账|用户选择，默认值：否True：转回凭证生成后，系统自动在对应的记账期间对转回凭证记账（按上述参数确定的记账期间记账）False：转回凭证生成后按凭证控制方案进行后续处理，手工触发记账|
