
# 功能描述

*  设置三大报表的显示栏目，预留自定义的栏目。

# 业务规则

*  启用总账（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|账簿|参照账簿档案录入|
|账簿版本|选择所选账簿的版本|
|资产负债竖排|勾选资产负债表是否竖排展示|
|报告类型|显示报表类型，资产负债表、利润表、现金流量表|
|栏目一|设置报表显示字段，下拉可选择发生额、年初余额等|
|栏目二|设置报表显示字段，下拉可选择发生额、年初余额等|
|栏目三|设置报表显示字段，当栏目一或者栏目二为自定义类型时，才可使用。|
|栏目三名称|自定义栏目三名称|
