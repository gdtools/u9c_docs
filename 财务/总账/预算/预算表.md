
# 功能描述

*  录入预算数据

# 业务规则

*  启用总账（必做）
*  建立预算年度
*  建立预算专项（可做）
*  设置预算期间
*  设置预算组

# 操作说明

补齐预算对象：当前组如果没有选择默认专项，系统补充一行默认数据。

*  操作前提
 
   *  定义预算组
*  操作步骤
 
   *  点击操作－>补齐预算对象按钮，系统根据当前预算组下的所有预算对象进行判断，没有选择默认专项的，将预算对象补充一行默认专项，由用户编制预算数据。

快速录入-均摊：根据分摊权重，预算数总额均摊到各预算期间。

*  操作步骤
 
   *  选中预算表上的行，点击操作－>快速录入－均摊按钮，进入均摊界面。
   *  点击确定按钮后，返回到预算表界面，如果预算表行上原先有预算数据，均摊后的数据将覆盖原数据。
   *  点击保存按钮，完成预算表预算数据的录入

快速录入-上年数：以上年预算数为基础快速录入预算数据。

*  操作前提
 
   *  编辑状态可用
   *  有上年预算数据，且上年的预算周期与本年相同
*  操作步骤
 
   *  选中预算表上的行，点击操作－>快速录入－上年预算数按钮，进入快速录入界面。
   *  点击确定按钮后，返回到预算表界面，如果预算表行上原先有预算数据，均摊后的数据将覆盖原数据。
   *  点击保存按钮，完成预算表预算数据的录入

快速录入-上年执行数：以上年预算数为基础快速录入预算数据。

*  操作前提
 
   *  编辑状态可用
   *  有上年预算数据，且上年的预算周期与本年相同
*  操作步骤
 
   *  选中预算表上的行，点击操作－>快速录入－上年执行数按钮，进入快速录入界面。
   *  点击确定按钮后，返回到预算表界面，如果预算表行上原先有预算数据，均摊后的数据将覆盖原数据。
   *  点击保存按钮，完成预算表预算数据的录入
