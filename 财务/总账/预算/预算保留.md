
# 功能描述

*  记录占用预算数的凭证，处理总账系统的预算保留，但只限于保留环节设置为总账的预算科目+币种组合及高级预算控制对象
*  预算保留凭证制单
*  预算保留凭证审核
*  可以取消保留

# 业务规则

*  启用总账（必做）
*  建立预算年度
*  建立预算专项（可做）
*  设置预算期间
*  设置预算组
*  预算年度开始执行

# 栏目说明

|栏目名称|说明|
|---|---|
|预算表||
|保留方式|系统维护：预算保留|
|账簿|根据列表界面带入|
|预算年度|根据列表界面带入，只显示[预算年度状态]<>“未开始执行”的预算年度|
|预算保留环节|系统维护：总账保留|
|凭证号|根据预算保留凭证的编号方式、编号原则处理，如果手工编号，由用户录入，非空|
|凭证类型|系统维护：预算保留凭证|
|日期|用户录入，可改；默认值：依据参数；若总账参数[制单序时=True]，则制单日期必须按时间顺序输入|
|预算控制对象|参照选择，要求[总账预算保留]=true|
|币种|根据预算控制对象带入|
|预算专项|根据[预算控制对象]判断：若该预算控制对象包含有可输入预算专项的科目预算对象，则必须输入；否则，不需输入；系统保存空为特殊标志‘0’ ；|
|行号|系统维护|
|摘要|用户录入，非空|
|控制周期|参照选择|
|金额|用户录入|
|已执行保留数|日常凭证对此预算保留凭证执行保留时，系统自动累加执行金额|
|可执行保留数|日常凭证对此预算保留凭证执行保留时，系统自动累减执行金额|
|制单人|显示制单人|
|审核人|显示审核人|
