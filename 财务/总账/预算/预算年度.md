
# 功能描述

通过本功能，用户可以对预算年度进行维护，包括：

*  增加预算年度
*  预算年度状态维护
*  设置控制段或组合控制等高级控制方式
*  可以查看当前预算年度的预算期间（预算期间不支持调整期）

# 业务规则

*  启用总账（必做）
*  设置会计日历
*  对应账簿中已经建立的会计年度
*  建立账簿
*  设置会计科目
*  预算科目控制（设置后，高级预算控制方式可设置）

# 栏目说明

|栏目名称|说明|
|---|---|
|预算年度页签||
|账簿|显示当前登录组织的主账簿|
|预算年度|用户选择，即打开预算年度不能选择已经存在的预算年度；不能选择该账簿建立之前的预算年度；除新增，不可以修改；|
|状态|系统维护，根据＂操作＂更新：未开始执行（新增默认），开始执行，冻结，关闭。注意：预算年度未确定主方案时为未开始执行状态，此时所有预算数据可以修改，不需变更处理，不能有预算执行数据；预算年度[开始执行]后，所有科目预算设置不能再修改；若已经录入预算数据，则预算年度不能够被取消打开；当预算年度被关闭，即本年度预算执行完毕，此时所有预算（无论是否是主方案）都不能再修改或变更，且预算执行数也不能再变动；关闭预算年度必须在会计年度结账之后，若取消年结，必须先取消预算年度的关闭。|
|高级预算控制方式|枚举值，可空：使用控制段（对预算控制段的段值相同的科目进行组合预算控制，同时支持对单个[科目+币种]控制预算）使用组合控制 （用户任意确定科目组合进行预算控制，同时支持对单个[科目+币种]控制预算）默认为空（只对单个[科目+币种]控制预算）若账簿总账参数“是否进行科目预算控制”=False时，不可设置。注意：开始设置科目预算控制对象后不可修改。|
|预算控制段|只有[预算控制方式=使用控制段]时，才选择参照选择编码结构的普通段；预算控制段可以是连续的，也可以是不连续的；[预算控制结束段]≥[预算控制开始段]|
|预算周期页签||
|预算年度|显示预算年度|
|周期编号|与会计年度一致（即预算年度的开始日期与结束日期与会计年度相同）不受会计年度是否打开的限制）|
|开始日期|其对应会计期间的开始日期|
|结束日期|其对应会计期间的结束日期|

# 按钮说明

<开始>：开始预算执行。

*  操作前提
 
   *  编制预算数据
   *  预算年度状态为“未开始执行”时
*  操作步骤
 
   *  点击操作－>开始按钮
   *  将当前预算年度状态置为“开始执行”；
   *  当该年度没有预算数时，不可以“开始执行”。

<取消开始>：取消预算执行。

*  操作前提
 
   *  只有预算年度状态为“开始执行”时可以操作
*  操作步骤
 
   *  点击操作－>取消开始按钮
   *  将当前预算年度状态置为“未开始执行”；
   *  当该年度有执行数时，不可以“取消开始执行”。

<冻结>：冻结预算执行。

*  操作前提
 
   *  只有“开始执行”的年度才可以选择冻结
*  操作步骤
 
   *  点击操作－>冻结按钮
   *  将当前预算年度状态置为“冻结”；

<取消冻结>：取消冻结的预算。

*  操作前提
 
   *  只有“冻结”的年度才可以选择取消冻结
*  操作步骤
 
   *  点击操作－>取消冻结按钮
   *  将当前预算年度状态置为“开始执行”；

<关闭>：关闭当前预算。

*  操作前提
 
   *  只有开始执行和冻结状态的年度才可以关闭
   *  关闭必须在会计年度结账之后，若取消年结，必须先取消预算年度的关闭
   *  以前预算年度未关闭，本年度不得关闭
*  操作步骤
 
   *  点击操作－>取消冻结按钮
   *  将当前预算年度状态置为“关闭”；

<取消关闭>：取消预算关闭

*  操作前提
 
   *  只有关闭状态的预算年度才可以取消关闭
   *  下一个预算年度已经关闭时，本年度不得取消关闭
*  操作步骤
 
   *  点击操作－>取消关闭按钮
   *  将当前预算年度状态置为“开始执行”；
