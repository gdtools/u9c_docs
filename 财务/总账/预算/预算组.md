
# 功能描述

在科目预算中维护预算组，以及建立预算科目与预算组的关联的相关规则，包括：

*  为预算组分配预算控制方案
*  分配预算币种

# 业务规则

*  启用总账（必做）
*  账簿总账参数“科目预算控制”为true
*  建立账簿
*  设置会计科目
*  建立预算年度
*  建立预算控制方案

# 按钮说明

<预算控制方案>：导航到[预算控制方案](/detail/b77a592d7476428398070e6f3a8e06d3)档案设置功能。

<预算年度>：导航到[预算年度](/detail/5993381cc5d646e7ad173390026f68c9)档案设置功能。

<预算方案>：导航到[预算方案](/detail/fff364b77a0e428e80a8e68371367e79)档案设置功能。

<预算表>：导航到[预算表](/detail/cb6763027fb84ae1bc7704d72038720a)档案设置功能。

<预算保留>：导航到[预算保留](/detail/934c2062aba34e3da313ee5733d9df7a)档案设置功能。

<复制预算组>：从其他预算组复制对应预算科目数据；。

*  操作前提
 
   *  对于采用全局段的科目弹性域结构，无此功能
*  操作步骤
 
   *  点击复制预算组按钮
   *  点击确定，返回预算组界面，完成复制预算组，系统自动用覆盖段值覆盖源预算组中科目的相应段，填充到界面中，是否有预算专项从源预算组中拷贝

<复制目标年度>：当前的预算组复制到目标年度。

*  操作前提
 
   *  定义预算组
   *  建立预算控制方案
*  操作步骤
 
   *  点击操作-复制到目标年度按钮，进入目标年度选择界面
   *  确定后，把当前预算组复制到目标年度。在预算组列表也可以进行批量复制的操作。

<批量录入预算组>：提供一次录入多个预算科目的功能。

*  操作前提
 
   *  定义预算组
   *  建立预算控制方案
*  操作步骤
 
   *  在预算组界面，点击批量录入预算科目按钮，进入预算科目批量录入界面
   *  选择不同的段值，确定后批量添加预算科目

<高级预算控制>：将预算组中设置的预算对象进行预算的控制。

*  操作前提
 
   *  定义预算组
   *  建立预算控制方案
*  操作步骤
 
   *  预算组界面，点击高级预算控制按钮，进入预算控制设置列表界面，设置预算组的预算控制对象
   *  新增时，此列表为空，点击新增按钮进入预算控制对象设置界面。已有预算控制对象时，双击行，也可进入此界面维护已有的预算控制对象
   *  保存后，点击列表按钮，返回到预算控制设置列表界面
   *  完成预算控制对象设置后，点击预算组按钮，返回到预算组设置界面
