
# 功能描述

*  针对不同的组织、料品、部门、项目、业务员设置不同的预算控制对象
*  在自动预算保留的时候，可以针对不同的组合，系统自动对应预算控制对象进行保留

# 业务规则

*  启用总账（必做）
*  账簿总账参数“科目预算控制”为true
*  建立账簿
*  设置会计科目
*  建立预算年度
*  建立预算控制方案
*  设置会计日历
*  预算科目控制（设置后，高级预算控制方式可设置）

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|组织|自动携带当前登录法人组织为业务组织； 可以手工修改 可以参照出与当前登录法人组织有平行关系的组织|
|料品|参照组织所属的料品档案|
|部门|参照组织所属的部门档案|
|项目|参照组织所属的项目档案|
|业务员|参照组织所属的业务员档案|
|预算控制对象|参照当前法人组织的科目预算控制对象数据录入 取当前组织对应的法人组织的主账簿且[执行环节]=“应付；付款”的预算控制对象|
|预算年度|参照预算年度|

# 操作说明

新增：

*  点击预算控制对象对应设置按钮，进入预算控制对象对应设置界面。
