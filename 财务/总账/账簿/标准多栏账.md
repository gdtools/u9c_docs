
# 功能描述

*  用户通过本功能节点可以设置自定义的以标准科目为分析对象的多栏帐

# 业务规则

*  已生成凭证

# 栏目说明

|栏目名称|说明|
|---|---|
|查询方案||
|账簿|选择账簿|
|多栏账设置|选择多栏账设置，多栏账设置通过点击页面下方操作键【多栏账设置】进行。|
|报表栏目格式|枚举值：金额式外币式：含核币信息数量式：含数量信息外币数量式：含核币及数量信息|
|期间范围|选择期间范围|
|会计期间|当期间范围选择为指定期间时可选|
|包含未记账凭证|是否包含未记账凭证|
|原币|选择原币，可以为空|
|合并显示|是否合并显示|
|对方科目显示级次|枚举值：一级或者末级|
|多栏账设置-表头||
|账簿|选择账簿，不能为空。|
|编码|设置多栏账设置方案编码，不能为空。|
|名称|设置多栏账设置方案名称|
|标准科目|选择标准科目，不能为空。|
|栏目定义依据|选择科目编码结构中一个字段成为栏目选择的依据，不能为空。|
|分析栏位置|前置或者后置|
|分析方向|余额方向，借方或者贷方|
|显示余额|是否显示余额|
|说明|用户自行录入|
|多栏账标体-分析栏目页签||
|栏目序号|系统编号|
|方向|借方或者贷方|
|栏目定义列|根据表头的栏目定义依据选择|
|栏目名称|栏目名称|
|分析方式|发生额或者余额|
|备查多栏查询||
|序号|系统编号|
|辅助核算段|选择科目的辅助核算段，选中的会成为标准多栏账的表头分组条件|
|名称|辅助核算段名称|

# 按钮说明

<查询方案>：用户自定义设置查询方案，过滤数据。

<列宽调整>：自定义列表行距。

<打印>：打印。
