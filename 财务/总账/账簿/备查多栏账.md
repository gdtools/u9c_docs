
# 功能描述

提供备查多栏账格式的定制：

*  提供备查多栏账的手工编制
*  提供备查多栏账的快速编制
*  可灵活的定义栏目的数据范围
*  可灵活的定义备查多栏账的格式

提供多栏帐的查询：

*  根据多栏帐格式的定义，提供灵活的查询条件
*  可以选择按金额分析，按余额分析
*  可以选择是否包含未记帐凭证
*  可以合并同凭证分录
*  可以选择排序方式
*  可以选择灵活查询对象

# 业务规则

*  已生成凭证

# 按钮说明

<快速编制>：快速录入备查多栏账栏目。

<栏目组>：定义栏目组。

# 操作说明

备查多栏账定义

*  初始时在备查多栏账列表界面，点击新增按钮定义备查多栏账的栏目：
*  定义公式后，点击校验按钮，提示“语法检查通过”后，点击确定按钮，返回备查多栏账定义画面，完成表达式定义

快速编制

*  点击快速编制按钮，进入分析栏目快速编制界面
*  点击编制按钮，将栏目填至备查多栏账定义界面的“栏目”上

定义栏目组

*  点击栏目组按钮，进入栏目组定义界面
*  点击确定按钮，返回多栏账定义界面
*  需要保存后，多栏账定义界面的栏目组参照才能显示定义的栏目组内容
