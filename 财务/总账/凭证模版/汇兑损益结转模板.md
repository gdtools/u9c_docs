
# 功能描述

处理会计期末及年末时进行汇兑损益结转等系统预制转账模版的设置

# 业务规则

*  启用总账（必做）
*  设置总账参数
*  建立会计科目
*  设置凭证类型


# 栏目说明

|栏目名称|说明|
|---|---|
|期末损益结转||
|账簿|只显示当前法人组织的账簿；默认为该操作员的默认账簿；无默认账簿时默认为该操作员上次调用此界面的账簿；首次使用默认为主账簿；|
|编码|用户录入，非空|
|名称|用户录入，非空|
|描述|用户录入，可空|
|凭证类型|用户参照，非空|
|摘要|默认：结转外币科目汇兑损益修改后自动覆盖填充列表的［摘要］|
|自动记账|用户选择默认：否|
|平衡体|参照输入若非空，表示针对指定平衡体；若为空，表示针对所有平衡体|
|转入汇兑收益科目|参照标准科目|
|收益科目方向|用户选择：默认、借、贷|
|转入汇兑损失科目|参照标准科目|
|损失科目方向|用户选择：默认、借、贷|
|币种类型|枚举值：所有币种（默认）指定币种|
|币种|当“币种类型”＝“指定币种”时可用参照选择|
|汇率类型|用户选择|
|收益／损失拆分凭证|用户选择默认：是|
|转入汇兑收益预算专项|参照预算专项指定转入的汇兑收益科目对应的预算专项|
|转入汇兑损失预算专项|参照预算专项指定转入的汇兑损失科目对应的预算专项|
|需要转回|用户选择默认：否|
|最后执行日|显示上一次运行该模版的时间；|
|序号|系统维护|
|转出科目|末级标准科目；通过“筛选转出科目”操作带入；生成转账凭证时，自动将转出科目(末级标准科目)对应的所有原币余额<>0的会计科目计算汇兑损益|
|摘要|用户录入默认：取自表头［摘要］，可改|
|预算专项|参照预算专项档案|
|执行历史||
|记账期间|显示记账期间|
|凭证类型|显示凭证类型|
|凭证号|显示按模版生成凭证的凭证编号|
|本位币借方金额|显示本币借方总金额|
|本位币贷方金额|显示本币贷方总金额|
|制单|显示制单人|
|制单日期|显示制单日期|
|审核|显示审核人|
|记账人|显示记账人|

# 操作说明

校筛选转出科目：

*  “汇兑损益结转”卡片画面点击“筛选转出科目”进入本画面

执行历史：

*  在“汇兑损益结转”画面点击“执行历史”按钮，或在“凭证模版生成”画面点击“执行历史”按钮进入。
