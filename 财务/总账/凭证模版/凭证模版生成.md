
# 功能描述

通过此功能，可以手工选择以前定义的凭证模版生成凭证。

# 业务规则

*  启用总账（必做）
*  定义常用凭证及批
*  定义批量分摊及批
*  定义期末损益结转
*  定义汇兑损益结转
*  定义转账组合

# 操作说明

模板生成

*  点击“凭证模版”页签－>选择需要生成的模版－>模拟生成按钮，弹出凭证列表画面。双击后弹出凭证卡片浏览。
