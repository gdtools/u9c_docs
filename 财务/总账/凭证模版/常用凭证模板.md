
# 功能描述

对于每个会计期都重复的业务，可以通过该功能定义为常用凭证，利用常用凭证在制单时可以直接生成所需要的会计凭证。

*  框架凭证：仅仅定义凭证分录所使用的科目、摘要等信息，不需要定义金额；
*  标准凭证：需要定义分录的科目、币种、汇率类型、汇率、数量及金额、项目，任务，预算专项金额录入固定数值；
*  公式凭证：与标准凭证相同，只是金额处可以录入公式；

# 业务规则

*  启用总账（必做）
*  设置总账参数
*  建立会计科目
*  设置凭证类型

# 操作说明

执行历史

*  在“常用凭证”画面点击“执行历史”按钮，或在“凭证模版生成”画面点击“执行历史”按钮进入。

总账凭证取数公式

*  点击“原币金额公式”参照－>“财务扩展函数”－>“总账凭证取数函数”按钮进入。
