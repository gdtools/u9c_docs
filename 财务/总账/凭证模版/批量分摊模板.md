
# 功能描述

对于每个会计期都重复的业务，可以通过该功能定义为凭证模版，利用该模版在制单时可以直接生成所需要的会计凭证。

*  与常用凭证不同的是，一个批量分摊模版可以生成多张记账凭证。
*  通过此功能可以实现批量分摊模版及批的维护，包括：增、删、改，以及查询该模版/批曾经生成的记账凭证；
*  批量分摊模版支持三种模式：
 
   *  平行结转：将一组科目的特定金额对应结转到相对应的等量另一组科目中去，通常要求转入科目与转出科目一一对应，数量相同、金额相同。
   *  批量分摊：将一个科目的特定金额依据权重设置结转到多个对应科目中去，通常用于处理成本、费用类科目的分摊，要求转入科目依据特定的权重系数，吸收转出科目的金额。
   *  批量汇总：将多个科目的特定金额结转到一个对应科目中去，通常用于将下级发生的费用、成本或者收入汇总到上级部门，要求转出科目依据特定的权重系数将各自的金额转入到转入科目中。

# 业务规则

*  启用总账（必做）
*  设置总账参数
*  建立会计科目
*  设置凭证类型

# 操作说明

校验：

*  系统针对转入转出科目的校验
*  除预算凭证其他凭证，转出科目和转入科目必须不能为空；
*  转入科目和转出科目中不能出现S；
*  转入科目和转出科目必须不能是公式或常数；
*  转入科目和转出科目的非自然科目段：末级段值必须为C，非末级段值可以是C可以L；
*  转入科目和转出科目的自然科目段：末级段值必须为C，非末级段值必须是L；
*  由末级段值组成的科目组合必须是合法组合；
*  在LSC规则相同的情况下，转入科目和转出科目必须不相同；
*   展开个数的判断：当转入与转出科目都应用段类型L时，展开的段值个数必须相等
*  系统针对ABC因子的校验
*  非末级段值可以为L、C或S；
*  末级段值科目段类型必须对应C；
*  由末级段值组成的科目组合必须是合法组合；
*  非末级段值应用为C时，必须组合成为汇总科目
*  展开个数的判断：当L在ABC中出现多次时，必须在相同的段上，而且展开的段值组成的个数必须相等；
*  ＡＢＣ展开个数与转入转出科目展开个数的判断：当L在ABC中出现时，而且展开的段值组成的合法科目组合码，必须与转入/转出科目数相等；
