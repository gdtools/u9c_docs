
# 功能描述

处理会计期末及年末时进行利润结转与分配、成本结转等系统预制转账模版的设置。

# 业务规则

*  启用总账（必做）
*  设置总账参数
*  建立会计科目
*  设置凭证类型


# 栏目说明

|栏目名称|说明|
|---|---|
|期末损益结转||
|账簿|只显示当前法人组织的账簿；默认为该操作员的默认账簿；无默认账簿时默认为该操作员上次调用此界面的账簿；首次使用默认为主账簿；|
|编码|用户录入，非空|
|名称|用户录入，非空|
|描述|用户录入，可空|
|凭证类型|用户参照，非空|
|摘要|默认：将损益科目的余额至结转本年利润修改后自动覆盖填充列表的［摘要］|
|自动记账|用户选择默认：否|
|平衡体|参照输入若非空，表示针对指定平衡体；若为空，表示针对所有平衡体|
|转出科目方向|用户选择：正数转出，科目余额方向反向。正数转出：是指永远以正数转出。取出的转出科目的数据如果是正数就放在借方，如果是负数，就放在贷方。科目余额方向反向：是指按照科目余额方向来确定转出科目的方向，而不是按照取出余额的正负进行区分。|
|转入科目|参照标准科目录入|
|需要转回|用户选择默认：否|
|最后执行日|显示上一次运行该模版的时间；|
|序号|系统维护|
|转出损益科目|末级标准科目通过“筛选转出科目”操作带入，筛选后：列示符合筛选条件的“标准科目”且“标准科目”.［科目属性］.［会计要素］.［是否损益科目］=‘是’的标准科目。|
|摘要|用户录入默认：取自表头［摘要］，可改|
|筛选转出科目||
|会计要素|参照“会计要素”．［是否损益科目］=‘True’ 的会计要素|
|科目属性|参照输入，可空，空表示全部，默认空参照“科目属性”.［是否损益科目］=‘True’的科目属性|
|科目分类|参照输入，可空，空表示全部，默认空参照“账簿标准科目”.［是否损益科目］=‘True’的科目分类|
|标准科目|标准科目范围参照|
|执行历史||
|记账期间|显示记账期间|
|凭证类型|显示凭证类型|
|凭证号|显示按模版生成凭证的凭证编号|
|本位币借方金额|显示本币借方总金额|
|本位币贷方金额|显示本币贷方总金额|
|制单|显示制单人|
|制单日期|显示制单日期|
|审核|显示审核人|
|记账人|显示记账人|

# 操作说明

校筛选转出科目：

*  “期末损益结转”卡片画面点击“筛选转出科目”进入本画面

执行历史：

*  在“期末损益结转”画面点击“执行历史”按钮，或在“凭证模版生成”画面点击“执行历史”按钮进入。
