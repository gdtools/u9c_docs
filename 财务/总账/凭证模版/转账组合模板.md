
# 功能描述

可以将已经定义好的常用凭证、期末损益结转、汇兑损益结转和批量分摊在此组合成一个组合，以便于生成凭证时依据相同的策略调用多个常用凭证或批量分摊。

可平行定义、顺序定义。

# 业务规则

*  启用总账（必做）
*  设置总账参数
*  建立会计科目
*  设置凭证类型


# 栏目说明

|栏目名称|说明|
|---|---|
|基本页签||
|账簿|只显示当前法人组织的账簿；账簿只显示主账簿和报告账簿；新增时，默认为该操作员的默认账簿；无默认账簿时默认为该操作员上次调用此界面的账簿；首次使用默认为主账簿；|
|编码|用户录入，非空|
|名称|用户录入，非空|
|描述|用户录入，可空|
|组合类型|枚举值：平行（默认）顺序|
|出错处理方式|枚举值：回滚（默认）忽略|
|生成方式|枚举值：覆盖（默认）保留|
|最后执行日|显示系统执行该模版日期|
|顺序号|系统维护|
|引用类型|枚举值：常用凭证批；常用凭证模版；批量分摊批；批量分摊模版；转账模版|
|引用对象|参照设置的凭证模版|
|自动记账|用户选择默认：否|
|执行历史||
|记账期间|显示记账期间|
|凭证类型|显示凭证类型|
|凭证号|显示按模版生成凭证的凭证编号|
|本位币借方金额|显示本币借方总金额|
|本位币贷方金额|显示本币贷方总金额|
|制单|显示制单人|
|制单日期|显示制单日期|
|审核|显示审核人|
|记账人|显示记账人|
