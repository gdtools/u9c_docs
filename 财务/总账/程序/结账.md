
# 功能描述

*  结账指结束一个会计期间的日常和期末业务处理，计算期间损益，并结转科目相应余额，结账后可以进行期间的关闭
*  提供期间状态管理列表
*  提供期间打开期间、关闭期间、取消关闭期间、永久关闭、冻结、解冻会计期间功能
*  提供关闭会计期间检查

# 业务规则

*  建立账簿
*  建立会计科目
*  若账簿总账参数［允许反结账］＝是，“取消结账”才能操作
*  账簿总账参数［未来期间数］，影响打开的期间数
*  若账簿总账参数［结账损益余额清零］＝是，要求结账前所有损益类科目余额为零。

# 栏目说明

|栏目名称|说明|
|---|---|
|账簿|参照选择只显示当前法人组织的除多币种账簿的其他账簿；默认为该操作员的默认账簿；无默认账簿时默认为该操作员上次调用此界面的账簿；首次使用默认为主账簿；|
|会计年度|用户选择默认当前年度|
|会计期间|显示全年所有的会计期间，包含调整期；启用期间之前的会计期间不需显示；|
|期间状态|系统维护|
|操作人|显示操作人|

# 按钮说明

<打开>：打开会计期间

*  操作步骤

选中会计期间行，点击操作－>打开按钮，系统根据判断打开该期间，期间状态刷新为“打开”。

*  注意：
*  如果焦点行不是账簿启用期间之后的最小未打开期间，置灰不可用；
*  打开会计期间是启用年度的启用会计期间，或者其上一个会计期间不是“未打开”状态（即会计期间要顺序打开，包括调整期）；
*  可以打开多个期间，要求当前已经打开的期间数+1 <= 账簿总账参数［未来期间数］；
*  当前打开的会计期间在账簿有效期内。

<关闭>：关闭会计期间

*  操作步骤

点击操作－>关闭按钮

*  系统弹出期末结账向导画面，进行试算平衡。
*  如果试算结果平衡后，点击下一步，系统弹出期间工作报告画面：
*  对本期凭证记账情况报告；
*  列出本期损益类未结转为零的一级科目；
*  本期试算平衡报告；
*  其他系统结账状态
*  显示结账内容，根据参数决定是否可以结账，如果可以结账，显示：“ 期间通过工作检查，可以结账，结账前请做好数据备份。” 点击“完成”按钮，返回结账界在给当前会计期间的期间状态刷新为“关闭”。
*  如果不可以结账，显示：“ 期间未通过工作检查，不可以结账!”，点击“取消”按钮退回到结账界面。
*  注意：
 
   *  如果焦点行不是最大已关闭期间的下一个期间，置灰不可用；
   *  其上一个会计期间为“关闭”或者“永久关闭”状态；
   *  本账簿不存在尚未转回的需要在本期转回的凭证；
   *  先进行记账检查，若有未记账的凭证，系统进入记账界面执行记账，然后进入向导画面。
   *  若账簿总账参数“结账损益余额清零”=T，则该期间该账簿的所有损益类科目的期末余额必须=0。
   *  无论总账参数“结账损益余额清零”是否为T，如果是当前会计年度的最后一个会计期间，要求所有损益类科目的期末余额必须为0
   *  对其他系统的结账检查：系统检查该法人组织的所有组织该期间必须为“关闭”或者“永久关闭”状态，其他模块已结账，财务可结账，其他模块未结账，财务不可结账；
   *  总账结账，系统自动打开未来会计期间数： 
   
      *  若已经打开期间数>=参数值，不作任何动作；
      *  若已经打开期间数<参数值，自动打开尚未打开的期间；
      *  对年度的最后一个期间结账时，自动打开下一年度的第一个期间，其他期间可以手工打开；

<取消关闭>：对已结账的会计期间取消关闭，将期间状态重新置为打开状态。

*  操作步骤

选中已关闭的会计期间行，点击操作－>取消关闭按钮，系统根据参数判断是否允许反结账，将该期间状态由“关闭”改为“打开”。

*  注意：
*  如果焦点行不是最大已关闭期间，置灰不可用；
*  只有最近关闭的会计期间可操作，包括普通会计期间和调整期间；
*  若是会计年度的最后一个会计期间，在取消关闭前要判断其对应的预算年度是否已经关闭，若预算年度已经关闭，不得取消关闭；
*  下一期间已关闭本期间不允许取消关闭；
*  要求输入口令进行确认。

<冻结>：对已打开的会计期间冻结

*  操作步骤

选中已关闭的会计期间行，点击操作－>取消关闭按钮，系统根据参数判断是否允许反结账，将该期间状态由“打开”改为“冻结”。

*  注意：
*  已经冻结的会计期间，只有冻结人可以进行业务操作。
*  只有打开的会计期间可操作；
*  如果焦点行不是已打开期间，置灰不可用。

<解冻>对冻结的会计期间解冻

*  操作步骤：

选中已冻结的会计期间行，点击操作－>解冻按钮，系统根据参数判断是否允许反结账，将该期间状态由“冻结”改为“打开”。

*  注意：
*  只有冻结的会计期间可操作；
*  如果焦点行不是已冻结期间，置灰不可用。

<永久关闭>：对已关闭的会计期间永久关闭

*  操作步骤

选中已关闭的会计期间行，点击操作－>永久关闭按钮，系统根据参数判断是否允许反结账，将该期间状态由“关闭”改为“永久关闭”。

*  注意：
*  只有关闭的会计期间可操作；
*  其上一个会计期间为“关闭”或者“永久关闭”状态；
*  如果焦点行不是已关闭期间，置灰不可用；
*  永久关闭后，将永远无法打开会计期间；
*  要求输入口令进行确认。
