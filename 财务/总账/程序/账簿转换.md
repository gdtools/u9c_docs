
# 功能描述

*  实现数据在不同的账簿之间的转换，满足数据在不同的账簿间传递的需求

# 业务规则

*  建立账簿
*  建立会计科目
*  定义账簿总账参数
*  凭证制单
*  定义账簿转换规则

# 按钮说明

<转换>：根据定义的转换条件，直接执行转换

*  注意：
*  必须在期间起、期间止输入内容才能转换。

<转换日志>：查看转换日志

*  可以查看是否转换成功。
*  如果没有成功，会显示失败的原因；
*  如果已经成功，会显示转换后的凭证号；
*  可以进行日志的维护，删除没有转换成功的日志记录；
*  会显示期间、转换人、转换状态、描述等信息
