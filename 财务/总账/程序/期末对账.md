
# 功能描述

*  提供期末对账
*  提供科目试算平衡
*  提供总账与明细账对账
*  提供总账与备查簿对账
*  提供对账错误报告

# 业务规则

*  建立账簿
*  建立会计科目
*  若有凭证，要求凭证已经全部记账

# 按钮说明

<平衡>：进行科目试算平衡。

*  本期所有科目SUM借方本币金额=SUM贷方本币金额；SUM借方本币调整=SUM贷方本币调整
*  本期科目余额=期初+增加-减少（科目余额方向在借、双向的增加在借，减少在贷；科目余额方向在贷的增加在贷，减少在借）
*  操作步骤
 
   *  点击平衡按钮
   *  点击确定后，返回到对账列表界面，将“平衡／不平衡”结果返填到平衡栏目

<备查检查>：对凭证的备查数据进行平衡检查。

*  凭证已经记账
*  操作步骤
 
   *  点击备查检查按钮，进入科目备查对账界面
   *  点击备查余额页签
   *  点击期末对账按钮，返回到对账列表界面
