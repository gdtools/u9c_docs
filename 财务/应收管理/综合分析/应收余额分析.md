
# 功能描述

可以查询各期应收余额、排名及趋势的情况；

可以按业务类型查询应收余额构成；

可以查询应收余额的金额构成；


# 业务规则

*  已启用应收管理

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|核算组织|参照组织档案录入|
|来源组织|参照组织档案录入|
|业务组织|参照组织档案录入|
|结算组织|参照组织档案录入|
|分析类型|枚举值：业务类型构成分析余额构成分析排名比较|
|比较方式|当分析类别＝比较时，有效；可以选择：环比(默认)：每一期与上期比较基比：每一期与指定的某一期(基准期)比较|
|比较期类别|当分析类别＝比较时，有效；可以选择：年季月会计期间(默认)|
|比较期范围|录入比较期个数|
|基准期|当比较方式＝基比时，有效|
|前排名|当分析类别＝比较时，有效；输入前排名的个数，筛选显示前排名内的记录，截去排名外的记录|
|排名顺序|当分析类别＝比较时，有效；可以选择：降序(默认)升序|
|业务类型|可限定查询应付单的业务类型范围|
|单据类型|可限定查询应付单的单据类型范围|
|包含未立账|确定满足截止时间的未立账单据是否包括在查询范围内|
|未立账单据|当[是否包含未立账]＝true时，可指定包含哪些未立账的单据类别，如未立账销售订单、预出货单、出货单、退货单、销售发票、资产调出单、管销费用单，未开票销售订单、出货单、退货单等|

应收余额排名画面

|栏目名称|说明|
|---|---|
|排名|各个期间的应收余额按排列顺序所得到的序号|
|趋势|将“排名”与上期比较，得出“↑”(升)、“↓”(降)、“--”(平)|

应收余额构成分析(按业务类型)画面

按照应收的业务类型作为栏分组显示

应收余额构成分析(按金额)画面

按照余额类型，如保证金、未税金额余额、税额余额等作为栏分组显示应收余额

应收余额分析画面

显示各个比较期的余额，比进行比较分析

# 操作说明

通过菜单<a href="/detail/593325f9dbbd4c03819e65cbae72574d">应收余额分析</a>进入应收余额分析界面；

*  操作步骤
 
   *  第1步：录入查询条件。
   *  第2步：点击保存/确定，即可查看应收余额分析。
