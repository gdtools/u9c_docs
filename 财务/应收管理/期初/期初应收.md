
# 功能描述

本节点用于在应收系统启用时录入期初应收数据。本节点采用卡片录入的方式，将应收系统启用前存在的应收业务以应收单的形式录入U9应收系统，以便这些业务的所有后续变化都在系统的控制之中。

# 业务规则

*  参数设定，与应收期初相关参数

|参数编码|参数名称|说明|
|---|---|---|
|AR501|是否提供应收批的处理|是：系统提供对应收单按批管理，也可以不使用应收批否：系统不提供应收单按批管理|

*  定义应收单类型档案（必做）
*  定义币种档案（必做）
*  定义客户档案（必做）
*  定义料品档案（必做）
*  定义应收批
*  定义立账条件
*  定义收款条件
*  定义费用项目
*  定义税别、税组合
*  定义部门、业务员档案
*  定义项目任务档案

# 栏目说明

期初应收单据卡片头－基本页签

|栏目名称|说明|
|---|---|
|应收批|当系统提供应收批管理时，选择当前单据所属的应收批。参见：应收批|
|单据类型|选择当前应收单的单据类型，单据类型决定了单据的业务类型和后续处理，期初应收单可以选择任意应收单据类型。参见：应收单类型|
|单号|显示或输入本收款单的编号。当您所选的单据类型定义为自动编号时，本栏目显示系统自动生成的单据编号；当您所选的单据类型定义为手工编号时，请在本栏目中输入单据编号。注意　:单据编号不允许重复，您在手工输入单号时需特别注意！|
|客户|选择当前应收单所代表的应收账款的立账客户|
|客户位置|选择当前应收单所代表的应收账款的立账客户位置|
|记账期间|期初应收单的记账期间固定为空|
|来源业务类型|选择产生当前应收债权的来源销售业务类型|
|来源组织|当前债权的来源销售业务所属的组织|
|税组合[]()|选择当前应收单所对应的税组合。如果您在本栏目选择的是属性为“单头税”的税组合，则该税组合将做为所有单据行税组合的默认值，并且不允许修改；如果您在本栏目选择的是属性为“单行税”的税组合，则该税组合也将做为所有单价行税组合的默认值，但允许修改。参见：税及税组合|
|状态|显示当前应收单的状态，点击该栏目弹出应收单表头状态画面显示详细的单据状态信息|

期初应收单据卡片头－客户页签

|栏目名称|说明|
|---|---|
|<分组>立账|本分组显示与债权确立相关的客户信息|
|<分组>付款|本分组显示与款项回收相关的客户信息|

期初应收单据卡片头－币种页签

|栏目名称|说明|
|---|---|
|信用客户位置|对客户有信用管理时，选择对当前客户实行信用管理的客户位置。参见：信用管理|
|额币|标识信用额度的币种|
|业务组织|当前债权的来源销售业务对应的营运组织|
|结算组织|启用资金结算模块时，需指定后续收款的结算组织|

期初应收单据卡片头－核算页签

|栏目名称|说明|
|---|---|
|立账条件|选择当前应收单的立账条件（应收），此立账条件将做为当前应收单所有单行立账条件的默认值|
|收款条件|选择当前应收单的收款条件，此收款条件将做为当前应收单所有单行收款条件的默认值|
|优先等级|用于设置当前应收单按优先等级核销时的优先等级，分为A、B、C、D、E五级，A级最高，E级最低|
|项目|选择当前应收业务所属的项目，此栏目将做为当前应收单所有单行所对应项目的默认值|
|任务|选择当前应收业务所属的任务，此栏目将做为当前应收单所有单行所对应任务的默认值|
|单价含税|当前单据行上输入的单据是否是含税单价，参见：单价|

期初应收单据卡片体－行页签

|栏目名称|说明|
|---|---|
|料品|选择当前行所针对的料品，有关料品的详细信息在料品页签录入。|
|单价|由单价含税栏目确定本栏目内输入单价的业务意义：单价含税：系统认为单体行页签上输入的单价为含税单价单价不含税：系统任务单体行页签上输入的单价为未税单价|
|未税金额|单价不含税时，可以在单价、数量信息不完整时输入本栏目以反算得到其他栏目的数据|
|税额|当前单据行业务所发生的税额。点击该栏目弹出税明细画面显示详细的税别和税额|
|价税合计|单价含税时，可以在单价、数量信息不完整时输入本栏目以反算得到其他栏目的数据|
|总金额|未税金额、税额和费用的金额合计|
|总金额余额|显示当前单据的总金额余额，点击该栏目弹出应收单总金额余额查询画面显示详细的余额信息|
|状态|显示当前应收单行的状态，点击该栏目弹出应收单表行状态画面|

期初应收单据卡片体－料品页签

|栏目名称|说明|
|---|---|
|客户料号|记录当前料品在当前客户的料品档案中的编号，以便于与客户交流|
|料号|选择或显示当前应收单行的料号和版本，前面的栏目代表料号，后面的栏目代表料品版本|
|品名|显示当前料品的品名，如果您选择的是一次性物料，则本栏目可以手工修改。参见：料品|
|物料分类体系|当预收对象为物料分类时，记录物料分类对应的物料分类体系|
|物料分类|当预收对象为物料分类时，记录物料分类名称|
|等级|显示或选择当前料品的等级。如果当前料品的等级由来源单据带入，则本栏目仅用于显示。如果当前料品需要等级控制，则本栏目必须选择。|
|成分|显示或选择当前料品的成分。如果当前料品的成分由来源单据带入，则本栏目仅用于显示。如果当前料品需要成分控制，则本栏目必须选择。|
|收货客户位置|选择收货客户位置，点击该栏目可以查看收货客户位置的详细信息|

期初应收单据卡片体－量价页签

|栏目名称|说明|
|---|---|
|<分组>税|维护当前单据行的税组合，参见：单头税组合|
