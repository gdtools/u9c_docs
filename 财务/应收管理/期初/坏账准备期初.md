
# 功能描述

本节点用于向U9应收系统输入系统启用时的坏账准备期初余额，以后的坏账准备计提期间期初余额由系统自动计算得到，无需手工录入。

# 业务规则

*  参数设定，与坏账准备期初相关参数

|参数编码|参数名称|说明|
|---|---|---|
|AR201|是否计提坏账准备|是：当前组织需要计提坏账准备否：当前组织不需要计提坏账准备|

*  定义SOB档案（必做）
*  定义币种档案（必做）
*  定义会计日历档案（必做）

# 栏目说明

坏账准备期初维护

|栏目名称|说明|
|---|---|
|期间|本栏目显示的是应收系统启用的会计期间期间|
|坏账准备期初余额|在本栏目输入当前期间的坏账准备期初余额|
