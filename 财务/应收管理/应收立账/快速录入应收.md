
# 功能描述

对本功能节点用于快速录入并批量提交审核借项账户单和贷项账户单


# 业务规则

*  参数设定，与应收单相关参数

|参数编码|参数名称|说明|
|---|---|---|
|AR501|是否提供应收批的处理|枚举值：是：在应收单中允许录入应收批号,但不是必须录入否：在应收单中不允许录入应收批号|

*  定义应收单单据类型（必做）
*  定义客户档案（必做）
*  定义货币档案（必做）
*  定义物料档案（必做）
*  定义税组合档案（必做）
*  定义立账条件档案
*  定义收款条件档案
*  定义业务员档案
*  定义部门档案
*  定义任务档案
*  定义项目档案
*  定义费用项目档案
*  定义预算专项档案
*  定义收支项目档案

# 栏目说明

行页签

|栏目名称|说明|
|---|---|
|单据类型|选择当前应收单的单据类型，只能选择业务类型为“借项通知单”或“贷项通知单”的单据类型参见：应收单类型|
|单号|显示或输入本收款单的编号。当您所选的单据类型定义为自动编号时，本栏目显示系统自动生成的单据编号；当您所选的单据类型定义为手工编号时，请在本栏目中输入单据编号。注意　:单据编号不允许重复，在手工输入单号时需特别注意！|
|客户|选择当前应收单所代表的应收账款的立账客户|
|客户位置|选择当前应收单所代表的应收账款的立账客户位置|
|币种|选择当前应收单的核算币种|
|立账日期|选择应收单的立账日期，该日期只能在未结账的应收期间内|
|记账期间|选择应收单的记账期间，只能是未结账的应收期间|
|税组合|选择当前应收单所对应的税组合。|
|未税金额|单价不含税时，可以在单价、数量信息不完整时输入本栏目以反算得到其他栏目的数据|
|税额|记录当前单据的税额。点击栏目名弹出税明细画面显示详细的税别和税额|
|价税合计|单价含税时，可以在单价、数量信息不完整时输入本栏目以反算得到其他栏目的数据|
|总金额|显示当前应收单的总金额|
|状态|显示当前应收单的状态，点击该栏目弹出应收单表头状态画面显示详细的单据状态信息|

其他页签

|栏目名称|说明|
|---|---|
|应收批|当系统提供应收批管理时，选择当前单据所属的应收批。参见：应收批|
|来源业务类型|选择产生当前债权的来源销售业务类型|
|优先等级|用于设置当前应收单按优先等级核销时的优先等级，分为A、B、C、D、E五级，A级最高，E级最低参见：应用专题－应收核销|
|收款条件|记录当前应收单行所对应应收账款的收款条件，点击栏目名可查看收款条件的详细信息|
|业务员|记录当前应收单行业务所对应的销售业务员，点击栏目名可查看业务员的详细信息|
|部门|记录当前业务所对应的部门，点击栏目名可查看部门的详细信息|
|收款员|记录当前应收单行业务所对应的收款员，点击栏目名可查看收款员的详细信息|
|项目|记录当前应收单行业务所对应的项目，点击栏目名可查看项目的详细信息|
|任务|记录当前应收单行业务所对应的任务，点击栏目名可查看任务的详细信息|
|预算专项|选择当前应收单行业务所对应的预算专项，点击栏目名可查看预算专项的详细信息，参见：预算专项|
|收支项目|选择当前应收单行业务所对应的收支项目，点击栏目名可查看收支项目的详细信息，参见：收支项目|
|备注|输入备注信息|

**按钮说明**

*  <提交操作>：本节点支持多张单据的批量提交，选择需要提交的单据点击提交按钮，系统会弹出提交报告画面，显示总的提交张数、提交成功的张数以及提交失败的张数，并将提交失败的记录列示在列表中。
*  <审核操作>：本节点支持多张单据的批量审核，选择需要提交的单据点击审核按钮，系统会弹出审核报告画面，显示总的审核张数、审核成功的张数以及审核失败的张数，并将审核失败的记录列示在列表中。
*  <列表批量修改>：可以批量修改应收单头的开票依据，记账期间、立账日期，税务发票号和开票日期，可以批量修改应收单行的税控发票号和开票日期。
