
# 功能描述

本功能用于生成催款函：

可以分别以应收单、销售订单、销售出货单、销售发票为依据进行催款

催款记录的明细程度可以按单、行、分期行；

可以保存催款记录单，

可以随时查看催款记录；

根据催款日期对逾期应收进行催款；

可以按账龄区间对应的不同催款级别进行催款；

可以按催款次数对应的不同级别进行催款；

# 业务规则

*  设置账龄区间方案

# **栏目说明**

生成催款函画面

|栏目名称|说明|
|---|---|
|付款客户：客户|选择需要催款的付款客户，可多选|
|付款客户：客户位置|选择需要催款的付款客户位置，可多选|
|立账客户：客户|选择立账客户用于过滤数据，可多选|
|立账客户：客户位置|选择立账客户位置用于过滤数据，可多选|
|按提前催款天数催款|可以选择按提前催款天数催款，提前催款天数定义在收款条件中，如果选择了本栏目，则在判断是否需要催款时要考虑提前催款天数的影响|
|显示依据|选择催款函数据的显示依据：按应收单：催款函中的应收数据按应收单号显示按立账来源单据：催款函中的应收数据按应收单的立账来源单据号显示|
|附账龄分布报表|选择是否需要在催款函中增加一个账龄分布的附属报表|
|账龄区间方案|需要附账龄分布报表时，选择生成账龄区间的账龄区间方案|

# **按钮说明**

*  <执行>：本操作用于手工生成催款函。
   *  操作步骤
   *  点击应收管理－>催款对账－>生成催款函－>执行按钮，手工生成催款函。具体步骤如下所示：
   *  第1步：在生成催款函画面中输入条件；
   *  第2步：点击执行按钮，如果客户属性[按账龄催款]已选择，则按账龄生成催款函；否则，按催款次数生成催款函，参见：催款级别
   *  第3步：系统自动根据输入的条件生成催款函（PDF格式），保存在催款维护记录中，可以在催款维护节点查看生成的催款函。
*  <调度>：本操作用于设置自动生成催款函的调度方案。
   *  操作步骤
   *  点击应收管理－>催款对账－>生成催款函－>调度按钮，设置自动生成催款函的调度方案。具体步骤如下所示：
   *  第1步：在生成催款函画面中输入条件；
   *  第2步：点击调度按钮弹出调度选择画面；
   *  第3步：在调度选择画面中设置需要自动生成催款函的调度方案，点击确定按钮，完成设置，系统将按设置的调度方案自动生成符合上述条件的催款函；点击取消按钮，放弃操作。
