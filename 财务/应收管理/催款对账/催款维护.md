
# 功能描述

本节点提供催款记录的维护功能，主要功能点如下：

*  可以维护催款记录；
*  可以查看催款函；
*  可以记录催款内容并设定以后的催款计划；
*  可以查看催款记录。

# 业务规则

*  有应收业务数据；
*  参数设定，[与催款维护相关参数](javascript:void(0);)

|参数编码|参数名称|说明|
|---|---|---|
|AR1121|是否按账龄催款|客户级参数，布尔值：是：表示该客户的应收账款以按账龄区间设定的催款级别方案催款；否：表示该客户的应收账款以按催款次数设定的催款级别方案催款。|

*  定义催款函设置档案（必做）

# **栏目说明**

|栏目名称|说明|
|---|---|
|催款函|本栏目记录与当前催款记录相关联的催款函，点击栏目可以打开该催款函；当前催款记录没有关联催款函时，点击栏目可以关联已有的催款函文件|
|催款结束|当前催款记录所关联的催款业务是否结束的标志。可以点击操作－>结束催款按钮为当前催款记录打上催款结束标志|

# **按钮说明**

*  <操作-结束催款>：本操作用来终止催款单的；
*  <操作-挂起客户>：点击该按钮，选择挂起原因，可挂起客户，被挂起的客户不允许接单、不允许出货、不允许开发票，但可以执行收款活动；
*  <相关功能-生成催款函>：导航到[生成催款函](/detail/f8989952c4ee4cada2fded75b0359f5a).设置该页面信息；
*  <相关功能-生成对账单>：导航到[生成对账单](/detail/d975624b28a54eeb863134b2110bc12d),设置该页面信息；
*  <相关功能-对账维护>：导航到[对账维护](/detail/48cd5353a5464d828a8bd4c308cfe5d9),设置该页面信息。

# **操作说明**

*  通过菜单[催款维护](/detail/2e1ca9aefe804004a8b6f8cd4a7e3691)进入催款维护界面；
*  操作步骤
 
   *  第1步：录入基本信息、业务信息等。
   *  第2步：点击保存，保存催款维护。
