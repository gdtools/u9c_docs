
# 功能描述

本节点提供对账记录的维护功能，主要功能点如下：

*  可以维护对账记录
*  可以查看对账单
*  可以查看对账记录
*  可以触发催款

# **业务规则**

*  存在已生成的对账单

# **栏目说明**

[对账单卡片](javascript:void(0);)

|栏目名称|说明|
|---|---|
|对账单|本栏目记录与当前对账记录相关联的对账单，点击栏目可以打开该对账单；当前对账记录没有关联对账单时，点击栏目可以关联已有的对账单文件|
|同时催款|当前的对账记录是否生成过催款记录的标识，参见：同时催款

# **按钮说明**

*  <同时催款>：本操作用于依据当前的对账记录生成催款记录。
*  <生成催款函>：导航到<a href="/detail/f8989952c4ee4cada2fded75b0359f5a">生成催款函</a>设置该页面信息。
*  <生成对账单>：导航到<a href="/detail/d975624b28a54eeb863134b2110bc12d">生成对账单</a>设置该页面信息。
*  <对账维护>：导航到<a href="/detail/48cd5353a5464d828a8bd4c308cfe5d9">对账维护</a>设置该页面信息。

# **操作说明**

*  通过菜单<a href="/detail/48cd5353a5464d828a8bd4c308cfe5d9">对账维护</a>进入对账维护界面；
*  操作步骤
 
   *  第1步：点击对账单下划线，上传对账单；
   *  第2步：录入对账日期、客户等相关信息；
   *  第2步：点击保存，保存对账维护。
   *  第3步：点击查找，可以打开已维护的数据，点击对账单下划线，可点击下载对账单。
