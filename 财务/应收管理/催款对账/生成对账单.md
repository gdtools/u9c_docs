
# 功能描述

本功能节点用于生成对账单：

可以查询应收款发生、收回及余额的情况；

可以按期间查询，也可以直接按单据查询；

可以包含未立账单据查询；

可以筛选包含未立账单据的单据类型；

可以分别以应收单、销售订单、销售出货单、销售发票为依据查询；

以不同查询依据显示时，影响显示方式，不影响查询结果；

可以以明细方式、回款方式对账；

可以将回款方式下的回款按核销明细显示；

可以保存对账单。

# 业务规则

*  有应收业务数据

# **栏目说明**

生成对账单页签

|栏目名称|说明|
|---|---|
|查询类型|可以选择生成对账单的查询类型：按期间：按期间对账，生成的对账单有期初数据按单据：按单据对账，对账的主体为应收单据|
|期间类别|可以选择对账的期间类别|
|对账期间|输入负整数，表示从当前期间向前推的期间数|
|立账客户：客户|选择需要对账的立账客户|
|立账客户：客户位置|选择需要对账的立账客户位置|
|付款客户：客户|选择付款客户用于过滤数据|
|付款客户：客户位置|选择付款客户位置用于过滤数据|
|显示依据|选择对账单数据的显示依据：按应收单：对账单中的应收数据按应收单号显示按立账来源单据：对账单中的应收数据按应收单的立账来源单据号显示|
|对账方式|查询类型为按期间时，可以选择对账数据的呈现方式：明细：按明细账流水的形式呈现对账数据回款：以应收发票为源头，显示针对此发票的回款等处理信息|
|应收单据明细显示|选择应收单按整单显示或按单据行（物料）显示|
|回款明细显示|回款方式对账时，选择是否需要明细显示每一笔回款数据|
|包含未立账单据|选择对账数据中是否需要包含未立账的销售单据|
|未立账单据|需要包含未立账单据时可选，选择需要包含的特定的未立账单据类别|
|包含已结清|按单据查询时，选择对账数据中是否需要包含已结清的发票及其回款信息|
|同时催款|选择是否需要在对账的同时触发催款|
|附账龄分布报表|选择是否需要在催款函中增加一个账龄分布的附属报表|
|账龄区间方案|需要附账龄分布报表时，选择生成账龄区间的账龄区间方案|

# **按钮说明**

*  <执行>：本操作用于手工生成对账单。

   *  操作步骤
      *  点击应收管理－>催款对账－>生成对账单－>执行按钮，手工生成对账单。具体步骤如下所示：
      *  第1步：在生成对账单画面中输入条件；
      *  第2步：点击执行按钮，如果选择的客户或客户位置的属性[邮寄对账单]已选中，则针对这些客户和客户位置生成对账单；
      *  第3步：系统自动根据输入的条件生成对账单（PDF格式），保存在对账维护记录中，可以在对账维护节点查看生成的对账单。
*  <调度>：本操作用于设置自动生成对账单的调度方案。
   *  操作步骤
      *  点击应收管理－>催款对账－>生成对账单－>调度按钮，设置自动生成对账单的调度方案。具体步骤如下所示：
      *  第1步：在生成对账单画面中输入条件；
      *  第2步：点击调度按钮弹出调度选择画面；
      *  第3步：在调度选择画面中设置需要自动生成对账单的调度方案，点击确定按钮，完成设置，系统将按设置的调度方案自动生成符合上述条件的对账单；点击取消按钮，放弃操作。
