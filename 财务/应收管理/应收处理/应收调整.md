
# 功能描述

本节点提供手工减少应收单余额的功能，可以维护和查看手工调整记录，同时可以查看系统生成的自动调整记录。

# 业务规则

*  参数设定，与自动应收调整相关参数

|参数名称|说明|
|---|---|
|质保金应收参与自动调整|确定质保金性质的应收单行是否参与自动应收调整|

*  定义应收处理类型档案中的调整类型（必做）
*  定义应收单类型
*  定义自动调整限额

# **栏目说明**

应收单查找画面

|栏目名称|说明|
|---|---|
|<分组>客户信息|本分组内可以选择付款客户、付款客户位置、立账客户、立账客户位置用于筛选应收单。其中，立账客户和立账客户位置可以多选；而付款客户和付款客户位置只能单选，并且用于生成应收调整单的客户和客户位置信息。|
|<分组>调整信息|本分组内可以选择币种、调整日期和记账期间用做筛选应收单的条件，同时也用于生成应收调整单表头相应信息。本分组内的栏目只能单选|
|<分组>单据信息|本分组内可以选择单据类型、单号和总金额余额，允许多选，用做筛选应收单的条件|
|调整方向|确定应收调整的方向，枚举值：借方：只选择借项应收单（正向应收单）贷方：只选择贷项应收单（负向应收单）空：不限制所选择应收单的借贷方向注意　:如果客户分组内选择的付款客户位置的核销明细程度为“按客户”，则本栏目必须在借贷方中选一项|

# **按钮说明**

*  <作废>：系统中存在已保存的应收调整单本操作用于作废当前应收调整单。
*  <调整单>：系统中存在已保存的应收调整单，本操作用于查看当前应收调整单的明细。
*  <交易分录>：系统中存在已保存的应收调整单，本操作用于查看或维护应收调整单通过自动会计平台（AAI）生成的交易分录。参见交易分录
*  <损益单>：当前应收调整单存在损益记录，本操作用于查看应收调整单对应的损益单的信息。
*  <客户状况>：本操作用于按客户查询汇总的财务余额信息，及最近发生业务的日期。

# **操作说明**

*  通过菜单<a href="/detail/14f9b880f56b482b8bfbc06a08cb8c15">应收调整</a>进入应收调整界面；
*  操作步骤

   *  手动调整：
      *  第1步：点击新增按钮，弹出应收单查找画面；
      *  第2步：在应收单查找画面输入选单条件和调整基本信息，参见：应收单查找画面栏目说明
      *  第3步：点击确定按钮到第4步，点击取消按钮返回第1步；
      *  第4步：进入调整应收单画面，如果当前付款客户的核销明细程度为“按客户”，则在调整总金额栏目输入本次调整的总金额；否则，在列表中选择本次需要调整的记录，并在列表的调整总金额栏目输入被选择列表行记录对应的本次调整金额；
      *  第5步：点击保存按钮保存调整记录，点击放弃按钮取消本次调整。
   *  自动调整：应收自动调整是在应收处理过程中，对于余额小于等于自动调整金额上限（参见自动调整限制）的应收单，系统自动将其余额减少为0，并记载应收调整记录的操作。此操作由系统自动完成，不能手工干预，只能在本节点查看系统生成的应收调整单。
