
# 功能描述

本节点用于处理债权转移的相关事务，主要功能点如下：

提供多种转移对象

转移结果可提交审核

可以联查相关应收单和交易分录

可以作废债权转移单

# 业务规则

*  定义应收处理类型档案中的债权转移类型（必做）

# **栏目说明**

债权转移画面

|栏目名称|说明|
|---|---|
|表头基本页签－新生单据合并|由于系统支持同时选择同一客户的多张应收单转移，则在转入新单据时，有两种处理方式：不选择本栏目：由被选择的应收单一对一生成多张新的应收单选择本栏目：将本次选择的全部应收单合并生成一张新的应收单|
|表头客户页签|当转移对象不包含客户时，无需关注本页签当转移对象包含客户时，在本页签中指定转入立账客户/位置、转入付款客户/位置、转入信用控制对象转移立账客户时，需要在核准代号栏目输入转入立账客户确认本次债权转移时给出的代号，此代号用于日后与转入立账客户的对账如果转入信用客户位置的额度币种与被转移单据的核算币种不一致，还需要确定核币与额币之间的汇率类型和汇率|
|表头其他页签|本页签用于在转移部门、业务员、收款员、项目、任务、来源单据时指定转入方，如果转移对象不包括上述几项，则无需关注本页签|
|表头料品页签|本页签用于在转移料品时显示转出、转入料品的详细信息|
|单据类型页签|本页签用于在转移单据类型时，显示转出、转入单据类型的详细信息。暂只支持负向应收单的单据类型转为预收的单据类型。|
|表体栏目－转移总金额|本栏目用于输入当前行本次需要转移的总金额，输入的金额不能大于当前行的可处理金额|

# **操作说明**

*  通过菜单<a href="/detail/e2f5faab673747dcbcba5c7932572242">债权转移</a>进入债权转移界面；
*  操作步骤

   *  点击应收管理－>应收处理－>债权转移按钮，进入债权转移功能画面。具体步骤如下所示。
   *  第1步：点击新增按钮，弹出应收单查找画面；
   *  应收单查找画面

|栏目名称|说明|
|---|---|
|分组－转移对象|本分组内的栏目用于确定转移对象和提供筛选应收单的条件。可选的转移对象有：立账客户/位置付款客户/位置信用客户位置部门业务员收款员项目任务单据类型（暂只支持负向应收单的单据类型转为预收的单据类型）其中，信用客户位置只有在转移立账客户或付款客户时才可以同时转移。提示　:上述转移对象被选中时为单选，未被选中时为范围式，不论单选或范围，都是选择应收单的条件|
|分组－转移信息|本分组内的项目提供转移的基本信息，包括币种、转移日期和记账期间，系统会提供默认值，并提供参照修改|

*      *  第2步：在应收单查找画面选择债权转移对象、输入选单条件和转移基本信息；
   *  第3步：点击确定按钮到第4步，点击取消按钮返回第1步；
   *  第4步：进入债权转移画面，输入本次债权转移的相关信息，具体需要输入的内容参见：债权转移画面栏目说明
   *  第5步：点击保存按钮保存调整记录，同时会减少原应收单的余额，生成一张新应收单；点击放弃按钮取消本次调整。
