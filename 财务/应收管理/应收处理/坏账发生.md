
# 功能描述

本节点提供坏账发生的处理，主要功能点如下：

提供按单发生

提供按客户发生

可以对坏账发生进行审核

可以联查相关应收单和会计分录

可以取消坏账发生

# 业务规则

*  定义应收处理类型档案中的坏账发生单据类型（必做）

# **栏目说明**

应收单查找画面

|栏目名称|说明|
|---|---|
|分组－坏账发生|本分组内可以选择客户、客户位置、坏账发生申请日期、记账期间、币种，这些栏目只能单选，是查找应收单的条件，同时也是生成的坏账发生单的基本信息|
|分组－应收查找多选条件|本分组内可以选择立账客户、立账客户位置和单据类型，可以多选，用做查找应收单的条件|
|分组－应收查找范围条件|本分组内可以选择应收单号、可处理金额、立账日期、记账期间的范围，用做查找应收单的条件|

# **按钮说明**

*  <坏账发生单>：本操作用于查看当前坏账发生单的明细。
*  <损益单>：当前坏账发生单存在损益记录，本操作用于查看坏账发生单对应的损益单的信息。
*  <客户状况>：本操作用于按客户查询汇总的财务余额信息，及最近发生业务的日期。
*  <作废>：系统中存在已保存的坏账发生单，本操作用于作废当前坏账发生单。
*  <交易分录>：系统中存在已保存的坏账发生单，本操作用于查看或维护坏账发生单通过自动会计平台（AAI）生成的交易分录。参见交易分录

# **操作说明**

*  通过菜单<a href="/detail/998c5976c8094868bfe369060780ad2e">坏账发生</a>进入坏账发生界面；
*  操作步骤

   *  第1步：点击新增按钮，弹出应收单查找画面；
   *  第2步：在应收单查找画面输入选单条件和坏账发生基本信息，参见：应收单查找画面栏目说明
   *  第3步：点击确定按钮到第4步，点击取消按钮返回第1步；
   *  第4步：进入坏账发生处理画面，如果当前付款客户的核销明细程度为“按客户”，则在坏账发生总金额栏目输入本次坏账发生的总金额；否则，在列表中选择本次需要发生坏账的记录，并在列表的坏账发生总金额栏目输入被选择列表行记录对应的本次坏账发生额；
   *  第5步：点击保存按钮保存坏账发生记录，点击放弃按钮取消本次操作。
