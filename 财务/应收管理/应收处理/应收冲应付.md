
# 功能描述

本节点用于处理应收冲应付的相关事务，主要功能点如下：

可以同币种对冲：需要对冲的应收单和应付单的币种相同；

可以异币种对冲：需要对冲的应收单和应付单的币种不同；

可以即时对冲，分别选择应收对冲单据和应付对冲单据：若应收对冲金额=应付对冲金额，全部冲销应收金额与应付金额；

可以生单对冲：

若应收对冲金额>应付对冲金额，全部冲销应收金额与应付金额，同时系统自动生成一张应付单(方向同应收单)；

若应付对冲金额>应收对冲金额，全部冲销应收金额与应付金额，同时，系统自动生成一张应收单(方向同应付单)；

或者都不用选单，直接录入对冲总金额，各生成一张应收单和应付单。

# **栏目说明**

对冲单头－基本页签

|栏目名称|说明|
|---|---|
|单据类型|对冲单单据类型|

|对冲模式|应收应付对冲的方式。枚举：即时对冲：直接筛选出需要对冲的客户应收单和供应商应付单，直接冲减双方单据的余额。但是，对冲金额不等时，对冲金额少的一方会生单。生单对冲：不需要筛选需要对冲的客户应收单、供应商应付单，直接给出一个对冲总金额，系统自动新增生成客户的应收单和供应商的应付单，用户后续再对新生单据进行核销处理。|
|币种|对冲币种|
|应收币种|异币种对冲时的客户应收单的币种|
|应付币种|异币种对冲时的供应商应付单的币种|
|中间币种|异币种对冲时，需要将客户应收单金额和供应商应付单金额转换成该币种的金额进行平衡对冲|
|生单币种|若对冲的金额不等，新生单据的币种|
|允许误差|应收单金额转换成中间币种金额后，与应付单转换成中间币种金额对冲，可以被系统接受的误差范围|
|汇率类型|对冲单的汇率类型|
|汇率|对冲币种对本币的汇率|
|本次对冲金额|系统生单方式时，按此录入的对冲金额生成应收单和应付单；客户［核销明细程度］=‘按客户’或供应商的［核销明细程度］=‘按供应商’时，也可输入，系统按此对冲金额生单。|

|客户位置|需要对冲的客户位置，指付款客户位置|
|供应商|需要对冲的供应商，指付款供应商|
|供应商位置|需要对冲的供应商位置，指付款供应商位置|
|对冲方向|指定对冲的方向。枚举：借方应收冲贷方应付贷方应收冲借方应付|
|备注|录入备注说明|

# **按钮说明**

*  <操作－追加行>：本操作用于在对冲主画面中的列表中再追加符合条件的应收/应付单行。

   *  操作步骤
      *  点击应收管理－>应收处理－>应收冲应付－>操作－>追加行按钮，弹出条件画面，输入预追加的过滤条件，即可将满足条件的应收应付单行分别追加到对冲操作主画面的相应列表中。
*  <操作－删除行>：本操作用于将对冲主画面中列表里选中的行，从列表中删除，不作为对冲操作选择的范围；删除后若需要再追加，可使用追加行操作。

   *  操作步骤

      *  在对冲操作主画面的列表中选中预删除的行，点击应收管理－>应收处理－>应收冲应付－>操作－>删除行按钮，画面列表中就会删除之前选中的行。
*  <操作－作废>：本操作用于作废当前应收应付对冲单。
   *  操作前提
      *  系统中存在已保存的应收应付对冲单
   *  操作步骤
      *  点击应收管理－>应收处理－>应收冲应付－>操作－>作废按钮，输入作废原因，完成作废操作。

   *  第1步：点击新增菜单，弹出对冲单操作画面；
      *  新增对冲单操作画面

|栏目名称|说明|
|---|---|
|对冲日期|对冲执行日期，默认登录日期，可改|
|记账期间|对冲单的记账期间，默认对冲日期对应的会计期间，可改|
|对冲模式|应收应付对冲的方式。枚举：即时对冲：直接筛选出需要对冲的客户应收单和供应商应付单，直接冲减双方单据的余额。但是，对冲金额不等时，对冲金额少的一方会生单。生单对冲：不需要筛选需要对冲的客户应收单、供应商应付单，直接给出一个对冲总金额，系统自动新增生成客户的应收单和供应商的应付单，用户后续再对新生单据进行核销处理。|
|客户|需要对冲的客户，指付款客户|
|客户位置|需要对冲的客户位置，指付款客户位置|
|供应商|需要对冲的供应商，指付款供应商|
|供应商位置|需要对冲的供应商位置，指付款供应商位置|
|□异币种对冲|本次对冲是否异币种对冲。是：客户应收单的币种与供应商付款单的币种不同，通过都换算成中间币种实现对冲；否：客户应收单与供应商付款单的币种必须相同，此为默认值。|

   *  第4步：进入对冲单卡片画面，输入本次对冲的金额和相关信息，具体需要输入的内容参见：对冲单画面栏目说明；
   *  第5步：点击保存按钮保存对冲单，点击放弃按钮取消本次对冲；
   *  第6步：点击提交按钮提交对冲单；
   *  第7步：点击审核按钮审核对冲单，若应收应付对冲金额有差异，差异金额将生单。
