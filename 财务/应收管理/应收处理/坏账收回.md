
# 功能描述

本节点提供坏账收回的处理，主要功能点如下：

提供按坏账收回单收回

提供按客户收回

可以联查相关应收单/收款单/交易分录

可以在线生成收款单，可以选取已有的收款单

可以取消坏账收回


# 业务规则

*  定义应收处理类型档案中的坏账收回单据类型（必做）

# **栏目说明**

坏账收回查找画面

|栏目名称|说明|
|---|---|
|分组－请选择|本分组内可选择按客户收回或按坏账发生单收回，不同的选择将导致不同的处理结果。|
|分组－坏账收回|本分组内可选择客户、客户位置、申请日期、记账期间、币种，这些栏目只能单选，是查找坏账发生单的条件，同时也是生成坏账收回单的基本信息|
|分组－查找坏账发生单|本分组内可以选择坏账发生单、可处理金额、坏账发生日期、记账期间的范围，用做查找坏账发生单的条件|

# **按钮说明**

*  <坏账收回单>：本操作用于查看当前坏账收回单的明细。
*  <收款单>：本操作用于查看坏账收回单对应的收款单的信息。
*  <客户状况>：本操作用于按客户查询汇总的财务余额信息，及最近发生业务的日期。
*  <作废>：系统中存在已保存的坏账收回单，本操作用于作废当前坏账收回单。
*  <交易分录>：系统中存在已保存的坏账收回单，本操作用于查看或维护坏账收回单通过自动会计平台（AAI）生成的交易分录。参见交易分录

# **操作说明**

*  通过菜单<a href="/detail/bc8048c5c3804498bb6863566dba575d">坏账收回</a>进入坏账收回界面；
*  操作步骤

   *  第1步：点击新增按钮，弹出坏账收回查找画面；
   *  第2步：在坏账收回查找画面选择处理方式，输入选单条件和坏账发生基本信息，参见：坏账收回查找画面栏目说明
   *  第3步：如果选择了“按客户收回”，点击确定按钮到第4步，如果选择了“按坏账发生单收回”，点击确定按钮到第5步，点击取消按钮返回第1步；
   *  第4步：进入按客户坏账收回处理画面，在收款单栏目参照选择已有的收款单，或者点击收款单栏目，在弹出的坏账收回收款单录入画面中在线录入收款单，在收回总金额栏目输入本次坏账收回的总金额，到第6步；
   *  第5步：进入按坏账发生单坏账收回处理画面，在表头收款单栏目参照选择已有的收款单，或者点击收款单栏目，在弹出的坏账收回收款单录入画面中在线录入收款单，在表体列表的收回总金额栏目输入当前坏账发生单行对应的坏账收回金额；
   *  第6步：点击保存按钮保存坏账发生记录，点击放弃按钮取消本次操作。
