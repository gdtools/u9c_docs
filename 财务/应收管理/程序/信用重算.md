
# 功能描述

立即或定期进行信用重算，有利于提高信用检查的效率

# 业务规则

*  参数设定，与信用重算相关参数

# 栏目说明

合同释放画面栏目说明

|栏目名称|说明|
|---|---|
|组织|非空，默认为当前组织，不可改|
|对象类型|可空，待重算的信用对象的类型，为空时表示所有对象类型都进行信用重算。备选项如下：客户：待重算的对象为客户类型客户位置：待重算的对象为客户位置客户集团：待重算的对象为客户集团类型部门：待重算的对象为业务部门类型业务员：待重算的对象为业务员类型全部：待重算对象包括所有对象类型；|
|重算对象|当【对象类型】非空时，本栏目可手工维护选择指定某个具体的重算对象。为空时表示指定的对象类型下的对象都进行信用重算。|
|客户位置|当【对象类型】＝“客户位置”，本栏目可手工维护指定某个具体的客户位置做为重算对象。。|

# 按钮说明

*  <执行>：按照指定的条件找出符合条件的信用对象，自动进行信用重算。
 
   *  操作步骤
   
      *  在画面中设定过滤条件后，点击【执行】按钮即可。
*  <调度>：将信用重算加入系统调度，在指定时间自动重算信用。
 
   *  操作前提
   
      *  如需重复执行，需先设定“调度计划”。
   *  操作步骤
   
      *  在画面中设定过滤条件后，点击【调度】，打开调度画面，选择调度方式。。
      *  执行一次：设定执行日期，系统将在指定日期进行信用重算。
      *  重复执行：指定“调度计划”，系统根据“调度计划”中定义重复执行信用重算。如未设定“调度计划”，可点击栏目链接在线创建调度计划。调度计划定义可参见相关文档。
      *  点击画面中【确定】按钮，将合同释放加入系统调度，点击【取消】按钮，放弃返回上级画面
