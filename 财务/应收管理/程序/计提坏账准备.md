
# 功能描述

本节点用于计提坏账准备，主要功能点如下：

按系统参数设定的计提依据计提坏账准备

查看坏账准备的计提情况

# 业务规则

*  参数设定，与计提坏账准备相关参数

|参数名称|说明|
|---|---|
|是否计提坏账准备|当前组织是否计提坏账准备，如果选择不计提则坏账计提功能不可用|
|计提坏账准备方法|选择本组织所使用的坏账计提方法，枚举：销售收入百分比应收百分比应收账龄|
|计提频度周期类型[]()|表示计提坏账准备的期间，需要计提坏账准备时方可选择，枚举值：每年：最小未结账会计期间对应的会计年度的最后一个会计期间每季：最小未结账会计期间对应的季度的最后一个会计期间每月：最小未结账会计期间对应的月度的最后一个会计期间每周：最小未结账会计期间对应的周的最后一个会计期间会计期间：最小未结账的会计期间注意　:本参数选取的周期类型必须大于等于主SOB的会计期间类型|
|账龄区间方案|计提坏账准备方法为应收账龄时，在本参数设置账龄区间方案|
|内部客户是否计提坏账准备|计提坏账准备方法为应收百分比或应收账龄时，内部客户的应收账款是否纳入计提坏账准备的基数|
|内部客户|当内部客户不参与计提时需要明确按立账客户还是按付款客户确定是否属于内部客户|
|按立账客户计提坏账|计提坏账准备时是否需要根据立账客户确定计提比率、计提金额|
|按付款客户计提坏账|计提坏账准备时是否需要根据付款客户确定计提比率、计提金额|
|按立账客户分类计提坏账|计提坏账准备时是否需要根据立账客户分类确定计提比率、计提金额|
|按付款客户分类计提坏账|计提坏账准备时是否需要根据付款客户分类确定计提比率、计提金额|
|按币种计提坏账|计提坏账准备时是否需要根据币种确定计提比率、计提金额|
|按单据类型计提坏账|计提坏账准备时是否需要根据单据类型确定计提比率、计提金额|

*  定义应收单类型
*  定义账龄区间档案

# 栏目说明

计提坏账准备画面

|栏目名称|说明|
|---|---|
|单据类型|录入计提坏账准备单据类型|
|计提期间|显示计提期间，计提期间的生成由参数AR203计提频度周期类型决定|
|默认计提比率|输入一个计提比率，为新增加的计提依据提供计提比率的默认值|
|单据类型|参数设置中选择的坏账计提方法为应收百分比或应收账龄，并且需要按单据类型计提坏账时，本栏目才可见，显示需要计提坏账准备的应收单据类型|
|账龄区间号|坏账计提方法为应收账龄时本栏目可见，显示参数中定义的账龄区间方案的账龄区间号|
|时间单位|坏账计提方法为应收账龄时本栏目可见，显示参数中定义的账龄区间方案的时间单位|
|账龄区间|坏账计提方法为应收账龄时本栏目可见，显示参数中定义的账龄区间方案的账龄区间|
|计提比率|设置对当前计提依据计提坏账准备的比率|
|计提坏账准备金额|以本位币记录的坏账准备计提金额：坏账计提方法为销售收入百分比时，在本栏目输入计提坏账准备的金额；坏账计提方法为应收百分比或应收账龄时，显示系统计算的坏账准备计提金额，不可修改|
|计提基数|按照计提方法系统自动计算计提基数，可点击下划线查看计提基数详情|

# **按钮说明**

*  <作废>：本操作用于作废当前计提坏账准备。
*  <交易分录>：本操作用于查看或维护提及坏账准备收回生成的交易分录。

# 操作说明

通过菜单<a href="/detail/772bd565cce943d2995a12b01acbd065">计提坏账准备</a>进入计提坏账准备界面；

*  操作步骤：
   *  第1步：点击新增按钮，系统自动找到尚未计提坏账准备的最小计提期间，注意：如果系统找的到计提期间对应的最后一个会计期间已经结账，系统会提示出错，您需要先对该会计期间取消结账，方可计提坏账准备；
   *  第2步：如果列表中显示的计提依据满足您的需要则直接到下一步，否则，点击补齐计提依据按钮，系统将按参数设置补齐全部计提依据；
   *  第3步：输入计提比率或计提金额。如果计提方法为销售收入百分比，则直接收入计提金额；如果计提方法为应收百分比或应收账龄，则输入各计提依据的计提比率，系统自动计算计提金额；
   *  第4步：点击保存按钮保存计提比率和计提数据，完成坏账准备计提；点击放弃按钮取消本次坏账计提。

提示：如果计提完成后需要补提或重新计提，都需要删除该计提期间计提的全部坏账准备数据后重新计提
