
# 功能描述

本节点提供应收系统结账功能，主要功能点如下：

可以查看应收期间状态

可以关闭待结账的期间

可以完成结账检查并结账

可以批量转暂收

可以取消结账

# 业务规则

*  参数设定，与应收结账相关参数

|参数名称|说明|
|---|---|
|期末时计算汇兑损益|是：期末需计算汇兑损益否：期末不计算汇兑损益|
|期末计算频度|表示计算期末汇兑损益的期间，期末需要计算汇兑损益时方可选择，枚举值：每年：最小未结账会计期间对应的会计年度的最后一个会计期间每季：最小未结账会计期间对应的季度的最后一个会计期间每月：最小未结账会计期间对应的月度的最后一个会计期间每周：最小未结账会计期间对应的周的最后一个会计期间会计期间：最小未结账的会计期间注意　:本参数选取的频度必须大于等于主SOB的会计期间类型|

# 栏目说明

期末处理画面

|栏目名称|说明|
|---|---|
|当前期间应立账的单据全部已立账|系统检查项，不是结账的必要条件单据检查范围：订单/出货单/退货单/预出货单/税务发票/管销费用单/资产调出单|
|当前期间关系企业交易单全部已审核|结账的必要条件，未完成则系统限制不能结账|
|当前期间的收款单、付款单全部已核准|参数[月结时收款付款单是否必须全部核准]为是时，是结账必要条件；否则只是检查项，不是必要条件|
|当前期间的其他单据全部已核准|结账的必要条件，未完成则系统限制不能结账|
|当前期间的单据已生成交易分录|当前组织有对应的法人组织，且法人组织启用总账，且参数[转总账]为是的情况下，此项是结账的必要条件，否则隐藏|
|当前期间的单据分录全部过账至总账|当前组织有对应的法人组织，且法人组织启用总账，且参数[转总账]为是的情况下，此项是结账的必要条件，否则隐藏|
|当前期间的标准用途收/付款单全部已核销|结账的必要条件，未完成则系统限制不能结账。如果当前期间标准用途的收款单没有全部核销完毕，点击显示处理情况报告按钮或双击此栏目，在弹出的查看画面中可以点击转暂收按钮批量转暂收|
|当前期间的收入与成本完全配比|库存管理模块启用时才有此检查项，结账的必要条件，未完成则系统限制不能结账|
|期末已计算汇兑损益|当前结账的期间需要计算汇兑损益时才有此检查项，结账的必要条件，未完成则系统限制不能结账|
|当期已计提坏账准备且已核准|当前结账的期间需要计提坏账准备时才有此检查项，结账的必要条件，未完成则系统限制不能结账|

# 按钮说明

*  <结账>：本操作用于对应收系统待结账的期间结账并关闭该期间
 
   *  操作前提
   
      *  当前期间未结账
      *  待结账期间之前的期间已结账
   *  操作步骤：点击应收管理－>程序－>结账按钮，期间状态管理画面。具体步骤如下所示。
   
      *  第1步：列表中显示应收期间状态，点击结账按钮，系统自动取最小未结账的期间结账，弹出期末处理画面；
      *  第2步：期末处理画面显示系统期末检查的项目和检查结果，所有未通过的项目都可以双击行，即可显示处理情况报告画面查看明细信息，属于结账的必要条件的项目如果未通过，系统不允许结账；
      *  第3步：所有属于结账必要条件的项目通过后，点击完成按钮完成结账。
