
# 功能描述

本功能提供将应收管理系统中业务单据生成的交易分录，转为总账系统的记账凭证的处理。

转总账主要功能如下：

可以将系统的交易分录转入总账系统生成记账凭证；

可以选择是否合并原始单据的交易分录生成记账凭证；

可以设定合并生成凭证的合并规则；

可以批量生成总账凭证；

可以联查交易分录相关的总账凭证和业务单据；

# 业务规则

*  总账系统启用（必做）
*  总账系统账簿、凭证等相关设置完成（必做）
*  交易分录已经生成（必做）
*  定义转总账规则
*  定义调度方案

# 栏目说明

凭证生成画面

|栏目名称|说明|
|---|---|
|转出账簿|选择待转总账的单据所在的账簿，即转总账的源账簿。提示　:由于应收系统此版本不支持多账簿，因此，本栏目只有一个选项。|
|合并制单|选择转总账生成的记账凭证是否需要合并：是：可以选择合并条件分组中的项目合并制单否：不合并制单，按单据一对一生成记账凭证|
