
# 功能描述

可以查询应收款期初、本期应收、收回及余额的情况；

可以查询单据余额；

可以查询逾期的应收；

可以查询到期的应收；

可以查询还在折扣期的应收；

# 业务规则

*  已启用应收管理

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|核算组织|参照组织档案录入|
|来源组织|参照组织档案录入|
|业务组织|参照组织档案录入|
|结算组织|参照组织档案录入|
|期间类型|枚举值：会计期间（默认）统计期间|
|会计期间范围|当［期间类型］＝会计期间，可用枚举值：当前期间上一期间去年同期指定期间|
|会计期间|当［期间范围］＝指定期间，可用参照选择|
|统计期间规则|当［期间类型］＝统计期间，可用参照选择|
|统计期间范围|当［期间类型］＝统计期间，可用|
|统计期间|当［期间类型］＝统计期间，可用|
|业务类型|可限定查询应付单的业务类型范围|
|单据类型|可限定查询应付单的单据类型范围|
|包含未立账|确定满足截止时间的未立账单据是否包括在查询范围内|
|未立账单据|当[是否包含未立账]＝true时，可指定包含哪些未立账的单据类别，如未立账销售订单、预出货单、出货单、退货单、销售发票、资产调出单、管销费用单，未开票销售订单、出货单、退货单等|
|有余额无发生显示|若查询期间无发生额，但有期初数，是否显示|

查询结果

|栏目名称|说明|
|---|---|
|期初_数量期初_核币期初_本币|显示应收款期初余额|
|应收_数量应收_核币应收_本币|显示应收款本期借方发生额|
|收回_数量收回_核币收回_本币|显示应收款本期贷方发生额|
|期末_数量期末_核币期末_本币|显示应收款期末余额|

# 按钮说明

*  <联查应收明细账>：在列表下方，联查栏目目选择“应收明细账”，可查询焦点行的明细账。
*  <联查应收对账单>：在列表下方，联查栏目目选择“应收对账单”，可查询焦点行的对账单。
*  <联查应收账龄分析>：在列表下方，联查栏目目选择“应收账龄分析”，可查询焦点行的账龄分析表。
*  <联查到期应收表>：在列表下方，联查栏目目选择“到期应收表”，可查询焦点行的到期应收表。
*  <联查逾期应收表>：在列表下方，联查栏目目选择“逾期应收表”，可查询焦点行的逾期应收表。

# 操作说明

通过菜单<a href="/detail/954c1d0f4252433c843b2c3da7f78243">应收余额表</a>进入应收余额表界面；

*  操作步骤
 
   *  第1步：录入查询条件。
   *  第2步：点击保存/确定，即可查看应收余额表。
