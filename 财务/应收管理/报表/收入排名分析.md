
# 功能描述

按客户、部门、业务员、产品、地区、项目等对象，查询各期应收余额、排名及趋势；

可以联查相关单据；

可以查询应上余额的金额构成；

# 业务规则

*  已启用应收管理

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|核算组织|参照组织档案录入|
|来源组织|参照组织档案录入|
|业务组织|参照组织档案录入|
|结算组织|参照组织档案录入|
|立账客户|可空，默认为全部|
|立账客户位置|可空，默认为全部|
|付款客户|可空，默认为全部|
|付款客户位置|可空，默认为全部|
|立账客户分类|可空，默认为全部|
|付款客户分类|可空，默认为全部|
|立账客户地区|可空，默认为全部|
|付款客户地区|可空，默认为全部|
|期间类型|可以选择会计期间统计期间： 当选择的[核算组织]为多组织时，只能选择“统计期间”被直接分析在对应的账龄区间中 |
|会计期间范围|可以选择：当前期间上一期间 去年同期指定期间|
|业务类型|可限定查询应付单的业务类型范围|
|单据类型|可限定查询应付单的单据类型范围|

# 按钮说明

*  <联查余额表>：在列表下方，可查询焦点行分组汇总项的余额表。
*  <联查明细账>：在列表下方，可查询焦点行分组汇总项的明细账。
*  <联查单据余额>：在列表下方，可查询焦点行分组汇总项的应收对账单。
*  <联查账齡>：在列表下方，可查询焦点行分组汇总项的账龄表。

# 操作说明

通过菜单<a href="/detail/09ab3d7d196e41a4b431507645223c85">收入排名分析</a>进入收入排名分析界面；

*  操作步骤

   *  第1步：录入查询条件。
   *  第2步：点击保存/确定，即可查看收入排名分析。
