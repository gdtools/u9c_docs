
# 功能描述

按客户、部门、业务员、产品、地区、项目等对象，查询截止到某一天的应收账龄；

可以联查相关单据； 

可以提供多套账龄区间的分析；


# 业务规则

*  已启用应收管理

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|核算组织|参照组织档案录入|
|来源组织|参照组织档案录入|
|业务组织|参照组织档案录入|
|结算组织|参照组织档案录入|
|分析余额类型|可以选择：实时余额：根据对应单据上实际存贮的余额进行分析，根据当前系统日期计算账龄历史余额：根据分析的“截至期间”末日计算账龄|
|分析日期类型|可以选择：到期日：区间方案以到期日为基准 单据日期：区间方案以单据日期为基准|
|期间类型|可以选择：会计期间统计期间自然日期|
|截止会计期间|期间类型＝ 会计期间时，有效|
|统计期间规则|期间类型＝ 统计期间时，有效|
|截止统计期间|期间类型＝ 统计期间时，有效|
|截止自然日期|期间类型＝ 自然日期时，有效|
|分析区间格式|可以选择：账龄：按已设置的账龄区间分析应收余额构成 会计期间：按即时设置的会计期间方案分析应收余额构成，表示应收的记账期间为该期间。自然期间：按即时设置的自然期间方案分析应收余额构成，表示应收的立账日期或到期日产生在该期间。|
|会计期间类别|分析区间格式=会计期间时，有效可以选择：年季月周会计期间(默认)|
|账龄区间方案|分析区间格式 ＝ 账龄时，有效|
|自然期间类别|分析区间格式=会计期间时，有效可以选择：年半年季月(默认)半月旬周日|
|分析期间范围|分析区间格式 <> 账龄时，有效|
|贷项单据处理方式|可以选择：不处理：不处理贷项单据，即这些贷项单据没有包含在当前账龄分析报表中。账龄：贷项单据处理与借项单据处理方式一样，被直接分析在对应的账龄区间中 单列：将贷项单据单独列示|
|贷项单据列示方案|贷项单据处理方式 = 单列时，有效 可以选择：合计列示：增加‘未结贷项合计’栏 按业务类型列示：增加贷项通知单、贷项账户单、保证金、预收、收款(暂收款和标准收款单合计)栏目|
|质保金是否单列|选择是否将质保金从借项单据中独立出来列示|
|分类性质|选择查询的物料分类性质，可在具体的物料分类性质下，再确定物料分类|
|业务类型|可限定查询应付单的业务类型范围|
|单据类型|可限定查询应付单的单据类型范围|
|包含未立账|确定满足截止时间的未立账单据是否包括在查询范围内|
|未立账单据|当[是否包含未立账]＝true时，可指定包含哪些未立账的单据类别，如未立账销售订单、预出货单、出货单、退货单、销售发票、资产调出单、管销费用单，未开票销售订单、出货单、退货单等|

# 按钮说明

*  <联查区间段明细>：在列表下方，联查栏目目选择“应收明细账”，可查询区间段明细。
*  <联查对象明细>：在列表下方，联查栏目目选择“应收对账单”，可查询对象明细。

# 操作说明

通过菜单<a href="/detail/34a06fdb1c6f496eb63f72b45a823573">应收账龄分析</a>进入应收账龄分析界面；

*  操作步骤
 
   *  第1步：录入查询条件。
   *  第2步：点击保存/确定，即可查看应收账龄分析。
