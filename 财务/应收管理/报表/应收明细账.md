
# 功能描述

可以查询应收款明细账；支持查询未立账数据，未立账金额可以按单价重算或者按金额想减计算，在查询条件中找到“未立账数据是否按单价重算”，参数为是则表示按单价重算金额，单据为否，则按总金额减去已立账金额计算剩余可立账金额。


# 业务规则

*  已启用应收管理

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|核算组织|参照组织档案录入|
|来源组织|参照组织档案录入|
|业务组织|参照组织档案录入|
|结算组织|参照组织档案录入|
|期间类型|枚举值：会计期间（默认）统计期间自然日期|
|会计期间范围|当［期间类型］＝会计期间，可用枚举值：当前期间上一期间去年同期指定期间|
|会计期间|当［期间范围］＝指定期间，可用参照选择|
|统计期间规则|当［期间类型］＝统计期间，可用参照选择|
|统计期间范围|当［期间类型］＝统计期间，可用|
|统计期间|当［期间类型］＝统计期间，可用|
|自然日期|当［期间类型］＝自然日期，可用，可输入任意日期|
|业务类型|可限定查询应付单的业务类型范围|
|单据类型|可限定查询应付单的单据类型范围|
|包含未立账|确定满足截止时间的未立账单据是否包括在查询范围内|
|未立账单据|当[是否包含未立账]＝true时，可指定包含哪些未立账的单据类别，如未立账销售订单、预出货单、出货单、退货单、销售发票、资产调出单、管销费用单，未开票销售订单、出货单、退货单等|
|应收单据显示方式|可以选择：整单(默认)单行分期行|
|有余额无发生显示|若查询期间无发生额，但有期初数，是否显示|

查询结果

|栏目名称|说明|
|---|---|
|本期应收|显示单据的应收额|
|本期收回|显示单据的收回额|
|余额本币|显示余额|

# 按钮说明

*  <联查凭证>：在列表中点“凭证号”链接，可联查凭证
*  <联查单据>：在列表中点“单据号”链接，可联查单据

# 操作说明

通过菜单<a href="/detail/e1050a4362ad402b892b4a3a3f79da68">应收明细账</a>进入应收明细账界面；

*  操作步骤

   *  第2步：点击保存/确定，即可查看应收明细账。
