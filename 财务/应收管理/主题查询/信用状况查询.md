
# 功能描述

按照指定的条件，查出当前组织下已设信的各信用对象（客户/客户位置/客户集团业务员/部门）的信用状况，包括授信额度、临时额度、已消耗额度、剩余额度等信息。

# 业务规则

*  系统已启用信用状况查询。

# 栏目说明

查询数据

已授信的信用对象

查询条件

系统在查询方案中提供默认的查询条件，

查询条件可在指定的范围内选取（通过属性选取设置）；

查询结果

不同的查询方式、查询条件决定了查询结果的不同。用户可根据需要织查询条件和要显示的栏目。

# 操作说明

通过菜单<a href="/detail/e372a78bc65d4787aaa4ab47a3a55021">信用状况查询</a>进入信用状况查询界面；

*  操作步骤
 
   *  第1步：录入查询条件。
   *  第2步：点击保存/确定，即可查询信用状况。
