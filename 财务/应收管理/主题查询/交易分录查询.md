
# 功能描述

提供对系统生成的交易分录进行列表查询。

列表显示栏目可以通过”查询“方案进行设置。详见【公共操作】中的【[查询方案](http://10.16.226.67/U9C/help/zh-CN/Content/PO/PO.Query.htm)】。

# 业务规则

*  定义预设科目
*  定义会计科目模版
*  定义账簿

# 栏目说明

具体栏目参见【公共操作】中的【[交易分录查询](http://10.16.226.67/U9C/help/zh-CN/Content/PO/PO.AAI.TranEntryList.htm)】栏目说明。

*  通过菜单<a href="/detail/5529547ed62c4b608ed3acdf1383d6f1">交易分录查询</a>进入交易分录查询界面；
*  具体操作参见【公共操作】中的【[交易分录查询](http://10.16.226.67/U9C/help/zh-CN/Content/PO/PO.AAI.TranEntryList.htm)】操作说明。
