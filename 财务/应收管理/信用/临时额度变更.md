
# 功能描述

通过录入【临时额度变更单】，可临时增加或减少信用控制对象(包括客户、业务员和业务部门)的信用额度。当【临时额度变更单】过期时，则客户丧失了这部分临时变更的额度。

对象实际有效的额度是由【信用等级】•[信用额度]加上本时间点上有效的【临时额度变更单】上的“变更额度”构成的。 另外，针对订单设定的专项额度(即只对某指定的订单或订单行有效的“专门额度”)，也通过此功能节点录入。

可利用此功能针对某项目订单设定专项额度，一张订单可以设定一笔专项额度。

可以终止设定的临时额度；

# 业务规则

*  参数设定与临时额度变更相关参数

|参数名称|说明|
|---|---|
|启用信用控制|选中此项，则系统启用信用控制。需要对信用对象进行信用检查；否则，不进行信用检查。|
|客户|是否按客户进行信用控制。选中此项则表示要按照客户进行信用控制；不选中则表示不按客户进行信用控制。|
|客户位置|是否按客户bill to位置进行信用控制。选中此项则表示按照客户bill to位置进行信用控制；否则不按照客户bill to 位置进行信用控制。|
|客户集团|是否按照客户集团进行信用控制。选中此项则表示要按照客户集团进行信用控制；否则，表示不按照客户集团进行信用控制。|
|业务部门|是否按业务部门进行信用控制。选中则表示控制业务部门的信用余额；否则表示不控制业务部门的信用余额。|
|业务员|是否按业务员进行信用控制。选中则表示控制业务员的信用余额；否则表示不控制业务员的信用余额。|
|多币种额度|是否按照币种纬度进行信用控制。选中则表示分币种进行信用额度控制；否则，信用额度检查不分币种。|
|产品/产品线纬度|是否按产品/产品线纬度进行信用控制。选中则表示按照产品/产品线进行信用控制；否则，不按此纬度进行信用控制。|
|是否自动释放信用暂挂的单据|对于信用检查挂起(hold)的单据，是否可以自动释放。选中则表示可以自动释放；否则，不能自动释放。|
|额度是否包含已暂挂订单|信用对象的额度占用是否包含了已挂起订单(hold)。 选中则表示已经包含；否则表示没有包含。|

*  定义组织机构
*  定义币种
*  定义客户（可选）
*  定义客户位置（可选）
*  定义客户关联关系（可选）
*  定义销售业务员（可选）
*  定义销售部门（可选）
*  定义料品（可选）
*  定义料品分类（可选）

# **栏目说明**

临时额度变更单头

|栏目名称|说明|
|---|---|
|单号|临时额度变更单编号，根据系统设定自动编号或手工录入。|
|额度类型|非空，手工可选，枚举值包括：临时额度：为信用对象临时设定的额度；自功能节点进入此界面时默认为“临时额度”专项额度：对订单或某订单行设定的额度。自订单行进入此界面时默认为“专项额度”|
|申请组织|非空，表示申请额度变更的组织，默认为当前组织。|
|申请人|非空，表示申请额度变更的业务员或录单人员，默认为当前操作员。|
|申请日期|非空，表示申请额度变更的日期，默认取当前系统日期。|
|描述|关于额度变更的描述。|
|状态|额度变更单状态。|
|对象类型|信用对象类型,枚举值：客户：对象类型为客户客户地址：对象类型为客户地址客户集团：对象类型为客户集团部门：对象类型为部门业务员：对象类型为业务员|
|对象|信用控制的对象。|
|客户位置|当分客户位置进行信用控制时，在此录入对应的客户位置。|
|适用组织|当前申请的临时额度在哪个组织下有效。注意：对于临时额度，目前只支持当前组织；对于专项额度，指订单所在组织。|
|适用订单|当前专项额度适用的订单。若[额度类型]=“临时额度”，则此栏目为空、不可编辑；若[额度类型]=“专项额度”，则此栏目非空。注意：一张订单只能有一笔专项额度(一张【临时额度变更单】)，若当前所选择的订单在系统中已经存在“已核准”的【临时额度变更单】了，则系统提示“该订单已有专项额度！”。|
|币种|系统维护，不可改。表示对象信用额度的币种。|
|信用额度|信用额度的宽限额。当额度类型=临时额度时，可以为空，也可以录入正数、负数；当额度类型=专项额度时，若单体中录入了信用额度，则等于单体中的“信用额度”之和，否则，手工维护，但不能大于订单金额。|
|逾期应收|表示超期应收账款的宽限额。[额度类型]=“临时额度”时可正可负，可空[额度类型]=“专项额度”时必为空、不可编辑|
|逾期天数|逾期账款的超期天数的宽限额。[额度类型]=“临时额度”时可正可负，可空[额度类型]=“专项额度”时必为空、不可编辑|
|货龄天数|最大货龄的宽限额。[额度类型]=“临时额度”时可正可负，可空[额度类型]=“专项额度”时必为空、不可编辑|
|账期天数|最大账期的宽限额。[额度类型]=“临时额度”时可正可负，可空[额度类型]=“专项额度”时必为空、不可编辑|
|呆票次数|不可编辑，表示呆票发生次数的宽限额。|
|呆票|不可编辑，表示呆票发生金额的宽限额。|
|坏账|坏账金额的宽限额。[额度类型]=“临时额度”时可正可负，可空[额度类型]=“专项额度”时必为空、不可编辑|
|出货未结|上次出货未结比率的宽限值。[额度类型]=“临时额度”时可正可负，可空[额度类型]=“专项额度”时必为空、不可编辑|
|保证金|客户需要缴纳的保证金的宽限额 。[额度类型]=“临时额度”时可正可负，可空[额度类型]=“专项额度”时必为空、不可编辑注意：保证金的校验方向和其他指标值是相反的。若保证金宽限额>0，则表明客户可以少缴纳保证金；若保证金宽限额<0，则表明客户必须多缴纳保证金。|
|订单赊销额|订单最大赊销额的宽限值。[额度类型]=“临时额度”时可正可负，可空[额度类型]=“专项额度”时必为空、不可编辑|
|生效日期|设定额度变更的有效期，超过有效期范围的额度变更单无效。[额度类型]=“临时额度”时可正可负，可空[额度类型]=“专项额度”时必为空、不可编辑|
|失效日期|

临时额度变更单体

|栏目|说明|
|---|---|
|行号|单体记录行序号。|
|订单行|额度类型=专项额度时，必须录入，取变更单头适用订单的订单行。|
|料品|当前额度变更对应的料品。|
|料品分类|当前额度变更对应的料品分类。|
|信用额度|额度类型=临时额度时,录入正数或负数；额度类型=专项额度时，只能录入正数，金额不能大于订单行的金额。|

# **按钮说明**

*  <终止>：定义了临时额度变更单且已核准，用于终止临时额度变更单，额度变更单一旦终止，立刻失效。

# **操作说明**

*  通过菜单<a href="/detail/3773d12204d546e1a62c9f7a033c227a">临时额度变更</a>进入临时额度变更界面；
*  操作步骤
 
   *  第1步：选择单据类型、额度类型等相关信息。
   *  第2步：录入子表信息。
   *  第3步：点击保存，保存临时额度变更。
