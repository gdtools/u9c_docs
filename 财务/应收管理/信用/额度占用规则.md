
# 功能描述

信用额度是指为交易对象设置的，可赊欠的应收账款金额。这里所指的应收账款不仅指应收系统立账的“应收账款”，它是广义的应收，可能包括应收系统立账的应收、已签订单未付款的或已出货未付款的等等内容。具体的计算公式由“信用额度计算内容”决定。

维护信用额度占用规则就是在系统中预先定义哪些项目要占用信用额度及其计算权重；

信用额度占用规则可被信用政策引用。

# 业务规则

*  编码为必填项，不允许重复

# **栏目说明**

额度占用规则维护画面

|栏目名称|说明|
|---|---|
|编码|额度占用规则编号,可根据系统定义自动生成编号。|
|名称|额度占用规则名称，非空。|
|描述|相关说明信息，可空。|
|销售订单占用时机|销售订单占用信用额度的时机。可选项：开立时、核准时。|
|出货计划占用时机|出货计划占用信用额度的时机。可选项：开立时、核准时。|
|（预）出货单占用时机|（预）出货单占用信用额度的时机。可选项：开立时、核准时。|
|退货单占用时机|退货单占用信用额度的时机。可选项：开立时、核准时。|
|应收账款|录入客户应收账款参与信用额度占用计算的权重，用“_%”表示，为>=0的数值。注意：此处的应收账款余额还未抵扣客户的预收/暂收款。|
|保证金冲应收|计算客户的信用额度占用时，客户支付的保证金是否要抵减应收账款余额，选中此项则抵减，不选中则不抵减。注意：这个选项只有[应收账款]大于0时才有效。|
|应收票据|表示录入客户应收票据参与信用额度占用计算的权重。注意：当前版本暂不支持。|
|未处理退货|录入已核准但还未立账的退货业务参与信用额度占用计算的权重。|
|预收款|若客户的预收款/暂收款允许冲减其额度耗用，则在此录入预收款/暂收款总额参与信用额度占用计算的权重。计算客户的信用额度总耗用时，[预收款]是减项。注意：只有“预收款”和“暂收款”性质的未核销完的收款单才会被计入此项。“标准”类型的收款单，是要与对应应收进行核销处理的，因此是在核销时通过冲减 应收余额来影响额度耗用的。注意：针对物料的预收款，可以更新到该物料或对应物料类下的额度耗用里；但是针对物料类的预收款，无法更新到某具体物料下的额度耗用里。|
|坏帐|若客户的已发生坏账也需要占用额度，则在此录入坏账余额参与信用额度占用计算的权重；|
|未立账出货|在此录入客户已经出货完毕、但还未立账的出货业务参与信用额度占用计算的权重。注意：未立账出货涵盖了预出货和出货两种业务。|
|未立账订单|对于立账依据为订单的销售订单，尚未立账的金额参与信用额度占用计算的权重；|
|即将出货|在N天内将要出货的销售订单金额参与信用额度占用计算的权重。|
|注意：和“未出货订单”项目比起来，“即将出货”多了一个出货时间上的限制； “即将出货”和“未出货订单”两项是互斥的。|
|出货天数|若录入了“即将出货”，则需要在此指定即将出货的天数。注意：只有当[即将出货]不为空时才能且必须录入本栏目。|
|未出货订单|还未出货的销售订单金额参与信用额度占用计算的权重。注意：“即将出货”和“未出货订单”两者是互斥的。|
|出货计划|对于立账依据为出货的出货计划，尚未立账的金额参与信用额度占用计算的权重。|

# **按钮说明**

*  <引用对象查询>：通过此功能可以查看当前定义的信用额度占用规则被哪些对象引用了，对象包括：客户（客户地址）、部门、业务员等。
*  <引用政策查询>：通过此功能可以查看当前信用额度占用规则被哪些信用政策所引用。
*  <下发参数>：点击下发参数，可以调整下发参数，然后根据下发参数下发。操作参见《下发参数》
*  <下发>：选择下发，可以把当前记录下发到其他组织。操作参见《下发》
*  <下发取消>：选择下发取消，可以取消下发到其他组织的下发记录。操作参见《取消下发》

# **操作说明**

*  通过菜单<a href="/detail/02093c0440f14d19bac79995a733521d">额度占用规则</a>进入额度占用规则界面；
*  操作步骤
 
   *  第1步：录入编码、名称等相关信息。
   *  第2步：点击保存，保存额度占用规则。
