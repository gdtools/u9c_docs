
# 功能描述

对于已定义信用政策的对象，用户可通过本功能改变对象的信用状态 （如将某客户在“正常校验”、“信用免检”、“信用暂挂”之间进行转换）。

正常校验：表示该信用对象在业务活动中进行信用检查并更新信用额度占用情况。

信用免检：表示该信用对象在业务活动中不进行信用检查，但系统仍然会自动计算并更新该对象的信用额度占用。

信用暂挂：表示该信用对象因为信用超出而被人工挂起，不能进行正常的业务活动（但可以收款），但系统仍然会自动计算并更新其信用额度占用。

# 业务规则

*  参数设定，与信用评估相关参数
*  参数设定，与信用状态调整相关参数

|参数名称|说明|
|---|---|
|启用信用控制|选中此项，则系统启用信用控制，需要对信用对象进行信用检查，否则，不进行信用检查；|
|客户|是否按客户进行信用控制，选中此项则表示要按照客户进行信用控制，不选中则表示不按客户进行信用控制；|
|客户位置|是否按客户bill to位置进行信用控制，选中此项则表示按照客户bill to位置进行信用控制，否则不按照客户bill to 位置进行信用控制；|
|客户集团|是否按照客户集团进行信用控制，选中此项则表示要按照客户集团进行信用控制，否则，表示不按照客户集团进行信用控制；|
|业务部门|是否按业务部门进行信用控制，选中则表示控制业务部门的信用余额，否则表示不控制业务部门的信用余额；|
|业务员|是否按业务员进行信用控制，选中则表示控制业务员的信用余额，否则表示不控制业务员的信用余额；|
|多币种额度|是否按照币种纬度进行信用控制，选中则表示分币种进行信用额度控制，否则，信用额度检查不分币种。|
|产品/产品线纬度|是否按产品/产品线纬度进行信用控制，选中则表示按照产品/产品线进行信用控制，否则，不按此纬度进行信用控制；|

*  为信用对象设置信用政策和信用等级。

# 栏目说明

信用状态调整：当前列表中内容不能手工直接修改，调整对象的信用状态需要在[操作]中进行。

|栏目名称|说明|
|---|---|
|组织|显示该信用记录是由哪个组织创建的。此功能结点可以根据组织授权列出下级组织所创建的信用记录。|
|对象类型|指定信用对象类型,分别是：客户、客户位置、客户集团、部门、业务员。|
|对象|显示符合过滤条件的信用控制对象。|
|客户位置|信用控制对象为客户时，显示客户bill to位置；|
|信用政策|显示该对象所分配的信用政策。|
|开单信用等级|若该对象在开单和出货环节分别分配了不同的信用等级，则点开链接可分别显示该对象在开单环节所分配的信用等级和出货环节所分配的信用等级。 点开链接可调出“对象信用等级维护画面”显示该对象的信用等级的详细信息。|
|出货信用等级|
|信用状态|显示该信用对象当前的信用状态。|
|挂起原因|若该对象当前处于“信用暂挂”的状态下，则显示该对象信用暂挂的原因。|

# 按钮说明

*  <修改信用等级>：此功能用于调出对象信用等级维护画面，对当前对象的信用等级进行修改。
   *  操作前提
      *  信用对象已定义了信用政策数据；
      *  信用对象已定义了信用等级数据。
   *  操作步骤
      *  选定列表中的一条记录，点击【操作】->【修改信用等级】按钮，
      *  若“客户信用需审批”参数为真，则打开“信用等级评定画面”，参见信用等级评定
      *  若“客户信用需审批”参数为否，则打开对象信用等级维护画面，进行对象信用等级数据的修改。修改完成返回信用评估列表界面。
*  <批量审定>：用于批量修改对象信用等级中的“最后核准日期”、“核定人”,如果要具体审定某信用对象的信用等级，须使用【操作】->【修改信用等级】功能。

   *  操作前提
      *  信用对象已定义了信用政策数据；
      *  信用对象已定义了信用等级数据。
   *  操作步骤
      *  先选定列表中的一行或多行记录，点击【操作】->【批量审定】按钮，系统自动将对象信用等级中的“最后核准日期”修改成当前系统日期，把“核定人”修改成当前操作员。此操作需要依据系统提示进行判断要否进行批量审定操作。
*  <过滤>：设定过滤条件，查找需要进行评估的信用对象。

   *  操作前提
      *  信用对象已定义了信用政策数据；
      *  信用对象已定义了信用等级数据。
   *  操作步骤
      *  点击【操作】->【过滤】按钮，即进入过滤条件设定画面，具体步骤如下所示。
      *  第1步：在弹出的过滤条件设定画面上录入各个栏目的值：组织、对象类型、评估对象等；
      *  第2步：确认录入无误后点击画面上的【确定】按钮，即依据设定的条件把需要的信用对象过滤出来，同时返回到信用评估列表界面。如果没有符合条件的信用对象，则提示“没有符合条件的对象，请重新设置过滤条件”。
*  <挂起/释放>：当选中对象的[信用状态]=“信用免检”或“正常校验”时，本操作为“挂起”。当选中对象的[信用状态]=“信用挂起”时，本操作为“释放”。
   *  操作前提
      *  为对象设定了信用政策和信用等级。
   *  操作步骤
      *  选中列表中的一条记录，点击【操作】->【挂起/释放】按钮，可以完成对选中对象的信用挂起/释放。
      *  执行挂起操作时，必须录入挂起原因，操作完成后当前对象的信用状态为“信用挂起”。若在“挂起原因录入画面”中未录入挂起原因而直接回到当前画面，则视为放弃当前挂起操作，不改变当前对象的信用状态。
      *  释放操作将当前行的[信用状态]改为“正常校验”，并清除挂起原因。
*  <信用免检>：当选中对象行的[信用状态]=“正常校验”时，“信用免检”按钮可用。
*  <正常检查>：当选中对象行的[信用状态]=“信用免检”或“未启用”时，“正常检查”按钮可用。
*  <清除对象>：清除对象操作将把选定对象的信用等级、信用政策、临时额度及信用占用等所有使用记录全部清空，请慎重使用。注意：该操作只允许清除当前组织下创建的信用记录。该操作还将清作进行信用评定中的信用记录。

   *  操作前提
      *  对象已设定信用政策、信用等级，且发生过信用相关记录。
*  <批量清除对象>：批量清除对象当前列表显示的所有信用对象的信用等级、信用政策、临时额度及信用占用等所有使用记录全部清空。注意：请慎重使用。该操作只允许清除当前组织下创建的信用记录。该操作还将清除进行信用评定中的信用记录。
   *  操作前提
      *  对象已设定信用政策、信用等级，且发生过信用相关记录。
   *  操作步骤
      *  先用【操作】->【过滤】过滤出需要清除的信用对象，点击【操作】->【清除对象】按钮，则会清除当前列表显示的所有信用对象的所有信用记录。
*  <过滤>：此功能用于定位需要进行信用状态调整的对象范围，类似搜索功能。
*  <全部启用>：此功能用于激活系统中所有满足启用条件、且尚未启用的对象信用检查。满足启用条件指：

   *           *  选中行已有信用政策和信用等级。
      *  若对象信用证策.信用控制点=开单+出货、且同等级=False，则必须同时存在开单点和出货点的两条对象信用等级记录。
   *  操作步骤
   *  点击【操作】->【全部启用】按钮，将所有满足启用条件的对象信用状态置为“正常检查”。注意：本操作只是改变对象的信用状态，并没有初始对象的信用数据，因此为避免信用检查结果出现异常情况，建议批量启用后进行信用重算以自动初始各对象的信用数据。
