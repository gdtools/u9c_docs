
# 功能描述

对于客户/客户位置/客户集团，U9的信用可以支持多（核算组织）层控管，如同时在集团、大区和分公司三个组织层面上，对同一客户设定不同的额度，客户在最底层的分公司下单时，必须同时满足这三个组织层面上的控制要求才能通过信用检查。

一般来说，每个核算组织只能决定客户在当前组织下的信用控管政策、额度，此客户是否需要在上级组织做多层复合控管，则是由上级核算组织来决定。我们也允许由当前组织自己决定。

这个节点就是用来指定客户除了在当前核算组织下做信用控管，还需在哪些直接下级组织里做多层复合控管。当然，也可以查到当前组织下哪些客户需要在上级核算组织里做多层复合控管。

注意：U9信用的多组织层次，是按照核算垂直关系来确定的；客户位置的控管层次是由其所属客户决定的，客户集团的控管层次是由其主客户决定的。


# 业务规则

*  参数设定，对象信用相关参数

|参数名称|说明|
|---|---|
|客户|是否按客户进行信用控制，选中此项则表示要按照客户进行信用控制，不选中则表示不按客户进行信用控制；|
|客户位置|是否按客户bill to位置进行信用控制，选中此项则表示按照客户bill to位置进行信用控制，否则不按照客户bill to 位置进行信用控制；|
|客户集团|是否按照客户集团进行信用控制，选中此项则表示要按照客户集团进行信用控制，否则，表示不按照客户集团进行信用控制；|
|业务部门|是否按业务部门进行信用控制，选中则表示控制业务部门的信用余额，否则表示不控制业务部门的信用余额；|
|业务员|是否按业务员进行信用控制，选中则表示控制业务员的信用余额，否则表示不控制业务员的信用余额；|
|多币种额度|是否按照币种纬度进行信用控制，选中则表示分币种进行信用额度控制，否则，信用额度检查不分币种。|
|产品/产品线纬度|是否按产品/产品线纬度进行信用控制，选中则表示按照产品/产品线进行信用控制，否则，不按此纬度进行信用控制；|
|客户信用需审批|若选中此选项，则给客户分配信用等级、或变更客户的信用等级时，必须通过信用等级评定表来完成，该评定表支持审批过程。若未选中此选项，则可直接修改客户的信用等级或给客户分配信用等级，不需要通过审批流程。|

# 栏目说明

主画面

显示在当前组织下，设定了哪些客户、在哪些下级核算组织（包括当前组织）里需要做多层复合控管。

即，列表里显示的客户，除了在列表里显示的组织做信用控管外，还需要在其上级核算组织里做信用控管。

|栏目名称|说明|
|---|---|
|客户|显示已设定控管范围的客户|
|控管组织|显示需要做复合控管的组织范围|

# 按钮说明

*  <操作_修改控管范围>：对于指定的客户，可以增加或去掉其做复合信用控管的组织范围。
*  这里只能处理由当前组织创建的记录，只能增减当前组织或其下级核算组织。
*  <操作_按组织批量修改>：在弹出画面，按组织维护客户控管范围。
*  <操作_过滤条件>：可按客户或组织过滤主画面里的记录，只显示当前关注的数据。
*  <追溯查询_已接收控管客户>：显示当前组织下，哪些客户除了受当前组织的信用约束，还需受上级核算组织的复合控管。
