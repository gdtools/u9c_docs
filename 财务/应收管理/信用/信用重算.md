
# 功能描述

当客户间关系（客户集团关系）发生变化，或企业的上下级组织间关系发生变化时，需要按照新的关系重新组织历史信用数据。

# 业务规则

*  参数设定，与信用重算相关参数

|参数名称|说明|
|---|---|
|启用信用控制|选中此项，则系统启用信用控制，需要对信用对象进行信用检查，否则，不进行信用检查；|
|客户|是否按客户进行信用控制，选中此项则表示要按照客户进行信用控制，不选中则表示不按客户进行信用控制；|
|客户位置|是否按客户bill to位置进行信用控制，选中此项则表示按照客户bill to位置进行信用控制，否则不按照客户bill to位置进行信用控制；|
|客户集团|是否按照客户集团进行信用控制，选中此项则表示要按照客户集团进行信用控制，否则，表示不按照客户集团进行信用控制；|
|业务部门|是否按业务部门进行信用控制，选中则表示控制业务部门的信用余额，否则表示不控制业务部门的信用余额；|
|业务员|是否按业务员进行信用控制，选中则表示控制业务员的信用余额，否则表示不控制业务员的信用余额；|
|多币种额度|是否按照币种纬度进行信用控制，选中则表示分币种进行信用额度控制，否则，信用额度检查不分币种。|
|产品/产品线纬度|是否按产品/产品线纬度进行信用控制，选中则表示按照产品/产品线进行信用控制，否则，不按此纬度进行信用控制；|
|是否自动释放信用暂挂的单据|对于信用检查挂起hold的单据，是否可以自动释放，选中则表示可以自动释放，否则，不能自动释放；|
|额度是否包含已暂挂订单|信用对象的额度占用是否包含了已挂起订单，选中则表示已经包含，否则表示没有包含；|

*  定义信用对象
*  定义客户位置
*  定义物料、物料分类
*  定义币种
*  定义额度占用规则
*  定义信用政策
*  定义信用等级
*  进行对象信用设定
*  对相关应收处理完成核准，已保证重算数据的准确性。

# **栏目说明**

待重算对象列表：当前列表内容不可修改

|栏目名称|说明|
|---|---|
||点击方框至当中出现“对勾”为选中当前记录，否则为未选中；|
|行号|记录的顺序号；|
|组织|默认为当前登陆的组织；|
|对象类型|待重算的信用对象的类型，备选项如下：客户：待重算的对象为客户类型客户集团：待重算的对象为客户集团类型部门：待重算的对象为业务部门类型业务员：待重算的对象为业务员类型全部：待重算对象包括所有对象类型；|
|营运组织|当前对象信用对象对应的营运组织；|
|重算对象|进行信用重算的信用对象；|
|信用状态|当前对象信用的信用状态；|
|信用政策|对象信用政策名称。可点开该链接在“对象信用政策维护画面”察看该信用对象的信用政策的详细内容。|
|开单信用等级|可空，信用对象在当前组织下的信用等级名称，显示“开单”控制点的信用等级记录。可点开该链接在“对象信用政策维护画面”察看该信用对象的信用政策的详细内容。|
|出货信用等级|可空，信用对象在当前组织下的信用等级名称，显示“出货”控制点的信用等级记录，可点开该链接在“对象信用政策维护画面”察看该信用对象的信用政策的详细内容。|

# **按钮说明**

*  <终止>：定义了临时额度变更单且已核准，用于终止临时额度变更单，额度变更单一旦终止，立刻失效。
*  <执行>：启动选中记录的信用余额重算操作。

   *  操作前提
      *  在列表中选中了一条或多条记录；
   *  操作步骤：点击【操作】->【执行】按钮，系统开始执行信用余额重算。
      *  若本次重算前后对象信用余额没有变化，则系统提示“重算完毕，本次重算没有产生差异记录”
      *  若本次重算前后对象信用余额有变化，则自动将有差异的记录背景变为蓝色，并将重算结果更新信用余额表，同时提示“重算完毕，已更新信用余额表”。
      *  重算过程中，其他按钮为灰不可用，直到重算执行完毕后，其他按钮才可用。
*  <过滤条件>：用于设定需重算信用余额的对象的过滤条件。
   *  操作步骤
      *  点击【操作】->【修改过滤条件】按钮，在弹出的过滤条件设定画面设定组织、对象类型、重算对象、客户位置等栏目,确定即可。
