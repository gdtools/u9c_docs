
# 功能描述

用户可按照一定的分类标准，在每个信用政策下将不同档次的信用额度分为不同的等级，并将这些等级分配给各个需要控制信用的客户。

# 业务规则

*  定义信用政策 [必选]
*  定义币种 [必选]
*  定义物料 （可选）
*  定义物料分类 （可选）
*  定义客户、客户位置（可选）
*  定义部门（可选）

# 栏目说明

单头-信用政策页签

|栏目名称|说明|
|---|---|
|信用政策|非空，信用政策名称。若未创建“信用政策”，可点选链接在线创建一个新的“信用政策”；若选择了一个信用政策，也可点击标题链接察看该“信用政策”的详细内容。|
|编码|非空，信用等级编码。可手工录入。|
|名称|手工录入，信用等级名称。|
|描述|手工录入，可空。|
|对象可改|此选项用于控制对象引用信用等级后，是否可以对等级设定值进行修改以满足对象自身的属性。选中此项则可以进行修改，不选中则不可以修改。|
|限制修改幅度|表示是否可以在“修改限制页签”中对信用额度修改幅度进行限制。注意：【信用政策】中定义“信用控管方式”为“余额式”时，且[对象可改]被选中时，当前项目可改；若“信用控管方式”为“押单式”，则当前项目为空不可编辑。|
|额币|系统维护，表示信用额度币种。|
|押单笔数|表示允许存在的未结应收账款的笔数。若【信用政策】中定义“信用控管方式”为“押单式”时非空，手工录入时仅允许录入正整数。注意：若“信用控管方式”为“余额式”，则[押单笔数]为空不可编辑。|
|订单赊销额|录入允许对象赊销的订单金额；注意：【信用政策】中定义[单张订单的赊销额]为“真”时才允许录入 。|
|信用额度|录入，表示对象被允许的信用金额；注意：【信用政策】•[信用额度]=True且【信用政策】•[信用控管方式]=“余额式”时才允许录入。|
|逾期应收|录入，表示允许对象的逾期应收金额；注意：【信用政策】•[逾期应收]=True且【信用政策】•[信用控管方式]=“余额式”时才允许录入 。|
|逾期天数|录入正整数，表示允许对象发生的最大逾期应收天数；注意：【信用政策】•[逾期应收逾期时间]=True且【信用政策】•[信用控管方式]=“余额式”时才允许录入|
|账期天数|录入正整数，表示允许对象发生的最大账期天数；注意：【信用政策】•[最大账期]=True且【信用政策】•[信用控管方式]=“余额式”时才允许录入 。|
|货龄天数|录入正整数，表示允许对象发生的最大货龄天数；注意：【信用政策】•[最大账期]=True且【信用政策】•[信用控管方式]=“余额式”时才允许录入 。|
|保证金比例|录入允许对象赊销的订单金额；注意：【信用政策】•[保证金]=True且【信用政策】•[信用控管方式]=“余额式”时才允许录入 。|
|保证金|录入允许对象支付保证金的额度，系统默认：保证金=信用额度*保证金比例。|
|呆票次数|表示允许对象发生呆票的次数。不可编辑，目前暂未支持。|
|呆票|表示允许对象发生呆票的最大金额。不可编辑，目前暂未支持。|
|坏账|录入，表示允许对象发生的的坏账金额；注意：【信用政策】•[坏账]=True且【信用政策】•[信用控管方式]=“余额式”时才允许录入|
|出货未结率|录入，表示允许对象的出货未结比率；注意：【信用政策】•[上次出货未结]=True且【信用政策】•[信用控管方式]=“余额式”时才允许录入 。|

# 按钮说明

*  <信用等级分配>：可以把定义的信用等级分配给信用对象（客户、部门），也可以查看当前信用等级在信用对象间的分配情况。若“客户信用需审批”参数为真，则分配的信用等级需通过信用等级评定的审批后,才增加对象信用等级，参见信用等级评定。若“客户信用需审批”参数为否，则直接增加对象信用等级。
   *  操作前提
      *  定义信用等级
      *  定义信用对象

# 操作说明

通过菜单<a href="/detail/d750287c27a641e7a5cdc108f8cadd2e">信用等级</a>进入信用等级界面；

*  操作步骤

   *  第1步：录入信用政策、编码等信息。
   *  第2步：录入子表信息。
   *  第3步：点击保存，保存信用等级。
