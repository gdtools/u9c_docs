
# 功能描述

用户可通过本结点将系统中已定义的信用政策及信用等级分配给信用对象；

可通过本节点有条件地增加、修改或删除对象的信用政策和信用等级；

可以查询对象的额度耗用情况；

# 业务规则

*  参数设定，对象信用相关参数

|参数名称|说明|
|---|---|
|客户|是否按客户进行信用控制，选中此项则表示要按照客户进行信用控制，不选中则表示不按客户进行信用控制；|
|客户位置|是否按客户bill to位置进行信用控制，选中此项则表示按照客户bill to位置进行信用控制，否则不按照客户bill to 位置进行信用控制；|
|客户集团|是否按照客户集团进行信用控制，选中此项则表示要按照客户集团进行信用控制，否则，表示不按照客户集团进行信用控制；|
|业务部门|是否按业务部门进行信用控制，选中则表示控制业务部门的信用余额，否则表示不控制业务部门的信用余额；|
|业务员|是否按业务员进行信用控制，选中则表示控制业务员的信用余额，否则表示不控制业务员的信用余额；|
|多币种额度|是否按照币种纬度进行信用控制，选中则表示分币种进行信用额度控制，否则，信用额度检查不分币种。|
|产品/产品线纬度|是否按产品/产品线纬度进行信用控制，选中则表示按照产品/产品线进行信用控制，否则，不按此纬度进行信用控制；|
|客户信用需审批|若选中此选项，则给客户分配信用等级、或变更客户的信用等级时，必须通过信用等级评定表来完成，该评定表支持审批过程。若未选中此选项，则可直接修改客户的信用等级或给客户分配信用等级，不需要通过审批流程。|

对象信用列表画面

|栏目名称|说明|
|---|---|
|对象类型|指定信用对象类型。用于区分客户、客户位置和客户集团类型的对象。备选项如下：客户：表体的列表里将列出的对象为客户、客户位置和客户集团；部门：表体的列表里将列出的对象为部门；业务员：表体的列表里将列出的对象为部门；全部：表体的列表里将列出当前组织下所有类型的对象；注意:若信用控制参数中定义不按照部门或业务员管理信用,备选项种对应内容将不显示.|
|对象|显示具体的信用对象名称，若为客户则显示客户名称；若为部门则显示部门名称|
|客户位置|若当前列出的是“客户位置”类型的信用控制对象，则此处显示客户位置名称|
|信用状态|显示对象当前的信用状态,系统有如下几种状态：“信用免检”——该对象虽已定义了信用政策，但当前状态为信用免检。虽然在交易过程中不进行信用检查，但系统仍然会自动计算并更新该对象的信用额度占用。“正常校验”——该对象正常进行信用检查、正常更新信用额度占用.“信用暂挂”——该对象因为信用不够而被人工挂起，不能进行正常的业务活动（除了可以进行收款），但系统仍然会自动计算并更新其信用额度占用。“未启用”——该对象已定义了信用政策、但还未正式启动它的信用控制，因而在交易过程中不进行信用检查、且系统不会计算其信用额度占用.|
|信用政策|显示对象所分配的信用政策。|
|信用控制点|显示对象在哪些信用控制点分配了信用等级。系统有如下几种信用控制点：“开单”——分配的信用等级数据适用于开单环节，在开订单时检查和控制信用“出货”——分配的信用等级数据适用于出货环节，在出货时检查和控制信用“开单+出货”——在开单和出货时都控制信用|
|信用等级|显示对象在每个信用控制点下所分配的信用等级。|

   *  1.进行系统初始时，设置好各对象的政策/等级后，为了提高操作速度和性能，批量启用对象，然后批量进行信用重算以自动初始各对象的信用数据。
   *  2.临时或单个增加信用检查对象时，设置好信用证策/等级后，直接使用“启用并初始”功能 启用对象、并自动初始。
*  <启用并初始>：若对象的信用证策、信用等级已设置完毕，则可以通过本操作正式启用对象的信用检查，并同步自动初始对象的信用数据。
