
# 功能描述

用于设置临时额度单据的审批方式、单据编号规则等。

# 业务规则

*  启用信用管理

# 栏目说明

执行【应收管理】－>【信用】－>【临时额度单据类型】，打开单据类型定义画面。

编码：手工输入，当前单据类型的编码。注意编码不能重复。

名称：手工输入，当前单据类型的名称，可空。

参数

参见单据类型公共说明

# 操作说明

通过菜单<a href="/detail/777c942d80fa4ebcadf0e3b5b5ea8001">临时额度单据类型</a>进入临时额度单据类型界面；

*  操作步骤：

   *  第1步：录入编码、名称等信息。
   *  第2步：点击保存，保存临时额度单据类型。
