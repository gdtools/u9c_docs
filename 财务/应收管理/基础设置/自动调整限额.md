
# 功能描述

对应收单有自动调整要求的企业需要设置自动调整限额，否则不需要设置自动调整限额。自动调整限额用于明确当应收单余额小于等于多少时就需要系统自动执行调整功能，将该应收单余额自动调整为0。自动调整限额按币种＋单据类型设置，若企业有自动调整的要求，但是不需要明细按币种设置限额，那么直接在应收单据类型中设置自动调整限额即可。

# 业务规则

*  定义货币档案（必做）
*  定义应收单类型档案

# 栏目说明

自动调整限额卡片

|栏目名称|说明|
|---|---|
|单据类型|选择需要系统自动调整的应收单单据类型|
|币种|选择要设定的自动调整限额所使用的币种|
|自动调整上限|输入一个金额，如果当前币种、当前单据类型的应收单在业务处理中余额小于等于本金额时，系统自动将该应收单的余额调整为0，并将调整额记录在应收调整单中。|

# 操作说明

通过菜单<a href="/detail/7068a19391e54b76b37f1cd9fbda8cff">自动调整限额</a>进入自动调整限额界面；

*  操作步骤

   *  第1步：选择币种、单据类型等信息。
   *  第2步：点击保存，保存自动调整限额。
