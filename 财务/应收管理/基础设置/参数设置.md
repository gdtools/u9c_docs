
# 功能描述

设置应收系统的参数。

# 关键应用

# 业务规则

*  启用应收管理

|坏账|按付款客户分类计提坏账|计提坏账准备时是否需要根据付款客户分类确定计提比率、计提金额|

|汇兑损益|期末时计算汇兑损益|可以选择：是或者否；当参数区分已实现汇兑损益＝是，需用户选择当参数区分已实现汇兑损益＝否，固定为是• 是：期末需计算汇兑损益• 否：期末不计算汇兑损益|

|汇兑损益|期末计算汇兑损益汇率类型|参照汇率类型档录入；当参数期末时计算汇兑损益＝是，用户选择当参数期末时计算汇兑损益＝否，不可用|

|信用控制|启用信用控制|选中此项表示，当前核算组织启用信用管理：可以设置信用额度、当前组织及其对应的 营运组织下录订单时会进行信用检查、当前组织及相应的营运/物流/工厂组织出货时会检查信用。注意:此参数是信用管理的总开关，只有本参数被选中后，其他信用控制参数才有效，才允许维护；当启用信用控制时，要求必须启用对客户的信用管控，即【信用控制在客户层】、【信用控制在立账位置层】、【信用控制在客户集团层】至少要选中一个，且允许多选（即支持复合控制）。|
|信用控制|信用控制在客户层|选中此项表示，允许按客户设置额度。即在客户层设置一个共享额度，客户下的所有位置共享此额度，按一个额度控制信用。若当前组织下已对“客户”设信，则必须勾选此参数，不能去掉。对1个组织来说，可以同时启用客户层和客户位置层的信用控管。但对1个客户来说，要么按客户层控管信用、要么按位置层控管信用，两者互斥。注意：若客户采用下发模式，在V2.0里必须将所有设信客户下发到当前组织的所有相关组织里，才能正常进行信用控管和信用查询。|
|信用控制|信用控制在立账位置层|选中此项表示，允许按客户立账位置设置额度。即在不在客户层设置共享额度，而是对客户下的各个立账位置分别设置额度；一个客户下的不同位置，可以采用不同的规则和额度进行信用管控，互不影响。若当前组织下已对“客户位置”设信，则必须勾选此参数，不能去掉。对1个组织来说，可以同时启用客户层和客户位置层的信用控管 。但对1个客户来说，要么按客户层控管信用、要么按位置层控管信用，两者互斥。注意：若客户采用下发模式，在V2.0里必须将所有设信客户位置下发到当前组织的所有相关组织里，才能正常进行信用控管和信用查询。|
|信用控制|信用控制在客户集团层|选中此项表示，允许按客户集团设置额度。即针对客户集团设置一个共享额度，该客户集团下的所有客户均共享此额度，按一个额度控制信用。信用里的“客户集团”，是由客户关系中互为“垂直”关系的一组客户组成的集合。虽然U9的客户关系支持多层嵌套（即一个客户集团下挂另一个客户集团，以此递归），但U9信用控制只能支持一层客户集团。若当前组织下已对“客户集团”设信，则必须勾选此参数，不能去掉。注意：若客户采用下发模式，在V2.0里必须将所有设信客户集团（客户档及客户关系）下发到当前组织的所有相关组织里，才能正常进行信用控管和信用查询。|
|信用控制|信用控制在业务部门层|选中此项表示，允许按业务部门设置额度。 即针对订单和出货单上的销售部门进行 信用管控。 对业务部门设置的额度相当于该部门允许发生的“放账额度”，其额度耗用的原始数据还是由对应的客户累加到该部门头上的。注意：若当前组织下已对“业务部门”设信，则必须勾选此参数，不能去掉。|
|信用控制|信用控制在业务员层|选中此项表示，允许按销售业务员设置额度。 即针对订单和出货单上的业务员进行 信用管控。 对业务员设置的额度相当于该业务员允许发生的“放账额度”，其额度耗用的原始数据还是由对应的客户累加到该业务员头上的。注意：若当前组织下已对“业务员”设信，则必须勾选此参数，不能去掉。|
|信用控制|启用产品/产品线纬度|选中此项表示，允许对于客户,同时按料品或料品(信用)分类进行复合信用控管。如,客户A享有10万的总赊账额度,同时对于某紧俏商品X要求必须先全款预付才能订货/出货.此时给客户分配10万的总信用额度,同时对该客户设置一个0额度的X料品额度。客户下订单时,若不含X料品,则只要满足10万的总额度即可；若订单中含X料品,则要求两个条件都满足。注意：若当前组织下已有客户按料品或料品类设信，则必须勾选此参数，不能去掉。|
|信用控制|允许在线新增临时额度|选中此项表示，在录入销售订单时，可以在线创建专项额度或临时额度。注意：若订单已保存，则默认创建专项额度；若订单未保存，则默认创建临时额度|
|信用控制|自动释放信用暂挂的单据|选中此项表示，若某客户订单因信用额度不足而被挂起，此后增加客户的临时额度、或对客户进行收款等降低额度耗用行为时，系统会自动按时间先后顺序（从小到大）重新检查此客户被信用挂起的订单，对于其中额度足够的订单进行自动释放。|
|信用控制|自动重挂订单|选中此项表示，若客户因为产生坏账、应收增加或者临时额度失效等增加额度耗用的行为时，系统会自动按时间顺序（从大到小）地对该客户还未完成出货的订单一一进行检查，对于其中额度不够的进行自动挂起。|
|信用控制|额度包含已暂挂单据|选中此项表示，虽然客户订单因额度不足而被自动挂起，但是该订单仍然会消耗客户的额度，该订单会影响客户的信用状况。如客户额度为10万，录入一张11万的订单，该订单因信用额度不够被自动挂起，此时再录入该客户的任何其他金额的订单，都会因信用额度不足而被挂起。因为此时客户的授信额度是10万，但已耗用额度是11万。未选中此选项表示，客户订单若因额度不足而被信用挂起，则该订单不会再消耗客户的额度，该订单不会影响客户的信用状况。如，客户额度为10万，录入一张11万的订单，该订单因信用额度不够被自动挂起，此时再录入该客户的小于10万的销售订单 ，仍然可以通过信用检查。因为此时客户的授信额度是10万，但已耗用额度是0。|
|信用控制|客户信用需评审|选中此项表示，给客户分配信用等级、或变更客户的信用等级、修改客户的信用额度时，都必须通过信用等级评定表来完成，不允许人工直接修改客户的信用等级。信用等级评定表支持审批流。未选中此选项表示，可人工直接给客户分配信用等级、修改客户的额度，而不需要 通过审批流程。|
|其他|单据日期和记账期间严格匹配|单据日期和记账期间严格匹配|
|其他|业务员、部门是否必须匹配|无来源应收单收款单的部门业务员是否必须匹配|
