
# 功能描述

挂起类型就是挂起和释放的原因分类，主要是为了便于更好地管理应收挂起和释放业务。


# 业务规则

*  编码为必填项，不允许重复。

# 栏目说明

应收挂起栏目

|栏目名称|说明|
|---|---|
|描述|可以在此栏目输入挂起或释放的原因|
|属性|枚举值：挂起：执行应收挂起时可以选择的挂起类型释放：释放挂起记录时可以选择的类型|
|默认类型|可以指定属性为“挂起”的类型为默认类型，以便在未指定挂起类型的情况下，系统依然能够获取此信息。提示：只有一种属性为“挂起”的类型可以指定为默认类型|

# 操作说明

通过菜单<a href="/detail/ecbded8cf139449d9a80680d1fa40753">应收挂起类型</a>进入应收挂起类型界面；

*  操作步骤

   *  第1步：录入编码、名称、属性等信息。
   *  第2步：点击保存，保存应收挂起类型。
