
# 功能描述

启用应收系统后首先应该定义应收单类型。针对应收单的每一种业务类型系统已经预置了一个单据类型，用户可以根据管理要求进行增删改。

设置应收单类型的作用：

应收单的归类，并且可以给应收单提供一些默认参数；

可以根据单据类型配置不同的审批流；

可以根据单据配置不同的交易分录模板。

# 栏目说明

应收单类型－基本页签

|栏目名称|说明|
|---|---|
|业务类型|选择该应收单类型所属的应收业务类型。参见：应收业务类型|
|默认类型|将当前应收单类型指定为默认的单据类型。提示：每种业务类型下有且仅有一种默认应收单类型|
|收款条件|指定属于当前应收单类型的应收单所使用的收款条件|
|计税|确定属于当前应收单类型的应收单是否允许计税。选择“否”时不允许计税；选择“是”时允许计税，当然也可以不计税|
|计费|确定属于当前应收单类型的应收单是否允许有费用发生。选择“否”时不允许有费用发生；选择“是”时允许有费用发生，当然也可以没有费用发生|
|贷项通知单|只有业务类型为“发票”的应收单类型可以选择本栏目，用于指定与当前发票所关联的贷项通知单类型。参见应用专题：通知单|
|借项通知单|只有业务类型为“发票”的应收单类型可以选择本栏目，用于指定与当前发票所关联的借项通知单类型。参见应用专题：通知单|
|核销顺序|选择当前应收单类型的单据参与核销时，单据内未税金额、税额和费用的核销顺序。参见应用专题：核销|
|自动调整金额上限|不需要按币种设定自动调整限额时在此栏目设定当前应收单类型的自动调整上限。相关主题|
|应收对账单方向|表示当前单据类型的应收单在应收对账单、应收明细账或应收余额表中显示的栏目位置：应收：表示当前单据类型的应收单在应收对账单、应收明细账或应收余额表中显示在应收栏目收回：表示当前单据类型的应收单在应收对账单、应收明细账或应收余额表中显示在收回栏目参见：应收对账单、应收明细账、应收余额表|
|应付对账单方向|表示当前单据类型的应收单在应收应付同列的应付对账单、应付明细账或应付余额表中显示的栏目位置：应付：表示当前业务类型的单据在应收应付同列的应付对账单、应付明细账或应付余额表中显示在应付栏目付款：表示当前业务类型的单据在应收应付同列的应付对账单、应付明细账或应付余额表中显示在付款栏目参见：应付对账单、应付明细账、应付余额表|
|单价含税|选择“是”：系统将您输入的单价按含税价处理；选择“否”：系统将您输入的单价按不含税价处理|
|更新客户余额|选择“是”：当前类型的应收单核准后将更新客户余额；选择“否”：当前类型的应收单核准后不更新客户余额|
|未结清参与期末汇兑损益计算|当前类型的应收单原币金额不为0时，按此参数判断是否参与汇兑损益|
|已结清参与期末汇兑损益计算|当前类型的应收单原币金额为0时，按此参数判断是否参与汇兑损益|
