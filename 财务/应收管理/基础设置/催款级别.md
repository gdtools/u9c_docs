
# 功能描述

系统提供按账龄区间和催款次数两种方式设置催款级别，对不同的客户可以根据管理要求设定按账龄区间催款或按催款次数催款。本功能用于设定两种方式下的催款级别和针对每个催款级别的催款用语，用于对属于不同催款级别的应收账款催款时系统自动生成不同催款语气的催款函。


# 业务规则

*  系统已经启用催款级别功能。

# 栏目说明

催款函级别设置画面－按账龄

|栏目名称|说明|
|---|---|
|账龄区间方案|按账龄区间催款时所使用的账龄区间方案，选择账龄区间方案后，可以对此方案中不同的账龄区间设置不同的催款级别，以便催款时生成不同语气的催款函|
|时间单位|当前所选择的账龄区间方案中所使用的时间单位，本栏目由系统根据账龄区间方案维护，不可更改|
|账龄区间|以起止的形式显示不同的账龄区间，由账龄区间方案生成，不可更改|
|催款用语|对当前账龄区间内的应收账款催款时所使用的语气。本栏目内输入的内容将出现在系统自动生成的催款函中，代表催款函所使用的语气。|

催款函级别设置画面－按催款次数

|栏目名称|说明|
|---|---|
|催款次数下限|

|催款次数区间的下限。本栏目由系统维护|

|催款次数上限|


|催款次数区间的上限。本栏目由用户定义|

|催款用语|以起止的形式显示不同的账龄区间，由账龄区间方案生成，不可更改|

# 操作说明

通过菜单<a href="/detail/f98c4f65839a4695aa98182953ea160b">催款级别</a>进入催款级别界面；

*  操作步骤

   *  第1步：选择账龄区间方案信息。
   *  第2步：录入子表信息。
   *  第3步：点击保存，保存催款级别。
