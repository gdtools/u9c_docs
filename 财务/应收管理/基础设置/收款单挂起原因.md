
# 功能描述

本节点提供收款单挂起原因的设置，主要功能点如下：

设置收款单挂起原因

设置收款单挂起原因的有效性和有效时间区间

设置允许使用该挂起原因的用户

为特定用户使用该挂起原因设定有效性和有效时间区间

查询收款单挂起原因的状态

# 业务规则

*  编码为必填项，不允许重复。

# 栏目说明

挂起设置画面表头

|栏目名称|说明|
|---|---|
|编码|手工输入当前收款单挂起原因的编码注意　:编码不能重复|
|名称|当前收款单挂起原因的描述|
|简称|当前收款单挂起原因的简称|
|生效|当前收款单挂起原因是否生效的状态|
|生效日期|当前收款单挂起原因的生效日期|
|失效日期|当前收款单挂起原因的失效日期|

挂起设置画面表体

|栏目名称|说明|
|---|---|
|操作员|选择对当前收款单挂起原因有使用权的操作员，只有在此列表中的操作员才有权使用当前收款单挂起原因|
|生效|当前列表行的用户是否有权使用当前收款单挂起原因的状态|
|生效日期|当前列表行的用户允许使用当前收款单挂起原因的开始日期|
|失效日期|当前列表行的用户允许使用当前收款单挂起原因的结束日期|

# 操作说明

通过菜单<a href="/detail/3909553752524e33b40226148cb37d88">收款单挂起原因</a>进入收款单挂起原因界面；

*  操作步骤

   *  第1步：录入编码、名称等信息。
   *  第2步：录入子表信息。
   *  第3步：点击保存，保存收款单挂起原因。
