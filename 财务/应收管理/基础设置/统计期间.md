
# 功能描述

设置每个应用系统的统计数据使用的统计规则。


# 业务规则

*  定义统计规则（必做）

# 栏目说明

统计规则画面

|栏目名称|说明|
|---|---|
|应用系统|显示设置统计期间的应用系统名称。固定为应收管理。|
|统计表名|选择当前应用系统中需要的执行统计功能的报表。|
|期间规则|录入统计表的统计规则。参照统计规则档案录入。点击链接，弹出统计规则编辑查询画面，可以在线新增统计规则数据。|

# 操作说明

通过菜单<a href="/detail/2a950504e06d4e9dbebd82bb907f1f82">统计期间</a>进入统计期间界面；

*  操作步骤

   *  第1步：选择统计表名、期间类型信息。
   *  第2步：点击保存，保存统计期间。
