
# 功能描述

查询逾期的应收单


# 业务规则

*  已启用应收管理

# 栏目说明

查询条件

|栏目名称|说明|
|---|---|
|核算组织|参照组织档案录入|
|来源组织|参照组织档案录入|
|业务组织|参照组织档案录入|
|结算组织|参照组织档案录入|
|立账客户|参照客户档案录入|
|立账客户位置|参照客户档案位置录入|
|付款客户|参照客户档案录入|
|付款客户位置|参照客户档案位置录入|
|立账客户分类|参照客户分类录入|
|付款客户分类|参照客户分类录入|
|立账客户地区|参照地区录入|
|付款客户地区|参照地区录入|
|核币|参照币种录入|
|单据状态|选择单据状态：开立核准中已核准|

查询结果

|栏目名称|说明|
|---|---|
|逾期天数|当前系统日期 – 到期日|

# 操作说明

通过菜单<a href="/detail/c7150b8fbb2b4dcbae20e34c00bfcde8">逾期应收表</a>进入逾期应收表界面；

*  操作步骤

   *  第1步：录入查询条件。
   *  第2步：点击保存/确定，即可查看逾期应收表。
