
# 功能描述

该报表可以查询应付明细账。

# **业务规则**

*  已启用应付管理。

# **栏目说明**

|栏目名称|说明|
|---|---|
|查询说明||
|核算组织|参照组织档案录入|
|来源组织|参照组织档案录入|
|业务组织|参照组织档案录入|
|结算组织|参照组织档案录入|
|期间类型|枚举值：
   *  会计期间（默认）
*  统计期间
*  自然日期
|
|会计期间范围|当［期间类型］＝会计期间，可用枚举值：
   *  当前期间
*  上一期间
*  去年同期
*  指定期间
|
|会计期间|当［期间范围］＝指定期间，可用参照选择|
|统计期间规则|当［期间类型］＝统计期间，可用参照选择|
|统计期间范围|当［期间类型］＝统计期间，可用|
|统计期间|当［期间类型］＝统计期间，可用|
|自然日期|当［期间类型］＝自然日期，可用，可输入任意日期|
|业务类型|可限定查询应付单的业务类型范围|
|单据类型|可限定查询应付单的单据类型范围|
|包含未立账|确定满足截止时间的未立账单据是否包括在查询范围内|
|未立账单据|当[是否包含未立账]＝true时，可指定包含哪些未立账的单据类别，如未立账的应付单、采购收货单、采购订单、配送对账单、资产调入单、管销费用单等|
|查询结果||
|本期应付|显示单据的应付额|
|本期付款|显示单据的付款额|
|余额|显示余额|

# **操作说明**

*  [联查凭证](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)

在列表中点“凭证号”链接，可联查凭证。

*  [联查单据](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)

在列表中点“单据号”链接，可联查单据。
