
# 功能描述

*  在此可以查询一段时期内的应付款发生及余额的情况；
*  可以追溯查询应付的相关处理情况（例如付款、调整等处理）； 
*  可以查询应付单未匹配的信息。

# **业务规则**

*  查询条件可以自定义（通过属性选取设置），应付单上的每一个字段都可以作为查询条件；
*  默认查询结果为按应付单显示每当的应付金额、应付余额。

# **栏目说明**

|栏目名称|说明|
|---|---|
|核算组织|确定核算组织范围|
|应付单号|可指定查询的应付单号|
|供应商类型|可选范围：立账供应商、付款供应商、全部供应商|

# **操作说明**[]()

*  [联查应付明细](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)：按应付单行显示每一行的应付金额、应付余额；
*  [联查匹配汇总信息](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)：按应付单显示每一单的可匹配、已匹配、未匹配的数量、金额信息；
*  [联查匹配明细信息](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)：按应付单行显示每一行的可匹配、已匹配、未匹配的数量、金额信息；
*  [联查核销明细](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)：联查对应应付单或者应付单行的已处理明细记录，包括核销、转移、调整、正在请款、正在挂起。
