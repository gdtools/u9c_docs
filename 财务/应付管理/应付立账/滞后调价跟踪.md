
# 功能描述

在交易过程中经常会碰到供应商的价格调整，由于价格调整信息不能即时地反应在相应的订单、收货单上，导致所立的应付账款会与实际价格有差异。滞后调价跟踪就是通过调价单所调整的物料、供应商、收货单查询出哪些交易记录所立的应付账款与调整后价格有差异，已经调整了多少金额，还缺多少金额，后续可以根据该表调整应付账款。

# **业务规则**

*  输入调价单（必做）

# **栏目说明**

|栏目名称|说明|
|---|---|
|表头||
|供应商|对应调价的供应商|
|调价单号|对应的调价单号|
|调价起始日期|调价单开始生效的日期|
|分析截至日期|滞后调价终止日期，取MIN（调价单录入日期，调价单对应调整价目表有效截至日期）|
|跟踪明细表||
|单据别|显示跟踪的单据类别是采购订单还是收货单|
|单号|被跟踪单据的单号|
|原单价|被跟踪单据行的原始单价|
|新单价|被跟踪单据行的调价后单价|
|应付单号|被跟踪单据已经立应付账款对应的应付单号|
|已立账数量|被跟踪单据行已经立的应付账款数量|
|已立账价税合计|被跟踪单据行已经立的应付账款价税合计金额|
|应立账价税合计|根据新单价计算应该立的应付账款价税合计|
|应调整价税合计|应调整计税合计＝应立账价税合计－已立帐价税合计|
|调整单号|针对调价已经手工调整的应付账款对应的应付单号|
|已调整金额|已经调整的应付账款金额|
|未调整金额|剩余还需要调整的应付账款金额|
|跟踪汇总表（按跟踪单据行汇总）||
|单据别|显示跟踪的单据类别是采购订单还是收货单|
|单号|被跟踪单据的单号|
|原单价|被跟踪单据行的原始单价|
|新单价|被跟踪单据行的调价后单价|
|已立账数量|被跟踪单据行已经立的应付账款数量|
|已立账价税合计|被跟踪单据行已经立的应付账款价税合计金额|
|应立账价税合计|根据新单价计算应该立的应付账款价税合计|
|应调整价税合计|应调整计税合计＝应立账价税合计－已立帐价税合计|
|已调整金额|已经调整的应付账款金额|
|未调整金额|剩余还需要调整的应付账款金额|
