
# 功能描述

对本功能节点用于快速录入并批量提交审核借项账户单和贷项账户单。

# **业务规则**

*  定义应付单单据类型（必做）
*  定义供应商档案（必做）
*  定义货币档案（必做）
*  定义物料档案（必做）
*  定义税组合档案（必做）
*  定义立账条件档案
*  定义付款条件档案
*  定义业务员档案
*  定义部门档案
*  定义任务档案
*  定义项目档案
*  定义费用项目档案
*  定义预算专项档案
*  定义收支项目档案

# **栏目说明**

|栏目名称|说明|
|---|---|
|行页签||
|单据类型|选择当前应付单的单据类型，只能选择业务类型为“借项通知单”或“贷项通知单”的单据类型，参见：[应付单类型](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)|
|单号|显示或输入本收款单的编号。当您所选的单据类型定义为自动编号时，本栏目显示系统自动生成的单据编号；当您所选的单据类型定义为手工编号时，请在本栏目中输入单据编号。注意：单据编号不允许重复，在手工输入单号时需特别注意！|
|立账供应商位置|选择当前应付单所代表的应付账款的立账供应商位置|
|付款供应商位置|选择当前应付单所代表的应付账款的付款供应商位置|
|币种|选择当前应付单的核算币种|
|立账日期|选择应付单的立账日期，该日期只能在未结账的应付期间内|
|记账期间|选择应付单的记账期间，只能是未结账的应付期间|
|税组合|选择当前应付单所对应的税组合。|
|未税金额|单价不含税时，可以在单价、数量信息不完整时输入本栏目以反算得到其他栏目的数据|
|税额|记录当前单据的税额。点击栏目名弹出税明细画面显示详细的税别和税额|
|价税合计|单价含税时，可以在单价、数量信息不完整时输入本栏目以反算得到其他栏目的数据|
|总金额|显示当前应付单的总金额|
|状态|显示当前应付单的状态，点击该栏目弹出应付单表头状态画面显示详细的单据状态信息|
|其他页签||
|应付批|当系统提供应付批管理时，选择当前单据所属的应付批。参见：[应付批](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)|
|来源业务类型|选择产生当前债务的来源采购业务类型|
|优先等级|用于设置当前应付单按优先等级核销时的优先等级，分为A、B、C、D、E五级，A级最高，E级最低，参见：[应用专题－应付核销](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)|
|付款条件|记录当前应付单行所对应应付账款的[付款条件](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)，点击栏目名可查看收款条件的详细信息|
|业务员|记录当前应付单行业务所对应的销售业务员，点击栏目名可查看业务员的详细信息|
|部门|记录当前业务所对应的部门，点击栏目名可查看部门的详细信息|
|项目|记录当前应付单行业务所对应的项目，点击栏目名可查看项目的详细信息|
|任务|记录当前应付单行业务所对应的任务，点击栏目名可查看任务的详细信息|
|预算专项|选择当前应付单行业务所对应的预算专项，点击栏目名可查看预算专项的详细信息，参见：[预算专项](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)|
|收支项目|选择当前应付单行业务所对应的收支项目，点击栏目名可查看收支项目的详细信息，参见：[收支项目](http://10.16.2.212/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)|
|备注|输入备注信息|

# **按钮说明**

*  <应付单>：选中行，点击该按钮，弹出应付单维护页面，可维护应付单详细信息；
*  <批量打印>：选择行，点击该按钮，可进入批量打印；
*  <批量输出>：选择行，点击该按钮，可输出已选数据。
