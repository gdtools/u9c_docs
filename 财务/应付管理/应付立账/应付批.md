
# 功能描述

本节点用于定义和维护应付批，使用应付批可以带来如下便利：

*  实现应付单据的分组管理；
*  减少手工录入单据的失误；
*  有利于应付单据的快速检索；
*  为进入批的单据提供部分共享属性。

# **业务规则**

*  定义应付单类型档案
*  定义币种

# **栏目说明**

|栏目名称|说明|
|---|---|
|业务类型|选择当前应付批需要控制的业务类型。如果选择了业务类型，则进入该应付批的所有应付单的业务类型都必须为此业务类型；否则，应付批不控制批内应付单的业务类型|
|单据类型|选择当前应付批需要控制的单据类型。如果选择了单据类型，则进入该应付批的应付单的单据类型都必须为此单据类型；否则，应付批不控制批内应付单的单据类型|
|控制币种|选择当前应付批需要控制的单据核算币种。如果选择了控制币种，则进入该应付批的应付单的核算币种都必须与控制币种相同；否则，应付批不控制批内应付单的核算币种|
|控制金额|设置当前应付批批内单据的金额合计上限注意：如果设置了控制币种，则此控制金额为控制币种金额；否则，为本位币金额|
|控制张数|设置当前应付批批内单据的张数合计上限|
|累计金额|当前批内单据的总金额合计，此合计不包括作废单据注意：如果设置了控制币种，则此累计金额为控制币种金额；否则，为本位币金额。此外，金额累计时，正向应付单的金额按正数计算，负向应付单的金额按负数计算。|
|累计张数|当前批内单据的张数合计，此合计不包括作废单据|
|金额差异|控制金额与累计金额之差，显示还有多大金额的应付单可以进入当前应付批|
|张数差异|控制张数与累计张数之差，显示还有多少张应付单可以进入当前应付批|
|批状态|显示当前应付批的状态：打开：可以向该批提交新单据，可以修改、删除或作废批内单据，可以修改批参数；关闭：不能向该批提交新单据，不能修改、删除或作废批内单据，不能修改批参数；可以通过操作按钮分组中的关闭和取消关闭按钮更改批状态。|

# **按钮说明**

*  <操作-关闭>：核销：本操作用于关闭当前未关闭的应付批，应付批关闭后不能再向批提交单据，也不能手工修改或删除当前批内的任何单据；
*  <操作-取消关闭>：本操作用于打开当前已关闭的应付批。
*  <执行明细>：本操作用于查看所有当前应付批内的单据。
