
# 功能描述

查询到期的应付单。

# **业务规则**

*  已启用应付管理。

# **栏目说明**

|栏目名称|说明|
|---|---|
|查询条件||
|核算组织|参照组织档案录入|
|来源组织|参照组织档案录入|
|业务组织|参照组织档案录入|
|结算组织|参照组织档案录入|
|立账供应商|参照供应商档案录入|
|立账供应商位置|参照供应商档案位置录入|
|付款供应商|参照供应商档案录入|
|付款供应商位置|参照供应商档案位置录入|
|立账供应商分类|参照供应商分类录入|
|付款供应商分类|参照供应商分类录入|
|立账供应商地区|参照地区录入|
|付款供应商地区|参照地区录入|
|核币|参照币种录入|
|单据状态|选择单据状态：
   *  开立
*  核准中
*  已核准
|
|提前天数|录入提前的天数，系统将查找截至到（当前系统日期＋提前天数）那日到期的应付单默认为3|
|包含未立账应付单|确定满足截止时间的未立账应付单是否包括在查询范围内|
|查询结果||
|逾期天数|当前系统日期-到期日|
