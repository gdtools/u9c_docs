
# 功能描述

设置自动核销时的核销匹配规则。

# 业务规则

*  按勾选的维度值相同的进行核销。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头-基本||
|编码|录入应付核销匹配规则编码|
|名称|录入应付核销匹配规则名称|
|应用对象|选择应用对象，可选所有供应商、人工指定|
|单据核准时即时核销|是否选项|
|状态||
|表头-基本-表体||
|供应商|人工指定时，可以选择供应商|
|供应商分类|人工指定时，可以选择供应商分类|
|表头-匹配对象||
|业务对象|按业务对象相同的进行核销|
|结算组织|按结算组织相同的进行核销|
|部门|按部门相同的进行核销|
|业务员|按业务员相同的进行核销|
|收款员|按收款员相同的进行核销|
|项目|按项目相同的进行核销|
|任务|按任务相同的进行核销|
|料品|按料品相同的进行核销|
|收支项目|按收支项目相同的进行核销|
|其他实体扩展字段|按其他试题扩展字段相同的进行核销，取自“应付单表行实体的公共段”|

# 操作说明

通过菜单<a href="/detail/4858fc7fba5247b7af8d63d7299afc62">应付核销匹配规则设置</a>进入应付核销匹配规则界面；

*  操作步骤
 
   *  第1步：在基本页签定义规则试用的对象；
   *  第2步：在匹配对象页签定义维度；
   *  第3步：点击<保存>按钮，可保存该规则。
