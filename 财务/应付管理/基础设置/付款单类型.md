
# 功能描述

使用付款功能之前应该定义付款单类型。系统已经预置了一个付款单类型，用户可以根据管理要求进行增删改。

设置付款单类型的作用：

*  付款单的归类，并且可以给付款单提供一些默认参数；
*  可以根据单据类型配置不同的审批流。

# **业务规则**

*  定义编码规则

# **栏目说明**

|栏目名称|说明|
|---|---|
|付款单类型-基本||
|默认类型|可以指定一种付款单类型为默认类型，以便在未指定付款单类型的情况下，系统依然能够获取此信息。提示：只有一种付款单类型可以指定为默认类型|
|应收对账单方向|系统固定为“收回”，不可修改，表示在应收应付同列的应收对账单、应收明细账或应收余额表中付款单显示在收回栏目。|
|应付对账单方向|系统固定为“付款”，不可修改，表示在应付对账单、应付明细账或应付余额表中付款单显示在付款栏目。|
|到账后入账|控制付款单到账前是否可以核销|
|付款单类型-参数|参见公共描述|
