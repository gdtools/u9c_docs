
# 功能描述

本节点提供手工减少应付单余额的功能，可以维护和查看手工调整记录，同时可以查看系统生成的自动调整记录。

# **业务规则**

*  定义应付处理类型档案中的调整类型（必做）
*  定义应付单类型
*  定义自动调整限额

# **栏目说明**

|栏目名称|说明|
|---|---|
|应付单查找画面||
|<分组>供应商信息|本分组内可以选择付款供应商、付款供应商位置、立账供应商、立账供应商位置用于筛选应付单。其中，立账供应商和立账供应商位置可以多选；而付款供应商和付款供应商位置只能单选，并且用于生成应付调整单的供应商和供应商位置信息。|
|<分组>单据信息|本分组内可以选择单据类型、单号和总金额余额，允许多选，用做筛选应付单的条件|
|<分组>核算信息|本分组内可选择部门、业务员、项目、任务、备注等核算信息用做筛选应付单的条件|
|<分组>调整信息|本分组内可以选择币种、调整日期和记账期间用做筛选应付单的条件，同时也用于生成应付调整单表头相应信息。本分组内的栏目只能单选|
|调整方向|确定应付调整的方向，枚举值：借方：只选择借项应付单（负向应付单）贷方：只选择贷项应付单（正向应付单）空：不限制所选择应付单的借贷方向注意：如果供应商分组内选择的付款供应商位置的核销明细程度为“按供应商”，则本栏目必须在借贷方中选一项|

# **操作说明**

*  <手工调整>

手工调整是手工减少应付单余额的操作。

**操作前提：**系统中存在可调整的应付单

**操作步骤：**

点击应付管理->应付处理->应付调整按钮，进入应付调整功能。**具体步骤如下所示。**

第1步：点击新增按钮，弹出应付单查找画面；

第2步：在应付单查找画面输入选单条件和调整基本信息，参见：[应付单查找画面栏目说明](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/FI.AP.Process.APAdjust.APAdjust.htm" \l "%E6%9F%A5%E6%89%BE%E5%BA%94%E4%BB%98%E5%8D%95)

第3步：点击确定按钮到第4步，点击取消按钮返回第1步；

第4步：进入调整应付单画面，如果当前付款客户的核销明细程度为“按客户”，则在调整总金额栏目输入本次调整的总金额；否则，在列表中选择本次需要调整的记录，并在列表的调整总金额栏目输入被选择列表行记录对应的本次调整金额；

第5步：点击保存按钮保存调整记录，点击放弃按钮取消本次调整。

*  <作废>

本操作用于作废当前应付调整单。

**操作前提：**系统中存在已保存的应付调整单

**操作步骤：**点击应付管理->应付处理->应付调整->作废按钮，输入作废原因，完成作废操作。

*  <调整单>

本操作用于查看当前应付调整单的明细。

**操作前提：**系统中存在已保存的应付调整单

**操作步骤：**

点击应付管理->应付处理->应付调整->调整单按钮，进入调整单卡片，查看调整单明细信息。

*  <[交易分录](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)>

本操作用于查看或维护应付调整单通过自动会计平台（AAI）生成的交易分录。参见[交易分录](http://10.16.226.67/U9C/help/zh-CN/Content/PO/PO.AAI.TranEntryMain.htm)。

**操作前提：**系统中存在已保存的应付调整单

**操作步骤：**

点击应付管理->应付处理->应付调整->交易分录按钮，可以维护交易分录。

*  <[损益单](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)>

本操作用于查看应付调整单对应的损益单的信息。

**操作前提:**当前应付调整单存在损益记录.

**操作步骤:**

点击应付管理->应付处理->应付调整->损益单按钮，进入损益单卡片，查看损益单明细信息。

*  <[供应商状况](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)>

本操作用于按供应商查询汇总的财务余额信息，及最近发生业务的日期。

**操作步骤:**点击应付管理->应付处理->应付调整->供应商状况按钮，查看供应商的相关信息。
