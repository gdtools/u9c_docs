
# 功能描述

本节点用于处理债务转移的相关事务，主要功能点如下：

*  提供多种转移对象
*  转移结果可提交审核
*  可以联查相关应付单和交易分录
*  可以作废债务转移单

# 业务规则

*  定义应付处理类型档案中的债务转移类型（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|表头-基本-新生单据合并|由于系统支持同时选择同一供应商的多张应付单转移，则在转入新单据时，有两种处理方式：不选择本栏目：由被选择的应付单一对一生成多张新的应付单选择本栏目：将本次选择的全部应付单合并生成一张新的应付单|
|表头-供应商|当转移对象不包含供应商时，无需关注本页签当转移对象包含供应商时，在本页签中指定转入立账供应商/位置、转入付款供应商/位置|
|表头-其他|本页签用于在转移部门、业务员、项目、任务、来源单据时指定转入方，如果转移对象不包括上述几项，则无需关注本页签|
|表头-物料签|本页签用于在转移料品时显示转出、转入料品的详细信息|
|表头-单据类型|本页签用于在转移单据类型和业务类型时显示转出、转入单据类型的详细信息，期初应付质保金支持转移为应付贷项账户单|
|表体-转移总金额|本栏目用于输入当前行本次需要转移的总金额，输入的金额不能大于当前行的可处理金额|

# 按钮说明

*  <作废>：生成的债务转移单，可点击<作废>按钮，作废单据；
*  <转移单>：点击该按钮，弹出债务转移卡片画面，可查看详细债务转移情况；
*  <交易分录>：点击该按钮，可查看债务转移单交易分录信息；
*  <损益单>：点击该按钮，可查看债务转移单汇兑损益单情况；
*  <相关功能-交易分录设置>：点击该按钮，导航至【基础设置:基础设置(组织):自动会计:分录模板】
*  <相关功能-应付单>：点击该按钮，导航至[应付单](/detail/149bb31339b340c48c0f5b0686fd374d)

# 操作说明

**操作前提：**系统中存在有可处理余额的应付单。

**操作步骤：**

点击应付管理->应付处理->债务转移按钮，进入债务转移功能画面。**具体步骤如下所示：**

第1步：点击新增按钮，弹出应付单查找画面；

[应付单查找画面](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)

|栏目名称|说明|
|---|---|
|分组-转移对象|本分组内的栏目用于确定转移对象和提供筛选应付单的条件。可选的转移对象有：
   *  立账供应商/位置
*  付款供应商/位置
*  部门
*  业务员
*  项目
*  任务
*  单据类型
提示：上述转移对象被选中时为单选，未被选中时为范围式，不论单选或范围，都是选择应付单的条件|
|分组-转移信息|本分组内的项目提供转移的基本信息，包括组织、币种、转移日期和记账期间，系统会提供默认值，并提供参照修改|

第2步：在应付单查找画面选择债务转移对象、输入选单条件和转移基本信息；

第3步：点击确定按钮到第4步，点击取消按钮返回第1步；

第4步：进入债务转移画面，输入本次债务转移的相关信息，具体需要输入的内容参见：[债务转移画面栏目说明](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/FI.AP.Process.APDT.APDT.htm#%E5%80%BA%E5%8A%A1%E8%BD%AC%E7%A7%BB)

第5步：点击保存按钮保存调整记录，同时会减少原应付单的余额，生成一张新应付单；点击放弃按钮取消本次调整。
