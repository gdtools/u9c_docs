
# 功能描述

本节点提供汇兑损益相关功能，主要功能点如下：

*  计算期末汇兑损益
*  查看期末汇兑损益计算记录
*  查看期初汇兑损益回冲记录
*  查看业务处理时的汇兑损益记录
*  删除汇兑损益计算单

# **业务规则**

*  定义应付处理类型档案的汇兑损益单据类型（必做）
*  定义币种（必做）
*  定义汇率（必做）

# **按钮说明**

*  <回冲单>：点击该按钮，可查看当前汇兑损益单生成的回冲单，注意此按钮可用的条件：
 
   *  1.应付参数设置里区分已实现汇兑损益为true；
   *  2.应付参数设置里期初冲回未实现汇兑损益为true；
   *  举例说明：2月有未实现的汇兑损益，期末汇兑损益计算后，系统会生成一张金额是20的汇兑损益单001；同时还会生成一张金额为-20的回冲单002，这张回冲单的记账日期是2012-03。在汇兑损益单001上点回冲单可以查到002；
*  <交易分录>：本操作用于查看或维护汇兑损益生成的交易分录。

# **操作说明**[]()

*  计算汇兑损益

本操作用于计算期末汇兑损益，业务处理过程中产生的汇兑损益由系统自动计算，本节点可以查看这些汇兑损益计算单。提供调度功能，可以自动计算汇兑损益并提高效率。

**操作前提：**

参数AR402＝是，即期末需要计算汇兑损益；

登录日期对应的会计期间大于等于参数AR404期末计算频度所定义的汇兑损益计算期间；

**操作步骤：**

点击应付->程序->汇兑损益按钮，进入期末汇兑损益计算功能。

**具体步骤如下所示。**

第1步：点击新增按钮，弹出汇率查看画面，可以查看本次需要计算汇兑损益的单据币种和汇率；

第2步：点击转暂付按钮，弹出未核销标准用途收、付款单画面，将需要参与汇兑损益计算的收付款单转为暂付款；

第3步：在汇率查看画面点击计算按钮到第3步，点击取消按钮返回；

第4步：弹出汇兑损益计算结果画面，显示汇兑损益计算结果，可以在查看方式栏目选择从不同的维度查看汇兑损益计算结果，可以选择的查看方式有：按币种（默认）、按单据、按单据类型和按供应商四种；

第5步：点击关闭按钮进入应付汇兑损益列表画面，列示本次计算生成的汇兑损益计算单；

第6步：双击列表记录可以查看汇兑损益计算单。
