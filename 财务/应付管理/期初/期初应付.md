
# 功能描述

本节点用于在应付系统启用时录入期初应付数据。本节点采用卡片录入的方式，将应付系统启用前存在的应付业务以应付单的形式录入U9C应付系统，并通过自动会计平台（AAI）生成到U9C总账系统，以便这些业务的所有后续变化都在系统的控制之中。

# **业务规则**

*  参数设定，参见应付期初相关参数
*  定义应付单类型档案（必做）
*  定义币种档案（必做）
*  定义供应商档案（必做）
*  定义料品档案（必做）
*  定义应付批
*  定义立账条件
*  定义付款条件
*  定义费用项目
*  定义税别、税组合
*  定义部门、业务员档案
*  定义项目任务档案

# **栏目说明**

|栏目名称|说明|
|---|---|
|表头-基本||
|批号|当系统提供应付批管理时，选择当前单据所属的应付批。参见：[应付批](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)|
|单据类型|选择当前应付单的单据类型，单据类型决定了单据的业务类型和后续处理，期初应付单可以选择任意应付单据类型。参见：[应付单类型](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)|
|单号|显示或输入本付款单的编号。当您所选的单据类型定义为自动编号时，本栏目显示系统自动生成的单据编号；当您所选的单据类型定义为手工编号时，请在本栏目中输入单据编号。注意：单据编号不允许重复，您在手工输入单号时需特别注意！|
|供应商|选择当前应付单所代表的应付账款的立账供应商|
|供应商位置|选择当前应付单所代表的应付账款的立账供应商位置|
|记账期间|期初应付单的记账期间固定为空|
|来源类型|选择产生当前应付债务的来源采购业务类型|
|匹配层级|期初应付单的匹配层级固定为“不匹配”|
|来源组织|当前债务的来源采购业务所属的组织|
|税组合|选择当前应付单所对应的税组合，该税组合将做为所有本单所有单据行税组合的默认值|
|状态|显示当前应付单的状态，点击该栏目弹出应付单表头状态画面显示详细的单据状态信息|
|表头-供应商||
|<分组>立账|本分组显示与债务确立相关的供应商信息|
|<分组>付款|本分组显示与款项支付相关的供应商信息|
|表头-核算||
|立账条件|选择当前应付单的[立账条件（应付）](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)，此立账条件将做为当前应付单所有单行立账条件的默认值|
|付款条件|选择当前应付单的[付款条件](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)，此付款条件将做为当前应付单所有单行付款条件的默认值|
|优先等级|用于设置当前应付单按优先等级核销时的优先等级，分为A、B、C、D、E五级，A级最高，E级最低|
|项目|选择当前应付业务所属的项目，此栏目将做为当前应付单所有单行所对应项目的默认值|
|任务|选择当前应付业务所属的任务，此栏目将做为当前应付单所有单行所对应任务的默认值|
|表头-发票||
|发票号|记录当前应付单所记载的应付款项对应的采购发票号|
|发票日期|记录采购发票的发票日期|
|收票日期|记录收到采购发票的日期|
|费用发票|选择当前应付单所记载的事项是否为费用，勾选本栏目则此应付单只能选择费用项目所对应的物料|
|资产发票|选择当前应付单所记载的是否与资产采购相关，勾选本栏目则此应付单只能记录资产类物料的采购或与资产相关的费用|
|单价含税|当前单据行上输入的单据是否是含税单价，参见：[单价](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/FI.AP.Process.APPeriod.APPeriodBegin.htm" \l "%E5%8D%95%E4%BB%B7)|
|业务组织|当前债务的来源采购业务对应的采购组织|
|结算组织|启用资金结算模块时，需指定后续付款的结算组织|
|表体-行||
|料品|选择当前行所针对的料品，有关料品的详细信息在料品页签录入。|
|单价|由单价含税栏目确定本栏目内输入单价的业务意义：单价含税：系统认为单体行页签上输入的单价为含税单价单价不含税：系统任务单体行页签上输入的单价为未税单价|
|未税金额|单价不含税时，可以在单价、数量信息不完整时输入本栏目以反算得到其他栏目的数据|
|税额|当前单据行业务所发生的税额。点击该栏目弹出税明细画面显示详细的税别和税额|
|价税合计|单价含税时，可以在单价、数量信息不完整时输入本栏目以反算得到其他栏目的数据|
|总金额|未税金额、税额和费用的金额合计|
|总金额余额|显示当前单据的总金额余额，点击该栏目弹出应付单总金额余额查询画面显示详细的余额信息|
|状态|显示当前应付单行的状态，点击该栏目弹出应付单表行状态画面|
|表体-料品||
|品名|由单行选择的料品带出，如果您选择的是一次性物料，则本栏目可以手工修改|
|物料分类体系|当预付对象为物料分类时，记录物料分类对应的物料分类体系|
|物料分类|当预付对象为物料分类时，记录物料分类名称|
|表体-量价||
|税组合|维护当前单据行的税组合，参见：[单头税组合](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/FI.AP.Process.APPeriod.APPeriodBegin.htm" \l "%E7%A8%8E%E7%BB%84%E5%90%88)|
|税额|当前单据行业务所发生的税额。点击该栏目弹出税明细画面显示详细的税别和税额|
|费用项目|显示当前由单据行业务发生的应由我方负担的相关费用，点击该栏目弹出[费用录入画面](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/FI.AP.Process.APPeriod.APPeriodBegin.htm" \l "%E8%B4%B9%E7%94%A8%E5%BD%95%E5%85%A5%E7%94%BB%E9%9D%A2)，可以维护相关费用信息|
|分组－本币|该分组内的本币金额允许手工修改|
|表体-核算||
|预付对象|当单据的业务类型为预付款时，记录当前应付单行所对应的预付对象|
|预算专项|选择当前应付单行业务所属的预算专项，参见：[预算专项](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)|
|收支项目|选择当前应付单行业务所属的收支项目，参见：[收支项目](http://10.16.226.67/U9C/help/zh-CN/Content/FI/AP/Function/javascript:void(0);)|
|到期日|输入当前单据行的应付款项的到期日，点击该栏目弹出期初分期付款行数据画面，维护分期付款信息|
|预计付款日期|输入预计将要支付当前应付款项的日期|
|表体-量价-总费用||
|费用项目|参照采购费用项目注意：当前费用项目是否需要计算税额|
|税组合|当前税组合默认从费用项目带出注意：在费用项目中，可选择与当前费用项目相关的税组合|
|核币总费用|在此栏目输入总费用，如果该费用项目需计税，系统会自动将该费用额拆分为未税费用和费用税额|
|本币总费用|根据核币总费用自动计算|
