
# 功能描述

本功能节点主要提供如下内容：

*  可以对请款单确认付款，并最终完成付款；
*  可以对请款单整单确认付款，或针对请款单的部分供应商确认付款；
*  可以一次对多张请款单确认付款；
*  自动执行保留。

# 业务规则

*  定义请款确认单单据类型（必做）
*  定义结算方式（必做）
*  定义银行账号

# 按钮说明

*  <付款>：

本操作可以自动生成后续的付款单或委托付款通知单。

**操作前提：**请款确认单相关信息输入正确、完整，且已保存。

**操作步骤：**

点击付款按钮，系统根据请款确认画面中的信息生成已核准状态的付款单或结算组织的委托付款通知单。

*  <取消付款>：

若操作错误，或有跳票发生，或核销错误，可以对请款确认单取消确认付款。

**操作前提：**请款确认单有完成付款。

**操作步骤：**

点击取消付款按钮，若符合取消付款条件，系统自动删除此请款确认单已生成的付款单或结算组织的委托付款通知单；否则系统抛错。

*  <自动分摊>：

本操作用于修改单体行页签的[总金额]后，不必手工维护请款单页签和请款明细页签中的数据，系统可自动根据比例将修改后的[总金额]分摊到此行对应的请款单页签和请款明细页签中的相关金额。

**操作前提：**请款确认单行页签中输入的各行[总金额]都大于0。

**操作步骤：**

点击自动分摊按钮，系统根据行页签中请款确认单各行的[总金额]，按比例分摊到请款确认单请款单页签和请款明细页签中各行的相关确认金额。

*  <追溯查询-对应付款单>：

本操作用于查看当前请款确认单对应生成的付款单的具体信息。

**操作前提：**当前请款确认单已完成付款。

# 操作说明

本操作用于对请款单确认付款。

**操作前提：**

有已审核的请款单；

请款单未确认付款。

**操作步骤：**

点击应付管理->付款->请款付款按钮,可以对请款单确认付款。

**具体场景和步骤如下所示：**

第1步：点击应付管理->付款->请款确认按钮，进入请款确认单主画面；

第2步：在请款确认单头、单行输入必要的信息，如请款对象、供应商、结算方式、金额等；

第3步：点击请款确认单行页签的“选单”或请款单页签中的“请款单”，在选单列表中选择对哪些请款单进行确认付款，并输入确认金额，点击“确定”后，系统自动生成请款确认单的请款明细数据；

第4步：对请款确认单的内容无疑义后，点击保存；

第5步：点击付款按钮，系统自动生成已核准状态的付款单或委托付款通知单。
