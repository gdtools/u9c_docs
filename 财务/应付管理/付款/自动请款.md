
# 功能描述

本节点维护自动请款的规则：

*  可以指定筛选应付单的过滤条件；
*  默认以预计付款日、币种、业务组织、结算组织、业务员、部门作为分单条件；
*  可以生成调度计划。

# **业务规则**

*  定义请款单据类型（必做）

# **栏目说明**

|栏目名称|说明|
|---|---|
|申请日期依据|可选择：执行日、固定日|
|<分组>供应商|确定请款对象的供应商范围，包括付款供应商和立账供应商|
|来源组织|确定应付单所属的组织|
|业务组织|确定应付单对应的业务组织|
|单据类型|可选范围：发票、贷项通知单、贷项账户单对应的单据类型|
|应付单范围|确定生成自动请款的应付单的范围|
|到期日|确定生成自动请款的应付单的到期日范围可选择：执行日、固定日执行日：还需确定[执行日前×日]、[执行日后×日]固定日：还需确定固定日范围|
|立账日期|确定生成自动请款的应付单的立账日期范围可选择：执行日、固定日执行日：还需确定[执行日前×日]、[执行日后×日]固定日：还需确定固定日范围|
|记账期间范围|确定生成自动请款的应付单的记账期间范围|
|预计付款日期|确定生成自动请款的应付单的预计付款日期范围可选择：执行日、固定日执行日：还需确定[执行日前×日]、[执行日后×日]固定日：还需确定固定日范围|
|<分组>其他|确定生成自动请款的应付单的其他核算信息，作为过滤的条件|
