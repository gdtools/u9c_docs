
# 功能描述

税务发票模块提供增值税发票取数设置，可根据账簿、自定义取值。

# 业务规则

*  启用税务发票（必做）
*  启用总账

# 栏目说明

|栏目名称|说明|
|---|---|
|账簿|参照主账簿选择，若账簿有多版本，需要选择账簿版本|
|销项税|选择取值方式，可选择科目余额或者科目发生额。|
|进项税|选择取值方式，可选择科目余额或者科目发生额|
|进项税转出|选择取值方式，可选择科目余额或者科目发生额。|
|免抵退货物应退税额|选择取值方式，可选择科目余额或者科目发生额|
|纳税检查应补缴税额|选择取值方式，可选择科目余额或者科目发生额。|
|简易征收办法计算的应纳税额|选择取值方式，可选择科目余额或者科目发生额|
|按简易征收办法计算的纳税检查应补缴税额|选择取值方式，可选择科目余额或者科目发生额。|
|应纳税减征税务|选择取值方式，可选择科目余额或者科目发生额|

设置取数公式画面

|栏目|说明|
|---|---|
|会计科目|参照会计科目选择|
|余额取数类型|选择余额取值方式，可选择期初余额或者期末余额|
|币种方式|默认本币|
|币种|默认本币币种|
|取数方式|选择取值方式，可选择科目余额或者借贷发生额|
|期间|显示年度、会计期间|
|包含未记账|是否包含未记账凭证|
|包含调整凭证|是否包含调整凭证|
