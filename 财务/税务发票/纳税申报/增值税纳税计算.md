
# 功能描述

本功能可进行各个期间的增值税纳税情况，根据设置的取数方式，系统自动计算应纳税额。

# 业务规则

*  启用税务发票（必做）
*  设置增值税纳税取数设置

# 栏目说明

|栏目名称|说明|
|---|---|
|纳税申报期间|参照纳税社保期间录入，|
|取值会计期间|参照会计期间录入，选择取数的会计期间|
|销项税本期数|根据取数公式自动计算，可修改|
|销项税本年数|根据取数公式自动计算，不可修改|
|进项税本期数|根据取数公式自动计算，可修改|
|进项税本年数|根据取数公式自动计算，不可修改|
|上期留抵税额|录入上期留抵税额|
|进项税额转出本期数|根据取数公式自动计算，可修改|
|进项税额转出本年数|根据取数公式自动计算，不可修改|
|纳税检查应补缴税额本期数|根据取数公式自动计算，可修改|
|纳税检查应补缴税额本年数|根据取数公式自动计算，不可修改|
|应抵扣税额合计|默认计算：上期留抵税额+本期进项税额-进项税额转出-免抵退税应退税。可更改。|
|实际抵扣税额本期数|录入实际抵扣本期数|
|实际抵扣税额本年数|自动计算实际抵扣额本年数|
|应纳税额本期数|自动计算，应纳税额=当期销项税额-当期进项税额|
|期末留抵税额|本期的进项税额大于本期的销项税额的差额|
|简易征收办法计算的应纳税额本期数|根据取数公式自动计算，可修改|
|简易征收办法计算的应纳税额本年数|根据取数公式自动计算，不可修改|
|按简易征收办法计算的纳税检查应补缴税额本期数|根据取数公式自动计算，可修改|
|按简易征收办法计算的纳税检查应补缴税额本年数|根据取数公式自动计算，不可修改|
|应纳税减征税务本期数|根据取数公式自动计算，可修改|
|应纳税减征税务本年数|根据取数公式自动计算，不可修改|
