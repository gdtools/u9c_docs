
# 功能描述

税务发票模块提供了发票勾选功能，具体有：

*  与税务云链接，可直接对发票进行勾选认证
*  勾选认证后，不可撤销

# 业务规则

*  启用税务发票（必做）
*  需要配置税务云相关参数

# 栏目说明

|栏目名称|说明|
|---|---|
|纳税人识别号码|显示纳税人识别号码|
|税局认证期间|默认当期期间|
|税局认证时间|默认当前时间|
|发票类型|显示发票类型|
|开票日期|显示开票日期|
|发票代码|显示发票代码|
|发票号码|显示发票号码|
|名称|显示名称|
|税额|显示税额|
|价税合计|显示价税合计|
|备注|显示备注|

# 按钮说明

<提交>：发起税局认证勾选。
