
# 功能描述

税务发票模块提供了收票管理，具体功能有：

*  批量收票
*  纸票扫码验真
*  电票批量导入
*  发票认证
*  税局勾选
*  发票与业务单据关联

# 业务规则

*  启用税务发票（必做）
*  使用电票导入、纸票验真时需要配置税务云相关参数

# 按钮说明

<认证>：发票认证。

<批量收票>：通过应付单拉取单据类型的发票的数据，勾选后，生成增值税发票

<扫码验真生单>：点击按钮，弹出扫码弹出，连接扫码枪，扫码后，点击导入发票，发送税务云进行纸票验真，验真通过后生成增值税发票。

<电子发票导入>：点击按钮，弹出电子发票导入选择的文件路径，确定文件后，发送税务云进行验证，验真通过后，生成增值税发票。

<税局勾选>：发票税局勾选。
