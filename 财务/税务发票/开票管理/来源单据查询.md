
# 功能描述

提供可参照开票的来源单据，包括：

*  销售订单
*  出货单
*  预出货单
*  退货单
*  应收单
*  应收单费用明细

# 业务规则

*  启用税务发票（必做）

# 操作说明

查看销售发票行来源单据

*  当销售发票行是参照来源单据生成的，则可以点击销售发票行列表下的相关查询－来源单据按钮，查询发票行的来源单据；
*  在弹出的来源单据列表画面，点单据号的链接，可以查询来源单据的卡片。

查看来源单据卡片

*  在来源单据行列表，点单据号的链接，可以查询来源单据的卡片。

查看销售发票卡片

*  在销售发票行列表，点发票号的链接，可以查询发票的卡片。
