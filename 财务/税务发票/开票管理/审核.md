
# 功能描述

*  提供发票的批量审核与批量弃审功能。

# 业务规则

*  启用税务发票（必做）
*  存在已提交或者已审核的发票

# 栏目说明

|栏目名称|说明|
|---|---|
|单据状态|显示单据状态|
|发票别|显示发票别|
|单据号|显示单据号|
|开票日期|显示开票日期|
|记账期间|显示记账期间|
|核算币种|显示核算币种|
|开票客户名称|显示发票购买方客户名称|
|开票客户位置名称|显示发票购买方客户位置名称|
|未税金额|显示未税金额|
|税额|显示税额|
|业务类型|显示业务类型，增值税发票、普通发票、增值税专用发票等；|
|红字发票|是否红字发票|

# 按钮说明

<查询>：用户按照自定义查询，过滤列表数据。

# 操作说明

审核

*  第1步：查询需要审核的发票
*  第2步：选中需要审核的发票
*  第3步：点操作菜单中的“审核”，执行批量审核。

弃审

*  第1步：查询需要弃审的发票
*  第2步：选中需要弃审的发票
*  第3步：点操作菜单中的“弃审”，执行批量弃审。
