
# 功能描述

提供可参照开票的来源单据，包括：

*  提供显示发票清单、发票清单打印、输出功能；
*  按照发票行显示；
*  按照发票头汇总显示。

# 业务规则

*  启用税务发票（必做）

# 栏目说明

报表画面

|栏目名称|说明|
|---|---|
|组织|显示当前组织|
|单据类别|显示单据类别|
|单据号|显示单据号|
|开票客户名称|显示发票购买方客户名称|
|开票客户位置名称|显示发票购买方客户位置名称|
|是否输出税控|显示是否已经输出税控|
|未税金额|显示未税金额|
|税额|显示税额|
|价税合计|显示价税合计|

查询条件

|栏目|说明|
|---|---|
|是否输出到税控|查询条件，勾选发票是否已经输出到税控|
|审核日期|查询条件，输入发票审核日期|
|税控发票号|查询条件，输入税控发票号|
|发票类型|查询条件，枚举下拉，发票类型|
|发票号|查询条件，录入发票号码|
|开票日期|查询条件，录入开票日期|
|客户|查询条件，参照客户档案录入|
|客户位置|查询条件，参照客户位置录入|
|业务员|查询条件，参照业务员档案录入|
|部门|查询条件，参照部门档案录入|
