
# 功能描述

在税务发票系统中，允许按照料品的分类汇总开票，可以按照客户及料品的销售分类设置开票料品的料号、品名、规格。

# 业务规则

*  启用税务发票（必做）
*  定义客户档案（必做）
*  定义料品的分类体系以及销售分类（必做）
*  定义料品档案（必做）

# 栏目说明

汇总开票设置画面

|栏目名称|说明|
|---|---|
|客户|参照客户档案录入；|
|分类体系|选择料品的分类体系；|
|分类编码|选择料品的分类；|
|料号|输入开票的料号；|
|品名|输入开票料品的品名，默认输入的料号对应的品名，允许修改；|
|规格|输入开票料品的规格。|
