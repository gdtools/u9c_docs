
# 功能描述

*  当客户将发票退回后，可以使用退票功能进行处理。
*  本功能引导用户一步步完成退票操作，根据被退回发票的状态，决定作废还是红冲，并且可以在后台自动找出对应的退货单据

# 业务规则

*  启用税务发票（必做）
*  存在已审核的发票。
*  发票未被作废。
*  发票未被红冲。

# 栏目说明

列表画面

|栏目名称|说明|
|---|---|
|发票别|显示发票别|
|单据号|显示单据号|
|开票日期|显示开票日期|
|记账期间|显示记账期间|
|核算币种|显示核算币种|
|开票客户名称|显示发票购买方客户名称|
|开票客户位置名称|显示发票购买方客户位置名称|
|未税金额|显示未税金额|
|税额|显示税额|
|总金额|显示价税合计|
|税控发票号|显示输出到税控的发票号码|
|单据状态|显示单据状态|
|财务关闭|若该发票立账的单据已经核销，自动勾选为财务关闭|
|退票|显示是否退票|
|退票原因|显示退票原因|
|已开红票|当发票为蓝字发票时，是否已经开具红票|
|作废|显示是否作废|
|业务类型|显示业务类型，增值税发票、普通发票、增值税专用发票等；|
|红字发票|是否红字发票|

退票处理步骤一画面

|栏目|说明|
|---|---|
|发票别|显示退回发票的发票别|
|发票号|显示退回发票的发票号|
|处理方法|显示退票的处理方法：作废红冲|
|退票原因|录入退票原因|

退票处理步骤二（作废处理）画面

|栏目|说明|
|---|---|
|是否有退货单|是:系统自动找出被退回发票相关的退货单否：不处理退货单|
|作废日期|录入作废日期，默认为系统日期|
|作废原因|录入作废原因|

退票处理步骤二（红冲处理）画面

|栏目|说明|
|---|---|
|是否有退货单|是:系统自动找出被退回发票相关的退货单否：不处理退货单|
|红票发票别|显示红票发票别，等于被退发票的发票别|
|红票发票簿|若进行发票簿管理，则选择红票的发票簿|
|红票发票号|录入红票发票号|
|红票开票日期|录入红票开票日期|
|红票记帐期间|录入红票记帐期间|

# 按钮说明

<查询>：用户按照自定义查询，过滤列表数据。

<退票>：发起退票操作，按照导航画面一步一步操作。

<退票详情>：查看已退发票的退票处理详细情况。

<红字发票>：查看已退发票对应的红字发票。
