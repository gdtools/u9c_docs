
# 功能描述

税务发票模块提供了与航天金税系统的接口，具体有：

*  销售发票导出
*  作废发票导出
*  取得税控发票号

# 业务规则

*  启用税务发票（必做）
*  录入销售发票已经审核
*  开票方式＝“税控开票”的销售发票才允许输出到金税系统

# 栏目说明

|栏目名称|说明|
|---|---|
|接口类型|选择对接金税的发票接口|
|发票别|参照发票别录入，可录入范围|
|业务类型|枚举下拉，选择普通发票或者增值税专用发票|
|发票号|录入发票号码，可录入范围|
|开票日期|录入开票日期范围|
|包括已经输出的发票|是否包含已经输出的发票|

# 操作说明

销售发票导出：将指定范围的销售发票输出到税控接口文件中。

*  主画面的“接口类型”选择“销售发票导出”；
*  点发票列表按钮，查询准备输出的销售发票；本步骤可以省略。
*  在主画面则直接点击执行按钮；或者发票列表画面选择要输出的发票后，点击执行按钮。
*  在弹出窗口选择输出文件存储的路径，然后点保存。

作废发票导出：将作废发票输出到税控接口文件中。

*  主画面的“接口类型”选择“作废发票导出”；
*  点发票列表按钮，查询准备输出的作废发票；本步骤可以省略。
*  在主画面则直接点击执行按钮；或者发票列表画面选择要输出的作废发票后，点击执行按钮。
*  在弹出窗口选择输出文件存储的路径，然后点保存。

取得税控发票号：从税控接口文件中读取税控发票号。

*  主画面的“接口类型”选择“取得税控发票号”；
*  点发票列表按钮，选择税控输出的文件，然后点确定按钮，可弹出发票列表画面，在发票列表画面可以查看税控输出文件中的发票，选择要读取税控发票号的发票后，点击执行按钮，系统将税控发票号写到销售发票上。
*  也可不执行上一步骤，直接在主画面则直接点击执行按钮，然后选择税控输出的文件，然后点确定按钮，系统将税控发票号写到销售发票上。
