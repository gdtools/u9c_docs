
# 功能描述

本功能可查看关联交易明细发生，从账簿、会计科目、期间、关联企业的维度，分析关联交易的发生额。

从当前组织及与当前组织有业务关系的凭证中抽取符合关联方交易的凭证展示的明细查询列表中

# 业务规则

*  启用IPO助手（必做）
*  定义关联企业设置（必做）

# 栏目说明

|栏目|说明|
|---|---|
|表头||
|账簿|默认为主账簿，可选择报告账簿|
|版本|默认所选账簿当前生效的账簿版本，可选择其他版本|
|期间范围|默认为当前期间，可选择其他期间|
|表行||
|账簿|显示账簿名称|
|会计科目编码|显示关联交易发生的会计科目编码|
|科目名称|显示会计科目名称|
|会计期间|显示发生的会计期间|
|凭证类型|显示凭证类型|
|凭证状态|显示凭证状态|
|凭证号|显示凭证号码|
|借方发生额|按照会计科目、期间、关联方为分析维度，显示借方发生额|
|贷方发生额|按照会计科目、期间、关联方为分析维度，显示贷方发生额|
|关联企业|显示关联方名称|
|关联类型|显示关联类型|
|对应组织|显示关联方档案上对应的组织|
|对应客户|显示关联方档案对应的客户|
|对应供应商|显示关联方档案上对应的供应商|

# 按钮说明

<获取数据>：获取数据，初始化加载所选表头条件数据。

<查询>：用户按照自定义条件过滤列表数据。
