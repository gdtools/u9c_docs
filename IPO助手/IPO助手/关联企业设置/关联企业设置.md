
# 功能描述

本功能从主体独立性的角度关注企业经营过程中的关联方情况，采取树状图可视化的方式查看关联关系图。

左图为关联关系的树状图，通过双击树状图的某一行，可在右边明细页签中查看该关联方详情档案。

# 业务规则

*  启用IPO助手（必做）

# 栏目说明

|栏目|说明|
|---|---|
|本方企业|默认为当前登录组织，只有法人组织才可显示IPO助手|
|编码|录入关联企业编码|
|名称|录入关联企业名称|
|关联类型|枚举下拉，母公司、子公司、同受控、其他，产品上提供的关联方有限，若所属的关联类型系统无法满足，可选择其他，然后将具体的关系录入备注中|
|生效|当前关联方档案是否生效|
|生效日期|录入生效日期|
|失效日期|录入失效日期|
|控股比例|录入控股比例，注意，同一被控主体，控股比例之和不能超过100%|
|上级公司|参照关联方档案录入，选择所属上级|
|下级公司|参照关联方档案录入，选择下级公司，上级公司、下级公司只能填写一个，且两者不能同时为空|
|对应组织|参照组织档案录入|
|对应客户|参照客户档案录入|
|对应供应商|参照供应商档案录入|
|备注|录入备注|

# 按钮说明

<数据拉取>：若启用全球合并，则会将全球合并中属于当前组织的投资与被投资关系拉取同步，自动生成关联方档案。

<关联企业关系图>：可查看关联企业网状图，可按照个人需要设置关系图显示。
