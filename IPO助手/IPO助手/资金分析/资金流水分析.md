
# 功能描述

*  本功能提供资金流水分析，可按照期间查询资金的收支情况，并且会标记大额资金的流出、流入，重点分析了大额资金的支出构成

# 业务规则

*  启用IPO助手（必做）
*  定义大额资金（必做）
*  启用现金银行（必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|期间|参照会计期间输入，默认所有，可更改|
|部门|参照部门档案录入，默认所有，可更改|
|是否大额|默认所有资金类型，可更改，|

资产流水综合分析

|栏目|说明|
|---|---|
|日期|显示业务日期|
|银行名称|显示银行名称|
|银行账号|显示银行账号|
|是否大额|显示是否大额|
|借方|显示借方发生额，标识流入|
|贷方|显示贷方发生额，标识支出|
|余额|显示余额|

大额资金支出构成

|栏目|说明|
|---|---|
|收支项目|显示资金的收支项目|
|发生额|显示发生额|
