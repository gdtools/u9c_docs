
# 功能描述

*  本功能提供资金存量分析
*  可按照资金类别分析当前组织下资金的构成情况
*  可按照各个组织的资金占用情况
*  可分析近三年资金存量趋势

# 业务规则

*  启用IPO助手（必做）
*  定义资金合理浮动上下限（必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|组织|参照组织档案录入，默认当前组织，可更改个|
|币种|参照币种档案|
|会计期间|参照会计期间|

资金存量分析

|栏目|说明|
|---|---|
|资金类别|显示资金类别构成|
|余额|显示各项资金的余额|

组织资金存量余额

|栏目|说明|
|---|---|
|部门|显示组织，与当前组织有核算关系的组织会同步显示|
|余额|显示余额|

资金存量趋势

|栏目|说明|
|---|---|
|期间|显示近三年的期间|
|资金存量|显示各期间主账簿的各类别的资金余额之和|
|资金合理浮动上限|计算36期间主账簿上现金类、银行存款类余额之和/36 平均值，再用平均值计算上限，具体比例通过参数设置中资金存量浮动确定，上限=平均（1+比例）|
|资金合理浮动下限|计算36期间主账簿上现金类、银行存款类余额之和/36 平均值，再用平均值计算下限，具体比例通过参数设置中资金存量浮动确定，下限=平均（1-比例）|
