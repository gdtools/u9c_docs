
# 功能描述

*  本功能提供资产负债综合分析，
*  从总计的维度分析上期数、本期数以及变动数
*  标记变动差异过大的部分

# 业务规则

*  启用IPO助手（必做）
*  定义资产负债分析（必做）

# 栏目说明

查询条件

|栏目|说明|
|---|---|
|账簿|参照账簿输入，默认选择主账簿，可修改|
|期间|参照会计期间输入，默认所有，可更改|

资产负债分析

|栏目|说明|
|---|---|
|项目|显示资产负债分析中的项目|
|本期数|本期期末数，取报表项目上本期期末余额|
|本期期末数占总资产比例|本期期末数/总资产|
|上年同期数|上期期末数：取所选期间上一期期末余额（年-1）|
|上年同期占总资产比例|上一期期末数/总资产|
|本期期末较上年变动比例|（本期期末-上年期末）/上年期末，若超出定义的合理变动范围，标记红色|
