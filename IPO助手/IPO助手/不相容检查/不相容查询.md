
# 功能描述

本功能提供不相容查询功能，可按照监控对象，执行日期等进行查看。

支持穿透到明细业务单据。

# 业务规则

*  启用IPO助手（必做）
*  定义不相容定义（必做）

# 栏目说明

|栏目|说明|
|---|---|
|表头||
|监控对象|参照监控对象，必填字段|
|起始日期|选择执行起始日期，默认当月1号，可修改|
|结束日期|选择执行结束日期，默认当月最后一天，可修改|
|表行||
|不相容编码|显示不相容编码|
|不相容名称|显示不相容名称|
|监控对象|显示监控对象|
|组织编码|显示组织编码|
|组织名称|显示组织名称|
|单据编号|显示业务单据编号，若监控对象为凭证，则显示凭证号|
|制单日期|显示制单日期|
|执行结束日期|显示执行结束日期|
|制单人|显示制单人|
|付款人|显示付款人|
|审核人|显示审核人|
|确认人|显示确认人|

# 按钮说明

<获取数据>：根据表头所选条件，获取初始化数据。

<查询>：用户按照自定义条件选择，过滤列表数据。
