
# 功能描述

本功能用来查询设备转每个期间中的异常频率，来判断该设备的生命周期。

# 业务规则

*  系统启用了设备管理系统；(必做)

# 操作说明

通过菜单[设备生命周期查询](/detail/1ee0fe5b1d28409b85ef2ee958ef2c8f)进入设备生命周期查询界面；

*  操作步骤
 
   *  第1步：选择查询条件；
   *  第2步：保存查询条件；
   *  第3步：获取查询结果。
