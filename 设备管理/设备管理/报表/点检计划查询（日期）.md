
# 功能描述

本功能主要是用来查询点检计划（日期）的。

# 业务规则

*  系统启用了设备管理系统；(必做)

# 栏目说明

用户也可以自定义查询条件。

|栏目名称|说明|
|---|---|
|查询条件||
|计划模板|选择一个需要查询的计划模板（必填）|
|计划点检日期|选择一个需要查询的日期（必填）|
|查询结果||
|期间|显示期间|
|计划模板|显示计划模板编号|
|设备编号|显示操作员|
|日期|显示日期下的点检状态|

**按钮说明**

*  <查询方案>：点击列表下的查询按钮，可以定义查询方案，包括查询条件、栏目及排序。具体内容可参见公共操作部分的查询方案。
*  <列宽调整>：点击列表下的列宽调整按钮，可以调整列表栏目显示及打印的宽度。

# 操作说明

通过菜单[点检计划查询（日期）](/detail/4bf8cf85c994438eb2d1565a4e656fa9)进入点检计划查询（日期）界面；

*  操作步骤
 
   *  第1步：选择查询条件；
   *  第2步：保存查询条件；
   *  第3步：获取查询结果。
