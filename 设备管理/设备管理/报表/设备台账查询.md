
# 功能描述

本功能主要是用来查询设备台账的。

# 业务规则

*  系统启用了设备管理系统；(必做)

# 栏目说明

用户也可以自定义查询条件。

|栏目名称|说明|
|---|---|
|查询条件||
|查询方式|枚举：会计期间、日期|
|会计期间|如果查询方式为会计期间，选择一个需要查询的会计期间（必填）|
|日期期间|如果查询方式为日期，选择一个要查询的日期（必填）|
|物权组织|参照组织机构，选择一个需要查询的组织（必填）|
|查询结果||
|设备编码|显示设备编码|
|设备主分类编码|显示设备主分类编码|
|料号|显示料号|
|期初数量|显示期初数量|
|本期收入|显示本期收入|
|本期发出|显示本期发出|
|期末数量|显示期末数量|

**按钮说明**

*  <查询方案>：点击列表下的查询按钮，可以定义查询方案，包括查询条件、栏目及排序。具体内容可参见公共操作部分的查询方案。
*  <列宽调整>：点击列表下的列宽调整按钮，可以调整列表栏目显示及打印的宽度。

# 操作说明

通过菜单[设备台账查询](/detail/99a92fe3e17c4d8788483b09ac3851d9)进入设备台账查询界面；

*  操作步骤
 
   *  第1步：选择查询条件；
   *  第2步：保存查询条件；
   *  第3步：获取查询结果。
