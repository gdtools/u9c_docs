
# 功能描述

设置设备入账的信息。

# 业务规则

*  系统启用了设备管理系统；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|参照选择单据类型|
|单号|系统自动编码，不支持手动设置|
|单据状态|系统根据单据进度自动变更单据状态|
|日期|默认当前日期，可手动修改|
|设备期间|参照选择设备期间|
|入账部门|参照选择部门|
|物权组织|默认当前组织不支持修改|
|使用组织|参照组织结构选择使用组织|
|库管员|参照业务员选择对应的库管员|
|表体||
|行号|自动生成行号|
|设备|参照设备卡片选择设备|
|料号|料号根据设备自动带出|
|存储地点|参照选择存储地点，不支持与使用位置同时录入|
|库位|根据存储地点自动带出|
|使用位置|参照选择使用位置，不支持与存储地点同时录入|
|责任部门|参照部门选择责任部门|
|责任人|根据设备自动带出责任人，支持手动修改|
|设备状态|参照选择设备当前状态|
|扩展字段|扩展内容|

# 操作说明

通过菜单《设备管理>设备管理>日常管理>设备入账》进入设备入账界面；

*  操作步骤
 
   *  第1步：选择单据类型；
   *  第2步：选择期间、入账部门、组织等相关信息；
   *  第3步：录入表体设备相关信息；
   *  第4步：保存设备入账。
