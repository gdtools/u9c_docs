
# 功能描述

用于设置设备调拨的信息。

# 业务规则

*  系统启用了设备管理系统；
*  已经定义了设备档案；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|参照选择单据类型|
|单号|系统自动编码，不支持手动设置|
|日期|默认当前日期，可手动修改|
|状态|系统根据单据进度自动变更单据状态|
|调出使用组织|默认当前组织|
|调入使用组织|参照组织结构选择调入使用组织|
|物权组织|默认当前组织不支持修改|
|设备期间|默认当前期间|
|业务部门|参照部门选择|
|业务员|参照业务员选择对应的库管员|
|备注|备注内容|
|表体||
|行号|自动生成行号|
|设备|参照设备卡片选择设备|
|料号|料号根据设备自动带出|
|调出位置|参照设备自动带出|
|调入位置|参照位置选择|
|调出责任部门|参照选择使用位置，不支持与存储地点同时录入|
|调入责任部门|参照部门|
|调出责任人|根据调出部门自动带出调出负责人|
|调入责任人|根据设备自动带出责任人，支持手动修改|
|调出存储地点|根据调出部门自动带出存储地点|
|调入存储地点|参照存储地点|
|调出库位|根据调出部门自动带出库位|
|调入库位|参照库位选择|
|扩展字段|扩展内容|

# 操作说明

通过菜单《设备管理>设备管理>日常管理>设备调拨》进入设备调拨界面；

*  操作步骤
 
   *  第1步：选择单据类型；
   *  第2步：选择日期、调入使用组织等相关信息；
   *  第3步：录入表体设备相关信息；
   *  第4步：保存设备调拨。
