
# 功能描述

本功能用来对设备状态的变更进行记录，修改设备当下的状态。设备状态变更是指设备由于验收移交、闲置封存、移装调拨、借用租赁、报废处理等情况引起的设备信息的变动。

# 业务规则

*  系统启用了设备管理系统；
*  已经定义了设备档案；
*  定义设备状态档案；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|参照选择设备变更单据类型|
|单号|系统自动编码，不支持手动设置|
|日期|默认当前日期，可手动修改|
|设备期间|默认当前期间，支持手动修改|
|使用组织|参照组织机构|
|物权组织|默认当前组织不支持修改|
|业务部门|参照部门选择|
|业务员|参照业务员|
|单据状态|系统根据单据进行状态变更|
|表体||
|行号|自动生成行号|
|设备|参照设备卡片|
|料号|根据设备自动带出，不支持手动修改|
|变更前设备状态|根据设备自动带出，不支持手动修改|
|变更后设备状态|参照设备状态选择|
|变更前物权组织专用|根据设备自动带出，不支持手动修改|
|变更后物权组织专用|是否变更后物权组织专用|
|使用部门|根据设备自动带出|
|使用位置|根据设备自动带出|
|使用责任人|根据设备自动带出|
|使用存储地点|根据设备自动带出|
|使用库位|根据设备自动带出|
|行状态|根据设备自动带出|
|扩展字段|扩展内容|

# 操作说明

通过菜单[设备状态变更](/detail/8f065add06e14e8799cb24a8d13e0562)进入设备状态变更界面；

*  操作步骤
 
   *  第1步：选择单据类型；
   *  第2步：选择使用组织、业务部门等相关信息；
   *  第3步：录入表体设备相关信息；
   *  第4步：保存设备状态变更。
