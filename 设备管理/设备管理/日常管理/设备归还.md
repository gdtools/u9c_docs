
# 功能描述

用于已经领用设备的使用组织，在归还设备的时候填写的信息。

# 业务规则

*  系统启用了设备管理系统；
*  已经定义了设备档案；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|参照选择单据类型|
|单号|系统自动编码，不支持手动设置|
|日期|默认当前日期，可手动修改|
|设备期间|默认当前期间，支持手动修改|
|还入组织|参照组织机构|
|还入部门|参照组织机构|
|物权组织|默认当前组织不支持修改|
|业务部门|参照部门选择|
|业务员|参照业务员|
|状态|系统自动更新|
|表体||
|行号|自动生成行号|
|设备|参照设备卡片|
|料号|根据设备自动带出，不支持手动修改|
|设备状态|根据设备自动带出，支持手动修改|
|还入位置|根据设备自动带出，支持手动修改，使用位置和使用存储地点不能同时填写|
|还入责任人|根据设备自动带出，支持手动修改|
|还入存储地点|参照存储地点选择，使用位置和使用存储地点不能同时填写|
|还入库位|参照库位选择|
|设备状态|参照设备状态|
|原使用组织|根据设备自动带出|
|原使用部门|根据设备自动带出|
|原使用位置|根据设备自动带出|
|原使用责任人|根据设备自动带出|
|原使用存储地点|根据设备自动带出|
|原使用库位|根据设备自动带出|
|扩展字段|扩展内容|

# 操作说明

通过菜单[设备归还](/detail/f192ce99a56a44e2850855b9692559ae)进入设备归还界面；

*  操作步骤
 
   *  第1步：选择单据类型；
   *  第2步：选择还入组织、部门等相关信息；
   *  第3步：录入表体设备相关信息；
   *  第4步：保存设备归还。
