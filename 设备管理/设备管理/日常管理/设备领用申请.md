
# 功能描述

用于使用组织或部门在申请设备领用时填写的申请单信息。

# 业务规则

*  系统启用了设备管理系统；
*  已经定义了设备档案；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|单据类型|参照选择单据类型|
|单号|系统自动编码，不支持手动设置|
|日期|默认当前日期，可手动修改|
|使用组织|参照组织机构|
|物权组织|默认当前组织不支持修改|
|使用部门|参照部门|
|单据状态|根据单据的进度自动变更|
|业务部门|参照部门选择|
|业务员|参照业务员|
|表体||
|行号|自动生成行号|
|料品|参照料品档案选择|
|品名|根据料品自动带出|
|规格|根据料品自动带出|
|申请数量|手动设置申请的料品数量|
|已领数量|系统自动筛查该组织该料品已经被申请领用过得数量|
|单位|系统自动带出|
|使用位置|参照位置|
|使用责任人|参照业务员|
|使用存储地点|根据料品系统自动带出，支持手动修改|
|使用库位|自动带出库位|
|扩展字段|扩展内容|

# 操作说明

通过菜单[设备领用申请](/detail/3b4cbf92f6384c1cbc0638b5faa9a954)进入设备领用申请界面；

*  操作步骤
 
   *  第1步：选择单据类型；
   *  第2步：选择使用组织、部门等相关信息；
   *  第3步：录入表体设备相关信息；
   *  第4步：保存设备领用申请。
