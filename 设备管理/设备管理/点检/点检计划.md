
# 功能描述

本功能用来设置点检计划。

# 业务规则

*  系统启用了设备管理系统；
*  定义计划模板；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|录入编码|
|名称|录入名称|
|状态|系统自动变更|
|点检路线|参照点检路线|
|业务日期|默认当前日期，支持手动修改|
|业务员|参照业务员|
|描述|描述内容|
|表体—人员计划||
|行号|自动生成|
|责任部门|参照部门|
|点检员|参照业务员|
|从日期|默认当前日期，支持手动修改|
|到日期|默认当前日期，支持手动修改|
|备注|备注内容|

# 操作说明

通过菜单[点检计划](/detail/4bc06e42e1f54bc2a002bfd2bf1ad275)进入点检计划界面；

*  操作步骤
 
   *  第1步：录入编码、名称，选择点检路线等信息；
   *  第2步：录入子表信息
   *  第3步：保存点检计划。
