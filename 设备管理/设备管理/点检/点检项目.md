
# 功能描述

点检项目是记录当前设备的点检规范，包括点检的设备和检查类型等。

# 业务规则

*  系统启用了设备管理系统；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|录入点检项目的编码|
|名称|录入点检项目的名称|
|检查类型|选择项目检查的类型，枚举：压力、温度、流量、泄露、润滑、异声、振动、磨损、松动|
|描述|描述内容|
|表体||
|生效|设置是否立即生效|
|生效日期|默认当前日期，支持手动修改|
|失效日期|可修改失效日期|

# 操作说明

通过菜单[点检项目](/detail/ff18b6e6c65d4577bc43700b4175ab11)进入点检项目界面；

*  操作步骤
 
   *  第1步：录入编码、名称等信息；
   *  第2步：选择检查类型；
   *  第3步：保存点检项目。
