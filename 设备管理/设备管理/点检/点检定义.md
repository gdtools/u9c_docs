
# 功能描述

本功能用来对设备点检和设备检查的内容等方面信息进行定义。检查内容相当于设备检查工艺，便于各种类型设备点检卡建立时选择，便于规范检查工作、检验项目等，主要是设备点检信息的实时信息。

# 业务规则

*  系统启用了设备管理系统；
*  定义料品档案；
*  定义设备分类；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|录入点检定义的编码|
|名称|录入名称|
|点检分类|选择点检分类，枚举：日常点检、重要点检、精密点检|
|设备物料|参照料品档案，选择料品（设备物料和设备主分类不能同时填写）|
|设备主分类|参照设备分类档案（设备物料和设备主分类不能同时填写）|
|状态|单据状态|
|描述|描述内容|
|表体||
|行号|自动生成|
|点检项目|参照点检项目选择|
|检查类型|根据点检项目自动带出检查类型|
|部件|手动录入部件|
|周期|选择检查的周期，枚举：每日、每周、每月、每季、每年|
|点检标准|手动录入点检的标准|
|生效|设置是否立即生效|
|备注|备注内容|

# 操作说明

通过菜单[点检定义](/detail/411b4ed40101413d9221fd3f8704bc16)进入点检定义界面；

*  操作步骤
 
   *  第1步：录入编码、名称等信息；
   *  第2步：选择点检分类、设备物料/设备主分类；
   *  第3步：录入子表信息
   *  第4步：保存点检定义。
