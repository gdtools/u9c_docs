
# 功能描述

本功能主要是用来设置点检完工和记录设备故障的。

# 业务规则

*  系统启用了设备管理系统；
*  定义计划模板；
*  定义点检计划；

# 栏目说明

|栏目名称|说明|
|---|---|
|计划点检日期|显示计划点检日期|
|设备编号|显示设备编号|
|点检项目|显示点检项目名称|
|点检责任部门|显示点检责任部门|
|点检责任人|显示点检责任人|
|是否点检完成|显示点检完成状态|
|点检结果|显示点检结果|
|部件|显示部件名称|
|实际点检日期|显示实际点检日期|
|点检结果描述|显示点检结果描述内容|

# 按钮说明

*  <查询>：通过设置查询条件，筛出点检计划。
*  <完工>：导航到点检完工窗口，确定点检计划完成。
*  <设备故障录入>：导航到设备故障申报窗口，进行故障填报。

# 操作说明

通过菜单[点检完工](/detail/50b90b7ed21d4f38960b0d1e4c2a88ed)进入点检完工界面；

*  操作步骤
 
   *  第1步：选择点检计划；
   *  第2步：点击完工
   *  第3步：录入点检日期、点检人等相关信息；
   *  第4步：确定，点检完成。
