
# 功能描述

本功能用来设置点检路线的具体信息，方便后续相关设置选择路线。

# 业务规则

*  系统启用了设备管理系统；
*  定义设备档案；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|录入编码|
|名称|录入名称|
|描述|描述内容|
|表体||
|行号|自动生成|
|设备|参照涉恶比档案选择|
|料品|根据设备自动带出|
|品名|根据设备自动带出|
|使用位置|根据设备自动带出|
|点检分类|选择一种点检类别，枚举：日常点检、重要点检、精密点检|
|点检顺序|手动录入点检的顺序|
|生效|设置是否立即生效|
|备注|备注内容|

# 操作说明

通过菜单[点检路线](/detail/64df2981172b4c47be23ccdd4832ca40)进入点检路线界面；

*  操作步骤
 
   *  第1步：录入编码、名称等信息；
   *  第2步：录入子表信息
   *  第3步：保存点检路线。
