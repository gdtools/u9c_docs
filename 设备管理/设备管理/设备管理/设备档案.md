
# 功能描述

用来设置设备档案。主要功能：

设备主档信息；

设备分类；

# 业务规则

*  系统启用了设备管理系统；
*  定义设备分类

# 栏目说明

|栏目名称|说明|
|---|---|
|设备信息||
|设备料号|参照料品，选择设备料号|
|设备品名|根据设备料号参照的料品，系统自动带出设备品名|
|设备规格|根据设备料号参照的料品，系统自动带出设备规格|
|设备编码|参照设备卡片，选择设备编码|
|档案信息||
|编号|录入编号，不允许重复|
|名称|录入设备名称|
|类别|参照档案分类选择类别|
|生效|是否生效|
|生效日期|默认当前日期|
|失效日期|支持修改失效日期|
|描述信息|描述内容|

# 操作说明

通过菜单《设备管理>设备管理>设备管理>设备档案》进入设备档案界面；

*  操作步骤
 
   *  第1步：选择设备料号；
   *  第2步：选择设备编码；
   *  第3步：录入设备编码、名称、类别等信息；
   *  第4步：保存设备档案。
