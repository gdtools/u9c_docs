
# 功能描述

设备卡片是用来记录设备信息的，可以记录设备的基本信息，设备的状态、设备使用部门、使用组织等信息。

# 业务规则

*  系统启用了设备管理系统；（必做）

# 栏目说明

基本信息

|栏目名称|说明|
|---|---|
|基本信息||
|设备编号|录入设备编号|
|卡片状态|根据单据状态自动变更|
|料号|参照料品档案，选择需要建卡的料号|
|品名|根据选择的料号自动带出料品名称|
|规格|根据选择的料号自动带出料品规格|
|设备单位|参照计量单位选择设备单位|
|设备主分类|参照设备分类选择主分类|
|物权组织|默认当前组织，参照组织结构可以修改组织|
|维修组织|默认当前组织，参照组织结构可以修改组织|
|设备来源|枚举：自由、租用|
|资产编号|自动带出资产编号|
|特种装备|标注是否是特种设备|
|物权组织专用|是否是物权组织专用|
|描述||
|状态信息||
|入账|是否入账|
|设备状态|根据料号自动带出设备当前的状态|
|使用组织|自动带出当前使用组织|
|存储地点|自动带出当前存储地点|
|库位|自动带出当前库位|
|使用位置|自动带出使用位置|
|使用部门|默认带出使用部门|
|责任人|参照选择责任人|
|备注信息||
|购入日期|选择设备购入的日期|
|购置值||
|出厂编号|录入设备的出场编号|
|建账日期|默认当前日期|
|出厂日期|选择设备出厂日期|
|使用截止日期|选择设备使用截止日期|
|已使用时长（月）|录入已经使用设备的时长|
|可使用时长（月）|录入设备还可以使用的时长|
|制造商|参照选择设备的制造商|
|供应商|参照选择设备的供应商|

# 按钮说明

*  <固定资产导入>：支持从固定资产卡片导入设备信息到设备卡片。
*  <附属设备导入>：支持从固定资产卡片附属设备导入设备信息到设备卡片。
*  <设备维护记录初始化>：支持维护设备维修记录。
*  <设备参数录入-参数初始化>：支持维护设备的初始化参数值。
*  <设备参数录入-参数日常录入>：支持日常使用设备的参数维护。
*  <相关查询-设备参数绑定查询>：支持查询设备相关参数。
*  <相关查询-设备档案查询>：支持查询设备的档案。
*  <相关查询-设备分类绑定查询>：支持查询设备分类。
*  <审批参数>：设置涉恶比档案的审批参数。

通过菜单<a href="/detail/5f483e5552a84f929b7513c06de0b04a">设备卡片</a>进入设备卡片界面；

*  操作步骤
 
   *  第1步：录入设备基本信息；
   *  第2步：保存设备卡片。
