
# 功能描述

设备参数绑定就是用来对设备进行参数设置。

# 业务规则

*  系统启用了设备管理系统；（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|自动生成编码|
|设备编码|参照设备卡片，选择设备编码|
|设备品名|自动带出设备名称|
|设备料号|自动带出设备料号|
|设备规格|自动带出设备规格|
|设备主分类|自动带出|
|设备来源|自动带出|
|物权组织|自动带出|
|维修组织|自动带出|
|设备供应商|自动带出|
|设备制造商|自动带出|
|描述|自动带出|
|参数信息||
|行号|自动编号|
|参数|参照设备参数|
|单位|根据设备参数自动带出|
|标准值|手动录入当前参数的标准值|
|上限|手动录入当前参数的上限值|
|下限|手动录入当前参数的下限值|
|参数累计值|手动录入当前参数的累计值|
|参数初始值|手动录入当前参数的初始值|
|备注|备注信息|
|生效|是否生效|

# 按钮说明

*  <快速复制到其他设备>：通过此操作可以快速将当前设备参数复制给其他设备卡片。

# 操作说明

通过菜单《设备管理>设备管理>设备管理>设备参数绑定》进入设备参数绑定界面；

*  操作步骤
 
   *  第1步：选择设备编码；
   *  第2步：录入参数信息；
   *  第3步：保存设备参数绑定。
