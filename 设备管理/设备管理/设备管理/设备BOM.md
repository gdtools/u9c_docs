
# 功能描述

设备BOM是用来设置设备的明细。

# 业务规则

*  系统启用了设备管理系统；（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|系统自动生成编码|
|设备料号|参照料品，选择设备料号|
|设备规格|根据设备料号参照的料品，系统自动带出设备规格|
|设备品名|根据设备料号参照的料品，系统自动带出设备品名|
|BOM用途|设置当前料品的BOM用途，通过枚举可以选择|
|生效日期|默认当前日期，支持修改|
|失效日期|支持修改失效日期|
|生效|默认生效|
|描述|描述内容|
|备品配件||
|行号|自动生成行号|
|备品配件|参照料品选择配件|
|品名|根据备品配件参照的料品，自动带出品名|
|规格|根据备品配件参照的料品，自动带出规格|
|用量单位|根据备品配件参照的料品，自动带出单位，支持修改|
|数量|手动修改数量|
|备注|备注信息|

# 按钮说明

*  <快速复制到其他设备>：通过此操作可以快速将当前设备BOM信息复制给其他设备卡片。

# 操作说明

通过菜单《设备管理>设备管理>设备管理>设备BOM》进入设备BOM界面；

*  操作步骤
 
   *  第1步：选择设备料号；
   *  第2步：选择BOM用途；
   *  第3步：录入备品配件；
   *  第4步：保存设备BOM。
