
# 功能描述

设备分类绑定是用来对设备分类中的设备进行绑定或删除绑定。

# 业务规则

*  系统启用了设备管理系统；（必做）

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|设备分类|参照选择设备分类|
|表体||
|设备号|设备卡片编号|
|料号|自动带出当前分类下的所有料号|
|品名|自动带出当前分类下的所有品名|
|规格|自动带出当前分类下的所有料品规格|
|设备主分类|自动带出|
|设备来源|自动带出|
|状态|自动带出|
|物权组织|自动带出|
|使用组织|自动带出|
|使用部门|自动带出|
|责任人|自动带出|
|使用位置|自动带出|
|存储地点|自动带出|
|库位|自动带出|
|制造商|自动带出|
|供应商|自动带出|
|是否特种设备|自动带出|

# 按钮说明

*  <查询>：可以通过设置查询方案进行查询。
*  <批量绑定>：支持批量绑定设备到设备分类。
*  <删除绑定>：支持删除已经绑定到设备分类的设备。

# 操作说明

通过菜单《设备管理>设备管理>设备管理>设备分类绑定》进入设备分类绑定界面；

*  操作步骤
 
   *  第1步：选择设备分类；
   *  第2步：查询已经绑定的设备。
