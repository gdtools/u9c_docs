
# 功能描述

日常工作中，一些大修，改造项目需要由外协单位来完成，本模块主要记录外包维修及付款情况。

# 业务规则

*  系统启用了设备管理系统；(必做)
*  定义设备档案（必做）
*  定义外协料品
*  定义税组合

# 栏目说明

|单据类型|参照请修单据类型|

|单据状态|根据单据进度系统自动变更状态|
|维修部门|参照部门选择|

|是否完工||

|业务员|参照业务员|
|备注|备注信息|

|计划维修时间|默认当前日期，支持手动修改|
|计划完工时间|默认当前日期，支持手动修改|
|建议完工时间|默认当前日期，支持手动修改|
|开始维修时间|默认当前日期，支持手动修改|
|完工工时|默认0，手动修改工时|
|责任人|支持手动修改，参照业务员|
|物权组织|根据设备卡片系统自动带出|
|使用组织|根据设备卡片系统自动带出|

|扩展字段|扩展内容|

**按钮说明**

*  <完工>：导航至完工画面。
*  <取消完工>：已经完工的单据,可进行取消完工的操作.
*  <故障信息>：导航至设备故障申报页面。
*  <设备参数>：导航到设备参数维护页面。
*  <批量生单>：导航到批量生单页面，选择多个作业、物料等生成外修单。
*  <任务清单全览>：导航到任务清单全览页面。
*  <备品配件全览>：导航到备品配件全览页面。

# 操作说明

通过菜单[外修单](/detail/354b7eab2d0748149d02cdc91c6d6904)进入外修单界面；

*  操作步骤
 
   *  第1步：选择单据类型、日期等相关信息；
   *  第2步：录入子表信息；
   *  第3步：保存外修单。
