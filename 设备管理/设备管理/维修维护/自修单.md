
# 功能描述

本功能主要是记录根据设备年度维修计划并结合车间现场生产情况提出设备大中修时间和大中修项目的维修申请单，便于车间安排生产计划及调整现场实物摆放。

# 业务规则

*  系统启用了设备管理系统；(必做)
*  定义维修项目

|故障日期|默认当前日期，支持手动修改|
|计划维修时间|默认当前日期，支持手动修改|

|责任人|根据设备卡片自动带出|

|使用组织|根据设备卡片系统自动带出|

|使用库位|根据设备卡片系统自动带出|

|作业行号|自动生成，可以手动修改|
|设备编码|根据设备信息中的设备卡片自动带出设备编码|

|名称|自动带出|

|单位|参照计量单位选择单位|

|耗用数量|手动填写耗用数量|
|杂发数量|自动带出|

**按钮说明**

*  <完工>：导航至完工画面。
*  <取消完工>：已经完工的单据,可进行取消完工的操作.
*  <故障信息>：导航至设备故障申报页面。
*  <设备参数>：导航到设备参数维护页面。
*  <批量生单>：导航到批量生单页面，选择多个作业、物料等生成外修单。
*  <任务清单全览>：导航到任务清单全览页面。
*  <备品配件全览>：导航到备品配件全览页面。
*  <杂发单查询>：导航至杂发单查询的页面。

# 操作说明

通过菜单[自修单](/detail/e91a3c643bb44b2d8a016374342e8198)进入自修单界面；

*  操作步骤
 
   *  第1步：选择单据类型、日期等相关信息；
   *  第2步：录入子表信息；
   *  第3步：保存自修单。
