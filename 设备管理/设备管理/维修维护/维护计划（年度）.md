
# 功能描述

本功能用来根据年度来定制设备的年度维修维护的计划。

# 业务规则

*  系统启用了设备管理系统；
*  定义设备台账；

# 栏目说明

|栏目名称|说明|
|---|---|
|主表||
|编码|显示维护计划的编码|
|维护计划模板|显示维护计划模板名称|
|年度|显示年度|
|评估日期|显示评估日期|
|表体—基本||
|设备卡片|显示设备卡片|
|维护项目|显示维护项目|
|作业|显示作业|
|已转月计划|显示已转月计划|
|维修组织|显示维修组织|
|维修部门|显示维修部门|
|维修商|显示维修商|
|计划维修日期|显示计划维修日期|
|维修策略|显示维修策略|
|上次计划维修时间|显示上次计划维修时间|

# 按钮说明

*  <查询>：不同的查询条件，查询结果也不相同；
*  <评估>：导航至评估计划的页面；
*  <转月计划>：导航至转月计划页面。

# 操作说明

通过菜单[维护计划（年度）](/detail/006802ea34be4cf3a76a10052e821589)进入维护计划（年度）界面；

*  操作步骤
 
   *  第1步：评估维修计划；
   *  第2步：查询维护计划；
   *  第3步：维护年度计划转月计划。
