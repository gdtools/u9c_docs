
# 功能描述

本功能用来根据设备的维护周期月度来定制设备的月维修维护计划。

# 业务规则

*  系统启用了设备管理系统；
*  定义设备台账；

# 栏目说明

|栏目名称|说明|
|---|---|
|主表||
|编码|显示维护计划的编码|
|维护计划模板|显示维护计划模板名称|
|年度|显示年度|
|月|显示月份|
|评估日期|显示评估日期|
|表体—基本||
|设备卡片|显示设备卡片|
|维护项目|显示维护项目|
|作业|显示作业|
|已转维修单|显示已转维修单|
|维修组织|显示维修组织|
|维修部门|显示维修部门|
|维修商|显示维修商|
|计划维修日期|显示计划维修日期|
|维修策略|显示维修策略|
|上次计划维修时间|显示上次计划维修时间|

# 按钮说明

*  <查询>：不同的查询条件，查询结果也不相同；
*  <评估>：导航至评估计划的页面；
*  <转维修单>：选择单据后，点击此按钮可将单据转为维修单。

# 操作说明

通过菜单[维护计划（月度）](/detail/5c0aa20779464ae693602348f8132006)进入维护计划（月度）界面；

*  操作步骤
 
   *  第1步：评估维修计划；
   *  第2步：查询维护计划；
   *  第3步：维护计划转维修单。
