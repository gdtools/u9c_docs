
# 功能描述

本功能用来根据设备的参数和状态来制定维修维护的计划。

# 业务规则

*  系统启用了设备管理系统；
*  定义设备台账；

# 按钮说明

*  <查询>：不同的查询条件，查询结果也不相同；
*  <评估>：导航至评估计划的页面；
*  <转维修单>：点击此按钮将选择的单据转至维修单。

# 操作说明

通过菜单[维护计划（设备状态）](/detail/4eabdb7d4e9b4f04847cd1fbd90065c6)进入维护计划（设备状态）界面；

*  操作步骤
 
   *  第1步：评估维修计划；
   *  第2步：查询维护计划；
   *  第3步：维护计划转维修单。
