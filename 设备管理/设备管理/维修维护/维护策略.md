
# 功能描述

本功能是用来设置维护策略。

# 业务规则

*  系统启用了设备管理系统；

# 栏目说明

|栏目名称|说明|
|---|---|
|编码|录入策略编码|
|名称|录入策略名称|
|策略类型|选择类型，枚举：参数状态、时间周期、参数步长|
|参数|参照设备参数|
|单位|当参数设置为“时间周期”，单位为天。不支持手动编辑|
|参数关系|选择参数关系，枚举：大于等于、小于等于、大于、小于、等于|
|参数值|手动录入值|
|步长|手动录入|
|生效|是否生效|
|描述|描述内容|

# 操作说明

通过菜单[维护策略](/detail/12b8959f6d7043239ac6ea63e246b90f)进入维护策略界面；

*  操作步骤
 
   *  第1步：录入编码、名称等相关信息；
   *  第2步：选择策略类型；
   *  第3步：保存维护策略。
