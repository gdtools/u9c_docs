
# 功能描述

主要是维护一些维修项目明细信息。

# 业务规则

*  系统启用了设备管理系统；
*  定义设备分类；
*  定义料品档案；
*  定义维护项目；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|自动生成编码|
|名称|录入项目名称|
|设备分类|参照设备分类|
|设备物料|参照料品档案|
|负责人|参照业务员|
|生效|设置单据是否生效|
|表体—基本||
|行号|自动生成|
|维护项目清单号|参照维护项目|
|维护项目清单|根据项目清单号自动带出|

# 操作说明

通过菜单[维护项目清单](/detail/39a407c3c13544fd9d96f1a3f1e9ceb7)进入维护项目清单界面；

*  操作步骤
 
   *  第1步：录入名称等相关信息；
   *  第2步：录入子表信息；
   *  第3步：保存维护项目清单。
