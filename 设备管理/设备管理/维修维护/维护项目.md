
# 功能描述

主要是维护一些项目相关信息。

# 业务规则

*  系统启用了设备管理系统；
*  定义维护策略；

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|编码|录入项目编码|
|名称|录入项目名称|
|设备主分类|参照设备分类|
|设备物料|参照料品档案|
|维护策略|参照维修策略|
|维护组织|默认当前组织，支持手动修改|
|部门|手动录入值|
|维护商|手动录入|
|业务员|是否生效|
|描述|描述内容|
|表体—基本||
|行号|自动生成|
|作业|手动录入|
|生效日期|默认当前日期，支持修改|
|失效日期|默认当前日期，支持修改|
|生效|是否生效，默认生效|
|表体—备品配件||
|备品配件行号|自动生成|
|备品配件|参照料品|
|备品配件名|根据配件自动带出|
|备品配件规格|根据配件自动带出|
|单位|根据配件自动带出，支持参照计量单位修改|
|数量|手动输入数量|

# 按钮说明

<全部配件明细>：导航至全部配件明细弹窗页面。

<参照设备BOM>：导航至设备BOM弹窗页面。

# 操作说明

通过菜单[维护项目](/detail/283d3781f7af4a70b8a8c938ca8cc464)进入维护项目界面；

*  操作步骤
 
   *  第1步：录入编码、名称等相关信息；
   *  第2步：录入子表信息；
   *  第3步：保存维护项目。
