
# 功能描述

主要是维护维修计划模板信息。

本功能用来对设备维护和保养的进行计划、维修方法、所需物资等方面信息进行定义。

# 业务规则

*  系统启用了设备管理系统；
*  定义设备分类；
*  定义料品档案；
*  定义维护项目；

|行号|自动生成|

|料号|根据设备卡片自动带出|
|物权组织|根据设备卡片自动带出|
|使用组织|根据设备卡片自动带出|

|责任人|根据设备卡片自动带出|

# 操作说明

通过菜单[维护计划模板](/detail/5ef002b15b6f401f9e9b03dde0264a23)进入维护计划模板界面；

*  操作步骤
 
   *  第1步：录入名称等相关信息；
   *  第2步：录入子表信息；
   *  第3步：保存维护计划模板。
