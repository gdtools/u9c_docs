
# 功能描述

本功能是根据设备的自修单来生成杂发单，及生成杂发单结果的查询。

# 业务规则

*  系统启用了设备管理系统；
*  定义料品档案；

# 栏目说明

|栏目名称|说明|
|---|---|
|主表||
|设备自修单号|显示维护计划的编码|
|设备自修单日期|显示维护计划模板名称|
|任务名称|显示维护计划模板的名称|
|设备编码|显示设备分类|
|料号|显示设备料品|
|品名|显示设备卡片|
|规格|显示评估日期|
|单位||
|需求数量|显示设备号|
|耗用数量|显示维护项目|
|转杂发数量|显示作业|
|备料属性|显示已转维修单|
|杂发组织|显示维修组织|
|杂发存储地点|显示维修部门|
|本次杂发数量|显示维修商|
|可杂发数量|显示计划维修日期|
|单据日期|显示维修策略|

# 按钮说明

*  <查询>：不同的查询条件，查询结果也不相同；
*  <操作-设置>：导航至转杂发单设置页面；
*  <操作-转杂发>：导航至转杂发单页面。
*  <操作-转库存杂发>：导航至按库存生成杂发单页面。
*  <杂发单查询>：导航至自修生单结果页面。

# 操作说明

通过菜单[备品配件转杂发（自修）](/detail/1ca3750e06fa45a9bd7dc8d8c410caef)进入备品配件转杂发（自修）界面；

*  操作步骤
 
   *  第1步：选择自修单；
   *  第2步：生成杂发单；
