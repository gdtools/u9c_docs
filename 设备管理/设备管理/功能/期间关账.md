
# 功能描述

期间关账主要用于控制特定期间内是否可以进行设备维护相关的业务操作。

# 业务规则

*  系统启用了设备管理系统；(必做)
*  定义设备档案
*  已经完成操作期间的业务数据。

# 栏目说明

|栏目名称|说明|
|---|---|
|表头||
|会计日历|参照请修单据类型|
|年度|系统自动生成单号|
|表体||
|期间名称|参照部门选择|
|开始日期|参照组织机构|
|结束日期|参照部门选择|
|是否结账|参照业务员|
|结账人|参照供应商|

**按钮说明**

*  <关账>：对已经完成业务的期间进行关账，关账后不能进行该期间的相关业务操作。
*  <取消关账>：对已经关账的单据取消关账，取消关账的期间可以继续补录业务单据
*  <未审核单据>：导航至未审核单据窗口页面。

# 操作说明

通过菜单[期间关账](/detail/d488199b14ae4e0a90779216e90c7f2d)进入期间关账界面；

*  操作步骤
 
   *  第1步：录入年度信息；
   *  第2步：选择期间；
   *  第3步：进行相关操作。
