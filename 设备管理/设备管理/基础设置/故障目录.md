
# 功能描述

本功能用来记录设备故障。

# 业务规则

*  系统启用了设备管理系统；
*  已设置设备类。

# 栏目说明

基本信息

|栏目名称|说明|
|---|---|
|编码|录入故障目录编码|
|名称|录入故障目录名称|
|设备类|选择对应的设备类，枚举：动力设备、金属切割机床、锻压设备、起重运输设备、电器设备工业炉窑、其他机械设备、其他动力设备|
|描述|描述内容|
|生效|默认勾选生效|
|生效日期|设置生效日期|
|失效日期|设置失效日期|

# 操作说明

通过菜单【设备管理>设备管理>基础设置>故障目录】进入故障目录界面；

*  操作步骤
 
   *  第1步：录入编码、名称、设备类等信息；
   *  第2步：保存故障目录。
