
# 功能描述

本功能用来设置设备管理中的单据类型。

# 业务规则

*  系统启用了设备管理系统；

# 栏目说明

单据类型—单头

|栏目名称|说明|
|---|---|
|单据|单据分类，枚举：设备领用申请、设备状态变更、故障申报、设备归还、设备入账、自修单、设备领用申请、设备销账、设备调拨、请修、外修单。|

外修单基本信息

|栏目名称|说明|
|---|---|
|编码|录入单据编码|
|名称|录入名称|
|描述|对说明描述|

单据参数

|栏目名称|说明|
|---|---|
|基本信息||
|上游单据推出|设置由上游单据推出生成当前单据类型|
|确认方式|选择单据审核确认方式，枚举：确认作业、审批流程1、确认作业：即单据需要提供单独的审核操作按钮，执行审核处理；2、审批流程：即单据需要执行多个审核环节，需要设置审批流程。|
|审批方式|确认方式为审批流程，选择审批方式：枚举：1.岗位汇报关系审批2.工作流审批|
|核准中修改重核|是否支持单据在审核中状态支持修改、收回、重新审核。|
|编号||
|编号方式|单据的编号方式，枚举：自动编号、手动编号默认为手动编号，如果单据为上游单据推出，编号方式为自动编号。|
|编号规则|可以根据不同单据的业务处理内容，设置不同的单据编号规则，选择不同的编号规则。|
|允许手动修改|支持手动变更额|
|打印||
|打印时机|设置单据打印，枚举：即时、核准后、不能打印|
|打印方式|设置单据打印的方式，枚举：客户端打印、服务器打印、客户端或服务器打印|
|打印模板|参照打印模板|
|网络打印机|选择连接的打印机|
|最大打印份数|编辑打印的份数|
|打印副本|首付需要打印副本|
|状态||
|生效|默认生效|
|生效日期|默认当前，可设置修改日期|
|失效日期|设置失效日期|

# 操作说明

通过菜单《设备管理>设备管理>基础设置>单据类型》进入单据类型界面；

*  操作步骤
 
   *  第1步：选择单据；
   *  第2步：录入基本信息编码、名称等相关信息；
   *  第3步：设置单据参数；
   *  第4步：保存单据类型
