
# 功能描述

本功能用来设置维护设备的分类。

# 业务规则

*  系统启用了设备管理系统；
*  已设置设备分类编码规则；
*  设备分类的主分类只能有一个主分类。

# 栏目说明

基本信息

|栏目名称|说明|
|---|---|
|编码规则|显示编码规则|
|编码|录入设备分类编码|
|名称|录入设备分类名称|
|上级分类|参照设备分类的上级分类|
|主分类|勾选设置设备分类为主分类。注意：设备分类只能有一个主分类|
|末级分类|默认新增的设备分类为末级分类，通过设置为中间级分类，改变末级分类属性|
|描述|描述内容|
|生效|默认勾选生效|
|生效日期|设置生效日期|
|失效日期|设置失效日期|

# 操作说明

通过菜单<a href="/detail/d06d1a7957e5445a96e3c2c701ebbe4f">设备分类</a>进入设备分类界面；

*  操作步骤
 
   *  第1步：录入编码、名称等信息；
   *  第2步：选择上级分类；
   *  第3步：保存设备分类。
