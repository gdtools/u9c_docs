
# 功能描述

本功能用来设置维护设备的状态。

# 业务规则

*  系统启用了设备管理系统；

# 栏目说明

基本信息

|栏目名称|说明|
|---|---|
|编码|录入设备状态编码|
|名称|录入设备状态名称|
|是否预置|系统后台会预置部分设备状态，不允许修改。|
|描述|描述内容|
|生效|默认勾选生效|
|生效日期|设置生效日期|
|失效日期|设置失效日期|

# 操作说明

通过菜单<a href="/detail/df6a5c57caa040f78e47b4621b0716fb">设备状态</a>进入设备状态界面；

*  操作步骤
 
   *  第1步：录入编码、名称等信息；
   *  第2步：保存设备状态。
