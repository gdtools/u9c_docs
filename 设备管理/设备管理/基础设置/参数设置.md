
# 功能描述

本功能用来设置设备管理系统的参数。

# 业务规则

*  系统启用了设备管理系统；

# 栏目说明

参数设置

|栏目名称|说明|
|---|---|
|参数分组|显示参数的分组名称|
|参数名称|显示参数名称|
|参数值|显示参数值|
|描述|显示单数描述内容|
|作用范围|显示参数的作用范围|
