
# 功能描述

主要用来记录某些设备重要测量点的参数值，以供相关技术人员判定设备的运行情况，是否需要保养、检修等操作提供必要的数据查询。

# 业务规则

*  系统启用了设备管理系统；(必做)
*  定义设备档案

# 栏目说明

|栏目名称|说明|
|---|---|
|设备卡片编码|显示设备卡片编码|
|参数名称|显示参数名称|
|单位|显示单位|
|初始参数值|显示设备初始参数值|
|参数值|显示设备的参数值|
|最近记录日期|显示最近记录日期|

# 按钮说明

*  <查询>：通过选择查询条件，筛查出设备的维护记录。

# 操作说明

通过菜单[设备运行参数查询](/detail/aed0b29c9dc24705be1479b376b67312)进入设备运行参数查询界面；

*  操作步骤
 
   *  第1步：选择查询条件；
   *  第2步：保存查询条件；
   *  第3步：获取查询结果。
