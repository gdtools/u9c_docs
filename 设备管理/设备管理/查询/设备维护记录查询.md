
# 功能描述

本功能用来对设备的维修作业进行查询。

# 业务规则

*  系统启用了设备管理系统；(必做)


# 栏目说明

|栏目名称|说明|
|---|---|
|设备卡片编码|显示设备卡片编码|
|作业清单名称|显示作业清单名称|
|作业明细名称|显示作业明细名称|
|维修日期|显示设备维修的日期|
|维护类别|显示设备的维护类别|
|维修单_单据号|显示维修单单据号|

**按钮说明**

*  <查询>：通过选择查询条件，筛查出设备的维护记录。

# 操作说明

通过菜单[设备维护记录查询](/detail/a33c72e64be941b1a69cac0ddca02b2e)进入设备维护记录查询界面；

*  操作步骤
 
   *  第1步：选择查询条件；
   *  第2步：保存查询条件；
   *  第3步：获取查询结果。
