
# 功能描述

本结点处理用户上线初期或者在应用过程中，委外订单的发料与订单收货情况无法进行核销勾稽，通过材料余额调整，将对应的材料费调整至成品成本中，同时在委托发出材料明细账中体现此部分调整数量信息

系统初始化的时候需要对索引进行一次维护，此时的维护是把数据库中存在的索引记录同步到企业搜索中来 ，以便于提高搜索效率

是将索引恢复到系统初始化完成时候的索引状态

由于索引项不需要用户自己维护，所以此处的索引维护使用的机率及小。一般在系统初始化、数据库恢复、程序出现问题等情况下需要对索引进行一次维护

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

索引维护表单－列表表头

|栏目|说明|
|---|---|
|状态|索引的状态，包括：等待中、执行中、完成和故障注意　:点击本页中的“刷新”可以查看当前操作中索引的执行状态|
|实体类型|当前系统中包含的实体类型|
|开始时间|为当前实体构建索引的开始时间|
|结束时间|为当前实体构建索引的完成时间|
|用时[妙]|为当前实体构建索引一共使用的时间长度，单位是秒|
|记录数量|表示当前这个实体上的索引数量|

索引维护表单－状态栏

|栏目|说明|
|---|---|
|索引状态|索引的状态|
|启动时间|上一次维护操作开始的时间|
|结束时间|上一次索引维护操作结束的时间|

# 按钮说明

*  索引首次填充：为系统执行索引填充操作
 
   *  操作前提
   
      *  系统初始化时或当前画面中有“搜索系统尚未建立任何索引，请点击【索引首次填充】按钮进行索引填充，同时可以实时地点击【刷新】按钮来观察索引填充的进度情况。”的提示时
   *  操作步骤
   
      *  点击协同－>搜索－>索引维护-->索引首次填充按钮
*  刷新：刷新当前索引维护操作的状态
 
   *  操作前提
   
      *  执行过索引填充操作后（无论是首次填充还是重新创建等）
   *  操作步骤
   
      *  点击协同－>搜索－>索引维护-->刷新状态按钮
*  重建索引：重新填充索引，将索引恢复到系统初始化完成时的索引状态
 
   *  操作前提
   
      *  当前画面的列表中有数据时
   *  操作步骤
   
      *  点击协同－>搜索－>重建索引-->刷新状态按钮

# 操作说明

*  通过菜单系统管理－>系统管理－>协同搜索－>索引维护进入该界面；
*  操作步骤
 
   *  第1步：点击索引首次填充按钮。
   *  第2步：维护相关信息。
   *  第3步：点击保存按钮。
