
# 功能描述

企业空间设置是U9V3.0新增的功能，打通了U9与企业空间的集成。可以将U9内部的组织、用户等信息同步到企业空间中。

# 业务规则

*  需要有相应的管理权限。

# 按钮说明

*  <关闭企业空间>：关闭企业空间。
*  <同步组织信息>：当前组织信息同步到企业空间。
*  <同步用户信息>：当前用户信息不同到企业空间。
*  <登录企业空间>：一键登录到企业空间。

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|管理员邮箱|显示管理员邮箱|


# 操作说明

*  通过菜单系统管理－>系统管理－>企业空间－>企业空间设置进入该界面；
*  操作步骤
 
   *  第1步：点击同步组织信息按钮；
   *  第2步：点击同步用户信息按钮；
   *  第3步：点击登录企业空间按钮。
