
# 功能描述

进入系统管理－>消息策略

设置系统中单据的消息发布策略；

支持自定义消息条件；

支持自定义消息调度方案；

# 业务规则

*  消息编码、名称必填；
*  编码唯一，不能重复；

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|编码|当前消息策略的编码，必填项|
|名称|当前消息策略的名称，必填项|
|条件|当前消息策略的执行条件，必填项|
|单据类别|当前消息策略面对的单据|
|调度方案|当前消息策略的调度方案，必填项单击调度方案，可自定义调度方案。|
|制定人|当前消息策略的制定人|
|组织|当前消息策略制定人所属的组织|
|生效checkbox|单击勾选该选项，代表该消息策略生效|
|生效日期|当前消息策略的生效日期当勾选了生效，该生效日期可使用；当未勾选生效，该生效日期不可用。|
|失效日期|当前消息策略的失效日期当勾选了生效，该失效日期可使用；当未勾选生效，该失效日期不可用。|

# 操作说明

*  通过菜单系统管理－>系统管理－>消息策略－>消息策略进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：维护条件、单据类别、调度方案等信息。
   *  第3步：点击保存按钮。
