
# 功能描述

进入系统管理－>系统日志清除

清除系统中的某一些日志；

内容包括请求执行结果、请求监控、预警日志；

# 业务规则

*  存在系统相关日志信息。

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|请求执行结果|用户必须选择后才能执行此选项；如果没有勾选“成功标志”，则删除所有的请求执行结果，勾选后则删除成功的请求执行结果；输入“已结束天数”，表示删除大于已结束天数的请求执行结果，默认值为0，表示删除已结束天数为0的请求执行结果。|
|请求监控|根据用户选择的请求监控的状态来删除请求监控；状态包括：未决，完成，挂起。|
|预警日志|如果勾选上“选择”，表示删除系统中的预警日志；已阅读天数表示：删除超过已阅读天数的预警日志。|
|状态|表示当前设置是否被执行。|

# 按钮说明

*  执行调度：把当前设置加入到执行调度计划中；

# 操作说明

*  通过菜单系统管理－>系统管理－>维护－>系统日志清除进入该界面；
*  操作步骤
 
   *  第1步：维护清除日志相关信息。
   *  第2步：点击保存按钮。
