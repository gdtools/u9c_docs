
# 功能描述 

设置企业中敏感数据的脱敏规则。

# 业务规则

*  针对实体字段设置脱敏规则。
*  实体、属性、脱敏规则非空。

# 栏目说明

组织机构页签

|栏目说明|说明|
|---|---|
|头|
|实体|选择需要设置的实体档案。|
|行|
|属性名称|不可维护，选择实体带入。|
|属性显示名称|不可以维护，选择实体带入。|
|属性类型|不可维护，选择实体带入。|
|脱敏规则|选择脱敏规则。|
|系统预制|不可维护|
|是否启用|维护是否启用|

# 操作说明

*  通过菜单系统管理－>系统管理－>隐私管理－>数据脱敏设置执行进入该界面；
*  操作步骤
 
   *  第1步：选择实体信息。
   *  第2步：选择脱敏规则，维护是否启用信息。
   *  第3步：点击保存按钮。
