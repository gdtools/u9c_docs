
# 功能描述 

设置企业中的脱敏规则。

# 业务规则

*  组织编码不允许重复。
*  系统预制的规则不能修改。

# 栏目说明

组织机构页签

|栏目说明|说明|
|---|---|
|基本信息|
|编码|录入编码。|
|名称|录入名称。|
|系统预制|不能修改。|
|脱敏信息|
|脱敏方式|选择脱敏方式：默认头部掩码。|
|固定位数|设置脱敏的位数。|
|备注||
|有效性|
|生效|生效标记勾选的才会有效。|
|生效日期|档案的开始生效时间。|
|失效日期|档案的失效时间。|

# 按钮说明

*  脱敏测试：弹出脱敏测试界面，输入原文查看当前规则的展示效果。

# 操作说明

*  通过菜单系统管理－>系统管理－>隐私数据－>脱敏规则设置进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：选择脱敏方式，维护固定位数等信息。
   *  第3步：点击保存按钮。
