
# 功能描述

设置预加载数据。

# 业务规则

*  相关菜单权限
*  系统保留最多前100条功能节点用于预热加速

# 栏目说明

主界面-头

|栏目|说明|
|---|---|
|**至**|选择预加载时间范围|
|**条|选择预加载的条数|

主界面-行

|栏目|说明|
|---|---|
|序号|显示预加载的序号|
|来源|显示预加载的来源|
|功能节点|显示预加载的功能节点|

# 按钮说明

*  手工选择：弹出手工选择界面，用户手工添加预加载数据。
*  导入常用功能：系统自动导入常用功能。

# 操作说明

*  通过菜单系统管理－>系统管理－>预加载－>预加载设置进入该界面；
*  操作步骤
 
   *  第1步：点击手工选择。
   *  第2步：选择预加载数据。
   *  第3步：点击确定按钮。
   *  第4步：点击保存按钮。
