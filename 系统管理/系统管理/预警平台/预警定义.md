
# 功能描述

进入系统管理－>预警定义

实现预警信息的定义、修改、删除功能；

实现语境信息的启用功能；

可以在预警定义画面直接导航到工作中心的异步调度和请求管理界面；

可以通过预警信息的列表察看所有预警定义；

可以通过预警日志察看预警的执行情况；

# 业务规则

*  必须先定义消息定义模板；
*  必须有工作中心平台；
*  必须先有应用定义；
*  必须先有预警对象定义；

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|应用|确定预警所在的应用；|
|预警对象|确定产生预警信息的对象；|
|预警条件|定义执行预警的条件规则；|
|消息模板|定义预警消息的显示形式；|


# 按钮说明

*  启用：对已经定义的预警进行启用，启用后系统会自动生成调度方案和一个执行请求；
*  调度方案：通过调度方案可以转入当前预警定义关联的调度方案，并允许进行相关修改；
*  请求管理：导航到[请求管理](/detail/547af614a90c4ff49159d6d7d3af4bda)功能节点。通过异步请求可以转入当前预警定义关联的请求信息，通过对相关请求进行控制，可以间接的控制预警的执行情况；

# 操作说明

*  通过菜单系统管理－>系统管理－>预警平台－>预警定义进入该界面；
*  操作步骤
 
   *  第1步：选择编码、请求名称等信息。
   *  第2步：维护应用、预警对象等信息。
   *  第3步：维护预警条件、描述信息。
   *  第4步：点击保存按钮。
