
# 功能描述

进入系统管理－>预警日志

记录预警定义的执行情况；

提供对预警日志的删除处理；

# 业务规则

*  定义预警、启用、执行相关请求；

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|预警定义|执行预警的定义信息；|
|检查时间|预警的检查时间；|
|是否预警|请求执行时是否满足预警条件并执行了预警；|
|预警消息|显示是否正确执行预警，或者预警执行的错误信息；|

# 操作说明

*  通过菜单系统管理－>系统管理－>预警平台－>预警日志进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮信息。
   *  第2步：输入查询条件信息。
   *  第3步：点击确定按钮。
