
# 功能描述

管理员可以在任务中心中进行管理工作流、业务操作、审批流中创建的任务,功能操作包括取消任务、挂起任务、激活任务、删除任务等。

# 业务规则

*  在工作流或者审批流中生成创建任务。

# 栏目说明

左树

|节点|说明|
|---|---|
|计划任务|指尚未到任务开始时间的任务。|
|待办任务|在任务处理期内的任务。|
|催办任务|工作流定义时，每个活动都有指定完成时间，当指定任务截止时间没有处理时，任务为催办任务状态。|
|挂起任务|挂起状态的任务。|
|已完成任务|已经完成的任务。|
|已取消任务|已经取消，不用再执行的任务。|

行页签

|栏目|说明|
|---|---|
|标题|标题|
|执行者|执行者|
|开始时间|开始时间|
|截止时间|截止时间|
|任务源|任务源|

# 按钮说明

*  取消任务操作：取消任务。
 
   *  操作前提
   
      *  选中要取消的任务。
   *  操作步骤
   
      *  在列表中选中要取消的任务－>操作按钮－>取消任务按钮。
*  挂起任务操作：挂起任务。
 
   *  操作前提
   
      *  选中要挂起的任务。
   *  操作步骤
   
      *  在列表中选中要挂起的任务－>操作按钮－>挂起任务按钮。
*  激活任务操作：激活任务。
 
   *  操作前提
   
      *  选中要激活的任务。
   *  操作步骤
   
      *  在列表中选中要激活的任务－>操作按钮－>激活任务按钮。
*  指派操作：指派任务。
 
   *  操作前提
   
      *  选中要指派的任务。
   *  操作步骤
   
      *  在列表中选中要指派的任务－>点任务页签－>选择任务接收人后点指派按钮。
*  删除任务：删除已完成、已取消的任务。
 
   *  操作前提
   
      *  只有管理员可以执行删除操作。并且只允许对已完成和已取消的任务进行删除操作。其它状态的任务不允许删除。。
   *  操作步骤
   
      *  在列表中选中要激活的任务－>操作按钮－>删除任务按钮。

# 操作说明

*  通过菜单系统管理－>系统管理－>任务中心－>任务中心进入该界面；
*  操作步骤
 
   *  第1步：点击新增，弹出新增界面。
   *  第2步：维护标题、日期等基本信息按钮。
   *  第3步：维护提醒时间、附件文本内容相关信息。
   *  第4步：点击保存按钮。
