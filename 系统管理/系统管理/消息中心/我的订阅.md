
# 功能描述

我的订阅是普通用户用来对当前系统中的预警事件进行订阅设置的产品模块。

# 业务规则

*  当前用户已设置对应的联系对象。

# 栏目说明

未订阅主题

|栏目|说明|
|---|---|
|编码|主题编码|
|主题名称|主题名称|

已订阅主题

|栏目|说明|
|---|---|
|编码|主题编码|
|主题名称|主题名称|
|开始日期|订阅开始日期|
|结束日期|订阅结束日期|


# 按钮说明

*  订阅操作：订阅选中的未订阅主题。
 
   *  操作前提
   
      *  选择要订阅的主题。
   *  操作步骤
   
      *  选择要订阅的主题－>点击“>”按钮。
*  取消订阅操作：取消选中的订阅主题。
 
   *  操作前提
   
      *  选择要取消订阅的主题。
   *  操作步骤
   
      *  选择要取消订阅的主题－>点击“<”按钮。

# 操作说明

*  通过菜单系统管理－>系统管理－>消息中心－>通知管理进入该界面；
*  操作步骤
 
   *  第1步：选择主题类别。
   *  第2步：选择订阅的主题或者取消订阅的主题。
   *  第3步：点击保存按钮。
