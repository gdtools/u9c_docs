
# 功能描述

添加可以使用MSN消息的用户，并为用户定义“MSN帐号”。

# 业务规则

*  MSN通道联系人的MSN帐号：页面中的帐号栏目为当前被选择对象的MSN帐号，在此页面中用户不能对该栏目进行任何操作，用户指定完联系对象栏目后，系统自动将被选择的联系对象的MSN帐号回填到帐号栏目中，如果被选择的在联系对象没有提供MSN帐号，系统将会给出相应的提示

# 栏目说明

消息通道-列表栏目

|栏目|说明|
|---|---|
|联系对象|选择联系对象|
|账号|MSN账号|


# 操作说明

*  通过菜单系统管理－>系统管理－>消息中心－>通知通道进入该界面；
*  操作步骤
 
   *  第1步：点击新增按钮。
   *  第2步：选择联系对象、账号。
   *  第3步：点击保存按钮。
