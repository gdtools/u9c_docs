
# 功能描述

管理员可以在通知管理模块中设置预警事件和实体事件的订阅。对实体事件，管理员还可以定义模板。对预警事件，管理员可以查看主题订阅者。

# 业务规则

*  联系对象启用通知管理

# 栏目说明

通知消息源

|**栏目**|**说明**|
|---|---|
|**消息源类型**|枚举 1.预警消息源 2.实体事件源|
|**消息源名称**|当消息源类型为1时，消息源从[预警消息源]中参照选择。当消息源类型为2时，消息源从[实体事件]中参照选择注：当参照选择后，在下面的列表中显示已经创建订阅规则，同时允许新建订阅规则。|

规则列表页签

|**栏目**|**说明**|
|---|---|
|**规则编码**|规则编码|
|**生效日期**|规则生效的日期|
|**失效日期**|规则失效的日期|
|**强制订阅**|当前规则是否强制订阅强制订阅的意义：如果当前规则为强制订阅类型，当前主题的事件执行结果会通知所有符合该规则订阅要求的订阅者，不考虑这些订阅者是否在我的订阅模块中订阅了该主题。如果当前规则不是强制订阅类型，则当前主题的事件招待结果只通知有符合该规则订阅要求并且在我的订阅中订阅了该主题的订阅者。|
|**语言**|当前规则的语言。当选定了事件之后语言字段自动默认成当前系统登录的语言。|

详细信息页签

|**栏目**|**说明**|
|---|---|
|**分发方式**|事件执行结束的消息分发方式，包括单独分发和集中分发|
|**实体字段**|单独分发时要选择的实体字段|
|**联系人字段**|单独分发时要选择的联系人字段|
|**规则条件**|规则表达式条件|
|**订阅方式**|订阅者范围的选择方式。简单订阅：用户需要选择订阅者类型，订阅者类型包括组织、客户、供应商、用户。选择联系人：用户需要选择联系人来做为订阅者。选择用户：用户需要选择用户做为订阅者。条件订阅：用户需要用条件编辑器来编辑条件，符合这些条件的记录，可以做为订阅者。当用户没有输入条件，则按无条件处理 。|

# 按钮说明

*  主题订阅者：查看当前主题的订阅者

# 操作说明

*  通过菜单系统管理－>系统管理－>消息中心－>通知管理进入该界面；
*  操作步骤
 
   *  第1步：选择消息类型、消息源等信息。
   *  第2步：维护规则编码、生失效日期等信息。
   *  第3步：维护通知详细信息。
   *  第4步：点击保存按钮。
