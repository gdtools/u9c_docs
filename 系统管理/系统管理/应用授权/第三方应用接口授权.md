
# 功能描述

对第三方接口进行管理，包括新增、停用、启用。

# 业务规则

*  相关菜单权限

# 栏目说明

主界面-头

|栏目|说明|
|---|---|
|搜索应用名称|输入搜索的应用名称|

主界面-行

|栏目|说明|
|---|---|
|ID|第三方应用的ID|
|应用名称|第三方应用的应用名称|
|是否启用|第三方应用的启用状态|
|操作|对第三方应用的操作：编辑、删除、停用（启用）、复制|

# 按钮说明

*  搜索：按照输入的应用名称查询相关应用信息。
*  新增：弹出新增界面，添加第三方应用。

# 操作说明

*  通过菜单系统管理－>系统管理－>应用授权－>第三方应用接口授权进入该界面；
*  操作步骤
 
   *  第1步：点击新增按钮。
   *  第2步：输入应用相关信息。
   *  第3步：点击确定按钮。
