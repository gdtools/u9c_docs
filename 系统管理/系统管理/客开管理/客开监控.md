
# 功能描述

可开监控会监控客开触发的一些事件等.

# 业务规则

*  存在客开插件

# 栏目说明

客开监控-头

|栏目|说明|
|---|---|
|插件类型|客开的插件类型|


客开监控-行

|栏目|说明|
|---|---|
|注册载体|显示客开插件的注册载体|
|插件类型|显示客开插件的插件类型|
|运行状态|显示客开插件的运行状态|
|平均耗时(ms)|显示客开插件的平均耗时(ms)|
|运行次数|显示客开插件的运行次数|
|加载信息|显示客开插件的加载信息|
|加载时间|显示客开插件的加载时间|
|首次执行时间|显示客开插件的首次执行时间|
|末次执行时间|显示客开插件的末次执行时间|
|程序集名称|显示客开插件的程序集名称|
|注册配置文件|显示客开插件的注册配置文件|

# 按钮说明

*  暂停运行：停止客开插件运行。
*  继续执行：停止的客开插件重新执行。

# 操作说明

*  通过菜单系统管理－>系统管理－>客开管理－>客开监控进入该界面；
*  操作步骤
 
   *  第1步：选择插件类型。
   *  第2步：选择客开插件。
   *  第3步：点击暂停运行或者继续执行。
