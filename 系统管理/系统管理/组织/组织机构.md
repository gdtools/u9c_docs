
# 功能描述

设置企业中各类职能机构档案。

# 业务规则

*  组织编码不允许重复。
*  联系对象与联系人的区别
 
   *  １、联系对象是Ｕ９系统建立组织、客户、供应商相互关联的标识，没有具体的业务含义。并且一个联系对象只能指定给一个组织。
   *  ２、联系人是一个组织具体的联络人员，具有一定的业务含义。一个组织可以有多个联系人。
*  一个组织不能即是物流组织又是工厂组织。即不能对一个组织同时标识为物流组织和工厂组织。

# 栏目说明

组织机构页签

|栏目|说明|
|---|---|
|行政组织：设置组织的基本信息|
|编码|录入组织编码。|
|名称|录入组织名称。|
|组织形态|录入组织存在形态。组织形态可以选择：集团、公司、事业部、工厂、部门。|
|工作日历|录入组织使用的工作日历。参照工作日历档录入；如果没有建立某组织能够使用的工作日历档案，可以点击本字段，弹出工作日历设置画面，在线新增工作日历档案。|
|联系对象|录入组织的联系对象。参照联系对象档案录入。如果在联系对象档案中没有设置组织的联系对象，可以点击本字段，弹出联系对象设置画面，在线新增组织的联系对象信息。|
|默认语言|录入组织登录产品后使用的语言|
|默认主题|录入组织登录产品后的默认主题|
|地址：录入组织的具体联系地址信息|
|办公地址|录入组织的办公地址。|
|注册地址|录入组织的注册地址。|
|格式：组织如果分布在不同国家、地域，由于习惯，可能有不同的数据显示、处理格式，在此设置组织的数据格式信息|
|数字格式|录入组织使用的数字字段的显示、处理格式。参照数字格式档案录入。如果没有设置某组织使用的数字格式档案，点击本字段下划线，弹出数字格式档案设置画面，在线新增数字格式档案。|
|货币格式|录入组织使用的货币字段的显示、处理格式。参照货币格式档案录入。如果没有设置某组织使用的货币格式档案，点击本字段下划线，弹出货币格式档案设置画面，在线新增货币格式档案。|
|日期格式|录入组织使用的日期字段的显示、处理格式。参照日期格式档案录入。如果没有设置某组织使用的日期格式档案，点击本字段下划线，弹出日期格式档案设置画面，在线新增日期格式档案。|
|时间格式|录入组织使用的时间字段的显示、处理格式。参照时间格式档案录入。如果没有设置某组织使用的时间格式档案，点击本字段下划线，弹出时间格式档案设置画面，在线新增时间格式档案。|
|组织职能|
|法人组织|如果某组织可以使用总帐系统、具有开具税务发票业务职能，加注此标识。|
|营运组织|如果某组织具有采购、销售业务职能，加注此标识。|
|核算组织|如果某组织具有应收、应付宽项核算管理职能，加注此标识。|
|物流组织|如果某组织具有仓库物流管理职能，加注此标识。|
|管理类型|1.内部物流2.外部物流当物流组织=‘True’时，管理类型默认为内部物流。|
|工厂组织|如果某组织具有生产管理职能，加注此标识。|
|人事组织|如果某组织具有人事管理、薪资管理等职能，加注此标识。|
|资产组织|如果某组织具有固定资产管理职能，加注此标识。|
|结算中心|责企业集团内各分支机构，对内/对外资金往来结算的业务组织。|
|预算组织|具有预算职能的组织，可以进行预算的编制、预算的监控、预算的考评。|

联系人页签

|栏目|说明|
|---|---|
|联系人|录入组织的联系人信息。参照联系人档案录入。如果没有设置某组织的联系人档案，点击本字段下划线，弹出联系人档案设置画面，在线新增组织联系人档案。|
|默认|如果某联系人是组织的默认联系人，加注此标识。|
|联系电话|显示联系人档案中设置的默认联系电话。|
|联系地址|显示联系人档案中设置的默认联系地址。|

# 操作说明

*  通过菜单系统管理－>系统管理－>组织－>组织机构执行进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等信息。
   *  第2步：选择组织形态、工作日历、联系对象等信息。
   *  第3步：点击保存按钮。
