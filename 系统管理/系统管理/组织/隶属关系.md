
# 功能描述

根据组织类型，设置组织间上下级隶属关系。

根据组织的上下级关系，将进行相关基础管理数据的下发复制，实现集中控制、分散管理。

# 业务规则

*  定义组织档案（必做）

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|关系类型|分别按照行政、法人、营运、核算、工厂、物流、资产、人事等组织职能设置组织的上下级关系。选择一种关系类型后，系统将具有此关系类型的组织全部列表显示，直接录入各组织对应的上级组织即可。注意　:上下级关系不可以循环设置。如果关系类型选择了“行政”，系统将列示全部组织档案。|
|组织|如果关系类型为“法人”，则显示具有“法人”职能的全部组织档案列表；  如果关系类型为“营运”，则显示具有“营运”职能的全部组织档案列表；  以此类推。如果关系类型为“行政”，显示全部组织档案列表。|
|组织形态|显示组织档案中设置的组织形态信息。|
|上级组织|参照组织档案录入某组织的上级组织。如果某组织没有上级，则为空。|

# 按钮说明

*  业务关系：导航到[业务关系](/detail/e2d7d338b0424524b0647dff0f6f976c)设置功能节点。

# 操作说明

*  通过菜单系统管理－>系统管理－>组织－>隶属关系执行进入该界面；
*  操作步骤
 
   *  第1步：选择关系类型。
   *  第2步：选择上级组织。
   *  第3步：点击保存按钮。
