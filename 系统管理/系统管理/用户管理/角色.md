
# 功能描述

进入系统管理－>角色管理

建立角色，为权限分配使用；

# 业务规则

*  必须先具有应用信息；
*  目前系统中的角色分为四种类型，分别是：
 
   *  EA：企业管理员；
   *  OA：组织管理员；
   *  AA：应用管理员；
   *  UA：普通管理员；
   *  EA、OA、AA：为系统预制角色；
   *  UA：是通过系统建立的角色；

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|编码|角色编码|
|名称|角色名称|
|简称|角色简称|
|描述|角色描述|


应用栏目

|栏目|说明|
|---|---|
|应用|角色所在的应用组，不允许为空；|

# 按钮说明

*  分配用户：给当前的角色分配没有分配过的用户；如果登录用户为EA则，组织为空，可以任意选择，否则，组织为当前的组织。如果当前用户为登陆组织组织管理员,则弹出界面组织自动带出当前组织,且不可编辑。用户列表只列出没有关联要分配角色的用户，关联的不在列出
*  删除用户：删除已经分配的用户；
*  查询分配：通过查询分配，可以看到当前角色被分配给的所有用户，包括不同组织的；

# 操作说明

*  通过菜单系统管理－>系统管理－>用户管理－>角色进入该界面；
*  操作步骤
 
   *  第1步：选择编码、名称等信息。
   *  第2步：维护应用信息。
   *  第3步：点击保存按钮。
