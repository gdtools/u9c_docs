
# 功能描述

进入系统管理－>组织门户；

定义门户与组织的对应关系；一个门户可以服务于多个组织，每个组织也可以对应多个门户；

勾选的组织表示该组织的业务可以在该门户中体现。

# 业务规则

*  必须先定义门户管理员；
*  必须先定义组织信息；

# 栏目说明

基本栏目

|栏目名称|说明|
|---|---|
|编码|显示组织的编码|
|名称|显示组织的名称|
|组织形态|显示组织的组织形态|
|是否法人组织|显示组织是否法人组织|
|是否营运组织|显示组织是否营运组织|
|是否核算组织|显示组织是否核算组织|
|是否物流组织|显示组织是否物流组织|
|是否工厂组织|显示组织是否工厂组织|
|是否人力资源组织|显示组织是否人力资源组织|
|是否资产组织|显示组织是否资产组织|
|办公地址.名称|显示组织办公地址.名称|

# 操作说明

*  通过菜单系统管理－>系统管理－>用户管理－>组织门户进入该界面；
*  操作步骤
 
   *  第1步：选择组织。
   *  第2步：点击保存按钮。
