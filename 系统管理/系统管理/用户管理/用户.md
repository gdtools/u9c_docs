
# 功能描述

创建U9系统使用人员，这里包括企业内部人员、客户或伙伴自助门户使用人员 。

进入系统管理－>用户管理

为系统创建用户；

如果不是EA管理员操作，系统会把新建立的自动关联到当前组织；

每一个新建用户的初始密码是“123456”；

# 业务规则

*  必须先定义登陆语言；

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|登陆语言|登陆时系统按照登陆语言进行默认登陆；|
|联系对象|设定用户的联系对象，整个系统中的用户不允许有相同的联系对象；|
|用户组|可以为用户配置一个组；|
|活动|只有活动的用户才允许登陆；|
|生效|只有生效的用户才允许登陆，并且受生效和失效的时间约束；|
|门户|只有当使用EA登录的时候，这个输入项才是可见的，可以设置用户为门户管理员。|
|节点编码|不在界面显示这个属性；记录启用门户的节点的编码；如果门户的类型为客户,节点编号、客户编号不能同时为空；登录客户门户,不显示有节点编码的用户 。|


# 按钮说明

*  修改密码：通过修改密码，可以对当前的用户进行密码修改。这里的密码修改属于系统管理员对用户密码进行初始化；
*  所在组织：通过所在组织，可以察看当前用户所在的组织；

# 操作说明

*  通过菜单系统管理－>系统管理－>用户管理－>用户进入该界面；
*  操作步骤
 
   *  第1步：维护账号、标识名称、显示名称等信息。
   *  第2步：维护登录语言、联系对象、用户组信息。
   *  第3步：点击保存按钮。
