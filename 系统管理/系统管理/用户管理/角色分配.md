
# 功能描述

进入系统管理－>角色分配

为某个组织下的用户分配角色；

只有系统预制超级用户EA才能对组织进行选择；

用户的权限与角色的分配是相互关联的；

# 业务规则

*  必须先定义用户；
*  必须先定义组织信息；
*  必须先定义角色信息；
*  必须先配置用户与组织之间的关系；
*  EA：可以分配所有无 应用属性，以及 所有 应用已经启用的 角色。但不包括自己；
*  OA：可以分配所有无 应用属性，以及 所有 应用已经启用的 角色。但不包括 EA 和OA属性的管理员角色；
*  AA：可以分配所有无 应用属性，以及 所有 应用已经启用的 角色。但不包括 EA 、OA和AA属性的管理员角色；
*  UA：如果只具有UA角色的用户是不允许进行任何角色分配的；

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|组织结构|EA用户可以选择组织进行分配角色，其他用户只能对他所在组织的用户分配角色；|
|用户信息|显示选定组织所拥有的所有用户；|
|角色信息|对选定的用户进行角色分配；规则：供应商门户用户只能分配角色类型是供应商门户的角色；客户门户用户只能分配角色类型是客户门户的角色；非门户用户只能分配角色类型是非门户角色的角色 。|

# 按钮说明

*  批量添加角色：通过此按钮，用户可以成批的添加角色信息到当前的组织用户中建立“组织－用户－角色"关系；
*  复制到其它用户：通过此按钮，可以把当前用户所拥有的角色复制给当前组织其它的选定的用户，复制规则是增量追加；
*  复制用户私有权限到其他用户：通过此按钮，可以把当前用户所拥有的私有权限复制给当前组织其它的选定的用户；此功能只能应用于组织管理员。

# 操作说明

*  通过菜单系统管理－>系统管理－>用户管理－>用户进入该界面；
*  操作步骤
 
   *  第1步：选择用户。
   *  第2步：选择角色。
   *  第3步：点击保存按钮。
