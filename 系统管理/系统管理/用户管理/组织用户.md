
# 功能描述

进入系统管理－>组织用户

为某个组织添加用户；

只有系统预制超级用户EA才能对组织进行选择；

# 业务规则

*  必须先定义用户；
*  必须先定义组织信息；

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|组织机构||
|组织结构|EA用户可以选择组织进行分配角色，其他用户只能对他所在组织的用户分配角色；|
|用户信息||
|用户|用户信息的账号；如果当前组织是门户组织，则可以参照出所有用户的门户的组织是当前组织的用户；如果当前组织不是门户组织，则可以参照出所有不是门户用户的当前组织中没有的用户记录。|
|名称|用户信息的名称；|
|简称|用户简称|
|描述|用户描述|

# 按钮说明

*  批量添加：通过批量添加，可以当前组织同时添加多个用户；

# 操作说明

*  通过菜单系统管理－>系统管理－>用户管理－>组织用户进入该界面；
*  操作步骤
 
   *  第1步：维护用户等信息。
   *  第2步：点击保存按钮。
