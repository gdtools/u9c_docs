
# 功能描述

定义在审批流中的终审权，由在各个纬度上的取值大小或者范围组成，同一纬度之间是and关系，不同纬度之间是or关系。

# 业务规则

*  预制审批纬度数据。

# 栏目说明

基本

|栏目|说明|
|---|---|
|编码|审批职责的编码|
|名称|审批职责的名称|

状态

|栏目|说明|
|---|---|
|生效|是否生效|
|生效日期|生效的日期|
|失效日期|在失效的日期之后当前审批职责就不能使用了。|

审批职责子表页签

|栏目|说明|
|---|---|
|审批纬度|审批操作关注的业务角度，通常与某个职位所管辖的业务领域相关。它表现为业务对象中特定数据项，如金额、物料、物料类型、收发货地点、科目等。从审批纬度参照选出。|
|纬度类型|只读，表示该纬度是额度纬度还是实体纬度或者枚举纬度。每个审批职责中只能有一个或0个额度类型的纬度。如果没有额度纬度则判断终审权时不判断非额度纬度的取值范围，只判断岗位关系。即分配的最高级别岗位才有终审权。|
|限额|额度的大小。对于额度纬度，表示在该纬度上的值在该限额以下时在该纬度上有终审权；对于非额度纬度，如果该职责中有额度纬度，则在在该额度纬度上的值在该限额以下时在该纬度上可能有终审权（是否有终审权还要看该非额度纬度本身的取值范围）。|
|枚举下限|当该纬度为枚举类型纬度，在该纬度上的取值如果大于等于该枚举下限，则在该纬度上可能有终审权（是否有终审权还要看取值是否小于等于上限以及额度纬度取值是否小于限额）|
|枚举上限|当该纬度为枚举类型纬度，在该纬度上的取值如果小于等于该枚举上限，则在该纬度上可能有终审权（是否有终审权还要看取值是否大于等于下限以及额度纬度取值是否小于限额）|
|实体下限编码|当该纬度为实体类型纬度，在该纬度上的取值如果大于等于该实体下限，则在该纬度上可能有终审权（是否有终审权还要看取值是否小于等于上限以及额度纬度取值是否小于限额）|
|实体上限编码|当该纬度为实体类型纬度，在该纬度上的取值如果小于等于该实体上限，则在该纬度上可能有终审权（是否有终审权还要看取值是否大于等于下限以及额度纬度取值是否小于限额）|
|是否限度内|对于非额度纬度的上下限范围取反操作。|

审批职责子表编辑页签：对审批职责子表页签的内容进行编辑。

# 按钮说明

*  审批预置数据设置：导航到审批预置数据设置。
*  审批分配：导航到审批分配。

# 操作说明

*  通过菜单系统管理－>系统管理－>审批流－>审批职责进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称。
   *  第2步：维护审批子表相关信息。
   *  第3步：点击保存按钮。
