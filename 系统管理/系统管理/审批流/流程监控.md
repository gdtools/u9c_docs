
# 功能描述

本结点提供查看审批流程监控执行的结果信息。

# 业务规则

*  启用工作流。

# 栏目说明

默认栏目

|栏目|说明|
|---|---|
|标题|审批流的标题|
|流程设计信息标题|流程设计标题|
|提交人|审批流程提交人|
|提交时间|审批流程提交时间|
|流程状态|审批流程的流程状态|
|备注|审批流程的备注信息|


# 按钮说明

*  催办：点击流程监控－>催办，通知审批流程处理人处理。
*  终止：点击流程监控－>终止，终止改流程。
*  修改处理人：点击流程监控－>修改处理人，修改当前处理人。
*  设为开立：点击流程监控－>设为开立，修改流程状态为开立状态。

# 操作说明

*  通过菜单系统管理－>系统管理－>审批流－>流程监控进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定按钮。
