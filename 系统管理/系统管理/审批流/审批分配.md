
# 功能描述

进入系统管理－>审批分配

将审批职责分配给系统中不同的职务或者岗位,以便不同的职务或者岗位具有不同的审批终审权.不同的审批分配之间取值为与（and）关系。

审批过程中支持兼职岗的审批。也就是说选择的岗位上有兼职的人员时也允许此人员参与审批。

# 业务规则

*  预制审批对象数据
*  定义职务，岗位，审批职责。

# 栏目说明

表头

|HR组织|选择HR组织|
|---|---|
|职务|选择职务|
|岗位|选择岗位|
|全局|全局审批表示该审批不受岗位树的限制。主要用于一些需要公共部门审批的场景，例如财务部。|

表体

|审批职责|选择审批职责|
|---|---|
|审批对象|选择审批对象|
|可跳过|在审批过程中，非终审可以不参与审批。|

# 按钮说明

*  审批预置数据设置：点击审批分配－>审批预置数据设置，导航到审批预置数据设置；
*  审批链顺序：点击审批分配－>审批链顺序数据设置，导航到审批链顺序的设置页面；

# 操作说明

*  通过菜单系统管理－>系统管理－>审批流－>审批分配进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称、HR组织等信息。
   *  第2步：维护审批职责、审批对象信息。
   *  第3步：点击保存按钮。
