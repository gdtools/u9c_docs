
# 功能描述

进入系统管理－>审批委托

由于临时有事情,不能进行审批,需要将审批任务委托给其他用户。

系统只支持一级的委托.例如审批流程为A->B->C,B委托给B',B'委托给B",那么B的审批任务会转给B'审批,而不会转给B"

系统不支持循环审批,例如A委托给B,B委托给C,C委托给A

系统不支持同一时间委托给多人,如果一个用户将自己的任务委托给多人,那么系统只会给其中一个人转发审批任务

为了保留痕迹,录入的审批委托,不允许删除,不允许修改,只能将录入的审批委托置为无效

# 业务规则

*  启用工作流（必做）

# 栏目说明

[表头](http://wangwq/U9C/help/zh-CN/Content/SM/Function/javascript:void(0);)

|委托人|选择一个用户,例如A不能审批,A即为委托人|
|---|---|
|被委托人|选择一个用户,例如A将审批任务委托由B完成,B为被委托人|
|实体类型|用户选择一个实体,那么此实体的审批任务由被委托人完成,如果不选择,则所有的审批任务均由被委托人完成|
|起始日期|委托的起始日期|
|结束日期|委托的结束日期|
|是否有效|审批委托是否有效|


# 操作说明

*  通过菜单系统管理－>系统管理－>审批流－>审批委托进入该界面；
*  操作步骤
 
   *  第1步：选择委派人、被委派人。
   *  第2步：选择起始日期、结束日期信息。
   *  第3步：点击保存按钮。
