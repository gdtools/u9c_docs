
# 功能描述

审批过程是某一审批流程的综合查看画面，可以看到该审批流程的全过程以及当前的状态。

# 业务规则

*  启用审批流程（必做）

# 栏目说明

审批结果

|栏目|说明|
|---|---|
|审批对象.名称|该审批的主审批对象。|
|审批对象.编码|该审批的主单据的显示名称。|
|提交时间|该审批的提交时间。|
|审批时间|该审批的审批时间。|
|是否通过|该审批是审批通过还是拒绝。|
|弃审时间|该审批弃审时间。|
|单据显示名|该审批的主单据的显示名称。|
|审批状态|该审批当前状态，有处理中、完成、弃审、终止四种状态。|

审批链

|栏目|说明|
|---|---|
|审批对象|该审批链的审批对象。|
|单据显示名|该审批链的单据的显示名称。|
|审批标志|该审批链是否完成。|

审批动作

|栏目|说明|
|---|---|
|汇报对象类型|该审批动作的汇报对象类型。|
|汇报对象|该审批动作的审批汇报对象，例如：岗位。|
|审批人|该审批动作的审批用户。|
|动作类型|该审批动作的类型，有同意、拒绝、转交三种。|
|审批意见|该审批动作的审批意见。|
|提交时间|该审批动作的提交时间。|
|审批时间|该审批动作的审批时间。|
|是否终审|该审批动作是否终审动作。|
|转交目标岗位|该审批动作如果是转交动作的，转交的目标岗位。|

# 按钮说明

*  查询：系统功能，按条件查询审批结果的列表。
*  双击网格行：显示当前行的审批结果。用户可以终止和查询主单据的内容。已经参与审批和提交的用户有权利使用终止功能。主单据按钮：单据类型如果是跨组织的单据类型，则单据显示方式为弹出式显示方式，否则为导航的方式； 在业务单据中选中单据的行，点“流程”按钮查看对应的审批流，这个审批流从上到下应该显示为审批链的顺序。

# 操作说明

*  通过菜单系统管理－>系统管理－>审批流－>审批过程进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击保存按钮。
