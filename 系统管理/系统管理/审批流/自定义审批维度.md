
# 功能描述

进入系统管理－>自定义审批维度

用户自定义业务对象中需要审批的属性。

# 业务规则

*  预制审批对象数据

# 栏目说明

表头

|审批对象|选择预置好的审批对象,即需要审批的实体,例如客户,销售订单|
|---|---|

表体

|审批维度|选择一个审批维度|
|---|---|
|审批类型|审批维度对应的类型1 额度,实体对应的金额属性2 实体,实体引用的实体属性,例如客户[地区],销售订单[客户]3 枚举,实体引用的枚举,例如客户[对账期间]|
|维度列|审批对象的审批维度对应的属性表达例如[地区]在客户的属性表达式,客户在订单上对应属性的表达式|


# 操作说明

*  通过菜单系统管理－>系统管理－>审批流－>审批自定义审批维度进入该界面；
*  操作步骤
 
   *  第1步：选择审批对象。
   *  第2步：维护审批维度行维度列、编码、名称、类型等信息。
   *  第3步：点击保存按钮。
