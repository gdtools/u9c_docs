
# 功能描述

添加可以使用短信审批的用户，并未这些用设置短信审批功能的启用状态。

# 业务规则

*  企用状态短信审批的启用状态，默认为启用并且在该页面中只能进行启用状态的设置。
*  短信审批的取消操作有两种形式：
 
   *  1、从本页面的列表中将要取消短信审批使用权的用户删除
   *  2、用户自己通过发送手机短信的形式主动取消

# 栏目说明

默认栏目

|栏目|说明|
|---|---|
|用户|需要开工短信审批的用户|
|账号|接收短信的用户手机号|
|状态|用户状态|
|状态变更时间|用户状态变更时间|


# 按钮说明

*  新增：添加可以使用短信审批的对象
 
   *  操作步骤
   
      *  单击新增进入短信审批服务开通页面
      *  在短信审批服务开通页面单击“用户”，新建一个用户信息，并将该用户返回到本页面的用户栏目中；或单击用户栏目文本框中的图标 —> 弹出用户对话框 —> 在用户对话框中选择一个用户，单击确定按钮将被选择的用户返回到短信审批服务开通页面
      *  录入帐号栏目。该栏目是用户栏目中指定的用户的手机号码，如果用户基础信息中已经设置了手机号码，则选择用户后系统自动将该用户的手机号码填写到帐号栏目中
      *  单击保存
*  删除：将用户从可用短信审批列表中删除，也就是说取消该用户使用短信审批权限
 
   *  操作步骤
   
      *  在列表中选择要删除的对象，至少选择一个
      *  单击删除，弹出确认对话框，然后选择确定
*  修改：修改用户短信审批服务的属性，如帐号(手机号码）等
 
   *  操作步骤
   
      *  在列表中双击要进行修改的用户所在的行，进入短信审批服务开通页面
*  查找：点击【查找】操作按钮，系统将根据用户设置的查询条件、栏目显示列表内容。用户设置查询方案后，一定要通过查找功能，以列表形式显示查看设置内容是否满足要求。

# 操作说明

*  通过菜单系统管理－>系统管理－>审批流－>短信审批进入该界面；
*  操作步骤
 
   *  第1步：点击新增按钮。
   *  第2步：维护用户、账号信息。
   *  第3步：点击保存按钮。
