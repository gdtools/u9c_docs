
# 功能描述

进入系统管理－>调度方案

定于请求执行的时间运行方案；

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|周期单位|定义执行的周期，系统支持的周期为：年、月、周、日、时、分；|
|重复周期|定义多少个周期执行一次，最小值为1；|
|是否月末|定义每个周期中是否是月末执行，只有周期为年、月的时候才起作用；|
|首次执行时间|定义调度开始的时间；|
|结束方式|定义调度的结束方式，目前结束方式有三种：无结束时间；重复次数，即执行定义的次数后结束；结束时间，即执行到指定的时间后结束；|


# 操作说明

*  通过菜单系统管理－>系统管理－>异步请求管理－>调度方案进入该界面；
*  操作步骤
 
   *  第1步：选择编码、名称等信息。
   *  第2步：维护周期单位、重复周期、首次执行时间等信息。
   *  第3步：点击保存按钮。
