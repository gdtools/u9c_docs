
# 功能描述

进入系统管理－>请求执行结果

显示请求执行过程中产生的结果信息，对于未执行成功的会给出错误信息；；

受请求个数和调度策略的影响，请求执行结果信息可能数据非常多，需要定期清理；

# 业务规则

*  定义请求，并提交执行；

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|请求名称|显示提交的请求名称；|
|执行类型|显示请求的执行类型，系统自动控制的。；|
|执行时间|显示请求每次执行的具体时间；|
|成功|显示请求是否执行成功；|
|错误信息|显示请求执行错误的可能原因；|

# 操作说明

*  通过菜单系统管理－>系统管理－>异步请求管理－>请求执行结果进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件等信息。
   *  第3步：点击确定按钮。
