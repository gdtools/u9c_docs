
# 功能描述

进入系统管理－>请求管理

定义一个系统自动运行的处理机制；

一旦请求定义并执行后，不需要用户交互就可以按照调度方案自定运行；

主要用于系统定期自动处理相关功能的时候；

# 业务规则

*  定义调度方案；

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|应用|定义请求所在应用分组；|
|调度方案|定义请求执行的时间方案；|
|异步程序|定义请求执行的具体功能；|
|状态|显示请求的状态（不可维护信息），一个请求包括：未决、执行、挂起、完成四种状态；|
|提交人|显示提交请求运行的人员（不可维护信息，在请求提交后自动生成）；|
|提交时间|显示请求提交运行的时间（不可维护信息，在请求提交后自动生成）；|

# 按钮说明

*  提交请求：当一个请求定以后需要进行提交才能加入的自动执行的队列中；
*  <请求监控>：导航到[请求监控](/detail/15d28fcc1fea489f9ba95e55f9f8a026)功能节点。
*  <请求执行结果>：导航到[请求执行结果](/detail/714cc60011124d8a9803e9ab684c560e)功能节点。

# 操作说明

*  通过菜单系统管理－>系统管理－>异步请求管理－>请求管理进入该界面；
*  操作步骤
 
   *  第1步：选择编码、请求名称等信息。
   *  第2步：维护调度方案、应用、异步程序等信息。
   *  第3步：维护监护条件信息。
   *  第4步：点击保存按钮。
