
# 功能描述

进入系统管理－>请求监控

查看已经提交过的请求运行状态；

控制请求的“执行”和“挂起”；

# 业务规则

*  定义请求，并提交执行；

# 栏目说明

基础栏目

|栏目|说明|
|---|---|
|编码|任务的编码|
|请求名称|显示请求的名称；|
|提交人.名称|显示当前请求的提交人；|
|提交时间|当前请求的提交时间|
|调度方案.名称|当前调度方案的名称|
|状态|显示当前请求所处的状态，可能是“执行、挂起和完成”；|
|描述|当前调度的描述信息|

# 按钮说明

*  激活：激活挂起状态的请求。
*  挂起：暂停执行状态的请求。

# 操作说明

*  通过菜单系统管理－>系统管理－>异步请求管理－>请求监控进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件等信息。
   *  第3步：点击确定按钮。
