
# 功能描述

维护PLM元数据信息。系统会预置PLM元数据信息，用户可通过此功能来修改相应的元数据信息。

# 业务规则

*  启用PLM（必做）

# 栏目说明

对接系统元数据-单头

|栏目|说明|
|---|---|
|编码|对接系统元数据编码|
|名称|对接系统元数据编码|
|对接系统|对接系统元数据的对接系统|
|类型|对接系统元数据的类型|

对接系统元数据-行

|栏目|说明|
|---|---|
|行号||
|名称|元数据名称|
|描述|元数据描述|
|默认值|元数据默认值|
|备注|备注信息|


# 操作说明

*  通过菜单系统管理－>系统管理－>系统对接设置－>对接系统元数据进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称、对接系统等信息。
   *  第2步：维护名称、描述、默认值等信息。
   *  第3步：点击保存按钮。
