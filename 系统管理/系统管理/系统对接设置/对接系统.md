
# 功能描述

配置PLM连接信息。

# 业务规则

*  启用PLM（必做）

# 栏目说明

主画面

|栏目|说明|
|---|---|
|编码|系统默认为“PLM”，无法直接修改。可通过参数：PLM系统编码进行修改。一般无需调整。|
|服务器地址|录入PLM服务器的ip地址，格式如：192.168.0.1:8000。其中8000为通信端口号。|
|返回对照关系|如勾选，表示将PLM和U9的数据字段对照关系同步到PLM系统中。这样更便于两个系统的解耦。如不勾选，每次同步数据时，PLM系统需要到U9系统中获取字段对照关系信息。|

# 按钮说明

*  更新元数据：PLM元数据发生变化时，需要更新相应的元数据信息。

操作说明

*  通过菜单系统管理－>系统管理－>系统对接设置－>对接系统进入该界面；
*  操作步骤
 
   *  第1步：点击“查找”按钮，找到编码为“PLM”的记录。选择该记录并点击“确定”按钮返回。
   *  第2步：维护服务器地址、返回对照关系、名称等信息。
   *  第3步：点击启用按钮。
