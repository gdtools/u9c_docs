
# 功能描述

通过该功能维护U9和PLM字段的映射关系及设置U9字段的默认值。系统会预置常用字段映射关系，用户可根据实际需求进行增减。

# 业务规则

*  启用PLM（必做）

# 栏目说明

主画面

|栏目|说明|
|---|---|
|对接系统|选择编码为“PLM”的记录。|
|对接实体|选择要进行字段映射的PLM数据表。|
|U9实体|选择相应的U9数据表。|
|u9实体属性|选择要进行数据映射的U9字段。|
|默认值|可以为U9字段设置默认值。在数据同步时，如果U9字段没有定义映射关系，则优先取此处设置的默认值。|
|对接实体属性|选择要进行数据映射的PLM字段。|

# 操作说明

*  通过菜单系统管理－>系统管理－>系统对接设置－>属性对照关系进入该界面；
*  操作步骤
 
   *  第1步：新增映射关系：进入新增状态。
   *  第2步：选择对接系统：找到编码为“PLM”的记录并选择。如果修改了参数：PLM系统编码，则需按修改后的参数值找到相应的对接系统记录。
   *  第3步：选择对接实体：如：物料、BOM等。注意：通过“对接系统元数据”功能来维护对接实体信息。 
   *  第4步：U9实体：选择相应的U9实体。 
   *  第5步：表体新增一行记录，选择U9实体字段，并选择PLM实体字段。 
   *  第6步：点击保存按钮。
