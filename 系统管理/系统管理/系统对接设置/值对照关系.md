
# 功能描述

通过该功能维护U9和PLM值的映射关系。系统会预置常用值映射关系，用户可根据实际需求进行增减。

# 业务规则

*  启用PLM（必做）

# 栏目说明

主画面-头

|栏目|说明|
|---|---|
|编码|值对照关系编码|
|名称|值对照关系名称|
|对接系统|选择编码为“PLM”的记录。|
|对接属性|选择要进行字段映射的PLM属性。|
|U9实体|选择相应的U9数据表。|
|u9实体属性|选择要进行数据映射的U9字段。|

主画面-行

|栏目|说明|
|---|---|
|行||
|对接系统属性值|对接系统属性值|
|U9属性值|U9属性值|

# 操作说明

*  通过菜单系统管理－>系统管理－>系统对接设置－>值对照关系进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称等相关信息。
   *  第2步：选择对接系统属性值和U9系统属性值。 
   *  第3步：点击保存按钮。
