
# 功能描述

将系统中的物料、BOM、工艺数据同步到PLM系统中。

# 业务规则

*  通过“对接系统”功能设置了有效的PLM服务器IP地址信息。

# 栏目说明

主画面

|栏目|说明|
|---|---|
|对接系统|选择编码为“PLM”的记录。|
|对照实体|选择要同步的数据表。如：物料、BOM、工艺等。在选择了对照实体后，系统会自动加载该实体相应的数据字段，并显示在下面的grid画面中。|

# 操作说明

*  通过菜单系统管理－>系统管理－>系统对接设置－>数据同步进入该界面；
*  操作步骤
 
   *  第1步：选择对接系统及想要同步的数据实体。系统根据默认查询方案加载出该数据实体显示的字段内容。
   *  第2步：选择一条或多条要同步的记录。
   *  第3步：点击“同步数据”按钮。
   *  第4步：系统弹出对话框，可以调度执行或立即执行。
