
# 功能描述

敏感日志列表，会记录敏感实体发生的操作日志，包括新增、修改、删除等等的操作日志。

# 业务规则

*  必须先进行授权；

# 栏目说明

结果栏目

|栏目|说明|
|---|---|
|敏感实体显示名|敏感实体显示名；|
|敏感属性显示名|敏感属性显示名；|
|编码|操作的用户编码；|
|操作方法|用户的操作方法；|
|操作前信息|操作前信息；|
|操作后信息|操作后信息；|
|用户名|操作的用户名称;|
|组织|用户所属的组织，无组织，表示企业管理员（EA）登录;|
|IP地址|用户所在的计算机的IP地址;|
|操作时间|记录操作发生的时间;|


# 操作说明

*  通过菜单系统管理－>系统管理－>日志管理－>敏感日志列表进入该界面；
*  操作步骤
 
   *  第1步：选择查询条件。
   *  第2步：点击查询按钮。
