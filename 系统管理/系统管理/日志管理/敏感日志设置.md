
# 功能描述

敏感日志设置可供用户设置敏感实体的监控.

# 业务规则

*  必须先进行授权；

# 栏目说明

敏感性日志-头

|栏目|说明|
|---|---|
|敏感实体|选择敏感实体|
|条件表达式|设置条件表达式|
|编码表达式|设置编码表达式|


敏感性日志-行

|栏目|说明|
|---|---|
|属性名称|显示敏感实体的属性名称|
|属性显示名称|显示敏感实体的属性显示名称|
|是否敏感|设置敏感实体的属性是否敏感信息|

# 操作说明

*  通过菜单系统管理－>系统管理－>日志管理－>敏感日志设置进入该界面；
*  操作步骤
 
   *  第1步：选择实体，设置条件表达式、编码。
   *  第2步：设置敏感字段。
   *  第3步：点击保存按钮。
