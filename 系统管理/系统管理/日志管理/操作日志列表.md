
# 功能描述

操作日志列表会记录所有的用户在任何时间使用系统的相关信息，并且记录操作是否成功等信息。

# 业务规则

*  必须先进行授权；

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|用户名|操作的用户名称;|
|组织|用户所属的组织，无组织，表示企业管理员（EA）登录;|
|IP地址|用户所在的计算机的IP地址;|
|操作时间|记录操作发生的时间;|
|动作名称|用户操作的动作名称。|

# 操作说明

*  通过菜单系统管理－>系统管理－>日志管理－>操作日志列表进入该界面；
*  操作步骤
 
   *  第1步：选择查询条件。
   *  第2步：点击查询按钮。
