
# 功能描述

本结点提供U9系统数据与云系统的同步结果查询以及取消同步结果，

# 业务规则

*  与云系统对接

# 栏目说明

同步结果查询栏目

|栏目|说明|
|---|---|
|来源实体_系统类型|来源实体_系统类型|
|来源实体_单号|来源实体_单号|
|来源实体_单据行号|来源实体_单据行号|
|来源实体_单据子行号|来源实体_单据子行号|
|目的实体_系统类型|目的实体_系统类型|
|目的实体_单号|目的实体_单号|
|目的实体_单据行号|目的实体_单据行号|
|目的实体_单据子行号|目的实体_单据子行号|
|是否成功|是否成功|
|同步时间|同步时间|

# 按钮说明

*  重新执行：重新执行数据同步。
*  取消同步：取消同步元数据。

# 操作说明

*  通过菜单系统管理－>系统管理－>现场云数据同步－>数据同步结果查询进入该界面；
*  操作步骤
 
   *  第1步：点击查询按钮。
   *  第2步：输入查询条件。
   *  第3步：点击确定按钮。
