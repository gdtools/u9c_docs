
# 功能描述

进入系统管理－>系统启用

设置各产品模块的启用状态；

提供对产品模块的锁定、解锁、停用处理；

模块首次启用，会发布元数据和菜单；

# 业务规则

*  组织管理员具有本功能节点权限；
*  解锁人和锁定人必须为同一个人；
*  未启用的系统不允许锁定；
*  已经锁定的系统不允许反启用；
*  组织的性质不同，可以使用的产品功能模块也不同；
*  不允许同时启用；
*  已经停用的产品不允许重新启用；

# 按钮说明

*  <启用>：进行系统启用，启用时间可以设定，默认当前系统时间。
*  <锁定>：进行锁定，锁定时间为当前系统时间,锁定后只有锁定人可以增加\修改\查询相关模块。
*  <解锁>：进行解锁,只有锁定人才能解锁。

# 操作说明

*  通过菜单系统管理－>系统管理－>系统启用－>系统启用进入该界面；
*  操作步骤
 
   *  第1步：选择启用的系统；
   *  第2步：点击启用按钮。
