
# 功能描述

本结点提供查看业务监控执行的结果信息：

查看业务监控汇总结果数据

查看业务监控汇总明细数据

手工对选择的业务监控检查项进行重新执行

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

监控结果

|栏目|说明|
|---|---|
|编码|业务监控的编码|
|开始执行时间|业务监控执行最近一次检查的开始时间|
|结束执行时间|业务监控执行最近一次检查的结束时间|
|执行状态|记录业务监控检查执行的状态，分为未执行、执行成功、执行失败|
|错误信息|显示业务监控执行失败的异常信息|
|异常实体数|显示业务监控检查执行成功后，不满足业务监控检查的数据条目数。通过链接显示对应选择业务监控检查的明细记录|


# 操作说明

*  通过菜单系统管理－>系统管理－>业务监控－>监控结果执行进入该界面；
*  操作步骤
 
   *  第1步：点击查询。
   *  第2步：输入查询条件。
   *  第3步：点击确定按钮。
