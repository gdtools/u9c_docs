
# 功能描述

本结点提供按监控分类设置自动执行方案，系统可按设置的方案执行业务监控检查

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

监控分类执行设置

|栏目|说明|
|---|---|
|监控分类|选择执行业务监控的监控分类|
|期间类型|指定检查业务数据的期间类型。|
|起始日期/j截止日期|如【期间类型】=指定日期，则可维护起始日期，截止日期|


# 按钮说明

*  调度信息查询：点击监控定义－>调度信息查询，弹出调度信息查询界面。

# 操作说明

*  通过菜单系统管理－>系统管理－>业务监控－>监控分类执行进入该界面；
*  操作步骤
 
   *  第1步：选择监控分类等信息。
   *  第2步：维护期间类型等信息。
   *  第3步：点击保存按钮。
