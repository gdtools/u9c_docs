
# 功能描述

本结点提供设置业务监控的对象、监控条件等

系统预置107条在基本档案初始化、日常业务处理、月末结账等环节易出现问题的业务监控项，用户可依据需要启用

# 业务规则

*  需要有相应的管理权限。

# 栏目说明

监控定义

|栏目|说明|
|---|---|
|编码|监控定义编码|
|名称|监控定义名称|
|应用|选择业务监控项对应的产品应用|
|监控对象|选择业务监控的对象，系统中的|
|监控分类|设置监控所属的监控分类，系统预置档案监控、单据监控、月结业务监控，用户可新增自定义分类|
|监控条件||

# 按钮说明

*  执行：点击监控定义－>执行，执行该监控定义。
*  <监控日志>：导航到[监控结果](/detail/081b706884604e399fb5e27cafd49c14)功能节点。

# 操作说明

*  通过菜单系统管理－>系统管理－>业务监控－>监控结果进入该界面；
*  操作步骤
 
   *  第1步：选择编码、名称等信息。
   *  第2步：维护应用、监控对象、监控分类等信息。
   *  第3步：维护监护条件信息。
   *  第4步：点击保存按钮。
