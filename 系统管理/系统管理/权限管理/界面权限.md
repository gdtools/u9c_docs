
# 功能描述

控制系统各业务界面访问权限，即每一个界面是否可见。

界面权限中包括界面的访问权限、表单权限、动作权限、字段权限、属性权限设置。表单的访问权限为默认允许。

# 业务规则

*  拥有系统管理功能权限。

# 栏目说明

表单权限-头

|栏目|说明|
|---|---|
|角色|参照系统的角色|
|模块|参照系统的模块|
|表单|参照模块的表单|


界面权限-表单权限

|栏目|说明|
|---|---|
|访问|设置表单的访问权限：拒绝、允许|
|个性化|设置表单的个性化权限：拒绝、允许|
|个性化模板|设置表单的个性化权限：拒绝、允许|

界面权限-动作权限

|栏目|说明|
|---|---|
|执行|设置界面动作的访问权限：拒绝、允许|
|动作名称|显示表单的动作名称|
|动作编码|显示表单的动作编码|
|分组名称|显示表单的分组名称|

界面权限-字段权限

|栏目|说明|
|---|---|
|显示|设置界面字段的显示权限：拒绝、允许|
|编辑|设置界面字段的显示权限：拒绝、允许|
|字段名称|显示界面的字段名称|
|字段编码|显示界面的字段名称|
|视图名称|显示界面的字段的视图名称|
|分组名称|显示界面的字段的分组名称|

界面权限-属性权限

|栏目|说明|
|---|---|
|显示|设置界面属性的显示权限：拒绝、允许|
|编辑|设置界面属性的显示权限：拒绝、允许|
|属性名称|显示界面的属性名称|
|属性编码|显示界面的属性名称|
|分组名称|显示界面的属性的分组名称|

# 按钮说明

*  权限查询：点击表单权限－>权限查询，进入权限查询功能界面。

# 操作说明

*  通过菜单系统管理－>系统管理－>权限管理－>界面权限进入该界面；
*  操作步骤
 
   *  第1步：选择角色。
   *  第2步：选择模块。
   *  第3步：选择表单。
   *  第4步：修改表单访问权限、动作权限、字段权限、属性权限等权限信息。
   *  第5步：点击保存按钮。
