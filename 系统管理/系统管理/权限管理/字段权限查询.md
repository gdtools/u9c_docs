
# 功能描述

查询出选定用户和字段的所有角色；

查询出选定角色和字段的所有用户；

# 业务规则

*  必须先进行角色分配；
*  必须先进行授权；

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|查询信息||
|用户|需要查询的用户。|
|表单|需要查询的字段所属的表单。|
|角色|需要查询的角色。|
|模块|需要查询的菜单项所属的模块，即应用信息。|
|字段|需要查询的字段项。|
|查询角色授权明细|是否需要查询角色授权的明细信息。|
|查询结果||
|用户编码|用户信息的编码；|
|用户名称|用户信息的名称；|
|角色编码|角色编码|
|角色名称|角色名称|
|表单名称|字段权限所在的表单的名称|
|字段名称|字段的名称|
|编辑|编辑权限的结果|
|显示|显示权限的结果|

# 按钮说明

*  查询：点此按钮，把菜单权限查询结果显示在查询结果列表中；当勾选[查询角色授权明细]之后，用户条件不可选择，查询的结果为当前角色的授权的明细信息。当没有勾选时，可以查询用户和角色的授权信息。用户/角色必须选择一个才能查询。

# 操作说明

*  通过菜单系统管理－>系统管理－>权限管理－>字段权限查询进入该界面；
*  操作步骤
 
   *  第1步：选择查询条件。
   *  第2步：点击查询按钮。
