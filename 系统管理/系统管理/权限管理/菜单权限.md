
# 功能描述

控制系统各功能节点的菜单访问权限，是整个系统的第一级权限控制，具有访问权限的菜单，可以显示并访问，不具有权限的菜单不显示。

菜单权限以允许优先为原则，即当一个用户具有多个角色时，对其中一个角色授予了某菜单的访问权限，该用户即拥有此菜单的访问权限！

单独授权界面点击批量授权，进入批量授权界面，批量授权界面可以批量选择角色，批量选择菜单，一次性完成对多个角色的诸多菜单授权。

# 业务规则

*  拥有系统管理功能权限。

# 栏目说明

菜单权限-头

|栏目|说明|
|---|---|
|角色|参照系统的角色|
|模块|参照系统的模块|


菜单权限-行

|栏目|说明|
|---|---|
|菜单|显示模块的菜单名称|
|访问|设置菜单的访问权限：拒绝、允许|

# 按钮说明

*  批量授权：点击菜单权限－>批量授权，进入批量授权功能界面。批量授权界面可以批量选择角色，批量选择菜单，一次性完成对多个角色的诸多菜单授权。
*  权限查询：点击菜单权限－>权限查询，进入权限查询功能界面。

# 操作说明

*  通过菜单系统管理－>系统管理－>权限管理－>菜单权限进入该界面；
*  操作步骤
 
   *  第1步：选择角色。
   *  第2步：选择模块。
   *  第3步：修改菜单访问权限。
   *  第4步：点击保存按钮。
