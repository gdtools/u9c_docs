
# 功能描述

控制系统各业务表单访问权限，即每一个界面是否可见。

表单权限中包括表单的访问权限、表单个性化的权限的设置、表单的个性化模板分配的权限设置。表单的访问权限为默认允许，个性化的权限的设置为默认允许，个性化模板分配为默认拒绝。

这里需要注意：某个表单授权为拒绝后，则通过各种形式都将不能再访问该表单，例如，菜单，链接，导航按钮等。

表单权限以拒绝优先为原则，即当一个用户具有多个角色时，对其中一个角色授予了某表单的拒绝权限，该用户即不能再执行该服务！

# 业务规则

*  拥有系统管理功能权限。

# 栏目说明

表单权限-头

|栏目|说明|
|---|---|
|角色|参照系统的角色|
|模块|参照系统的模块|


表单权限-行

|栏目|说明|
|---|---|
|表单|显示模块的表单名称|
|访问|设置表单的访问权限：拒绝、允许|
|个性化|设置表单的个性化权限：拒绝、允许|
|个性化模板|设置表单的个性化权限：拒绝、允许|

# 按钮说明

*  批量授权：点击菜单权限－>批量授权，进入批量授权功能界面。批量授权界面可以批量选择角色，批量选择表单，一次性完成对多个角色的诸多表单授权。
*  权限查询：点击表单权限－>权限查询，进入权限查询功能界面。

# 操作说明

*  通过菜单系统管理－>系统管理－>权限管理－>表单权限进入该界面；
*  操作步骤
 
   *  第1步：选择角色。
   *  第2步：选择模块。
   *  第3步：修改表单访问权限。
   *  第4步：点击保存按钮。
