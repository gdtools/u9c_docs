
# 功能描述

查询出选定用户和表单的所有角色；

查询出选定角色和表单的所有用户；

# 业务规则

*  必须先进行角色分配；
*  必须先进行授权；

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|查询信息||
|用户|需要查询的用户。|
|表单|需要查询的表单项。|
|角色|需要查询的角色。|
|模块|需要查询的菜单项所属的模块，即应用信息。|
|查询角色授权明细|是否需要查询角色授权的明细信息。|
|查询结果||
|用户编码|用户信息的编码；|
|用户名称|用户信息的名称；|
|角色编码|角色编码|
|角色名称|角色名称|
|表单名称|表单的名称|
|访问|是否可以访问表单的权限。|
|个性化|当前表单的个性化权限的设置。|
|个性化模板分配|是否允许当前表单的个性化模板的分配权限。|

# 按钮说明

*  查询：点此按钮，把表单权限查询结果显示在查询结果列表中；当勾选[查询角色授权明细]之后，用户条件不可选择，查询的结果为当前角色的授权的明细信息。当没有勾选时，可以查询用户和角色的授权信息。

# 操作说明

*  通过菜单系统管理－>系统管理－>权限管理－>表单权限查询进入该界面；
*  操作步骤
 
   *  第1步：选择查询条件。
   *  第2步：点击查询按钮。
