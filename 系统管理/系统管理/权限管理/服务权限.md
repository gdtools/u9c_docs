
# 功能描述

服务可能出现的调用场景：

（1）界面中功能按钮调用

（2）内部程序调用

（3）有可能为其他业务系统对外提供服务，由第三方调用。

服务权限以拒绝优先为原则，即当一个用户具有多个角色时，对其中一个角色授予了某服务的拒绝权限，该用户即不能再执行该服务！

这里举一个具体的例子：对服务--编译汇率表设定拒绝执行权限，这时在汇率页面中，当点击编译按扭时会调用到编译汇率表这个服务，这时系统会提示：当前用户没有权限执行操作:编译汇率表，该操作也就不能执行成功！

# 业务规则

*  拥有系统管理功能权限。

# 栏目说明

服务权限-头

|栏目|说明|
|---|---|
|角色|参照系统的角色|
|模块|参照系统的模块|


服务权限-行

|栏目|说明|
|---|---|
|服务|显示模块的服务名称|
|访问|设置菜单的访问权限：拒绝、允许|

# 按钮说明

*  批量授权：点击服务权限－>批量授权，进入批量授权功能界面。批量授权界面可以批量选择角色，批量选择服务，一次性完成对多个角色的诸多服务授权。
*  权限查询：点击服务权限－>权限查询，进入权限查询功能界面。

# 操作说明

*  通过菜单系统管理－>系统管理－>权限管理－>服务权限进入该界面；
*  操作步骤
 
   *  第1步：选择角色。
   *  第2步：选择模块。
   *  第3步：设置服务访问权限。
   *  第4步：点击保存按钮。
