
# 功能描述

动态视图是为了配合数据权限一并使用的选定模块，选定实体后，点击表达式控件，设定该实体条件！

# 业务规则

*  拥有系统管理功能权限。

# 栏目说明

动态视图

|栏目|说明|
|---|---|
|编码|动态视图的编码|
|名称|动态视图的名称|
|应用|选择动态视图的应用|
|实体|选择动态视图的实体|
|动态视图类型|动态视图的动态视图类型|
|条件|动态视图的条件|
|作用范围|动态视图的作用范围|
|描述|动态视图的描述|


关联性控制

|栏目|说明|
|---|---|
|关联实体|显示关联实体的实体名称|
|类名|显示关联实体的类名称|
|条件|显示关联实体的条件|

# 按钮说明

*  高级修改：点击权限动态视图－>高级修改，进入高级修改功能界面。

# 操作说明

*  通过菜单系统管理－>系统管理－>权限管理－>权限动态视图进入该界面；
*  操作步骤
 
   *  第1步：维护编码、名称。
   *  第2步：选择应用、实体。
   *  第3步：设置动态视图条件。
   *  第4步：点击保存按钮。
