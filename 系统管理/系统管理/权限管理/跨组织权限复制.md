
# 功能描述

提供私有角色权限 和 非私有角色权限跨组织复制功能。

# 业务规则

*  相关菜单权限

# 栏目说明

基本栏目

|栏目|说明|
|---|---|
|私有角色权限|
|来源组织|选择角色的来源组织|
|来源组织角色|选择来源组织角色|
|目标组织|选择目标组织|
|目标组织角色|选择目标组织角色|
|非私有角色权限|
|来源组织|选择角色的来源组织|
|来源组织角色|选择来源组织角色|
|目标组织|选择目标组织|

# 按钮说明

*  复制私有角色权限：点击复制私有角色权限功能，将所选私有角色的权限 复制到目的组织所选私有角色上。

# 操作说明

*  通过菜单系统管理－>系统管理－>权限管理－>跨组织权限复制进入该界面；
*  操作步骤
 
   *  第1步：选择选择来源组织和目的组织。
   *  第2步：选择选择来源组织角色和目的组织角色。
   *  第3步：点击保存按钮。
